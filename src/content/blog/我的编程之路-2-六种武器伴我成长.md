**1、技术杂志**

在《程序员》创刊的时候，正上高二的我就拿到了第一本。“看”完第一期——基本我都看不懂，但是，杂志还是让我增长了知识，它让我知道除了 C、VB 以外还有 JAVA、C#。这也使我喜欢上了 JAVA 和 .NET 的。可惜的是，当时杂志在玉溪的销量并不好，我买到第一期之后就没有买到第二期了。

总的说来，技术杂志就想一个风向标，它可以指引你开拓眼界，走向世界。

**2、技术社区**

上了大学以后，终于可以上网了。除了继续看技术杂志、学习新技术以外，开始进入了我的第一个技术社区——CSDN。在技术社区，虽然我不能回答别人的问题，也没有很多时间去等待别人回答我的问题，但是，我看了不少别人已经解决的问题，使我不用去亲自编程就学到了很多经验。

**3、搜索引擎**

大二的时候，我进入了学校的研究室，并接手了我的第一个项目开发。这时候问题出现了——我有不少的理论经验，但实际编程经验取不多，在开发期间经常出现了令人费解的异常，急需解决而又无法忍受技术社区缓慢的解答速度。此时，我想起了搜索引擎。我把异常信息往里一放…… Bingo！ 就这样，我用搜索引擎解决了不少的问题。

**4、即时聊天工具**

搜索引擎并不是万能的，有时候有些问题它也无法解决，这种时候多想有一位高手当面知道啊。就在我逛社区想办法的时候，我看到 CSDN 上有很多人在收集开发高手的 QQ 号！我便翻出 QQ，把帖子里留了号的程序员都加了进去。很多技术问题就这样迎刃而解。

**5、BLOG**

我认识 BLOG 也是通过《程序员》，程序员是一个需要大量知识积累的工作，俗话说好记性不如烂笔头，做为一个程序员，当然不能用书本或是 WORD 来记录零碎的东西了。一个真正的程序员都应该有一个 BLOG。

**6、参考文档**

每个程序员对 HTML 这类简单的语言都应该很熟悉，可是，只有很少的人对它很精通。每次我看别人的 HTML 代码的时候，总是让我看到了一些我不熟悉的 HTML 标记，于是，我就准备了一些经常用到的手册——HTML Tag 参考、JavaScript 参考等。有了这些手册，我就不必去熟悉 HTML 等这些东西了。
