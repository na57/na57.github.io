10.1 转折

所有点互相远离且远离得一样多——但数据其实躺在低维流形上

📉 距离集中
维度升高，任意两点距离挤进很窄的范围；最近邻与最远邻几乎一样远，kNN、密度估计、Ch9 全部聚类的地基随之松动。
🗺️ 流形假设（Manifold）
人脸照片几十万像素，却只由姿态、光照、表情等少数自由度量出——数据躺在高维空间中的低维流形附近。
关键一跃：「局部」是低维借给我们的直觉，高维里它是奢侈品；而内在维度低、观察维度高，正是降维能扔掉冗余维度而不丢本质的原因。
10.2 定义

MDS ＝ 只有距离表，也能反推出保距离的低维坐标

📥 输入
m×m 距离矩阵 D（dij 为样本 i、j 的距离），不需要原始坐标
📤 输出
m 个低维坐标 z1,…,zm ∈ ℝd′，使两两欧氏距离尽量等于 dij
$$\text{双中心化：}\quad B=-\tfrac{1}{2}HD^{(2)}H,\qquad H=I-\tfrac{1}{m}\mathbf{1}\mathbf{1}^{\top},\quad D^{(2)}\text{ 为逐元素平方}$$
读法：把「距离」翻译成「内积」得到 B，再对 B 特征分解取前 d′ 个——坐标 = √λ × 特征向量分量
10.2 手算

边长为 1 的等边三角形：从距离表反推出整张地图

① 平方 + 均值：D 的元素非 0 即 1，平方不变；每行和为 2，总和为 6

$$d^2_{i\cdot}=d^2_{\cdot j}=\tfrac{2}{3},\qquad d^2_{\cdot\cdot}=\tfrac{6}{9}=\tfrac{2}{3}$$

② 双中心化得内积矩阵 B

$$b_{ij}=-\tfrac12\big(d^2_{ij}-d^2_{i\cdot}-d^2_{\cdot j}+d^2_{\cdot\cdot}\big)\;\Rightarrow\; b_{ii}=\tfrac13,\quad b_{ij}=-\tfrac16\ (i\ne j)$$

③ 特征分解：$B=\tfrac12 I-\tfrac16\mathbf{1}\mathbf{1}^{\top}$，与 𝟏 正交的向量都是特征向量

$$\lambda_1=\lambda_2=\tfrac12,\quad \lambda_3=0\ \Rightarrow\ \text{两个非零特征值：结构本质是二维}$$
$$z_A=(\tfrac12,\tfrac{\sqrt3}{6}),\quad z_B=(-\tfrac12,\tfrac{\sqrt3}{6}),\quad z_C=(0,-\tfrac{\sqrt3}{3});\quad \text{验证：三条边距离全为 } 1\ \checkmark$$

按空格 / → 逐步展开推导（解与真实坐标差一个旋转/平移——距离表不含方向与原点信息）

10.3 定义

PCA ＝ 方差最大的方向，就是协方差矩阵的特征向量

🎯 最近重构性
样本到投影超平面的距离之和最小——投影后还能尽量还原
📊 最大可分性
投影后方差最大——点在低维里尽量散开；两视角同一解
$$C=\tfrac{1}{m}\textstyle\sum_{i=1}^{m}x_i x_i^{\top}\ (\text{已中心化});\qquad \max_{w}\, w^{\top}Cw,\ \ \text{s.t. } w^{\top}w=1 \;\Longrightarrow\; Cw=\lambda w$$
读法：主成分 = 协方差矩阵按特征值降序的单位特征向量；第 k 个方向上的投影方差恰好是 λk
10.3 演练

手算 PCA：四个二维点降到一维，第一主成分拿走 80% 方差

① 中心化：$\bar{x}=(2.5,\,2.5)$，四点变为 $(-1.5,-0.5),\,(-0.5,-1.5),\,(0.5,1.5),\,(1.5,0.5)$

② 协方差矩阵（按 1/m，m = 4）

$$C=\begin{pmatrix} 5/4 & 3/4\\[2pt] 3/4 & 5/4 \end{pmatrix}$$
✍️
暂停推导

请接着往下推：写出特征方程，解出两个特征值，求出第一主成分的单位方向，并算出方差占比

③ 特征方程

$$\det(C-\lambda I)=\big(\tfrac54-\lambda\big)^2-\big(\tfrac34\big)^2=0 \;\Rightarrow\; \tfrac54-\lambda=\pm\tfrac34 \;\Rightarrow\; \lambda_1=2,\ \lambda_2=\tfrac12$$
$$w_1=\big(\tfrac{1}{\sqrt2},\tfrac{1}{\sqrt2}\big)\ (\text{方向 ↗});\qquad \text{方差占比 } \frac{\lambda_1}{\lambda_1+\lambda_2}=\frac{2}{2.5}=80\%,\quad z_i=\pm\sqrt2$$

按空格 / → 逐步展开推导

10.3 判读

特征值就是「方向的价格」：占比选维数，方差不等于可分

1读特征值：第 k 个主成分上的投影方差 = λk；例中 2 vs ½，第一方向独占八成
2选维数：按 λ 降序累加方差占比，够到阈值（如 90% / 95%）即停
3两条纪律：必须先中心化；方差最大 ≠ 对分类最有利（那是 LDA，见 Ch3）
$$\text{累计方差占比：}\quad \frac{\lambda_1+\cdots+\lambda_{d'}}{\lambda_1+\cdots+\lambda_d}\ \ge\ \text{阈值}$$
❌ 忘中心化 → 算的是绕原点的二阶矩，第一主成分被均值方向绑架　｜　❌ 拿 PCA 当分类器特征 → 它无监督、不看标签
深挖

欧氏距离下，MDS 与 PCA 是同一枚硬币的两面

$$\underbrace{ZZ^{\top}}_{\text{MDS 的 } B}\ \ \text{与}\ \ \underbrace{Z^{\top}Z}_{\text{PCA 的 } mC}\ \ \text{共享同一组非零特征值}$$
🧭 MDS
输入：距离表 D；保内积（距离）；解在旋转、镜像、平移下不唯一
📊 PCA
输入：原始坐标 X；保方差；取前 d′ 个特征向量即投影矩阵 W，zi = Wᵀxi
💡 距离表来自欧氏空间时，两者给出同一组坐标（至多差旋转）；保留全部主成分时完全等价，截断时准则不同
10.4 核化

KPCA：一切只需内积，内积皆可核化

非线性映射 φ 把弯曲结构「捋直」到高维特征空间，再做普通 PCA——全程不碰 φ，只碰核矩阵：

$$\text{① } K_{ij}=\kappa(x_i,x_j)\quad\Rightarrow\quad \text{② } \tilde{K}=HKH\ (\text{隐式中心化})\quad\Rightarrow\quad \text{③ 特征分解 } \tilde{K}\ \text{取前 } d' \text{ 个}$$
🔗 与 SVM 同源
PCA 的全部计算只涉及内积 φ(xi)ᵀφ(xj)，核函数 κ 恰好等于这个内积
🪞 换个角度看
KPCA ＝ 在核内积上做 MDS / PCA——线性工具箱整体核化
10.4 流形

Isomap ＝ 近邻图 ＋ MDS：把直线距离换成沿纸面的距离

沿纸面走，不穿过卷层"] C --> D["③ 把测地距离表喂给 MDS
摊成二维平面"]
等度量映射（Isometric Mapping）保的是全局测地距离：整张纸摊开不变形，像画世界地图要保距
10.4 流形

LLE：保住每块「小补丁」的形状，整张纸就保住了

$$\text{① 学权重：}\min_{w_{ij}}\Big\|x_i-\textstyle\sum_j w_{ij}x_j\Big\|^2 \qquad \text{② 找坐标：}\min_{y_i}\textstyle\sum_i\Big\|y_i-\sum_j w_{ij}y_j\Big\|^2\ (\text{同一组 } w_{ij})$$
🧩 两点小例
$x=(1,1)$ 的近邻是 $(2,0)$ 与 $(0,2)$，恰好 $x=\tfrac12(2,0)+\tfrac12(0,2)$，权重 = (½, ½)
🔒 约束
低维中 $y$ 的像也必须位于两个邻居像的 ½＋½ 组合处（即中点）——权重是局部几何的指纹
局部线性嵌入（Locally Linear Embedding）保的是局部重构关系：每块地砖形状不变，再拼起来
10.4 对比

Isomap 保全局距离、LLE 保局部形状，但都怕「稀疏 + 噪声」

Isomap（等度量映射）LLE（局部线性嵌入）
保住什么全局测地距离（整张纸摊开不变形）局部重构权重（每块补丁形状不变）
机制近邻图最短路 → MDS学权重 → 低维中同一组权重成立
直觉世界地图要保距马赛克地砖逐块保形再拼回
⚠️ 共同硬前提：采样足够稠密（近邻才真的近）＋ 噪声小（一个噪声点可能在纸的两层间搭「短路」边）。样本不够时，老老实实用 PCA
10.5 定义

度量学习：不降维，直接学一把「马氏距离」的尺子

$$d^2(x,z)=(x-z)^{\top}M(x-z),\quad M\succeq 0\ (\text{半正定});\qquad M=WW^{\top}\ \Rightarrow\ d^2(x,z)=\|Wx-Wz\|^2$$
📐 半正定的意义
保证平方距离非负、三角不等式成立；且保证 M 能分解成 WWᵀ，变回欧氏距离
🎚️ M 的读法
对角元大 = 该维度被拉长（差异放大）；小 = 被压扁（差异忽略）。学 M 即学线性变换 W
读法：马氏距离 ＝ 先做一次线性变换 W，再算普通欧氏距离——度量学习骨子里仍是学线性变换，只是拿它当尺子
10.5 例子

把类间方向拉长 4 倍，最近邻判决立刻翻转

类 ＋：(0, 0)、(0, 4)；类 −：(1, 1)、(1, 3)；测试点 t = (0, 2)，真实类别 ＋

t 到各点＋ (0, 0)＋ (0, 4)− (1, 1)− (1, 3)
欧氏距离22√2 ≈ 1.414（最近！）√2 ≈ 1.414
马氏距离 M = diag(16, 1)22√17 ≈ 4.123√17 ≈ 4.123
💡 欧氏尺子下 1NN 误判为 −；学出 M 后 x 方向（类间）拉长 4 倍、y 方向（类内）相对压扁，判决翻转为 ＋。等价视角：W = diag(4, 1)，点 (1, 1) 被映成 (4, 1)
避坑

本章最容易错的三件事

❌ 「特征才几十个，谈不上维数灾难」
✅ d = 10 时 10% 邻域边长已达 0.794；是否受灾看「样本量 ÷ 维度」的比值，不看维度绝对值
❌ 「MDS 算出的坐标和原坐标对不上，肯定算错了」
✅ 距离表对旋转、镜像、平移天然不敏感，解在刚体运动下不唯一；比较两次 MDS 结果要先对齐再比
❌ 「M 只要对称就能当距离」
✅ 必须半正定：否则 d² 会出现负值，距离三公理全垮；半正定还保证 M = WWᵀ 能变回欧氏距离
