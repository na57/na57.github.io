主线

一条追问链：从经验误差追问到三代容量尺子

1经验误差小不等于泛化好 → 需要给泛化误差一个概率上界
2有限假设空间 + 可分：PAC 框架把样本复杂度数出来（m ≥ 140）
3目标不在空间里（不可分）：Hoeffding 不等式接手（m ≥ 734）
4无限空间：数个数失效 → VC 维度量有效容量（全章枢纽，界 ≈ 0.269）
5VC 维只看最坏情形 → Rademacher 复杂度随数据自适应；代价：界太松
这条链就是本章目录：12.1 对应第 1–2 环，12.2 对应第 3 环，12.3 对应第 4 环，12.4 对应第 5 环。
动机

经验误差可以是零，泛化误差却可以一塌糊涂

把训练集「背下来」的模型：经验误差 Ê(h) = 0，在新数据上却可能错误率极高——背下的内容里包含噪声。

😇 老办法一：信训练误差
模型够强就能把它刷到 0，证据会造假。
🙂 老办法二：留测试集
用一次就污染一次；很多场景没有多余数据。
💡 本章方案：不做绝对承诺，给泛化误差一个概率化的上界，并算清「需要多少样本」。
定义

先把两个误差分开：一个看得见，一个看不见

📏 经验误差（Empirical Error）
训练集上的错误率，看得见、算得出。
🌫️ 泛化误差（Generalization Error）
真实分布上的错误率，看不见、是随机变量。
$$\hat{E}(h)=\frac{1}{m}\sum_{i=1}^{m}\mathbb{1}\bigl(h(x_i)\neq y_i\bigr) \qquad E(h)=P_{(x,y)\sim\mathcal{D}}\bigl(h(x)\neq y\bigr)$$
读法：Ê 是这 m 个点上的成绩，E 是将来所有数据上的成绩；h 由随机抽到的训练集学出，所以两者的差距只能谈概率。
定义

PAC：用 ε 管精度、δ 管运气，把「学成了」写成概率命题

🎯 ε：精度参数
负责「近似正确」（Approximately Correct）：误差不超过 ε。
🎲 δ：置信参数
负责「大概」（Probably）：以 ≥ 1−δ 的概率成立，允许抽坏训练集。
$$\boldsymbol{P\bigl(E(h)\leq\varepsilon\bigr)\geq 1-\delta} \qquad \text{（对任意 }0\lt\varepsilon,\delta\lt 1\text{，}m\text{ 足够大）}$$
读法：近似正确、大概靠谱。若目标概念（Target Concept）c 恰在假设空间（Hypothesis Space）ℋ 中，称可分（Separable）情形。
推导

有限空间可分情形：样本复杂度可以一步步数出来

① 固定一个坏假设 h（E(h) > ε）：单样本上蒙对的概率

$$P\bigl(h(x)=c(x)\bigr)=1-E(h)\lt 1-\varepsilon$$

② m 个独立同分布样本上全部蒙对（概率相乘）

$$P\bigl(h\text{ 在 }m\text{ 个样本上全对}\bigr)\lt (1-\varepsilon)^m$$

③ 联合界 + 放缩 1−x ≤ e−x：存在坏假设蒙混过关的概率

$$P(\exists\,\text{坏假设过关})\leq|\mathcal{H}|(1-\varepsilon)^m\leq|\mathcal{H}|\,e^{-m\varepsilon}$$
$$\text{令 }|\mathcal{H}|e^{-m\varepsilon}\leq\delta\text{，取 ln 解出：}\quad \boldsymbol{m\geq\frac{1}{\varepsilon}\Bigl(\ln|\mathcal{H}|+\ln\frac{1}{\delta}\Bigr)}$$

按空格 / → 逐步展开推导

演练

手算布尔合取：m 大于等于 140 就够了

布尔合取（Boolean Conjunction）：n = 10，$|\mathcal{H}|=3^{10}=59049$；要求 $\varepsilon=0.1$、$\delta=0.05$。

✍️
暂停推导

请你自己代入上一页的公式，算出一个具体的 m——交付物是一个整数。

① $\dfrac{1}{\varepsilon}=\dfrac{1}{0.1}=10$

② $\ln|\mathcal{H}|=\ln 3^{10}=10\ln 3\approx 10.986$；　③ $\ln\dfrac{1}{\delta}=\ln 20\approx 2.996$

④ $m\geq 10\times(10.986+2.996)=139.82$，向上取整：$\boldsymbol{m\geq 140}$——95% 概率保证真实误差 ≤ 10%

按空格 / → 逐步揭示答案

直觉

公式的本质：用样本把坏假设逐个「枪毙」

🔫 每个样本以 ≥ ε 的概率杀死一个坏假设；m 个样本后漏网概率随 $e^{-m\varepsilon}$ 指数衰减。
📦 $\ln|\mathcal{H}|$ = 假设空间的描述长度：用多少比特能给一个假设编号。空间越大，要枪毙的坏假设越多，所需样本越多。
✂️ 奥卡姆剃刀的第一个严格版本：在能拟合数据的前提下，选更小的假设空间——它直接进入样本复杂度公式。
12.2

没有完美假设可对照时，只能靠大数定律收敛

不可分情形（Agnostic）：连 Ê(h)=0 的 h 都不存在，算法只能挑经验误差最小的（ERM，经验风险最小化）。

$$\text{Hoeffding：}\quad P\bigl(|E(h)-\hat{E}(h)|\geq\varepsilon\bigr)\leq 2e^{-2m\varepsilon^2}$$
$$\text{联合界并令其}\leq\delta\text{：}\quad \boldsymbol{m\geq\frac{1}{2\varepsilon^2}\Bigl(\ln(2|\mathcal{H}|)+\ln\frac{1}{\delta}\Bigr)}$$
盯住变化：对 ε 的依赖从 $1/\varepsilon$ 恶化为 $1/\varepsilon^2$——下一页算给你看代价有多大。
演练

同一问题从 140 涨到 734：不可分的代价是 ε 变平方

可分：$m\geq\dfrac{1}{\varepsilon}(\ln|\mathcal{H}|+\ln\dfrac{1}{\delta})$
→ m ≥ 140
不可分：$m\geq\dfrac{1}{2\varepsilon^2}(\ln 2|\mathcal{H}|+\ln\dfrac{1}{\delta})$
→ m ≥ 734（约 5 倍）
  1. $\dfrac{1}{2\varepsilon^2}=\dfrac{1}{0.02}=50$
  2. $\ln(2|\mathcal{H}|)=\ln 2+\ln 59049\approx 11.68$
  3. $\ln\frac{1}{\delta}=\ln 20\approx 3.00$
  4. $m\geq 50\times(11.68+3.00)=734$
可分：坏假设每个样本以 ≥ ε 概率「自爆」（乘法淘汰）；不可分：只能靠大数定律按 $1/\sqrt{m}$ 收敛。
12.3

空间无限时，把「数个数」换成「数标记方案」

ℋ = { 实轴上所有区间 [a,b] } 时 |ℋ| = ∞，联合界失效——但区间族明明很简单，是尺子太粗糙。

📈 增长函数（Growth Function）
Πℋ(m)：ℋ 在 m 个样本上能产生的不同 ±1 标记方案数。
💥 打散（Shatter）
某 m 点集合上全部 2m 种标记都能被 ℋ 实现。
$$\Pi_{\mathcal{H}}(m)\leq 2^m \qquad \text{若某 }m\text{ 点集上 }\Pi_{\mathcal{H}}(m)=2^m\text{，称 }\mathcal{H}\text{ 打散该集合}$$
定义

VC 维：存在 d 个点任你标，任意 d+1 个点有一种标法做不到

$$\boldsymbol{d_{VC}(\mathcal{H})=\max\{\,m:\ \exists\ m\text{ 点集合被 }\mathcal{H}\text{ 打散}\,\}}$$
证 $d_{VC}\geq d$：只需存在一组 d 个点能被打散——可以挑好位置。
证 $d_{VC}\leq d$：必须对任意 d+1 个点给出一种实现不了的标记——一个都不能漏。
VC 维（Vapnik-Chervonenkis Dimension）度量「有效容量」，无限空间因此有了有限的尺子。
判定

实轴区间族 VC 维等于 2：连续一段罩不住「正负正」

2 个点 x₁ < x₂ 的标记怎么放区间
(+, +)区间罩住两点
(−, −)区间挪到两点之外
(+, −) / (−, +)区间只罩住需要标 + 的那一个
3 个点 x₁ < x₂ < x₃：标记 (+, −, +) 要求含首尾却排除中间——区间是连续一段，含 x₁ 与 x₃ 必含 x₂，永远做不到。

能打散 2 个点 + 任意 3 个点打不散 ⟹ dVC = 2

判定

平面上一条直线能打散 3 个点，打不散 4 个

✅ 任意不共线 3 点：8 种标记都能分开（同色放远；两正一负把负点单独隔开）⟹ $d_{VC}\geq 3$
❌ 任意 4 点：凸四边形的「对角为正」或「一点在内部标负」都分不开 ⟹ $d_{VC}=3$
$$\mathbb{R}^d\text{ 中的超平面（线性分类器）：}\quad \boldsymbol{d_{VC}=d+1}$$
恰好等于「参数个数 +1」只是常见巧合，不是定理——记住 sin(ωx) 这个反例马上登场。
演练

一万样本只保证差距 27 个点：界很松，但趋势是对的

$$E(h)\leq\hat{E}(h)+\sqrt{\frac{8d\ln\frac{2em}{d}+8\ln\frac{4}{\delta}}{m}}\qquad(d=10,\ m=10^4,\ \delta=0.05)$$

① $8d=80$；　② $\ln\frac{2em}{d}=\ln(2000e)\approx 8.601$，$80\times 8.601=688.1$

③ 置信项 $8\ln\frac{4}{\delta}=8\ln 80\approx 35.1$，分子 $688.1+35.1=723.2$

④ $\sqrt{723.2/10000}=\sqrt{0.07232}\approx \boldsymbol{0.269}$（$m=10^5$ 时缩到 0.095，按 $1/\sqrt{m}$ 收缩）

三项结构：经验项 Ê(h) ＋ 容量项（含 d）＋ 置信项（含 ln(4/δ)）——结构风险最小化（SRM）的思想源头。
避坑

本章三颗雷：零经验误差、δ 的含义、VC 维等于参数个数

❌ 「经验误差为 0 就等于泛化误差为 0」
✅ Ê(h)=0 只说明在这 m 个点上蒙对了；PAC 界给出的正是「蒙对」与「真对」之间的概率关系。
❌ 「δ 是模型的错误率」
✅ ε 才管错误率；δ 是「拿到坏训练集」的倒霉概率，随机性来自抽样。
❌ 「VC 维 = 参数个数」
✅ 反例：h(x)=sign(sin(ωx)) 只有 1 个参数，ω 足够大就能拟合任意标记，VC 维 = ∞。
12.4

Rademacher 复杂度：看空间能把纯随机标签蒙对多少

给每个样本独立随机打 ±1 噪声标签 σi（各 1/2 概率），问 ℋ 里最好的 h 能对齐多少。

$$\hat{R}(\mathcal{H})=\mathbb{E}_{\sigma}\Bigl[\sup_{h\in\mathcal{H}}\frac{1}{m}\sum_{i=1}^{m}\sigma_i h(x_i)\Bigr]$$
读法：拟合纯随机噪声的期望最好成绩。连掷硬币的标签都能背下来的空间，什么也学不到——它在泛化界里是罚金项，越小越好。
对比 VC 维：回答「在这份数据上平均能蒙对多少噪声」，数据依赖、可从样本估计，比最坏情形更细。
12.4

换尺子不换结构：经验项 + 容量项 + 置信项

$$\boldsymbol{E(h)\leq\hat{E}(h)+2\hat{R}(\mathcal{H})+3\sqrt{\frac{\ln(2/\delta)}{2m}}}$$
🧩 稳定性（Stability）：换走一个样本，学出的模型几乎不变 ⟹ 经验表现 ≈ 真实表现。正则化正是让算法对单样本不敏感——这就是「正则化为什么有效」的理论解释。
收尾

尺子越来越细，但「大网络为什么能泛化」仍是开放问题

遗留问题：大网络参数远超样本数仍泛化良好，经典 worst-case 界全部失效——深度学习理论远未完成。理论的价值此刻是定性方向：控容量、要稳定、置信与精度不可兼得。

小结

三句话讲完第 12 章

1解决什么：经验误差小 ≠ 泛化好；给 E(h) 一个概率上界，并回答「需要多少样本」。
2核心机制：用容量换置信——|ℋ|（联合界+Hoeffding）→ VC 维 → Rademacher；统一三项结构，m 压住后两项。
3承上启下：前十一章教怎么学，本章教可信吗；Ch13 在「样本不够」的困境下给出路。
