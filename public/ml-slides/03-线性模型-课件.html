主线

本章主线：一条直线先回归、再分类，撞墙了就加约束

1要预测连续值：给特征打分、加权求和 → 最小二乘闭式解一步算出

4类别不止两个 → 多分类：OvR 与 OvO 拆解投票；类别悬殊要换尺子
5遗留：数据线性不可分怎么办 → 通向后续章节
这条链就是本章的目录：回归（3.1）→ 正则化（3.2）→ 对率回归（3.3）→ LDA（3.4）→ 多分类与不平衡（3.5）。
动机

最朴素的预测直觉：面积重要就乘大数，楼层次要就乘小数

预测房价：面积、楼层、朝向、房龄……每个特征重要性不同，权重组合却有无穷多种。

$$\text{预测价} = w_1 \times \text{面积} + w_2 \times \text{楼层} + w_3 \times \text{朝向} + \cdots + b$$
😇 拍脑袋定权重
全凭经验，换一批房子就失灵，说不清为什么是这个数
🙂 穷举所有权重
权重是连续实数，组合有无穷多种，永远试不完
💡 本章方案：让数据自己说话——用「最小二乘」把最优权重一步算出来。
定义

线性模型就两件事：给每个特征打分，再把分数加起来

🗺️ 权重向量 $\boldsymbol{w}$
每个特征的重要性打分，可正可负，绝对值越大影响越大，由数据学出
📋 偏置 $b$
所有特征都取零时的基准预测，决定直线（超平面）的整体位置
$$f(\boldsymbol{x}) = \boldsymbol{w}^{\top}\boldsymbol{x} + b = \sum_{j=1}^{d} w_j x_j + b$$
读法：线性模型（Linear Model）的预测值 = 特征的加权求和。一个特征是直线，两个特征是平面，更多特征是超平面。
方法

最小二乘：让平方误差之和最小，权重就有唯一的闭式解

最小二乘法（Least Square Method）：选一把尺子——所有样本预测值与真实值之差的平方和最小。

$$(w^{*}, b^{*}) = \arg\min_{(w,\,b)} \; \sum_{i=1}^{m} \left( y_i - w x_i - b \right)^2$$
$$w = \frac{\sum_{i} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i} (x_i - \bar{x})^2}, \qquad b = \bar{y} - w\,\bar{x}$$
读法：$w$ 的分子是 $x$ 与 $y$ 的协同波动，分母是 $x$ 自身的波动——同涨同落越整齐，斜率越大；$b$ 保证直线穿过数据中心点 $(\bar{x}, \bar{y})$。
推导

四个点手算最小二乘：$w$ 等于 1.94，$b$ 等于 0.15

样本1234
$x$1234
$y$2.13.96.27.8

① 算均值：$\bar{x} = \frac{1+2+3+4}{4} = 2.5$，　$\bar{y} = \frac{2.1+3.9+6.2+7.8}{4} = 5$

② 偏差求和：$\sum_i (x_i-\bar{x})(y_i-\bar{y}) = 4.35+0.55+0.60+4.20 = 9.7$；$\sum_i (x_i-\bar{x})^2 = 2.25\times2 + 0.25\times2 = 5$

③ 算 $w$ 与 $b$：$w = \frac{9.7}{5} = \boldsymbol{1.94}$；　$b = 5 - 1.94\times 2.5 = \boldsymbol{0.15}$

④ 验证：$f(x)=1.94x+0.15$，代回四点得 2.09、4.03、5.97、7.91，残差 $-0.01, +0.13, -0.23, +0.11$，和约等于 0 ✅

推广

多元情形不用重学：一个矩阵公式打包所有特征

$$\hat{\boldsymbol{w}} = (\boldsymbol{X}^{\top}\boldsymbol{X})^{-1} \boldsymbol{X}^{\top} \boldsymbol{y}$$
  • $\boldsymbol{X}^{\top}\boldsymbol{X}$：特征两两之间的协同波动表；$\boldsymbol{X}^{\top}\boldsymbol{y}$：每个特征与标记的协同波动
  • 左乘逆矩阵 = 把特征间互相纠缠的贡献拆解开，剩下每个特征干净的贡献
  • 几何直觉：$\hat{\boldsymbol{y}} = \boldsymbol{X}\hat{\boldsymbol{w}}$ 是 $\boldsymbol{y}$ 在特征张成平面上的投影——最小二乘 ⟺ 欧氏距离最小
⚠️ 特征共线或特征数多于样本数时，$\boldsymbol{X}^{\top}\boldsymbol{X}$ 不可逆，闭式解失效——这正是下一节正则化的登场理由。
正则化

系数太放肆会闯祸：正则化给系数戴上嚼子

两个隐患一个药方：过拟合（系数极大、穿过每个训练点）与 矩阵不可逆，都靠「别让系数太大」来治——这就是正则化（Regularization）。

$$\min_{\boldsymbol{w}} \; \|\boldsymbol{X}\boldsymbol{w} - \boldsymbol{y}\|^2 + \lambda \|\boldsymbol{w}\|^2$$
$$\text{岭回归（Ridge Regression）：} \quad \hat{\boldsymbol{w}} = (\boldsymbol{X}^{\top}\boldsymbol{X} + \lambda \boldsymbol{I})^{-1} \boldsymbol{X}^{\top} \boldsymbol{y}$$
$\lambda\boldsymbol{I}$ 给主对角线垫高一截（那道「山脊」），保证可逆；$\lambda = 0$ 退化回普通最小二乘，$\lambda$ 越大系数压得越狠。
演练

一算就懂：$\lambda$ 取 14 时，$w$ 从 1 被压到 0.5

3 个样本：$x: 1, 2, 3$；$y: 1, 2, 3$（直线过原点，无截距）。

✍️
暂停推导

先自己算无正则的 $w$，再算 $\lambda = 14$ 时的 $w$，体会分母多了什么。

① 无正则（$\lambda = 0$）：$w = \dfrac{\sum_i x_i y_i}{\sum_i x_i^2} = \dfrac{1+4+9}{1+4+9} = \dfrac{14}{14} = \boldsymbol{1}$——完美拟合，毫不意外

② 加岭正则（$\lambda = 14$）：$w = \dfrac{\sum_i x_i y_i}{\sum_i x_i^2 + \lambda} = \dfrac{14}{14+14} = \dfrac{14}{28} = \boldsymbol{0.5}$

$$\lambda = 0 \Rightarrow w = 1; \qquad \lambda = 14 \Rightarrow w = 0.5; \qquad \lambda \uparrow \; \Rightarrow \; w \to 0$$

对比

换一种惩罚就换一种性格：L2 只缩小，L1 能清零

LASSO（Least Absolute Shrinkage and Selection Operator）：$\min_{\boldsymbol{w}} \|\boldsymbol{X}\boldsymbol{w} - \boldsymbol{y}\|^2 + \lambda \sum_j |w_j|$。菱形顶点戳在坐标轴上 → 稀疏解，顺带完成特征选择。
定义

想输出类别：先把线性输出光滑地压成 0 到 1 之间的概率

阶跃函数在零点不可导，学习链断掉 → 需要光滑替代品：对数几率函数（Logistic Function，即 sigmoid）

$$\sigma(z) = \frac{1}{1 + e^{-z}} \qquad (z \to -\infty \Rightarrow \sigma \to 0; \; z = 0 \Rightarrow \sigma = 0.5; \; z \to +\infty \Rightarrow \sigma \to 1)$$
$$\text{对率回归（Logistic Regression）：} \quad p = P(y=1 \mid \boldsymbol{x}) = \sigma(\boldsymbol{w}^{\top}\boldsymbol{x} + b)$$
名字来历：反解得 $z = \ln \dfrac{p}{1-p}$，$p/(1-p)$ 叫几率（Odds）——用线性模型拟合「对数几率」。
损失

交叉熵配 sigmoid：梯度干净得只剩预测减真实再乘输入

用极大似然衡量概率准不准，取负对数得交叉熵损失（Cross-Entropy Loss）：

$$L = -\big[ y \ln p + (1 - y) \ln (1 - p) \big]$$
$$\frac{\partial L}{\partial \boldsymbol{w}} = (p - y)\, \boldsymbol{x}, \qquad \frac{\partial L}{\partial b} = p - y$$
读法：$y=1$ 时只剩 $-\ln p$，$y=0$ 时只剩 $-\ln(1-p)$，一个式子自动切换；梯度 =（预测概率 − 真实标签）× 输入——预测越离谱步子越大，预测对了梯度自动归零。
手算

一步梯度下降：概率 0.5 涨到 0.525，损失 0.693 降到 0.644

单特征单样本：$x = 1$，$y = 1$；初始 $w_0 = 0$，$b_0 = 0$，学习率 $\eta = 0.1$。

① 前向算概率：$z_0 = 0\times 1 + 0 = 0$，$p_0 = \sigma(0) = 0.5$——五五分，完全没把握

② 算损失：$L_0 = -\ln 0.5 = \ln 2 \approx 0.693$

③ 算梯度：$\frac{\partial L}{\partial w} = (0.5 - 1)\times 1 = -0.5$；$\frac{\partial L}{\partial b} = -0.5$

④ 更新：$w_1 = 0 - 0.1\times(-0.5) = \boldsymbol{0.05}$，$b_1 = \boldsymbol{0.05}$

$$\text{⑤ 验证：} \quad p_1 = \sigma(0.1) \approx 0.525, \qquad L_1 \approx 0.644 \lt 0.693 \;\; \text{——损失真的降了}$$

定义

线性判别分析：找一个方向投影，让同类抱团、异类远离

线性判别分析（Linear Discriminant Analysis, LDA）：分类 = 降维到一条线 + 阈值。好方向 $\boldsymbol{w}$ 要同时满足：

  • 类间远：两类均值的投影离得尽量开——$|\,\boldsymbol{w}^{\top}(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)\,|$ 尽量大
  • 类内近：每类自己的投影尽量抱团——$\boldsymbol{w}^{\top}\boldsymbol{S}_w\boldsymbol{w}$ 尽量小（$\boldsymbol{S}_w$ 为类内散度矩阵）
$$\boldsymbol{w} \propto \boldsymbol{S}_w^{-1} (\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1)$$
读法：先取「两均值之差」方向，再用 $\boldsymbol{S}_w^{-1}$ 修正——类内散布大的方向压一压。$\propto$ 表示正比于：学的是方向，长度无所谓。
手算

四个点验证 LDA：方向取 $(-1, 1)$，两类投影完全分开

类 0：$(1,2)$、$(3,4)$；类 1：$(3,2)$、$(5,0)$。

① 均值：$\boldsymbol{\mu}_0 = (2, 3)$，$\boldsymbol{\mu}_1 = (4, 1)$

② 类内散度（偏差外积求和）：$\boldsymbol{\Sigma}_0 = \begin{bmatrix} 2 & 2 \\ 2 & 2 \end{bmatrix}$，$\boldsymbol{\Sigma}_1 = \begin{bmatrix} 2 & -2 \\ -2 & 2 \end{bmatrix}$，$\boldsymbol{S}_w = \begin{bmatrix} 4 & 0 \\ 0 & 4 \end{bmatrix} = 4\boldsymbol{I}$——两类散布恰好抵消成球形

③ 投影方向：$\boldsymbol{w} \propto \boldsymbol{S}_w^{-1}(\boldsymbol{\mu}_0 - \boldsymbol{\mu}_1) = \frac{1}{4}(-2, +2) \propto \boldsymbol{(-1, +1)}$

④ 投影验证（$\boldsymbol{w}^{\top}\boldsymbol{x} = -x_1 + x_2$）：类 0 → $+1, +1$（完全抱团）；类 1 → $-1, -5$。区间 $[+1,+1]$ 与 $[-5,-1]$ 零重叠，阈值取 0 即全对 ✅

多分类

二分类器干多分类的活：拆开打，再投票

OvR 一对其余（One-vs-Rest）OvO 一对一（One-vs-One）
分类器个数（$N$ 类）$N$ 个$N(N-1)/2$ 个
$N = 4$ 时4 个（「是1?」「是2?」「是3?」「是4?」）6 个（两两配对）
$N = 10$ 时10 个45 个
每个分类器数据全部 $m$ 个样本只用过两类的样本，问题更简单
特点训练、预测开销小投票互相纠错，精度常更好；类多时开销大
还有更一般的 MvM 多对多（Many-vs-Many）：每次挑若干类作正类、若干类作负类，纠错输出码（ECOC）是其代表——本章只需知道有这条路。
不平衡

九十九比一时全猜多数类也有 99 分：不平衡要换尺子

99 封正常邮件对 1 封垃圾邮件：全判「正常」也有 99% 精度——可模型连一封垃圾邮件都没抓到过，毫无用处。

  • 欠采样：从多数类删掉一些样本，让两类数量相当（代价：丢弃信息）
  • 过采样：给少数类「复制」或插值出新样本（代价：可能放大噪声）
  • 再缩放：不改数据改决策——预测时用「观测几率 ÷ 训练集原始几率」校正，阈值向多数类方向挪
⚠️ 类别不平衡时精度失灵：换第2章的尺子——查准率、查全率、F1、AUC；先处理不平衡，再谈精度。
避坑

本章最容易踩的三个坑

❌ 「最小二乘要求误差服从正态分布，否则解没意义」
✅ 因果倒置：几何上它永远对应「最近投影」，与分布无关；只是误差恰好正态时它恰好也等于最大似然解。
❌ 「λ 越大越好，惩罚越狠越不容易过拟合」
✅ λ 过大把所有系数压向 0，模型退化成水平线——从过拟合栽进欠拟合；λ 是超参数，只能在验证集上调。
❌ 「对率回归名字里有回归，所以是回归模型」
✅ 它回归的是概率（对数几率），干的活是分类——「回归」说中间那步，「分类」说最后那步。
