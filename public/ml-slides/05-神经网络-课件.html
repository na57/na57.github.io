主线

表达力不够就堆层，堆层之后靠 BP 分摊误差，再防住两个坑

1表达力见底：线性模型卡在 XOR，一条直线切不开对角分布
2标准件：M-P 神经元 ＋ 非线性激活——没有非线性，堆层白堆
3堆层：加隐层得多层前馈网络，万有近似定理保证表达力
4训练：隐层错多少没人告诉它 → 误差逆传播（BP）按链式法则逐层分摊
5防坑：局部最小靠多起点与随机性，过拟合靠早停与正则化

动机

一条直线切不开异或——线性模型的表达力到此为止

西瓜的「好」取决于色泽、纹理、触感的组合，一刀切不出来。最简反例——异或（XOR）：

正类 $(0,1)$、$(1,0)$ 占一条对角，负类 $(0,0)$、$(1,1)$ 占另一条——任何直线都分不开。
😇 旧方案一：换条更复杂的直线
直线终究是直线，几何上根本不存在解。
🙂 旧方案二：人工构造特征
把难题推回给人，特征工程没有尽头。
💡 本章方案：让网络自己学特征——非线性激活 ＋ 多层堆叠。
定义

M-P 神经元 = 加权求和 ＋ 减阈值 ＋ 过非线性激活

⚖️ 权重 $w_i$ 与阈值 $\theta$（Threshold）
权重决定每项输入的话语权；阈值就是第3章偏置 $b$ 的角色，决定这个神经元有多难被「点着」。
🌀 激活函数 $f$（Activation Function）
给线性打分「掰弯」的那一下，注入非线性——四种常见选择下一页逐个看。
$$\boldsymbol{y = f\!\left(\sum_{i=1}^{n} w_i x_i - \theta\right)}$$
读法：把各项输入按权重加总、减去门槛，再过一道非线性的弯——M-P 神经元（McCulloch-Pitts Neuron，1943）至今是所有网络的祖先单元。
激活

激活函数必须非线性，否则堆多少层都等价一层

激活函数写法值域一句话特点
阶跃（Step）$\mathbf{1}[x \geq 0]$$\{0,1\}$理想神经元模型；不连续不可导，没法做梯度下降
Sigmoid$\sigma(x)=\frac{1}{1+e^{-x}}$$(0,1)$光滑可导；$\sigma^{\prime}=\sigma(1-\sigma)$；两端饱和导数趋零
双曲正切（tanh）$\tanh(x)$$(-1,1)$居中版 sigmoid，输出居中更利于训练
ReLU$\max(0,x)$$[0,+\infty)$计算最省，深网里最常用
💡 关键一跃：若 $f$ 是线性（含恒等），则 $f_2(f_1(x))$ 仍是线性函数，多层退化为单层——非线性是让「多层」有意义的唯一理由，每一层都能把上一层的输出掰弯。
感知机

感知机只在犯错时学习，线性可分必在有限步收敛

感知机（Perceptron）= 阶跃激活的 M-P 神经元 ＋ 一条从错误中学习的规则：

$$\boldsymbol{w_i \leftarrow w_i + \eta\,(y - \hat{y})\,x_i, \qquad \theta \leftarrow \theta - \eta\,(y - \hat{y})}$$
  • 预测对时 $y-\hat{y}=0$，什么都不改——只在犯错时学习；
  • 学习率（Learning Rate）$\eta \in (0,1)$，控制每一步迈多大；
  • 保证：数据线性可分时，有限步内必收敛到一个全分对的解。
⚠️ 它只修正当前犯错的那个样本，可能在别的样本上引入新错误——保证的是「收敛」，不是「每步总误差下降」。
手算

一步更新：$\boldsymbol{w}$ 从 $(0,0)$ 到 $(2,1)$，$\theta$ 到 $-1$，样本立刻分对

初始 $w=(0,0)$、$\theta=0$、$\eta=1$；来样本 $x=(2,1)$，真实标签 $y=1$。

① 前向打分：$\sum_i w_i x_i - \theta = 0\times 2 + 0\times 1 - 0 = 0 \;\Rightarrow\; \hat{y}=f(0)=0$，与 $y=1$ 不符，犯错

② 计算误差项：$y - \hat{y} = 1 - 0 = 1$

③ 更新参数：$w \leftarrow (0,0) + 1\times 1 \times (2,1) = \boldsymbol{(2,1)}$；$\theta \leftarrow 0 - 1\times 1 = \boldsymbol{-1}$

$$\text{验证：}\; 2\times 2 + 1\times 1 - (-1) = \boldsymbol{6 \gt 0} \;\Rightarrow\; \text{判为 1，分对了 ✓}$$

直觉：把正例误判成负例，说明权重太弱、门槛太高——沿 $x$ 方向加权重，同时把阈值往下拉。

结构

输入层不算层数、信号只向前流——多层前馈网络的三条约定

  • 层：输入层只透传、不做计算，不计入层数；隐层与输出层才带权重和激活——「单隐层网络」也叫两层网络。
  • 前馈（Feedforward）：信号只从输入流向输出，同层不互连、不跨层回头，没有环。
  • 全连接：相邻两层每个神经元两两相连，每条边一个权重，每个隐层/输出神经元一个偏置。
多层前馈神经网络（Multi-layer Feedforward Neural Network）：让隐层先把输入「重新表示」，输出层再在新表示上做划分。
flowchart LR i1((i1)) -- w1 --> h1((h1)) i1 -- w3 --> h2((h2)) i2((i2)) -- w2 --> h1 i2 -- w4 --> h2 b1((b1)) --> h1 b1 --> h2 h1 -- w5 --> o1((o1)) h1 -- w7 --> o2((o2)) h2 -- w6 --> o1 h2 -- w8 --> o2 b2((b2)) --> o1 b2 --> o2

本章反复使用的 2-2-2 全连接网络：$w_1 \dots w_8$ 为连接权重，$b_1$、$b_2$ 为两层偏置

表示

隐层把样本搬到更好分的空间：异或的两个正类点重合了

两隐元分工：$h_1$ = 「$x_1$、$x_2$ 至少一个为正」，$h_2$ = 「两个同时为正」。四点经隐层变换后的新坐标：

原输入 $(x_1,x_2)$$h_1$$h_2$新坐标 $(h_1,h_2)$类别
$(0,0)$00$(0,0)$0
$(0,1)$10$(1,0)$1
$(1,0)$10$(1,0)$1
$(1,1)$11$(1,1)$0
两个正类点在新空间重合到同一点 $(1,0)$，负类被送到 $(0,0)$ 与 $(1,1)$——判 $h_1 - h_2 \gt 0.5$ 为正即可分开。隐层 = 把样本搬到更好分的空间，这就是「神经网络自己学特征」。
定理

一个隐层就足够逼近任意连续函数——但定理只管「存在」

📜 万有近似定理（Universal Approximation Theorem）
只需一个含足够多神经元的隐层，多层前馈网络就能以任意精度逼近任意连续函数。
🔪 切刀直觉：每个隐神经元在输入空间「切一刀」，划出一个半空间；足够多的刀围出任意区域，再让每块区域对输出的贡献可调，函数形状就近似出来了。
⚠️ 别把「存在」读成「划算」：定理不告诉你需要多少隐神经元（可能是天文数字），更不给训练方法。实践用「深而窄」替代「浅而宽」——这正是深度学习的出发点。
💡 视角转换：线性模型是「人定特征、模型学权重」；神经网络把特征也变成参数——隐层权重就是特征提取器。
思想

BP 的答案：把输出误差按链式法则逐层分摊回每个权重

隐层神经元的「正确答案」没人告诉它——误差逆传播（Error BackPropagation，BP，1986 年重新流行）给出解法：

$$\text{输出层误差项：}\; \delta o_k = (o_k - t_k)\cdot o_k\,(1 - o_k)$$
$$\text{隐层分摊：}\; \frac{\partial E}{\partial h_1} = \delta o_1 \cdot w_5 + \delta o_2 \cdot w_7$$
💡 BP 不是新数学，是链式法则的记账术：输出层的 $\delta$ 由目标直接算，隐层的 $\delta$ 由下游 $\delta$ 按权重加权求和再乘本地导数——每个权重只为「经它流过去的那一份误差」负责。记住这句，BP 所有公式都能现场推出来。
手算①

前向一轮：每个神经元先加权再过 sigmoid，误差 $E=0.2984$

类别取值（$\eta = 0.5$，激活全为 sigmoid，$E=\frac{1}{2}\sum_k (o_k - t_k)^2$）
输入$i_1 = 0.05$，$i_2 = 0.10$；目标 $t_1 = 0.01$，$t_2 = 0.99$
隐层参数$w_1\!\sim\!w_4 = 0.15,\, 0.20,\, 0.25,\, 0.30$；$b_1 = 0.35$
输出层参数$w_5\!\sim\!w_8 = 0.40,\, 0.45,\, 0.50,\, 0.55$；$b_2 = 0.60$

① 隐层：$net_{h1} = 0.15\times 0.05 + 0.20\times 0.10 + 0.35 = 0.3775 \Rightarrow h_1 = \sigma(0.3775) = \boldsymbol{0.5933}$；同理 $h_2 = \boldsymbol{0.5969}$

② 输出层：$net_{o1} = 0.40\times 0.5933 + 0.45\times 0.5969 + 0.60 \approx 1.1059 \Rightarrow o_1 = \boldsymbol{0.7514}$；$o_2 = \boldsymbol{0.7729}$

$$\text{③ 总误差：}\; E = \tfrac{1}{2}(0.7514 - 0.01)^2 + \tfrac{1}{2}(0.7729 - 0.99)^2 = 0.2748 + 0.0236 = \boldsymbol{0.2984}$$

暂停推导

合上书，用 $\delta o = (o-t)\,o(1-o)$ 和「下游 $\delta$ 按权重加权求和」，自己推出 $\delta o_1$、$w_5^{\prime}$、$\delta h_1$、$w_1^{\prime}$ 四个数。

① 输出层误差项：$\delta o_1 = (0.7514 - 0.01)\times 0.7514\times(1 - 0.7514) = 0.7414\times 0.1868 = \boldsymbol{0.1385}$

② 更新 $w_5$：$\frac{\partial E}{\partial w_5} = \delta o_1 \cdot h_1 = 0.1385\times 0.5933 = 0.0822 \;\Rightarrow\; w_5^{\prime} = 0.40 - 0.5\times 0.0822 = \boldsymbol{0.3589}$

③ 灵魂一步·误差分摊回隐层：$\frac{\partial E}{\partial h_1} = \delta o_1 w_5 + \delta o_2 w_7 = 0.1385\times 0.40 + (-0.0381)\times 0.50 = \boldsymbol{0.0364}$

④ 更新 $w_1$：$\delta h_1 = 0.0364\times 0.2413 = 0.00878 \;\Rightarrow\; \frac{\partial E}{\partial w_1} = \delta h_1 \cdot i_1 = 0.000439 \;\Rightarrow\; w_1^{\prime} = 0.15 - 0.5\times 0.000439 = \boldsymbol{0.1498}$

验证

再前向一轮验证：误差从 0.2984 降到 0.2910，方向对了

$$\text{更新后再前向一轮：}\; E^{\prime} \approx \boldsymbol{0.2910} \;\lt\; 0.2984 = E \quad (\text{一轮降 } 0.0074)$$
1前向算输出：每个神经元先加权求和，再过激活函数
2反向摊误差：链式法则把 $E$ 逐层分摊成每个权重的梯度
3更新：沿负梯度方向走 $\eta$ 步长——一步梯度下降
4循环：重复几千轮，误差一路滚下去
⚠️ 一轮 BP = 一步梯度下降，不是一次训好；真实训练迭代成千上万轮，每轮喂一个样本（随机梯度）或一批样本。
陷阱一

蒙眼下山会卡进洼地：三个办法跳出来

多层网络的误差曲面坑坑洼洼：四周都比我高的洼地是局部最小（Local Minimum），远处更深的谷才是全局最小（Global Minimum）。梯度下降走到洼地就停了。

  • 多组随机初始值：从不同起点各训一个网络，取误差最小者——换起点就是换一座山。
  • 模拟退火（Simulated Annealing）：允许以一定概率接受「变差的解」，靠概率蹦出洼地。
  • 随机梯度下降（SGD）：每轮只用单个或小批样本，梯度自带的噪声恰好能帮参数晃出浅洼。
💡 现代高维网络里，鞍点其实比差的局部最小更常见；但「多起点重来」仍是最便宜的对策，先用它。
陷阱二

验证误差回升就停手：早停与正则化，一时一空

⏱️ 早停（Early Stopping）
同时盯训练误差与验证集误差；验证误差一旦回升立刻停止，留住回升前的权重——从时间上限制复杂度。
📏 正则化（Regularization）
$E \leftarrow E + \lambda \sum_i w_i^2$：惩罚大权重，偏好「小而分散」——从空间上限制复杂度，与第3章 L2 正则同源。

避坑

这三个误解最常见：线性堆层、逐步降误差、盯着训练误差

❌ 「层数够多，线性激活也能逼近任意函数」
✅ 线性函数的复合仍是线性函数：$f_2(f_1(x))$ 恒为线性，叠多少层都等价一个单层，连 XOR 都解决不了。非线性才是让层数有意义的机制。
❌ 「感知机每步更新都让训练集总误差减小」
✅ 它只修当前犯错的那个样本，可能在别的样本上引入新错误；保证的是「线性可分时有限步收敛」（终点存在），不是「每步单调下降」（路径性质）。
❌ 「训练误差还在降，就应该继续训」
✅ 训练误差单调下降恰恰是过拟合温床，它不含泛化信息；停止信号看验证误差，回升即早停。

小结
