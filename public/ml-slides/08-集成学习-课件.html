定义

集成学习 = 足够好 ＋ 足够不同，两个条件缺一不可

💪 足够好
每个学习器准确率高过瞎猜（二分类即错误率 $\varepsilon \lt 0.5$），否则它投的是反票，人越多错得越稳
🎲 足够不同
彼此错误不抱团——你错的我刚好对，计票时才能互相抵消；错误完全相关时，一万个学习器也等于一个
$$\text{集成有效} \iff \underbrace{\varepsilon \lt 0.5}_{\text{好}}\;\text{且}\;\underbrace{\text{错误不相关}}_{\text{不同}}$$
读法：集成学习（Ensemble Learning）训练一组个体学习器（Base Learner）再按策略结合——它不是新模型，而是把已有模型组织起来的元方法。
手算

5 个错误率 0.3 的独立学习器投票，错误率几乎腰斩到 0.163

① 集成出错 ⟺ 至少 3 个学习器出错（5 票多数），按出错个数 k 枚举：

$k{=}3:\ \binom{5}{3}\,0.3^3 0.7^2 = 0.1323 \qquad k{=}4:\ \binom{5}{4}\,0.3^4 0.7 = 0.0284 \qquad k{=}5:\ 0.3^5 = 0.0024$
$$P(\text{集成出错})=\sum_{k=3}^{5}\binom{5}{k}\,0.3^{k}\,0.7^{5-k}\approx \boldsymbol{0.163} \quad(\text{单个是 }0.3)$$
霍夫丁不等式（Hoeffding）：$\varepsilon \lt 0.5$ 且错误相互独立时，T 增大，多数投票错误率按指数压向 0（T=7 时仅 0.126）。「独立」正是现实中缺的那一味药。

机理

误差是被「分歧」吃掉的；两条路线分攻方差与偏差

📉 误差-分歧分解（Error-Ambiguity）
回归任务可证：集成平方误差 = 成员平均误差 − 分歧度
⚖️ 偏差-方差分解（Bias-Variance）
单学习器误差 = 偏差² + 方差 + 噪声；噪声消不掉，能下手的是前两块
$$\text{集成误差} \;=\; \text{成员平均误差} \;-\; \text{分歧度}$$
分工：Bagging 平均预测主攻方差（8.2）；Boosting 逐轮补错主攻偏差（8.3–8.4）——全章就是这两条的展开
8.2

Bagging：T 次自助采样各训一个学习器，全程并行

flowchart LR D["训练集 D
（m 个样本）"] --> S1["自助采样 D₁"] D --> S2["自助采样 D₂"] D --> S3["自助采样 D_T"] S1 --> H1["学习器 h₁"] S2 --> H2["学习器 h₂"] S3 --> HT["学习器 h_T"] H1 --> V["投票 / 平均"] H2 --> V HT --> V
Bagging = Bootstrap Aggregating：有放回抽 m 个 × T 次 → 并行训练 → 分类投票、回归平均。T 份采样互不依赖，可同时开训。
手算

自助采样只用上约 63.2% 的样本，剩 36.8% 白送一个验证集

① 某样本 m 次都没被抽中的概率（每次抽中它的概率是 1/m）：

$$P(\text{始终没被抽中})=\Bigl(1-\frac{1}{m}\Bigr)^{m}$$

② 取极限：m=10 时 0.3487，m=100 时 0.3660，m=10⁶ 时 0.36788 →

$$\Bigl(1-\frac{1}{m}\Bigr)^{m}\to \frac{1}{e}\approx 0.368 \;\Rightarrow\; \text{采样集约含 } \boldsymbol{63.2\%} \text{ 的不同样本}$$
剩下约 36.8% 叫袋外样本（OOB）：用「没采到它」的学习器对它投票即可估计泛化误差——袋外估计（OOB Estimate），免费验证集。

推导

平均法的方差账：T 再大也消不掉 ρσ² 这块地板

① T 个学习器平均的方差（各方法差 σ²，两两相关 ρ）：

$$\mathrm{Var}(\text{平均})=\rho\sigma^{2}+\frac{(1-\rho)\sigma^{2}}{T}$$

② 两个极端校准：完全独立（ρ=0）→ σ²/T，T=25 压到 4%；完全相关（ρ=1）→ σ²，平均白做。

③ 代入现实情形 ρ=0.5、T=25（设 σ²=1）：

情形计算方差
单个学习器σ²1.00
独立集成 T=25（假想）1/250.04
相关集成 ρ=0.5、T=250.5 + 0.5/25 = 0.5 + 0.020.52
相关集成 T→∞只剩 ρσ²0.50（再也降不动）
$$\text{瓶颈不是 } T \text{，是 } \rho \;:\quad T\to\infty \Rightarrow \mathrm{Var}\to \boldsymbol{\rho\sigma^{2}}$$

8.2

随机森林：每个节点随机限选 k 个特征，把 ρ 本身压低

💡 关键一跃：随机森林（Random Forest）= Bagging + 决策树 + 每节点先从 d 个特征中随机抽 k 个（分类常取 $k=\log_2 d$）再选最优分裂。数据扰动之外再加一层输入属性扰动，树结构错开更彻底，ρ 变小 → ρσ² 这块「地板」整体缩水。
🌳 纯 Bagging 的病
只在样本层面扰动；若有超强特征，每棵树都抢它分裂，结构雷同，ρ 居高不下
🌲 RF 的药
强特征在多数节点被随机排除，树被迫用不同特征组合分裂，相关性 ρ 明显下降
⚠️ 平均降的是方差：对不稳定学习器（决策树、神经网络）收益最大；对稳定学习器（k 近邻、线性回归）几乎没收益。
8.3

AdaBoost 三个词：样本权重、学习器权重、串行更新

flowchart TB D1["权重分布 D₁"] --> H1["训练 h₁，算 ε₁ 与 α₁"] H1 --> U1["更新：分错样本变重，得 D₂"] U1 --> H2["训练 h₂，专补 h₁ 的窟窿"] H2 --> U2["继续更新 ……"] H1 -.-> F["加权投票输出"] H2 -.-> F
  • 样本权重：初始均分；每轮算出加权错误率 εt，分错变重、分对变轻
  • 学习器权重：错误率越低发言权越大
  • 串行更新：ht+1 依赖 ht 的纠错结果，无法并行（对照 Bagging）
$$\alpha_t=\frac{1}{2}\ln\frac{1-\varepsilon_t}{\varepsilon_t},\qquad H(x)=\mathrm{sign}\Bigl(\sum_t \alpha_t h_t(x)\Bigr)$$
演练

10 个样本、h₁ 分错 3 个：一轮四步走完，权重变成 1/14 与 1/6

在纸上算出 ε₁、α₁、两个乘数、Z₁，以及归一化后分对/分错样本各占多少——再翻页对答案

① 加权错误率：$\varepsilon_1 = 3\times 0.1 = \boldsymbol{0.3}\ (\lt 0.5$，有资格留下）

② 学习器权重：$\alpha_1=\frac12\ln\frac{0.7}{0.3}=\frac12\ln\frac{7}{3}\approx \boldsymbol{0.4236}$；乘数 $e^{\alpha_1}\approx 1.5275$，$e^{-\alpha_1}\approx 0.6547$

④ 归一化：$Z_1=0.4583+0.4583\approx \boldsymbol{0.9165}$ → 分对每个 $\approx\boldsymbol{1/14}\;(0.0714)$，分错每个 $\approx\boldsymbol{1/6}\;(0.1667)$

8.3

权重分布自动逼下一轮补窟窿——这就是「串行纠错」

🔍 第二轮的压力：3 个分错样本合计 $3\times\frac16=\boldsymbol{0.5}$，7 个分对样本合计 $7\times\frac1{14}=0.5$——h₂ 想让 $\varepsilon_2\lt0.5$，几乎必须先把这 3 个旧错样本分对（一个就值 1/6）
✅ 理论收束：AdaBoost = 前向分步 + 指数损失；训练误差按 $\prod_t Z_t=\prod_t 2\sqrt{\varepsilon_t(1-\varepsilon_t)}$ 下降，只要每轮 $\varepsilon_t\lt0.5$ 就被指数级压下去——主攻偏差。
❌ 「AdaBoost 和 Bagging 一样抗噪」
✅ 恰恰相反：串行纠错对标错的脏数据极敏感，永远学不对的离群点会被一轮轮加重、抢走全部注意力；噪声多请用 Bagging / 随机森林。
8.4

GBDT 把「纠错」推广到任意损失：每轮拟合负梯度

💡 关键一跃：梯度提升（Gradient Boosting）每轮直接拟合损失函数的负梯度——负梯度就是「往哪改预测损失降得最快」，是广义的残差；基学习器用回归树，即 GBDT。
$$L=\tfrac{1}{2}(y-F)^{2}\;\Rightarrow\;-\frac{\partial L}{\partial F}=\boldsymbol{y-F}\;\;\text{恰好就是残差}$$
平方损失下的 GBDT = 一轮轮拟合残差；换损失只需把「残差」换成「负梯度」，流程原样照搬。AdaBoost（指数损失）是这个框架在分类上的特例——差别不在思想，只在损失函数。
手算

4 个样本一轮迭代：拟合残差，SSE 从 68 砍到 4

① 初始化（平方损失下最优常数 = 均值）：$F_0=\frac{2+4+10+12}{4}=\boldsymbol{7}$；残差 $r=y-F_0=(-5,-3,+3,+5)$，$\mathrm{SSE}_0=25+9+9+25=\boldsymbol{68}$

② 用深度 1 回归树（stump）拟合残差，枚举三个候选分裂（叶值取该侧残差均值）：

候选分裂左叶 / 右叶均值SSE
$x\lt1.5$−5 / ≈1.667≈ 34.67
$x\lt2.5$ ✓−4 / +44（最优）
$x\lt3.5$≈−2.667 / +5≈ 37.67

③ 更新：$F_1=F_0+\text{stump}(x)$ → $x\in\{1,2\}$ 时 $F_1=\boldsymbol{3}$，$x\in\{3,4\}$ 时 $F_1=\boldsymbol{11}$

$$\text{新残差}=(-1,+1,-1,+1),\quad \mathrm{SSE}_1=\boldsymbol{4}\;:\;68\to 4\text{，一轮下降约 }94\%$$

8.5

结合策略三大类：平均、投票、学习（Stacking）

策略具体做法适用与要点
平均法简单平均各 1/T；加权平均权重可不同、和为 1回归默认；权重多时易在训练集上调参过拟合，数据少宁用简单平均
投票法绝对多数：过半才判，否则拒判；相对多数：谁票多算谁；可加权分类默认；绝对多数适合「宁可不判不可错判」（如医疗）
Stacking初级学习器的输出当新特征，再训次级学习器（元学习器）做最终预测学习法；成员很强且各擅一隅时收益最大；工艺关键见下页
平均 / 投票是「死规则结合」，Stacking 是「学出来的结合」——会看菜下碟的元学习器，比一刀切的人均一票强。
8.5

Stacking 的次级训练集，必须用交叉验证「生产」

❌ 直接用初级学习器在训练集上的预测去训次级学习器
✅ 初级学习器对训练集滚瓜烂熟，预测漂亮得失真——次级学到的是「谁最会背题」而非「谁泛化好」，必然过拟合。
✅ 正确工艺：K 折交叉验证产出次级训练集——每个样本的次级特征，都来自那些没见过它的初级学习器（在它所属留出折之外训练的那批）的预测。
🧠 直觉：交叉验证让每个预测都诚实——它反映的是模型对陌生样本的泛化能力，而不是对旧题的记忆。
8.5

「不同」从哪来：多样性增强的四路扰动

扰动路线做法本章对号入座
数据样本扰动改变训练样本的构成或权重Bagging 自助采样 · AdaBoost 权重更新
输入属性扰动随机子空间：只用部分特征随机森林每节点随机限选 k 个特征
输出表示扰动改变输出的编码方式ECOC：把多类拆成不同二分类组合
算法参数扰动换随机种子 / 超参数同一算法跑多个配置
多样性度量（分歧度、Q 统计量）知道名字即可；主线始终是 8.1 那句：误差 − 分歧，此消彼长。
实战

欺诈初筛案例：噪声多、要重训、要特征重要性 → 选随机森林

某银行「交易欺诈初筛」：200 万条交易、欺诈占 0.3%、60 维特征含噪声；要求稳定、每周自动重训、输出特征重要性。

业务约束随机森林（Bagging）GBDT（Boosting）
特征含噪声✅ 平均机制对脏数据天然钝化⚠️ 串行纠错被异常样本吸走注意力
每周自动重训✅ T 棵树互不依赖，可分布式并行⚠️ 必须串行，慢且依赖上一轮
要特征重要性✅ 袋外估计顺手度量特征贡献可给但无袋外赠品
选型的判别题：先想清楚误差主要在偏差还是方差——漏报严重（偏差主导）时再换 GBDT 或加代价敏感学习。
避坑

本章三个高频误解，逐个拆掉

❌ 「学习器越多越好」
✅ 0.163 的前提是独立且 ε<0.5；错误相关时 T 增大收益迅速饱和，混入 ε>0.5 的成员反被拖垮——先求「好而不同」，再谈数量。
❌ 「Bagging 什么模型都能往上套」
✅ 平均只降方差：对不稳定学习器（决策树、神经网络）收益大；对稳定学习器（k 近邻、线性回归）几乎零收益，白付 T 倍训练成本。
❌ 「GBDT 每棵树都在学原始标签 y」
✅ 从第二轮起学的是负梯度 / 残差；更新别漏学习率 η——每步只走一小段，用更多的树换更稳的泛化。
小结

三句话讲完第8章

1解决什么：多个「好而不同」的学习器组合成更强的学习器——集成误差 = 平均误差 − 分歧度，误差靠分歧抵消
