主线

延迟奖赏 → 探索-利用 → 贝尔曼方程 → 免模型采样逼近

1问题：没有即时监督，只有延迟奖赏——没人指明哪一步对（探索-利用两难）

4免模型：P、R 未知时用采样逼近期望——蒙特卡罗 → 时序差分 → Q-learning / Sarsa

动机

围棋与倒水：监督与无监督都在这里失灵

前十五章都有「老师」：监督有标注、无监督有结构。本章把老师撤走——评价要等几十步之后、终局那一刻才到来。

♟️ 学下围棋
落子瞬间没人打分，终局才知胜负 +1 / −1；几十手棋共同造成这一个数字，它不指明哪一手立功、哪一手埋雷。
🤖 机器人倒水
「水洒了 −1」要等症状发生才知道；它无法指明刚才那串关节动作里哪一步错了。
$$G=\sum_{t=0}^{\infty}\gamma^{t} r_{t+1}\;\;=\;\; r_1+\gamma r_2+\gamma^2 r_3+\cdots$$
💡 本章方案：不追求每步答对，而是最大化长期的折扣累积奖赏——把终点的哨声折算成每一步的指南针。
定义

强化学习 = 状态·动作·奖赏 三要素 ＋ 马尔可夫性假设

🧩 三要素（state / action / reward）
状态 $s\in S$：环境当前局面；动作 $a\in A$：可执行操作；奖赏 $r$：环境反馈的标量评价，可正可负。
🔗 马尔可夫性（Markov property）
下一状态只依赖当前状态与当前动作，与更早历史无关：$P(s_{t+1}\mid s_t,a_t,\text{历史})=P(s_{t+1}\mid s_t,a_t)$。
$$\boldsymbol{G=\sum_{t=0}^{\infty}\gamma^{t} r_{t+1}}\qquad \gamma\in[0,1)$$
读法：学习目标不再是「每个样本都答对」，而是让长期的折扣累积奖赏最大——$\gamma$ 是耐心系数，越接近 0 越短视，越接近 1 越愿为远期大目标忍受眼前损失。
对照

奖赏不是标签：四个维度把两者钉死

监督学习强化学习
反馈形式每个样本的标注（「正确答案」）延迟、稀疏的奖赏标量（「做得好不好」）
反馈时机即时：每预测一次立即对答案延迟：走完一串动作才知结果
指明错误指明——标注就是正确答案不指明——奖赏不说哪个动作该背锅
数据来源独立同分布的样本集机器自己选动作产生的轨迹（分布被策略改变）
⚠️ 把延迟奖赏正确地分摊到每一步（功劳分配），正是本章后续所有算法要解决的核心难题。
K 摇臂

单状态·即时奖赏：把探索-利用剥离出来单独研究

K 摇臂赌博机（K-armed Bandit）：只有一个状态、奖赏即时。每步从 K 个臂选一个拉，真实期望 $\mu(k)$ 未知，靠样本均值 $Q(k)$ 估计。

💰 利用（exploitation）
选当前 $Q$ 最大的臂，稳拿眼下最好收益；但可能把「开局走运」的次优臂误当最好，困在局部。
🧭 探索（exploration）
试别的臂，能纠正错误估计；但每次试错都付出机会成本。
$$\varepsilon\text{-贪心：以 }1-\varepsilon\text{ 选 }\arg\max_k Q(k)\text{（利用），以 }\varepsilon\text{ 在 K 臂中均匀随机（探索）}$$
$\varepsilon$ 是唯一旋钮：$\varepsilon=0$ 纯贪心永不探索，$\varepsilon=1$ 纯随机永不利用。
演练

Softmax 手算：τ 从 0.1 到 1，概率从 0.731 掉到 0.525

① 规则（Boltzmann 分布）：$P(k)=\dfrac{e^{Q(k)/\tau}}{\sum_{j=1}^{K} e^{Q(j)/\tau}}$。设 $Q(1)=0.6,\;Q(2)=0.5$。

✍️
暂停推导

请分别算出 τ = 0.1 与 τ = 1 时选中臂 1 的概率，写全：指数项 → 分母 → 归一化。

② $\tau=0.1$（低温）：$e^{6}\approx 403.43$，$e^{5}\approx 148.41$，分母 $551.84$。$P(1)=403.43/551.84\approx\mathbf{0.731}$——Q 只差 0.1，概率拉到 0.731 vs 0.269。

③ $\tau=1$（高温）：$e^{0.6}\approx 1.822$，$e^{0.5}\approx 1.649$，分母 $3.471$。$P(1)=1.822/3.471\approx\mathbf{0.525}$——同样的 Q 差距几乎五五开。

$$\boldsymbol{\tau\to 0\ \text{退化为贪心（独大）},\qquad \tau\to\infty\ \text{退化为均匀随机}}$$

MDP

补回状态转移：MDP 四元组 ⟨S, A, P, R⟩ ＋ γ

成分含义
$S$状态空间
$A$动作空间
$P(s'\mid s,a)$转移概率：在 $s$ 执行 $a$ 后到达 $s'$ 的概率（马尔可夫性已内置）
$R(s,a,s')$奖赏函数：该次转移带来的期望奖赏
$\gamma\in[0,1)$折扣因子
有模型学习（model-based）＝ P 与 R 已知（哪怕来自模拟器或系统辨识）：环境 dynamics 写在纸面上，剩下是纯计算问题。策略 $\pi(a\mid s)$：状态 $s$ 下选各动作的概率分布。
值函数

今天的价值 = 眼前奖赏 ＋ 明天的价值打 γ 折

🏠 状态值函数 $V^{\pi}(s)$
从 $s$ 出发、按 $\pi$ 行动，折扣累积奖赏的期望。「这个状态本身有多好？」
👣 状态-动作值函数 $Q^{\pi}(s,a)$
从 $s$ 出发、先执行 $a$ 再按 $\pi$ 行动的累积期望。「在此状态做这个动作有多好？」——差别只在「先钉死第一步」。
$$\boldsymbol{V^{\pi}(s)=\sum_{a}\pi(a\mid s)\sum_{s'}P(s'\mid s,a)\big[\,R(s,a,s')+\gamma\,V^{\pi}(s')\,\big]}$$
读法：Bellman 期望方程把「无穷步全局优化」拆成「一步一价的局部方程」——能拆的前提正是马尔可夫性：明天只由今天决定。
最优方程

把「按 π 选」换成「挑最好」，期望方程升级为最优方程

Bellman 期望方程评估「给定策略有多好」；真正想要的是最优策略 $\pi^{*}$ 的值函数——只改一处：按 $\pi$ 加权 $\to$ 取 max。

$$\boldsymbol{V^{*}(s)=\max_{a}\sum_{s'}P(s'\mid s,a)\big[\,R(s,a,s')+\gamma\,V^{*}(s')\,\big]}$$
  • 期望变最大化 → 方程非线性；右侧出现 $V^{*}$ 自身 → 不动点方程。
  • $\gamma \lt 1$ 保证唯一不动点存在；有模型时可迭代直接求解。
读法：一个状态的最优价值 = 挑最好的动作后，「眼前落袋的奖赏 ＋ 下一状态最优价值打 γ 折」的期望。先记住它的长相，下一页看怎么解。
有模型

策略迭代「评估-改进交替」，值迭代「把最优方程当更新式」

🔁 策略迭代（policy iteration）
评估：对当前 $\pi$ 解 Bellman 期望方程组得 $V^{\pi}$；改进：$\pi'(s)=\arg\max_a \sum_{s'}P[\,R+\gamma V^{\pi}(s')\,]$。交替至策略不变即最优。
📈 值迭代（value iteration）
把最优方程本身当更新式：$V_{k+1}(s)\leftarrow\max_a\sum_{s'}P[\,R+\gamma V_k(s')\,]$；收敛后一次贪心提策略。
✅ 值迭代必收敛的依据：$\gamma \lt 1$ 使 Bellman 更新成为压缩映射——每次迭代把与不动点 $V^{*}$ 的差距乘以 $\gamma$，任意初值都收敛到同一个 $V^{*}$。
⚠️ 「有模型」＝ P、R 已知（哪怕来自模拟器），不是「人类专家手写规则」。
推导

值迭代手算：0 → 1.8 → 3.42 → 4.878 → … → V* = 18

① 设定：单状态 $s$；$a_1$ 确定回 $s$、奖赏 $1.8$；$a_2$ 确定回 $s$、奖赏 $1$；$\gamma=0.9$。转移确定（$P=1$）：

$$V\leftarrow\max(\,1.8+0.9V,\;\;1+0.9V\,)$$

② 迭代（$V_0=0$）：$V_1=\max(1.8,\,1)=1.8$；$V_2=\max(3.42,\,2.62)=3.42$；$V_3=\max(4.878,\,4.078)=4.878$ …

③ 收敛验证：$a_1$ 每步占优，不动点满足 $V^{*}=1.8+0.9V^{*}$ → $0.1V^{*}=1.8$：

$$\boldsymbol{V^{*}=\frac{1.8}{1-0.9}=18}\qquad \text{代回：}1.8+0.9\times 18=18\ \checkmark$$

④ 提策略：$\pi^{*}(s)=a_1$，每次都拿 1.8；迭代序列每步把与 18 的差距 ×0.9，稳步逼近。

免模型

P、R 未知：蒙特卡罗用整幕真实回报代替期望

免模型学习（model-free）：P、R 未知，只能交互收集 $(s,a,r,s')$ 样本，用采样逼近期望。核心问题：怎么用样本估计 $V^{\pi}$ / $Q^{\pi}$？

🎲 蒙特卡罗（Monte Carlo, MC）：一幕（episode）走到底得真实回报 $G$，然后更新 $V(s)\leftarrow V(s)+\alpha\big(G-V(s)\big)$。
  • 无偏：目标 $G$ 是真实采样到的累积奖赏（真期望的样本）。
  • 方差大：整幕所有随机性（环境的、策略的）压进一个数字。
  • 必须等幕末：下围棋输了才知道学，中途每一步都得憋着。
💡 能不能不等剧终、每步就学？——这就是下一页的时序差分。
TD

时序差分：边下棋边复盘，每步用一步样本立即校正

$$V(s)\leftarrow V(s)+\alpha\big[\,r+\gamma V(s')-V(s)\,\big]\qquad \text{TD 误差 }\delta=r+\gamma V(s')-V(s)$$
蒙特卡罗时序差分（TD）
更新目标真实回报 $G$（整幕走完才知）$r+\gamma V(s')$（一步即可构造）
更新时机一幕结束后每一步之后
偏差无偏有偏（自举 bootstrapping）
方差大（整幕随机性）小（一步随机性）
读法：TD 用「眼前奖赏 ＋ 对下一站的当前估计」校正本站估值——用估计更新估计，换来每步都能学。
对照

同轨按「实际的我」计价，离轨按「理想的我」计价

🧍 Sarsa（on-policy 同轨）
目标用行为策略实际选出的 $a'$：评估「行为策略自己」的价值，含探索代价。名自五元组 $(s,a,r,s',a')$。
$$Q(s,a)\leftarrow Q+\alpha\big[\,r+\gamma Q(s',a')-Q\,\big]$$
🦸 Q-learning（off-policy 离轨）
目标直接用 $s'$ 处最大 $Q$：评估「贪心目标策略」的价值，行为只管探索——故能直接逼近 $Q^{*}$。
$$Q(s,a)\leftarrow Q+\alpha\big[\,r+\gamma\max_{a'} Q(s',a')-Q\,\big]$$
差别只有一句话：更新目标里 $s'$ 处按「理想的我」（max，离轨）还是「实际的我」（$a'$，同轨）计价。
推导

同一笔经验：Q-learning 抬到 2.85，Sarsa 压到 1.95

① 设定：$Q(s,a_1)=2.0$，$r=1$，到 $s'$；$Q(s',a_1)=1.0$，$Q(s',a_2)=3.0$；$\alpha=0.5$，$\gamma=0.9$。

② Q-learning：$s'$ 处取 max $=\max(1.0,3.0)=3.0$；目标 $1+0.9\times 3.0=3.7$；$\delta=3.7-2.0=1.7$：

$$\boldsymbol{Q(s,a_1)\leftarrow 2.0+0.5\times 1.7=2.85}$$

③ Sarsa 对照（行为策略实际选出 $a'=a_1$）：目标 $1+0.9\times 1.0=1.9$；$\delta=1.9-2.0=-0.1$：

$$Q(s,a_1)\leftarrow 2.0+0.5\times(-0.1)=1.95$$

④ 差异解释：Q-learning 假设「到 $s'$ 必选最优 $a_2$」（学最优目标策略）；Sarsa 用实际要走的 $a_1$（学含探索代价的行为策略）。行为尽情探索，估值照样向贪心收敛——离轨精髓。

收束

状态爆炸用函数近似，奖赏难设计向人类示范借力

📦 值函数近似（value function approximation）
围棋状态约 $10^{170}$，Q 表开不出格子 → 把「查表」换成「函数」：$V(s)=\theta^{T}x(s)$，沿 TD 误差方向调参 $\theta\leftarrow\theta+\alpha\,\delta\, x(s)$。换神经网络即深度强化学习入口。
🧑‍🏫 模仿学习（imitation learning）
直接模仿：示范 $(s,a)$ 当监督数据学映射，软肋是分布偏移、错误累积。
逆强化学习（Inverse RL）：从示范反推奖赏函数再求最优，软肋是奖赏不唯一、问题欠定。
⚠️ 奖赏黑客（reward hacking）：策略钻奖赏函数的空子拿高分却不完成真目标——奖赏只挂真实目标，辅助项作陪。
避坑

本章最容易错的三件事

❌ 「奖赏就是标签——拿到正奖赏的那步就是正确动作」
✅ 奖赏延迟且稀疏：终局 +1 是几十步共同造成，不指明哪步立功。把延迟奖赏分摊到每步（功劳分配）正是值函数与 TD 要解决的核心难题。
❌ 「ε 越小越好，尽快锁定最优臂」
✅ 纯利用（ε=0）被早期运气锁死：最优臂开局走背字就永无翻身机会。ε / τ 应随时间衰减——先探索后利用，而非一开始给小值。
❌ 「Q-learning 用了 max，训练时就必须按贪心行动」
✅ max 只在更新目标里；行为仍需 ε-贪心探索，否则没走过的动作永远没数据。「离轨」＝目标策略与行为策略分离，互不耽误。
