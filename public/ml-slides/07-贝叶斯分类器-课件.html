本章解决「用概率做最优决策」——上一章交付判别边界，本章交付概率模型本身，下一章把多个概率型基学习器组合起来。

主线

从「最小风险决策」出发，一路解决「后验从哪来、维度爆炸怎么办、隐变量怎么办」

1最优 = 最小决策风险：贝叶斯决策论给出金标准（7.1）
2后验从哪来：贝叶斯定理拆成先验 × 似然，MLE 估参数（7.2）
3维度爆炸怎么办：朴素贝叶斯条件独立假设 + 拉普拉斯平滑（7.3）
4假设太强 / 有隐变量怎么办：半朴素贝叶斯、贝叶斯网、EM 算法（7.4–7.5）
这条链就是本章的目录：7.1 决策论 → 7.2 估参数 → 7.3 朴素贝叶斯 → 7.4 贝叶斯网 → 7.5 EM。
动机

判别式模型不算代价，生成式模型又估不动高维联合分布

癌症筛查场景：漏诊代价远高于误诊，但 SVM 只给你一条边界，不告诉你代价怎么算进去。

$$d = 30 \text{ 个二值属性} \;\Rightarrow\; \text{联合分布需 } 2^{30}-1 \approx 10^9 \text{ 个参数}$$
😇 判别式（SVM / 逻辑回归）
直接学边界或 P(c|x)，但无法表达「判错的代价不对称」
🙂 朴素生成式
想建联合分布 P(x, c)，但参数随维度指数爆炸，数据不够估
💡 本章方案：用贝叶斯决策论把代价算进决策，用条件独立假设把参数从指数压回线性。
定义

条件风险 = 「误判代价」按后验加权的期望，最优决策就是选它最小的类

📋 误判代价 λij
把真实类 cj 误判为 ci 的代价，可不对称（漏诊 ≫ 误诊）
🎯 贝叶斯判定准则
对每个 x，选使条件风险 R(ci|x) 最小的类，即 h*(x) = argmini R(ci|x)
$$R(c_i \mid \boldsymbol{x}) = \sum_{j} \lambda_{ij} \, P(c_j \mid \boldsymbol{x})$$
读法：把 x 判成 c i 的条件风险，等于「是 c j 的后验概率」乘「把 c j 误判成 c i 的代价」，对所有 j 求和。贝叶斯最优分类器 = 挑这个加权和最小的类。
推论

0-1 损失下，「最小风险」退化为「最大后验概率」（MAP）

① 0-1 损失代入：λij = 0（i=j），λij = 1（i≠j），求和只剩 j≠i 的项

$$R(c_i \mid \boldsymbol{x}) = \sum_{j \ne i} P(c_j \mid \boldsymbol{x})$$

② 概率归一：所有类后验之和为 1，所以求和 = 1 − P(ci|x)

$$R(c_i \mid \boldsymbol{x}) = 1 - P(c_i \mid \boldsymbol{x})$$
$$\text{最小化 } R \;\Longleftrightarrow\; \text{最大化 } P(c_i \mid \boldsymbol{x}) \;\Longrightarrow\; \boldsymbol{h^*(\boldsymbol{x}) = \arg\max_i P(c_i \mid \boldsymbol{x})}$$

例子

不对称损失下，即使后验各半，最优决策也不是随便挑

两类 c₁、c₂：λ₁₂ = 2（漏诊 c₂ 代价高），λ₂₁ = 1。逐样本算条件风险：

样本P(c₁|x)P(c₂|x)R(c₁|x) = 2·P(c₂|x)R(c₂|x) = 1·P(c₁|x)贝叶斯决策
x₁0.70.30.60.7c₁（0.6 小）
x₂0.40.61.20.4c₂（0.4 小）
x₃0.50.51.00.5c₂（0.5 小）
⚠️ x₃ 是关键：P(c₁) = P(c₂) = 0.5，但漏诊 c₂ 代价高，最优仍是 c₂。决策边界被推到 P(c₁|x) > λ₁₂/(λ₁₂+λ₂₁) = 2/3 ≈ 0.667，而不是 0.5。
估计

生成式路线：后验 = 先验 × 似然，参数用极大似然估计

$$P(c \mid \boldsymbol{x}) = \frac{P(c)\, P(\boldsymbol{x} \mid c)}{P(\boldsymbol{x})} \;\propto\; P(c)\, P(\boldsymbol{x} \mid c)$$
🔪 判别式
直接建模 P(c|x)（Ch3 线性、Ch5 神经网络）
🌱 生成式（本章）
先建 P(x, c) = 先验 × 似然，再用贝叶斯定理翻后验
$$\text{MLE 三步：写似然 } L(\theta) \;\to\; \text{取对数} \;\to\; \text{求导置零解 } \hat{\theta} \quad\text{（例：10 抛 7 正} \Rightarrow \hat{\theta} = \tfrac{7}{10}\text{）}$$
推导

MLE 三步走：从「10 抛 7 正」到 θ̂ = 7/10

① 写似然（独立伯努利试验，组合数与 θ 无关可略）

$$L(\theta) \;\propto\; \theta^{7} (1-\theta)^{3}$$

② 取对数（单调，不改变 argmax 位置）

$$\ln L(\theta) = 7 \ln\theta + 3 \ln(1-\theta) + \text{常数}$$

③ 求导置零：$\dfrac{7}{\theta} - \dfrac{3}{1-\theta} = 0 \Rightarrow 7(1-\theta) = 3\theta \Rightarrow 7 = 10\theta$

$$\boldsymbol{\hat{\theta} = \dfrac{7}{10}} \quad\text{—— 在 i.i.d. 伯努利假设下，MLE 就是观测频率}$$

假设

条件独立假设：把高维似然拆成各属性条件概率的连乘

$$P(\boldsymbol{x} \mid c) = \prod_{i=1}^{d} P(x_i \mid c) \;\Longrightarrow\; P(c \mid \boldsymbol{x}) \propto P(c) \prod_{i=1}^{d} P(x_i \mid c)$$
📉 参数爆炸被压住
d 个二值属性：从 2d−1 个参数降到 2d 个（每个属性每类一个）
🗳️ 直觉：各证据独立投票
先验是底牌，后验 = 底牌 × 各证人证词的连乘
为何朴素贝叶斯在文本分类很强？概率值不一定准，但排序常常对——而分类只需要排序。坑：属性强相关时同一信息被重复计票，后验会过度自信。
手算

拉普拉斯平滑：分子 +1、分母 +取值数，防止「没见过」被当成「不可能」

10 条瓜数据（5 好 5 坏），测试样本 x =（青绿，蜷缩，浊响，清晰）。先验 P(好) = P(坏) = 0.5；分母统一 5+3 = 8：

P(色泽=青绿|c)23/8 = 0.37523/8 = 0.375

暂停推导

自己动手：用上面的表，把两个未归一化后验得分（好瓜一行、坏瓜一行）各乘出来，再判定该判哪一类。

对答案

好瓜得分 ≈ 0.0366 ≫ 坏瓜得分 ≈ 0.0004，判好瓜，关键差别来自三个 1/8

$$\text{好瓜得分} = 0.5 \times 0.375 \times 0.625 \times 0.500 \times 0.625 \approx 0.0366$$
$$\text{坏瓜得分} = 0.5 \times 0.375 \times 0.125 \times 0.125 \times 0.125 \approx 0.0004$$
$$P(\text{好} \mid \boldsymbol{x}) \approx \frac{0.0366}{0.0366 + 0.0004} \approx \boldsymbol{0.9901} \;\Longrightarrow\; \text{判好瓜}$$
关键差别来自后三项：蜷缩 / 浊响 / 清晰在坏瓜类中计数为 0，平滑后各压到 1/8；三个 1/8 连乘直接把坏瓜得分压垮——「没见过」≠「不可能」，但也绝不是「常见」。
放松一点

SPODE：所有属性共享同一个「超父」，把一对相关性显式吃掉

$$P(\boldsymbol{x} \mid c) \;\approx\; P(x_{sp} \mid c) \prod_{i \ne sp} P(x_i \mid c,\, x_{sp}) \quad\text{（}x_{sp}\text{ 为超父属性）}$$
😇 朴素贝叶斯
敲声=浊响 与 纹理=清晰 高度相关时，同一信息被计两遍
🌱 SPODE
改为 P(纹理 | 好, 敲声=浊响)，把相关性写进条件，避免重复计票
「半」朴素的「半」：只允许一个超父属性，所有其他属性共享这一个额外依赖——既不完全独立，也不放开成任意结构（那是贝叶斯网的事）。
结构化

贝叶斯网：DAG + 「每个节点只听父母的话」，联合分布 = 各节点条件概率的乘积

flowchart TB C["感冒"] --> F["发烧"] C --> K["咳嗽"] F --> D["就医"] K --> D

同父（C→F, C→K）＋ 顺序（C→F→D）＋ 对撞（F→D←K）三结构齐聚

$$P(X_1,\dots,X_n) = \prod_{i} P\!\left(X_i \,\middle|\, \mathrm{父}(X_i)\right)$$
$$P(\text{感,烧,咳,医}) = P(\text{感})\, P(\text{烧}|\text{感})\, P(\text{咳}|\text{感})\, P(\text{医}|\text{烧,咳})$$
读法：联合概率 = 每个变量「以其父节点为条件」的概率连乘。每个变量只「听父母的话」，更远的祖先被父节点屏蔽。
三结构

同父 / 顺序：给定中间节点则独立；V 结构：给定对撞节点反而相关

flowchart TB C["C"] --> F["F"] C --> K["K"]
同父
不给 C：F 与 K 相关
给定 C：F ⊥ K
flowchart LR A["A"] --> B["B"] --> D["C"]
顺序
不给 B：A 与 C 相关
给定 B：A ⊥ C
flowchart TB F["F"] --> D["D"] K["K"] --> D
V 结构（对撞）
不给 D：F ⊥ K
给定 D：F 与 K 相关
口诀：同父、顺序「关闸」在中间——给定中间就独立；对撞「开闸」在对撞点——给定反而相关（解释消除 Explaining Away）。
判断

d-分离：路径全阻断则独立——同一张网上两个相反答案

判断 1：给定「感冒」，发烧 ⊥ 咳嗽 吗？
① 路径只有 发烧→感冒→咳嗽（同父）；② 中间节点「感冒」∈ S；③ 同父结构中间节点被给定 → 阻断；④ 所有路径阻断 ⟹ 独立。
判断 2：给定「就医」，发烧 ⊥ 咳嗽 吗？
① 路径只有 发烧→就医←咳嗽（V 结构）；② 对撞节点「就医」∈ S；③ V 结构对撞节点被给定 → 不阻断；④ 存在未阻断路径 ⟹ 不独立（解释消除）。
直觉：已知就医了，若没发烧，咳嗽的可能性就上升——两个父节点在给定共同子节点时互相「解释」，此消彼长。
隐变量

有未观测变量时似然无闭式解，EM 用「估分组 ⇄ 估参数」交替绕开

🐔 E 步（Expectation）
用当前参数算隐变量后验（责任度 γ），相当于「软指派」
🥚 M 步（Maximization）
把软指派当带权数据，做加权 MLE 重新估参数
$$\text{E 步} \to \text{M 步} \to \text{E 步} \to \cdots \;\Longrightarrow\; \text{对数似然单调不降，收敛到局部最优}$$
「鸡生蛋、蛋生鸡」：知道分组就能估参数，知道参数就能估分组。两头都不知道就先猜一头，来回修正，每步都让数据更可能。K-means 就是责任度取 0/1 的硬指派特例。
手算

一轮 EM：μ₁ 从 2 到 1.994，μ₂ 从 6 到 7.459，对数似然 −11.54 → −9.31

① E 步：算责任度（π = 0.5 约掉，σ² = 1，初值 μ₁=2、μ₂=6）

$$\gamma_1(x) = \tfrac{\varphi(x;\mu_1)}{\varphi(x;\mu_1)+\varphi(x;\mu_2)} \;\Rightarrow\; x{=}1,2,3 \text{ 几乎全属第1组},\; x{=}7,8 \text{ 几乎全属第2组},\; \gamma_1(3) \approx 0.982$$

② M 步：加权平均更新 μ（N₁ ≈ 2.982，N₂ ≈ 2.018）

$$\mu_1^{new} = \tfrac{1 \cdot 1 + 2 \cdot 1 + 3 \cdot 0.982}{2.982} \approx 1.994, \qquad \mu_2^{new} = \tfrac{3 \cdot 0.018 + 7 \cdot 1 + 8 \cdot 1}{2.018} \approx 7.459$$
$$\boldsymbol{\ell(2,6) \approx -11.54 \;\longrightarrow\; \ell(1.994, 7.459) \approx -9.31} \quad\text{—— 对数似然确实上升}$$

避坑

三个最常踩的雷：MAP 滥用、朴素贝叶斯被低估、EM 全局最优幻觉

❌ 后验概率最大就一定最优
✅ 只在 0-1 损失下成立。误分代价不对称（医疗、风控、垃圾邮件）时必须用条件风险，不能用 MAP，否则高代价错误被当低代价处理。
❌ 属性独立，所以朴素贝叶斯很烂
✅ 小数据高维稀疏（文本分类）反而常常很强——概率值不准但排序对，分类只需排序。真坑：属性强相关时信息被重复计票，后验过度自信。
❌ EM 能找到全局最优
✅ 只保证单调不降到局部最优，初值敏感；初值都取中点会塌缩成退化解。实践：多次随机初始化取最好。
