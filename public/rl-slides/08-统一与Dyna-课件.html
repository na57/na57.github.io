本章解决「学习与规划是否两回事」——留下的账是表格装不下大状态空间，归第9章。

主线

统一收编 → 经验喂出模型 → 同炉更新 → 模型会错 → 优先扫掠

1收编：深度 × 宽度 × 策略，三维坐标收编前五章
2模型：经验的第二用途，Model(s,a) ← (r, s′) 一个字典就够
3同炉：Dyna——真实与模拟经验灌进同一个更新公式
4过时：阻塞自爆、捷径失明 → Dyna-Q+ 的 $r + \kappa\sqrt{\tau}$
5聚焦：优先扫掠——TD 误差排队，更新花在刀刃上
这条链就是本章目录：8.1 统一 → 8.2 模型 → 8.3 Dyna → 8.4 模型会错 → 8.5 优先扫掠。
定义

三个维度张成设计空间：深度、宽度、策略关系

📏 更新深度
目标回望多远
1 步（TD/DP）↔ n 步 ↔ ∞（MC）
📐 更新宽度
目标对后继怎么取
采样（一个后继）↔ 期望（按概率加权和）
🎭 策略关系
学的是谁
在策略（学行为策略）↔ 离策略（学目标策略）
⚠️ 是坐标轴不是开关：期望 Sarsa 只在目标动作处取期望——宽度可以局部取值。也别指望「期望全面优于采样」：期望要模型或算力，函数逼近下还会把逼近误差焊死进估计。

骨架

所有方法共用一个更新骨架，差别只在「目标怎么造」

$$\boldsymbol{\text{新估计} \leftarrow \text{旧估计} + \text{步长} \times (\,\text{目标} - \text{旧估计}\,)}$$
方法目标的造法深度宽度
DP对模型求期望1 步期望
MC整回合回报 $G_t$∞采样
TD / Sarsa一步自举 $R + \gamma Q(S',A')$1 步采样
n 步n 步回报 $G_{t:t+n}$居中采样
骨架不动，不仅跨算法，还跨经验来源——真实与模拟经验灌进同一骨架，这就是 Dyna。
模型

表格型样本模型 = 一个字典：Model(s,a) ← (r, s′)

📊 分布模型
给出完整 $p(s',r \mid s,a)$
支持期望更新（DP 用它）
🎲 样本模型
只按概率吐出单个采样 $(r, s')$
支持采样更新，一个字典就够
$$\boldsymbol{\mathrm{Model}(s, a) \leftarrow (r, s')} \;\;\text{——确定性环境一次命中，随机环境按经验频率抽样}$$
模拟经验 = 从字典随机挑一个见过的 $(s,a)$，查出当初的 $(r,s')$——一分钱真实交互都不用花。
分工

同一条经验用两次：当场更新 Q，存进模型供日后重放

🍚 直接 RL（第5–7章）
经验当场喂更新公式
「吃一堑，长一智」
🏭 规划 Planning（本章）
经验先学模型，模型产模拟经验再更新
「把堑记下来，在脑内反复摔」
⚠️ model-based / model-free 的边界不在名册上，而在一个问题：价值的改进是否经由模型产生的经验。Dyna-Q 两条通路并行，两者都是。

演练

一条确定性链：0.5 → 0.9375 → 0.421875

① 真实经验 (C,右,+1,终止)：$Q(C) = 0 + 0.5\times(1 - 0) = \boldsymbol{0.5}$；模型记下 Model(C,右) = (+1, 终止)

② Q-planning × 3（都抽中 (C,右)，目标恒为 1）：$0.5 \to \boldsymbol{0.75} \to \boldsymbol{0.875} \to \boldsymbol{0.9375}$

$$\text{③ 真实经验 (B,右,0,C)：}\;Q(B) = 0.5\times(0 + 0.9\times 0.9375) = \boldsymbol{0.421875}\;\text{（无规划只有 }0.225\text{）}$$
✍️

洞察

Dyna 的本质：用算力换样本——真实经验点火，规划鼓风

💰 时间账本
真实交互最贵（机器人真动、用户真等）
模型内模拟几乎免费 → 用算力换样本
🔥 点火与鼓风
一份真实经验撬动 n 份额外更新
同一目标上反复迭代 ≈ 加速收敛
⚠️ 反面：鼓风吹的是模型记下的世界——模型错了，planning 越勤快错得越扎实。
陷阱

模型过时两个方向：阻塞会自爆，捷径会失明

🧱 阻塞 Blocking（环境变坏）
模型记着已堵的老路
真实反馈立刻矛盾 → 模型被纠正，自爆型
🕳️ 捷径 Shortcut（环境变好）
模型里没有的路永远不会被模拟
越规划越确定，越难偶然撞见 → 失明型
本质：误差能否自我暴露。探索的首要任务不是「纠错」，而是让未知的选项保持发言权。
补丁

Dyna-Q+：给「久违」发奖金，r + κ√τ

$$\boldsymbol{r \;+\; \kappa\sqrt{\tau}} \qquad \tau = \text{该 } (s,a) \text{ 未在真实经验中出现的步数}$$
效果：动作越久没试，规划里越诱人 → 定期重探冷门，捷径一出现就被撞上。
⚠️ 它故意让 Q 偏离当前最优——服务长期发现，不是短期收敛；且是表格型启发式，计时器要装得下。
「给不确定性发奖金」的思想通向后续探索专题：上置信界、计数奖励一脉相承。
聚焦

优先扫掠：TD 误差排队，涟漪从终点向外逐格扩散

1入队：更新后 $|\delta| > \theta$ 的 $(s,a)$ 按 $|\delta|$ 为优先级入队
2弹出：每次规划弹出优先级最高者，执行一次更新
3前驱入队：查模型找一步前驱，预测其误差，超 θ 也入队——涟漪反传
DP 地毯式扫全空间 → 优先扫掠只扫「惊讶」的前沿：TD 误差是探测器，模型（反向）是涟漪扩散的地图。
推导

涟漪全程：1.0 → 0.45 → 0.2025 → 0.091，每格恰好一次

步骤弹出更新结果前驱预测 $|\delta|$判定
①—（真实经验触发）—$|\delta_C| = 1.0$入队 1.0
②(C,右)$Q = 0.5$$|\delta_B| = 0.9\times 0.5 = 0.45$入队 0.45
③(B,右)$Q = 0.225$$|\delta_A| = 0.9\times 0.225 = 0.2025$入队 0.2025
④(A,右)$Q = 0.10125$$0.9\times 0.10125 \approx \boldsymbol{0.091}$< θ，停止
四次更新逐格反传、每格恰好一次——算力自动聚焦在「惊讶」的前沿上。
调参

θ 是灵敏度：太小退化成全空间扫描，太大等于不规划

🌊 θ → 0
门槛消失，涟漪传得又远又久
≈ 全空间反复更新，失去聚焦
🪨 θ 过大
石子落水激不起浪
队列几乎总空 ≈ 不做 planning
⚠️ 优先扫掠非普适加速器：队列维护与前驱反查有真实开销；甜头在「大状态空间 ＋ 局部变化」的任务。
对偶

学习与规划共用同一公式，差别只在经验来源

🌍 学习 Learning
用真实经验更新——经验来自环境
🧠 规划 Planning
用模拟经验更新——经验来自模型
💡 真实经验与模拟经验是同一种燃料：模型是炼油厂，Dyna-Q+ 防止油品老化，优先扫掠把油送到最需要动力的气缸。
避坑

三个最容易带走的错误直觉

❌ 「Dyna 是一个新算法」
✅ Dyna 是架构：只规定三条管线怎么接，壳里的更新公式可以是统一视图上的任何一格。
❌ 「先把模型学准再规划」
✅ 仅确定性表格环境成立；随机环境里字典模型本身有偏，闷头多学再规划会把偏差夯实——边学边规划、用真实经验持续纠偏。
❌ 「优先扫掠总是划算」
✅ 队列与前驱反查有真实开销；价值在「大状态空间 ＋ 局部变化」，小任务随机规划可能更快。

小结

三句话讲完第8章

1解决什么：用深度 × 宽度 × 策略收编前五章；回答学习与规划是否两回事
2核心机制：Dyna 双通路共用一个更新公式；Dyna-Q+ 治捷径，优先扫掠聚焦算力
3承上启下：表格方法齐备，容器装不下大状态空间——第 9 章函数逼近换容器，地图照带
$$\text{真实经验与模拟经验是同一种燃料，灌进同一个更新引擎}$$
