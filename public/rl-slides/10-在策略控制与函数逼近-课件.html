主线

从「比较动作」到「双时标」，每一步都在补上一环的缺口

1缺口：控制要在同一状态比较动作，$\hat{v}(s)$ 做不到（10.1）
2动作进特征：$\hat{q}(s,a,\boldsymbol{w})$ + ε-贪心 = 半梯度 Sarsa（10.1–10.2）
3新问题：持续任务没有终点，折扣目标随策略漂移（10.3–10.4）
4新目标：平均奖励 $r(\pi)$ + 差分回报（10.3）
5新算法：差分半梯度 Sarsa，$\boldsymbol{w}$ 与 $\bar{r}$ 双时标（10.5）
目录对应：10.1 半梯度 Sarsa → 10.2 n 步与爬山车 → 10.3 平均奖励 → 10.4 折扣失效 → 10.5 差分 Sarsa → 10.6 反驳 γ≈1。
动机

v̂ 只会打分不会选择：无模型时状态值推不出动作

🧭 预测的问题
「这个状态值多少？」—— $\hat{v}(s)$ 一个数就够，Ch9 已解决。
⚔️ 控制的问题
「在这里哪个动作最好？」—— 要在同一状态比较动作，无模型时 $\hat{v}(s)$ 无能为力。
决策的那一刻需要的是「每个候选动作各值多少」——动作必须成为函数的输入，这就是动作价值 $\hat{q}(s,a,\boldsymbol{w})$。
⚠️ 有模型时可用 $\hat{v}$ 做一步前瞻 $\max_a \sum p\,\hat{v}(s')$；无模型设定下此路不通。
定义

动作价值 = 动作进特征，所有动作共享一个 w

🗺️ 动作进特征
$\boldsymbol{x}(s,a)$ 把动作编码进特征（如每动作一段槽位），动作价值随动作可比较。
📋 共享参数 + ε-贪心
一个 $\boldsymbol{w}$ 服务所有动作（泛化白送）；决策时逐动作算 $\hat{q}$，取 max 或以 ε 探索。
$$\hat{q}(s, a, \boldsymbol{w}) = \boldsymbol{w}^\top \boldsymbol{x}(s, a) \;\approx\; q_\pi(s, a), \qquad \nabla \hat{q} = \boldsymbol{x}(s,a)$$
读法：把表格 Sarsa 的「查表项」换成 w 转置 x——one-hot 特征就是它的特例，你早就见过它。
方法

半梯度 Sarsa：表格 Sarsa 的查表项换成 wᵀx

$$\boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\, \big[\, R + \gamma\, \hat{q}(S', A', \boldsymbol{w}) - \hat{q}(S, A, \boldsymbol{w}) \,\big]\, \nabla \hat{q}(S, A, \boldsymbol{w})$$
  • 样本是五元组 $(S, A, R, S', A')$；终止态约定 $\hat{q}(\text{终止}, \cdot) = 0$；
  • 在策略：行为策略 = 目标策略 = 对 $\hat{q}$ 的 ε-贪心；
  • 「半梯度」同 Ch9：自举目标含 $\boldsymbol{w}$ 却被冻结成常数。
💡 线性时 $\nabla\hat{q} = \boldsymbol{x}(S,A)$：更新量 = $\alpha\,\delta\,\boldsymbol{x}$，朝着当前特征方向挪一步。
演练

两步回合：w 从 (0.2, 0.5) 走到 (0.35, 0.75)

① 设定：$\boldsymbol{x}(S_0,\mathrm{right})=(1,0)$，$\boldsymbol{x}(S_1,\mathrm{right})=(0,1)$；$\boldsymbol{w}_0=(0.2,\,0.5)$，$\alpha=0.5$，$\gamma=1$。轨迹：$(S_0,\mathrm{right}) \xrightarrow{R=0} (S_1,\mathrm{right}) \xrightarrow{R=1}$ 终止。

② 第 1 步：$\hat{q}(S_0)=0.2$，自举项 $\gamma\hat{q}(S_1)=0.5$，$\delta = 0 + 0.5 - 0.2 = \boldsymbol{0.3}$；$\boldsymbol{w} \leftarrow (0.2,0.5) + 0.5{\times}0.3{\times}(1,0) = \boldsymbol{(0.35,\, 0.5)}$。

③ 第 2 步：终止自举为 0，$\delta = 1 + 0 - 0.5 = \boldsymbol{0.5}$；$\boldsymbol{w} \leftarrow (0.35,0.5) + 0.5{\times}0.5{\times}(0,1) = \boldsymbol{(0.35,\, 0.75)}$。

④ 对照真值 $q(S_0)=q(S_1)=1$：w 两分量 $0.2{\to}0.35$、$0.5{\to}0.75$，都朝 1 移动 ✅

拓展

n 步回报把靶子放长，偏置–方差权衡在逼近下原样保留

$$G_{t:t+n} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^{n}\, \hat{q}(S_{t+n}, A_{t+n}, \boldsymbol{w})$$
$$\boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\, \big[\, G_{t:t+n} - \hat{q}(S_t, A_t, \boldsymbol{w}) \,\big]\, \nabla \hat{q}(S_t, A_t, \boldsymbol{w})$$
🎚️ n 大 → 偏 MC：实测占比高、方差大、更新延迟长。
🎚️ n 小 → 偏一步 TD：自举偏置大，但快、稳。
n 只调自举偏差，调不动逼近偏差——逼近偏差是特征与函数类的责任。
实战

Mountain Car：瓦片编码把「近者值近」硬编码进特征

🚗 任务：动力不足的小车要先反向荡起积蓄动能才能翻顶；状态 =（位置，速度）连续量，奖励恒 −1 直到过顶。

🧱 瓦片编码（Tile Coding）
多层彼此偏移的网格；每层点亮一格 → 稀疏二值特征；线性 $\hat{q}=\boldsymbol{w}^\top\boldsymbol{x}$ 即够用。
  • 邻近状态共享大量瓦片 → 更新自动泛化到附近；
  • 多层偏移提供分辨率——层数与粒度是泛化与分辨率的权衡；
  • ε-贪心 + n 步：Sutton 对比 $n{=}1$ 与 $n{=}8$，中等 n 学习明显更快。
本质：手工设计的「核」——用粗粒度划分换线性方法的速度、稳定与可解释性。
问题

没有终点，「总回报」发散——好的定义本身塌了

🔁 持续任务（Continuing）
服务器调度、恒温控制、常驻机器人：无终止态，交互永不停止。
🏁 回合任务（Episodic）
爬山车总会过顶：有终止态，前几节的折扣武器照用。
$$\text{若每步平均进账 } > 0:\quad \sum_{t} R_t \;\to\; \infty \quad\Rightarrow\quad \text{「总回报」无法定义「好」}$$
⚠️ 折扣 γ<1 能让回报收敛，但逼近下它的评价标准随策略漂移（10.4）——持续任务需要新目标。
定义

平均奖励 r(π)：与起点无关、与 w 无关的单一标量

$$r(\pi) = \lim_{h\to\infty} \frac{1}{h} \sum_{t=1}^{h} \mathbb{E}[R_t] \;=\; \sum_{s} \mu_\pi(s) \sum_{a} \pi(a|s) \sum_{s', r} p(s', r | s, a)\; r$$
⚖️ 稳态分布 $\mu_\pi$
策略 $\pi$ 长期运行下各状态的时间占比。
🔗 遍历性（Ergodicity）
任何状态可达任何状态 → 极限存在、与起点无关、$\mu_\pi$ 唯一。
读法：长期跑下去每步平均进账多少——它是策略的固有属性，一个干净的标量。
例子

两状态环：每两步进账 2，r(π) = 1

① 稳态分布：周期 2 确定性环 → $\mu(A) = \mu(B) = \frac{1}{2}$

② 平均奖励：$r(\pi) = 0.5 \times 0 + 0.5 \times 2 = \boldsymbol{1}$

③ 直觉检验：每两步进账 2，平均每步 1 ✓

确定性 MRP：μ 各半，与起点无关

定义

差分值只确定到常数：有意义的只是「比平均好多少」

$$G_t = \big(R_{t+1} - r(\pi)\big) + \big(R_{t+2} - r(\pi)\big) + \cdots, \qquad v(s) = \mathbb{E}\big[\, R - r(\pi) + v(S') \,\big]$$

续算两状态环：$v(A) = 0 - 1 + v(B)$；$v(B) = 2 - 1 + v(A) = 1 + v(A)$。取基准 $v(A)=0$ → $v(B)=\boldsymbol{1}$，回代 ✓

直觉：平均奖励是基准线，每步先与基准比较；全体 v 同加常数方程仍成立 → 只有相对差有意义。
清算

折扣目标的软肋：μ_π 随被评估的策略一起动

表格法函数逼近
误差目标逐状态精确表示，零误差目标明确只能最小化 $\|v_\pi - \hat{v}\|_{\mu_\pi}$ 投影误差
权重 $\mu_\pi$不影响目标定义随被评估策略改变 → 循环定义
后果「最优」无歧义两套权重下的误差无法比较，「改进」说不清
$$\text{continuing + 逼近} \;\Rightarrow\; r(\pi)\text{（单一标量）} \;;\qquad \text{episodic} \;\Rightarrow\; \gamma \lt 1 \text{ 照用}$$
方法

差分半梯度 Sarsa：γ 退休，r̄ 上岗，双时标走路

$$\delta_t = R_{t+1} - \bar{r}_t + \hat{q}(S_{t+1}, A_{t+1}, \boldsymbol{w}) - \hat{q}(S_t, A_t, \boldsymbol{w})$$
$$\boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\, \delta_t\, \nabla \hat{q}(S_t, A_t, \boldsymbol{w}), \qquad \bar{r} \leftarrow \bar{r} + \beta\, \delta_t, \qquad \beta \ll \alpha$$
🎯 δ 一肩挑两职：告诉 w 哪里比预期好，同时告诉 r̄ 基准线该往哪挪。
⏱️ 双时标：r̄ 近似冻结当锚，w 围锚快速追踪；β≪α 避免互相追逐振荡。
演练

两步更新：δ = −0.5 压 r̄ 到 0.45，δ = 1.3 又抬到 0.58

① 设定：$\boldsymbol{x}(A)=(1,0)$，$\boldsymbol{x}(B)=(0,1)$；$\boldsymbol{w}_0=(0.5,0.5)$，$\bar{r}_0=0.5$，$\alpha=0.5$，$\beta=0.1$（真值 $r(\pi)=1$）。

② $A{\to}B$（$R{=}0$）：$\delta = 0 - 0.5 + 0.5 - 0.5 = \boldsymbol{-0.5}$；$\boldsymbol{w} \leftarrow (0.25,\,0.5)$；$\bar{r} \leftarrow 0.5 + 0.1{\times}(-0.5) = \boldsymbol{0.45}$。

③ $B{\to}A$（$R{=}2$）：$\delta = 2 - 0.45 + 0.25 - 0.5 = \boldsymbol{1.3}$；$\boldsymbol{w} \leftarrow (0.25,\,1.15)$；$\bar{r} \leftarrow 0.45 + 0.1{\times}1.3 = \boldsymbol{0.58}$。

④ 方向检查：$\bar{r}\colon 0.5 \to 0.45 \to 0.58$ 朝真值 $1$ 震荡爬升；$\hat{q}(B) - \hat{q}(A) = 0.9 \approx 1$ —— 正是 $v(B)-v(A)=1$ 的形状 ✅

反驳

「γ 取 0.999 就行了」为什么不成立

1方差爆炸：有效时域 $\approx 1/(1-\gamma)$ 步；γ=0.999 → 约 1000 步奖励噪声灌进一个更新信号。
2$\mu_\pi$ 依赖不消失：循环定义源于「权重随策略变」，γ 再大也原样保留。
3最优策略不一致：折扣偏爱「先甜后苦」，只有 γ→1 的病态极限才趋于平均奖励最优。
平均奖励是 continuing 的母语，γ<1 是 episodic 的母语——用错语言不是不能表达，而是词不达意。
避坑

三颗雷：分头训练、滑动平均、n 越大越好

❌ 「每个动作单独训练一个函数」
✅ 特征是 (s,a) 的函数，所有动作共享一个 w——动作间泛化是白送的收益，拆开等于扔掉。
❌ 「r̄ 用历史奖励的滑动平均估就行」
✅ 滑动平均是行为分布下的滞后均值，与值函数不自洽；δ 驱动才让 w 与 r̄ 收敛到差分 Bellman 方程的同一组解。
❌ 「n 越大信息越全，直接取到回合结束最好」
✅ n 大偏 MC（方差大、更新慢），n 小偏一步 TD（偏置大）；Mountain Car 上中等 n 优于两端。

1解决什么：逼近下的在策略控制 + 持续任务的目标定义。
2核心机制：动作进特征 $\boldsymbol{x}(s,a)$；episodic 用半梯度 Sarsa，continuing 用差分版（δ 减 $\bar{r}$，双时标 β≪α）。
