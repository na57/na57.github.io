本章解决「一步与全程之间怎么折中」——留下的账是λ 回报的在线实现，归第12章资格迹。

主线

两端争执 → n 步回报 → 装进更新式 → 截断纠偏 → λ 回报统一

1争执：MC 无偏高方差 ↔ TD 低方差有偏，各占一端
2折中：n 步回报 = n 步真实奖励 ＋ 旧估计收尾
3算法：装进更新骨架 → n 步 TD 与 n 步 Sarsa
4离策略：重要性采样比截断到 n 步，压住连乘方差
5统一：λ 回报 = 所有 n 步目标的几何加权平均
这条链就是本章目录：7.1 光谱 → 7.2 算法 → 7.3 离策略 → 7.4 λ 回报 → 7.5 清算。
动机

MC 与 TD 不是二选一，中间隔着 2 步、3 步、任意 n 步

💵 MC 目标：全程现金
完整回报 $G_t$——无偏，但每步随机性全累加 → 方差大、等到底
🧾 TD 目标：一步现金＋全赊
$R + \gamma V(S')$——方差小、立刻更新，但旧估计误差缝进目标 → 有偏
💡 洞察：真实奖励是「现金」，自举的 $V$ 是「赊账」——n 步回报 = 收 n 步现金，再赊尾款。
定义

n 步回报：真实奖励用到第 n 步，再用估计值收尾

$$\boldsymbol{G_{t:t+n} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1} R_{t+n} + \gamma^{n}\, V(S_{t+n})}$$
🔩 n = 1
$G_{t:t+1} = R_{t+1} + \gamma V(S_{t+1})$
→ 退化为第6章 TD 目标
🏁 n ≥ 剩余步数
尾部 $V(S_T) = 0$
→ 退化为完整回报 $G_t$（MC 目标）
n 是旋钮：往小拧用偏差换方差，往大拧用方差换偏差——MC 与 TD 被统一成一家。
算例

同一条轨迹拧五次：1.7 → 0.4976 → 3.122

n计算过程目标值信息构成
1$-1 + 0.9\times 3$1.71 步真实 ＋ $V(s_1)$
2$-1 - 0.9 + 0.81\times 4$1.342 步真实 ＋ $V(s_2)$
3$-2.71 + 0.729\times 5$0.9353 步真实 ＋ $V(s_3)$
4$-3.439 + 0.6561\times 6$0.49764 步真实 ＋ $V(s_4)$
≥5$-3.439 + 0.6561\times 10$3.122全部真实，零自举
四步目标被旧估计 $V(s_4)=6$ 拉低（真实尾巴值 6.561）——自举偏差的具象化。
演练

手算四步回报：−3.439 ＋ 3.9366 = 0.4976

① 真实奖励部分：$-1 - 0.9 - 0.81 - 0.729 = -3.439$

② 自举收尾：$\gamma^4 V(s_4) = 0.6561 \times 6 = 3.9366$

$$\boldsymbol{G_{0:4} = -3.439 + 3.9366 = 0.4976} \quad\text{（对照：}G_{0:1}=1.7，\ G=3.122\text{）}$$

算法

骨架一行不动，只换目标的「真实含量」

$$V(S_t) \leftarrow V(S_t) + \alpha\,\big[\,G_{t:t+n} - V(S_t)\,\big]$$
$$\boldsymbol{Q(S_t,A_t) \leftarrow Q + \alpha\,\big[\,G_{t:t+n}^{(q)} - Q\,\big]} \;\;\text{尾部用实际采样的 } A_{t+n} \text{ 自举（on-policy）}$$
$$\text{算例（}n=5\text{）：}\;Q \leftarrow 2.0 + 0.1\times(3.122 - 2.0) = \boldsymbol{2.1122}$$
⚠️ 尾部不能随手换 $\max$——那是离策略混搭，必须纠偏（下页）。
辨析

多等 n 步是真的，「更慢」是假的——单次更新信息量大 n 倍

⏱️ 代价：n 步延迟
t 时刻的经验到 $t{+}n$ 才结算
实现：缓存最近 n 步 $(S,A,R)$，统一更新
🚀 收益：信息 ×n
一次更新消化 n 步真实奖励
19 状态随机游走实验：中等 n 学习最快
n 与步长 $\alpha$ 同级，是头等超参数，不是实现细节——选法见倒数第二页的流程。
离策略

重要性采样比只需截断到 n 步：连乘变短，方差被压住

$$\boldsymbol{V(S_t) \leftarrow V(S_t) + \alpha\,\rho_{t:t+n-1}\,\big[\,G_{t:t+n} - V(S_t)\,\big]}$$
$$\rho = 1.8 \times 0.4 \times 1.8 = 1.296 \;\Rightarrow\; \Delta V = 0.1 \times 1.296 \times 2 = \boldsymbol{0.2592}$$
ρ = 0 → 样本作废；ρ 大 → 这条更典型，一条顶几条。
⚠️ 截断非免费午餐：压住 ρ 的方差，代价是尾部自举重新引入偏差。
统一

λ 回报：不选 n，全都要——按几何权重分账

$$\boldsymbol{G_t^{\lambda} = (1-\lambda)\sum_{n=1}^{T-t-1} \lambda^{\,n-1}\, G_{t:t+n} \;+\; \lambda^{\,T-t-1}\, G_t}$$
⚖️ 权重结构
每个 n 步目标分 $(1-\lambda)\lambda^{n-1}$
末尾剩余质量 $\lambda^{T-t-1}$ 全落在完整回报上
🎚️ 两个极端
$\lambda = 0$ → 只剩一步目标（TD）
$\lambda = 1$ → 全部压在完整回报（MC）
把「选哪个 n」换成「调 λ」——几何权重把整条光谱收成一个数。
算例

λ=0.8 的权重表：末端完整回报独得 0.4096

项权重公式权重值作用对象
n=1$(1-\lambda)\lambda^0$0.2一步 TD 目标
n=2$(1-\lambda)\lambda^1$0.16两步回报
n=3$(1-\lambda)\lambda^2$0.128三步回报
n=4$(1-\lambda)\lambda^3$0.1024四步回报
末项$\lambda^4$0.4096完整回报 $G_t$
⚠️ λ=0.8 ≠ 「相信 80% 的一步回报」——最大份额在末端；纯一步要用 λ=0。
推导

五个目标按几何权重投票：λ 回报 ≈ 2.004

$$G_0^{\lambda} = 0.2{\times}1.7 + 0.16{\times}1.34 + 0.128{\times}0.935 + 0.1024{\times}0.4976 + 0.4096{\times}3.122$$
$$\boldsymbol{= 0.34 + 0.2144 + 0.1197 + 0.0510 + 1.2788 \approx 2.004}$$
落在 $0.4976$ 与 $3.122$ 之间——短 n 目标拉它向下，完整回报拉它向上，折中是加权平均的本性。
代价

前向视角要等回合结束——在线实现留给资格迹

🔭 前向视角（本章）
站在 t 时刻向前眺望整条轨迹
理论清晰，但要等回合结束，不能在线
👣 后向视角（第12章）
资格迹：边走边把 TD 误差分摊给刚路过的状态

💡 记住分工：λ 回报是目标，资格迹是实现它的引擎。
避坑

三个最容易带走的错误直觉

❌ 「n 步只是实现细节」
✅ n 是偏差–方差的工作点：不同 n 收敛速度可差数倍（随机游走实验：中等 n 最优），与 α 同为头等超参数。
❌ 「n 越大越接近 MC 越好」
✅ 无偏光环只在估计成熟后兑现；训练早期大 n 目标被漂移的旧值污染，Cliff Walking 类任务中大 n 反而吃亏。
❌ 「λ 回报和 n 步是两派方法」
✅ λ 回报 = 全部 n 步回报的几何加权平均：n 步是「选一个点」，λ 是「全都要、按权重分账」——同一世界两种表述。
工程

选 n 的实用流程：先跑通 n=1，再用学习曲线投票

1先让 TD(0) 跑通（n=1）：确认环境接口、更新代码、α 量级都对
2再试 n ∈ {2, 4, 8}：固定其他超参，画每个 n 的回报–回合数学习曲线
3比学习速度，不比渐近性能：上升最快、最早稳定者胜，不盲目追大 n
4按任务给先验：回合长、随机强 → 小 n；近确定、回合短 → 可放大 n
原则：n 是旋钮不是信仰——用学习曲线投票。
