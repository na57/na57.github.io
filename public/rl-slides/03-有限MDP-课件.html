动机

补上「动作 → 状态转移」这条边，老虎机就装不下了

🎰 上下文老虎机（Ch2）
有状态，但动作不影响下一个状态——只关心「这一步赚多少」。
♟️ 序贯决策（本章）
动作改变未来状态——「这一步赚多少」≠「这一步值多少」。
$$\text{这一步的即时奖励 } r \;\neq\; \text{这一步的长期价值 } q_\pi(s,a)$$
💡 本章方案：用马尔可夫决策过程（Markov Decision Process, MDP）把「状态 + 转移 + 奖励」说死，决策的长期后果才有得算。
定义

MDP = 三个有限集合 ＋ 一个写尽「物理定律」的动态函数

🗺️ 三个有限集合
状态集 $\mathcal{S}$、动作集 $\mathcal{A}$、奖励集 $\mathcal{R}$（三者有限 → 有限 MDP）。
⚙️ 动态函数（Dynamics）
$p(s',r\mid s,a)$：在 $s$ 执行 $a$ 后转移到 $s'$ 并得奖励 $r$ 的概率。
🔑 马尔可夫性质（Markov Property）：$p$ 只依赖 $(s,a)$，不依赖更早的历史——状态是对未来的充分统计量，知道现在，过去怎么来的无所谓。
⚠️ 马尔可夫性质不是说环境没有记忆，而是说状态已经把记忆装下了——「状态要足以决策」是建模者的责任。
例子

网格世界把 p 写具体：每个 (s,a) 的后果一目了然

情形$p(s',r\mid s,a)$ 的取值
(2,2) 走上$p((1,2),{-1}\mid(2,2),\text{上})=1$（确定性）
(1,3) 走上（撞墙）$p((1,3),{-1}\mid(1,3),\text{上})=1$，原地不动
(2,1) 走左（撞墙）$p((2,1),{-1}\mid(2,1),\text{左})=1$
(1,2) 走左（进终点）$p((1,1),{-1}\mid(1,2),\text{左})=1$，吸收态
设定：4×4 网格，终点 (1,1) 与 (4,4)，每步 −1，撞墙停原地，$\gamma=1$。框架允许随机转移（打滑 0.8/0.2 也合法）。

MDP 单步转移：p 是环境的全部「物理」，第 4 章将假定它已知。

定义

值函数 = 回报的期望：v_π 评局面，q_π 评这步棋

策略（Policy）$\pi(a\mid s)$：在 $s$ 选 $a$ 的概率分布（确定性策略是其特例）。

$$v_\pi(s)=\mathbb{E}_\pi[\,G_t\mid S_t=s\,] \qquad q_\pi(s,a)=\mathbb{E}_\pi[\,G_t\mid S_t=s,A_t=a\,]$$
📍 状态值函数（State-Value Function）
「局面分」：在 s，之后一切按 π 行事，平均拿多少回报。
🎯 动作值函数（Action-Value Function）
「这步棋分」：先强制走一步 a，之后按 π 行事，平均拿多少。
💡 值永远相对于策略：v_π 不是地图的属性，是「地图 + 走法」的共同属性。选动作用 q，描述局面用 v。
实例

随机策略的值表：每个格子 = 乱走到终点的期望步数取负

$v_\pi$列1列2列3列4
行10−14−20−22
行2−14−18−20−20
行3−20−20−18−14
行4−22−20−140
读法：$v_\pi(2,2)=-18$ → 随机乱走平均还要 18 步到终点；角落 (1,4)=−22 离终点最远。
两个终点值为 0（已结束，无更多 −1）。值函数把「延迟回报」变成每个格子上可比较的数字。
转折

「对无穷步取期望」没法算，但回报的递推结构给出出路

$$G_t = R_{t+1} + \gamma\, G_{t+1} \quad\Rightarrow\quad \text{值 = 眼前一步的收获 + 下一局面的分}$$

把拆法套进期望 $\mathbb{E}_\pi$：$v_\pi(s)$ 可由后继状态的 $v_\pi(s')$ 表示——值函数在引用它自己。

💡 定义里出现它自己，这正是「方程」的样子：未知数之间的关系被列出来了。下一页把它写完整——Bellman 期望方程。
核心

Bellman 期望方程：当前局面的分 = 一步平均收获 + 下一局面的分

$$v_\pi(s)=\sum_a \pi(a\mid s)\sum_{s',r} p(s',r\mid s,a)\bigl[\,r+\gamma\, v_\pi(s')\,\bigr]$$
🎲 外层 $\sum_a$：按策略 π 对动作取平均
🌍 内层 $\sum_{s',r}$：按环境 p 对结果取平均
q_π 平行式：$q_\pi(s,a)=\sum_{s',r}p(s',r\mid s,a)\bigl[r+\gamma\sum_{a'}\pi(a'\mid s')q_\pi(s',a')\bigr]$
Bellman 期望方程（Bellman Expectation Equation）是一致性条件，不是优化工具；未知数线性出现 → 线性方程组，可解。
演练

手算验证：v_π(2,2) 为什么正好是 −18

① 列出四方向的「即时奖励 + 下一局面的分」（γ=1，均匀随机策略各 ¼）：

  • 上 → (1,2)：$-1+(-14)=-15$　　下 → (3,2)：$-1+(-20)=-21$
  • 左 → (2,1)：$-1+(-14)=-15$　　右 → (2,3)：$-1+(-20)=-21$
$$v_\pi(2,2)=\tfrac14\times[(-15)+(-21)+(-15)+(-21)]=\tfrac14\times(-72)=\boldsymbol{-18}\ \checkmark$$
✍️
暂停推导

合上讲义，拿纸笔把四个方向各算一遍再平均，验证是否等于表中值 −18；学有余力再算带撞墙的 (1,3)。

再验一个带撞墙的 (1,3)：p 把「停原地」当普通转移

① (1,3) 四方向的 $r+\gamma v_\pi(s')$（γ=1）：

  • 上 → 撞墙停 (1,3)：$-1+(-20)=-21$　　下 → (2,3)：$-1+(-20)=-21$
  • 左 → (1,2)：$-1+(-14)=-15$　　右 → (1,4)：$-1+(-22)=-23$
$$v_\pi(1,3)=\tfrac14\times[(-21)+(-21)+(-15)+(-23)]=\tfrac14\times(-80)=\boldsymbol{-20}\ \checkmark$$
💡 撞墙 = 停原地的一次普通转移，奖励仍 −1，方程一个字不用改——撞墙、打滑、吸收态统统塞进同一个框架。

核心

Bellman 最优方程：把「按 π 平均」换成「取 max」，评价变最优

最优值函数：$v_*(s)=\max_\pi v_\pi(s)$，$q_*(s,a)=\max_\pi q_\pi(s,a)$——有限 MDP 中存在且唯一（但最优策略可不唯一）。

$$v_*(s)=\max_a \sum_{s',r} p(s',r\mid s,a)\bigl[\,r+\gamma\, v_*(s')\,\bigr] \qquad q_*(s,a)=\sum_{s',r} p(s',r\mid s,a)\bigl[\,r+\gamma\max_{a'} q_*(s',a')\,\bigr]$$
直觉：最优局面的分 = 选最好的那步棋 + 领最优的下一局面分。
⚠️ Bellman 最优方程（Bellman Optimality Equation）含 max → 非线性，不能解线性方程组，第 4 章用迭代。
实例

最优值表 = 最短路距离表：验证 v*(2,2) = −2，上左并列最优

$v_*$列1列2列3列4
行10−1−2−3
行2−1−2−3−2
行3−2−3−2−1
行4−3−2−10
验证 (2,2)，四个动作的 $r+\gamma v_*(s')$：
上 → (1,2)：$-1+(-1)=-2$　　左 → (2,1)：$-1+(-1)=-2$
下 → (3,2)：$-1+(-3)=-4$　　右 → (2,3)：$-1+(-3)=-4$
$$v_*(2,2)=\max\{-2,-2,-4,-4\}=\boldsymbol{-2}\ \checkmark$$
上、左并列最优 → 值唯一，最优策略不唯一。
洞察

拿到 q* 最优策略就是白送的；但对 v* 不能一步贪心

✅ 对 q* 一步贪心 = 全局最优
$\pi_*(s)=\arg\max_a q_*(s,a)$：q* 已把「先走 a 后全最优」的长期后果折进分数，无需额外搜索。
⚠️ 对 v* 一步贪心 = 行不通
v*(s′) 是下一局面的分；从 s 选动作必须借 p 算期望折算成 q，否则不知道哪个 a 送进好的 s′。
$$\text{有了 } q^* \Rightarrow \text{甩开模型直接查表；只有 } v^* \Rightarrow \text{还得请 } p \text{ 回来}$$
这个 v 与 q 的差别，第 6、7 章选 Q-learning / SARSA 时会反复出现——第 4 章的策略改进定理会给「贪心化」严格证明。
避坑

三个误区：值≠即时奖励，γ 是任务定义，马尔可夫是对状态的要求

❌ 值函数就是「这一格的奖励」
✅ 每步即时奖励都是 −1，但 v_π 从 −14 到 −22 不等。值是对未来全部奖励的折扣期望——v(2,2)=−18 要读成「随机走平均还要 18 步」，不是「这格扣 18 分」。
❌ γ 小是「近视的缺陷」
✅ γ 是任务定义的一部分：规定多远算远。金融风控 γ 接近 1、高频交易 γ 很小都合理——随手调 γ 等于悄悄换了优化目标。
❌ 马尔可夫假设是「作弊的简化」
✅ 它是对状态设计的要求，不是对世界的断言：影响未来的历史都该装进状态。真正的问题不是假设太强，是状态设计太懒。

小结

三句话讲完第3章

1解决什么：动作改变未来状态时，用有限 MDP（𝒮, 𝒜, ℛ, p）建模序贯决策，用值函数 v_π / q_π 把延迟回报折算成局面与动作的分。
2核心机制：Bellman 方程——期望方程是线性的一致性条件；换成 max 得非线性最优方程；对 q* 一步贪心即最优策略。
3承上启下：本章只列方程；p 已知时求解是第 4 章动态规划，p 未知时采样逼近是第 5 章起的事。
$$v_\pi(s)=\sum_a \pi(a\mid s)\sum_{s',r} p(s',r\mid s,a)\bigl[\,r+\gamma\, v_\pi(s')\,\bigr] \quad\text{——合上书也要能默写}$$
