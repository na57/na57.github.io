策略梯度方法

Policy Gradient Methods —— 不再先估值再取 max，直接对策略本身求梯度
本章要回答：能不能不经过值函数的 argmax，直接优化策略这个对象本身？
配套讲义：《强化学习互动讲义》第13章 · 基于 Sutton & Barto (2018, 2nd ed)

定位

全书收口：剪断「值函数 + argmax」的脐带，策略成为参数本身

前 12 章的策略都藏在 argmax 里；本章让 策略本身成为可微的优化对象，主线闭环。

主线

六步链：断裂 → 定理 → REINFORCE → 基线 → Actor-Critic → 代价

1断裂：连续动作 / 随机最优 / 逼近突变——argmax 翻译器三处失效。
2定理：$\nabla J \propto E[\nabla\ln\pi \cdot q_\pi]$，$\mu(s)$ 的梯度被吸收 ⇒ 无模型可估。
3REINFORCE：用采样回报 $G_t$ 顶替 $q$——无偏，但方差大。
4基线：减 $b(s)$，期望不变、方差大降（玩具例 $6.25 \to 0$）。
5Actor-Critic：学 $V$ 当基线，$\delta$ 一步自举——值函数与策略会师。
6代价：非凸、步长敏感 ⇒ 自然梯度 / 信赖域 / PPO 等前沿。
动机

argmax 翻译器的三处断裂：连续、随机、跳变

断裂点场景为什么 argmax 救不了
连续动作机械臂力矩、方向盘转角 $\in\mathbb{R}$无穷多动作，$\max_a Q(s,a)$ 是每步要现场解的非凸优化
随机最优石头剪刀布、部分可观测牌局最优策略本身必须随机；argmax 只给确定性策略
逼近突变函数逼近下的 QQ 微小变化使 argmax 跳变，策略不随参数光滑变化
对策：策略近似——直接写 $\pi(a|s,\boldsymbol{\theta})$，让 $\boldsymbol{\theta}$ 成为优化对象。离散动作用 softmax，连续动作用高斯。
设定

softmax 参数化 + 目标 J：梯度难在状态分布那层依赖

$$\pi(a|s,\boldsymbol{\theta}) = \frac{e^{h(s,a,\boldsymbol{\theta})}}{\sum_b e^{h(s,b,\boldsymbol{\theta})}},\qquad J(\boldsymbol{\theta}) = v_{\pi_{\boldsymbol{\theta}}}(s_0)$$
✅ 第一层依赖（好办）：动作概率 $\pi$ 依赖 $\boldsymbol{\theta}$——有解析式，可直接求导。
🚫 第二层依赖（要命）：状态分布 $\mu(s)$ 也依赖 $\boldsymbol{\theta}$；对 $\mu$ 求导需要环境转移模型——我们没有。

死结：$\nabla J$ 里藏着 $\nabla\mu$。下一页的定理让这项自行消失。

定理

策略梯度定理：四步推导，∇μ 在期望中被吸收

第 1-2 步：展开定义 + 乘积法则：

$$\nabla v_\pi(s) = \nabla \sum_a \pi(a|s)\, q_\pi(s,a) = \sum_a \big[ \nabla\pi(a|s)\, q_\pi(s,a) + \pi(a|s)\, \nabla q_\pi(s,a) \big]$$

第 3 步：展开 $\nabla q$（$\nabla r = 0$、$\nabla p = 0$），递归出现：

$$\nabla q_\pi(s,a) = \gamma \sum_{s'} p(s'|s,a)\, \nabla v_\pi(s')$$

第 4 步：到达概率收敛为 $\mu(s)$，$\nabla\mu$ 被期望吸收；再用 $\nabla\pi = \pi\,\nabla\ln\pi$：

$$\nabla J(\boldsymbol{\theta}) \;\propto\; \sum_s \mu(s)\sum_a \nabla\pi(a|s,\boldsymbol{\theta})\, q_\pi(s,a) \;=\; E_\pi\big[\, \nabla\ln\pi(A|S,\boldsymbol{\theta})\cdot q_\pi(S,A) \,\big]$$
按 → 逐步展开推导
解读

定理的礼物：无模型不是假设，是模型项被消掉了

1$\nabla\ln\pi$ 只涉及策略自身——有解析式，随时可算。
2$q_\pi(S,A)$ 未知——但可从采样估计（13.3 起三节的主题）。
3$\mu(s)$ 根本不出现——整个梯度无模型可估。
⚠️ 常见误区：把 $\propto$ 当 $=$。常数与 $\boldsymbol{\theta}$ 无关 ⇒ 梯度方向无偏、可上升；但理论书写时二者不能混。
算法

REINFORCE：用采样回报 G 顶替 q，无偏但方差大

$$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \alpha\, G_t\, \nabla\ln\pi(A_t|S_t,\boldsymbol{\theta})$$
✅ 为何仍无偏：$E[G_t|S_t,A_t] = q_\pi(S_t,A_t)$——$G_t$ 是 $q_\pi$ 的无偏采样，代入期望形式不改变梯度期望。
💡 直觉：回报高 ⇒ 推高该动作的对数概率；回报低 ⇒ 压。MC 哲学搬进策略空间：等整局才知好坏。
⚠️ 隐患预告：MC 回报方差大；且若回报全为正，所有被采动作都被推高——信号不干净。基线正是为此而来。
推导

手算 REINFORCE：一次正回报，Δθ 一正一负各 0.05

单状态、两动作 $L/R$；$h = \theta_L, \theta_R$，初始 $\theta_L=\theta_R=0$，$\alpha=0.1$；采样到 $R$，$G=1$。

量算式值
$\pi(R|\boldsymbol{\theta})$$e^0/(e^0+e^0)$$0.5$
$\nabla_{\theta_R}\ln\pi(R)$$1-\pi(R)$$0.5$
$\nabla_{\theta_L}\ln\pi(R)$$0-\pi(L)$$-0.5$
✋
推出来了吗？

$\Delta\theta_R = 0.1\times1\times0.5$、$\Delta\theta_L = 0.1\times1\times(-0.5)$——先心算，再翻下一步核对。

$$\Delta\theta_R = \mathbf{+0.05},\qquad \Delta\theta_L = \mathbf{-0.05} \;\Rightarrow\; \theta_R = 0.05,\ \theta_L = -0.05$$
按 → 逐步展开推导
核对

新概率 0.500 → 0.525：1−π 因子让概率天然饱和

$$\pi(R) = \frac{e^{0.05}}{e^{0.05}+e^{-0.05}} = \frac{1.0513}{1.0513+0.9512} \approx \mathbf{0.525}$$
✅ 饱和机制：$\nabla\ln\pi$ 自带 $1-\pi$ 因子——已高概率的动作推得更少，策略随参数光滑变化（回应「逼近突变」断裂）。
🚫 低效之处：回报全为正时，所有被采动作都被推高（幅度不同）——没有绝对标准，只有相对信号才干净。
病灶

REINFORCE 的两条病根：方差大，且全正回报推高一切

1方差大：$G_t$ 是 MC 回报，同状态两条轨迹可差数倍，参数被噪声来回拉扯。
2全正回报：好坏动作都被推高，只是幅度不同——缺一个「预期之内」的基准。
3处方：更新改用 $G_t - b(S_t)$，驱动力变成「比预期好多少」。
⚠️ 待证：减掉 $b(s)$ 会不会把梯度方向带歪？——下一页一行推导给答案。
基线

一行推导：基线在期望中自动消失，只改方差不改方向

$$\theta \leftarrow \theta + \alpha\,\big(G_t - b(S_t)\big)\, \nabla\ln\pi(A_t|S_t,\theta)$$
$$\sum_a b(s)\, \nabla\pi(a|s,\theta) = b(s)\, \nabla \underbrace{\sum_a \pi(a|s,\theta)}_{=\,1} = b(s)\, \nabla 1 = \mathbf{0}$$
💡 直觉：基线不问「这个动作好不好」，只问「比预期好多少」。$G-b>0$ 推概率，$<0$ 压概率——相对标准才产生干净信号。
验证

玩具实测：期望不变 −0.5，方差 6.25 → 0

采到 L（p=0.5）采到 R（p=0.5）$E$$E[\cdot^2]$$\mathrm{Var}$
无基线 $G\cdot g$$6\times(-0.5)=-3$$4\times0.5=+2$$-0.5$$0.5{\times}9+0.5{\times}4=6.5$$6.5-0.25=\mathbf{6.25}$
有基线 $(G-5)\cdot g$$1\times(-0.5)=-0.5$$(-1)\times0.5=-0.5$$-0.5$$0.25$$0.25-0.25=\mathbf{0}$
✅ 期望同为 $-0.5$：方向不变（更差的 R 被相对压下）。归零是玩具特例，机制普遍。
💡 基线越接近「该状态的期望回报」，残差越小——而那正是 $V(s)$：critic 登场的理由。
会师

Actor-Critic：学一个 V 当基线，δ 是唯一的沟通语言

$$\delta_t = R_{t+1} + \gamma V(S_{t+1};\boldsymbol{w}) - V(S_t;\boldsymbol{w})$$
$$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \alpha^{\theta}\, \delta_t\, \nabla\ln\pi(A_t|S_t,\boldsymbol{\theta}),\qquad \boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha^{w}\, \delta_t\, \nabla_{\boldsymbol{w}} V(S_t;\boldsymbol{w})$$
Actor（演员）：策略 $\boldsymbol{\theta}$，按 $\delta$ 的褒贬调整对数概率。
Critic（评论家）：价值 $\boldsymbol{w}$，学 $V$、产出基线与 $\delta$。

$E[R+\gamma V(S')|S,A] = q(s,a)$ ⇒ δ 是 $q - V$ 的单样本版 = 「比预期好多少」。

推导

手算 Actor-Critic：δ=0.5，Δθ 减半，回报被 V 逐步消化

承接 13.3（$\pi(R)=0.5$）；critic 已学 $V(s)=0.5$；本步 $R=1$、$S'$ 终止；$\gamma=1$、$\alpha^\theta=\alpha^w=0.1$：

$$\delta = 1 + 1\times 0 - 0.5 = \mathbf{0.5}$$
谁更新结果
Actor$\Delta\theta_R = 0.1\times0.5\times(1-0.5)$$\mathbf{+0.025}$（REINFORCE 是 $+0.05$：惊喜减半）
Critic$V(s) \leftarrow 0.5 + 0.1\times0.5$$\mathbf{0.55}$
再来一次$\delta = 1 - 0.55$$\mathbf{0.45}$：驱动信号自动衰减
回报被逐步「消化」进 $V$ —— 自举换来在线性：每步可更新，不等回合结束。
按 → 逐步展开推导
评价

偏差换方差：δ 有偏但在线、低方差；critic 必须学得快

✅ 换到了什么：方差远低于 MC 的 $G$；每步在线更新——TD 哲学搬进策略空间。
⚠️ 付出了什么：$\delta$ 里的 $V(S')$ 是未收敛估计 ⇒ 有偏；这是主动选择的交易。
1两个时间尺度：通常 $\alpha^w > \alpha^\theta$——critic 供基线，错一点 actor 就偏。
2偏差传染：两者共享同一行为策略的数据，critic 的偏差直接变成 actor 的系统性错推。
连续

高斯策略：不需枚举动作，只需能采样、能算 ∇lnπ

$$a \sim \mathcal{N}\big(\mu(s;\boldsymbol{\theta}),\, \sigma^2\big),\qquad \nabla_{\boldsymbol{\theta}}\ln\pi(a|s,\boldsymbol{\theta}) = \frac{a - \mu(s;\boldsymbol{\theta})}{\sigma^2}\, \nabla_{\boldsymbol{\theta}}\mu(s;\boldsymbol{\theta})$$
1$a - \mu$：采样偏离均值的方向（比均值大 ⇒ 把均值往上推）。
2$\sigma^2$：缩放——方差大则梯度小；σ 也是探索旋钮（可参数化自学）。
3$\nabla\mu$：均值对参数的敏感度。
推导

手算高斯策略：∇lnπ=0.6，Δθ=+0.03，μ → 1.03

量算式值
$\nabla_\theta\ln\pi$$(1.6-1.0)/1 \times 1$$\mathbf{0.6}$（$a>\mu$ ⇒ 均值调大）
$\Delta\theta$$0.1\times0.5\times0.6$$\mathbf{+0.03}$ → 新 $\mu = \mathbf{1.03}$
若 $a=0.7$（δ 仍正）$(0.7-1.0)$$-0.3$：均值往回拉
🚫 离散化替代方案的代价：7 关节 × 20 档 $= 20^7 \approx$ 12.8 亿个动作——维度灾难搬进动作维。高斯策略用两个参数覆盖整个实数轴。
误区

「策略梯度不需要值函数」：摆脱的是 argmax，不是值函数

说法判定准确的说法
「策略梯度不需要值函数」错定理里的 $q_\pi$ 就是值函数；摆脱的只是「argmax 翻译层」
「策略梯度收敛到全局最优」错$J(\theta)$ 一般非凸，只保证局部最优
「基线引入偏差」错基线期望恒为 0，只改方差；有偏的是自举的 δ（主动交易）
「策略梯度样本效率天然高」错恰好相反：MC 版方差大；值方法的离策略 + 回放常常更强
💡 一句话校正：策略管「怎么动」（可随机、可连续），值函数管「比预期好多少」——actor-critic 里会师，谁也不可缺席。

小结

定理消掉 μ，基线压方差，critic 供基准——策略与值会师

1解决什么：argmax 三处断裂 ⇒ 策略本身参数化，沿 $\nabla J$ 直接上升。
2核心机制：$\nabla J \propto E[\nabla\ln\pi \cdot q]$；REINFORCE → 基线（$6.25\to0$）→ Actor-Critic（$\delta$ 自举）；高斯策略开连续动作。
3毕业赠言：全书是一套拆解语法——目标 → 结构 → 估计 → 泛化 → 行动。
$$\boldsymbol{\theta} \leftarrow \boldsymbol{\theta} + \alpha\, \delta_t\, \nabla\ln\pi(A_t|S_t,\boldsymbol{\theta}) \quad\text{——合上书也要能默写}$$
毕业

毕业三问：答完这三问，全书毕业

第一问 · 预测与控制如何统一？
统一在广义策略迭代：评估与改善交替、互为对方目标。值方法的改善靠 argmax，策略梯度靠沿 $\nabla J$ 上升——MC / TD / AC 只是评估颗粒度不同的实例。
第二问 · 表格法为什么「崩」？
两层：规模崩（状态指数爆炸、无泛化）与收敛崩（逼近 + 自举 + 离策略 = 致命三角）。表格法在自己的世界里收敛得很好，「崩」是被推出自己世界的代价。
第三问 · 值方法与策略方法怎么取舍？
不取舍：值方法高效但策略被 argmax 绑架；策略方法可随机可连续但方差大、易局部最优。Actor-Critic 让值函数当 critic 降噪、参数化策略当 actor 行动——两家合流。
