动机

离策略不是可选项：三种刚需场景全是「学与做分离」

🎬 学演示数据
看专家操作录像，评估「换我来会怎样」——数据来自专家，目标是自己。
♻️ 回放旧经验
经验回放池里是几十个版本前的旧策略产生的数据——深度 RL 的标配。
🎯 Q-learning
学贪心策略、行动用 ε-贪心保持探索——学与做本来就是两个策略。
$$\text{数据来自行为策略 } b, \qquad \text{评估对象是目标策略 } \pi \;\;——\text{分布错位，更新方向就偏了}$$
定义

重要性采样比 ρ：把行为策略的经验按「稀缺度」折算到目标策略

⚖️ 重要性采样比
同状态同动作，两策略概率之比；$\pi$ 下稀罕的动作按倍计入，$\pi$ 不做的动作折算为 0。
🔧 离策略半梯度 TD(0)
在策略更新式前面乘 $\rho_t$，就完成「折算」——形式上与 Ch9 只差这一个因子。
$$\rho_t = \frac{\pi(A_t \mid S_t)}{b(A_t \mid S_t)}$$
$$\boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\, \rho_t\, \delta_t\, \nabla \hat{v}(S_t, \boldsymbol{w})$$
读法：ρ 是汇率——π 下稀罕的经验按倍计入，π 不做的动作汇率为零。
手算

一步带 ρ 的更新：w 从 0.3 涨到 0.44；若观测到 a1 则纹丝不动

设定：$b$ 对 a1/a2 各半随机、$\pi$ 必取 a2；$\hat{v}(S)=w=0.3$、$x(S)=(1)$、$\alpha=0.1$；观测 $(S, a2) \to R=1 \to$ 终止。

步骤量算式结果
1重要性采样比 $\rho$$\pi(a2\mid S)/b(a2\mid S) = 1/0.5$2
2TD 误差 $\delta$$R + \gamma\cdot 0 - \hat{v}(S) = 1 + 0 - 0.3$0.7
3更新量$\alpha\,\rho\,\delta\,\nabla\hat{v} = 0.1 \times 2 \times 0.7 \times 1$0.14
4新权重$w \leftarrow 0.3 + 0.14$0.44
💡 若观测到的是 a1：$\rho = 0/0.5 = 0$，更新量整个被乘没——目标策略从不做 a1，这条数据对评估 $\pi$ 没有信息。
转折

ρ 修的是均值，不是稳定性：方向对了照样炸

✅ ρ 修好了什么
更新方向的期望被折算到目标策略口径——均值层面无偏。
🚫 ρ 没修什么
更新的稳定性原封不动；多步连乘 $\rho$ 还会放大方差（Ch12 再面对）。
⚠️ 常见误区：以为「乘上 ρ，离策略问题就解决了」。下一节的 Baird 反例正是带着 ρ 发散的——它是必要性证明，不是充分性证明。
推导

w→2w 玩具例：放大因子 1.62 > 1，期望更新精确发散

设定：估值 $w$ 的状态以 $1-\varepsilon$ 转移到估值恰为 $2w$ 的状态（特征成比例、共享同一标量 $w$），以 $\varepsilon$ 终止；奖励全 0。按期望更新逐步计算：

$$w_{k+1} = 2\gamma(1-\varepsilon)\, w_k$$
✋
推出来了吗？

代入 $\gamma=0.9$、$\varepsilon=0.1$：放大因子是多少？大于 1 意味着什么？先心算，再翻下一步。

Baird 星形：目标策略把一切吸向中心，更新却把权重平摊给边缘

病根

期望更新矩阵含正特征值 +0.0222 / +0.2393，任何 α>0 都救不了

$$\boldsymbol{w}_{k+1} = A\,\boldsymbol{w}_k \quad\Rightarrow\quad \lambda(A) \supset \{\,+0.0222,\;\; +0.2393\,\} \;\;——\text{对应方向每步放大 } \approx 1.24 \text{ 倍}$$
🔍 先降后炸的解释
不稳定方向上的初始分量小，前 10 轮看似收敛；指数增长终将主导一切。
🚫 调小步长无用
矩阵有正实部特征值 ⇒ 任何 α>0 都发散；α 改变的只是爆炸的时间尺度（采样版 α=0.01 照样 t≈9038 炸）。
💡 对照：表格情形的更新矩阵是 $\gamma$-收缩（特征值模 <1）——逼近 + 错位把收缩改造成了放大。
确诊

致命三角：逼近 × 自举 × 离策略，三者凑齐才发散，缺一即安全

The Deadly Triad：三者叠加 ⇒ 更新矩阵出现正特征值
拆掉哪只角为何安全
去逼近（表格）Bellman 算子 $\gamma$-收缩，逐格不串扰
去自举（MC 目标）目标是真实回报，误差自喂回路断开
去离策略（在策略）更新分布与转移结构匹配，关键矩阵正定
⚠️ 前八章缺逼近、第九章缺离策略、MC 缺自举——此前平安，只因三兄弟从未凑齐。
验证

三个对照实验：各拆一角，各自收敛——缺一不可炸，实锤

对照实验拆掉的角实测过程结局

② 换 MC 目标自举t=20000，w ≈ (0.308,…,1.231,−0.615)收敛到真值

⚠️ DQN 能跑靠目标网络、巨量数据等工程稳定器——是对三角的绕行，不是理论豁免。
救场

第一个念头：直接最小化贝尔曼误差 MSBE——目标天经地义

$$\overline{\mathrm{MSBE}}(\boldsymbol{w}) = \sum_{s}\, \mu(s)\, \Big[\, \mathbb{E}\big[\, R + \gamma \hat{v}(S',\boldsymbol{w}) \mid s \,\big] - \hat{v}(s,\boldsymbol{w}) \,\Big]^2$$
📐 定义读法
「期望 TD 误差的平方」按 $\mu$ 加权；$\hat{v}$ 越接近满足 Bellman 方程，MSBE 越小。
🌩️ 坏消息预告
它看得见状态的内部墙，数据只看得见奖励流——从数据里估不出来（下页证明）。
打击

同样的数据，MSBE 一个是 0.125 一个是 0.25——贝尔曼误差不可学习

flowchart LR subgraph G1["MRP 一"] A(("A")) -->|"0.5, R=0"| B(("B 终止")) A -->|"0.5, R=1"| C(("C 终止")) end subgraph G2["MRP 二"] A2(("A'")) -->|"0.5, R=0/1"| T1(("终止")) end
MRP期望 TD 误差（$\hat{v}\equiv 0$）MSBE
一A 处 $=0.5$；B、C 处 $=0$$0.5 \times 0.25 = \mathbf{0.125}$
二A′ 处 $=0.5$$1 \times 0.25 = \mathbf{0.25}$
🚫 数据相同而 MSBE 差一倍 ⇒ 任何只看数据的估计量都无法同时等于两者——不可学习。
辨析

残差梯度最小化的是 E[δ²]，比贝尔曼误差多罚了一个方差项

$$\mathbb{E}[\delta^2] = (\mathbb{E}[\delta])^2 + \mathrm{Var}[\delta] \quad——\text{MSBE 只有前半截}$$
🌊 多罚的代价
转移与奖励的噪声也被惩罚；噪声大的转移上，宁愿牺牲期望误差也要压方差 ⇒ 最优点系统性不同。
🚫 无偏估计的门槛
估 $(\mathbb{E}[\delta])^2$ 需对同一状态采两个独立后继（double sampling）——连续状态下几乎做不到。
💡 目标函数一换，学出来的东西就变了——「直接压样本误差」不等于「满足贝尔曼方程」。
出路一

TDC：换一个可学习的目标 MSPBE，对它做真梯度下降

$$\overline{\mathrm{MSPBE}} = \|\, \Pi\, B\, \hat{v} \,\|^2_{\mu} \quad——\text{先 Bellman 更新再投影回可表示空间，可从数据一致估计}$$
$$\boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\,\rho\,\big[\, \delta\,\boldsymbol{x} - \gamma\,\boldsymbol{x}'\,(\boldsymbol{x}^{\top}\boldsymbol{v}) \,\big], \qquad \boldsymbol{v} \leftarrow \boldsymbol{v} + \beta\,\rho\,(\delta - \boldsymbol{x}^{\top}\boldsymbol{v})\,\boldsymbol{x}$$
半梯度只走了真梯度的一半；TDC 用辅助向量 $\boldsymbol{v}$ 把丢掉的投影修正项 $-\gamma\boldsymbol{x}'(\boldsymbol{x}^{\top}\boldsymbol{v})$ 补回来——线性 + 离策略也保证收敛。
实测

TDC 在 Baird 上 300 万步降到 2.103：稳定是买来的，价格是慢

$\alpha=0.005$、$\beta=0.05$，模拟实测 $\hat{v}$ 的变化：

$\hat{v}$≈3.02.9692.8322.6692.103
✅ 单调、稳定地逼近真值 0——同一个反例，不再发散。
💰 对照 MC 两万步收工：TDC 三百万步还在半路。参数翻倍 + 双时标调参 + 慢一到两个数量级。
出路二

Emphatic TD：不改目标改权重，让目标策略关心的状态嗓门更大

$$F_t = \gamma\, \rho_{t-1}\, F_{t-1} + I_t \;\; (F_{-1}=0), \qquad M_t = \rho_t\, F_t$$
$$\boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\, M_t\, \delta_t\, \boldsymbol{x}(S_t)$$
F 负责记账（目标策略到这里有多顺），M 负责放大（这一步更新喊多响）；更新分布从行为分布扭向「目标策略重视的状态」，关键矩阵重新正定。
实测

同一个 Baird、同一个 α：半梯度 t≈9038 发散，Emphatic 一万步收敛

✅ 收敛依据：更新权重换成目标策略加权占用，关键矩阵恢复正定。
💰 代价：$M_t$ 沿轨迹连乘 $\rho$，方差大、学习忽快忽慢——与 TDC 的「慢」对照着记。
正名

半梯度不是 bug：那一项是故意丢的，因为真梯度的目标不可学习

  • 故意丢：真梯度对应贝尔曼误差目标，而 MSBE 不可从数据学习（两 MRP 已证）——补了也没法用数据驱动。
  • 恰好稳：在策略下更新分布 $= d^{\pi}$，与转移结构匹配，关键矩阵正定——Ch9 的证明正建立于此。
  • 地基问题：离策略发散是目标函数的隐含收缩性失效，不是实现写错。
$$\text{出路只有两类：换目标（TDC / MSPBE）\quad 或 \quad 换权重（Emphatic）——没有「补全梯度」的第三条路}$$
误区

三个高频错觉：ρ 万能、步长救命、回放无害——全错

❌ 「乘上 ρ，离策略就解决了」
ρ 只修更新方向的期望，不修稳定性；Baird 反例正是带 ρ 发散的。
❌ 「步长调小就没事」
矩阵有正特征值 ⇒ 任何 α>0 都发散；α=0.01 的采样版照样 t≈9038 炸。
❌ 「经验回放只是把数据存起来再学」
回放 = 离策略（数据由旧策略产生），三角照样在；DQN 靠目标网络等稳定器绕行，非豁免。
接口

小结

ρ 修期望不修稳定；三角凑齐必炸；出路只有换目标、换权重

1解决什么：离策略 + 逼近下半梯度 TD 的发散事故——查清病根，给出修复。
2核心机制：致命三角 ⇒ 更新矩阵正特征值（+0.0222 / +0.2393）⇒ 指数发散；MSBE 不可学习，残差梯度多罚方差。
3两条出路：TDC 对 MSPBE 做真梯度（代价：慢，300 万步到 2.103）；Emphatic 改更新权重（代价：高方差）。
$$\rho_t = \frac{\pi}{b}, \qquad \boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\,\rho_t\,\delta_t\,\nabla\hat{v}, \qquad F_t = \gamma\rho_{t-1}F_{t-1} + I_t \quad\text{——合上书也要能默写}$$
