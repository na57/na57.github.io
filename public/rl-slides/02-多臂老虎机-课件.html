动机

你要学的只有每个臂的「身价」，可它藏在噪声后面

10 臂测试台：每个拉杆 a 有真实期望收益 $q_*(a)$，每次拉动拿到的奖励围绕它波动（方差为 1）；连拉 1000 次，目标是总收益最大。

$$R_t \sim \mathcal{N}\left(q_*(a),\; 1\right)\quad\text{——真值看不见，只看得见带噪声的奖励}$$
😇 纯贪心：永远拉当前看起来最好的
早期某个次优臂运气好，就会被锁死，最优臂永无出头之日
🙂 均匀乱试：完全不计较估值
宝贵的步数被浪费在明显差的臂上，总收益上不去
💡 本章方案：先估计动作价值，再用三种探索机制纠正「估计不可靠」
定义

q*(a) 是期望奖励，Q 只是对它的估计——两者必须分清

🎯 真实价值 $q_*(a)$（Action Value）
选动作 a 时的期望奖励；客观存在，但你永远看不见
📝 估计值 $Q_t(a)$
到时刻 t 为止对 $q_*(a)$ 的猜测；由带噪声的奖励一步步维护
$$\boldsymbol{q_*(a) = \mathbb{E}\left[\,R_t \,\middle|\, A_t = a\,\right]}$$
读法：选 a 时期望拿多少奖励。Q 最大 ≠ q* 最大——Q 最大的可能只是运气最好的，这正是贪心翻车的根源。
估计

样本均值只存两个数：新估计 = 旧估计 + 步长 × 误差

样本均值（Sample Average）：把 a 被选过的所有奖励取平均；大数定律保证 $N_t(a)\to\infty$ 时 $Q_t(a)\to q_*(a)$。实现上只需存 $(n,\,Q_n)$ 两个数。

$$\boldsymbol{Q_{n+1} = Q_n + \frac{1}{n+1}\left[R_{n+1} - Q_n\right]}$$
全书元模板：新估计 = 旧估计 + 步长 × 误差。方括号里的差是预测误差——新信息带来的惊讶程度；第 5–7 章蒙特卡洛、时序差分更新全是这个形状。
推导

增量式手算：每步只把估计往新样本方向挪一小步

① 三次奖励 1, 2, 3：$Q_1 = 1$（第一次直接取奖励）

② $Q_2 = 1 + \frac{1}{2}(2-1) = 1.5$　✓ 与 $(1+2)/2$ 一致

③ $Q_3 = 1.5 + \frac{1}{3}(3-1.5) = 2$　✓ 与 $(1+2+3)/3$ 一致

$$\text{再练：}\;Q_3=2.4,\; R_4=3 \;\Rightarrow\; Q_4 = 2.4 + \tfrac{1}{4}(3-2.4) = \boldsymbol{2.55}\quad ✓\; (2.4\times3+3)/4 = 10.2/4$$

策略

ε-贪心：九成熟客点招牌菜，一成机会随机尝鲜

贪心（Greedy）：永远选当前 Q 最大 → 早期估计不可靠，会锁死在运气好的次优臂上。最简修补：ε-贪心（ε-Greedy），ε 常取 0.01–0.1。

🍽️ 利用：概率 1−ε
选当前估计最高的动作 $\arg\max_a Q_t(a)$
🎲 探索：概率 ε
在全部动作中均匀随机选一个——包括当前最优臂
探索是均匀洒向所有臂的，不是只洒向差臂——下一页手算见分晓。
演练

10 臂、ε=0.1：最优臂被选中的概率是 0.91，不是 0.9

✍️
暂停推导

10 个臂、ε=0.1、3 号臂当前估计最高：算出 3 号臂与其余每个臂各自被选中的概率

① 利用分支：概率 0.9 → 必中 3 号臂

② 探索分支：概率 0.1 均匀洒向 10 臂 → 每臂 $0.1/10 = 0.01$（含 3 号臂）

$$P(\text{3号}) = 0.9 + 0.01 = \boldsymbol{0.91}\;;\quad P(\text{其余每臂}) = \boldsymbol{0.01}$$

非平稳

环境会变，步长就不能再用 1/n，要换恒定 α

非平稳（Nonstationary）：$q_*(a)$ 随时间缓慢漂移（用户口味在变、机器在老化）。$1/n$ 步长随 n 萎缩，学到后面几乎不更新 → 跟不上变化。对策：恒定步长 α。

$$Q_{n+1} = Q_n + \alpha\left[R_{n+1} - Q_n\right]\;\Rightarrow\; Q_{n+1} = (1-\alpha)^n Q_1 + \sum_{i=1}^{n}\alpha(1-\alpha)^{n-i}R_i$$
指数近因加权平均（Exponential Recency-Weighted Average）：旧奖励权重按 $(1-\alpha)$ 逐次衰减，近期样本主导。判定：平稳用 $1/n$（收敛无偏）；非平稳用恒定 α（能跟踪，但永不完全收敛）。
技巧

把 Q₁ 故意设成 +5，贪心自己会去探索

乐观初始值（Optimistic Initial Values）：$q_*(a)\sim\mathcal{N}(0,1)$，绝大多数在 ±2 内；把全部 $Q_1(a)$ 故意设为 +5。

  1. 首次真实奖励 ≈ 0，远低于 +5 → 该臂估值被大幅拉低（α=0.1：$Q \leftarrow 5 + 0.1\times(0-5) = 4.5$，仍虚高）
  2. 贪心立刻转向另一个还是 +5 的臂
  3. 每个臂都被「失望」轮流试一遍——探索自动发生，不需要任何随机数
⚠️ 两个硬伤：① 一次性——乐观耗尽后遇到非平稳不再探索；② 需要知道「多乐观才算乐观」。它是技巧，不是原则。
UCB

UCB 给「没把握」定价：估值项 + 置信项

$$\boldsymbol{A_t = \arg\max_a \left[\, Q_t(a) + c\sqrt{\frac{\ln t}{N_t(a)}} \,\right]}\quad\text{估值项 + 置信项；}N_t(a)=0\text{ 视为 }+\infty\text{ 必选}$$

手算：$t=11$，$\ln 11 \approx 2.3979$，$\sqrt{2.3979}\approx 1.5485$；四个臂的已选次数为 5、3、1、0：

臂$N_t(a)$置信项 $c\sqrt{\ln t / N_t(a)}$数值（以 c 为单位）
1 号5$c\sqrt{2.3979/5}=c\sqrt{0.4796}$≈ 0.6925c
2 号3$c\sqrt{2.3979/3}=c\sqrt{0.7993}$≈ 0.8942c
3 号1$c\sqrt{2.3979/1}$≈ 1.5485c
4 号0未试过，视为 $+\infty$必被选中
💡 $N$ 越小置信项越大，$\ln t$ 缓慢增长保证没有臂被永久冷落——选的是「乐观估计」最大的臂。
梯度

不估值，直接学偏好 H(a)，softmax 变成选择概率

梯度老虎机（Gradient Bandit）：跳过价值，直接学习每个动作的数值化偏好（Preference）$H_t(a)$，偏好越大被选概率越高。

$$\boldsymbol{\pi_t(a) = \frac{e^{H_t(a)}}{\sum_b e^{H_t(b)}}}\quad\text{（softmax，即玻尔兹曼分布）}$$
H 只有相对意义：全体同加一个常数，softmax 概率不变（分子分母同乘 $e^c$）——别把 H 当 Q 读。
梯度

比平均好就加分、比平均差就减分：基线 R̄ 是裁判

$$\text{被选中的动作：}\; H_{t+1}(A_t) = H_t(A_t) + \alpha\left(R_t - \bar{R}_t\right)\left(1 - \pi_t(A_t)\right)$$
$$\text{其余所有 } a \neq A_t\text{：}\; H_{t+1}(a) = H_t(a) - \alpha\left(R_t - \bar{R}_t\right)\pi_t(a)$$
基线 $\bar{R}_t$ = 到目前为止的平均奖励（增量式样本均值维护），负责判断「这步比平均好还是差」；没有它，奖励绝对值主导更新，方差大增、学习不稳（期望方向不变）。
演练

一步更新：被选中的 2 号臂概率从 0.4319 升到 0.4426

① 备料 $H=[0.30,\,0.50,\,-0.20]$：$e^{0.3}\approx1.3499$，$e^{0.5}\approx1.6487$，$e^{-0.2}\approx0.8187$，和 $\approx 3.8173$

② softmax：$\pi \approx (0.3536,\; 0.4319,\; 0.2146)$

③ 选中 2 号臂，$R=1$，$\bar{R}=0.5$，$\alpha=0.1$：$H_2 \leftarrow 0.50+0.05\times0.5681 = \boldsymbol{0.5284}$；$H_1 \leftarrow 0.30-0.05\times0.3536 = \boldsymbol{0.2823}$；$H_3 \leftarrow -0.20-0.05\times0.2146 = \boldsymbol{-0.2107}$

$$\text{新 softmax：}\;\pi' \approx (0.3460,\; \boldsymbol{0.4426},\; 0.2114)\quad\text{选中者升，其余被压}$$

半步

上下文老虎机：按上下文各记一本账，但动作不改状态

上下文老虎机（Contextual Bandit，又称关联搜索 associative search）：每时刻环境先给出上下文（状态），依据上下文选动作，只收即时奖励。策略变成 $\pi(a\,|\,s)$——每个上下文维护自己的一套 Q 或偏好。

🎯 推荐系统：用户画像是上下文，推荐内容是动作，点击是即时奖励；单次推荐基本不改变下一个到达的用户。
与完整 RL 只差一条边：动作 → 状态转移。下棋落子改变之后的局面；上下文老虎机像随机翻牌。少了这条边，就没有延迟回报、没有信度分配 → 第 3 章 MDP 把它补回来。
避坑

三颗雷：把估计当真值，把技巧当原则

❌ Q 收敛了，贪心就安全了
✅ 收敛前提是「每个臂被试无穷多次」——这是探索策略保证的，纯贪心自己破坏前提，次优臂被锁死后再无纠错机会。
❌ ε 越小越好，最好为 0
✅ ε=0 意味着永不纠错；10 臂测试台上 ε=0.1 通常显著优于 0.01 和 0——探索花掉的 10% 步数，换来锁定真正最优臂。
❌ 「哪个方法最好」有标准答案
✅ 没有。UCB 方向性探索通常占优，乐观初值在特定设定下反超，梯度老虎机动作多时更稳——按平稳性、动作数、噪声挑工具。

小结

三句话讲完第2章

1解决什么：无状态、只有动作与带噪声奖励时，估计动作价值，并在估计不可靠时决定选谁
2核心机制：新估计 = 旧估计 + 步长×误差（非平稳换恒定 α）＋ 三种探索：ε-贪心 / UCB / 梯度老虎机
3承上启下：一切建立在「无状态」上；状态回来后动作价值升级为状态-动作价值 → Ch3 MDP
