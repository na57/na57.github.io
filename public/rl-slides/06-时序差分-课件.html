Temporal-Difference Learning —— 不等回合结束，每走一步就自举更新
本章要回答：能否不等回合结束，每走一步就用自举目标更新价值？

本章解决「不等回合结束怎么更新」——留下的账是目标里一步与全程的折中，归第7章。

主线

等不起 → 走一步就更新 → δ 驱动 → 三种控制 → 清算偏差

1矛盾：MC 等回合结束，持续任务没法学、长回合方差大
2自举：走一步就更新，目标 $= R + \gamma V(S')$
3信号：TD 误差 $\delta$ = 目标 − 旧估计，驱动一切更新
4控制：Sarsa 用 $A'$、Q-learning 用 $\max$、期望 Sarsa 用期望
5清算：$\max$ 引来最大化偏差，双 Q 学习解它
这条链就是本章目录：6.1 一步自举 → 6.2 δ → 6.3–6.5 三种控制 → 6.6 误区清算。
动机

MC 的两个代价：等回合结束、整条轨迹的方差

⏳ 代价一：必须等结束
回报 $G_t$ 要到终止时刻才算得出
持续性任务没有终止态 → 永远无法更新
🌊 代价二：高方差
$G_t$ 是整条随机轨迹的累加
每个随机环节都把噪声灌进这一个数
💡 本章方案：像 MC 一样只采样一步，像 DP 一样拿旧估计自举——两家的优点各取一半。
定义

TD(0) = MC 的采样 ＋ DP 的自举，结构只差一个目标

$$\boldsymbol{V(S) \leftarrow V(S) + \alpha\,\big[\,\underbrace{R + \gamma V(S')}_{\text{TD 目标}} - V(S)\,\big]}$$
方法采样（免模型）自举（不等结束）更新目标
动态规划 DP否是对模型求期望
蒙特卡洛 MC是否完整回报 $G_t$
TD(0)是是一步 $R + \gamma V(S')$
读法：MC 说「走完再信」，DP 说「查表再信」，TD 说「走一步、信一半」——剩下的路用旧猜测顶上。
演练

一步转移，当场把 0.5 更新成 0.71

① 算 TD 目标：$R + \gamma V(S') = -1 + 0.9 \times 4.0 = 2.6$

② 算 TD 误差（目标 − 旧估计）：$\delta = 2.6 - 0.5 = \boldsymbol{2.1}$

$$\text{③ 按步长靠拢：}\;V(S) \leftarrow 0.5 + 0.1 \times 2.1 = \boldsymbol{0.71}$$
✍️
暂停推导

合上答案自己算一遍，交付物：TD 目标 2.6、δ = 2.1、新 V = 0.71

难点

δ 是意外程度，不是病灶；MC 误差 = 沿途各步 δ 的折扣和

$$\boldsymbol{\delta = R + \gamma V(S') - V(S)} \qquad V(S) \leftarrow V(S) + \alpha\,\delta$$
$$G_t - V(S_t) = \sum_{k=0}^{T-t-1} \gamma^{k}\, \delta_{t+k} \;\;\text{——MC 攒到底结算，TD 每步结算}$$
⚠️ δ 大 ≠ 学得差：δ 大说明信息量大；收敛判据是 $\mathrm{E}[\delta] \to 0$，不是每个样本的 δ 都小。
控制

Sarsa：五元组 $(S,A,R,S',A')$，学「含探索的自己」

$$\boldsymbol{Q(S,A) \leftarrow Q(S,A) + \alpha\,\big[\,R + \gamma\, Q(S',A') - Q(S,A)\,\big]}$$
🔤 名字由来
一次更新用到五元组 $(S, A, R, S', A')$，念出来即 Sarsa
🪞 在策略（On-Policy）
$A'$ 是行为策略实际选中的动作（含 ε-贪心手滑）
评估改进的就是产生数据的策略本身
On-policy 学的是「我会成为的那个我」——探索噪声被当作自身性格计入价值，天生风险敏感。
场景

Cliff Walking：贴悬崖是最短路，但每次手滑都掉下去

4×12 网格 · 每步 −1 · 最短路径约 −13 但贴悬崖
Sarsa 把「下一步可能手滑」算进价值 → 悬崖边状态被压低 → 学到绕远的安全路径。
控制

Q-learning：目标用 $\max$，盯「理想中的最优」学

$$\boldsymbol{Q(S,A) \leftarrow Q(S,A) + \alpha\,\big[\,R + \gamma\, \max_a Q(S',a) - Q(S,A)\,\big]}$$
🎯 目标策略（想学的）
纯贪心策略：$\max_a Q(S',a)$
🏃 行为策略（跑数据的）
ε-贪心——两者明确分离 → 离策略
判据只有一条：学的策略与跑数据的策略是不是同一个。Q-learning 是离策略的教科书例子。
推导

同一条转移：Sarsa 得 1.16，Q-learning 得 1.205

设定：$Q(s,a)=1.0$，$R=-1$；$s'$ 处实际选中动作值 $4.0$，$\max_a Q(s',a)=4.5$，$\gamma=0.9$，$\alpha=0.1$

① Sarsa（信实际选中的 $4.0$）：目标 $= -1 + 0.9\times 4.0 = 2.6$；新 $Q = 1.0 + 0.1\times(2.6-1.0) = \boldsymbol{1.16}$

$$\text{② Q-learning（信最优 }4.5\text{）：目标} = -1 + 0.9\times 4.5 = 3.05；\;\text{新 } Q = 1.0 + 0.1\times 2.05 = \boldsymbol{1.205}$$
差别浓缩成一个问题：目标里的下一步，按现实（我实际怎么走）算，还是按理想（最优怎么走）算？

对比

Q-learning 学到最短路，却在线表现更差——评价先定标准

🛡️ Sarsa
学到绕远的安全路径
学习期间几乎不掉悬崖 → 在线回报高
⚔️ Q-learning
学到贴悬崖的最短路径（真最优）
学习期间手滑就吃 −100 → 在线回报低
⚠️ 「Sarsa 保守所以更差」不成立：比学成后的确定性策略，Q-learning 赢；比在线学习期间的真实累积回报，Sarsa 常赢。
控制

期望 Sarsa：对下一步按策略求期望，消掉选动作的方差

$$\boldsymbol{Q(S,A) \leftarrow Q(S,A) + \alpha\,\big[\,R + \gamma\, \textstyle\sum_a \pi(a \mid S')\, Q(S',a) - Q(S,A)\,\big]}$$
$$\text{手算：}\;0.925\times 4.5 + 0.025\times(4.0+3.0+2.0) = 4.3875 \;\Rightarrow\; \text{目标} = -1 + 0.9\times 4.3875 = 2.949 \;\Rightarrow\; \boldsymbol{Q = 1.195}$$
同一转移三个目标并排：Sarsa $2.6$（采样谁信谁）＜ 期望 Sarsa $2.949$（按策略期望）＜ Q-learning $3.05$（只信最优）。

π 取行为策略 → on-policy 期望版；π 取贪心 → 退化为 Q-learning
选目标 = 在「方差、偏差、忠实于哪个策略」之间点菜——没有免费的午餐。
陷阱

对噪声估计取 max：max 的期望 ＞ 期望的 max

🎲 小算例
三个动作真值全为 $-0.1$
估计值 $+0.3,\ -0.4,\ +0.1$（无偏噪声）
$\max(\text{估计}) = \boldsymbol{+0.3}$，真实 $\max = -0.1$
🧨 机制
max 专挑「噪声最走运」的动作
→ $\mathrm{E}[\max] > \max(\mathrm{E})$，系统性高估
一切贪心化更新都在危险区，不止 Q-learning
⚠️ 病源是「噪声 ＋ max」的组合：真值已知时 max 无偏；估计带噪时 max 必偏。
解药

双 Q 学习：一张表选动作，另一张表打分

$$\boldsymbol{a^* = \arg\max_a Q_1(S',a)，\ \text{目标用 } Q_2(S', a^*)}\;\;\text{（随机轮换 } Q_1, Q_2\text{）}$$
🧪 接上例
$Q_1$ 挑出 $+0.3$ 的动作
独立的 $Q_2$ 评估它 $= \boldsymbol{-0.05}$
目标用 $-0.05$ → 正偏差消除
⚖️ 代价与传承
内存翻倍、每张表只吃一半数据
函数逼近时代回归为 Double DQN
直觉：挑中和打分用两套独立噪声，「挑中走运者」的运气传不进分数。
避坑

三个最容易带走的错误直觉

❌ 「TD 比 MC 准」
✅ MC 目标无偏方差大，TD 目标有偏方差小——这是偏差–方差权衡的两端，没有绝对赢家；第 7 章 n 步方法在这条曲线上自由移动。
❌ 「Q-learning 用了 max，所以是 on-policy」
✅ 判据只有一条：目标策略与行为策略是否同一个。Q-learning 目标纯贪心、行为 ε-贪心，明确分离——离策略的教科书例子。
❌ 「TD 收敛了就是学对了」
✅ 仅在表格型 ＋ 适当步长下成立；自举 ＋ 函数逼近 ＋ 离策略三者叠加成「致命三联」，第 9 章起要重新审查。

1解决什么：不等回合结束，每走一步就用自举目标更新价值
