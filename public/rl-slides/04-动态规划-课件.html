主线

模型已知 → 方程变更新规则 → 评估与改进交替逼近最优

1模型 p 已知，Bellman 方程组在数学上可解（第3章的账）
2把 Bellman 等式改写成更新规则：等号「=」读成赋值「←」
3策略评估：固定 π，迭代求 v_π
4策略改进：对 v_π 贪心，得到更好的 π′
5策略迭代：评估与改进交替，直到改进不动
6值迭代：把评估压成一步，max 合并两动作
7账单：全程要完整模型 p → 第5章起无模型
4.1

把等号「=」改读成赋值「←」，压缩映射保证收敛

🔁 等式 → 更新规则
动态规划（Dynamic Programming, DP）的核心动作只有一步：等式 v = T(v) 变迭代 v ← T(v)，反复逼近不动点。
📉 压缩映射（Contraction）
Bellman 算子每作用一次，与真值的最大误差至少缩 γ 倍 → 几何衰减 → 必然收敛。
🔁 自举（Bootstrapping）：用当前估计值去更新另一个估计值——不等真实回报走完，先拿「下一局面的当前估值」顶上。DP 全程自举。
⚠️ 两个前提：动态函数 p 完全已知（每个 Σp 都真算出来）；状态空间可用表格枚举。
4.2

策略评估：把 Bellman 期望方程改写成迭代更新

策略评估（Policy Evaluation）= 预测问题：给定 π，求 v_π。

$$V_{k+1}(s)\leftarrow\sum_a\pi(a|s)\sum_{s',r}p(s',r|s,a)\left[r+\gamma V_k(s')\right]$$
  • 从 V₀ = 0 起，逐轮扫描（sweep）所有状态，每轮用上一轮的值整体更新
  • 直到最大变化量小于阈值，即收敛到 v_π
💧 信息流图像：终点值 0 是「水源」，值像水波每轮向外扩一格——这就是自举的物理图像。

4.3

对 v_π 贪心化必不差：一步不亏 ⟹ 步步不亏

改进做法：每状态选 $\arg\max_a q_\pi(s,a)$（对 v_π 贪心化）。

$$\text{策略改进定理：}\quad q_\pi(s,\pi'(s))\ge v_\pi(s)\ \ \forall s \;\;\Longrightarrow\;\; v_{\pi'}(s)\ge v_\pi(s)\ \ \forall s$$
读法：策略改进定理（Policy Improvement Theorem）——既然「先走一步更优的 a、之后照旧」都不亏，那永远这么走只会更好：一步不亏 ⟹ 步步不亏。
✅ 判据：贪心化后策略不再变化 ⟹ π 已满足 Bellman 最优方程 ⟹ π = π*。「改进不动」就是最优性判据。

4.4

策略迭代：评估与改进交替，有限步必收敛到 π*

求 v_π"] EV --> IM["策略改进
对 v_π 贪心"] IM -->|"改进成功"| EV IM -->|"改进不动"| DONE["π = π* 停止"] classDef hot fill:#fffaf0,stroke:#dd6b20,stroke-width:2.5px,color:#744210; class DONE hot;

策略迭代（Policy Iteration）收敛依据：策略数量有限 ＋ 每轮严格改进 ⟹ 有限步登顶。

⏳ 抱怨：每轮内嵌一次完整策略评估（多轮 sweep），太贵——值迭代冲着这点来。
4.4

值迭代：把评估压成一轮，max 把评估与改进合并

值迭代（Value Iteration）= 直接把 Bellman 最优方程改写成更新：

$$V_{k+1}(s)\leftarrow\max_a\sum_{s',r}p(s',r|s,a)\left[r+\gamma V_k(s')\right]$$
  • 式子里没有显式策略：max 合并了评估与改进；收敛后对 V* 贪心即得 π*
  • 每次更新都假装「下一步已经走最优」
🎚️ 同一谱系的两端：评估跑无穷轮再改进 = 策略迭代；只扫一轮 = 值迭代。评估轮数是一个旋钮，不是两种算法。
演练

2×2 网格值迭代：两轮收敛，V(2,2) 走到 −2

终点 (1,1)，每步 −1，γ=1，撞墙停原地，V₀ 全 0；非终点：(1,2)、(2,1)、(2,2)。

① 第 1 轮：每个动作的 $[r+\gamma V_0(\text{邻})]$ 全为 −1+0，max = −1 → 三格全 −1。

② 第 2 轮：(1,2) 左→终点：−1+0=−1 为 max（走左）；(2,1) 对称 max = −1（走上）；(2,2) 上/左/撞墙全 −1+(−1)=−2，max = −2。

③ 第 3 轮：值不再变化，收敛。$V(2,2):\ 0\to-1\to-2\to-2$（恰为到终点最少步数取负）。

④ 提取策略：对 V* 贪心，(2,2) 的上与左 q 同为 −2，并列最优，任选其一即最优策略。

4.5

异步 DP 松绑扫描顺序，GPI 统一几乎所有 RL 算法

🔀 异步 DP（Asynchronous DP）
任意顺序/频率更新，只要每状态被无限次更新即收敛；把计算花在重要状态上 → 第8章优先级清扫。
广义策略迭代（Generalized Policy Iteration, GPI）：评估与改进两过程互相推搡，同时停在最优——几乎所有 RL 算法都是 GPI。

边界

维数灾难：DP 是思想模板与理论基准，不是主流实用方法

⚠️ 维数灾难（curse of dimensionality）：计算按「状态数 × 动作数」计价，而状态数随变量个数指数增长——10 层楼电梯调度的状态就已爆炸。这是表格法的天花板，不是实现问题。
🧭 公允定位：DP 的真正价值是思想模板——评估/改进交替（GPI）、自举更新、贪心化，第5–8章原样继承，只把精确期望换成采样估计。
💬 「DP 需要模型，所以不是无模型方法」——这不是贬低，是分类。第9章函数逼近就是冲着维数灾难来的。
避坑

本章最容易错的三件事

❌ 「DP 是 RL 的主流实用方法」
✅ DP 要完整模型 p，而 RL 主战场是模型未知；DP 是思想模板与理论基准，不是上场选手。
❌ 「值迭代是独立于策略迭代的另一种算法」
✅ 值迭代 = 策略评估只扫一轮的策略迭代；max 里隐含着每轮的贪心改进——同一谱系（评估轮数旋钮）的两端。
❌ 「自举是用猜测更新猜测，不靠谱」
✅ 压缩映射保证误差几何衰减、不累积；真正的问题在模型——无模型方法的自举还要叠一层采样噪声（第6、7章处理）。

小结

三句话讲完第4章

1解决什么：p 已知时，把 Bellman 方程从「定义」变成「算法」，算出值函数与最优策略。
2核心机制：等号改读成赋值（压缩映射保证收敛）；评估求值、改进定理保证贪心不亏；交替 = 策略迭代，压成一轮 = 值迭代。
3承上启下：留下 GPI、自举、贪心化三大模板；每个更新都含精确期望 Σp → 第5章用采样替代。
$$V_{k+1}(s)\leftarrow\sum_a\pi(a|s)\sum_{s',r}p\left[r+\gamma V_k(s')\right] \quad\text{与}\quad V_{k+1}(s)\leftarrow\max_a\sum_{s',r}p\left[r+\gamma V_k(s')\right]\;\;\text{——合上书也要能默写}$$
本 章 结 束
