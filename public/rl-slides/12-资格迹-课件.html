光谱已有（Ch7）、参数化已有（Ch9-11）；本章补的是每步可执行的多步信用机制。

主线

五步链：旋钮 → 定义 → 机制 → 控制 → 代价

1动机：MC 与 TD(0) 是两端，n 步回报是离散选项——要连续旋钮 λ。
2定义：λ 回报 $G_t^\lambda$——前向视角，规定「该学什么」，但不能在线执行。
3机制：资格迹 $e_t(s)$ 按 $\gamma\lambda$ 衰减记账，$\delta_t$ 沿迹回传——TD(λ) 上线。
4控制：Sarsa(λ) 记 $(s,a)$ 的迹；Watkins Q(λ) 偏离贪心即切断（$E[L]=9$ 步）。
5代价：逼近 + 在线下前后向等价失效 ⇒ 荷兰迹；致命三角仍是前提。
💡 一句话预告：资格迹是把多步信用分配改写成一个每步可维护的记账系统。
动机

不选 n 了：把「看多远」从整数档位变成连续旋钮

✅ MC（等到底）
完整回报 $G_t$：无偏，但方差大、必须等回合结束。
✅ TD(0)（看一步）
$R+\gamma V(S')$ 自举：方差小、每步可更新，但有偏。

Ch7 的 n 步回报 $G_{t:t+n}$ 说明两端之间有整排折中——但仍要离散地选 n。

关键一跃：λ 不是「看几步」，而是「每多看远一步，重要性就打一次 λ 折」。λ 是偏差—方差旋钮，0 与 1 是两个端点，中间连续。
定义

λ 回报：所有 n 步回报的几何加权，残差归完整回报

$$G_{t:t+n} = R_{t+1} + \gamma R_{t+2} + \cdots + \gamma^{n-1}R_{t+n} + \gamma^{n}\hat{v}(S_{t+n})$$
$$G_t^\lambda = (1-\lambda)\sum_{n=1}^{T-t-1}\lambda^{n-1} G_{t:t+n} \;+\; \underbrace{\lambda^{\,T-t-1} G_{t:T}}_{\text{终止残差}}$$
📎 呼应 Ch7 算例：$\lambda=0.8$、$T-t=5$ 时权重 $0.2/0.16/0.128/0.1024/0.4096$，算得 $G^\lambda \approx \mathbf{2.004}$，落在 $0.4976$ 与 $3.122$ 之间。
⚠️ $G_t^\lambda$ 是前向视角的分析工具：算它要看到未来全部回报、还要知道何时终止——它定义理想目标，本身不能在线执行。

手算权重：λ=0.5、还剩 4 步，四项权重恰好凑成 1

检验

端点检验：λ=0 退回 TD(0)，λ=1 退回 MC

λ权重分布退化为性质
$\lambda = 0$全部压在 $n=1$TD(0)一步自举，方差小、有偏
$0 < \lambda < 1$几何衰减铺开连续折中族偏差—方差旋钮
$\lambda = 1$中间全 0，残差 $=1$MC完整回报，无偏、方差大
⚠️ λ 回报是前向视角：定义「理想目标」的数学对象，不是可在线执行的算法——变成算法要靠下一节的资格迹。
机制

资格迹：γλ 折旧的短期记忆，TD 误差沿迹回敬

$$e_0(s)=0,\qquad e_t(s) = \gamma\lambda\, e_{t-1}(s) + \mathbb{1}\{S_t = s\}$$
$$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t),\qquad V(s) \leftarrow V(s) + \alpha\,\delta_t\, e_t(s)\ \ (\forall s)$$
γλ 两职责：γ 折扣目标里的远期回报；λ 衰减旧访问的责任。别混成 λ 一个。
✅ 迹是「责任额度」：误差出现时，按额度付账；误差不出现，迹立着也不更新。

对比

0.05 落在 0 与 0.10 正中间：前向视角与后向视角的一枚硬币

算法$V(A)$$V(B)$为什么
TD(0)00.10只更新当前状态 B
TD($\lambda{=}0.5$)0.050.10A 按迹 0.5 拿一半责任
MC（$\lambda{=}1$）0.100.10A 的迹不衰减，全额更新
前向 = 后向（表格 + 离线 + 每局批量）：用 λ 回报算目标 ≡ 用迹每步回传 δ。三个限定词缺一不可——12.5 节将看到逼近 + 在线下它失效。
变体

累积迹叠加责任，替换迹只记最近一次访问

更新规则性质对应
累积迹$e \leftarrow \gamma\lambda e + 1$重复访问可 $>1$，责任叠加精确对应 λ 回报
替换迹访问时 $e \leftarrow 1$只记最近一次，实践更稳近似对应 λ 回报
⚠️ 回传的载体是 TD 误差 δ（含自举估值），不是奖励；迹只决定分配比例。直觉：沙滩脚印，γλ 是潮水冲刷的速度。
控制

Sarsa(λ)：迹升到状态—动作对，误差照旧是 Sarsa 的

$$e_t(s,a) = \gamma\lambda\, e_{t-1}(s,a) + \mathbb{1}\{S_t{=}s, A_t{=}a\}$$
$$\delta_t = R_{t+1} + \gamma Q(S_{t+1},A_{t+1}) - Q(S_t,A_t),\qquad Q(s,a) \leftarrow Q(s,a) + \alpha\,\delta_t\, e_t(s,a)$$
💡 同一轨迹代入，数字不变：$\delta_1=0$、$e(A,\text{右})=1$；$\delta_2=1$ 时 $Q(A,\text{右})$ 得 $0.05$、$Q(B,\text{左})$ 得 $0.10$。Sarsa(λ) = Sarsa 的误差 + TD(λ) 的记账本。
细节

迹记的是「实际执行的动作」——探索动作同样留痕

✅ 后果：Sarsa(λ) 评估的是带探索的行为策略——与 Sarsa 的 on-policy 本性一致。
🚫 想要贪心目标的价值？那是离策略：行为与目标分家，历史迹无法再用贪心目标解释。
矛盾成形：一条迹代表「执行过的动作负过的责任」，可 Q-learning 的目标策略根本没执行过那些动作——凭什么用贪心目标更新它们？

Watkins 的答案：最保守、也最粗暴——切断。下一页。

离策略

Watkins Q(λ)：行为一偏离贪心，全部迹清零

$$\text{若 } A_{t+1} = \arg\max_a Q(S_{t+1},a)\ \Rightarrow\ \text{正常更新};\qquad \text{否则 } e(s,a) \leftarrow 0\ \text{（全部切断）}$$
💡 直觉：脚印一旦离开目标路线，整串作废——信用链断开重来。
⚠️ 切断是正确性要求，不是省计算：继续用贪心目标更新探索路径 = 分布错配（与 Ch7 树回溯 / 重要性采样同源）。

代价随即而来：迹能活多久？下一页算给你看。

代价

ε=0.1 时迹平均只活 9 步：长程信用名存实亡

ε-贪心、$\varepsilon=0.1$、贪心动作唯一：每步踩中贪心的概率 $\approx 1-\varepsilon = 0.9$；迹连续存活 $L$ 步的概率 $= 0.9^L$。

$$E[L] = \frac{0.9}{1-0.9} = \mathbf{9\ \text{步}}$$
🚫 λ 的长程信用在离策略下名存实亡——这是 Q(λ) 相对 Sarsa(λ) 优势缩水的根本原因，也是树回溯 Q(λ) 出现的原因。
✅ 选 Q(λ) 的理由不是「更先进」，而是你确实需要离策略（旧数据、人类示教）。
裂缝

逼近 + 在线 + 策略在变：前后向等价的三个保护条件全破

1函数逼近：权重 $\boldsymbol{w}$ 被所有状态共享，一处更新处处牵连。
2在线更新：每步用当前 $\boldsymbol{w}$ 算 δ，而迹是旧 $\boldsymbol{w}$ 时代记下的方向。
3策略在变：评估对象本身在移动，错位持续累积。
🚫 后果：普通 TD(λ) 的每步更新 ≈ λ 回报更新，不再精确相等——系统性错位。
💡 病根不是迹错了，是记账口径随 w 漂移；修法：把重复计入的那笔账扣掉。
修复

荷兰迹：扣掉「这笔账会改变未来记账口径」的重复部分

$$\boldsymbol{e} \leftarrow \gamma\lambda\,\boldsymbol{e} + \underbrace{\left(1 - \alpha\gamma\lambda\, \boldsymbol{e}^{\top}\boldsymbol{x}\right)}_{\text{标量修正}}\, \boldsymbol{x}$$
✅ 真实在线 TD(λ)：每步更新量 恰好等于「此刻终止时对当前 $\boldsymbol{w}$ 施加 λ 回报更新」的量（线性情形精确；普通 TD(λ) 只是近似）。
⚠️ 代价：每步多一次内积；干净解释只对线性成立。它修的是等价性，不解决致命三角——Ch11 的收敛条件仍是前提。
误区

「资格迹只是加速技巧」：表格下勉强对，逼近下错

说法判定准确的说法
「迹只是加速，答案不变」表格下勉强对
逼近下错		表格中各 λ 同收敛到 $v_\pi$，只改瞬态速度；逼近下 λ 改变不动点（优化目标本身）
「迹把奖励反向传播」错回传的是 TD 误差 δ；迹只决定每个状态分到多少
「λ 越大越好」错λ 大 → 方差大；λ 小 → 偏差大。旋钮不是越大越好
「迹可免费替代回放」错迹只留责任额度，不留原始样本，无法重复利用旧数据
💡 一句话校正：迹把多步信用分配改写成每步可维护的记账系统——改变的是记在谁头上、记多久。
接口

三个工程旋钮：λ 怎么选、在线语义怎么保、离策略怎么办

1选 λ：稀疏奖励 + 长回合 ⇒ 偏大（0.8–0.95）；稠密高噪 ⇒ 偏小。默认 0.9 + 替换迹起步。
2保语义：要每步在线更新 ⇒ 用迹；要精确等价语义（线性逼近）⇒ 上荷兰迹。
3离策略：别指望 Watkins（$E[L]=9$）；优先树回溯 Q(λ)，或回 Ch11 的 ρ + 梯度 TD 组合。
➡️ 下一站 Ch13 策略梯度：本章没动「值函数 + argmax」这条路线；下一章把翻译器整个拆掉，直接优化策略。
小结

λ 回报定目标，资格迹管记账，前后向等价有保护期

1解决什么：离散选 n ⇒ 连续旋钮；整局回溯 ⇒ 每步在线更新。
2核心机制：$G^\lambda$ 定目标 + $e$ 按 $\gamma\lambda$ 记账 + δ 沿迹回传；表格离线下前向 ≡ 后向（$\Delta V(A)=0.05$ 居中为证）。
3边界：Sarsa(λ) 记探索；Watkins 切断 $E[L]=9$；逼近在线下靠荷兰迹，致命三角仍是前提。
$$e_t \leftarrow \gamma\lambda\, e_{t-1} + x_t,\qquad \boldsymbol{w} \leftarrow \boldsymbol{w} + \alpha\,\delta_t\, e_t \quad\text{——合上书也要能默写}$$
