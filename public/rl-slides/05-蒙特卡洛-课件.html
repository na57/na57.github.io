蒙特卡洛方法

Monte Carlo Methods —— 没有模型，就拿经验平均当价值
本章要回答：环境模型完全未知、只能一条一条经历回合时，如何估计价值并改进策略？
配套讲义：《强化学习互动讲义》第5章 · 基于 Sutton & Barto (2018)

本章解决「没有模型怎么估计价值」——代价是等回合结束、方差大，留给第6章。

主线

没有模型 → 跑回合拿回报 → 平均 → 探索 → 纠偏

1矛盾：DP 要完备模型，现实只有一条条回合
2样本：跑完整回合，从终点倒推出回报 $G_t$
3估计：平均多条回合逼近 $v_\pi$，增量均值省存储
4控制：改进要靠 $q(s,a)$，探索保证每个动作被试到
5纠偏：数据来自行为策略，用重要性采样比 $\rho$ 加权
这条链就是本章目录：5.1 矛盾 → 5.2 回报与均值 → 5.4 控制与探索 → 5.5 离策略纠偏。
动机

DP 的软肋：每一次更新都要对模型求期望

$$v_\pi(s)=\sum_a \pi(a\mid s)\sum_{s',r} p(s',r\mid s,a)\,\big[\,r+\gamma\, v_\pi(s')\,\big]\;\;\text{——\,$p(s',r\mid s,a)$ 从哪来？}$$
🃏 打扑克
你不知道对手的发牌与出牌分布，模型无从写起
🤖 机器人行走
写不出「关节力矩 → 下一姿态」的转移函数
💡 本章方案：看着地图规划行不通，就亲自走几趟再下结论——跑出完整回合，拿回报平均。
定义

蒙特卡洛 = 完整回合 ＋ 样本平均，不是新算法而是估计哲学

🎬 部件一：完整回合
$S_0,A_0,R_1,S_1,A_1,R_2,\dots,S_{T-1},A_{T-1},R_T$
必须跑到终止，才知道这条轨迹值多少
📊 部件二：样本平均
期望算不出来 → 抽样取平均
大数定律保证样本均值收敛到期望
$$\boldsymbol{v_\pi(s)=\mathrm{E}_\pi[\,G_t \mid S_t=s\,]\;\approx\;\frac{1}{n}\sum_{i=1}^{n} G^{(i)}(s)}$$
读法：价值的定义是「期望回报」；期望算不出来，就跑 n 条回合，把回报平均。
例子

5×5 gridworld：一条固定轨迹，8 步，前 7 步各 −1、末步 +10

设定项取值
起点 / 终点(1,1) / (5,5)
每步奖励−1（进终点 +10 结束）
折扣因子$\gamma = 0.9$
被评估策略先一路向右，再一路向下
前四章用 4×4 便于手推 Bellman；第 5–7 章改用 Sutton 原书的 5×5，数字与原文对齐。
flowchart LR A["(1,1) 起点"] -->|"4 步 · 各 −1"| B["(1,5) 右转"] B -->|"4 步 · 末步 +10"| C["(5,5) 终点"]

傻瓜策略的固定轨迹：共 8 步，回报从终点倒推

推导

回报从终点往回倒推：每一步只做一次乘加

① 工具：回报递推式（终止后 $G_T = 0$）

$$G_t = R_{t+1} + \gamma\, G_{t+1}$$

② 从终点开始：$G_7 = 10$，$G_6 = -1 + 0.9 \times 10 = 8$，$G_5 = -1 + 0.9 \times 8 = 6.2$

③ 一路倒回起点：$G_4 = 4.58$，$G_3 = 3.122$，$G_2 = 1.8098$，$G_1 = 0.62882$

$$\boldsymbol{G_0 = -1 + 0.9 \times 0.62882 = -0.434062 \approx -0.434}$$

每个数都满足「$-1 + 0.9 \times$ 后一个数」——确定性环境下每条回合相同；一旦有随机性，不同回合给出不同 $G$，「平均」才真正上场。
估计

增量均值：新估计 = 旧估计 ＋ 步长 ×（目标 − 旧估计）

$$\boldsymbol{V_n = V_{n-1} + \frac{1}{n}\,\big(\,G_n - V_{n-1}\,\big)}$$
$$\text{手算：}\;V_2 = -0.434 + \tfrac{1}{2}\times\big(2.2-(-0.434)\big) = -0.434 + 1.317 = \boldsymbol{0.883}$$
$\alpha=\frac{1}{n}$ 只适用平稳环境；控制问题里策略一直在变（移动靶），换常数 $\alpha$（如 0.1）——用「永不收敛」换「永远跟踪」。
定义

同一状态两次相遇：只取第一次，还是每次都算？

1️⃣ 首次访问 MC（First-Visit）
只用第一次到达 $s$ 之后的回报
样本定义干净，理论证明都以它为对象
🔁 每次访问 MC（Every-Visit）
每次到达 $s$ 后的回报都计入
样本重叠相关，但有时更易实现
flowchart LR A1["A (t=0)"] --> B1["B (t=1)"] --> A2["A (t=2)"] --> C1["C (t=3)"] --> T["终止"]
奖励序列 $-1,-1,-1,+10$，$\gamma=0.9$
状态 A 一回合内被访问两次
演练

同一条回合，两种方法给出 4.58 与 6.29 两个估计

① 倒推：$G_3 = 10$；A 第二次访问 $G_2 = -1 + 0.9\times 10 = 8$

② 继续：$G_1 = -1 + 0.9\times 8 = 6.2$；A 第一次访问 $G_0 = -1 + 0.9\times 6.2 = 4.58$

$$\text{首次访问：}\;V(A)=4.58 \qquad \text{每次访问：}\;V(A)=\frac{4.58+8}{2}=\boldsymbol{6.29}$$
✍️

控制

没有模型做不了前瞻，贪心改进只能直接估计 q(s,a)

沿用 GPI 框架，但改进一步没有模型可用：

$$\boldsymbol{\pi'(s) = \arg\max_a\, q(s,a)}$$
有模型：用 $v$ 和 $p(s',r\mid s,a)$ 算一步前瞻；无模型：只能直接估计每个动作的 $q(s,a)$ 再取 $\arg\max$。
flowchart LR E["评估当前策略
估计 q"] --> I["贪心改进
得到新策略"] --> E
MC 版 GPI：评估与改进转圈，直到收敛
探索

估计 q 的前提是每个 (s,a) 都被试过——三条出路

  • 探索性开端（Exploring Starts）：每条回合从随机 $(s,a)$ 出发——简单，但很多任务做不到
  • ε-贪心（on-policy）：$1-\varepsilon$ 选最优、$\varepsilon$ 随机；让 $\varepsilon \to 0$ 即 GLIE，收敛到最优
  • 离策略（off-policy）：跑数据的策略与要学的策略分家——下一页的主题
💡 MC 控制的死穴不在「平均」，而在「覆盖」：估计准不准是统计问题，有没有数据是存在性问题。
离策略

用别人的数据学自己的策略：逐动作概率比连乘纠偏

🎯 目标策略 $\pi$
要学、要评估的策略（通常贪心）
🏃 行为策略 $b$
实际跑数据的策略（更随机，保证覆盖）
$$\boldsymbol{\rho_{t:T-1} = \prod_{k=t}^{T-1} \frac{\pi(A_k \mid S_k)}{b(A_k \mid S_k)}}$$
环境转移概率在分子分母中一模一样，全部约掉——这就是离策略「免模型」的关键。
推导

一个比率、两种估计：普通 IS 得 20，加权 IS 得 10

① 算比率：$\pi$ 确定选 $a_1$，$b$ 各半。两步都选 $a_1$：$\rho = \frac{1}{0.5}\times\frac{1}{0.5} = 4$；一步选 $a_2$：$\rho = 0$

② 普通 IS（分母 = 样本条数）：$\dfrac{4\times 10 + 0\times(-6)}{2} = \dfrac{40}{2} = \boldsymbol{20}$ —— 超出已见回报范围！

③ 加权 IS（分母 = 权重和）：

$$\boldsymbol{V(s) = \frac{4\times 10 + 0\times(-6)}{4 + 0} = \frac{40}{4} = 10}$$

难点

20 不是 bug：无偏 ≠ 好用，好坏看均方误差

📏 普通 IS
无偏，期望恰为 $v_\pi$；但方差可爆炸，单次估计飞出已见范围（如 20）
🧭 加权 IS
有偏（分母随机），偏差随样本消失，方差小得多——实践几乎总是首选
$$\text{均方误差} = \text{偏差}^2 + \text{方差}\;\;\text{——别只盯偏差那一项}$$
$\rho$ 是连乘积：轨迹越长越容易爆炸，长回合是离策略 MC 的阿喀琉斯之踵。
避坑

三个最容易带走的错误直觉

❌ 「蒙特卡洛是一种新算法」
✅ 它是估计哲学：用样本平均替代期望。预测、控制都能套，第 6、7 章都在它上面做时间维度的折中。
❌ 「无偏，所以普通 IS 一定更好」
✅ 好坏看均方误差 = 偏差² + 方差；普通 IS 无偏但方差爆炸（估计 20 飞出范围），加权 IS 几乎总是首选。
❌ 「重要性采样比里有环境转移概率」
✅ 环境项在分子分母中完全相同、全部约去，只剩策略之比——免模型的关键，也是对策略概率极敏感的软肋。
接口

MC 用「等到底」换无偏，TD 用「自举」换不等

更新时机等回合结束每走一步就更新
更新目标真实回报 $G_t$一步奖励 + 后继估计（自举）
偏差 / 方差无偏、方差大有偏、方差小
适用任务仅回合制持续性任务也行
钩子：能不能不等回合结束就更新？可以——代价是自举，这笔交易第 6 章算给你看。
小结

三句话讲完第5章

1解决什么：没有环境模型时，用完整回合的经验估计价值并改进策略
2核心机制：跑回合 → 倒推回报 → 增量平均；控制靠探索，离策略靠重要性采样
3承上启下：经验平均替代了模型，代价是等回合结束、方差大——第 6 章用自举还这笔账
$$\boldsymbol{V(S_t) \leftarrow V(S_t) + \alpha\,\big[\,G_t - V(S_t)\,\big]} \quad\text{——合上书也要能默写}$$
本 章 结 束

期望算不出来，就抽样平均
