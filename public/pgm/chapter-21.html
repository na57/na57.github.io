21.1看到的 ≠ 做出来的：一个数字上的反转

前面二十章里，我们所有的查询都是观测查询：给定证据 e，算 P(Y | e)。但人真正关心的问题常常是另一种：如果我把这个变量强行设成某个值，世界会怎样？——"吃药能不能治病""加息能不能降通胀""这个教学法能不能提分"。这叫干预查询（Interventional Query），记作

P(Y | do(X = x))

读作"把 X 强制设为 x 之后，Y 的分布"。注意它和条件概率 P(Y | X = x) 写法只差一个 do，含义却可能天差地别：

查询符号回答的问题数据来源
观测P(Y | X = x)在"自己取了 x 值"的那部分人里，Y 长什么样被动收集的数据
干预P(Y | do(X = x))如果把所有人的 X 都拧到 x，Y 会长什么样理想实验（随机对照）

例 1：一种看起来有害、其实有效的药（辛普森悖论）

某药 D（服/不服）与康复 R（愈/未愈）之间，夹着一个变量 S：病情轻重（轻/重）。医生倾向于给重症开药。真实的因果结构是 S → D，S → R，D → R（病情既影响开药倾向、也影响康复概率；药本身也影响康复）。数据如下：

  • 总体人群：P(S = 轻) = 0.5，P(S = 重) = 0.5
  • 开药倾向：P(D = 服 | S = 轻) = 0.2，P(D = 服 | S = 重) = 0.8（重症更容易被开药）
  • 康复概率：轻症服药 0.9、轻症不服 0.85；重症服药 0.4、重症不服 0.35

注意分层看：无论轻症还是重症，服药组康复率都更高（0.9 > 0.85，0.4 > 0.35）。药是有效的。现在算观测查询。

第一步：算服药组里的病情构成。先求 P(D = 服) = 0.2×0.5 + 0.8×0.5 = 0.5。由贝叶斯公式：

  • P(S = 重 | D = 服) = P(服|重)·P(重) / P(服) = 0.8×0.5 / 0.5 = 0.8
  • P(S = 重 | D = 不服) = 0.2×0.5 / 0.5 = 0.2

第二步：算观测条件概率。

  • P(愈 | D = 服) = 0.8×0.4 + 0.2×0.9 = 0.32 + 0.18 = 0.50
  • P(愈 | D = 不服) = 0.2×0.35 + 0.8×0.85 = 0.07 + 0.68 = 0.75

单看观测数据，服药组康复率 0.50 远低于不服药组 0.75——药"看起来有害"！

第三步：算干预查询。把 do(D = 服) 理解为"对全人群统一给药"：此时每个人的病情仍按总体分布 P(S) 出现（干预不改变 S，因为 S 在因果上先于 D），于是：

  • P(愈 | do(服)) = Σs P(愈 | 服, s)·P(s) = 0.5×0.9 + 0.5×0.4 = 0.65
  • P(愈 | do(不服)) = 0.5×0.85 + 0.5×0.35 = 0.60

干预之下，服药（0.65）优于不服药（0.60）——药确实有效。观测说"有害"，干预说"有益"，方向完全相反。这就是辛普森悖论（Simpson's Paradox），而它的机制是混杂（Confounding）：S 同时影响 D 和 R，造成一条 D ← S → R 的后门路径，把病情的相关性"偷运"进了药与康复的相关性里。

图 21.1 例 1 的因果图。红色 S 是混杂因素：路径 D←S→R 是"后门"，观测相关里混着它的贡献。
💡 关键一跃

P(Y | X) 问的是"哪类人自己走到了 X = x"——他们可能本来就和别人不一样；P(Y | do(X = x)) 问的是"把所有人拧到 x 之后 Y 怎样"——它抹平了"自己走过来"的选择效应。两者的差，就是混杂的大小。

⚠️ 常见误区

"数据量大就能消除这个问题"——错。混杂是结构性偏差，不是随机噪声：数据再多，P(愈|服) 都稳稳收敛到 0.50，而不是 0.65。消除混杂靠的是知道因果结构并正确处理（21.3 节），不是靠堆数据。

21.2结构因果模型：给贝叶斯网络装上"机制"

上一节的矛盾说明：光有联合分布，回答不了干预查询。缺的那块是什么？例 1 第三步我们偷偷用了一个假设——"把 D 拧成'服'之后，S 的分布不变、康复机制 P(R|D,S) 也不变，只是 D 不再由 S 决定"。把这个假设说清楚的框架，叫结构因果模型（Structural Causal Model，SCM）。

定义：一个 SCM 就是一个贝叶斯网络，外加一条因果语义解读：

  1. 每个节点的 CPD P(Xᵢ | Pa(Xᵢ)) 不是"条件概率"那么简单，而是一个机制（Mechanism）：父节点决定子节点的物理过程；
  2. 模块性（Modularity）：每个机制独立于其他机制——你可以"敲掉"其中一个（换掉 X 的生成方式），其余机制原封不动；
  3. 边的方向 = 因果方向：Pa(Xᵢ) 是 Xᵢ 的直接原因。

于是干预 do(X = x) 有了精确的图操作定义：

✅ 干预的图操作（切断父节点）

do(X = x)：删除所有指向 X 的入边（X 不再由它的原因决定），把 X 固定为 x，其余所有机制保持不变。干预后的联合分布由这个"动过手术"的网络给出。

图 21.2 干预 = 手术：删掉 S→D 这条入边（医生怎么开药不再重要），把 D 钉在"服"。注意 S→R 与 D→R 两条机制原样保留。

写出来就是截断因子分解（Truncated Factorization）：原分布 P(X₁,…,Xₙ) = ∏ᵢ P(Xᵢ | Paᵢ)，在 do(X = x) 之后，把被干预变量的那个因子拿掉，其余照乘：

P(X₁,…,Xₙ | do(X = x)) = ∏i：Xᵢ ≠ X P(Xᵢ | Pa(Xᵢ))，其中 X 的取值一律代入 x

对例 1 的图：P(S, D, R) = P(S)·P(D|S)·P(R|D,S)。do(D = 服) 之后：

P(S, R | do(服)) = P(S) · P(R | 服, S)

对 S 求和即得 P(R | do(服)) = Σs P(R|服,s)·P(s) = 0.65——正是 21.1 节第三步的算法。现在它不是"偷偷假设"，而是 SCM 语义的直接推论。

例 2：同一个观测分布，两个不同的因果图

这是本章最重要的一个例子，请慢慢看。考虑两个二元变量 X、Y，联合分布为：

因果图甲：X → Y（X 是 Y 的原因）。参数化：P(X = 1) = 0.5；P(Y = 1 | X = 0) = 0.20/0.50 = 0.4；P(Y = 1 | X = 1) = 0.40/0.50 = 0.8。乘起来正好复现上表。

因果图乙：X ← Y（Y 是 X 的原因）。参数化：P(Y = 1) = 0.6；P(X = 1 | Y = 0) = 0.10/0.40 = 0.25；P(X = 1 | Y = 1) = 0.40/0.60 ≈ 0.667。同样精确复现上表。

两个图产生的观测分布一模一样——再多的观测数据也分不出谁对。但它们的干预答案截然不同：

  • 图甲：do(X = 1) 会顺着 X→Y 传下去，P(Y = 1 | do(X=1)) = P(Y=1|X=1) = 0.8（X 没有父节点，此时 do 与条件化恰好相同）；
  • 图乙：do(X = 1) 要删掉 X 的入边 Y→X，Y 的机制 P(Y) 不受影响，P(Y = 1 | do(X=1)) = P(Y = 1) = 0.6。

同一个分布，"拧 X"的结果一个是 0.8、一个是 0.6。想知道哪个对，必须知道图的方向——而这个信息不在观测数据里。

⚠️ 这不是巧合，是定理级困难

回忆第 3 章与第 18 章：I-等价的 DAG（同骨架、同 V-结构，如链 X→Z→Y 与分岔 X←Z→Y）编码完全相同的条件独立性，因此观测分布原则上无法区分它们——但它们对 do(X) 的回答可以相反。这就是"因果发现"（Causal Discovery）的根本边界：纯观测数据一般只能把因果图确定到一个等价类，剩下的要靠时间顺序、领域知识、或主动做干预实验。

💡 直觉

观测分布是一本书的"成片"，因果模型是"拍摄剧本"。同一部成片可以由不同的剧本拍出；要问"改一个镜头会怎样"，光看片子不够，得拿到剧本。SCM 就是剧本：每条边是一个可以单独拆卸的机制。

21.3后门准则：什么时候观测数据就够用

前两节一定一破：干预查询有明确定义，但观测数据一般回答不了它。这一节给出最重要的"够用"判据：什么条件下，P(Y | do(X)) 可以只用观测分布算出来。

回看例 1 的第三步：P(愈 | do(服)) = Σs P(愈 | 服, s)·P(s)。注意右边两个因子都是观测分布里的量——分层条件概率乘上分层变量的边际，再加总。这个操作叫调整（Adjustment）：按混杂变量 S 分层算、再按 S 的总体占比加权平均。它为什么对？因为在例 1 的图里，S 恰好"挡住"了唯一的后门路径 D←S→R，而且 S 不是 D 的后代（给药不会改变病情轻重的事前分布）。抽象出来就是后门准则（Backdoor Criterion）：

✅ 后门准则与后门调整公式

变量集 Z 对有序对 (X, Y) 满足后门准则，如果：
① Z 阻断了所有从 X 指向 Y 的后门路径（即以指向 X 的箭头开头的路径，按 d-分离判定，且 X 的出边保留）；
② Z 中不含 X 的任何后代。
此时因果效应可识别，且

P(Y | do(X = x)) = ∑z P(Y | X = x, Z = z) · P(Z = z)

例 3：用调整公式重算例 1。Z = {S}：它阻断唯一后门 D←S→R，且 S 不是 D 的后代 ✓。代入：

  • P(愈 | do(服)) = P(愈|服,轻)P(轻) + P(愈|服,重)P(重) = 0.9×0.5 + 0.4×0.5 = 0.65 ✓
  • P(愈 | do(不服)) = 0.85×0.5 + 0.35×0.5 = 0.60 ✓

与 21.2 节截断因子分解的结果完全一致——后门调整就是"截断因子分解 + 后门被阻断"时的可计算形式。随机对照试验（RCT）可以看作它的特例：随机化直接砍断 X 的所有入边，使 P(X) 与任何混杂无关，此时连分层都不需要。

哪些变量不能调：两个经典错误

  • 调了 X 的后代（中介）：若结构是 X → M → Y（X 通过 M 起作用），调整 M 会把因果路径本身截断，算出来的"效应"只剩直接效应，严重低估；
  • 调了对撞节点：若 X → C ← Y，C 是 X、Y 的共同后代，条件化 C 会打开一条本来关闭的路径（第 3 章 V-结构），人为制造虚假相关。
⚠️ "把所有能测的变量都控制起来"是错的

机器学习里"特征越多越好"的直觉在这里翻车：多控制一个变量，可能截断因果路径（中介），也可能打开对撞路径。控制谁，必须看图决定——这正是"先画 DAG，再谈回归"的原因。

如果混杂测不到呢？当混杂因素不可观测时，后门准则失效。但因果推断并未走进死胡同：若存在一个完全被 X 决定、又完全决定 Y 的中介变量 M，且 M 不受混杂污染，可以用前门准则（Frontdoor Criterion）识别效应——经典例子是"吸烟 → 焦油沉积 → 癌症"，其中"吸烟↔癌症"的直接混杂（基因）测不到，但焦油沉积量把因果链条撑开了。它可由 21.4 节的 do-演算严格推出。

21.4do-演算、反事实与问题的边界

后门准则只是"够用"的一种情形。更一般地问：给定任意因果图，P(Y | do(X)) 能不能化成只含观测分布的式子？Pearl 的do-演算（do-Calculus）给出三条机械规则，专门用来把含 do 的表达式一步步"消 do"：

规则干什么成立条件（在动过手术的图上判独立）
规则 1：插入/删除观测P(Y|do(X), z, w) 中的观测 z 可以删掉删掉 X 入边的图里，Y ⊥ Z | X, W
规则 2：干预 ↔ 观测互换do(Z) 换成观测 z（或反之）再删掉 Z 出边的图里，Y ⊥ Z | X, W
规则 3：删除干预do(Z) 整个删掉删掉 X 入边、再删掉"与 W 无关的 Z"入边的图里，Y ⊥ Z | X, W

规则 2 是灵魂：它说的正是"什么条件下 do 可以当普通条件看待"——对照例 1，X 是根节点时没有任何入边，do(X) 与条件化一致（例 2 图甲就是这种情况）。若一套推导能把 P(Y | do(X)) 化成完全不含 do 的表达式，就称这个因果效应可识别（Identifiable）；后门调整公式就是一次成功的推导。反过来，当图中存在 X ↔ Y 形的未观测双向混杂（弓形结构）且没有可用中介时，可以证明任何推导都会失败——不可识别，此时唯一出路是改变数据：测量新变量，或直接做干预实验。

比干预更进一步：反事实

还有一类更"贪心"的问题："这个病人吃了药痊愈了，如果他当时没吃，还会好吗？"这不是对一群人拧变量，而是对同一个体追问平行世界——反事实（Counterfactual）。SCM 用三步法回答，称为溯因—行动—预测（Abduction–Action–Prediction）：

例 4：一个完整的手算。设 SCM：治疗效果 Y = 2X + U，其中 X 是药量（0/1/2），U 是病人体质（外生噪声，假设 −3 ≤ U ≤ 3）。观测到某病人 X = 1，Y = 5。

  1. 溯因：由观测反推 U = Y − 2X = 5 − 2 = 3（这个病人的体质被唯一确定）；
  2. 行动：把模型改成 do(X = 2)，机制 Y = 2X + U 与 U 的值都不变；
  3. 预测：Y′ = 2×2 + 3 = 7——"他若当时加倍药量，效果会是 7"。
⚠️ 反事实比干预要更强的东西

注意溯因那一步：我们假设了 U 可以被观测唯一反推，这要求知道机制的完整函数形式（这里是确定性的线性式）。只有干预分布 P(Y|do(X)) 是推不出反事实的——关联、干预、反事实是三级台阶，每上一级都需要更强的假设。Pearl 称之为"因果之梯"。

💡 本章账单一览

因果推断给了我们干预的精确定义（SCM + 截断因子分解）和一套"观测数据何时够用"的判据（后门准则 / do-演算）；但它也立了一块碑：因果方向不在观测数据里（例 2），图必须来自领域知识或实验。拿到"干预会怎样"之后，下一个问题自然是——所以该怎么选？这就是第 22 章效用理论与第 23 章影响图的任务。

概念卡 1
干预 do 算子（do-Operator）
点击翻面 →
定义do(X = x)：删除 X 的全部入边并固定 X = x 后，模型给出的分布。
解决问题区分"看到 X = x"与"把 X 拧成 x"，为"行动的后果"提供形式语义。
直觉给图做手术：把 X 的"输入线"剪断，接上外部电源。
误区以为它只是条件概率的新记号——无混杂时两者才相等，有混杂时南辕北辙。
何时用一切"政策/治疗/干预效果"问题；Ch23 决策节点改变分布的语义源头。
概念卡 2
混杂因素（Confounder）
点击翻面 →
定义同时影响 X 与 Y、从而在 X→Y 的因果效应之外制造相关性的变量（后门路径的源头）。
解决问题解释"相关 ≠ 因果"的机制：相关性里混着别的路径的贡献。
直觉冰激凌与溺水：夏天的太阳在背后同时推高了两者。
误区以为数据够大就能淹没它——混杂是结构偏差，大样本照样稳定存在。
何时用观察性研究的因果推断；判断该控制哪些变量（后门准则）。
概念卡 3
结构因果模型（Structural Causal Model）
点击翻面 →
定义BN + 因果语义：每个 CPD 是一个独立机制，父节点是直接原因，机制可单独替换（模块性）。
解决问题让"干预"有了定义：换机制而不动其他机制。
直觉乐高模型：每块积木（机制）独立，可以抽换其中一块。
误区以为任何 BN 自动是因果模型——只有方向按因果解读、且承认模块性时才是。
何时用本章所有干预/反事实计算的地基；与 Ch18 结构学习相接。
概念卡 4
截断因子分解（Truncated Factorization）
点击翻面 →
定义do(X=x) 后的联合分布：原因子分解中删掉 X 的因子，X 一律代入 x。
解决问题把"手术后的网络"翻译成可直接计算的公式。
直觉菜谱里删掉"X 由什么决定"那一页，改成"X 就取 x"。
误区忘记它含未观测变量时无法直接算——可计算性要靠后门/前门等进一步条件。
何时用推导后门调整、证明可识别性的起点。
概念卡 5
后门准则（Backdoor Criterion）
点击翻面 →
定义Z 阻断所有指向 X 的后门路径且不含 X 的后代，则 P(Y|do(X)) = Σz P(Y|X,Z)P(Z)。
解决问题给出"用观测数据估计因果效应"最常用的一张许可证。
直觉把混杂的后门堵上，前门（因果路径）就干净了。
误区"控制得越多越好"——控制中介截断因果、控制对撞点打开假路径。
何时用流行病学、政策评估、A/B 测试之外的一切观察性因果分析。
概念卡 6
可识别性（Identifiability）
点击翻面 →
定义P(Y|do(X)) 能否表示为只含观测分布的表达式（do-演算可推导到底）。
解决问题回答"这个问题靠观测数据原则上能不能解"，不能解就要换数据。
直觉图纸审查：动工（收集数据）之前先问"这栋楼靠现有材料盖不盖得起来"。
误区以为是算法/算力问题——不可识别是信息问题，再强的模型也救不了。
何时用设计研究方案时的第一道检查；不可识别 → 加测量或做实验。
概念卡 7
反事实（Counterfactual）
点击翻面 →
定义对同一个体问"如果当时做了别的选择"：P(YX=x′ | 观测到的 X, Y)。
解决问题回答归因、追责、个体化"假如"类问题，比群体干预更细。
直觉平行宇宙：保留这个宇宙的 U，只改写一个决定。
误区以为和干预是一回事——反事实还需溯因，要求机制的完整函数形式。
何时用法律责任判定、个性化医疗复盘；因果之梯最高一级。

📝分层习题

L1 概念辨析判断对错：只要 X 在因果图中没有父节点，P(Y | X = x) 就一定等于 P(Y | do(X = x))。说明理由。
提示

X 无父节点意味着没有指向 X 的边，那么 do(X) 的手术还剪得掉什么吗？后门路径存在吗？

完整解答
对。X 无父节点 ⟹ 不存在以"指向 X 的箭头"开头的路径 ⟹ 无后门路径 ⟹ 空集满足后门准则，P(Y|do(X=x)) = Σ∅ P(Y|x) = P(Y|x)。等价地，do 手术"无入边可删"，干预分布与条件分布一致。例 2 的图甲正是这种情形。这也是随机化实验（X 由抛硬币决定，无父节点）无需调整任何变量的原因。
L1 概念辨析判断对错：为了估计 X 对 Y 的因果效应，回归模型里控制的变量越多，估计越可靠。举出两类反例。
提示

想想 X → M → Y 里的 M，和 X → C ← Y 里的 C。

完整解答
错。两类反例：①控制中介 M（X→M→Y）：条件化 M 截断了因果路径本身，估计的只剩直接效应，总效应被低估甚至归零；②控制对撞节点 C（X→C←Y）：C 本来阻断 X←…→Y 之外的假路径，条件化它反而打开路径，制造虚假相关（Berkson 悖论）。变量该不该控制，由图上的后门准则决定，不是"越多越好"。
L2 手算推导设因果图 Z → X，Z → Y，X → Y，参数：P(Z=1) = 0.5；P(X=1|Z=1) = 0.9，P(X=1|Z=0) = 0.1；Y = X ⊕ Z（异或：X、Z 不同则 Y=1）。手算 P(Y=1|X=1) 与 P(Y=1|do(X=1))，并解释差距。
提示

观测查询要用贝叶斯公式先求 P(Z|X=1)；干预查询用截断因子分解（删掉 Z→X），Z 保持 P(Z) 不变。

完整解答

观测：P(X=1) = 0.9×0.5 + 0.1×0.5 = 0.5。P(Z=0|X=1) = P(X=1|Z=0)P(Z=0)/P(X=1) = 0.1×0.5/0.5 = 0.1。X=1 时 Y=1 要求 Z=0，故 P(Y=1|X=1) = P(Z=0|X=1) = 0.1。

干预：do(X=1) 删掉 Z→X，Z 分布不变。Y=1 要求 Z=0（因 X 固定为 1），故 P(Y=1|do(X=1)) = P(Z=0) = 0.5。

解释：观测里"X=1 的人"几乎全是 Z=1 的人（0.9），所以 Y=1 只占 0.1；干预把 X 赋给所有人，其中一半是 Z=0，Y=1 占一半。0.4 的差就是混杂 Z 的贡献。

L2 手算推导接上题。验证：{Z} 满足后门准则，并用后门调整公式重算 P(Y=1|do(X=1))。
提示

检查两条条件：Z 是否阻断唯一后门 X←Z→Y？Z 是不是 X 的后代？然后套调整公式。

完整解答

唯一后门路径是 X←Z→Y，条件化 Z 后该路径被阻断 ✓；Z 是 X 的父节点而非后代 ✓。{Z} 满足后门准则。

调整公式：P(Y=1|do(X=1)) = Σz P(Y=1|X=1, z)·P(z)。

逐项：z=1 时 Y = 1⊕1 = 0，P(Y=1|X=1,Z=1) = 0；z=0 时 Y = 1⊕0 = 1，P(Y=1|X=1,Z=0) = 1。

故 = 0×0.5 + 1×0.5 = 0.5，与上题截断因子分解结果一致 ✓。

L3 建模应用研究"教育年限 X 对收入 Y 的因果效应"。已知：个人能力 U（不可观测）同时影响教育年限与收入；父亲教育年限 F 影响 X 但不直接影响 Y；智商测试分数 Q 是 U 的带噪声测量。①画出因果图（含 U 不可观测的双向混杂表示）；②判断能否用后门调整估计 X→Y 的效应，若能，调整集是什么？若不能，说明原因并提出一条出路。
提示

U 不可观测且是共同原因——后门路径 X←U→Y 能用谁堵住？Q 是 U 的后代，它能完全替代 U 吗？想想前门准则需要什么样的中介。

完整解答

① 图：U → X，U → Y，U → Q（U 不可观测），X → Y，F → X。

② 后门路径 X←U→Y 的源头 U 不可观测，观测变量里没有能阻断它的集合：调 Q 只是 U 的噪声代理，无法完全阻断（残余混杂仍在）；F 不是混杂的阻断点。因此单纯后门调整不可行，效应不可识别。

出路（任答一条即可）：Ⓐ 找到 X→Y 的可观测中介 M（如"职业技能认证"），满足前门条件时用前门调整；Ⓑ 利用 F 作工具变量（F 只通过 X 影响 Y）；Ⓒ 做干预实验或自然实验（如义务教育法变动）直接操纵 X 附近的变异。核心信息：画图先识别"测不到的混杂"，再决定数据策略，而不是先跑回归。
