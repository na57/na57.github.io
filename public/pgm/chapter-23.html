23.1三类节点与两种弧：把决策画进图

第 22 章的决策计算（例 1 的治疗方案、例 4 的检查）都是手工完成的：列概率、乘效用、取最大。问题复杂一点——多个决策、中间有观测、效用依赖多个变量——手工列表就失控了。就像第 3 章用图模型驯服了联合分布，影响图（Influence Diagram）用图驯服决策问题。它在贝叶斯网络上增加两种新节点，共三类：

节点类型图形含义携带的参数
机会节点（Chance Node）圆形/椭圆随机变量，世界替它"掷骰子"CPD：P(X | Pa(X))
决策节点（Decision Node）矩形行动变量，你替它选值无 CPD；取值由策略决定
价值节点（Value/Utility Node）菱形效用的计分项，无子节点效用函数 U(Pa(V))，确定性

边也分成两种语义，必须分清：

弧的类型指向含义类比
影响弧（Relevance Arc）机会/决策 → 机会节点
机会/决策 → 价值节点		概率依赖或效用依赖：它改变下游的分布或得分BN 里的普通有向边（含 Ch21 干预语义）
信息弧（Information Arc）机会/决策 → 决策节点做该决策时，父节点的取值已经被你观测到"决策时摆在桌面上的情报"

图 23.1 带伞决策的影响图（含信息弧版本）。圆 = 机会节点，矩形 = 决策节点（橙色），菱形 = 价值节点。虚线是信息弧：决策时已知天气；两条实线是影响弧：天气与决策共同决定效用。
✅ 一条硬性时序规则

决策节点的父节点，必须是在该决策之前就能确定的量——否则"策略 = 给定父节点取值选行动"这张规则表里会出现"决策时还不知道答案"的格子，整个决策规则无从执行。多个决策节点时，影响图还要求存在一个全序：D₁ 的信息弧来自 D₁ 之前观测到的变量与之前的决策（人不会忘记自己做过什么）。

⚠️ 信息弧不是因果弧

图 23.1 里 W → D 的虚线不表示"天气导致带伞"，它只表示"带伞前看了天气"。反过来，决策 D → V 的实线才是因果：带不带伞改变你的处境。判断一条边是哪种，看箭头落点：落在决策节点上是信息弧，落在机会/价值节点上是影响弧。

23.2单决策完整手算：带伞问题与信息弧的价格

把第 22 章的手工计算搬进图里，看影响图如何"算"决策。带伞问题：决策 D（带/不带），天气 W（雨 0.3 / 晴 0.7），效用表：

U(D, W)W = 雨（0.3）W = 晴（0.7）
D = 带70（干爽但累赘）60（白拿一天）
D = 不带0（落汤鸡）100（一身轻）

情形一：无信息弧（出门前看不到天气）

没有 W ⇢ D，决策时 W 未知，最优行动是全局比较期望效用：

  • EU(带) = 0.3×70 + 0.7×60 = 21 + 42 = 63
  • EU(不带) = 0.3×0 + 0.7×100 = 0 + 70 = 70

最优策略：δ*(D) = 不带，EU = 70。

情形二：有信息弧（出门前看了完美预报）

现在决策规则是 W 的函数：对每种天气分别取最优——

  • W = 雨：带（70）> 不带（0）→ δ*(雨) = 带
  • W = 晴：不带（100）> 带（60）→ δ*(晴) = 不带

期望效用 = 0.3×70 + 0.7×100 = 21 + 70 = 91。

对比：信息弧的价值 = 91 − 70 = 21，正是第 22 章 VPI 的图上版本。注意它全部来自"晴天才改主意"：无信息时被迫选"不带"，在雨天赔掉 70（0.3×70 = 21）。信息弧只可能让期望效用变高或不变——多一张可用的情报不会变差，这就是"信息弧单调性"（VPI ≥ 0 的图读法）。

💡 图在替你记账

情形一与情形二的唯一差别是图上一条虚线。影响图把"你知道什么"也变成图结构：加信息弧 = 策略表里多一个条件列。第 22 章手工算的 VPI，在这里变成"比较两张图的期望效用"——图本身就是决策分析的账本。

23.3多阶段决策：从后往前算的逆向归纳

真实决策是序列：先做 D₁，观测一些结果，再做 D₂。信息弧编码这个顺序（D₂ 的父节点 = 做 D₂ 时已知的量）。最优策略怎么求？答案是逆向归纳（Backward Induction）：最后一个决策先定——它的信息最全；定好之后把它"固化"成一个普通机会节点，再倒推前一个。

例 2：检查—治疗，完整手算

病情 D（病/健康，各 0.5）。可选做一次检查（成本 5 效用单位），结果 R 与病情相关：P(+|病) = 0.8，P(+|健康) = 0.2。随后决定治疗/不治。效用（不含检查成本）：治+病 = 90，治+健康 = 40（白挨副作用），不治+病 = 0，不治+健康 = 100。

flowchart LR D(("D 病情")) --> R(("R 检查结果")) D1["D1 做检查否"] --> R R -.->|"信息弧"| D2["D2 治疗否"] D --> V{"V 效用"} D2 --> V D1 -->|"检查成本"| V classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#c4651f; class D1,D2 hot;
图 23.2 两阶段决策。D₁ 决定是否获取信息，R 经信息弧进入 D₂，D₂ 与病情共同决定效用，D₁ 还直接向效用收"成本"。逆向归纳先定 D₂ 的规则，再回头定 D₁。

第 0 步：准备工作（贝叶斯）。P(+) = 0.5×0.8 + 0.5×0.2 = 0.5。检查后验：

  • P(病|+) = 0.8×0.5 / 0.5 = 0.8；P(病|−) = 0.2×0.5 / 0.5 = 0.2

第 1 步：先定最后的决策 D₂（对 R 的每个取值各选最优）。

  • R = +：EU(治|+) = 0.8×90 + 0.2×40 = 72 + 8 = 80；EU(不治|+) = 0.8×0 + 0.2×100 = 20。→ δ*(+) = 治（80）
  • R = −：EU(治|−) = 0.2×90 + 0.8×40 = 18 + 32 = 50；EU(不治|−) = 0.2×0 + 0.8×100 = 80。→ δ*(−) = 不治（80）

此时把 D₂"固化"：它不再自由，而是一个按 δ* 执行的规则——图上的一个普通机会节点。

第 2 步：倒推 D₁。若做检查：按 δ* 执行后的期望效用（扣除成本 5）= P(+)×80 + P(−)×80 − 5 = 0.5×80 + 0.5×80 − 5 = 80 − 5 = 75。若不做检查：D₂ 无信息可用，全局比较 EU(治) = 0.5×90 + 0.5×40 = 45 + 20 = 65，EU(不治) = 50——选治，得 65。

第 3 步：D₁ 取最优。75 > 65 → δ*(D₁) = 做检查。完整最优策略：做检查；阳性则治，阴性则不治。期望效用 75，比"不做检查直接治"（65）多 10——检查的信息价值（80−65=15）盖过了成本 5。

✅ 逆向归纳的一般形式

按决策时序的逆序处理每个决策节点 D：对它父节点的每种赋值，选 max 行动（这就是 δ* 的一行）；然后把 D 替换为执行 δ* 的机会节点，继续向前。每个决策只被优化一次，且每次优化时它需要的全部信息都已就绪——这正是"父节点必须先确定"规则在算法层的回声。

⚠️ 顺序不能反

若先定 D₁ 再定 D₂，D₂ 的规则表还没填，D₁ 的两个分支就没有可比较的期望效用。"从后往前"不是技巧，是时序约束的必然结果。这也解释了为什么 23.1 节要求影响图存在决策全序。

23.4影响图上的推理：sum-max 变量消去

例 2 是手工倒推的，但它暗示了一个通用算法。第 9 章变量消去对联合分布做"乘因子、按序求和"；影响图的期望效用计算只需改一个符号：

节点类型消去时做什么对应第 22 章
机会节点求和（对不确定取期望）概率项 Σ P(·)
决策节点取最大（并记下 argmax 作为策略）MEU 的 max
价值节点累加（多个价值节点求和为一个总效用因子）加性分解

消去顺序服从时序约束：机会变量按任意合法顺序求和，决策节点必须逆时序取 max（先消最后的决策）——这正是逆向归纳。同样，第 10 章的团树也可以改造：团需包含影响同一决策的全部变量，消息传递中遇到决策节点做 max 而非 sum。表示、推理两阶段投资的所有算法，在决策问题上原样复用——这就是把决策画进图的红利。

💡 望向更远处

把时间维度铺开，影响图的序列版本就是马尔可夫决策过程（MDP，状态→行动→状态→行动……），求解它用动态规划；状态看不全时就是 POMDP——第 15 章动态贝叶斯网络的过滤/平滑与本章决策的合流。强化学习里的"值函数"正是逆向归纳中"固化后的期望效用"的递归写法。

定义贝叶斯网络 + 决策节点（矩形）+ 价值节点（菱形）构成的决策模型。
解决问题把概率、决策、效用统一到一张图上，使"求最优决策"成为图上的计算。
直觉决策的作战地图：情报（信息弧）、行动（矩形）、战果（菱形）。
误区以为只是 BN 的图示变体——多出的两类节点改变了语义与算法（max 登场）。
何时用医疗决策、诊断测试选择、任何结构化单/多阶段决策分析。
概念卡 2
决策节点（Decision Node）
点击翻面 →
定义矩形节点：行动变量，取值由策略（而非 CPD）决定。
解决问题把"我们能做什么"显式放进模型——世界不替它掷骰子。
直觉棋盘上轮到你走的格子。
误区给它配 CPD——决策节点没有概率，只有规则；其"分布"由策略诱导。
何时用一切可选行动的建模点；Ch21 do 算子的图形化身。
概念卡 3
信息弧（Information Arc）
点击翻面 →
定义指向决策节点的弧：声明做该决策时父节点取值已被观测。
解决问题显式编码"决策时知道什么"，决定策略表的形状。
直觉开考前允许带进考场的纸条——有它，策略才能按它分栏。
误区当成因果弧——它只传递"可知性"，不代表影响。
何时用多阶段决策建模；增删一条信息弧的期望效用差 = VPI（Ch22）。
概念卡 4
策略 / 决策规则（Policy / Decision Rule）
点击翻面 →
定义δD：Pa(D) → Val(D)，给定决策时的全部已知信息，选定行动。
解决问题把"随机应变"形式化：不是选一个行动，而是选一张行动表。
直觉棋谱：每种局面（父节点赋值）对应一步棋。
误区以为策略是固定行动——有信息弧时策略必须是信息的函数。
何时用一切多阶段决策；MDP/RL 中的 policy 即此物。
概念卡 5
最优策略与 MEU（Optimal Policy）
点击翻面 →
定义δ* = argmaxδ EPδ[U]：使策略诱导分布下期望效用最大的策略。
解决问题定义影响图的"解"：不是概率查询，而是一张最优行动表。
直觉全书公式的终点站：概率（Ch1-21）× 效用（Ch22）取最大。
误区逐行动独立贪心——决策间有信息传递时须全局（逆向）优化。
何时用本章所有例题的目标量；由逆向归纳/sum-max VE 计算。
概念卡 6
逆向归纳（Backward Induction）
点击翻面 →
定义从最后一个决策开始：对其父节点每种赋值取 max 记下规则，固化为机会节点，再倒推前一个。
解决问题多阶段最优策略的可行求法，尊重"信息按序到达"的时序约束。
直觉下棋先算残局：终局最优确定后，倒数第二步才有意义。
误区顺序搞反——前决策的期望效用依赖后决策的规则，无法先算。
何时用影响图求解、博弈论、动态规划（值函数是其递归形式）。
概念卡 7
sum-max 变量消去
点击翻面 →
定义变量消去的决策版：机会节点求和、决策节点逆序取 max、价值节点累加。
解决问题让第 9–10 章的推理机器直接输出最优策略。
直觉同一台发动机（因子运算），换挡位：Σ 换 max。
误区随意排消去顺序——决策节点必须逆时序，否则算的不是最优策略。
何时用影响图的通用求解；团树同样可改造（决策团内做 max）。

📝分层习题

L1 概念辨析判断对错：信息弧 W → D（W 为机会节点、D 为决策节点）表示"W 是 D 的原因"。说明理由。
提示

回到信息弧的定义：它声明的是什么？有因果含义吗？决策的值由谁决定？

完整解答
错。信息弧只声明"做决策 D 时已观测到 W"，是可知性关系而非因果关系；D 的取值由策略决定，不由 W 概率性地"导致"（策略可以是 δ(W) 的任意函数，包括完全无视 W）。混淆两者会错误地用 CPD 给 D 参数化，或把"加信息弧提高期望效用"误读为"W 对 D 有因果作用"——它提高的是信息条件下的决策质量。
L1 概念辨析判断对错：在影响图中，决策节点 D 的父节点可以包含一个决策时尚未确定取值的变量。
提示

策略 δD：Pa(D) → Val(D) 是一张什么表？如果某列的"条件"在填表时还不存在会怎样？

完整解答
错。策略是以父节点赋值为条件的行动规则表；若某父变量在决策时未定，该规则表出现"无法查"的格子，策略无法执行，逆向归纳也随之失效（max 对未知的条件无法取）。因此影响图要求时序约束：决策节点的父节点必须先于它可确定，多决策时存在信息全序。
L2 手算推导带伞问题改参数：P(雨) = 0.4，效用表不变（带：雨 70 / 晴 60；不带：雨 0 / 晴 100）。分别计算无信息弧与有完美预报信息弧时的最优策略与期望效用，并求信息价值。
提示

无信息：全局比较 EU(带) 与 EU(不带)；有信息：对每种天气分别取 max，再按天气分布加权。

完整解答

无信息：EU(带) = 0.4×70 + 0.6×60 = 28 + 36 = 64；EU(不带) = 0.4×0 + 0.6×100 = 60。→ 选带，EU = 64（注意与 23.2 节结论相反：雨概率升高后带伞转正）。

有信息：δ*(雨) = 带（70），δ*(晴) = 不带（100）。EU = 0.4×70 + 0.6×100 = 28 + 60 = 88。

信息价值 = 88 − 64 = 24，来自晴天才改主意的分支：0.6×(100−60) = 24。

L2 手算推导例 2 中把检查成本从 5 改为 20，其余不变。重做逆向归纳，给出完整最优策略，并回答"检查还值不值"。
提示

D₂ 的规则与检查成本无关（成本挂在 D₁ 上）；只有第 2、3 步的数字会变。

完整解答

第 1 步不变：δ*(+) = 治（80），δ*(−) = 不治（80）。

第 2 步：做检查的期望效用 = 0.5×80 + 0.5×80 − 20 = 60；不做检查的最优 = 治（65）。

第 3 步：60 < 65 → δ*(D₁) = 不做检查，直接治疗。完整策略：不检查、治疗，EU = 65。

解读：检查的信息价值仍是 80 − 65 = 15，但成本 20 超过了它——信息再好，贵过它能带来的改变就不买。VPI 给出了"最多愿付多少"的精确上界。

L3 建模应用石油钻探：是否钻一口井（决策 D₂），事前可做地震勘探（决策 D₁，有成本），勘探结果 S（好/差信号）与地下含油 O 相关，钻探收益取决于 O 与 D₂。①画出影响图（标三类节点、信息弧、影响弧）；②说明为什么 S → D₂ 是信息弧而 D₂ → V 是影响弧；③描述求最优策略的算法步骤（不必算数）。
提示

时序：先决定勘不勘（D₁），看到信号 S，再决定钻不钻（D₂）。O 是世界的状态，谁依赖它？

完整解答

① 机会节点：O（含油，带先验）、S（信号，P(S|O,D₁)）；决策节点：D₁（矩形）、D₂（矩形）；价值节点：V（菱形）。边：O→S、D₁→S（影响弧）；S⇢D₂、D₁⇢D₂（信息弧，D₂ 时已知是否勘探及信号）；O→V、D₂→V（影响弧，收益函数）；D₁→V（勘探成本）。

② S⇢D₂ 只声明"钻井决策前看到了信号"，不表示信号导致决策——决策由策略选定；D₂→V 表示钻不钻（与 O 一起）因果地改变收益。箭头落点定语义：落在决策节点上是信息弧，落在价值节点上是影响弧。

③ 算法（逆向归纳 / sum-max VE）：㈠ 对每个 S 取值计算 P(O|S)（贝叶斯）；㈡ 对 D₂ 的每种信息赋值（含"未勘探"分支）取 max，得规则 δ*(D₂)；㈢ 将 D₂ 固化为机会节点，对 S 与 O 求和，比较"勘探−成本"与"不勘探"两个分支的期望效用；㈣ 取 max 得 δ*(D₁)，输出完整策略。
