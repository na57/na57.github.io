18.1结构学习难在哪：超指数空间 + I-等价

第17章我们假设图结构 𝒢 已知，学习只是"填数字"。本章问一个更深的问题：如果没人告诉你图长什么样呢？这正是现实——基因调控网络没人画好给你，症状之间的因果没人排好序。

第一道难关：搜索空间超指数增长

n 个节点上可能的 DAG 有多少个？

n（节点数）234510
DAG 数量32554329,281≈ 4.2 × 10¹⁸

这不是指数，是超指数（Super-exponential）增长——比 2ⁿ 快得多。10 个变量就有 4.2 亿亿个候选图，穷举连门都没有。结构学习本质上是一个离散组合优化问题，而且被证明是 NP-hard 的。

第二道难关：I-等价——数据天生分不清方向

更微妙的困难：即使你有无穷多数据、无穷算力，有些结构之间永远无法区分。回忆第3章的I-等价（I-Equivalence）：两张图若编码完全相同的独立性集合，就叫 I-等价。

💡 关键一跃

对两个变量 X、Y：X→Y 和 Y→X 编码的独立性集合完全相同（都是"无独立性"），它们可以用不同的 CPD 参数化同一个联合分布。既然如此，任何数据集给这两张图的似然都一样——数据对它们一视同仁。所以结构学习的输出只能是等价类（表示为 PDAG：部分有向无环图），只有 V-结构（X→Z←Y 这类）的方向能被数据锁定，因为它们携带不同的独立性。

⚠️ 常见误区

"数据够多就能学出因果方向"——错。方向辨识需要的是 V-结构、干预实验或时间顺序，不是样本量。X→Y 与 Y→X 在任何样本量下似然完全相同（18.2 节会当场算给你看）。这是"相关 ≠ 因果"在算法层面的精确表述，也是第21章存在的理由。

18.2评分函数：似然必须减去惩罚

既然不能穷举，至少得能"比较"：给任意一张候选图 𝒢 打一个分数 Score(𝒢 : D)，分数越高越好。最天真的候选是似然——用第17章的 MLE 填好参数，算 log P(D | 𝒢)。但它有一个致命缺陷：

过拟合：加边永远不会降低似然

给任何节点加一个父节点，CPD 就多了一张按新配置细分的表——模型自由度变大，拟合数据只会更好或持平。推到极限：让每个节点以所有其他节点为父节点的"饱和模型"，其似然就是经验分布本身，全场最高。但它是零泛化的死记硬背：参数比数据点还多，新数据一来立刻崩盘。

✅ 核心机制

似然只奖励"拟合得好"，从不惩罚"模型复杂"。结构学习需要的评分必须自带奥卡姆剃刀：拟合收益必须超过复杂度代价，一条边才配存在。

BIC 评分：拟合 − 复杂度

最常用的BIC 评分（Bayesian Information Criterion）：

ScoreBIC(𝒢 : D) = ℓ(θ̂𝒢 : D) − k2 · ln M

其中 ℓ 是该结构下用 MLE 参数达到的对数似然，k 是自由参数总数（所有 CPD 的独立条目数），M 是样本量。第二项就是惩罚：每个自由参数收半条 ln M 的"税"。样本越多税越贵，但似然项随 M 线性增长而惩罚只随 ln M 增长——数据足够时真结构总会胜出；数据少时，惩罚自动把模型压简单。这正体现了"小数据信简单、大数据容复杂"的自动权衡。

💡 一句话记住 MDL 视角

BIC 与最小描述长度（Minimum Description Length, MDL）同源：最好的结构 = "描述模型所需的比特 + 用模型描述数据所需的比特" 最小的那个。复杂模型自身描述就贵，天然被罚。

例 1：完整手算——16 个样本，两个结构对决

两个二元变量 X、Y，M = 16 个样本的计数：

Y=0Y=1行合计
X=0718
X=1178

候选 G₀（无边，X ⊥ Y）：MLE 为 P(X=0) = P(Y=0) = 8/16 = 0.5，P(X=1) = P(Y=1) = 0.5。每个样本的似然 = 0.5 × 0.5 = 0.25：

ℓ₀ = 16 × ln 0.25 ≈ 16 × (−1.386) = −22.18，k = 2（X 一个参数 + Y 一个参数）
BIC₀ = −22.18 − 22 ln 16 ≈ −22.18 − 2.77 = −24.95

候选 G₁（X→Y）：P(X=0) = P(X=1) = 0.5；条件表 P(Y=0|X=0) = 7/8 = 0.875，P(Y=1|X=0) = 1/8 = 0.125，P(Y=0|X=1) = 0.125，P(Y=1|X=1) = 0.875。14 个样本走 0.875、2 个走 0.125，且每个样本再乘 P(X) = 0.5：

ℓ₁ = 16 ln 0.5 + 14 ln 0.875 + 2 ln 0.125 ≈ −11.09 − 1.87 − 4.16 = −17.12
BIC₁ = −17.12 − 32 ln 16 ≈ −17.12 − 4.16 = −21.28

判决：BIC₁ (−21.28) > BIC₀ (−24.95)，边 X→Y 成立。似然提升了 5.06，代价只有 1.39 的惩罚——这笔交易划算。注意惩罚项在干什么：它替我们问"这 5.06 的提升，是真信号还是 16 个样本里的运气？"答案是真信号。

当场演示 I-等价

再算 Y→X：P(Y=0) = 8/16 = 0.5，P(X=0|Y=0) = 7/8 = 0.875……完全对称的计数表给出 完全相同的 ℓ = −17.12，k 也相同，BIC 相同。数据宣布：X→Y 与 Y→X 打平，永远打平。这就是 I-等价在评分函数上的投影——评分再高也只能选出等价类。

18.3搜索：可分解性让局部贪婪成为可能

评分有了，但 4.2×10¹⁸ 个候选怎么搜？救星是 BN 评分的可分解性（Decomposability）——和第17章似然分解同源：

Score(𝒢 : D) = ∑i=1n FamScore(Xᵢ, Pa(Xᵢ) : D)

总分 = 每个节点（连同其父节点集）的局部得分之和。这意味着：对图做一次局部改动（加/删/反转一条边），只有一两个"族"的分数变化，其余 n−2 项原封不动。不用重算全图，只需缓存每个 (节点, 父节点集) 组合的局部分——搜索从"全局重估"变成"局部增量更新"。

爬山搜索（Hill Climbing）

  1. 从初始图开始（常用空图）；
  2. 每轮考察所有合法操作：加边、删边、反转边（保持无环）；
  3. 执行评分提升最大的那个操作；
  4. 没有任何操作能提升时停止——到达局部最优。

变体：给定变量拓扑序的 K2 算法（每个节点只向前面的节点找父节点，搜索空间大幅收缩）；多次随机重启缓解局部最优。实践中 n ≤ 100 时爬山 + 缓存 + 重启相当好用。

⚠️ 局部最优是常态

爬山只看一步之内的提升，会卡在局部最优。更糟的是"方向陷阱"：先加上了 A→B，后来 B→A 才是对的，但反转操作未必能一步爬出。多重启、禁忌搜索是标准对策。

为什么必须加约束：树宽与入度上限

还有一个工程现实：学出来的模型是要拿去做推理的。第9–10章说过，精确推理的复杂度随图的树宽（Treewidth）指数增长。如果结构学习不加约束，评分函数可能选出一张推理根本跑不动的稠密图——学得再准也用不了。所以实践中必须加：

  • 最大入度约束：每个节点父节点数 ≤ d（同时控制 CPD 参数量 2^d 的爆炸）；
  • 树宽约束：限制候选图的树宽（如 ≤ 4），保证学出的模型推理可行。可惜"树宽受限的结构学习"本身也是 NP-hard，通常用启发式近似执行。

18.4PC 算法：用独立性检验代替搜索

评分搜索的哲学是"比较谁拟合得好"。另一条路线是约束方法（Constraint-Based）：不比较模型，直接问数据"哪些条件独立性成立？"，用答案反推图结构。代表是 PC 算法：

  1. 学骨架：从完全无向图开始。对每对节点 (X, Y)，从小到大枚举条件集 S，做条件独立性检验 X ⊥ Y | S；只要找到某个 S 使独立性成立，就删边并记录分离集 S。
  2. 定向 V-结构：对每对不相邻但有公共邻居 Z 的 X、Y——若 Z 不在它们的分离集里，说明"给定 Z 后 X、Y 反而相关"，正是 V-结构的指纹，定向为 X→Z←Y。
  3. 传播方向：用约束规则（避免成环、避免新 V-结构）尽可能多地确定剩余边的方向。定不了的就留作无向边。

输出是 PDAG（Partially Directed Acyclic Graph）：有向边是数据能锁定的方向，无向边是 I-等价中不可辨识的部分——PC 算法诚实地承认自己的认识论极限。

💡 一个现实：小样本时结构学习基本靠先验

两条路线都怕小样本。评分路线：样本少时惩罚项主导，倾向删光所有边；约束路线：条件独立性检验在小样本下功效极低，"检验不出相关"会被误判为"独立"，漏掉真边。结论：数据少时，结构学习的答案主要由先验决定——比如稀疏偏好 P(𝒢) ∝ α|edges|（α < 1，边越多先验越低），或领域专家指定的禁边/必边。这不是缺陷，是诚实：结构本来就是比参数强得多的断言，它需要相应的证据强度。

评分搜索（爬山/K2）约束方法（PC）
核心操作比较候选图得分做条件独立性检验
输出一个 DAG（等价类代表）PDAG（诚实保留不确定方向）
小样本软肋惩罚主导 → 过度稀疏检验功效低 → 假独立、漏边
计算缓存局部分后较快快，但检验次数随条件集爆炸

📝分层习题

L1 概念辨析判断对错：样本量足够大时，结构学习可以确定所有边的方向。说明理由。
提示

想想 X→Y 与 Y→X 在大样本下的似然关系；方向辨识靠什么信息？

完整解答
错。I-等价是样本量无法克服的：X→Y 与 Y→X 参数化同一个联合分布族，任何样本量下似然完全相同。大样本只能让"哪些边存在、哪些是 V-结构"判断更准；方向辨识需要的是 V-结构指纹、干预实验或时间/领域信息，不是更多观测数据。
L1 概念辨析判断对错：BIC 的惩罚项随样本量 M 增长，所以数据越多越倾向选简单模型。说明理由。
提示

比较似然项与惩罚项各自随 M 的增长速度。

完整解答
错。似然项 ℓ 随 M 线性增长（每样本贡献一个 log 因子），惩罚项只随 ln M 增长。数据越多，真实信号带来的似然差越大、相对惩罚越微不足道，BIC 越敢选复杂结构。数据越少惩罚才越主导、越倾向简单模型——方向恰好相反。
L2 手算推导沿用例 1 的 16 样本计数表（(0,0)=7, (0,1)=1, (1,0)=1, (1,1)=7）。手算：① G₀（无边）与 G₁（X→Y）的 BIC；② 解释胜者及惩罚项的作用。
提示

ℓ₀ = 16 ln 0.25；ℓ₁ = 16 ln 0.5 + 14 ln 0.875 + 2 ln 0.125；惩罚 = (k/2) ln 16，k₀=2，k₁=3。

完整解答

① ℓ₀ = 16 × (−1.386) ≈ −22.18，BIC₀ = −22.18 − (2/2)×2.773 ≈ −24.95。

ℓ₁ = −11.09 − 1.87 − 4.16 ≈ −17.12，BIC₁ = −17.12 − (3/2)×2.773 ≈ −21.28。

② G₁ 胜出（−21.28 > −24.95）：边带来的似然提升 5.06 远超新增一个参数的惩罚 1.39，判定为真信号而非噪声。若计数更平（如 (4,4,4,4)），ℓ 提升趋近 0，惩罚使无边模型胜出——惩罚项正是"边存在的证据门槛"。

L2 手算推导在 G₁（X→Y）基础上考虑 G₂：再加一条 Z→Y（Z 是与 Y 无关的二元变量）。定性分析：ℓ 大约变化多少？k 变化多少？BIC 会怎么判？
提示

Z 与 Y 无关时，新 CPD 的条件表和原来的表几乎一样；数一下新增的自由参数。

完整解答

ℓ：Z ⊥ Y 时，P(Y|X,Z) ≈ P(Y|X)，似然提升 ≈ 0（只有 16 样本的噪声级波动，量级远小于 1）。

k：Y 的条件表从 2 个自由参数（每个 X 配置 1 个）变成 4 个（X×Z 四配置各 1 个），新增 2 个自由参数，惩罚增加 (2/2)·ln 16 ≈ 2.77。

BIC：得分净变化 ≈ 0 − 2.77 < 0，G₂ 被否决。这就是惩罚项在实战中挡掉伪边的标准过程——无关变量带来的噪声级提升，交不起每个参数 1.39 的税。

L3 建模应用四个变量 A、B、C、D。独立性检验结果：A ⊥ D（空集即成立）；B ⊥ D | {C}；其余所有检验都拒绝独立。① 用 PC 算法画出骨架；② 定向所有能定的 V-结构；③ 指出哪些边方向不可定，并说明原因。
提示

从完全图开始，按检验结果删边；然后检查每对不相邻节点的公共邻居是否在其分离集中。B—C 定向拿不准时，把 B→C 与 C→B 各自宣布的 B、D 独立性写出来，与检验结果逐条对账——有一个方向会两头都说错话。

完整解答

① 骨架：完全图有 6 条边。A⊥D（S=∅）→ 删 A—D；B⊥D|{C}（S={C}）→ 删 B—D。剩 4 条边：A—B、A—C、B—C、C—D。

② V-结构检查：不相邻对为 (A,D) 和 (B,D)。对 (A,D)：公共邻居是 C，C ∉ S(A,D)=∅ → 定向 A→C←D。对 (B,D)：公共邻居 C，而 C ∈ S(B,D)={C} → 不定 V-结构（恰是"给定 C 独立"的链/分叉模式）。

③ 先定 B—C：候选定向与检验结果的逐条对账见下，结论是只能定为 C→B。再定 A—B：此时若取 B→A，则 A→C→B→A 首尾相接成环，DAG 不允许——为避免成环，A—B 必须定为 A→B（A 与 C 相邻，A→B←C 不构成新 V-结构，合法）。最终输出是一张全有向 DAG：A→C←D、C→B、A→B——本题没有任何边"不可定"，I-等价类恰好只剩一个成员。

把 B—C 这一步的定向推理展开成一次完整对账。无向边 B—C 只有两种候选定向：

定向甲：B→C。此时 D→C 已定，B 与 D 不相邻却共指 C——在 C 处新增一个 V-结构 B→C←D。V-结构的语义是"两个父节点无条件独立、给定公共子节点后相关"，即这个定向宣布：B ⊥ D（边际独立），且 B ⊥̸ D | C（条件相关）。

定向乙：C→B。C 处只保留已定的 A→C←D，不新增任何 V-结构；B、D 之间只剩链式路径 B←C←D，宣布的是"边际相关、给定 C 独立"。

候选定向宣布的 B、D 关系检验结果判决
B→C（新增 B→C←D）B ⊥ D 边际独立；给定 C 后相关B ⊥ D 被拒绝（"其余所有检验都拒绝独立"）；B ⊥ D | {C} 成立两条全反 ⟹ 排除
C→B（无新 V-结构）链 B←C←D：边际相关；给定 C 独立同上全部吻合 ⟹ 采纳

对账结果：B→C 新增的 V-结构把检验确认的相关（B、D 边际相关）说成了独立，又把检验确认的独立（B ⊥ D | {C}）说成了相关——与数据两头冲突，这个方向被排除；只剩反向 C→B。这正是 18.4 节 PC 第 ③ 步"避免新 V-结构"的传播规则在一次具体定向上的执行：D→C 已定、B 与 D 不相邻，B—C 就必须背向 C。

⚠️ 订正：本题曾把 A—B 写成"方向不可定"，这是错的。错因是只检查了两条定向是否产生新 V-结构（都不产生），漏掉了另一条传播规则——避免成环：B→A 会造成 A→C→B→A 的有向环。两条规则（不新增 V-结构、不成环）都过完，才算检查完毕。

📖 回看：V-结构的判定与语义（为何"两父无条件独立、观测汇聚点后反而相关"）见第 3 章 §3.3「d-分离：用图读出独立性」；"只有 V-结构的方向能被独立性信息锁定"的判定定理见 §3.4「反过来：从分布到图（I-Map 与 I-等价）」。

  • B. Z 与 X、Y 都强相关
  • C. X、Y 在给定 Z 后独立
  • D. Z 不在 X、Y 的分离集中
选 D。V-结构的指纹是"X、Y 边际独立，给定 Z 后相关"——即把 X、Y 分开的条件集里不含 Z。A 与 D 相反，对应的是链/分叉结构；C 说的恰是链/分叉的独立性，方向不定。
