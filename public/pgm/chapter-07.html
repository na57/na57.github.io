7.1连续变量逼我们换语言：从列不出的表到多元高斯

第 3 到 6 章有一个安静的默认假设：每个变量取有限个离散值，CPD 就是一张表——父节点每种组合一行，行内是和为 1 的概率。但很多真实变量是连续的：温度、位置、浓度、股价。给"明天气温"列条件概率表？温度有无穷多个取值，表有无穷多行；更糟的是，连续变量取到任何单点的概率都是 0，"P(温度 = 23.5℃)" 这个写法本身就塌了。

补救办法是换一个数学对象：用概率密度函数（Probability Density Function, PDF）p(x) 代替概率。密度本身不是概率，概率是密度曲线下某段区间的面积：P(a ≤ X ≤ b) = ∫ab p(x)dx。单点区间面积为零，这正好解释了"单点概率恒为 0"。

密度函数的形状有无穷多种候选：均匀、指数、拉普拉斯、t 分布……为什么整章只押注高斯分布（Gaussian Distribution，即正态分布）？三个理由，一个比一个硬：

  • 它天然常见：中心极限定理（Central Limit Theorem）说，大量独立小随机因素之和趋向高斯。测量误差、身高、热噪声——自然界处处是高斯。
  • 它参数极少：n 元多元高斯分布（Multivariate Gaussian Distribution）完全被两样东西决定——均值向量 μ（n 个数）与协方差矩阵（Covariance Matrix）Σ（对称正定，n(n+1)/2 个数）。不需要表，不需要形状参数。
  • 它在运算下封闭：这是决定性的一条。高斯经过线性变换仍是高斯；对联合高斯做边缘化仍是高斯；做条件化（观测一部分变量）仍是高斯。推理的每一步都不离开高斯家族，每步都有闭式公式。

多元高斯的协方差形式定义：

p(x) = (2π)−n/2 |Σ|−1/2 · exp( −½ (x − μ)ᵀ Σ⁻¹ (x − μ) )

其中 |Σ| 是 Σ 的行列式。看形状：指数部分是一个二次型，等高线（密度相等的点）是椭圆；μ 决定椭圆中心，Σ 决定椭圆的轴向与胖瘦。一维时退化成熟悉的钟形曲线 N(μ, σ²)。

封闭性不是口号：条件化的闭式公式与一次完整手算

把变量分成两组：要查询的 XA 与观测到的 XB。联合高斯的条件化定理说，观测 XB = xB 之后，XA 仍是高斯，且：

μA|B = μA + ΣAB ΣBB⁻¹ (xB − μB)
ΣA|B = ΣAA − ΣAB ΣBB⁻¹ ΣBA

其中 ΣAB 是 Σ 中"A 行、B 列"的子块。这就是高斯网络推理的全部秘密：不用枚举、不用数值积分，套公式代入数字即可。下面完整算一遍。

例 1：二维高斯的条件化手算

设两个连续变量（比如某房间的真实温度 X₁ 与传感器读数 X₂）服从联合高斯：

μ = ( 1 , 0 )，   Σ = [ 2   1 ;   1   2 ]

即 Var(X₁) = 2，Var(X₂) = 2，Cov(X₁,X₂) = 1（相关系数 ρ = 1/√(2·2) = 0.5）。现在观测到传感器读数 X₂ = 3，问真实温度的后验分布。

第一步：认出各子块。A = {1}，B = {2}。μA = 1，μB = 0；ΣAA = 2，ΣAB = 1，ΣBB = 2。

第二步：算条件均值。ΣBB⁻¹ = 1/2（标量求逆就是取倒数）：

μ1|2 = 1 + 1 · 12 · (3 − 0) = 1 + 1.5 = 2.5

第三步：算条件方差：

Σ1|2 = 2 − 1 · 12 · 1 = 2 − 0.5 = 1.5

结论：观测 X₂ = 3 后，X₁ ~ N(2.5, 1.5)。读数高于预期（3 比均值 0 高），把温度的估计从 1 拉高到 2.5——拉高幅度由协方差之比 Σ₁₂/Σ₂₂ = 0.5 控制，这个比值正是"用 X₂ 线性预测 X₁"的回归系数。不确定性从 2 收缩到 1.5：观测永远削减（或保持）方差，且条件方差与观测值无关，只取决于 Σ——这是高斯特有的性质。

💡 直觉

联合高斯的等高线是椭圆。观测 X₂ = 3 就是拿一条竖直线去切这个椭圆——切出来的截面仍是一条（一维）钟形曲线，只是中心偏移、宽度变窄。条件化 = 切椭圆，这就是全部几何内容。

⚠️ 常见误区

"连续而已，把区间切成小格子离散化不就行了？"——精度每提高 10 倍，每个变量的格子数乘 10，n 个变量就是 10ⁿ 倍的表，第 9 章会精确看到这张表如何吃掉所有计算。高斯闭式解的意义正是绕开离散化。反过来也要记住：高斯单峰、对称、轻尾，多峰或重尾的真实数据它表示不了——这个局限会在 7.4 节以另一种方式回来找我们。

7.2信息形式：图的结构藏在哪个矩阵里

7.1 节用 (μ, Σ) 表示高斯，很直观。但如果给你一张稀疏的图——比如链 X—Y—Z——再问"Σ 的哪个元素反映这条链的结构"，答案会让人失望：Σ 通常是稠密的。X 与 Z 之间明明没有边，Cov(X,Z) 却不是 0，因为相关性会沿路径 X—Y—Z 传过去。想在矩阵里"看见"图，得换一个参数化。

把密度公式里的二次型展开：−½(x−μ)ᵀΣ⁻¹(x−μ) = −½xᵀΣ⁻¹x + (Σ⁻¹μ)ᵀx − ½μᵀΣ⁻¹μ。最后一项是常数，吸进归一化系数；前两项给出信息形式（Information Form）：

p(x) ∝ exp( −½ xᵀ J x + hᵀ x )

其中 精度矩阵（Precision Matrix）J = Σ⁻¹——也叫信息矩阵（Information Matrix）；信息向量（Information Vector）h = Jμ。两个参数化等价：(μ, Σ) ⟺ (h, J)，换算只需一次矩阵求逆。

✅ 高斯马尔可夫随机场的核心定理

对联合高斯分布：Jᵢⱼ = 0 ⟺ Xᵢ ⊥ Xⱼ | 其余所有变量。也就是说，J 的零元素精确对应高斯马尔可夫随机场（Gaussian Markov Random Field, Gaussian MRF）中不存在的边：J 的零模式就是图的结构。严格地说，−Jᵢⱼ/Jᵢᵢ 是"用其余所有变量线性回归 Xᵢ 时 Xⱼ 的系数"——它为 0，说明给定其余变量后 Xⱼ 对 Xᵢ 毫无额外信息。

对比鲜明：Σ 是稠密的，J 是稀疏的。相关性能沿图传播，所以协方差处处非零；条件独立却会在精度矩阵上留下精确的零。想看图，别看 Σ，看 J。

💡 为什么这件事值得激动

第 4 章里，无向图的结构要靠图分离去读；在高斯世界，图结构直接等于一个矩阵的稀疏模式。这带来两个工程红利：存储——稀疏图只存 J 的非零元；计算——高斯推理本质是解线性方程组 J·(解) = h，稀疏矩阵有专门的快速算法。顺便，信息形式下做条件化也更省：观测 XB = xB 后，XA 的信息矩阵就是 JAA（直接取子块），信息向量变为 hA − JABxB，连逆都不用求——与协方差形式里的 ΣBB⁻¹ 对照，各有千秋。

例 2′：对照手算——同一个观测，Σ 形式与信息形式各算一遍

上面那句"信息形式下条件化就是取子块"，字面好懂、机制却容易含糊：为什么不用求逆？算出来的数和 7.1 节真的一样吗？用例 1 的同一个分布、同一个观测两条路径各走一遍，数字对上了才算懂。

设定（同例 1）：μ = (1, 0)，Σ = [ 2 1 ; 1 2 ]，观测 X₂ = 3，求 X₁ 的条件分布。

路径一（协方差形式，例 1 已算）：需要求 ΣBB⁻¹ = 1/2，得 μ₁|₂ = 1 + 1·(1/2)·3 = 2.5，Σ₁|₂ = 2 − 1·(1/2)·1 = 1.5。求逆发生在"观测变量"那一侧。

路径二（信息形式），分三步：

第一步：换成 (J, h)。det(Σ) = 2·2 − 1·1 = 3，故 J = Σ⁻¹ = (1/3)·[ 2 −1 ; −1 2 ]；h = Jμ = (1/3)·(2·1 + (−1)·0, −1·1 + 2·0) = (2/3, −1/3)。

第二步：条件化 = 取子块 + 修正 h。规则：观测 XB = xB 后，XA 的条件精度 JA|B = JAA（直接取子块，不求逆），条件信息向量 hA|B = hA − JABxB。代入 A = {1}、B = {2}：

J1|2 = J₁₁ = 23，   h1|2 = h₁ − J₁₂·x₂ = 23 − (−13)·3 = 23 + 1 = 53

第三步：换回 (μ, Σ) 读数。方差 = 精度的倒数：Σ₁|₂ = 1/(2/3) = 1.5 ✓；均值 = J1|2⁻¹·h1|2 = (3/2)·(5/3) = 2.5 ✓。与路径一分毫不差。

💡 机制一句话

信息形式下 p(x) ∝ exp(−½xᵀJx + hᵀx)。"观测 X₂ = 3"就是把这个变量钉成常数：二次型 −½xᵀJx 展开后，只含 x₂ 的项整个变成常数（吸进归一化系数），含 x₁x₂ 的交叉项 −J₁₂x₂·x₁ 则并入 x₁ 的线性项——所以 JAA 原样保留，hA 只修正一个 JABxB。观测 = 代入一个数，不是求一个逆。观测越多（B 越大），Σ 形式的逆越贵，信息形式的优势越实在。

⚠️ 本章最容易记反的一件事

"矩阵的零元素 ⟺ 图中无边"说的是 J = Σ⁻¹，不是 Σ！Σ₁₃ ≠ 0 恰恰因为相关性会传播。口诀：协方差看（无条件）相关，精度看（条件）独立。考试和论文里记反这两个矩阵，是本章出错率最高的地方。

7.3高斯贝叶斯网络：线性高斯 CPD，与一张读不全的图

7.2 节是无向视角。有向世界（第 3 章的因果方向）怎么处理连续变量？答案是高斯贝叶斯网络（Gaussian Bayesian Network）：每个节点的 CPD 是父节点的线性函数加一个独立高斯噪声——线性高斯模型（Linear Gaussian Model）：

Xᵢ = β₀ + ∑j ∈ Pa(i) βⱼ Xⱼ + εᵢ，   εᵢ ~ N(0, σᵢ²)

注意 CPD 的形式：Xᵢ 给定父节点后是均值为 β₀ + Σβⱼxⱼ、方差为 σᵢ² 的高斯。由于高斯的线性组合加上独立高斯噪声仍是高斯，按拓扑序逐节点代入可得一个优美结论：

✅ 定理

若每个节点的 CPD 都是线性高斯，则全体变量的联合分布必为多元高斯。于是 7.1、7.2 节的一切（条件化闭式解、J 的稀疏性）全部免费继承。

联合高斯的 μ 和 Σ 不必积分，可以按拓扑序递归算出来（父节点永远先于子节点被处理）：

E[Xᵢ] = β₀ + ∑j βⱼ E[Xⱼ]
Cov(Xᵢ, Xₖ) = ∑j βⱼ Cov(Xⱼ, Xₖ)  （k 排在 i 之前）
Var(Xᵢ) = ∑j ∑l βⱼ βl Cov(Xⱼ, Xl) + σᵢ²

例 3：两节点高斯 BN——递归手算 Σ 的全部四个元素

flowchart LR X["X = ε₁，ε₁~N(0，1)"] --> Y["Y = 2X + 3 + ε₂，ε₂~N(0，1)"]
图 7.3 两节点线性高斯 BN：X 是外生噪声，Y 是 X 的线性函数加独立噪声。

第一步：均值（拓扑序 X 先于 Y）。E[X] = E[ε₁] = 0。E[Y] = 2·E[X] + 3 + E[ε₂] = 0 + 3 + 0 = 3。

第二步：Var(X)。X = ε₁，所以 Var(X) = 1。

第三步：Cov(X, Y)。把 Y 的定义代入，用协方差的双线性性质，常数 3 与独立的 ε₂ 都不贡献：

Cov(X, Y) = Cov(X, 2X + 3 + ε₂) = 2·Cov(X, X) = 2·1 = 2

第四步：Var(Y)。独立和的方差 = 方差之和（系数要平方）：

Var(Y) = 2²·Var(X) + Var(ε₂) = 4·1 + 1 = 5

汇总：μ = (0, 3)，Σ 的四个元素为 Σ₁₁ = 1、Σ₁₂ = Σ₂₁ = 2、Σ₂₂ = 5，行列式 = 1·5 − 2·2 = 1 > 0，确实是合法协方差矩阵。X 与 Y 的相关系数 ρ = 2/√5 ≈ 0.89——强相关，来自系数 2 与较小的噪声。

反直觉点：这张图的独立性"可靠但不完备"

第 3 章我们习惯了"d-分离读出独立性"。在高斯 BN 上，这件事必须说得更精确：

  • 可靠（sound）：d-分离判出的独立性，在分布里一定成立。图说独立，必真独立。
  • 不完备（incomplete）：分布里可能藏着图读不出的独立性。图说相关，实际可能独立。

看一个精确的反例。菱形结构：X 经两条路径影响 W——X→Y→W 与 X→Z→W。

flowchart TB X["X ~ N(0，1)"] -->|"系数 1"| Y["Y = X + εy"] X -->|"系数 1"| Z["Z = X + εz"] Y -->|"系数 1"| W["W = Y − Z + εw"] Z -->|"系数 −1"| W classDef danger fill:#fae9e7,stroke:#b03a2e,stroke-width:2.5px,color:#b03a2e; class W danger;
图 7.4 忠实性失效：图上 X 经两条有向路径连通 W（d-分离判相关），但两条路径的系数恰好一正一负，效应在 W 处精确抵消——分布里 X 与 W 实际独立。

手算协方差验证（εy、εz、εw 都是独立 N(0,1)）：Cov(X, Y) = Var(X) = 1，Cov(X, Z) = Var(X) = 1，于是

Cov(X, W) = Cov(X, Y − Z + εw) = Cov(X,Y) − Cov(X,Z) + 0 = 1 − 1 = 0

而高斯分布有个离散分布没有的好性质：不相关 ⟺ 独立（一般分布只有"独立 ⇒ 不相关"）。Cov(X, W) = 0 直接给出 X ⊥ W。但看图：X→Y→W 与 X→Z→W 都是活路径，d-分离判它们相关。图漏报了一条真实存在的独立性。

⚠️ 忠实性失效：高斯网络与离散 BN 的重要差别

理论上离散 BN 也可能因参数巧合漏报独立性，但高斯情形格外突出：这里的"相关"完全由协方差一个数决定，两条路径的效应在协方差上精确相加，一正一负就归零——控制系统里的对消、两条等幅反相的物理路径，都是工程上真实会撞见的情形，不是测度零的怪胎。结论：在高斯 BN 上读图，只能把 d-分离读出的独立性当作分布独立性的子集；要相信"相关"，必须回到参数本身。这个性质叫忠实性（Faithfulness）失效——图不再忠实地反映分布的全部独立性。

最后一句带过的远景：把线性高斯链沿时间展开（Xt+1 = AXt + 噪声，观测 Ot = CXt + 噪声），就是线性动态系统（Linear Dynamical System, LDS）；在它上面做高斯推理——预测步推进 (μ, Σ)、更新步做条件化——就是著名的卡尔曼滤波（Kalman Filter）。细节留给第 15 章（动态网络中的推理）。

7.4条件线性高斯：通往混合网络的门（与一笔留给第 14 章的账）

前三节的世界很干净：全员连续、全员高斯。现实往往混杂：连续变量的行为被一个离散开关决定——传感器正常时读数紧贴真值，故障时漂移；经济平稳期股价小幅波动，危机期剧烈震荡。让离散变量只做连续变量的父节点（不反向），且每个离散取值决定一套线性高斯参数，这就是条件线性高斯（Conditional Linear Gaussian, CLG）：

p(Xᵢ | Pad = d, Pac = x) = N( β₀(d) + ∑j βⱼ(d) xⱼ ; σᵢ²(d) )

即：离散父节点选定"工况"（regime），同一工况下，连续父节点以线性方式进入。例如传感器：D = 正常时 Y = X + ε（σ = 0.1）；D = 故障时 Y = 0.5X + 10 + ε′（σ = 2）。

flowchart LR D["D 离散：传感器工况"] --> Y["Y 连续：读数"] X["X 连续：真实温度"] --> Y classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#c4651f; class D hot;
图 7.5 CLG 的骨架：离散父 D 选择哪套线性高斯参数生效，连续父 X 线性进入 Y。离散节点只允许做父节点——这是 CLG 能维持可分析性的底线。

表示很优雅，推理却撞上一堵墙。问"Y 的边际分布是什么"，就得把离散父 D 边缘化掉：

p(Y) = ∑d P(d) · N( μ(d), σ²(d) )

这是若干座钟形曲线的加权叠加——高斯混合（Mixture of Gaussians）。它不再是高斯：可能多峰、可能偏斜。7.1 节赖以生存的三条封闭性里，"边缘化封闭"在 CLG 中失效了。更糟的是爆炸速度：每多一个二值离散变量，混合分量数翻倍；n 个二值离散变量就是 2ⁿ 个分量。10 个就是 1024 项，每项还要带着自己的 μ 和 Σ 参与后续推理。

⚠️ 本章买下的账单

纯高斯网络推理是闭式代数；一旦混入离散父节点，精确推理要追踪随离散变量数指数增长的高斯分量，很快不可行。这笔账本章不还——它正是第 14 章"混合网络中的推理"要对付的核心难题（近似、剪枝、消息近似都是为此而生）。记住这条线索：CLG 表示容易、推理难，难在边缘化离散变量后高斯性丢失。

高斯假设强，却换来了全书唯一一处"推理是纯线性代数"的天堂；一旦离散变量掺进来，天堂关门，混合爆炸。第 8 章会告诉你高斯其实是指数族的一员（与离散分布同一框架），第 14 章则负责收拾混合网络的残局。

回忆例 2：链 X—Y—Z 里 X 和 Z 没有边，Σ₁₃ 等于多少？哪个矩阵的零元素才对应无边？

完整解答
错。对应"无边"的是精度矩阵 J = Σ⁻¹ 的零元素：Jᵢⱼ = 0 ⟺ Xᵢ ⊥ Xⱼ | 其余变量 ⟺ 无边。Σ 一般是稠密的，因为相关性沿路径传播——例 2 中 X、Z 无边但 Σ₁₃ = 1。口诀：协方差看相关，精度看条件独立。把两个矩阵的角色记反，是本章最高频的错误。
L1 概念辨析判断对错："两个变量协方差为 0 却不能判独立"——这句话对高斯分布成立。说明理由。
提示

想想 7.3 节我们凭什么从 Cov(X, W) = 0 直接断言 X ⊥ W？这个推理对一般分布成立吗？

完整解答
错。对联合高斯分布，不相关 ⟺ 独立：协方差为 0 时密度可分解为两个独立高斯的乘积。这是一般分布没有的特权——一般分布只有"独立 ⇒ 不相关"，反向不成立（如 Y = X²，X 对称分布时 Cov(X,Y)=0 但显然不独立）。所以这句话恰好说反了：高斯里协方差为 0 就能判独立。
L2 手算推导设 (X₁, X₂) 服从联合高斯，μ = (0, 0)，Σ 的元素为 Σ₁₁ = 9、Σ₁₂ = 3、Σ₂₂ = 4。观测到 X₂ = 8，手算 X₁ 的条件均值与条件方差。
提示

套条件化公式：μ₁|₂ = μ₁ + Σ₁₂·Σ₂₂⁻¹·(x₂ − μ₂)；Σ₁|₂ = Σ₁₁ − Σ₁₂²/Σ₂₂。注意 Σ₂₂ 是标量，求逆即取倒数。

完整解答

第一步：子块——μ_A = 0，μ_B = 0，Σ_AB = 3，Σ_BB = 4，Σ_AA = 9；Σ_BB⁻¹ = 1/4。

第二步：条件均值 μ₁|₂ = 0 + 3·(1/4)·(8 − 0) = 3·2 = 6。回归系数 Σ₁₂/Σ₂₂ = 3/4，观测高出均值 8 个单位，估计上调 (3/4)×8 = 6。

第三步：条件方差 Σ₁|₂ = 9 − 3·(1/4)·3 = 9 − 9/4 = 27/4 = 6.75。

验证合理性：6.75 < 9，观测使不确定性下降 ✓；且条件方差与观测值 8 无关（公式里只有 Σ），符合高斯特性。结论：X₁ | X₂=8 ~ N(6, 6.75)。

L2 手算推导高斯贝叶斯网络：X = ε₁，Var(ε₁) = 2；Y = −3X + 1 + ε₂，Var(ε₂) = 4，两个噪声独立、均值都是 0。按拓扑序递归手算联合分布的均值向量与协方差矩阵的全部元素。
提示

先算 E[X]、Var(X)，再用双线性算 Cov(X,Y)（常数与独立噪声不贡献），最后用"独立和的方差可加（系数平方）"算 Var(Y)。别忘了验证行列式为正。

完整解答

均值：E[X] = 0；E[Y] = −3·E[X] + 1 + 0 = 1。

Var(X) = Var(ε₁) = 2。

Cov(X,Y) = Cov(X, −3X + 1 + ε₂) = −3·Cov(X,X) + 0 + 0 = −3·2 = −6（负号来自系数 −3：X 越大 Y 越小）。

Var(Y) = (−3)²·Var(X) + Var(ε₂) = 9·2 + 4 = 22。

汇总：μ = (0, 1)，Σ = [[2, −6], [−6, 22]]。正定性检查：det = 2·22 − (−6)² = 44 − 36 = 8 > 0 ✓，且 Σ₁₁ = 2 > 0 ✓。相关系数 ρ = −6/√(2·22) ≈ −0.905，强负相关，与系数 −3 的语义一致。

L3 建模应用某化工厂反应釜：真实温度 T（连续）先验 N(180, 25)；一个离散工况开关 D ∈ {正常, 清洗}，P(正常) = 0.9；温度传感器 S 在正常档紧贴真值（S = T + ε₁，σ₁ = 0.5），清洗档因蒸汽干扰读数漂移（S = 0.8T + 20 + ε₂，σ₂ = 5）。用 CLG 建模：画出图、写出每个 CPD；说明边缘化 D 后 S 的分布形态；若工厂有 5 个独立二值工况开关共同影响 S，S 的边际分布至多有多少个高斯分量？
提示

变量三个：D（离散）、T（连续）、S（连续）。D 和 T 谁是 S 的父节点？边缘化 D 就是按 P(d) 加权叠加两个工况下的高斯。分量数 = 离散变量联合状态数。

完整解答

图：D → S ← T（D 离散做父，T 连续做父，S 连续做子；T 无父，用先验）。

CPD：T ~ N(180, 25)；P(D=正常) = 0.9，P(D=清洗) = 0.1；

S | (D=正常, T=t) ~ N(t, 0.25)；S | (D=清洗, T=t) ~ N(0.8t + 20, 25)。

S 的边际：p(S) = 0.9·N(180, 25.25) + 0.1·N(164, 41)——两个高斯的加权和（清洗档均值 0.8×180+20 = 164，方差 0.64×25+25 = 41）。这是高斯混合：双峰、非高斯。注意边缘化后 S 失去了"单高斯"身份，这正是 CLG 推理变难的根源。

5 个二值开关：联合状态 2⁵ = 32 种，至多 32 个高斯分量。指数爆炸的直觉到此坐实。

  • C. 给定其余所有变量后，X₁ 与 X₂ 条件独立；图上二者之间没有边
  • D. X₁ 与 X₂ 之间有边，但边权为 0
选 C。定理：Jᵢⱼ = 0 ⟺ Xᵢ ⊥ Xⱼ | 其余变量 ⟺ 无边。A 错：条件独立不蕴含无条件独立（链上 X、Z 就无条件相关）；B 错：J 的零不对应 Σ 的零，例 2 里 J₁₃ = 0 而 Σ₁₃ = 1；D 错：Jᵢⱼ = 0 恰恰表示没有边，而不是"有边但权重为零"。
自测 3
三变量高斯链 X—Y—Z。关于它的 Σ 与 J，下列说法正确的是：
  • A. Σ 一般满（Σ₁₃ ≠ 0），J 是三对角的（J₁₃ = 0）
  • B. Σ 是三对角的，J 是满的
  • C. Σ 和 J 都是三对角的
  • D. Σ 和 J 都是满的
选 A。相关性沿链传播，X 与 Z 无条件相关，故 Σ₁₃ ≠ 0，Σ 稠密；给定 Y 后 X ⊥ Z，故 J₁₃ = 0，J 只在对角与相邻位置非零（三对角）。B 把两个矩阵说反了；C、D 都误判了其中至少一个的稀疏性——例 2 的手算就是反例。
自测 4
高斯 BN 中，X 经 X→Y→W 与 X→Z→W 两条路径连通 W，但参数使两路效应恰好抵消（Cov(X,W)=0）。这说明：
  • A. d-分离规则在高斯 BN 上不再可靠，图说独立也可能不独立
  • B. 这张图不是合法的高斯 BN，必须删去一条路径
  • C. Cov(X,W)=0 不能推出独立，所以 X 与 W 仍相关
  • D. 图独立性可靠但不完备：图说相关，分布里却可能因参数抵消而独立
选 D。图读出的独立性 ⊆ 分布真实独立性，这个例子漏报的是 X ⊥ W。A 错：方向恰好相反，d-分离判"独立"永远可信，失效的是"相关"这一侧；B 错：图与参数都合法，问题在图的可读性而非合法性；C 错：联合高斯下不相关 ⟺ 独立，Cov=0 就是独立。
自测 5
一个 CLG 网络含 3 个二值离散变量（都做连续变量的父节点）。把离散变量全部边缘化后，某连续变量的边际分布是：
  • A. 仍然是单个高斯，因为边缘化保持高斯性
  • B. 至多 8 个分量的高斯混合，不再是高斯
  • C. 至多 6 个分量的高斯混合（3 个变量各贡献 2）
  • D. 均匀分布，因为离散化抹平了峰值
选 B。3 个二值离散变量有 2³ = 8 种联合状态，每种状态给出一套高斯参数，边缘化后至多是 8 分量高斯混合；混合一般多峰，不再是高斯。A 错：边缘化封闭性只对纯高斯网络成立，对 CLG 失效——这正是本章埋给第 14 章的难题；C 错：分量数是联合状态数（乘积 8），不是求和 6；D 错：与均匀分布毫无关系。
