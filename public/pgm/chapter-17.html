17.1问题设置：为什么这是最简单的学习问题

第16章说过，学习问题的难度取决于两个维度：结构是否已知、数据是否完全。本章站在最友好的那个角落：

  • 结构已知：图 𝒢 给定（来自专家知识，或第18章学出来的结果）；
  • 数据完全：数据集 D = {x⁽¹⁾, …, x⁽ᴹ⁾} 中每条样本的每个变量都被观测，没有缺失值，没有隐变量；
  • 任务：估计每个 CPD P(Xᵢ | Pa(Xᵢ)) 里的参数 θᵢ。

为什么简单？因为贝叶斯网络的因子分解会把学习问题"拆开"。写出整个数据集的似然（Likelihood）：

P(D | θ) = ∏m=1M ∏i=1n P(xᵢ⁽ᵐ⁾ | paᵢ⁽ᵐ⁾ ; θᵢ) = ∏i=1n [ ∏m=1M P(xᵢ⁽ᵐ⁾ | paᵢ⁽ᵐ⁾ ; θᵢ) ]

第一步是每个样本用链式法则分解；第二步只是交换连乘顺序——但效果惊人：参数 θᵢ（第 i 个 CPD 的参数）只出现在第 i 个方括号里。要最大化总似然，只需分别最大化每个方括号。

💡 关键一跃

BN 的因子分解是学习问题的"解耦器"：一个全局优化问题自动拆成 n 个互不干扰的局部问题。估计"成绩"的 CPD 时，完全不用管"智力"的 CPD 长什么样。这是 BN 比马尔可夫网络容易学的根本原因——17.6 节会看到无向模型没有这份礼物。

⚠️ 常见误区

"分解是近似"——错。交换连乘顺序是恒等变形，一步近似都没有。分解之所以成立，恰恰是因为 BN 的联合分布本来就按结构因子化：结构已知，分解白送。

17.2表 CPD 的 MLE：就是频率计数

对离散变量的表格 CPD，逐个方括号求最大值，解是闭式的，而且朴素得不像话——最大似然估计（Maximum Likelihood Estimation, MLE）等于频率计数：

θ̂x|u = #{X = x, Pa = u}#{Pa = u}

读法：在所有"父节点配置 = u"的样本里，数一下 X = x 占了多大比例。这个比例就是 MLE。

例 1：学生网络 G 的 CPD，完整手算

回到学生网络：成绩 G 依赖难度 D（Easy/Hard）与智力 I（High/Low）。收集了 130 名学生的完整记录，按父节点配置分组计数：

DIG = AG = BG = C行合计
EasyHigh305035
EasyLow1510530
HardHigh5201035
HardLow052530

逐行除以行合计，整张 CPD 一次算完：

P(G | D, I)ABC
Easy, High30/35 ≈ 0.8575/35 ≈ 0.1430/35 = 0
Easy, Low15/30 = 0.50010/30 ≈ 0.3335/30 ≈ 0.167
Hard, High5/35 ≈ 0.14320/35 ≈ 0.57110/35 ≈ 0.286
Hard, Low05/30 ≈ 0.16725/30 ≈ 0.833

比如 P(G=A | Easy, High) = 30/35 ≈ 0.857——简单课 + 高智力，85.7% 拿 A。这就是参数学习的全部：数清楚，除一下。

✅ 为什么计数就是 MLE（一句话推导）

对某一行配置 u，似然中涉及它的部分是 ∏x θx|u#(x,u)，约束 Σx θx|u = 1。这是加权几何平均最大化，用拉格朗日乘子法（或对数似然求导）一步解出 θ̂x|u ∝ #(x,u)。计数不是近似，是精确最优解。

其他 CPD 的 MLE 是什么

CPD 类型MLE 对应闭式解？
表格 CPD（离散）频率计数✅ 有
线性高斯 X = β₀ + ΣβⱼXⱼ + ε最小二乘回归估 β，残差方差估 σ²✅ 有
Logistic P(1|u) = σ(βᵀu)逻辑回归❌ 无 → 梯度上升（17.5）
💡 直觉

MLE 的世界观是"看到什么就信什么"：数据频率是多少，概率就填多少。这在数据充足时近乎完美；但下一节会看到，它对"没见过的"过于自信——直接判死刑。

17.3零概率灾难：为什么必须平滑

回看上一节算出的 CPD，有一个刺眼的格子：

P̂(G = A | Hard, Low) = 030 = 0

"难题 + 低智力"的 30 个学生里没人拿 A，于是 MLE 宣布：这件事的概率是 0——绝对不可能。

一个 0 如何毁掉整个数据集

现在来了一名新学生：课难、智力平平，却拿了 A。问模型"这条记录的概率是多少"：

P(Hard, Low, A, …) = P(D)·P(I)·P(A | Hard, Low)·… = P(D)·P(I)·0·… = 0

一条 CPD 条目是 0，整条样本的联合概率就是 0。更狠的是：如果测试集里有这么一名学生，整个测试集的似然变成 0（对数似然 −∞）——其余 129 条样本提供的全部证据瞬间作废。这就是零概率灾难（Zero-Frequency Problem）：模型把"没见过"当成"不可能"，而真实世界总会送来没见过的事。

⚠️ 这是 MLE 的结构性缺陷，不是数据问题

30 个样本不足以排除一个真实概率 1% 的事件（30 次都不中的概率仍有 0.99³⁰ ≈ 74%）。样本量永远有限，未观测 ≠ 不可能。任何要用似然做评估、做推理的系统，都必须消灭参数里的 0。

拉普拉斯平滑：给每个格子发"保底票"

拉普拉斯平滑（Laplace Smoothing）的做法：给每个计数先加上一个伪计数 α，再照常相除：

θ̂x|u = #{x, u} + α#{u} + α · |Val(X)|

α = 1 时叫加一平滑。用它重算两个关键格子（|Val(G)| = 3）：

  • P̂(G=A | Easy, High) = (30+1)/(35+3) = 31/38 ≈ 0.816（比 0.857 略低，向均匀方向收缩）；
  • P̂(G=A | Hard, Low) = (0+1)/(30+3) = 1/33 ≈ 0.030（不再是 0，新学生的似然得救了）。
💡 直觉

平滑 = 假装每个格子里预先躺了 α 个"保底样本"。数据多（35 个）时它们几乎没影响（0.857→0.816）；数据少或为零时，它们撑起一个不为零的地板。α 控制的是"先验均匀信念"与"数据证据"的配比——下一节会看到，这正是 Dirichlet 先验的贝叶斯解读。

17.4贝叶斯估计：把平滑变成原则，而非补丁

拉普拉斯平滑像事后打的补丁。贝叶斯参数估计（Bayesian Parameter Estimation）给出它的原则性来源：把 θ 本身当作随机变量，用数据更新对它的信念。

Dirichlet 先验与后验更新

对一个 K 值的 CPD 行 θ = (θ₁,…,θK)，配Dirichlet 先验（Dirichlet Prior）Dir(α₁,…,αK)——它是多项分布的共轭先验（Conjugate Prior），意思是：看到计数数据后，后验仍是 Dirichlet，参数简单相加：

P(θ | D) = Dir(α₁ + #(x¹,u), α₂ + #(x²,u), …, αK + #(xK,u))

预测下一条样本时，用后验期望，得到后验预测（Posterior Predictive）：

P(X = x | u, D) = αx + #(x, u)Σx′ αx′ + #(u)

注意它和拉普拉斯平滑长得一模一样：α 就是伪计数。拉普拉斯平滑 = 带 Dirichlet 先验的贝叶斯估计。

例 2：抛硬币，完整手算

一枚可疑硬币，先验 Dir(2, 2)（相当于预先见过 2 正 2 反）。抛 4 次，结果 3 正 1 反：

  • 后验：Dir(2+3, 2+1) = Dir(5, 3)；
  • 贝叶斯预测下一次为正：5/(5+3) = 5/8 = 0.625；
  • 对照 MLE：3/4 = 0.75。

贝叶斯把 0.75 往均匀方向拉回 0.625——4 次抛掷不足以推翻"硬币大概率接近公平"的先验。若抛 400 次仍是 3:1，后验 Dir(302,102)，预测 302/404 ≈ 0.748，几乎等于 MLE：数据多了，先验自然退场。

💡 等价样本量

定义等价样本量（Equivalent Sample Size）N′ = Σx αx：先验相当于在数据之外预先看过的样本数。Dir(2,2) 的 N′=4，所以 4 个真样本只能把信念"扳动一半"；400 个样本则完全压过它。选先验的本质 = 决定用多少个"虚拟样本"表达你的先见。

回到学生例子

给 Easy,High 行配先验 Dir(2,2,2)，后验 = Dir(32,7,2)，预测 P(G=A|Easy,High,D) = 32/41 ≈ 0.780（对比 MLE 0.857、加一平滑 0.816）。三种方法给出三个数，数据越多，三个数越接近。

⚠️ 常见误区

"贝叶斯估计比 MLE 准"——不一定。先验是把双刃剑：数据少时它是护栏，先验错了它就是偏见。只能说贝叶斯估计给出了诚实的答案：一个包含不确定性的后验，而不是一个假装确定的小数。

17.5广义 CPD：当计数不够用时，梯度上升登场

表格 CPD 的参数量随父节点数爆炸（k 个二元父节点就有 2k 行），所以第5章引入了紧凑的广义 CPD。它们的 MLE 不再只是数数：

  • 线性高斯 X = β₀ + Σj βⱼXⱼ + ε：最大化似然 ⟺ 最小化平方误差，β 的最小二乘解有闭式公式，σ² 用残差方差估计。回归就是 MLE。
  • Logistic CPD P(X=1|u) = σ(βᵀu)：似然是凹函数（无局部最优），但没有闭式解——σ 的非线性让"令导数为 0"得不到解析式。用梯度上升（Gradient Ascent）迭代：
∂ℓ/∂βⱼ = ∑m [ x⁽ᵐ⁾ − σ(βᵀu⁽ᵐ⁾) ] · uⱼ⁽ᵐ⁾

读法：（真实标签 − 预测概率）× 特征值，在全数据集上求和。预测偏高的样本把 β 往回拉，偏低的往上推，直到平衡。这正是逻辑回归的训练式——在 PGM 视角下，它就是 logistic CPD 的 MLE。

✅ 一个统一的图景

完全数据 + 有向结构下，每个 CPD 的学习都是一个独立的小问题：表 CPD → 计数；线性高斯 → 最小二乘；logistic → 逻辑回归。你在机器学习课学过的"单点估计器"，在这里全部各就各位——PGM 只是把它们挂到图结构上。

17.6关键反直觉点：无向模型的 MLE 没有闭式解

本章的一切轻松——分解、计数、闭式更新——都是有向 + 归一化局部带来的。换到马尔可夫网络，试试同样的 MLE。对数线性 MN 的对数似然：

ℓ(θ) = ∑m ∑i θᵢ fᵢ(x⁽ᵐ⁾) − M · log Z(θ)

前一项是按样本、按特征分解的，很好算。麻烦全在第二项：配分函数 Z(θ) = Σx exp(Σᵢ θᵢfᵢ(x)) 依赖所有参数，而且要对全体赋值求和。它把每个 θᵢ 都拽进同一个全局归一化里——似然无法分解成独立的局部问题，"分别令导数为零"得到的方程组互相纠缠，没有闭式解。

连梯度都带着推理的负担：

∂ℓ/∂θᵢ = ∑m fᵢ(x⁽ᵐ⁾) − M · Eθ[fᵢ(X)]

第二项是模型分布下的特征期望——算它就等于做一次推理（第9–11章的事）。也就是说：MN 每走一步梯度，都要先解一个推理问题。

完整推导：logZ 是怎样把一切耦在一起的

上面两条结论——似然里的 −M·log Z(θ)、梯度里的 Eθ[fᵢ]——不是断言。这里一步不跳地推一遍，顺便把"耦合"摸到手里。

第一步：写对数似然，盯住第二项。对数线性模型下，单条样本的对数概率是：

log P(x; θ) = ∑i θᵢ fᵢ(x) − log Z(θ)

M 条独立样本的似然相乘，取对数后变成连加：

ℓ(θ) = ∑m=1M ∑i θᵢ fᵢ(x⁽ᵐ⁾) − M · log Z(θ)

麻烦全在第二项：log Z(θ) 是对全体赋值求和，而 exp 里躺着每一个参数——所有 θ 被耦进同一个数。对比 17.1：BN 的归一化在每个 CPD 内部就地完成，参数互不相欠；MN 把归一化拖到了全局，耦合由此而来。

第二步：对 θᵢ 求导，梯度露出真身。第一项的导数白送（就是数据计数）；关键是把 log Z 的导数算到底——链式法则、代入 Z 的定义、最后认出期望：

∂ log Z∂θᵢ = 1Z · ∂Z∂θᵢ = 1Z ∑x fᵢ(x) · exp( ∑j θⱼ fⱼ(x) ) = ∑x fᵢ(x) · P(x; θ) = Eθ[fᵢ]

代回 ∂ℓ/∂θᵢ = ∑m fᵢ(x⁽ᵐ⁾) − M·(∂logZ/∂θᵢ)，梯度 = 数据计数 − 模型期望：

∂ℓ/∂θᵢ = ∑m fᵢ(x⁽ᵐ⁾) − M · Eθ[fᵢ] = M · ( ED[fᵢ] − Eθ[fᵢ] )

其中 ED[fᵢ] = (1/M)·∑m fᵢ(x⁽ᵐ⁾) 是特征在数据里的平均——它就是"数数"，闭式可得；难的是第二项，它要在当前模型下做推理。

✅ 矩匹配：无向版的"频率计数"

令梯度为零，得 Eθ[fᵢ] = ED[fᵢ]（对每个特征 i）：最优模型的特征期望必须等于数据中的特征频率——模型矩对齐数据矩，这就是矩匹配（Moment Matching）。形式上就是 BN"填频率"的推广；但左边 Eθ[fᵢ] 通过 Z(θ) 依赖全部 θ，方程组互相纠缠，除最简模型外没有闭式解，只能迭代：梯度上升（每步先做一次推理算 Eθ）、有隐变量时换 EM（第19章）、或迭代比例拟合（Iterative Proportional Fitting, IPF）。

⚠️ 常见误区

"无向模型不过是换种写法，照样拿频率直接填格子"——错。BN 里频率就是答案，因为每个 CPD 各自归一化、参数互不相欠；MN 里频率 ED[fᵢ] 只是矩匹配方程的右半边，左半边随全体参数一起动，没有任何一个 θᵢ 能单独写成计数比。把频率硬填进去，得到的"模型"连矩匹配条件都不满足。

第三步：一个能枚举到底的小例子，亲手摸"耦合"。链 X—Y—Z，全部二值；两个特征 f₁(x,y) = 1{x=y}、f₂(y,z) = 1{y=z}（邻居相等得 1 分），即 P(x,y,z) ∝ exp(θ₁f₁ + θ₂f₂)。8 种赋值全部列出：

x, y, zf₁f₂未归一化权重 exp(θ₁f₁+θ₂f₂)
0,0,011eθ₁+θ₂
0,0,110eθ₁
0,1,0001
0,1,101eθ₂
1,0,001eθ₂
1,0,1001
1,1,010eθ₁
1,1,111eθ₁+θ₂
Z(θ)2eθ₁+θ₂ + 2eθ₁ + 2eθ₂ + 2

对它求 ∂logZ/∂θ₁：只有 f₁=1 的四行对 ∂Z/∂θ₁ 有贡献，分子是 2eθ₁+θ₂+2eθ₁，分母是整个 Z：

Eθ[f₁] = ∂ log Z∂θ₁ = 2eθ₁+θ₂ + 2eθ₁2eθ₁+θ₂ + 2eθ₁ + 2eθ₂ + 2

看分母：θ₂ 就站在 Eθ[f₁] 的表达式里；对称地，θ₁ 也站在 Eθ[f₂] 里。想定 θ₁ 必须先知道 θ₂，反之亦然——没有一个参数能被单独解出来，这就是"耦合"的具体形态。（这条链小到 Z 碰巧还能因式分解、把另一个参数约掉；一旦图里出现环或特征变多，这种运气立刻消失，Eθ[fᵢ] 就钉死在全体 θ 上。）

代入数字感受一下迭代在干什么。θ₁=θ₂=0 时 Z = 2+2+2+2 = 8，Eθ[f₁] = 4/8 = 0.5（全均匀，邻居自然一半概率相等）。把 θ₁ 拧到 ln3、θ₂ 保持 0：Z = 2·3+2·3+2+2 = 16，Eθ[f₁] = (2·3+2·3)/16 = 12/16 = 0.75。若数据频率恰为 ED[f₁] = 0.75（且 ED[f₂] = 0.5，此点的模型值），梯度在这点为零——矩匹配达成；否则梯度继续推着 θ 走，而每走一步都得重算 Z 和这些期望。

第四步：记住它在全书的位置。这个推导是第20章（马尔可夫网络学习）的前置：那里正式处理 MN 的参数学习，包括 CRF——条件模型的配分函数变成 Z(x)，随每条样本的观测 x 变化，梯度仍是"数据计数 − 模型期望"，只是期望要对每条样本各算一遍：推理负担从"每步一次"涨到"每步 M 次"。伪似然、对比散度等技术，本质上都是在绕开这一步。

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
似然分解（Likelihood Decomposition）
点击翻面 →
定义P(D|θ) = ∏ᵢ[∏ₘ P(xᵢ⁽ᵐ⁾|paᵢ⁽ᵐ⁾;θᵢ)]，全局似然拆成每个 CPD 的局部项。
解决问题让全局学习变成 n 个独立小问题，是 BN 易学性的根源。
直觉分科考试：每科单独阅卷，互不干扰。
误区以为是近似——交换连乘顺序是恒等变形，分文不差。
何时用Ch17 全部闭式解的基础；Ch19 EM 的 M 步仍靠它。
概念卡 2
最大似然估计（MLE）
点击翻面 →
定义θ̂ = argmax P(D|θ)；表 CPD 下 = 频率计数 #(x,u)/#(u)。
解决问题给"参数从哪来"一个唯一、可计算、数据驱动的答案。
直觉看到什么信什么：频率即概率。
误区以为它总是最优——小样本时高方差，未见事件直接判 0。
何时用数据充足时的默认选择；EM 的 M 步内核（Ch19）。
概念卡 3
零概率灾难（Zero-Frequency Problem）
点击翻面 →
定义未观测配置的 MLE 概率为 0，使任何含该配置的样本似然整体为 0。
解决问题它本身是被解决的问题：MLE 的结构性缺陷。
直觉一个人考零分，全班的总成绩单被判作废。
误区以为多收数据就能根治——样本永远有限，长尾永远存在。
何时用任何要用似然评估/推理的系统上线前的必检项。
概念卡 4
拉普拉斯平滑（Laplace Smoothing）
点击翻面 →
定义θ̂ = (#(x,u)+α) / (#(u)+α·|Val(X)|)，每个格子加伪计数 α 再归一化。
解决问题消灭零概率，给未见事件留一个非零地板。
直觉每个选项先发 α 张保底票，再按真实得票分配。
误区以为 α 越大越好——α 过大把分布抹成均匀，抹掉真实信号。
何时用文本分类、小样本 CPD；与 Dirichlet 先验的贝叶斯估计等价。
概念卡 5
Dirichlet 先验与等价样本量（Dirichlet Prior / ESS）
点击翻面 →
定义多项 CPD 的共轭先验 Dir(α₁…α_K)；后验 = 先验参数加计数；ESS N′=Σα。
解决问题让"平滑"从补丁变成原则：先验即伪样本，后验有闭式。
直觉预先看过 N′ 个虚拟样本，再和真数据一起数。
误区以为先验免费——先验错了，小数据下它比噪声更误导。
何时用小数据、需要不确定性量化、BDe 评分（Ch18）的基石。
概念卡 6
logZ(θ) 耦合（Partition-Function Coupling）
点击翻面 →
定义MN 的 Z(θ) 依赖全部参数且需全局求和，使似然不可分解。
解决问题它是被绕开的对象：MN 学习困难的总根源。
直觉全班调分：动一个人的分，所有人的排名都变。
误区以为只是"算得慢"——它还让梯度必须做推理，让结构评分不可分解。
何时用Ch20 全部技术的靶子：伪似然、CD、CRF 都在绕它。

📝分层习题

L1 概念辨析判断对错：完全数据下，BN 各 CPD 的 MLE 必须联合优化，因为所有参数共享同一个似然函数。说明理由。
提示

回到似然分解：每个 θᵢ 出现在几个方括号里？

完整解答
错。似然分解 P(D|θ) = ∏ᵢ[∏ₘ P(xᵢ⁽ᵐ⁾|paᵢ⁽ᵐ⁾;θᵢ)] 中，每个 θᵢ 只出现在自己的方括号内，各括号可以独立最大化。"共享同一个似然"在乘法结构下不构成耦合——这正是 BN 参数学习简单的根本原因。联合优化只在似然不可分解时（如无向模型的 logZ 耦合）才被迫出现。
L1 概念辨析判断对错：拉普拉斯平滑的 α 越大，参数估计越准确。说明理由。
提示

α 的贝叶斯含义是什么？α 趋于无穷时估计趋于什么分布？

完整解答
错。α 是伪计数，等价于 Dirichlet 先验的强度。α 越大，估计越被拉向均匀分布（先验形状），与真实数据无关；α→∞ 时任何 CPD 行都变成均匀分布，数据信号被彻底淹没。正确说法是：α 控制先验与数据的权衡，数据少时适度 α 防过拟合，数据多时小 α 即可——它是一个需要根据数据量和先验信念权衡的超参数，不是越大越准。
L2 手算推导学生网络中 Easy,Low 行的计数为 (A, B, C) = (15, 10, 5)。手算：① 该行的全部 MLE 条目；② 加一平滑（α=1）后的全部条目。
提示

MLE 除以行合计；平滑后分子加 1、分母加 |Val(G)| = 3。

完整解答

行合计 = 15+10+5 = 30。

① MLE：P(A) = 15/30 = 0.500；P(B) = 10/30 ≈ 0.333；P(C) = 5/30 ≈ 0.167。

② 加一平滑（分母 30+3 = 33）：P(A) = 16/33 ≈ 0.485；P(B) = 11/33 = 1/3 ≈ 0.333；P(C) = 6/33 ≈ 0.182。

观察：高频项（A）被略微压低，低频项（C）被抬高——平滑把概率质量从高频向低频转移，方向朝均匀。

L2 手算推导硬币先验 Dir(2,2)，抛 4 次得 3 正 1 反。手算：① 后验分布；② 下一次为正的贝叶斯预测；③ 与 MLE 比较并解释差异来源。
提示

后验参数 = 先验参数 + 对应计数；预测 = 后验期望 = 归一化后的后验参数。

完整解答

① 后验 = Dir(2+3, 2+1) = Dir(5, 3)。

② P(正|D) = 5/(5+3) = 5/8 = 0.625。

③ MLE = 3/4 = 0.75，比贝叶斯预测高 0.125。差异来源：先验 Dir(2,2) 的等价样本量 N′=4，相当于预先见过 2 正 2 反；贝叶斯预测实为 (3+2)/(4+4)，是 4 个真实样本与 4 个虚拟样本的折中。真实数据增至 400 条时先验影响可忽略——数据与先验按"样本数"加权竞争。

L3 建模应用某医院用已知结构的 BN 做辅助诊断：Disease（流感/感冒/罕见病R）→ Cough（咳嗽）、Disease → Fever（发烧）。收集 202 条完整病历：流感 80 例（咳嗽 70、发烧 60）；感冒 120 例（咳嗽 40、发烧 30）；罕见病 R 仅 2 例（咳嗽 2、发烧 0）。① 估计三张 CPD；② 指出哪一行最危险、为什么；③ 给出修复方案并重算该行。
提示

每个症状一张以 Disease 为条件的 CPD；注意 R 行的样本量和发烧计数。

完整解答

① P(Cough|Disease)：流感 70/80 = 0.875；感冒 40/120 ≈ 0.333；R 2/2 = 1.0。P(Fever|Disease)：流感 60/80 = 0.75；感冒 30/120 = 0.25；R 0/2 = 0。

② R 行最危险：只有 2 个样本，P(Fever|R)=0 是零概率——若一个 R 病人发烧，模型给他的病历概率为 0，可能直接排除正确诊断。而且 2 个样本给出的 1.0 / 0 两个极端值都极不可靠。

③ 修复：拉普拉斯平滑 α=1（或等价 Dir(1,1) 先验）。R 行发烧 CPD 重估：P(Fever|R) = (0+1)/(2+2) = 0.25；咳嗽 P(Cough|R) = (2+1)/(2+2) = 0.75。更彻底的做法：R 太罕见时引入医学先验（如 Dir(5,5)）而非均匀先验，或直接合并到"其他疾病"类别。
