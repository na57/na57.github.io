3.1为什么需要贝叶斯网络：从维度诅咒说起

要对 n 个随机变量做概率推理，原则上你需要完整的联合分布 P(X₁, X₂, …, Xₙ)。如果每个变量取 d 个值，你需要 dⁿ 个参数。100 个二元变量就是 2¹⁰⁰ ≈ 10³⁰ 个参数——没有任何计算机存得下。

出路只有一条：利用变量之间的独立性结构，把大分布拆成小因子的乘积。

最极端的情况是所有变量相互独立：

P(X₁, X₂, …, Xₙ) = P(X₁) · P(X₂) · … · P(Xₙ)

参数从指数级降到线性级。但现实中变量很少完全独立。于是退而求其次——朴素贝叶斯：假设给定类别 C 后，所有特征条件独立：

P(C, X₁, …, Xₙ) = P(C) · ∏ P(Xᵢ | C)
💡 关键一跃

朴素贝叶斯的假设太强（所有特征只通过类别关联）。贝叶斯网络的核心思想就是放宽这个假设：用一张图来精确声明"谁直接影响谁"，而不是假设所有人都只依赖同一个原因。图越贴近真实结构，模型就越紧凑又越准确。

3.2贝叶斯网络的定义：图 + 条件概率表

一个贝叶斯网络由两部分组成：

  • 结构 𝒢：一个有向无环图（DAG）。节点是随机变量，有向边 X → Y 表示 X 直接影响 Y。
  • 参数 Θ：每个节点 Xᵢ 携带一个条件概率分布（CPD）：P(Xᵢ | Pa(Xᵢ))，其中 Pa(Xᵢ) 是 Xᵢ 在图中的父节点集合。

两者合起来，给出全书最重要的公式——链式法则的图结构化版本：

P(X₁, X₂, …, Xₙ) = ∏i=1…n P(Xᵢ | Pa(Xᵢ))

读法：联合分布 = 每个变量"以自己父节点为条件"的概率的乘积。图告诉你每个 P(Xᵢ | ·) 里该填谁。

学生例子（Student Example）

这是全书反复使用的经典例子，务必熟悉。一位教授要根据学生情况写推荐信：

变量含义取值
D课程难度 Difficulty简单 / 困难
I学生智力 Intelligence低 / 高
G成绩 GradeA / B / C
SSAT 分数低 / 高
L推荐信质量 Letter弱 / 强
图 3.1 学生例子的 DAG。注意 G 处是一个 V-结构：D → G ← I（后面要考）。

按因子分解公式展开：

P(D, I, G, S, L) = P(D) · P(I) · P(G | D, I) · P(S | I) · P(L | G)

参数对比（假设 G 取 3 个值，其余二元）：

  • 完整联合分布：2×2×3×2×2 − 1 = 47 个自由参数
  • 贝叶斯网络：1 + 1 + 8 + 2 + 3 = 15 个参数

变量越多差距越恐怖——这就是因子分解的意义。

3.3d-分离：用图读出独立性

这是本章——也是全书——最核心、最实用的工具。它要回答的问题是：给定这张图，观察到某些变量后，另外两个变量还相关吗？

答案不需要任何概率计算，只需要看图的连通性。秘诀在于：任何长路径都可以分解为三种基本的两节点结构，每种结构有自己的"通断规则"。

图 3.2 三种基本两节点路径结构。前两种"观测即阻断"，第三种恰好相反。

逐个理解

① 链式 X → Z → Y：X 通过 Z 间接影响 Y。例子：火灾 → 烟雾 → 警报。一旦你知道了烟雾浓度，火情本身对警报的猜测不再提供新信息：X ⊥ Y | Z。

② 共同原因 X ← Z → Y：Z 同时导致 X 和 Y。例子：季节 → 流感，季节 → 过敏。季节固定后，得没得流感不会改变你对过敏的判断：X ⊥ Y | Z。

③ V-结构 X → Z ← Y：X 和 Y 共同导致 Z。规则与前两种恰好相反：

  • 不观测 Z 时：X 和 Y 独立（X ⊥ Y）
  • 观测 Z（或 Z 的后代）后：X 和 Y 变得相关（X ⊥̸ Y | Z）
⚠️ V-结构：全书最反直觉的概念

例子：学生例子中 智力(I) → 成绩(G) ← 难度(D)。一个学生聪明与否、课程难不难，本来毫不相干（I ⊥ D）。

但一旦你得知他成绩是 C（观测了 G），再告诉你"这门课很简单"（D=简单），你立刻会推断"这学生可能不太聪明"——I 和 D 突然相关了。这叫解释消除（Explaining Away）：两个原因竞争解释同一个结果，确认一个就削弱另一个。

这个机制解释了现实中大量的"选择偏差"：比如"被名校录取的学生里，家境和天赋负相关"——因为录取是 V-结构的汇聚点。

d-分离的正式规则

✅ 判定规则

路径 X₁ — X₂ — … — Xₙ 在给定观测集 Z 下被阻断，当且仅当路径上存在某个三节点段满足以下任一条件：

① 链式或共同原因（→ Z →、← Z →、← Z ←）且 Z 被观测；
② V-结构（→ Z ←）且 Z 及其所有后代都未被观测。

如果 X 和 Y 之间的每一条路径都被阻断，则 X ⊥ Y | Z——称 X 与 Y 被 Z d-分离。

在学生例子上练手（对照图 3.1）：

  • D ⊥ I？——D 和 I 之间唯一路径 D → G ← I 是 V-结构，G 未观测 ⟹ 独立 ✓
  • D ⊥ I | G？——观测了 G，V-结构被激活 ⟹ 不独立 ✗（这就是解释消除）
  • D ⊥ S | I？——路径 D → G ← I → S：在 I 处是链式结构且 I 被观测 ⟹ 阻断 ⟹ 独立 ✓

3.4反过来：从分布到图（I-Map 与 I-等价）

3.3 节回答的是"给定图，分布满足哪些独立性"。这一节反过来问：给定一个分布，哪张图能表示它？这个问题是第 18 章结构学习的理论根基。

  • I-Map（独立映射）：图 𝒢 说"独立"的地方，分布 P 确实独立，即 I(𝒢) ⊆ I(P)。完全图（任意两节点相连）永远是 I-Map——它什么都不声明，自然不会错。我们要的是最小 I-Map：再删任何一条边就不再是 I-Map。
  • P-Map（完美映射）：图与分布的独立性完全一致，I(𝒢) = I(P)。P-Map 不一定存在——有些分布的独立结构没有 DAG 能完美表达。

I-等价：方向不是都能学出来的

一个惊人的事实：X → Y → Z、X ← Y → Z、X ← Y ← Z 三张图编码的独立性集合完全相同（都只有 X ⊥ Z | Y）。它们互为 I-等价。

✅ 判定定理

两个 DAG I-等价，当且仅当：① 骨架相同（忽略方向后的无向图一样）；② V-结构集合相同。

推论：只有 V-结构（X→Z←Y）的方向可以从独立性信息中确定。因此从纯观测数据学结构（第 18 章），最多只能学到等价类，而不是唯一的图。要从"相关"跨到"因果方向"，需要额外信息：时间顺序、干预实验、或领域知识（第 21 章）。

📝分层习题

L1 概念辨析链式结构 X → Z → Y 中，观测 Z 之后 X 和 Y 仍然相关。对吗？
提示

对照三种基本路径结构的"观测后通/断"表。

完整解答
不对。链式结构中 Z 是中间节点，观测它会阻断路径，故 X ⊥ Y | Z 成立。易错点：和 V-结构记反——X→Z←Y 才是"观测 Z 反而连通"。口诀：链式分叉"观测才断"，V-结构"观测才通"。
L1 概念辨析"完全图（任意两节点相连）是任何分布的 P-Map。"这个说法对吗？
提示

P-Map 要求 I(𝒢) = I(P)，两边都要相等。

完整解答
不对，它只是 I-Map。完全图不声明任何独立性（I(𝒢) = ∅），自然 ⊆ I(P)——"什么都不承诺，自然不会错"。但 P-Map 要求反向也成立：分布里真实存在的独立性图也得声明，完全图做不到。易错点：I-Map 只要求"图说的都对"，P-Map 要求"说的全对且说全"。
L2 手算推导学生例子（图 3.1）：D、I、S、L 为二元，G 为三元。分解为 P(D)·P(I)·P(G|D,I)·P(S|I)·P(L|G)。验证总自由参数恰为 15。
提示

k 个父节点的 CPD：参数数 = 父节点组合数 ×（自身取值数 − 1）。

完整解答
P(D)：1；P(I)：1；P(G|D,I)：父组合 2×2=4，G 三元各 2 个 → 4×2=8；P(S|I)：2×1=2；P(L|G)：3×1=3。
合计 1+1+8+2+3 = 15 ✓。
对比完整联合分布：2×2×3×2×2 − 1 = 47 个——图结构砍掉约 2/3。变量一多，差距从"2/3"变成"天文 vs 线性"。
L2 手算推导学生例子（图 3.1）中分别判定：① L ⊥ I（不观测任何变量）？② L ⊥ I | G？说明每条路径上发生了什么。
提示

L 与 I 之间只有一条路径：L ← G ← I。看中间节点 G 属于哪种结构。

完整解答
路径 L←G←I 是链式结构（I→G→L 倒着走），G 是中间节点。
① 不观测 G：路径连通，L 与 I 相关（智力影响成绩、成绩影响推荐信）——L ⊥ I 不成立。
② 观测 G：链式中间节点被观测 → 路径阻断 → L ⊥ I | G 成立。
注意别选 V-结构来分析：虽然 G 也是 I→G←D 的汇聚点，但那是"G 与 D 之间"的事，与 L—I 这条路径无关。
L3 建模应用场景：睡眠质量 Q 和复习时长 R 共同影响考试成绩 E，E 又影响能否拿奖学金 W。① 画出 DAG；② 写出因子分解；③ 指出图中的 V-结构；④ 已知某同学成绩差（E=差），"他睡得少"和"他复习少"还独立吗？用解释消除说明。
提示

两个原因一个结果，先想谁是汇聚点；观测汇聚点会发生什么？

完整解答
① Q → E ← R，E → W。
② P(Q)·P(R)·P(E|Q,R)·P(W|E)。
③ V-结构：Q → E ← R（E 是汇聚点）。
④ 不独立了。Q ⊥ R 边际成立（睡眠和复习原本各不相干），但观测 E=差 激活了 V-结构：若知道他复习很充分，成绩差就更可能"怪"睡眠——解释消除。这正是学生例子里 I 与 D 在观测 G 后联动的同款机制。

第 1 题 · 因子分解
某 BN 有边 A→C、B→C。它的联合分布因子分解为：
  • A. P(A)·P(B)·P(C)
  • B. P(A)·P(B)·P(C | A, B)
  • C. P(C)·P(A | C)·P(B | C)
  • D. P(A | B, C)·P(B | A, C)·P(C)
每个节点以父节点为条件：A 和 B 无父节点，C 的父节点是 {A, B}。答案 B。注意 A 和 B 是 V-结构的两个父节点，边际独立但给定 C 后相关。
第 2 题 · d-分离
学生例子（图 3.1）中，"S ⊥ D | G"是否成立？
  • A. 成立，因为 S 和 D 没有直接边
  • B. 成立，因为观测 G 阻断了所有路径
  • C. 不成立，因为观测 G 激活了 V-结构
  • D. 无法判断
路径 S ← I → G ← D：观测 G 使 V-结构 I→G←D 被激活，路径连通，所以 S 和 D 在观测 G 后相关（已知 SAT 低且成绩差，课程难度信息会改变你对智力的推断）。答案 C。直觉：G 是"汇聚点"，观测它会把它上游的原因都联动起来。
第 3 题 · V-结构直觉
"才华 → 被录取 ← 家境"是 V-结构。以下哪个现象是它的直接推论？
  • A. 在被录取的学生中，才华和家境呈负相关
  • B. 在全体人群中，才华和家境呈负相关
  • C. 才华和家境永远无关，无论是否只看录取者
  • D. 家境好的学生一定更有才华
全体人群中才华 ⊥ 家境（边际独立）。但"只看录取者"= 观测了 V-结构的汇聚点，激活了两原因的关联：家境普通的人被录取，更可能靠才华。答案 A。这就是著名的"伯克森悖论"（Berkson's paradox）。
第 4 题 · I-等价
以下哪组 DAG 不互为 I-等价？（提示：检查 V-结构）
  • A. X→Y→Z 与 X←Y←Z
  • B. X→Y→Z 与 X→Y←Z
  • C. X←Y→Z 与 X←Y←Z
  • D. X→Y→Z 与 X←Y→Z
I-等价要求骨架相同 + V-结构相同。选项 B 中第二张图 X→Y←Z 含 V-结构（独立性集合为空：X 与 Z 无条件独立……不，是 X⊥Z 边际成立而条件不成立），而 X→Y→Z 没有 V-结构。两者独立性集合不同。答案 B。
第 5 题 · 参数计数
5 个二元变量的链式 BN：X₁→X₂→X₃→X₄→X₅。完整联合分布 vs BN 分解，各需多少自由参数？
  • A. 31 与 10
  • B. 32 与 5
  • C. 31 与 9
  • D. 32 与 10
完整联合分布：2⁵−1 = 31。BN：X₁ 需要 1 个参数，其余 4 个节点各有一个二元父节点、各需 2 个参数：1 + 4×2 = 9。答案 C。
