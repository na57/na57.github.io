5.1为什么表格 CPD 会爆炸：把参数一个一个数出来

第 3 章告诉我们：贝叶斯网络 = 图 + 每个节点一张条件概率表（Conditional Probability Distribution, CPD）。当时我们默认 CPD 就是一张表：每种父节点取值组合对应一行，行内给出子节点各取值的概率。第 4 章又给了无向图这套"骨架"。但骨架搭好之后，一个被刻意回避的问题浮出来：这些表到底有多大？

手算例 1：参数计数

设节点 X 是二值的（如"是否发烧"），有 k 个二值父节点（k 个可能病因）。表格 CPD 需要为每一种父节点组合写一行，共 2ᵏ 行；每行里 P(x⁰) 与 P(x¹) 和为 1，只有 1 个自由参数。所以自由参数总数 = 行数 = 2ᵏ。逐个数：

k（父节点数）父节点组合数（行数）自由参数数
12¹ = 22
22² = 44
32³ = 88
52⁵ = 3232
102¹⁰ = 10241024
202²⁰ ≈ 1.05 × 10⁶约 105 万

一般地，若每个父节点取 d 个值、子节点取 m 个值，则行数 = dᵏ，自由参数数 = dᵏ · (m − 1)。指数在 k 上——这就是爆炸的精确位置。

⚠️ 爆炸不只是存储问题

1024 个参数意味着：想用数据估计这张表，每种父节点组合都得见过足够多的样本。组合数指数增长，数据需求也指数增长——这就是第 17 章参数学习里"数据不够、过拟合"的直接根源。省参数就是省数据。

💡 关键一跃

爆炸的根源是表格 CPD "一视同仁"地对待全部 2ᵏ 行——它不允许行与行之间共享任何规律。但真实世界里的 CPD 几乎总有规律：某些行完全相同、某些父节点在某些情形下根本无关、多个原因的影响各自独立……本章就是把这些"行间规律"逐条形式化，每条规律换一批参数。

5.2第一类规律：有些行被钉死（确定性 CPD），有些父节点在特定情形下无关（树 CPD 与 CSI）

上一节说爆炸源于"行间无规律"。最简单的规律是：给定父节点后，子节点的值被完全钉死。

确定性 CPD（Deterministic CPD）

如果 X = f(Pa(X)) 是父节点的函数，那么

P(X = f(pa) | pa) = 1

每行都是一个 0/1 的退化分布，自由参数为 0。例子：数字电路里的 OR 门 Z = X ∨ Y（4 行表，每行概率非 0 即 1）；物理关系 Z = X + Y。确定性依赖虽然极端，在电路诊断、方程约束类问题里却非常自然——而且它会改变推理的难度（确定性等式可以直接传播取值）。

树 CPD（Tree-CPD）：不同上下文，看不同的父节点

更常见的情形是：子节点在某些父节点取值下，对其余父节点"免疫"。看一个具体例子。

手算例 2：Job 录用——树 CPD 的叶节点 vs 完整表的行数

招聘场景：J = 是否录用（二值），父节点三个：A = 实习经历（强/弱）、L = 推荐信（强/弱）、S = SAT 分数（高/低）。完整表格 CPD 需要 2³ = 8 行、8 个自由参数。

但真实决策过程是：实习强的候选人直接录用概率 0.9，雇主根本不看推荐信和 SAT；实习弱的，才看推荐信；推荐信强的，再看 SAT。画成决策树：

图 5.1 Job 例子的树 CPD：内部节点（蓝）测试父节点，叶节点（橙）给出分布。注意"实习强"分支一刀切断了 L 与 S。

数参数：这棵树有 4 个叶节点，每个叶是一个 Bernoulli 分布（1 个自由参数），共 4 个自由参数——完整表是 8 个。省下的 4 个来自两处"免疫"：

  • A = 强的分支：1 个叶顶替了完整表里的 4 行（L、S 的 4 种组合全共享一个分布）；
  • A = 弱且 L = 弱的分支：1 个叶顶替了 2 行（S 的 2 种取值共享一个分布）。

一般结论：树 CPD 的自由参数数 = 叶节点数 ×（每叶分布的自由参数数）。树越"不平衡"（早分支早收叶），省得越多。

上下文特定独立性（CSI）

树 CPD 里"在某些取值下无关"的现象有正式名字：上下文特定独立性（Context-Specific Independence, CSI）。

定义：X 与 Y 在给定 Z 与上下文 C = c 下独立，记作

X ⊥c Y | Z, C = c

意思是：只在 C 取特定值 c 的那些"世界切片"里，X ⊥ Y | Z 才成立；C 取别的值时未必。Job 例子里：

  • J ⊥c {L, S} | A = 强（实习强时，推荐信与 SAT 都不再影响录用）；
  • J ⊥c S | L, A = 弱, L = 弱（实习弱且推荐信弱时，SAT 也不影响）。
⚠️ CSI 读不出图

这是本章最重要的警示：标准 d-分离只能读出"对所有上下文都成立"的独立性。Job 例子里图上有边 L→J、S→J，d-分离永远不会告诉你"L 有时不影响 J"——这条信息藏在 CPD 的内部结构里，图上完全不可见。要利用 CSI 加速推理，需要扩展的图算法（书上 5.x 节），这是第 9、10 章推理算法的一个增强方向。

💡 直觉

表格 CPD 把 2ᵏ 行当作 2ᵏ 个互不相干的"格子"；树 CPD 承认格子之间有层级结构——先问哪个变量、在哪个分支下其余变量失效。参数压缩 = 让共享同一命运的行合并成一个叶。

5.3第二类规律：多个原因各自独立地起作用（ICI 与 Noisy-Or）

上一节的规律是"某些父节点在某些情形下无关"。还有一种更结构化的规律：在医学诊断里，发烧可能由流感、感冒、过敏中任何一个引起——多个原因像多扇独立的"门"，每扇门各自有一定概率把结果"顶开"，且各门的失效互不相关。这就是因果影响独立性（Independence of Causal Influence, ICI）：每个父节点对子节点的影响通过一个独立的噪声机制传递，各机制之间互不干扰。

Noisy-Or 模型

ICI 最经典的实例是Noisy-Or 模型，适用于全二值变量。设 X 有父节点 Y₁,…,Yₖ。语义：X 为真，当且仅当至少一个为真的父节点"成功激活"了它；第 i 个父节点单独激活失败的概率记为 λi（失效概率）。各激活通道独立，所以"X 为假"要求所有活跃通道都失败：

P(x⁰ | y₁,…,yₖ) = ∏i : yᵢ = 1 λi

（没有父节点激活时，乘积为空 = 1，即 X 必为假——这是"无渗漏"版本。）P(x¹ | …) = 1 − 上式。参数数：k 个 λ，而不是 2ᵏ 行。

⚠️ Noisy-Or 是强假设，不是万能压缩器

它假设：①各病因独立起作用（不存在"流感 + 过敏同时得会格外危险"这类交互）；②X 为假 ⟺ 全部激活失败（无其他杂因）。假设不满足时，压缩换来的不是省参数而是系统性偏差。变体：可加一个"渗漏参数" λ₀ 表示未知病因；有序多值变量用 Noisy-Max / Noisy-Min。

💡 直觉

树 CPD 的规律在"行"上（哪些行共享分布）；ICI 的规律在"列"上（每个父节点一列影响，各列以乘法方式复合）。两者压缩的是不同方向的冗余。

5.4连续变量进门：Logistic CPD 手算，以及 CLG 的一句话预告

到目前为止，父节点、子节点都是离散的。现实中变量常常是连续的：学习时长、收入、体温。连续变量一旦进门，表格 CPD 连"行"都写不出来（父节点取值无穷多）。本章只开两扇小门，系统处理留给第 7 章（高斯网络）与第 14 章（混合网络推理）。

父连续、子离散：Logistic CPD（Sigmoid）

子节点 Y 二值、父节点 X₁,…,Xₖ 可取连续值时，标准选择是把父节点影响的线性加权和压进 sigmoid 函数——这就是Logistic CPD（也叫 sigmoid CPD）：

P(y¹ | x₁,…,xₖ) = σ(w₀ + ∑i wixi)，其中 σ(z) = 11 + e−z

σ 把任意实数 z 平滑压到 (0,1)：z→−∞ 时趋于 0，z = 0 时恰为 0.5，z→+∞ 时趋于 1。wi 是第 i 个父节点影响的强度与方向，w₀ 是基线。参数数：k+1 个权重，与父节点取值个数无关——表格的 2ᵏ 在这里彻底消失。

手算例 4：把 sigmoid 的数值一个一个摁出来

设录用模型 P(y¹ | G, A) = σ(−3 + 2G + 2A)，G、A ∈ {0,1}（成绩好、实习强）。先摁 σ 的几个关键点（记住 e¹ ≈ 2.718，e² ≈ 7.389，e³ ≈ 20.086）：

  • σ(−3) = 1/(1+e³) = 1/(1+20.086) = 1/21.086 ≈ 0.047
  • σ(−1) = 1/(1+e¹) = 1/(1+2.718) = 1/3.718 ≈ 0.269
  • σ(0) = 1/(1+1) = 0.5
  • σ(1) = 1/(1+e⁻¹) = 1/(1+0.368) = 1/1.368 ≈ 0.731

代入四种 (G, A) 组合：

GAz = −3+2G+2AP(y¹) = σ(z)
00−3≈ 0.047
10−1≈ 0.269
01−1≈ 0.269
11+1≈ 0.731

注意两个结构性质：①G 与 A 权重相同 → 两行概率相等，这是线性形式的必然结果（想表达"实习比成绩重要"就调权重）；②z 每加 2，概率沿 S 形曲线爬升一段——影响是可加的、单调的，没有交互项。父节点换成连续值（如 GPA = 3.7）也直接代入，无需离散化。这把贝叶斯网络和逻辑回归/神经网络直接接上了：一个 sigmoid CPD 就是一层神经元。

父离散、子连续：CLG 的一句话预告

反过来的组合——父节点离散、子节点连续——常用条件线性高斯（Conditional Linear Gaussian, CLG）：每种父节点配置下，子节点是一个（线性）高斯分布。例如体温计读数 T 连续，依赖是否发烧 F：

p(T | f⁰) = 𝒩(36.6, σ₀²)，p(T | f¹) = 𝒩(38.5, σ₁²)

若父节点也连续，则均值可以是父节点的线性函数（如 T 的均值 = a·体温真值 + b）。高斯分布的性质、参数估计、以及离散-连续混合网络如何推理，全部留给第 7 章和第 14 章——本章只需要记住"CLG 存在、它解决'父离散子连续'这一格"即可。

手算例 5：给定父配置，把一次 CLG 条件密度摁到底

预告太抽象，摁一次数字就有手感了。设体温计读数 T（连续）有两个父节点：F = 是否发烧（离散），X = 体温真值（连续）。CLG 给每种离散工况一套线性高斯参数：

p(T | f⁰, x) = 𝒩(0.98x + 0.86 ; 0.04)，   p(T | f¹, x) = 𝒩(0.98x + 0.86 ; 0.25)

（发烧时出汗蒸发干扰测量，读数波动更大：σ₀ = 0.2 vs σ₁ = 0.5。）

第一步：代入父配置 X = 37.0、F = f⁰，定出条件分布。均值 = 连续父的线性函数：0.98 × 37.0 + 0.86 = 36.26 + 0.86 = 37.12；方差取离散父对应的那一套：σ₀² = 0.04。于是 p(T | f⁰, x=37.0) = 𝒩(37.12, 0.04)——均值随连续父线性滑动、方差沿离散父切换，CLG 的两个特征各就各位。

第二步：算密度值。问读数 T = 37.2 在两种工况下各有多"典型"。一维高斯密度 p(t) = 1/(√(2π)σ) · exp(−(t−μ)²/(2σ²))，取 √(2π) ≈ 2.507，同一偏差 37.2 − 37.12 = 0.08：

工况前置系数 1/(2.507σ)指数部分p(37.2 | …)
f⁰（σ = 0.2）1/(2.507 × 0.2) ≈ 1.995exp(−0.08² / 0.08) = exp(−0.08) ≈ 0.9231.995 × 0.923 ≈ 1.84
f¹（σ = 0.5）1/(2.507 × 0.5) ≈ 0.798exp(−0.08² / 0.5) = exp(−0.0128) ≈ 0.9870.798 × 0.987 ≈ 0.79

解读：均值同为 37.12，但方差沿离散父翻倍多，同一条读数的密度从 1.84 掉到 0.79——方差越大，钟形越扁，同一偏离就越"不典型"。两个提醒：密度值可以大于 1（它不是概率，只有比较和积分才有意义）；若 F 本身也要边缘化，T 就变成两座钟的叠加——高斯混合，那是第 7.4 节和第 14 章的账单。

💡 全章统一视角

四类机制是同一个交易：拿一条关于世界的假设，换一批参数。确定性 CPD 押"关系是函数"；树 CPD 押"某些上下文下部分父节点无关"；Noisy-Or 押"各原因独立起作用"；Logistic/CLG 押"影响是线性（再套一个固定的形状）"。假设越准，省得越多；假设越错，偏得越远。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
确定性 CPD（Deterministic CPD）
点击翻面 →
定义X = f(Pa(X))：给定父节点，子节点取值概率为 1 地确定。
解决问题逻辑门、物理方程等严格关系，用 0 个参数表达一张 CPD。
直觉查表不如代入公式：输入定了，输出就钉死了。
误区以为它让推理变平凡——确定性等式可传播取值，但也会使某些概率为 0，需谨慎处理证据。
何时用电路诊断、约束模型；Noisy-Or 可看作"确定性 OR + 独立噪声"。
概念卡 2
树 CPD（Tree-CPD）
点击翻面 →
定义用决策树表示 CPD：内部节点测试某个父节点，叶节点给出该路径（上下文）下的分布。
解决问题不同父节点配置下子节点只依赖部分父节点时，完整表的行大量冗余。
直觉分诊台：先问最关键的问题，某些答案一出来，其余问题就不用问了。
误区以为参数数 = 内部节点数——是叶节点数（每叶一个分布）。
何时用规则型决策过程；Ch9-10 推理中利用 CSI 加速的入口。
概念卡 3
上下文特定独立性（CSI）
点击翻面 →
定义X ⊥c Y | Z, C=c：只在 C 取特定值 c 的上下文里成立的条件独立。
解决问题刻画"某些情形下才成立"的独立性，是树 CPD 压缩力的来源。
直觉语境决定相关性：实习一强，推荐信就"失聪"了。
误区以为 d-分离能读出它——CSI 取决于变量取值，不在图拓扑上，标准 d-分离完全看不见。
何时用利用 CPD 内部结构加速精确推理（Ch9/10 的增强方向）。
概念卡 4
因果影响独立性（ICI）
点击翻面 →
定义每个父节点经独立的噪声机制影响子节点，各机制的随机性互不相关。
解决问题多原因场景（k 个病因）的 CPD 从 2ᵏ 行压到每原因一个机制。
直觉多扇独立上锁的门：结果出不来 ⟺ 每扇门都恰好没开。
误区以为它免费——它排除了原因间的交互作用，假设错了就是系统性偏差。
何时用医学诊断、故障诊断；Noisy-Or / Noisy-Max 都是它的实例。
概念卡 5
Noisy-Or 模型
点击翻面 →
定义P(x⁰|y) = ∏_{i:yᵢ=1} λᵢ：X 为假 ⟺ 所有活跃病因都激活失败。
解决问题k 个二元病因的 CPD 只需 k 个失效概率，而非 2ᵏ 个表格行。
直觉每个病因一把枪，各自以概率 1−λᵢ 打响；全部哑火才不发病。
误区忘记"无渗漏"前提（无活跃病因时 X 必为假）；需要时加渗漏参数 λ₀。
何时用诊断网络标配；BN2TCR 等经典医学模型；Ch17 里它是参数学习的友好目标。
概念卡 6
Logistic CPD（Sigmoid CPD）
点击翻面 →
定义P(y¹|x) = σ(w₀ + Σ wᵢxᵢ)，σ(z)=1/(1+e⁻ᶻ)，父节点可连续。
解决问题父节点连续时表格 CPD 连行都写不出；sigmoid 用 k+1 个权重覆盖无穷多输入。
直觉影响先线性相加，再过一个 S 形软开关压成概率。
误区以为它能表达任意交互——线性形式意味着各父影响可加，等权父节点的组合必然等概率。
何时用连续/混合父节点 + 二值子节点；与逻辑回归、神经网络的接口。
概念卡 7
条件线性高斯（CLG）
点击翻面 →
定义每种父节点（离散）配置下，连续子节点服从一个（均值可线性依赖连续父的）高斯分布。
解决问题"父离散、子连续"这一格的参数化（如体温读数依赖是否发烧）。
直觉每种离散状态配一口"钟形曲线"，状态切换 = 换钟。
误区与 Logistic CPD 记反——Logistic 是父连续子离散，CLG 是父离散子连续。
何时用Ch7 高斯网络系统展开；Ch14 混合网络推理处理它带来的困难。

📝分层习题

L1 概念辨析判断对错：表格 CPD 的行数只取决于父节点的个数，与每个父节点有多少取值无关。说明理由。
提示

行数 = 父节点取值的组合数。把"每个父 3 个值"和"每个父 2 个值"各代一次试试。

完整解答
错。行数是各父节点取值数的乘积：k 个 d 元父节点 → dᵏ 行。同样 3 个父节点，二值时 2³=8 行，三值时 3³=27 行。爆炸的指数在父节点个数 k 上，但底数 d（每父取值数）同样决定基数——两个维度都能让表变大。
L1 概念辨析判断对错：既然树 CPD 揭示了 CSI，那么用第 3 章的 d-分离算法照样能把这些独立性从图上读出来。说明理由。
提示

d-分离的输入只有图拓扑（节点与边），它能看见 CPD 表里"某些行相等"这件事吗？

完整解答
错。d-分离只看图的连通结构，而 CSI（如 J ⊥c S | A=强）成立与否取决于父节点的具体取值——这是 CPD 内部的结构，图上边 S→J 照常存在，d-分离永远判定"相连即可能相关"。读出 CSI 需要扩展算法（结合 CPD 结构），这正是本章"代价"节点在主线图上的含义。
L2 手算推导节点 X 为二值，有 4 个父节点，每个父节点取 3 个值。(a) 完整表格 CPD 有多少行、多少自由参数？(b) 若改用树 CPD 且树有 9 个叶节点，自由参数多少？压缩比多少？
提示

行数 = 各父取值数的乘积；每行自由参数 = m−1（X 二值所以是 1）；树 CPD 参数 = 叶节点数 × 每叶参数。

完整解答

(a) 行数 = 3 × 3 × 3 × 3 = 3⁴ = 81 行。X 二值，每行 P(x⁰)+P(x¹)=1，自由参数 1 个，故自由参数总数 = 81 × 1 = 81。

(b) 树 CPD：每个叶是一个 Bernoulli 分布（1 个自由参数），9 个叶 → 9 个自由参数。压缩比 = 81 / 9 = 9 倍。注意：省参数的前提是真实 CPD 确实有"72 行可与另外 9 行共享分布"的结构——树形状必须与现实吻合。

L2 手算推导Noisy-Or：X 有两个病因父节点 Y₁（病毒）、Y₂（细菌），失效概率 λ₁ = 0.3、λ₂ = 0.5。写出完整 CPD 的全部 4 行（P(x⁰) 与 P(x¹)），并验证各行归一化。
提示

P(x⁰) = 活跃病因的 λ 连乘；无活跃病因时为空乘积 = 1；P(x¹) = 1 − P(x⁰)。

完整解答

逐行：

① (Y₁=0, Y₂=0)：无活跃病因，P(x⁰) = 1，P(x¹) = 0。和 = 1 ✓

② (1, 0)：P(x⁰) = λ₁ = 0.3，P(x¹) = 1 − 0.3 = 0.7。和 = 1 ✓

③ (0, 1)：P(x⁰) = λ₂ = 0.5，P(x¹) = 1 − 0.5 = 0.5。和 = 1 ✓

④ (1, 1)：P(x⁰) = λ₁·λ₂ = 0.3 × 0.5 = 0.15，P(x¹) = 1 − 0.15 = 0.85。和 = 1 ✓

2 个参数（0.3 与 0.5）生成了 4 行表；若用表格需 4 个自由参数。病因升到 10 个时对比变为 10 vs 1024。

L3 建模应用发热门诊建模：发烧 F（二值）可能由三个病因引起——流感、肺炎、中暑（均二值）；体温计读数 T 是连续变量，依赖 F。画出图、为每个 CPD 选择本章的合适形式并说明理由、写出联合分布的因子分解式。
提示

三个独立病因 → 想到哪种 ICI 模型？T 连续、其父 F 离散 → 本章哪一格？

完整解答

图：流感 Y₁、肺炎 Y₂、中暑 Y₃ 三个无父节点 → 共同指向 F；F → T。

CPD 选择：①P(F | Y₁,Y₂,Y₃) 用 Noisy-Or：病因各自独立致病、无交互的假设在门诊场景近似合理，3 个 λ 替代 8 行表；若存在"无病因也发烧"的可能，加渗漏参数 λ₀。②p(T | F) 用 CLG：F 离散、T 连续，每种 F 取值配一个高斯（如 𝒩(36.6, σ₀²) 与 𝒩(38.5, σ₁²)），高斯细节引用第 7 章。

因子分解：P(Y₁)·P(Y₂)·P(Y₃)·P(F|Y₁,Y₂,Y₃)·p(T|F)。

代价声明：Noisy-Or 排除了"流感+肺炎并发格外高热"这类交互；CLG 假设读数噪声是高斯形——两者都是拿假设换参数的赌注。

节点 X 为二值，有 10 个二值父节点。完整表格 CPD 的自由参数数是多少？

树 CPD 的自由参数数由什么决定？
  • A. 内部节点（测试节点）的个数
  • B. 叶节点的个数 × 每个叶分布的自由参数数
  • C. 树的深度
  • D. 父节点个数 k 决定的 2ᵏ
选 B。每个叶给出该上下文下的一个完整分布，参数集中在叶上。A 错：内部节点只是路由，不含概率；C 错：深度与参数无直接关系（一棵深而秃的树可能叶很少）；D 错：那正是树 CPD 要摆脱的完整表行数。
自测 3
Noisy-Or 中，Y₁ = 1、Y₂ = 1，λ₁ = 0.4、λ₂ = 0.5。P(x¹ | y₁=1, y₂=1) 等于多少？
  • A. 0.2
  • B. 0.7
  • C. 0.8
  • D. 0.9
选 C。P(x⁰) = λ₁·λ₂ = 0.4×0.5 = 0.2，故 P(x¹) = 1 − 0.2 = 0.8。A 错在把 P(x⁰) 当成答案；B 错在只算 1−λ₁（漏掉第二条通道）；D 错在用 1−λ₁λ₂/2 之类无依据的拼凑——公式是失效概率连乘取补。

  • B. 它只在马尔可夫网络中存在，贝叶斯网络没有
  • C. 它会增加 CPD 的参数数量
