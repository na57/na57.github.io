10.1为什么需要团树：变量消去在重复劳动

上一章的变量消去（Variable Elimination）回答的是"一次查询怎么算"。但真实系统里，查询从来不是一次性的：诊断系统要轮番报告每个变量的后验，传感器网络要持续回答"现在每个节点处于什么状态"。对同一个网络问第二次、第三次时，变量消去会从头再来——而它并不知道，自己刚刚算过几乎一样的东西。

例 1：同一个网络，跑两次查询

本章全程使用同一个例子：四个二值变量 A、B、C、D 组成一个四元环，边为 A—B、B—C、C—D、D—A（这正是第 4 章"误解例子"里贝叶斯网络表达不了的那张图，现在我们直接以马尔可夫网络起步）。四个势函数形状相同：两端取值一致得 5，不一致得 1（邻居倾向一致）。

flowchart LR A["A"] --- B["B"] B --- C["C"] C --- D["D"] D --- A classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#c4651f; class A,C hot;
图 10.1 本章的常驻例子：四元环 A—B—C—D—A，无向、无弦。四个势函数均为 φ(x,y)：一致 5 / 不一致 1。

第一次查询 P(A)，选消元顺序 D, C, B（始终先消叶度最小的节点）。初始因子：φ₁(A,B)、φ₂(B,C)、φ₃(C,D)、φ₄(D,A)。

  • 消 D：含 D 的因子是 φ₃、φ₄，乘起来得中间因子 ψ(C,D,A)，再对 D 求和得 τ₁(C,A)。
  • 消 C：含 C 的因子是 φ₂、τ₁，乘得中间因子，对 C 求和得 τ₂(A,B)。
  • 消 B：φ₁ × τ₂ 对 B 求和，得 τ₃(A)。归一化即 P(A)。

第二次查询 P(C)，选顺序 D, A, B。消 D 时含 D 的因子还是 φ₃、φ₄——ψ = φ₃ × φ₄ 这张 8 行的表，我们几分钟前刚算过一遍，现在原样重算。消 A、消 B 同理，大半个流程是第一次查询的回放。

⚠️ 重复的不是巧合，是结构性浪费

两次查询的消元过程里，凡是"不经过查询变量"方向上的求和，两次是完全相同的。n 个变量、n 次单变量查询，变量消去就把网络从头扫 n 遍；而真正"不同"的只是最后一步留在哪个变量上。查询越多，浪费越大——这不是实现不够好，是算法本身没有记忆。

💡 关键一跃

变量消去的每一步"乘起来再求和"，产出的中间因子只依赖于网络的某个局部，与"这次想问谁"无关。那么：把这些中间因子存下来、组织好、标明谁依赖谁——之后任何查询直接取缓存即可。这棵"缓存的组织结构"，就是本章的主角团树（Clique Tree）。

10.2先把图变成弦图：为什么非弦不可

上一节说"缓存消元的中间因子"。但缓存要有货架：中间因子定义在哪些变量组上，得事先定下来。消元时"消去变量 X，把含 X 的因子乘起来"——这个乘积的作用范围是 X 的全部邻居；要让它成为一个合法的"团"，这些邻居必须两两相连。在原图上这并不成立，于是消元会悄悄往图里加边。

例 2：在四元环上手算一次弦化

回到图 10.1 的四元环。它是非弦图：环 A—B—C—D—A 长度 4，却没有任何"弦"（连接环上不相邻节点的边，如 A—C 或 B—D）。试着按顺序 D, C, B, A 消元，并盯住图的变化：

  1. 消 D：D 的邻居是 C 和 A。含 D 的因子 φ₃(C,D)、φ₄(D,A) 相乘后作用域是 {C,D,A}——这要求 C 与 A 之间有一条边。原图没有，被迫加入填充边 A—C。
  2. 消 C：此时 C 的邻居是 B 和 A（A—C 已是边）。φ₂(B,C) × τ₁(C,A) 作用域 {A,B,C}——恰好 A—B、B—C、A—C 三边俱全，{A,B,C} 已是团，不再需要新边。
  3. 消 B、A：作用域 {A,B}、{A}，均为已有团。

图 10.2 左：四元环含长度 4 的无弦环。右：消 D 时其邻居 A、C 必须相连，红色虚线 A—C 是填充边（fill-in edge）。加边后图中不再有无弦环。

这个"先加边、再消元"的预处理叫弦化（Triangulation，又称三角化）：不断给无弦环加弦，直到图中所有长度 ≥ 4 的环都有弦。这样的图叫弦图（Chordal Graph）。

✅ 为什么团树依赖弦性

弦图有一个决定性好性质：存在一种消元顺序（完美消元序），使消去每个节点时其邻居两两相连，每一步产生的中间因子恰好落在一个已有的团上，一条填充边都不用再加。这意味着：消元产生的全部中间因子的作用域，可以事先从弦图的最大团里读出来——货架尺寸在建树前就定死了。非弦图上做不到这一点：中间因子的形状要跑到半路才知道，缓存无从规划。

⚠️ 常见误区

"弦化只是画图好看"——错。加哪条弦由消元顺序决定，而不同的弦化结果会造出不同大小的最大团。四元环加 A—C，最大团是三元组；若原图是更大的网格，糟糕的顺序可能加出一个巨型团。团的大小直接决定推理成本（见 10.6 节树宽），所以"选消元顺序"就是"选弦化"，是精确推理里真正的优化战场。

10.3团树的构造：同一棵缓存树

弦图有了，现在把"缓存"正式组织起来。直觉很简单：消元的每个中间因子住在某个团上，那么让团当节点，让"谁把中间因子交给谁"当边——得到的就是团树（Clique Tree），也叫联结树（Junction Tree）。它不是一张新图，而是同一套消元计算被重新排成了一棵树。

三个构造动作，一棵树

① 找最大团：弦化后的图 10.2（右）里，两两全连且不能再扩大的节点组只有两个：C₁={A,B,C}（A—B、B—C 与填充边 A—C 两两全连）和 C₂={A,C,D}（C—D、D—A 与填充边 A—C 两两全连）。其余边如 {A,D}、{B,C} 都被这两个三元团包含，不构成新的最大团。

② 按分隔集连边：两个团共享的变量集合叫分隔集（Sepset）Sij = Ci ∩ Cj。C₁ 与 C₂ 共享 {A,C}，用一条标着 {A,C} 的边把它们连起来。一般地，在所有候选边里选一棵"分隔集总权重最大"的生成树（最大生成树），保证信息走最宽的路。

图 10.3 本章例子的团树：两个团、一条边、分隔集 {A,C}。每个团的初始势能 = 分配到该团的原始因子之积（每个因子至少分配给一个包含它的团）。

③ 验证运行交性质：运行交性质（Running Intersection Property）要求：若变量 X 出现在两个团里，则 X 必须出现在连接它们的唯一路径上的每一个团里。本例中 A 与 C 都同时出现在 C₁、C₂ 中，而路径就是那条边本身——满足。这条性质的语义是：每个变量在团树上占据一片连通区域，信息沿树传递时不会"绕过"某个持有该变量的团，求和时也就不会把同一变量错误地消两次或漏消。

💡 这棵树是什么

把 10.1 节的消元过程 D, C, B 倒过来看：消 D 产生 τ₁(C,A) 交给含 {A,C} 的下一步；消 C 产生 τ₂(A,B)……团树只是把这条"因子交接链"摆成了图：团是工作站，分隔集是传送带，消息就是消元里的中间因子 τ。团树 = 变量消去的可复用存档格式。

⚠️ 常见误区

"团树是随便一棵连接团的树"——错。少了运行交性质，同一个变量可能出现在树的两处而不连通，消息传递时信息会断裂，校准等式不再成立。运行交性质是团树合法性的全部核心；最大生成树只是满足它的一种顺手构造法。

10.4消息传播与校准：两遍传遍全树

树建好了，缓存还是空的。填缓存的机制叫消息传播（Message Passing）：相邻团之间互相发送"我这边的信息汇总"，每条边两个方向各发一次，整棵树就同步了。

消息公式：团 Ci 发给邻居 Cj 的消息，是定义在分隔集 Sij 上的因子：

δi→j(Sij) = ∑Ci ∖ Sij ψi(Ci) · ∏k ∈ N(i) ∖ j δk→i(Ski)

读法：把自己的初始势能，乘上除 j 以外所有邻居发来的消息，再把"只属于自己、不属于分隔集"的变量求和消掉——剩下的就是"i 这一侧对分隔集的全部意见"。这正是变量消去里"乘起来、求和消去"那一步，只不过结果被记在边上，谁都能来取。

两遍就够：任选一个团当根，先收集（Collect，叶子→根：每个团等齐上游消息后向上发），再分发（Distribute，根→叶子：反向发回）。每条边两个方向各一条消息后，树达到校准（Calibration）：对每条边，两侧团在分隔集上的边缘完全一致。

校准后读答案：每个团的信念（Belief）

βi(Ci) = ψi(Ci) · ∏k ∈ N(i) δk→i(Ski)

就是该团变量的未归一化联合边缘 P̃(Ci)——任取一个含目标变量 X 的团，把 β 对团内其余变量求和再归一化，即得 P(X)。

💡 直觉

收集阶段像"逐级汇报"：每个分支把自己的信息压缩成分隔集上的一条简报交给上级；分发阶段像"逐级传达"：全局信息再沿树回流。两遍之后，每个团都坐拥全局——却只在局部做了乘法与求和。

  • ΣB β₁(0,B,0) = β₁(0,0,0)+β₁(0,1,0) = 25×26 + 1×26 = 650+26 = 676 ✓
  • ΣD β₂(0,0,D) = β₂(0,0,0)+β₂(0,0,1) = 25×26 + 1×26 = 650+26 = 676 ✓

两侧同为 676，校准通过。这正是校准等式的用法：分隔集边缘必须相等，不等就是算错了。

⚠️ 错误示范：660 是怎么来的（别学这个数）

假如算第一侧时把 β₁(0,1,0) 的消息格子查错——按 (A,B)=(0,1) 而不是按分隔集 (A,C)=(0,0) 去查 δ2→1——就会写成：

ΣB β₁(0,B,0) = 25×26 + 1×10 = 650 + 10 = 660 ≠ 676

660 不是"另一个合法的中间值"，它就是错的：红色那项把 δ2→1(0,0) = 26 误取成了 δ2→1(0,1) = 10，正确值 676 直接覆盖它，没有任何商量余地。

自查口诀：如果你在第一侧算出 660，说明你读团 C₁ = {A,B,C} 的 B=1 那一行时查错了消息格——回到 C₁，确认那一行乘的是分隔集 (A,C)=(0,0) 对应的 δ2→1(0,0) = 26，而不是 (0,1) 格的 10。校准等式的全部价值就在这一刻：两边对不上时，它替你把错误定位到具体哪个团、哪一格。

读答案：P(A) 与 P(C) 都来自同一次校准

  • P̃(a⁰) = ΣB,C β₁(0,B,C) = 650+50+26+50 = 776（四项分别对应 (B,C)=(0,0),(0,1),(1,0),(1,1)：25×26、5×10、1×26、5×10）；由对称性 P̃(a¹) = 776，故 P(a⁰) = 776/1552 = 0.5。
  • P̃(c⁰) = ΣA,B β₁(A,B,0) = 650+26+50+50 = 776，同样得 P(c⁰) = 0.5。
  • 顺便，配分函数 Z = 1552 也从团信念里免费得到（Σ β₁ = Σ β₂ = 1552）。

注意第二行没有发动任何新的传播——校准过的树回答 P(C) 只是"在 β₁ 上换个方向求和"。

10.6消元 vs 团树：同一网络，逐条数运算

现在兑现 10.1 节的承诺：把"变量消去跑两次查询"和"团树校准一次"的因子运算逐条列出来对比。计数以一次"因子相乘"或一次"对变量求和"为一个因子运算。

步骤VE 查询 P(A)（顺序 D,C,B）VE 查询 P(C)（顺序 D,A,B）团树校准（一次）
1φ₃ × φ₄ → ψ(C,D,A)φ₃ × φ₄ → ψ(C,D,A)　← 重复建势能：ψ₁ = φ₁×φ₂，ψ₂ = φ₃×φ₄
2ΣD ψ → τ₁(C,A)ΣD ψ → τ₁(C,A)　← 重复收集：δ2→1 = ΣD ψ₂
3φ₂ × τ₁ → ψ(A,B,C)φ₁ × τ₁ → ψ(A,B,C)分发：δ1→2 = ΣB ψ₁
4ΣC → τ₂(A,B)ΣA → τ₂(B,C)团信念：β₁ = ψ₁·δ2→1，β₂ = ψ₂·δ1→2
5φ₁ × τ₂，ΣB → τ₃(A)，归一化φ₂ × τ₂，ΣB → τ₃(C)，归一化读 P(A)：ΣB,C β₁；读 P(C)：ΣA,B β₁——局部求和，无新传播
合计6 次因子运算6 次，其中 2 次与左列完全重复约 6 次建势能/消息/信念运算，之后每个新查询 0 次传播

规律：两次查询，VE 共 12 次运算、团树约 6 次加 2 次局部求和；查询数变成 k 时，VE 是 6k，团树仍然是"一次校准 + k 次局部求和"。查询越多，团树省得越多——这就是"给消元加缓存"的全部含义。

✅ 判定规则：什么时候用团树

单次查询、且图稀疏 → 变量消去更省（无建树开销）；需要反复查询、在线更新、或想要所有变量的边缘 → 团树。现实中"诊断系统持续回答每个变量的后验"几乎都是后者。

证据怎么进入团树

观测到证据 X = x 时：任取一个含 X 的团，把指示因子 1[X = x] 乘进它的势能（相当于把势能里 X ≠ x 的行清零），然后只需从该团出发重新传播——树结构、其他团的初始势能都不变。这叫增量更新：证据是局部事件，不需要推倒重来。

10.7代价与出路：树宽封顶，以及带环图的诱惑

团树并非免费午餐。它的成本由最大团的大小决定：团内势能表有 d|C| 项（d 为变量取值数），而最大团多大由弦化加了多少边决定。图的树宽（Treewidth）=（最优弦化下最大团大小 − 1），精确推理复杂度 O(dw+1)——树宽是精确推理的天花板。稠密网络（如大网格）树宽随规模线性增长，团再大也算不动。

另一个更微妙的问题藏在 10.4 节：消息传播的正确性证明依赖"树"——每条边切断后两侧变量的信息只沿这条边流动，所以每条消息只算一次、不循环。如果图本身带环、我们又懒得弦化（因为弦化会造出巨型团），直接把消息公式搬到带环图上迭代会怎样？直觉上消息会绕圈回流、自我加强；但实践中这种"违规操作"常常意外地好用。这就是第 11 章环上置信传播（Loopy Belief Propagation）的起点——用近似换可行。

⚠️ 常见误区

"团树是万能升级版，建了就比消元强"——错。单次查询时建树 + 两遍传播比一次消元更贵；树宽大的网络里团表本身就存不下。团树的价值场景是"多查询 / 在线证据 / 要全部边缘"，不是"任何推理"。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
弦化（Triangulation）
点击翻面 →
定义给无向图加填充边，直到所有长度 ≥ 4 的环都有弦，得到弦图。
解决问题非弦图上消元会在半路引入新边，中间因子的形状无法事先规划，缓存无从建。
直觉先把仓库的货架尺寸定死，货物（中间因子）才好入库。
误区以为加边随意——弦化方式决定最大团大小，即决定推理成本。
何时用一切团树/联结树推理的预处理；树宽也由它定义（Ch10–11）。
概念卡 2
团树 / 联结树（Clique Tree / Junction Tree）
点击翻面 →
定义以弦图最大团为节点、按分隔集连边且满足运行交性质的树，各团持初始势能。
解决问题变量消去多查询时重复计算同一批中间因子。
直觉消元的存档格式：中间结果存进树里，查询随取随用。
误区以为团树是新模型——它是同一套消元计算的重组，不改分布。
何时用多查询、在线证据更新、需要全部边缘的精确推理（Ch10）；Ch11 的对照组。
概念卡 3
分隔集（Sepset）
点击翻面 →
定义相邻两团的变量交集 Sij = Ci ∩ Cj，消息就定义在它上面。
解决问题划定两团之间信息交换的"接口宽度"：消息只谈共享变量。
直觉两部门之间的联络员——只传递双方都管的事。
误区以为消息定义在整个团上——消息的作用域只有分隔集，其余变量已被消掉。
何时用消息公式与校准等式的主角；Ch11 BP 消息的同型物。
概念卡 4
运行交性质（Running Intersection Property）
点击翻面 →
定义若变量 X 同时出现在两团中，则它出现在连接两团路径上的每个团里。
解决问题保证同一变量的信息在树中连续，消息传递不重不漏，校准等式成立。
直觉每个变量在树上占据一片连通辖区，不能"飞地"。
误区以为任意连接团的树都行——缺了它，校准等式直接失效。
何时用构造与验证团树的合法性标准（最大生成树是满足它的构造法）。
概念卡 5
消息传播（Message Passing / Sum-Product）
点击翻面 →
定义δi→j(Sij) = ΣCi∖Sij ψi·∏k≠j δk→i，沿边两个方向各传一次。
解决问题把"消元的中间因子"变成可缓存、可复用的边上对象。
直觉逐级汇报再逐级传达：收集（叶→根）+ 分发（根→叶）两遍传遍。
误区以为要传很多轮——树上恰两遍即收敛；多轮迭代是带环图（Ch11）的事。
何时用本章校准机制；Ch11 把它搬到带环图即 Loopy BP。
概念卡 6
校准与团信念（Calibration / Belief）
点击翻面 →
定义校准：每边两侧团在分隔集上边缘一致；βi = ψi·∏k δk→i = P̃(Ci)。
解决问题校准后任意查询只需局部边缘化，无需新传播。
直觉全树信息同步完成：每个团都坐拥全局。
误区以为 β 是归一化概率——它是未归一化边缘，读答案时还要归一化。
何时用读 P(X)、算 Z、手算查错（分隔集边缘必须相等）。
概念卡 7
树宽（Treewidth）
点击翻面 →
定义w = 最优弦化下最大团大小 − 1；精确推理复杂度 O(dw+1)。
解决问题给出精确推理是否可行的判据：w 大则精确推理指数爆炸。
直觉图"离一棵树有多远"的度量——树 w=1，环 w=2，网格 w 随边长涨。
误区以为树宽是图的固有数字——它由最优消元顺序定义，顺序差则表观树宽虚高。
何时用决定选精确（Ch9/10）还是近似（Ch11–13）推理的分水岭。

📝分层习题

L1 概念辨析判断对错：团树上每个团的信念 βi 就是该团变量的归一化联合概率分布。说明理由。
提示

回顾 βi 的构成：初始势能与消息的乘积。消息和势能归一化过吗？

完整解答
错。βi = ψi·∏ δk→i 是该团变量的未归一化边缘 P̃(Ci)：各行之和等于配分函数 Z（本章例中 Σβ₁ = 1552），不是 1。读答案时必须再做一次归一化。校准保证的是"分隔集边缘一致"，不保证"和为 1"。
L1 概念辨析判断对错：只要把所有最大团任意连成一棵树，消息传播两遍后就能得到正确边缘。说明理由。
提示

想想运行交性质：如果变量 X 出现在树的两处但路径上有个团不含 X，会发生什么？

完整解答
错。必须满足运行交性质。反例：三团 C₁={A,B}、C₂={C,D}、C₃={A,D} 连成 C₁—C₂—C₃，A 出现在 C₁、C₃ 但中间 C₂ 不含 A。消息 δ1→2 在 {B} 或空集上传递，A 的信息在 C₂ 处断裂，C₃ 拿到的"全局"信息漏掉了 C₁ 关于 A 的部分，校准等式失效。运行交性质不是装饰，是正确性的全部来源。
L2 手算推导五元环 A—B—C—D—E—A。按消元顺序 C, D 开始消元，写出前两步各引入了哪条填充边（若有），并给出弦化后含 {A,B} 的最大团。
提示

消去一个节点时，它的所有当前邻居两两之间必须有边；缺哪条就补哪条。

完整解答

消 C：C 的邻居为 B、D，二者原不相连 → 加填充边 B—D。此时含 C 的因子合并为作用域 {B,C,D} 的中间因子。

消 D：D 的当前邻居为 C（待消路径上）、B、E——C 已消后 D 的邻居为 B、E，且 B—D 边存在使作用域涉及 {B,D,E}，B 与 E 原不相连 → 加填充边 B—E。

两条填充边 B—D、B—E 加入后，环上不再有无弦四环/五环。含 {A,B} 的最大团为 {A,B,E}（A—B、B—E、E—A 两两全连）。另两个最大团：{B,C,D}、{B,D,E}。

L2 手算推导用本章例子的校准结果，计算 P(b⁰|c⁰)。要求写出用了哪个团、哪条消息，以及归一化常数。
提示

B 和 C 同在团 C₁ 中：先取 β₁ 的边缘 P̃(B,C)，再按条件概率定义相除。

完整解答

P̃(B,C) = ΣA β₁(A,B,C) = ΣA ψ₁(A,B,C)·δ2→1(A,C)。

P̃(b⁰,c⁰) = β₁(0,0,0)+β₁(1,0,0) = 25×26 + 5×10 = 650+50 = 700。

P̃(c⁰) = 776（10.5 节已算，即归一化所用的未归一化边缘）。

P(b⁰|c⁰) = 700/776 ≈ 0.902。看到邻居 C=0，B=0 的概率从 0.5 升到约 0.90——依赖穿过分隔集传了过来。全程只用团 C₁ 的信念与消息 δ2→1，无新传播。

L3 建模应用某电网监控系统有 12 个节点排成 3×4 网格，每小时要报告每个节点的故障后验，且新的传感器读数每分钟到达。在"变量消去"与"团树"之间做架构选择，说明理由；并指出该网格的树宽量级对选择的约束。
提示

两个维度：查询频率（12 个/小时）与证据更新频率（每分钟）；3×n 网格的树宽约为 3。

完整解答

选团树。理由一：12 个节点轮番查询，VE 每次全网重扫，团树一次校准后每个查询只做局部边缘化。理由二：证据每分钟到达——团树把指示因子乘进含证据变量的团、局部重新传播即可，VE 则每次从零开始。

树宽约束：3×4 网格最优弦化后最大团约 4 个变量，树宽 w ≈ 3，二值变量下团表 2⁴ = 16 项，精确推理完全可行。若换成 30×40 大网格，w ≈ 30，团表 2³¹ 项存不下——此时无论 VE 还是团树都不可行，只能转向第 11 章的近似推理。网格宽度就是这条架构选择的分界线。

  • B. 树宽 w 决定成本 O(dw+1)；w 太大时精确推理不可行，只能转向近似推理（如 Loopy BP）
  • C. 带环图上直接跑消息传播一定发散，所以第 11 章没有意义
  • D. 树宽大的图可以通过更多轮消息传播克服
选 B。团表 d|C| 项是硬约束，w 大则连存储都不可行，A 错。C 错：Loopy BP 不保证收敛、结果是近似的，但实践中常常好用，这正是它值得学的原因。D 错：消息轮数改不了团表大小，瓶颈在空间不在迭代。

句3：它和前后章怎么分工？——
参考答案：Ch9 管"一次查询怎么消元"，本章把消元存档成树管"多次查询怎么复用"；但树宽封顶 + 算法离不开树结构，带环图上的消息传播（Loopy BP）和各类近似推理交给 Ch11 及以后。
