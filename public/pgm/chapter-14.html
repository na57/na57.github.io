14.1为什么"先离散化再套老算法"是个陷阱

前几章的世界很整齐：要么全离散（BN/MN，Ch3–4），要么全连续（高斯网络，Ch7）。现实不整齐：疾病（离散）影响血压（连续）；市场体制（离散：牛市/熊市）影响收益率（连续）；地形类型（离散）影响激光雷达读数（连续）。这种网络叫混合网络（Hybrid Network）。

第一直觉：把连续变量切成区间，全部变离散，然后直接用第 9 章的变量消去。这个方案有两副毒药，必须选一副：

  • 切得粗：10 个区间。每个条件概率表确实小，但"血压在 120–140 之间"这种分辨率的模型对诊断毫无意义——误差是建模时就锁死的。
  • 切得细：1000 个区间。一个连续变量带两个离散父节点，CPD 就是几千行；两个连续变量相邻，因子表直接爆炸到百万项。第 9 章教的"复杂度随诱导宽度指数增长"在这里以"区间数"为底数炸开。
⚠️ 混合网络的本质困难

离散变量的消去是求和，连续变量的消去是积分——混合网络要求在同一套消息传递里同时做这两件事。求和产出表格，积分产出函数；表格和函数相乘之后是什么数据结构？这就是本章全部技术问题的源头。

💡 出路预告

唯一的希望：找到一类连续分布，使"乘积、积分、边缘化"的结果仍在这类分布里（封闭性）。第 7 章已经给过答案：高斯分布。于是本章的核心策略是——连续部分全程保持高斯，离散部分全程保持表格，交互处用"表格索引的高斯"缝合。这就是 CLG。

14.2CLG：表格化的线性高斯，混合世界的"最大公约数"

第 7 章学过：纯高斯网络里所有操作（条件化、边缘化、乘积）都封闭于高斯。条件线性高斯（Conditional Linear Gaussian, CLG）把这个性质扩展到混合网络，代价是两条结构性限制：

✅ CLG 的两条家规

① 离散变量不能有连续父节点（离散变量的 CPD 只依赖离散父母，就是普通表格）；
② 连续变量给定父母后是线性高斯：均值是连续父母的线性函数，方差固定；离散父母的作用只是"切换参数"——每个离散父母配置一套 (斜率, 截距, 方差)。

形式上，连续变量 X 的 CPD 是：

P(X | D = d, Y₁…Yₖ) = 𝒩( β₀(d) + β₁(d)y₁ + … + βₖ(d)yₖ ; σ²(d) )

其中 D 是离散父母，Y 是连续父母。注意上标 (d)：每个离散配置 d 一套高斯参数——这就是"表格化的高斯"：表格的行不再是概率数，而是高斯参数组。家规①同样关键：若允许离散变量有连续父（比如用 sigmoid 把连续值压成概率），连续变量边缘化时就再也回不到高斯，封闭性立刻死亡。

连续变量作父的 CLG：一次完整手算与消去后的分裂

例 1 的 X 只有离散父，CPD 退化为"每行一个截距"。家规②的完整形态是连续变量还可以有连续父——这时"线性高斯"四个字才真正登场。下面用两个变量把 (a) CPD 长什么样、(b) 消去连续父、(c) 消去离散父各算一遍，看两种消去的命运有何不同。

(a) 两变量 CLG：均值随父线性走，方差雷打不动。设 X ~ 𝒩(μₓ, σₓ²) = 𝒩(2, 1)，Y 以 X 为（连续）父：

Y | X = x ~ 𝒩( 3x + 1 , 4 ) ，即 p(y | x) = 𝒩( y ; 3x + 1, 4 )

条件均值 E[Y | x] = 3x + 1 是父取值的线性函数，条件方差 Var(Y | x) = 4 与 x 无关——"线性"说的是均值随父线性变化，"高斯"说的是钟形与胖瘦固定。代入三个父取值：

(b) 消去连续父 X：风平浪静。对 p(y | x)·p(x) 做积分。第 7 章的封闭性保证"高斯 × 高斯再积分"仍是高斯，所以只需算出 Y 的前两阶矩：

p(y) = ∫ p(y | x) · p(x) dx = ∫ 𝒩( y ; 3x + 1, 4 ) · 𝒩( x ; 2, 1 ) dx
E[Y] = 3·E[X] + 1 = 3×2 + 1 = 7
Var(Y) = 3²·Var(X) + 4 = 9×1 + 4 = 13
p(y) = 𝒩( 7, 13 )

一般地，Y | X ~ 𝒩(aX + b, σ²) 且 X ~ 𝒩(μₓ, σₓ²) 蕴含 Y ~ 𝒩(aμₓ + b, a²σₓ² + σ²)：高斯对"边缘化连续变量"封闭，消去连续父后仍是单一高斯——均值 aμₓ + b，方差 a²σₓ² + σ²。这是好消息。

(c) 消去离散父 D：一分为二。现在给 Y 再加一个离散父 D ∈ {d⁰, d¹}，P(d⁰) = P(d¹) = 0.5，每个离散配置一套高斯参数：

dP(D = d)Y | X = x, D = d 的分布
d⁰0.5𝒩(3x + 1, 4)
d¹0.5𝒩(x − 2, 1)

对 D 求和消去：

p(y | x) = 0.5·𝒩( y ; 3x + 1, 4 ) + 0.5·𝒩( y ; x − 2, 1 )

这是两分量的混合高斯——还能精确写出，但已经不具有 CLG 的形式。证据藏在矩里。混合均值恰好仍是 x 的线性函数：

E[Y | x] = 0.5·(3x + 1) + 0.5·(x − 2) = 2x − 0.5

但混合方差要用 E[Y²] − E[Y]² 推。先算二阶矩（高斯 𝒩(μ, σ²) 有 E[Y²] = σ² + μ²，故两个分量分别贡献 4 + (3x+1)² = 9x² + 6x + 5 与 1 + (x−2)² = x² − 4x + 5）：

E[Y² | x] = 0.5·(9x² + 6x + 5) + 0.5·(x² − 4x + 5) = 5x² + x + 5
Var(Y | x) = E[Y² | x] − E[Y | x]² = (5x² + x + 5) − (2x − 0.5)² = x² + 3x + 4.75
⚠️ 方差不再是常数 = CLG 形式死亡

Var(Y | x) = x² + 3x + 4.75 随 x 变化，直接违反家规②"给定父母后条件方差为常数"的形式要求。也就是说：CLG 对消去连续父封闭，对消去离散父不封闭。每消去一个离散变量，高斯分量数可能翻倍——k 个离散变量消完，一个因子要携带 2k 个分量。这正是 14.4 节"闭包灾难"的微观现场，也是第 9 章变量消去搬到混合网络上会变难的根源。

💡 一句话记住

高斯怕离散父：消去连续父风平浪静（还是一只钟），消去离散父分身乏术（变成一群钟）。

14.3手算一个混合网络的完整推理：观测连续值，更新离散信念

接着例 1：现在观测到温度读数 X = 2。问：机器老化的概率是多少？这是混合网络最典型的查询——连续证据更新离散信念。

第一步：写出似然。观测 X=2 在两个假设下的密度（正态密度公式 𝒩(x; μ, σ²) = (1/√(2πσ²))·e−(x−μ)²/(2σ²)）：

  • P(X=2 | 正常) = (1/√(2π))·e−(2−0)²/2 = (1/√(2π))·e−2 ≈ 0.3989 × 0.1353 ≈ 0.0540
  • P(X=2 | 老化) = (1/√(2π))·e−(2−3)²/2 = (1/√(2π))·e−0.5 ≈ 0.3989 × 0.6065 ≈ 0.2420

第二步：乘先验。

  • 正常：0.4 × 0.0540 = 0.0216
  • 老化：0.6 × 0.2420 = 0.1452

第三步：归一化。总和 = 0.0216 + 0.1452 = 0.1668。

  • P(老化 | X=2) = 0.1452 / 0.1668 ≈ 0.87
  • P(正常 | X=2) ≈ 0.13

读数 2 离老化中心 3 更近，后验从先验的 0.6 翻到 0.87——贝叶斯更新的机制与离散情形完全一样，只是把"表格查数"换成了"高斯密度求值"。

例 2：混合高斯的矩——弱边缘化的预习

不观测任何东西时，X 的边缘（混合高斯）的均值和方差是多少？用全期望公式与全方差公式：

E[X] = ED[ E[X|D] ] ， Var(X) = ED[Var(X|D)] + VarD(E[X|D])

均值：E[X] = 0.4×0 + 0.6×3 = 1.8。

方差（两项分开算）：

  • 组内项 E[Var(X|D)] = 0.4×1 + 0.6×1 = 1
  • 组间项 Var(E[X|D])：E[X|D] 以 0.4 概率取 0、0.6 概率取 3，均值为 1.8，故 Var = 0.4×(0−1.8)² + 0.6×(3−1.8)² = 0.4×3.24 + 0.6×1.44 = 1.296 + 0.864 = 2.16
  • Var(X) = 1 + 2.16 = 3.16
💡 关键一跃

这个双峰混合分布，可以用单个高斯 𝒩(1.8, 3.16) 来"冒充"——均值和方差完全一致，丢掉的只是形状（双峰性）。这个操作叫矩匹配（Moment Matching），它就是 14.4 节弱边缘化的全部内容，也是整个混合网络精确推理失败后的止血钳。

14.4消元的闭包灾难：为什么精确推理在 CLG 上也会死

现在把 CLG 网络交给第 9 章的变量消去。逐个检查两种消去：

消去离散变量：安全

对离散变量求和，相当于把若干"表格行 × 高斯"按权重相加。结果是混合高斯——不是纯高斯，但仍然是可以精确表示的有限对象（分量数 = 被消变量的取值数 × 原有分量数）。坏消息藏在"分量数"里：每消一个离散变量，高斯分量的数量可能翻倍。

消去连续变量：看位置

如果被消的连续变量只和连续变量打交道（线性高斯之间），积分是解析的，结果仍是高斯——安全。但如果它有离散"亲属"（比如它是某个连续子的父，而该子还有离散父），积分之后落到离散变量上的因子就是每个离散配置一个不同的高斯——混合高斯爬上离散因子，分量随消去步数指数增长。

⚠️ CLG 闭包的真实边界

CLG 对"条件化连续证据"封闭，对"消去连续变量"不封闭：消元会把高斯混合传染到越来越多的因子上，k 步之后一个因子要携带 2k 个高斯分量。这就是"混合网络上精确推理一般不可行"的精确含义——不是算法没想到，是表示本身指数膨胀。

止血方案一：弱边缘化（Weak Marginalization）

既然分量爆炸，就定期"坍缩"：把一个有 m 个分量的混合高斯，用矩匹配（例 2 的全期望/全方差公式）压回单个高斯，再继续消元。这叫弱边缘化（Weak Marginalization）：

  • 保留：分布的前两阶矩（均值、方差/协方差）；
  • 丢弃：分布的形状（多峰性、偏度）。

代价是严格说结果不再精确——它是对真实消息的最好单高斯近似（在 KL 意义下，单高斯内矩匹配就是最优）。

止血方案二：强边缘化（Strong Marginalization）

换个思路：先消完所有连续变量，让网络塌缩成纯离散网络，再用第 9/10 章的离散算法收工。这要求道德化、三角化之后，不存在离散-连续混合的团——即图结构上离散与连续区域本来就近乎分离。多数真实模型不满足，所以强边缘化是奢侈品，能用则用。

止血方案三：干脆近似

  • 采样（接 Ch12）：Gibbs 采样天然适配混合网络——离散变量的条件分布是表格，连续变量的条件分布在 CLG 下是高斯，两种条件都好采样。
  • 期望传播（Expectation Propagation, EP）：每条混合高斯消息立即投影回单高斯再往下传，相当于"每步都做弱边缘化"的消息传递版。
  • 假设密度滤波（Assumed Density Filtering）：在线场景下，每步推理后把信念投影回简单分布族——第 15 章切换卡尔曼滤波的标准做法。

弱：矩匹配把混合高斯压回单高斯（保两阶矩、丢形状），任何 CLG 都能用但不精确。强：先消完全部连续变量再做离散推理，要求三角化后无离散-连续混合团。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
混合网络（Hybrid Network）
点击翻面 →
定义同时含离散变量与连续变量的概率图模型。
解决问题现实系统本来就混杂：疾病与血压、体制与收益率、地形与读数。
直觉一栋楼里住两户人家：一家说"表格话"，一家说"函数话"，消息翻译不过来。
误区以为离散化连续变量就能套老算法——精度与参数量不可兼得。
何时用金融体制模型、机器人传感、医学监护；Ch15 切换动态系统。
概念卡 2
条件线性高斯（Conditional Linear Gaussian, CLG）
点击翻面 →
定义离散变量只有离散父；连续变量给定父母为线性高斯，离散父切换参数。
解决问题让混合网络在"条件化连续证据"下保持解析可算。
直觉一张表格，每行不是概率而是一套高斯参数。
误区以为 CLG 对所有推理操作封闭——它对消去连续变量不封闭。
何时用混合网络建模的第一选择；Ch15 切换卡尔曼滤波的基础。
概念卡 3
混合高斯（Gaussian Mixture）
点击翻面 →
定义若干高斯分布的加权和：∑ wᵢ·𝒩(μᵢ, σᵢ²)，权重和为 1。
解决问题CLG 中连续变量的边缘分布天然是混合高斯（每个离散配置一个分量）。
直觉多座山叠在一起：每座山一个高斯，权重决定山的高度占比。
误区以为混合高斯仍是高斯——双峰分布没有单高斯的形状。
何时用本章推理的中间表示；Ch19 EM 的经典应用场景。
概念卡 4
弱边缘化（Weak Marginalization）
点击翻面 →
定义用矩匹配把混合高斯消息坍缩为单高斯：保留前两阶矩，丢弃形状。
解决问题消元过程中混合分量指数爆炸，必须定期压缩表示。
直觉给多峰分布拍一张"平均照"：中心对、胖瘦对，山峰细节没了。
误区以为它精确——它是单高斯族内的最优近似，不是真消息。
何时用CLG 消元；EP 与假设密度滤波每一步都在做它。
概念卡 5
强边缘化（Strong Marginalization）
点击翻面 →
定义先消去全部连续变量（解析积分），塌缩成纯离散网络后再做离散推理。
解决问题避开混合因子的表示膨胀，保持全程精确。
直觉先让说"函数话"的住户全部退租，楼里只剩一种语言。
误区以为总能用——要求三角化后无离散-连续混合团，多数模型不满足。
何时用离散区与连续区近乎分离的模型；消去顺序设计的理论上限。
概念卡 6
期望传播（Expectation Propagation, EP）
点击翻面 →
定义消息传递中每条复杂消息（如混合高斯）立即矩匹配投影回简单族再继续。
解决问题把"弱边缘化"嵌入消息传递循环，得到可控的近似推理。
直觉快递中转站：每站都把奇形怪状的包裹重新打包成标准箱。
误区以为投影无代价——每次投影丢形状信息，顺序与频率影响精度。
何时用混合网络与 Ch11 置信传播的衔接；Ch15 切换系统滤波。

📝分层习题

L1 概念辨析判断对错：CLG 网络中，连续变量的边缘分布仍然是高斯分布。说明理由。
提示

回想例 1：D 有两个取值时，X 的边缘长什么样？

完整解答
错。连续变量若有离散父（或离散祖先），边缘分布是混合高斯：每个离散配置贡献一个高斯分量。例 1 中 X 的边缘是 0.4·𝒩(0,1)+0.6·𝒩(3,1)，双峰，显然不是高斯。只有纯连续（且线性高斯）子网络里边缘才是高斯。
L1 概念辨析判断对错：CLG 限制"离散变量不能有连续父节点"只是为了建模方便，放松它对推理没有本质影响。
提示

放松后，连续父被积分消去时，离散子的分布会变成什么？

完整解答
错。若离散子有连续父（如 sigmoid CPD），消去连续父时需要对 sigmoid×高斯 积分——无解析解，且结果无法用"表格 × 高斯"表示，CLG 的封闭表示当场死亡。这条限制是封闭性的承重墙，不是审美偏好。
L2 手算推导CLG 网络：D ∈ {0,1}，P(D=1)=0.3；X|D=0 ~ 𝒩(10, 4)，X|D=1 ~ 𝒩(20, 4)。观测 X=16。手算 P(D=1 | X=16)。（提示：e−4.5 ≈ 0.0111，e−2 ≈ 0.1353，1/√(2π·4) ≈ 0.1995）
提示

先算两个密度值，再乘先验、归一化。注意方差是 4，指数里除以 2σ²=8。

完整解答

密度：P(X=16|D=0) = 0.1995·e−(16−10)²/8 = 0.1995·e−4.5 ≈ 0.1995×0.0111 ≈ 0.00221。

P(X=16|D=1) = 0.1995·e−(16−20)²/8 = 0.1995·e−2 ≈ 0.1995×0.1353 ≈ 0.02700。

乘先验：D=0：0.7×0.00221 = 0.00155；D=1：0.3×0.02700 = 0.00810。

归一化：P(D=1|X=16) = 0.00810 / (0.00155+0.00810) = 0.00810/0.00965 ≈ 0.84。读数 16 离 D=1 的中心 20 更近，后验从 0.3 翻到 0.84。

L2 手算推导同上网络，不观测任何证据。手算 X 边缘分布的均值与方差，并写出矩匹配后的单高斯近似。
提示

全期望 + 全方差：组内项 + 组间项。

完整解答

E[X] = 0.7×10 + 0.3×20 = 7+6 = 13。

组内：E[Var(X|D)] = 0.7×4+0.3×4 = 4。

组间：E[X|D] 以 0.7 取 10、0.3 取 20，均值 13：Var = 0.7×(10−13)² + 0.3×(20−13)² = 0.7×9 + 0.3×9 = 9。

Var(X) = 4 + 9 = 13。矩匹配近似：𝒩(13, 13)。真实的边缘是双峰混合，近似丢掉了双峰性。

L3 建模应用ICU 监护：病人感染状态 I（离散：无/轻/重）影响心率 H（连续）与血氧 O（连续）；H 还受病人基础心率 B（连续）影响。设计 CLG 模型：(1) 画图并写出 H、O 的 CPD 形式；(2) 指出该结构里哪个消去顺序会引爆混合分量；(3) 给出一个可落地的推理方案。
提示

谁当离散父、谁当连续父？消 B 时会发生什么？弱边缘化或采样能怎么救场？

完整解答

(1) 图：I → H，I → O，B → H。CPD：P(I) 为表格；H | I=i, B=b ~ 𝒩(αᵢ + βᵢ·b, σᵢ²)（三个感染等级三套参数）；O | I=i ~ 𝒩(μᵢ, τᵢ²)。满足 CLG 两条家规（I 无连续父）。

(2) 若先消去 B：H 的因子里含 I 与 B，对 B 积分后落到 I 的因子上是混合高斯（每个 i 一个分量）；继续消去含连续变量的因子会让分量随 I 的配置数翻倍。消去顺序 B→H→O 且在 I 之前消连续变量，即触发表示膨胀。

(3) 落地方案：对 I 的每个取值做条件化（网络变成关于 B,H,O 的纯高斯网络，可用第 7 章精确推理），再按 P(I) 与证据似然加权合并——这里 I 只有 3 个取值，"枚举离散 + 高斯解析"的混合策略精确且便宜。若离散变量多（几十个），则改用弱边缘化（EP）或 Gibbs 采样。

  • B. 结果仍是单个高斯，只是均值改变
