20.1为什么难：logZ(θ) 把参数耦成一团

回忆第4章：马尔可夫网络用对数线性形式写为 P(x) = (1/Z(θ))·exp(Σᵢ θᵢ fᵢ(x))，其中 fᵢ 是特征（Feature），θᵢ 是其权重。M 条完整数据的对数似然：

ℓ(θ : D) = ∑m ∑i θᵢ fᵢ(x⁽ᵐ⁾) − M · log Z(θ)

前一项是"数据特征计数"，按样本、按特征分解，好算。全部麻烦在第二项：配分函数 Z(θ) = Σx exp(Σᵢ θᵢfᵢ(x)) 依赖所有参数，而且要对全体赋值求和——第17章结尾预告的"耦合"就在这里：每个 θᵢ 都被拽进同一个全局归一化，"分别令导数为零"得到互相纠缠的方程组，无闭式解。

看梯度更清楚：

∂ℓ/∂θᵢ = ∑m fᵢ(x⁽ᵐ⁾) − M · Eθ[fᵢ(X)]

第一项：数据中特征 i 出现了多少次（数一下就行）。第二项：当前模型认为特征 i 应该出现多少次——模型分布下的期望，算它要做一次推理（第9–11章）。梯度的方向异常优美：把每个特征的"模型预期"拉向"数据现实"，不动时就是 MLE（矩匹配）。但每走一步梯度，都要先解一个推理问题。

✅ 好消息坏消息对

坏消息：无闭式解，必须迭代，且每步内嵌推理。好消息：ℓ(θ) 是 θ 的凹函数——没有局部最优，迭代收敛到的就是全局最优（对比第19章 EM 的多峰困境）。MN 参数学习难在"每一步贵"，不难在"会迷路"。

例 1：最小模型完整手算

两个二元变量 X—Y，一条边，一个特征 f = 1[X=Y]（"两者一致"），当前参数 θ = ln 2（即一致时势函数 eθ = 2，不一致时 1）。枚举 4 种赋值：

赋值 (X,Y)f未归一化权重 eθf
(0,0)12
(0,1)01
(1,0)01
(1,1)12

Z = 2+1+1+2 = 6；模型期望 E_θ[f] = P(X=Y) = (2+2)/6 = 2/3 ≈ 0.667。若数据中一致的比例是 0.8，则梯度 = 0.8 − 0.667 = +0.133（每条样本平均）——θ 应该增大，模型确实"低估"了一致性。若数据比例是 0.5，梯度为负，θ 减小。方向永远由"数据 vs 模型预期"的差给出。

20.2绕行方案一：伪似然、Piecewise 与对比散度

既然全局 Z 太贵，能不能把"全局归一化"拆成一堆"局部归一化"？伪似然（Pseudo-Likelihood）正是这个思路：不建模联合 P(x)，改为建模每个变量给定其邻居的条件分布，然后相乘：

ℓPL(θ) = ∑m ∑i log P(xᵢ⁽ᵐ⁾ | x−i⁽ᵐ⁾ ; θ)

关键：P(xᵢ | x−i) 只依赖 i 的马尔可夫毯（邻居），其归一化只对单个变量的取值求和——二元变量就是 2 项相加，便宜至极。全局 Z 被拆成 n 个局部小 Z，彻底驯服。

例 1 续算：P(X=1 | Y=1) = eθ·1 / (eθ·0 + eθ·1) = 2/(1+2) = 2/3；P(X=1 | Y=0) = 1/(1+2) = 1/3。若数据中 Y=1 时 X=1 占 0.8，伪似然会推高 θ——与全似然同向，但全程没碰 Z=6 那个全局量。

⚠️ 伪似然 ≠ 似然

条件概率的乘积一般不等于联合分布，伪似然是一个"代理目标"。好消息：它在一致性上有理论保证（样本趋于无穷时收敛到真参数）；坏消息：小样本下可能比真 MLE 差，且不能直接用来比较结构。

两个近亲，各一句话：

  • Piecewise / 条件似然：把图切成小块，每块内部精确归一化、块间近似独立——伪似然是"块 = 单变量马尔可夫毯"的极端情形，块越大越接近真似然、越贵。
  • 对比散度（Contrastive Divergence, CD）：回到全似然梯度，但把"模型期望"换成从数据出发只跑 k 步 MCMC 的采样期望：Δθ ∝ f(xdata) − f(xsampled)。k 小到 1 都常常够用——RBM/深度玻尔兹曼机的标配训练法。

20.3绕行方案二：CRF——条件化让 Z 变局部（本章最该讲透）

大量真实任务其实是判别式的：给定输入 X，预测输出 Y——词性标注、图像分割、实体识别。这时我们根本不需要建模 P(X)，只需要 P(Y|X)。条件随机场（Conditional Random Field, CRF）就是"MN 的条件版"：

P(Y | X) = 1Z(X) exp( ∑i θᵢ fᵢ(Y, X) )，其中 Z(X) = ∑y exp( ∑i θᵢ fᵢ(y, X) )

看 Z(X) 和生成式 MN 的 Z 差在哪：生成式的 Z 要对 X 和 Y 的全体赋值求和；CRF 的 Z(X) 里 X 是给定的，只对 Y 求和。这带来两个决定性变化：

  1. Z 变成"每个样本的局部量"：对数似然 ℓ = Σₘ [Σᵢ θᵢfᵢ(y⁽ᵐ⁾,x⁽ᵐ⁾) − log Z(x⁽ᵐ⁾)]，每个样本贡献自己的一项，互不耦合——恢复了按样本分解，样本间可以并行。
  2. 链式结构上 Z 精确可算：Y 排成链（序列标注的典型结构）时，对 y 求和可以用前向-后向算法（Forward-Backward，HMM 同款动态规划）在线性时间完成——不用枚举指数级序列。

梯度同样变成"数据计数 − 每样本局部期望"：

∂ℓ/∂θᵢ = ∑m [ fᵢ(y⁽ᵐ⁾, x⁽ᵐ⁾) − EP(Y|x⁽ᵐ⁾)[fᵢ] ]
💡 为什么这是全章最该带走的洞见

CRF 没有发明新数学，它只是换了一个问题：不建模输入的分布，配分函数就从"全局怪物"缩成"每样本的局部和"。生成式（MN）要学整个世界 P(X,Y)，判别式（CRF）只学分界线 P(Y|X)——目标小了，Z 就驯服了。这也是"生成式 vs 判别式"之争在 PGM 里的精确形态。

例：NER 一瞥。给句子"云南大学位于昆明"标注实体序列 Y₁…Y₆。特征如 f = 1[Y_t = 地名 且 X_t = "昆明"]、转移特征 g = 1[Y_t = 人名 且 Y_{t+1} = 机构名]。Y 是链 → 前向-后向算 Z(x) 与每个位置的边际 → 梯度可算 → 梯度上升求解。整条流水线没有一步需要枚举 6 个标签的全组合。

链上 CRF 的前向-后向：把 Z(x) 亲手算出来

"前向-后向线性可算"这句话到此为止还只是承诺。现在拿一条最小的 3 节点链，把 Z(x) 和每个位置的边际从头到尾手算一遍——算完你会发现，这套递推你其实已经学过。

设定：链 Y₁—Y₂—Y₃，标签二值 {0,1}。观测 x 通过节点因子进入：ψ₁(y₁)：y₁=0 时取 3、y₁=1 时取 1（来自观测 x₁ 的局部证据；其余节点因子为 1）。边因子"相同 2 / 不同 1"：ψ₁₂(a,b) 与 ψ₂₃(b,c) 均在 a=b 时取 2、a≠b 时取 1。未归一化得分与配分函数：

P̃(y | x) = ψ₁(y₁)·ψ₁₂(y₁,y₂)·ψ₂₃(y₂,y₃)， Z(x) = ∑y P̃(y | x)

前向递推 α：定义 α₁(y₁) = ψ₁(y₁)，通项为

αt(yt) = ∑yt−1 αt−1(yt−1)·ψt−1,t(yt−1, yt)

逐格代入数字（每个向量按 (y=0, y=1) 两个取值列出）：

α₁ = ψ₁ = (3, 1)
α₂(0) = 3·2 + 1·1 = 7， α₂(1) = 3·1 + 1·2 = 5 ⟹ α₂ = (7, 5)
α₃(0) = 7·2 + 5·1 = 19， α₃(1) = 7·1 + 5·2 = 17 ⟹ α₃ = (19, 17)
Z(x) = ∑y₃ α₃(y₃) = 19 + 17 = 36

后向递推 β：从链尾出发，β₃ = (1, 1)，通项为

βt(yt) = ∑yt+1 ψt,t+1(yt, yt+1)·βt+1(yt+1)
β₂(0) = 2·1 + 1·1 = 3， β₂(1) = 1·1 + 2·1 = 3 ⟹ β₂ = (3, 3)
β₁(0) = 2·3 + 1·3 = 9， β₁(1) = 1·3 + 2·3 = 9 ⟹ β₁ = (9, 9)

交叉验证：在任意节点汇合都该得到同一个 Z。用链头验：Z(x) = ∑y₁ α₁(y₁)·β₁(y₁) = 3·9 + 1·9 = 36 ✓——两个方向算的是同一个量，方向不同只是求和顺序不同。

边际：每个位置的后验用 α·β/Z 直接读出：

✅ 这和第10章是同一件事

回头对照第10章 §10.4（消息传播与校准：两遍传遍全树）：这里的 α 递推就是在链上做变量消去——α₂ 正是消去 Y₁ 后留下的因子，α₃ 是再消去 Y₂，最后对 Y₃ 求和得 Z。前向-后向没有新数学，它只是"从两端各消一遍"（收集 + 分发）：左端到 Yt 的部分和存进 αt，右端到 Yt 的部分和存进 βt，于是每个节点的边际都能用 α·β/Z 拿到，不必为每个查询重新消元——这正是团树"一次校准、回答所有查询"在链上的样子。

最后把学习闭环接上：对数线性视角下，ln Z(x) 对特征权重的梯度仍是"数据计数 − 模型期望"（回看第17章 §17.6）——

∂ ln Z(x)∂θᵢ = EP(Y|x)[fᵢ]

只不过这里的期望要用上面这套前向-后向对每个样本 x 各算一遍：每轮迭代先跑一遍这张图拿到 α、β 与边际，再按"数据 vs 模型预期"的差更新 θ。学习 CRF 的每一步梯度，内循环里跑的都是这条链。

20.4结构学习：评分不可分解，L1 来软删边

第18章的结构学习靠"评分可分解"活着：Score = Σᵢ FamScore，局部改动局部重算。无向模型这份礼物也被 logZ 收走了：每条边的增删都改变 Z(θ)，从而改变所有参数的 MLE 和整个似然——评分不可分解，第18章的高效爬山在 MN 上失效，每次候选评估都要重训一次全模型。

主流出路是把"结构学习"转化为"参数学习的正则化"：L1 正则

maxθ ℓ(θ : D) − λ ∑i |θᵢ|

L1 惩罚的几何性质会把不重要的 θᵢ 精确压到 0——θᵢ = 0 意味着特征 i 消失、对应的边被删掉。λ 控制稀疏度：λ 大则图稀疏。于是"选结构"变成"调 λ 的连续优化"，绕开了离散图搜索。配套做法还有伪似然邻域选择：对每个变量用伪似然 + L1 学"谁是我的邻居"，拼起来即得骨架。

定义梯度 = 数据特征计数 − M·E_θ[fᵢ]；不动点处模型预期 = 数据现实。
解决问题给出无闭式解时的迭代方向；MLE 等价于矩匹配。
直觉教练纠正动作：看（数据）的和做（模型）的对齐为止。
误区以为能一次算完——每步都要重新推理，参数变了期望就变。
何时用一切对数线性模型（最大熵、CRF、RBM）的训练核心。
概念卡 3
伪似然（Pseudo-Likelihood）
点击翻面 →
定义ℓ_PL = ΣₘΣᵢ log P(xᵢ⁽ᵐ⁾|x₋ᵢ⁽ᵐ⁾;θ)，条件概率乘积代替联合似然。
解决问题把全局归一化拆成单变量局部归一化，绕开 Z。
直觉不问"整张卷子多难"，只问"给定同桌答案，我这道题多难"。
误区以为等于真似然——条件乘积一般 ≠ 联合；不能用它比较结构。
何时用大图上快速估参、邻域选择学骨架。
概念卡 4
条件随机场（CRF）
点击翻面 →
定义P(Y|X) = (1/Z(X))·exp(Σᵢθᵢfᵢ(Y,X))，Z(X) 只对 Y 求和。
解决问题判别式任务：不建模 P(X)，配分缩成每样本局部量。
直觉不描绘全世界，只画分界线——目标小了，账就好算了。
误区以为 CRF 是新数学——它只是把 MN 条件化，好处全来自换问题。
何时用序列标注（NER/词性）、图像分割等结构化预测标配。
概念卡 5
对比散度（Contrastive Divergence）
点击翻面 →
定义Δθ ∝ f(x_data) − f(x_sampled)：用 k 步 MCMC 采样代替模型期望。
解决问题精确推理太贵时的梯度近似，k=1 都常够用。
直觉不看全世界的平均，只看"从现实出发走一小步"的样子。
误区以为是无偏梯度——有偏，但偏差在实践中可接受。
何时用RBM、深度玻尔兹曼机等能量模型的标准训练法。
概念卡 6
L1 结构学习（ℓ₁-Regularized Structure Learning）
点击翻面 →
定义max ℓ − λΣ|θᵢ|：连续惩罚把不重要权重压到精确的 0。
解决问题把不可分解的离散结构搜索转化为连续凸优化。
直觉税收到边头上：交不起税的边自动消失。
误区以为 λ 越大越好——过大把真边也删了，需按验证集调。
何时用高维 MN/高斯图模型（GLASSO）结构学习主流方案。

📝分层习题

L1 概念辨析判断对错：MN 的似然是凹函数，所以它的 MLE 和 BN 一样有闭式解。说明理由。
提示

凹性保证的是什么？闭式解需要的是"令导数为零可解析求解"，MN 的梯度方程满足吗？

完整解答
错。凹性只保证"无局部最优、迭代必达全局最优"，不保证"能一步解出"。MN 的梯度方程 ∂ℓ/∂θᵢ = Σₘfᵢ − M·E_θ[fᵢ] = 0 中，E_θ[fᵢ] 是 θ 的复杂非线性函数（还要先推理才能算），方程组互相纠缠，无法解析求解——所以必须迭代优化。凹性是"不会迷路"，不是"有直达电梯"。
L1 概念辨析判断对错：伪似然等于真实似然的近似，因此可以用伪似然比较两个结构的好坏。说明理由。
提示

条件概率的乘积等于联合分布吗？两个不同结构的伪似然在同一量纲上吗？

完整解答
前半句勉强、后半句错。伪似然是代理目标：条件乘积一般不等于联合分布，不是同一量纲上的"近似似然值"。两个结构的伪似然各自在不同的条件分解下计算，数值不可比——所以伪似然适合"固定结构估参数"和"逐节点选邻居"，不适合像 BIC 那样做结构评分比较。
L2 手算推导例 1 模型：X—Y 二元，f = 1[X=Y]，θ = ln 2。手算：① Z；② E_θ[f]；③ 若 M=100 条数据中 80 条 X=Y，写出一个样本平均的梯度值并说明更新方向。
提示

枚举 4 种赋值，一致时权重 e^θ = 2，不一致时 1。

完整解答

① Z = 2 + 1 + 1 + 2 = 6。

② E_θ[f] = P(X=Y) = (2+2)/6 = 2/3 ≈ 0.667。

③ 样本平均数据计数 = 80/100 = 0.8；梯度（每样本）= 0.8 − 0.667 = +0.133。梯度为正 → θ 增大 → 一致赋值的权重 e^θ 相对变大 → 模型对"一致"的预测从 0.667 向 0.8 靠拢。这就是"把模型预期拉向数据现实"的一次具体迈步。

L2 手算推导同例 1 模型与参数（θ = ln 2）。手算伪似然的局部条件：① P(X=1|Y=1)；② P(X=1|Y=0)；③ 说明这两个量为什么不需要全局 Z。
提示

给定 Y 时，X 只有两个取值，归一化只对 X 的两种取值求和。

完整解答

① P(X=1|Y=1) = e^{θ·1}/(e^{θ·0}+e^{θ·1}) = 2/(1+2) = 2/3。

② P(X=1|Y=0) = e^{θ·0}/(e^{θ·0}+e^{θ·1}) = 1/(1+2) = 1/3。

③ 给定 Y=y 后，归一化只对 X 的两个取值求和（e^{θf(0,y)} + e^{θf(1,y)}），是一个 2 项的局部小 Z；不需要对 (X,Y) 的全部 4 种联合赋值求和。变量一多，这个差别从"4 项 vs 2 项"变成"2ⁿ 项 vs 2 项"——伪似然的全部价值就在这里。

L3 建模应用用 CRF 做中文 NER：输入字序列 X = x₁…x_T，输出标签序列 Y ∈ {人名, 地名, 机构, O}^T。① 画出因子图（链式）；② 设计两类特征函数；③ 写出 Z(x) 并解释为什么前向-后向能在线性时间算它；④ 若改成生成式 MN（同时建模 P(X,Y)），会多出什么困难？
提示

链式：Y_t—Y_{t+1} 转移 + Y_t—x_t 发射；Z 只对 Y 求和；生成式还要对 X 的联合分布建模。

完整解答

① 因子图：链 Y₁—Y₂—…—Y_T，每个 Y_t 连一个发射因子 ψ(Y_t, x_t)，相邻对连转移因子 ψ(Y_t, Y_{t+1})。

② 发射特征：f = 1[Y_t = 地名 且 x_t ∈ 地名词表]、1[Y_t = 人名 且 x_t 是常见姓氏]；转移特征：g = 1[Y_t = 人名 且 Y_{t+1} = 机构]、1[Y_t = O 且 Y_{t+1} = 地名]。

③ Z(x) = Σ_{y₁…y_T} exp(Σ_t [θ·f(y_t,x_t) + θ·g(y_t,y_{t+1})])。朴素枚举是 |标签|^T 项；但链式结构下可定义前向消息 α_t(y_t) = Σ_{y_{t-1}} α_{t-1}(y_{t-1})·ψ(y_{t-1},y_t,x)，每步只对单变量求和（|标签| 项），T 步线性完成——这就是前向-后向（变量消去在链上的特例）。

④ 生成式要建模 P(X,Y)，需要额外参数化字的生成分布（特征覆盖 x 自身的依赖），配分 Z 变成对 X、Y 全体求和——x 的取值组合天文数字，Z 无法精确计算，只能伪似然/CD 近似；而且要浪费容量去建模输入分布，判别性能通常反而下降。CRF 的全部优势正是"不为 X 建模"。
