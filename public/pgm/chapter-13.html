13.1MAP 到底是什么：它和"每个变量各自最可能"不是一回事

第 9–12 章的推理任务都是求和推理（Sum Inference）：给定证据，算出某个（或每个）查询变量的边缘分布 P(Xᵢ | E)。但很多实际任务不需要分布，只需要一个答案：医学诊断要的是"最可能的疾病组合"，图像分割要的是"最可能的一组像素标签"。这就是 最大后验（Maximum A Posteriori, MAP）任务：

MAP(Y | E = e) = arg maxy P(Y = y | E = e) = arg maxy P(Y = y, E = e)

等号成立是因为 P(E=e) 与 y 无关，归一化常数不影响 arg max。当查询集 Y 是全部非证据变量时，这个任务也叫最可能解释（Most Probable Explanation, MPE）。

⚠️ 本章最重要的反直觉事实

MAP 答案 ≠ 每个变量各自取边缘最可能值。先算每个变量的边缘分布、再逐变量取 arg max，得到的一般不是联合最可能赋值。下面用一个 2×2 的分布亲手验证。

例 1：联合最可能 ≠ 逐变量最可能（完整手算）

两个二元变量 X、Y 的联合分布：

y⁰y¹行和（X 的边缘）
x⁰0.040.300.34
x¹0.360.300.66
列和（Y 的边缘）0.400.601.00

第一步：逐变量取边缘最可能。P(x¹) = 0.66 > 0.34，所以 X 取 x¹；P(y¹) = 0.60 > 0.40，所以 Y 取 y¹。拼起来得到 (x¹, y¹)，其联合概率是 0.30。

第二步：直接找联合最可能。四格里最大的是 (x¹, y⁰) = 0.36。

结论：边缘拼出的答案 (0.30) 比真正的 MAP (0.36) 少了 20% 的概率质量。原因不难理解：取边缘时，x¹ 的胜利靠的是 (x¹,y⁰) 和 (x¹,y¹) 两格加总的优势；一旦要求两个变量"同时落在一格里"，加总优势用不上了。

💡 关键一跃

边缘推断回答的是"平均而言每个变量倾向什么"；MAP 回答的是"哪一幅完整画面最可信"。画面内部的相容性（各变量取值是否配套）只有联合视角才能看见。所以 MAP 不能被分解成逐变量问题——必须整体优化。

13.2Max-Product 变量消去：把第 9 章的 ∑ 换成 max

上一节明确了任务：对联合打分取最大。好消息是，max 对乘法同样满足分配律：

maxx [ f(x) · g ] = g · maxx f(x) （g 不含 x 时）

这正是第 9 章变量消去依赖的分配律的 max 版。于是整个消去流程原封不动搬过来：每个因子照乘，消去变量时把"对取值求和"换成"对取值取最大"。这就是 Max-Product 变量消去（Max-Product Variable Elimination）。

但有一个新需求：sum-product 只产出数字（边缘概率），MAP 还要产出那组赋值。所以每次取最大时，必须同时记下"是哪个取值赢了"——一根回溯指针（Traceback Pointer）：

τ(Y) = maxX φ(X, Y) ， δ(Y) = arg maxX φ(X, Y)

τ 存赢家的分数，δ 存赢家的取值；消完所有变量后，从最后的 arg max 出发沿 δ 倒着走，就还原出完整的 MAP 赋值。

例 2：链上 Max-Product 消去的完整手算

二元变量链 A—B—C，两个因子（未归一化的打分即可，MAP 不需要 Z）：

abφ₁(a,b)bcφ₂(b,c)
002001
011013
101102
114111

第一步：消去 A。对 b 的每个取值，在 a 上取最大：

  • τ₁(b⁰) = max(φ₁(0,0), φ₁(1,0)) = max(2, 1) = 2，δ₁(b⁰) = a⁰
  • τ₁(b¹) = max(φ₁(0,1), φ₁(1,1)) = max(1, 4) = 4，δ₁(b¹) = a¹

第二步：消去 B。新因子 τ₁(b)·φ₂(b,c)，对 b 取最大：

  • c = 0：b⁰ 给 2·1 = 2，b¹ 给 4·2 = 8 → τ₂(c⁰) = 8，δ₂(c⁰) = b¹
  • c = 1：b⁰ 给 2·3 = 6，b¹ 给 4·1 = 4 → τ₂(c¹) = 6，δ₂(c¹) = b⁰

第三步：取全局最大并回溯。max(8, 6) = 8，赢家 c = c⁰。回溯：δ₂(c⁰) = b¹ → b = b¹；δ₁(b¹) = a¹ → a = a¹。

MAP 赋值：(a¹, b¹, c⁰)，分数 = φ₁(1,1)·φ₂(1,0) = 4·2 = 8。不信可以枚举全部 8 种赋值核对——最大的确实是 8。

💡 直觉

Max-Product 就是动态规划：消去变量时只把"局部冠军"往后传，冠军是谁用指针记着。复杂度和 Sum-Product VE 完全一样：O(n · dw+1)，w 为诱导宽度——同一棵团树上，两遍 Max-Product 消息传递也能给出精确 MAP（Ch10 的骨架直接复用）。

⚠️ 常见误区

"既然复杂度一样，MAP 和边缘推断一样难"——错。同样的 精确算法复杂度一样，但两者的可近似性天差地别：边缘概率可以用采样近似（Ch12），MAP 却连"近似得好不好"都难以验证。这个差距就是 13.4 节的 NP-hard。

边缘 MAP：先求和再取最大，max 与 ∑ 不可交换（完整手算）

13.1 节的 MAP 任务里，查询集可以是全部非证据变量（MPE），也可以只是其中一部分 Y，其余变量 W 只是陪衬（nuisance）。后一种任务叫边缘 MAP（Marginal MAP）：先把 W 求和边缘化，再对 Y 取 arg max：

arg maxy P(y | e) = arg maxy ∑w P(y, w, e)

它和联合 MAP 的分工：

联合 MAP（MPE）边缘 MAP
查询对象全部非证据变量部分变量 Y，其余 W 是陪衬
目标arg maxy,w P(y, w, e)arg maxy ∑w P(y, w, e)
需要的算子只有 max（Max-Product 直接给出）∑ 与 max 都要
消去顺序任意顺序均可求和变量必须先于取最大变量被消去

为什么不能把 Max-Product 直接拿来用？因为 max 与 ∑ 不可交换：

maxx ∑y f(x, y) ≤ ∑y maxx f(x, y)　（max of sums ≤ sum of maxes）

左边先加总再取最大，是边缘 MAP 要的顺序；右边先对每个 y 取最大再加总——每个 y 可以让不同的 x 当冠军，把所有局部冠军都收进来，结果必然虚增（等号只在"所有 y 的冠军是同一个 x"时成立）。所以消去顺序受到硬约束：求和变量 W 必须先于取最大变量 Y 被消去，Max-Product 那种"随便挑顺序消"的自由没了。下面用一条三变量链把这件事算透。

例：链 X—Y—Z 上两种答案的分歧。全部二值，因子 φ₁(X,Y) 与 φ₂(Y,Z)（φ₂ 的规则是"相同得 2、不同得 1"）：

xyφ₁(x,y)yzφ₂(y,z)

0128011
1016101
1130112

未归一化权重 w(x,y,z) = φ₁(x,y)·φ₂(y,z)。查询变量只有 X，Y、Z 是陪衬变量。

第一步：枚举全部 8 个权重（顺便得到总质量 Z = 300）：

(x, y, z)φ₁(x,y) · φ₂(y,z)w
(0,0,0)26 · 252
(0,0,1)26 · 126
(0,1,0)28 · 128
(0,1,1)28 · 256
(1,0,0)16 · 232
(1,0,1)16 · 116
(1,1,0)30 · 130
(1,1,1)30 · 260

第二步：联合 MAP。单格最大是 w(1,1,1) = 60（次大的两格是 w(0,1,1) = 56 与 w(0,0,0) = 52）。联合 MAP 赋值 = (x,y,z) = (1,1,1)，其 x 分量 = 1。

第三步：边缘 MAP（先求和，再取最大）。注意对每个 y 都有 ∑z φ₂(y,z) = 2 + 1 = 3，因此：

P(x) ∝ ∑y,z w(x,y,z) = 3 · ∑y φ₁(x,y)
  • x = 0：3 × (26 + 28) = 3 × 54 = 162
  • x = 1：3 × (16 + 30) = 3 × 46 = 138

归一化（除以 Z = 300）：P(x=0) = 162300 = 0.54，P(x=1) = 138300 = 0.46。边缘 MAP 答案 x = 0——与联合 MAP 的 x 分量 1 不一致。

第四步：顺序不可交换的数值证据。同一个网络上把两种顺序各算一遍：

  • 正确顺序（先 ∑ 后 max）：maxx ∑y,z w = max(162, 138) = 162 ✓
  • 错误顺序（先 max 后 ∑）：∑y,z maxx w = 52 + 26 + 30 + 60 = 168 ≠ 162 ✗

168 的虚增从哪来？逐格看冠军：(y,z)=(0,0) 时 x=0 赢（52）、(0,1) 时 x=0 赢（26）、(1,0) 时 x=1 赢（30）、(1,1) 时 x=1 赢（60）——四个格子的冠军不是同一个 x，先取 max 把它们的分数全部收进总分；而正确顺序只允许一个 x 带走它自己那一列的全部加总。这正是"max of sums ≤ sum of maxes"的现场版。

第五步：消去顺序的结论。边缘 MAP 必须先用 ∑ 消去全部非查询变量（本例先消 Z 再消 Y，或先 Y 再 Z 皆可），最后才对 X 取 max。这个硬约束缩小了消去顺序的选择空间，可能被迫采用诱导宽度更大的顺序——所以边缘 MAP 一般比联合 MAP 更难（概念卡 6 说"两种最难的操作叠在一起"，根源就在这里）。

⚠️ 常见误区

"对联合 MAP 的赋值取 x 分量，就是 x 的边缘 MAP"——错，本例当场翻车：联合 MAP (1,1,1) 的 x 分量是 1，边缘 MAP 答案却是 0。联合 MAP 要的是"整幅画面同时最吻合"；边缘 MAP 允许 x 靠多幅画面的加总优势获胜（x=0 的团体分 162 > x=1 的 138）。任务是哪个就解哪个，两者不能互相代替。

💡 直觉：各有各的消去时刻表

把变量消去想成两条流水线：陪衬变量走"∑ 口"，查询变量走"max 口"，且 ∑ 口必须全部排在 max 口之前。联合 MAP 里所有变量同走一条 max 流水线，顺序随便排；边缘 MAP 里两条流水线有先后，调度被卡死——顺序选择变少、诱导宽度可能变大，这就是它更难的结构性原因。

13.3Max-Sum 与能量视角：乘积变加法，MAP 变最小化

连乘一大堆小数值，数值上容易下溢；取对数，乘法变加法——这就是 Max-Sum 形式。对马尔可夫网络 P(X) = (1/Z)∏C ψC(XC)：

arg maxX P(X) = arg maxX ∑C log ψC(XC) = arg minX ∑C EC(XC)

最后一步令 EC = −log ψC，就是第 4 章见过的能量函数（Energy Function）。于是：

✅ 判定规则

MAP = 能量最小化。Max-Product（乘积上取最大）、Max-Sum（对数上取最大）、能量最小化（能量上取最小）是同一个问题的三张面孔。选哪张脸取决于工具：消息传递用前两张，组合优化用第三张。

这张"能量"的脸价值巨大：它把 PGM 接进了组合优化几十年的工具箱。计算机视觉里图像去噪、立体匹配、分割的标准做法，就是把任务写成能量最小化——每个像素一个标签变量，相邻像素标签不一致要付能量代价。这正是 13.5 节图割的舞台。

13.4为什么 MAP 是 NP-hard：不用定理名，用直觉

13.2 节说精确 Max-Product 和精确 Sum-Product 复杂度相同，怎么这里又说 MAP 更难？关键在于：那个"相同"是树上的相同；离开树之后，两者的命运分岔了。

先看一个最直接的难度证据——从 3-SAT 到 MAP 的归约。任给一个 3-SAT 公式（若干个子句的合取，如 (x₁ ∨ ¬x₂ ∨ x₃) ∧ …），为每个子句建一个因子：子句被满足得 1 分，不满足得 0 分。那么：

✅ 归约一眼看穿

这个网络的 MAP 分数 > 0 ⟺ 存在满足所有子句的赋值 ⟺ 原 3-SAT 公式可满足。也就是说，任何一个能高效解 MAP 的算法，都能顺手高效解 3-SAT。而 3-SAT 是 NP-complete 的招牌问题——所以 MAP 不可能有多项式通用算法，除非 P = NP。这就是"MAP 是 NP-hard"的全部直觉：它至少和布尔可满足性一样难。

再和边缘推断对比。边缘推断（算 P(Xᵢ|E)）的难属于 #P 类——要对指数多个赋值全部加总，连"验证一个答案"都贵。但它的好消息是：采样可以给出越来越准的近似（Ch12），误差随样本数平滑下降。MAP 不同：

  • 没有"部分正确"：赋值差一位，分数可能从最高掉到零（想想 3-SAT 里一个子句被违反）。近似算法难以给出"离最优还有多远"的保证。
  • 验证不了：有人递给你一组赋值说"这是 MAP"，你只能验证它分数高，无法验证"没有更高的"——那要扫完整个指数空间。
  • 对环极度敏感：树上精确 MAP 很便宜（和 sum-product 同价），一旦图有环，消息传递不再收敛到正确答案，组合优化的全部难度瞬间回来。
💡 一句话总结两难

求和的难是"量大"——每项都贡献一点，采样可以摊薄；取最大的难是"藏针"——最优解只有一根针，插在指数大的草垛里，而且不承认"差不多找到"。

13.5求解思路地图：整数规划、LP 松弛，以及图割这块"特例绿洲"

既然通用精确解无望，工程上的策略是：把 MAP 翻译成组合优化的标准语言，然后看自己的问题落在哪个可解特例里。

翻译一：整数线性规划（ILP）

引入 0/1 指示变量 μi(xi)（"节点 i 是否取值 xi"）和 μij(xi,xj)（"边两端是否同时取这对值"），MAP 变成：

max ∑i ∑xi θi(xi)·μi(xi) + ∑ij ∑xi,xj θij(xi,xj)·μij(xi,xj)

其中 θ = log ψ。约束：μ 取 0/1，且边上的联合指示必须与两端节点指示一致。整数约束是全部难度所在。把 0/1 放松成 [0,1] 区间，就得到 LP 松弛（LP Relaxation）：多项式可解，给出 MAP 的上界；若松弛解恰好是整数，则中奖——它就是精确 MAP（树上永远如此，这叫松弛是"紧"的）。切割平面（Cutting Plane）法不断加入新约束把分数解"切掉"，逐步收紧松弛，是一般含环图的主力精确武器之一。

翻译二：图割（Graph Cuts）——特例绿洲

有一类能量函数可以精确地、多项式时间地最小化：二元变量的成对 MRF，且每条边的能量满足子模性（Submodularity）：

Eij(0,0) + Eij(1,1) ≤ Eij(0,1) + Eij(1,0)

读法："两端一致"的总代价不超过"两端不一致"的总代价——邻居倾向取相同标签，这正是图像分割的物理直觉。此时 MAP 可以精确转化为网络流上的最小割问题，用最大流算法秒解。

例 3：验证子模性并手算一个 2 像素分割

两个相邻像素 X₁、X₂，各自倾向"前景"（1）：一元能量 E₁(0)=2, E₁(1)=0；E₂(0)=3, E₂(1)=0。相邻一致性边能量：E₁₂(0,0)=0，E₁₂(1,1)=0，E₁₂(0,1)=E₁₂(1,0)=2。

第一步：验证子模。E₁₂(0,0)+E₁₂(1,1) = 0 ≤ E₁₂(0,1)+E₁₂(1,0) = 4。✓ 可以用图割精确求解。

第二步：枚举四种赋值的总能量：

(x₁, x₂)E₁E₂E₁₂总能量
(0,0)2305
(0,1)2024
(1,0)0325
(1,1)0000

MAP = (1,1)：两个像素都是前景，总能量 0。注意"保持一致"帮 (1,1) 省掉了 2 点不一致代价——子模条件保证的正是这种"一致偏好"能被图割利用。

多标签怎么办？ 图割只管二元。多标签时用 α-Expansion：每轮选一个标签 α，把"保持原标签 vs 换成 α"编成二元子问题用图割解，迭代改进；αβ-Swap 类似，在两个标签间做交换。它们是近似算法，但在视觉任务上效果极好，是事实标准。

⚠️ 常见误区

"图割能解 MAP"——只在二元 + 成对 + 子模三个条件同时成立时精确。三元以上、高阶项、非子模能量，图割全部失效，只能回到 LP 松弛/α-Expansion 这类近似或松弛路线。

概念卡 1
MAP / MPE（Maximum A Posteriori / Most Probable Explanation）
点击翻面 →
定义arg maxy P(Y=y | E=e)：给定证据下联合最可能的赋值；查全体非证据变量时叫 MPE。
解决问题决策只要一个答案，不需要完整后验分布。
直觉不问"每门课平均考多少"，问"哪份全科成绩单最可能"。
误区以为逐变量取边缘 arg max 再拼起来就是 MAP——例 1 证明它可以错。
何时用诊断、分割、解码（Ch15 Viterbi）、影响图决策（Ch23）。
概念卡 2
Max-Product 变量消去（Max-Product VE）
点击翻面 →
定义Sum-Product VE 把消去算子从 ∑ 换成 max，并记录回溯指针 δ。
解决问题在因子结构上高效找全局最大赋值，不用枚举全部赋值。
直觉淘汰赛：每轮只把局部冠军往后传，冠军名单用指针记着。
误区只记最大值不记指针——能拿到分数却还原不出赋值。
何时用树上/低树宽图精确 MAP；Ch15 Viterbi 是它的链上特例。
概念卡 3
Max-Sum / 能量最小化（Energy Minimization）
点击翻面 →
定义取对数后 MAP = max ∑ log ψ = min ∑ E，E = −log ψ 为能量。
解决问题乘法变加法（数值稳定），并接通组合优化工具箱。
直觉同一座山的两张地图：找最高峰 = 找最低谷（海拔取负）。
误区以为换了形式换了问题——三者数学上严格等价。
何时用计算机视觉能量模型；LP 松弛与图割都以能量形式陈述。
概念卡 4
LP 松弛与切割平面（LP Relaxation / Cutting Plane）
点击翻面 →
定义把 MAP 写成整数线性规划后放松整数约束为连续区间，得多项式可解的 LP；切割平面逐步加约束收紧。
解决问题一般含环图上 NP-hard 的 MAP，需要一个可计算的界与收紧机制。
直觉先允许"半个标签"的作弊解，再一刀刀把作弊空间削掉。
误区以为松弛解能直接用——分数解不是合法赋值，只有取整（且取整解=松弛解）时才中奖。
何时用含环图的精确/认证近似 MAP；树上松弛必紧。
概念卡 5
图割与子模性（Graph Cuts / Submodularity）
点击翻面 →
定义二元成对 MRF 且边能量满足 E(0,0)+E(1,1) ≤ E(0,1)+E(1,0) 时，MAP 精确等价于网络最小割。
解决问题NP-hard 大海中的一块多项式绿洲：一大类视觉能量可精确最小化。
直觉"一致比分歧便宜"的能量，可以画成水管网络，最小割一刀切出最优标签。
误区以为图割是通用 MAP 算法——三元以上、非子模、高阶项全部失效。
何时用图像分割、立体匹配；多标签靠 α-Expansion 迭代调用它。
概念卡 6
边缘 MAP（Marginal MAP）
点击翻面 →
定义arg maxy P(Y=y|E) 但 Y 只是部分变量：要先对其余变量求和再取最大。
解决问题只关心一部分变量的最可能取值时（其余变量是 nuisance）。
直觉既要加总（边缘化 nuisance）又要取最大（选 Y）——两种最难的操作叠在一起。
误区以为它比 MPE 简单——max 与 ∑ 不可交换，消去顺序受限，复杂度反而更高。
何时用诊断只查病因子集；理论上本章最难的推广。

📝分层习题

L1 概念辨析判断对错：只要用 Max-Product 变量消去，MAP 推理就和边缘推理一样便宜，所以 MAP 不是 NP-hard 的说法是误传。说明理由。
提示

回忆"相同复杂度"成立的条件是什么图结构；NP-hard 谈的是哪一类图。

完整解答
错。Max-Product VE 与 Sum-Product VE 复杂度相同（O(n·dw+1)），但这个"相同"对两者都随诱导宽度 w 指数爆炸。NP-hard 指的是：不存在对所有图都多项式的 MAP 算法（3-SAT 归约）。树上的便宜是特例，不推翻一般情形的难度结论。
L1 概念辨析判断对错：对任意分布，MAP 赋值中每个变量的取值一定等于该变量边缘分布的 arg max。
提示

回到 13.1 节的 2×2 反例表，逐格核对。

完整解答
错。13.1 例 1 中 MAP = (x¹, y⁰)，但 Y 的边缘 arg max 是 y¹（0.60 > 0.40）。MAP 的 y 分量 y⁰ 不是 Y 的边缘最可能值。原因：MAP 优化的是单格联合概率，边缘 arg max 优化的是整行/整列的加总，两者的目标函数不同。
L2 手算推导二元链 X—Y，因子 φ(x,y)：φ(0,0)=3，φ(0,1)=2，φ(1,0)=1，φ(1,1)=5。用 Max-Product 消去（消 X）求 MAP 赋值与分数，写出回溯指针。
提示

先对每个 y 在 x 上取 max（记指针），再对 y 取 max，最后回溯。

完整解答

消去 X：τ(y⁰) = max(3, 1) = 3，δ(y⁰) = x⁰；τ(y¹) = max(2, 5) = 5，δ(y¹) = x¹。

全局最大：max(3, 5) = 5，y = y¹。

回溯：δ(y¹) = x¹。

MAP = (x¹, y¹)，分数 = 5。枚举核对：3、2、1、5 中最大确为 5。✓

L2 手算推导某二元成对能量边：E(0,0)=1，E(1,1)=0，E(0,1)=3，E(1,0)=1。问：(1) 它满足子模性吗？(2) 若把 E(0,0) 从 1 改成 4，结论怎么变，意味着什么？
提示

比较"同标签和"与"异标签和"。

完整解答

(1) E(0,0)+E(1,1) = 1+0 = 1 ≤ E(0,1)+E(1,0) = 3+1 = 4。✓ 满足子模性，可用图割精确求解。

(2) 改后：4+0 = 4 ≤ 3+1 = 4，仍满足（等号是允许的）。若改成 4.1，则 4.1 > 4，子模被破坏——这条边实际上"偏好不一致"（x=0 和两端相异都便宜），图割不再适用，只能退回 LP 松弛等通用方法。

L3 建模应用医学诊断：两种疾病 D₁、D₂（各取 有/无），症状 S 受两者影响。临床要"最可能的疾病组合"而不是每种病各自的概率。请：(1) 说明该用 MAP 还是逐变量边缘 arg max，为什么；(2) 若还要求同时给出 S 的最可能值，任务变成什么；(3) 说出一个让图割能用上的建模限制。
提示

回忆例 1 的教训；"所有非证据变量一起查"是哪种任务；图割的三个前提。

完整解答

(1) 用 MAP（对 {D₁,D₂} 联合取 arg max）。两病可能有交互（共生或互斥），逐变量边缘 arg max 可能拼出一组联合概率并非最高的组合——例 1 的反例结构在医学里真实存在。

(2) 查询集扩大为全部非证据变量 {D₁,D₂,S}，任务变成 MPE（最可能解释）。

(3) 限制模型为：二元变量（有/无）+ 只含成对交互 + 所有边能量子模（如"两病共生"与"症状吻合"的边都是同标签便宜）。此时可用图割精确求得最优诊断组合；一旦加入"三病联合效应"这类高阶项或"互斥"型（非子模）边，就要改用 LP 松弛。

L3 建模应用临床决策：病情 X∈{轻，重}（编码 0/1），两项检查 Y、Z 与病情成链 X—Y—Z（Y、Z 均为二值结果）。因子沿用正文手算例：φ₁(X,Y)：φ₁(0,0)=26，φ₁(0,1)=28，φ₁(1,0)=16，φ₁(1,1)=30；φ₂(Y,Z)：相同得 2、不同得 1。医生只关心最可能的病情 X，不关心检查结果的具体取值。问：(1) 该用联合 MAP 还是边缘 MAP？(2) 分别算出两种答案；(3) 解释两者为什么不同。
提示

"只关心 X"意味着 Y、Z 是陪衬变量——该对它们做什么操作？回忆正文手算中 60 与 162 各代表什么。

完整解答

(1) 用边缘 MAP：arg maxx ∑y,z w(x,y,z)。医生的决策变量只有 X，检查结果 Y、Z 不被询问，应当对它们求和边缘化，而不是连同它们一起取最大。

(2) 联合 MAP：w(1,1,1) = 30·2 = 60 为全局最大（次大 56、52），赋值 = （重， 阳性， 阳性），x 分量 = 重。边缘 MAP：对每个 y 有 ∑z φ₂ = 3，故 P(x) ∝ 3·∑y φ₁(x,y)——x=轻得 3×(26+28) = 162（即 162/300 = 0.54），x=重得 3×(16+30) = 138（0.46），答案 = 轻。两种算法给出相反结论。

(3) 差异根源：联合 MAP 找的是"病情与两项检查同时最吻合"的单幅画面，"重"只赢在 w（重，阳，阳）=60 这一个格子；边缘 MAP 把每个病情下所有检查组合的概率质量加总，"轻"靠 52+26+28+56 = 162 的团体分获胜。由于 max 与 ∑ 不可交换（先 max 后 ∑ 会虚增成 168 ≠ 162），"先取联合 MAP 再读 x 分量"是错误流程。结论：决策对象是谁，就把谁留到最后取 max，其余变量先求和——本例医生应报告轻。
