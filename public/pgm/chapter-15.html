15.1为什么不能把轨迹展开成一个大贝叶斯网络

第 6 章引入了动态贝叶斯网络（Dynamic Bayesian Network, DBN）：用两块模板描述一个时序系统——先验模板（t=0 时刻的分布）和 两时间片贝叶斯网络（Two-slice Temporal Bayesian Network, 2TBN），它描述"从时刻 t 到时刻 t+1 的转移"。最简单的 2TBN 就是隐马尔可夫模型（HMM）：

flowchart LR subgraph T0["先验模板 t0"] X0["X0 隐状态"] end subgraph TT["2TBN 模板 从t到t+1"] Xt["Xt"] --> Xt1["Xt+1"] Xt --> Ot["Ot 观测"] Xt1 --> Ot1["Ot+1"] end classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#c4651f; class Xt,Xt1 hot;
图 15.1 2TBN：只需描述相邻两时间片内的边（状态转移 X→X' 与发射 X→O），整段历史由模板复制生成。参数只有一份，与序列长度无关。

要推理，先把模板按时间复制展开（展开，Unrolling）：X⁰→X¹→X²→…→Xᵀ，每个 Xᵗ 下挂观测 Oᵗ。展开后的确是一个普通贝叶斯网络，理论上第 9/10 章的算法都能跑。那为什么不行？两个硬理由：

  • 内存爆炸：T 步展开后图有 2T 个节点。在线场景（机器人定位、行情监控）T 无限增长，内存必须跟着涨——不可接受。我们想要的算法是空间复杂度与 T 无关的。
  • 浪费结构：展开网的每一片完全相同（参数共享），但通用消去算法看不见这个对称性，会把同样的计算重复 T 遍，且消去顺序稍差就让诱导宽度随 T 增长。利用马尔可夫结构后，推理可以写成固定大小的递推：每步只做一次"预测+更新"。
💡 马尔可夫假设是全部魔法的来源

2TBN 的语义：给定 Xᵗ，未来（Xᵗ⁺¹ 及以后）与过去（X⁰…Xᵗ⁻¹）独立。所以任何时刻，过去对未来全部的影响都浓缩在"当前状态的后验"这一个对象里。我们只需要维护这一个信念状态，随时间滚动更新——旧时刻可以全部扔掉。这叫 rollup（折叠）：永远只保留"接口变量"Xᵗ。

15.2四个任务，一张地图：滤波、预测、平滑、最可能序列

动态网络上的查询有四种标准口味，区别只在"用哪些观测，问哪个时刻"：

任务数学形式直觉典型算法
滤波（Filtering）P(Xᵗ | O¹…ᵗ)边看边猜现在前向递推 / 卡尔曼滤波
预测（Prediction）P(Xᵗ⁺ᵏ | O¹…ᵗ)用现在推未来滤波 + 转移模型前推 k 步
平滑（Smoothing）P(Xᵗ | O¹…ᵀ)，t < T事后回看，用全部证据修正历史前向-后向算法
最可能序列arg max P(X⁰…ᵀ | O¹…ᵀ)整条轨迹的整体最优解释Viterbi（max-product）
⚠️ 平滑 ≠ 滤波的事后重放，最可能序列 ≠ 逐时刻滤波取 arg max

平滑用了未来证据，答案可以不同于滤波（下面例子里你会亲眼看到数值差异）。最可能序列是联合最优——第 13 章的教训原样适用：逐时刻取平滑边缘的 arg max，拼出来的路径可能根本不是联合最可能路径。

15.3前向递推：滤波的完整手算

马尔可夫性给出的递推只有两步：预测（用转移模型把上一时刻信念前推）+更新（用新观测修正）。定义前向消息 αt(x) = P(Xᵗ=x, O¹…ᵗ)（未归一化的联合），则：

αt+1(x′) = P(Ot+1 | x′) · ∑x P(x′ | x) · αt(x)

例 1：天气-心情 HMM 的两步滤波

隐状态 X ∈ {0, 1}（0=阴郁，1=晴朗的心情），观测 O ∈ {0, 1}（看到的行为信号）。模型参数：

  • 先验：P(X¹=0) = P(X¹=1) = 0.5
  • 转移：心情有惯性，P(X′=X) = 0.7，翻转 = 0.3
  • 发射：信号基本可信，P(O=X) = 0.9，错位 = 0.1

观测序列：O¹=1，O²=1。

t=1（先验 × 第一个观测）：

  • α₁(0) = P(X¹=0)·P(O¹=1|X¹=0) = 0.5 × 0.1 = 0.05
  • α₁(1) = P(X¹=1)·P(O¹=1|X¹=1) = 0.5 × 0.9 = 0.45

归一化得滤波结果 P(X¹=1|O¹) = 0.45/0.50 = 0.9。

t=2（预测 + 更新）：

  • 预测：∑x P(X²=0|X¹=x)·α₁(x) = 0.05×0.7 + 0.45×0.3 = 0.035 + 0.135 = 0.17
  • 更新：α₂(0) = P(O²=1|X²=0) × 0.17 = 0.1 × 0.17 = 0.017
  • 预测：∑x P(X²=1|X¹=x)·α₁(x) = 0.05×0.3 + 0.45×0.7 = 0.015 + 0.315 = 0.33
  • 更新：α₂(1) = 0.9 × 0.33 = 0.297

滤波结果 P(X²=1|O¹,O²) = 0.297/(0.017+0.297) = 0.297/0.314 ≈ 0.946。两个一致的观测把信念从 0.9 推到 0.946。顺手记下：证据概率 P(O¹=1, O²=1) = 0.314——它是所有 α₂ 之和，算似然时白送的。

💡 直觉

前向递推就是"滚动的水位"：每个时刻只有 d 个数（d = 状态数），计算量 O(d²) 每步，与已经流逝的时间无关。rollup 的全部好处在这里兑现。

15.4后向递推与平滑：让未来证据倒流回历史

平滑要用"未来"的证据修正"过去"的估计。定义后向消息 βt(x) = P(Ot+1…T | Xᵗ=x)：假设时刻 t 状态为 x，之后的观测序列有多可能。它从时间终点倒着递推：

βt(x) = ∑x′ P(x′ | x) · P(Ot+1 | x′) · βt+1(x′)

边界：βT(x) = 1（没有未来观测，什么都可能）。前向后向相乘即得平滑：

P(Xᵗ=x | O¹…ᵀ) ∝ αt(x) · βt(x)

例 1 续：手算 t=1 时刻的平滑

边界：β₂(0) = β₂(1) = 1。

β₁（代入转移、发射 O²=1、β₂）：

  • β₁(0) = P(0→0)·P(O²=1|0)·β₂(0) + P(0→1)·P(O²=1|1)·β₂(1) = 0.7×0.1×1 + 0.3×0.9×1 = 0.07 + 0.27 = 0.34
  • β₁(1) = P(1→0)·P(O²=1|0)·β₂(0) + P(1→1)·P(O²=1|1)·β₂(1) = 0.3×0.1×1 + 0.7×0.9×1 = 0.03 + 0.63 = 0.66

读 β₁：若 t=1 心情晴朗（x=1），"未来观测 O²=1"出现的可能性 0.66 远高于阴郁时的 0.34——未来证据在替 t=1 的"晴朗"投票。

合成平滑（t=1）：

  • α₁(0)·β₁(0) = 0.05 × 0.34 = 0.017
  • α₁(1)·β₁(1) = 0.45 × 0.66 = 0.297

归一化：P(X¹=1 | O¹, O²) = 0.297/0.314 ≈ 0.946。对比滤波值 0.9：看完 O²=1 之后回看 t=1，"晴朗"的把握从 0.9 升到 0.946——未来证据确实倒流回来修正了历史。

15.5最可能序列：Viterbi，链上的 Max-Product

语音识别要问的不是"第 37 帧最可能是什么音素"，而是"整条音素序列哪条最可能"。把第 13 章的 Max-Product 搬到链上：定义 δt(x) = 以 Xᵗ=x 结尾、且解释 O¹…ᵗ 的最优路径分数：

δt+1(x′) = P(Ot+1 | x′) · maxx [ P(x′ | x) · δt(x) ]

与前向递推唯一的差别：∑ 换成 max，外加一根回溯指针记赢家。这就是 Viterbi 算法。

例 1 续：手算最可能序列

t=1：δ₁(0) = 0.5×0.1 = 0.05；δ₁(1) = 0.5×0.9 = 0.45。

t=2：

  • δ₂(0) = 0.1 × max(0.05×0.7, 0.45×0.3) = 0.1 × max(0.035, 0.135) = 0.1×0.135 = 0.0135，指针 → X¹=1
  • δ₂(1) = 0.9 × max(0.05×0.3, 0.45×0.7) = 0.9 × max(0.015, 0.315) = 0.9×0.315 = 0.2835，指针 → X¹=1

回溯：终点 arg max = X²=1（0.2835）；指针指回 X¹=1。最可能序列 = (1, 1)，分数 0.2835。

对照验证：枚举全部 4 条路径的联合概率，(0,0)=0.5·0.1·0.7·0.1=0.0035，(0,1)=0.5·0.1·0.3·0.9=0.0135，(1,0)=0.5·0.9·0.3·0.1=0.0135，(1,1)=0.5·0.9·0.7·0.9=0.2835。Viterbi 答案与穷举一致。

⚠️ 与前向递推的数字游戏

注意 δ 和 α 的前半步一样（0.05 / 0.45），差别从第二步开始：前向把两条来路加总（0.17、0.33），Viterbi 只留最强来路（0.135、0.315）。当序列变长、路径分叉变多时，两者答案可以分道扬镳——要边缘用 α，要路径用 δ，别拿错。

15.6超越离散 HMM：卡尔曼、固定滞后与粒子滤波

离散 HMM 的四个任务都已收工。但状态常常是连续的（位置、速度）——这时α/β 递推里的求和变成积分，只有当所有分布保持高斯时才解析可算：线性高斯动态系统（X′ = AX + 噪声，O = CX + 噪声，接 Ch7）上，前向递推的每一步都保持高斯，这就是著名的卡尔曼滤波（Kalman Filter）——预测步推均值与协方差，更新步用卡尔曼增益折中"相信模型"与"相信观测"。它的后向版叫卡尔曼平滑。

例 2：一次完整的卡尔曼手算——预测变宽、更新收窄

把上面一句话展开成完整数字：在一维线性高斯链上把"预测 → 更新"完整走一遍。设定（沿用本节记号：转移 X′ = X + 噪声、观测 O = X + 噪声）：

  • 上一时刻滤波后验：X⁰ | O⁰ ~ N(μ₀, σ₀²) = N(10, 4)，即 μ₀ = 10、σ₀² = 4
  • 转移：X¹ = X⁰ + W，W ~ N(0, 1)（过程噪声方差 Q = 1）
  • 观测：O¹ = X¹ + V，V ~ N(0, 4)（观测噪声方差 R = 4），实际观测到 o¹ = 12

预测步：把上一时刻的信念沿转移模型前推。均值不变，方差叠加过程噪声：

μ₁⁻ = μ₀ = 10，  σ₁⁻² = σ₀² + Q = 4 + 1 = 5

方差从 4 涨到 5——不看新数据，只会更不确定。这就是预测的"变宽"：过程噪声每前推一步，就往信念里掺进一份新的不确定。

更新步：新观测 o¹ = 12 到达，先算卡尔曼增益（Kalman Gain）——它分配"相信预测"与"相信观测"的话语权：

K = σ₁⁻²σ₁⁻² + R = 55 + 4 = 59 ≈ 0.556
μ₁ = μ₁⁻ + K · (o¹ − μ₁⁻) = 10 + 59 × 2 = 1009 ≈ 11.11
σ₁² = (1 − K) · σ₁⁻² = 49 × 5 = 209 ≈ 2.22（等价写法 σ₁⁻² · Rσ₁⁻² + R = 209）

后验均值落在 10 与 12 之间，但明显偏向 12——这就是更新的"收窄"加"纠偏"。为什么偏观测一侧？看下面的秤。

步骤公式本例数字直觉
预测均值μ₁⁻ = μ₀10随机游走不改变中心位置
预测方差σ₁⁻² = σ₀² + Q4 + 1 = 5（变宽）不看新数据只会更不确定
卡尔曼增益K = σ₁⁻² / (σ₁⁻² + R)5/9 ≈ 0.556观测与预测的话语权分配
更新均值μ₁ = μ₁⁻ + K·(o¹ − μ₁⁻)10 + (5/9)×2 ≈ 11.11按精度折中，略偏观测
更新方差σ₁² = (1 − K)·σ₁⁻²20/9 ≈ 2.22（收窄）每条新观测都在压缩不确定性
💡 直觉：两台秤的读数怎么合并

同一物体用两台秤各称一次：甲秤（模型预测）报 10，乙秤（传感器）报 12。哪台秤更准就多信哪台——甲秤标准差 √5 ≈ 2.24，乙秤标准差 √4 = 2，乙更准。按精度（方差的倒数）加权：预测与观测的精度之比 (1/5):(1/4) = 4:5，于是合并读数 = (4×10 + 5×12)/9 = 100/9 ≈ 11.11，观测拿到的权重 5/9 正是卡尔曼增益 K。卡尔曼更新并不神秘，就是高斯世界里按精度加权的平均。

⚠️ 后验均值 ≠ 简单平均

看到预测 10、观测 12，第一反应是取平均 (10+12)/2 = 11——错。简单平均隐含"两者同样可信"，但本例观测精度更高（R = 4 < σ₁⁻² = 5），正确答案 100/9 ≈ 11.11 偏向观测一侧。只有当 σ₁⁻² = R 时，简单平均才恰好等于卡尔曼更新。

三个收尾要点：

  • 每条新观测都在压缩不确定性：更新后方差 20/9 ≈ 2.22，既小于预测方差 5，也小于上一时刻的 4。预测把钟形曲线拉宽，更新把它重新捏窄——滤波就是这对动作的无限循环。
  • 增益 K = σ₁⁻²/(σ₁⁻² + R) 的直觉：观测噪声 R 越大 K 越小（少信观测，极端 R→∞ 时 K→0，观测白看）；预测越不准（σ₁⁻² 越大）K 越大（多信观测，极端 σ₁⁻²→∞ 时 K→1，后验均值直接照抄观测）。
  • 与第 9 章的呼应：预测 + 更新合起来，正是变量消去在高斯链上的解析形态——求和变积分、因子全是高斯、每步消去封闭，于是整条前向递推坍缩成对 (μ, σ²) 的两个更新式。15.3 节离散链上的 α 消息，在这里的化身就是这一对数字。

还有两种工程上绕不开的变体：

  • 固定滞后平滑（Fixed-lag Smoothing）：完整平滑要存全部 α/β，在线场景太贵。折中：只回看的 L 步，估计 P(Xt−L | O¹…ᵗ)——代价常数化（随 L 指数、与 t 无关），精度通常已够用。
  • 粒子滤波（接 Ch12）：非线性、非高斯（或多峰，如第 14 章的切换系统）时，用一堆带权粒子表示信念状态，传播-赋权-重采样。它是机器人定位（SLAM 前端）的事实标准。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
2TBN（Two-slice Temporal Bayesian Network）
点击翻面 →
定义描述相邻两时间片内依赖关系的模板，含片内边与跨片转移边。
解决问题让任意长序列的参数只有一份：模型大小与序列长度解耦。
直觉印章：一张模子沿时间轴无限盖下去。
误区以为 2TBN 本身就是完整模型——还要配先验模板（t=0 分布）。
何时用一切时序建模；HMM、卡尔曼滤波器都是它的特例。
概念卡 2
滤波与前向消息（Filtering / α）
点击翻面 →
定义P(Xᵗ|O¹…ᵗ)；递推 αt+1(x′)=P(Ot+1|x′)·∑xP(x′|x)αt(x)。
解决问题在线估计当前状态：边看观测边更新，内存与时长无关。
直觉滚动水位：预测把水位前推并摊平，观测把水位重新捏尖。
误区忘归一化时把 α 当概率——α 是未归一化的联合，和为证据似然。
何时用一切在线任务：定位、跟踪、监控。
概念卡 3
平滑与前向-后向算法（Smoothing / Forward-Backward）
点击翻面 →
定义P(Xᵗ|O¹…ᵀ) ∝ αt·βt；β 从终点倒推未来证据的可能性。
解决问题事后重建历史：让未来观测倒流回去修正过去估计。
直觉两支队伍从两端夹攻同一时刻，会师处的乘积就是真相。
误区以为平滑只是滤波的重放——它用了更多证据，答案可以不同。
何时用离线分析；Ch19 EM 学 HMM 参数时的 E 步。
概念卡 4
Viterbi 算法
点击翻面 →
定义链上的 Max-Product：δt+1(x′)=P(O|x′)·maxx[P(x′|x)δt(x)] + 回溯指针。
解决问题求联合最可能的整条状态序列，而非逐时刻最可能。
直觉淘汰赛接力：每个状态只记住"从我这里出发的最强前半程"。
误区拿逐时刻平滑 arg max 冒充最可能序列——两者一般不同。
何时用语音识别解码、基因序列标注、通信译码。
概念卡 5
卡尔曼滤波（Kalman Filter）
点击翻面 →
定义线性高斯动态系统上的解析前向递推：预测步前推 (μ, Σ)，更新步用卡尔曼增益融合观测。
解决问题连续状态跟踪的闭式解：信念始终是高斯，只需维护均值与协方差。
直觉两票加权：模型预测一票、传感器一票，谁噪声小听谁的。
误区以为它普适——非线性/非高斯立即失效，只能 EKF/UKF/粒子滤波近似。
何时用导航、航天、GPS 融合；工程界最成功的 PGM 算法。
概念卡 6
Rollup 与固定滞后平滑（Fixed-lag Smoothing）
点击翻面 →
定义Rollup：只维护接口变量 Xᵗ 的信念并滚动更新；固定滞后：用未来 L 步证据平滑 Xt−L。
解决问题让在线推理的空间/时间成本与序列总长度无关。
直觉只带今天的行囊上路，历史压缩进一张卡片。
误区以为 L 越大越划算——成本随 L 指数增长，够用即可。
何时用实时监控、流式语音、一切"不能等整段录完再算"的场景。

📝分层习题

L1 概念辨析判断对错：把 DBN 沿时间展开成大 BN 后用变量消去做推理，结果与前向-后向算法一定不同，因为后者用了近似。说明理由。
提示

前向-后向是精确算法还是近似算法？两者差在结果还是效率？

完整解答
错。前向-后向是精确算法，结果与展开网上的精确消去完全一致。差别在效率与内存：展开法内存随 T 增长且浪费参数共享结构；前向-后向利用马尔可夫性把计算写成固定大小的递推，每步 O(d²)，空间与 T 无关。
L1 概念辨析判断对错：最可能序列一定包含每个时刻滤波分布的 arg max 状态。
提示

这是第 13 章哪个事实的时序版？

完整解答
错。最可能序列优化的是整条路径的联合概率（Viterbi/max-product）；逐时刻 arg max 优化的是每个时刻的边缘（前向/平滑）。MAP ≠ 边缘 arg max——转移约束可能迫使联合最优路径在某些时刻经过"边缘上不占优"的状态。
L2 手算推导沿用例 1 的 HMM（先验各 0.5，转移 留0.7/翻0.3，发射 对0.9/错0.1），观测改为 O¹=1，O²=0。手算：(1) α₂ 与滤波 P(X²=1|O¹,O²)；(2) Viterbi 最可能序列与分数。
提示

t=1 的 α 不变（0.05/0.45）；t=2 的发射换成 P(O=0|X)：X=0 时 0.9，X=1 时 0.1。预测部分和例 1 相同（0.17 / 0.33）。

完整解答

α₁(0)=0.05，α₁(1)=0.45（同例 1）。预测：X²=0 得 0.17，X²=1 得 0.33。

(1) 更新：α₂(0) = 0.9×0.17 = 0.153；α₂(1) = 0.1×0.33 = 0.033。滤波 P(X²=1|O) = 0.033/0.186 ≈ 0.177——矛盾观测把信念拉回阴郁。

(2) Viterbi：δ₂(0) = 0.9×max(0.05×0.7, 0.45×0.3) = 0.9×0.135 = 0.1215（指针→X¹=1）；δ₂(1) = 0.1×max(0.05×0.3, 0.45×0.7) = 0.1×0.315 = 0.0315（指针→X¹=1）。终点 arg max = X²=0，回溯得最可能序列 (1, 0)，分数 0.1215。注意：最优路径经过 X¹=1——尽管只看 t=2 时 X²=0 占优，路径整体仍认为"先是晴、后转阴"最合理。

L2 手算推导在例 1 原始观测（O¹=1, O²=1）下，手算 t=2 时刻的"一步预测" P(X³=1 | O¹,O²)（不看新观测，只把滤波信念前推一步）。
提示

预测 = 转移矩阵作用于滤波后验，不需要新发射概率。

完整解答

滤波后验：P(X²=0|O)=0.017/0.314≈0.0541，P(X²=1|O)≈0.9459。

P(X³=1|O¹,O²) = 0.0541×0.3 + 0.9459×0.7 = 0.01623 + 0.66213 ≈ 0.678。

没有新观测时，信念向稳态（0.5 附近）回退——转移噪声在"冲淡"旧证据。这正是预测不确定度随步数增长的机制。

L3 建模应用网络丢包诊断：链路真实状态 G ∈ {好, 差} 每 10ms 可能切换（惯性 0.9），监控系统收到粗粒度信号 O ∈ {正常, 告警}（好链路 5% 误报，差链路 80% 告警）。要求在线给出"当前链路为差"的概率。请：(1) 写出 2TBN 的全部参数；(2) 说明该用滤波/平滑/Viterbi 中哪个任务及理由；(3) 说明该方案的内存为何与监控时长无关。
提示

先验自定一个合理值；任务是"边看边判断现在"；回忆 rollup。

完整解答

(1) 先验模板：P(G⁰=好)=0.95（链路多数时候正常）。2TBN：转移 P(G′=G)=0.9、切换 0.1；发射 P(告警|好)=0.05、P(告警|差)=0.8。

(2) 用滤波：任务是在线估计"当前"状态，只用历史观测，P(Gᵗ|O¹…ᵗ) 正是滤波分布。平滑需要未来证据（在线拿不到），Viterbi 回答的是整段历史路径（不是当前判断）。

(3) 前向递推每步只维护 d=2 个 α 值（滚动水位），旧时刻全部丢弃（rollup），故内存 O(d) 与监控时长 T 无关；每步计算 O(d²)=4 次乘加，10ms 预算绰绰有余。
