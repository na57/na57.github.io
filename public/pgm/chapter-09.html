9.1推理任务是什么，暴力法为什么不可行

前 8 章解决的是"表示"：把一个联合分布紧凑地写成一堆因子的乘积——贝叶斯网络是 P = ∏i P(Xi|Pa(Xi))，马尔可夫网络是 P = (1/Z)·∏C ψC。但表示本身不是目的。模型建好之后，我们真正想做的是回答查询：这个学生拿到好推荐信的概率多大？看到 SAT 高分之后呢？这就是推理（Inference）。

定义：推理任务的输入是一个模型（图 + 参数）、一组查询变量（Query Variables）Y，以及一组证据（Evidence）E = e（观测到的变量取值）。要算的是条件概率 P(Y | E = e)；当没有证据时，就是边缘概率（Marginal Probability）P(Y)。另一个重要查询——最可能赋值 MAP（Maximum A Posteriori）——留到第 13 章。

最直接的算法是暴力枚举：把联合分布的全部行里"证据匹配"的行挑出来，按查询变量的取值分组求和：

P(Y | E = e) = ∑W P(Y, E = e, W)∑Y ∑W P(Y, E = e, W)

其中 W 是除 Y、E 之外的其余变量。问题在于：联合分布有 ∏i |Val(Xi)| 行。n 个二值变量就是 2n 行——n = 30 时约 109，n = 100 时约 1030，而一张 CT 图像动辄上千个像素。枚举全部赋值，这条路在表示省下的空间里又全部还了回去。

💡 关键一跃

暴力法浪费了表示阶段辛苦拆出来的结构：联合分布明明是一堆小因子的乘积，枚举却先把它乘回大表再求和。更聪明的做法是永远不要造出那张完整大表——在"乘"与"加"之间精打细算。这就是变量消去。

⚠️ 常见误区

"图模型把联合分布分解了，所以推理就免费了"——错。因子分解省的是存储（参数量从指数降到多项式），不是计算：把边缘概率从因子乘积里算出来，仍然可能指数级贵。本章的全部内容，就是在回答"贵在哪、怎么省、省到什么程度是极限"。

9.2两个运算与一条代数变形：把求和号往内推

上一节立下了靶子：不造大表。这一节给出武器。变量消去（Variable Elimination, VE）只反复使用两个因子运算：

  • 因子乘积（Factor Product）：φ₁(X, Y) ⊗ φ₂(Y, Z) 得到因子 ψ(X, Y, Z)，其中 ψ(x, y, z) = φ₁(x, y)·φ₂(y, z)。变量的公共部分对齐（同取值的行才相乘），结果的变量集是两个因子作用域的并集。
  • 边缘化（Marginalization，对某变量求和消去）：τ(Y) = ∑X ψ(X, Y)，把 X 的每个取值对应的行加起来，得到一个不再含 X 的新因子。

边缘化的行数会"缩"：因子从 |Val(X)|·|Val(Y)| 行变成 |Val(Y)| 行。每消去一个变量，因子就丢掉一维。

核心代数变形：求和与乘积的分配

整条链 A → B → C → D 上算 P(D)。暴力法是 ∑A,B,C P(A)·P(B|A)·P(C|B)·P(D|C)，共 2³ = 8 个乘积项相加。但注意：不是每个因子都含每个变量。利用分配律，把不含被求和变量的因子提到求和号外面：

P(D) = ∑A P(A) ∑B P(B|A) · ∑C P(C|B) P(D|C)

最内层那个橙色求和只碰 P(C|B) 和 P(D|C) 两个因子，产出中间因子 τ₁(B, D)；然后是 τ₂(A, D) = ∑B P(B|A)·τ₁(B, D)；最后 P(D) = ∑A P(A)·τ₂(A, D)。每一步只处理一张小表，完整大表从头到尾没有出现过。

✅ 求和-乘积规则（Sum-Product）

对不涉及 X 的因子，求和号可以穿过它向内推：∑X(φ₁·φ₂) = φ₁·∑Xφ₂（当 X 不出现在 φ₁ 中）。VE 的全部节省都来自这一步：先消元、后相乘，乘的永远是小表。

💡 VE 就是动态规划

τ₁、τ₂ 是被存储复用的子问题答案：τ₁(b, d) 在每个 a 的求和里被用了一次（这里是 2 次），避免了对每个 (a, d) 重算 C 的求和。存中间结果、不重复计算——动态规划的标准味道。同时注意：τ₁(b,·) 的两个值加起来是 1，它恰好是 P(d|b)——CPD 沿链消元时保持归一，这个性质 9.4 节讲证据时会再用到。

⚠️ L 去哪了？

第 1 步消 L 时它带着自己的 CPD 一起归一化消失了，最后留下的是 τ₄(D) = P(D) 和一个隐藏的结果：所有因子乘积的总和 = 1。这正确地告诉我们 P(l¹) + P(l⁰) = 1，却没给出各自的值——顺序"先消查询变量"对 P(L) 这个查询来说是错误的使用方式（这个顺序对"算配分函数 Z"反而是对的，见 9.4）。要求 P(L)，应该最后消 L，或者干脆查 P(D)——本顺序算出的正是 P(D)。下面我们换一个顺序重算，真正拿到 P(L)，顺便看看代价差多少。

9.4例 3：换个顺序重算，代价从哪来

同一个网络、同一个查询 P(L)，换消元顺序二：G → S → I → D（先消 V 结构的"汇"G，查询变量 L 留到最后）。这个顺序看起来"差不多"，算完你会发现代价差了一个量级。

第 1 步，消 G。G 出现在 P(G|D, I) 与 P(L|G) 中——等等，例子里 L 依赖 S 不依赖 G，P(L|S) 里没有 G。所以 G 只出现在 P(G|D,I) 中。τ₁(d, i) = ∑g P(g|d, i) = 1，又凭空消失了？

⚠️ 停一下——这是对的使用方式吗？

是的，而且这暴露了一个重要现象：如果查询是 P(L)，那么 G 和 D 对答案毫无影响。它们是"L 的上游之外的分支"（L ← S ← I ← G ← D 里 G、D 挂在链的侧枝上），先验下它们的信息传不到 L。任何正确实现都会把 P(G|D,I)、P(D) 归一化消掉，问题塌缩成 I → S → L 的三变量链。为了真正看到"顺序影响代价"的戏剧性场面，我们需要一个让全部变量都纠缠进来的查询——证据查询。这正是 9.5 节的内容，这里先把例 3 换成那个版本。

检查：0.404 + 0.596 = 1 ✓。这就是未归一化的 P(L, d¹)。归一化（它和 = 1，所以这里不变）：P(l¹|d¹) = 0.404，P(l⁰|d¹) = 0.596。作为对照，无证据时 P(l¹) = 0.26×0.7 + ……用第 2 步的 τ₂：P(l¹) = 0.404？不对——那是同一个数。想想为什么：先验下 D 与 L 本来独立吗？D → G ← I → S → L，D 到 L 的路径 D→G←I 是 V 结构，被阻断，所以 D ⊥ L 无条件成立，P(L|d¹) = P(L)。数值自洽 ✓。若观测了 G（共同效应），D 与 L 就相关了——这是 d-分离的老知识在新算法里的回声。

顺序真正的代价差异：一个会"长大"的中间因子

上面的例子里因子都很小，戏剧冲突不足。现在看查询 P(D) 用坏顺序 L → S → I → G…… 9.3 节已经演示过它很顺（中间因子最大 3 变量、且多步凭空消失）。真正的反面教材是：先消 D、I 之外的中间节点，把 G 留到和它父母同场的时候再处理邻居。考虑顺序 S → L → I → G（查询 P(D)）：

  • 消 S：τ₁(i) = ∑s P(s|i) = 1，消失（L 的因子 P(L|S) 此时还没轮到——注意 S 出现在 P(S|I) 和 P(L|S) 两个因子里！τ₁(i, l) = ∑s P(s|i)P(l|s)，不消失，就是上面算过的 0.26/0.74/0.74/0.26 那张表）。
  • 消 L：τ₂(i) = ∑l τ₁(i, l) = 1，消失。
  • 消 I：I 在 P(I)、P(G|D,I) 里，τ₃(d, g) 同 9.3 节第 3 步（0.48 / 0.52 / 0.185 / 0.815）。
  • 消 G：τ₄(d) = P(d)·∑gτ₃(d,g) = P(D)。✓

对比两种顺序的中间因子"最大作用域"：所有正确顺序里，最大的中间因子都是消 I（或 G）时那张 {D, G, I} 三变量的表——它对应 V 结构的"父母 + 孩子"三人组，躲不掉。而如果你在 G 还没消时先消 D（顺序 D → …），D 出现在 P(D) 和 P(G|D,I)，乘出 ψ(D, G, I) 再消 D 得到 τ(G, I)——同样是三变量表。看起来差不多？差别在网络变大时：三变量表在 4 节点网络里无伤大雅，但如果 G 有 k 个父母，那张表是 2k+1 行。顺序决定的是"最大那张中间表有多大"。

对照手算：四元环加一条侧枝——坏顺序贵出一个数量级

学生网络是条"链加侧枝"，因子怎么消都大不了。要看清顺序的杀伤力，得换一个带环网络：四元环 A—B—C—D—A（四条边连成圈），加一条侧枝 E—A。五个因子 φ₁(A,B)、φ₂(B,C)、φ₃(C,D)、φ₄(D,A)、φ₅(A,E)，查询 P(E)，E 留到最后。环上没有"凭空归一消失"的死角，五个变量全部纠缠在一起。代价只取决于因子作用域，与具体数值无关；设每个变量取 d 个值，最后代入 d = 10 看量级。

顺序一（好）：C → B → D → A——先消环上离 E 最远的普通节点，枢纽 A 留到倒数第二步。

  • 消 C：φ₂·φ₃ 乘成 ψ(B,C,D)，求和得 τ₁(B,D)。最大表 3 变量。
  • 消 B：φ₁·τ₁ 乘成 ψ(A,B,D)，求和得 τ₂(A,D)。最大表 3 变量。
  • 消 D：φ₄·τ₂ 乘成 ψ(A,D)（2 变量），得 τ₃(A)。
  • 消 A：φ₅·τ₃（2 变量），得 τ₄(E) = P̃(E)。

最大中间因子 3 变量（d³ 行）；乘法总次数 ≈ 2d³ + 2d²（两张 d³ 乘积表 + 两张 d² 乘积表）。

顺序二（坏）：A → C → D → B——一上来就消枢纽 A。

  • 消 A：A 连着 B、D、E 三个邻居，φ₁·φ₄·φ₅ 乘成 ψ(A,B,D,E)——4 变量大表，d⁴ 行，求和得 τ₁(B,D,E)。环被"焊"死：B、D、E 两两相连。
  • 消 C：φ₂·φ₃ 乘成 ψ(B,C,D)（3 变量），得 τ₂(B,D)。
  • 消 D：τ₁·τ₂ 乘成 ψ(B,D,E)（3 变量），得 τ₃(B,E)。
  • 消 B：τ₃ 直接求和得 τ₄(E)。

最大中间因子 4 变量（d⁴ 行）；乘法总次数 ≈ 2d⁴ + 2d³。

顺序中间因子（逐步乘积表作用域）最大因子维度乘法次数（d = 10）
C → B → D → A（好）{B,C,D} → {A,B,D} → {A,D} → {A,E}3 变量 = 10³ = 1,000 行≈ 2×10³ + 2×10² = 2,200
A → C → D → B（坏）{A,B,D,E} → {B,C,D} → {B,D,E} → {B,E}4 变量 = 10⁴ = 10,000 行≈ 2×10⁴ + 2×10³ = 22,000

解读：两种顺序算出的是同一个 P(E)（分配律保证结果与顺序无关），但坏顺序第一步就把 A 的三个邻居焊进同一张表，最大因子多出整整一个变量——代价乘上 d。二值变量时只差 2 倍（48 vs 24，体感不强）；d = 10 时就是整整一个数量级：22,000 次 vs 2,200 次乘法。若枢纽有 k 个邻居，差距是 dk−2 倍——网络越大、枢纽越肥，坏顺序死得越快。这就是"顺序决定代价"的全部含义，也正是下一节诱导图要度量的东西：好顺序留下的最大表 3 变量，对应这个网络的树宽 w = 2。

诱导图：把"顺序 → 代价"翻译成图语言

每次消去变量 X 时，我们把所有含 X 的因子乘成一张大表——这张表的变量集是"X 及其当前邻居"。等价地图操作：在图上把 X 的所有邻居两两连边（填充边，fill edge），然后删掉 X。把整个消元过程新增的所有边叠加到原图（道德化图）上，得到的就是诱导图（Induced Graph）。诱导图的最大团大小减 1 叫该顺序的诱导宽度（Induced Width）w；VE 的总复杂度是 O(n · dw+1)。

✅ 因果链总结（本章最重要的一张图）

消元顺序 → 中间因子的最大作用域 → 诱导图的最大团 → 诱导宽度 w → 复杂度 O(n·dw+1)；所有顺序取最小，复杂度指数于树宽。树的树宽 = 1（推理线性代价！）；网格图树宽 ≈ min(m, n)（大图精确推理不可行，交给 Ch11 近似推理）。注意：找最优顺序本身是 NP-hard，实践用启发式——最小度（Min-Degree，每次消当前度数最小的节点）与最小填充（Min-Fill，每次消"新增填充边最少"的节点）。

9.5证据先约简，以及顺手算出配分函数 Z

9.4 节已经提前用了证据处理手法，这一节把它正式化。观测 E = e 之后，不需要任何新运算：

✅ 因子约简（Factor Reduction）

把每个含 E 的因子 φ(…, E, …) 替换为 φ(…, E = e, …)——只保留 E = e 的那些行。约简后的因子乘积 = 未归一化联合 P(·, e)。对它做 VE，消元到最后得到的常数就是 P(e)；要 P(Y|e) 就让 Y 留到最后，得到 P(Y, e) 后归一化：除以 P(e) = ∑Y P(Y, e)。

例 4：证据约简不一定是概率表——P(G | D = d¹)

查询 P(G|d¹)。约简因子清单：P(G|I, d¹)（9.4 节那张表）、P(I)、P(S|I)、P(L|S)。消元顺序 L → S → I：L、S 依次凭空归一消失（回忆 9.3-1），剩 P(I) 与 P(G|I,d¹)。消 I：τ(g) = ∑i P(i)·P(g|i,d¹)：

  • τ(g¹) = 0.7×0.05 + 0.3×0.5 = 0.035 + 0.15 = 0.185
  • τ(g⁰) = 0.7×0.95 + 0.3×0.5 = 0.665 + 0.15 = 0.815

和 = 1，归一化不变：P(g¹|d¹) = 0.185。（对照 9.3 节 τ₃： τ₃(d¹, g¹)/P(d¹) = 0.185/0.4 = 0.4625？不对——τ₃(d,·) 已经是条件分布 P(G|d)，因为 τ₃(d,g) = ∑i P(i)P(g|d,i) 里 P(i) 和为 1。所以 P(g¹|d¹) 直接就是 τ₃(d¹, g¹) = 0.185 ✓，两处自洽。）

例 5：与第 4 章的桥——VE 算出配分函数 Z

回忆第 4 章：马尔可夫网络 P = (1/Z)·∏ψC，Z 是全局归一化常数，"本章埋下的账"。现在可以还债了：Z = ∑所有变量 ∏ψC 正是一个"没有查询变量、没有证据"的 VE——把所有变量按任意顺序消光，最后剩下的常数就是 Z。链 A—B—C（同 10 / 异 1）上验证：消 C 得 τ₁(b) = 10 + 1 = 11；消 B 得 τ₂(a) = 11×(10+1) = 121；消 A 得 Z = 121 + 121 = 242，与第 4 章枚举 8 行的结果分毫不差，但一次完整大表都没造。

💡 关键一跃

证据不是推理的"附加功能"，而是让推理变便宜的机制：约简把证据变量从因子里删掉，因子更小、诱导图更稀疏。MN 里的 Z、BN 里的 P(e)，都是"全部消完剩下的常数"——归一化常数从来不是外加的，它是推理的副产品。

9.6本章买下的账单：多查询时的重复计算

到此变量消去看起来完美：多项式次的单查询（低树宽时）。但回到真实场景——医生要分别查询"发烧的概率""肺炎的概率""某种化验结果的概率"；系统要对每一个变量都算边缘。每跑一次 VE，你都从头来一遍：同样的中间因子（比如 9.3 节的 τ₃(D,G)）在不同查询里被反复重算。

⚠️ 重复计算就是下一章的靶子

n 个查询 × 每个查询 O(n·dw+1) = O(n²·dw+1)。但换个角度看：不同查询的消元过程共享大量中间因子——如果有一张"工作台"能把它们缓存起来、让每个因子只算一次，多查询的总代价就能压回单查询的量级。这张工作台就是第 10 章的团树（Clique Tree）：节点 = 诱导图的团，边上跑消息，一次预处理、所有查询各取所需。

另一个方向：树宽大的图（网格、稠密网络）连单查询都贵到不可行。那是第 11 章（近似推理：采样、变分）的领土。而本章的"求和"如果换成"取最大"，就是第 13 章的 MAP 推理——算法骨架几乎不变。VE 是推理四章的母算法：看懂它，后面三章都是它的变奏。

概念卡 1
推理任务（Inference Task）
点击翻面 →
定义给定模型与证据 E = e，计算查询变量的后验 P(Y | E = e)。
解决问题模型建好后要回答查询：边缘、条件概率、MAP（Ch13）。

何时用推理四章（Ch9–13）每章都在解这个任务的不同变体。
概念卡 2
因子乘积与边缘化（Factor Product / Marginalization）
点击翻面 →
定义乘积：公共变量对齐相乘，作用域取并；边缘化：对某变量求和，把它从作用域删掉。
解决问题VE 仅有的两个操作，一切消元都是它们的组合。
直觉乘积 = 两表按公共列 join；边缘化 = 分组求和后删列。
误区以为乘积后行数不变——它膨胀为作用域并集的联合行数。
何时用Ch9 每步消元；Ch10 团树消息传递的底层运算。
概念卡 3
变量消去（Variable Elimination）
点击翻面 →
定义按某个顺序，对每个非查询变量：收集含它的因子→相乘→对它求和，存下中间因子。
解决问题避免枚举完整联合表，把全局求和拆成局部求和序列。
直觉动态规划：子问题的答案（τ 表）存下来复用。
误区以为结果与顺序无关所以代价也无关——结果相同，代价天差地别。
何时用精确推理的母算法；Ch10 团树是它的多查询缓存版。
概念卡 4
消元顺序（Elimination Ordering）
点击翻面 →
定义消去非查询变量的先后次序；查询变量留到最后。
解决问题顺序决定中间因子的最大作用域，从而决定总代价。
直觉拆快递：先拆哪箱决定桌上最多同时摊多少东西。
误区以为存在通用规则手算最优——找最优顺序是 NP-hard，实践用最小度/最小填充启发式。
何时用一切 VE/团树实现的预处理步骤。
概念卡 5
诱导图（Induced Graph）
点击翻面 →
定义消 X 时把 X 的当前邻居两两连边再删 X；全部填充边叠加原图所得。
解决问题把"顺序→代价"翻译成图语言：最大中间因子 = 诱导图最大团。
直觉送走一个人前，让它的所有朋友互相加微信——朋友团越来越大。
误区以为诱导图由原图唯一决定——它由顺序决定，不同顺序不同图。
何时用复杂度分析；Ch10 团树的节点就是诱导图的团。
概念卡 6
树宽（Treewidth）
点击翻面 →
定义所有消元顺序的诱导宽度的最小值，图的固有属性。
解决问题划出精确推理的可行边界：复杂度 O(n·dw+1)，指数于树宽。
直觉图的"循环程度"：树 w=1，环越多越密 w 越大。
误区以为树宽容易算——计算树宽本身 NP-hard。
何时用判断"该用精确（Ch9/10）还是近似（Ch11/12）"的分水岭。
概念卡 7
因子约简（Factor Reduction）
点击翻面 →
定义观测 E = e 后，含 E 的因子只保留 E = e 的行，E 从作用域删除。
解决问题把"条件概率查询"变成"无证据的消元 + 最后归一化"。
直觉答案已知的填空题：把已知项划掉，表立刻变小。
误区以为约简因子仍是概率表——一般是未归一化的切片（CPD 纵切是例外）。

📝分层习题

L1 概念辨析判断对错：变量消去的结果取决于消元顺序，所以必须选对顺序才能得到正确答案。说明理由。
提示

求和与乘积满足交换律、结合律、分配律——最终答案是什么的求和？顺序影响的是答案还是别的东西？

完整解答
错（前半句本身就是错的）。任何顺序算出的都是同一个边缘——分配律保证代数等价，9.3 与 9.4 两节用不同顺序算出同一个数就是证据。顺序影响的是代价：中间因子的最大维度与总运算量，可差出指数级。正确说法：结果与顺序无关，复杂度与顺序生死攸关。
L1 概念辨析判断对错：VE 的复杂度指数于网络中的变量个数 n。如果不准确，给出准确的刻画。
提示

链式网络有 n 个变量，它的 VE 代价是指数于 n 吗？复杂度公式里指数位置站的是谁？

完整解答
不准确。复杂度是 O(n·dw+1)：指数位置是诱导宽度 w（最终是树宽），不是 n。链式网络 n 再大，w = 1，代价随 n 线性增长——9.2 节的链就是例子。只有当结构迫使中间因子变大（稠密环、网格）时代价才爆炸。所以"变量多"不可怕，"缠得紧"才可怕。
L2 手算推导二值链 X → Y → Z，参数：P(x⁰) = 0.5；P(y⁰|x⁰) = 0.6，P(y⁰|x¹) = 0.2；P(z⁰|y⁰) = 0.9，P(z⁰|y¹) = 0.3。用 VE（顺序 X → Y）手算 P(Z)，列出每张中间因子的完整数值表。
提示

先消 X：τ₁(y) = ∑x P(x)P(y|x)；再消 Y：P(z) = ∑y τ₁(y)P(z|y)。最后检查两行之和。

完整解答

第 1 步，消 X：τ₁(y⁰) = 0.5×0.6 + 0.5×0.2 = 0.3 + 0.1 = 0.4；τ₁(y¹) = 0.5×0.4 + 0.5×0.8 = 0.2 + 0.4 = 0.6。（和为 1 ✓，τ₁ 即 P(Y)。）

第 2 步，消 Y：P(z⁰) = 0.4×0.9 + 0.6×0.3 = 0.36 + 0.18 = 0.54；P(z¹) = 0.4×0.1 + 0.6×0.7 = 0.04 + 0.42 = 0.46。

检查：0.54 + 0.46 = 1 ✓。中间因子最大 1 个变量——链的树宽 1，代价线性。

L2 手算推导在 9.3 节学生网络（D→G←I→S→L）上，设证据 S = s¹，用 VE 手算 P(l¹ | s¹)。（顺序随意，注意先约简。）
提示

约简 S = s¹：P(S|I) 变成 φ(i)（取 s¹ 那一列：i⁰→0.2，i¹→0.8），P(L|S) 变成 φ(l)（取 s¹ 行：l¹→0.9，l⁰→0.1）。D、G 分支与 L 先验无关，会归一化消失。

完整解答

约简后因子：φ₁(i) = P(s¹|i)（0.2 / 0.8）、φ₂(l) = P(l|s¹)（0.9 / 0.1）、P(I)、P(D)、P(G|D,I)。

消 L：L 只在 φ₂ 里，但 φ₂ 不归一（0.9 + 0.1 = 1，恰好归一——它是 CPD 的纵切）……它对 I 无影响，直接作为关于 L 的因子保留到最后。消 D、G：分别归一化消失。

消 I：τ(l) = φ₂(l)·∑i P(i)·φ₁(i)。先算括号：0.7×0.2 + 0.3×0.8 = 0.14 + 0.24 = 0.38（这就是 P(s¹)）。于是未归一化：l¹: 0.9×0.38 = 0.342；l⁰: 0.1×0.38 = 0.038。

归一化（除以 P(s¹) = 0.38，即两数之和 0.38）：P(l¹|s¹) = 0.342/0.38 = 0.9。合理：L 只依赖 S，给定 S = s¹ 后其他证据无关，P(l¹|s¹) 就是 CPD 表里的 0.9 本身 ✓。

L3 建模应用某医院用贝叶斯网络做辅助诊断：疾病 D（3 种）影响症状 S₁…S₂₀（各二值），共 21 个变量、结构是"D 为唯一父节点"的朴素贝叶斯（多树）。医生抱怨系统慢。①写出该网的树宽并说明理由；②说明为什么对任何单一症状的查询，VE 都很快；③如果医生想一次性拿到全部 20 个症状的边缘概率，指出直接重复跑 VE 的浪费，并说出第 10 章将如何解决。
提示

道德化这张图——V 结构存在吗？消 D 时中间因子多大？消症状时呢？回忆团树的"缓存"思想。

完整解答

①树宽 = 1。每个症状只有一个父节点，无 V 结构，道德化不加边；图是星形（一种树）。先消全部症状（每个只在自己的 CPD 里，乘 D 的先验后逐个处理），最大中间因子只含 {D, Sᵢ} 两个变量。

②复杂度 O(n·dw+1) = O(21×3²) 量级——秒出。慢的原因不在结构，多半是实现问题（比如没用 VE 而在枚举）。

③20 个查询 × 每次从头消元：消 D 产生的关于各症状的中间因子被算了 20 遍。Ch10 团树把团 {D, Sᵢ} 组织成树，一次双向消息传递后所有团的边缘同时可得，重复计算被缓存消除。

自测 1
n 个二值变量的贝叶斯网络，暴力枚举算一个边缘概率的复杂度量级是？
  • A. O(n)
  • B. O(n²)
  • C. O(2ⁿ)
  • D. O(n!)
选 C。要枚举全部 2ⁿ 个联合赋值求和。A/B 错在把"因子分解省存储"误当成"推理省计算"——暴力法先把因子乘回完整联合表，放弃了全部结构。D 过度估计，阶乘比指数还快，但没有任何步骤需要全排列。
自测 2
"把求和号往内推"之所以省计算，根本原因是：
  • A. 求和比乘法快，所以多做求和少做乘法
  • B. 被求和变量只出现在部分因子里，先求和让表变小再相乘
  • C. 求和号位置不影响结果，所以可以随便推
  • D. 推到最内层后可以直接查表，不用计算
选 B。分配律：∑X(φ₁·φ₂) = φ₁·∑Xφ₂（X 不在 φ₁ 中）——先消元后相乘，乘的永远是小表。A 本末倒置（问题不是运算种类而是表的大小）；C 只说对一半：结果确实不变，但代价剧变，"随便推"会推到天价中间因子；D 无此机制。
自测 3
消去变量 X 时，在图上的等价操作是：
  • A. 直接删掉 X 及其所有边
  • B. 把 X 的边全部反向再删除
  • C. 把 X 的邻居排成一个环再删除 X
  • D. 把 X 的所有当前邻居两两连边（填充），然后删除 X
选 D。含 X 的因子相乘后，X 的邻居出现在同一张中间表里——图上就是邻居两两相连（填充边）。A 错：漏掉填充边就丢了中间因子变大的信息；B 无向图没有方向可言，且反向不是消元语义；C 排成环只连了相邻对，遗漏了其他邻居对。
自测 4
关于树宽，下列说法正确的是：
  • A. 树宽是所有消元顺序的诱导宽度的最小值，是图的固有属性
  • B. 树宽等于图中最大团的大小
  • C. 树宽大的图可以用更聪明的消元顺序把代价降到线性
  • D. 网格图的树宽是 1，因为它很规则
选 A。B 错：原图最大团只是下界，填充边会让诱导图的团更大；树宽要对所有顺序取最小。C 错：树宽正是"最聪明顺序"能达到的极限，再聪明也越不过它（且找最优顺序 NP-hard）。D 错：m×n 网格树宽 ≈ min(m,n)，这正是大规模网格精确推理不可行的原因。
自测 5
观测证据 E = e 后，对含 E 的因子执行的操作是：
  • A. 把 E 的取值全部重新归一化
  • B. 删除所有含 E 的因子
  • C. 只保留 E = e 的行，把 E 从因子作用域中去掉
  • D. 把 E = e 代入后对 E 求和
选 C。因子约简：切片保留匹配证据的行，E 从作用域消失，消元在更小的因子集上进行。A 错：约简因子一般不重新归一（归一化在末尾统一做，常数就是 P(e)）。B 错：删因子等于丢弃证据携带的信息。D 错：证据是"固定取值"，不是"求和消去"——求和会把它当未知变量边缘化掉。
