本章角色：Ch6 的残差在这里获得概率身份——高斯噪声下的对数似然；同一套凸语言延伸到估计、检验与实验设计。

主线

本章主线：似然 → 对数 → 凹性，凹性一通，统计四件事全是凸问题

1观测 $\boldsymbol{y}$ 背后有未知参数 $\theta$ → 写似然 $p(\boldsymbol{y};\theta)$（§7.1）
2取对数：乘积变求和；真正的判官是凹性（§7.1）
3$\ell$ 凹 ⟹ ML 是凸问题；高斯测量下退化为最小二乘（§7.2）
4把判决概率 $t_k$ 当变量：检测器设计是 LP，ROC 是 Pareto 前沿（§7.3）
5更上游：采集前优化预算，D-最优 $=\max\log\det$（§7.4）
💡 链条末端的代价：模型错了，凸性再好也白搭——凸性只对「模型正确」负责。
动机

「频率就是概率」谁都会猜，但猜的凭什么全局最优？

硬币正面概率 $p$ 未知，抛 $n=10$ 次，$k=7$ 次正面——$p$ 该取多少？

$$\text{直觉答案 } \hat{p}=\tfrac{7}{10}=0.7 \qquad\text{——对，但目前只是「蒙」对的}$$
😇 靠直觉蒙
简单模型碰巧对；换混合分布等复杂模型，直觉立刻失灵。
😟 网格搜参数
维度稍高就爆炸，且没有任何最优性保证。
💡 本章方案：把「最像真的」写成 $\max$ 对数似然，用凹性判定是否凸问题——凹则有全局最优保证。
定义

最大似然 = 似然函数 ＋ 取对数 ＋ 对参数求最大，凹性是判官

📊 似然 $p(\boldsymbol{y};\theta)$：视角切换——$\boldsymbol{y}$ 已固定，$\theta$ 是变量
🪵 对数似然 $\ell(\theta)$：$\log$ 严格递增，argmax 位置不变
⛰️ 凹性：$\ell$ 关于 $\theta$ 凹 ⟺ 凸优化，全局最优有保证
$$\text{最大似然（MLE）}\quad \boldsymbol{\hat{\theta} = \operatorname*{argmax}_{\theta}\; p(\boldsymbol{y};\theta) = \operatorname*{argmax}_{\theta}\; \ell(\theta)}$$
读法：哪个参数最能把已发生的事解释成「理所当然」，就选谁。
好解不好解，一眼看凹性：凹 → 凸优化；不凹 → 爬山碰运气。
7.1

取对数只是顺手，凹性才决定这题好不好解

$$\ell(\theta) = \log \prod_i p(y_i;\theta) = \sum_i \log p(y_i;\theta) \quad\text{——乘积变求和，argmax 位置不变}$$
🔍 第三个性质才是判官
$\ell(\theta)$ 凹 ⟺ 最大化 = 凸优化 ⟹ 第9–11章算法全盘适用，驻点即全局最优。
🎁 指数族的结构性礼物
高斯、Bernoulli、Poisson 的对数似然关于自然参数自动凹——不是巧合。
🔑 判定流程：见到新似然模型，第一步先查凹性（或能否化成凹），再谈求解。
演练

手算抛硬币：导数置零给出 0.7，二阶导为负才敢说全局最优

① 写对数似然（$n=10$，$k=7$，似然 $p^7(1-p)^3$）

$$\ell(p) = 7\ln p + 3\ln(1-p)$$

② 一阶导置零

$$\ell'(p) = \frac{7}{p} - \frac{3}{1-p} = 0 \;\Longrightarrow\; 7(1-p) = 3p \;\Longrightarrow\; \hat{p} = \frac{7}{10} = 0.7$$

③ 二阶导验证凹性（两项恒负）

$$\ell''(p) = -\frac{7}{p^2} - \frac{3}{(1-p)^2} \lt 0 \;\Longrightarrow\; \ell \text{ 严格凹，}\ \boldsymbol{\hat{p} = \tfrac{k}{n} = 0.7} \text{ 就是全局最优} \;\;(1)$$
✍️
暂停推导

自己动手：求一阶导 → 置零解出 $\hat{p}$ → 算二阶导说明「为什么这个驻点就是全局最优」。

7.2

高斯噪声下取对数，最大似然正好就是最小二乘

线性测量模型 $\boldsymbol{y} = A\boldsymbol{x} + \boldsymbol{w}$，噪声 $\boldsymbol{w} \sim \mathcal{N}(\boldsymbol{0}, \sigma^2 I)$：

$$\ell(\boldsymbol{x}) = \text{常数} - \frac{1}{2\sigma^2}\,\|\boldsymbol{y} - A\boldsymbol{x}\|_2^2$$
$$\max_{\boldsymbol{x}}\ \ell(\boldsymbol{x}) \;\Longleftrightarrow\; \boldsymbol{\min_{\boldsymbol{x}}\ \|y - Ax\|_2^2} \quad\text{——残差平方和的概率身份} \;\;(2)$$
🔑 第6章罚函数表格的每一行背后都站着一个噪声分布：高斯 ↔ 平方罚；重尾分布 ↔ Huber 一族稳健罚。
推导

三步会师：从高斯密度到残差平方和

① 写密度（指数上正是负的残差平方和）

$$p(\boldsymbol{y};\boldsymbol{x}) = (2\pi\sigma^2)^{-m/2}\,\exp\!\left(-\frac{1}{2\sigma^2}\|\boldsymbol{y}-A\boldsymbol{x}\|_2^2\right)$$

② 取对数（归一化常数与 $\boldsymbol{x}$ 无关，并入常数项）

$$\ell(\boldsymbol{x}) = \underbrace{-\tfrac{m}{2}\log(2\pi\sigma^2)}_{\text{常数}} \;-\; \frac{1}{2\sigma^2}\|\boldsymbol{y}-A\boldsymbol{x}\|_2^2$$

③ 系数为正：最大化 $\ell$ ⟺ 最小化残差平方和

$$\boldsymbol{\hat{x}_{\mathrm{ML}} = \operatorname*{argmin}_{\boldsymbol{x}}\ \|y - Ax\|_2^2} \quad\text{——ML 与最小二乘同解} \;\;(3)$$

7.2

「ML 等于最小二乘」有三个前提，缺一条就换人

前提数学写法被破坏后 ML 变成
各分量独立$\Sigma_w$ 对角相关噪声 → 加权最小二乘（白化后再投影）
同方差$\sigma^2 I$异方差 → 各残差权重不同
高斯分布$\boldsymbol{w}\sim\mathcal{N}(\boldsymbol{0},\sigma^2 I)$重尾噪声 → ℓ1 型 / Huber 稳健罚
口诀：罚函数的形状由噪声分布决定——把最小二乘当默认之前，先问噪声是什么分布。
例子

同一点测三次，样本均值就是最大似然

未知 $\mu$ 独立测 3 次：$y = 2,\,4,\,6$，$\sigma^2 = 1$。最大化 $\ell$ ⟺ 最小化 $\sum_i (y_i-\mu)^2$：

$$\frac{d}{d\mu}\sum_{i=1}^{3}(y_i-\mu)^2 = -2\sum_{i=1}^{3}(y_i-\mu) = 0 \;\Longrightarrow\; \boldsymbol{\hat{\mu} = \frac{2+4+6}{3} = 4}$$
🔑 样本均值 $=$ ML 估计。目标是严格凸的二次函数，唯一驻点即全局最优——又一次「凸性保证」。
7.2

协方差估计对 Σ 不凹，换成逆矩阵 S 就凹了

协方差估计（Covariance Estimation）：$\boldsymbol{y}_i \sim \mathcal{N}(\boldsymbol{0}, \Sigma)$，估 $\Sigma$。对数似然（差常数）：

$$\ell(\Sigma) = -\frac{n}{2}\log\det\Sigma - \frac{1}{2}\sum_i \boldsymbol{y}_i^{\top}\Sigma^{-1}\boldsymbol{y}_i \quad\text{——对 $\Sigma$ 不凹}$$
$$\text{换变量 } S=\Sigma^{-1}\text{：}\quad \ell(S) = \frac{n}{2}\underbrace{\log\det S}_{\text{凹}} - \frac{1}{2}\underbrace{\operatorname{tr}\!\big(S\textstyle\sum_i \boldsymbol{y}_i\boldsymbol{y}_i^{\top}\big)}_{\text{线性}} \;\Rightarrow\; \text{对 } S \text{ 凹} \checkmark$$
$$\text{梯度置零：}\quad \boldsymbol{\hat{\Sigma} = \frac{1}{n}\sum_{i=1}^{n} \boldsymbol{y}_i\boldsymbol{y}_i^{\top}} \quad\text{（样本协方差）} \;\;(4)$$
样本少、维度高时 $\hat{\Sigma}$ 接近奇异 → 加 $\delta I$ 正则，即第6章 Tikhonov 的统计翻版：正则化是被显式写出的先验。
7.3

估计回答「是多少」，检验回答「是哪个」——判决规则也能优化

$P(X{=}0)$$P(X{=}1)$
$H_0$0.90.1
$H_1$0.30.7
🚨 虚警（False Positive）：$H_0$ 为真却判 $H_1$
🕳️ 漏检（False Negative）：$H_1$ 为真却判 $H_0$
$$\text{「}X{=}1\text{ 判 }H_1\text{」：}\quad P_{fp} = 0.1,\quad P_{fn} = 0.3,\quad \text{总错误率} = 0.4 \quad(\text{反着判：} 0.9+0.7=1.6\text{，更糟})$$
7.3

把判决概率当变量，检测器设计就是线性规划

随机化检测器（Randomized Detector）：$X=k$ 时以概率 $t_k\in[0,1]$ 判 $H_1$——$t_k$ 本身是优化变量：

$$P_{fp} = 0.9\,t_0 + 0.1\,t_1,\qquad P_{fn} = 0.3(1-t_0) + 0.7(1-t_1) \quad\text{——都是 } \boldsymbol{t} \text{ 的线性函数}$$
$$\min\ (P_{fp} + P_{fn}) \;\;\text{或}\;\; \min\ P_{fn}\ \ \text{s.t.}\ \ P_{fp} \le \alpha \quad\Longrightarrow\quad \boldsymbol{\text{都是 LP}} \;\;(5)$$
🔑 Neyman–Pearson：最优检测器必是似然比检验（Likelihood Ratio Test）。本例 $L(1)=0.7/0.1=7 \gg L(0)=0.3/0.9=\tfrac13$，$X{=}1$ 强烈支持 $H_1$。
7.3

ROC 曲线是检测问题的 Pareto 前沿，与第6章权衡曲线同构

(P_fp, P_fn)"] B --> C["ROC 曲线"] C --> D["Pareto 前沿
≅ Ch6 权衡曲线"]
① 虚警与漏检被锁在同一条前沿上：压低一个必抬高另一个；想整体下移，只能换更 informative 的观测。
② 选工作点 = 工程判断，和选正则参数 $\lambda$ 一模一样——曲线上处处 Pareto 最优，选点看代价权重，不看曲线。
7.4

实验设计：在采集数据之前，先优化「测什么、各测多久」

可选实验 $k=1,\dots,p$，第 $k$ 个测方向 $\boldsymbol{v}_k$；$\lambda_k$ = 分给它的预算占比：

$$E(\boldsymbol{\lambda}) = \Big(\sum_k \lambda_k \boldsymbol{v}_k\boldsymbol{v}_k^{\top}\Big)^{-1},\qquad \lambda_k \ge 0,\ \ \textstyle\sum_k \lambda_k = 1$$
$$\text{D-最优设计（D-optimal）}\quad \boldsymbol{\max_{\boldsymbol{\lambda}}\ \log\det\Big(\sum_k \lambda_k \boldsymbol{v}_k\boldsymbol{v}_k^{\top}\Big)} \;\Longleftrightarrow\; \min \text{置信椭球体积} \;\;(6)$$
🔑 $\log\det$ 在正定锥上凹，约束是单纯形（凸集）→ 凸问题：「压小矩阵」被标量化为 $\log\det E$。
例子

两个互相垂直的实验，最优预算是平分

$$\boldsymbol{v}_1=(1,0)^{\top},\ \ \boldsymbol{v}_2=(0,1)^{\top} \;\Rightarrow\; \textstyle\sum_k\lambda_k\boldsymbol{v}_k\boldsymbol{v}_k^{\top} = \operatorname{diag}(\lambda_1,\lambda_2),\qquad \max\ \log(\lambda_1\lambda_2),\ \ \lambda_1+\lambda_2=1$$
$$\text{AM–GM：}\ \lambda_1\lambda_2 \le \Big(\tfrac{\lambda_1+\lambda_2}{2}\Big)^2 = \tfrac14,\ \ \text{等号} \iff \boldsymbol{\lambda_1 = \lambda_2 = \tfrac{1}{2}} \;\;(7)$$
💡 预算跟着信息增量走，不跟实验个数走：方向相关的实验信息重叠，不该平分。

避坑

本章最容易错的三件事：最优、等价、两全，都别想当然

❌ ML 估计就是最优估计
✅ 它只是「让已发生的数据最可能」——不含方差与偏差信息；「怎么更准」是 §7.3、§7.4 的问题，不是「哪个最像」。
❌ ML = 最小二乘，随时成立
✅ 仅在「独立、同方差、高斯」三前提下成立；噪声相关 → 加权最小二乘，重尾 → Huber 稳健罚。
❌ 虚警和漏检可以同时任意小
✅ 两者被 ROC 锁在一条 Pareto 前沿上：压低一个必抬高另一个；要整体下移，换更好的观测，而非更聪明的判决。

小结

三句话讲完第7章

1解决什么：估计、协方差、检验、实验设计——统计四件事各自写成优化问题并判定凸性。
