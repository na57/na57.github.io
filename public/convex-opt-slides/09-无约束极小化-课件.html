动机

知道解存在不等于算得出：大规模凸问题只能迭代逼近

Ch6–8 留下的都是光滑凸目标，但「凸」只保证解好，不保证解好算：

$$\text{最小二乘：解 } n \text{ 阶正规方程 } \sim O(n^{3}) \qquad \text{logistic：对数似然无闭式解}$$
😇 方案一：等闭式解
最小二乘是幸运的例外；logistic、解析中心之类根本没有闭式表达，等不到。
🙂 方案二：硬解方程
$n=10^{5}$ 时 $O(n^{3})=10^{15}$ 次浮点，一次都嫌贵，别说反复求解。
💡 本章方案：迭代 $x^{+}=x+t\Delta x$——每步只要求「确实变好」，用小钱攒高精度。
定义

下降方法就三个部件：方向、步长、停止准则

🧭 方向 $\Delta x$：下降方向（Descent Direction）
$\nabla f(x)^{T}\Delta x \lt 0$ 即保证微步必降；代表：$-\nabla f$（梯度法）、牛顿步。
📏 步长 $t$：线搜索（Line Search）
精确线搜索解 $\min_t f(x+t\Delta x)$；回溯线搜索只查一条充分下降不等式。
🛑 停止准则
$\|\nabla f(x)\|$ 够小，或牛顿减量 $\lambda^{2}/2\le\varepsilon$（9.3），即宣布收敛。
$$\boldsymbol{x^{+}=x+t\,\Delta x},\qquad \nabla f(x)^{T}\Delta x \lt 0$$
读法：站在当前点，挑一个下坡方向，迈一步「够好」的步子，重复到没油水为止。
9.1

回溯线搜索只要「够好」：真实下降压过打折直线就接受

$$f(x+t\Delta x)\;\le\; f(x)+\alpha\, t\, \nabla f(x)^{T}\Delta x,\qquad \alpha\in(0,\tfrac12);\ \ \text{不满足则 } t:=\beta t,\ \beta\in(0,1)$$
📉 几何读法
右端是一条斜率打 $\alpha$ 折的直线；真实曲线压过它即「足够下降」。
🎛️ 两个旋钮
$\alpha$ 管「要求多大幅度的下降」（宽容度）；$\beta$ 管「不满足时缩多快」（回溯力度）。
设计哲学：用可检查的充分条件代替最优条件——这个思想在第 11 章内点法里还会回来。
推导

手算一步回溯：先试大步，摔了减半，两次命中最优

① 设定：$f(x)=x^{2}$，$x=2$，$\nabla f=4$，$\Delta x=-4$，$\alpha=\tfrac14$，$\beta=\tfrac12$，从 $t=1$ 试起

② 试 $t=1$：左端 $f(2-4)=4$，右端 $4+\tfrac14\cdot 1\cdot(-16)=0$

$$4\ \not\le\ 0 \quad\Rightarrow\quad \text{拒绝，}t:=\beta t=\tfrac12$$

③ 试 $t=\tfrac12$：左端 $f(0)=0$，右端 $4+\tfrac14\cdot\tfrac12\cdot(-16)=2$

$$0\ \le\ 2\ \ \checkmark\quad\Rightarrow\quad \text{接受}$$
$$x^{+}=2+\tfrac12\cdot(-4)=\boldsymbol{0}\quad\text{——一步到最优（回溯两次，只算函数值）}$$
✍️
暂停推导

自己动手：写出两次试验的左右两端数值，判定各接受还是拒绝，给出 $x^{+}$。

9.2

梯度下降是线性收敛，速度快慢由条件数说了算

强凸假设与条件数（Condition Number）：

$$mI\preceq \nabla^{2}f(x)\preceq MI\ \ (0\lt m\le M),\qquad \kappa=\tfrac{M}{m}$$
$$f(x^{(k)})-p^{\star}\ \le\ c^{k}\bigl(f(x^{(0)})-p^{\star}\bigr),\qquad c=1-\tfrac{m}{M}\ \ \text{（回溯）};\quad c=\Bigl(\tfrac{\kappa-1}{\kappa+1}\Bigr)^{2}\ \ \text{（二次+精确）}$$
线性收敛（Linear Convergence）= 对数误差随 $k$ 直线下降。$\kappa\to 1$ 则 $c\to 0$（圆等高线）；$\kappa\to\infty$ 则 $c\to 1$（扁椭球爬行）。
例子

一步实测收缩 0.669，与理论预言分毫不差

$f(x_1,x_2)=\tfrac12(x_1^{2}+10x_2^{2})$，$Q=\mathrm{diag}(1,10)$，$\kappa=10$，起点 $x^{(0)}=(10,1)$：

步骤计算结果
① 梯度$g=Qx^{(0)}$$(10,10)$
② 精确步长$t=g^{T}g\,/\,g^{T}Qg=200/(100+1000)$$t=2/11\approx0.1818$
③ 更新$x^{(1)}=x^{(0)}-t\,g$$(90/11,\,-9/11)\approx(8.18,-0.82)$
④ f 值$f(x^{(0)})=\tfrac12(100+10)=55$，$f(x^{(1)})=4455/121$$\approx 36.82$
⑤ 收缩比$36.82/55$$\approx 0.669=\bigl(\tfrac{9}{11}\bigr)^{2}\ \checkmark$
$x_1$ 慢降、$x_2$ 冲过头——梯度方向被长轴「绑架」，这就是锯齿（Zigzag）。
难点

等高线越扁，梯度轨迹越在两壁之间来回弹

⭕ $\kappa\approx 1$：等高线接近圆
负梯度直指谷底，$c\to 0$，几步收敛。
🫓 $\kappa\gg 1$：扁椭球（Zigzag）
负梯度垂直等高线切线，几乎横切长轴，在两壁间来回弹，$c\to 1$。
一句话：梯度法用「局部最陡」方向，最优解在「全局谷底」方向，$\kappa$ 就是这两个方向偏离的度量。
推论：数据归一化 = 压 $\kappa$；牛顿法 = 用海森把坐标系揉圆，等效于令 $\kappa=1$（下一页）。
9.3

牛顿步直取抛物模型的谷底，二次函数一步收敛

$$\boldsymbol{\Delta x_{\mathrm{nt}}=-\nabla^{2}f(x)^{-1}\nabla f(x)},\qquad x^{+}=x+\Delta x_{\mathrm{nt}}$$
$$\text{二次 } f=\tfrac12 x^{T}Qx\text{：}\quad x^{+}=x-Q^{-1}(Qx)=\boldsymbol{0}\ \ \text{（一步到最优，与起点无关）}$$
牛顿 = 先用海森把坐标系揉圆，再在新坐标里走最速下降。仿射不变 ⇒ 「条件数」在牛顿章节里消失。
例子

近优解区误差逐次平方，有效数字每步近乎翻倍

$f(x)=x^{2}+x^{4}$：$f'=2x+4x^{3}$，$f''=2+12x^{2}$，牛顿更新：

$$x^{+}=x-\frac{2x+4x^{3}}{2+12x^{2}}=\frac{4x^{3}}{1+6x^{2}}$$
步$x$误差 $=|x-0|$误差行为
起点$1$$1$
①$4/7$$\approx 0.5714$压缩 $0.57\times$
②$\approx 0.2523$$0.2523$$\approx$ 上步误差的平方量级
③$\approx 0.0465$$0.0465$$0.2523^{2}=0.0637$，同级 $\checkmark$
工程化

离远了要阻尼包一层，停不停看牛顿减量

🛡️ 阻尼牛顿（Damped Newton）
远离最优：回溯线搜索包一层保全局收敛；近优解区：必须能接受全步长 $t=1$，否则退化为慢速。
🅂 自和谐（Self-Concordant）
$|f'''|\le 2(f'')^{3/2}$：三阶导被二阶导管住，log-barrier 属此类——Ch11 复杂度证明的地基。
$$\text{牛顿减量（Newton Decrement）：}\ \lambda^{2}=\nabla f^{T}\nabla^{2}f^{-1}\nabla f,\qquad f(x)-p^{\star}\approx\tfrac{\lambda^{2}}{2}\ \Rightarrow\ \tfrac{\lambda^{2}}{2}\le\varepsilon\ \text{即停}$$
$\lambda^{2}/2$ 是「无需知道 $p^{\star}$」的可计算次优间隙估计——模型说没油水了，就停车。
9.4

次线性、线性、二次：三档速率各管一片

速率档误差行为代表算法每步代价适用
次线性$O(1/k)$次梯度法$O(n)$不可微（LASSO、SVM 合页）
线性$c^{k}$，$c=\bigl(\tfrac{\kappa-1}{\kappa+1}\bigr)^{2}$梯度法 + 回溯$O(n)$大规模光滑、$\kappa$ 适中
二次误差逐次平方阻尼牛顿$O(n^{3})$中小规模、要高精度
规律：档位越高每步越贵——比较算法必须「迭代数 × 每步代价」一起报。
总账

没有免费的二次收敛：迭代数 × 每步代价才是总账

$$\text{压 }10^{6}\text{ 倍：梯度 }k\ge\tfrac{\log 10^{-6}}{\log 0.669}\approx 34\text{ 步}\sim 34n\quad\text{vs}\quad\text{牛顿 }1\text{ 步}\sim n^{3}\ \ (n=10^{5}\text{ 时 }10^{15})$$

$n=2$ 牛顿赢，$n=10^{5}$ 梯度法赢九个量级——量级反转，只看迭代数会误判。

避坑

三个最常见误判：小步长迷恋、「线性 = 慢」、步数少 = 算法好

❌ 「步长越小越安全，t 取很小总没错」
✅ 过小步长让 $c\to 1$、慢到不可用；回溯是「先试大、不行再缩」，牛顿近优区更要求全步长 $t=1$。
❌ 「线性收敛 = 慢」
✅ 线性收敛是指数收缩 $c^{k}$，已经很快；真正慢的是次线性 $O(1/k)$。看 $\log$ 误差：斜率 $\log c$ 的直线。
❌ 「迭代次数少 = 算法好，牛顿总比梯度强」
✅ 牛顿一步顶梯度几十步，但每步贵 $n^{2}$ 倍；$n=10^{6}$ 时牛顿一步都算不动。报算法须报两个数：迭代数与每步代价。
