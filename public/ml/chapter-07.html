7.1为什么"最优分类"等价于"最小决策风险"：贝叶斯决策论

前 6 章大多把分类当作"找一个边界"：线性模型找超平面，决策树找划分，SVM 找最大间隔。本章换一个更根本的视角：分类是一个在不确定性下做决策的问题，而"最优"应当定义为"期望损失最小"。这就是贝叶斯决策论（Bayes Decision Theory）的出发点。

设样本 x 的真实类别是 cj 之一，我们把 x 判为 ci 的损失记为 λij（把 cj 误判成 ci 的代价）。在已知后验概率 P(cj|x) 的前提下，把 x 判为 ci 的条件风险（Conditional Risk）是：

R(ci | x) = ∑j λij · P(cj | x)

贝叶斯判定准则（Bayes Decision Rule）：对每个样本 x，选择使条件风险最小的那个类别——h*(x) = argmini R(ci|x)。这样得到的分类器叫贝叶斯最优分类器（Bayes Optimal Classifier），其风险称贝叶斯风险（Bayes Risk），是任何分类器能达到的下界。

最常用的0-1 损失（0-1 Loss）：判对损失 0，判错损失 1，即 λij = 0（i=j）、1（i≠j）。此时：

R(ci | x) = ∑j≠i P(cj | x) = 1 − P(ci | x)

最小化风险 ⟺ 最大化 P(ci|x)，于是贝叶斯判定准则退化为一句大白话：把 x 判给后验概率最大的类（最大后验准则，Maximum A Posteriori，MAP）。

小例子：两类、三个样本，逐样本算风险

两类 c₁、c₂。误分代价不对称：把真 c₂ 误判为 c₁ 损失 λ₁₂ = 2（例如漏诊），把真 c₁ 误判为 c₂ 损失 λ₂₁ = 1（例如误诊）。则：

R(c₁|x) = 2·P(c₂|x)，   R(c₂|x) = 1·P(c₁|x)
样本P(c₁|x)P(c₂|x)R(c₁|x) = 2·P(c₂|x)R(c₂|x) = 1·P(c₁|x)贝叶斯决策
x₁0.70.30.60.7c₁（0.6 小于 0.7）
x₂0.40.61.20.4c₂（0.4 小于 1.2）
x₃0.50.51.00.5c₂（0.5 小于 1.0）

注意 x₃：即使 P(c₁|x₃) = 0.5 与 P(c₂|x₃) = 0.5 一样大，由于"漏诊 c₂"代价更高，最优决策仍是 c₂。这正是不对称损失的意义——决策边界被推向了 P(c₁|x) 大于 λ₁₂/(λ₁₂+λ₂₁) = 2/3 ≈ 0.667，而不是 0.5。

💡 关键一跃

贝叶斯决策论把"分类"翻译成"算账"：后验概率是账本上各行的概率权重，λ 是每行的代价，条件风险是加权总价，最优决策就是挑总价最低的那一行。

⚠️ 常见误区

"后验概率最大就一定最优"——只在 0-1 损失下成立。一旦误分代价不对称（医疗、金融风控、垃圾邮件），就必须用条件风险而不是 MAP，否则会把高代价错误当低代价处理。

7.2后验概率从哪来：判别式 vs 生成式，以及极大似然估计

上一节告诉我们：有了 P(c|x)，最优决策就是查表。但 P(c|x) 不会从天上掉下来。第3章的线性模型、第5章的神经网络走的是判别式（Discriminative）路线——直接对 P(c|x) 建模；本章走生成式（Generative）路线——先对联合分布 P(x, c) 建模，再用贝叶斯定理翻出后验：

P(c | x) = P(c) · P(x | c)P(x) ∝ P(c) · P(x | c)

其中 P(c) 叫先验（Prior），P(x|c) 叫类条件概率 / 似然（Likelihood），P(x) 是与类别无关的归一化因子（比较时通常不用算）。于是"估计 P(c|x)"被拆成两个更简单的估计问题：估先验 + 估似然。怎么估？最经典的办法是极大似然估计（Maximum Likelihood Estimation，MLE）：在参数化分布族里，选让"已观测数据出现概率最大"的那个参数。

完整推导：抛硬币 10 次 7 正，θ̂ = 7/10

设硬币正面朝上概率为 θ，抛 n = 10 次，观察到 k = 7 次正面。单次试验服从伯努利分布，n 次独立试验正面次数服从二项分布（Binomial Distribution）。观测到"7 正 3 反"的似然（先不管组合数 C(10,7)，因为它与 θ 无关）：

L(θ) = P(数据 | θ) ∝ θ7 · (1 − θ)3

取对数，把乘积变求和（θ 在 [0,1]，对数单调，不改变 argmax 位置）：

ln L(θ) = 7 · ln θ + 3 · ln(1 − θ) + 常数

对 θ 求导并置零：

d ln Ldθ = 7θ − 31 − θ = 0

通分解出：

7 · (1 − θ) = 3 · θ   ⟹   7 − 7θ = 3θ   ⟹   7 = 10θ   ⟹   θ̂ = 710

验证：θ = 0.69 时导数 ≈ +0.4675（应往大调），θ = 0.71 时导数 ≈ −0.4857（应往小调），θ = 0.70 时导数 = 0——确为极大值点。这就是"频率即概率"的严格由来：在 i.i.d. 伯努利假设下，MLE 给出的就是观测频率。

✅ 判定规则

MLE 三步走：① 写出似然 L(θ)（数据在参数下的概率）；② 取对数变求和；③ 求导置零解出 θ̂。对二项/多项分布，答案就是"次数 / 总数"；对高斯，答案就是样本均值与样本方差。

⚠️ 常见误区

"MLE 就是最小二乘"——错。最小二乘是高斯噪声假设下 MLE 的特例。MLE 的适用面更宽：只要你能写出似然函数，就能用。反过来，没有概率模型就谈不上 MLE。

7.3朴素贝叶斯与拉普拉斯平滑：条件独立假设把高维似然拆成连乘

上一节解决了"怎么估参数"，但真正的拦路虎是：x 通常是高维向量，P(x|c) 的参数随维度爆炸。比如 d 个二值属性，联合分布要 2d − 1 个参数——d=30 就是 10 亿。朴素贝叶斯（Naive Bayes）用一个强假设把问题打回原形：属性条件独立假设（Attribute Conditional Independence Assumption）——给定类别 c，各属性相互独立：

P(x | c) = ∏i=1..d P(xi | c)

于是每个属性只需单独估计一个一维分布，参数从指数降为线性。后验比较时 P(x) 相同，只需比较：

P(c | x) ∝ P(c) · ∏i=1..d P(xi | c)

完整手算：好瓜 / 坏瓜（10 条数据，4 个属性）

自编数据集：3 个离散属性（色泽、根蒂、敲声，各 3 个取值）+ 1 个离散属性（纹理，3 个取值），共 4 个离散属性；类别 5 好 5 坏：

#色泽根蒂敲声纹理类别
1青绿蜷缩浊响清晰好瓜
2乌黑蜷缩沉闷清晰好瓜
3青绿硬挺清脆模糊坏瓜
4乌黑稍蜷浊响清晰好瓜
5浅白蜷缩浊响清晰好瓜

10浅白稍蜷清脆模糊坏瓜

第 1 步：先验。P(好) = 5/10 = 0.5，P(坏) = 5/10 = 0.5。

第 2 步：条件概率 + 拉普拉斯平滑。直接数频次会出事——比如"根蒂=蜷缩"在坏瓜里出现 0 次，P(蜷缩|坏) = 0，连乘就把整个后验清零。拉普拉斯平滑（Laplacian Smoothing）给每个取值"先验地"加一次计数：分子 +1，分母 +该属性的取值数 Ni（这里每个属性 Ni = 3，每类样本数 5，故分母都是 5+3 = 8）。

测试样本 x =（青绿，蜷缩，浊响，清晰）。逐项计算：

条件概率好瓜类计数P(·|好)坏瓜类计数P(·|坏)
P(色泽=青绿|c)2（样本 1,9；样本 3,6 是坏）(2+1)/8 = 3/8 = 0.3752（样本 3,6）(2+1)/8 = 3/8 = 0.375
P(根蒂=蜷缩|c)4（1,2,5,9）(4+1)/8 = 5/8 = 0.6250(0+1)/8 = 1/8 = 0.125
P(敲声=浊响|c)3（1,4,5）(3+1)/8 = 4/8 = 0.5000(0+1)/8 = 1/8 = 0.125
P(纹理=清晰|c)4（1,2,4,5）(4+1)/8 = 5/8 = 0.6250(0+1)/8 = 1/8 = 0.125

第 3 步：连乘比较（P(x) 两边相同，省略）：

好瓜得分 = 0.5 × 0.375 × 0.625 × 0.500 × 0.625 ≈ 0.036621
坏瓜得分 = 0.5 × 0.375 × 0.125 × 0.125 × 0.125 ≈ 0.000366

好瓜得分约为坏瓜的 100 倍（0.036621 / 0.000366 ≈ 100），归一化后 P(好|x) ≈ 0.036621 / (0.036621 + 0.000366) ≈ 0.9901（若把连续属性密度也算进去则更高，约 0.9960）。判为好瓜——决策毫无悬念，关键差别来自后三项：坏瓜类里"蜷缩、浊响、清晰"一次都没出现，平滑把它们压到了 1/8。

💡 关键一跃

朴素贝叶斯 = "各证据独立投票"。每个属性是一个独立证人，先验是底牌，后验是"底牌 × 各证人证词"的连乘。拉普拉斯平滑则是给每个证人一张"保底的一票"，防止"从没见过"被翻译成"绝不可能"。

⚠️ 常见误区

"属性独立所以朴素贝叶斯很烂"——未必。它常在小数据、高维稀疏（文本分类！）场景表现惊人地好：虽然概率值本身不准，但"谁大谁小"的排序常常是对的，而分类只需要排序。真正的坑是：当属性间存在强相关（如"面积"与"周长"），同一信息被重复计票，后验会过度自信。

7.4假设太强怎么办：半朴素贝叶斯与贝叶斯网

上一节的条件独立假设简单粗暴，但现实里属性往往相关。"放一点相关性进来"有两条递进路线：半朴素贝叶斯（Semi-Naive Bayes）只放一点点；贝叶斯网（Bayesian Network）则允许任意结构化依赖。

半朴素贝叶斯：SPODE 的一句话机制

SPODE（Super-Parent ODE，独依赖估计）：假设所有属性都依赖类别，外加同一个超父属性。例如选"色泽"作超父，则 P(x|c) ≈ P(色泽|c) · ∏i≠色泽 P(xi|c, 色泽)。小例：若"敲声=浊响"与"纹理=清晰"在好瓜中高度相关（都出现 3 次），朴素贝叶斯会把这条信息计两遍；SPODE 改成 P(纹理|好, 敲声=浊响)，把相关性显式吃掉，避免重复计票。

贝叶斯网：用 DAG 写出联合概率的因子分解

贝叶斯网把变量画成有向无环图（DAG）的节点，边表示直接依赖。联合概率分解为"每个节点以其父节点为条件"的乘积：

P(X₁, X₂, …, Xn) = ∏i P(Xi | 父节点(Xi))

用一个自编 5 节点"感冒就医"例子：

flowchart TB C["感冒"] --> F["发烧"] C --> K["咳嗽"] F --> D["就医"] K --> D
图 7.1 贝叶斯网例子：感冒 → 发烧、感冒 → 咳嗽，发烧 + 咳嗽 → 就医。

因子分解式：

P(感冒, 发烧, 咳嗽, 就医) = P(感冒) · P(发烧|感冒) · P(咳嗽|感冒) · P(就医|发烧, 咳嗽)

三种条件独立结构

结构形状不给定中间量给定中间量
同父结构C → F，C → KF 与 K 相关F ⊥ K | C（独立）
顺序结构A → B → CA 与 C 相关A ⊥ C | B（独立）
V 结构（对撞）F → D ← KF ⊥ K（独立）F 与 K 相关（"解释消除"）

用 d-分离判断两组"给定 X 后 Y 与 Z 是否独立"

d-分离（d-Separation）的判断规则：在 DAG 中，给定集合 S，若 Y 到 Z 的每条无向路径都被 S 阻断，则 Y ⊥ Z | S。一条路径被阻断，当它含同父/顺序结构且中间节点 ∈ S，或含 V 结构且对撞节点及其后代都 ∉ S。也可用道德图（Moral Graph）：先把每个节点的多个父节点两两连边（"结婚"），再去掉所有方向——在道德图上，Y 与 Z 被 S 中的点分隔开 ⟺ 条件独立。

判断 1：给定"感冒"后，"发烧"与"咳嗽"独立吗？ 步骤：① 找发烧→咳嗽的所有无向路径，只有 发烧→感冒→咳嗽 一条；② 该路径是同父结构，中间节点"感冒" ∈ S = {感冒}；③ 同父结构中间节点被给定 → 路径被阻断；④ 所有路径都阻断，发烧 ⊥ 咳嗽 | 感冒。直觉：知道感冒与否后，发烧不再给咳嗽带来新信息。

判断 2：给定"就医"后，"发烧"与"咳嗽"独立吗？ 步骤：① 仍只有路径 发烧→就医←咳嗽（V 结构，对撞节点是"就医"）；② 对撞节点"就医" ∈ S = {就医}；③ V 结构对撞节点被给定 → 路径不被阻断；④ 存在未阻断路径，发烧与咳嗽不独立 | 就医。直觉：已知患者就医了，若他没发烧，那咳嗽的可能性就上升——两个父节点在给定共同子节点时互相"解释"，这就是解释消除（Explaining Away）。

✅ 判定规则

同父与顺序：给定中间节点 → 独立。V 结构：不给定对撞节点 → 独立，给定对撞节点（或其后代）→ 反而相关。这是贝叶斯网里最反直觉、也最常考的一条。

⚠️ 常见误区

"DAG 里有边 = 相关，没边 = 独立"——错。没直接边只是"不存在直接依赖"，是否独立必须沿所有路径做 d-分离判断；尤其 V 结构的对撞节点被观测后，原本独立的两个父节点会变得相关。

7.5有未观测变量怎么办：EM 算法

前三节都假设"每个样本属于哪一类是已知的"。但现实中常存在隐变量（Latent Variable）——比如一批身高数据混了男女两组，但"哪条数据属于哪组"没记录。这时对数似然里出现"log 套求和"，求导置零得不到闭式解。EM 算法（Expectation-Maximization Algorithm）用交替迭代绕开它：E 步（Expectation）用当前参数估计隐变量的后验分布（软指派）；M 步（Maximization）把这个软指派当成"带权数据"，重新做加权 MLE。两步交替，对数似然单调不降，直到收敛到局部最优。

完整手算：一维两高斯混合，一轮 EM

5 个观测点：x = 1, 2, 3, 7, 8。模型：两个一维高斯，混合系数 π = 0.5，两方差固定 σ² = 1（只剩两个均值要估）。初始值 μ₁ = 2，μ₂ = 6。高斯密度 φ(x;μ) = exp(−(x−μ)²/2) / √(2π)，其中 1/√(2π) ≈ 0.3989。

E 步：算每个点的责任度 γ1(x) = π·φ(x;μ₁) / [π·φ(x;μ₁) + π·φ(x;μ₂)]（π 约掉，即两个密度的归一化）：

xφ(x; μ₁=2)φ(x; μ₂=6)γ₁(x)γ₂(x)
10.3989·e−0.5 ≈ 0.24200.3989·e−12.5 ≈ 0.0000011.00000.0000
20.3989·e0 = 0.39890.3989·e−8 ≈ 0.00010.99970.0003
30.3989·e−0.5 ≈ 0.24200.3989·e−4.5 ≈ 0.00440.98200.0180
70.3989·e−12.5 ≈ 0.0000010.3989·e−0.5 ≈ 0.24200.00001.0000
80.3989·e−18 ≈ 0.00000.3989·e−2 ≈ 0.05400.00001.0000

直觉：x=1, 2, 3 几乎是"第 1 组的"，x=7, 8 几乎是"第 2 组的"，x=3 离两组最近，责任度 0.982 / 0.018 体现了那点犹豫。

M 步：用责任度做加权平均更新 μ。先算有效样本数 N₁ = Σγ₁ = 1.0000 + 0.9997 + 0.9820 + 0 + 0 = 2.9817，N₂ = 0 + 0.0003 + 0.0180 + 1 + 1 = 2.0183。然后：

μ₁ⁿᵉʷ = 1×1.0000 + 2×0.9997 + 3×0.9820 + 7×0 + 8×02.9817 = 5.94542.9817 ≈ 1.9940
μ₂ⁿᵉʷ = 1×0 + 2×0.0003 + 3×0.0180 + 7×1.0000 + 8×1.00002.0183 = 15.05462.0183 ≈ 7.4590

对数似然上升：ℓ(μ₁=2, μ₂=6) = Σx ln[πφ(x;μ₁) + πφ(x;μ₂)] ≈ −11.5419；更新后 ℓ(1.9940, 7.4590) ≈ −9.3121。−9.3121 大于 −11.5419，对数似然确实上升了——这正是 EM 的收敛保证：每一步都不会让数据变得更不可能。继续迭代，μ₁ 会收敛到约 2（前三个点的均值），μ₂ 收敛到约 7.5（后两个点的均值）。

💡 关键一跃

EM 是"鸡生蛋、蛋生鸡"的优雅解法：知道分组就能估参数（M 步），知道参数就能估分组（E 步）。既然两头都不知道，就先随便猜一头，然后来回修正——每次修正都让整体解释力更好。这正是第9章 GMM 聚类的引擎：K-means 的"硬指派"就是 EM 责任度取 0/1 的特例。

⚠️ 常见误区

"EM 能找到全局最优"——错。EM 只保证对数似然单调不降到局部最优，初值不同结果可能不同（本例若初值两个 μ 都取 4.5，责任度会塌缩成 0.5/0.5，更新后两均值相同，陷入退化解）。实践中要多次随机初始化取最好。

概念卡 1
朴素贝叶斯（Naive Bayes）
点击翻面 →
定义假设各属性在给定类别下相互独立的生成式分类器。
解决问题高维似然参数爆炸——把联合分布拆成各属性条件概率的连乘。
直觉各证据独立投票，先验是底牌，后验 = 底牌 × 各证词连乘。
误区以为概率值准——其实常常只有排序对，但分类只需要排序。
何时用文本分类、垃圾邮件过滤、小数据高维稀疏场景。
概念卡 2
拉普拉斯平滑（Laplacian Smoothing）
点击翻面 →
定义计数估计时分子 +1、分母 +取值数的修正。
解决问题某取值在类中未出现时条件概率为 0，连乘使整个后验清零。
直觉给每个证人一张保底票："没见过"≠"不可能"。
误区以为只用于朴素贝叶斯——任何频次估计都可用（如 n-gram）。
何时用离散属性的条件概率估计，样本量小的场合。
概念卡 3
贝叶斯网（Bayesian Network）
点击翻面 →
定义用 DAG 表示变量间依赖，联合分布 = 各节点以其父为条件的乘积。
解决问题朴素贝叶斯假设太强——允许任意结构化依赖，又避免全联合的参数爆炸。
直觉因果家谱：每个变量只"听"它父母的话。
误区以为边=相关、无边=独立——独立性必须沿路径做 d-分离判断。
何时用医疗诊断、故障分析；通向第14章概率图模型。
概念卡 4
条件独立与 d-分离（d-Separation）
点击翻面 →
定义给定 S 后 Y 与 Z 的所有路径被阻断 ⟺ Y⊥Z|S；规则依三种结构判定。
解决问题在 DAG 上机械地读出所有条件独立关系，不必算概率。
直觉信息流的水管：观测中间节点像关闸，观测对撞节点像开闸。
误区以为 V 结构给定子节点仍独立——恰恰相反，会引入相关（解释消除）。
何时用读贝叶斯网、设计变量集合、因果推断入门。
概念卡 5
EM 算法（Expectation-Maximization）
点击翻面 →
定义E 步估隐变量后验、M 步加权 MLE，交替到收敛的迭代算法。
解决问题有未观测变量时对数似然无闭式解（log 套求和）。
直觉鸡生蛋蛋生鸡：猜分组→估参数→改分组→再估参数，每步都让数据更可能。
误区以为收敛到全局最优——只保证局部最优，初值敏感。
何时用GMM、HMM、缺失数据；第9章 GMM 聚类的引擎。
概念卡 6
极大似然估计（MLE）
点击翻面 →
定义在参数化分布族中，选使观测数据概率最大的参数。
解决问题给"从数据估参数"一个统一、可操作的准则。
直觉哪个参数最可能"生出"眼前这批数据，就选谁。
误区以为等于最小二乘——那只是高斯噪声下的特例。
何时用先验/似然估计、EM 的 M 步、几乎一切统计学习。

📝分层习题

L1 概念辨析判断对错并说理由：① 生成式模型直接对 P(c|x) 建模；② 判别式模型把后验拆成"先验 × 似然"来估计；③ 逻辑回归是判别式，朴素贝叶斯是生成式。
提示

回想 P(c|x) 的两条获得路线：直接建模，还是先建 P(x, c) 再用贝叶斯定理。

完整解答

① 错。直接对 P(c|x) 建模的是判别式；生成式先对联合 P(x, c)（= 先验 × 似然）建模，再用贝叶斯定理推出后验。两者恰好说反了。

② 错。把后验拆成"先验 × 似然"的是生成式路线（本章 7.2 的贝叶斯定理分解）。

③ 对。逻辑回归直接学 P(c|x) 的参数化形式（sigmoid 套线性），是判别式；朴素贝叶斯学 P(c) 与 P(x|c) 再翻成后验，是生成式。易错点：别被"两个都是分类器"迷惑——判别/生成说的是建模对象，不是任务。

L1 概念辨析在 V 结构 F → D ← K 中，哪个说法正确？A. 不给定 D 时 F 与 K 相关；B. 给定 D 后 F 与 K 仍独立；C. 给定 D 后 F 与 K 相关（解释消除）；D. 无论是否给定 D，F 与 K 都独立。
提示

想象已知"就医"发生，若排除了"发烧"，"咳嗽"的可信度会怎样变化。

完整解答

选 C。V 结构里对撞节点 D 未被观测时，路径 发烧→就医←咳嗽 被阻断，F ⊥ K；一旦观测 D（或其后代），路径打开，两父节点通过"解释消除"相关。

A 错：不给定 D 时恰恰独立。B 错：给定 D 反而打开路径。D 错：忽略了"观测对撞节点会引入相关"这一 V 结构的独有现象。

L2 手算推导用 7.3 的 10 条瓜数据，对新测试样本 x′ =（乌黑，稍蜷，沉闷，清晰），带拉普拉斯平滑手算 P(好|x′) 与 P(坏|x′) 的未归一化得分并给出判决（列出每个条件概率的分子分母）。
提示

逐属性数：乌黑在好瓜出现几次？稍蜷在好瓜出现几次？分母统一是 5+3=8。

完整解答

先验：P(好) = P(坏) = 0.5。各条件概率（分子 = 类内计数+1，分母 = 8）：

好瓜类：P(乌黑|好) = (2+1)/8 = 3/8 = 0.375（样本 2,4）；P(稍蜷|好) = (1+1)/8 = 2/8 = 0.25（样本 4）；P(沉闷|好) = (2+1)/8 = 3/8 = 0.375（样本 2,9）；P(清晰|好) = (4+1)/8 = 5/8 = 0.625（样本 1,2,4,5）。

好瓜得分 = 0.5 × 0.375 × 0.25 × 0.375 × 0.625 = 0.5 × 0.021973 ≈ 0.010986。

坏瓜类：P(乌黑|坏) = (1+1)/8 = 2/8 = 0.25（样本 7）；P(稍蜷|坏) = (3+1)/8 = 4/8 = 0.5（样本 6,7,10）；P(沉闷|坏) = (2+1)/8 = 3/8 = 0.375（样本 6,8）；P(清晰|坏) = (0+1)/8 = 1/8 = 0.125。

坏瓜得分 = 0.5 × 0.25 × 0.5 × 0.375 × 0.125 = 0.5 × 0.005859 ≈ 0.002930。

0.010986 大于 0.002930，判为好瓜（归一化后 P(好|x′) ≈ 0.010986/0.013916 ≈ 0.7895）。注意本例中"稍蜷"一项好瓜反而更低，但被"清晰"一项的 5/8 vs 1/8 拉了回来——多证据连乘的拉锯就是这样体现的。

L2 手算推导接着 7.5 的例子，把刚得到的 μ₁ = 1.9940、μ₂ = 7.4590 当作新初值，再算一轮 EM：写出 x = 3 这一点的责任度（其余点的 γ 与上一轮几乎相同，可只验算 x=3），并给出新的 μ₁、μ₂（保留 4 位小数）。
提示

φ(3; 1.994) = 0.3989·e−(3−1.994)²/2；φ(3; 7.459) = 0.3989·e−(3−7.459)²/2。先算两个密度再归一化。

完整解答

x=3 处：φ(3;1.994) = 0.3989·e−0.506 ≈ 0.3989 × 0.6029 ≈ 0.2405；φ(3;7.459) = 0.3989·e−9.941 ≈ 0.3989 × 4.83×10−5 ≈ 0.0000193。归一化：γ₁(3) = 0.2405/(0.2405+0.0000193) ≈ 0.99992，γ₂(3) ≈ 0.00008。

其余四点责任度与上轮基本相同：γ₁(1)≈1，γ₁(2)≈1（更贴近 1），γ₁(7)≈0，γ₁(8)≈0。

于是 N₁ ≈ 1 + 1 + 0.99992 ≈ 2.99992，N₂ ≈ 0 + 0 + 0.00008 + 1 + 1 = 2.00008。

μ₁ⁿᵉʷ = (1×1 + 2×1 + 3×0.99992)/2.99992 ≈ 5.99976/2.99992 ≈ 2.0000；μ₂ⁿᵉʷ = (3×0.00008 + 7×1 + 8×1)/2.00008 ≈ 15.00024/2.00008 ≈ 7.4998。

可以看到仅两轮，μ 已收敛到真实组均值 (2, 7.5) 附近——EM 在分得开的数据上收敛很快。

L3 建模应用垃圾邮件过滤：一封邮件是否垃圾（Spam）影响"含免费字样"（Free）与"含链接"（Link）的出现；而"含免费字样"与"含链接"共同影响"被判分器标红"（Flag）。① 画出 4 节点贝叶斯网 DAG；② 写出联合概率因子分解式；③ 指出哪一步用了条件独立假设；④ 若已知"被标红"，"含免费字样"与"含链接"独立吗？为什么？
提示

Spam 是 Free 和 Link 的共同父节点；Flag 是 Free 和 Link 的共同子节点（V 结构）。

完整解答

① DAG：Spam → Free，Spam → Link，Free → Flag，Link → Flag（与 7.4 的"感冒就医"完全同构）。

② 因子分解：P(Spam, Free, Link, Flag) = P(Spam) · P(Free|Spam) · P(Link|Spam) · P(Flag|Free, Link)。

③ 条件独立假设出现在两处：Free ⊥ Link | Spam（同父结构，给定 Spam 后两特征独立——这正是朴素贝叶斯式的假设）；以及 Flag 只依赖 Free、Link，不直接依赖 Spam（顺序结构，给定 Free、Link 后 Flag 与 Spam 独立）。

④ 不独立。Free → Flag ← Link 是 V 结构，给定对撞节点 Flag 后两父节点通过解释消除相关：已知邮件被标红，若发现它不含免费字样，则"含链接"的概率上升。

  • D. 0.5（取两类平均）
解析：A 对——分子 +1、分母 +取值数（3）。B 错：不加平滑会使连乘清零，正是要防的情况。C 错：分母加的是取值数 3，不是 1（+1 是分母为类的另一种平滑变体，本讲义统一用 +Ni）。D 错：平滑不是跨类取平均。
自测 4
在顺序结构 A → B → C 与同父结构 B ← A → C 中，"给定 A"分别导致什么？
  • A. 两者都使 B 与 C 相关
  • B. 顺序结构使 B⊥C，同父结构使 B 与 C 相关
  • C. 两者都使 B 与 C 独立——但同父结构给定的是 A 时才独立，这里顺序结构给定的是中间节点 B 才独立，题干把给定对象搞混了
  • D. 顺序结构给定中间节点 B 使 A⊥C；同父结构给定父节点 A 使 B⊥C
解析：D 对——顺序结构"阻断在中间"：给定 B 则 A⊥C；同父结构"阻断在共同父"：给定 A 则 B⊥C。A 错：两种结构给定中间量都是独立而非相关（V 结构才相反）。B 错：把两种结构张冠李戴。C 错：题干问的是"各自给定什么导致独立"，D 完整正确地回答了两边，C 的批判不成立。
自测 5
关于 EM 算法，哪个说法正确？
  • A. EM 保证收敛到全局最优
  • B. E 步估计隐变量的后验分布（责任度），M 步据此做加权 MLE，且对数似然单调不降
  • C. EM 只适用于高斯混合，不能用于其他隐变量模型
  • D. K-means 与 EM 毫无关系
解析：B 对——这正是 EM 的定义与单调性定理。A 错：只保证局部最优，所以实践要多次初始化。C 错：HMM 的 Baum-Welch、缺失数据填补等都是 EM。D 错：K-means 是 GMM 责任度取 0/1、方差趋 0 时的 EM 特例（硬指派）。
