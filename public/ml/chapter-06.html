6.1间隔：为什么"最中间"的线最好

第 3 章的线性模型已经能用超平面 wᵀx + b = 0 把两类分开。但它带出一个问题：能把训练集分开的超平面有无数条——只要两类之间有缝，就能在这道缝里摆出无数个角度不同的分界面，它们在训练集上的错误率都是 0。第 2 章说过，训练误差相同就要比泛化能力。直觉上，离两类样本都"最远"的那条线最稳：它对新样本的轻微扰动最不敏感。这个直觉就是本章的起点。

给定超平面 wᵀx + b = 0，样本点 x 到超平面的带符号距离正比于 wᵀx + b。若样本被正确分类，y(wᵀx+b) 必为正（y ∈ {+1, −1}）。于是定义：

  • 函数间隔（Functional Margin）：γ̂ = y(wᵀx+b)。它有正有负的大小，但有个毛病：w、b 同乘 10，超平面没变，函数间隔却放大 10 倍——所以它随缩放而变，不能客观度量"离边界多远"。
  • 几何间隔（Geometric Margin）：把函数间隔除以 ‖w‖，即 γ = y(wᵀx+b) / ‖w‖。这才是欧氏空间里真正的点到面距离，缩放不变。

完整手算例：四个点定一条线

看一个能完全手算的最小例子。训练集只有 4 个点，都在 x 轴上：

样本(0, 0)(1, 0)(3, 0)(4, 0)
类别 y−1−1+1+1

负类最靠右的点是 (1, 0)，正类最靠左的点是 (3, 0)，缝隙是 x ∈ (1, 3)。"最中间"的分界线自然是 x = 2。写成超平面 wᵀx + b = 0：取 w = (1, 0)，b = −2，则 wᵀx + b = x₁ − 2 = 0 即 x₁ = 2 ✓。

逐点验证（全部代入 wᵀx + b = x₁ − 2）：

样本 xywᵀx+by(wᵀx+b)位置
(0, 0)−10 − 2 = −2(−1)×(−2) = 2间隔边界外，安全
(1, 0)−11 − 2 = −1(−1)×(−1) = 1恰在边界上
(3, 0)+13 − 2 = +1(+1)×(+1) = 1恰在边界上
(4, 0)+14 − 2 = +2(+1)×(+2) = 2间隔边界外，安全

离分界面最近的点 (1, 0) 和 (3, 0) 满足 wᵀx+b = ±1——它们叫支持向量（Support Vector）。此时 ‖w‖ = √(1²+0²) = 1，最近点的几何间隔 = 1/‖w‖ = 1。两侧边界之间的总宽度：

总间隔 = 2‖w‖ = 21 = 2（每侧各 1，正是 x=1 与 x=3 之间的距离）

关于"恰好等于 ±1"的约定：注意 w = (1, 0)、b = −2 与 w = (2, 0)、b = −4 是同一个超平面（x = 2），几何间隔也相同（后者函数间隔全翻倍，但除以 ‖w‖=2 后还是 1）。既然缩放不改变任何实质，我们索性把缩放固定下来：规范化到支持向量处 |wᵀx+b| = 1。这个约定白送、无损失，却让目标函数变得极漂亮。

于是"找最中间的线"就写成：在所有人都不越界（函数间隔 ≥ 1）的前提下，把几何间隔 1/‖w‖ 最大化。最大化 1/‖w‖ 等价于最小化 ‖w‖，再添个 ½ 和平方只是为了求导干净（½·2w = w）：

minw,b ½‖w‖² s.t. yi(wᵀxi+b) ≥ 1, i = 1,…,m

这就是 SVM 的基本型：目标函数是二次的（凸），约束是线性的——一个标准的凸二次规划（Convex Quadratic Programming），有唯一全局最优解，没有局部最优的坑（对比第 5 章神经网络的非凸优化）。

💡 关键一跃

"最中间的线最好"的直觉，翻译过来就是：几何间隔最大 ⟺ ‖w‖ 最小。而规范化约定（支持向量处函数间隔 = 1）把这个几何问题压缩成了一句干净的话：约束 yi(wᵀxi+b) ≥ 1 下最小化 ½‖w‖²。间隔大意味着两类之间的"隔离带"宽，新样本稍微挪一点也不容易越界——这就是泛化能力的几何来源（Ch12 会给出它的理论界）。

⚠️ 常见误区

误区一：把函数间隔当距离。函数间隔可以任意放大（w,b 同乘常数），它只负责"符号对不对"，不负责"离得多远"；真正度量距离的是除以 ‖w‖ 后的几何间隔。误区二：以为间隔是"一条线的粗细"。间隔 2/‖w‖ 是两条边界线之间的宽度：wᵀx+b=+1 与 wᵀx+b=−1 之间不允许有任何训练样本，分界面位于正中央。

6.2对偶问题与支持向量：解为什么只挂在少数点上

6.1 把问题写成了凸二次规划，可以直接解。但它带出一个更有意思的问题：约束有 m 条（每个样本一条），最后真正"顶"在最优解上的有几条？答案藏在拉格朗日对偶里，而这个答案正是 SVM 名字的由来。

对每条约束 yi(wᵀxi+b) ≥ 1 引入一个拉格朗日乘子（Lagrange Multiplier）αi ≥ 0，构造拉格朗日函数，先对 w、b 求极小。对 w 求偏导并令其为零，得到：

w = ∑i=1m αiyixi

代回原式，问题化为只关于 α 的对偶问题（Dual Problem）：在 αi ≥ 0、∑αiyi = 0 的约束下，最大化 ∑αi − ½∑i∑jαiαjyiyjxiᵀxj。注意最后一项：训练样本只以内积形式出现。

关键的性质来自 KKT 条件（Karush-Kuhn-Tucker Conditions）中的互补松弛：

αi · [ yi(wᵀxi+b) − 1 ] = 0

每一项都是两个非负数（αi 与"超出间隔的量"）的乘积等于 0，所以每个样本必然落在两种情况之一：

  • αi = 0：样本在间隔边界之外（函数间隔 > 1），它对 w = ∑αiyixi 的贡献为零；
  • αi > 0 ⟺ yi(wᵀxi+b) = 1：样本恰好压在间隔边界上——它就是支持向量（Support Vector），只有它进入 w 的线性组合。

回代 6.1 的例子：最优解 w = (1, 0) = ∑αiyixi。x 分量只有 (1,0) 与 (3,0) 能贡献 x 方向：α₂·(−1)·(1,0) + α₃·(+1)·(3,0) = (3α₃ − α₂, 0) = (1, 0)，配约束 α₂ = α₃（∑αiyi = 0），得 α₂ = α₃ = 0.5；而 (0, 0) 与 (4, 0) 的 α₁ = α₄ = 0。于是 w = 0.5×(−1)×(1,0) + 0.5×(+1)×(3,0) = (−0.5+1.5, 0) = (1, 0) ✓。

💡 关键一跃

SVM 的解是稀疏的：w 只是少数支持向量的加权和。在 6.1 的例子中，把 (0,0) 和 (4,0) 这两个非支持向量挪到更远的地方（比如 (−5,0) 和 (9,0)），甚至干脆删掉，重新求解得到的分界面纹丝不动——分界面 x=2 完全由压在边界上的 (1,0)、(3,0) 两个点决定。这就是"支持向量机"这个名字的全部含义：模型 = 支持向量撑起来的机器。

⚠️ 常见误区

误区：以为支持向量是"最难分对的坏样本"。恰好相反：支持向量是最"守规矩"的边缘样本——它们被分对了，而且恰好压在间隔边界上。离边界远的样本（多数派）完全不参与决策。另一个误区：以为对偶只是为了数学漂亮。对偶形式里训练样本只以内积 xiᵀxj 出现、预测时也只算 wᵀx = ∑αiyixiᵀx——清一色的内积。这一点在 6.4 会变成核技巧的入口。

6.3软间隔：允许个别点犯错

6.1–6.2 都假设两类之间真的存在一条干净的缝。但现实数据几乎总有噪声：个别样本标错了、测歪了，硬生生插在对方阵营里。此时硬间隔的约束 yᵢ(wᵀxᵢ+b) ≥ 1 无解——整个优化问题直接崩溃。怎么办？答案很务实：允许个别样本不满足约束，但要为"不满足的程度"付费。

给每个样本一个松弛变量（Slack Variable）ξi ≥ 0，把约束放宽为 yᵢ(wᵀxᵢ+b) ≥ 1 − ξi，并在目标函数里收"罚款"：

minw,b,ξ ½‖w‖² + C·∑i=1m ξi s.t. yi(wᵀxi+b) ≥ 1 − ξi, ξi ≥ 0

这就是软间隔（Soft Margin）SVM。惩罚参数 C > 0 控制"间隔宽度"与"犯错数量"的权衡。ξi 的取值有清晰的含义：

ξi 取值含义
ξi = 0样本在间隔边界上或之外，无犯规
0 < ξi ≤ 1样本越过自己的边界，但仍在正确一侧（掉进了隔离带）
ξi > 1样本被分错（越过了分界面）

等价的另一种写法是hinge 损失（Hinge Loss）：ℓ(z) = max(0, 1 − z)，其中 z = y(wᵀx+b)。函数间隔 ≥ 1 时损失为 0；不足 1 时每差一分罚一分（线性增长）。软间隔目标就是 ½‖w‖² + C·∑ℓ(yᵢ(wᵀxᵢ+b))——"结构风险 + 经验损失"的又一个实例（呼应 Ch1）。

完整手算例：越界点该罚多少

沿用 6.1 的分界面：w = (1, 0)，b = −2（即 x₁ = 2），支持向量处函数间隔 = 1。现在加入一个新样本 (1.5, 0)，标签为负类（y = −1）——它在 x 轴上位于 1 和 2 之间，越过了负类边界 x₁ = 1，掉进了隔离带，但还没过分界面 x₁ = 2，仍被正确分类。逐步代入：

步骤计算结果
① 算 wᵀx+b1.5 − 2−0.5（符号为负 → 分对了 ✓）
② 算函数间隔 z = y(wᵀx+b)(−1)×(−0.5)0.5（< 1 → 不满足硬约束）
③ 算 ξ = max(0, 1 − z)max(0, 1 − 0.5)0.5（掉进隔离带，未分错：0<ξ≤1 ✓）
④ 计入目标函数C × 0.5C=1 罚 0.5；C=10 罚 5

若这个点再往右挪到 (2.5, 0)（越过了分界面）：z = (−1)×(0.5) = −0.5，ξ = max(0, 1−(−0.5)) = 1.5 > 1，被分错。C 的角色一目了然：C → ∞ 时任何犯规都是天价，软间隔退化为硬间隔；C 很小时罚款不痛不痒，模型宁愿牺牲几个样本也要把隔离带留宽。

💡 关键一跃

软间隔把"必须全部满足"的硬约束换成"不满足就付费"的弹性约束。hinge 损失的形状很有意思：分对了且离边界够远 → 零损失；分对了但贴太近 → 照样罚；分错了 → 罚得更狠，且越错越罚（线性）。它与 Ch3 对率回归的对数损失对比鲜明：logistic loss 对所有样本都有非零"唠叨"，hinge 损失对安全样本完全沉默——这正是 SVM 解稀疏（只依赖支持向量）在损失函数层面的镜像。

⚠️ 常见误区

误区一：以为 ξ 大 = 分错。ξ > 1 才分错；0 < ξ ≤ 1 是分对了但掉进了隔离带（如上面 ξ=0.5 的例子）。误区二：以为 C 越大越好。C 大 → 模型对每个训练样本的犯规都锱铢必较 → 隔离带被压窄 → 对噪声过拟合；C 小 → 容忍犯规 → 间隔宽但训练误差上升。C 是偏差-方差旋钮，必须用交叉验证调，不是越大越好。

6.4核技巧：把非线性问题抬高维度

软间隔解决了"个别点越界"，但还有更根本的失败：有些数据本质上就不是线性可分的。经典反例是异或（XOR）：四个点 (0,0)、(1,1) 为正类，(0,1)、(1,0) 为负类——平面上任何一条直线都无法把它们分开（第 5 章用隐层解决了它）。SVM 的答案不是加层，而是换空间：把样本映射到更高维的特征空间 φ(x)，让数据在那里变得线性可分，然后在新空间里跑标准的线性 SVM。

问题来了：高维映射后，6.2 的对偶问题和预测式里的内积都变成 φ(xᵢ)ᵀφ(xⱼ)，维度一高（甚至无穷维）根本算不动。核技巧（Kernel Trick）的观察是：算法从头到尾只需要内积，不需要映射本身。于是定义核函数（Kernel Function）：

K(x, z) = φ(x)ᵀφ(z)

只要一个二元函数 K 恰好等于"某个映射后的内积"，我们就可以直接在原空间算 K，效果等价于先映射再算内积——绕开了显式构造 φ。这叫"核函数免显式映射"。

完整手算例：验证 K(x,z) = (xᵀz)² 是一个核

取二维映射 φ(x₁,x₂) = (x₁², x₂², √2·x₁x₂)。我们验证：先算内积再平方 与 先映射再算内积，结果必须一致。取 x = (1, 2)，z = (3, 4)：

路径计算结果
① 原空间：xᵀz1×3 + 2×4 = 3 + 811
② 平方：K = (xᵀz)²11²121
③ 显式映射 φ(x)(1², 2², √2×1×2)(1, 4, 2√2)
④ 显式映射 φ(z)(3², 4², √2×3×4)(9, 16, 12√2)
⑤ 高维内积 φ(x)ᵀφ(z)1×9 + 4×16 + (2√2)×(12√2) = 9 + 64 + 48121 ✓

两条路径殊途同归：121 = 121 ✓。（注意第⑤步 (2√2)(12√2) = 24×2 = 48。）也就是说，算一次二二维内积再平方（约 3 次乘法），就等于在三维空间里做完整内积——映射维度越高，这个"偷步"省得越多。对 XOR 四点，这个 φ 恰好让它们在高维线性可分：正类 (0,0)、(1,1) 的交叉项 x₁x₂ 分别为 0、1，负类 (0,1)、(1,0) 的交叉项都是 0——映射后沿 x₁x₂ 这一维一刀切即可。

常用核函数（"常用核"几乎就是背这三行）：

核名称表达式参数一句话直觉
线性核（Linear Kernel）K(x,z) = xᵀz无不做映射，就是普通线性 SVM；高维稀疏数据（如文本）的首选起点
多项式核（Polynomial Kernel）K(x,z) = (xᵀz)d次数 d ≥ 1显式引入特征交叉项；d=2 即上面手算的映射，d 越大边界越弯
高斯核 / RBF 核（Radial Basis Function）K(x,z) = exp(−‖x−z‖² / (2σ²))（常写 exp(−γ‖x−z‖²)）带宽 σ（或 γ=1/(2σ²)）"相似度随距离指数衰减"；等效于无穷维映射，表达力最强、最常用
💡 关键一跃

核技巧的本质是偷换"相似度"的定义：内积 xᵀz 是原空间的一种相似度，核函数 K(x,z) 是某个（可能无穷维的）特征空间里的相似度。SVM 的对偶形式和预测式里只有内积，所以把内积整个换成核函数，算法一行不改，就获得了在那个高维空间里工作的能力——复杂度按原空间付账，表达力按高维空间收钱。这也是 6.2 为什么要强调"解只以内积出现"。

⚠️ 常见误区

误区一：以为核函数是"随便一个相似度函数"。不是——K 必须能写成某映射的内积 φ(x)ᵀφ(z)（ Mercer 条件：核矩阵半正定），否则对偶问题不再是凸的，整套理论失效。误区二：以为 RBF 核参数 γ 越大越灵活越好。γ 大 → 相似度衰减极快 → 每个样本只影响自己周围一小圈 → 边界贴着训练点打转，过拟合。γ 和 C 一样，要用交叉验证调。

6.5软间隔 + 核的实战观与 SVM 复盘

6.1–6.4 把 SVM 的两块拼图备齐了：软间隔对付噪声，核技巧对付非线性。实战中的 SVM 几乎总是两者合体：min ½‖w‖² + C·∑ξi，样本以 K(xᵢ,xⱼ) 的形式出现。剩下的问题是工程性的：核怎么选？参数怎么调？

核选择的经验法则（顺序有讲究）：

情形推荐理由
先试线性核最便宜、最不易过拟合；很多任务（尤其高维）线性就够
样本少、特征多（如文本，特征数万维）线性核或高斯核高维空间中数据天然稀疏易分，复杂映射容易过拟合
样本多、特征少、边界明显弯曲高斯核（RBF）表达力最强，等效无穷维，能雕出任意形状的边界
已知问题有明确的多项式交互结构多项式核把领域知识直接编码进核

调参：C（软间隔的罚款力度）与核参数（RBF 的 γ、多项式的 d）一起决定模型复杂度，标准做法是网格搜索（Grid Search）配交叉验证：在 (C, γ) 的对数网格（如 C ∈ {0.1, 1, 10, 100}，γ ∈ {0.01, 0.1, 1, 10}）上逐点做 k 折交叉验证，选验证精度最高的组合。调参顺序的经验：先固定一个中等 γ 粗调 C 找到量级，再细调 γ，最后联合微调。

回归变体一句话：同一套思想换个损失就是 支持向量回归（Support Vector Regression, SVR）：不惩罚"掉进隔离带"，而是定义一条 ε 宽的"间隔带"，带内误差为零、带外才计线性损失，同样可用核技巧——间隔思想从分类平移到了回归。

与第 3 章对率回归的正面对比：

维度SVM（本章）对率回归（Ch3）
关心谁只关心压在间隔边界上的少数支持向量所有样本都贡献梯度（logistic loss 永不为 0）
输出硬分类符号 sign(wᵀx+b)，不输出概率天然输出后验概率 p(y|x)
非线性手段核技巧（不增参数个数的升维）特征工程，或交给神经网络（Ch5）
优化问题凸二次规划，全局唯一最优凸优化，全局唯一最优
💡 关键一跃

SVM 的实战心法可以压成三句话：先试线性核；不行换 RBF；(C, γ) 用网格搜。它的独门优势是"小样本科班出身"：解只依赖支持向量，样本量不大、特征维度高（文本、生物信息）时，泛化往往好于更需要数据喂养的神经网络。

⚠️ 常见误区

误区：把 SVM 的输出当概率用。SVM 原生输出的是到分界面的带符号距离 wᵀx+b，不是概率：sign 给出类别，但 |wᵀx+b| 大不等于"把握大"的概率化度量。需要概率输出时要做额外的校准（如 Platt 缩放，用逻辑回归把距离映射成概率），不能直接把分数 sigmoid 一压就当概率。需要天然概率的场景，回 Ch3 用对率回归或等 Ch7 贝叶斯方法。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
几何间隔（Geometric Margin）
点击翻面 →
定义点到超平面的真实欧氏距离（带符号）：y(wᵀx+b)/‖w‖；训练集间隔 = 所有样本几何间隔的最小值，规范化后总宽度 2/‖w‖。
解决问题函数间隔随 w,b 缩放而变，无法客观度量"离边界多远"；几何间隔缩放不变。
直觉两类之间的"隔离带"宽度，越宽越稳。
误区把函数间隔当距离——函数间隔只负责符号对不对。
何时用Ch12 计算学习理论：间隔大小直接进入泛化误差界。
概念卡 2
支持向量（Support Vector）
点击翻面 →
定义恰好压在间隔边界上的样本（y(wᵀx+b)=1，对应 αᵢ>0），w = Σαᵢyᵢxᵢ 中只有它们系数非零。
解决问题让分界面只由少数关键点决定，模型对远离边界的样本增删免疫。
直觉撑起隔离带的几根"桩子"，其余样本都是看客。
误区以为是"最难分的坏样本"——它们恰恰是被分对的边缘样本。
何时用预测只需支持向量（快）；Ch12 泛化界与支持向量数量相关。
概念卡 3
对偶问题（Dual Problem）
点击翻面 →
定义对每条约束引入乘子 αᵢ≥0，先对 w,b 求极小后得到的只关于 α 的等价优化问题。
解决问题暴露两件事：解 w=Σαᵢyᵢxᵢ 只依赖支持向量；样本只以内积形式出现。
直觉把"约束难处理"换成"给每个样本发工资（α），边界外的工资为零"。
误区以为只是数学技巧——它是核技巧能成立的前提。
何时用6.4 核技巧直接改对偶式里的内积；KKT 条件是支持向量的判据。
概念卡 4
hinge 损失与软间隔（Hinge Loss / Soft Margin）
点击翻面 →
定义ℓ(z)=max(0,1−z)；软间隔 = min ½‖w‖² + C·Σξᵢ，允许约束被违反但按量罚款。
解决问题现实数据有噪声、线性不可分时硬间隔无解；软间隔让问题总有解。
直觉隔离带内犯规收罚款，C 是罚款单价。
误区ξ>0 不等于分错；C 不是越大越好（过拟合）。
何时用几乎所有实际 SVM 都是软间隔；C 是交叉验证的头号调参对象。
概念卡 5
核函数（Kernel Function）
点击翻面 →
定义K(x,z)=φ(x)ᵀφ(z)：在原空间直接计算、效果等于某高维映射后内积的二元函数。
解决问题高维（甚至无穷维）映射算不动；核技巧绕开显式映射获得非线性。
直觉偷换"相似度"的定义：复杂度按原空间付账，表达力按高维收钱。
误区不是任意相似度都行——必须满足 Mercer 条件（核矩阵半正定）。
何时用一切"算法里只有内积"的模型都可核化（SVM、核 PCA 等）。
概念卡 6
RBF 核 / 高斯核（Radial Basis Function Kernel）
点击翻面 →
定义K(x,z)=exp(−‖x−z‖²/(2σ²))，常写 exp(−γ‖x−z‖²)，γ=1/(2σ²)。
解决问题等效无穷维映射，表达力最强，是线性核不够时的默认替补。
直觉相似度随距离指数衰减；σ 控制"影响圈"半径。
误区γ 越大越好——γ 太大每个点只管自己脚下一小圈，严重过拟合。
何时用样本多、特征少、边界弯曲的低维问题；与 C 一起做网格搜索。

📝分层习题

L1 概念辨析

判断对错并说明理由：①"把训练集中所有非支持向量删掉，重新训练，最优分界面不变。"②"把训练集中一个支持向量挪远一点点，最优分界面不变。"

提示

想想 w = Σαᵢyᵢxᵢ 中哪些系数非零；支持向量的定义是"恰好压在边界上"，挪动它会发生什么？

完整解答

① 对。非支持向量 αᵢ = 0，对 w = Σαᵢyᵢxᵢ 毫无贡献；删掉它们后 KKT 条件的解不变，分界面纹丝不动（这正是解的稀疏性）。

② 错。支持向量恰好满足 y(wᵀx+b)=1，是决定分界面位置/方向的"桩子"。挪远一点点，原来的边界就不再是最大间隔边界，重新求解后分界面会跟着动（通常在两条边界都变宽的方向上偏移）。为什么易错：以为"挪一点点"无所谓——支持向量没有"一点点"的余地，它们就钉在边界上，动桩子就动墙。

L1 概念辨析

选择：以下关于核函数的说法，哪个正确？A. 任何二元对称函数都能当核函数；B. 核函数必须先显式写出映射 φ 才能使用；C. K(x,z) 必须等于某个映射后的内积（核矩阵半正定），使用时不需显式映射；D. RBF 核的 γ 越大，模型越不容易过拟合。

提示

回忆 Mercer 条件，以及核技巧"免显式映射"的含义。

完整解答

C 正确。核函数必须能写成 K(x,z)=φ(x)ᵀφ(z)（等价于任意数据集上的核矩阵半正定），否则对偶问题失去凸性；但使用时直接算 K 即可，无需构造 φ——这正是"免显式映射"。

为什么其他错：A 错在"任何"——不满足半正定的函数会让优化问题非凸、理论失效；B 与核技巧的初衷完全相反（能显式映射就不需要核了）；D 说反了——γ 越大，相似度衰减越快，模型只信任紧邻样本，越容易过拟合。

L2 手算推导

训练集：负类 (−1, 0)、(0, 0)；正类 (2, 0)、(3, 0)。手算：①最优分界面方程；②w 与 b；③总间隔；④支持向量，并逐点验证支持向量满足 wᵀx+b = ±1。

提示

先找负类最右点与正类最左点，"最中间"就是缝隙中点；再按"支持向量处函数间隔 = 1"的规范化写出 w、b。

完整解答

① 负类最右点 (0, 0)，正类最左点 (2, 0)，缝隙 x₁ ∈ (0, 2)，中点 x₁ = 1，即分界面方程 x₁ = 1。

② 规范化取 w = (1, 0)，b = −1：wᵀx+b = x₁ − 1 = 0 ⟺ x₁ = 1 ✓。

③ 逐点验证：负类 (0,0)：x₁−1 = −1，y(wᵀx+b) = (−1)(−1) = 1 ✓ 恰在边界上；正类 (2,0)：x₁−1 = +1，y(wᵀx+b) = (+1)(+1) = 1 ✓ 恰在边界上。外围点 (−1,0)：x₁−1 = −2，y·(−2) = 2 > 1；(3,0)：x₁−1 = 2，y·2 = 2 > 1，均在边界外。

④ ‖w‖ = 1，总间隔 = 2/‖w‖ = 2（每侧 1，即 x₁=0 到 x₁=2 的宽度）。支持向量 = (0, 0) 与 (2, 0)，它们满足 wᵀx+b = ±1 ✓；(−1,0)、(3,0) 的 α = 0，删掉不影响结果。

L2 手算推导

验证多项式核 K(x,z) = (xᵀz)²（对应映射 φ(x₁,x₂) = (x₁², x₂², √2·x₁x₂)）：取 x = (2, 1)，z = (1, 3)，分别计算 (xᵀz)² 与 φ(x)ᵀφ(z)，确认两者相等。

提示

先算原空间内积再平方；再把两个三维映射向量写出来逐分量相乘求和。注意 (a√2)(b√2) = 2ab。

完整解答

路径一：xᵀz = 2×1 + 1×3 = 2 + 3 = 5；(xᵀz)² = 25。

路径二：φ(x) = (2², 1², √2×2×1) = (4, 1, 2√2)；φ(z) = (1², 3², √2×1×3) = (1, 9, 3√2)。

φ(x)ᵀφ(z) = 4×1 + 1×9 + (2√2)×(3√2) = 4 + 9 + 6×2 = 4 + 9 + 12 = 25 ✓。

两值相等，验证通过。原空间一次内积+一次平方（约 3 次乘法）就代替了三维空间内积——维度越高，核技巧省得越多。

L3 建模应用

两个真实场景：A. 文本垃圾邮件分类——特征为词袋/TF-IDF，上万维、高度稀疏，样本几千封；B. 二维传感器信号分类——只有 2 个特征，决策边界明显弯曲（类 XOR 形状），样本数万个。分别回答：选什么核？为什么？并说明 C 与核参数的调节顺序。

提示

对照 6.5 的核选择表：看"样本量 vs 特征维数"的比例，以及边界是否弯曲。调节顺序：先粗后细。

完整解答

场景 A：选线性核。理由：特征维数（上万）远超样本量（几千），高维稀疏空间中数据本就近乎线性可分；再用 RBF 等效升维到无穷维，容量过剩、极易过拟合，且计算昂贵。线性核 + 软间隔（调 C）通常就是此类任务的强基线。

场景 B：选 RBF 高斯核。理由：特征只有 2 维、边界明显弯曲，线性核必然欠拟合；样本数万个足以支撑 RBF 的表达力，且低维空间计算核矩阵代价可接受。

调节顺序：场景 A 只需调 C：先在对数网格 {0.01, 0.1, 1, 10, 100} 上交叉验证找到量级，再在该量级附近加密。场景 B 调 (C, γ) 组合：先固定中等 γ（如 1/特征数），粗调 C 找到量级 → 再扫 γ ∈ {0.001, 0.01, 0.1, 1} → 最后在优胜邻域内 (C, γ) 联合细调。全程用交叉验证精度说话，不看训练集表现（训练集高分恰恰是过拟合信号）。

  • C. 删除所有 αᵢ = 0 的样本
  • D. 把一个远离边界的样本改标成另一类
C 对：αᵢ=0 的样本不进入 w = Σαᵢyᵢxᵢ，删除后 KKT 解不变。A 错：支持向量钉在边界上，动它就动解。B 错：整体平移会改变最优分界面在坐标系中的位置（b 会变）——几何关系不变但"w,b 不变"不成立，题目问的是分界面，平移后分界面位置随之平移，此选项描述含混，按"不改变（原坐标系下的）分界面"判错。D 错：改标可能让该点变成新问题的边界点甚至导致不可分，解必然重算。
自测 3
某样本算得 z = y(wᵀx+b) = 0.5，它在软间隔 SVM 中：
  • A. 被分对了，但掉进了隔离带，ξ = 0.5
  • B. 被分错了，ξ = 0.5
  • C. 被分对了且在隔离带外，ξ = 0
  • D. 是分界面本身，ξ = 1
A 对：z = 0.5 > 0 说明符号对（分对），但 z < 1 说明越过了自己的间隔边界，ξ = max(0, 1−0.5) = 0.5，属于"掉进隔离带"。B 错：分错要求 z < 0（ξ > 1）。C 错：z ≥ 1 才在带外。D 错：分界面是 wᵀx+b = 0 即 z = 0，对应 ξ = 1，与本题数值不符。
自测 4
核技巧之所以对 SVM 成立，最关键的结构前提是：
  • A. SVM 的目标函数是二次的
  • B. SVM 的解是稀疏的
  • C. 核函数都很好算
  • D. 对偶问题与预测式中，训练样本只以内积形式出现
D 对：正因为算法从头到尾只需要 xᵢᵀxⱼ，才能把内积整体换成 K(xᵢ,xⱼ)=φ(xᵢ)ᵀφ(xⱼ)，实现"免显式映射"。A 错：二次性保证凸性，与核化无因果关系。B 错：稀疏性是结果不是前提，且稀疏本身不蕴含可核化。C 错："好算"是工程优点，不是理论前提——理论上 K 只需满足半正定。
自测 5
与第 3 章对率回归相比，下列说法正确的是：
  • A. SVM 天然输出概率，LR 不输出
  • B. SVM 只由边界上的支持向量决定，LR 的所有样本都参与（logistic loss 永不为 0）；SVM 原生不输出概率，需额外校准
  • C. SVM 的优化是非凸的，LR 是凸的
  • D. 高维稀疏文本数据上，RBF 核 SVM 总是优于线性核
B 对：hinge 损失对安全样本为 0 → 解稀疏；logistic loss 对所有样本非零 → 全员参与。SVM 输出带符号距离而非概率。A 说反了。C 错：两者都是凸优化，SVM 是凸二次规划。D 错："总是"必错——样本少特征多时线性核往往更稳，RBF 易过拟合。

🗣️ 用自己的话，三句话讲完本章

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：能把两类分开的分界面有无数条，SVM 要选出泛化最好的那一条；并且要解决两个现实障碍——数据有噪声（软间隔）和本质上非线性（核技巧）。
句2：核心机制是什么？——
参考答案：把分界面规范化为支持向量处函数间隔 = 1，最大化几何间隔等价于最小化 ½‖w‖²（凸二次规划）；对偶问题揭示解只依赖支持向量（KKT：αᵢ>0 ⟺ 样本在边界上）且样本只以内积出现——前者给稀疏性，后者给核技巧的入口；噪声用 hinge 损失 + C 软化，非线性用 K(x,z) 替换内积升维。
句3：它和前后章怎么分工？——
参考答案：Ch3 给出线性分界面的一种选法（最小化损失），Ch5 用隐层解决非线性；本章用"最大间隔"给出分界面的另一种选法，用"核"给出非线性的另一条路，且解由少数支持向量决定；Ch12 计算学习理论将用间隔大小解释为什么这样选泛化好。
