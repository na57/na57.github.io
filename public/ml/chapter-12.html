12.1为什么经验误差小不够：泛化误差与 PAC 学习

前面十一章里，我们让模型在训练集上把误差降到最低，然后默认"训练误差小 → 新数据上也好"。这个默认靠谱吗？一个能把训练集背下来的模型（比如一层的决策树桩记住了所有样本的噪声），经验误差可以是 0，但在新数据上可能一塌糊涂。本章的第一步，就是把这件事说严格：训练误差和真实表现之间到底差多少？

形式化：设样本空间 𝒳 上有未知分布 𝒟，目标概念（真实标记规则）为 目标概念（Target Concept）c。学习算法从假设空间（Hypothesis Space）ℋ 中挑出一个假设 h。定义两个误差：

  • 经验误差（Empirical Error）：Ê(h) = (1/m) ∑i=1m 𝟙(h(xi) ≠ yi) —— 训练集上的错误率，看得见、算得出；
  • 泛化误差（Generalization Error）：E(h) = P(x,y)∼𝒟(h(x) ≠ y) —— 在真实分布上的错误率，看不见、是随机变量。

注意：h 是从随机采样得到的训练集上学出来的，所以 h 本身是随机的，E(h) 与 Ê(h) 的差距也是随机的。我们只能谈概率保证，这正是 PAC 的名字来源：

PAC 可学习（Probably Approximately Correct Learnable）：若存在算法，对任意 0 < ε, δ < 1，只要样本数 m 足够大（m 是关于 1/ε、1/δ、问题规模的多项式），就能输出 h 使得

P( E(h) ≤ ε ) ≥ 1 − δ

则称该问题 PAC 可学习。其中 ε 是精度参数：输出"近似正确"（Approximately Correct，误差不超过 ε）；δ 是置信参数：这件事以至少 1−δ 的概率发生（Probably，允许倒霉碰到坏训练集）。若算法输出的 h 本身还要求属于 ℋ 且与训练集完全一致（即存在这样的 h，称可分（Separable）情形），并称"恰 PAC 可学习"。

有限假设空间、可分情形：样本复杂度可以"数"出来

当 ℋ 是有限集合、且目标概念 c ∈ ℋ（可分情形）时，我们能给出 m 的显式公式。推导思路（写全，不跳步）：

  1. 学习算法输出任何一个与训练集 D 完全一致的 h（所有这样的 h 构成版本空间（Version Space））。我们要排除的坏事件是："存在一个 E(h) > ε 的坏假设，却碰巧在 D 上全对"。
  2. 先固定一个坏假设 h（E(h) > ε）。它在一个随机样本上与 c 一致的概率 = 1 − E(h) < 1 − ε。
  3. 样本独立同分布，所以它在 m 个样本上全部一致的概率 < (1−ε)m。
  4. ℋ 中至多有 |ℋ| 个假设，用联合界（Union Bound）：P(存在坏假设蒙混过关) ≤ |ℋ|(1−ε)m。
  5. 利用不等式 1−x ≤ e−x，得 |ℋ|(1−ε)m ≤ |ℋ|e−mε。
  6. 令 |ℋ|e−mε ≤ δ，两边取 ln：ln|ℋ| − mε ≤ ln δ，即 mε ≥ ln|ℋ| + ln(1/δ)，解出：
m ≥ 1ε ( ln|ℋ| + ln 1δ )

手算例 1：布尔合取需要多少样本

考虑 n 个布尔变量的布尔合取（Boolean Conjunction）假设空间：每个文字可以"以正例出现"（如 x₃）、"以反例出现"（如 ¬x₃）、或"不出现"，共 3 种状态，故 |ℋ| = 3n。

取 n = 10，则 |ℋ| = 3¹⁰ = 59049。要求 ε = 0.1（误差不超过 10%）、δ = 0.05（95% 置信），代入公式逐步计算：

  1. 1/ε = 1/0.1 = 10；
  2. ln|ℋ| = ln 59049 = ln 3¹⁰ = 10 × ln 3 = 10 × 1.098612 = 10.986；
  3. ln(1/δ) = ln(1/0.05) = ln 20 = 2.996；
  4. 括号内合计 = 10.986 + 2.996 = 13.982；
  5. m ≥ 10 × 13.982 = 139.82，向上取整 m ≥ 140。

结论：只要有 140 个独立同分布的样本，任何与训练集一致的布尔合取假设，都以至少 95% 的概率保证真实误差不超过 10%。140 这个数不大——这就是"有限假设空间 + 可分"为什么是最理想的情形。

💡 关键一跃

样本复杂度公式在做一件事：用样本把坏假设逐个"枪毙"。每个样本以至少 ε 的概率杀死一个坏假设，m 个样本后漏网的概率随 e−mε 指数衰减；假设空间越大（ln|ℋ| 越大），要枪毙的坏假设越多，需要的子弹（样本）也越多。ln|ℋ| 就是"假设空间的描述长度"——用多少比特能编号一个假设。

⚠️ 常见误区

误区一："经验误差为 0 就等于泛化误差为 0"。错——经验误差为 0 只说明 h 在这 m 个点上蒙对了，PAC 界告诉你的正是"蒙对"和"真对"之间的概率关系。
误区二："δ 是模型的错误率"。错——ε 才约束错误率；δ 是"拿到一个坏训练集"的倒霉概率。P(E(h)≤ε) ≥ 1−δ 里，随机性来自训练集的抽样，不来自数据本身。

12.2目标概念不在空间里怎么办：不可分情形与 Hoeffding

上一节假设目标概念 c 恰好在 ℋ 里，且训练集里存在零误差假设（可分）。现实里这两条经常都不成立：数据有噪声、真实规则比我们能表达的更复杂。这时连"经验误差为 0 的假设"都不存在，算法只能挑经验误差最小的 h（ERM，经验风险最小化）。问题变成：Ê(h) 与 E(h) 的差距能对所有 h 同时控制住吗？

工具是 Hoeffding 不等式（Hoeffding's Inequality）：对任意固定的 h，把每个样本上"h 是否犯错"看作一个 0/1 随机变量，其期望正是 E(h)，样本均值正是 Ê(h)。Hoeffding 给出

P( |E(h) − Ê(h)| ≥ ε ) ≤ 2 e−2mε²

再对全部 |ℋ| 个假设用联合界：P(存在 h 使 |E(h)−Ê(h)| ≥ ε) ≤ 2|ℋ|e−2mε²。令其 ≤ δ：ln(2|ℋ|) − 2mε² ≤ ln δ，解出不可分情形（Agnostic，又称不可知情形）的样本复杂度：

m ≥ 12ε² ( ln(2|ℋ|) + ln 1δ )

手算：同一个布尔合取问题，不可分要多少样本

仍取 |ℋ| = 59049（n = 10 的布尔合取），ε = 0.1，δ = 0.05，逐步计算：

  1. 2ε² = 2 × 0.01 = 0.02，故 1/(2ε²) = 1/0.02 = 50；
  2. 2|ℋ| = 2 × 59049 = 118098，ln(118098) = ln 2 + ln 59049 = 0.693 + 10.986 = 11.679 ≈ 11.68；
  3. ln(1/δ) = ln 20 = 2.996 ≈ 3.00；
  4. 括号内合计 = 11.68 + 3.00 = 14.68；
  5. m ≥ 50 × 14.68 = 734。

对比可分情形的 m ≥ 140：同样的问题，仅仅因为"目标可能不在 ℋ 里、只能用 ERM"，样本需求从 140 涨到 734，约 5 倍。

💡 关键一跃

看 m 对 ε 的依赖：可分情形 m = O(1/ε)，不可分情形 m = O(1/ε²)。为什么更贵？可分情形里，一个坏假设每个样本以 ≥ ε 的概率"自爆"，淘汰是乘法的（指数衰减）；不可分情形里没有完美的假设可以对照，只能靠大数定律让 Ê(h) 收敛到 E(h)，而集中不等式的收敛速度是 1/√m——要精度高 10 倍，样本就得多 100 倍。这就是"1/ε²"的来源。

⚠️ 常见误区

"样本复杂度只由问题难度决定，与 |ℋ| 无关"。恰恰相反：两个公式里 |ℋ| 都直接进入对数项。同一个任务，你选的假设空间越大（哪怕表达力富余），所需的样本就越多——这是"奥卡姆剃刀"的第一个严格版本：在能拟合数据的前提下，选更小的假设空间。

12.3假设空间无限大怎么办：VC 维

前两节的公式都含 ln|ℋ|，可一旦 ℋ 无限——比如"实轴上所有区间 [a,b]"，a、b 取遍全体实数，|ℋ| = ∞——联合界直接失效。但直觉告诉我们：实轴区间族其实"很简单"，不该因为无限就不可学。问题出在我们用"个数"度量容量太粗糙。需要的是一把能度量无限空间有效容量的尺子。

这把尺子从"能对样本造成多少种不同的标记方式"出发。给定 m 个样本 {x₁,…,xm}，ℋ 中每个 h 给它们打出一套 ±1 标记；所有 h 能产生的不同标记方案数记为 增长函数（Growth Function）Πℋ(m)，显然 Πℋ(m) ≤ 2m。若某个 m 点集合上 Πℋ(m) = 2m（即所有 2m 种标记方案都能被 ℋ 中某个 h 实现），则称 ℋ 打散（Shatter）了这个集合。

VC 维（Vapnik-Chervonenkis Dimension）：ℋ 能打散的最大集合的大小，记 dVC(ℋ)。即：存在 dVC 个点能被任意标记方式实现，而任何 dVC+1 个点都存在实现不了的标记。

判定示例 1：实轴上的区间族，VC 维 = 2

ℋ = { 所有形如 [a,b] 的区间 }，规则：x ∈ [a,b] 标 +，否则标 −。

  1. 能打散 2 个点：任取 x₁ < x₂，四种标记都可行——(+,+)：取区间罩住两点；(−,−)：取区间避开两点；(+,−)：取区间只罩 x₁（如 [x₁, (x₁+x₂)/2]）；(−,+)：取区间只罩 x₂。故 VC ≥ 2。
  2. 打不散 3 个点：任取 x₁ < x₂ < x₃，考虑标记 (+,−,+)——要求区间同时包含 x₁ 和 x₃ 却排除 x₂。但区间是连续的一段：含 x₁ 与 x₃ 必含其间的 x₂。所以 (+,−,+) 永远无法实现。3 个点尚且如此，更多点更不行，故 VC < 3。
  3. 合起来：dVC = 2。注意 VC 维只要求"存在" d 个点能打散，不是"任意" d 个点都能打散——找一组好位置即可；而证明不能打散 d+1 个点时必须对"任意" d+1 个点成立。

判定示例 2：ℝ² 中的线性划分，VC 维 = 3；d 维超平面，VC = d+1

  • ℝ² 中任取不共线的 3 个点，8 种标记都能用一条直线分开（逐一举例：同色时直线放一侧或拿远；两正一负时直线把负点单独隔开，不共线保证做得到）。故 VC ≥ 3。
  • 任意 4 个点做不到：若四点构成凸四边形，标记"对角为正、另两角为负"（即 XOR 构型）无法用一条直线分开；若有一点在另三点内部，把内部点标负、外部三点标正也分不开。故 VC = 3。
  • 一般地，ℝd 中的超平面（线性分类器）dVC = d + 1——恰好等于"参数个数 +1"，这容易让人误以为 VC 维总等于参数个数，下面的警告框专门破除它。

有了 VC 维，无限假设空间也有了泛化界（形式之一）：

E(h) ≤ Ê(h) + √8d ln 2emd + 8 ln 4δm

（其中 d 为 VC 维，e 为自然常数，以至少 1−δ 的概率成立。）

手算例 2：这个界具体有多大

取 d = 10（如 9 维空间里的线性分类器，或粗略看作一个 10 自由度模型），m = 10000，δ = 0.05，逐项算根号里的分子：

  1. 第一项系数：8d = 8 × 10 = 80；
  2. 对数项：ln(2em/d) = ln(2e × 10000 / 10) = ln(2000e) = ln 2000 + ln e = 7.601 + 1 = 8.601；
  3. 第一项合计：80 × 8.601 = 688.1；
  4. 置信项：ln(4/δ) = ln(4/0.05) = ln 80 = 4.382，8 × 4.382 = 35.06 ≈ 35.1；
  5. 分子合计：688.1 + 35.1 = 723.2；
  6. 除以 m：723.2 / 10000 = 0.07232；
  7. 开根号：√0.07232 ≈ 0.269。

结论：E(h) ≤ Ê(h) + 0.269——以 95% 的置信度，泛化误差最多比经验误差高 26.9 个百分点。再算 m = 100000 对比：

  1. ln(2e × 100000 / 10) = ln(20000e) = ln 20000 + 1 = 9.903 + 1 = 10.903；
  2. 80 × 10.903 = 872.3；加置信项 35.1，分子 = 907.4；
  3. 907.4 / 100000 = 0.009074；√0.009074 ≈ 0.095。

样本多 10 倍，界的附加项从 0.269 缩到 0.095（约按 1/√m 收缩）。界本身很松（1 万样本只能保证 27 个点的差距，实践中往往好得多），但趋势是对的：容量 d 越大界越松，样本 m 越大界越紧。

💡 关键一跃

两个直觉。其一：VC 维 ≈ 有效自由度——不是参数个数，而是假设空间"能独立表达的判别方向"有几个。其二：泛化界是三项结构——经验项 Ê(h)（拟合得多好）+ 容量项（含 d，空间多大）+ 置信项（含 ln(1/δ)，要多稳）。训练误差往下压、容量往上顶，最优模型在两者平衡处——这就是结构风险最小化（SRM）的思想源头。

⚠️ 常见误区

"VC 维 = 参数个数"。错。反例：单参数函数族 hω(x) = sign(sin(ωx))，只有一个参数 ω，但 VC 维是无穷大——对任意 m 个点和任意标记，只要把 ω 取得足够大，正弦振荡足够密，就能让每个点落在所需的符号区间里。反过来也有参数很多但 VC 维小的例子（受正则约束的线性族）。参数个数只是一个粗略代理，VC 维度量的是"对标记方案的表达能力"。

12.4更细的容量尺子：Rademacher 复杂度与稳定性

VC 维有一个毛病：它是"最坏情形"的尺子——只要存在一组 d 个点能被打散，d 就 +1，完全不看数据分布。但现实中数据往往很"乖"，假设空间在实际数据上的有效容量远小于最坏情形。能不能让容量尺子依赖数据本身？这就是 Rademacher 复杂度（Rademacher Complexity）的出发点。

定义（经验 Rademacher 复杂度）：给定样本 S = {x₁,…,xm}，给每个样本独立地随机打一个 ±1 的"噪声标签" σi（各以 1/2 概率取 ±1），然后问：ℋ 里最好的那个假设，能把这套纯随机标签对齐到什么程度？

R̂(ℋ) = Eσ [ suph∈ℋ 1m ∑i=1m σi h(xi) ]

读法：σih(xi) = +1 表示 h 在这个点上与噪声标签一致。R̂(ℋ) 就是"ℋ 拟合纯随机噪声的期望最好成绩"。一个假设空间连噪声都能拟合得很好，说明它容量过大、容易过拟合——拟合噪声越厉害，泛化越差。VC 维回答"最坏能打散多少点"，Rademacher 复杂度回答"在这份数据上平均能蒙对多少噪声"，因此更细、且可以直接从数据估计。

用它表达的泛化界形状（0/1 损失的一种典型形式，以至少 1−δ 概率成立）：

E(h) ≤ Ê(h) + 2R̂(ℋ) + 3 √ln(2/δ)2m

同样是三项结构：经验项 + 容量项（这次是 R̂(ℋ)，可数据驱动地估计）+ 置信项（按 1/√m 收缩）。

另一条互补的线索是稳定性（Stability）：不分析假设空间多大，而是分析算法——如果换走训练集中的一个样本，学出来的模型变化很小，那么它的经验表现就接近真实表现。稳定性为正则化提供了理论解释：正则项正是让算法对单个样本不敏感，从而"稳定"，从而泛化。

本章的收尾与遗留问题：无论 VC 界还是 Rademacher 界，都是 worst-case 的保证。现代深度学习里，网络参数量远超样本数（按 VC 维的直觉早该过拟合到失控），实际却泛化得相当好——所有经典界在这种超参数化 regime 下都松得失去意义。"为什么大网络能泛化"至今是开放问题，深度学习理论仍远未完成。理论的价值此刻不在于给出精确数字，而在于给出正确的定性方向：控容量、要稳定、置信与精度不可兼得。

💡 关键一跃

三代容量尺子的进化逻辑：|ℋ|（数个数，只对有限空间有效）→ VC 维（数"能打散多少点"，对无限空间有效但只看最坏情形）→ Rademacher 复杂度（数"能拟合多少噪声"，随数据分布自适应）。尺子越来越细，共同的内核不变：容量即"能对随机性照单全收的能力"，这种能力越强，从有限样本到无限分布的外推越不可信。

⚠️ 常见误区

误区一："Rademacher 复杂度高说明模型拟合能力强，是好事"。要看场合：它衡量的是拟合噪声的能力，这正是过拟合的定义，出现在泛化界的"罚金"位置，越小越好。
误区二："理论界算出来 0.269，说明这个模型真的要比训练误差差 26.9%"。界是充分条件式的上界：保证"不会超过"，不预测"实际会是"。实践中的差距往往比界小得多——界用来比较趋势（加样本、减容量有没有用），不用来报实测值。

点击翻面 →

📝分层习题

L1 概念辨析判断正误并说明理由：①"PAC 可学习要求算法对所有可能的训练集都输出误差 ≤ ε 的假设"；②"实轴区间族的 VC 维是 2，意味着任意 2 个实数点都能被区间族打散"。
提示

① 回顾 P(E(h)≤ε) ≥ 1−δ 中随机性的来源；② 回顾 VC 维定义中"存在"与"任意"的位置。

完整解答

① 错。PAC 只要求以 ≥ 1−δ 的概率成功，允许 δ 比例的"坏运气"训练集（随机性来自抽样）。"对所有训练集都成功"要求 δ = 0，这在有限样本下一般不可能。

② 错（方向反了）。VC 维 ≥ 2 只需要"存在"一组 2 点被打散——确实任意 2 点也能打散（本题恰好成立），但 VC 维定义本身只断言存在性；真正含"任意"的是上界那半句：任意 3 点都打不散。混淆"存在/任意"是 VC 维判定里最常见的丢分点。

L1 概念辨析下列哪个函数族的 VC 维"不等于"其自由参数个数？A. ℝ² 中的线性分类器（3 个参数，VC=3）；B. 实轴区间 [a,b]（2 个参数，VC=2）；C. 单参数族 hω(x) = sign(sin(ωx))（1 个参数）；D. ℝd 超平面（d+1 个参数，VC=d+1）。
提示

回忆警告框里那个"振荡可以任意密"的反例。

完整解答

选 C。sin(ωx) 只有一个参数，但取 ω 足够大时函数在任意有限点集上都能振荡出任意指定的 ±1 模式，故 VC 维为无穷大。A、B、D 的参数个数与 VC 维恰好相等，这正是"VC 维 = 参数个数"错觉的来源——C 说明这种相等只是常见巧合，不是定理。

L2 手算推导布尔合取问题，n = 15 个布尔文字（|ℋ| = 3¹⁵），可分情形，要求 ε = 0.05、δ = 0.01。求 PAC 保证所需的样本数 m。
提示

用 m ≥ (1/ε)(ln|ℋ| + ln(1/δ))；ln(3¹⁵) = 15 ln 3，ln 3 ≈ 1.0986。

完整解答
  1. |ℋ| = 3¹⁵ = 14348907；
  2. 1/ε = 1/0.05 = 20；
  3. ln|ℋ| = ln(3¹⁵) = 15 × 1.0986 = 16.48；
  4. ln(1/δ) = ln(1/0.01) = ln 100 = 4.61；
  5. 括号合计 = 16.48 + 4.61 = 21.09；
  6. m ≥ 20 × 21.09 = 421.8，向上取整 m ≥ 422。

结论：422 个样本即可以 ≥ 99% 的概率保证任何与训练集一致的合取假设误差 ≤ 5%。与手算例 1（n=10, ε=0.1, δ=0.05 → 140）对比：ε 减半使系数 1/ε 翻倍，δ 更严使对数项略增——样本需求的主要杠杆是 ε。

L2 手算推导判定实轴上"两个区间的并"函数族 ℋ = { [a₁,b₁] ∪ [a₂,b₂] }（在任一区间内标 +）的 VC 维。写出判定思路，证明 VC = 4 的两个方向。
提示

模仿区间族 VC=2 的证明：能打散 d 点只需构造一组位置；打不散 d+1 点要对任意位置给出一个实现不了的交替标记。

完整解答

VC ≥ 4：取 x₁ < x₂ < x₃ < x₄ 四点。逐类验证 2⁴ = 16 种标记：

  • 全 −：两个区间都放到四点之外；
  • 全 +：一个区间罩住全部四点（另一个任意，如与之重合）；
  • 恰一个 +：一个区间只罩该点；
  • 恰两个 + 且相邻（++−−、−++−、−−++）：一个区间罩住这对相邻点即可；
  • 恰两个 + 且不相邻（+−+−、+−−+、−+−+）：两个区间各罩一个正点；
  • 恰三个 +（即恰一个 −）：两个区间分别罩负点左侧与右侧的正点段（如 −+++：一个区间罩 x₂x₃ 段、一个罩 x₄，或直接一个区间罩 [x₂,x₄] 而负点 x₁ 在外）。

16 种全部可实现，故 VC ≥ 4。

VC ≤ 4（任意 5 点打不散）：任取 x₁ < x₂ < x₃ < x₄ < x₅，考虑交替标记 (+,−,+,−,+)。每个标 + 的点都需要被某个区间覆盖，而每个区间是连续一段——一个区间若覆盖两个不相邻的正点，必然把中间的负点也罩进去，产生错误。因此每个区间至多覆盖"一段连续的正点"，而 (+,−,+,−,+) 的正点分成 3 段，只有 2 个区间，至少有一段罩不到。故该标记无法实现，任意 5 点打不散。

合起来 dVC = 4。规律：k 个不相交区间的并，VC 维 = 2k——交替标记 (+,−,…,+) 需要 2k+1 个点才能逼出 k+1 段正点。

L3 建模应用某医院用逻辑回归（线性分类器）做疾病辅助诊断，特征共 10 维，只收集到 200 个标注样本。请：①用本章的 VC 泛化界（δ = 0.05）估算"泛化误差 − 经验误差"的上界；②评价这个界对临床上线是否有用；③给出至少三条改进路线。
提示

10 维线性分类器 VC 维 d = 11；把 d=11、m=200、δ=0.05 代入根号项。若结果大于 1，想想这意味着什么。

完整解答

① 计算（d = 11, m = 200, δ = 0.05）：

  1. 8d = 88；
  2. ln(2em/d) = ln(2e × 200 / 11) = ln(400e/11) = ln(36.36e) = ln 36.36 + 1 = 3.593 + 1 = 4.593；
  3. 88 × 4.593 = 404.2；
  4. 置信项：8 × ln(4/0.05) = 8 × ln 80 = 8 × 4.382 = 35.1；
  5. 分子 = 404.2 + 35.1 = 439.3；439.3 / 200 = 2.196；√2.196 ≈ 1.48。

界为 E(h) ≤ Ê(h) + 1.48。误差上界超过 100%，是废话界——200 个样本对 d=11 的容量完全不够。

② 评价：这个界对临床上线没有任何背书作用。若想让附加项 ≤ 0.1，试 m = 100000：ln(2e×10⁵/11) = ln(18181.8e) ≈ 9.808 + 1 = 10.808；88 × 10.808 + 35.1 = 986.2；986.2/10⁵ = 0.00986，√ ≈ 0.0993。即需要约 10 万样本级别——远超医院现有数据。理论在此的价值恰恰是提前喊出"数据不够"，而不是事后补救。

③ 改进路线：（a）压容量——用第11章的特征选择把 10 维降到 3–4 维（d 从 11 降到 4–5），根号项分子近似按比例缩小；（b）加正则/限模——L2 正则、限制范数可降低有效容量（稳定性视角），同样缩小容量项；（c）增样本——第13章半监督学习利用大量未标注病例；（d）换更细的尺子——用 Rademacher 复杂度在这 200 个真实样本上估计数据依赖的界，通常远紧于 VC 界；（e）降置信或精度要求（如 δ=0.1）只能微调 ln 项，救不了量级，不应作为主路线。

句2：核心机制是什么？——
参考答案：用假设空间的容量换置信——有限空间用 |ℋ|（联合界 + Hoeffding），无限空间用 VC 维（打散/增长函数），更细的用 Rademacher 复杂度；统一形式是"泛化误差 ≤ 经验误差 + 容量项 + 置信项"，样本 m 按 1/√m 或更快压住后两项。
句3：它和前后章怎么分工？——
参考答案：前十一章教"怎么学"，本章教"学出来的信不信得过、要多少数据"；第11章的特征选择、正则化在这里获得理论解释（压容量、增稳定），第13章半监督学习则在本章揭示的"样本不够"困境下给出出路。
