9.1没有标签，凭什么分组：先把"相似"定义出来

前八章的每个样本都写成 (x, y)，标签 y 是老师；本章把老师撤走，手里只剩样本集 D = {x₁, x₂, …, x_m}。聚类（Clustering）要做的，是把 D 分成 k 个互不相交的簇 {C₁, C₂, …, C_k}，希望同一簇里的点彼此相似、不同簇的点彼此不相似。但"相似"不是一个客观存在的东西——它必须先被定义，而定义的工具就是距离度量（Distance Measure）。

距离度量的四条公理

一个函数 dist(·,·) 能叫"距离"，必须满足四条基本性质：

公理数学表述一句话含义
非负性dist(xᵢ, xⱼ) ≥ 0距离不能是负数
同一性dist(xᵢ, xⱼ) = 0 当且仅当 xᵢ = xⱼ距离为 0 只因为自己跟自己
对称性dist(xᵢ, xⱼ) = dist(xⱼ, xᵢ)A 到 B 与 B 到 A 一样远
直递性dist(xᵢ, xⱼ) ≤ dist(xᵢ, xₖ) + dist(xₖ, xⱼ)三角不等式：抄近路不会更远

闵可夫斯基距离：一个参数 p 装下一族距离

对 n 维连续属性，最常用的是闵可夫斯基距离（Minkowski Distance）：

dist(xᵢ, xⱼ) = ( ∑u=1n |xiu − xju|p )1/p

参数 p 取不同值就得到不同的"远近观"。用两个点 A = (1, 2)、B = (4, 6) 各算一遍（坐标差为 3 和 4）：

p名称代入计算结果
p = 1曼哈顿距离（Manhattan Distance）|1−4| + |2−6| = 3 + 47
p = 2欧氏距离（Euclidean Distance）√(3² + 4²) = √(9 + 16) = √255
p → ∞切比雪夫距离（Chebyshev Distance）max(3, 4)（只取最大的坐标差）4

同一对点，三种距离给出 7、5、4 三个答案——"多远"取决于你选哪把尺子。直觉上：p=1 像在街区里沿马路走，p=2 是直线飞行，p=∞ 只看差距最大的那个维度（像国际象棋里王的最少步数）。

属性不都是连续数

连续属性（身高、价格）可以直接做减法，称为有序属性（Ordinal / Numerical Attribute）；而颜色、国籍这类无序属性（Nominal Attribute）不能相减——"红色 − 蓝色"没有意义。对无序属性常用 VDM（Value Difference Metric）：按两个取值在各类别上的分布差异来定义距离，分布越像距离越小；混合属性则把两类距离加权合并（MinkowskiDM）。细节知道"有这套办法"即可，本章后面都假设属性已转成可减的连续数。

💡 关键一跃

距离度量是聚类的"宪法"：先立宪（选定 dist），再分组（一切算法都在这把尺子下运作）。换一把尺子，"谁和谁像"就全变了，后面任何算法给出的簇也随之改变。

⚠️ 常见误区

"距离是数据的客观属性"——错。距离是你选的假设。最隐蔽的坑是量纲：一个属性取值 0~100000、另一个 0~1，欧氏距离几乎完全被前者主导。聚类前通常要做归一化（min-max 或 z-score），否则"相似"被一个属性绑架。

9.2分得好不好谁说了算：外部指标与内部指标

上一节定义了"相似"，但它立刻带出一个尴尬问题：聚类没有标签，也就没有标准答案——分完一堆簇，凭什么说分得好？性能度量（Performance Measure）分两种处境：手里恰好有一份参考划分时，用外部指标（External Index）"对答案"；什么都没有时（这才是常态），用内部指标（Internal Index）"看体型"。

外部指标：把样本两两配对，数四种情况

设参考划分为 S，聚类结果为 C。遍历全部 m(m−1)/2 个样本对，按"在 C 里同不同簇 × 在 S 里同不同类"数四个计数：

计数含义名字
a在 C 中同簇，且在 S 中同类同-同（都对）
b在 C 中同簇，但在 S 中不同类同-异（误并）
c在 C 中不同簇，但在 S 中同类异-同（误拆）
d在 C 中不同簇，且在 S 中不同类异-异（都对）
a + b + c + d = m(m−1)2，JC = aa + b + c，FM = √( aa + b · aa + c )，RI = 2(a + d)m(m − 1)

三个指数都在 [0, 1] 内、越大越好：Jaccard 系数（Jaccard Coefficient）只认"同簇且同类"的样本对占所有"至少一边同"的比例；FM 指数（Fowlkes–Mallows Index）是查准与查回的几何平均；Rand 指数（Rand Index）把"双双不同"的 d 也算作得分。

完整手算：6 个样本、两簇、有参考划分

样本 x₁…x₆。参考划分 S：{x₁, x₂, x₃} 与 {x₄, x₅, x₆}；聚类结果 C：{x₁, x₂, x₄} 与 {x₃, x₅, x₆}。共 6×5/2 = 15 个样本对。

第一步：列出两边各自的"同"对。在 C 中同簇的对有 6 个：(1,2)、(1,4)、(2,4)、(3,5)、(3,6)、(5,6)；在 S 中同类的对也有 6 个：(1,2)、(1,3)、(2,3)、(4,5)、(4,6)、(5,6)。

第二步：数四个计数。

计数数法值
a（C同 且 S同）两列的交集：{(1,2), (5,6)}2
b（C同 但 S异）C 同簇对去掉交集：{(1,4), (2,4), (3,5), (3,6)}4
c（C异 但 S同）S 同类对去掉交集：{(1,3), (2,3), (4,5), (4,6)}4
d（C异 且 S异）15 − 2 − 4 − 45

第三步：代入公式。

JC = 22 + 4 + 4 = 210 = 0.2　　FM = √( 26 · 26 ) = 13 ≈ 0.333　　RI = 2 × (2 + 5)6 × 5 = 1430 ≈ 0.467

三个数差异很大（0.2 vs 0.47）：JC 对误并、误拆都敏感所以最苛刻；RI 把 5 对"双双不同"也算分，所以最宽松。报指标时必须说是哪一个。

内部指标：没有答案可看，就看"体型"

没有参考划分时，总原则只有一句话：簇内要紧，簇间要松。定义四个辅助量：avg(C) 簇内平均距离、diam(C) 簇内最远点对距离、d_min(Cᵢ, Cⱼ) 两簇最近点对距离、d_cen(μᵢ, μⱼ) 两簇中心距离。两个代表：

DB 指数 = 1k ∑i=1k maxj≠i ( avg(Cᵢ) + avg(Cⱼ)d_cen(μᵢ, μⱼ) )　　DB 指数（Davies–Bouldin Index）越小越好
Dunn 指数 = mini≠j { d_min(Cᵢ, Cⱼ)maxl diam(Cl) }　　Dunn 指数（Dunn Index）越大越好

直觉：DB 用"簇内胖瘦之和 ÷ 中心距离"衡量两个簇有多难分开，取最糟糕的一对再平均，所以越小越好；Dunn 用"最近簇间距 ÷ 最胖簇直径"衡量最不利的分离度，所以越大越好。方向相反，别记反。

💡 关键一跃

外部指标是"对答案"（需要参考划分，只在评测算法时用得上）；内部指标是"看体型"（不需要任何标签，是真实场景里唯一可用的裁判）。两者的灵魂是同一条：簇内紧、簇间松。

⚠️ 常见误区

"Rand 指数 0.8 就说明聚类好"——不一定。RI 的分子里 d（双双不同）通常占大头，参考划分越碎、d 越多，随便聚类也能刷出高 RI；而且 RI 没有减去"随机划分也能拿到的基线分"。严谨报告常用做过随机校正的 ARI（Adjusted Rand Index），或干脆同时报 JC 与 FM。

9.3原型聚类 k-means：假设簇是一团球

评价有了裁判，现在进入算法。第一条路线假设：每个簇都是一团"球"，球心是一个原型（Prototype）——簇的均值向量 μᵢ。这就是 k-means（k 均值）：给定簇数 k，把划分做到让平方误差（Sum of Squared Errors）最小：

E = ∑i=1k ∑x∈Cᵢ ‖x − μᵢ‖²，其中 μᵢ = 1|Cᵢ| ∑x∈Cᵢ x

E 越小，各点离自己簇中心越近，"簇内紧"。直接枚举所有划分是 NP 难的，k-means 用贪心迭代逼近：① 初始化 k 个中心；② 分配：每个点归入离它最近的中心所在簇；③ 更新：每个簇重算均值作为新中心；④ 重复 ②③，直到中心（或划分）不再变化。②固定中心优化分配、③固定分配优化中心，每一步都让 E 不增，而划分方案有限，所以必然在有限步内停（停在局部极小）。

完整手算：6 个点、k=2、指定初始中心，跑一轮迭代

样本：P₁=(1,1)，P₂=(2,1)，P₃=(1,2)，P₄=(6,4)，P₅=(7,5)，P₆=(6,5)。取初始中心 μ₁ = (1,1)（即 P₁）、μ₂ = (6,4)（即 P₄）。

第一步：逐点算到两个中心的欧氏距离（列出精确根式与小数）：

点d(·, μ₁=(1,1))d(·, μ₂=(6,4))分配
P₁=(1,1)0√(25+9) = √34 ≈ 5.831C₁
P₂=(2,1)1√(16+9) = √25 = 5C₁
P₃=(1,2)1√(25+4) = √29 ≈ 5.385C₁
P₄=(6,4)√(25+9) = √34 ≈ 5.8310C₂
P₅=(7,5)√(36+16) = √52 = 2√13 ≈ 7.211√(1+1) = √2 ≈ 1.414C₂
P₆=(6,5)√(25+16) = √41 ≈ 6.403√(0+1) = 1C₂

第二步：分配。C₁ = {P₁, P₂, P₃}，C₂ = {P₄, P₅, P₆}。

第三步：重算中心（各坐标取均值）。

μ₁′ = ( 1+2+13, 1+1+23 ) = ( 43, 43 ) ≈ (1.333, 1.333)　　μ₂′ = ( 6+7+63, 4+5+53 ) = ( 193, 143 ) ≈ (6.333, 4.667)

此时平方误差 E = 4/3 + 4/3 = 83 ≈ 2.667（每个簇内三项贡献分别为 2/9、5/9、5/9）。

第四步：再迭代一轮。对新中心重算全部距离：P₁ 距 μ₁′ 为 √2/3 ≈ 0.471，P₂、P₃ 各为 √5/3 ≈ 0.745；P₄、P₅ 距 μ₂′ 各为 √5/3 ≈ 0.745，P₆ 为 √2/3 ≈ 0.471——所有点归属不变，中心也不再移动，停止。这就是 k-means 的停止条件：中心不再变化（实际工程里也常用"变化小于阈值"或"达到最大轮数"提前停）。

初始化不是小事：k-means++

上面的例子故意把初始中心选在两头；若两个初始中心挤在同一团里，迭代会收敛到很差的局部极小。k-means++ 的改进只有一句话：选初始中心时让"离已选中心越远的点越优先被选中"，把 k 个种子尽量撒开，再跑标准迭代。

💡 关键一跃

k-means 是"选举—改选"循环：先按现任中心给所有点划分选区，再按选区重选中心，直到没人想换区。它隐含的簇假设是：每个簇是以均值为中心的球（各向同性、大小相近）。

⚠️ 常见误区

"k-means 收敛了，所以找到了最优划分"——错。E 对划分而言非凸，迭代只保证 E 单调不增并停在局部极小，不同初始中心可能给出完全不同的结果。实践上多换几组初始化（或用 k-means++）取 E 最小的一次；k 本身也要外部给定，算法不会替你发现"该分几簇"。

9.4密度聚类 DBSCAN：假设簇是连片的稠密区

k-means 的球假设一旦不成立——比如数据呈月牙形、环形，或混着离群点——分出来的簇就面目全非。第二条路线换假设：簇不是"离某个中心近"，而是连片的稠密区域，簇之间由稀疏地带隔开。这就是 DBSCAN（Density-Based Spatial Clustering of Applications with Noise），它只问一个问题：每个点身边有没有足够多的邻居？

五个核心概念

给定两个参数：邻域半径 ε 和密度阈值 MinPts。

概念定义
ε-邻域（ε-Neighborhood）N_ε(x) = { xⱼ ∈ D | dist(x, xⱼ) ≤ ε }（含 x 自身）
核心对象（Core Object）|N_ε(x)| ≥ MinPts 的点
边界点（Border Point）自身非核心，但落在某个核心点的 ε-邻域内
噪声点（Noise Point）既不是核心点也不是边界点
密度直达 / 可达 / 相连密度直达（Directly Density-Reachable）：xⱼ 在核心点 xᵢ 的邻域内；密度可达（Density-Reachable）：存在核心点链把两点串起来；密度相连（Density-Connected）：两点被同一个核心点可达

算法一句话：任取一个未访问的核心点，从它出发把所有密度可达的点收成一个簇；再找下一个未访问核心点，直到核心点用尽。剩下的非核心点若能挂靠到某簇核心点邻域内就是边界点，否则是噪声。

完整手算：10 个点、ε = 1.5、MinPts = 3

对比 k-means 就能看出 DBSCAN 的两个长处：不用预先定 k（簇数由密度结构自己冒出来）；能发现非球形簇（只要稠密片连续，月牙、环形都照收），而且噪声点会被明确标记而不是硬塞进某个簇。代价是参数敏感：ε 太小则一大片被判成噪声，太大则所有簇连成一团；数据密度不均匀时，一组 (ε, MinPts) 很难两头兼顾。

💡 关键一跃

k-means 问"你离哪个球心近"，DBSCAN 问"你身边邻居够不够多、你连着谁"。前者产出 k 个球，后者产出任意形状的稠密片加一份噪声名单——簇假设不同，同一份数据的分法就不同。

⚠️ 常见误区

"|N_ε(x)| 不数 x 自己"——错，邻域含自身，MinPts 的计数包含自己（所以本例 MinPts=3 时 x₇ 恰好达标）。另一个高频错误是认为"边界点可以同时属于两个簇"：若它同时落在两簇核心点的邻域内，那两簇经由它密度相连，本应合并成一簇——所以一个边界点恰好属于一个簇。

9.5层次聚类 AGNES 与高斯混合模型：从硬划分到软分配

前两条路线都把数据拍平成一层簇，层次关系（小簇套大簇）看不见；而且每个点"非此即彼"，叫硬分配。本节做两件事：先用 AGNES（AGglomerative NESting，凝聚式层次聚类）把"谁在什么距离上合并"的历史完整保留下来，再用高斯混合模型（Gaussian Mixture Model, GMM）把硬分配软化成概率。

高斯混合模型：把"属于"换成"有多大概率属于"

换个概率视角看聚类：假设数据由 k 个高斯分布混合生成，每个点先以概率 αᵢ 抽中第 i 个成分，再从 𝒩(μᵢ, Σᵢ) 中采样：

p(x) = ∑i=1k αᵢ · 𝒩(x | μᵢ, Σᵢ)，αᵢ > 0 且 ∑i αᵢ = 1

参数 {αᵢ, μᵢ, Σᵢ} 用第 7 章见过的 EM 算法（Expectation-Maximization）迭代求解，直觉是两步循环：E 步——用当前参数算每个点属于第 i 个成分的后验概率（隶属度）：

γ(x, i) = αᵢ · 𝒩(x | μᵢ, Σᵢ)∑j=1k αⱼ · 𝒩(x | μⱼ, Σⱼ)

M 步——用 γ 作权重重估参数：μᵢ = ∑γ(x,i)·x / ∑γ(x,i)（加权均值），αᵢ = ∑γ(x,i) / m，Σᵢ 取加权协方差。来回迭代直到对数似然不再上升。

GMM 与 k-means 的关系：软化的极限就是硬化

对照k-meansGMM
分配方式硬分配（Hard Assignment）：每点恰属一簇软分配（Soft Assignment）：每点对各簇有隶属度 γ，Σᵢ γ = 1
簇的形状球（到中心等距即同簇）椭球（协方差 Σᵢ 控制方向与胖瘦）
中心更新簇内算术均值按 γ 加权的均值
求解分配—更新交替EM 的 E—M 交替

深刻的一句：k-means 是 GMM 的退化情形。令各成分协方差都收缩为同一个标量矩阵 σ²I 且 σ² → 0，同时各混合系数相等（αᵢ = 1/k），则后验 γ(x, i) 变成"离哪个中心最近就取 1、其余全 0"——软分配被挤成硬分配，EM 的 E 步退化为 k-means 的分配步、M 步退化为重算均值。所以 9.3 说"k-means 假设簇是球"，在 GMM 语言里就是"等协方差、等权重、方差趋零"的极限假设。

💡 关键一跃

三条路线的统一视角：k-means 用"离中心近"定义相似，DBSCAN 用"邻居够多"定义相似，AGNES 用"合并历史"定义相似；GMM 则说它们都是概率生成模型的特例——簇结构从来是你假设的生成方式，不是数据里写着的事实。

⚠️ 常见误区

"GMM 给出了概率，所以它找到的簇更真实"——错。γ 是在当前模型下的后验概率，模型假设（k 个高斯）本身就可能是错的；EM 同样只保证收敛到似然的局部极大。成分数 k 仍需外部给定或用 BIC 等准则另选，EM 不会替你决定有几个簇。

📝分层习题

L1 概念辨析DBSCAN 中，一个边界点最多能属于几个簇？如果它同时落在两个簇的核心点的 ε-邻域内，会发生什么？
提示

回想"密度相连"的定义：两个核心点通过同一个点产生联系时，它们的簇还能保持分开吗？

完整解答

恰好一个簇。边界点 x 非核心，不能"向外发"密度直达；它属于那个能密度可达它的核心点所在的簇。

若 x 同时落在核心点 c₁（属簇 A）与核心点 c₂（属簇 B）的 ε-邻域内，则 c₁ 与 c₂ 经由 x 互相密度可达（c₁→x 直达，c₂→x 直达，两点经公共邻居 x 密度相连），按 DBSCAN 的规则 A 和 B 本应合并成同一个簇——所以"属于两个簇"的情形在算法输出里不会出现。实现上边界点通常被分给先扫描到的那簇，只是实现细节，不影响"一簇"的结论。易错项：以为边界点"属于零个簇"——那是噪声点的定义，张冠李戴。

L1 概念辨析"Rand 指数 RI = 0.85，所以这个聚类结果很好"——这句话有什么问题？
提示

看 RI 的分子：a + d 里谁通常占大头？随机乱分能拿到多高的 RI？

完整解答

两个问题。其一，RI 把 d（在 C 与 S 中都不同对的样本对）也计分，而数据被分得越碎、d 的数量级通常远大于 a，RI 被 d 灌水；参考划分簇数越多，这个效应越明显。其二，RI 没有基线校正：把样本随机切成两半，RI 的期望也在 0.5 附近而不是 0，0.85 里有多少是"超过随机的部分"说不清。

正确做法：报做过随机校正的 ARI（Adjusted Rand Index，随机基线被校正到 0），或同时报更苛刻的 JC 与 FM（它们不用 d）；内部指标另算 DB（越小越好）与 Dunn（越大越好）佐证。

L2 手算推导新数据：q₁=(0,0)，q₂=(0,2)，q₃=(4,0)，q₄=(4,2)，k=2，初始中心 μ₁=(0,0)、μ₂=(4,0)。手算 k-means 一次完整迭代：逐点列出两个距离、写出分配、算出新中心，并判断下一轮是否还会变化。
提示

先列表：每个点到 (0,0) 与 (4,0) 的欧氏距离（可保留根式），取小者入簇；新中心 = 簇内各坐标均值。

完整解答

距离表：q₁：d(μ₁)=0，d(μ₂)=√(16+0)=4 → C₁。q₂：d(μ₁)=√(0+4)=2，d(μ₂)=√(16+4)=√20=2√5≈4.472 → C₁。q₃：d(μ₁)=4，d(μ₂)=0 → C₂。q₄：d(μ₁)=√(16+4)=2√5≈4.472，d(μ₂)=√(0+4)=2 → C₂。

分配：C₁ = {q₁, q₂}，C₂ = {q₃, q₄}。

新中心：μ₁′ = ((0+0)/2, (0+2)/2) = (0, 1)；μ₂′ = ((4+4)/2, (0+2)/2) = (4, 1)。

下一轮：q₁ 距 (0,1) 为 1、距 (4,1) 为 √17≈4.123 → 仍 C₁；q₂ 对称仍 C₁；q₃、q₄ 对称仍 C₂。分配不变、中心不动，迭代停止。最终两簇即上下两条边：{q₁,q₂} 与 {q₃,q₄}。

L2 手算推导5 个点 a、b、c、d、e 的距离矩阵：d(a,b)=3，d(a,c)=7，d(a,d)=9，d(a,e)=10，d(b,c)=6，d(b,d)=8，d(b,e)=9，d(c,d)=2，d(c,e)=5，d(d,e)=4。用最大距离（complete linkage）写出 AGNES 的完整合并序（每步合并谁、新簇间距离怎么算）。
提示

每步先找当前矩阵里最小的簇间距离合并；合并后新距离取"跨簇点对的最大值"，与单链接正好相反。

完整解答

第 1 步：矩阵最小值 d(c,d)=2 → 合并为 {c,d}。更新（取最大）：d({c,d},a) = max(7,9) = 9；d({c,d},b) = max(6,8) = 8；d({c,d},e) = max(5,4) = 5。

第 2 步：当前距离 {a,b}=3、{a,e}=10、{b,e}=9、{a,{c,d}}=9、{b,{c,d}}=8、{e,{c,d}}=5，最小为 d(a,b)=3 → 合并为 {a,b}。更新：d({a,b},{c,d}) = max(9,8) = 9；d({a,b},e) = max(10,9) = 10。

第 3 步：当前 {c,d}–e = 5、{a,b}–{c,d} = 9、{a,b}–e = 10，最小为 5 → 合并 {c,d} 与 e 为 {c,d,e}。更新：d({a,b},{c,d,e}) = max(9, 10) = 10。

第 4 步：只剩两簇，在距离 10 处合并为全集。

合并序汇总：{c,d}@2 → {a,b}@3 → {c,d,e}@5 → 全集@10。在 5 与 10 之间切一刀得两簇 {a,b} 与 {c,d,e}。对照单链接（9.5 节例子是另一组坐标，但方法相同）：complete linkage 每步取最大值，合并更"保守"，簇更紧凑。

L3 建模应用电商要给 10 万用户做分群运营：每个用户有三个特征（最近消费距今天数 R、年消费次数 F、年消费金额 M）。请在 k-means / DBSCAN / AGNES 三类算法中做选型，说出每类算法隐含的簇假设，并给出评估方案。
提示

考虑：数据规模、簇形状预期、是否要给运营一个明确的"分几群"、有没有刷单的离群用户、怎么验证分群有用。

完整解答

① 预处理：R、F、M 量纲悬殊（天数、次数、金额），先做 z-score 或 min-max 归一化——否则距离被金额绑架（呼应 9.1）。

② 选型：主力用 k-means。理由：10 万点规模下它最快；运营需要"明确分 k 群、每群一个画像"的硬划分；RFM 空间里的高价值/活跃/沉睡人群大致呈团块状，符合"簇是以均值为中心的球"的假设。初始化用 k-means++，多组种子取 E 最小。

③ DBSCAN 做复核与补充：它的簇假设是"连片的稠密区"，不用定 k，还能把孤立点标成噪声——正好用来识别刷单/异常账号（噪声点名单即风控线索）；若 DBSCAN 发现主人群被切成许多碎簇，说明密度不均，k-means 的球假设可疑。

④ AGNES 只做小样探索：O(m³) 级别的合并代价扛不住 10 万点；抽 500 个代表用户跑全链接，看树状图了解"分几群比较自然"（在最大间隙处切），给 k 的选择提供参考。

⑤ 评估：无参考划分，用内部指标——对 k = 2…8 各跑一次 k-means，算 DB（越小越好）与 Dunn（越大越好）并结合业务可解释性（每群 R/F/M 画像是否讲得通）选 k；上线后用业务指标（各群对差异化运营的响应率差异）做终极验证。这就闭环了本章主线：选算法 = 选簇假设，评估 = 在该假设下检验"簇内紧、簇间松"加业务价值。

自测 1
下列哪一条不是距离度量必须满足的公理？
  • A. 非负性：dist(xᵢ, xⱼ) ≥ 0
  • B. 同一性：dist(xᵢ, xⱼ) = 0 当且仅当 xᵢ = xⱼ
  • C. 对称性：dist(xᵢ, xⱼ) = dist(xⱼ, xᵢ)
  • D. 单调性：坐标差越大，dist 的增长率必须越来越大
解析：D 对——距离只要求非负、同一、对称、直递（三角不等式）四条，对"增长率"没有任何要求；比如 p→∞ 的切比雪夫距离取 max，根本不随差值加速增长。A/B/C 错：它们正是四公理中的三条（第四条直递性 dist(xᵢ,xⱼ) ≤ dist(xᵢ,xₖ)+dist(xₖ,xⱼ) 未列入选项）。
自测 2
k-means 迭代为什么必然在有限步内停止？停在什么位置？
  • A. 因为 E 是凸函数，所以收敛到全局最优
  • B. 因为样本数 m 有限，所以中心算两次就不动了
  • C. 每轮 E 单调不增且划分方案有限，停在 E 的局部极小
  • D. 因为 EM 算法保证全局收敛
解析：C 对——分配步与更新步都让 E 不增，而 m 个点的 k-划分数量有限，不能无限下降，必停；停在局部极小，不保证全局。A 错：E 对"划分"而言非凸，"凸"是错觉。B 错：m 有限只说明方案有限，"算两次就不动"不是必然，有的数据要很多轮。D 错：k-means 不是 EM（它是 GMM 的退化），且 EM 也只保证局部极大。
自测 3
DBSCAN 中 (ε, MinPts=3)，点 x 的 ε-邻域内连自己在内共 2 个点，但 x 落在核心点 y 的 ε-邻域内。x 是？它属于几个簇？
  • A. 核心点，属于一个簇
  • B. 边界点，恰好属于一个簇（y 所在簇）
  • C. 噪声点，不属于任何簇
  • D. 边界点，同时属于 x 能触达的所有簇
解析：B 对——|N_ε(x)|=2 < 3 非核心，但在核心点 y 邻域内，是边界点，经 y 密度可达而并入 y 的簇。A 错：核心点要求邻域计数 ≥ MinPts=3。C 错：噪声点要求"不在任何核心点邻域内"，x 在 y 的邻域内。D 错：若它能触达另一簇的核心点，两簇就密度相连应合并——边界点恰好属于一个簇。
自测 4
什么条件下 GMM 的 EM 迭代会退化为 k-means？
  • A. 各成分等权（αᵢ=1/k）、协方差同为 σ²I 且 σ²→0，后验变成"最近者取 1"
  • B. 把协方差矩阵 Σᵢ 取得足够大，覆盖所有样本
  • C. 把混合系数 αᵢ 全部设为 0
  • D. 把成分数 k 设为样本数 m
解析：A 对——σ²→0 时各高斯瘦成针尖，后验 γ 被最近中心独占（硬分配），E 步退化为"选最近中心"，M 步退化为"重算均值"，正是 k-means；这也是"k-means 假设簇是等大的球"的概率解释。B 错：σ² 大则隶属度摊平，离硬分配更远。C 错：αᵢ 必须为正且和为 1，全 0 非法。D 错：k=m 是另一个极端（每点一簇），与 k-means 退化无关。
自测 5
关于 AGNES 的簇间距离（linkage），哪个说法正确？
  • A. 单链接用两簇最远点对的距离
  • B. 全链接用两簇最近点对的距离
  • C. 单链接用最近点对，容易被一串中间点"搭桥"产生链式长簇
  • D. 三种 linkage 在任意数据上给出的合并序完全相同
解析：C 对——d_min 取跨簇最近点对（single linkage），只要两簇间有一串渐近的中间点就会逐节合并，产生 chaining。A 错：最远点对是全链接（d_max），A 把两者说反了。B 错：同 A，全链接用的是最大距离。D 错：9.5 的例子在单链接下 @4 并入 p₅，换成全链接后合并距离和顺序都会变（本习题 L2-2 就是例证），linkage 选择直接改变簇形态。
