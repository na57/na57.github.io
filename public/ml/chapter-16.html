16.1没有标准答案怎么学：任务与奖赏

前十五章的学习都有一个共同的「老师」：监督学习里每个样本带着标注（第1–7章），无监督学习里数据本身带着结构（第9、13章），连半监督学习也有少量标签指路（第13章）。本章把这位老师撤走：想象学下围棋——落子的瞬间没有人告诉你「这步棋打 60 分」，评价要等几十手之后、终局那一刻才以胜负的形式到来；再看机器人学倒水——「水洒了」这个结果要等症状发生才知道，而且它无法指明刚才一连串关节动作里哪一步错了。这就是强化学习（Reinforcement Learning, RL）面对的世界：没有即时监督信号，只有延迟到来的奖赏。

形式化地，强化学习任务由三个要素刻画：

要素记号含义围棋例倒水例
状态（state）s ∈ S环境当前局面的描述棋盘上的棋子分布机械臂各关节角度 + 水面高度
动作（action）a ∈ A机器可执行的操作在某个交叉点落子各关节的目标角速度
奖赏（reward）r环境反馈的标量评价，可正可负终局胜 +1 / 负 −1，中途 0洒出水 −1，倒满杯子 +10

机器与环境反复交互：在状态 sₜ 选动作 aₜ，环境转移到新状态 sₜ₊₁ 并给出奖赏 rₜ₊₁，如此循环。要让这套交互可被数学分析，需要一个关键假设——马尔可夫性（Markov property）：下一状态只依赖当前状态与当前动作，与更早的历史无关，即 P(sₜ₊₁ | sₜ, aₜ, sₜ₋₁, aₜ₋₁, …) = P(sₜ₊₁ | sₜ, aₜ)。围棋天然满足它（棋盘已包含全部对局信息）；若状态描述不全（例如扑克牌看不到对手手牌），马尔可夫性就破缺，需要把历史压进状态里才行。

学习目标也随之改变：不再是「每个样本都答对」，而是最大化长期的折扣累积奖赏（discounted cumulative reward）：

G = ∑t=0∞ γt rt+1 = r₁ + γr₂ + γ²r₃ + …

其中折扣因子 γ ∈ [0, 1) 起两个作用：① 数学上保证无穷步的累积和收敛（|r| 有界时级数收敛）；② 直觉上表达「未来的奖赏要打折扣」——γ 越接近 0 越短视（只顾眼前一步），γ 越接近 1 越有耐心（愿意为大目标忍受眼前的负奖赏）。与监督学习的对照如下：

监督学习强化学习
反馈形式每个样本的标注（「正确答案」）延迟、稀疏的奖赏标量（「做得好不好」）
反馈时机即时：每预测一次立即对一次答案延迟：走完一串动作才知结果
指明错误指明——标注就是正确答案不指明——奖赏不说哪个动作该背锅
数据来源独立同分布的样本集机器自己选动作产生的轨迹（数据分布被策略改变）
💡 关键一跃

强化学习是「只给期末成绩、不给平时作业批改」的学习：奖赏是终点处的一声哨响，机器要自己倒推出整场比赛里每一步的功过。γ 就是「耐心系数」——它决定机器愿意为多远之后的哨声负责。

⚠️ 常见误区

把奖赏当标签，以为「给正奖赏的那步就是正确动作」。错。奖赏延迟且稀疏：终局 +1 是几十手棋共同造成的，它不指明哪一手立了功、哪一手埋了雷——把延迟奖赏正确地分摊到每一步（功劳分配），正是本章后续所有算法要解决的核心难题。

16.2探索-利用两难的最小模型：K 摇臂赌博机

16.1 埋下的第一个难题是：动作的好坏不能马上知道，那早期该「试新动作」还是「用已知好动作」？这就是探索与利用（exploration & exploitation）的两难。把它单独剥出来研究的最小模型是 K 摇臂赌博机（K-armed Bandit）：只有一个状态（没有状态转移，也就没有长期后果），每步从 K 个摇臂中选一个拉，获得该臂随机分布给出的奖赏；目标是在有限步内让总奖赏尽量大。每个臂 k 的真实期望奖赏 μ(k) 未知，机器靠已观察的样本均值 Q(k) 去估计它。

两难在于：利用——选当前 Q 最大的臂，稳拿眼下最好收益，但可能早早把某个「开局走运」的次优臂误当成最好，从此困在局部；探索——试别的臂，能纠正错误估计，但每次试错都付出机会成本。两种经典平衡策略：

① ε-贪心（ε-greedy）：以概率 1−ε 选当前 Q 最大的臂（利用），以概率 ε 在全部 K 个臂中均匀随机选一个（探索）。ε 是唯一的旋钮：ε = 0 退化为纯贪心（永不探索），ε = 1 退化为纯随机（永不利用）。

② Softmax：按 Boltzmann 分布把「估计值的大小」直接转成「被选中的概率」，Q 越大的臂概率越高，但差距被温度参数 τ 调制：

P(k) = eQ(k)/τ∑j=1K eQ(j)/τ

温度 τ 的作用：τ → 0 时，指数把 Q 的微小差距急剧放大，分布退化为一山独大的贪心；τ → ∞ 时，所有 Q(j)/τ → 0，各项都趋于 1，分布退化为均匀随机。τ 居中时，「好臂多选、差臂少选但不封死」，比 ε-贪心的「一视同仁地随机」更精细。

【手算例 1】2 摇臂赌博机的 Softmax 选择概率。设已估计 Q(1) = 0.6，Q(2) = 0.5，分别算 τ = 0.1 与 τ = 1 时选中臂 1 的概率。

情形一：τ = 0.1（低温，接近贪心）。

① 算指数项：Q(1)/τ = 0.6/0.1 = 6 → e⁶ ≈ 403.43；Q(2)/τ = 0.5/0.1 = 5 → e⁵ ≈ 148.41。
② 求归一化分母：403.43 + 148.41 = 551.84。
③ 归一化：P(1) = 403.43 / 551.84 ≈ 0.731，P(2) = 148.41 / 551.84 ≈ 0.269。
Q 只差 0.1，概率差距却拉到 0.731 vs 0.269——低温把微小优势放大了。

情形二：τ = 1（高温，接近随机）。

① 算指数项：Q(1)/τ = 0.6 → e⁰·⁶ ≈ 1.822；Q(2)/τ = 0.5 → e⁰·⁵ ≈ 1.649。
② 分母：1.822 + 1.649 = 3.471。
③ 归一化：P(1) = 1.822 / 3.471 ≈ 0.525，P(2) = 1.649 / 3.471 ≈ 0.475。
同样的 Q 差距，概率几乎五五开——高温下 Softmax 接近均匀随机。

结论：τ 越小越贪心，τ 越大越随机；实践中常让 τ 随时间衰减（先大胆探索，后安心利用），或让 ε 随时间衰减，同理。

💡 关键一跃

探索-利用是「试新餐厅还是去常去那家」的日常抉择：估计越不可靠（刚来这座城市），越该多试几家；估计越可靠（住了三年），越该直奔心头好。ε 与 τ 都是同一个旋钮的两个形状——控制「信任当前估计」的程度。

⚠️ 常见误区

以为「ε 越小越好、尽快收敛到最优臂」。错。纯利用（ε = 0）会被早期运气锁死：若最优臂前两把恰好走背字，它的 Q 就永远翻不了身——探索一旦停止，错误估计再没有被纠正的机会。ε/τ 应随时间衰减，而不是一开始就给个小值。

16.3有模型学习：MDP 与 Bellman 方程

16.2 的赌博机只有一个状态，而真实任务有状态转移——这一步的选择会影响下一步站在哪里。把它补回来，就得到完整的形式化框架：马尔可夫决策过程（Markov Decision Process, MDP），四元组 ⟨S, A, P, R⟩ 外加折扣 γ：

成分含义
S状态空间
A动作空间
P(s′|s,a)转移概率：在 s 执行 a 后到达 s′ 的概率（马尔可夫性已内置）
R(s,a,s′)奖赏函数：该次转移带来的期望奖赏
γ ∈ [0,1)折扣因子

所谓有模型学习（model-based learning），就是 P 与 R 已知的情形——环境 dynamics 完全写在纸面上，剩下的是纯计算问题。要算的对象是策略（policy）π(a|s)：在状态 s 下选各动作的概率分布；以及衡量策略好坏的两类值函数（value function）：

值函数定义回答的问题
状态值函数 Vπ(s)从 s 出发、按 π 行动，折扣累积奖赏的期望「这个状态本身有多好？」
状态-动作值函数 Qπ(s,a)从 s 出发、先执行 a 再按 π 行动，折扣累积奖赏的期望「在此状态下做这个动作有多好？」

值函数的美妙之处在于它可以「自己用自己」递归定义——今天的价值 = 眼前一步的奖赏 + 明天的价值 × γ。展开即得 Bellman 期望方程（Bellman expectation equation）：

Vπ(s) = ∑a π(a|s) ∑s′ P(s′|s,a) [ R(s,a,s′) + γ Vπ(s′) ]

我们真正想要的是最优策略 π* 的值函数。把期望方程里的「按 π 选动作」换成「挑最好的动作」，就得到 Bellman 最优方程（Bellman optimality equation）：

V*(s) = maxa ∑s′ P(s′|s,a) [ R(s,a,s′) + γ V*(s′) ]

有模型时，这个非线性方程组可以「直接解」，两种经典算法：

① 策略迭代（policy iteration）：策略评估 → 策略改进交替进行。评估：对当前策略 π 解 Bellman 期望方程组（线性方程组，可迭代求解），得到 Vπ；改进：对每个状态贪心改选动作，π′(s) = argmaxₐ Σₛ′ P[R + γVπ(s′)]。不断交替，直到策略不再变化——此时即最优。

② 值迭代（value iteration）：干脆把 Bellman 最优方程本身当作更新式，反复应用直到收敛：

Vk+1(s) ← maxa ∑s′ P(s′|s,a) [ R(s,a,s′) + γ Vk(s′) ]

因为 γ < 1，这个更新是一个压缩映射（每次迭代都把误差乘以 γ），必然收敛到唯一不动点 V*。收敛后提最优策略只需一次贪心：π*(s) = argmaxₐ Σₛ′ P[R + γV*(s′)]。

【手算例 2】单状态两动作微型 MDP 上的值迭代。只有一个状态 s；动作 a₁：确定性地回到 s，期望奖赏 1.8；动作 a₂：确定性地回到 s，期望奖赏 1。γ = 0.9。转移确定（P = 1），Bellman 更新简化为 V ← max( 1.8 + 0.9V, 1 + 0.9V )。

① 初始化 V₀ = 0。
② 第 1 次迭代：V₁ = max(1.8 + 0.9×0, 1 + 0.9×0) = max(1.8, 1) = 1.8。
③ 第 2 次迭代：两个动作各自的候选值——a₁：1.8 + 0.9×1.8 = 1.8 + 1.62 = 3.42；a₂：1 + 0.9×1.8 = 1 + 1.62 = 2.62。V₂ = max(3.42, 2.62) = 3.42。
④ 第 3 次迭代：a₁：1.8 + 0.9×3.42 = 1.8 + 3.078 = 4.878；a₂：1 + 0.9×3.42 = 4.078。V₃ = max(4.878, 4.078) = 4.878。
⑤ 收敛验证：由于 a₁ 每步都占优（1.8 > 1 且 γV 项两边相同），不动点满足 V* = 1.8 + 0.9V*。解方程：V* − 0.9V* = 1.8 → 0.1V* = 1.8 → V* = 1.8/(1−0.9) = 18。代回验证：1.8 + 0.9×18 = 1.8 + 16.2 = 18 ✓。迭代序列 0 → 1.8 → 3.42 → 4.878 → … 正稳步逼近 18（每步把与 18 的差距乘以 0.9）。最优策略 π*(s) = a₁，每次都拿 1.8 而非 1。

💡 关键一跃

Bellman 方程是「把长远利益分期摊还」：一个状态的价值 = 这一步落袋的奖赏 + 下一步价值打 γ 折。它把「无穷步的全局优化」拆成「一步一价的局部方程」——能拆的前提正是马尔可夫性：明天只由今天决定。

⚠️ 常见误区

以为「有模型」=「有人类专家手工设计的规则」。错。「有模型」特指 P 与 R 已知（哪怕来自系统辨识、来自模拟器），此时不需要真实交互，靠规划（策略迭代/值迭代）就能算出最优策略；与之相对的「免模型」才是下一节的主角——P、R 未知，只能与环境交互采样。

V*(s) = maxₐ Σₛ′ P(s′|s,a)[R(s,a,s′) + γV*(s′)]。策略迭代：评估当前策略（解期望方程）→ 贪心改进策略，交替至策略不变。值迭代：把最优方程本身当更新式反复迭代，靠 γ < 1 的压缩性收敛到 V*，再一次性贪心提策略。

16.4免模型学习：蒙特卡罗与时序差分

16.3 的值迭代很优雅，但前提苛刻：P 与 R 必须已知。现实里——机器人接触新地面、玩家面对没读过的规则书——转移概率与奖赏函数都未知，机器只能亲自与环境交互、收集 (s, a, r, s′) 这样的样本，用采样去逼近那些算不出来的期望。这就是免模型学习（model-free learning）。核心问题变成：怎么用样本估计 V^π 或 Q^π？

路线一：蒙特卡罗（Monte Carlo, MC）。最朴素的想法：值函数定义为「折扣累积奖赏的期望」，期望算不出，那就整幕走完、用真实回报代替期望。一幕（episode）从 s 出发走到底，得到实际回报 G，然后向它更新：V(s) ← V(s) + α(G − V(s))。MC 的目标 G 是真实采样到的累积奖赏，因此估计无偏（unbiased）；但一幕里所有随机性（环境的、策略的）全部压进这一个数字，方差大，而且必须等一幕结束才能更新——下围棋输了才知道学，中途每一步都得憋着。

路线二：时序差分（Temporal Difference, TD）。不必等剧终：在状态 s 执行一步、看到 r 与 s′ 后，就用「r + γV(s′)」作为 V(s) 的目标立即更新：

V(s) ← V(s) + α [ r + γV(s′) − V(s) ]

括号里的量叫 TD 误差（TD error）δ = r + γV(s′) − V(s)，它是「这一步实际看到的」与「原来估计的」之差。TD 的目标 r + γV(s′) 里用到了当前的估计值 V(s′)，属于「用估计更新估计」（bootstrapping，自举），因此有偏；但它只依赖一步的随机性，方差小，且每步都能学。MC 与 TD 的对照：

蒙特卡罗时序差分（TD）
更新目标真实回报 G（整幕走完才知道）r + γV(s′)（一步即可构造）
更新时机一幕结束后每一步之后
偏差无偏（目标是真期望的样本）有偏（目标里含当前估计，自举）
方差大（累积了整幕的随机性）小（只含一步的随机性）

把 TD 的思想用到「状态-动作值函数」Q(s,a) 上，就得到两个最著名的免模型算法，差别只在更新目标里 s′ 处的动作怎么选：

① Sarsa（同轨策略，on-policy）：目标用实际将要执行的下一个动作 a′（由当前行为策略，如 ε-贪心，真实选出）——Q(s,a) ← Q(s,a) + α[ r + γQ(s′,a′) − Q(s,a) ]。算法名来自更新所用的五元组 (s, a, r, s′, a′)。它评估的是「行为策略自己」的价值：行为策略在探索，学到的价值就包含探索的代价。

② Q-learning（离轨策略，off-policy）：目标不管下一步实际会做什么，直接用 s′ 处的最大 Q 值——

Q(s,a) ← Q(s,a) + α [ r + γ maxa′ Q(s′,a′) − Q(s,a) ]

它评估的是「贪心目标策略」的价值：哪怕行为上还在用 ε-贪心探索，目标一律按「下一步选最优动作」来算。行为策略负责探索收集数据，目标策略负责定义最优——两者分离，正是「离轨」的含义；这也是 Q-learning 能直接逼近最优值函数 Q* 的原因。

【手算例 3】Q-learning 的一步更新（并与 Sarsa 对照）。设 Q(s,a₁) = 2.0，执行 a₁ 后得奖赏 r = 1，到达 s′；s′ 处有两个动作，Q(s′,a₁) = 1.0，Q(s′,a₂) = 3.0。学习率 α = 0.5，折扣 γ = 0.9。

Q-learning 更新：
① 在 s′ 处取 max：max(1.0, 3.0) = 3.0（对应动作 a₂）。
② 构造目标：r + γ·maxa′ Q(s′,a′) = 1 + 0.9×3.0 = 1 + 2.7 = 3.7。
③ TD 误差：δ = 3.7 − 2.0 = 1.7。
④ 更新：Q(s,a₁) ← 2.0 + 0.5×(3.7 − 2.0) = 2.0 + 0.5×1.7 = 2.0 + 0.85 = 2.85。

Sarsa 对照：假设行为策略实际选出的下一动作是 a₁（即 a′ = a₁）。
① 目标：r + γ·Q(s′,a′) = 1 + 0.9×1.0 = 1.9。
② TD 误差：δ = 1.9 − 2.0 = −0.1。
③ 更新：Q(s,a₁) ← 2.0 + 0.5×(1.9 − 2.0) = 2.0 − 0.05 = 1.95。

差异解释：同一笔经验 (s, a₁, 1, s′)，Q-learning 把 Q(s,a₁) 从 2.0 抬到 2.85，Sarsa 却压到 1.95。原因：Q-learning 的目标假设「到了 s′ 一定会选最好的 a₂（价值 3.0）」，学的是最优目标策略的价值；Sarsa 的目标用的是行为策略实际要走的 a₁（价值 1.0），学的是含探索的行为策略的价值。行为策略可以尽情探索，Q-learning 照样向「按贪心走」的价值收敛——这是离轨学习的精髓。

💡 关键一跃

TD 是「边下棋边复盘」：不用等终局哨响，每走一步就用「眼前奖赏 + 对下一站的当前估计」校正本站的估值。Q-learning 与 Sarsa 的差别只有一句话——更新目标里，s′ 处按「理想的我」（max，离轨）还是「实际的我」（a′，同轨）计价。

⚠️ 常见误区

以为「Q-learning 用了 max，所以训练时必须按贪心策略行动」。错。max 只出现在更新目标里；行为上仍用 ε-贪心等策略去探索，否则没走过的动作永远没有数据。离轨的「轨」指的是目标策略与行为策略分离——探索照旧，估值向最优看齐，二者互不耽误。

16.5值函数近似与模仿学习：本章收束，全书收束

16.4 的 Q-learning 把「学动作」变成了「填一张 Q 表」——每个 (s,a) 一格。但表格有个致命前提：状态数得有限且不太大。围棋的状态约 10¹⁷⁰ 种，机械臂的关节角是连续值，Q 表根本开不出这么多格子。出路是把「查表」换成「函数」：值函数近似（value function approximation），用参数化函数代替表格，最简形式是线性模型：

V(s) = θT x(s)

其中 x(s) 是状态的特征向量，θ 是待学参数。更新沿 TD 误差的方向调参：θ ← θ + α·δ·x(s)（δ 为 TD 误差，x(s) 是误差对 θ 的梯度方向）——一句话：TD 误差为正就把特征方向的参数抬高，为负就压低。把线性函数换成神经网络，便是深度强化学习的入口；表格版的收敛保证随之消失，这是近似要付的代价。

第二个遗留难题更根本：奖赏从哪来？采样交互又慢又贵（样本效率低：AlphaGo 级的训练量人类几辈子下不完），更麻烦的是很多任务里奖赏函数本身设计不出来——「倒水的奖赏」好写，「开车开得稳」的奖赏怎么写？写歪了，机器会照着字面钻空子。当奖赏稀疏或难设计时，与其让机器从零试错，不如直接利用人类示范——模仿学习（imitation learning），两条路线：

直接模仿（行为克隆）逆强化学习（Inverse RL）
学什么把示范轨迹 (s,a) 当监督数据，直接学「状态 → 动作」的映射从示范反推出奖赏函数，再用强化学习在该奖赏下求最优策略
假设示范即正确答案示范者在某个未知奖赏函数下（近似）最优
优点简单，退化为普通监督学习学到的是「意图」，可泛化到与示范不同的局面
软肋分布偏移：机器偏离示范轨迹后进入没见过的状态，错误会累积奖赏函数不唯一（同一批示范可由多个奖赏解释），问题欠定

本章的遗留问题也就摆在台面上了：样本效率（免模型方法动辄需要百万次交互）与安全性（探索阶段的试错在真实系统里可能闯祸）至今仍是强化学习落地的两大闸门。

全书收束。回头看这套讲义的主线：第 1 章从「有标注就能学」出发——监督学习有全量的标准答案；第 9、13 章撤走标注，靠结构与非监督/半监督信号；第 15 章把答案换成人类可读的规则；本章把答案撤到最薄——只剩延迟、稀疏的奖赏标量，机器仍能通过 Bellman 方程把终点哨声折算成每一步的指南针。机器学习研究的主线由此显形：监督信号越弱，机器越要会自己找结构。

💡 关键一跃

值函数近似 = 把「百科全书式的大表格」压缩成「一个会举一反三的函数」；模仿学习 = 「老师做一遍，你照着学」，逆强化学习再多走一步——「从老师的做法里猜出老师在乎什么」。

⚠️ 常见误区

以为「奖赏函数随便写写，差不多就行」。错。机器是按字面优化的：给「船跑得越快奖赏越高」，它可能学会原地转圈刷分而不进港——这叫奖赏黑客（reward hacking）：策略钻奖赏函数的空子拿高分，却不完成真实目标。奖赏设计本身就是强化学习最难的工程环节之一，本章习题 L3 会正面碰到它。

概念卡 1
马尔可夫决策过程（MDP）
点击翻面 →
定义⟨S, A, P, R⟩ + γ：状态、动作、转移概率、奖赏函数与折扣因子构成的序贯决策框架，下一状态只依赖当前状态与动作。
解决问题把「在环境中连续做动作、拿延迟奖赏」的问题变成可分析、可求解的数学对象。
直觉一盘棋：棋盘是状态、落子是动作、规则是 P、终局胜负是 R。
误区以为马尔可夫性天然成立；状态描述不全（如看不到对手手牌）时它破缺，需把历史压进状态。
何时用本章全部算法的地基；机器人、游戏 AI、资源调度的通用建模语言。
概念卡 2
值函数与 Bellman 方程（Value Function & Bellman Equation）
点击翻面 →
定义V^π(s)：从 s 按 π 行动的折扣累积奖赏期望；Bellman 最优方程 V*(s) = maxₐ Σₛ′ P[R + γV*(s′)] 把它递归定义。
解决问题把「无穷步全局优化」折成「一步一价的局部方程」，使长远利益可被逐步计算。
直觉分期摊还：今天的价值 = 眼前落袋 + 明天价值打 γ 折。
误区以为 Bellman 方程是数值算法；它是值函数必须满足的「自洽条件」，策略迭代/值迭代才是求解算法。
何时用16.3 有模型求最优策略；16.4 的 TD、Q-learning 都是它的免模型近似版。
概念卡 3
K 摇臂赌博机（K-armed Bandit）
点击翻面 →
定义单状态、即时奖赏的简化任务：每步从 K 个期望未知的摇臂选一个拉，目标是总奖赏最大。
解决问题把探索-利用两难从状态转移中剥离出来，单独研究「试新 vs 用旧」的权衡。
直觉试新餐厅还是去常去那家——估计越不可靠越该多试。
误区以为 ε 越小越好；纯利用会被早期运气锁死在次优臂上，ε/τ 应随时间衰减而非一开始就给小值。
何时用16.2 的 ε-贪心与 Softmax；也是所有 RL 算法探索机制的母体。
概念卡 4
时序差分（Temporal Difference, TD）
点击翻面 →
定义免模型更新法：每步以 r + γV(s′) 为目标更新 V(s)，更新量 α 倍的 TD 误差 δ = r + γV(s′) − V(s)。
解决问题P、R 未知且等不起整幕结束：用一步样本立即校正估值。
直觉边下棋边复盘，不等终局哨响就改棋谱。
误区以为 TD 与 MC 一样无偏；TD 用估计更新估计（自举），有偏但方差小。
何时用16.4 的 Sarsa、Q-learning；对 V 的近似版即 TD 学习。
概念卡 5
Q-learning（离轨 TD 控制）
点击翻面 →
定义Q(s,a) ← Q(s,a) + α[r + γ maxₐ′ Q(s′,a′) − Q(s,a)]，目标策略取贪心 max，与行为策略分离。
解决问题免模型直接逼近最优值函数 Q*：行为策略尽管探索，估值照样向「按贪心走」收敛。
直觉记账按「理想的我」计价，干活允许「实际的我」试错。
误区以为用了 max 就必须按贪心行动；max 只在更新目标里，行为仍需 ε-贪心探索，否则没走过的动作永远没数据。
何时用16.4 手算例 3 的主角；与同轨的 Sarsa 对照记忆；深度版即 DQN。
概念卡 6
模仿学习（Imitation Learning）
点击翻面 →
定义利用人类示范替代/补充奖赏信号：直接模仿把示范当监督数据学策略；逆强化学习从示范反推奖赏函数再求最优。
解决问题奖赏稀疏、难设计或交互昂贵时，让机器站在示范者的肩膀上起步。
直觉学徒制：师傅做一遍徒弟照着做（直接模仿）；更高段位是猜出师傅在乎什么（逆强化学习）。
误区以为模仿到示范就万事大吉；直接模仿遇分布偏移会错误累积，逆强化学习的奖赏解不唯一。
何时用16.5 收束节；自动驾驶、机器人操作等「奖赏写不出但示范拿得到」的任务。

📝分层习题

L1 概念辨析判断正误并说明理由：「强化学习里的奖赏就是监督学习里标签的另一种叫法——拿到正奖赏的那个动作就是标准答案。」
提示

从三个角度对照：反馈的时机（即时还是延迟）、反馈的密度（每步都有还是稀疏）、反馈是否指明「哪个动作对」。

完整解答
错。① 标签是即时的：每个样本预测完立刻对答案；奖赏是延迟的，一串动作走完后才到。② 标签是稠密的：每个样本都有；奖赏是稀疏的，大量步骤奖赏为 0。③ 最关键：标签指明正确答案，奖赏不指明——终局 +1 是几十步共同造成的，它不说哪一步立功、哪一步埋雷。把延迟奖赏分摊到各步（功劳分配）正是值函数与 TD 要解决的问题；把奖赏当标签，等于绕开了本章的核心难题。
L1 概念辨析「ε-贪心里的 ε 越小越好——反正目标是尽快找到并锁定最优臂，ε 调小收敛更快。」这个说法错在哪？
提示

想想：若最优臂前两把恰好走了背字，它的样本均值 Q 会怎样？此后纯利用策略还会再拉它吗？

完整解答
错。纯利用（ε→0）会被早期运气锁死：最优臂若开局几把奖赏偏低，其 Q 估计被压低，纯贪心从此不再选它，错误估计永远没有被纠正的机会——这就是困在局部最优。探索的作用是持续修正估计，因此正确做法是 ε（或 Softmax 的 τ）随时间衰减：早期估计不可靠时多探索，后期估计稳定后多利用；而不是一开始就把 ε 压到小值。
L2 手算推导3 摇臂赌博机，Softmax 选择：Q(1) = 1.0，Q(2) = 0.8，Q(3) = 0.2，温度 τ = 0.5。求三个臂各自被选中的概率，步骤写全。（已知 e² ≈ 7.389，e^1.6 ≈ 4.953，e^0.4 ≈ 1.492）
提示

先算每个臂的 Q(k)/τ，再取指数，最后归一化：P(k) = e^(Q(k)/τ) / Σⱼ e^(Q(j)/τ)。

完整解答
① 各臂 Q(k)/τ：臂1：1.0/0.5 = 2.0；臂2：0.8/0.5 = 1.6；臂3：0.2/0.5 = 0.4。
② 取指数：e²·⁰ ≈ 7.389；e¹·⁶ ≈ 4.953；e⁰·⁴ ≈ 1.492。
③ 归一化分母：7.389 + 4.953 + 1.492 = 13.834。
④ 归一化：P(1) = 7.389/13.834 ≈ 0.534；P(2) = 4.953/13.834 ≈ 0.358；P(3) = 1.492/13.834 ≈ 0.108。
⑤ 验证：0.534 + 0.358 + 0.108 = 1.000 ✓。最好的臂概率过半，最差的臂仍有约 11% 的探索机会——这正是 Softmax「好臂多选、差臂不封死」的样子。
L2 手算推导Q-learning 一步更新：Q(s,a) = 0.5，执行 a 后得奖赏 r = 0，到达 s′，且 maxa′ Q(s′,a′) = 4.0。学习率 α = 0.1，折扣 γ = 1。求更新后的 Q(s,a)，步骤写全。
提示

三步走：构造目标 r + γ·max Q(s′,a′) → 算 TD 误差（目标 − 旧值）→ 按 α 步长更新。

完整解答
① 目标：r + γ·maxa′ Q(s′,a′) = 0 + 1×4.0 = 4.0。
② TD 误差：δ = 4.0 − 0.5 = 3.5。
③ 更新：Q(s,a) ← 0.5 + 0.1×(4.0 − 0.5) = 0.5 + 0.1×3.5 = 0.5 + 0.35 = 0.85。
说明：这一步本身没拿到奖赏（r = 0），但 s′ 处的前景（4.0）透过 γ = 1 全额传导回来，Q(s,a) 被抬高——TD 类方法「用未来估计反哺当前估计」的机制在这一个数字里看得清清楚楚。
L3 建模应用场景：仓储机器人拣货路径优化——仓库内一台机器人从货架取货送到打包台，要规划每条拣货路径使单位时间完成的订单最多。请为它定义 MDP 的 S / A / R / γ；说明「若能拿到精确的仓库物理仿真器」该选哪类算法、「只能在真实仓库里边干边学」该选哪类算法；写出你的奖赏设计，并指出一个可能的「奖赏黑客」风险。
提示

状态要满足马尔可夫性：把「决定下一步所需的一切」装进去。算法选择的分界线只有一条：P 与 R 是否已知（仿真器能否充当模型）。奖赏黑客：想一个「字面得分高、实际活没干好」的漏洞。

完整解答

① MDP 定义。S：机器人当前位置与朝向、已拣/待拣商品清单、各待拣货位坐标（必须含全，否则马尔可夫性破缺）；A：移动方向 / 加减速 / 抓取 / 放下等离散或连续控制量；R：每完成一张订单 +10，每步时间消耗 −0.1（惩罚磨蹭），碰撞 −50（安全硬约束）；γ：取 0.99 左右——订单序列长，需要耐心，但仍需折扣保证收敛。

② 算法选择。若有精确物理仿真器：P、R 可在仿真中廉价获得，属有模型情形——用值迭代/策略迭代在仿真里把策略算好，再部署到真实仓库（样本免费、试错安全）。若只能真实环境边干边学：P、R 未知，属免模型情形——用 Q-learning（离轨，探索数据也能用于学最优值），以 ε-贪心作行为策略保证探索，状态连续时再配值函数近似。

③ 奖赏黑客风险。若把奖赏写成「每拣起一件商品 +5」而不与「送达打包台」绑定，机器人可能学会反复拣起-放下同一商品刷分：字面上奖赏滚滚来，实际订单零完成。对策：奖赏只挂在「订单完成」这个真实目标上，时间惩罚与安全惩罚作为辅助项——设计奖赏时永远问一句：「有没有不看真目标也能刷高分的捷径？」

自测 1
强化学习与监督学习的反馈信号，本质差别是？
  • A. 强化学习的反馈是实数，监督学习的是类别
  • B. 奖赏延迟、稀疏且不指明哪个动作对；标签即时、稠密且就是正确答案
  • C. 监督学习的数据有噪声，强化学习的没有
  • D. 二者没有本质差别，只是叫法不同
B 对：三个差别缺一不可——时机（延迟 vs 即时）、密度（稀疏 vs 每样本都有）、信息量（只说「好不好」，不说「哪个对」）。A 错：实数还是类别只是表面形式，回归的标签也是实数。C 错：奖赏同样带噪声（随机环境），噪声不是分水岭。D 错：正因其延迟稀疏、不指明对错，才需要值函数把终点奖赏分摊到每一步——整套 Bellman/TD 机制都为此存在。
自测 2
Softmax 动作选择中，温度参数 τ 的作用是？
  • A. τ 越大越贪心，τ→∞ 时只选 Q 最大的臂
  • B. τ 只控制学习速度，与探索无关
  • C. τ 越小越贪心（τ→0 退化为纯贪心），τ 越大越随机（τ→∞ 均匀选择）
  • D. τ 必须固定为 1，不能调整
C 对：τ→0 时指数把 Q 的微小差距急剧放大，最大 Q 者概率→1（贪心）；τ→∞ 时各 Q/τ→0、指数项都→1，概率→1/K（均匀）。A 错：方向说反了。B 错：τ 直接控制探索-利用的平衡，与学习率 α 是两回事。D 错：τ 是关键旋钮，实践中常随时间衰减——先探索后利用。
自测 3
值迭代收敛的理论依据是？
  • A. 学习率 α 取得足够小
  • B. γ < 1 使 Bellman 更新成为压缩映射，必收敛到唯一不动点
  • C. 迭代次数足够多总会碰巧停在最优点
  • D. 初值 V₀ 必须取为零
B 对：每次迭代把当前值与不动点的差距乘以 γ（<1），压缩映射保证任意初值都收敛到同一个 V*。A 错：值迭代的更新式里没有学习率（α 是免模型采样式更新里的步长）。C 错：「碰巧」不是依据——收敛性来自压缩映射的数学保证。D 错：压缩映射从任意初值出发都收敛，取零只是方便。
自测 4
Q-learning 与 Sarsa 的一步更新，差别在哪？
  • A. Q-learning 不用学习率 α，Sarsa 用
  • B. Q-learning 是有模型算法，Sarsa 是免模型算法
  • C. Q-learning 的目标用 maxₐ′ Q(s′,a′)（离轨，按贪心目标策略计价）；Sarsa 的目标用行为策略实际选出的 a′（同轨）
  • D. Sarsa 不能处理连续状态，Q-learning 可以
C 对：两式只差目标里 s′ 处的动作——max（理想的我）还是实际 a′（实际的我），这就是离轨与同轨之分。A 错：两者都用 α 作步长。B 错：两者都是免模型 TD 控制，都不需要 P、R。D 错：能否处理连续状态取决于是否配值函数近似，与同轨/离轨无关。
自测 5
关于模仿学习，下列哪项正确？
  • A. 逆强化学习把示范当监督数据，直接学状态到动作的映射
  • B. 直接模仿学「怎么做」，逆强化学习从示范反推「在乎什么」（奖赏函数）再求最优策略
  • C. 模仿学习要求奖赏函数已知，否则无法使用
  • D. 直接模仿不会出错，因为老师总是对的
B 对：两条路线的分水岭就是「学动作映射」还是「反推奖赏函数」。A 错：说反了，那是直接模仿（行为克隆）。C 错：恰恰相反，模仿学习正是为「奖赏稀疏/难设计」而生的——有现成奖赏就不必模仿了。D 错：直接模仿有分布偏移——机器偏离示范轨迹后进入没见过的状态，错误会累积；示范也不可能覆盖所有局面。
