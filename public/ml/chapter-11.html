特征选择与稀疏学习

特征太多太杂时，怎样选出（或学出）"少而精"的特征表示：子集搜索是 NP 难的，工程上用三条近似路线替代，而它们的共同信仰是——真正重要的维度很少。

本章在主线上的位置：第10章用"混合压缩"的方式降维，得到的新特征是原特征的加权组合，可解释性差；本章改走另一条路——直接从原始特征中挑出一个子集，或让模型在训练中自动学出稀疏权重 → 第12章计算学习理论将回答"什么样的假设类、多少样本才学得到"，为本章的"稀疏假设"提供理论背书。

11.1为什么不能枚举所有特征子集：组合爆炸与三条出路

第10章的降维（如 PCA）把 d 个原始特征"混合压缩"成 k 个新特征——新特征是全体旧特征的线性组合，物理含义被搅浑了：医生没法向病人解释"0.3×血糖 + 0.7×血压"是什么指标。另一条路是原样保留被选中的特征：特征选择（Feature Selection）——从 d 个特征中挑出一个子集，扔掉其余。扔掉什么？两类特征：

  • 无关特征（Irrelevant Feature）：与学习任务毫不相干，例如用"患者编号"预测疾病；
  • 冗余特征（Redundant Feature）：本身有用，但它携带的信息能被其他特征完全推出来，例如同时记录"身高（cm）"与"身高（inch）"。

注意二者不重合：冗余特征可能每个都高度相关，只是"重复报到"。理想做法是枚举所有特征子集、用验证集性能打分、取最优——但 d 个特征的非空子集有 2d − 1 个，这就是灾难的源头：

特征数 d非空子集数 2d − 1直观感受（每秒评估 10⁶ 个子集）
101024 − 1 = 1023约 1 毫秒，瞬间完成
20约 1.05 × 10⁶约 1 秒
30约 1.07 × 10⁹约 18 分钟
501125899906842623 ≈ 1.126 × 10¹⁵约 1.126 × 10⁹ 秒 ≈ 35.7 年
子集数 = 2d − 1：d=10 时是 1023，d=50 时约 1.126×10¹⁵

每加一个特征，搜索空间翻倍——这是教科书级的组合爆炸（Combinatorial Explosion），最优子集选择已被证明是 NP 难问题。工程上只能放弃"最优"，改用三类近似策略：

💡 关键一跃

三条路线的区别就在"选择与学习谁先谁后、是否互相可见"：过滤式先筛后学（选择不看学习器）；包裹式边搜边学（学习器给每个候选子集打分）；嵌入式不分先后（选择就是学习的副产品）。

⚠️ 常见误区

"冗余特征既然有用就都应该保留"——错。冗余特征徒增维度与过拟合风险，还可能让后续的 ℓ1 选择在高度相关的几个特征间"随机站队"（见 11.3 的稳定性讨论），该扔就扔。

11.2过滤式：先筛后学，Relief 用"近邻对比"给特征打分

上一节说过滤式"不看学习器"，那它凭什么判断特征好坏？Relief 的答案是：看特征能不能帮样本"区分同类与异类的近邻"。对每个采样到的样本 x，找两个邻居——猜中近邻（Near-Hit）：与 x 同类且最近的样本；猜错近邻（Near-Miss）：与 x 异类且最近的样本。然后对每个特征 j 累计：

δj = ∑i（ −diff(xij, xi,nhj)² + diff(xi,nmj)² ）

直觉：好特征应该"离猜错近邻远、离猜中近邻近"，即第二项大、第一项小，δj 为正且越大越好。diff 对连续特征取差值的绝对值（通常先归一化），离散特征相等为 0、不等为 1。分量 δj 大于 0 意味着：在该特征上，异类近邻比同类近邻离得更远——此特征有助于分类。

完整手算一例。6 个样本、2 个类、3 个特征（已归一化到 [0,1]）：

样本f₁f₂f₃类别
x₁0.00.50.9A
x₂0.10.40.8A
x₃0.20.60.85A
x₄0.90.450.1B
x₅0.80.550.2B
x₆1.00.50.15B

取 i = 1，即对 x₁ = (0.0, 0.5, 0.9) 更新一次。用全特征欧氏距离找两个近邻：

候选与 x₁ 的距离结论
x₂（同类）√(0.1²+0.1²+0.1²) = √0.03 ≈ 0.173猜中近邻 nh（同类最近）
x₃（同类）√(0.2²+0.1²+0.05²) = √0.0525 ≈ 0.229同类次近
x₄（异类）√(0.9²+0.05²+0.8²) = √1.4525 ≈ 1.205—

x₆（异类）√(1.0²+0²+0.75²) = √1.5625 = 1.25—

逐特征算 diff 分量（diff 取绝对差，公式中带平方）：

特征−diff(x₁, nh)²+diff(x₁, nm)²本次分量
f₁−|0.0−0.1|² = −0.01+|0.0−0.8|² = +0.64+0.63
f₂−|0.5−0.4|² = −0.01+|0.5−0.55|² = +0.0025−0.0075
f₃−|0.9−0.8|² = −0.01+|0.9−0.2|² = +0.49+0.48

结论一目了然：f₁（+0.63）与 f₃（+0.48）分量为正——异类近邻在这两维上确实更远，它们是有用特征；f₂ 分量约为 0 甚至为负（−0.0075）——它几乎不帮忙区分。对所有样本重复此过程并累加，δ 大的特征入选。

对比包裹式的代表 LVW（Las Vegas Wrapper）：它在特征子集空间里随机试，每试一个子集就真刀真枪训练一次学习器、用交叉验证打分，满意才停。裁判是真实学习器性能（比过滤式的统计量更准），代价是算力——每评估一个子集都要完整训练一遍。

💡 关键一跃

Relief 的评分标准本质是"留一法 1-近邻分类器在该特征上犯错的方向"：离猜错近邻越近越容易分错。它用几何距离代替了显式训练，这是"过滤"二字的全部含义。

⚠️ 常见误区

"Relief 打分时只看单个特征，所以能处理任意维度"——打分确实逐特征进行，但近邻是在全特征空间里找的；高维下距离集中（维度灾难），near-hit/near-miss 失去区分度，Relief 同样需要先用别的方法粗筛。

11.3嵌入式：ℓ1 正则为什么能"自动"选特征

过滤式与学习器脱节，包裹式又太贵。第三条路让特征选择长在训练目标里：给线性回归的平方误差加一个 ℓ1 惩罚项，就是 LASSO（Least Absolute Shrinkage and Selection Operator）：

minw ‖y − Xw‖² + λ‖w‖₁

‖w‖₁ = |w₁| + |w₂| + … 是所有权重绝对值之和；λ 控制惩罚力度。几何直觉一句话：平方误差项的等高线是椭球，ℓ1 约束 |w₁|+|w₂| ≤ t 的区域是菱形，菱形顶点恰好落在坐标轴上——椭球与菱形首次相切的点大概率是顶点，而顶点处某些坐标恰为 0。ℓ2（ridge）的约束区域是圆，切点几乎不可能落在轴上，所以只收缩、不归零。

LASSO 怎么解？坐标下降（Coordinate Descent）：每次只动一个维度 wj，其余冻结。对 wj 而言，目标化为关于它的二次函数加 λ|wj|，闭式解由软阈值（Soft Thresholding）算子给出：

wj = S(ρj, λ) / zj，其中 S(z, λ) = sign(z) · max(|z| − λ, 0)
ρj = ∑i xij(yi − ∑k≠j xikwk)（部分残差），zj = ∑i xij²

完整手算坐标下降的一轮。微型回归：4 个样本、2 个特征（无截距），λ = 1：

特征 1 强相关（对应 y=3），特征 2 弱相关（对应 y=0.4）。从 w = (0, 0) 出发：

第 1 步，更新 w₁（冻结 w₂ = 0）：

  • z₁ = 1² + 1² + 0² + 0² = 2；
  • ρ₁ = 1·(3 − 0·w₂) + 1·(3 − 0·w₂) + 0 + 0 = 6；
  • w₁ = S(6, 1)/2 = sign(6)·max(6−1, 0)/2 = 5/2 = 2.5。

第 2 步，更新 w₂（冻结 w₁ = 2.5）：

  • z₂ = 0² + 0² + 1² + 1² = 2；
  • 样本 3、4 的 x_i1 = 0，故部分残差不受 w₁ 影响：ρ₂ = 1·(0.4 − 0) + 1·(0.4 − 0) = 0.8；
  • |ρ₂| = 0.8 < λ = 1，软阈值直接归零：w₂ = S(0.8, 1)/2 = 0。

第二轮 ρ₁ 仍为 6、w₁ = 2.5 不变，收敛。最终解 w = (2.5, 0)：特征 2 被自动删除，特征选择完成。对照 ridge（同样 λ=1，惩罚 ‖w‖²）：w₁ = 6/(2+1) = 2.0，w₂ = 0.8/(2+1) ≈ 0.267——被收缩但不是 0，特征全部保留。

✅ 判定规则

软阈值的生死线：|ρj| ≤ λ ⟹ wj = 0。特征 j 想"活下来"，它解释部分残差的能力必须超过 λ。λ 就是入选门槛本身——调 λ 就是调入选难度。

⚠️ 常见误区

"LASSO 选出的特征就是真特征"——错。高度相关的一组特征里，LASSO 往往随机挑一个、把其余压成 0，换一批数据可能换另一个"代表"；这是 11.5 末尾"可解释性错觉"的伏笔。想要整组入选可加少量 ℓ2（弹性网）。

11.4从选特征到造字典：稀疏编码与字典学习

前三节都在"挑"已有特征。能不能更进一步：学一组新的"零件"，让每个样本都能用少数几个零件拼出来？这就是稀疏编码（Sparse Coding）：给定字典 B（k 个原子），把每个样本 x 表示成 B 的稀疏线性组合，系数 α 要求稀疏：

minB, α ∑i ‖xi − Bαi‖² + λ∑i ‖αi‖₁

B 不预先给定、也从数据里学，就是字典学习（Dictionary Learning）。整体难解，但交替优化拆开就简单：固定 B 解 α——逐样本就是一个 LASSO（坐标下降+软阈值伺候）；固定 α 解 B——惩罚项消失，退化为普通最小二乘。两个熟问题来回迭代即可。

玩具例（1 维、3 样本、2 原子）：字典原子 b₁ = 1、b₂ = 2，样本 x ∈ {2, −1, 0.5}，λ = 1。用坐标下降给每个样本编码（单维特征时 αj 的更新就是 S(bj·部分残差, λ)/bj²）：

样本 x更新 α₁更新 α₂编码结果
2ρ=1·2=2 → S(2,1)/1² = 1部分残差 2−1·1=1，ρ=2·1=2 → S(2,1)/2² = 0.25(1, 0.25)，重构 1·1+2·0.25 = 1.5
−1ρ=−1 → |−1|≤λ，α₁ = 0部分残差 −1，ρ=2·(−1)=−2 → S(−2,1)/4 = −0.25(0, −0.25)，重构 −0.5
0.5ρ=0.5 ≤ λ，α₁ = 0ρ=2·0.5=1 ≤ λ，α₂ = 0(0, 0)，完全放弃重构

注意 λ=1 的杀伤力：弱样本 x=0.5 的两个系数全被压成 0——它被认为"不值得用任何原子表示"。再固定这些编码，对字典做一步最小二乘更新。以 b₂ 为例：b₂ = Σi αi2(xi − b₁αi1) / Σi αi2²：

  • 分子 = 0.25·(2 − 1·1) + (−0.25)·(−1 − 0) + 0 = 0.25 + 0.25 = 0.5；
  • 分母 = 0.25² + (−0.25)² + 0² = 0.125；
  • 新 b₂ = 0.5 / 0.125 = 4（由 2 更新到 4）。同理新 b₁ = 1·(2 − 2·0.25)/1² = 1.5（由 1 更新到 1.5）。

字典朝着"更能解释数据"的方向移动了一步；如此往复交替，直到收敛。

⚠️ 常见误区

上面 b₂ 从 2 一下跳到 4，暴露了字典学习的尺度模糊（Scale Ambiguity）：B 放大 k 倍、α 缩小 k 倍，目标值不变。所以实践中每步更新后都要把原子归一化（如 ‖bj‖ = 1），否则原子会无限膨胀、系数无限缩小。

💡 关键一跃

普通字典（如傅里叶基、小波基）是人造的通用零件；字典学习是为手头数据定制零件。图像上它学出的原子天然是边缘、角点等局部结构——稀疏表示的"零件"第一次有了语义。

B 放大 k 倍同时 α 缩小 k 倍，目标值不变，原子会无限膨胀。处理：每步字典更新后把每个原子归一化（如单位范数）。

11.5稀疏性的极限礼物：压缩感知

前几节把"稀疏"当作整理数据的手段。本章最后一节展示稀疏假设能走多远：采样本身都可以被压缩。传统观念里，采样率必须不低于信号最高频率的两倍（奈奎斯特定理），否则信息必损。压缩感知（Compressed Sensing）说：如果信号在某个基下是稀疏的，且测量方式足够"乱"，那么远少于信号维度的测量数也能精确还原原信号。

形式化：真实信号 x ∈ ℝⁿ，在某基下是 k-稀疏的（至多 k 个非零分量）；我们拿不到 x，只能拿 m 个线性测量 y = Ax（A 是 m×n 矩阵，m ≪ n）。欠定方程通常有无穷多解，但只要——

  • 前提 1：x 在某基下稀疏（k ≪ n）；
  • 前提 2：A 满足限定等距性（Restricted Isometry Property, RIP）——A 作用在任何 k-稀疏信号上都近似保距，不把它们"压扁"到无法区分。随机高斯/伯努利矩阵以很高概率满足它。

——那么把 NP 难的 ℓ0 最小化放松成 ℓ1 最小化（min ‖x‖₁ s.t. y = Ax），就能以很高概率精确恢复 x。一个数值直觉：n = 10 维信号、只有 3 个非零分量，用约 m = 6 个随机测量即可精确还原——测量数取决于稀疏度 k（约 k·log(n/k) 量级），而不是信号维度 n。这正是"奈奎斯特观念被颠覆"之处：信息量的瓶颈不是信号有多长，而是信号有多"不简单"。

✅ 判定规则

一句话收束本章：稀疏假设贯穿始终——特征选择假设"有用特征很少"，字典学习假设"用少数原子就能拼出样本"，压缩感知假设"非零分量很少所以少量测量够用"。选特征、写字典、压采样，本质都是同一句话：真正重要的维度很少。

⚠️ 常见误区（本章的总代价）

稀疏不是免费的午餐：① 稳定性差——数据抖一抖，LASSO 选出的特征集可能换一茬；② 超参数敏感——λ 大一格稀疏到欠拟合，小一格稀疏性荡然无存，且没有原则性的选法；③ 可解释性错觉——被算法选中 ≠ 因果上重要，相关特征组的"随机站队"会骗你讲故事。稀疏给的是可处理的近似，不是真理。

LASSO（ℓ1 正则）
点击翻面 →
定义min ‖y − Xw‖² + λ‖w‖₁：平方误差加权重绝对值之和的惩罚。

概念卡 4

点击翻面 →

概念卡 5
字典学习与稀疏编码（Dictionary Learning / Sparse Coding）
点击翻面 →

解决问题从"挑现成特征"升级为"为数据定制表示零件"。

概念卡 6
压缩感知（Compressed Sensing）
点击翻面 →
定义k-稀疏信号 + 满足 RIP 的测量矩阵 ⟹ m≪n 个测量经 ℓ1 最小化精确恢复。
解决问题采样成本极高的场合（医学成像、传感器），少采样也能还原。

误区以为推翻奈奎斯特——它换了前提（稀疏性），并非无条件少采样。
何时用MRI 加速、单像素相机；稀疏假设威力的理论天花板。

📝分层习题

L1 概念辨析判断对错并说理由：冗余特征一定是无关特征，所以可以直接删除。
提示

回想两个定义的关键词：无关 = 与任务不相干；冗余 = 信息可被其他特征推出。

完整解答

错，错在把两个不相交的概念混为一谈。冗余特征本身可能与任务高度相关（如"身高（cm）"对预测体重非常有用），只是它的信息被另一个特征（身高（inch））完全覆盖；无关特征则与任务毫不相干（患者编号）。结论"可以删除"碰巧对，但理由全错：删冗余是因为重复、不是因为它没用。易错点：误以为"有用"和"该留"等价——冗余特征有用仍该删。

L1 概念辨析包裹式（如 LVW）比过滤式（如 Relief）贵在哪里？这笔钱买来的好处是什么？
提示

算一算：评估一个候选子集，两边各要做什么？

完整解答

贵在裁判：过滤式评估特征只算统计量（如 Relief 找近邻算 diff），一次扫数据就够；包裹式每评估一个候选子集都要完整训练一次学习器并做交叉验证，子集搜索过程中这样的训练要重复成百上千次，算力开销高几个数量级。

买来的好处：评价标准就是最终学习器的真实性能，选出的子集与后续模型"门当户对"，通常精度更高；而过滤式的统计量与学习器脱节，可能筛掉对模型其实有用的特征。

L2 手算推导① 软阈值：分别计算 S(−1.8, 0.5) 与 S(0.3, 0.5)，并解释后者为什么对特征选择至关重要。
提示

套 S(z,λ)=sign(z)·max(|z|−λ,0)，先看 |z| 与 λ 谁大。

完整解答

S(−1.8, 0.5)：|−1.8| = 1.8 > 0.5，故 = sign(−1.8)·(1.8−0.5) = −1.3。S(0.3, 0.5)：|0.3| = 0.3 ≤ 0.5，max(0.3−0.5, 0) = 0，故 = 0。后者正是 ℓ1 产生稀疏解的机制：部分残差不够强（|z| ≤ λ）的维度被直接归零、彻底删除，而不是仅仅变小——特征选择就是成片的"0.3 → 0"。

L2 手算推导② Relief：5 个样本 s₁=(0, 0, A)、s₂=(0.2, 0.8, A)、s₃=(0.9, 0.3, B)、s₄=(1.0, 0.6, B)、s₅=(0.85, 0.1, B)，对 s₂ 用全特征欧氏距离找近邻，并计算特征 f₁、f₂ 的一次 diff 分量（带平方）。
提示

s₂ 的同类只有 s₁；异类里分别算到 s₃、s₄、s₅ 的距离再取最小。

完整解答

距离：d(s₂,s₁) = √(0.2²+0.8²) = √0.68 ≈ 0.825 → 猜中近邻 = s₁。d(s₂,s₃) = √(0.7²+0.5²) = √0.74 ≈ 0.860；d(s₂,s₄) = √(0.8²+0.2²) = √0.68 ≈ 0.825；d(s₂,s₅) = √(0.65²+0.7²) = √0.9125 ≈ 0.955 → 猜错近邻 = s₄。

f₁ 分量 = −|0.2−0|² + |0.2−1.0|² = −0.04 + 0.64 = +0.60（正，f₁ 有用）；f₂ 分量 = −|0.8−0|² + |0.8−0.6|² = −0.64 + 0.04 = −0.60（负，f₂ 帮倒忙）。

L3 建模应用文本分类：词袋特征 d = 100000 维，样本仅 n = 5000，算力预算有限。你该怎么选特征选择方案？具体说明为什么排除包裹式，以及 λ 调大、调小各自的后果。
提示

先算包裹式在这个 d 下的成本；再想想线性模型 + 什么正则天然适合"特征数 ≫ 样本数"。

完整解答

选型：嵌入式 ℓ1（LASSO 逻辑回归/线性 SVM + ℓ1）。理由：

① 排除包裹式：d = 10⁵ 时子集空间 2^(10⁵) 完全是天文数字，LVW 每试一个子集还要在 5000 样本上训练+交叉验证一次，随机搜索几千轮也未必碰到像样子集，算力预算直接爆掉。

② 为何嵌入式合适：d ≫ n 恰是 ℓ1 的主场——训练一次模型即顺带完成选择，成本约等于一次普通线性模型训练；文本任务中大量词特征本就接近无关，稀疏解通常保留几百到几千词，还顺带缓解了 d≫n 的过拟合。可用过滤式（如 χ² 统计量）先做一轮粗筛再进 ℓ1，进一步提速。

③ λ 的后果：λ 调大 → 门槛抬高，更多词权重归零，模型更稀疏、更省内存，但可能误删判别性词导致欠拟合、精度下降；λ 调小 → 稀疏性消失，解趋近普通最小二乘/逻辑回归，在 d≫n 下立即过拟合，验证集性能崩。实践中用交叉验证沿 λ 的路径（从大到小）选验证性能拐点。
