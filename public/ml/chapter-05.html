5.1从神经元到感知机：一个"打分器"能做什么

第 3 章的线性模型本质上就是一个"加权打分器"：给每个属性一个权重，加总后和阈值比较。但现实中的决策往往不是这样一刀切——西瓜的"好"取决于色泽、纹理、触感之间的组合，单一超平面切不出来。神经网络的出发点，是先把这个打分器打磨成一个标准件，再谈怎么把它们串起来。

M-P 神经元：加权、比较、点火

M-P 神经元（McCulloch-Pitts Neuron）是神经网络的基本零件，1943 年提出，至今没变过样。它做三件事：接收 n 个输入 xᵢ，各自乘权重 wᵢ 求和，减去阈值（Threshold）θ，再把结果送进激活函数（Activation Function）f 得到输出：

y = f(∑i=1n wixi − θ)

阈值 θ 也可以看成"偏置"（Bias）：它和 Ch3 线性模型里的 b 是同一个角色，决定这个神经元有多容易被点着。激活函数 f 是关键——它给这个线性打分器注入非线性。常见的有四种：

激活函数公式值域特点
阶跃函数（Step）f(x) = 1（x ≥ 0），否则 0{0, 1}理想神经元模型，但不连续、不可导，没法做梯度下降
Sigmoidσ(x) = 11 + e−x(0, 1)光滑可导，把任意实数压成"概率感"的输出；两端饱和、导数趋零
双曲正切（tanh）tanh(x) = ex − e−xex + e−x(−1, 1)关于原点对称版的 sigmoid，居中的输出更利于训练
ReLU（Rectified Linear Unit）f(x) = max(0, x)[0, +∞)正半轴恒等、负半轴截零；计算最省，深网里最常用
💡 关键一跃

为什么必须是非线性激活？如果 f 是线性（含恒等），那么多层堆叠等价于一层：f₂(f₁(x)) 仍是 x 的线性函数。非线性是让"多层"有意义的唯一理由——每一层都能把上一层的输出掰弯，层数才真正换来表达力。

感知机：单个 M-P 神经元 + 一条学习规则

感知机（Perceptron）= 一个以阶跃函数为激活的 M-P 神经元 + 一条从错误中学习的规则。对每个样本 (x, y)，感知机先算出预测 ŷ = f(∑wᵢxᵢ − θ)，若预测错了，就按误差 (y − ŷ) 的方向把权重朝"下次能对"推一把：

wi ← wi + η(y − ŷ)xi，  θ ← θ − η(y − ŷ)

其中 η ∈ (0, 1) 是学习率（Learning Rate），控制每一步迈多大。预测对时 y − ŷ = 0，什么都不改——感知机只在犯错时学习。

手算例 1：感知机的一步更新

初始：w = (0, 0)，θ = 0，η = 1。来样本 x = (2, 1)，真实标签 y = 1。分三步：

步骤计算结果
① 前向打分∑wᵢxᵢ − θ = 0×2 + 0×1 − 0 = 0 → ŷ = f(0) = 0（不点火）ŷ = 0 ≠ y = 1，犯错
② 计算误差项y − ŷ = 1 − 0 = 11
③ 更新参数w ← (0,0) + 1×1×(2,1)；θ ← 0 − 1×1w = (2, 1)，θ = −1

验证：更新后同一样本的打分 = 2×2 + 1×1 − (−1) = 4 + 1 + 1 = 6 > 0 ✓，判为 1，分对了。直觉很直白：错把正例判负，说明权重太弱、阈值太高——于是沿着 x 的方向加权重、同时把阈值往下拉，让下次更容易点火。

感知机的边界：XOR 学不会

感知机定理保证了：只要数据线性可分，这条规则有限步内必收敛到一个解。但只要看一个反例就知道它的天花板——异或（XOR）：

x₁x₂y（异或）
000
011
101
110

四个点画在坐标系里：正类 (0,1)、(1,0) 在对角，负类 (0,0)、(1,1) 在另一条对角。任何一条直线都无法把两类分开——这就是"线性不可分"。单个感知机对此无能为力，历史上正是这个批评（Minsky, 1969）让神经网络研究沉寂了十几年。出路只有一个：堆层。

⚠️ 常见误区

误区一："感知机学习规则每步都在减小总误差。"错。它只修正当前犯错的那一个样本，可能在别的样本上引入新错误；保证的是"线性可分时有限步收敛"，不是单调下降。误区二："XOR 说明感知机没用。"恰恰相反，XOR 说明的是单层的边界——加一层隐层，两个"半平面判决"合起来就能围住对角区域（下一节就围给你看）。

5.2多层网络与万有近似：隐层在学什么

上一节把感知机逼到了 XOR 的墙角。出路很直接：既然一刀切不开，那就多切几刀——在输入和输出之间插入一层（或多层）神经元，让中间层先把输入"重新表示"一遍，再由输出层在这个新表示上做线性划分。这就是多层前馈神经网络（Multi-layer Feedforward Neural Network）。

结构约定

  • 层：输入层只是"透传"，不做计算，通常不计入层数；隐层与输出层的神经元才带权重和激活。所以"单隐层网络"也叫两层网络。
  • 前馈（Feedforward）：信号只从输入流向输出，同层不互连、不跨层回头（没有环）。
  • 全连接：相邻两层之间每个神经元两两相连，每条边一个权重，每个隐层/输出神经元一个阈值。

下图为本章反复使用的网络：2 输入、2 隐元、2 输出，权重与偏置的编号在 5.3 的手算中会一一对应。

隐层在干什么：把输入"重新摆放"

看 XOR 怎么被解开。用一个两隐元的网络：h₁ 实现"x₁ 或 x₂ 至少一个为正"，h₂ 实现"x₁ 与 x₂ 同时为正"。四点经隐层变换后的新坐标 (h₁, h₂)：

原输入 (x₁, x₂)h₁（至少一个为 1）h₂（两个都为 1）新坐标 (h₁, h₂)类别
(0, 0)00(0, 0)0
(0, 1)10(1, 0)1
(1, 0)10(1, 0)1
(1, 1)11(1, 1)0

关键变化发生了：原来两个正类点 (0,1)、(1,0) 在新空间里重合到了同一点 (1,0)，而负类点被分别送到了 (0,0) 和 (1,1)。新空间里一条直线（比如判 h₁ − h₂ > 0.5 为正）就能分开两类。隐层做的事，本质是把样本搬到一个更好分的空间里——这就是"神经网络自己学特征"的含义。

万有近似：一层隐层就够强大

万有近似定理（Universal Approximation Theorem）一句话：只需一个含足够多神经元的隐层，多层前馈网络就能以任意精度逼近任意连续函数。直觉版本：每个隐神经元在输入空间里"切一刀"（划分一个半空间），足够多的刀围起来，就能拼出任意的区域边界；再让每个边界对输出的贡献可调，函数形状就近似出来了。

💡 关键一跃

线性模型是"人为定好特征、模型只学权重"；神经网络把特征也变成了参数——隐层的权重就是特征提取器。所谓"学"，是同时学"用什么角度看数据"（隐层）和"从这个角度怎么下结论"（输出层）。

⚠️ 常见误区

误区："万有近似定理说一个隐层就够，所以网络不需要加深。"这是把"存在一个能逼近的网络"误读成"这个规模划算、且能被找到"。定理不告诉你需要多少隐神经元（可能是天文数字），更不给训练方法。实践中用"深而窄"替代"浅而宽"，往往省参数得多——这正是深度学习的出发点，也是本章末尾遗留问题的入口。

5.3误差逆传播：BP 算法一轮完整手算

感知机学习规则很优雅，但它只适用于单层：输出层的误差人人看得见，可隐层神经元的"正确答案"没人告诉它——隐层错在哪、错多少？这是多层网络训练的核心难题。1986 年重新流行的误差逆传播（Error BackPropagation，BP）算法给出答案：把输出端的误差，按链式法则一路分摊回每个权重。

设定：网络、数据与记号

就用图 5.1 的 2-2-2 网络。激活函数全部取 sigmoid：σ(x) = 1/(1 + e−x)，它有个好性质：σ′(x) = σ(x)(1 − σ(x))。学习率 η = 0.5。

类别取值
输入i1 = 0.05，i2 = 0.10
隐层权重与偏置w1 = 0.15，w2 = 0.20，w3 = 0.25，w4 = 0.30，b1 = 0.35
输出层权重与偏置w5 = 0.40，w6 = 0.45，w7 = 0.50，w8 = 0.55，b2 = 0.60
目标输出t1 = 0.01，t2 = 0.99

损失函数用平方误差：

E = 12∑k (ok − tk)²

第一步：前向传播（算出每个神经元的输出）

步骤算式结果
① h1 的输入net_h1 = w1·i1 + w2·i2 + b1 = 0.15×0.05 + 0.20×0.10 + 0.35net_h1 = 0.3775
② h1 的输出h1 = σ(0.3775) = 1/(1 + e−0.3775)h1 = 0.5933
③ h2 的输入net_h2 = w3·i1 + w4·i2 + b1 = 0.25×0.05 + 0.30×0.10 + 0.35net_h2 = 0.3925
④ h2 的输出h2 = σ(0.3925)h2 = 0.5969
⑤ o1 的输入net_o1 = w5·h1 + w6·h2 + b2 = 0.40×0.5933 + 0.45×0.5969 + 0.60net_o1 = 1.1059
⑥ o1 的输出o1 = σ(1.1059)o1 = 0.7514
⑦ o2 的输入net_o2 = w7·h1 + w8·h2 + b2 = 0.50×0.5933 + 0.55×0.5969 + 0.60net_o2 = 1.2249
⑧ o2 的输出o2 = σ(1.2249)o2 = 0.7729
⑨ 总误差E = ½(0.7514 − 0.01)² + ½(0.7729 − 0.99)² = 0.2748 + 0.0236E = 0.2984

第二步：输出层的误差项（δo）与 w5 的更新

对输出神经元 k，定义误差项 δok = ∂E/∂net_ok。由链式法则：∂E/∂o 再乘 sigmoid 的导数 o(1−o)：

δok = (ok − tk) · ok(1 − ok)
步骤算式结果
⑩ o1 的误差项δo1 = (0.7514 − 0.01) × 0.7514×(1 − 0.7514) = 0.7414 × 0.1868δo1 = 0.1385
⑪ w5 的梯度∂E/∂w5 = δo1 · h1 = 0.1385 × 0.5933∂E/∂w5 = 0.0822
⑫ w5 更新w5′ = w5 − η·∂E/∂w5 = 0.40 − 0.5×0.0822w5′ = 0.3589

同理可得输出层其余权重的梯度：∂E/∂w6 = δo1·h2 = 0.0827，∂E/∂w7 = δo2·h1，∂E/∂w8 = δo2·h2，其中 δo2 = (0.7729 − 0.99)×0.7729×(1 − 0.7729) = (−0.2171)×0.1754 = −0.0381。

第三步：误差"分摊"回隐层（BP 的精髓）

隐层神经元 h1 没有自己的目标值，但它的输出同时喂给了 o1 和 o2——所以 h1 要背的锅，是两条下游路径误差按权重加权的和：

步骤算式结果
⑬ h1 分到的误差∂E/∂h1 = δo1·w5 + δo2·w7 = 0.1385×0.40 + (−0.0381)×0.50 = 0.0554 − 0.0190∂E/∂h1 = 0.0364
⑭ h1 的误差项δh1 = (∂E/∂h1) · h1(1 − h1) = 0.0364 × 0.2413δh1 = 0.00878
⑮ w1 的梯度∂E/∂w1 = δh1 · i1 = 0.00878 × 0.05∂E/∂w1 = 0.000439
⑯ w1 更新w1′ = w1 − η·∂E/∂w1 = 0.15 − 0.5×0.000439w1′ = 0.1498

注意第 ⑬ 步是全部算法的灵魂：h1 的误差 = δo1×w5 + δo2×w7，误差沿着来时的边按权重比例倒流。w2…w4 与偏置的更新完全同理：先分摊、再乘本地导数、再乘本地输入。

第四步：更新后再前向一轮，误差真的降了

把更新后的全部权重代回去重算前向，得到新误差 E ≈ 0.2910，比原来的 0.2984 下降了约 0.0074。一步 BP 只走了一小步，但方向对：重复几千轮，误差就一路滚下去。这就是全部神经网络训练的骨架：前向算输出、反向摊误差、梯度下降更新、循环往复。

💡 关键一跃

BP 不是新数学，它是链式法则的记账术：每个权重只为"经它流过去的那一份误差"负责。误差项 δ 是每层的"责任分摊凭证"——输出层的 δ 由目标直接算，隐层的 δ 由下游 δ 按权重加权和再乘本地导数。记住这句话，BP 的所有公式都能现场推出来。

⚠️ 常见误区

误区一："隐层误差是凭空估计的。"错，隐层误差有明确定义：∂E/∂h = Σ（下游δ × 连接权重），是链式法则的直接结果。误区二："BP 一次就把网络训练好。"错，一次前向+反向只完成一步梯度下降；训练要迭代成千上万轮，每轮喂一个样本（随机梯度）或一批样本。误区三："学习率越大收敛越快。"过大易在最优解附近震荡甚至发散，过小则慢——η 是最常用的调参旋钮之一。

5.4训练的坑与对策：局部最小与过拟合

BP 给了训练的方法，但不保证训练顺利。多层网络的误差曲面坑坑洼洼，两个陷阱最常遇到：卡在局部最小出不来，和训练得太好反而过拟合。

陷阱一：局部最小 vs 全局最小

梯度下降像蒙眼下山：每一步都朝眼前最陡的方向走，走到一个四周都比我高的洼地（局部最小，Local Minimum）就停了，尽管远处还有更深的谷（全局最小，Global Minimum）。常见跳出策略（各一句，了解即可）：

  • 多组随机初始值：从不同起点各训一个网络，取误差最小的那个——换起点就是换一座山。
  • 模拟退火（Simulated Annealing）：允许以一定概率接受"变差的解"，靠概率跳出洼地。
  • 随机梯度下降（SGD）：每轮只用单个（或小批）样本，梯度自带噪声，噪声恰好能帮参数晃出浅的局部最小。

陷阱二：过拟合——早停与正则化

网络容量大、权重多，是 Ch2 定义的过拟合高危户。两个标准对策：

  • 早停（Early Stopping）：训练过程中同时盯着训练集误差和验证集误差。训练误差一直降，但验证误差一旦开始回升，立刻停止训练——在"学过头"之前收手。
  • 正则化（Regularization）：在误差函数里加一项对权重大小的惩罚，例如 E ← E + λ∑wᵢ²，逼着网络偏好"小而分散"的权重，降低复杂度。这与 Ch3 的 L2 正则完全同源。

小例子：一条验证曲线定早停点

迭代轮次12345678
训练误差0.300.240.190.150.120.100.080.06
验证误差0.310.260.220.190.180.180.190.21

训练误差一路降到 0.06，但验证误差在第 6 轮触底（0.18）后第 7、8 轮连续回升——早停策略应在第 6 轮收手，留住那时的权重。继续训下去，模型在训练集上越学越好，泛化反而越差，这正是过拟合的标准画像。

还有一堆超参数

隐层个数、每层神经元个数、学习率、迭代轮数……这些不是学出来的，是调出来的（超参数，Hyperparameter）。西瓜书的态度很诚实：隐层神经元个数至今仍靠试错——常用做法是按经验给一个起点，再用验证集做网格搜索。这提醒我们：神经网络的"自动化"是有边界的，特征学习交给了网络，结构选择还留在人手里。

💡 关键一跃

早停和正则化是一体两面：一个从时间上限制模型复杂度（不许学太久），一个从空间上限制（不许权重太大）。两者都在做 Ch2 那件事——用验证集盯住泛化，而不是盯住训练分数。

⚠️ 常见误区

误区一："训练误差还在降，就应该继续训。"错，训练误差单调下降恰恰是过拟合的温床；该看的是验证误差。误区二："局部最小是神经网络的致命伤。"在现代高维网络中，鞍点远比差的局部最小常见，且实践中 SGD 的噪声、好的初始化让这个问题远没有理论上可怕——但"多起点重来"仍是最便宜的对策。

概念卡 1
M-P 神经元（McCulloch-Pitts Neuron）
点击翻面 →
定义y = f(∑wᵢxᵢ − θ)：加权求和、减阈值、过激活函数的标准计算单元。
解决问题给神经网络一个可堆叠的基本零件；没有它谈不上"层"和"网"。
直觉一个挑剔的打分器：各项得分加权过线就点火。
误区以为它是生物神经元的模拟——它只是数学抽象，1943 年至今形态未变。
何时用本章全部结构；深度学习所有网络的祖先单元。
概念卡 2
激活函数（Activation Function）
点击翻面 →
定义套在加权和外的非线性函数：阶跃、sigmoid、tanh、ReLU 等。
解决问题没有非线性，多层复合退化为单层，深度毫无意义。
直觉给线性打分"掰弯"的那一下，让每层能重新塑造空间。
误区以为随便选——BP 需要它可导（阶跃不行），深层偏好 ReLU 防梯度消失。
何时用每个隐层/输出神经元；Ch6 之后所有模型的常备件。
概念卡 3
感知机学习规则（Perceptron Learning Rule）
点击翻面 →
定义犯错即更新：w ← w + η(y − ŷ)x，θ ← θ − η(y − ŷ)。
解决问题第一个"从错误自动学习"的算法；线性可分时有限步收敛。
直觉判错了就把打分杆往正确方向推一把，推多远由学习率 η 控制。
误区以为它逐步单调降总误差——它只修当前样本，可能带歪其他样本。
何时用线性可分二分类；BP 的思想源头（δ 的雏形）。
概念卡 4
万有近似定理（Universal Approximation）
点击翻面 →
定义一个含足够多隐元的单隐层前馈网络，可以任意精度逼近任意连续函数。
解决问题回答"多层网络的表达力有没有理论保障"——有，且一层隐层就够。
直觉每个隐神经元切一刀，足够多的刀围出任意区域、拼出任意形状。
误区读成"所以不需要深度"——它只说存在，不说规模划算、能被找到。
何时用为神经网络表达力背书；理解"为什么还要加深"的出发点。
概念卡 5
误差逆传播（Error BackPropagation, BP）
点击翻面 →
定义前向算输出与误差，反向用链式法则把误差逐层分摊，得每个权重的梯度并下降更新。
解决问题多层网络"隐层错多少没人告诉它"的训练难题。
直觉链式法则的记账术：每个权重只为流经自己的那份误差负责。
误区以为一轮就训好——一轮只是一步梯度下降，训练要迭代成千上万轮。
何时用一切多层网络训练；深度学习框架自动微分的理论原型。
概念卡 6
早停（Early Stopping）
点击翻面 →
定义训练中盯验证集误差，一旦回升就停止，保留回升前的权重。
解决问题大容量网络训练过久必然过拟合，早停在"学过头"前收手。
直觉从时间上限制复杂度：不许学太久，与正则化（从空间上限制）一体两面。
误区拿训练误差当停止信号——训练误差单调下降，恰恰不含泛化信息。
何时用一切迭代式训练；与 Ch2 验证集思想、Ch3 正则化直接呼应。

📝分层习题

L1 概念辨析

判断并说明理由："只要网络层数足够多，用线性激活函数也能逼近任意函数。"

提示

回顾 5.1 的"关键一跃"：线性函数复合的结果是什么？

完整解答

错。线性函数的复合仍是线性函数：f₂(f₁(x)) = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)，无论叠多少层，整体等价于一个单层线性模型，连 XOR 都解决不了。万有近似的前提恰恰是非线性激活（sigmoid、ReLU 等）。易错点：把"深度带来表达力"当成了层数本身的功劳，而忽略了非线性才是让层数有意义的机制。

L1 概念辨析

判断并说明理由："感知机学习规则每次更新都让网络在整个训练集上的总误差减小。"

提示

更新是由哪个样本触发的？它管不管其他样本？

完整解答

错。感知机只在当前犯错样本上更新：w ← w + η(y − ŷ)x。这次更新保证该样本的打分朝正确方向移动，但可能在原本判对的样本上引入新错误，总误差不保证单调下降。感知机收敛定理说的是"若数据线性可分，则有限步内找到某个全部分对的解"，而非"每步总误差递减"。易错点：把"收敛保证"与"单调下降"混为一谈——前者是对终点存在性的保证，后者是对路径性质的要求。

L2 手算推导 ①

单隐元小网络：输入 i1 = 1，i2 = 0；隐层权重 w1 = w2 = 0.5，偏置 b1 = 0；输出层 w5 = 1，b2 = 0。激活函数全部取 sigmoid，目标 t = 1。手算前向传播：net_h、h、net_o、o 与误差 E = ½(o − t)²，写出 σ 的算式与近似值。

提示

先算 net_h = w1·i1 + w2·i2 + b1；σ(x) = 1/(1 + e−x)；e−0.5 ≈ 0.6065。

完整解答

① 隐层输入：net_h = 0.5×1 + 0.5×0 + 0 = 0.5。

② 隐层输出：h = σ(0.5) = 1/(1 + e−0.5) = 1/(1 + 0.6065) = 1/1.6065 ≈ 0.6225。

③ 输出层输入：net_o = w5·h + b2 = 1×0.6225 + 0 = 0.6225。

④ 输出：o = σ(0.6225) = 1/(1 + e−0.6225) = 1/(1 + 0.5365) ≈ 0.6508。

⑤ 误差：E = ½(0.6508 − 1)² = ½×(−0.3492)² = ½×0.1219 ≈ 0.0610。

L2 手算推导 ②

接上题：η = 0.5。手算一步 BP 反向传播：先求 ∂E/∂w5 并更新 w5，再求 ∂E/∂w1 并更新 w1，给出更新后的权重值，步骤写全。

提示

输出层误差项 δo = (o − t)·o(1 − o)；隐层误差 ∂E/∂h = δo·w5，再乘 h(1 − h) 得 δh；权重梯度 = δ × 该权重的输入。

完整解答

① 输出层误差项：δo = (o − t)·o(1 − o) = (0.6508 − 1)×0.6508×(1 − 0.6508) = (−0.3492)×0.6508×0.3492 = (−0.3492)×0.2273 ≈ −0.0794。

② w5 的梯度：∂E/∂w5 = δo·h = (−0.0794)×0.6225 ≈ −0.0494。

③ 更新 w5：w5′ = 1 − 0.5×(−0.0494) = 1 + 0.0247 = 1.0247。

④ 误差分摊回隐层：∂E/∂h = δo·w5 = (−0.0794)×1 = −0.0794（注意：用更新前的 w5 = 1 做分摊）。

⑤ 隐层误差项：δh = (∂E/∂h)·h(1 − h) = (−0.0794)×0.6225×0.3775 = (−0.0794)×0.2350 ≈ −0.01866。

⑥ w1 的梯度：∂E/∂w1 = δh·i1 = (−0.01866)×1 = −0.01866。

⑦ 更新 w1：w1′ = 0.5 − 0.5×(−0.01866) = 0.5 + 0.0093 = 0.5093。

检查方向：输出偏小（0.65 < 1），需要增大输出——w5 与 w1 都增大，方向正确 ✓。

L3 建模应用

场景：给西瓜拍照片，用手机端模型自动判断好坏。输入是照片的像素（例如 128×128 灰度图，共 16384 个像素值）。请回答：① 为什么结构化表格数据（色泽、纹理等人工记录的属性）适合决策树/线性模型，而像素数据要用神经网络？② 画出你设计的网络（层数、各层规模），并说明激活函数与损失函数的选择。

提示

想想"特征从哪来"：表格数据的特征是谁提取的？像素的"特征"又是什么？输出是二分类，输出层该用什么激活、什么损失？

完整解答

① 表格数据的特征（色泽、纹理）已由人提取好、语义明确、维度低，决策树/线性模型直接在特征空间划分即可，且可解释。像素数据相反：单个像素没有语义，"纹理清晰"这种概念藏在大量像素的组合模式里，人工无法写成属性。神经网络（尤其多层结构）的隐层正是自动学特征的机制：底层学边缘、颜色斑块，中层学纹理走向，高层学"瓜脐形态"这类整体模式——这正好补上"特征从哪来"的缺口。

② 参考设计（全连接示意，实际可用卷积结构，思想相同）：

flowchart TB X["输入层 16384（128×128 像素）"] --> H1["隐层1：256 个神经元 · ReLU"] H1 --> H2["隐层2：64 个神经元 · ReLU"] H2 --> O["输出层：1 个神经元 · sigmoid → 好瓜概率"]

参考答案：线性模型切不开线性不可分的数据（如 XOR），本章要解决两个问题——多层网络为什么能表达任意复杂函数（表达力），以及这些网络该怎么训练（可学性）。
句2：核心机制是什么？——
参考答案：把 M-P 神经元用非线性激活串成多层前馈网络，隐层自动学出特征表示（万有近似保证表达力）；训练靠 BP——前向算输出，反向用链式法则把误差逐层分摊成每个权重的梯度，迭代下降；用早停与正则化防过拟合，用多起点/SGD 缓解局部最小。
句3：它和前后章怎么分工？——
参考答案：Ch3 线性模型卡在表达力上，本章用非线性 + 堆层破局，并首次让模型自己学特征；Ch2 的过拟合概念在早停、正则化中落地；后继 Ch6 支持向量机用核技巧走另一条路解决同一个"线性不可分"问题，而本章遗留的"加深为什么有效、梯度消失"直接通向深度学习。
