3.1线性回归与最小二乘：闭式解从哪来

第 2 章给了我们评估模型的尺子，但还缺一个被评估的对象。从本章开始登场的，是机器学习里最古老也最长寿的模型族：线性模型（Linear Model）。它的想法朴素到一句话：给每个特征打一个分数，加权求和，就是预测值。预测房价，面积重要、楼层次要，那就面积乘一个大一点的数、楼层乘一个小一点的数，加起来。

先看只有一个特征的情形。给定数据集 {(x₁,y₁), (x₂,y₂), …, (xm,ym)}，我们要学一条直线：

f(x) = wx + b，使得 f(xi) ≈ yi

什么叫"≈"？需要一把尺子衡量这条直线离数据有多远。最小二乘法（Least Square Method）的选择是：让所有样本的预测值与真实值之差的平方和最小。平方有两个好处：误差的正负不会抵消；且它恰好对应欧氏几何里的"距离"。

(w*, b*) = arg min(w,b) ∑i=1m ( yi − wxi − b )²

这个目标对 w、b 各求偏导并令其为零，就得到两个方程，解出来是漂亮的闭式解（不用迭代、一步算到底）：

w = ∑i (xi − x̄)(yi − ȳ)∑i (xi − x̄)² ，   b = ȳ − w x̄

其中 x̄ = (1/m)∑xi 是 x 的均值，ȳ 是 y 的均值。w 的分子是"x 与 y 的协同波动"，分母是"x 自身的波动"——y 随 x 同涨同落得越整齐，斜率越大。

多元情形：一个矩阵公式打包

特征不止一个时（面积、楼层、朝向、房龄……），模型变成 f(x) = wᵀx + b。把 b 吸收进 w（给每个样本补一个恒为 1 的特征），把所有样本堆成矩阵 X（每行一个样本），所有标记堆成向量 y，同样的"平方误差最小"求导、令导数为零，得到：

ŵ = (XᵀX)⁻¹ Xᵀ y

这个式子值得逐块读：XᵀX 是特征与特征两两之间的"内积表"（各维协同波动的汇总），Xᵀy 是每个特征与标记的协同波动。左乘逆矩阵，相当于"把特征之间互相纠缠的贡献拆解开"，剩下每个特征干净的贡献。这正是上面一元公式 w = 协同波动/自身波动 的矩阵版。

一个直觉：对每个样本，预测 ŷ = Xŵ 其实就是把真实标记向量 y 投影到所有特征张成的平面上——投影点是平面上离 y 最近的点，所以均方误差最小等价于欧氏距离最小。"最小二乘"四个字，几何上就是"找最近的投影"。

💡 关键一跃

线性回归的全部内容可以压成一句话：预测值是特征的加权求和，权重由"让总平方误差最小"唯一确定，且有闭式解。不用迭代、不用调参、一步算出——这就是为什么它是所有人的第一个模型。

⚠️ 常见误区

误区一："最小二乘是因为误差服从正态分布才对的。"——因果倒置：几何上它永远对应"最近投影"，与分布无关；只是当误差恰好正态时，它恰好也等于最大似然解，两者互相印证。误区二："XᵀX 总能求逆。"——当特征数多于样本数、或两个特征完全共线（如"面积（平方米）"与"面积（平方英尺）"同时进入模型），XᵀX 不可逆，闭式解失效。这正是 3.2 正则化要解决的问题之一。

3.2过拟合与正则化：给系数戴上嚼子

上一节的闭式解干净利落，但藏着一个隐患。第 2 章说过过拟合（Overfitting）：模型把训练集里的噪声当规律学走。线性模型也会过拟合——尤其当特征很多、样本很少时，闭式解可以把每个系数调得极大，让直线穿过每一个训练点，训练误差为零，新数据却完全失灵。另一个隐患上一节末尾提过：XᵀX 不可逆时，闭式解直接不存在。

两个隐患，同一个药方：别让系数太放肆。在损失函数里加一项对系数的惩罚，这就是正则化（Regularization）。

岭回归：平方惩罚，把系数整体往回收

岭回归（Ridge Regression）在均方误差后面加上系数的平方和（L2 范数的平方），λ ≥ 0 控制惩罚力度：

minw ‖ Xw − y ‖² + λ ‖w‖²

同样求导令其为零，闭式解还在，只是括号里多了一块：

ŵ = ( XᵀX + λI )⁻¹ Xᵀ y

λI 是 λ 乘单位矩阵——它像给 XᵀX 的主对角线垫高了一截，保证矩阵可逆（"岭"这个名字正来自对角线上这道"山脊"）。λ = 0 时退化回普通最小二乘；λ 越大，系数被压得越小。

手算例 2：一个 λ 如何把 w 从 1 压到 0.5

用一个能口算的一维例子看惩罚项怎么起作用。3 个样本，直线过原点（无截距）：x : 1, 2, 3；y : 1, 2, 3。

  • 不加正则（λ = 0）：损失 = Σ(yi − w·xi)²。对 w 求导：−2Σ xi(yi − w·xi) = 0，得 w = Σxiyi / Σxi²。
  • 算分子：Σxiyi = 1×1 + 2×2 + 3×3 = 1 + 4 + 9 = 14；算分母：Σxi² = 1 + 4 + 9 = 14。
  • 于是无正则解 w = 14/14 = 1。完美拟合，毫不意外——数据本来就在直线 y = x 上。
  • 加岭正则（λ = 14）：一维情形下公式退化为 w = Σxiyi / (Σxi² + λ)。
  • 代入：w = 14 / (14 + 14) = 14/28 = 0.5。

看清发生了什么：数据本身毫无噪声，完美落在 y = x 上，可仅仅因为加了惩罚，系数就被从 1 拉向 0，拉到了 0.5。λ 越大，拉力越强。这就是正则化的全部机制：用一点点训练集上的偏差，换系数的大幅收缩，从而换来新数据上的稳定（偏差-方差权衡，Ch2 的老朋友）。

LASSO：换一种惩罚，顺带做特征选择

把平方惩罚换成绝对值惩罚（L1 范数），就得到 LASSO（Least Absolute Shrinkage and Selection Operator）：

minw ‖ Xw − y ‖² + λ ∑j |wj|

差别在几何上：L2 的可行域是个光滑的圆（高维是球），误差等高线与圆相切的点几乎不可能恰好在坐标轴上；而 L1 的可行域是个菱形（高维是多面体），顶点恰好都戳在坐标轴上——等高线最先碰到的往往就是这些顶点，顶点处某些系数恰为 0。于是 LASSO 会把不重要特征的系数直接清零，顺带完成了特征选择，给出的解是稀疏的。

💡 关键一跃

正则化 = 给学习立一条家规：系数想变大，必须拿出足够的数据证据来换。L2 让系数普遍变小，L1 让没证据的系数直接归零。λ 是家规的严厉程度，用验证集来挑（Ch2 的工具）。

⚠️ 常见误区

误区："λ 越大越好，惩罚越狠越不容易过拟合。"错。λ 过大会把所有系数都压向 0，模型变成一条水平线，什么都不学——从过拟合一头栽进欠拟合。λ 是超参数，没有理论最优值，只能在验证集上调：这正是 Ch2"评估尺子"在本章的第一次实战。

3.3对率回归：把线性输出变成概率

前两节都在预测连续值。可生活中更多的是分类问题：这个瓜好不好、这封邮件是不是垃圾。能不能让线性模型直接输出类别？最直接的补丁是：把 z = wᵀx + b 扔进一个阶跃函数，z > 0 判正类，z < 0 判负类。但阶跃函数在零点不可导，整条学习链断在那里。我们需要一个长得像阶跃、却处处光滑可导的替代品——对数几率函数（Logistic Function，即 sigmoid）：

σ(z) = 11 + e−z

它把任意实数 z 压扁到 (0, 1) 区间：z → −∞ 时 σ → 0，z = 0 时 σ = 0.5，z → +∞ 时 σ → 1，且在 z = 0 附近最陡。压扁之后的数可以理直气壮地读作概率："样本属于正类的概率是 p = σ(z)"。

为什么名字叫"对数几率"？把式子倒过来解出 z：z = ln( p / (1−p) )。p/(1−p) 叫几率（Odds，正类概率与负类概率之比），取对数就是"对数几率"。所以这个名字的本义是：用线性模型去拟合对数几率。

对率回归（Logistic Regression）：p = P(y=1 | x) = σ(wᵀx + b)

损失函数：不用平方误差，用交叉熵

p 是概率，怎么衡量"预测得准不准"？用极大似然（Maximum Likelihood）：让每个样本的真实标签在模型下出现的概率尽量大。对单个样本，"出现得对不对"可以写成一个紧凑式子，取负对数就是交叉熵损失（Cross-Entropy Loss）：

L = − [ y · ln p + (1 − y) · ln(1 − p) ]

读法：y = 1 时只剩 −ln p（p 越接近 1 损失越小）；y = 0 时只剩 −ln(1−p)（p 越接近 0 损失越小）。一个式子，两种情况自动切换。

交叉熵对 w 求导，会得到一个惊人地干净的结论（推导略，结论是本章最重要的口粮公式）：

∂L∂w = (p − y) · x ，   ∂L∂b = p − y

梯度 = （预测概率 − 真实标签）× 输入。预测得越离谱，步子迈得越大；预测对了，梯度自动归零。这正是 sigmoid 与交叉熵"天作之合"的地方——e 的指数、对数全部约掉了。

手算例 3：一步梯度下降，看清损失怎么降

单特征、单样本：x = 1，y = 1。初始参数 w₀ = 0，b₀ = 0，学习率 η = 0.1。

  • 第 1 步，前向算概率：z₀ = w₀·x + b₀ = 0×1 + 0 = 0；p₀ = σ(0) = 1/(1+e⁰) = 1/2 = 0.5。模型完全没把握，五五分。
  • 第 2 步，算当前损失：L₀ = −[1·ln 0.5 + 0] = −ln 0.5 = ln 2 ≈ 0.693。
  • 第 3 步，算梯度：∂L/∂w = (p₀ − y)·x = (0.5 − 1)×1 = −0.5；∂L/∂b = p₀ − y = −0.5。
  • 第 4 步，更新参数（沿梯度反方向）：w₁ = w₀ − η·∂L/∂w = 0 − 0.1×(−0.5) = 0.05；b₁ = 0 − 0.1×(−0.5) = 0.05。
  • 第 5 步，验证损失真的降了：新的 z₁ = 0.05×1 + 0.05 = 0.1；p₁ = σ(0.1) = 1/(1+e−0.1) = 1/(1+0.9048) ≈ 1/1.9048 ≈ 0.525。
  • 新损失 L₁ = −ln 0.525 ≈ 0.644 < 0.693。一步之后，概率从 0.500 涨到 0.525，损失从 0.693 降到 0.644——梯度下降确实在干活。

照此迭代几百上千步，w、b 会持续增大，p → 1，损失 → 0。这就是对率回归训练的全过程：前向算概率、算梯度、反向更新，循环往复。第 5 章神经网络的反向传播，骨架与此一模一样。

💡 关键一跃

为什么叫"回归"却干分类的活？因为它回归的对象是概率（确切说，是对数几率 z）：先用线性模型回归出一个连续的概率值，再用阈值（通常 0.5）把概率切成类别。名字里的"回归"说的是中间那一步，"分类"说的是最后那一步。

⚠️ 常见误区

误区一："对率回归用均方误差当损失也行。"理论上能算，但平方误差下 σ 的指数与对数约不掉，梯度变得又小又别扭，训练极慢；交叉熵让梯度恰好等于 (p−y)x，干净利落。误区二："输出 0.8 就是 80% 把握这个瓜好。"方向对，但要记住这个概率是模型自己打分，它是否真值得信任（校准好不好）是另一回事——评估它还得回到 Ch2 的尺子。

L = −[y·ln p + (1−y)·ln(1−p)]；∂L/∂w = (p−y)x。预测越离谱步子越大，预测对则梯度自动归零。

3.4线性判别分析 LDA：找个方向投影

对率回归的思路是"给线性输出裹一层概率"。还有一条完全不同的岔路：不纠结输出形式，直接在几何上动手。想象二维平面上两类点，线性判别分析（Linear Discriminant Analysis，LDA）的想法是：找一根合适的直线，把所有样本投影上去，让投影点"同类抱团、异类远离"——降维之后，一个阈值就把两类切开。

把这句话拆成两个可计算的指标。设两类的均值向量为 μ₀、μ₁，类内散布（各样本离自己类均值的偏离）汇总成类内散度矩阵 Sw。好方向 w 要同时满足：

  • 类间远：两类均值的投影离得尽量开，即 wᵀ(μ₀−μ₁) 的绝对值尽量大；
  • 类内近：每类自己的投影尽量抱团，即 wᵀSww 尽量小。

"分子大、分母小"的最优方向有闭式解：

w ∝ Sw−1 ( μ₀ − μ₁ )

读法：先取"两均值之差"这个方向（它们当然隔得开），再用 Sw−1 修正——若某个方向类内散布很大，就把它压一压。（∝ 表示"正比于"：方向最重要，长度无所谓，反正最后只看投影值的相对位置。）

手算例 4：两个类、四个点，算出投影方向并验证分开

类 0 两个样本：(1,2)、(3,4)；类 1 两个样本：(3,2)、(5,0)。一步步来：

第 1 步，算两类均值：

  • μ₀ = ( (1+3)/2, (2+4)/2 ) = (2, 3)；
  • μ₁ = ( (3+5)/2, (2+0)/2 ) = (4, 1)。

第 2 步，算各样本对自己类均值的偏差：

  • 类 0：(1,2)−(2,3) = (−1,−1)；(3,4)−(2,3) = (+1,+1)。
  • 类 1：(3,2)−(4,1) = (−1,+1)；(5,0)−(4,1) = (+1,−1)。

第 3 步，算类内散度（偏差的外积求和，不除以样本数）。外积 uvᵀ 的含义：若偏差为 (a,b)，外积就是 [[a², ab],[ab, b²]]。

  • 类 0 第一项：(−1,−1) 的外积 = [[(−1)², (−1)(−1)],[(−1)(−1), (−1)²]] = [[1, 1],[1, 1]]；第二项 (+1,+1) 的外积同样是 [[1, 1],[1, 1]]。相加得 Σ₀ = [[2, 2],[2, 2]]。
  • 类 1 第一项：(−1,+1) 的外积 = [[1, −1],[−1, 1]]；第二项 (+1,−1) 的外积同样是 [[1, −1],[−1, 1]]。相加得 Σ₁ = [[2, −2],[−2, 2]]。
  • 类内散度矩阵 Sw = Σ₀ + Σ₁ = [[2+2, 2−2],[2−2, 2+2]] = [[4, 0],[0, 4]] = 4I。

第 4 步，求投影方向。Sw = 4I 是单位阵的倍数，它的逆就是自身除以 4：Sw−1 = (1/4)I。而 (1/4)I 乘任何向量都不改变方向，所以：

w ∝ Sw−1(μ₀−μ₁) = 14 · (μ₀−μ₁) ∝ μ₀−μ₁ = (2−4, 3−1) = (−2, +2)，即方向 (−1, +1)

这个例子故意构造得干净：两类的类内散布（一个沿"左上-右下"散开，一个沿"左下-右上"散开）恰好互相抵消，Sw 变成纯粹的球（4I），于是最优方向就是均值连线方向，不用修正。

第 5 步，投影验证：投影值 = 样本向量与 w 的内积（取 w = (−1, 1)）：

类别样本投影值 wᵀx = (−1)·x₁ + (1)·x₂
类 0(1, 2)−1 + 2 = +1
(3, 4)−3 + 4 = +1
类 1(3, 2)−3 + 2 = −1
(5, 0)−5 + 0 = −5

看结果：类 0 两点投影同为 +1（完全抱团），类 1 两点为 −1、−5（类均值投影恰为 −3，与类 0 相距 4）。两类投影区间 [+1,+1] 与 [−5,−1] 零重叠——投影之后完全分开，阈值取 0 即可全对。LDA 承诺的"类内近、类间远"在这个例子上分毫不差。

💡 关键一跃

LDA 把分类问题翻译成了几何问题：分类 = 降维 + 阈值。方向 w 负责把高维样本压到一条线上，压的时候兼顾"同类近、异类远"；压完以后，分类只需要在这条线上找一个分界点。它也是"降维"思想的第一次正式登场（Ch10 还会再见）。

⚠️ 常见误区

误区一："最优方向就是 μ₀−μ₁，不用管 Sw。"只有像本例这样类内散布呈球形（Sw ∝ I）时才成立；一旦类内散布有方向性（某方向很散），Sw−1 会把方向往"散布小的轴"上拧。误区二："LDA 的 w 长什么样都行。"在 w 与 −w 上投影只是正负对调，分类效果相同——学的是方向，不是向量本身。

3.5多分类与类别不平衡：二分世界的出口

对率回归和 LDA 都只会做二分类：好瓜/坏瓜、垃圾邮件/正常邮件。可现实标签常常有更多取值——手写数字有 10 类、水果有几十种。怎么让二分类器干多分类的活？思路是拆解：把多分类问题拆成若干个二分类问题，训练多个分类器，最后投票汇总。两种经典拆法：

  • 一对其余（One-vs-Rest，OvR）：每类各训练一个分类器，第 k 个分类器回答"是第 k 类、还是其余所有类？"。N 个类别需要 N 个分类器。预测时让 N 个分类器都打分（对率回归正好给出概率），选得分最高的那一类。
  • 一对一（One-vs-One，OvO）：每两个类别之间训练一个分类器，只区分"是 A 还是 B"。N 个类别需要 N(N−1)/2 个分类器。预测时全体投票，得票最多的类胜出。

算一笔账：4 个类别要训几个分类器

OvR 一对其余OvO 一对一
分类器个数（N 类）NN(N−1)/2
N = 4 时4 个（"是1?"、"是2?"、"是3?"、"是4?"）6 个（1v2、1v3、1v4、2v3、2v4、3v4）
每个分类器用多少数据全部 m 个样本只用过两类的样本（更少）
训练总开销小类多时大（但单个快）
预测开销小（N 次打分）类多时大（N(N−1)/2 次投票）

N = 4 时 OvO 已经是 6 个分类器；N = 10（手写数字）时 OvR 10 个、OvO 45 个。类别越多，两者差距越悬殊——但 OvO 每个分类器只用两类数据、问题更简单，投票机制还能互相纠错，实际精度常常更好。没有免费午餐，按数据量与类别数权衡着选。

类别不平衡：当一类淹没另一类

还有一个现实刺头：两类样本数量悬殊。99 封正常邮件对 1 封垃圾邮件，分类器把所有邮件都判"正常"就有 99% 精度——可这模型毫无用处（Ch2 警告过：此时精度是骗人的尺子）。三种处理思路，一句话版本：

  • 欠采样：从多数类里删掉一些样本，让两类数量相当（代价：丢弃信息）；
  • 过采样：给少数类"复制"或插值出新样本（代价：可能放大噪声）；
  • 再缩放：不改数据，改决策——预测时用"观测几率 ÷ 训练集原始几率"做校正，相当于把分类阈值向多数类方向挪。
💡 关键一跃

多分类的核心思想是拆解与汇总：复杂的 N 类问题拆成一堆简单的二分类，再把多个判决汇总成最终结论。这个"拆-合"范式后面会反复出现——Ch8 集成学习本质上也是它的亲戚。

⚠️ 常见误区

误区一："OvR 和 OvO 只是实现细节，效果一样。"类数大时训练开销、预测开销、精度都可能拉开差距。误区二："类别不平衡时看精度就知道模型好不好。"99:1 的数据上"全猜多数类"也有 99% 精度——不平衡数据要换尺子（查准率、查全率、AUC，回 Ch2 查），或者先处理不平衡再谈精度。

点击翻面 →
定义p = σ(wᵀx + b)，用线性模型拟合对数几率，输出正类概率做分类。
解决问题让线性模型从"预测连续值"跨界到"输出概率做分类"。

概念卡 4
sigmoid / 对数几率函数
点击翻面 →
定义σ(z) = 1/(1+e⁻ᶻ)，把任意实数光滑地压进 (0,1)。
解决问题替代不可导的阶跃函数，让"输出概率"可以求导、可以梯度下降。

点击翻面 →

解决问题从纯几何角度做二分类：分类 = 降维到一条线 + 阈值。
直觉顺着两堆点的"质心连线"打光，影子最分开；影子太散就把方向往散得小的轴上拧。

📝分层习题

L1 概念辨析

判断并说明理由："对率回归（Logistic Regression）是一种回归模型，因为它预测一个 0 到 1 之间的连续值。"

提示

区分"中间步骤做什么"与"最终任务是什么"；想想它输出之后那个 0.5 阈值。

完整解答

错。对率回归是分类模型。它中间的连续输出 p 是正类的概率估计，最终判定要靠阈值（通常 0.5）把概率切成 0/1 类别。"回归"指它用线性模型拟合对数几率这个中间量，而不是指任务类型。易错点：把中间步骤的"回归概率"误当成最终任务——判别标准是输出最终被用作什么。

L1 概念辨析

判断并说明理由："岭回归中 λ 越大，模型越不容易过拟合，所以实践中应把 λ 调得尽量大。"

提示

想想 λ → ∞ 时模型变成什么样；过拟合的对立面是什么。

完整解答

错。λ 控制的是偏差-方差权衡：λ 大确实压低方差（抗过拟合），但同时抬高偏差。λ → ∞ 时所有系数被压到 0，模型退化为常数预测——彻底欠拟合，训练集都拟合不了。正确做法是把 λ 当超参数，在验证集上选出泛化误差最小的值（Ch2 方法）。易错点：把"正则化有益"推成"正则化越强越有益"，忽略了它是权衡而非单向好事。

L2 手算推导

给定 3 个样本：x : 0, 1, 2；y : 1, 3, 5。用最小二乘闭式解手算一元线性回归的 w 和 b，步骤写全。

提示

先算 x̄ 和 ȳ，再列偏差表算 Σ(x−x̄)(y−ȳ) 与 Σ(x−x̄)²，最后 w 与 b。

完整解答

① 均值：x̄ = (0+1+2)/3 = 1；ȳ = (1+3+5)/3 = 9/3 = 3。

② 偏差表：x=0：x−x̄=−1，y−ȳ=−2，乘积 2，平方 1；x=1：0，0，乘积 0，平方 0；x=2：+1，+2，乘积 2，平方 1。

③ 求和：Σ(x−x̄)(y−ȳ) = 2+0+2 = 4；Σ(x−x̄)² = 1+0+1 = 2。

④ w = 4/2 = 2；b = ȳ − w·x̄ = 3 − 2×1 = 1。

⑤ 验证：f(x) = 2x+1 → f(0)=1，f(1)=3，f(2)=5，三点全部命中（数据本就在直线 y=2x+1 上，残差全为 0）。

L2 手算推导

对率回归单样本一步更新：x = 2，y = 0，当前 w₀ = 0.5，b₀ = 0，学习率 η = 0.1。手算：前向概率 p₀、梯度 ∂L/∂w 与 ∂L/∂b、更新后的 w₁ 与 b₁。（σ(1) = 1/(1+e⁻¹) ≈ 0.731）

提示

z = wx + b；p = σ(z)；梯度公式 ∂L/∂w = (p−y)x，∂L/∂b = p−y；沿负梯度方向走一步。

完整解答

① 前向：z₀ = w₀·x + b₀ = 0.5×2 + 0 = 1；p₀ = σ(1) = 1/(1+e⁻¹) ≈ 1/(1+0.3679) ≈ 0.731。真实标签是 0，模型却给了 0.731 的正类概率——错得不轻。

② 梯度：∂L/∂w = (p₀ − y)·x = (0.731 − 0)×2 = 1.462；∂L/∂b = p₀ − y = 0.731。

③ 更新：w₁ = w₀ − η·∂L/∂w = 0.5 − 0.1×1.462 = 0.5 − 0.1462 ≈ 0.354；b₁ = 0 − 0.1×0.731 ≈ −0.073。

④ 验证方向：新 z₁ = 0.354×2 + (−0.073) = 0.635，p₁ = σ(0.635) ≈ 0.654 < 0.731——正类概率下降，朝正确答案 0 靠近，损失同步下降。方向对了。

L3 建模应用

西瓜场景：你手上有 200 个瓜的数据，每个瓜有"密度"（连续）和"含糖率"（连续），以及专家标注的"好/坏"。三个任务：① 预测一个新瓜的含糖率数值；② 判断新瓜好不好；③ 若好瓜只占 3%，评估第②问的模型时该注意什么。请为每个任务选模型/方法并给出理由，评估指标要接上 Ch2。

提示

任务①的输出是连续值还是类别？任务②的两个候选模型各给什么额外信息（概率？几何分界面？）？任务③回想 Ch2 哪个指标在 99:1 下会骗人。

完整解答

① 线性回归：输出是连续数值，正是最小二乘的主场。用密度（可加其他特征）做特征，含糖率为 y，闭式解一步出参数。评估用均方误差 / 平均绝对误差（回归尺子）。

② 对率回归或 LDA，两者都行，差别在附带产物：对率回归给出"好瓜概率"，便于设定不同阈值（如更保守地少错杀好瓜）；LDA 给出几何分界面与降维后的投影值，便于可视化和解释"沿哪个方向分开"。评估不能只看精度——见③。

③ 好瓜仅 3% 即严重类别不平衡："全判坏瓜"也有 97% 精度，精度尺子失灵。应换用 Ch2 的查准率、查全率、F1 或 AUC；训练上可做欠采样/过采样/再缩放（阈值校正）；最终结论须在按同样比例或分层采样的测试集上报告。

  • B. 它通过梯度下降迭代逼近最优解
  • C. 它最小化预测值与真实值之差的平方和，几何上等于找最近投影
  • D. 它的解总能由 (XᵀX)⁻¹Xᵀy 算出
解析：C 对——平方和最小 ⟺ 欧氏距离最小 ⟺ 最近投影，这是定义层面的事实。A 错：因果倒置，正态假设只是让它恰好等于最大似然，不是前提。B 错：线性回归有闭式解，一步算出，无需迭代。D 错：XᵀX 不可逆（特征共线或特征数多于样本数）时闭式解失效，需加 λI 等处理。
自测 2
岭回归与 LASSO 的关键差别是？
  • A. 岭回归用于分类，LASSO 用于回归
  • B. LASSO 的 L1 惩罚易产生系数恰为 0 的稀疏解，岭回归的 L2 只缩小不清零
  • C. 岭回归没有闭式解，LASSO 有
  • D. LASSO 的惩罚力度不受 λ 控制
解析：B 对——L1 可行域是菱形，顶点在坐标轴上，等高线先碰到顶点 → 系数清零（稀疏解，顺带特征选择）；L2 是圆，切点任意，只缩小。A 错：两者都是回归的正则化。C 错：恰好相反，岭回归有闭式解 (XᵀX+λI)⁻¹Xᵀy，LASSO 因 L1 不可导而没有。D 错：两者的惩罚力度都由 λ 控制。
自测 3
对率回归中，交叉熵损失对 w 的梯度是？
  • A. (y − p) · x
  • B. (p − y) · x
  • C. p · (1 − p) · x
  • D. −ln(p) · x
解析：B 对——sigmoid 与交叉熵配套求导，e 与 ln 全部约掉，剩 (p−y)x。A 错：符号反了，用它更新会让参数朝错误方向走（梯度上升）。C 错：p(1−p) 是 sigmoid 自身的导数 σ′(z)，单独对 z 求导时才出现，配上交叉熵后被约掉。D 错：那是损失函数的形状，不是梯度。
自测 4
LDA 选择投影方向 w ∝ S_w⁻¹(μ₀−μ₁) 的目标是？
  • A. 让所有样本的投影值尽量接近 0
  • B. 让两类均值投影尽量远即可，类内散布无所谓
  • C. 让投影方向与 μ₀−μ₁ 垂直，避免过拟合
  • D. 让同类投影尽量抱团、异类投影尽量远离
解析：D 对——"类内近、类间远"是 LDA 的全部目标，S_w⁻¹ 正是为压制类内散布大的方向而存在。A 错：投影值的具体位置不重要，重要的是两类是否分开。B 错：只看均值会选出类内散布极大的方向，投影后两类仍混作一团。C 错：恰恰相反，方向以 μ₀−μ₁ 为基础做修正，绝非垂直。
自测 5
某数据集有 10000 封正常邮件和 100 封垃圾邮件。某模型把所有邮件都判为"正常"，精度 99.01%。下列说法正确的是？
  • A. 99.01% 精度说明该模型很优秀，可以上线
  • B. 这是过拟合的典型表现，用 L2 正则化即可解决
  • C. 类别不平衡下精度尺子失灵，应换查准率/查全率/AUC，并用采样或再缩放处理不平衡
  • D. 该模型查全率很高，只是查准率略低
解析：C 对——99:1 下"全猜多数类"也能拿 99% 精度，精度失效；须换尺子（查准率/查全率/F1/AUC），并用欠采样、过采样或再缩放处理不平衡。A 错：该模型连一封垃圾邮件都没抓到过，毫无用处。B 错：这不是过拟合问题，是评估指标与数据分布问题，正则化帮不上。D 错：它对垃圾邮件的查全率是 0%（一封没抓到），说反了。
