16.1财富是连乘的，所以要最大化对数

前面 15 章里，对数一直是"信息的单位"。这一章它换了一身衣服登场：财富的单位。原因朴素：投资收益不是相加的，而是相乘的——今天涨 10% 明天跌 10%，你的财富不是不变，而是 1.1×0.9 = 0.99。要理解长期财富，就必须理解连乘积，而连乘积的天敌是：它不听话、不可加。对数恰好把乘变成加。

设定：每期你按一个比例向量 b = (b₁, …, bm) 分配财富（bᵢ ≥ 0，Σbᵢ = 1，不许卖空不许借贷）；市场这期的表现是一个相对价格向量（Price Relative）X = (X₁, …, Xm)，Xᵢ = 资产 i 期末价/期初价（Xᵢ = 2 表示翻倍）。那么 1 元财富经过这一期变成 bᵀX = Σ bᵢXᵢ 元；n 期独立重复后：

Sn = ∏i=1..n bᵀXi

连乘积的概率行为由大数定律接管，但接管的是对数：

1n log₂ Sn = 1n Σi log₂ bᵀXi → E log₂ bᵀX ≝ W(b)　（依概率收敛）

于是 Sn ≈ 2nW(b)：财富以每期 2W 倍指数增长。W(b) 叫作该策略的翻倍率（Doubling Rate）——它度量"财富翻一番需要几期"的倒数：W = 1 表示每期翻一倍，W = 0 表示原地踏步，W < 0 表示走向破产。长期投资者的唯一目标：选 b 使 W(b) 最大。

热身模型：赛马（Horse Race）

赛马是"每期财富一次性全押"的极简市场：m 匹马，马 i 赢的概率为 pᵢ；若马 i 赢，押在它身上的每 1 元变成 oᵢ 元（赔率，Odds），其余注金没收。这就是相对价格：Xᵢ = oᵢ（若 i 赢），其余为 0。按比例 b 下注后，一期财富变为 bᵢoᵢ（i 为胜者），翻倍率为：

W(b, p) = Σi pi log₂(bioi)

赔率叫公平赔率（Fair Odds），如果 Σ 1/oᵢ = 1（等价为 oᵢ = 1/rᵢ 且 Σrᵢ = 1，r 可解读为"庄家眼里的概率"）。

例 1（手算）：最优下注是按真实分布下注

断言：无论赔率如何，W(b,p) 在 b* = p 处取最大值。证明只用一条老工具 D(p‖·) ≥ 0，一步不落：

W(b,p) − W(p,p) = Σi pi log₂(bioi) − Σi pi log₂(pioi)
= Σi pi log₂ bioipioi = Σi pi log₂ bipi = −D(p‖b) ≤ 0

等号当且仅当 b = p。这就是赛马等价（Proportional Betting，也称 Kelly betting 的赛马版）：按真实概率下注是最优的，最优翻倍率 W* = Σ pᵢ log₂(pᵢoᵢ)。

特例：赔率全部相同，oᵢ = m（m 匹马、完全公平，因为 Σ1/m = 1）：

W* = Σi pi log₂(pi·m) = log₂ m + Σi pi log₂ pi = log₂ m − H(X)

读法：log₂ m 是"赛道白送的"增长率，H(X) 是赛果的不确定性。熵每少 1 比特，财富每期多翻一倍——这是本章第一次出现"熵直接换钱"。

最小数值例：两匹马，p = (1/2, 1/2)，公平赔率 2 赔 1（o = (2,2)）。此时 m = 2，H(X) = 1 比特，W* = log₂2 − 1 = 0。按 b* = (1/2,1/2) 下注：无论谁赢，财富都变成 ½×2 = 1 元——信息和钱刚好打平：赛果的 1 比特不确定性恰好吃掉赔率白送的那 1 比特增长率。

💡 关键一跃

连乘世界里，平均财富 E[Sₙ] 和典型财富 Sₙ 是两回事。E[Sₙ] 被极小概率的暴富路径抬高，而你的那条路径几乎必然按 2nW 走。最大化 E log（而不是 log E、更不是 E）才是对你自己的钱包负责——这是全章的公理，也是凯利准则（Kelly Criterion）的全部直觉。

⚠️ 常见误区

"期望收益为正就值得全押"——错。全押单匹马时，只要有一期押错财富就归零（log 0 = −∞），W = −∞。翻倍率惩罚一切把财富清零的可能；它奖励的不是"赌赢"，而是"活得久且复利快"。下一节的例 2 会给你看到一个 E[X] > 1 却必须只押一半的资产。

16.2对数最优组合：算术平均赚钱，几何平均原地踏步

赛马太干净了：每期只能有一匹马赢，资产互相排斥。真实的组合里，各资产各自涨跌、结果相加（bᵀX），这才是对数最优组合（Log-Optimal Portfolio）的一般问题：maxb W(b) = E log bᵀX。本节用一个可以全程手算的市场，看它给出什么反直觉的答案。

例 2（核心手算例）：翻倍或减半的股票 + 不动的现金

市场每期独立：股票相对价格 X ∈ {2, 1/2}，各以概率 1/2（要么翻倍要么腰斩）；现金 X = 1（无风险、无利息）。

第一步：先看算术平均的诱惑。股票的期望回报 E[X] = ½×2 + ½×(1/2) = 1 + 1/4 = 1.25 > 1——"平均而言每期赚 25%"，看起来很诱人。

第二步：全押股票的长期下场。设 b = 1 全押股票：

W = 12 log₂ 2 + 12 log₂ 12 = 12×1 + 12×(−1) = 0

W = 0：典型路径上财富原地踏步。直觉：涨一倍再腰斩，1×2×½ = 1，两期回到起点。算术平均每期 +25%，几何平均（典型路径）每期 +0%——波动本身在吃掉复利，这叫波动拖累（Volatility Drag）。

第三步：设 b 投股票、(1−b) 持现金，写出 W(b)。期末财富相对值：股票赢时 b·2 + (1−b)·1 = 1 + b；股票输时 b·(1/2) + (1−b) = 1 − b/2。所以：

f(b) = 12 log₂(1+b) + 12 log₂(1 − b/2)，　b ∈ [0,1]

第四步：求导找驻点。（log₂ 求导换底：d/db log₂ u = u′/(u ln 2)，常数因子 1/ln 2 不影响零点。）

f′(b) = 12(1+b) − 1/22(1−b/2) = 12(1+b) − 14−2b

令 f′(b) = 0：2(1+b) = 4 − 2b ⟹ 2 + 2b = 4 − 2b ⟹ 4b = 2 ⟹ b* = 1/2。端点检查：f(0) = 0，f(1) = 0，均小于驻点值，故 b* = 1/2 是最大值点。

第五步：读出最优增长率。b* = 1/2 时，每期财富变为 1 + ½ = 3/2（股票赢）或 1 − 1/4 = 3/4（股票输）：

W* = 12 log₂ 32 + 12 log₂ 34 = 12 log₂ 98 ≈ 12×0.1699 = 0.085 比特

换算成倍数：每期财富约乘 20.085 ≈ 1.061，即每期稳定增长约 +6.1%。对比：全押现金 W = 0（每期 ×1），全押股票 W = 0。两个各自都不增长的资产，按 1:1 混合后反而正增长——再平衡（Rebalancing）每期把涨多的卖一点补到跌多的，等于自动"低买高卖"，这就是常被称作"免费的多元化午餐"的现象。

💡 关键一跃

对数最优组合做的事只有一件：在"增长"与"波动"之间取几何最优的折中。加杠杆放大 E[X] 的同时也放大波动拖累，W(b) 这条曲线自动把最优杠杆给你——本例中恰好是半仓。凯利判据 = 对数最优 = 长期复利最大化，三者是同一个东西。

⚠️ 常见误区

"E[X] > 1 的资产就该多配，E[X] ≤ 1 就不配"——错。配多少取决于整条 W(b) 曲线而非 E[X]：例 2 里 E[X] = 1.25 的资产最优只配一半；而 E[X] = 1 的现金配另一半，因为它把 W 从 0 抬到 0.085。资产的价值要看它进入组合后对几何增长率的边际贡献——下一节的 Kuhn–Tucker 条件把这句话变成等式。

16.3最优的指纹：Kuhn–Tucker 条件

例 2 只有两资产，求导就够。一般 m 资产、带约束 bᵢ ≥ 0 时，最优解 b* 由一个统一条件刻画——它就是 W(b) 在 b* 处"沿每个允许方向都不再上升"的精确翻译，即Kuhn–Tucker 条件（Kuhn–Tucker Conditions，拉格朗日乘子法在不等式约束下的形式）：

✅ 判定规则（Kuhn–Tucker 特征）

b* 是对数最优组合，当且仅当对每个资产 i：

E Xib*ᵀX ≤ 1，　且若 bi* > 0 则取等号

直觉：Xᵢ / b*ᵀX 是"资产 i 的回报除以组合总回报"——把它当作资产 i 在组合里的相对表现，其期望恰好 ≤ 1。进组合的（bᵢ* > 0）相对表现期望精确等于 1；不进组合的更差（< 1）。每个资产对最优组合的边际贡献都已被榨干到同一个水平。

例 3（手算验证）：在例 2 的 b* = (1/2, 1/2) 上逐项检验

组合每期财富 b*ᵀX：股票赢时为 3/2，股票输时为 3/4（例 2 已算）。两个资产各算一次期望：

现金（X₁ = 1）：

E 1b*ᵀX = 12×23 + 12×43 = 13 + 23 = 1 ✓

股票（X₂ = 2 或 1/2）：

E X₂b*ᵀX = 12×2×23 + 12×12×43 = 23 + 13 = 1 ✓

两个资产都进了组合（b* 分量都为正），所以两个期望都必须精确等于 1——确实如此。如果你随手换 b = (1, 0) 全押股票再算一次，现金的 E[1/bᵀX] = ½×(1/2) + ½×2 = 5/4 > 1：现金的相对表现期望超过 1，说明"把钱从股票挪到现金"还能改善 W——组合不是最优，K–T 条件立刻诊断出来。

💡 关键一跃

K–T 条件把"求 max W(b)"变成一个不用求导的验算工具：给你一个候选组合，逐资产算 E(Xᵢ/bᵀX)，全 ≤ 1 且持仓项取等，它就是最优。多资产市场没有解析解时，也正是靠它（配合迭代算法，如 Cover 的通用组合算法）逼出数值解。

⚠️ 常见误区

"K–T 条件里 ≤ 1 的那个'1'是无风险利率"——不是。这个 1 来自约束 Σbᵢ = 1 的拉格朗日乘子，含义是"组合自身的回报归一化"：每个资产跟自己的组合比。它与现金回报无关——即便没有现金资产，条件照样成立。

16.4边信息的价值：1 比特 = 每期财富翻一倍

回到赛马。如果开赛前你收到一条与赛果相关的消息 Y（线人、天气预报、马匹状态），你的最优翻倍率能提高多少？答案精确而漂亮：恰好提高互信息 I(X;Y)。

✅ 定理（边信息的价值）

赛果 X 与边信息 Y 联合分布已知。知道 Y 后按条件分布下注（b* = p(x|y)），最优条件翻倍率比无条件时高出：

ΔW = W*(X|Y) − W*(X) = I(X;Y)

含义：1 比特的边信息，精确等于每期财富多翻一倍（×2¹）；I 比特就是 ×2I。信息论里 I(X;Y) 这个抽象量，在赌马/市场里有一个硬通货价格。

例 4（手算）：完美线人值多少

继续 16.1 的最小例：两马 p = (1/2, 1/2)，公平赔率 o = (2,2)，无信息时 W* = log₂2 − H(X) = 1 − 1 = 0（打平）。

现在线人 Y 完全揭示胜者：I(X;Y) = H(X) − H(X|Y) = 1 − 0 = 1 比特。知道 Y 后全押必胜马：每期财富 ×(1×2) = ×2，W = log₂(1×2) = 1 比特。

核对公式：ΔW = 1 − 0 = 1 = I(X;Y) ✓。财富从"每期打平"变成"每期翻倍"——1 比特信息换每期 ×2，n 期就是 2ⁿ 倍的差距。若线人只有部分质量（比如以 90% 概率猜对），则 I(X;Y) = H(X) − H(X|Y) = 1 − H(0.1) ≈ 1 − 0.469 = 0.531 比特，每期多增长 20.531 ≈ 1.445 倍——公式照样精确成立。

承上启下：这一切都假设"分布已知且平稳"

把本章四个结果连起来看：W(b) = E log bᵀX 里的期望要按真实分布取；b* = p 要知道 p；K–T 验算要知道联合分布；ΔW = I(X;Y) 要知道联合分布。整个理论的地基是"分布已知且逐期平稳"——而真实市场偏偏不满足：分布要估计、会漂移、有厚尾。这正是第 13–14 章"未知分布下的通用编码"问题在金融里的回声：第 13 章的通用压缩对应着 Cover 的通用组合（Universal Portfolio）——不假设分布，渐近追平事后最优的定比例组合（思路与本章 b* 一脉相承，代价是多付一个 O((m/2)log n) 级别的"学费项"）。而支撑从 b* = p 到 ΔW = I 所有证明的那几件不等式工具（D ≥ 0、Jensen、数据处理），第 17 章将系统成箱地交付。

💡 关键一跃

本章最大的顿悟不是某个公式，而是一个统一视角：增长率的单位就是比特。压缩、通信、假设检验、投资——每次 log 出现的地方，都是同一个"乘性世界里化乘为加"的操作；熵、互信息在金融里的价格，与它们在编码里的码长，是同一个量的两种货币。

⚠️ 常见误区

"ΔW = I 说明内幕信息可以无限套利"——公式里的 I 是对真实联合分布而言的互信息。现实中你估计的 p(x,y) 有误差，按错分布下注会亏掉 D 那么大的增长率（16.1 证明里 −D(p‖b) 那一项）；市场非平稳时，历史估计的 I 还会过期。信息值钱，但"以为自己有信息"更费钱。

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
翻倍率（Doubling Rate）
点击翻面 →
定义W(b) = E log₂ bᵀX；n 期财富 Sₙ ≈ 2^{nW}。
解决问题给连乘的财富一个可相加、可最大化的增长度量。
直觉财富仪表盘的"对数刻度"：W=1 每期翻倍，W=0 踏步，W<0 走向破产。
误区与期望回报 E[bᵀX] 混淆——后者是算术平均，被稀有暴富路径抬高，不代表你的路径。
何时用本章全部四个结果的主角；Ch17 用它举例信息论不等式。
概念卡 2
对数最优组合（Log-Optimal Portfolio）
点击翻面 →
定义使 W(b) = E log bᵀX 最大的比例向量 b*；等价于凯利组合。
解决问题回答"长期复利最大化的仓位是多少"。
直觉在增长与波动之间取几何最优折中，自动给你最优杠杆。
误区以为期望收益最高就该全押——例 2 中 E[X]=1.25 的资产最优只配一半。
何时用16.3 K–T 条件刻画它；16.4 边信息改变它；通用组合（Ch13 思路）逼近它。
概念卡 3
赛马等价：b* = p（Proportional Betting）
点击翻面 →
定义赛马 W(b,p) = Σ pᵢ log(bᵢoᵢ) 在 b* = p 处最大，W* = Σ pᵢ log(pᵢoᵢ)。
解决问题给出"信源分布"与"资金分配"的精确对应：按真实概率下注。
直觉下注比例 = 你对世界的信念；错配 b ≠ p 恰好亏 D(p‖b)。
误区以为该押"最可能赢的马"——全押热门会破产（W = −∞）。
何时用16.1 证明（−D(p‖b) ≤ 0）；L2 习题三马扩展；边信息定价的基础。
概念卡 4
算术平均 vs 几何平均（波动拖累）
点击翻面 →
定义E[X] 是算术平均（+25%）；典型路径增长由几何平均 2^{E log X} 决定，两者之差即波动拖累。
解决问题解释"平均赚钱、长期不赚钱"的悖论。
直觉×2 再 ×½ = 回到原点：乘法世界里涨跌不对称，波动是纯成本。
误区以为只是近似差异——Jensen 不等式 E log X ≤ log E[X]，等号仅当无波动，差距可任意大。
何时用16.2 例 2 的核心；理解一切"再平衡溢价"与杠杆衰减。
概念卡 5
Kuhn–Tucker 条件（K–T 特征）
点击翻面 →
定义b* 最优 ⟺ E(Xᵢ / b*ᵀX) ≤ 1 对所有 i 成立，且 bᵢ* > 0 时取等号。
解决问题给"候选组合是否最优"一个免求导的验算判据，也是多资产数值求解的基础。
直觉每个资产与自己组合比相对表现：进组合的期望恰好 1，不进的更差。
误区把那个"1"当成无风险利率——它来自 Σb=1 的乘子，与现金无关。
何时用16.3 例 3 逐项验证；L3 题中评估组合改进方向。
概念卡 6
边信息的价值 ΔW = I(X;Y)
点击翻面 →
定义知道 Y 后最优翻倍率的增量恰为 I(X;Y) 比特。
解决问题给"信息"定出硬通货价格：每条消息渠道值多少增长率。
直觉1 比特 = 每期财富 ×2；I 比特 = 每期 ×2^I。
误区以为任何"消息"都值钱——公式里的 I 对真实联合分布而言；估计错了反而亏 D。
何时用16.4 例 4；L3 基金经理题；与 Ch7 信道容量（max I）同源。

📝分层习题

L1 概念辨析判断对错：既然例 2 中股票的期望回报 E[X] = 1.25 大于现金的 1，理性投资者应把全部财富投入股票。说明理由。
提示

财富是相加还是相乘？全押股票时 W = E log X 是多少？

完整解答
错。财富连乘，长期增长由翻倍率 W = E log bᵀX 决定而非 E[bᵀX]。全押股票：W = ½log₂2 + ½log₂(1/2) = ½×1 + ½×(−1) = 0，典型路径原地踏步（×2 再 ×½ = 1）；E[X] = 1.25 只是算术平均，被暴涨路径抬高。最优是 b* = 1/2，W* = ½log₂(9/8) ≈ 0.085 比特，每期 ×1.061。把 E[X] 当决策依据是本章最典型的错误。
L1 概念辨析判断对错：公平赔率（Σ 1/oᵢ = 1）的赛马中，按真实分布下注 b = p 就能稳定赚钱。
提示

算一下 W* = Σ pᵢ log₂(pᵢoᵢ) 在公平赔率下的值——注意公平意味着 1/oᵢ 构成一个分布。

完整解答
错。公平时 rᵢ = 1/oᵢ 是一个概率分布，而 b = p 时 W* = Σ pᵢ log₂(pᵢ/rᵢ) = D(p‖r) ≥ 0，一般只有当庄家分布 r 不等于 p 时才严格为正（你赚的是庄家定价错误的钱）。若庄家也准（r = p，如两马 o=(2,2)、p=(1/2,1/2)），则 W* = D(p‖p) = 0——按真实分布下注只是不亏，信息和钱刚好打平。特例 oᵢ = m 时 W* = log m − H(X) ≥ 0，等号在均匀分布时成立。公平赛马里没有免费午餐，只有"信息差"才有午餐。
L2 手算推导市场改为：股票每期变 3 倍或 1/3（各以概率 1/2），现金收益 1。求对数最优仓位 b*、最优翻倍率 W* 与每期增长倍数（对数取 2 为底）。
提示

股票赢时财富为 (1−b) + 3b = 1 + 2b；输时为 (1−b) + b/3 = 1 − 2b/3。写出 f(b)，求导令其为 0。

完整解答

第一步，写 W(b)：f(b) = ½log₂(1+2b) + ½log₂(1−2b/3)，b ∈ [0,1]。

第二步，求导（换底常数 1/ln2 略去）：f′(b) = ½·2/(1+2b) − ½·(2/3)/(1−2b/3) = 1/(1+2b) − 1/(3−2b)。

第三步，令 f′(b) = 0：1+2b = 3−2b ⟹ 4b = 2 ⟹ b* = 1/2。端点 f(0)=0，f(1) = ½log₂3 + ½log₂(1/3) = 0，均小于驻点值。

第四步，算 W*：每期财富为 1+1 = 2（赢）或 1−1/3 = 2/3（输）。W* = ½log₂2 + ½log₂(2/3) = ½log₂(2×2/3) = ½log₂(4/3) ≈ ½×0.4150 = 0.2075 比特。

第五步，换算倍数：20.2075 ≈ 1.155，每期约 +15.5%。对照例 2：波动更大（×3 与 ×1/3），但最优组合的增长也更快——因为期望回报 E[X] = 5/3 更高，半仓恰好把波动拖累控制在可接受范围。

L2 手算推导三马赛马：p = (1/2, 1/4, 1/4)，赔率 o = (2, 4, 4)。（a）验证赔率公平；（b）证明 b* = p 使 W 最大（写全 −D 论证）；（c）算 b = p 时的 W*；（d）算全押马 1（b = (1,0,0)）的 W。
提示

(a) 检查 Σ1/oᵢ；(b) 算 W(b,p) − W(p,p)；(c) 逐项算 pᵢ log₂(pᵢoᵢ)；(d) 马 1 不输的那些期里财富是多少？

完整解答

(a) Σ 1/oᵢ = 1/2 + 1/4 + 1/4 = 1，公平 ✓。

(b) W(b,p) − W(p,p) = Σ pᵢ log₂(bᵢoᵢ) − Σ pᵢ log₂(pᵢoᵢ) = Σ pᵢ log₂(bᵢ/pᵢ) = −D(p‖b) ≤ 0，等号 ⟺ b = p。故 b* = p。

(c) W* = Σ pᵢ log₂(pᵢoᵢ) = ½·log₂(½×2) + ¼·log₂(¼×4) + ¼·log₂(¼×4) = ½·log₂1 + ¼·log₂1 + ¼·log₂1 = 0。公平赔率 + 庄家分布与真实分布一致（r = p），按真实分布下注恰好打平。

(d) 全押马 1：马 1 赢（概率 ½）时财富 ×2；马 1 输（概率 ½）时财富 ×0。W = ½log₂(1×2) + ½log₂(0) = ½×1 + ½×(−∞) = −∞。解读：约一半的期里财富直接清零，长期必然破产——这就是把 b ≠ p 推到极端的代价，也是对数效用惩罚破产的最直观演示。

L3 建模应用你是一位基金经理，市场就是 16.2 的两资产市场（股票 {2, 1/2} 各 1/2 + 现金）。一个数据供应商出售"明日涨跌预测"渠道，其质量用互信息 I(X;Y) 刻画。问：(a) 渠道满质量 I = 1 比特时，它把每期财富增长倍数从多少提到多少？(b) 一般地，每 1 比特信息相当于每期财富乘以多少？(c) 若分布只能历史估计、且市场非平稳，你会如何给这条公式打折？
提示

(a) 无信息时 b* = 1/2，W* ≈ 0.085；(b) 用 ΔW = I 换算倍数；(c) 回忆"按错分布下注亏 D"与"真实 I 会过期"。

完整解答

(a) 无信息：W* = ½log₂(9/8) ≈ 0.085 比特，每期 ×1.061。满质量 I = 1 比特：Y 完全揭示明日涨跌，全押必胜方向。明日涨（概率 ½）：全押股票 ×2；明日跌（概率 ½）：全押现金 ×1。W = ½log₂2 + ½log₂1 = ½ 比特/期，每期 ×20.5 ≈ 1.414。注意 ΔW = 0.5 − 0.085 ≈ 0.415 < 1 = I——ΔW = I 的等号是赛马模型的结果（那里财富只有一匹马存活、赔率与概率对偶）；在可加组合市场里信息的价值一般不等于 I，本题渠道价值约为每期 ×20.415 ≈ 1.333 的额外增长。这正是 L3 的味道：公式适用的模型前提要先核对。

(b) 在赛马模型中精确地：每比特 = 每期财富 ×2（ΔW = I）。在一般市场中它是"每比特边信息约值每期 ×2^I 量级增长"的标尺——方向不变，系数依市场结构而定。

(c) 两处打折：其一，估计误差——按估计分布 q 而非真实 p 下注，增长率亏掉一个 D(p‖·) 量级的项（16.1 证明里的 −D），所以报价前先用留出数据验证 I 的稳健性；其二，非平稳——市场漂移使历史估计的 I(X;Y) 过期，有效信息只有当前仍成立的部分。实务上应对估计的 I 乘一个小于 1 的置信系数，并持续滚动重估。理论给上限，兑现靠分布质量。
