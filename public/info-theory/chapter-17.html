17.1一个不等式家族的总根源：ln x ≤ x − 1

第 16 章用对数最优组合给金融问题收了口。现在回看整本书：第 2 章证 I ≥ 0、第 5 章证码长下界、第 7 章证 Fano 逆定理、第 10 章证率失真下界、第 15 章证多用户率域的外界——这些证明风格各异，但都在某一步做过同一个小动作：把对数放缩成一条直线。这个动作就是本章的主角：

ln x ≤ x − 1　（x > 0），等号成立当且仅当 x = 1

一眼看懂它：ln x 是凹函数，它在 x = 1 处的切线恰好是 y = x − 1，整条曲线被自己的切线压在下方。要写证明也只有一行：令 f(x) = x − 1 − ln x，则 f′(x) = 1 − 1/x，在 x = 1 处取唯一极小值 f(1) = 0。

从它推出第一个定理：D(p‖q) ≥ 0

相对熵（Relative Entropy）的非负性是全书不等式家族的长子。把 −D 写出来，对每一项应用 ln x ≤ x − 1（取 x = q(x)/p(x)），一步不跳：

−D(p‖q) = ∑x p(x) · ln q(x)p(x) ≤ ∑x p(x) · (q(x)p(x) − 1) = ∑x q(x) − ∑x p(x) = 1 − 1 = 0

于是 D(p‖q) ≥ 0。等号条件：放缩对每一项都生效，要等号成立，必须每个使 p(x) > 0 的 x 都满足 q(x)/p(x) = 1，即 p = q。整个证明只用了一条切线不等式和"概率和为 1"——这就是第 2 章那个让无数人觉得"来路不明"的定理的全部机关。

数据处理不等式：信息只会被加工损耗

设 X → Y → Z 构成马尔可夫链（Markov Chain），即给定 Y 时 X 与 Z 独立。数据处理不等式（Data Processing Inequality, DPI）断言：

I(X;Y) ≥ I(X;Z)

证明用链式法则把 I(X;Y,Z) 按两种顺序展开：

  • 先 Y 后 Z：I(X;Y,Z) = I(X;Y) + I(X;Z|Y) = I(X;Y) + 0（马尔可夫性使条件互信息为 0）；
  • 先 Z 后 Y：I(X;Y,Z) = I(X;Z) + I(X;Y|Z) ≥ I(X;Z)（条件互信息非负）。

两式相等，立得 I(X;Y) ≥ I(X;Z)。直觉：Y 是对 X 的观测，Z 是对观测的再加工——任何不参考原件的再加工都不可能增加关于原件的信息。第 7 章的"译码器无法创造信息"、第 10 章的"压缩必有代价"，都是它的化身。

Fano 不等式：剩余不确定性给错误率划出下界

要从 Y 估计 X（估计量 X̂ = g(Y)，错误概率 Pe = P(X̂ ≠ X)），Fano 不等式（Fano's Inequality）说：

H(X|Y) ≤ h(Pe) + Pe · log₂(|𝒳| − 1)

其中 h(Pe) = −Pelog₂Pe − (1−Pe)log₂(1−Pe) 是二元熵函数。证明思路（三步）：令 E 为"是否出错"的示性变量；一方面 H(E,X|Y) = H(X|Y) + H(E|X,Y) = H(X|Y)（E 由 X 和 Y 决定）；另一方面 H(E,X|Y) = H(E|Y) + H(X|E,Y) ≤ h(Pe) + Pe·log₂(|𝒳|−1)——出错时 X 至多在其余 |𝒳|−1 个值里不确定。两式夹出结论。

例 1（手算）：Fano 不等式给出错误率下界

设 |𝒳| = 4，已知 H(X|Y) = 1.5 比特。问：任何估计方案的错误率 Pe 至少是多少？

Fano 给出约束 h(Pe) + Pe·log₂3 ≥ 1.5。log₂3 ≈ 1.585。试错两次：

  • 试 Pe = 0.3：h(0.3) = −0.3×log₂0.3 − 0.7×log₂0.7 = 0.3×1.737 + 0.7×0.515 = 0.521 + 0.360 = 0.881；再加 0.3×1.585 = 0.476，合计 1.357 < 1.5——不够，0.3 的错误率解释不了这么大的剩余不确定性。
  • 试 Pe = 0.4：h(0.4) = 0.4×1.322 + 0.6×0.737 = 0.529 + 0.442 = 0.971；再加 0.4×1.585 = 0.634，合计 1.605 ≥ 1.5 ✓。

在 0.3 与 0.4 之间线性插值：(1.5 − 1.357)/(1.605 − 1.357) = 0.143/0.248 ≈ 0.58，故 Pe ≳ 0.36。含义：只要译码后还剩 1.5 比特的不确定性，无论你的估计器多聪明，错误率都不可能低于约三分之一——这正是第 7 章 Fano 逆定理"速率超容量则错误率有正下界"的定量来源。

💡 关键一跃

ln x ≤ x − 1 是"曲线被切线压住"这一件几何事实；D ≥ 0 是它的概率化身；I ≥ 0、条件化减熵、DPI、Fano 全是化身的化身。本章后面两节会再看到同样的戏法在微分熵与 Fisher 信息上重演——信息论的不等式，全是"一家子"。

⚠️ 常见误区

"数据处理不等式说处理必然丢信息"——错。它说的是不增：I(X;Z) ≤ I(X;Y)，等号可以成立（当 Z 是 Y 关于 X 的充分统计量时，加工一滴信息不丢）。把"不增"误记成"严格递减"，会在判断"什么处理是无损的"时全军覆没。

17.2熵功率不等式：连续世界的"方差守恒"

17.1 的家族统治着离散世界。第 8 章把熵推广到连续变量（微分熵，Differential Entropy），第 9 章发现高斯分布霸占了一切极限——固定方差 σ² 时 h(X) ≤ ½log(2πeσ²)，等号仅由高斯取得。这提示我们：连续世界里"高斯程度"本身可以度量。香农为此造了一个量：

熵功率 N(X) = 22h(X)2πe　　（h 以比特计时）

定义的反解读法：若 X 是方差 σ² 的高斯变量，h = ½log(2πeσ²)，代回得 N(X) = σ²。所以 熵功率（Entropy Power）是"与 X 熵相同的高斯变量的方差"——一把"高斯化程度"的尺子。由最大熵定理，任何分布都有 N(X) ≤ Var(X)，等号 ⟺ X 是高斯。

例 2（手算）：均匀分布的熵功率

X ~ 均匀分布 [−1, 1]。逐步算：

  • 微分熵：密度恒为 1/2，h(X) = −∫ ½·log₂½ dx = log₂2 = 1 比特；
  • 熵功率：N(X) = 22×1/(2πe) = 4/(2πe) ≈ 4/17.079 ≈ 0.234；
  • 方差：Var(X) = (1−(−1))²/12 = 4/12 = 1/3 ≈ 0.333。

检验：0.234 < 0.333 ✓——固定方差下高斯的熵功率最大，均匀分布"欠高斯"约 30% 的等效方差。

熵功率不等式（EPI）

独立的 X、Y 相加（密度做卷积），和的熵功率满足熵功率不等式（Entropy Power Inequality, EPI）：

N(X + Y) ≥ N(X) + N(Y)，等号成立当且仅当 X、Y 都是高斯

对比方差的精确等式 Var(X+Y) = Var(X) + Var(Y)：方差是"加法守恒量"，而熵功率在卷积下只会超额增长，多出来的部分正是分布远离高斯被"惩罚"的量。等号条件再次把高斯推到舞台中央。

例 3（手算）：两个均匀分布之和，验证整条不等式链

X、Y 独立同分布于均匀 [−1,1]，则 S = X + Y 服从 [−2,2] 上的三角分布，密度 f(s) = (2−|s|)/4（峰值 1/2 在 0 处）。逐项算：

  • S 的微分熵：三角分布的熵公式 h = ½ + ln(底宽/2)（以奈特计）。底宽为 4，故 h(S) = ½ + ln 2 = 0.5 + 0.6931 = 1.1931 奈特，换算成比特 1.1931 × 1.4427 ≈ 1.7213 比特。
  • S 的熵功率：N(S) = 22×1.7213/(2πe) = 23.4426/17.079 ≈ 10.874/17.079 ≈ 0.637。
  • EPI 左边与右边：N(X) + N(Y) = 0.234 + 0.234 = 0.468 ≤ 0.637 ✓（且远离等号——X、Y 都不是高斯）。
  • 与方差上界对照：Var(S) = Var(X) + Var(Y) = 1/3 + 1/3 = 2/3 ≈ 0.667 ≥ 0.637 ✓。

把三个数排成一行：0.468 ≤ 0.637 ≤ 0.667。中间量不但达标，而且已经贴到上界附近——均匀分布自己只有 0.234（离上界 30%），两个相加后熵功率占方差的比例升到 0.637/0.667 ≈ 95.5%。卷积让分布变得更像高斯。

💡 关键一跃：中心极限定理的信息论读法

把例 3 继续做下去：X₁、X₁+X₂、……（每步适当归一化保持方差不变），沿这条卷积序列，熵功率 N 单调递增，而它的天花板就是方差本身——也就是同方差高斯的熵功率。序列的极限分布只能是高斯。这就是中心极限定理（Central Limit Theorem）的信息论版本：归一化和的熵功率一路爬升，直到撞顶，撞顶处正是高斯。CLT 不再只是"分布长得像钟形"，而是一个熵单调增的爬坡过程。

⚠️ 常见误区

EPI 的不等号方向极易记反：是 N(X+Y) ≥ N(X)+N(Y)，不是 ≤。记"方差精确相加、熵功率超额增长"就不会反。另外注意 EPI 里没有自由参数——它对所有独立对成立，等号条件（双高斯）是它最锋利的部分，做题时别漏写。

17.3Fisher 信息与 Cramér–Rao 下界：估计一侧的镜像

17.2 度量了"一个分布自带多少随机性"。换一个场景：分布的形式已知，但参数 θ 未知（比如藏在噪声里的直流电平），数据能告诉我们多少关于 θ 的信息？这需要另一种信息——Fisher 信息（Fisher Information）。

给定参数化分布族 pθ(x)，定义得分函数（Score Function）：

V(x) = ∂∂θ ln pθ(x)

它度量"数据 x 的出现对 θ 有多敏感"。对 ∫pθdx = 1 关于 θ 求导（正则条件下可交换求导与积分），得 E[V] = ∫ pθ·(∂ln pθ/∂θ) dx = ∂(∫pθdx)/∂θ = 0：得分的均值恒为 0。于是它的二阶矩就是方差：

Fisher 信息 I(θ) = Eθ[ (∂∂θ ln pθ(X))2 ] = −Eθ[ ∂²∂θ² ln pθ(X) ]

第二种形式（对数似然的曲率取负再取期望）在正则条件下与第一种等价，常常更好算：log 似然越"弯"，θ 的微小移动引起的分布变化越大，θ 越好辨认。

例 4（手算，写全）：高斯位置模型的 Fisher 信息

模型：X = θ + Z，Z ~ N(0, σ²)，σ² 已知，θ 未知。逐步算：

  • 对数似然：ln pθ(x) = −(x−θ)²/(2σ²) − ½ln(2πσ²)；
  • 得分：∂/∂θ ln pθ(x) = (x−θ)/σ²（把 −(x−θ)² 对 θ 求导：−2(x−θ)(−1)/(2σ²) = (x−θ)/σ²）；
  • Fisher 信息：I(θ) = E[(X−θ)²/σ⁴] = E[Z²]/σ⁴ = σ²/σ⁴ = 1/σ²；
  • n 个独立样本：联合对数似然是各样本之和，得分相加且独立，方差相加：In(θ) = n/σ²。（用曲率形式验证：∂²/∂θ² ln pθ(x) = −1/σ²，取负取期望也得 1/σ² ✓。）

Cramér–Rao 下界：信息直接兑换成精度

Cramér–Rao 下界（Cramér–Rao Lower Bound, CRLB）说：对 θ 的任何无偏估计量 θ̂（用 n 个独立样本），

Var(θ̂) ≥ 1In(θ) = σ²n　（高斯位置模型）

而样本均值 X̄ = (1/n)ΣXi 恰好有方差 σ²/n——它达到了下界，是这个模型里最好的无偏估计。信息论把一句口号变成了等式："信息越多方差越小"的定量版，就是 Var ≥ 1/I。

最后把 17.2 与 17.3 接上。Fisher 信息与（微分）熵并非两个世界：de Bruijn 恒等式（de Bruijn's Identity）说，给 X 掺入强度 t 的高斯噪声时，熵的变化率恰由 Fisher 信息给出——d/dt h(X + √t Z) = ½ I(X + √t Z)。由它出发可以证明 Stam 不等式（Stam's Inequality）1/I(X+Y) ≥ 1/I(X) + 1/I(Y)（独立 X、Y），而 Stam 与 EPI 互为推论——17.4 节把这张关系网画出来。

💡 关键一跃

熵测度"随机性有多少"，Fisher 信息测度"分布对参数有多敏感"——de Bruijn 恒等式说它们是同一枚硬币的两面：给分布掺噪声时，熵按 Fisher 信息的速度增长。CR 下界则是这把尺子的决算单：n 份样本的信息是 n 份，换来的精度就是 1/n 的方差。

⚠️ 常见误区

CR 下界只约束无偏估计。允许偏差时，某些有偏估计（如收缩估计）在均方误差意义下可以做得更好——下界不是宇宙真理，而是"无偏家族内部"的物理极限。另外，I(θ) 一般依赖 θ（本例恰好不依赖），引用下界时要看清在哪个参数点上取值。

17.4不等式之间的关系网：不是新结论，是共同的根

三节学了三族不等式，它们彼此之间还有深层勾连——本章的真正主题不是"再多几条定理"，而是让你看到前 16 章所有定理共用同一张根系。

三对呼应，逐一说清

  • EPI ⟷ Brunn–Minkowski：几何学中的 Brunn–Minkowski 不等式说，两组体积之"Minkowski 和"按幂增长；把"集合体积"换成"分布的熵幂"（熵功率），就得到 EPI——前者是体积语言，后者是熵语言，证明可以互相翻译。
  • EPI ⟺ Stam：Stam 不等式 1/I(X+Y) ≥ 1/I(X) + 1/I(Y) 与 EPI 互为推论，中间的桥就是 de Bruijn 恒等式（熵的变化率 = Fisher 信息的一半）。熵与 Fisher 信息在这对等价中完成兑换。
  • DPI 是"互信息的单调性"：马尔可夫链 X→Y→Z 上 I(X;·) 单调不增。它和"条件化减熵""相对熵非负"一样，全部是 ln x ≤ x−1 的不同面具。
✅ 本章的判定规则

遇到信息论里任何一条"极限定理"（压缩到 H、容量 C、R(D)、Slepian–Wolf 率域、CR 界），问一句：它的证明里放缩对数的那一步在哪？找出来，你就抓住了这条定理的根。本章之后，前 16 章不再有"来路不明"的定理。

概念卡 1
数据处理不等式（Data Processing Inequality）
点击翻面 →
定义马尔可夫链 X→Y→Z 上，I(X;Y) ≥ I(X;Z)。
解决问题证明"任何再加工都不能创造关于原件的信息"，是一切逆定理的基石。
直觉复印件的复印件，不会比原件更清楚。
误区以为处理必然丢信息——充分统计量加工后等号成立，一滴不丢。
何时用Ch7 Fano 逆定理、Ch10 率失真外界、Ch15 多用户外界、本章族谱。
概念卡 2
Fano 不等式（Fano's Inequality）
点击翻面 →
定义H(X|Y) ≤ h(Pe) + Pe·log₂(|𝒳|−1)，Pe 为从 Y 估计 X 的错误概率。
解决问题把"译码后剩余的不确定性"兑换成"错误率的下界"，让逆定理有数值。
直觉还剩多少疑问，就至少要犯多少错。
误区当成可达性结果——它只给下界，不保证存在达到它的估计器。
何时用Ch7 信道编码逆定理、Ch15 逆命题、本章例 1 的 Pe ≳ 0.36。
概念卡 3
熵功率（Entropy Power）
点击翻面 →
定义N(X) = 22h(X)/(2πe)：与 X 熵相同的高斯变量的方差。
解决问题把微分熵翻译成"等效方差"，让熵可以像方差一样比较大小。
直觉分布的"高斯含量"刻度尺：N ≤ Var，等号只有高斯。
误区以为任何分布 N = Var——均匀分布只有 0.234，而方差是 0.333。
何时用EPI 的主角；Ch9 高斯信道的逆命题；CLT 的信息论表述。
概念卡 4
熵功率不等式（Entropy Power Inequality）
点击翻面 →
定义独立 X、Y：N(X+Y) ≥ N(X)+N(Y)，等号 ⟺ 两者都是高斯。
解决问题刻画卷积如何"抬高"熵功率，是高斯信道逆命题与 CLT 的引擎。
直觉方差精确相加，熵功率超额增长——多出的就是"更像高斯"的部分。
误区不等号记反成 ≤；或漏掉等号条件"双高斯"。
何时用本章例 3；与 Stam 不等式、Brunn–Minkowski 的互译；CLT 爬坡。
概念卡 5
Fisher 信息（Fisher Information）
点击翻面 →
定义I(θ) = E[(∂/∂θ ln pθ)²] = −E[∂²ln pθ/∂θ²]，得分的方差。
解决问题度量数据关于参数 θ 的灵敏度，回答"数据里有多少 θ 的信息"。
直觉对数似然曲线越弯，θ 越好认——曲率就是信息。
误区与香农熵混为一谈——它属于参数化分布族，靠 de Bruijn 恒等式才与熵接通。
何时用CR 下界的分母；Stam 不等式；统计物理与机器学习中的自然梯度。
概念卡 6
Cramér–Rao 下界（Cramér–Rao Lower Bound）
点击翻面 →
定义任何无偏估计 θ̂：Var(θ̂) ≥ 1/In(θ)。
解决问题给"估计能有多准"划出不可逾越的线，把 Fisher 信息兑换成精度。
直觉信息是货币，方差是价格——1 份信息最多买 1 份方差的缩减。
误区以为约束一切估计——只管无偏家族；有偏估计（收缩）可绕过。
何时用本章例 4（σ²/n，样本均值达到）；一切参数估计的极限分析。

📝分层习题

L1 概念辨析判断对错：对任意两个分布 p、q，都有 D(p‖q) = D(q‖p)，且两者均非负。说明理由。
提示

非负性由本章的推导保证，没问题；检查等号那一半——D 的定义里 p 和 q 的角色对称吗？

完整解答
错在等式那一半。D(p‖q) ≥ 0 与 D(q‖p) ≥ 0 都对（都由 ln x ≤ x−1 推出），但一般 D(p‖q) ≠ D(q‖p)：D 度量"真实为 p 却按 q 办事"的代价，p 与 q 角色不对称，交换后代价一般不同（第 2 章已见数值反例），也不满足三角不等式。正确的说法是：两者均非负，且各自为 0 当且仅当 p = q。
L1 概念辨析判断对错：均匀分布的熵功率等于它的方差，因为熵功率本来就是"另一种方差"。
提示

N(X) ≤ Var(X) 的等号条件是什么？例 2 算出的两个数各是多少？

完整解答
错。N(X) 是"与 X 同熵的高斯变量的方差"，最大熵定理保证 N(X) ≤ Var(X)，等号仅当 X 是高斯。例 2：均匀 [−1,1] 的 N = 4/(2πe) ≈ 0.234，严格小于 Var = 1/3 ≈ 0.333。"熵功率 = 方差"只对高斯成立；对非高斯分布，两者的差正是它"欠高斯"的度量。
L2 手算推导从 ln x ≤ x−1（x>0，等号 ⟺ x=1）出发，完整推导 D(p‖q) ≥ 0，并严格指出等号条件。
提示

对 −D 放缩更顺手：把 ln(q/p) 中的 q/p 当作 x 套用切线不等式，然后拆开两个求和。

完整解答

−D(p‖q) = −Σx p(x) ln(p(x)/q(x)) = Σx p(x) ln(q(x)/p(x))。

对每一项应用 ln u ≤ u − 1（u = q(x)/p(x)，约定 p(x)=0 的项为 0）：

−D ≤ Σx p(x)·(q(x)/p(x) − 1) = Σx q(x) − Σx p(x) = 1 − 1 = 0。

故 D(p‖q) ≥ 0。等号条件：放缩对每个 p(x) > 0 的项独立生效，要等号需每项 q(x)/p(x) = 1，即 q(x) = p(x) 对所有 x 成立。反之 p = q 时 ln 1 = 0，D = 0。所以 D(p‖q) = 0 ⟺ p = q。

L2 手算推导用最大熵原理（与 EPI 同源的思想）重读高斯信道容量 C = ½log₂(1 + P/N)：给定输入功率约束 E[X²] ≤ P、噪声 Z ~ N(0, N) 与输入独立，证明 I(X;Y) ≤ ½log₂(1 + P/N)，并说明为什么高斯输入达到它（写出 h(Y) ≤ ½log(2πe(P+N)) 的关键两步）。
提示

I(X;Y) = h(Y) − h(Y|X)；噪声独立给出 h(Y|X) = h(Z)；再用 Var(Y) ≤ P+N 配合最大熵定理。

完整解答

第一步（拆开互信息）：I(X;Y) = h(Y) − h(Y|X)。因 Z 独立于 X，h(Y|X) = h(X+Z|X) = h(Z) = ½log₂(2πeN)。

第二步（给 h(Y) 封顶）：E[Y²] = E[X²] + 2E[X]E[Z] + E[Z²] ≤ P + 0 + N（独立使交叉项为 E[X]·E[Z]，而 E[Z]=0）。固定二阶矩时高斯熵最大，故 h(Y) ≤ ½log₂(2πe·Var(Y)) ≤ ½log₂(2πe(P+N))。

合并：I(X;Y) ≤ ½log₂(2πe(P+N)) − ½log₂(2πeN) = ½log₂((P+N)/N) = ½log₂(1 + P/N)。

可达性：取 X ~ N(0, P)，则 Y = X+Z ~ N(0, P+N)，上面两处 ≤ 同时取等。这就是为什么第 9 章的最优输入是高斯——与 EPI"等号 ⟺ 高斯"同根同源。

L3 建模应用你要估计一个未知直流电平 θ，每次测量得 Xi = θ + Zi，Zi ~ N(0, σ²) 独立，σ² = 1。(a) 用 Cramér–Rao 下界回答：要求无偏估计的标准差不超过 0.1，至少需要多少样本？不超过 0.01 呢？(b) 若预算只有 n = 25 个样本，能承诺的最好（无偏）标准差是多少？(c) 说明这个下界与信道容量、Fano 不等式是"同一枚硬币的不同面"。
提示

例 4 已给出 In = n/σ²；标准差是方差的平方根；硬币的"面值"是信息，三处分别用它买速率、买错误率下界、买方差下界。

完整解答

(a) CR：Var(θ̂) ≥ σ²/n = 1/n，标准差 ≥ 1/√n。要求 1/√n ≤ 0.1 → √n ≥ 10 → n ≥ 100；要求 ≤ 0.01 → n ≥ 10,000。精度提高 10 倍，样本要 100 倍——这是 1/√n 的铁律。

(b) n = 25：标准差 ≥ 1/5 = 0.2。样本均值恰好达到它，所以 0.2 是可承诺的最好无偏精度。

(c) 三面一枚：信道容量用互信息给"可靠传输的速率"封顶（R ≤ C = max I）；Fano 用剩余熵给"译码错误率"托底（Pe 由 H(X|Y) 下界）；CR 用 Fisher 信息给"估计方差"托底（Var ≥ 1/I）。三者都是同一个兑换原则——信息量 ↔ 可达性能：信息是硬通货，速率、错误率、方差是三种标价，而"超过极限不可达"的方向（逆定理）全部由本章的不等式家族守卫。
