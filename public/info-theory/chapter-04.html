4.1从一串符号到一个过程：随机过程与平稳性

Ch3 的全部结论建立在"X₁, X₂, … 独立同分布"上。但睁开眼睛看看真实信源：英文文本里 q 后面几乎必跟 u；天气预报里今天晴天则明天大概率晴天；股票收益率前后相关。独立假设是教学沙盘，不是真实世界。本章把沙盘拆了。

随机过程：带索引的一族随机变量

随机过程（Stochastic Process）就是一列随机变量 {X₁, X₂, X₃, …}，允许任意依赖。它的统计全貌由所有有限维联合分布 p(x₁, x₂, …, xₙ) 刻画。依赖一旦放开，Ch3 的大数定律不再自动成立——压缩极限还是不是"某个 H"？整个第 4 章就在回答这个问题。

平稳性：让"每符号不确定度"有意义的最低假设

完全任意的随机过程没法谈"每符号平均信息量"——今天的分布和明天的分布毫无关系，平均没有意义。需要的最小结构是平稳性（Stationarity）：过程的统计规律不随时间平移改变。

对任意 n、任意时刻 t：p(X₁…Xₙ) 与 p(X_{t+1}…X_{t+n}) 同分布

两条直接推论，后面反复用：

  • 边际不随时变：H(X₁) = H(X₂) = … 每个符号的边际分布相同；
  • 条件结构只依赖相对距离：p(Xₙ|X₁ⁿ⁻¹) 只取决于"往前看 n−1 步"这个结构，与绝对时刻无关。形式上 H(Xₙ|X₁ⁿ⁻¹) = H(X_{n+t}|X_{t+1}ⁿ⁺ᵗ⁻¹)。

熵率的两个候选定义

i.i.d. 情形"每符号信息量"就是 H(X₁)，没什么好争的。有依赖时，两个定义各有道理：

定义 A（打包摊销）：H(𝒳) = limn→∞ 1n H(X₁, X₂, …, Xₙ)
定义 B（边际增量）：H′(𝒳) = limn→∞ H(Xₙ | X₁, X₂, …, Xₙ₋₁)

定义 A 的直觉：把 n 个符号当作一个整体，总不确定度 H(X₁…Xₙ)，平摊到每符号是多少，n 趋于无穷的摊销值。定义 B 的直觉：看过全部历史之后，下一个符号还剩多少不确定度——这是预测者真正面对的不确定度。4.2 节将证明：对平稳过程，这两个极限都存在，而且相等。这个共同的值就叫熵率（Entropy Rate）。

💡 关键一跃

熵是一个随机变量的不确定度；熵率是一个过程每符号的不确定度。从变量到过程，自然的推广不是 H(Xₙ)（那只是边际熵，忽略了记忆），而是"知道全部过去后，下一符号的不确定度"——记忆的价值就藏在条件里。

⚠️ 常见误区

"过程的每符号不确定度 = 边际熵 H(X₁)"——错，除非过程独立。边际熵只用了一个符号的分布，丢掉了全部依赖信息。英文每个字母的边际熵约 4.1 比特，但熵率只有约 1.3 比特——差出来的 2.8 比特就是"记忆"帮你消掉的不确定度。

4.2本章核心定理：平稳 ⟹ 两个定义相等

这是本章唯一需要完整吃透的证明。拆成三步，每步只用 Ch2 的工具。

第一步：条件熵序列单调不增

看序列 aₙ = H(Xₙ|X₁ⁿ⁻¹)。比较相邻两项：

H(Xₙ₊₁|X₁ⁿ) ≤ H(Xₙ₊₁|X₂ⁿ) = H(Xₙ|X₁ⁿ⁻¹)

不等号是 Ch2 的"条件化减少熵"（多给一个条件 X₁，不确定度不增）；等号是平稳性（结构 {X₂…Xₙ₊₁} 与 {X₁…Xₙ} 同分布）。所以 aₙ 单调不增。

第二步：极限存在

熵非负：aₙ ≥ 0。单调不增且有下界的实数列必有极限（实数的单调收敛定理）。于是定义 B 的极限存在：

B = limn→∞ H(Xₙ|X₁ⁿ⁻¹)　存在

第三步：Cesàro 均值让两定义会师

链式法则（Ch2）把联合熵拆成条件熵之和：

1n H(X₁…Xₙ) = 1n Σᵢ₌₁ⁿ H(Xᵢ|X₁ⁱ⁻¹) = aₙ 的算术平均

Cesàro 均值定理：若数列 aₙ → B，则其算术平均 (1/n)Σaᵢ → B（平均不会跑输极限）。于是定义 A 的极限也存在且等于 B：

H(𝒳) = lim 1n H(X₁…Xₙ) = lim H(Xₙ|X₁ⁿ⁻¹) = H′(𝒳)
💡 关键一跃

整个证明只用三样东西：条件化减熵（Ch2）、平稳性（平移不变）、单调有界收敛。没有新数学——这说明熵率概念的稳健：它不是新公理，而是熵的性质在时间维度上的自然展开。

⚠️ 常见误区

"既然 aₙ 单调不增趋于 B，那 H(Xₙ|X₁ⁿ⁻¹) 一定严格递减"——错，可以恒为常数（i.i.d. 时 aₙ ≡ H(X₁)）。另外注意：A = B 依赖平稳性；非平稳过程两个极限可以一个存在一个不存在，定义 A 的 Cesàro 平均甚至可能"洗掉"瞬态而定义 B 发散。

4.3马尔可夫链：熵率真的能算出来

定义再漂亮，算不出来也只是哲学。有一类过程熵率可以精确计算：马尔可夫链（Markov Chain）——下一状态只依赖当前状态：

p(Xₙ₊₁ | Xₙ, Xₙ₋₁, …, X₁) = p(Xₙ₊₁ | Xₙ)

马尔可夫链的熵率公式

对不可约、非周期的平稳马尔可夫链，"知道全部历史"等价于"知道当前状态"：

H(𝒳) = H(X₂|X₁) = Σᵢ μᵢ · H(转移矩阵第 i 行)

其中 μ 是平稳分布（Stationary Distribution）：满足 μP = μ 的概率向量，也是长时间运行后各状态的出现频率。公式的读法：在状态 i 时，下一步的不确定度是转移矩阵第 i 行的熵；再按各状态的驻留频率 μᵢ 加权平均。

完整数值例：两状态马尔可夫链

两个状态，转移规则：状态 1 以 α = 1/4 的概率跳到状态 2；状态 2 以 β = 1/2 的概率跳回状态 1。

图 4.1 两状态马尔可夫链：转移概率 α = 1/4（1→2），β = 1/2（2→1）。

第一步：求平稳分布。两状态链的平稳分布有公式 μ₁ = β/(α+β)、μ₂ = α/(α+β)（由 μ₁α = μ₂β 流量平衡 + 归一化解出）：

μ₁ = βα+β = 1/23/4 = 23，　　μ₂ = αα+β = 13

验证 μP = μ：状态 1 的流入 = μ₁·(3/4) + μ₂·(1/2) = (2/3)(3/4) + (1/3)(1/2) = 1/2 + 1/6 = 2/3 = μ₁ ✓

第二步：算各行熵。

行 1（3/4, 1/4）：H = −34log₂34 − 14log₂14 = 0.75×0.415 + 0.25×2 = 0.311 + 0.500 = 0.811 比特
行 2（1/2, 1/2）：H = 1 比特

第三步：加权平均。

H(𝒳) = μ₁×0.811 + μ₂×1 = 23×0.811 + 13×1 = 0.541 + 0.333 = 0.874 比特/符号

对比：记忆到底省了多少？

同一个过程，假装它独立（只用边际分布 μ = (2/3, 1/3)），每符号不确定度是：

H(X₁) = H(23, 13) = 23×0.585 + 13×1.585 = 0.390 + 0.528 = 0.918 比特

0.918 → 0.874：利用一步记忆，每符号省 0.044 比特。再看摊销序列怎么收敛到熵率：

量数值含义
H(X₁)0.918只用边际，高估
H(X₁X₂)/2 = (0.918 + 0.874)/20.896两个符号摊销，逼近中
H(𝒳) = lim0.874熵率，真实极限

单调下降趋于熵率——这正是 4.2 节定理在一个具体例子上的显影。

💡 关键一跃

马尔可夫链的熵率公式把"无限长的历史依赖"压缩成"有限状态的加权平均"——因为马尔可夫性保证历史的影响力全部凝结在当前状态里。能算，是因为记忆有边界。

⚠️ 常见误区

"熵率 = 各行熵的平均，即 (0.811+1)/2 = 0.906"——错！权重不是 1/2，是平稳分布 μ = (2/3, 1/3)：状态驻留频率才是正确的权重。用均匀权重等于假设两个状态各待一半时间，而这个链明显更"赖"在状态 1。

4.4案例：英文的熵率，与"冗余"的度量

把英文文本看成一个随机过程：每个字母是一个符号，字母间有强依赖（q 后必 u、th 后多为 e）。这个案例让"记忆降低熵率"变成可触摸的数字。

三个层次的估计

模型每字母比特数说明
假设均匀（27 符号含空格）log₂27 ≈ 4.76完全不用任何统计
只用字母频率（边际熵）≈ 4.1用上 e 多 z 少这类信息
Shannon 的估计（利用长程依赖）≈ 1.3用真人做"猜下一字母"实验

Shannon 的实验很朴素：让受试者逐字母猜文本，猜得越准说明剩余不确定度越低；把猜对率换算成熵，得到约 1.3 比特/字母。含义：英文里约 73% 的内容是冗余的（1 − 1.3/4.76 ≈ 0.73）——理论上 100 页的英文书，极限压缩后只需 27 页等效比特。

💡 关键一跃

冗余 = 1 − 熵率/最大可能熵。冗余不是浪费的同义词：它既是可压缩的空间（Ch5 的收益来源），也是抗噪声的缓冲（Ch7 纠错码刻意注入受控冗余）。同一现象，两章各取一面。

⚠️ 常见误区

"熵率 ≈ 1.3 比特，所以任何英文文本都能压到 1.3 比特/字母"——错。1.3 是对"英文"这个信源的渐近估计，依赖模型对长程依赖的刻画深度；具体文本、具体编码器都有差距。且这是无损极限——有损压缩（Ch10 率失真）还能更低，但要付出失真代价。

4.5边界与账单：隐马尔可夫、非平稳，与交给 Ch5 的任务

隐马尔可夫模型：熵率存在但难算

比马尔可夫链更一般的是隐马尔可夫模型（Hidden Markov Model, HMM）：观测到的符号 Yₙ 由隐状态 Sₙ 驱动，而 Sₙ 是马尔可夫链。文字、语音、DNA 序列都是 HMM 的常客。坏消息：Y 过程本身一般不是马尔可夫的，熵率 lim H(Yₙ|Y₁ⁿ⁻¹) 存在（过程平稳时），但没有 ΣμᵢH(行) 这样的封闭公式——通常只能靠递推数值逼近。这是"能算"与"只能逼近"的分界线。

非平稳过程怎么办

本章定理的大门是平稳性。非平稳（分布随时间漂移，如季节性数据）时，两个极限可能不等甚至不存在。工程上的折衷：局部平稳——把数据切成近似平稳的段，逐段估计熵率；或引入时变模型。这已超出本书范围，但你要知道边界在哪。

本章交给 Ch5 的账

现在极限一侧已完备：i.i.d. 是 H（Ch3），平稳过程是熵率（Ch4），马尔可夫链上熵率可算。但算出极限 ≠ 达到极限。Ch3 的两段式编码只是存在性论证（要对 2ⁿᴴ 条典型序列编号，根本不可操作）。下一章回答：什么样的具体码（前缀码、霍夫曼码）能真的逼近 H？怎样保证无歧义译码？——从"极限是多少"转向"用什么达到"。

💡 关键一跃

基础段四章的分工至此清晰：Ch2 定义度量，Ch3 证明 i.i.d. 极限，Ch4 推广到平稳过程。定义—极限—可达性三步走完前两步，Ch5 走第三步：把 H 变成你手里能运行的编码器。

观测过程 Y 一般不是马尔可夫的——当前观测不能凝结全部历史信息（隐状态未知），条件熵 H(Yₙ|Y₁ⁿ⁻¹) 无法折叠成有限状态的加权平均，只能递推逼近。
回忆 4.5-2

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
随机过程（Stochastic Process）
点击翻面 →
定义带时间索引的一族随机变量 {X₁, X₂, …}，允许任意依赖。
解决问题把 i.i.d. 推广为可建模真实信源（文本、语音、天气）的对象。
直觉从"一袋独立弹珠"升级为"一条有记忆的流水线"。
误区以为过程 = 序列值——它是随机变量的族，分布才是本体。
何时用一切有记忆信源：Ch4 熵率、Ch5 上下文编码、HMM。
概念卡 2
平稳性（Stationarity）
点击翻面 →
定义任意有限维联合分布在时间平移下不变。
解决问题让"每符号平均不确定度"这个量有意义——是熵率存在的大门。
直觉统计规律没有"几点钟"：从哪开始看都长一个样。
误区与"独立"混淆——平稳允许任意依赖，只禁时间漂移。
何时用熵率两定义相等定理、马尔可夫链平稳分布存在性。
概念卡 3
熵率（Entropy Rate）
点击翻面 →
定义H(𝒳) = lim (1/n)H(X₁…Xₙ) = lim H(Xₙ|X₁ⁿ⁻¹)（平稳时相等）。
解决问题给出有记忆信源每符号的极限不确定度 = 压缩极限。
直觉看完所有历史后，下一个符号还剩多少"意外"。
误区当成边际熵 H(X₁)——忽略了记忆，系统性高估。
何时用平稳信源的压缩极限、文本冗余度估计、Ch5 的目标值。
概念卡 4
Cesàro 均值（Cesàro Mean）
点击翻面 →
定义aₙ → B 则 (1/n)Σᵢaᵢ → B。
解决问题把"逐项收敛"翻译成"平均收敛"，连接熵率两个定义。
直觉平均不会跑输极限：尾部都贴着 B，均值甩不掉。
误区反向使用——均值收敛推不出逐项收敛（震荡列可反例）。
何时用熵率 A=B 证明、一切时间平均 vs 渐近值的论证。
概念卡 5
马尔可夫链熵率（Markov Entropy Rate）
点击翻面 →
定义H(𝒳) = Σᵢ μᵢ H(转移矩阵第 i 行)。
解决问题把熵率从极限变成有限步可算的数。
直觉当前状态凝结全部历史；按驻留频率给各行的不确定度加权。
误区权重取均匀——必须是平稳分布 μ。
何时用两状态/有限状态链的精确计算，建模天气、信道错误。
概念卡 6
平稳分布（Stationary Distribution）
点击翻面 →
定义满足 μP = μ 的概率向量；不可约非周期链上唯一。
解决问题给出各状态的长期驻留频率——熵率公式的权重。
直觉流动的水位：各状态流入=流出时的分布，跑久了必然逼近它。
误区与初始分布混为一谈——μ 由转移矩阵决定，与起点无关。
何时用马尔可夫链熵率、PageRank、MCMC 采样。

📝分层习题

L1 概念辨析(a) i.i.d. 过程的熵率是多少？用两个定义各验证一次。(b) 一个完全确定的过程（如恒定序列 0,0,0,…）的熵率是多少？这与"熵率是有记忆信源的压缩极限"矛盾吗？
提示

(a) 独立时条件熵退化为边际熵；(b) 想想 H(Xₙ|历史) 在结局已定时是多少。

完整解答

(a) 定义 B：独立 ⟹ H(Xₙ|X₁ⁿ⁻¹) = H(Xₙ) = H(X₁)，常数列极限 = H(X₁)。定义 A：H(X₁…Xₙ) = ΣH(Xᵢ) = nH(X₁)（独立加性），除以 n 取极限也是 H(X₁)。两定义都回到 Ch3 的 H——熵率是熵的推广而非替代 ✓

(b) 恒定序列：给定历史后 Xₙ 完全确定，H(Xₙ|X₁ⁿ⁻¹) = 0，熵率 = 0。不矛盾：确定过程没有不确定度，极限压缩率就是 0 比特/符号（整条序列只需存"它恒为 0"这个规则）。为什么易错：把"熵率 0"误读为"理论失效"——恰恰相反，它正确预言了完全可预测的数据不占比特。

L1 概念辨析判断并说明理由：(a) "Xᵢ 同分布"的过程一定平稳；(b) 平稳过程的熵率一定小于等于边际熵 H(X₁)；(c) 马尔可夫链的熵率等于 H(X₂|X₁)。
提示

(a) 平稳要求联合分布平移不变，同分布只是边际层面；(b) 条件化减熵；(c) 注意定义 B 的极限形式。

完整解答

(a) 错。反例：X₁ ~ Bern(1/2)，令 X₂ = X₁（完全复制），X₃ 独立 Bern(1/2)，X₄ = X₃，X₅ 独立 Bern(1/2)……每个 Xᵢ 边际都是 Bern(1/2)（同分布），但 (X₁,X₂) 是完全相关对，(X₂,X₃) 却是独立对——平移一步联合分布就变了，非平稳。平稳约束的是联合分布的平移不变，同分布只约束边际。

(b) 对。H(𝒳) = lim H(Xₙ|X₁ⁿ⁻¹) ≤ H(Xₙ) = H(X₁)，条件化减熵 + 平稳。等号 ⟺ 独立。

(c) 对（平稳马尔可夫链时）。马尔可夫性：H(Xₙ|X₁ⁿ⁻¹) = H(Xₙ|Xₙ₋₁)；平稳性：= H(X₂|X₁) 与 n 无关，常数列的极限是它本身。为什么易错：忘了前提是"平稳"——非平稳马尔可夫链（转移矩阵时变）此式不成立。

L2 手算推导把 4.3 节的例子完整复算一遍：α = 1/4、β = 1/2 的两状态马尔可夫链。要求：(a) 由流量平衡方程解出 μ；(b) 验证 μP = μ；(c) 算两行熵（保留三位小数）；(d) 算熵率；(e) 算边际熵 H(X₁) 并指出记忆带来的每符号收益。
提示

流量平衡：μ₁α = μ₂β，配 μ₁+μ₂=1。行熵套二元熵公式。

完整解答

(a) μ₁·(1/4) = μ₂·(1/2) 且 μ₁+μ₂ = 1 ⟹ μ₁ = 2μ₂ ⟹ μ₂ = 1/3，μ₁ = 2/3。

(b) 状态 1 流入 = (2/3)(3/4)+(1/3)(1/2) = 1/2+1/6 = 2/3 = μ₁ ✓；状态 2 流入 = (2/3)(1/4)+(1/3)(1/2) = 1/6+1/6 = 1/3 = μ₂ ✓

(c) 行 1：−0.75·log₂0.75 − 0.25·log₂0.25 = 0.75×0.4150 + 0.25×2 = 0.311+0.500 = 0.811；行 2：1.000。

(d) H(𝒳) = (2/3)(0.811)+(1/3)(1) = 0.541+0.333 = 0.874 比特/符号。

(e) H(X₁) = H(2/3,1/3) = (2/3)(0.585)+(1/3)(1.585) = 0.390+0.528 = 0.918。收益 = 0.918−0.874 = 0.044 比特/符号。为什么易错：(c) 中 log₂(3/4) 取成正值忘加负号，或 (d) 误用 1/2 均匀权重得 0.906。

L2 手算推导新链：状态 1 以 0.9 留在 1、以 0.1 去 2；状态 2 等概率去 1 或 2。即 P = [[0.9, 0.1], [0.5, 0.5]]。求：(a) 平稳分布；(b) 熵率；(c) 与 4.3 例（0.874）比较，这条链更可预测还是更不可预测？用直觉解释。
提示

μ₁ = β/(α+β)，这里 α = 0.1、β = 0.5。H(0.1) ≈ 0.469。

完整解答

(a) μ₁ = 0.5/(0.1+0.5) = 5/6，μ₂ = 0.1/0.6 = 1/6。验证：状态 1 流入 = (5/6)(0.9)+(1/6)(0.5) = 0.75+0.0833 = 0.8333 = 5/6 ✓

(b) 行 1 熵 = H(0.9,0.1) = 0.9×0.152+0.1×3.322 = 0.137+0.332 = 0.469；行 2 熵 = 1。H(𝒳) = (5/6)(0.469)+(1/6)(1) = 0.391+0.167 = 0.557 比特/符号。

(c) 更可预测（0.557 < 0.874）。直觉：这条链 5/6 的时间赖在状态 1，而状态 1 的行熵只有 0.469（九一开，几乎确定留下）——大部分时间处于"低不确定度状态"，且该状态本身粘性极强。对比 4.3 例：那里状态 1 也占优（2/3）但粘性弱（3/4 留下）。为什么易错：只看行熵不看 μ——行 2 熵 = 1 很大，但它只占 1/6 的时间，对熵率贡献有限。

L3 建模应用把某城市"每日天气"建模为两状态马尔可夫链：晴（S）、雨（R）。历史数据显示：晴天后次日仍晴概率 0.8；雨天后次日转晴概率 0.4。(a) 写出转移矩阵并求平稳分布与熵率；(b) 若要把该城市 10 年（3650 天）的天气记录极限压缩，约需多少比特？与定长 1 比特/天相比压缩比多少？(c) 这个模型的哪条假设最可疑？如果放宽它，熵率会怎么变？
提示

(a) α = P(S→R) = 0.2，β = P(R→S) = 0.4；(b) 总量 = n×熵率；(c) 马尔可夫性 vs 平稳性，哪个先被现实打破？

完整解答

(a) P = [[0.8, 0.2], [0.4, 0.6]]（行 S、R）。μ_S = 0.4/(0.2+0.4) = 2/3，μ_R = 1/3。行熵：H(0.8,0.2) = 0.8×0.322+0.2×2.322 = 0.258+0.464 = 0.722；H(0.4,0.6) = 0.4×1.322+0.6×0.737 = 0.529+0.442 = 0.971。熵率 = (2/3)(0.722)+(1/3)(0.971) = 0.481+0.324 = 0.805 比特/天。

(b) 3650 × 0.805 ≈ 2938 比特 ≈ 367 字节。定长需 3650 比特，压缩比 0.805（约省 19.5%）。

(c) 最可疑的是马尔可夫性（天气有持续性：连阴雨、季风期，明天不只依赖今天）和平稳性（季节漂移）。放宽马尔可夫性：用 k 阶马尔可夫（看过去 k 天），条件更多，H(Xₙ|近 k 天) ≤ H(Xₙ|前一天)，熵率下降——更长的记忆暴露更多可预测性。放宽平稳性：熵率极限可能不存在，需分段处理。为什么易错：以为"模型越细熵率越高"——恰相反，条件只会减少熵，精细模型给出更低（更接近真实）的极限。
