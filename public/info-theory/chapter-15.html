15.1为什么单链路理论不够：容量从一个数变成一个区域

第 7 章给出了信息论最漂亮的结论之一：离散无记忆信道的容量 C = maxp(x) I(X;Y)。一个发送者、一个接收者、一条信道——香农第二定理说：只要码率 R < C 就有任意可靠的码，R > C 则必错。

但真实的通信网络里，这三者都成"多"：

  • 多发送者：同一基站接收两部手机的上行信号（多址接入，MAC）；
  • 多接收者：同一颗卫星向千家万户广播（广播信道，Broadcast Channel）；
  • 相关分布信源：两个气象站观测同一片天气，各自把数据压回总部，编码端互相看不见（分布式信源编码，Slepian–Wolf）。

这些场景带来的第一个观念冲击是：容量不再是一个数，而是一个区域。两个用户同时通信，用户 1 想让 R₁ 尽量大，用户 2 也想让 R₂ 尽量大，二者通过共享信道互相牵制——不存在"最优速率"，只存在一张"哪些速率对 (R₁, R₂) 同时可达"的地图。这张地图的边界线，全部用互信息和条件熵的不等式写出。

💡 关键一跃

网络信息论的统一语言：用互信息（或条件熵）的不等式组圈出可达速率区域。单链路的 C = max I(X;Y) 是退化特例——一个变量时"区域"退化成数轴上的一段区间，上界就是一个数。

⚠️ 常见误区

"多用户就是几条单链路并行"——错。多址信道里两个信号在接收端叠加，谁也躲不开谁；广播信道里一份发送要同时服务多个接收者；相关信源之间藏着可以互相利用的冗余。网络效应不是单链路的叠加，这正是本章存在的理由。

15.2多址接入信道（MAC）：两路信号叠加，容量区是一个凸五边形

上一节立了三类新对象的靶子，本节先打第一个：两个发送者、一个接收者。多址接入信道（Multiple Access Channel, MAC）的模型：发送者 1 与发送者 2 各自独立地选消息，分别编码成 X₁ⁿ 与 X₂ⁿ 送入信道，信道输出 Yⁿ，接收者要同时还原两条消息。手机上行、Wi-Fi 多终端回传，都是它。

✅ 定理（MAC 容量区，Ahlswede–Liao）

对固定的输入分布 p(x₁)p(x₂)，可达速率对 (R₁, R₂) 的集合是满足下面三条不等式的凸区域，再对所有输入分布取并集的凸包：

R₁ ≤ I(X₁;Y|X₂)，　R₂ ≤ I(X₂;Y|X₁)，　R₁+R₂ ≤ I(X₁,X₂;Y)

三条约束各有一句话的读法：第一条——把 X₂ 当作已知礼物时，用户 1 单独能传多快；第二条对称；第三条——把两个用户打包看成一个"超级用户"，总速率不能超过联合输入与输出之间的互信息。区域通常是凸五边形：两条边来自单用户约束，一条斜边来自和率约束。

角点怎么达到？用串行译码（successive decoding）：接收者先把 X₂ 的码字当作已知噪声背景译出用户 1 的消息，此时用户 1 的速率上限是 I(X₁;Y)；译出用户 1 后把它"减掉"，用户 2 面对的等效信道已知 X₁，上限 I(X₂;Y|X₁)。这就扫出一个角点 (I(X₁;Y), I(X₂;Y|X₁))；交换译码次序得到另一个角点；两角点之间用时分复用连起来。

例 1：无噪声二元求和 MAC 的完整手算

X₁、X₂ 独立 Bern(1/2)，信道无噪声地把两者相加：Y = X₁ + X₂ ∈ {0, 1, 2}。我们来把容量区完整算出来。

第一步：算 Y 的分布。四种输入对 (X₁,X₂) 各以概率 1/4 出现：

  • (0,0) → Y=0，概率 1/4；
  • (0,1) 与 (1,0) → Y=1，概率 1/4+1/4 = 1/2；
  • (1,1) → Y=2，概率 1/4。

所以 Y 服从 (1/4, 1/2, 1/4)，H(Y) = H(1/4, 1/2, 1/4)。展开：

H(Y) = −14·log₂14 − 12·log₂12 − 14·log₂14 = 12 + 12 + 12 = 1.5 比特

第二步：算角点 A——先译用户 1。用户 1 把 X₂ 当背景噪声：

I(X₁;Y) = H(Y) − H(Y|X₁)

给定 X₁ 之后，Y = X₁ + X₂ 的全部随机性来自 X₂，而 X₂ ~ Bern(1/2) 与 X₁ 独立，所以 H(Y|X₁) = H(X₂) = 1 比特。于是

I(X₁;Y) = 1.5 − 1 = 0.5 比特

译出 X₁ 后，接收者从 Y 中减掉它，剩下 Y − X₁ = X₂——用户 2 面对一条无噪声信道：

I(X₂;Y|X₁) = H(X₂|X₁) − H(X₂|Y,X₁) = H(X₂) − 0 = 1 比特

（第一个等号后第一项用了 X₁ ⊥ X₂；第二项为 0 因为给定 X₁ 与 Y，X₂ = Y − X₁ 被唯一决定。）角点 A = (0.5, 1)。

第三步：对称性给出角点 B。信道对两个用户完全对称，交换角色得角点 B = (1, 0.5)。

第四步：算和率上界。

I(X₁,X₂;Y) = H(Y) − H(Y|X₁,X₂) = H(Y) − 0 = 1.5 比特

（给定两个输入，输出无噪声，条件熵为 0。）所以 R₁ + R₂ ≤ 1.5，而角点 A、B 的和率恰好都是 1.5——斜边上的每一点都顶到和率界。

速率点R₁R₂R₁+R₂达到方式

和时分复用对比——本章第一个"意外红利"。如果两用户轮流独占信道（时分复用，TDMA），单人独占时这条无噪声二元信道每用户每时隙最多传 1 比特（自己的一个二元符号被对方零贡献送出去），各占一半时间就和率只有 1 比特。而联合译码允许两路信号真正叠加，和率达到 1.5 比特——多出来的 0.5 比特从哪来？从 Y=1 这个"叠加态"里来：Y=1 以概率 1/2 出现，它携带了"两输入恰好一 0 一 1"这半比特的信息，时分复用根本制造不出这个状态。叠加不是干扰，是信息。

💡 关键一跃

MAC 的本质是"把对手先当噪声、译出后减掉"。串行译码把五边形的两个角点变成现实；斜边上的点用时分复用两角点即可。整个区域因此不再需要更花哨的技术。

⚠️ 常见误区

"容量区矩形 R₁ ≤ C₁, R₂ ≤ C₂ 各自独立"——错。两用户共享同一条信道，和率约束 R₁+R₂ ≤ I(X₁,X₂;Y) 把矩形左上角削掉，区域是五边形不是矩形。忽视和率约束，会误以为两用户能同时跑满各自单用户速率。

15.3Slepian–Wolf 定理：编码端互不相见，总和率却不打折扣

MAC 解决"多发送者共享信道"，本节转向第二个新对象：相关分布信源。两个信源 X、Y 有相关（比如相邻两个气象站的温度读数），各自独立编码——编码器 1 只看见 Xⁿ，编码器 2 只看见 Yⁿ——译码端收到两路码流后要同时还原 Xⁿ 和 Yⁿ。

直觉的预算是：X 单独压缩要 H(X)，Y 单独压缩要 H(Y)，合计 H(X)+H(Y)。但如果两个编码器能商量（集中式编码），第 3 章告诉我们总和率只要 H(X,Y)。编码端互不相见，要不要为此付出代价？

✅ 定理（Slepian–Wolf，1973）

两个相关离散无记忆信源 (X,Y) 分别编码、联合译码，可达速率域为：

R₁ ≥ H(X|Y)，　R₂ ≥ H(Y|X)，　R₁+R₂ ≥ H(X,Y)

三条约束各有一句话的读法：第一条——就算译码端白送 Y 给编码器 1 当边信息，X 也得花 H(X|Y)（条件化减熵，这是 X 的底线）；第二条对称；第三条——两路总和率不得低于联合熵 H(X,Y)，否则两信源联合可区分的状态数装不下。反直觉之处：总和率下界 H(X,Y) 与编码器互相能看见时一模一样——分离编码在速率上零损失，全部代价只是译码复杂度。

例 2：相关二元信源的完整手算

X ~ Bern(1/2)，Z ~ Bern(0.1) 与 X 独立，Y = X ⊕ Z（X 经过一条翻转概率 0.1 的二元对称信道得到 Y）。两站各记各的读数，上传给总部。

第一步：算边际熵。X 均匀，H(X) = 1。Y 也是 Bern(1/2)（均匀变量模 2 加任何独立噪声仍均匀：P(Y=0) = 0.5×0.9 + 0.5×0.1 = 0.5），所以 H(Y) = 1。

第二步：算条件熵。H(Y|X) = H(Z) = h(0.1)（给定 X，Y 的随机性全部来自 Z）。展开二元熵函数：

h(0.1) = −0.1·log₂ 0.1 − 0.9·log₂ 0.9 = 0.3322 + 0.1368 = 0.469 比特

由对称结构（BSC 的反向信道同样是翻转概率 0.1 的 BSC）有 H(X|Y) = h(0.1) = 0.469 比特。

第三步：算联合熵。用链式法则：

H(X,Y) = H(X) + H(Y|X) = 1 + 0.469 = 1.469 比特

第四步：读出率域并对比 naive 方案。

方案R₁ 下界R₂ 下界总和率

率域是一个五边形：R₁ ≥ 0.469、R₂ ≥ 0.469、R₁+R₂ ≥ 1.469。角点 (0.469, 1) 的读法：编码器 2 老老实实花 1 比特/符号把 Y 无损送达；译码端拿着 Y 当边信息，编码器 1 只需 0.469 比特/符号——它甚至从头到尾不知道 Y 是什么。

为什么可能：典型序列 + 随机装箱（Binning）

给定 Yⁿ 之后，与之"相容"的 Xⁿ 有多少条？Yⁿ 已知时，Xⁿ 与 Yⁿ 的差异序列 Zⁿ 必须典型——大约 n·0.1 个位置翻转——这样的 Zⁿ 约 2n·h(0.1) = 20.469n 条，因此候选 Xⁿ 也只有约 20.469n 条。编码器 1 的任务从"指出 2n 条 Xⁿ 里的哪一条"缩小为"在 20.469n 个候选里挑一个"。

随机装箱（Random Binning）的做法：把所有 2n 条 Xⁿ 随机扔进 2nR₁ 个桶，编码器 1 只发送桶号（花 nR₁ 比特）。译码端在桶内找与 Yⁿ 联合典型的那条 Xⁿ。只要桶数 ≥ 候选数，即 nR₁ ≥ 0.469n，桶内几乎不会有两条都与 Yⁿ 相容——译码成功。桶数是码本大小的指数级缩小，这就是"互不相见也不损失"的机关。

💡 关键一跃

Slepian–Wolf = 把"边信息"从编码端搬到译码端而速率不变。编码端盲发桶号，译码端拿着 Yⁿ 在桶里挑相容者——边信息只需要在译码时出现，不需要在编码时出现。

⚠️ 与第 10 章的关系

本章是无损版本：译码端要精确还原 Xⁿ。若允许失真（率失真，Ch10）且译码端有边信息，对应结论是 Wyner–Ziv 定理——同样"编码端不见边信息"，但在有损情形下一般会有速率损失（高斯/二元等特例无损失）。别把"Slepian–Wolf 零损失"误记成"所有带边信息的编码都零损失"。

15.4广播与中继：一份发送服务多人，一个帮手打通远距

还剩第三类对象中的两件：多接收者（广播信道）与中转节点（中继信道）。这两块没有 MAC 与 Slepian–Wolf 那样干净的一般性定理，本章只做定性刻画加一个小例子——但要记住哪些是精确已知的、哪些只是可达方案。

广播信道：叠加编码，强者通吃粗精两层

广播信道（Broadcast Channel, BC）：一个发送者、多个接收者，例如卫星对千家万户。一般广播信道的容量区未知；但退化广播信道（Degraded BC，接收者按信道质量排成一列，弱用户的输出是强用户输出再加噪）有精确答案，编码思想叫叠加编码（Superposition Coding）：

  • 把信息分两层：粗信息（基本服务，码率低、抗噪强）与精信息（增强服务，叠加在粗信息之上）；
  • 弱用户（信道差）只解粗信息，把精信息当噪声；
  • 强用户（信道好）先解粗信息、减掉，再解精信息——这正是 15.2 的串行译码思想在接收端的对偶。

小例：高斯广播信道（只给结论与直觉）。发送功率 P，弱用户噪声 N₂ > 强用户噪声 N₁，把功率的 α 份额分给强用户的精信息、1−α 分给弱用户的粗信息。可达率对为：

R₂ = 12 log₂( 1 + (1−α)PαP + N₂ )，　R₁ = 12 log₂( 1 + αPN₁ )

直觉读法：弱用户的分母里有 αP——强用户的精信息对它就是噪声；强用户先解出粗信息并减掉，自己的精信息只面对干净噪声 N₁。α 从 0 扫到 1，就描出整个容量区边界：α=0 时全部功率给弱用户，α=1 时全部给强用户。这里不做推导，记住结构：功率分配参数 α 扮演"服务两用户的预算旋钮"。

中继信道：两段割，瓶颈取小

中继信道（Relay Channel）：发送者 X 想到接收者 Y，中间有个中继站 R 帮忙（收到 Y₁，转发 X₁）。对物理退化中继，一个经典可达率是：

R < min { I(X; Y₁),　I(X, X₁; Y) }

两项各是一段"割"：第一项 I(X;Y₁) 是"发送者 → 中继"这一段——中继再聪明，也得先听清发送者说了什么；第二项 I(X,X₁;Y) 是"发送者与中继合力 → 接收者"这一段——把 X 与 X₁ 看作联合输入的超级用户，对 Y 能送多快。两段瓶颈取小，就是"接力速度由最慢一棒决定"。一般中继信道的容量仍是开放问题，这个 min 式只是（退化情形的）可达率。

⚠️ 本章账单：一般网络容量区仍未知

双用户干扰信道（两对收发互相干扰）、一般广播信道、一般中继信道——它们的容量区至今未知。本章的精确结论只覆盖：MAC、Slepian–Wolf、退化广播、（物理退化）中继等结构良好的特例。网络信息论是一张"已知边界的地图"，不是完工的大厦。

💡 关键一跃

把 15.2–15.4 串起来看：MAC 里接收者做减法（串行译码），广播信道里强用户做减法（叠加编码），Slepian–Wolf 里译码端做匹配（装箱）。网络信息论的技术主线就是一句话——让掌握更多信息的一方先解、再减、再解。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
MAC 容量区（MAC Capacity Region）
点击翻面 →
定义满足 R₁≤I(X₁;Y|X₂)、R₂≤I(X₂;Y|X₁)、R₁+R₂≤I(X₁,X₂;Y) 的速率对集合（取凸包）。
解决问题多个发送者共享一条信道时，速率资源如何分配才算"极限"。
直觉五边形：两个角点 = 两种"先解谁"的次序，斜边 = 总和率天花板。
误区以为是矩形 R₁≤C₁、R₂≤C₂——和率约束把左上角削掉了。
何时用蜂窝上行、多终端 Wi-Fi；串行干扰消除（SIC）接收机的理论基础。
概念卡 2
联合译码 vs 时分复用（Joint Decoding vs TDMA）
点击翻面 →
定义联合译码：接收者同时/串行解出所有用户消息；时分复用：用户轮流独占信道。
解决问题多用户是"挤在一起传"还是"排队传"的根本路线选择。
直觉叠加态本身是信息：二元求和 MAC 里 Y=1 白送半比特，时分复用造不出它。
误区以为时分"公平所以不亏"——例 1 中和率 1 vs 1.5，严格亏 0.5 比特。
何时用评价多址协议效率；理解现代蜂窝为何用 SIC/NOMA 而非纯 TDMA。
概念卡 3
Slepian–Wolf 定理（Slepian–Wolf Theorem）
点击翻面 →
定义相关信源分离编码、联合译码的率域：R₁≥H(X|Y)、R₂≥H(Y|X)、R₁+R₂≥H(X,Y)。
解决问题分布式压缩：编码端互不相见时，相关性还能不能被利用？
直觉边信息只需在译码时出现——盲发桶号，译码端拿 Y 挑相容者。
误区以为分离编码必有速率损失——无损情形下总和率与集中式完全相同。
何时用传感器网络、分布式视频编码（DVC）；有损推广见 Wyner–Ziv（Ch10 后续）。
概念卡 4
随机装箱（Random Binning）
点击翻面 →
定义把 2^n 条典型序列随机分进 2^(nR) 个桶，编码端只发桶号，译码端在桶内找与边信息相容的序列。
解决问题编码端看不见边信息时，如何把码率压到 H(X|Y)。
直觉桶数 ≥ 候选数即可：候选只有 2^(nH(X|Y)) 条，每桶几乎不会撞车。
误区以为装箱是" hash 冲突难免"——联合典型性把候选集合缩到指数级小，冲突概率随 n 消失。
何时用Slepian–Wolf、Wyner–Ziv、Gelfand–Pinsker 的证明骨架，网络信息论的万能工具。
概念卡 5
叠加编码（Superposition Coding）
点击翻面 →
定义把粗信息与精信息分层叠加发送：弱用户只解粗层，强用户先解粗层、减掉再解精层。
解决问题退化广播信道如何一份发送同时服务好、差两类接收者并达到容量区。
直觉像分层视频编码：基础层人人能看，增强层只有带宽够的人才能叠加享用。
误区以为该给弱用户单独发一份——叠加+串行译码严格优于时分/频分切资源。
何时用退化广播信道容量区证明；NOMA、分层调制的理论源头。
概念卡 6
广播信道与中继信道（Broadcast & Relay Channel）
点击翻面 →
定义广播：一发送者多接收者；中继：发送者经中转站协助到达接收者。
解决问题多接收者与有帮手两类基本网络结构的速率极限刻画。
直觉广播 = 分层服务；中继 = 接力，速度由"发→中继"与"发+中继→收"两段割取小。
误区以为两者都有一般容量公式——只有退化等特殊情形有精确解，一般情形开放。
何时用卫星/蜂窝下行（广播）、mesh 网络与协作通信（中继）的极限分析。

📝分层习题

L1 概念辨析判断：在 Slepian–Wolf 场景中，"编码器 1 看不见 Yⁿ，所以它的码率必须比 H(X|Y) 高出一截，作为对'看不见'的补偿"。对还是错？说明理由。
提示

回忆率域三条约束中哪一条管"总和率"，再比较它与集中式编码的总和率。

完整解答
错。Slepian–Wolf 的第三条约束 R₁+R₂ ≥ H(X,Y) 与集中式编码的总和率完全相同——"看不见"在速率上零损失。编码端缺的边信息由译码端补：编码器 1 盲发桶号（随机装箱），译码端拿 Yⁿ 在桶内挑相容序列。真正的代价是译码复杂度，不是码率。易错点：把"编码端需要边信息才能压低码率"的直觉误当成定理——装箱机制恰恰绕开了它。
L1 概念辨析选择：两用户 MAC 的容量区为什么不是矩形 {R₁ ≤ I(X₁;Y)，R₂ ≤ I(X₂;Y)}？选出最准确的一条。A. 因为互信息算不准；B. 因为和率约束 R₁+R₂ ≤ I(X₁,X₂;Y) 把矩形削去一角，两用户不能同时跑满各自的"对手当噪声"速率；C. 因为译码器算力有限；D. 因为信道有记忆。
提示

把两个用户打包成"超级用户"，总信息量有没有天花板？

完整解答
B。把 (X₁,X₂) 视为联合输入，信道总共只能送 I(X₁,X₂;Y) 的信息，R₁+R₂ 不得越过它。矩形的右上角 (I(X₁;Y), I(X₂;Y)) 一般越出这条斜边——例 1 里 I(X₁;Y)=I(X₂;Y)=0.5 时尚未越界，但若两用户都要求更高的单边速率就会撞上 1.5 的和率天花板。A 错：互信息是精确可算的；C 错：容量是信息论极限，与算力无关；D 错：本章全部模型都是离散无记忆信道。
L2 手算推导对例 1 的二元求和 MAC：① 直接验证角点 B = (1, 0.5)（即先译用户 2）；② 用链式法则证明和率 1.5 比特不可超越。
提示

① 交换例 1 第二步里的用户角色；② 对任意可行方案，写出 R₁+R₂ ≤ I(X₁,X₂;Y) 的推理链，再展开这个互信息。

完整解答

① 角点 B。先译用户 2：I(X₂;Y) = H(Y) − H(Y|X₂)。给定 X₂，Y = X₁+X₂ 的随机性全来自 X₁，H(Y|X₂) = H(X₁) = 1，故 I(X₂;Y) = 1.5 − 1 = 0.5。译出 X₂ 后减掉，用户 1 面对无噪声信道：I(X₁;Y|X₂) = H(X₁|X₂) − H(X₁|Y,X₂) = 1 − 0 = 1。所以角点 B = (R₁, R₂) = (1, 0.5)。✓

② 和率不可超越。设两用户消息 W₁、W₂ 独立，速率 R₁、R₂。Fano 不等式 + 数据处理不等式给出：n(R₁+R₂) = H(W₁,W₂) = I(W₁,W₂;Yⁿ) + H(W₁,W₂|Yⁿ) ≤ I(W₁,W₂;Yⁿ) + nεₙ ≤ I(X₁ⁿ,X₂ⁿ;Yⁿ) + nεₙ（数据处理，因 W₁,W₂ → X₁ⁿ,X₂ⁿ → Yⁿ 构成马尔可夫链）。无记忆性展开：I(X₁ⁿ,X₂ⁿ;Yⁿ) = H(Yⁿ) − H(Yⁿ|X₁ⁿ,X₂ⁿ) = H(Yⁿ) − Σᵢ H(Yᵢ|X₁ᵢ,X₂ᵢ) ≤ Σᵢ H(Yᵢ) − Σᵢ H(Yᵢ|X₁ᵢ,X₂ᵢ) = Σᵢ I(X₁ᵢ,X₂ᵢ;Yᵢ)。代入本信道：每项 I(X₁ᵢ,X₂ᵢ;Yᵢ) = H(Yᵢ) = 1.5（输入取 Bern(1/2) 独立时达到；而任何输入下 H(Y) ≤ H(1/4,1/2,1/4) 需验证——直接枚举输入分布 p = (p₀₀,p₀₁,p₁₀,p₁₁)，Y 分布 (p₀₀, p₀₁+p₁₀, p₁₁)，其熵在 p₀₀=p₁₁=1/4、p₀₁+p₁₀=1/2 时最大为 1.5）。故 R₁+R₂ ≤ 1.5 + εₙ，n→∞ 得 R₁+R₂ ≤ 1.5。和率 1.5 比特是硬上界，而角点 A、B 已达到——不可超越。✓

① 新率域。H(X) = H(Y) = 1 不变（均匀模 2 加噪仍均匀）。H(X|Y) = H(Y|X) = h(0.25) = 0.8113；H(X,Y) = 1 + 0.8113 = 1.8113。率域：R₁ ≥ 0.8113，R₂ ≥ 0.8113，R₁+R₂ ≥ 1.8113。注意相关性变弱（翻转更频繁），条件熵从 0.469 涨到 0.8113，可省的压缩空间随之缩小。

② R₁ = 1 时 R₂ 的下界。两条约束都管 R₂：单速率约束 R₂ ≥ H(Y|X) = 0.8113；和率约束 R₂ ≥ H(X,Y) − R₁ = 1.8113 − 1 = 0.8113。两者一致，故 R₂ 最小 = 0.8113 比特/符号。读法：X 已被无损送达译码端当边信息，Y 只需付出"给定 X 后的剩余不确定度" h(0.25)——这就是角点 (1, 0.8113)。（⚠️ 注意：0.189 = 1 − 0.8113 是互信息 I(X;Y)，是本题不能当答案的迷惑数字——条件熵才是单边压缩的下界。）
