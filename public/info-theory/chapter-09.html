9.1为什么需要高斯信道：从带限连续信道到 Y = X + Z

第 7 章给出了信道容量 C = max I(X;Y) 的定义和编码定理，第 8 章为连续变量备好了微分熵。但真实的物理信道——电话线里的电压波形、无线电里的电磁场——是连续时间、连续幅度的。这带出一个问题：怎么把一条连续波形信道变成我们能代入容量公式的对象？本节搭起这座桥。

第一步：采样定理把连续信道切成"每秒 2W 个自由度"

设信道带宽为 W Hz（只允许频率不超过 W 的信号通过）。采样定理（Sampling Theorem，Nyquist）说：带宽 W 的信号由每秒 2W 个等间隔采样完全决定——采样值给全了，整条波形可以用 sinc 插值无损重建。反过来，信道那头收到的带限波形，也只需每秒看 2W 个采样点就掌握了全部信息。

于是一条带宽 W 的连续信道，每秒相当于 2W 次独立的信道使用——这就是"自由度"的含义。把连续信道算容量的问题，化成了"每次使用能传多少比特"的离散问题。

第二步：每个自由度是一条离散时间 AWGN 信道

每次使用时，发送端发一个实数 X，接收端收到：

Yi = Xi + Zi，　Zi ~ N(0, N)

噪声在各自由度上独立同分布（"白"噪声的含义：频谱平坦 ⟹ 时域采样互不相关，高斯 ⟹ 不相关即独立）。这个模型叫加性高斯白噪声信道（AWGN Channel，Additive White Gaussian Noise Channel）。

第三步：噪声凭什么取高斯？两条理由

  • 中心极限定理（CLT）：导体热噪声、器件散粒噪声是海量独立微小扰动的叠加，叠加和的分布趋于高斯——这是物理层面的理由。
  • 最坏情形理由：在固定方差的所有噪声分布中，高斯分布的微分熵最大（第 8 章的结论）。噪声熵越大，h(Y|X) 越大，容量 I(X;Y) = h(Y) − h(Y|X) 越小——高斯噪声是同等功率下最坏的噪声。按高斯设计，等于给容量买了保险。这条理由的严格表述（给定矩约束下最大化熵的分布族）正是第 12 章最大熵原理的内容，这里先记账。
💡 关键一跃

一根带宽 W 的电话线，在信息论眼里不是一条管道，而是每秒 2W 条并行的小信道，每条独立地做 X → X+Z。后面所有公式里的"每次使用"，指的就是这 1/(2W) 秒里的一个自由度。

⚠️ 常见误区

"采样必丢信息，所以连续信道的容量永远算不准"——错。采样定理保证：对严格带限于 W 的信号，每秒 2W 个采样是无损表示。真正丢信息的是采样率低于 2W（混叠）。另外，"噪声取高斯只是工程近似"也不全对——第二条理由说明它还是理论上的最坏情形假设。

9.2容量公式怎么来：功率约束下，高斯输入摘走了最大熵

上一节把连续信道切成了 Y = X + Z 的离散自由度，但模型本身不是极限——它带出一个问题：在这条信道上，每次使用最多能可靠传多少比特？如果发送功率不受限，答案是无穷（把星座点摆得越来越密即可）。现实中的硬约束是平均功率约束（Average Power Constraint）：

1n ∑i=1n xi² ≤ P　（每个码字）；等价地 E[X²] ≤ P

推导：三步，每步都有名字

第一步：把互信息拆成"输出熵减噪声熵"。给定 X 时 Y = X + Z 只是 Z 的平移，所以 h(Y|X) = h(Z)：

I(X;Y) = h(Y) − h(Y|X) = h(Y) − h(Z)，　h(Z) = 12 log(2πeN)

h(Z) 与输入分布无关，所以最大化 I(X;Y) 就是最大化 h(Y)。

第二步：给 h(Y) 盖上天花板。X 与 Z 独立 ⟹ Var(Y) = Var(X) + N ≤ P + N。第 8 章的定理：固定方差下高斯分布微分熵最大，于是

h(Y) ≤ 12 log( 2πe·Var(Y) ) ≤ 12 log( 2πe(P+N) )

第三步：检查等号能不能取到。取 X ~ N(0, P)，则 Var(X) = P（功率预算用满），且 Y = X + Z 是两个独立高斯之和 ⟹ Y ~ N(0, P+N)，两个 ≤ 同时取等。天花板够得着，所以它就是答案：

✅ 高斯信道容量（定理）

平均功率约束 P、噪声方差 N 的 AWGN 信道，容量为

C = 12 log₂( 1 + PN )　比特/次

达到容量的输入分布是 X ~ N(0, P)。反方向（converse）：用 Fano 不等式加联合典型（第 7 章那套工具）可证，任何速率超过 C 的编码，错误概率都压不到零——细节见教材 9.1 节，思想与离散信道完全相同。

例 1：两组 P/N 的完整手算

P/N = 15（约 12 dB 的信噪比）：

  • 第 1 步：1 + P/N = 1 + 15 = 16；
  • 第 2 步：log₂(16) = 4；
  • 第 3 步：C = ½ × 4 = 2 比特/次。

P/N = 255（约 24 dB）：

  • 第 1 步：1 + P/N = 1 + 255 = 256；
  • 第 2 步：log₂(256) = 8；
  • 第 3 步：C = ½ × 8 = 4 比特/次。

注意这两组数字并排看的信息量：信噪比从 15 放大到 255（17 倍），容量只从 2 涨到 4（翻倍）。容量对功率是对数关系——这个观察后面习题还要考。

几何直觉：n 维空间里的球体填充

把 n 次使用看成一个 n 维向量。发送码字功率 ≤ nP，噪声向量的典型长度是 √(nN)（每个坐标方差 N，n 维欧氏长度约 √n·√N）。接收向量 = 码字 + 噪声，落在以原点为中心、半径 √(n(P+N)) 的大球内；译码要的是：以各接收点为中心、半径 √(nN) 的小"噪声球"互不重叠。能装下的码字个数 ≈ 体积比：

M ≈ ( √(n(P+N))√(nN) )n = ( 1 + PN )n/2

每个码字对应一个可靠消息，码率 R = (1/n)·log₂M = ½log₂(1+P/N)——和优化推导殊途同归。这幅图叫球体填充（Sphere Packing）：发送就像往大球房间里摆台球，每个台球自带半径 √(nN) 的"私人空间"，摆得下多少个不重叠，就能传多少消息。维度 n 越高，球的体积越集中在表面附近，这个计数越精确。

⚠️ 常见误区

"功率翻倍，容量翻倍"——错。C 对 P 是对数关系：功率从 P 翻倍到 2P，容量增量只有 ½log((1+2P/N)/(1+P/N))，且随 P 增大而递减（P≫N 时趋近 0.5 比特）。上面的例 1 就是证据：17 倍功率只买来 1 倍容量。功率换比特的汇率是对数级的，越换越不划算。

9.3多信道怎么分功率：并行高斯信道与注水

上一节解决了一条信道。但 DSL、OFDM 这类现代系统的做法是把一个物理媒介切成 K 条子信道，各频段噪声不一样——电话线上低频干净、高频被串扰污染。这带出一个问题：总功率只有一份，往各条子信道各倒多少，总容量最大？

模型：K 条独立并行 AWGN 信道，Yᵢ = Xᵢ + Zᵢ，Zᵢ ~ N(0, Nᵢ)，总功率约束 Σᵢ Pᵢ ≤ P。K 条独立信道一起用，容量是各信道容量之和的最大化：

C = maxΣPᵢ≤P ∑i=1K 12 log₂( 1 + PᵢNᵢ )

目标函数对每个 Pᵢ 是凹的（log），约束是线性的，用拉格朗日乘子法（KKT 条件，Karush–Kuhn–Tucker Conditions）求驻点，解呈闭式：

✅ 注水定理

最优功率分配为 Pᵢ = (ν − Nᵢ)⁺（x⁺ = max(x, 0)），其中水位 ν 由 Σᵢ (ν − Nᵢ)⁺ = P 唯一确定。代入得容量 C = Σ ½log₂(ν/Nᵢ)（只对 Pᵢ > 0 的信道求和）。

💡 关键一跃：为什么叫"注水"

注水（Water-filling）：把每条子信道看成一个深度为 Nᵢ 的容器（噪声越深容器越深），总功率 P 像水一样倒进去。水面永远齐平在高度 ν：容器 i 里的水（功率）深度 = ν − Nᵢ。噪声比水位还深的容器，一滴水都进不去——它被完全放弃。好信道多喝，差信道不喝，这就是最优。

例 A（三条全用）：N = (1, 2, 3)，总功率 P = 6

  • 第 1 步：假设三条都分到功率，则 ν − Nᵢ 全为正，求和得 Σ(ν−Nᵢ) = 3ν − (1+2+3) = 6 ⟹ ν = (6+6)/3 = 4；
  • 第 2 步：检验假设：ν = 4 > 3 = max Nᵢ ✓，每条噪声都低于水位，假设成立；
  • 第 3 步：P = (4−1, 4−2, 4−3) = (3, 2, 1)，合计 3+2+1 = 6 ✓ 功率用尽；
  • 第 4 步：容量 C = ½[log₂(1+3/1) + log₂(1+2/2) + log₂(1+1/3)] = ½[log₂4 + log₂2 + log₂(4/3)] = ½[2 + 1 + 0.4150] ≈ 1.71 比特（log₂(4/3) = 0.4150）。

例 B（有一条被淹）：N = (1, 2, 8)，总功率 P = 5

  • 第 1 步：先假设三条全用，ν = (P + ΣNᵢ)/3 = (5+11)/3 ≈ 5.33；
  • 第 2 步：检验：5.33 < 8 = N₃ ✗——水位没不过第三条信道的噪声，它会分到负功率，假设不成立，弃用信道三；
  • 第 3 步：只对前两条重算水位：ν = (5+1+2)/2 = 4，检验 4 > 2 = 剩余最大噪声 ✓；
  • 第 4 步：P = (4−1, 4−2, 0) = (3, 2, 0)；
  • 第 5 步：C = ½[log₂(1+3/1) + log₂(1+2/2)] = ½[log₂4 + log₂2] = ½(2+1) = 1.5 比特。
⚠️ 常见误区

"差信道噪声大，应该多分功率补偿它"——与最优解正好相反。log 的边际收益递减：把一单位功率投进浅噪声信道，换得的 ½log(1+Pᵢ/Nᵢ) 增量更大；深噪声信道投入回报太低，KKT 干脆判它零功率。最优策略是锦上添花，不是雪中送炭。工程对应：OFDM/DSL 系统会干脆关掉被干扰毁掉的子载波。

9.4带宽和功率怎么换算：带限信道与 −1.59 dB 香农极限

上一节把多信道的功率分配讲清了，现在回到连续时间把总账算出来：9.1 节说带宽 W 的信道每秒有 2W 个自由度，9.2 节说每个自由度容量 ½log(1+SNR)——两者相乘就是带限信道的容量。剩下唯一的问题：每个自由度上的信噪比是多少？

带限信道容量公式

设白噪声的双边功率谱密度（Power Spectral Density）为 N₀/2。带宽 W 内积出的噪声总功率 N = N₀·W（正负两个半边各贡献 N₀W/2）。信号总功率 P 摊到每秒 2W 个自由度上，等价于每个自由度的信噪比 P/(N₀W)。代入 2W × ½log(1+SNR)：

✅ 带限 AWGN 信道容量（香农公式）
C = W · log₂( 1 + PN₀W )　比特/秒

例 2：电话线的理论天花板

老式电话线：带宽 W = 3000 Hz，线路信噪比（Signal-to-Noise Ratio，SNR）30 dB，即 P/(N₀W) = 10³ = 1000。逐步算：

  • 第 1 步：1 + SNR = 1 + 1000 = 1001；
  • 第 2 步：log₂(1001) = 9.967；
  • 第 3 步：C = 3000 × 9.967 ≈ 29 900 ≈ 29.9 kbps。

这就是传统电话线信道的理论上限量级——上世纪 56k 调制解调器能逼近这个量级（实际利用了电话网数字段的技巧），靠的正是把 SNR 用到了极限。想再快，只能加带宽或加功率，而这两者怎么换算，就是下一个话题。

带宽 ↔ 功率：一场不对等的交换

公式里 W 出现在两个位置：线性地乘在外面（自由度变多），也藏在 SNR 里做分母（噪声功率 N₀W 随带宽线性变大）。所以加带宽不是免费的：自由度多了，但每个自由度更差了。固定 P，让 W 增大：log 增长越来越慢，最终饱和。用近似 log₂(1+x) ≈ x/ln2（x 小时）：

W·log₂( 1 + PN₀W ) ≈ W · PN₀W·ln 2 = PN₀·ln 2　（W → ∞ 的极限）

无限带宽也买不来无限容量，饱和值是 P/(N₀·ln2)。

香农极限：每比特能量的地板

设码率为 R，则每比特消耗的能量 Eb（Energy per Bit）= P/R。可靠传输要求 R ≤ C ≤ P/(N₀·ln2)，于是

EbN₀ = P/N₀R ≥ P/N₀C ≥ ln 2 = 0.693

换算成分贝：10·log₁₀(0.693) = −1.59 dB。这就是香农极限（Shannon Limit）：任何编码方案，想可靠传输，每比特能量与噪声谱密度之比都不能低于 ln2；注意它是负的——只要带宽足够，在信噪比低于 0 dB 的环境里照样可以可靠通信。深空通信、LDPC、Turbo 码几十年的工程史，就是在逼近这条 −1.59 dB 的地板。

💡 关键一跃

带宽和功率是两种可以互换的货币，但汇率悬殊：功率换容量是对数汇率（9.2 节），带宽换容量先是接近线性、然后饱和。工程设计的自由度全在这场兑换里——而 −1.59 dB 是无论怎么兑换都跌破不了的底价。

⚠️ 常见误区 + 本章留账

"带宽趋于无穷，容量也趋于无穷"——错，饱和到 P/(N₀·ln2)，因为噪声功率随带宽同步增长。留账：本章把"信道这头"解决了——给定信道能传多少比特。但信源那头还没解决：一个连续信源（语音、图像）最少要压到多少比特？这是第 10 章率失真理论的问题。

解决问题给物理信道贴上精确的价格标签：功率和噪声给定，速率上限钉死。

注水原理（Water-filling）
点击翻面 →

概念卡 6
香农极限 −1.59 dB（Shannon Limit）
点击翻面 →
定义可靠传输要求 Eb/N₀ ≥ ln2 = 0.693，即 −1.59 dB；由 W→∞ 时 C → P/(N₀·ln2) 推出。
解决问题回答"传一比特最少花多少能量"——通信的能量地板。

误区惊讶于它是负 dB——带宽足够时，信噪比低于 0 dB 也能可靠通信，这正是深空通信的现实。

📝分层习题

L1 概念辨析判断对错："既然功率受限，输入分布取 [−√P, √P] 上的均匀分布最自然，它就能达到容量。"说明理由。
提示

达到容量要求 h(Y) 最大——回忆：固定方差下什么分布的微分熵最大？再检查这个均匀分布的方差是不是真的用满了功率预算 P。

完整解答
错，且错在两处。①容量在 X ~ N(0, P) 时达到：Var(Y) = Var(X)+N 被功率约束钉住后，固定方差下高斯分布的微分熵最大，任何非高斯输入的 h(Y) 都严格更小，所以均匀输入严格次优。②[−√P, √P] 上均匀分布的方差只有 (2√P)²/12 = P/3，连功率预算都没用满。即使改用 [−√(3P), √(3P)] 把方差凑到 P，仍因①而达不到容量。"最自然"不等于"最优"。
L1 概念辨析判断对错："发射功率翻倍，信道容量也翻倍。"说明理由。
提示

写出 C 作为 P 的函数，看看它的形状；算一算功率从 P 翻倍到 2P 时容量增量是多少，再和原容量比。

完整解答
错。C = ½log(1+P/N) 对 P 是对数关系，不是线性。功率 P → 2P 的容量增量 Δ = ½log((1+2P/N)/(1+P/N)) < C(P)；P≫N 时 Δ ≈ ½log₂2 = 0.5 比特，而原容量可能远大于它。例：P/N = 15 时 C = 2 比特；功率翻倍到 30，C = ½log₂31 ≈ 2.48 比特，只多了 0.48 比特（24%），远非翻倍。功率换容量是越换越亏的对数汇率。
L2 手算推导AWGN 信道，分别计算 P/N = 15 与 P/N = 255 时的容量（比特/次），写全步骤，并评论两个数字的关系。
提示

代公式 C = ½log₂(1+P/N)；这两组数字都被设计过——1+P/N 恰好是 2 的幂。

完整解答

P/N = 15：1+P/N = 16；log₂(16) = 4；C = ½×4 = 2 比特/次。

P/N = 255：1+P/N = 256；log₂(256) = 8；C = ½×8 = 4 比特/次。

评论：信噪比从 15 提到 255（放大 17 倍），容量只从 2 涨到 4（翻倍）。再次印证对数关系——想靠堆功率线性提升容量是死路，这正是 9.4 节"带宽↔功率折中"如此重要的原因。

L2 手算推导并行高斯信道，噪声 N = (1, 2, 3)，总功率 P = 6。求最优功率分配与总容量。追问：若总功率改为 P = 2，结果如何？
提示

先假设三条信道全用，解 ν = (P+ΣNᵢ)/3，再检验 ν 是否大过每条噪声；不成立就把最深的信道扔掉重算。追问里注意：水位可能淹没浅信道——P 变小时，原来能分到功率的信道也可能被淹。

完整解答

P = 6：假设全用，ν = (6+1+2+3)/3 = 12/3 = 4；检验 4 > 3 = max Nᵢ ✓。P = (4−1, 4−2, 4−3) = (3, 2, 1)，合计 6 ✓。C = ½[log₂4 + log₂2 + log₂(4/3)] = ½[2 + 1 + 0.4150] ≈ 1.71 比特。

追问 P = 2：试全用，ν = (2+6)/3 = 8/3 ≈ 2.67 < 3 ⟹ 第三信道被淹，弃用。重算：ν = (2+1+2)/2 = 2.5，检验 2.5 > 2 ✓。P = (2.5−1, 2.5−2, 0) = (1.5, 0.5, 0)。C = ½[log₂(1+1.5) + log₂(1+0.25)] = ½[log₂2.5 + log₂1.25] = ½[1.3219 + 0.3219] = 0.82 比特。功率缩到 1/3，容量从 1.71 掉到 0.82——最差的信道最先被牺牲。

L3 建模应用DSL 场景：一对铜线切成 3 个频段，测得各频段噪声功率 N = (1, 2, 8)，调制解调器总功率预算为 5。要求：①把场景映射为并行高斯信道模型；②画出注水示意图；③算出最优功率分配与总容量；④解释为什么最差的信道被完全放弃，以及这在工程上对应什么操作。
提示

每个频段就是一条独立 AWGN 子信道，约束是 ΣPᵢ ≤ 5。注水时先试"三条全用"，检验水位与最大噪声 8 的关系。

完整解答

① 模型：3 条独立并行 AWGN 信道，Yᵢ = Xᵢ + Zᵢ，Zᵢ ~ N(0, Nᵢ)，N = (1, 2, 8)，总功率约束 P₁+P₂+P₃ ≤ 5。目标：max Σ ½log₂(1+Pᵢ/Nᵢ)。

重算 ν = 4"] C --> D["信道一 噪声 1

注水过程：先试全用 → 发现水位没不过最深的噪声 → 弃用后重算，水位落定在 4。

③ 计算：试全用 ν = (5+11)/3 ≈ 5.33 < 8 ⟹ 弃信道三；重算 ν = (5+1+2)/2 = 4 > 2 ✓。P = (4−1, 4−2, 0) = (3, 2, 0)。C = ½[log₂4 + log₂2] = ½(2+1) = 1.5 比特（每次联合使用）。

④ 解释：信道三噪声 8 超过水位 4——往里面投任何一小份功率，边际容量增量都低于把同一份功率投给信道一（log 边际收益递减 + 分母 N₃ 太大），KKT 条件于是判它零功率。工程对应：DSL/OFDM 系统会直接关掉被串扰或射频干扰（如 AM 电台）毁掉的子载波，把全部功率集中给干净频段——这正是现代调制解调器"比特加载"算法做的事。

三条并行高斯信道，噪声 N = (1, 2, 8)，总功率 P = 5。最优功率分配是：

  • B. 噪声最大的信道三分得最多功率，补偿它的劣势
