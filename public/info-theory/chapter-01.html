1.1信息论关心的两件事：压缩的极限与传输的极限

1948 年以前，"压缩"和"通信"是两类手艺：电报员知道常见字母用短码（摩尔斯电码里 E 是一个点），电话工程师知道线路越吵越要放慢语速。但没有人回答过两个极限问题：

  • 压缩问题：一个信源产生的数据，最少能用多少比特无差错地表示？
  • 传输问题：一条有噪声的信道，最多能以多快的速率可靠地传信息？

香农（Claude Shannon）1948 年的论文《通信的数学理论》（A Mathematical Theory of Communication）把两个问题都变成了有精确答案的数学问题。答案是惊人的对称：压缩的极限是熵 H，传输的极限是信道容量 C，而 C 也由一个熵式的量（互信息的最大值）给出。整本书就是这两个答案的展开。

例 1：压缩有没有极限？一个有四个符号的信源

某信源每步独立地发出 A、B、C、D 之一，概率分别为 p = (1/2, 1/4, 1/8, 1/8)。

方案一：定长码。4 个符号各配 2 比特：A→00，B→01，C→10，D→11。每个符号恒用 2 比特，平均码长 L = 2 比特。

方案二：短码给常客。学摩尔斯电码的思路：A→0，B→10，C→110，D→111。注意任何码字都不是另一个码字的前缀（前缀码，Prefix Code），所以接收方能无歧义地切分码流。算平均码长，一步不落：

L = p(A)·1 + p(B)·2 + p(C)·3 + p(D)·3
= 12×1 + 14×2 + 18×3 + 18×3 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 比特

同样的数据，平均码长从 2 降到 1.75，省了 12.5%。问题是：还能更低吗？香农说：不能低于一个只由分布决定的数——这个信源的熵 H = 1.75 比特（第 2 章会算出这个数，第 5 章证明它是最优下界）。上面这个码恰好达到了极限，这不是巧合，学完第 5 章你会自己造出这种码。

例 2：噪声信道上，重复是不是好办法？

一个二元对称信道（Binary Symmetric Channel, BSC）：发 0 或 1，信道以概率 p = 0.1 翻转它。

图 1.1 二元对称信道：每次使用以 10% 的概率出错。裸传的错误率是 0.1，不可接受。

朴素办法：重复三遍取多数。每个比特发 3 次，接收端按少数服从多数判决。出错当且仅当 3 次里翻错 ≥ 2 次：

Pe = C(3,2)·p²·(1−p) + p³ = 3×0.01×0.9 + 0.001 = 0.027 + 0.001 = 0.028

错误率从 0.1 降到 0.028，代价是速率变成原来的 1/3。想把错误率压到任意小，就得重复任意多次——速率趋向 0。这就是"降速换可靠"的老手艺。

香农的断言：这条信道的容量是 C = 1 − H(0.1) 比特/次，其中 H(0.1) 是二元熵函数（第 2 章定义，1.2 节末尾我们先把数算出来）：

H(0.1) = −0.1·log₂0.1 − 0.9·log₂0.9 = 0.1×3.3219 + 0.9×0.1520 = 0.3322 + 0.1368 = 0.469 比特
C = 1 − 0.469 = 0.531 比特/次

含义：存在编码方案，以接近 0.531 的正速率传输且错误率任意小——比"速率 1/3 才换到 0.028"好得不可同日而语；而任何超过 0.531 的速率都注定有不可消除的错误。这就是信道编码定理（Ch7）。

💡 关键一跃

压缩和传输看似两个工程问题，香农把它们统一成同一个数学对象的两个侧面：信息的量由概率分布决定，极限由熵给出。剩下的事就是把"熵"这个数定义清楚、算明白。

⚠️ 常见误区

"信源编码就是查表替换、信道编码就是加冗余重发"——错在把极限问题当成了技巧问题。信息论回答的不是"怎么设计一个好码"，而是"最好的码能好到什么程度"。设计是 Ch5、Ch7 的事，极限本身才是本章要预告的主角。

1.2香农的回答：信息可以度量，单位是比特

上一节把极限都归到了一个叫"熵"的数上。但在定义熵之前，先要回答更根本的问题：一条消息携带多少信息，这件事本身怎么度量？

香农的出发点是一条朴素的观察：收到"明天太阳升起"没有信息量，收到"明天日食"信息量很大——信息量是意外程度。意外程度应由概率决定，且要满足三条常识：

  1. 单调性：概率越小，信息量越大；概率 1（必然事件）信息量为 0；
  2. 可加性：两个独立消息的信息量等于各自信息量之和（联合概率相乘，信息量应相加）；
  3. 连续性：概率的微小变化只引起信息量的微小变化。

能同时满足这三条的函数（在相差一个正常数因子的意义下）只有一个：对数的负值。于是单个消息的信息量——也叫自信息（Self-Information）——定义为：

h(x) = −log₂ p(x)　　单位：比特（bit）

底数取 2，单位就是比特；底数取 e，单位叫奈特（nat），只相差一个换算系数 log₂e ≈ 1.443。本讲义一律用比特。

例 3：手算几个自信息，建立手感

消息概率 p(x)计算h(x)
公平硬币掷出正面1/2−log₂(1/2)1 比特
均匀骰子掷出 61/6−log₂(1/6)≈ 2.585 比特
8 张牌等概率抽到指定一张1/8−log₂(1/8)3 比特
彩票中头奖1/10⁷−log₂(1/10⁷) = 7·log₂10≈ 23.25 比特
明天下雨（当地雨季）0.9−log₂0.9≈ 0.152 比特

注意最后一行：概率 0.9 的事件只有 0.152 比特——确定的事不携带信息。还要注意可加性的体现：掷两次公平硬币（联合概率 1/4）的信息量 = 2 比特 = 1 + 1，正是两个独立事件之和。

💡 关键一跃

自信息是一条消息的信息量；而我们真正关心的是一个信源平均每条消息给多少信息。答案自然是对 h(x) 按概率取期望：H(X) = Σ p(x)·h(x) = −Σ p(x) log₂ p(x)。这就是熵——第 2 章的全部起点。1.1 节例 1 里那个 1.75，就是这么算出来的（第 2 章会一步步复算）。

⚠️ 常见误区

"比特"在这里是信息量的单位，不是"一个 0 或 1 的存储位"。一条消息信息量 1.75 比特，意思是无差错表示它的成本下限是平均 1.75 个存储位；3 比特的信息量完全可能要用 4 个物理位来存（如果码设计得差）。把"信息量"与"存储位数"分开，是理解两大定理的前提。

1.3全书三个主角：熵、相对熵、互信息

上一节从一条消息走到了自信息。但信源不是一条消息，而是无穷多条消息背后的分布；我们还关心两个分布差多远、两个变量共享多少信息。全书 17 章里反复出场的只有三个度量，现在先给它们一人一句画像，精确定义留给第 2 章。

度量记号一句话回答的问题首次登场
熵（Entropy）H(X)描述 X 平均需要多少比特？（不确定性的量）Ch2，压缩极限 Ch5
相对熵（Relative Entropy）D(p‖q)以为分布是 q、实际是 p，平均每条消息多付多少比特？Ch2，统计推断 Ch11
互信息（Mutual Information）I(X;Y)知道 Y 后，X 的不确定性减少多少比特？Ch2，信道容量 Ch7

三者不是并列的三个定义，而是一条生成链：熵是最基本的量；相对熵是"两个分布的熵之差"的适当推广；互信息是熵与条件熵的差。第 2 章会给出精确关系：I(X;Y) = H(X) − H(X|Y)，而 H(X|Y)（条件熵）又是联合熵与熵的差。全书的不等式（D ≥ 0、I ≥ 0、条件化减熵）都是这一条链上的推论。

💡 关键一跃

记住这张"家族谱"就够了：D(p‖q) 是万用扳手——互信息本身就是 p(x,y) 与 p(x)p(y) 之间的相对熵；熵是 X 与常数分布的某种相对熵。第 2 章结尾你会发现，几乎所有信息论不等式都由一条"相对熵非负"推出。

⚠️ 常见误区

"相对熵是两个分布的距离"——它不是距离：一般 D(p‖q) ≠ D(q‖p)，也不满足三角不等式。它的正确读法是用错分布的代价（编码、假设检验里的代价都精确等于它），第 2 章会用数值例子让你看到这种不对称。

概念卡 1
自信息（Self-Information）
点击翻面 →
定义单条消息的信息量：h(x) = −log₂ p(x)，单位比特。
解决问题把"信息量"从直觉变成可计算的数；没有它，熵无从定义。
直觉意外程度计：越不可能的消息，发生时带来的信息越多。
误区以为概率大信息量大——恰恰相反，p=1 时 h=0。
何时用Ch2 定义熵的原材料；Ch3 典型集里"每条序列约 2^{−nH}"的依据。
概念卡 2
熵（Entropy，预告）
点击翻面 →
定义信源自信息的期望：H(X) = −Σ p(x) log₂ p(x)。
解决问题度量一个分布（而非一条消息）的平均不确定性。
直觉描述这个信源平均每符号最少花多少比特。
误区与热力学熵混为一谈——同名同源，但信息论里它是纯概率量，无物理单位。
何时用全书第一主角：Ch5 压缩极限、Ch7 容量、Ch10 率失真全是它。
概念卡 3
相对熵（Relative Entropy，预告）
点击翻面 →
定义D(p‖q) = Σ p(x) log₂(p(x)/q(x))，又称 KL 散度。
解决问题量化"真实分布是 p 却按 q 办事"的平均代价。
直觉拿错的地图赶路的平均冤枉路。
误区当作距离——它不对称、无三角不等式，只是非负且 D=0 ⟺ p=q。
何时用Ch2 推一切不等式；Ch11 假设检验的错误指数；Ch12 最大熵。
概念卡 4
互信息（Mutual Information，预告）
点击翻面 →
定义I(X;Y) = H(X) − H(X|Y) = D(p(x,y) ‖ p(x)p(y))。
解决问题度量两个变量共享多少信息（比相关系数更一般的依赖度量）。
直觉知道 Y 后，关于 X 还需要问多少个是非题。
误区以为只度量线性相关——它捕捉一切统计依赖，I=0 ⟺ 独立。
何时用Ch7 信道容量 = 输入分布上 I 的最大值；Ch10、Ch15 处处出现。
概念卡 5
信源编码定理（Source Coding Theorem）
点击翻面 →
定义无差错压缩 i.i.d. 信源，平均每符号所需比特数 ≥ H，且存在码任意逼近 H。
解决问题回答"压缩的极限在哪里"：就是熵。
直觉长序列里只有约 2^{nH} 条典型序列，只需给它们编号。
误区以为单符号编码就能到 H——需要把符号串成块联合编码。
何时用Ch3 AEP 给出概率基础，Ch5 给出可达的构造（香农码、Huffman 码）。
概念卡 6
信道容量（Channel Capacity）
点击翻面 →
定义C = maxp(x) I(X;Y)，信道每次使用最多能可靠传输的比特数。
解决问题回答"传输的极限在哪里"：R < C 则可达任意小错误率，R > C 则不可能。
直觉噪声吃掉的信息是 H(Y|X)，剩下能穿过的最多是 max I。
误区以为靠重复发送就能逼近——重复使速率归零；靠长随机码逼近。
何时用Ch7 证明与计算；Ch9 高斯信道 C = ½log(1+SNR)；Ch15 网络推广。

📝分层习题

L1 概念辨析判断对错：一条消息的概率越大，它发生时携带的信息量越大。说明理由。
提示

回到 h(x) = −log₂ p(x) 的单调性，以及"必然事件"应该给多少信息量这条常识。

完整解答
错。h(x) = −log₂ p(x) 是 p 的严格递减函数：概率越大，信息量越小；必然事件（p=1）信息量为 0。直觉上"信息 = 意外程度"，早已被预料到的事不提供新信息。把方向记反会导致后面所有熵的直觉全部颠倒。
L1 概念辨析判断对错：信道编码定理表明：只要把每个比特重复足够多次，就能以任意小的错误率传任意速率的信息。
提示

重复 k 次之后，速率变成原来的多少？定理里"任意小错误率"对速率 R 提的条件是什么？

完整解答
错，两处都错。其一，重复 k 次速率降为 R/k，要把错误率压到任意小需要 k→∞，速率随之归零——例 2 里重复 3 次只把 0.1 降到 0.028，速率已损失 2/3。其二，定理的方向是：速率 R < C 时存在编码使错误率任意小（且 R 不为 0）；R > C 时任何方案都办不到。正速率 + 任意小错误，靠长分组编码而非简单重复。
L2 手算推导信源符号 A、B、C、D 的概率为 (1/2, 1/4, 1/8, 1/8)。给定前缀码 A→0、B→10、C→110、D→111，手算平均码长；再算每个符号的自信息 h(x)，比较二者。
提示

平均码长 = Σ p(x)·码长(x)；自信息 = −log₂ p(x)。把两组数排成一行对着看。

完整解答

平均码长：L = (1/2)×1 + (1/4)×2 + (1/8)×3 + (1/8)×3 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 比特。

自信息：h(A) = −log₂(1/2) = 1；h(B) = −log₂(1/4) = 2；h(C) = h(D) = −log₂(1/8) = 3。

对照：每个符号的码长恰好等于它的自信息（1、2、3、3）！于是 L = Σp·h = H = 1.75。这不是巧合——当所有概率都是 2 的负整数幂时，香农码达到逐符号最优；一般分布做不到逐符号相等，这正是第 5 章要处理的缝隙（平均意义下仍能逼近 H）。

L2 手算推导二元对称信道 p = 0.1。手算二元熵 H(0.1) 与容量 C = 1 − H(0.1)（保留三位小数），并算重复三次码的错误率与速率，说明它与容量的差距。
提示

log₂0.1 = −3.3219，log₂0.9 = −0.1520；重复码错误 = 3 次中错 ≥2 次的概率。

完整解答

H(0.1) = −0.1×(−3.3219) − 0.9×(−0.1520) = 0.33219 + 0.13680 = 0.46899 ≈ 0.469 比特。

C = 1 − 0.469 = 0.531 比特/次。

重复三次：Pe = 3×0.1²×0.9 + 0.1³ = 0.027 + 0.001 = 0.028，速率 = 1/3 ≈ 0.333 比特/次。

差距：重复码用 0.333 的速率只换到 0.028 的错误率；而定理保证存在速率 0.5 的编码错误率任意小。再降错误率，重复码速率→0，编码方案速率不动——这就是"手艺"与"定理"的距离。

L3 建模应用一个气象站每 10 秒上报一次天气状态：晴(1/2)、阴(1/4)、雨(1/8)、雪(1/8)，各次上报近似独立；每天共 8640 条。数据经一条 BSC(p=0.1) 信道回传。问：(a) 用定长码每天需传多少比特？(b) 用 1.1 节的前缀码每天需传多少比特？(c) 该信道每天至少要被使用多少次才能可靠传完 (b) 的比特数？
提示

(a) 4 个状态定长需几位？(b) 平均码长已算过。(c) 信道每次使用最多可靠传 C = 0.531 比特。

完整解答

(a) 定长 2 比特/条：8640×2 = 17,280 比特/天。

(b) 平均 1.75 比特/条：8640×1.75 = 15,120 比特/天，省 12.5%。

(c) 信道每次使用最多传 C = 0.531 比特，故至少需要 15120/0.531 ≈ 28,475 次信道使用。注意一个反直觉的结论：信道使用次数反而比数据比特数多——可靠传输本身要付出近一倍的冗余，这就是噪声的价格；而压缩省下的 2160 比特是信源分布不均匀白送的。

自测 1
一条概率为 1/16 的消息，其自信息为多少比特？
  • A. 2 比特
  • B. 3 比特
  • C. 4 比特
  • D. 16 比特
选 C。h = −log₂(1/16) = log₂16 = 4。A、B 是把 16 错当成 2² 或 2³；D 把概率的倒数直接当成了信息量——信息量取的是对数。
自测 2
信源编码定理声明：无差错压缩 i.i.d. 信源的平均码长——
  • A. 可以小于熵 H，只要码表设计得足够巧
  • B. 不低于 H，且存在编码任意逼近 H
  • C. 等于符号个数的对数 log₂|𝒳|
  • D. 只取决于最长的码字
选 B。下界是熵、可达性逼近熵，两条缺一不可。A 错：低于 H 必有差错（第 5 章证明）；C 错：log₂|𝒳| 是均匀分布的熵，是 H 的最大值而非一般值；D 错：平均码长由全部分布决定。
自测 3
BSC(p=0.1) 的信道容量约为 0.531 比特/次，其含义是：
  • A. 每次使用信道恰好能传 0.531 个比特
  • B. 速率超过 0.531 也能可靠传输，只是码更长
  • C. 重复 3 次取多数判决即可达到这个速率
  • D. 存在速率任意接近 0.531 且错误率任意小的编码；超过则不可能
选 D。容量是渐近极限：长分组码可逼近。A 错在"恰好"——0.531 是上确界不是每次的确定值；B 错：R > C 不可可靠；C 错：重复码速率 1/3 且错误率只能降到 0.028，离容量又慢又不准。
自测 4
"信息量的比特"与"存储位（物理 bit）"的区别是：
  • A. 前者是分布决定的成本下限，后者是具体编码实际使用的位数，后者可以大于前者
  • B. 两者永远相等
  • C. 前者只能取整数值
  • D. 前者只用于信道，后者只用于压缩
选 A。例 1 中熵 1.75 比特（下限），定长码用 2 个物理位（实际）。B 错：只有最优码渐近相等；C 错：1.75、0.469 都是合法的比特数；D 错：压缩与信道都用同一个信息量单位。
自测 5
关于相对熵 D(p‖q) 的预告性说法，正确的是：
  • A. 它是 p 与 q 之间的距离，满足对称性与三角不等式
  • B. 它度量"真实为 p 却按 q 编码/决策"的平均代价，一般 D(p‖q) ≠ D(q‖p)
  • C. 它恒等于 H(p) − H(q)
  • D. 它可以取负值
选 B。A 错：相对熵不对称、无三角不等式，不是距离；C 错：H(p)−H(q) 可以任意为负，与 D ≥ 0 矛盾；D 错：第 2 章将证明 D(p‖q) ≥ 0，等号当且仅当 p = q。
