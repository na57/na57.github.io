6.1赛马问题：财富为什么是个乘积过程？

第 5 章把熵兑现成了压缩码：分布 p 越不均匀，平均码长越能贴近 H。本章换一张桌子——赌场。你会发现，赌桌上的最优策略和压缩码表出自同一支笔。

赛马模型（Horse Race）：一场赌局无限次重复，每场结果 X ∈ {1, 2, …, m} 独立地按分布 p 产生。赌客每场把全部财产按比例 b = (b₁, b₂, …, bₘ) 分押各匹马，其中 bᵢ ≥ 0 且 Σbᵢ = 1；若 i 号马赢，押在它身上的钱变成 oᵢ 倍（赔率，Odds），其余全输光。

设初始财富 S₀ = 1。第 i 场结果 Xᵢ 揭晓后，财富变为原来的 b(Xᵢ)·o(Xᵢ) 倍——只有押中那一份钱活了回来。n 场之后的总财富是：

Sn = ∏i=1n b(Xi)·o(Xi)

注意这个结构的麻烦之处：财富是乘积，不是求和。一场失手不会只减掉一点，而是按比例缩掉全部身家。处理乘积过程的标准武器是取对数——乘积变求和：

1n log₂ Sn = 1n Σi=1n log₂ b(Xi)o(Xi) ⟶ E[log₂ b(X)o(X)]　（大数定律）

右边这个期望就是本节的主角——双倍率（Doubling Rate）：

W(b, p) = Σi=1m pi log₂(bioi)

含义：长期看财富按指数速率增长，Sₙ ≈ 2nW。W 每大 1 比特，财富每场翻一倍；W = 0 则原地踏步；W < 0 则指数衰减走向破产。"双倍率"之名由此而来。

手算例 A（上）：两种看似合理的策略，为什么都不行？

掷币赛（本章主例之一，反复使用）：m = 2，真实分布 p = (3/4, 1/4)——1 号"马"是热门，胜率 3/4；赔率 o = (2, 2)，押中哪匹都翻 2 倍。

策略一：平均分押 b = (1/2, 1/2)。"分散投资，总不会错吧？"逐场算倍率：无论哪匹马赢，财富倍率都是 (1/2)×2 = 1。于是：

W = 34log₂(12×2) + 14log₂(12×2) = 34×0 + 14×0 = 0

财富原地踏步。注意这是几何平均的判决：虽然每场期望收益是 (3/4)(1) + (1/4)(1) = 1 倍（算术意义不亏），但乘积过程看的不是算术平均而是对数平均——0.5 倍的损失需要 2 倍的盈利才能补回，平均主义在这里赚不到一分钱。

策略二：全押热门 b = (1, 0)。"既然 1 号胜率 3/4，押它期望最高！"逐场看：1 号赢，财富 ×2；2 号赢，财富 ×0。双倍率：

W = 34log₂(1×2) + 14log₂(0×2) = 34×1 + 14×(−∞) = −∞

W = −∞ 不是修辞：只要 2 号马赢一次（几乎必然会发生，每场概率 1/4），财富直接归零，且永世不得翻身——乘积过程里 0 是吸收壁。期望财富再高也救不了你，因为那条"发财世界线"的概率以 (3/4)ⁿ 指数衰减到 0。

两个极端都死了：一个不赚钱，一个必破产。中间的 b 显然值得优化——这就是下一节的事。

💡 关键一跃

乘积过程的"平均"不是算术平均而是几何平均，几何平均的数学化身就是 E log。所以赌局问题的天然目标函数不是"期望财富最大"，而是"期望对数财富最大"——双倍率 W 因此登场。

⚠️ 常见误区

"期望收益为正的游戏就值得全押"——错。全押热门的期望财富 E[Sₙ] = (3/4×2)ⁿ = 1.5ⁿ 确实指数爆炸，但它由概率越来越小的极端路径贡献；以概率 1 你会破产。乘积过程里，几乎必然发生的事由 E log 决定，不是由 E 决定。

6.2Kelly 准则：按比例下注为什么最优？

上一节留下一个优化问题：在约束 bᵢ ≥ 0、Σbᵢ = 1 下，选 b 使 W(b,p) 最大。这个问题有出人意料的干净答案，而且证明只用第 2 章的一件旧工具。

把 W 拆开：

W(b, p) = Σi pi log₂ bi + Σi pi log₂ oi

第二项只含赔率，与 b 无关，是常数。要最大化的只有第一项 Σ pᵢ log₂ bᵢ。回忆第 2 章：相对熵非负（D(p‖q) ≥ 0，等号当且仅当 p = q），也就是 Σ pᵢ log₂(pᵢ/bᵢ) ≥ 0，移项即 Σ pᵢ log₂ bᵢ ≤ Σ pᵢ log₂ pᵢ，等号当且仅当 b = p。于是：

✅ Kelly 准则（Kelly Criterion）/ 按比例下注（Proportional Betting）

最优投注比例就是真实分布本身：b* = p，即 b*ᵢ = pᵢ。每匹马分到的钱恰好等于它赢的概率。

而且偏离最优的代价可以精确计价：W(b*,p) − W(b,p) = D(p‖b)——你亏掉的增长率恰好是你的投注分布与真实分布之间的相对熵。

证明只差一步代入：W(b*,p) − W(b,p) = Σ pᵢ log₂(pᵢoᵢ) − Σ pᵢ log₂(bᵢoᵢ) = Σ pᵢ log₂(pᵢ/bᵢ) = D(p‖b) ≥ 0。一行证完——这就是"旧工具换新场景"的教科书示范。

手算例 A（中）：Kelly 策略到底赚多少？

掷币赛 p = (3/4, 1/4)、o = (2,2)，Kelly 策略 b* = (3/4, 1/4)：

W* = 34log₂(34×2) + 14log₂(14×2) = 34log₂32 + 14log₂12
= 0.75×0.5850 + 0.25×(−1) = 0.4387 − 0.2500 = 0.1887 ≈ 0.19 比特/场

财富 Sₙ ≈ 20.19n ≈ 1.14ⁿ：平均每场涨 14%，且以概率 1 永不破产（每匹马都押了正比例，log 不会碰到 −∞）。三种策略摆在一起：

策略 bW（比特/场）财富渐近行为命运
平均 (1/2, 1/2)0Sₙ ≈ 1原地踏步
全押热门 (1, 0)−∞以概率 1 归零迟早破产
Kelly (3/4, 1/4)+0.1887Sₙ ≈ 1.14ⁿ指数增长

验证一下偏离代价：平均分押时 D(p‖b) = (3/4)log₂(3/2) + (1/4)log₂(1/2) = 0.4387 − 0.2500 = 0.1887，恰好等于 W* − W = 0.1887 − 0 ✓。账完全对得上。

💡 关键一跃

Kelly 准则的本质是用对数给风险定价。log 函数在 0 处掉到 −∞，等于给"破产"判了无期徒刑——任何可能导致财富归零的押法都被自动排除；同时 log 增长放缓，逼你在热门与冷门之间保持分散。比例 b = p 正是这股"既贪婪又保命"的力量平衡出来的点。

⚠️ 常见误区

"Kelly 最大化期望财富"——错，它最大化的是对数财富的期望（即长期增长率），不是期望财富本身。真要最大化 E[Sₙ]，应该每场全押期望倍率最高的一匹马：本例中 E[Sₙ] = 1.5ⁿ，比 Kelly 的 1.14ⁿ 高得多——但那条策略以概率 1 破产。期望被低概率的极端路径绑架，而你的财富曲线只走一条路径。长期主义者选 E log，不选 E。

6.3公平赔率下的惊喜：增长率为什么等于 log m − H(p)？

上一节的最优策略 b* = p 对任意赔率成立。现在给赔率加一个没有庄家的限制，看看 W* 会露出什么真面目。

公平赔率（Fair Odds）：赔率满足 Σᵢ 1/oᵢ = 1，即庄家不抽水——把钱按 1/oᵢ 的比例分押可以保证不亏不赚。最强的一种公平是均匀公平赔率：oᵢ = m，无论哪匹马赢都翻 m 倍（相当于庄家按"每匹马等可能"开的盘）。此时 Kelly 最优值：

W** = Σi pi log₂(pi·m) = Σi pi log₂ m + Σi pi log₂ pi = log₂ m − H(p)
✅ 判定规则

均匀公平赔率下，最优双倍率 = log₂m − H(p)。熵直接变成了钱：赛果每多 1 比特不确定性，赌客每场少赚 1 比特增长率。

手算例 B：4 马赛，与 Ch1、Ch5 同一个分布

4 马赛 p = (1/2, 1/4, 1/8, 1/8)——正是第 1 章算过熵、第 5 章算过 Huffman 码的那个分布，H = 1.75 比特。庄家开均匀公平赔率 oᵢ = 4。Kelly 策略 b* = p，逐匹马算倍率与贡献：

马 ipᵢ = b*ᵢ中 i 的倍率 b*ᵢ·oᵢlog₂(倍率)贡献 pᵢ·log₂
1 号1/2211/2
2 号1/4100
3 号1/81/2−1−1/8
4 号1/81/2−1−1/8
W** = 12 − 18 − 18 = 0.25 比特/场　=　log₂4 − 1.75 ✓

财富每场几何增长 20.25 ≈ 1.19 倍。对照表格外一行：若分布均匀 p = (1/4,1/4,1/4,1/4)，H = log₂4 = 2，W** = 0——真正不可预测的赛果，谁都赚不到钱，公平游戏无利可图。

💡 关键一跃

压缩与赌博的对偶第一次显形：熵低 = 可压缩 = 可预测 = 可盈利。第 5 章里 H 是"平均能省多少码长"，本章里 log m − H 是"平均能赚多少增长率"——同一个 H，一本账的收支两面。分布越不均匀，压缩省得越多，赌局赢得越狠。

附：一般公平赔率的一致性检查。若 oᵢ = 1/pᵢ（按真实分布开的公平盘），Kelly 策略 b = p 下每场倍率 b(Xᵢ)o(Xᵢ) = pᵢ·(1/pᵢ) = 1——财富恒不变，W** = Σp log₂(oᵢpᵢ) = Σp log₂1 = 0。这与均匀公平公式不矛盾：均匀公平 oᵢ = m 相当于庄家按"均匀分布"开盘，当真实分布 p 不均匀时，等式 W** = Σp log₂(oᵢpᵢ) 给出 Σp log₂(mpᵢ) = log₂m − H(p) > 0；而当庄家的盘与真实分布完全一致（oᵢ = 1/pᵢ）时，利润恰好被抹平为 0。两类赔率设定别混淆：利润来自庄家对分布的误判。

⚠️ 常见误区

"公平赔率下赌客必输/必不赚"——只有庄家的盘与真实分布吻合时才不赚（W** = 0）。只要庄家按错误分布开盘（如均匀公平盘而真实分布偏斜），Kelly 赌客就能稳定抽水，抽水的速率 = 庄家分布与真实分布之间"差出来的熵"。赌场赚钱靠的正是反向的同一公式：赌客按均匀心理下注，真实分布给了赌场 D 的差价。

6.4边信息的价值：一条情报值多少比特？

到目前为止，赌客每场只凭分布 p 下注。如果开赛前有人递来一张与赛果相关的纸条 Y（"内部情报"：天气预报、马匹状态、神秘来电），它值多少钱？信息论给出了精确的牌价。

设定：每场赛果 X 与消息 Y 按联合分布 p(x,y) 产生，赌客在看到 Y 之后下注。此时最优策略是把 Kelly 准则用到条件分布上：给定 Y = y，按 b(x|y) = p(x|y) 下注，双倍率达到 Σ p(x,y) log₂(o(x)p(x|y))。与无情报时的最优值相减：

✅ 边信息的价值（Value of Side Information）

ΔW = Σ p(x,y) log₂ [p(x|y)/p(x)] = I(X;Y)

边信息带来的增长率提升恰好等于它与赛果之间的互信息。互信息就是情报的货币价值：1 比特互信息 = 每场多赚 1 比特增长率 = 财富增速翻倍。

手算例 A（下）：完全情报值多少？

掷币赛 p = (3/4, 1/4)、o = (2,2)，Y 完全预告每场结果（Y = X）。有情报时每场全押赢家：倍率恒为 1×2 = 2，故

Wwith = Σi pi log₂(1×2) = log₂2 = 1 比特/场　　财富 = 2ⁿ，每场稳定翻倍
ΔW = Wwith − W* = 1 − 0.1887 = 0.8113 比特/场

用定理验证：Y 完全预告时 H(X|Y) = 0，所以 I(X;Y) = H(X) = H(3/4)。手算二元熵：

H(34) = −34log₂34 − 14log₂14 = 0.75×0.4150 + 0.25×2 = 0.3113 + 0.5000 = 0.8113 ✓

ΔW = I(X;Y)，小数点后四位完全吻合。财富曲线从 1.14ⁿ 提到 2ⁿ——这条情报让增长率翻了 5 倍多。

⚠️ 常见误区

"情报越多越值钱"——只有与赛果相关的情报才值钱。若 Y 与 X 独立（比如纸条上写的是昨天的天气），I(X;Y) = 0，ΔW = 0，一文不值；哪怕情报内容本身很"惊人"。I 度量的是对这场赌局有用的信息量，不多不少。

6.5从赛马到股市：压缩和赌博为什么是同一个问题？

把"马"换成"股票"，赛马故事立刻变成金融故事：每场的结果 X 变成市场的每日状态，赔率向量变成各股票的相对收益，投注比例 b 变成资产组合权重。财富仍是乘积过程，目标仍是最大化 E log——这就是对数最优组合（Log-Optimal Portfolio）：固定比例、每期再平衡的组合，其长期增长率同样在 E log 下最优，Kelly 是它的离散原型。完整处理见 Cover & Thomas 第 16 章，本讲义在对应位置会再回到这个话题；此处只需记住：赛马里的每个结论，把名词换掉就是组合投资的结论。

💡 关键一跃

学会像信息论专家一样看世界：凡是"重复面对不确定结果、要按比例配置资源"的问题——下注、投资、缓存分配、AB 测试流量分配——先问它的对数期望长什么样。对数一取，熵和互信息就会自己走出来结账。

⚠️ 常见误区

"对偶只是类比"——不是类比，是同一个凸优化问题的两种解释。证据：两侧的误差代价都是 D，两侧的极限都由 H 封死，边信息价值 ΔW = I(X;Y) 与"知道 Y 能省的码长 = I(X;Y)"是同一条恒等式。把它当修辞会漏掉可计算的内容。

📝分层习题

L1 概念辨析判断对错：Kelly 准则最大化的是期望财富 E[Sₙ]。说明理由，并举一反例。
提示

回到乘积过程：长期行为由 E log 还是 E 决定？全押一匹马时两个目标各给什么建议？

完整解答
错。Kelly 最大化的是期望对数财富 E[log₂ Sₙ]，即双倍率 W，对应长期几乎必然实现的增长率。反例：掷币赛 p=(3/4,1/4)、o=(2,2)，最大化 E[Sₙ] 应全押热门，得 E[Sₙ] = 1.5ⁿ 指数爆炸；但 2 号马每场有 1/4 概率出现，n 场全胜概率 (3/4)ⁿ → 0，以概率 1 破产。期望被概率指数衰减的极端路径绑架，而实际只走一条路径——E log 才是路径意义的正确目标。
L1 概念辨析判断对错：在均匀公平赔率 oᵢ = m 下，赛果分布越均匀，赌客的最优增长率越高。
提示

W** = log₂m − H(p)。H 在什么时候取到最大值 log₂m？

完整解答
错，方向恰好相反。W** = log₂m − H(p)：分布越均匀 H 越大，增长率越低；当 p 完全均匀时 H = log₂m，W** = 0，无利可图。赌客的利润来自赛果的可预测性（熵亏 log₂m − H），不确定性本身是赌场的保护伞。直觉：越能预测越能赢，越混乱越只能陪跑。
L2 手算推导三马赛：p = (1/2, 1/4, 1/4)，赔率 o = (2, 4, 4)（注意 oᵢ = 1/pᵢ，是公平赔率）。(a) 用 Kelly 策略 b* = p，算 W*；(b) 改用均匀分押 b = (1/3, 1/3, 1/3)，算 W；(c) 验证 W* − W = D(p‖b)。
提示

先算每场的财富倍率 bᵢoᵢ；Kelly 下 pᵢoᵢ = 1/2×2、1/4×4、1/4×4 各是多少？D(p‖b) = Σ pᵢ log₂(pᵢ/bᵢ)。

完整解答

(a) Kelly：p₁o₁ = (1/2)×2 = 1，p₂o₂ = (1/4)×4 = 1，p₃o₃ = (1/4)×4 = 1。每场倍率恒为 1，W* = Σ pᵢ log₂1 = 0 比特/场——公平赔率且按真实分布下注，财富原地不动（与 6.3 节末尾的定理一致）。

(b) 均匀分押 b = (1/3,1/3,1/3)：b₁o₁ = 2/3，b₂o₂ = 4/3，b₃o₃ = 4/3。W = (1/2)log₂(2/3) + (1/4)log₂(4/3) + (1/4)log₂(4/3) = (1/2)(−0.5850) + (1/2)(0.4150) = −0.2925 + 0.2075 = −0.0850 比特/场——指数衰减，迟早输光。

(c) D(p‖b) = Σ pᵢ log₂(pᵢ/bᵢ) = (1/2)log₂((1/2)/(1/3)) + (1/4)log₂((1/4)/(1/3)) + (1/4)log₂((1/4)/(1/3)) = (1/2)log₂(3/2) + (1/2)log₂(3/4) = (1/2)(0.5850) + (1/2)(−0.4150) = 0.2925 − 0.2075 = 0.0850。

验证：W* − W = 0 − (−0.0850) = 0.0850 = D(p‖b) ✓。三个数完全自洽：偏离 Kelly 的代价精确等于投注分布与真实分布的相对熵。

L2 手算推导4 马赛 p = (1/2, 1/4, 1/8, 1/8)，均匀公平赔率 4 倍。情报 Y 只告诉你"赢家是不是 1 号马"（Y = 1 表示是）。手算 I(X;Y) 与有情报时的最优增长率。
提示

I(X;Y) = H(X) − H(X|Y)。Y = 1 时 X 确定；Y = 0 时把剩余概率归一化再算熵。ΔW = I，无情报时 W** = 0.25（正文已算）。

完整解答

H(X) = 1.75 比特（Ch1 已算）。

Y = 1 的概率 = p₁ = 1/2，此时 X = 1 确定，条件熵 H(X|Y=1) = 0。

Y = 0 的概率 = 1/2，此时后验分布 = (1/4, 1/8, 1/8)/(1/2) = (1/2, 1/4, 1/4)，H(X|Y=0) = −(1/2)log₂(1/2) − (1/4)log₂(1/4) − (1/4)log₂(1/4) = 0.5 + 0.5 + 0.5 = 1.5 比特。

H(X|Y) = (1/2)×0 + (1/2)×1.5 = 0.75，故 I(X;Y) = 1.75 − 0.75 = 1.0 比特。

由 ΔW = I(X;Y)，最优增长率从 0.25 升到 0.25 + 1.0 = 1.25 比特/场。直观验证：Y = 1 的场次（占一半）全押 1 号赚 log₂(1×4) = 2 比特；Y = 0 的场次在 (1/2,1/4,1/4) 上按 Kelly 下注赚 log₂4 − 1.5 = 0.5 比特；平均 (2 + 0.5)/2 = 1.25 ✓。两条路径独立算出同一个数。

L3 建模应用一位量化交易员面对一个每日两种状态的杠杆产品：涨（概率 0.55）/ 跌（概率 0.45），赔率对称——猜对方向 +100%，猜错 −100%（等价于 o = 2 的赛马）。(a) 用 Kelly 给出最优仓位 b* 并算双倍率 W*；(b) 解释为什么不能满仓；(c) 若有一个准确率 60% 的涨跌信号，说明它为什么有价值（算出 I 即可，log₂0.6 ≈ −0.7370，log₂0.4 ≈ −1.3219，log₂0.55 ≈ −0.8625，log₂0.45 ≈ −1.1520）。
提示

(a) b* = p；注意 0.55×2 = 1.1、0.45×2 = 0.9。(b) 满仓押涨时，跌的那场倍率是多少？(c) 信号准确率 60% ⟹ H(X|Y) = H(0.6)。

完整解答

(a) 建模：X ∈ {涨, 跌}，p = (0.55, 0.45)，o = (2, 2)，仓位 = 投注比例。Kelly：b* = (0.55, 0.45)，即 55% 仓位做多（或等价地以 0.55 的比例押"涨"）。W* = 0.55·log₂(0.55×2) + 0.45·log₂(0.45×2) = 0.55·log₂1.1 + 0.45·log₂0.9 = 0.55×0.1375 + 0.45×(−0.1520) = 0.0756 − 0.0684 = 0.0072 比特/天，财富 ≈ 2^{0.0072n} ≈ 1.005ⁿ——每天约涨 0.5%，年化可观但不暴利：55% 的胜率优势本就单薄。

(b) 满仓 = b = (1, 0)：跌的那场倍率为 0，log₂0 = −∞，W = −∞。杠杆产品每天 45% 的概率清零，破产是吸收壁，进去就出不来。Kelly 的 55% 仓位正是 log 定价风险给出的"既用足优势又不赌命"的平衡点。

(c) 信号 Y 以 60% 准确率预告 X：H(X) = H(0.55) = 0.55×0.8625 + 0.45×1.1520 = 0.4744 + 0.5184 = 0.9928 比特；H(X|Y) = H(0.6) = 0.6×0.7370 + 0.4×1.3219 = 0.4422 + 0.5288 = 0.9710 比特。I(X;Y) = 0.9928 − 0.9710 = 0.0218 比特。由 ΔW = I，日增长率从 0.0072 升到约 0.029 比特/天——增长近乎翻两番。哪怕只是 60% 准的弱信号，货币价值也精确可算；而 50% 准的信号 I = 0，一文不值。

选 B。某匹马不押 ⟹ 它赢的那场倍率 = 0 ⟹ log₂0 = −∞ ⟹ W = −∞；只要该马概率非零，n 场中它至少出现一次的概率 → 1，财富归零且无法恢复。A 错：恰恰相反，全押热门时 E[Sₙ] = 1.5ⁿ 指数爆炸——期望好得很，路径死得很；C 错：问题不在赔率高低而在结构；D 错：大数定律照常成立，正是它给出 W = −∞。

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：面对一场无限重复的赌局（赛马/市场），长期最优的投注策略是什么，它的财富增长率由什么决定。
句2：核心机制是什么？——
参考答案：财富是乘积过程，取对数化乘为加，大数定律把长期行为逼成最大化双倍率 W = Σp log(b·o)；由相对熵非负得 Kelly 准则 b* = p，偏离代价恰为 D(p‖b)；均匀公平赔率下 W** = log₂m − H(p)，熵直接变成钱；边信息的价值 ΔW = I(X;Y)。
句3：它和前后章怎么分工？——
参考答案：Ch5 压缩是熵这本账的正面（码长省到 H），本章是同一账本的另一面（增长率赚到 log m − H，码长对码表、投注对比例）；Ch7 接着问：信息穿过噪声信道后还剩多少价值——信道容量。
