8.1微分熵的定义：为什么不能直接搬离散公式

第 7 章把信道容量写成了 C = max I(X;Y)，漂亮利落。但回忆一下：从第 2 章到第 7 章，所有随机变量都在离散字母表上取值——比特、符号、码字。可是真实的物理世界几乎都是连续的：麦克风电压、天线收到的波形、温度、股价。问题立刻来了：熵的公式能直接用吗？

不能。原因很硬：连续变量取任何一个具体值的概率都是 0（概率密度函数在单点上的"面积"为零）。如果对无穷多个取值各配一份 −p log p，每一项都是 −0·log 0 型的不定式，而项数无穷多——离散熵公式直接发散。更直观地看 8.3 节会精确证明的事实：把一个连续变量按 Δ 步长量化，量化越细（Δ 越小），所得离散熵越大，且大约每加一位精度就涨 1 比特，没有极限。所以"连续变量的熵"不存在，存在的是另一个量。

定义：设 X 有概率密度函数 f(x)，定义微分熵（Differential Entropy）为

h(X) = −∫ f(x) log₂ f(x) dx

形式上就是把 Σ 换成 ∫、把概率 p(x) 换成密度 f(x)。它是有良好定义的积分（只要收敛），但——马上会看到——它的脾气和离散熵很不一样。

例 1：均匀分布 U[0,a]，算出第一个微分熵

X 在 [0,a] 上均匀分布，密度 f(x) = 1/a（x ∈ [0,a]），其余为 0。一步步算：

h(X) = −∫₀ᵃ 1a · log₂1a dx = 1a · log₂ a · ∫₀ᵃ dx = 1a · log₂ a · a = log₂ a

代入几个数值看行为：

ah = log₂ a读法
21 比特正常
10 比特边界
1/2−1 比特负的！

区间越窄，h 越小，甚至可以任意负（a = 1/8 时 h = −3）。这在离散世界绝无可能——离散熵恒非负。微分熵为负不是计算错误，而是它的本性：密度可以大于 1，−log f 就可以为负。

⚠️ 常见误区

"微分熵就是连续版的不确定性度量"——错在两个地方。其一，它可以为负，而"不确定性"不该是负数。其二，它依赖坐标刻度：把 X 换成 2X（只是换单位，比如米换成半米），密度减半，h(X) 增加 1 比特。同一段"不确定性"换了把尺子就变了数。所以 h(X) 不是绝对度量，只是相对量；真正幸存为绝对信息量的，是相对熵 D 与互信息 I（8.4 节）。

例 2：指数分布，步骤写全

设 f(x) = e−x（x ≥ 0）。这是均值和方差都是 1 的指数分布（先验证归一化：∫₀∞ e−x dx = 1 ✓）。

第一步，算 −log₂ f(x)：

−log₂ f(x) = −log₂ e−x = x · log₂ e

第二步，代入定义：

h(X) = ∫₀∞ f(x) · x · log₂ e dx = log₂ e · ∫₀∞ x e−x dx

第三步，括号里的积分正是 E[X] = 1（指数分布的均值）：

h(X) = log₂ e × 1 = log₂ e ≈ 1.443 比特

记住这个数：8.5 节会拿它和"方差同为 1 的高斯分布"对比，检验本章最重要的定理。

💡 关键一跃

微分熵度量的不是"不确定性本身"，而是密度铺满空间的对数尺度：密度摊得越开，h 越大；挤得越紧，h 越小、可以为负。它是一把"相对尺"，8.3 节的量化桥会告诉你：尺的零点可以随意挪，但两个分布的 h 之差是稳定的、有操作意义的。

8.2连续情形的 AEP：典型集的"体积"

上一节定义了 h(X)，但它还只是个积分式。它凭什么配得上"熵"这个名字？答案要看它是否继承了离散熵最核心的角色——第 3 章的 AEP 说过：长序列几乎必然落在典型集里，而典型集的"尺寸"由熵决定。本节把这句话原样翻译到连续世界。

先回忆离散版（Ch3）：独立同分布地生成 n 个符号，当 n 很大时——

  • 典型序列约有 2nH(X) 条；
  • 每条典型序列的概率约 2−nH(X)；
  • 典型集的总概率 ≈ 1（非典型部分可以忽略）。

连续版完全平行。设 X₁,…,Xₙ 独立同分布，密度为 f。把"数序列有多少条"换成"量区域有多大"：集合 S 的体积（Volume）定义为

Vol(S) = ∫S dx₁ dx₂ … dxₙ

连续 AEP：当 n 很大时，存在典型集 Aε(n)，满足——

  • 典型集的体积约 2nh(X)；
  • 落在典型集里的序列，其联合密度约 2−nh(X)；
  • P((X₁,…,Xₙ) ∈ Aε(n)) ≈ 1。

💡 关键一跃

微分熵扮演的角色与离散熵完全平行：它度量"典型空间"的对数尺寸。只是空间从有限集合变成了连续区域，数个数换成了量体积。体积可以小于 1（典型空间比单位超立方还小），取对数就是负的——h 为负在这里毫不神秘，它只是说典型体积的对数是负的。

⚠️ 常见误区

"典型集体积 2^{nh} 意味着概率也按体积均匀摊开"——只在典型集内近似成立。连续 AEP 的三条陈述全是"约等于"（指数尺度上的渐近），把它当成精确等式去算有限 n 的题会出错；它真正的用途和 Ch3 一样：把"几乎所有概率"集中到一小块区域上，为压缩与编码计数。

8.3量化桥梁：微分熵与离散熵的精确关系

8.1 说离散熵搬不过来，8.2 说微分熵继承了熵的角色。这两个说法之间还缺一座桥：把连续变量量化成离散的，它的离散熵和 h(X) 到底差多少？这座桥一旦搭好，"h 可为负""h 依赖坐标"就都有了统一的解释。

把 X 的取值范围切成宽度 Δ 的小格子，定义量化变量 XΔ：X 落进哪个格子，XΔ 就取该格子的代表值 xᵢ。当 Δ 足够小，密度在一个格子里近似不变：

P(XΔ = xi) ≈ f(xi) · Δ

第一步：写出量化变量的离散熵，代入上式：

H(XΔ) = −Σi f(xi)Δ · log₂( f(xi)Δ )

第二步：把对数拆开（log(fΔ) = log f + log Δ）：

= −Σi f(xi)Δ · log₂ f(xi) − log₂ Δ · Σi f(xi)Δ

第三步：第一个和式在 Δ→0 时趋于积分 h(X)；第二个和式里 Σ f(xᵢ)Δ ≈ ∫f dx = 1。于是：

H(XΔ) ≈ h(X) + log₂ 1Δ

数值例：U[0,1) 的逐位量化

X ~ U[0,1)，h = log₂ 1 = 0。做 8 比特均匀量化（Δ = 2−8）：

H(XΔ) ≈ h + log₂ 28 = 0 + 8 = 8 比特 ✓（直接数格子也是 2⁸ 个等概率格子，H = 8）

16 比特量化（Δ = 2−16）：H(XΔ) ≈ 0 + 16 = 16 比特。每加一位精度，离散熵恰好加 1。

✅ 判定规则

把一个连续变量描述到 n 位二进制精度，平均约需 h(X) + n 比特。微分熵就是"去掉精度项之后剩下的本底"：它告诉你这个分布本身的散布程度，而 n 是你自己选的刻度。

⚠️ 常见误区

"h(X) 为负与熵非负矛盾"——不矛盾。量化后的离散熵 H(XΔ) ≥ 0 永远成立，因为 log₂(1/Δ) 随 Δ 变小而趋于无穷，总压得过负的 h。h 为负只是说典型体积小于 1、本底成本低；只要精度取得够细，每加一位就实实在在地多付 1 比特。

8.4联合、条件微分熵与互信息：哪些公式幸存

桥搭好了，现在盘点家底：第 2 章为离散熵建立的一整套关系式，哪些能原样搬进连续世界？答案分三类：幸存、修改、失效。先说幸存的，而且幸存得比预期多。

联合微分熵与条件微分熵（Joint / Conditional Differential Entropy）按同一模板定义：

h(X,Y) = −∫ f(x,y) log₂ f(x,y) dx dy　　h(X|Y) = h(X,Y) − h(Y)

链式法则原样成立：

h(X₁, X₂, …, Xₙ) = Σi h(Xi | X₁, …, Xi−1)

相对熵同样按模板定义，且非负性幸存：

D(f‖g) = ∫ f(x) log₂ f(x)g(x) dx ≥ 0

互信息的两个等价写法也都幸存：

I(X;Y) = h(X) − h(X|Y) = D( f(x,y) ‖ f(x)f(y) ) ≥ 0

这里有一个比离散情形更漂亮的性质：I 在可逆坐标变换下不变。把 X、Y 分别做光滑可逆变换，联合密度与边际密度被同一个 Jacobian 因子缩放，比值 f(x,y)/(f(x)f(y)) 里的因子恰好抵消，积分不变。而 h(X) 自己在变换下会变（8.1 的 X→2X 就加 1 比特）——h 变了，h(X|Y) 同幅度地变，差值 I 纹丝不动。这就是为什么 I 才是真正的"信息量"：它与用哪把尺子无关。

条件化减熵 h(X|Y) ≤ h(X) 也幸存——它就是 I(X;Y) ≥ 0 的改写。

离散结论（Ch2）连续版命运说明
链式法则 H = ΣH(Xᵢ|X₁..Xᵢ₋₁)幸存逐字成立
D(p‖q) ≥ 0幸存D(f‖g) ≥ 0，同样推出一切不等式
I(X;Y) ≥ 0，I=0 ⟺ 独立幸存且在可逆坐标变换下不变
条件化减熵 H(X|Y) ≤ H(X)幸存由 I ≥ 0 直接得到
H(X) ≥ 0失效h 可为负（8.1 的 U[0,1/2]）
H(X) 在坐标重排下不变失效X→2X 时 h 增加 1 比特
H(X) ≤ log|𝒳|，均匀分布最大修改连续支撑集无有限"大小"；改成：方差给定时高斯分布熵最大（8.5）
💡 关键一跃

盘点结果一句话：凡是由"比值"和"差"定义的量（D、I、条件化减熵）都幸存；凡是依赖"绝对计数"的量（非负性、坐标不变性、均匀最大）都要改写。这正呼应 8.1 的判断：h 是相对尺，D 与 I 才是绝对量。

8.5高斯最大熵定理：方差给定，谁最"散"

8.4 的盘点留下一个空位：离散世界里"均匀分布熵最大"，连续世界里支撑集没有有限大小，这个宝座空了。本节把它填上——只是约束条件从"支撑集给定"换成"方差给定"，冠军从均匀换成高斯。

✅ 定理（高斯最大熵）

在所有满足 E[X]=0、Var(X) ≤ σ² 的概率密度中，微分熵最大的是正态分布 N(0,σ²)，其值为

hmax = 12 log₂(2πeσ²)

证明骨架：只用一条 D(f‖g) ≥ 0

设 f 是任意一个方差为 σ² 的密度，g 是 N(0,σ²) 的密度。由相对熵非负：

第一步：展开 D(f‖g) 的定义：

0 ≤ D(f‖g) = ∫ f log₂ fg = −h(f) − ∫ f log₂ g

第二步：关键观察——log g 是 x 的二次函数（g 是钟形曲线，取对数后是抛物线：log g(x) = 常数 − x²/2σ²·log₂e）。因此 ∫ f log₂ g 只通过一阶矩、二阶矩依赖 f。而 f 与 g 的均值、方差完全相同，所以：

∫ f log₂ g = ∫ g log₂ g = −h(g)

第三步：代回第一步：0 ≤ −h(f) + h(g)，即

h(f) ≤ h(g) = 12 log₂(2πeσ²)

证完。整个证明只用了一件旧工具：相对熵非负（8.4 的幸存者）。这正是"D 是万用扳手"的又一次兑现。

数值验证：σ² = 1，高斯 vs 指数

先算 2πe ≈ 17.079，再取对数：log₂(17.079) = log₂(2⁴×1.0675) = 4 + log₂1.0675 ≈ 4 + 0.0943 = 4.0943。于是 σ² = 1 时：

hmax = 12 × 4.0943 = 2.047 比特

对比 8.1 例 2 的指数分布（均值方差都是 1，平移到零均值不改变方差与 h 的比较逻辑）：h = log₂e ≈ 1.443 比特。

1.443 < 2.047 ✓

同样方差为 1，指数分布的熵比高斯少了 0.6 比特多——定理所言不虚。差距的来源：指数分布在 x=0 处有个尖峰且向右偏斜，这些"形状偏好"都在压缩典型体积。

💡 关键一跃

高斯分布是"最没有形状偏好"的分布：固定了散布范围（方差）之后，它不再表达任何额外结构。任何别的形状——尖峰、偏斜、重尾、双峰——都在方差的预算之内加进了结构，而结构只会缩小典型体积、降低熵。最大熵 = 最少承诺。

回忆 8.5-2
证明的三步骨架是什么？哪一步用到"log g 是二次函数"？
点击翻面 →

8.6熵与估计误差：h 越小越好猜

最后一节回答一个工程味十足的问题：微分熵和"猜得准不准"有什么关系？直觉是 h 越小分布越集中，应该越好猜。信息论把这句直觉变成了一条精确不等式。

✅ 定理（估计误差的熵下界）

对任意基于观测 Y 的估计量 X̂(Y)，均方误差满足

E (X − X̂)² ≥ 12πe · 22h(X|Y)

特别地，没有任何观测时（无条件版）：E(X−X̂)² ≥ 22h(X) / (2πe)。

读法：给定条件微分熵 h(X|Y)，任何估计方法——不管多聪明——的均方误差都有一个由 2^{2h(X|Y)} 决定的地板。h 每减小 1 比特，误差下界缩小到原来的 1/4。熵确实在度量"可猜性"，方向也对：h 越小越好猜。

自洽检验：高斯情形等号成立

取 X ~ N(0,σ²)，无观测。8.5 已算 h(X) = ½log₂(2πeσ²)。代入下界，一步步来：

第一步：算 2^{2h}：

22h = 22 × ½log₂(2πeσ²) = 2log₂(2πeσ²) = 2πeσ²

第二步：除以 2πe：

E(X − X̂)² ≥ 2πeσ²2πe = σ²

第三步：核对——不用任何观测猜 X 的最优值就是均值 0，此时均方误差恰为 Var(X) = σ²。下界被达到，等号成立。这说明：对高斯变量，"猜均值"已经是最优估计，不可能更准；下界是紧的，不是松的口号。

💡 通向第 9 章的一句话

现在把 8.5 与 8.6 拼起来：方差给定时，高斯噪声的熵最大（8.5），因而它带来的估计误差下界也最高（8.6）——高斯噪声是给定功率下"最坏"的噪声。第 9 章的高斯信道 Y = X + Z（Z 为高斯噪声）里，容量公式 C = ½log₂(1+P/N) 分子分母上的两个量，本质上都是 2^{2h} 之比——信号加噪声的散布对噪声散布的倍数。本章的工具将在下一章一字不差地全部登场。

概念卡 1
微分熵（Differential Entropy）
点击翻面 →
定义h(X) = −∫ f(x) log₂ f(x) dx，连续密度的"熵"。
解决问题离散熵对连续变量发散；微分熵是去掉精度项后的本底散布度量。
直觉典型体积的对数：密度摊得越开 h 越大，挤得越紧越小、可为负。
误区当作绝对不确定性——它可为负、随坐标缩放变化，只是相对尺。
何时用Ch9 高斯信道容量、Ch10 率失真函数的全部原材料。
概念卡 2
典型集体积（Volume of Typical Set）
点击翻面 →
定义Vol(S) = ∫_S dx₁…dxₙ；连续 AEP 中 Vol(A_εⁿ) ≈ 2^{nh(X)}。
解决问题把"典型序列有 2^{nH} 条"翻译到连续世界：条数换成体积。
直觉长序列几乎全部概率挤在体积 2^{nh} 的一小块区域里。
误区当成精确等式去算有限 n——它只是指数尺度上的渐近陈述。
何时用连续信源压缩论证；Ch9 球填充式的容量几何图像。
概念卡 3
量化关系（Quantization Relation）
点击翻面 →
定义H(X^Δ) ≈ h(X) + log₂(1/Δ)，Δ 为量化步长。
解决问题精确连接离散熵与微分熵：差的就是精度项 log(1/Δ)。
直觉描述到 n 位精度 = 本底 h + 精度 n；每加一位多付 1 比特。
误区以为 h 为负与熵非负矛盾——H(X^Δ) 永远非负，精度项总会压过负 h。
何时用估算连续量的编码成本；理解模数转换（ADC）位数与比特率。
概念卡 4
条件微分熵与链式法则（Conditional Differential Entropy）
点击翻面 →
定义h(X|Y) = h(X,Y) − h(Y)；链式法则 h(X₁..Xₙ) = Σh(Xᵢ|X₁..Xᵢ₋₁)。
解决问题度量知道 Y 后 X 的剩余散布，是 I(X;Y) 的组成件。
直觉剩余典型体积的对数：Y 每多一分信息，X 的典型空间缩一圈。
误区以为它非负——联合/条件微分熵都可为负，只有它们的差 I 非负。
何时用8.6 估计误差下界；Ch9 中 h(Y|X) = h(Z) 的关键一步。
概念卡 5
高斯最大熵（Gaussian Maximal Entropy）
点击翻面 →
定义方差 ≤ σ² 的密度中，N(0,σ²) 熵最大：h = ½log₂(2πeσ²)。
解决问题连续版"均匀分布熵最大"的替代：支撑集无限，改用方差作约束。
直觉固定散布预算后，高斯没有任何额外形状；结构只会吃掉熵。
误区忘了约束条件——无约束时微分熵没有最大值（可以任意大）。
何时用Ch9 证明高斯输入达到信道容量；Ch12 最大熵原理的主角。
概念卡 6
熵与估计误差（Entropy and Estimation Error）
点击翻面 →
定义任意估计量满足 E(X−X̂)² ≥ 2^{2h(X|Y)}/(2πe)。
解决问题把"h 小则好猜"变成精确的均方误差地板。
直觉条件典型体积决定最好的猜测误差；高斯时猜均值恰好达到地板。
误区以为存在更聪明的估计能突破下界——对高斯变量猜均值已是最优。
何时用Ch9 信道容量的几何解释；估计理论与信息论的接口。

📝分层习题

L1 概念辨析判断对错：微分熵和离散熵一样恒非负。说明理由并给出反例。
提示

回到 8.1 的均匀分布：a 取小于 1 的值时 log₂ a 是什么符号？

完整解答
错。反例：X ~ U[0,1/2]，h = log₂(1/2) = −1 比特。根源是密度 f(x) = 2 可以大于 1，−log₂ f 处处为 −1，积分得 −1。离散熵非负是因为概率 p ≤ 1 保证 −log p ≥ 0；密度没有这个上界。微分熵是相对量而非绝对不确定性。
L1 概念辨析判断对错：连续情形下 I(X;Y) 仍非负，且在可逆坐标变换下不变。
提示

I 有两个等价写法；坐标变换时联合密度和边际密度各乘一个什么因子？

完整解答
对。非负性：I(X;Y) = D(f(x,y)‖f(x)f(y))，而 D(f‖g) ≥ 0 在连续情形幸存（8.4）。变换不变性：对 X、Y 分别做可逆变换，f(x,y) 与 f(x)f(y) 乘上同一个 Jacobian 因子，比值 f(x,y)/(f(x)f(y)) 不变，故积分 I 不变。对比之下 h(X) 单独会变（X→2X 加 1 比特），所以 I 而非 h 才是坐标无关的"信息量"。
L2 手算推导手算 U[0,4] 与 N(0,4)（σ² = 4）的微分熵并比较；注意两者方差不同，再做一次等方差的公平比较。
提示

U[0,a]：h = log₂ a；高斯：h = ½log₂(2πeσ²)，log₂(2πe) = 4.0943。U[0,4] 的方差是 a²/12。

完整解答

直接算（方差不同，仅供参考）：

均匀：h = log₂ 4 = 2 比特。

高斯：h = ½log₂(2πe·4) = ½log₂(68.32) = ½(log₂4 + 4.0943) = ½(2 + 4.0943) = ½×6.0943 = 3.047 比特。

表面看高斯大 1 比特多——但公平吗？U[0,4] 的方差是 4²/12 = 16/12 = 4/3，而 N(0,4) 的方差是 4。高斯的"散布预算"本来就大三倍，比较不公平。

等方差比较（σ² = 4/3）：

h(N(0,4/3)) = ½log₂(2πe·4/3) = ½(log₂(2πe) + log₂(4/3)) = ½(4.0943 + 0.4150) = ½×4.5093 = 2.255 比特。

2.255 > 2 ✓：同方差之下高斯仍然胜出，与 8.5 定理一致（均匀分布是方差约束下的一种形状，不可能超过高斯）。

L2 手算推导X ~ N(0,1)（h = 2.047 比特）。用 10 比特均匀量化覆盖其有效范围，估算量化后离散熵 H(X^Δ)，并解释"约"字从何而来。
提示

量化关系 H(X^Δ) ≈ h(X) + log₂(1/Δ)；10 比特意味着 Δ = 2⁻¹⁰。

完整解答

H(X^Δ) ≈ h(X) + log₂(1/Δ) = 2.047 + log₂2¹⁰ = 2.047 + 10 = 12.047 比特。

"约"有两层来源：其一，量化关系本身是 Δ→0 时的渐近式（把格内密度当常数）；其二，高斯分布支撑在整个实轴上，10 比特的格子只能覆盖有限范围（比如 ±4σ），尾部被截断——截断外的概率质量被忽略或归入边界格，真实离散熵与 12.047 有一个小偏差。覆盖范围越宽，偏差越小。

L3 建模应用麦克风噪声建模：已知噪声平均功率（方差）约束为 0.01 W。工程师要在均匀、三角、高斯三种噪声模型中选最保守（最坏情况）的一种来设计系统。选哪个？算出它的微分熵，并说明这与第 9 章的关系。
提示

"最坏情况"= 不确定性最大；方差约束下谁的熵最大？log₂0.01 = −6.6439。

完整解答

选高斯。8.5 定理：方差给定时高斯分布微分熵最大，即不确定性最大、最"不可预测"——按最坏情况设计就应选它。

数值：h = ½log₂(2πe × 0.01) = ½(4.0943 + log₂0.01) = ½(4.0943 − 6.6439) = ½×(−2.5496) = −1.275 比特。

h 为负无碍——比较的是三个模型在同一方差下的相对大小，高斯仍然最大（均匀、三角只会更负）。

与第 9 章的关系：真实加性噪声信道 Y = X + Z 正是按高斯噪声分析，因为给定噪声功率时它是最坏（最大熵）的假设；由此推出的容量 C = ½log₂(1+P/N) 因此是保守而可靠的性能保证。本章的高斯最大熵定理就是那个公式的理论地基。
