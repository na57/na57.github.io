10.1为什么需要率失真：无损这条路已经走到头了

第 5 章给出了无损压缩的答案：平均码长的极限是熵 H(X)，多好的码也压不破它。第 9 章给出了信道那头的答案：AWGN 信道容量 C = ½log(1+P/N)。两章之间缺了一块——信源这头。很多情形下"无损"根本不是合理目标，本节给出两层理由，它们共同引出本章的主线问题。

理由一：连续信源的精确表示根本不存在

取 X ~ U[0,1]。把 X 写成二进制小数 0.b₁b₂b₃…，它是一个无限长的比特序列：任何有限比特的表示都对应一个区间，而不是一个点。第 8 章定义的微分熵（Differential Entropy）h(X) 在这里是有限的（h = log 1 = 0），但第 8 章也警告过：微分熵不是"表示 X 所需的比特数"——连续变量的精确表示需要无穷多比特，不存在任何"无损压缩连续信源"的编码。

所以对连续信源，"压缩"这个词要重新定义：不再问"最少多少比特精确表示"，而问"最少多少比特表示到误差不超过 D"。

理由二：即使离散信源，很多应用也不要求逐比特一致

语音、图像、视频：人耳分辨不出 16 bit 与 15 bit 量化的差别，人眼看不出相邻灰度 1 级的变化。坚持无损等于为人感知不到的差别付比特。MP3、JPEG 这些工程系统的存在说明"有损"早就是现实——本章要回答的是：这场交易的最优汇率是多少？给定可容忍的平均失真 D，每样本最少要多少比特？

✅ 本章的中心结论（预告）

对每个信源和失真度量，存在一个只由它们决定的函数 R(D)：任何平均失真不超过 D 的压缩方案，码率都不能低于 R(D)；而存在码率任意接近 R(D) 的方案。R(D) 与 H、C 同级——是定理级的极限，不是工程经验。

💡 关键一跃

把无损看作 D = 0 的特例，整张图景就统一了：离散信源 R(0) = H(X)（回到第 5 章），连续信源 R(0) = ∞（精确表示不可能），而 0 < D 时的 R(D) 是一条"用失真换比特"的折扣曲线。本章就是要把这条曲线算出来。

⚠️ 常见误区

"有损压缩是一堆工程技巧（变换、量化、心理声学模型），没有统一的理论极限"——错。技巧决定你多接近极限，R(D) 决定极限在哪里。码率低于 R(D) 而失真不超 D 的方案不存在，与创意无关；正如第 7 章容量之上无可靠通信。

10.2把"允许失真"变成优化问题：失真度量与 R(D) 的定义

上一节说"必须允许失真"，但"失真"是多少、"最少比特"对谁取最小，都需要严格化。本节做两件事：给失真标价，然后在一个假想"信道"的空间里做优化，得到率失真函数。

失真度量：给每种误差明码标价

失真度量（Distortion Measure）是一个非负函数 d(x, x̂) ≥ 0，表示"信源发出 x、重建给出 x̂"这件事有多糟。最常用的两个：

失真度量定义期望失真的含义
汉明失真（Hamming Distortion）d(x,x̂) = 1（x ≠ x̂ 时），否则 0错误概率 Pr(X ≠ X̂)
平方误差（Squared Error）d(x,x̂) = (x − x̂)²均方误差 E[(X − X̂)²]

对长度为 n 的序列，失真按坐标平均：d(xⁿ, x̂ⁿ) = (1/n) Σi d(xi, x̂i)。注意：失真度量由应用选定，不是数学内生的——选错度量，优化得再准也答错了问题。

率失真函数：在所有假想"信道"上取最小

固定信源分布 p(x)。一个压缩方案把 x 映到重建 x̂，其统计行为可以用条件分布 p(x̂|x) 完整刻画——我们把它叫试验信道（Test Channel）：假装信源过了一道我们自己选的"信道"，输出就是重建。于是"最少多少比特"变成一个优化问题：

R(D) = minp(x̂|x) : E[d(X,X̂)] ≤ D I(X; X̂)

读法：在所有满足失真预算 E[d(X,X̂)] ≤ D 的试验信道中，找互信息最小的那个。互信息 I(X;X̂) 度量"重建必须携带多少关于信源的信息"——它越小，描述 X̂ 所需的比特越少。这个最小值就叫率失真函数（Rate Distortion Function）。

✅ R(D) 的三条性质（记住形状）

① 非负：I(X;X̂) ≥ 0，故 R(D) ≥ 0；② 单调不增：D 只出现在约束里，预算放松则可行集变大，最小值不会变大；③ 凸：I(X;X̂) 对条件分布 p(x̂|x) 是凸函数，两个可行试验信道的混合仍可行、且互信息不超过二者的混合，取下确界保持凸性。凸 + 非增 ⇒ R(D) 是一条向右下方弯的平滑折扣曲线。

完整手算例：Bernoulli(1/2) 信源 + 汉明失真

结论：R(D) = 1 − H₂(D)（0 ≤ D ≤ 1/2）；D ≥ 1/2 时 R(D) = 0。其中二元熵

H₂(p) = −p·log₂ p − (1−p)·log₂(1−p)

第一步：证下界。汉明失真下，错误指示比特 E = X ⊕ X̂ 满足 E[d] = Pr(X ≠ X̂) = Pr(E = 1) ≤ D。对任意可行试验信道：

I(X;X̂) = H(X) − H(X|X̂) = 1 − H(X⊕X̂ | X̂) ≥ 1 − H(X⊕X̂) = 1 − H₂(Pr(X≠X̂)) ≥ 1 − H₂(D)

用了三步：条件不会增熵（H(E|X̂) ≤ H(E)）；二元熵只由错误概率决定；H₂(p) 在 [0, 1/2] 上单调增，而错误概率 ≤ D ≤ 1/2，故 H₂(Pr) ≤ H₂(D)。

第二步：构造达到下界的试验信道。取最优试验信道为二元对称信道（Binary Symmetric Channel, BSC）：令 X̂ ~ Bernoulli(1/2)，噪声 Z ~ Bernoulli(D) 独立于 X̂，X = X̂ ⊕ Z。验证三件事：

  • 失真：Pr(X ≠ X̂) = Pr(Z = 1) = D，恰好顶满预算 ✓
  • 边缘：X 仍是 Bernoulli(1/2)（对称信道保持均匀分布）✓
  • 互信息：I(X;X̂) = H(X) − H(X|X̂) = 1 − H(Z) = 1 − H₂(D)，等于下界 ✓

第三步：代数值。D = 0.1 时（log₂ 0.1 ≈ −3.3219，log₂ 0.9 ≈ −0.1520）：

H₂(0.1) = −0.1×(−3.3219) − 0.9×(−0.1520) = 0.3322 + 0.1368 = 0.4690 bit
R(0.1) = 1 − 0.4690 = 0.531 bit/样本

读数：允许 10% 的比特错误，每样本只需约 0.53 bit，比无损的 1 bit 省下近一半。这就是"失真换比特"的第一笔成交。

💡 直觉

试验信道不是真实硬件，而是压缩方案的"数学化身"。设计最优压缩 ⟺ 在所有满足失真预算的假相信道里找泄露信息最少的那个。R(D) 曲线上的每一点，背后都站着一条最优试验信道——它同时给出极限值和（原则上的）实现方式。

⚠️ 常见误区

"允许的失真越大，需要的比特越多"——恰好相反。D 出现在约束里：预算越松，可行试验信道越多，最小互信息只会更小。极端情形：D ≥ 1/2 时 R(D) = 0——接收方不看任何信息、恒输出 0，期望错误率恰好 1/2，一个比特都不用发。

10.3高斯信源 + 平方误差：½log(σ²/D) 的来历

上一节在离散世界成交了第一笔"失真换比特"。现在回到 10.1 的原始痛点——连续信源。高斯信源配平方误差是唯一有漂亮闭式解的连续情形，也是语音、图像编码实践中最常用的基准近似。

✅ 定理（高斯率失真）

设 X ~ N(0, σ²)，失真度量为平方误差。则 0 < D ≤ σ² 时

R(D) = 12 log₂ σ²D

D ≥ σ² 时 R(D) = 0——直接重建为均值 0，失真即方差 σ²，已经满足预算，一个比特都不用花。

推导第一步：下界（任何方案都不能低于它）

对任意满足 E[(X−X̂)²] ≤ D 的试验信道，一串不等式（每步标注理由）：

I(X;X̂) = h(X) − h(X|X̂) = h(X) − h(X−X̂ | X̂) （平移不改变微分熵）
≥ h(X) − h(X−X̂) （条件不增熵）
≥ 12log(2πeσ²) − 12log(2πe·E[(X−X̂)²]) （给定方差，高斯微分熵最大）
≥ 12log(2πeσ²) − 12log(2πeD) = 12log σ²D （预算 E[(X−X̂)²] ≤ D，且 log 单调）

关键一步是第三个不等号：方差固定时高斯分布的微分熵最大（第 8 章结论），所以 h(X−X̂) ≤ ½log(2πe·E[(X−X̂)²])，减去的项被控制在最小。

推导第二步：反向试验信道，达到下界

正面猜 p(x̂|x) 很难。反向试验信道（Backward Test Channel）反过来写——不写"X̂ 怎么由 X 来"，而写"X 怎么由 X̂ 来"：

X = X̂ + Z，其中 X̂ ~ N(0, σ²−D)，Z ~ N(0, D)，二者独立

验证三件事，一步不落：

  1. 边缘对：独立高斯相加，方差可加，X ~ N(0, (σ²−D) + D) = N(0, σ²) ✓
  2. 失真对：E[(X−X̂)²] = E[Z²] = D，恰好顶满预算 ✓
  3. 互信息对：I(X;X̂) = h(X) − h(X|X̂) = h(X) − h(Z) = ½log(2πeσ²) − ½log(2πeD) = ½log(σ²/D)，等于下界 ✓

下界可达，所以它就是 R(D)。叫"反向"是因为：正向看这是 X̂ → X 的加噪信道（给定重建，信源是重建加噪声），与直觉的 X → X̂ 方向相反。它是证明可达性的数学道具，不代表编码器真的这么连。

数值例：σ² = 4 的两个点

Dσ²/DR(D) = ½log₂(σ²/D)
14½ × 2 = 1 bit
0.2516½ × 4 = 2 bit

规律：失真缩小到 1/4，码率多花 1 bit；等价地，D 每除以 2，R 增加 0.5 bit。这条斜率是所有有损编码器的"汇率表"。

⚠️ 反直觉点

D → 0 时 R(D) → ∞。连续信源的"无损"在数学上不存在：完美重建要求无穷码率。10.1 的定性直觉在这里变成了公式——不是工程做不到，是极限本身就是 ∞。

💡 直觉

把 ½log(σ²/D) 与第 9 章的 C = ½log(1+P/N) 并排看：σ²/D 是"信源功率对失真功率的比"，P/N 是"信号功率对噪声功率的比"。同一个 ½log 结构，一个度量"描述信源要多少比特"，一个度量"信道能搬多少比特"——10.4 会把它们焊在一起。

10.4与信道编码的对偶：分离定理把全书缝成一条链

到这里手里有两张牌：信源这头的 R(D)（本章）与信道那头的 C（第 7、9 章）。它们各管一段，能不能拼成端到端的完整通信链路？答案是信息论中最有建筑美的结果之一。

对偶：同一枚硬币的两面

信道容量 C率失真 R(D)

回答的问题这条信道最多能传多少这个信源最少要多少比特
💡 直觉

容量是"信道的计价"，率失真是"信源的标价"。通信可行的条件就是一句话：标价不超过计价，R(D) ≤ C。香农把端到端通信劈成两个独立的优化问题，中间只用这条不等式缝合。

✅ 信源信道分离定理（Source-Channel Separation Theorem）

点对点通信中，失真 D 可达 当且仅当 R(D) ≤ C。而且达到它的架构是两段式的：先用率失真码把信源压到 R(D) 比特/样本，再用信道码以不超过 C 的速率传输——两段分开设计，拼起来就是端到端最优。高斯情形解出显式公式：½log(σ²/D) = C ⟹ D_min = σ²·2−2C。

完整联合例：高斯信源过高斯信道（呼应第 9 章）

信源 X ~ N(0, 1)，即 σ² = 1；信道为 AWGN，P/N = 15。第 9 章算过这条信道的容量：

C = 12 log₂(1 + P/N) = 12 log₂ 16 = 2 bit/次

可达条件 R(D) ≤ C 即 ½log₂(1/D) ≤ 2，逐步解：

log₂(1/D) ≤ 4 ⟹ 1/D ≤ 16 ⟹ D ≥ 2−4 = 116
D_min = σ²·2−2C = 1 × 2−4 = 1/16 = 0.0625

惊人之处：高斯信源配高斯信道，逐个样本标量量化、逐个符号使用信道（不做长码字、不做联合编码）就能达到这个界——"高斯对高斯"是无失配最优的幸运配对。对一般信源与信道，逼近极限需要长码字（联合典型性），但"两段分开"的架构本身依然最优。

⚠️ 常见误区

"分离定理说信源编码和信道编码必须分开设计"——错。它说"分开设计不损失最优性"，是许可不是强制。另外两点别误读：①两段都必须各自逼近极限（用足 R(D) 与 C），随便拼两段并不最优；②分离结论一般只对点对点成立——第 15 章的网络场景中，联合设计可以严格胜过分离。

⚠️ 本章买下的账（通向第 11 章）

Bernoulli 与高斯是两个幸运的闭式解。一般信源的 R(D) 没有闭式，连数值计算都要专门算法；而"失真事件发生的概率随码长指数衰减得多快"这类问题，需要统计与大偏差工具——方法型（Method of Types）与 Sanov 定理。这正是第 11 章"信息论与统计"的开工理由。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
失真度量（Distortion Measure）
点击翻面 →
定义定义在（信源符号，重建符号）对上的非负函数 d(x,x̂)，量化"重建差多少"。
解决问题把"失真"从形容词变成可预算的数；没有它 R(D) 无从定义。
直觉给误差标价：每种误差花多少失真额度，明码标价。
误区以为失真度量天然唯一；它由应用选定，选错度量整个优化答错问题。
何时用本章全部；第 13 章通用编码也要在未知分布下控制失真。
概念卡 2
率失真函数 R(D)（Rate Distortion Function）
点击翻面 →
定义R(D) = min I(X;X̂)，对所有满足 E[d(X,X̂)] ≤ D 的试验信道取最小。
解决问题回答"允许失真 D 时最少多少比特/样本"——有损压缩的极限。
直觉失真预算换来的信息折扣曲线：D 越大，必须携带的信息越少。
误区当成 D 的增函数；恰好相反，它单调不增且凸。
何时用本章 10.2–10.4；评价任何有损编码器离极限多远。
概念卡 3
试验信道（Test Channel）
点击翻面 →
定义假想的条件分布 p(x̂|x)，描述信源如何变成重建；R(D) 在所有满足预算的试验信道上取最小。
解决问题把"设计压缩方案"变成"在分布空间里做优化"，可算可证。
直觉压缩器的心灵模型：假装信源过了一道我们自己选的噪声信道。
误区当成真实物理信道；它是优化变量，不是硬件。
何时用求 R(D) 的每一步；高斯情形的反向试验信道（概念卡 5）。
概念卡 4
高斯率失真 ½log(σ²/D)
点击翻面 →
定义X ~ N(0,σ²) 在平方误差下 R(D) = ½log₂(σ²/D)（0<D≤σ²），D ≥ σ² 时为 0。
解决问题连续信源唯一的闭式解，语音/图像编码的基准线。
直觉"信源失真比"取对数的一半，与容量 ½log(1+P/N) 完全同构。
误区以为 D→0 时 R 有限；R→∞，连续信源完美重建永远不可能。
何时用10.3 全部推导；10.4 与容量配对得 D_min = σ²·2−2C。
概念卡 5
反向试验信道（Backward Test Channel）
点击翻面 →
定义把 X 写成 X = X̂ + Z（X̂ ~ N(0,σ²−D)、Z ~ N(0,D) 独立），从重建端反写信源的构造。
解决问题正面猜 p(x̂|x) 很难；反向一写，边缘、失真、互信息三件事一眼可验。
直觉先造好成品再配原料：倒着设计，顺着验证。
误区以为编码器真按 X̂→X 方向工作；它只是证明可达性的数学道具。
何时用高斯 R(D) 可达性证明；第 15 章网络信息论中类似构造反复出现。
概念卡 6
信源信道分离定理（Source-Channel Separation Theorem）
点击翻面 →
定义点对点通信中失真 D 可达 ⟺ R(D) ≤ C；两段编码可分开独立设计而不失最优性。
解决问题把端到端通信设计劈成两个可独立攻克的子问题。
直觉比特是通用货币：信源换成比特，信道只管搬比特。
误区以为它说"必须分开"；它说"分开不亏"。多用户场景（第 15 章）分离会失效。
何时用10.4 联合例；一切数字通信系统的架构基石。

📝分层习题

L1 概念辨析判断并说明理由："率失真函数 R(D) 是 D 的增函数——允许的失真越大，需要的比特越多。"
提示

回到定义：D 出现在目标函数里还是约束里？约束放松时，一个最小化问题的值会怎么变？

完整解答

错，恰好相反。R(D) 是对可行集 {p(x̂|x) : E[d] ≤ D} 取 min。D 变大 ⇒ 可行集变大 ⇒ 最小值不变或变小，故 R(D) 单调不增。两个极端印证：高斯情形 D ≥ σ² 时 R = 0（直接重建均值）；Bernoulli 情形 D ≥ 1/2 时 R = 0。直觉：允许错得越多，需要记的越少。错误说法是把它和"质量随码率上升"的因果方向搞反了——是"预算松 ⇒ 需求降"，不是"失真大 ⇒ 比特多"。

L1 概念辨析判断并说明理由："Bernoulli(1/2) 信源在汉明失真下，R(0.5) = 0。"
提示

允许错一半时，完全不接收任何信息的"盲猜"方案能达到多少错误率？再代入 R(D) = 1 − H₂(D) 验证。

完整解答

对。代数上：R(1/2) = 1 − H₂(1/2) = 1 − 1 = 0。操作上：允许 50% 错误率时，接收方不看任何信息、恒输出常数（全 0 或全 1），由于信源本身均匀，期望错误率恰好 1/2，满足预算——所以一个比特都不用发。这正是"R(D) 单调不增到触地"的端点。

L2 手算推导Bernoulli(1/2) 信源、汉明失真。① 计算 H₂(0.1) 与 R(0.1)；② 计算 R(0.2)。（已知 log₂0.1 ≈ −3.3219，log₂0.9 ≈ −0.1520，log₂0.2 ≈ −2.3219，log₂0.8 ≈ −0.3219）
提示

先写 H₂(p) = −p·log₂p − (1−p)·log₂(1−p)，再用 R(D) = 1 − H₂(D)。两项分开算再相加。

完整解答

① H₂(0.1) = −0.1×(−3.3219) − 0.9×(−0.1520) = 0.3322 + 0.1368 = 0.4690 bit；R(0.1) = 1 − 0.4690 = 0.531 bit/样本。

② H₂(0.2) = −0.2×(−2.3219) − 0.8×(−0.3219) = 0.4644 + 0.2575 = 0.7219 bit；R(0.2) = 1 − 0.7219 = 0.2781 ≈ 0.278 bit/样本。

读数：失真预算从 0.1 放宽到 0.2，码率从 0.531 降到 0.278，几乎减半——再次印证 R(D) 随 D 递减且下弯（凸）。

L2 手算推导X ~ N(0, 4)，平方误差。① 求 R(1)；② 求 R(0.25)；③ 对 D = 1 写出反向试验信道，并验证方差分解 σ² = (σ²−D) + D。
提示

R(D) = ½log₂(σ²/D)。反向信道取 X̂ ~ N(0, σ²−D)、Z ~ N(0, D) 独立，X = X̂ + Z，用"独立高斯方差可加"验证。

完整解答

① R(1) = ½log₂(4/1) = ½ × 2 = 1 bit。

② R(0.25) = ½log₂(4/0.25) = ½log₂16 = ½ × 4 = 2 bit。

③ D = 1：取 X̂ ~ N(0, 3)，Z ~ N(0, 1)，独立，令 X = X̂ + Z。验证：Var(X) = Var(X̂) + Var(Z)（独立方可加）= 3 + 1 = 4 = σ² ✓；E[(X−X̂)²] = E[Z²] = 1 = D ✓；I(X;X̂) = h(X) − h(Z) = ½log(2πe·4) − ½log(2πe·1) = ½log 4 = 1 bit，与 ① 一致 ✓。三件事全对上，构造有效。

L3 建模应用无损音频存不下，要做有损语音编码。信源近似为高斯、方差 σ² = 4；听觉可容忍均方失真 D = 0.5；传输信道是 P/N = 15 的 AWGN。要求：① 写出 R(D) 与 C；② 判断该信道能否承载；③ 若用满信道，可达的最小失真是多少；④ 说明分离定理在此处的含义。
提示

R(D) = ½log₂(σ²/D)；C = ½log₂(1+P/N)；可达判据 R(D) ≤ C；用满信道时令 R(D) = C 解 D，即 D_min = σ²·2−2C。

完整解答

① R(0.5) = ½log₂(4/0.5) = ½log₂8 = ½ × 3 = 1.5 bit/样本；C = ½log₂(1+15) = ½log₂16 = 2 bit/次。

② 判据：1.5 ≤ 2 ✓，信道可以承载，还富余 0.5 bit。

③ 用满信道：D_min = σ²·2−2C = 4 × 2−4 = 4/16 = 0.25——比客户要求的 0.5 还好一倍，可以把音质再提一档。

④ 分离定理的含义：系统可拆成两段独立设计——先设计一个码率 1.5 bit/样本（或 2 bit/样本）的量化器达到失真 0.5（或 0.25），再独立设计一个速率接近 2 bit/次 的信道码逼近容量；两段拼起来即端到端最优，无需联合优化，两拨工程师可以并行开工。
