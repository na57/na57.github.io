11.1方法型：大数定律只管"平均"，我们问"涨落"

上一章率失真理论告诉我们：压缩得越狠，误差越大，但"误差超标的概率有多大"只在小节末尾给了一个指数估计，没有交代它从哪来。这类问题在统计里无处不在：样本均值偏到某个值以上的概率、检验中犯错的概率、罕见配置出现的概率。大数定律只说这些事会发生得越来越少，却不说少得多快。本章第一件工具回答"多快"：把序列按它的经验分布归档。

定义：设序列 xⁿ = (x₁,…,xₙ)，每个 xᵢ 取自有限字母表 𝒳。序列 xⁿ 的型（Type）是它的经验分布 Pxⁿ：对 a ∈ 𝒳，

Pxⁿ(a) = 1n ·（xⁿ 中 a 出现的次数）

二元字母表下，一个型就是"序列里 1 的比例"，例如 P = (0.7, 0.3)。所有型为 P 的序列组成的集合叫型类（Type Class），记作 T(P)。型类就是"换序不计"的同分布序列家族——它把 |𝒳|ⁿ 条序列按经验分布归拢成少量几堆。

✅ 方法型的三个核心事实

① 型的总数是多项式级：长度为 n 的不同型的个数 ≤ (n+1)|𝒳|（每个符号的计数取 0…n，共 |𝒳| 个符号，再扣掉"和为 n"的约束只会更少）。

② i.i.d. 序列的概率只依赖它的型：若 Xᵢ i.i.d. ~ Q，则 Q(xⁿ) = 2−n(H(P)+D(P‖Q))，其中 P 是 xⁿ 的型。同一型类里的每条序列概率完全相同。

③ 型类大小是指数级：2nH(P)/(n+1)|𝒳| ≤ |T(P)| ≤ 2nH(P)。

事实②的证明只要一行乘法：Q(xⁿ) = ∏i Q(xᵢ) = ∏a Q(a)nP(a) = 2n·Σ P(a) log Q(a)，再把指数里的 Σ P log Q 拆成 Σ P log(P·Q/P) = −H(P) − D(P‖Q)。注意这个恒等式：相对熵自己从计数里长出来了，不需要任何额外假设。

例 1：二元序列 n = 10，型 P = (0.7, 0.3) 的完整手算

第一步：型类大小。型由"1 的个数"唯一决定，10 个位置选 7 个放 1：

|T(P)| = C(10,7) = 10!7!·3! = 120

第二步：每条序列的概率。设真实分布 Q = (1/2, 1/2)，则任何一条 10 位序列概率都是 2−10。于是该型的总概率：

P(xⁿ 的型为 (0.7,0.3)) = 120 × 2−10 = 1201024 ≈ 0.117

第三步：用公式②③复核，看谁是大头。先算熵与相对熵（以 2 为底）：

  • H(P) = H₂(0.3) = −0.7·log₂0.7 − 0.3·log₂0.3 = 0.3602 + 0.5211 = 0.8813 bit
  • D(P‖Q) = log₂ 2 − H(P) = 1 − 0.8813 = 0.1187 bit

代入事实②：每条序列概率 = 2−10·(0.8813+0.1187) = 2−10 ✓（与第一步一致，公式自洽）。再合成型类概率：

|T(P)|·Q(xⁿ) ≈ 2nH(P) · 2−n(H(P)+D(P‖Q)) = 2−n·D(P‖Q) = 2−1.187 ≈ 0.44

精确值 0.117 与指数估计 0.44 之间差一个约 0.27 的因子——这正是事实③里被上界抹掉的多项式因子（本题实测 0.117/0.44 ≈ 0.27；定理的最粗下界只保证 ≥ 1/(n+1) = 1/11 ≈ 0.09，真实值介于其间）。结论：指数项 2−n·D 主导一切，多项式只是修正。这就是大偏差思想的全部骨架。

第四步：数型的个数。二元情形 k = 0,1,…,10 共 n+1 = 11 个型——对照粗界 (n+1)|𝒳| = 11² = 121，实际更省。11 个型瓜分 2¹⁰ = 1024 条序列，平均每堆近百条。

💡 关键一跃

把"序列"换成"型"来思考，就像把"每个学生的分数"换成"分数段人数分布"：个体有指数多个，分布形状却只有多项式种。于是任何关于序列的事件 = 若干型的并，而总概率 ≈ 最大那一堆的概率（指数上）——这直接把"罕见事件概率"变成"找最省力的那个罕见型"的优化问题，11.2 节就来解它。

⚠️ 常见误区

"型有指数多个"——错，恰相反。指数增长的是每个型类内部的序列数（≈ 2nH），型的种数只有 (n+1)|𝒳| 这个多项式。两个数量级张冠李戴，后面所有推导都会跟着错。

11.2Sanov 定理：罕见事件由"离真相最近的罕见分布"决定

上一节我们看到：一个型的概率 ≈ 2−n·D(P‖Q)。任何一个关于序列的事件 E——"样本均值 ≥ 4""某个字母占比异常"——都不过是若干型的并。由于型只有多项式种，E 的概率在指数尺度上由其中最大的那一型说了算：

P(经验分布落入 E) ≈ 2−n·D(P*‖Q)，其中 P* = argminP ∈ E D(P‖Q)

这就是Sanov 定理（Sanov's Theorem）的内容（严格版本要求 E 有一定正则性，例如闭包与内部指数相同；对一切"均值 ≥ 某值"类事件自动满足）。注意优化问题的形状：在约束集合 E 内，找离真分布 Q 最近（D 最小）的那个分布，它的距离就是罕见事件的概率指数。

💡 关键一跃：罕见事件以"最省力的方式"发生

要观察到一个均值偏高的样本，大自然不会乱来——它会把经验分布扭曲成刚好满足约束、且偏离 Q 最小的形状。好比逃课被抓概率最低的方案是"刚好凑够点名次数"，而不是全逃。Sanov 定理就是这条直觉的指数化：大数定律的精化版——不只说"会收敛"，还说"偏离的代价 = D，单位是每样本比特"。

例 2：均匀骰子，样本均值 ≥ 4 的指数（完整手算）

设 Q = 均匀六面骰（真均值 3.5），X₁,…,Xₙ i.i.d. ~ Q，问样本均值 ≥ 4 的概率指数。即 E = { P : Σᵢ i·Pᵢ ≥ 4 }，由 Sanov：

第一步：写出优化问题。P* = argmin D(P‖U)，约束 Σ i·Pᵢ ≥ 4。直觉上最优解会把约束用满（Σ i·Pᵢ = 4），因为再多偏离只会加大 D。

第二步：解的形状。对均匀 Q，D(P‖U) = log₂6 − H(P)，所以"min D(P‖U)"等价于"max H(P)"——在满足均值的分布里找熵最大的。拉格朗日乘子法给出解必为指数倾斜（Exponential Tilting）形式：

P*i = λiΣⱼ λj，i = 1,…,6，λ 由均值约束定

第三步：数值解。令均值 = 4 解得 λ ≈ 1.19，配分（分母）Σⱼ λj ≈ 13.40，于是：

i123456
P*i0.1030.1230.1460.1740.2070.246
Ui（对照）0.1670.1670.1670.1670.1670.167

验均值：1×0.103 + 2×0.123 + 3×0.146 + 4×0.174 + 5×0.207 + 6×0.246 ≈ 0.103+0.246+0.438+0.696+1.035+1.476 ≈ 4.00 ✓。倾斜分布只把概率质量平缓地推向大点数一侧——既不极端（没有全押在 6 上），又刚好达标，这就是"最省力"的具体长相。

第四步：算指数。H(P*) ≈ 2.523 bit，所以

D(P*‖U) = log₂6 − H(P*) = 2.585 − 2.523 = 0.062 bit/样本

n = 1000 次投掷时：P(均值 ≥ 4) ≈ 2−1000×0.062 = 2−62 ≈ 2.2×10−19。掷一千次骰子均值还站在 4 以上，概率约等于从地球上随机指定一粒沙——罕见得可以忽略，但我们精确知道它多罕见。

✅ 通往第 12 章的桥

注意第二步出现的事实：对均匀 Q，min D(P‖Q) 与 max H(P) 是同一个优化问题，解就是"满足约束的最少假设分布"。一般 Q 下解是指数倾斜族 P*_i ∝ Q_i·λ^i。这个"约束 + 最少假设 → 指数族"的形状在第 12 章（最大熵）会被当作主角专门研究。

⚠️ 常见误区

"Sanov 说罕见事件概率 ≈ 2−n·D(P*‖Q)，P* 是 E 中熵最大的分布"——半对。P* 的准确定义是 argmin D(·‖Q)；只有当 Q 均匀时它才等价于熵最大。Q 不均匀时，"离 Q 近"与"熵大"是两回事，解是一般的指数倾斜分布。把均匀情形的结论背成普适结论，是本节最常见的错误。

11.3假设检验：Neyman–Pearson 与 Chernoff 指数

Sanov 处理的是"一个真分布 Q，经验分布跑远了"的单边问题。统计里更常见的是两个候选分布对峙：X₁,…,Xₙ i.i.d.，要么来自 P₁（假设 H₁），要么来自 P₂（假设 H₂），要根据样本判决。两类错误各有身价：第一类错误 α = P₁ 为真却判 P₂（冤枉好人）；第二类错误 β = P₂ 为真却判成 P₁（放走坏人）。Neyman–Pearson 的经典方案是：先把 α 钉死在容忍线以下，再让 β 尽量小。

✅ Chernoff–Stein 引理

固定 α < ε（任意小正常数）后，最优检验的第二类错误按指数衰减：

βn ≈ 2−n·D(P₁‖P₂)。

注意方向：被约束的是 α，被优化的是 β，而指数由真分布 P₁ 对被拒分布 P₂ 的相对熵给出。D 的两个不对称自变量在这里第一次有了"岗位分工"。最优判决区域的形状正是对数似然比检验 log(P₁(xⁿ)/P₂(xⁿ)) > T——这等价于"经验分布离 P₁ 比离 P₂ 近"，与 11.2 的几何完全一致。

图 11.2 假设检验的决策链：似然比定判决，两类错误各管一头；对称化之后得到 Chernoff 信息。

如果两类错误要对称地一起压（贝叶斯总误差 P_e = π₁α + π₂β，先验 π 固定），最优指数不再是任何一个单边 D，而是二者的"中点"——Chernoff 信息（Chernoff Information）：

C(P₁,P₂) = −log₂ [ min0 ≤ λ ≤ 1 Σx P₁(x)λ · P₂(x)1−λ ]

贝叶斯总误差 P_e ≈ 2−n·C(P₁,P₂)。几何上，最优 λ* 对应的分布 Pλ* 恰好是"D(Pλ‖P₁) = D(Pλ‖P₂)"的那个等距点——两个世界的分界判官。当 λ = 1/2 时，求和项 Σ√(P₁P₂) 叫Bhattacharyya 系数（Bhattacharyya Coefficient），它度量两分布的重叠程度；重叠越小越好分。它是 C 的一个现成下界式近似，也是很多工程场合的默认选择。

例 3：公平硬币 vs 偏硬币（完整手算）

P₁ = (1/2, 1/2)（公平），P₂ = (3/4, 1/4)（偏向正面）。

第一步：两个方向的 D。

  • D(P₁‖P₂) = 0.5·log₂(0.5/0.75) + 0.5·log₂(0.5/0.25) = 0.5·log₂(2/3) + 0.5·log₂2 = −0.2925 + 0.5 = 0.2075 bit
  • D(P₂‖P₁) = 0.75·log₂(0.75/0.5) + 0.25·log₂(0.25/0.5) = 0.75·log₂1.5 + 0.25·(−1) = 0.4387 − 0.25 = 0.1887 bit

两者不相等——相对熵不对称，固定哪一类错误，指数就跟着哪边走。

第二步：求 Chernoff 信息。展开加权和（取 x = 正面项 + 反面项）：

f(λ) = (1/2)λ(3/4)1−λ + (1/2)λ(1/4)1−λ = (3/4)·(2/3)λ + (1/4)·2λ

对 λ 求导令零：f′(λ) = (3/4)·(2/3)λ·ln(2/3) + (1/4)·2λ·ln2 = 0，整理得 3λ = (3·ln(3/2))/ln2 ≈ 1.755，故 λ* = ln1.755/ln3 ≈ 0.512（几乎就是 Bhattacharyya 的 1/2）。代回：

  • f(λ*) = 0.75·(2/3)0.512 + 0.25·20.512 ≈ 0.75×0.8128 + 0.25×1.4261 ≈ 0.6096 + 0.3565 = 0.9659
  • C = −log₂0.9659 ≈ 0.050 bit/样本（Bhattacharyya 近似：f(1/2) ≈ 0.9660，几乎一样）

第三步：落成错误概率。n = 100 次抛掷，P_e ≈ 2−100×0.050 = 2−5 ≈ 3%。要再降一个数量级，大约需要 n ≈ 200——指数的好处是"加样本"与"降错误"是线性兑换。

⚠️ 常见误区

"Chernoff–Stein 的指数用 D(P₂‖P₁) 还是 D(P₁‖P₂)，反正差不多"——在本例 0.2075 与 0.1887 确实接近，但原则完全不同：指数的方向由"谁为真时犯的错误被优化"唯一决定。本例若 P₁、P₂ 差距拉大（如 (0.9,0.1) 对 (0.1,0.9)），两个方向的 D 会同样拉大差距吗？不会——不对称性可以非常显著，选错方向等于报错所需样本量。

C(P₁,P₂) = −log min_{0≤λ≤1} Σ P₁^λ·P₂^(1−λ)，P_e ≈ 2^(−nC)。λ = 1/2 时求和项 Σ√(P₁P₂) 是 Bhattacharyya 系数，度量两分布的重叠程度。

11.4收束与桥梁：相对熵从抽象量变成可操作的"涨落指数"

第 2 章引入相对熵 D(P‖Q) 时，它只是一个"两个分布差多少"的抽象度量——非负、不对称、不满足三角不等式。经过本章，它有了精确的操作意义：D 是偏离的单价，单位是每样本比特。回头看三件工具，它们共享同一个形状：

工具回答的问题指数最优分布的形状
方法型（11.1）一个特定经验分布出现多频繁D(P‖Q)（含多项式修正）就是 P 本身
Sanov 定理（11.2）落入集合 E 的概率多小minP∈E D(P‖Q)指数倾斜 P*_i ∝ Q_i·λ^i
Chernoff 指数（11.3）区分 P₁ 与 P₂ 的错误多小D(P₁‖P₂) 或 C(P₁,P₂)指数倾斜族 Pλ ∝ P₁^λ·P₂^(1−λ)

三处答案都是"在约束下最小化 D(P‖Q)"的分布；而当先验 Q 均匀时，它恰好就是"满足约束的最大熵分布"。这不是巧合：最大熵原则本来就是"最少意外"原则的概率化。第 12 章将把这个反复出现的解的形状立为主角——给定若干矩约束，熵最大的分布族（指数族）长什么样、怎么求、凭什么它是"最少假设"的推断。

💡 本章在全书中的位置

第 10 章问"误差指标的罕见超标多罕见"，本章给了通用的估算器；第 13 章通用信源编码里"未知分布下的冗余"，分析方法型的变种仍是主力；第 17 章不等式里 D 继续扮演通用"距离"。本章是把第 2 章的定义变成计算工具的那座桥。

⚠️ 常见误区

"大偏差只适用于 i.i.d. 样本均值"——方法型 + Sanov 处理的是整个经验分布的偏差，比"均值"宽得多：任何能写成"经验分布落在某集合"的事件都在射程内。但注意前提确实是 i.i.d.（或稍加推广的平稳遍历）；相关序列的大偏差需要第 4 章熵率的思想另行推广。

📝分层习题

L1 概念辨析判断对错："型的总数随 n 指数增长，所以方法型只适合小样本。"说明理由。
提示

型的总数有上界 (n+1)|𝒳|——这是 n 的几次方？指数增长的究竟是哪个量？

完整解答
错。型的总数 ≤ (n+1)|𝒳|，只是 n 的多项式（次数固定为 |𝒳|）。真正指数增长的是每个型类内部的序列数 |T(P)| ≈ 2nH(P)。这个"多项式种型 × 指数大类"的不对称正是方法型全部威力的来源：因为型少，"最大那一型"才能在指数尺度上代表整个事件；若型有指数多种，Sanov 型论证直接失效。所以方法型恰恰是为大样本渐近分析而生的。
L1 概念辨析判断对错："Sanov 定理说罕见事件的概率约等于 2−n·D(P*‖Q)，其中 P* 是 E 中熵最大的分布。"
提示

P* 的定义是什么？D(P‖Q) 在什么特殊情形下变成 log|𝒳| − H(P) 这种只含熵的形式？

完整解答
半对。P* 的准确定义是 argminP∈E D(P‖Q)。只有当 Q 是均匀分布时，D(P‖U) = log₂|𝒳| − H(P)，此时"离 U 最近"⟺"熵最大"，命题才成立。对一般的 Q，D(P‖Q) = Σ P log(P/Q) 里 Q 的形状参与加权，最优解是指数倾斜分布 P*_i ∝ Q_i·λ^i，一般既不是熵最大、也不在 E 的"熵意义中心"。把特例当通例会导致对非均匀先验的问题给出错误指数。
L2 手算推导二元序列 n = 10、型 P = (0.7, 0.3)、真分布 Q = (1/2, 1/2)。手算：①|T(P)|；②该型的精确概率；③指数近似 2−n·D(P‖Q)，并指出与精确值的差是什么因子。
提示

①用组合数；②同一型类每条序列概率相同；③先算 H₂(0.3) 与 D = 1 − H₂(0.3)，再比较。

完整解答

① |T(P)| = C(10,7) = 10!/(7!·3!) = (10×9×8)/(3×2×1) = 120。

② 每条序列概率 = 2−10（用公式验：H(P) = 0.8813，D(P‖Q) = 0.1187，H + D = 1 ⟹ Q(xⁿ) = 2−10 ✓）。型概率 = 120 × 2−10 = 120/1024 ≈ 0.117。

③ 2−n·D = 2−10×0.1187 = 2−1.187 ≈ 0.44。比值 0.117/0.44 ≈ 0.27，即被 |T(P)| ≤ 2nH 上界抹掉的多项式修正因子（最粗下界给出 ≥ 1/(n+1) = 1/11 ≈ 0.09）。指数项主导、多项式修正——大偏差骨架。

L2 手算推导P₁ = (1/2, 1/2)、P₂ = (3/4, 1/4)。手算：①D(P₁‖P₂) 与 D(P₂‖P₁)；②Chernoff 信息 C(P₁,P₂)（求出 λ*）；③n = 100 时的贝叶斯总误差量级。
提示

②设 f(λ) = (3/4)(2/3)λ + (1/4)2λ，对 λ 求导令零，整理出关于 3λ 的方程。

完整解答

① D(P₁‖P₂) = 0.5·log₂(2/3) + 0.5·log₂2 = −0.2925 + 0.5 = 0.2075 bit；D(P₂‖P₁) = 0.75·log₂1.5 + 0.25·log₂0.5 = 0.4387 − 0.25 = 0.1887 bit。

② f′(λ) = 0 ⟹ (1/4)·2λ·ln2 = (3/4)·(2/3)λ·ln(3/2) ⟹ 3λ = 3·ln(3/2)/ln2 ≈ 1.755 ⟹ λ* ≈ 0.512。f(λ*) ≈ 0.75×0.8128 + 0.25×1.4261 ≈ 0.9659，C = −log₂0.9659 ≈ 0.050 bit。（Bhattacharyya 特例 f(1/2) ≈ 0.9660，几乎相同。）

③ P_e ≈ 2−100×0.050 = 2−5 ≈ 3%。

L3 建模应用质检场景：某工厂产线"正常"时次品率 10%，"异常"时次品率 30%。抽检 n 件产品（好/坏二元），要区分 P₁ = (0.9, 0.1)（正常）与 P₂ = (0.7, 0.3)（异常）。①映射为假设检验问题；②算 D(P₁‖P₂) 与 D(P₂‖P₁)；③管理要求"冤枉正常产线"（第一类错误）必须卡死，问 n 多大才能让"放走异常"（第二类错误）β ≤ 10−6；④说明第③问里为什么用 D(P₁‖P₂) 而不是 D(P₂‖P₁)。
提示

①Xi ∈ {好, 坏} i.i.d.，H₁: X ~ P₁，H₂: X ~ P₂。③用 Chernoff–Stein：β ≈ 2−n·D，反解 n；注意 10−6 = 2−19.93。④回到"约束加在哪个错误上"。

完整解答

① 二元假设检验：抽检序列 xⁿ ∈ {好,坏}ⁿ，H₁: i.i.d. ~ P₁ = (0.9, 0.1)，H₂: i.i.d. ~ P₂ = (0.7, 0.3)。判决用对数似然比检验。

② D(P₁‖P₂) = 0.9·log₂(0.9/0.7) + 0.1·log₂(0.1/0.3) = 0.9×0.3626 + 0.1×(−1.585) = 0.3263 − 0.1585 = 0.1678 bit；D(P₂‖P₁) = 0.7·log₂(0.7/0.9) + 0.3·log₂(0.3/0.1) = 0.7×(−0.3626) + 0.3×1.585 = −0.2538 + 0.4755 = 0.2217 bit。

③ 由 Chernoff–Stein，固定 α 后 β ≈ 2−n·D(P₁‖P₂) = 2−0.1678n。要求 2−0.1678n ≤ 10−6 ⟺ 0.1678n ≥ 6·log₂10 ≈ 19.93 ⟹ n ≥ 119（约 119 件抽检）。

④ 方向由 Chernoff–Stein 引理唯一决定：约束加在第一类错误 α（冤枉正常产线，即 P₁ 为真时犯错）上，被优化的是第二类错误 β，其指数是 D(真分布 P₁ ‖ 被拒分布 P₂)。若误用 D(P₂‖P₁) = 0.2217，会得出 n ≥ 90 的乐观估计——实际抽检 90 件达不到 β ≤ 10−6 的承诺，质检标准将被虚报。
