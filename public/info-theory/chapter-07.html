7.1什么是信道容量：从"每次使用能穿过多少信息"说起

第 5 章兑现了第一个承诺：无噪声时，数据可以压到熵 H 比特/符号。但真实的信道有噪声——第 1 章例 2 里那条翻转概率 0.1 的二元信道还欠着一笔账：当时我们用"重复三遍取多数"换来 0.028 的错误率，代价是速率只剩 1/3；而香农声称这条信道能以 0.531 比特/次的正速率做到错误任意小。本章就是兑现这个声称。

先把信道说精确。本章研究的是离散无记忆信道（Discrete Memoryless Channel, DMC）：输入 X 取自离散字母表 𝒳，输出 Y 取自离散字母表 𝒴，"无记忆"指每次使用时输出只由当次输入决定，完全由一张转移矩阵 p(y|x) 刻画——信道的全部脾气都在这张表里。

转移矩阵 p(y|x)"] C --> Y["输出 Y
取自字母表 𝒴"] classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#c4651f; class C hot;
图 7.1 离散无记忆信道：每次使用独立地按 p(y|x) 把 X 变成 Y。我们控制不了信道，只能控制怎么用它。

信道给定后，一次使用能"穿过"多少信息？第 2 章已给了量具：互信息 I(X;Y)——知道输出 Y 后，关于输入 X 的不确定性减少了多少。用熵的分解式读它：

I(X;Y) = H(Y) − H(Y|X)

读法：输出端一共有 H(Y) 比特的不确定性，其中 H(Y|X) 比特是信道噪声自己制造的（给定输入后输出还在抖），减掉它，剩下的才是真正"从输入穿过来的"部分。噪声吃掉了 H(Y|X)，剩下的是可穿过部分。

注意 I(X;Y) 由两样东西共同决定：信道表 p(y|x)（我们不能调）和输入分布 p(x)（我们可以调）。发端用均匀分布还是用偏斜分布，穿过来的信息量不同。把输入分布调到最优，穿过去的最大信息量就是这条信道的本事上限：

✅ 定义：信道容量（Channel Capacity）

C = maxp(x) I(X;Y)，单位比特/次。它是"对所有输入分布取最优后，每次使用信道最多能穿过的信息"。容量只由信道转移矩阵 p(y|x) 决定，是信道本身的属性，与我们实际采用哪种编码无关。

这个最大值一定存在吗？存在，而且好求。Ch2 证明过 I(X;Y) 固定 p(y|x) 时是 p(x) 的凹函数——一个定义在概率单纯形（凸集）上的凹函数必有最大值，且可用凸优化（如 Blahut–Arimoto 迭代算法）数值求解。所以"取最大"不是修辞，是一个可以真正算出来的数。

💡 关键一跃

信道像一根有漏的水管：H(Y) 是出口的总水量，H(Y|X) 是管壁渗漏混入的杂水，I(X;Y) 是从入口真正流到出口的净水。我们唯一能动的是入口的"注水方式" p(x)；调到最优，净水流量就是 C。本章后面四节要回答：C 怎么算、能不能达到、为什么超不过。

⚠️ 常见误区

"容量是我们当前编码方案的实际速率"——错。C 是对所有输入分布取最大后的理论上限，是信道属性。实际方案速率可以远低于 C（重复码在 BSC(0.11) 上速率只有 0.2）；反过来，任何方案都不可能稳定地超过 C（7.4 节证明）。

7.2三个信道的容量怎么算：手算 BSC 与 BEC

上一节给出了 C 的定义，但它能不能真的算出来？这一节把三条经典信道从头算到尾，一步不跳。算完你会看到：容量的形状完全由"噪声怎么捣乱"的方式决定。

例 1：无噪声二元信道——先校准一下定义

Y = X，收到什么就是发了什么。此时 H(Y|X) = 0（给定输入输出不再有不确定性），所以

I(X;Y) = H(Y) − H(Y|X) = H(X) − 0 = H(X) ≤ 1

等号在输入均匀（p(x) = (1/2, 1/2)）时取得。故 C = 1 比特/次——无噪声二元信道每次使用恰好传 1 比特，与直觉吻合，定义通过第一关。

例 2：二元对称信道 BSC(p)——完整推导

二元对称信道（Binary Symmetric Channel, BSC）：输入输出都是 {0,1}，无论发什么，都以概率 p 被翻转、以 1−p 原样到达。

flowchart LR X0["发 0"] -- "1−p" --> Y0["收 0"] X0 -- "p" --> Y1["收 1"] X1["发 1"] -- "p" --> Y0 X1 -- "1−p" --> Y1 classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#c4651f; class X0,X1 hot;
图 7.2 二元对称信道 BSC(p)：两条交叉边是出错路径，各带概率 p。

用 I(X;Y) = H(Y) − H(Y|X) 分两步算：

第一步：算 H(Y|X)。给定 X = 0，输出是以概率 p 翻转的伯努利变量，熵为 H(p)（二元熵函数，Ch2 定义）；给定 X = 1，对称地也是 H(p)。无论输入是什么，输出条件熵都是翻转动作本身的不确定性 H(p)：

H(Y|X) = p(0)·H(p) + p(1)·H(p) = H(p)

第二步：最大化 H(Y)。Y 是二元变量，H(Y) ≤ 1，等号当且仅当输出均匀。取输入均匀 p(x) = (1/2, 1/2)，则 P(Y=0) = ½(1−p) + ½p = ½，输出恰好也均匀，等号达到。合起来：

C = max I(X;Y) = 1 − H(p)　　BSC 的容量

数值代入 p = 0.11（Cover 书上的经典数字）：查 log₂(1/0.11) = 3.1844，log₂(1/0.89) = 0.1681：

H(0.11) = 0.11×3.1844 + 0.89×0.1681 = 0.3503 + 0.1496 = 0.4999 ≈ 0.5 比特
C = 1 − 0.5 = 0.5 比特/次

翻译：翻转率 11% 的信道，每次使用还能可靠穿过约半比特——噪声吃掉了恰好一半。对比第 1 章 p = 0.1 时 C ≈ 0.531，口径一致。

例 3：二元删除信道 BEC(α)——换一条展开式

二元删除信道（Binary Erasure Channel, BEC）：输入 {0,1}，输出 {0, 1, e}。比特以概率 1−α 原样到达，以概率 α 被"擦除"成 e——收方知道自己这一位丢了（类比网络丢包，与 BSC 的"悄悄翻转"不同）。

flowchart LR X0["发 0"] -- "1−α" --> Y0["收 0"] X0 -- "α" --> YE["收到 e"] X1["发 1"] -- "α" --> YE X1 -- "1−α" --> Y1["收 1"] classDef danger fill:#fae9e7,stroke:#b03a2e,stroke-width:2.5px,color:#b03a2e; class YE danger;
图 7.3 二元删除信道 BEC(α)：出错不是翻转而是"这一位没了"，e 节点（红色）收集所有擦除。

这次用另一条展开式 I(X;Y) = H(X) − H(X|Y) 更顺手（谁好算就用谁）：

算 H(X|Y)：给定 Y，分三种情况。Y = 0：X 必为 0，条件熵 0；Y = 1：同理为 0；Y = e（发生概率 α）：X 完全未知，条件熵 = H(X)。于是

H(X|Y) = (1−α)·0 + α·H(X) = αH(X)
I(X;Y) = H(X) − αH(X) = (1−α)·H(X) ≤ 1−α

等号在输入均匀（H(X) = 1）时达到：

C = 1 − α　　BEC 的容量；数值：α = 0.25 → C = 0.75 比特/次
💡 直觉对比：擦除 vs 翻转

删除信道的容量按可用比例线性缩减：擦除不误导你，只是"这次白用"，所以 α = 0.25 时恰好保住 3/4。BSC 的惩罚是非线性的 H(p)：p = 0.11 的小翻转就吃掉一半容量（H(0.11) ≈ 0.5 ≫ 0.11），因为翻转的错误会混在正确比特里骗人。同样是噪声，"明说丢了"远比"悄悄搞错"仁慈。

信道噪声方式容量 C最优输入直觉
无噪声二元信道无（Y = X）1均匀每次恰好一比特
BSC(p)以 p 悄悄翻转1 − H(p)均匀翻转的不确定性 H(p) 被吃掉
BEC(α)以 α 擦除为 e1 − α均匀擦除比例线性缩减
⚠️ 常见误区

"BSC 里 p 越小 H(p) 越小，那 p = 0.5 时 C = 1 − 1 = 0 是不是算错了？"——没错，这正是要害：p = 0.5 时输出与输入统计独立，信道彻底报废，容量为 0。另一个易错方向：以为 p > 0.5 的信道没用——其实收方把输出全部翻转，就等效于 BSC(1−p)，容量是 1 − H(p) = 1 − H(1−p) 仍然为正。

7.3可达性：随机码 + 联合典型译码为什么行

上一节算出了 C，但"定义的上限"不等于"能达到的速率"。信道编码定理的可达半边说：只要 R < C，就存在速率为 R、错误率任意小的编码。香农的证明思路当时震惊了整个领域：不构造具体码，而是证明"随机抽一个码几乎必然是好码"。三步骨架如下。

第一步：随机编码——好码满地都是

要传速率 R（比特/次），用 n 次信道，则消息共有 2nR 个，需要一本 2nR 行的码本（Codebook），每行是一个长为 n 的码字。随机编码（Random Coding）：码本的每个符号独立地按最优输入分布 p(x) 抽取（使 I 达到 C 的那个分布）。

💡 类比：往高维空间撒点

所有长为 n 的输入序列约 2nH(X) 条典型序列（Ch3 的 AEP），而信道输出端能区分的"桶"约 2nH(Y) 个。随机撒 2nR 个码字进去，只要撒的点数远少于桶数（2nR ≪ 2nI 量级的间隔），点与点自动离得远远的——不是精心设计的距离，是高维空间的空旷白送的。

第二步：联合典型译码——找唯一对得上的码字

收到输出序列 yⁿ 后，译码器在码本里查找：是否存在唯一一个码字 xⁿ(w)，使得 (xⁿ(w), yⁿ) 联合典型（Jointly Typical，Ch3：两者的联合经验分布接近 p(x,y)）。有唯一解就译作 w，否则宣布译码错误。

第三步：错误分析——两类错误都被按住

  1. 正确码字不联合典型：由 AEP（Ch3），(Xⁿ, Yⁿ) 联合典型的概率随 n 趋向 1，这类错误概率 → 0；
  2. 某个错误码字撞上联合典型：随机码本里另一个码字与 yⁿ 是独立抽取的，它俩恰好联合典型的概率 ≈ 2−nI(X;Y)。竞争者共 2nR − 1 个，用联合界：
Pe ≲ 2nR · 2−nI(X;Y) = 2n(R − I(X;Y))

只要 R < I(X;Y)（取最优输入即 R < C），指数是负的，错误率随 n 指数趋向 0。数值感：n = 1000、R − C = −0.1 时，错误率量级 2−100 ≈ 10−30——比"硬盘被陨石击中"还稀有。

最后一步逻辑很香农：随机码的平均错误率都这么小，那么至少存在一本具体的码错误率同样小（平均值小 ⟹ 存在不高于平均的个体）。证明完成，而我们甚至不知道那本好码长什么样。

💡 为什么不用重复码？

重复码把 1 比特当 n 比特用，速率 1/n → 0——用速率归零换可靠。随机码把 nR 比特装进 n 次信道使用，速率保持正的，靠"码长 n 拉大"换取错误率指数下降。同样用 n 次信道，一个速率归零、一个速率贴着 C，差别全在码字是"同一比特的拷贝"还是"在高维空间里撒开的点"。

⚠️ 常见误区

随机码是存在性证明，不是工程方案：随机码本需要指数级存储，译码要逐条比对 2nR 个码字，根本无法实现。但定理指明了方向——结构化的好码真的存在：LDPC 码（1962 年被遗忘、1990 年代复兴）和 Polar 码（Arıkan 2009 年证明在二元删除/对称信道上可达容量）都实实在在逼近了 C。香农给的是地图，后人修出了公路。

7.4逆定理：为什么超过 C 一定失败（Fano 不等式）

可达半边说 R < C 行。现在要把门从另一边焊死：R > C 时，任何编码方案的错误率都有正的下界。注意"任何方案"——不只是重复码、不只是已知技术，而是过去未来一切可能的方案。这种全称否定靠什么工具？靠一条把"猜错概率"与"条件熵"绑在一起的不等式。

✅ Fano 不等式（Fano's Inequality）

由 Ŷ 估计 X 的错误概率为 Pe，则 H(X|Ŷ) ≤ 1 + Pe·log|𝒳|。对 M 个等概消息 W 的传输：H(W|Ŵ) ≤ 1 + Pe·log M。读法：猜错之后剩下的不确定性，最多是"错没错"这 1 比特加上"在 M 个候选里挑错的那一个"的 log M 比特（加权 Pe）。

推导骨架（不写全，只看清两步展开）：定义错误指示变量 E（E=1 当 Ŵ ≠ W）。一方面 H(E, W|Ŵ) = H(W|Ŵ)（知道 W 和 Ŵ 就知道 E，E 是免费附带）；另一方面按链式法则展开 H(E, W|Ŵ) = H(E|Ŵ) + H(W|Ŵ, E) ≤ 1 + Pe·log M——第一项是二元熵 ≤ 1，第二项中 E=0 时 W 已知（熵 0）、E=1 时 W 至多在 M 个值里（熵 ≤ log M，以概率 Pe 加权）。两步一夹，Fano 得证。

逆定理链条：设速率 R 的码以任意小错误率 Pe → 0 传输等概消息 W（共 2nR 个）。逐环推进：

nR = H(W) = I(W;Yⁿ) + H(W|Yⁿ)
≤ I(Xⁿ;Yⁿ) + nεn
≤ nC + nεn

三个环节各司其职：

  • 第一环：W 在 2nR 个消息上等概，H(W) = nR；再用熵分解 I + H(·|·)（Ch2）。
  • 第二环：Fano 给出 H(W|Yⁿ) ≤ 1 + Pe·nR =: nεn，Pe → 0 时 εn → 0；而 W → Xⁿ → Yⁿ 是马尔可夫链，数据处理不等式（Data Processing Inequality，Ch2）给出 I(W;Yⁿ) ≤ I(Xⁿ;Yⁿ)——消息经过编码、信道两级加工，信息只减不增，Ch2 的工具在这里顶上了用场。
  • 第三环：无记忆性使 I(Xⁿ;Yⁿ) ≤ Σi I(Xi;Yi) ≤ nC——n 次使用一条无记忆信道，总互信息超不过 n 次各用容量之和（每次使用之间不互相创造信息）。

除以 n：R ≤ C + εn，令 Pe → 0 得 R ≤ C。焊死。与 7.3 节合并，就是完整的信道编码定理：R < C 可达，R > C 不可达，C 是精确的分界线。

💡 关键一跃

逆定理的美感在于：它没有分析任何具体编码方案，只用三条普适原理（熵分解、Fano、数据处理）就把"所有方案"一网打尽。这正是极限定理的力量——第 5 章压缩定理的逆半边是同一种打法。

⚠️ 常见误区

"逆定理只是说目前的工程技术做不到 R > C，将来也许行"——错。它是数学定理：对一切满足定义的编码方案（包括还没发明的）都成立，超 C 必有不可压制的错误概率。它锁死的是信息本身，不是工艺水平。

7.5两个加深：反馈为何不增容、信源信道为何能分离

定理证完了，但两个自然的追问值得各给一段：如果发方能"回头看"收方收到了什么，能不能传得更快？压缩（Ch5）和信道编码（本章）分开各自最优，拼起来还最优吗？

反馈：不增容，但有用

反馈（Feedback）指发第 i 位之前，发方能先看到历史输出 Y₁,…,Yi−1（电话里的"喂，你听到了吗"）。直觉上这应该有帮助——但定理说：

✅ 定理（反馈不增容）

对离散无记忆信道，反馈容量 CFB = C。证明要点：即使有反馈，逆定理链条中 I(W;Yⁿ) 仍可按无记忆性拆开，逐次使用 I(Xi;Yi) ≤ C 求和，故 I(W;Yⁿ) ≤ Σi I(Xi;Yi) ≤ nC 依旧成立——反馈改变不了单次使用的互信息上限。

那反馈有什么用？降低复杂度。例子：删除信道 BEC(α) 上，有反馈时策略朴素到可笑——发一个比特，若被擦除（发方从反馈里看到 e）就重发，直到收到为止。平均每个比特用 1/(1−α) 次信道，速率恰好 1−α = C，连编码都不需要。同样的容量，无反馈要靠长随机码逼近，有反馈一个"重传协议"就达到了。反馈买不到更高的速率，但买到了简单。

⚠️ 别把结论用过头

"反馈不增容"只对无记忆信道成立。信道有记忆（如突发错误、衰落信道）时，反馈让发方能探测信道状态、避开坏时段，容量可以严格增大。结论的边界和结论本身一样重要。

信源信道分离：数字世界的分层宪法

要把一份数据（如照片）经噪声信道传走，工程上的做法是两段式：先用 Ch5 的办法压缩到约 H 比特/符号，再用本章的办法按约 C 比特/次编码传输。信源信道分离定理（Source-Channel Separation Theorem）说：当速率匹配（每秒产生的 H 不超过每秒可用的 C）时，两段各自独立最优，合起来就是整体最优——联合设计一套"压缩-信道一体化"编码也超不过这个组合。

💡 为什么这条定理是架构基石

它意味着数字系统可以分层设计：压缩工程师只管逼近 H，通信工程师只管逼近 C，两层之间只传干净的比特流，互不打扰。今天你手机里的 JPEG 压缩、5G 的 LDPC/Polar 信道码就是这样各干各的——整个数字通信架构的理论基石，就是这条"分离不亏"的定理。它也解释了为什么 Ch5 与本章可以分开学。

章末点账：本章的边界在哪

本章的一切都是离散输入、离散输出。可真实物理信道的输入是连续电压、噪声是高斯分布——𝒳 不再有限，H(X) 发散，整个框架需要连续版的熵。这正是下一步：Ch8 定义微分熵（Differential Entropy）并校准它与离散熵的差异，Ch9 用它推出高斯信道的容量公式 C = ½log(1 + SNR)——通信工程里出现频率最高的一个公式。

概念卡 1
信道容量（Channel Capacity）
点击翻面 →
定义C = maxp(x) I(X;Y)，信道每次使用最多能可靠穿过的比特数。
解决问题回答"噪声信道上可靠传输的速率极限在哪"：R < C 可达，R > C 不可能。
直觉漏水水管的净水流量上限——噪声吃掉 H(Y|X)，最优注水方式下剩多少是多少。

概念卡 2
二元对称信道（Binary Symmetric Channel）
点击翻面 →
定义输入输出 {0,1}，每位以概率 p 被悄悄翻转的 DMC；C = 1 − H(p)。
解决问题最经典的噪声模型：bit 翻转类信道（存储、传输误码）的默认抽象。
直觉每次使用都被噪声吃掉 H(p) 比特，剩下的才是你的。
误区以为 p > 0.5 就没用——收方翻转输出等效 BSC(1−p)，容量照样 1 − H(p) 为正。
何时用容量推导的第一个非平凡例子；LDPC/Polar 码分析的基准信道。
概念卡 3
二元删除信道（Binary Erasure Channel）
点击翻面 →
定义输出 {0,1,e}：比特以概率 α 被擦除为 e（收方知丢），C = 1 − α。
解决问题建模"丢包"型信道：错了不如明说没了的场景（网络丢包、深空弱信号）。
直觉擦除不误导，只是"这次白用"，容量按可用比例线性缩减。
误区与 BSC 混淆——翻转是"悄悄骗你"，擦除是"明说丢了"，后者温和得多。
何时用喷泉码/纠删码的理论底座；反馈下"重发即达 C"的示例信道。
概念卡 4
联合典型译码（Jointly Typical Decoding）
点击翻面 →
定义收 yⁿ 后，在码本中找唯一与 yⁿ 联合典型的码字作为译码结果。
解决问题给可达性证明一个可分析的译码规则：错误概率可用 AEP 逐类估界。

📝分层习题

L1 概念辨析判断对错：信道容量依赖于我们实际使用的输入分布，换一种输入分布容量就变了。说明理由。
提示

回到定义：C 的表达式里 max 是对什么取的？改变实际输入分布改变的是 I(X;Y) 还是 C？

完整解答
错。C = maxp(x) I(X;Y) 是对所有输入分布取最优后的结果，只由信道转移矩阵 p(y|x) 决定，是信道自身属性。换实际输入分布改变的是实际获得的 I(X;Y)（可以低于 C），容量本身纹丝不动——就像水管的最大流量不因你今天接的是细龙头而改变。
L1 概念辨析判断对错：反馈能让发方回看输出，所以反馈信道的容量严格大于无反馈容量。
提示

7.5 节的定理对哪类信道成立？它的边界在哪一类信道上会被打破？

完整解答
错。对离散无记忆信道，CFB = C——无记忆性使 I(W;Yⁿ) ≤ Σ I(Xi;Yi) ≤ nC 在反馈下依然成立。反馈的收益是降低编码复杂度（如 BEC 上"擦除就重发"即达 C），不是提高容量。只有在有记忆信道上（可借反馈探测信道状态），反馈才可能严格增容——结论的边界要一并记住。
L2 手算推导BSC(p = 0.2)：(a) 手算 H(0.2) 与容量 C（log₂(1/0.2) = 2.3219，log₂(1/0.8) = 0.3219）；(b) 计算"重复 5 次多数表决"方案的错误率与速率；(c) 对比说明差距。
提示

(b) 错在 5 次中翻转 ≥ 3 次：Pe = C(5,3)p³(1−p)² + C(5,4)p⁴(1−p) + p⁵。

完整解答

(a) H(0.2) = 0.2×2.3219 + 0.8×0.3219 = 0.4644 + 0.2575 = 0.7219 比特；C = 1 − 0.7219 = 0.278 比特/次。

(b) 错误率：C(5,3)×0.2³×0.8² = 10×0.008×0.64 = 0.0512；C(5,4)×0.2⁴×0.8 = 5×0.0016×0.8 = 0.0064；0.2⁵ = 0.0003。合计 Pe = 0.0512 + 0.0064 + 0.0003 = 0.0579。速率 = 1/5 = 0.2 比特/次。

(c) 重复码用 0.2 的速率仍残留 5.79% 的错误；而定理保证存在速率任意接近 0.278 且错误任意小的码。继续加大重复次数，错误率下降但速率同步归零——重复码永远够不到"正速率 + 任意小错误"的组合。

L2 手算推导BEC(α = 0.3)：(a) 写出容量；(b) 输入均匀时完整计算一遍 I(X;Y)：H(X)、H(X|Y)、I 各是多少；(c) 回答：为什么 BEC 和 BSC 的最优输入都是均匀分布？
提示

(b) 用 I = H(X) − H(X|Y)，按 Y 的三种取值拆开 H(X|Y)；(c) 想"对称"二字：信道对两个输入完全一视同仁时，输入分布该怎样才不被浪费。

完整解答

(a) C = 1 − α = 0.7 比特/次。

(b) 输入均匀：H(X) = 1。H(X|Y)：Y=0（概率 0.7×½… 直接用全概率）——Y=0 时 X 确定为 0，熵 0；Y=1 时熵 0；Y=e（概率 0.3）时 X 完全未知，熵 = H(X) = 1。故 H(X|Y) = 0.3×1 + 0.7×0 = 0.3，I(X;Y) = 1 − 0.3 = 0.7 比特 = C。

(c) 两条信道都输入对称：对换 0 与 1 的角色，信道行为完全不变（BSC 翻转概率不区分输入，BEC 擦除概率也不区分）。对称信道的 I(X;Y) 在均匀输入处达到最大——任何偏斜都白白降低 H(X) 或 H(Y) 而换不到补偿，所以最优输入是均匀分布。

L3 建模应用深空探测器下行链路可建模为 BSC(p = 0.05)，每秒可使用信道 10⁶ 次。(a) 可靠传输的速率上限是多少比特/秒（log₂(1/0.05) = 4.3219，log₂(1/0.95) = 0.0740）？(b) 要传 2×10⁹ 比特压缩后的图像数据，最少约需多少秒？
提示

先算 C = 1 − H(0.05)（比特/次），再乘 10⁶ 次/秒换算成比特/秒；最后用数据量除以速率。

完整解答

(a) H(0.05) = 0.05×4.3219 + 0.95×0.0740 = 0.2161 + 0.0703 = 0.2864 比特；C = 1 − 0.2864 = 0.7136 比特/次。乘每秒 10⁶ 次使用：上限 ≈ 7.136×10⁵ 比特/秒（约 71.4 万比特/秒）。

(b) 最少时间 = 2×10⁹ ÷ (7.136×10⁵) ≈ 2803 秒 ≈ 47 分钟。注意两步换算缺一不可：容量单位是"比特/次"，必须乘信道使用速率才能得到"比特/秒"——直接拿 2×10⁹ ÷ 0.7136 是初学者最典型的单位错误，会得出荒谬的 2.8×10⁹ 秒（约 89 年）。

为什么随机码能做到"正速率 + 错误任意小"，而重复码做不到？

  • B. 随机码把 nR 比特装进 n 次使用，错误率按 2n(R−C) 随码长指数下降而速率保持 R；重复码速率 1/n 随错误归零而归零
  • C. 重复码的错误率不能降到任意小
  • D. 随机码每个码字都经过精心优化
选 B。核心差别在"靠什么换可靠"：随机码靠码长 n（错误率指数衰减，速率不动），重复码靠牺牲速率（1/n → 0）。A 错：2n(R−C) 强烈依赖 n；C 错：重复足够多次错误率确实可以任意小，只是速率同时归零；D 错：随机码恰恰不做任何精心优化——好码是高维空间的空旷白送的。
自测 5
关于"反馈不增加信道容量"，正确的是：
  • A. 对一切信道成立，包括有记忆信道
  • B. 因为反馈占用了反向信道资源
  • C. 对 DMC 成立（无记忆性保证 I(W;Yⁿ) ≤ Σ I(Xi;Yi) ≤ nC），但反馈能降低编码复杂度；有记忆信道上反馈可严格增容
  • D. 只在 BSC 上成立，BEC 上反馈可以增容
选 C。定理的适用范围与边界必须一起记：DMC 上 CFB = C，但 BEC 上"重发被擦除比特"显示反馈能大幅简化编码。A 错：有记忆信道（突发、衰落）反馈可严格增容；B 错：定理与反向资源无关，是无记忆性的代数后果；D 错：结论对一切 DMC（含 BEC）成立，与具体信道无关。
