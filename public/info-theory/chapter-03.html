3.1长序列的秘密：逐点概率什么都抓不住

Ch2 说 H(X) 是压缩极限。但"极限"要成立，必须先回答一个问题：当我们压缩的不是一个符号，而是一百万个符号时，概率分布告诉我们什么？

先看一个反直觉的计算。设 X₁, X₂, … 独立同分布（i.i.d.，Independent and Identically Distributed）服从 Bern(0.9)：每符号 90% 是 1。取 n = 100。

问：最可能的单条序列是哪条？答：全 1 序列，概率 0.9¹⁰⁰：

0.9¹⁰⁰ = 2100·log₂0.9 = 2−100×0.152 = 2−15.2 ≈ 2.65×10⁻⁵

问：一条"正常长相"的序列——恰好 90 个 1——概率多少？任何一条具体的 90 个 1 的序列，概率是 0.9⁹⁰·0.1¹⁰：

log₂ p = 90×(−0.152) + 10×(−3.322) = −13.68 − 33.22 = −46.9　⟹　p = 2−46.9

奇怪的事情发生了：最可能的序列（全 1，2⁻¹⁵·²）比正常序列（2⁻⁴⁶·⁹）高出 31 个数量级，可你几乎永远不会看到全 1——因为 90 个 1 的序列有 C(100,90) ≈ 1.731×10¹³ ≈ 2⁴⁴·⁰ 条，合起来概率 2⁴⁴·⁰⁻⁴⁶·⁹ = 2⁻²·⁹ ≈ 0.134；而全 1 只有 1 条，概率 2.65×10⁻⁵。单条概率和"这类序列的总概率"是两回事，长序列世界里后者才说了算。

大数定律：频率被迫靠近概率

上面的"90 个 1 附近"不是巧合。弱大数定律（Weak Law of Large Numbers, WLLN）：对 i.i.d. 序列，样本均值依概率收敛（Convergence in Probability）于期望——任意 ε > 0，

P( | 1n Σᵢ Xᵢ − E[X] | > ε ) → 0　（n → ∞）

关键技巧：把 −log p(xⁿ) 本身看作随机变量的和。对 i.i.d. 有 p(xⁿ) = ∏ p(xᵢ)，于是

−1n log₂ p(xⁿ) = 1n Σᵢ [ −log₂ p(xᵢ) ] → E[−log₂ p(X)] = H(X)

右边括号里是 Ch1 的自信息 h(x)，它的期望正是熵。于是"每条长序列的平均自信息 ≈ H"就是大数定律换了一身衣服——这就是渐近均分性的全部种子。

💡 关键一跃

短序列里什么都会发生；长序列里，概率几乎全都集中在一小撮"典型"序列上，而它们每条的自信息都几乎相等（≈ 2⁻ⁿᴴ）。"渐近均分"四个字的意思：n 很大时，实际发生的序列在概率上被均分了。

⚠️ 常见误区

"典型序列 = 最可能的序列"——错。Bern(0.9) 里最可能的序列是全 1（2⁻¹⁵·²），但它是非典型的；典型序列是 90 个 1 的那些（每条仅 2⁻⁴⁶·⁹）。典型与否看的是"自信息是否接近 H"，不是概率绝对大小。单个再可能，一类才决定命运。

3.2典型集：把"几乎必然"圈成一个集合

把 3.1 的观察落成定义。典型集（Typical Set）A_ε⁽ⁿ⁾ 是所有"平均自信息落在 H 的 ε 邻域内"的序列：

A_ε⁽ⁿ⁾ = { xⁿ : 2−n(H+ε) ≤ p(xⁿ) ≤ 2−n(H−ε) }

等价写法（取 −(1/n)log₂）：| −(1/n)log₂ p(xⁿ) − H | ≤ ε。注意两条边：典型序列的概率被夹在两个非常接近的界之间——它们"几乎等概率"，每条约 2⁻ⁿᴴ。"均分"二字正来自这里。

典型集三性质（AEP 定理）

1. 高概率：n 充分大时 P( A_ε⁽ⁿ⁾ ) > 1 − ε
2. 上界：| A_ε⁽ⁿ⁾ | ≤ 2n(H+ε)
3. 下界：n 充分大时 | A_ε⁽ⁿ⁾ | ≥ (1−ε) · 2n(H−ε)

证明各一句话，都值得自己推一遍：

  • 性质 1：正是大数定律——"−(1/n)log p(xⁿ) 偏离 H 超过 ε"的概率趋于 0，所以它落在 ε 邻域内（即 xⁿ ∈ A）的概率 → 1。
  • 性质 2：概率总和 ≤ 1，而典型集里每条至少 2⁻ⁿ⁽ᴴ⁺ᵉ⁾：1 ≥ Σxⁿ∈A p(xⁿ) ≥ |A|·2−n(H+ε)，移项即得 |A| ≤ 2n(H+ε)。一行证完。
  • 性质 3：由性质 1，1−ε < P(A) = Σ_A p(xⁿ) ≤ |A|·2−n(H−ε)（每条至多 2⁻ⁿ⁽ᴴ⁻ᵉ⁾），移项即得。

三条性质合起来说什么

全部序列有 |𝒳|ⁿ 条（二元情形 2ⁿ 条），但概率的几乎全部（> 1−ε）挤在约 2ⁿᴴ 条典型序列上。当 H < 1（比如 Bern(0.1)，H = 0.469），典型集只占全部序列的 2ⁿᴴ/2ⁿ = 2⁻ⁿ⁽¹⁻ᴴ⁾——指数级小的一撮，却扛着几乎全部概率。

💡 关键一跃

典型集把"概率论"翻译成了"组合计数"：想知道需要多少比特，不用再管概率分布的细节，只要数一数典型集有多大。2ⁿᴴ 这个数，就是压缩极限的几何化身。

⚠️ 常见误区

"典型集是概率最大的 2ⁿᴴ 条序列"——错。典型集由自信息接近 H 定义，不是按概率排序取头部。全 1 序列概率很大却不在典型集里。按概率取头部的集合叫高概率集（3.4 节的 B_δ），它与典型集高度重叠但不是同一个东西，这个区别是考试和证明里最常见的坑。

3.3AEP 的兑现：压缩极限恰好是 H

现在把典型集变成编码定理。这是 Ch1 承诺的"信源编码定理"的第一次严格兑现。

正方向：n(H+ε) 比特足够

构造一个两段式编码：

  • 把典型集里的序列排序，每条配一个 ⌈n(H+ε)⌉ 比特的编号（性质 2 保证编号够用）；
  • 非典型序列不管，统一配一个"出错"标记。

译码错误 ⟺ 出现非典型序列 ⟺ 概率 < ε（性质 1）。于是：平均每个符号只用 H+ε 比特，错误率任意小。

逆方向：少于 n(H−ε) 比特做不到

假设只用 n(H−2ε) 比特，至多能区分 2ⁿ⁽ᴴ⁻²ᵉ⁾ 条序列。而性质 3 说典型序列有 (1−ε)·2ⁿ⁽ᴴ⁻ᵉ⁾ 条、每条概率 ≈ 2⁻ⁿᴴ——能覆盖的概率至多是

2n(H−2ε) · 2−n(H−ε) = 2−nε → 0

能正确表示的那部分序列的总概率趋于 0，错误率必然接近 1。所以 H 是硬边界：高于它任意小的错误率可达，低于它必然崩溃。

✅ 判定规则

信源编码定理（i.i.d. 版）：对任意 ε > 0，存在速率 < H+ε 且错误率 → 0 的分组码；任何速率 < H−ε 的分组码错误率 → 1。压缩极限 = H 比特/符号，这就是 Ch1 那句"极限由熵给出"的完整兑现。

⚠️ 常见误区

"AEP 说所有长序列都典型"——错。AEP 说观察到典型序列的概率 → 1，非典型序列永远存在（全 0、全 1 都在），只是它们的总概率趋于 0。压缩方案允许在非典型序列上出错，正是用这 ε 的容忍换来了 H 的下限。

3.4两个补丁：高概率集与"用错分布"的代价

补丁一：最小高概率集 B_δ 与典型集一样大

3.2 节警告过：典型集不是"概率最大的那些序列"。现在把那个集合定义出来：B_δ⁽ⁿ⁾ 是满足总概率 ≥ 1−δ 的最小集合（按概率从大到小往里塞，直到凑够）。它显然是压缩的最优选择——给 B_δ 编号用的比特最少。

一个重要结论（Cover 定理 3.3.1 的味道）：B_δ 的大小也大约是 2ⁿᴴ——它与典型集必然有巨大交集，一阶指数完全相同。所以"给典型集编号"这个看似粗糙的方案，指数阶上已是最优。这也解释了为什么压缩理论里可以只盯着典型集。

补丁二：用错分布，每符号多花 D(p‖q)

如果你以为分布是 q、按 −log q(x) 分配码长，而真实分布是 p，平均码长变成：

Ep[ −log₂ q(X) ] = −Σ p(x) log₂ q(x) = H(p) + D(p‖q)

最后一行拆开即得：−Σp log q = −Σp log p + Σp log(p/q)。用错模型的代价恰好是相对熵——Ch2 说"D 是编码代价"，这里第一次变成真金白银。例：对 (1/2,1/4,1/8,1/8) 误用均匀码，每符号多花 D(p‖u) = 2 − 1.75 = 0.25 比特，n = 10⁶ 个符号白扔 25 万比特。

💡 关键一跃

本章教会你一种"指数阶思维"：n 大时，一切集合的大小、概率、码长都由指数（H、D、I）决定，ε 阶的误差无关紧要。之后全书——信道容量、率失真、假设检验——都是这套思维的换皮。

✅ 本章给下一章留的账

整个 AEP 建立在 i.i.d. 假设上：符号之间独立同分布。可真实信源——文本、语音、基因——前后强烈相关，"熵 H(X)"这个说法本身都不再适用。需要一个新的量：每符号的极限不确定度，即熵率。这是第 4 章的任务。

📝分层习题

L1 概念辨析判断并说明理由：(a) Bern(0.9) 的 n 长序列中，全 1 序列是典型序列；(b) 典型集包含了全部序列概率的至少 1−ε，所以典型集占全部序列个数的比例也接近 1。
提示

(a) 算全 1 序列的平均自信息，与 H(0.9) 比；(b) 概率占比与条数占比是两回事，算 2ⁿᴴ/2ⁿ。

完整解答

(a) 错。全 1 序列的 −(1/n)log p = −log₂0.9 ≈ 0.152，而 H(0.9) = H(0.1) = 0.469，偏离 0.317——n 大时远超任意 ε，故非典型。它单条概率最高，但"最可能 ≠ 典型"。

(b) 错。概率占比 > 1−ε，但条数占比是 |A|/|𝒳|ⁿ ≈ 2ⁿᴴ/2ⁿ = 2⁻ⁿ⁽¹⁻ᴴ⁾ → 0（二元 H < 1 时）。典型集是"条数指数级少、概率指数级多"的集合——这正是压缩之所以可能的根本原因。为什么易错：把均匀分布下的直觉（条数比=概率比）搬到非均匀分布。

L1 概念辨析典型集三性质中，哪一条依赖大数定律？哪一条只用"概率总和为 1"？哪一条依赖前两条？
提示

回忆 3.2 节三条各一句话的证明。

完整解答
性质 1（P(A) > 1−ε）依赖大数定律；性质 2（|A| ≤ 2ⁿ⁽ᴴ⁺ᵉ⁾）只用 1 ≥ Σ_A p(xⁿ) ≥ |A|·2⁻ⁿ⁽ᴴ⁺ᵉ⁾，纯计数；性质 3（下界）先用性质 1 得 P(A) > 1−ε，再用每条概率 ≤ 2⁻ⁿ⁽ᴴ⁻ᵉ⁾ 移项——依赖性质 1。为什么易错：以为性质 2 也要大数定律，其实它对任意 n 精确成立，不需要渐近。
L2 手算推导Bern(0.1)、n = 100（H = 0.469 比特）。取 ε 使典型集定义为自信息落在 H 附近。计算：(a) 恰好 10 个 1 的单条序列的概率（对数形式）；(b) 这类序列的条数与总概率；(c) 典型集大小与全部序列个数之比的数量级。
提示

(a) p = 0.1¹⁰·0.9⁹⁰ 取 log₂；(b) 条数 C(100,10) ≈ 1.731×10¹³，换成 2 的幂；(c) 比值 = 2ⁿᴴ/2¹⁰⁰。

完整解答

(a) log₂ p = 10·log₂0.1 + 90·log₂0.9 = 10×(−3.322) + 90×(−0.152) = −33.22 − 13.68 = −46.90，p = 2⁻⁴⁶·⁹。验证典型性：−(1/100)·(−46.9) = 0.469 = H，正在中心 ✓

(b) C(100,10) ≈ 1.731×10¹³ = 2⁴⁴·⁰；总概率 = 2⁴⁴·⁰ × 2⁻⁴⁶·⁹ = 2⁻²·⁹ ≈ 0.134。

(c) 典型集约 2¹⁰⁰×⁰·⁴⁶⁹ = 2⁴⁶·⁹ 条；全部序列 2¹⁰⁰ 条；比值 ≈ 2⁻⁵³·¹ ≈ 10⁻¹⁶。也就是说：概率几乎全部集中在万亿亿分之一（10⁻¹⁶）的序列上。为什么易错：把 −(1/n)log p(xⁿ) 与 log p(xⁿ) 搞混，忘了除以 n 后与 H 比较。

L2 手算推导设 X 在 4 个符号上均匀分布，n 任意。写出典型集的定义并化简——这个典型集是多大？三条性质的界此时变成什么？这个例子说明了什么？
提示

均匀分布每条序列概率恒为 4⁻ⁿ，H = 2。代入定义看不等式变成什么。

完整解答

p(xⁿ) = 4⁻ⁿ = 2⁻²ⁿ 对所有序列成立。典型集条件 2⁻ⁿ⁽²⁺ᵉ⁾ ≤ 2⁻²ⁿ ≤ 2⁻ⁿ⁽²⁻ᵉ⁾ 对一切 xⁿ 恒成立——典型集 = 全部 4ⁿ 条序列。

性质 2：|A| = 4ⁿ = 2²ⁿ ≤ 2ⁿ⁽²⁺ᵉ⁾ ✓（宽松）；性质 3：|A| = 2²ⁿ ≥ (1−ε)2ⁿ⁽²⁻ᵉ⁾ ✓；性质 1：P(A) = 1 ✓。

说明：均匀分布时没有压缩空间（H = log|𝒳|，典型集占满全部），AEP 的"集中"现象完全来自分布的不均匀。为什么易错：以为典型集总是"小集合"——它的小完全由 H < log|𝒳| 的程度决定。

L3 建模应用某传感器每 10 ms 上报一次状态（0/1，P(1) = 0.1，独立），需存 100 秒数据（n = 10⁴ 个符号）。用 AEP 两段式编码估算所需存储上界，并与定长存储对比；再讨论：若实际中相邻符号强相关（连续同状态），你的方案与理论极限各会发生什么变化。
提示

两段式：典型序列编号需 ⌈n(H+ε)⌉ 比特。先算 H(0.1)。相关情形想 Ch4 的熵率方向：条件熵 ≤ 边际熵。

完整解答

独立情形：H(0.1) = 0.469 比特/符号。典型集编号约需 n·H = 10⁴ × 0.469 ≈ 4690 比特（加 ε 余量与 1 比特标志位，上界约 n(H+ε)+2）。定长存储需要 10⁴ 比特。压缩比约 47%，且 n 越大错误率（非典型出现概率）越小。

强相关情形：若相邻状态强相关（比如 0 之后 99% 还是 0），i.i.d. 假设失效，典型集理论不再直接适用；但直觉上可压得更狠——因为条件熵 H(Xₙ|Xₙ₋₁) ≤ H(Xₙ)，记忆降低了每符号的真实不确定度。正确的极限量是熵率（第 4 章定义），它将给出比 0.469 更低的压缩极限。为什么易错：直接对非 i.i.d. 数据套 n·H(X)——这时 H(X₁)（边际熵）高估了极限，真实极限是熵率 lim H(Xₙ|X₁ⁿ⁻¹)。

  • B. 大数定律保证典型序列很多

  • B. 非典型序列概率太大
  • C. 大数定律失效

自测 5
误把分布 q 当成真实分布来设计码，而真实分布是 p，平均每符号多花的比特数是：
