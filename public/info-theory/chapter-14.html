14.1从"这条序列本身有多复杂"说起

上一章的通用编码给了一个漂亮的承诺：不知道信源分布，也能把平均码长压到接近熵。但注意，那是对分布、对平均的承诺。现在换一个更"个人"的问题：桌上放着一条具体的 1000 位串，不谈它是哪个信源生的，就问它本身最短能被描述成多少位？这就是本章的主角——柯氏复杂度（Kolmogorov Complexity，又译柯尔莫哥洛夫复杂度）。

定义：固定一台通用计算机（Universal Computer，可理解为通用图灵机或你手里的编程语言解释器）U，串 x 的柯氏复杂度是能让 U 输出 x 然后停机的最短程序的长度：

KU(x) = minp：U(p) = x 且停机 ℓ(p)

其中 ℓ(p) 是程序 p 的比特长度。三个要点：程序必须无输入（一切信息都在程序里）、必须停机（死循环不算）、取最短（所有能输出 x 的程序里的最小值）。

例 1：两条 1000 位的串，复杂度天差地别

串甲：0101…01，"01"重复 500 次，共 1000 位。它有一个短程序："循环 500 次，每次打印 01"。这个程序需要多少位？

  • 循环次数 500 要编码：log₂500 ≈ 8.97，向上取整 9 位；
  • "循环、打印 01"这套指令骨架是固定的一段代码，长度是与 1000 无关的常数，比如解释器里几十位，记为 c。

合计 K(串甲) ≤ 9 + c——当串长翻倍到 2000 位，只需把 500 改成 1000，多 1 位；串长变 2ⁿ 位，程序只长 n + c 位。规律性把 1000 位压缩到了约 9 位加常数。

串乙：掷 1000 次公平硬币记下的随机串。它没有任何可总结的规律，最短的程序只能是"打印 0110100110…（原样照抄 1000 位）"——程序本身就得装进这 1000 位：K(串乙) ≈ 1000 + c′。14.3 节将严格证明：绝大多数串都像串乙。

💡 关键一跃

熵 H 度量的是一个分布的平均信息量，K(x) 度量的是一条具体序列的信息量——它把"信息"从统计学里解放出来，变成了纯粹的算法概念：一条串的信息 = 它的最短自包含描述。

⚠️ 常见误区

"K(x) 是某个编程语言的属性"——不完全是。定义里那台通用机 U 一旦固定，K 就是 x 的客观属性；换机器确实会改数值，但 14.2 的不变性定理保证改动被一个有界常数吸收。另一个误区是以为 π 的位数"随机所以 K 大"——π 的位由短程序生成，K 极小；看着乱 ≠ 复杂。

14.2不变性定理：换台机器，K 只差一个常数

上一节的定义里写着"固定一台通用机 U"，这立刻引来质疑：用 Python 解释器和用 Java 虚拟机算出来的 K(x) 不一样，那这个定义还有什么客观性？不变性定理（Invariance Theorem）正是来扑灭这个质疑的。

定理：对任意两台通用机 U 与 U′，存在一个只取决于两台机器、不取决于 x 的常数 c，使得对一切串 x：

KU(x) ≤ KU′(x) + c

证明思路（模拟器论证）：U 是通用机，所以它能在自身上模拟 U′——写一段固定程序 s，功能是"读入一个 U′ 程序并照着执行"。这段模拟器的长度 ℓ(s) = c 是固定的。现在任取 U′ 上输出 x 的最短程序 p′（长度 KU′(x)），把它交给"U 上的 s + p′"这个组合程序：s 先启动，模拟 U′ 跑 p′，输出 x 并停机。组合长度 = c + KU′(x)，于是 U 上存在长度不超过 c + KU′(x) 的程序输出 x，即 KU(x) ≤ KU′(x) + c。交换 U 与 U′ 得反向不等式，合起来 |KU(x) − KU′(x)| ≤ c。

💡 关键一跃

模拟器常数 c 就像两种货币之间的一次性汇兑手续费：换机器只付一次，之后每个串的复杂度差异都被它封顶。因此所有渐近结论（随串长 n 增长的陈述）对机器的选择完全免疫——O(1) 的差异在 O(n) 的增长面前消失。

⚠️ 常见误区

"既然 K 依赖机器，纠结某台具体机器上 K 的精确值才有意义"——恰好相反。不变性定理告诉我们纠结具体常数没有理论价值：本章所有重要结论（不可计算性、(1/n)EK → H、不可压缩的普遍性）都在"相差常数"的意义下成立，对机器选择一视同仁。

14.3不可计算与不可压缩：K 的两大坏消息与一个大会合

K 定义得漂亮，但接下来必须坦白三件事：它算不出来；它对几乎所有串都很大；以及——作为补偿——它在期望意义下恰好等于老朋友熵。这一节把三笔账一次算清。

坏消息一：Berry 悖论 ⟹ K 不可计算

假如存在一个算法，输入任意 x 都能输出 K(x)，看下面的推理链——这就是Berry 悖论（Berry Paradox）的威力：

描述的最小正整数"] --> B["上面这句话本身不足1000字"] B --> C["它完整描述了 n
故 K n 小于 1000"] C --> D["但 n 的定义要求 K n 至少 1000"] D --> E["矛盾根源：假设了 K 可计算
故不存在这样的算法"] classDef danger fill:#fae9e7,stroke:#b03a2e,stroke-width:2.5px,color:#b03a2e; class E danger;
图 14.3 Berry 悖论的推理链：若 K 可计算，就能用短描述构造出"不可短描述"的对象，矛盾。

把链条写细：假设有程序 Q 能计算任意串的 K。写一个程序 P：从小到大枚举所有正整数 m，用 Q 检查每个 m 的最短描述长度，输出第一个满足 K(m) ≥ 1000 的 m 并停机。P 的长度是多少？枚举与比较是固定代码，常数 c；数字 1000 本身只需 log₂1000 ≈ 10 位。所以 ℓ(P) ≈ 10 + c，远小于 1000。可是 P 输出的那个 m 按定义满足 K(m) ≥ 1000——P 用远少于 1000 位的程序描述了 K ≥ 1000 的对象，矛盾。唯一可推卸的前提就是"Q 存在"。结论：K(x) 是不可计算函数（Uncomputable Function），没有算法能对任意 x 求出它的最短描述。

坏消息二（手算例 2）：计数论证——绝大多数串不可压缩

长度严格小于 k 位的二元程序有多少个？长度为 0、1、…、k−1 的串分别是 1、2、…、2ᵏ⁻¹ 个，几何级数求和：

1 + 2 + 4 + … + 2ᵏ⁻¹ = 2ᵏ − 1

每个程序至多输出一条串，所以满足 K(x) < k 的串至多有 2ᵏ − 1 条。现在取 n 位串全体（共 2ⁿ 条），问：能被压缩掉至少 10 位的串——即 K(x) < n − 10——占多大比例？

比例 ≤ 2ⁿ⁻¹⁰ − 12ⁿ < 2ⁿ⁻¹⁰2ⁿ = 2⁻¹⁰ = 11024 ≈ 0.001

逐步核对：分子是"长度 < n−10 的程序数"上界 2ⁿ⁻¹⁰ − 1；分母是全体 n 位串数 2ⁿ；约分后 2ⁿ⁻¹⁰⁺⁽⁻ⁿ⁾ = 2⁻¹⁰。不到千分之一的 n 位串能被压缩哪怕 10 位。这同时是"万能压缩软件不存在"的严格证明：任何映射若把某些串变短，鸽笼原理就迫使它把另一些串变长——压缩必有例外。

K 接近串长的串叫不可压缩串（Incompressible String），也称算法随机（Algorithmic Randomness）的串：它没有任何规律可被程序利用。注意这是逐条串的性质，与"它是不是从某个均匀分布里抽出来的"无关。

大会合（手算例 3）：K 与熵——期望意义下是同一个量

设 Xⁿ = X₁…Xⁿ 为 i.i.d. Bern(p) 序列。两个方向各证一次，数字取 n = 1000、p = 0.11（回忆 H(0.11) = −0.11·log₂0.11 − 0.89·log₂0.89 ≈ 0.3503 + 0.1496 ≈ 0.5 比特）。

上界（用第 3 章典型集构造短程序）：给 Xⁿ 写这样一个程序——

  1. 先编码 n：用 O(log₂n) 位（n = 1000 时约 10 位，可定长）；
  2. 再编码序列的类型（含 1 的个数 k，或等价地经验 p̂）：只有 n+1 种可能，再花 O(log₂n) 位；
  3. 该类型的所有序列等概率且数目为 C(n,k)，用 Stirling 近似 log₂C(n,k) ≈ nH(k/n)；对典型序列 k/n ≈ p，故只需 ≈ nH(p) = 1000 × 0.5 = 500 位给出集内下标。

合计 K(Xⁿ) ≤ nH(p) + O(log₂n)，取期望：

E[K(Xⁿ)] ≤ nH(X) + c·log₂n　（n=1000 时约 500 + 几十位）

下界（用第 5 章 Kraft 不等式）：停机程序的集合可以组织成前缀码（任何程序都不是另一个程序的前缀，否则短程序跑完就停机了），故其码长满足 Kraft 不等式 Σx 2^(−K(x)) ≤ 1。而第 5 章证明过：任何满足 Kraft 不等式的码长函数，期望码长不小于熵。于是

E[K(Xⁿ)] ≥ H(Xⁿ) = nH(X)　（n=1000 时 ≥ 500 位）

两界一夹：500 ≤ E[K(X¹⁰⁰⁰)] ≤ 500 + 几十。除以 n 取极限，得到本章最优美的结论：

limn→∞ 1n E[K(Xⁿ)] = H(X)
💡 关键一跃

柯氏复杂度是熵的"逐序列版本"：熵说"这个分布的序列平均要 nH 位"，K 说"这一条序列本身要 K(x) 位"；对长随机序列取平均，两者精确会合。香农从分布走向极限，柯尔莫哥洛夫从单条序列走向极限，终点是同一个 H。

⚠️ 常见误区

"K 不可计算，所以这套理论没用"——错。不可计算的是对任意 x 求精确 K；但上界（给出具体短程序）永远可验证，下界可用计数论证批量给出（绝大多数串 K 大）。14.4 节的 MDL 正是把"最短描述"从理论对象变成每天可用的建模原则。

14.4从复杂度到学习：两部分码与 MDL

K 不可计算，但它的思想可以直接"贴现"成工程原则。建模的本质是什么？给数据 x 找一个短描述。把描述拆成两段——先描述模型，再描述给定模型后的数据——这就是两部分码（Two-Part Code），而"选总描述长度最短的模型"就是最小描述长度（Minimum Description Length, MDL）原则：

L总(M, x) = L(M) + L(x | M)　　选 M* = arg minM L总

第一项惩罚模型的复杂，第二项奖励模型的贴合：模型越复杂，L(M) 越大，但残差 L(x|M) 越小；模型太简单，L(M) 小而残差大。总长度最短处就是偏差与方差的平衡点——奥卡姆剃刀（Occam's Razor）"如无必要勿增实体"由此获得精确的比特度量。

数据的描述长度 L x 竖线 M"] B --> D["总长相加
最短者胜出"] C --> D D --> E["过简单欠拟合 过复杂过拟合

更理论化的对应物是柯氏充分统计量（Kolmogorov Sufficient Statistic）：把 x 拆成"结构 + 噪声"——选一个含 x 的集合 S，使 K(S) + log₂|S| 最小；S 的描述捕获 x 的全部规律（充分统计量），log₂|S| 位下标则是 x 在集合内的纯随机位置。最优 S* 恰好把"有意义的结构"与"无规律的噪声"切开，这与统计里充分统计量的角色一一对应。

两个漂亮但本书不展开的延伸，各记一句：其一，通用先验（Universal Prior）PU(x) ≈ 2^(−K(x))——越简单的对象先验概率越大，把这当先验做贝叶斯预测就是所罗门诺夫的通用归纳理论；其二，停机概率（Halting Probability）Ω = Σp：U(p) 停机 2^(−ℓ(p))——Chaitin 的这个数是每个前缀程序随机被抽中时恰好停机的概率，它的每一位都不可计算，是算法信息论里"随机性的极限标本"。

💡 关键一跃

MDL 是 K 的"可计算替身"：把全集上的最短程序换成一个模型类里的两部分码，不可计算的优化就变成了可查表、可比较的实用准则。学统计学习时见过的 BIC、正则化，都是这条思想的不同近似。

⚠️ 常见误区

"MDL 说永远选最简单的模型"——不对，它选的是总码长最短的模型：若数据真有复杂结构，复杂模型靠残差项的大幅节省照样胜出。MDL 反对的不是复杂，而是"复杂度没有换来足够的描述节省"。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
柯氏复杂度（Kolmogorov Complexity）
点击翻面 →
定义K(x) = minp：U(p)=x ℓ(p)：固定通用机上输出 x 并停机的最短程序长度。
解决问题给"单条序列本身含多少信息"一个不依赖分布的终极定义。
直觉一条串的最短"自包含说明书"的厚度。
误区以为看着乱就是 K 大——π 的位看着乱但由短程序生成，K 很小。
何时用本章全程；MDL、通用先验、算法随机性都建立在它上面。
概念卡 2
不变性定理（Invariance Theorem）
点击翻面 →
定义任意两台通用机间存在常数 c，使 |KU(x) − KU′(x)| ≤ c 对一切 x 成立。
解决问题消除"K 依赖具体机器"的定义危机，保证渐近结论客观。
直觉换机器只付一次性的"模拟器手续费"，之后逐条串都被它封顶。
误区纠结某台机器上的精确 K 值——理论上只有相差常数的陈述才有意义。
何时用一切关于 K 的渐近命题（如 (1/n)EK → H）的合法性来源。
概念卡 3
不可计算性与 Berry 悖论（Uncomputability / Berry Paradox）
点击翻面 →
定义不存在对任意 x 输出 K(x) 的算法；Berry 悖论给出对角线式证明。
解决问题划定算法信息论的边界：最短描述是理论上存在、实践上不可全求的对象。
直觉"不能用少于一千字描述的最小整数"被这句话用不到一千字描述了。
误区以为不可计算 = 不可研究——上界可构造、下界可计数、期望可渐近。
何时用14.4 MDL 的动机：正因为 K 求不出，才需要可计算的替身。
概念卡 4
算法随机性 / 不可压缩（Algorithmic Randomness / Incompressibility）
点击翻面 →
定义K(x) ≥ |x| 量级（压不出水分）的串称为不可压缩串，即算法随机串。
解决问题把"随机"从分布属性变成单条序列的可判定性质。
直觉最短描述就是原样照抄——这条串是它自己最短的摘要。
误区以为随机串罕见——恰恰相反，n 位串中可压缩 10 位以上的不足 0.1%。
何时用计数论证的主角；"万能压缩软件不存在"的严格依据。
概念卡 5
K 与熵的渐近等价（lim (1/n)EK = H）
点击翻面 →
定义i.i.d. 序列上 nH ≤ E[K(Xⁿ)] ≤ nH + O(log n)，故 (1/n)E[K(Xⁿ)] → H(X)。
解决问题证明算法信息论与香农信息论是同一枚硬币的两面。
直觉K 是熵的逐序列版本：平均下来，单条最短描述就是 nH。
误区以为对每条串都有 K(xⁿ) ≈ nH——只在期望/大概率意义下成立。
何时用连接 Ch3 典型集、Ch5 码长下界与本章的枢纽结论。
概念卡 6
两部分码与 MDL（Two-Part Code / Minimum Description Length）
点击翻面 →
定义L总 = L(M) + L(x|M)，选总长度最短的模型 M。
解决问题把 K 的"最短描述"思想变成可计算的模型选择准则。
直觉模型是压缩工具：工具本身要花钱（L(M)），用它压数据省钱（L(x|M)）。
误区以为 MDL 永远选最简单模型——它选的是总码长最短，不是第一项最小。
何时用模型/阶数选择、正则化、BIC 的共同源头；统计学习与机器学习处处可见。
概念卡 7
柯氏充分统计量（Kolmogorov Sufficient Statistic）
点击翻面 →
定义含 x 的集合 S 中使 K(S) + log₂|S| 最小者；S 是结构，集内下标是噪声。
解决问题把一条序列严格切成"全部规律"与"纯随机残差"两半。
直觉x = 一份浓缩的结构说明 + 一个骰子在该结构允许范围内的落点。
误区以为 S 越精确越好——S 太细（如 S={x}）K(S) 飙升，总长度反而变大。
何时用MDL 的理论原型；理解"充分统计量"在算法信息论中的镜像。

📝分层习题

L1 概念辨析判断对错：既然 K 依赖所选通用机，那么"换一台机器 K 最多差常数 c"说明关于 K 的渐近结论（如 (1/n)EK → H）不牢靠。说明理由。
提示

常数 c 随 n 增长吗？(1/n)·c 在 n→∞ 时是多少？

完整解答
错。不变性定理中的常数 c 只取决于两台机器，与 x、与串长 n 都无关。渐近结论的两端 nH 与 nH + O(log n) 都随 n 增长，附加一个 O(1) 的常数后除以 n 趋于 0，极限丝毫不变。恰恰是不变性定理保证了渐近结论对机器选择的"免疫"，而不是削弱它。
L1 概念辨析判断对错："因为 K(x) 不可计算，所以对任何具体序列我们都无法说出关于它复杂度的任何话。"
提示

要证明 K(x) ≤ 某个数，需要做什么？要证明"几乎所有串 K 大"，需要逐条算 K 吗？

完整解答
错。不可计算指的是"没有算法能对任意 x 求出精确 K(x)"，但两类陈述仍然可行：其一，上界可构造——只要写出一个输出 x 的短程序（如"循环打印 01 共 500 次"），就证明了 K(x) 不超过它的长度；其二，批量下界可计数——计数论证表明 n 位串中 K(x) < n−10 的比例不足 2⁻¹⁰，无需逐条计算。不可计算挡住的是精确值，不是理论本身。
L2 手算推导完整重做计数论证：在全部 100 位二元串中，满足 K(x) < 90 的串至多占多大比例？写出从程序计数到比例约分的每一步。
提示

先数"长度小于 90 位的程序"总数（几何级数），再除以串的总数 2¹⁰⁰，然后约分。

完整解答

第一步：数短程序。长度恰好为 i 位的二元串有 2ⁱ 条，故长度 < 90 的程序总数 ≤ Σi=089 2ⁱ = 2⁹⁰ − 1（几何级数：首项 1、公比 2、共 90 项）。

第二步：程序→串至多一一对应。每个程序停机后只输出一条串，故满足 K(x) < 90 的 100 位串至多有 2⁹⁰ − 1 条。

第三步：除以串总数并约分。100 位串共 2¹⁰⁰ 条，比例 < 2⁹⁰ / 2¹⁰⁰ = 290−100 = 2⁻¹⁰ = 1/1024 ≈ 0.00098。

结论：在 100 位串中，能被压缩超过 10 位的串不足千分之一。一般地，K(x) < n−k 的比例 < 2⁻ᵏ——可压缩性是指数稀缺的。

L2 手算推导用两部分码给 8 个数据点选模型。三个候选：常数模型（均值）、线性模型、二次模型。各自的两部分码长如下表，手算总码长并用 MDL 选出最优模型，解释为什么二次模型落败。
提示

总码长 = 模型描述长度 + 残差（数据|模型）描述长度，逐行相加再取最小。

完整解答
模型L(M) 模型位L(x|M) 残差位L总
常数（1 个参数）24042
线性（2 个参数）81826
二次（3 个参数）121628

逐行相加：42、26、28。MDL 选线性模型（总长 26 位最短）。二次模型的残差只比线性少 2 位（18→16），却要多花 4 位描述自己（8→12），净亏 2 位——新增的复杂度没换来足够的描述节省，这正是过拟合在码长语言里的样子；常数模型则相反，省了 6 位模型位却多付 22 位残差，是欠拟合。

L3 建模应用实验课上你测得某物理量随时间变化的曲线（12 个采样点，带测量噪声），要在多项式模型中选定阶数：0 阶（常数）、1 阶、2 阶、3 阶。用 MDL 语言写出完整的决策流程，并说明它与奥卡姆剃刀、过拟合的关系。
提示

两部分码的两项分别对应什么？阶数升高时两项各自怎么变？决策规则取什么的最小值？

完整解答

决策流程（MDL 版）：

  1. 约定编码方案：每个参数用固定位宽编码（如 16 位浮点），阶数越高参数越多，L(M) 越大；
  2. 对每个候选阶数 k ∈ {0,1,2,3}，用最小二乘拟合出最优参数，计算残差平方和 RSSk；
  3. 残差码长用高斯噪声模型给出：L(x|Mk) ≈ (n/2)·log₂(RSSk/n) + 常数（n = 12）；
  4. 计算 L总(k) = L(Mk) + L(x|Mk)，选 arg mink L总(k)。

与奥卡姆剃刀：剃刀说"如无必要勿增实体"，MDL 把"必要"量化成比特——新参数必须靠自己的加入让残差码长下降超过它的身价，否则不增。剃刀从美学口号变成可执行的不等式。

与过拟合：3 阶多项式能把 12 个带噪点拟合得很漂亮（RSS 很小），但它把噪声当成了结构记进了参数；MDL 的模型项对这种行为直接收费，只有当残差的真实节省超过参数成本时才放行。两部分码的总长最小点，就是统计学习里偏差—方差权衡的算法信息论版本。
