2.1熵：一个分布平均携带多少信息

第 1 章给出了单条消息的信息量 h(x) = −log₂ p(x)。但工程上我们面对的不是一条消息，而是一个不断发消息的信源（Source）——一个随机变量 X。自然的问题：这个信源平均每条消息携带多少信息？答案就是按概率取期望：

H(X) = E[ −log₂ p(X) ] = − Σx∈𝒳 p(x) · log₂ p(x)　　（单位：比特）

这就是熵（Entropy）。三个注释，每一个都很重要：

  • 熵是分布的性质，不是取值的性质。H(X) 只由概率向量 p 决定，与 𝒳 里装的是字母、数字还是颜色无关。所以也常写作 H(p)。
  • 约定 0·log 0 = 0。概率为 0 的符号从不出现，不贡献信息；数学上这是 x log x 在 0 处的连续延拓。
  • 熵 ≥ 0。因为每项 −p log₂p 都非负（0 ≤ p ≤ 1 时 log₂p ≤ 0）。

例 1：把第 1 章欠的 1.75 算出来

信源分布 p = (1/2, 1/4, 1/8, 1/8)。一步不落：

H(X) = −[ 12·log₂12 + 14·log₂14 + 18·log₂18 + 18·log₂18 ]
= 12×1 + 14×2 + 18×3 + 18×3 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 比特

这正是第 1 章例 1 里前缀码达到的平均码长——熵与最优码长的关系不是巧合，是第 5 章的定理。

熵的上界：均匀分布最不确定

直觉上，均匀分布最难猜，熵应该最大。严格结论：

H(X) ≤ log₂ |𝒳|，等号成立 ⟺ X 服从均匀分布

证明思路（2.3 节会正式给出工具）：取均匀分布 u(x) = 1/|𝒳|，则 D(p‖u) = log₂|𝒳| − H(X) ≥ 0。例如 4 符号信源 H ≤ log₂4 = 2 比特；上面例 1 的 1.75 < 2，离均匀还差 0.25 比特——这 0.25 就是"分布不均匀省下的压缩空间"。

二元熵函数：出现频率最高的一个特例

X 只取两个值（概率 p 与 1−p）时，熵叫二元熵函数（Binary Entropy Function）：

H(p) = −p·log₂ p − (1−p)·log₂(1−p)

它关于 p = 1/2 对称，在 p = 1/2 取最大值 1 比特，两端 p→0、1 时趋于 0。第 1 章已算过 H(0.1) = 0.469 比特。这个数字马上要在信道容量里反复出现。

💡 关键一跃

熵不是"某条消息的信息量"，而是信源的不确定度：你在收到消息之前平均有多疑惑，收到之后就平均消除多少疑惑。压缩极限、信道容量、机器学习里的交叉熵——全是这一个数的化身。

⚠️ 常见误区

"熵大说明随机变量取值多"——不对。熵度量的是不确定性不是取值个数：1000 个取值但 99.99% 概率集中在一个值上，熵可以接近 0；只有 2 个取值但等概率，熵就是满的 1 比特。决定熵的是概率的分布形状，不是支撑集大小。

2.2联合熵、条件熵与链式法则

一个变量不够看——现实里变量总是成对出现：信源与码字、发送与接收、症状与疾病。熵的概念要升级成"两个变量"的版本。

联合熵（Joint Entropy）：把 (X,Y) 当成一个大随机变量，照样定义：

H(X,Y) = − Σx,y p(x,y) · log₂ p(x,y)

条件熵（Conditional Entropy）：已知 Y 之后，X 还剩多少不确定度？先固定 Y = y 算条件分布的熵，再对 y 取平均：

H(X|Y) = Σy p(y) · H(X|Y=y) = − Σx,y p(x,y) · log₂ p(x|y)

注意条件熵是两次平均：对内是 −Σ p(x|y) log p(x|y)（条件分布的熵），对外按 p(y) 加权。联合概率 p(x,y) 出现在外层，不是 p(x) 也不是 p(y)——这是最容易写错的地方。

链式法则：整体不确定度 = 先定一个 + 剩多少

H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)

直觉：要知道 (X,Y) 两个值，先告诉你 X（花 H(X) 比特），再告诉你"已知 X 后还差多少 Y"（花 H(Y|X) 比特）。由 log 乘法变加法立即可证。n 个变量版本：H(X₁,…,Xₙ) = Σᵢ H(Xᵢ | X₁,…,Xᵢ₋₁)，第 4 章定义熵率全靠它。

例 2（Cover 例 2.2.1）：一张联合表算出全部六个量

这是本章最重要的一个例子，后面所有量都从这张表里长出来。设 (X,Y) 的联合分布为：

p(x,y)Y=1Y=2Y=3Y=4行和 p(x)

第一步：边际熵。p(x) 均匀 → H(X) = log₂4 = 2 比特。p(y) = (1/2, 1/4, 1/8, 1/8)，由例 1 → H(Y) = 1.75 比特。

第二步：逐行算 H(Y|X=x)，再加权。每行除以自己的行和得到条件分布：

X=1(1/2, 1/4, 1/8, 1/8)1.751/4

H(Y|X) = 14(1.75 + 1.75 + 2 + 0) = 14 × 5.5 = 1.375 比特（= 11/8）

条件条件分布 p(x|y)H(X|Y=y)权重 p(y)

第四步：链式法则两个方向互相验证。

H(X,Y) = H(X) + H(Y|X) = 2 + 1.375 = 3.375 比特 = H(Y) + H(X|Y) = 1.75 + 1.625 ✓

注意 H(Y|X) = 1.375 ≠ H(X|Y) = 1.625：条件熵不对称。知道 X 后 Y 平均只剩 1.375 比特不确定，但知道 Y 后 X 还剩 1.625——X 从 Y 那里得到的信息（0.375）与 Y 从 X 那里得到的信息（也是 0.375）才是相等的，这个相等的量就是 2.4 节的互信息。

💡 关键一跃

条件熵 H(X|Y) 是"别人已经告诉你 Y，你猜 X 还剩多难"。它衡量的是观测 Y 之后 X 的残存不确定性——通信里接收端的困惑、机器学习里的损失下界、Fano 不等式的主角，全是它。

⚠️ 常见误区

"H(X|Y) 是对某个 y 算的熵"——错。H(X|Y=y) 才是固定某个 y 的熵（一个普通熵）；H(X|Y) 是对所有 y 按 p(y) 加权后的平均。前者随 y 而变（例 2 里 1.75、1.5、1.5、0 各不相同），后者是一个确定的数。加权时必须用联合分布 p(x,y)，忘了这层是手算出错的第一原因。

2.3相对熵：两个分布差多远

现在换一个视角。假设真实分布是 p，但你以为它是 q——这个"以为错了"的代价怎么度量？相对熵（Relative Entropy），也叫 KL 散度（Kullback–Leibler Divergence）：

D(p‖q) = Σx p(x) · log₂ p(x)q(x) = Ep[ log₂ p(X)q(X) ]

约定：0·log(0/q) = 0；若存在某 x 使 p(x) > 0 而 q(x) = 0，则 D(p‖q) = +∞（你以为不可能的事发生了，代价无穷大）。

例 3：手算一对非对称的相对熵

取 p = (0.9, 0.1)，q = (0.5, 0.5)（比如真实天气 90% 晴，你的模型以为 50/50）：

D(p‖q) = 0.9·log₂0.90.5 + 0.1·log₂0.10.5 = 0.9×log₂1.8 + 0.1×log₂0.2
= 0.9×0.848 + 0.1×(−2.322) = 0.763 − 0.232 = 0.531 比特

反过来：

D(q‖p) = 0.5·log₂0.50.9 + 0.5·log₂0.50.1 = 0.5×(−0.848) + 0.5×2.322 = −0.424 + 1.161 = 0.737 比特

0.531 ≠ 0.737——相对熵不对称，因而不是数学意义下的"距离"（它也不满足三角不等式）。叫它"散度"而不是"距离"正是这个原因。不对称有明确含义：D(p‖q) 是"世界是 p，模型是 q"的代价，D(q‖p) 是相反方向的代价，二者本来就不该相等。

相对熵与压缩：分布里藏着多少冗余

取 q 为均匀分布 u(x) = 1/|𝒳|，展开：

D(p‖u) = Σ p(x)·log₂[ p(x)·|𝒳| ] = log₂|𝒳| − H(p)

2.1 节的例 1：D(p‖u) = 2 − 1.75 = 0.25 比特。含义将在第 5 章兑现：如果你误用"均匀"模型去设计编码，平均每个符号要比最优码多花 0.25 比特。相对熵 = 用错分布的编码代价，这是它在全书最重要的物理解读。

💡 关键一跃

相对熵是"惊讶的平均差距"：真实发生 x 时，按 q 你以为的惊讶是 −log q(x)，实际应得的惊讶是 −log p(x)，差值 log(p/q) 按真实概率 p 平均。它把"两个分布像不像"变成了可计算的比特数。

⚠️ 常见误区

"D(p‖q) 是 p 和 q 之间的距离"——三重错误：不对称（例 3）、不满足三角不等式、可以是无穷大。它是有方向的代价：被除数位置（q）是"你的模型/你的码"，被乘位置（p）是"真实世界"。写论文或推导时把两个位置弄反，结论会整个错向。

2.4互信息：两个变量共享多少信息

最后一个、也是最重要的度量。X 与 Y 是相关的（比如发送比特与接收比特），Y 里有多少关于 X 的信息？用熵的语言：Y 把 X 的不确定度削掉了多少：

I(X;Y) = H(X) − H(X|Y)

展开条件熵定义并整理（log 减法变除法），得到更对称的形式：

I(X;Y) = Σx,y p(x,y) · log₂ p(x,y)p(x)p(y) = D( p(x,y) ‖ p(x)p(y) )

最后一等号是全书最浓缩的公式之一：互信息 = 真实联合分布与"假装独立"的乘积分布之间的相对熵。由此立刻得到三个性质：

  • 对称性：I(X;Y) = I(Y;X) = H(Y) − H(Y|X)。"X 告诉你多少 Y"和"Y 告诉你多少 X"是同一个数——2.2 节例 2 末尾那个 0.375 的巧合，其实是必然。
  • 非负性：I(X;Y) ≥ 0（相对熵非负，2.5 节证），等号 ⟺ X 与 Y 独立。
  • 自信息：I(X;X) = H(X)。自己与自己的共享信息就是全部熵。

例 4：例 2 的收官——互信息 0.375 比特

I(X;Y) = H(X) − H(X|Y) = 2 − 1.625 = 0.375 比特（= 3/8）
验证另一方向：H(Y) − H(Y|X) = 1.75 − 1.375 = 0.375 ✓

💡 关键一跃

互信息是信道容量的原材料：第 7 章会证明信道能可靠传输的最高速率 C = max I(X;Y)，对输入分布取最大。今天你把 I(X;Y) 算熟，第 7 章就只是"再多取一个 max"。

⚠️ 常见误区

"互信息大说明 X 决定 Y"——不一定。I 是对称的，只度量共享多少，不分因果、不分方向；而且 I(X;Y) 大可以是 H(Y) 本身大（Y 很随机且与 X 强相关），也可以是 Y 几乎被 X 完全决定。判断"谁决定谁"要看 H(Y|X) 是否接近 0，而不是 I 的大小。

2.5不等式工具箱：Jensen、数据处理与 Fano

前面用到的每一条"显然"（D ≥ 0、I ≥ 0、条件化减熵）其实都站在同一块基石上。本节把它补齐，并推出两个全书反复使用的工具。

基石：Jensen 不等式

f 是凸函数，则 E[f(X)] ≥ f(E[X])；f 凹则反向。log 是严格凹函数，于是：

E[log₂ X] ≤ log₂ E[X]

推论：D(p‖q) ≥ 0，等号 ⟺ p = q。证明：D(p‖q) = −E_p[log(q/p)] ≥ −log₂ E_p[q/p] = −log₂ Σ_x p(x)·q(x)/p(x) = −log₂ 1 = 0。一步推出本章所有非负性：

  • I(X;Y) = D(p(x,y)‖p(x)p(y)) ≥ 0 ⟹ H(X|Y) ≤ H(X)：知道别的信息，不确定度只会降（等号 ⟺ 独立）。
  • D(p‖u) ≥ 0 ⟹ H ≤ log|𝒳|（2.1 节欠的证明，已还）。

工具一：数据处理不等式——信息经过加工只会流失

若 X → Y → Z 构成马尔可夫链（Markov Chain，即给定 Y 时 Z 与 X 条件独立），则：

I(X;Z) ≤ I(X;Y)

直觉：Z 是 Y 的加工品，加工不能凭空造出关于 X 的信息。数据压缩、特征提取、神经网络层数再深，关于原始标签的互信息只会沿链条不增——这是"没有任何后处理技巧能超越原始观测"的数学表述。

工具二：Fano 不等式——残存不确定度决定猜错率下限

用 Y 来估计 X，错误概率 Pe = P(X̂ ≠ X) 满足：

Pe ≥ H(X|Y) − 1log₂|𝒳|

例 5：X 在 4 个值上均匀（H(X) = 2），观测 Y 后 H(X|Y) = 1.5 比特。则任何估计器的错误率至少：

Pe ≥ 1.5 − 1log₂4 = 0.52 = 0.25

残存 1.5 比特不确定度，任你估计器多聪明，四次里至少猜错一次。Fano 不等式是第 7 章信道逆定理的发动机，也是机器学习里"特征信息量决定误差下限"的出处。

💡 关键一跃

本节三条是一条食物链：Jensen → D ≥ 0 → I ≥ 0 与条件化减熵 → 数据处理与 Fano。记住这条链，本章一半的不等式不用背——全是 D ≥ 0 的换皮。

⚠️ 常见误区

"H(X|Y) ≤ H(X) 说明知道 Y 永远有帮助"——两个坑：一是对某个特定 y，H(X|Y=y) 完全可以大于 H(X)（坏消息让你更困惑），平均后才保证不增；二是等号条件是 X、Y 独立，不是"Y 没用"这种模糊说法。说结论时把"平均"和"独立"两个词带上，就不会错。

✅ 本章给下一章留的账

📝分层习题

L1 概念辨析判断并说明理由：(a) H(X|Y) ≤ H(X) 对每个随机变量对都成立；(b) H(X|Y=y) ≤ H(X) 对每个 y 都成立；(c) D(p‖q) = D(q‖p) 恒成立。
提示

(a) 从 I(X;Y) ≥ 0 想；(b) 回到例 2 的表里找反例——有没有某列的条件熵比 H(X)=2 还大？没有？那想一个 Y 偶尔会带来坏消息的分布；(c) 回例 3。

完整解答

(a) 成立。H(X) − H(X|Y) = I(X;Y) ≥ 0（互信息是相对熵，Jensen 保证非负）。

(b) 不成立。反例：设 X 均匀二元，Y = X 以概率 0.9、Y 独立随机以概率 0.1；则 H(X|Y="独立分支且取罕见值") 可以接近 1 比特……更直接的反例：取 X∈{0,1} 均匀，Y 恒等于 0 但当 X=1 时以 50% 报"?"——具体构造不必背，关键是逻辑：平均不等式不对每一项负责，坏消息会让特定 y 的条件熵超过边际熵。为什么易错：把"平均不增"脑补成"处处不增"。

(c) 不成立。例 3 已算出 D(p‖q) = 0.531 ≠ D(q‖p) = 0.737。为什么易错：被"散度像距离"的直觉带跑，忘记它有方向。

L1 概念辨析"相对熵"与"互信息"满足以下哪种关系？(A) 互信息是相对熵的特例；(B) 相对熵是互信息的特例；(C) 两者无关。并说明理由。
提示

看 I(X;Y) = D(?, ?) 的两个位置分别填了什么分布。

完整解答
选 (A)。I(X;Y) = D(p(x,y) ‖ p(x)p(y))：互信息就是"真实联合分布"对"独立乘积分布"的相对熵，是相对熵取了两个特定分布后的特例。由此 I ≥ 0 免证继承。为什么 (B) 错：一般相对熵的两个分布定义在同一空间上，没有"联合 vs 乘积"结构，无法写成某对变量的互信息。为什么 (C) 错：关系是包含而非无关。
L2 手算推导设联合分布 p(x,y) 为：p(1,1) = 1/2，p(1,2) = 1/4，p(2,1) = 0，p(2,2) = 1/4。计算 H(X)、H(Y)、H(X|Y)、H(Y|X)、H(X,Y)、I(X;Y)，并用两种方式验证链式法则。
提示

先写边际：p(x) = (3/4, 1/4)，p(y) = (1/2, 1/2)。H(X,Y) 直接按联合分布四项算最快——注意 0·log 0 = 0。

完整解答

边际熵：H(Y) = H(1/2,1/2) = 1 比特。H(X) = H(3/4,1/4) = 0.75×log₂(4/3) + 0.25×2 = 0.75×0.415 + 0.5 = 0.311 + 0.5 = 0.811 比特。

联合熵：H(X,Y) = −[0.5·log0.5 + 0.25·log0.25 + 0 + 0.25·log0.25] = 0.5 + 0.5 + 0.5 = 1.5 比特。

条件熵（沿 Y 方向）：Y=1 列条件分布 (1,0) → H = 0；Y=2 列条件分布 (1/2,1/2) → H = 1。H(X|Y) = 0.5×0 + 0.5×1 = 0.5 比特。验证：H(Y)+H(X|Y) = 1+0.5 = 1.5 = H(X,Y) ✓

条件熵（沿 X 方向）：X=1 行条件分布 (2/3,1/3) → H = 0.9183；X=2 行 (0,1) → H = 0。H(Y|X) = 0.75×0.9183 + 0.25×0 = 0.689 比特。验证：H(X)+H(Y|X) = 0.811+0.689 = 1.5 = H(X,Y) ✓

互信息：I = H(X)−H(X|Y) = 0.811−0.5 = 0.311 比特；另一方向 H(Y)−H(Y|X) = 1−0.689 = 0.311 ✓。为什么易错：X=2 行里有 0 概率项，忘了 0·log0=0 会算出 −∞；或把 H(X|Y) 的权重错写成 p(x)。

L2 手算推导计算 D(p‖q) 与 D(q‖p)：p = (1/2, 1/4, 1/4)，q = (1/2, 1/8, 3/8)。验证二者不相等。（log₂(2/3) ≈ −0.585，log₂(3/2) ≈ 0.585）
提示

逐项拆开：第一项 p=q=1/2，log 比值为 0，不贡献。

完整解答

D(p‖q) = 0.5·log₂1 + 0.25·log₂(0.25/0.125) + 0.25·log₂(0.25/0.375) = 0 + 0.25×1 + 0.25×log₂(2/3) = 0.25 − 0.25×0.585 = 0.104 比特。

D(q‖p) = 0.5·log₂1 + 0.125·log₂(0.125/0.25) + 0.375·log₂(0.375/0.25) = 0 − 0.125×1 + 0.375×0.585 = −0.125 + 0.219 = 0.094 比特。

0.104 ≠ 0.094，不对称 ✓。为什么易错：把 q 当权重来加权 log(p/q)——权重永远是第一个分布（真实分布）。

L3 建模应用某病发病率 P(X=1) = 0.01。检测的灵敏度与特异度都是 0.95：P(Y=+|X=1) = 0.95，P(Y=−|X=0) = 0.95。计算检测结果 Y 给疾病状态 X 带来多少互信息，并评论"95% 准确的检测"到底有多大信息量。（可用：log₂0.059 ≈ −4.084，log₂0.161 ≈ −2.635，log₂0.941 ≈ −0.0877，log₂0.000531 ≈ −10.88）
提示

路线：P(Y+) = 全概率 → P(X|Y) 后验 → H(X|Y) 按 Y 两值加权 → I = H(X) − H(X|Y)。H(X) 是二元熵 H(0.01)。

完整解答

第一步：P(Y+) = 0.01×0.95 + 0.99×0.05 = 0.0095 + 0.0495 = 0.059。

第二步：P(X=1|Y+) = 0.0095/0.059 = 0.161——阳性者真患病的概率只有 16%（基础率陷阱）。P(X=1|Y−) = 0.01×0.05/0.941 ≈ 0.000531。

第三步：H(X|Y=+) = H(0.161) = 0.161×2.635 + 0.839×(−log₂0.839) ≈ 0.424 + 0.212 ≈ 0.636；H(X|Y=−) = H(0.000531) ≈ 0.000531×10.88 + 0.9995×0.00077 ≈ 0.0064。

第四步：H(X|Y) = 0.059×0.636 + 0.941×0.0064 ≈ 0.0375 + 0.0060 = 0.0435 比特。H(X) = H(0.01) = 0.01×6.644 + 0.99×0.0145 ≈ 0.0808 比特。

结论：I(X;Y) = 0.0808 − 0.0435 ≈ 0.037 比特。一次"95% 准确"的检测平均只带来 0.037 比特信息——因为疾病太罕见，检测前你就已经 99% 确定"没病"（H(X) 本来就只有 0.08）。为什么易错：把"检测准确率 95%"当成"信息量大"，忽略了互信息是相对检测前的不确定度而言的；基础率越低，同样的检测给的信息越少。
