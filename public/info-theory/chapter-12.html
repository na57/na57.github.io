最大熵

只知道部分统计量时，哪个分布才是"不多假设"的诚实选择？答案：满足约束下熵最大的那个——而且它必然属于指数族。

12.1为什么需要最大熵：只知道部分统计量时，该选哪个分布

上一章（Ch11）的 Sanov 定理告诉我们：在大偏差事件中，最可能出现的"型"是在满足观测约束的所有分布里使 D(q‖p₀) 最小的那个。当基准 p₀ 均匀时，最小化 D(q‖p₀) 等价于最大化 H(q)——"熵最大"的分布形状已经反复出现，本章把它从推论扶正为原则。

动机例：一颗被做了手脚的骰子

掷一颗骰子很多次，你只知道一件事：均值是 4.5（公平骰子的均值是 3.5）。要你猜点数分布，两个现成的答案都不及格：

  • 均匀分布（每面 1/6）：均值是 3.5，与观测直接矛盾——它假设了"没有被做手脚"，而我们明明看到了证据。
  • 正态分布（均值 4.5、配个方差）：支撑集是全实数，会给"点数 7.3"分配正概率——它假装骰子有无穷多面。

两个答案的毛病相同：都塞进了我们并不知道的假设。我们需要一条"只用已知、不多假设"的选择原则：

✅ 最大熵原理（Maximum Entropy Principle）

在满足全部已知约束的分布中，选熵最大的那个。熵度量不确定程度，取最大熵就是：对已知的部分严格遵守，对未知的部分保持最大的诚实无知。

骰子例子里，约束只有"Σp(x) = 1"与"Σx·p(x) = 4.5"两条。12.2 节会证明：这个问题的解必为 p(x) ∝ rˣ 的形状（截断在 {1,…,6} 上的几何型分布），由均值 4.5 唯一锁定 r——不多不少，刚好把已知用足。

💡 关键一跃

最大熵不是"觉得均匀好看"，而是一个反欺骗装置：任何低于最大熵的分布，都必然在某个方向上假装知道了一些约束里根本没有的信息（某个面被偏爱、某个区间被排除……）。选最大熵分布 = 只陈述证据，不添加想象。

⚠️ 常见误区

"最大熵分布就是均匀分布"——错。均匀只是没有任何额外约束（且支撑集有限）时的特例。一旦加上均值约束，答案就变成指数族（几何/指数分布）；给定均值与方差，答案是高斯。12.2 的对照表会钉死这件事。

12.2最大熵定理：最优解为什么必然是指数族

上一节给了原则，这一节把它变成可解的数学问题。设约束为 m 个统计量的均值已知：Σx p(x)·fᵢ(x) = αᵢ（i = 1,…,m）。要求：

maxp H(p) = −∑x p(x) ln p(x)，  s.t. ∑x p(x) = 1，∑x p(x)fᵢ(x) = αᵢ

拉格朗日全步骤推导（一步不跳）

第一步：写拉格朗日函数——每个约束配一个乘子，归一化约束配 λ₀，均值约束配 λᵢ：

L = −∑x p(x) ln p(x) − λ₀(∑x p(x) − 1) − ∑i λᵢ(∑x p(x)fᵢ(x) − αᵢ)

第二步：对每个 p(x) 逐一求偏导并令零。注意 d[p ln p]/dp = ln p + 1，且每个 p(x) 在每条约束的求和里各出现一次：

∂L∂p(x) = −ln p(x) − 1 − λ₀ − ∑i λᵢfᵢ(x) = 0

第三步：解出 p(x)。移项得 ln p*(x) = −1 − λ₀ − Σᵢ λᵢfᵢ(x)，取指数：

p*(x) = exp(−1 − λ₀) · exp(−∑i λᵢfᵢ(x))

前面的常数因子由归一化唯一确定。把常数与符号重新吸收进乘子（λ₀ ← −1−λ₀，λᵢ ← −λᵢ），写成标准形：

p*(x) = exp( λ₀ + ∑i λᵢfᵢ(x) )
✅ 最大熵定理

在均值型约束下最大化熵的分布，必属指数族（Exponential Family）：密度（或概率）写成"充分统计量 fᵢ 的线性组合取指数"的形状。乘子 λᵢ 叫自然参数（Natural Parameters），λ₀ 充当归一化常数（log 配分函数）。由于 H(p) 严格凹、约束线性，最优解存在且唯一。

同一个推导换一个目标立刻升级：对任意基准分布 m 最小化相对熵 D(p‖m)（m 均匀时就是最大熵），同法可得 p*(x) ∝ m(x)·exp(Σᵢ λᵢfᵢ(x))——最大熵与最小相对熵是同一条定理的两张面孔。

例 1（完整手算）：三能级系统，X ∈ {0, 1, 2}，约束 E[X] = 0.5

第一步：写出指数族形状。只有一个约束 f(x) = x，故 p(x) ∝ eλ₁x。记 r = eλ₁，则 p(x) = rˣ/Z，Z = 1 + r + r²。

第二步：代入均值约束解 r。E[X] = (0·1 + 1·r + 2·r²)/(1 + r + r²) = 0.5：

r + 2r²1 + r + r² = 12 ⟹ 2r + 4r² = 1 + r + r² ⟹ 3r² + r − 1 = 0
r = −1 + √136 ≈ −1 + 3.60566 ≈ 0.434（舍去负根，r = eλ₁ 必须为正）

第三步：算配分常数与三个概率。

Z = 1 + r + r² ≈ 1 + 0.434 + 0.189 ≈ 1.623
p ≈ ( 11.623, 0.4341.623, 0.1891.623 ) ≈ ( 0.616, 0.268, 0.116 )

第四步：验证约束。E[X] = 0×0.616 + 1×0.268 + 2×0.116 = 0.268 + 0.232 = 0.500 ✓

第五步：算熵，看约束吃掉了多少自由度。

H = −(0.616·log₂0.616 + 0.268·log₂0.268 + 0.116·log₂0.116) ≈ 0.431 + 0.509 + 0.361 ≈ 1.30 bit

对照无约束时的最大值 log₂3 ≈ 1.585 bit——一条"均值 0.5"的约束吃掉了约 0.28 bit 的自由度。这个差值就是这条信息的价值。

⚠️ 常见误区

"λ 是惩罚强度，越大约束越紧"——错。λ 可正可负，它的取值由约束值 α 唯一反解出来（对偶问题凸优化），不是人为调的旋钮。例 1 里 λ₁ = ln r ≈ −0.83 为负，正是因为均值 0.5 小于均匀时的均值 1——分布要向小值倾斜。

12.3与热力学的联系：同一套数学，温度只是拉格朗日乘子

上一节的解 p*(x) = exp(λ₀ + λ₁f(x)) 看着眼熟——把 f(x) 换成能量 Eᵢ，它立刻变成物理学里最著名的分布。

玻尔兹曼分布 = 能量均值约束下的最大熵分布

一个物理系统可处于能量为 E₁, E₂, … 的微观状态。若我们只知道平均能量 U = Σ pᵢEᵢ，最大熵原理直接给出：

pᵢ = e−βEᵢZ(β)，  Z(β) = ∑i e−βEᵢ

这就是玻尔兹曼分布（Boltzmann Distribution），其中 Z 叫配分函数（Partition Function），β 是"平均能量 U"这条约束的拉格朗日乘子（差一个符号约定）。

💡 Jaynes 的颠覆性读法

Jaynes 指出：统计力学不是一门"发现新物理定律"的学科，而是对微观世界无知时的最大熵推断。温度不是什么神秘的物理实体——它只是"平均能量已知"这条约束的拉格朗日乘子换上 1/(kT) 的马甲。孤立系统趋向平衡，就是分布演化到满足守恒约束的熵最大态。

这也回收了第 9 章的伏笔：为什么热噪声是高斯的？因为固定方差（平均功率）下高斯分布熵最大——Nature 只知道功率约束时，"最诚实"的噪声就是高斯噪声。香农用它来算信道容量，物理家用它来描写热涨落，背后是同一条定理。

⚠️ 常见误区

"热力学第二定律证明了最大熵原理"——方向搞反了。在 Jaynes 视角下，第二定律（孤立系统熵不减）是宏观经验规律，最大熵是推断原则；二者数学同构但解释层级不同：一个管自然界实际发生什么，一个管我们在信息不全时应该相信什么。把它们当同一件事会同时误解两个学科。

12.4Burg 最大熵谱估计：最诚实的外推是让它长成 AR 过程

前三节处理的是静态分布。这一节把同一原则用在随机过程上：观测一段平稳时间序列，只可靠估计出前 p+1 个自相关 r₀, r₁, …, r_p，要重建整条功率谱 S(ω)。难点在于：谱由全部自相关决定，而 r_{p+1} 往后的值我们一无所知。

最大熵原则的过程版

Burg 的答案：在所有"前 p+1 个自相关与观测一致"的平稳过程中，选熵率最大的那个。对高斯过程，熵率为 ½log(2πeσ²)（σ² 是一步预测误差方差），最大化熵率 ⟺ 让过程"在已知约束之外尽量白"——不把任何没观测到的周期性、相关性偷偷塞进去。

✅ 定理（最大熵谱 = AR 谱）

匹配 r₀,…,r_p 的熵率最大平稳过程，恰好是 p 阶自回归过程（Autoregressive Process, AR(p)）：Xn = −Σk=1..p akXn−k + εn。系数由 Yule–Walker 方程（Yule–Walker Equations）解出，可用 Levinson 递推在 O(p²) 内高效求解。

例 2（完整手算）：AR(1) 的最大熵谱

已知 r₀ = 1，r₁ = 0.5，其余未知。

第一步：Yule–Walker 方程解系数。p = 1 时方程就是一条：r₁ = −a₁·r₀（约定 Xn = −a₁Xn−1 + εn），故 a₁ 的预报系数幅度为

a₁ = r₁r₀ = 0.51 = 0.5（即 Xn = 0.5·Xn−1 + εn）

第二步：算激励白噪声方差。一步预测误差 σ² = r₀ − a₁·r₁：

σ² = 1 − 0.5×0.5 = 0.75

第三步：写出谱。AR(1) 的功率谱为

S(ω) = σ²|1 − a₁e−iω|² = 0.75|1 − 0.5e−iω|²

它在 ω = 0 处取得峰值（分母 |1−0.5|² = 0.25，S(0) = 3），向高频单调下降——一条平滑的低通谱，全部由两个观测数字决定。

对照周期图法：两种"填未知"的哲学

经典周期图法等价于把 r_{p+1} 之后的自相关全部设为零——这是一个强硬且虚假的假设（序列突然变得完全不相关），导致谱线泄漏、分辨率受限。最大熵谱相反：高阶相关不设零，而是由 AR 模型自由生长——r_{p+1}, r_{p+2}, … 由递推自然延伸，是"在已知之外最不武断"的外推。

⚠️ 常见误区

"最大熵谱估计假设高阶自相关为零"——恰恰相反，那是周期图法的假设。最大熵是让高阶相关不受额外约束地由模型生成。也正因如此，它对短数据的谱峰分辨率远好于周期图，代价是谱的形状完全由 AR(p) 这一个族决定——族选错，再诚实也救不回来（见 12.5）。

12.5最大熵为什么合理：三条理由与一条边界

前面三节展示了最大熵"能做什么"，最后一节回答"凭什么信它"。理由有三条，硬度递增；边界有一条，必须记住。

理由一（最硬）：熵集中——压倒性多数的序列都长这样

熵集中（Entropy Concentration）：在满足约束的全部长度-n 序列中，型（经验分布）落在最大熵分布附近一个小区间内的序列，占比随 n 指数趋向 1。这是第 11 章型方法的直接推论：一个型为 q 的序列类的概率约为 2−n·D(q‖p*)，只要 q 偏离 p*，D > 0，它的份额就被指数碾压。选最大熵分布不是审美选择，而是押注那个几乎必然出现的宏观态。

理由二（最直观）：Wallis 计数论证

N 个球分进 m 个盒子，宏观态 (n₁,…,nₘ) 的实现方式有 N!/(n₁!…nₘ!) 种。用 Stirling 近似：

1N ln N!n₁!⋯nₘ! ≈ H(p₁,…,pₘ)（pᵢ = nᵢ/N）

熵就是"宏观态的计数对数"。均匀（或满足约束的熵最大）宏观态的实现方式数以指数级碾压其他宏观态——物理系统"奔向平衡"，不过是奔向实现方式最多的状态。

理由三（最哲学）：Jaynes 的诚实性论证

最大熵是"最少假设"的推断：熵是唯一满足几条自然公理（连续性、单调性、组合规则）的不确定性度量；任何低于最大熵的选择，都等价于声称掌握了约束之外的信息。它是推断逻辑里"不撒谎"的唯一选项。

⚠️ 边界：它不回答"约束从哪来"

最大熵只对"给定的约束"负责，对"约束选得对不对"一概不管。骰子例子里若均值其实是 3.5 而你误记成 4.5，最大熵会老老实实地给你一个偏离真相的分布——约束选错，再诚实也白搭。更深一层：如果连用哪一族统计量、哪个分布族都不知道呢？那是下一章的事——第 13 章通用信源编码要在对信源几乎零假设的情况下照样逼近熵极限。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
最大熵原理（Maximum Entropy Principle）
点击翻面 →
定义在满足全部已知约束的分布中，选熵最大的那个。
解决问题只知部分统计量（如均值）时如何选分布——不引入证据之外的假设。
直觉法庭上只陈述证据、不添加想象的证人。
误区以为它总给出均匀分布——均匀只是"无额外约束+有限支撑集"的特例。
何时用Ch11 Sanov 最优型的正面展开；统计力学（12.3）、谱估计（12.4）、机器学习中的最大熵模型。
概念卡 2
指数族（Exponential Family）
点击翻面 →
定义形如 p(x) = exp(λ₀ + Σᵢλᵢfᵢ(x)) 的分布族，fᵢ 为充分统计量。
解决问题最大熵（或最小相对熵）问题的解必然落入此族——把"选分布"变成"解几个乘子"。
直觉约束有多少条，旋钮就有几个；形状永远是"线性组合取指数"。
误区以为只有高斯、指数等"漂亮"分布才属于它——骰子问题里的截断几何分布同样是。
何时用本章 12.2 定理的主角；统计学习理论、广义线性模型的统一框架。
概念卡 3
拉格朗日乘子与自然参数（Natural Parameters）
点击翻面 →
定义每条均值约束配一个乘子 λᵢ；在最优解处它们就是指数族的自然参数，λ₀ 兼作 log 配分函数。
解决问题把"约束值 αᵢ"翻译成"分布形状 λᵢ"，一一对应（对偶凸优化保证唯一）。
直觉约束的价格标签：约束值动一点，λ 告诉你最优熵跟着动多少。
误区以为 λ 是人为调的惩罚强度——它由约束值唯一反解，可正可负。
何时用12.2 推导的核心变量；12.3 中它摇身一变成为倒温度 β。
概念卡 4
配分函数与热力学对应（Partition Function）
点击翻面 →
定义Z(β) = Σᵢ e^(−βEᵢ)，指数族的归一化常数；其各阶导数生成各阶统计量。
解决问题把"求归一化常数"与"算均值/方差"统一：ln Z 对乘子求导即得约束量的均值。
直觉全部状态的"总门票钱"；F = −kT·lnZ 说自由能就是门票总账。
误区以为它只是归一化细节——它是整个热力学量的生成函数。
何时用12.3 热力学对应的枢纽（S = kH、F = −kTlnZ）；概率图模型里同名概念的祖先。
概念卡 5
Burg 最大熵谱估计（Burg's Maximum Entropy Spectral Estimation）
点击翻面 →
定义匹配前 p+1 个自相关的平稳过程中取熵率最大者，其谱即 AR(p) 谱。
解决问题短数据下估计功率谱：不外推零相关，分辨率优于周期图法。
直觉已知之外"尽量白"——让高阶相关由模型自由生长，而不是强行设零。
误区以为它假设高阶自相关为零（那是周期图）；也别忘了结果完全受 AR 族形状限制。
何时用12.4 全部；语音/地震/雷达等短记录谱分析的标准工具。
概念卡 6
熵集中原理（Entropy Concentration）
点击翻面 →
定义满足约束的长度-n 序列中，型落在最大熵分布附近的占比随 n 指数趋于 1。
解决问题为最大熵原理提供最硬的正当性：选它 = 押注几乎必然出现的宏观态。
直觉茫茫人海里，"最普通"的那类人占掉几乎所有名额。
误区以为它只是大数定律的复述——它说的是型的指数集中（概率 ≈ 2^(−nD)），强得多。
何时用12.5 理由一；Ch11 型方法的直接推论，也是统计力学"平衡态"的信息论解释。

📝分层习题

L1 概念辨析判断对错："最大熵分布就是均匀分布。"说明理由，并各举出一个反例。
提示

回忆"约束 → 分布"对照表：均匀分布成立的前提条件是什么？加上均值约束后 12.2 的例 1 给出了什么形状？

完整解答
错。均匀分布只在除归一化外没有其他约束、且支撑集有限时才是最大熵分布。反例一：[0,∞) 上已知均值 μ，最大熵分布是指数分布 (1/μ)e^(−x/μ)，远非均匀；反例二：三能级例子中 E[X]=0.5 给出 p ≈ (0.616, 0.268, 0.116)，是几何型（指数族），不是 (1/3, 1/3, 1/3)；全实数给定均值方差时是高斯。"最大熵 ⟹ 均匀"是把特例当成了通则。
L1 概念辨析判断对错："热力学第二定律（熵增）与最大熵原理是同一件事的两种说法。"
提示

区分两个东西：①自然界实际演化的方向（经验物理定律）；②信息不全时我们应该怎样选分布（推断原则）。它们的数学结构相同，但管辖范围相同吗？

完整解答
半对（数学同构、解释层级不同）。对的部分：在 Jaynes 视角下，孤立系统趋向平衡 ⟺ 分布演化到满足守恒约束的最大熵态，二者共用同一套"约束下最大化熵"的数学。不对的部分：第二定律是关于自然界实际行为的经验物理定律，可以被实验检验、原则上可能被证伪；最大熵原理是关于"我们该如何推断"的逻辑原则，无所谓被实验推翻。说"同一件事"会混淆描述性定律与规范性原则——正确说法是"同构不同义"。
L2 手算推导X ∈ {0, 1, 2}，仅知 E[X] = 0.5。纸笔完成：①写出最大熵分布的指数族形状；②解出参数；③给出三个概率；④验证约束并计算熵，与 log₂3 比较。
提示

设 p(x) ∝ rˣ，把均值约束写成关于 r 的分式方程，交叉相乘得一元二次方程。

完整解答

①一个约束 f(x)=x ⟹ p(x) = rˣ/Z，r = e^λ₁，Z = 1+r+r²。

②均值方程 (r+2r²)/(1+r+r²) = 1/2 ⟹ 2r+4r² = 1+r+r² ⟹ 3r²+r−1 = 0 ⟹ r = (−1+√13)/6 ≈ 0.434（舍负根）。

③Z ≈ 1+0.434+0.189 ≈ 1.623；p ≈ (0.616, 0.268, 0.116)。

④验证：E[X] = 0.268 + 2×0.116 = 0.500 ✓。H = −(0.616·log₂0.616 + 0.268·log₂0.268 + 0.116·log₂0.116) ≈ 0.431+0.509+0.361 ≈ 1.30 bit，比无约束最大值 log₂3 ≈ 1.585 bit 少约 0.28 bit——这条约束的信息量。

L2 手算推导已知平稳过程的前两个自相关 r₀ = 1、r₁ = 0.5。纸笔完成 Burg 最大熵谱：①用 Yule–Walker 方程解 AR(1) 系数；②算激励方差 σ²；③写出谱 S(ω)。追问：若 r₁ = 0（观测到序列当前不相关），最大熵外推给出什么过程？
提示

p=1 时 Yule–Walker 只有一条方程；σ² 是一步预测误差 r₀ − a₁r₁。追问里先算 a₁ 再看谱的形状。

完整解答

①a₁ = r₁/r₀ = 0.5/1 = 0.5，即 Xn = 0.5·Xn−1 + εn。

②σ² = r₀ − a₁·r₁ = 1 − 0.5×0.5 = 0.75。

③S(ω) = σ²/|1 − a₁e^(−iω)|² = 0.75/|1 − 0.5e^(−iω)|²（ω=0 处峰值 S(0) = 0.75/0.25 = 3，向高频单调降）。

追问：r₁ = 0 ⟹ a₁ = 0 ⟹ Xn = εn 即白噪声，S(ω) = σ² 为常数。这正是最大熵的诚实之处：观测不到相关，就绝不假装看到结构——外推出"最白"的过程。

L3 建模应用客服排队仿真：已知平均通话时长 μ = 3 分钟，其余一无所知。①写出约束；②查表给出最大熵分布；③计算 P(T > 5) 与 P(T ≤ 1)；④说明若改用"均匀分布在 [0, 6]"（均值也是 3）会怎样。
提示

时长非负 → 支撑集 [0,∞)；对照表里这一行给出哪个分布？它的尾部概率怎么算（指数分布的生存函数）？均匀版本额外声称了什么？

完整解答

①约束：T ∈ [0, ∞)，E[T] = 3（外加归一化）。

②查对照表第二行：最大熵分布 = 指数分布 f(t) = (1/3)e^(−t/3)（t ≥ 0）。

③指数分布生存函数 P(T > t) = e^(−t/μ)：P(T > 5) = e^(−5/3) ≈ e^(−1.667) ≈ 0.189；P(T ≤ 1) = 1 − e^(−1/3) ≈ 1 − 0.717 ≈ 0.283。

④均匀 [0,6] 均值也是 3，但它偷偷塞进了两个额外假设：通话绝不超过 6 分钟（硬截断，P(T>6)=0），且方差被固定为 (6−0)²/12 = 3（指数分布的方差是 μ² = 9，尾部更厚）。仿真中长通话恰好是排队积压的主要来源——均匀假设会系统性低估等待时间。最大熵选择指数分布，正是因为它除均值外不做任何这类假装知道的事。
