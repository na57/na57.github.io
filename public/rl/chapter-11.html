11.1为什么需要离策略：重要性采样修正半梯度

第 9–10 章一直在在策略（On-policy）的世界里：产生数据的策略和被评估、被改进的策略是同一个。但很多刚需场景天然不是这样——这就是离策略（Off-policy）：用行为策略（Behavior Policy）b 产生的数据，去评估另一个目标策略（Target Policy）π。三种典型动机：

  • 学演示数据：看专家开车的录像，评估"如果我来开会怎样"——数据来自专家，目标是自己的策略。
  • 回放旧经验：经验回放（Experience Replay）池里的数据是几十个版本前的旧策略产生的。
  • Q-learning：学的是贪心目标策略，行动上却用 ε-贪心保持探索——学与做本来就是两个策略。

数据分布错了位，更新方向就偏了。修正工具是重要性采样比（Importance Sampling Ratio）：

ρt = π(At | St)b(At | St)

把它乘到每一步更新前面，得到离策略半梯度 TD(0)：

w ← w + α ρt δt ∇v̂(St, w)，   δt = Rt+1 + γv̂(St+1, w) − v̂(St, w)

完整算例：一步带 ρ 的更新

状态 S 下，行为策略 b 以 0.5 / 0.5 选动作 a1 / a2，目标策略 π 必取 a2。设 v̂(S) = w = 0.3，特征 x(S) = (1)（故 ∇v̂ = 1），步长 α = 0.1。观测到 (S, a2) → R = 1 → 终止：

步骤量算式结果
1重要性采样比 ρπ(a2|S) / b(a2|S) = 1 / 0.52
2TD 误差 δR + γ·0 − v̂(S) = 1 + 0 − 0.30.7
3更新量α ρ δ ∇v̂ = 0.1 × 2 × 0.7 × 10.14
4新权重w ← 0.3 + 0.140.44

若这次观测到的是 a1：ρ = π(a1|S) / b(a1|S) = 0 / 0.5 = 0，更新量整个被乘没——w 不动。这完全合理：目标策略永远不会做 a1，这次观测对"目标策略下的价值"没有任何信息。

💡 关键一跃

ρ 是汇率：把行为策略下的一单位经验，按它在目标策略下的稀缺程度折算。a2 在 b 下出现的频率只有 π 下的一半，所以每见一次 a2 都按双倍计入；a1 在 π 下根本不存在，汇率是 0。

⚠️ 常见误区

以为"乘上 ρ，离策略问题就解决了"。错。重要性采样只修正更新方向的期望——它改的是均值，不是稳定性。下一节就会看到：方向修对了，更新照样能把 w 吹到无穷。此外多步场景下 ρ 要沿轨迹连乘，方差会爆炸（第 12 章的资格迹还要再面对它一次）。

11.2发散实例：从 w→2w 到 Baird 星形反例

上一节给了带 ρ 的更新式，期望方向也修正了——那离策略半梯度 TD 能用了吗？答案是不能，它会发散。本节看两个例子：一个玩具级的精确推导，一个经典的星形反例。

算例一：w→2w，期望更新精确算

极小的一条"转移"：估值为 w 的状态以概率 1−ε 转移到一个估值恰为 2w 的状态（两个状态的特征成比例、被迫共享同一个标量参数 w），以 ε 终止；奖励全 0。按期望更新逐步计算（把步长按每次扫掠归一），半梯度更新变成：

wk+1 = 2γ(1−ε) · wk

取 γ = 0.9、ε = 0.1：放大因子 = 2 × 0.9 × 0.9 = 1.62 > 1。从 w₀ = 1 开始迭代：

k01234510…
wk11.622.62444.25156.887511.1577124.4945→ ∞

机制解剖——三件事同时成立才会炸：

  • 自举（Bootstrapping）：更新目标是"自己估出来的 2w"，误差自喂；
  • 函数逼近：特征成比例 ⇒ w 被强制共享，2w 那个状态的新估值反过来抬高源状态的目标；
  • 更新分布错位：更新按我们指定的分布加权，不看过程实际停在哪个状态——离策略的本质。

算例二：Baird 反例（Baird's Counterexample）

这是 RL 理论里最著名的反例。7 个状态排成星形，参数 w ∈ R⁸，γ = 0.99，奖励恒为 0（所以真值 vπ 处处 = 0）。特征设计：

  • 状态 i（i = 1..6）：x(i) = 2ei + e₈，即 v̂(i) = 2wi + w₈
  • 状态 7（中心）：x(7) = e₇ + 2e₈，即 v̂(7) = w₇ + 2w₈

每个状态有两个动作：dashed 均匀跳到状态 1..6 之一；solid 跳到中心状态 7。离策略预测：目标策略 π = 恒选 solid，而更新按行为分布把 7 个状态均匀加权。

先做期望（DP 式）扫掠，初值 w₀ = (1,…,1)（此时 v̂ 处处 = 3.0）。按期望更新逐步计算可得：

再做采样版：半梯度 TD + 重要性采样（行为策略 50/50 选两动作，选中 solid 时 ρ = 2，α = 0.01）。模拟（α=0.01）实测：t=100 时 v̂≈2.91；t=1000 时降到 −2.44；t=5000 时 ≈−84033；约 t≈9038 发散。

这不是噪声问题，是动力系统意义上的不稳定：期望更新矩阵的特征值含正实部 +0.0222 与 +0.2393——对应方向上的分量每步被放大，按几何速度增长。注意 w₀ 全 1 时估值先降后炸（前 10 次扫掠还在朝 0 走）：不稳定特征向量方向上的初始分量小，但指数增长终将主导一切。

💡 关键一跃

把 w 的迭代想成 wk+1 = A·wk。表格里这个矩阵是 γ-收缩（所有特征值模小于 1）；Baird 用特征共享 + 分布错位把它改造成含特征值 +0.2393 的矩阵——每一次迭代在那个方向放大 1.24 倍，没有任何数据量能救。

⚠️ 常见误区

以为"步长调小就没事"。错。矩阵有正实部特征值时，任何 α > 0 都发散，只是快慢不同——α 改变的是爆炸的时间尺度，不是稳定性本身。采样版用 α=0.01 照样在 t≈9038 发散，就是证据。

11.3致命三角：三要素缺一不可

上一节看到了发散。错不在代码，而在三个" ingredient "的化学反应。Sutton 把它命名为致命三角（The Deadly Triad）：函数逼近 × 自举 × 离策略。三者凑齐，稳定性保证就没了；缺任意一个，都安全。下面三个对照实验，在同一个 Baird MDP 上每次只拆掉一个角。

对照①：去离策略（改回在策略）

同一个目标策略，改用目标策略自身的占用分布 dπ 做期望更新（π 恒走 solid，全部权重落在状态 7 上）。按期望更新逐步计算可得 v̂(7)：

sweep01050500
v̂(7)3.01.79620.23080.0（收敛）

机制：更新分布与转移结构匹配，关键矩阵正定，更新重新成为收缩。

对照②：去自举（改用蒙特卡洛目标）

目标换成真实回报 G = 0（奖励恒 0，回合结束后回报就是 0），保持同样的离策略采样。模拟实测：t = 20000 时精确收敛到 v̂ = 0（w = (0.308, …, 0.308, 1.231, −0.615)）。机制：目标不再依赖自己的估值，误差不会自喂放大——最小化的就是真正的均方误差。

对照③：去逼近（退回表格）

每个状态独立一格（表格是"特征互不相同"的特例），保持同样的离策略更新分布。按期望更新逐步计算可得 V（各状态相同）：

sweep01005001000
V1.00.3660.00660（收敛）

机制：表格下 Bellman 算子是 γ-收缩，逐格互不串扰，离策略只影响收敛速度不影响稳定性。

💡 关键一跃

三角不是"三个 bug 叠加"，而是三个各自无害的设计撞在一起：逼近让参数共享（误差在状态间串扰），自举让目标依赖自身（误差自喂放大），离策略让更新分布与过程占用错位（收缩性证明失效）。三者凑齐，收缩映射的地基就塌了。

⚠️ 常见误区

以为"DQN 有目标网络和经验回放，不就证明三角其实不存在？"错。DQN 恰恰三角全占（深度逼近 × Q 自举 × 回放离策略），它能跑是靠工程手段硬压：目标网络把自举目标冻结半衰，海量回放数据把更新分布拉宽、压住不稳定方向。这是绕行，不是理论豁免——不稳的影子在第 12–13 章还会反复出现。

11.4想直接最小化贝尔曼误差？它不可学习

上一节确认了病根。救场的第一个念头很自然：半梯度不靠谱，那就别绕弯子，直接最小化贝尔曼误差。定义均方贝尔曼误差（MSBE）：

MSBE = ∑s μ(s) [ E[R + γv̂(S′) | s] − v̂(s) ]²

即"期望 TD 误差的平方"按分布 μ 加权。v̂ 越接近满足 Bellman 方程，MSBE 越小——目标看起来天经地义。问题是：它从数据里估不出来。

完整算例：两个 MRP，同样的数据，不同的贝尔曼误差

两个 MRP 产生的数据完全相同：每回合只观测到一个奖励，0 或 1 各半，然后终止。但内部结构不同：

  • MRP1：A → B（R = 0，概率 0.5）或 A → C（R = 1，概率 0.5），B、C 随后终止；
  • MRP2：A′ → 直接终止，R 以各半概率为 0 或 1。
flowchart LR subgraph G1["MRP 一"] A(("A")) -->|"P 0.5 R 0"| B(("B 终止")) A -->|"P 0.5 R 1"| C(("C 终止")) end subgraph G2["MRP 二"] A2(("A'")) -->|"P 0.5 R 0"| T1(("终止")) A2 -->|"P 0.5 R 1"| T1 end
图 11.3 两个 MRP：数据流一模一样（0/1 各半），内部状态结构不同——贝尔曼误差看得见这堵墙，数据看不见。

取候选 v̂ ≡ 0，逐步计算两个 MSBE：

MRP期望 TD 误差MSBE
MRP1BE(A) = 0.5×0 + 0.5×1 − 0 = 0.5；B、C 处为 0μ(A) × 0.5² = 0.5 × 0.25 = 0.125
MRP2BE(A′) = 0.5×0 + 0.5×1 − 0 = 0.51 × 0.5² = 0.25

数据分布一模一样，MSBE 却差一倍。任何只看数据的估计量都无法同时等于这两个值——贝尔曼误差不可学习（Not Learnable）：它依赖 MDP 的内部结构，而不只是数据。

顺带一提残差梯度法（Residual Gradient）：它直接对样本最小化 E[δ²]。做方差分解：

E[δ²] = (E[δ])² + Var[δ]

它比真正的贝尔曼误差多了一个方差项：奖励和转移的随机性也被惩罚，即使期望误差已经是 0。要想无偏地估计 (E[δ])²，需要对同一状态采两个相互独立的后继（double sampling）——表格里勉强可行，函数逼近下几乎做不到（连续状态不会精确重访）。

💡 关键一跃

MSBE 问的是"住在状态 s 内部看，期望误差多大"——这涉及"哪些数据来自同一个内部状态"。数据里只有奖励流；两个 MRP 内部状态划分不同，数据却相同。贝尔曼误差看得见状态的内部墙，数据看不见。

⚠️ 常见误区

把 E[δ²] 当贝尔曼误差最小化。两者差一个 Var[δ]，最优点可能系统性不同：在噪声大的转移上，残差梯度法宁愿牺牲期望误差也要压方差。目标函数一换，学出来的东西就变了。

11.5出路一 · 梯度 TD：换一个可学习的目标

上一节说 BE 不可学。但不是所有"贝尔曼系"的目标都不可学——换一个：均方投影贝尔曼误差（MSPBE）：

MSPBE = ‖ Π B v̂ ‖²μ

读法：先对 v̂ 做 Bellman 期望更新 B，再把结果投影 Π 回可表示的函数空间，量这个"投影后的期望更新"有多大。关键性质：它可以从数据一致地估计——可学习。

TDC（TD with Gradient Correction）对 MSPBE 求真梯度，推出双变量更新：

w ← w + α ρ [ δ x − γ x′ (x⊤ v) ]
v ← v + β ρ (δ − x⊤ v) x

v 是辅助向量（估计投影修正项的方向），用第二个步长 β 学习，β 通常远大于 α 或与之同量级——这叫双时标（two-timescale）。因为它是一个定义良好目标上的真梯度下降，线性 + 离策略也保证收敛（标准步长条件下）。

💡 关键一跃

半梯度 TD 相当于"只走真梯度的一半路"——丢掉了投影带来的修正项。TDC 用辅助向量 v 把丢掉的另一半（−γx′(xᵀv)）补回来。补上了，它就真的在下一个可学习目标的坡，离策略也塌不了。

⚠️ 常见误区

以为 TDC 是"免费的修复"。代价明明白白：参数多一倍（v 与 w 同维）、两个步长要调（β/α 的比例直接影响收敛速度）、实测收敛极慢。理论保证与工程效率在这里是明牌交换。

11.6出路二 · Emphatic TD：不改目标改权重

TDC 改的是目标函数。另一条路完全反过来：目标不动（还是半梯度那套），改更新分布——把行为分布扭向目标策略重视的状态。这就是 Emphatic TD。三个量：

Ft = γ ρt−1 Ft−1 + It  （F−1 = 0）
Mt = ρt Ft，   w ← w + α Mt δt x(St)

兴趣（Interest）It 表示我们多在乎状态 St（常取 1）；追随量（Followon）Ft 沿轨迹累积"目标策略走到这里来的程度"（不断乘 γρ）；强调（Emphasis）Mt 是本步更新的放大倍数。思想：半梯度离策略发散，根源是关键矩阵在行为分布下不正定；把更新权重换成"目标策略下的加权占用"，矩阵重新正定，收敛恢复。

实测：Emphatic TD(0) 在 Baird 反例上

目标策略 = 必 solid、行为策略 50/50、I ≡ 1、α = 0.01。模拟实测：t = 1000 时 v̂(1) ≈ 0.175，已在回落；t = 10000 起 v̂(1..6) = 0.000、v̂(7) = 0.000，收敛到真值；稳态 M ≈ 2.0。对照 11.2：同一个问题、同一个 α，普通半梯度 TD 在 t≈9038 发散，Emphatic 在一万步收敛。

💡 关键一跃

一句话：让"目标策略关心的状态"在更新里嗓门更大，而不是让行为策略的访问频率说了算。F 负责记账（目标策略到这里有多顺），M 负责放大（这一步更新喊多响）。

⚠️ 常见误区

以为 Emphatic 是"既保收敛又没副作用"。代价：强调 Mt 沿轨迹连乘 ρ，方差很大——学习曲线忽快忽慢、瞬态噪声明显。这是它换来"线性离策略收敛保证"的价码；用 Emphatic 就要接受高方差。

11.7错误直觉："半梯度是个 bug"

看完 11.2 的发散，最容易得出的结论是："半梯度 TD 少算了 γ∇v̂(S′) 那一项，是个实现 bug，补上就好了。"这个直觉是错的，值得专门一节说清楚。

  • 半梯度是故意丢掉 γ∇v̂(S′) 的取舍：因为真梯度对应的贝尔曼误差目标不可学习（11.4 已证）——不是算不出来，是从数据里估计不出来。
  • 半梯度在在策略下恰好稳定：第 9 章的收敛证明正是建立在"更新分布 = dπ、与转移结构匹配"上。
  • 它到离策略下发散，不是"实现写错"，而是目标函数的地基问题：在策略下隐含的收缩性不再成立。
  • 所以出路只有两类：换目标（11.5 梯度 TD）或换权重（11.6 Emphatic）。不存在"把梯度补全"的第三条路。
💡 关键一跃

半梯度 TD 是在"可学习"与"忠实于贝尔曼方程"之间的工程妥协：宁可目标歪一点（只要求 TD 不动点），也要保证目标能由数据驱动。它在在策略下歪打正着地稳定；离策略只是把这笔账翻了出来。

⚠️ 常见误区

另一个对称的错误直觉："离策略 + 经验回放，就是把数据存起来再学，能直接用。"错——回放正是离策略的一种（数据由旧策略产生），致命三角照样在。DQN 能跑靠的是目标网络、巨量数据这些额外稳定器，不是回放本身无害。

概念卡 1
重要性采样比 ρ（Importance Sampling Ratio）
点击翻面 →
定义ρt = π(At|St) / b(At|St)，两策略在同状态选同动作的概率之比。
解决问题数据来自 b 却想评估 π——用 ρ 把经验折算到目标策略口径。
直觉汇率：π 下稀罕的动作按倍计入，π 不做的动作汇率为零。
误区以为它解决离策略的一切问题——只修期望方向，不修稳定性，连乘方差还大。
何时用一切离策略校正：本章、Ch12 的离策略资格迹、策略梯度。
概念卡 2
致命三角（The Deadly Triad）
点击翻面 →
定义函数逼近 × 自举 × 离策略三者同时具备时，半梯度 TD 可发散的现象。
解决问题不是工具而是警报：画清价值学习在什么条件下失去稳定性保证。
直觉参数共享（串扰）+ 目标自喂（放大）+ 分布错位（收缩失效）= 地基塌。
误区以为三选一就有害——任意两两组合都安全，必须三者凑齐。
何时用设计任何"逼近 + TD + 回放/演示数据"系统前的自查清单（DQN、离线 RL）。
概念卡 3
Baird 反例（Baird's Counterexample）
点击翻面 →
定义7 状态星形 MRP + 8 维线性特征，γ=0.99、奖励全 0；离策略半梯度期望更新权重发散。
解决问题用最简单的线性系统证明：发散不是噪声，是动力系统不稳定（特征值 +0.0222、+0.2393）。
直觉中心状态被目标策略独宠，更新分布却把权重平摊给边缘——错位产生放大。
误区以为调小步长能救——矩阵有正特征值时任何 α>0 都炸，只是慢。
何时用检验新离策略算法的试金石（TDC、Emphatic 都在它上面验证）。
概念卡 4
贝尔曼误差不可学习（Bellman Error is Not Learnable）
点击翻面 →
定义MSBE 依赖 MDP 内部结构：存在两个数据分布完全相同但 MSBE 不同的 MRP（0.125 vs 0.25）。
解决问题回答"为什么不直接最小化贝尔曼误差"——因为它从数据里估不出来。
直觉贝尔曼误差看得见状态的内部墙，数据只看得见奖励流。
误区把 E[δ²] 当 MSBE 最小化——差一个 Var[δ]，最优点可能错。
何时用理解半梯度为何是取舍、为何需要 MSPBE 这类可学习替代目标。
概念卡 5
梯度 TD / TDC（Gradient-TD）
点击翻面 →
定义对可学习目标 MSPBE 做真梯度下降；TDC 用辅助向量 v 与双时标（α, β）实现。
解决问题线性 + 离策略 + 自举下的收敛保证。
直觉把半梯度丢掉的"投影修正项"用 v 补回来，真正下 MSPBE 的坡。
误区以为是免费修复——参数翻倍、两个步长要调、实测慢一到两个数量级。
何时用需要理论保证的离策略预测；GTD2、GQ 等同族算法。
概念卡 6
Emphatic TD（强调式 TD）
点击翻面 →
定义w ← w + αMtδtxt，Mt=ρtFt，Ft=γρt−1Ft−1+It；不改目标，改更新权重。
解决问题把更新分布从行为分布扭向"目标策略重视的状态"，让关键矩阵重新正定。
直觉让目标策略关心的状态在更新里嗓门更大。
误区以为它方差小——M 沿轨迹连乘 ρ，学习忽快忽慢，这是收敛保证的价码。
何时用兴趣 I 可定制的离策略预测；与资格迹结合（呼应 Ch12）。

📝分层习题

L1 概念辨析致命三角的三要素各是什么？为什么说"任意缺一个就安全"？
提示

回忆 11.3 的三个对照实验：每个实验拆掉的分别是哪一角，结果各自收敛到什么。

完整解答

三要素：函数逼近、自举、离策略。缺任意一个，就重新获得收缩映射或可学习目标：

  • 缺逼近（表格）：Bellman 算子是 γ-收缩，逐格不串扰——对照③收敛到 0；
  • 缺自举（MC 目标）：目标是真实回报，误差自喂的回路断开——对照②收敛到真值；
  • 缺离策略（在策略）：更新分布 = dπ 与转移结构匹配，关键矩阵正定——对照①收敛到 0。

易错点：把"三要素各自有害"当成结论。单个要素都无害（本书前 10 章全在用），危险的是三者叠加。

L1 概念辨析E[δ²] 与 (E[δ])² 差在哪？哪一个才是贝尔曼误差？
提示

用方差恒等式：E[X²] = (E[X])² + Var[X]。

完整解答

E[δ²] = (E[δ])² + Var[δ]，两者差一个方差项。(E[δ])² 的 μ 加权和才是贝尔曼误差 MSBE。E[δ²] 多出 Var[δ]：转移与奖励的随机噪声也被惩罚，即使期望误差已为 0。因此最小化 E[δ²]（残差梯度法）的最优点可能与最小化 MSBE 的点系统性不同。易错点：把"样本 TD 误差的平方和"直接当作贝尔曼误差来优化。

L2 手算推导w→2w 例子改参数：γ = 0.95、ε = 0.2。求放大因子、w₃（从 w₀ = 1 起），并推导一般发散条件。
提示

先写 wk+1 = 2γ(1−ε)·wk，再逐级代入；发散条件 = 放大因子与 1 比大小。

完整解答

第一步，放大因子 = 2γ(1−ε) = 2 × 0.95 × (1−0.2) = 2 × 0.95 × 0.8 = 1.52。

第二步，逐级迭代：w₁ = 1.52；w₂ = 1.52² = 2.3104；w₃ = 1.52³ = 1.52 × 2.3104 = 3.511808 ≈ 3.512。1.52 > 1，发散。

第三步，一般条件：发散 ⟺ 2γ(1−ε) > 1 ⟺ γ(1−ε) > 1/2。反过来给定 γ 可解临界 ε：γ = 0.95 时 ε 的临界值 = 1 − 1/(2×0.95) = 1 − 0.5263 ≈ 0.474——ε 小于它就发散。

L2 手算推导Baird 反例期望更新的第一步手算：w₀ = (1,…,1)，按 1/7 均匀加权求 Δw 的各分量。
提示

先算每个状态的估值与 Bellman 目标（π 恒走 solid，下一步必是状态 7），再按特征把 δ 摊到 w 的各分量。

完整解答

第一步，初始估值：i ≤ 6 时 v̂(i) = 2wi+w₈ = 2×1+1 = 3；v̂(7) = w₇+2w₈ = 1+2 = 3。处处为 3。

第二步，Bellman 目标：π 恒选 solid ⇒ 下一状态恒为 7，奖励 0，故 T = γ·v̂(7) = 0.99 × 3 = 2.97。

第三步，TD 误差：δ(s) = 2.97 − 3 = −0.03，七个状态相同。

第四步，按 1/7 均匀加权摊到特征（Δw = (1/7)∑s δ(s)·x(s)）：

  • j ≤ 6：wj 只出现在 x(j) 中，系数 2 ⇒ Δwj = (2/7)(2.97−3) = (2/7)(−0.03) = −0.00857；
  • w₇ 只出现在 x(7) 中，系数 1 ⇒ Δw₇ = (1/7)(−0.03) ≈ −0.00429；
  • w₈ 出现在全部 7 个特征中（i≤6 系数 1、状态 7 系数 2）⇒ Δw₈ = (1/7)[6×(−0.03) + 2×(−0.03)] = (1/7)(−0.24) = −0.0343。

第五步，解读：第一步方向是"温和下调"，看起来完全正常。但期望更新矩阵含正特征值 +0.2393——这个方向里藏着的不稳定模式每步放大 1.24 倍，sweep 20 左右开始主导（v̂ 已到 −34/−41），到 sweep 69 超过 10⁶。方向正确不等于稳定。

L3 建模应用场景：用十万车辆的历史驾驶日志（人类司机行为各异、状态覆盖不均），训练一个线性特征的车载状态估值器，评估"新自动驾驶策略 π 下各状态的安全价值"。指出致命三角三要素各自在哪里，预测直接上半梯度 TD 会发生什么，并在 TDC 与 Emphatic TD 之间做选择、说明代价。
提示

问自己三个问题：能不能为每种路况建表？目标里有没有用到自己的估值？数据是谁的策略产生的？

完整解答

三要素定位：①函数逼近——路况连续，不可能建表，只能线性/深度特征；②自举——事故罕见，等完整回报（MC）方差太大等不起，TD 用 R+γv̂(S′) 当目标；③离策略——日志由人类司机（行为策略 b）产生，与 π 的占用分布不同，且覆盖不均：危险状态在日志里本就稀少，b 小则 ρ 巨大。

预测：直接上半梯度 TD 会缓慢发散——权重沿不稳定模式漂移，估值先"看起来在收敛"（对照 Baird 前 10 次扫掠还在降），随后爆炸；覆盖差的方向 ρ 巨大，进一步加速失稳。

选择：离线批量评估、对速度不敏感 ⇒ 选 TDC：拿到 MSPBE 真梯度的收敛保证，代价是参数翻倍、双时标（β/α）调参、收敛慢（Baird 上要百万步量级）。若必须在线流式学习、且想用兴趣 I 显式标记高风险状态重点学习 ⇒ 选 Emphatic TD，代价是 M 沿轨迹连乘 ρ 带来的高方差、学习曲线忽快忽慢。两害相权：本场景是离线评估，TDC 更稳。

两个 MRP 产生完全相同的数据（每回合奖励 0 或 1 各半），但 v̂≡0 时 MSBE 分别为 0.125 与 0.25。这说明：
  • A. 数据不足以估计奖励的均值
  • B. 贝尔曼误差依赖 MDP 的内部结构，不能仅从数据估计
  • C. 两个 MRP 的最优 v̂ 相同
  • D. μ 加权的方式写错了
选 B。数据分布相同而 BE 不同 ⇒ 任何只看数据的估计量都无法同时等于两者 ⇒ BE 不可学习。A 错：奖励均值 0.5 完全可以从数据估计；C 与题意无关且事实相反（结构不同）；D 错：差异来自 MRP 内部状态划分，不是权重写错。
自测 4
TDC 在线性离策略下保证收敛，根本原因是：
  • A. 它把步长取得足够小
  • B. 它用重要性采样比修正了更新均值
  • C. 它对可学习目标 MSPBE 做真正的梯度下降
  • D. 它冻结了目标网络
选 C。MSPBE 可从数据一致估计，真梯度下降有标准收敛理论支撑，与在/离策略无关。A 错：小步长救不了半梯度——矩阵有正特征值时任何 α>0 都发散；B 错：ρ 只修均值不修稳定性；D 错：目标网络是 DQN 的工程稳定器，与 TDC 的理论保证无关。
自测 5
Emphatic TD 的主要代价是：
  • A. 需要双时标步长
  • B. 目标函数不可学习
  • C. Mt 沿轨迹连乘 ρ，更新方差大、学习忽快忽慢
  • D. 不能在 Baird 反例上收敛
选 C。强调 Mt = ρtFt，F 沿轨迹不断乘 γρ，连乘使方差放大——这是收敛保证的价码。A 是 TDC 的代价（双时标）；B 错：Emphatic 不换目标，谈不上目标可学性；D 错：实测 t=10000 起 v̂ 收敛到真值 0。
