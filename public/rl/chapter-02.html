2.1动作价值：先回答"哪个动作值得选"

第 1 章的 10 臂测试台就是本章的考场：10 个拉杆，每个拉杆 a 有真实期望收益 q*(a)，但每次拉动拿到的奖励围绕它波动（方差为 1）。你连拉 1000 次，目标是总收益最大。你唯一要学的就是每个动作的"身价"。

形式化：动作 a 的真实价值（True Action Value）定义为选它时的期望奖励：

q*(a) = 𝔼[ Rt | At = a ]

q*(a) 对环境是客观存在的，但你看不见——你只能看到一次次带噪声的奖励。能做的是维护一个估计值 Qt(a)：到时刻 t 为止对 q*(a) 的猜测。最自然的估计就是样本均值（Sample Average）：把 a 被选过的所有奖励取平均：

Qt(a) = a 被选过的各次奖励之和a 被选过的次数 Nt(a)

由大数定律，Nt(a) → ∞ 时 Qt(a) → q*(a)。估计本身无偏，问题是：前期 N 很小时估计很不可靠——这正是探索存在的理由。

增量式更新：不用存全部历史

样本均值有个实现技巧：不必保存所有历史奖励，只需存 (n, Qn)，新奖励 Rn+1 到来时：

Qn+1 = Qn + 1n+1 [ Rn+1 − Qn ]

这条式子是全书的元模板：新估计 = 旧估计 + 步长 ×（新信息 − 旧估计）。方括号里的差是"误差"，步长决定学多快。第 5–7 章的蒙特卡洛、时序差分更新全是这个形状。

手算例：序列 1, 2, 3 的增量均值

设某臂连续三次奖励为 1, 2, 3，用增量式逐步算：

  • Q1 = 1（第一次，直接取奖励）
  • Q2 = Q1 + ½(2 − 1) = 1 + 0.5 = 1.5（= (1+2)/2 ✓）
  • Q3 = Q2 + ⅓(3 − 1.5) = 1.5 + 0.5 = 2（= (1+2+3)/3 ✓）

再练一个：设某臂已选 3 次、Q3 = 2.4，第 4 次奖励 R4 = 3：

Q4 = 2.4 + 14(3 − 2.4) = 2.4 + 0.15 = 2.55

验证：(2.4×3 + 3)/4 = (7.2+3)/4 = 10.2/4 = 2.55 ✓。增量式与直接平均永远一致。

💡 关键一跃

"新估计 = 旧估计 + 步长 × 误差"这个形式值得背下来。误差是新信息带来的惊讶程度：奖励比预期好就往上调，比预期差就往下调。学习 = 系统性地消除惊讶。

⚠️ 常见误区

"Q(a) 是动作的价值"——不准确。Q(a) 只是对价值的估计，q*(a) 才是价值本身。混淆两者会以为"选 Q 最大的就是选最好的"，实际上 Q 最大的可能只是运气最好的——这恰是贪心策略翻车的根源（2.2 节）。

2.2ε-贪心：探索的最简答案，与非平稳性的账单

有了估计 Q(a)，怎么选动作？最直接的答案：永远选当前估计最高的——贪心（Greedy）。但 1.6 节已经宣判过它的死刑：早期估计不可靠，贪心会锁死在运气好的次优臂上。

最简修补：ε-贪心（ε-Greedy）——以 1−ε 的概率选当前估计最高的动作（利用），以 ε 的概率在全部动作中均匀随机选一个（探索）。ε 通常取 0.01–0.1。

手算例：10 臂、ε = 0.1 时每个臂被选中的概率

设当前估计最高的是 3 号臂。一次选择中：

  • 以 0.9 概率走"利用"分支 → 必中 3 号臂；
  • 以 0.1 概率走"探索"分支 → 10 个臂均匀随机，每个 0.1/10 = 0.01，其中也包括 3 号臂。
P(3号臂) = 0.9 + 0.01 = 0.91；P(其余每个臂) = 0.01

注意：探索分支占总选择的 0.1，即每 1000 步约有 100 步在探索。贪心臂以 91% 的概率被选中——ε-贪心不是"ε 概率探索、其余纯贪心"就结束了，探索是均匀洒向所有臂的，包括当前最好的那个。

非平稳问题：步长 1/n 的失效

到目前为止的考场里 q*(a) 是固定的（平稳 stationary）。但现实中目标常常缓慢变化：用户口味在变、机器在老化——这叫非平稳（Nonstationary）问题。此时步长 1/n 是灾难：n 越大步长越小，学到后面几乎不再更新，完全跟不上变化。

对策：用恒定步长 α ∈ (0,1]：

Qn+1 = Qn + α [ Rn+1 − Qn ]

把它递归展开，会发现 Qn+1 其实是历史奖励的指数近因加权平均（Exponential Recency-Weighted Average）：

Qn+1 = (1−α)n Q1 + ∑i=1n α(1−α)n−i Ri

越老的奖励权重按 (1−α) 逐次衰减——近期样本主导估计，目标漂移时估计能跟上。代价：权重和不随 n 收敛到"无限多的证据"，估计永远在波动，不会完全收敛。这是非平稳性收的第一个过路费。

✅ 判定规则

平稳问题用 1/n（收敛、无偏）；非平稳问题用恒定 α（跟踪、永不完全收敛）。判断依据是环境本身会不会变，不是算法偏好。

2.3乐观初始值：把探索"编进"初始信念

ε-贪心的探索是"盲目"的：均匀乱试，不区分哪个臂更没底。其实还有一个几乎零成本的探索手段——动手脚的地方不是选择规则，而是初始估计。

10 臂测试台的 q*(a) 来自 N(0,1)，绝大多数在 ±2 以内。把全部 Q1(a) 故意初始化为 +5（一个过分乐观的值），会发生什么？

  1. 第一次无论选哪个臂，拿到的真实奖励大约都在 0 附近，远低于 +5；
  2. 更新后该臂 Q 值被大幅拉低（如 α=0.1：Q ← 5 + 0.1×(0−5) = 4.5，仍然虚高）；
  3. 贪心规则立刻转向另一个还是 +5 的臂；
  4. 于是每个臂都会被"失望"着轮流试一遍——探索自动发生，不需要任何随机数。

这叫乐观初始值（Optimistic Initial Values）：用系统性高估的初始信念诱导贪心策略去"逐一证伪"每个动作。在早期它甚至比 ε-贪心更有效，因为探索由"失望"驱动、天然覆盖所有臂。

⚠️ 常见误区

"乐观初始值是万能探索方案"——它有两个硬伤：① 一次性：所有臂都被证伪之后，乐观耗尽，若此后环境变化它不会再探索（非平稳问题失效）；② 需要知道"多乐观才算乐观"——初值设低了没效果，设高了浪费早期步数。它是技巧，不是原则。

💡 关键一跃

乐观初始值揭示了一个深刻观点：初始估计本身也是策略的一部分。探索不仅可以来自"选择规则里的随机性"，也可以来自"信念里的偏差"。第 13 章之后你会在"乐观面对不确定性"（optimism in the face of uncertainty）这一原则下再次见到它。

2.4UCB：让"没把握的程度"自己定价

ε-贪心探索时在所有非贪心臂中均匀乱选。可一个试了 1 次的臂和一个试了 100 次的臂，"没把握"程度天差地别——探索应该优先投向没把握的臂。怎么量化"没把握"？

置信上界（Upper Confidence Bound, UCB）动作选择给出答案：

At = argmaxa [ Qt(a) + c √ ln t√ Nt(a) ]

结构一目了然：估值项 + 置信项。置信项里，Nt(a) 越小（越没把握）项越大；ln t 随时间缓慢增长，保证任何臂都不会被永远冷落；常数 c 控制探索强度。若某臂从未被试过（N=0），置信项视为无穷大——必被优先选中。

手算例：t = 11 时各臂的置信项

先备材料：ln 11 ≈ 2.3979，√2.3979 ≈ 1.5485。四个臂的已选次数分别为 5、3、1、0：

臂N(a)置信项 c√(ln t / N)数值（以 c 为单位）
1 号5c × √(2.3979/5) = c × √0.4796≈ 0.6925c
2 号3c × √(2.3979/3) = c × √0.7993≈ 0.8942c
3 号1c × √(2.3979/1)≈ 1.5485c
4 号0未试过，视为 +∞必被选中

读表：3 号臂估值就算不高，也有 1.5485c 的"怀疑加成"；1 号臂被试得多，加成只剩 0.69c。UCB 把"不确定性"折算成分数加在估值上，选的是"乐观估计"最大的臂——这正是"面对不确定性保持乐观"原则的具体化。

⚠️ 常见误区

"ln t 是玄学常数"——不是。它来自 Hoeffding 不等式给出的置信区间：要让"真值超过上界"的概率随时间足够快地衰减，上界宽度必须含 √ln t。换个更糙的项（如常数）会导致某些臂被永久误判。另外注意：UCB 假定问题平稳，且每次决策要遍历全部臂——在非平稳、大动作空间下不实用。

2.5梯度老虎机：不估值，直接学"偏好"

前三节都在"估计价值、再按价值选"。还有一条思路：跳过价值，直接学习每个动作的数值化偏好（Preference）Ht(a)，偏好越大被选概率越高。这就是梯度老虎机（Gradient Bandit）。

动作概率由 softmax（玻尔兹曼分布）给出：

πt(a) = eHt(a)∑b eHt(b)

每步拿到奖励后更新偏好（α 为步长，R̄t 为到目前为止的平均奖励基线）：

Ht+1(At) = Ht(At) + α (Rt − R̄t) (1 − πt(At))
Ht+1(a) = Ht(a) − α (Rt − R̄t) πt(a)，对其余所有 a ≠ At

直觉：奖励 R 超过基线 R̄，说明这步走得比平均水平好 → 提高该动作偏好（幅度按 1−π，越冷门的动作升幅越大），同时压低其余动作的偏好；低于基线则反向。基线 R̄ 用增量式样本均值维护即可。

手算例：三臂梯度老虎机的一步更新

设 H = [0.30, 0.50, −0.20]。先算 softmax（e0.3≈1.3499，e0.5≈1.6487，e−0.2≈0.8187，和≈3.8173）：

π = ( 1.3499/3.8173, 1.6487/3.8173, 0.8187/3.8173 ) ≈ ( 0.3536, 0.4319, 0.2146 )

设选中了 2 号臂，得 R = 1，基线 R̄ = 0.5，α = 0.1：

  • 2 号（被选中）：H₂ ← 0.50 + 0.1×(1−0.5)×(1−0.4319) = 0.50 + 0.05×0.5681 = 0.5284
  • 1 号（未选中）：H₁ ← 0.30 − 0.05×0.3536 = 0.2823
  • 3 号（未选中）：H₃ ← −0.20 − 0.05×0.2146 = −0.2107

新 softmax：exp(0.2823)≈1.3261，exp(0.5284)≈1.6962，exp(−0.2107)≈0.8101，和≈3.8324：

π′ ≈ ( 0.3460, 0.4426, 0.2114 )

2 号臂被选中且奖励高于基线 → 选中概率从 0.4319 升到 0.4426；两个未选中臂概率被压。验证完毕。

💡 关键一跃

梯度老虎机更新式其实是随机梯度上升：可以证明它的期望方向正比于期望奖励对 H 的梯度。这条"直接对策略参数求梯度"的思路，是第 13 章策略梯度方法的雏形——本章先在最简环境里见到它。

2.6上下文老虎机：往完整 RL 迈半步

本章所有方法共用一个致命假设：永远面对同一台机器。但如果"机器"会变呢？比如推荐系统：同一批内容，对不同用户（不同上下文）最优选择不同。

升级一步：上下文老虎机（Contextual Bandit，又叫关联搜索 associative search）。每个时刻环境先给出一个"上下文"（状态），智能体依据上下文选动作，只收到即时奖励。动作影响的是"这一步赚多少"，不影响"下一步看到什么上下文"。

策略自然变成 π(a|s)：每个上下文维护一套自己的 Q 或偏好——第 2 章的全部工具原封不动搬过来，只是按上下文各记一本账。

💡 为什么只是"半步"

完整 RL 比上下文老虎机多一件事：动作会改变下一个状态。下棋时你的落子改变了之后的局面；上下文老虎机里上下文与动作无关，像随机翻牌。少了"动作 → 状态转移"这条边，就没有延迟回报、没有信度分配——第 3 章的 MDP 正是把这条边补回来。

回忆 2.6-1
上下文老虎机与普通老虎机的区别是什么？与完整 RL 还差什么？
点击翻面 →
参考答案
前者每个时刻有可观察的上下文（状态），策略依赖状态；但动作不影响下一个上下文。完整 RL 中动作会改变状态，从而引出延迟回报与信度分配。
回忆 2.6-2
推荐系统为什么适合建模成上下文老虎机？

参考答案
用户画像是上下文，推荐内容是动作，点击是即时奖励；单次推荐基本不改变下一个到达的用户，故无需建模状态转移。

2.7错误直觉大扫除

本章公式少、策略多，误区集中在"把估计当真值"和"把技巧当原则"两类。集中拆三颗雷。

⚠️ 误区一：Q 收敛了，贪心就安全了

样本均值收敛需要"每个臂被试无穷多次"。ε-贪心能保证这一点，纯贪心不能——一旦某个臂早期运气好被锁定，其余臂的 Q 永远停在错误初值上。收敛性是被探索策略保证的，不是估计公式自带的。

⚠️ 误区二：ε 越小越好，最好为 0

ε=0 在平稳、确定的环境下也许侥幸成功，但只要奖励有噪声或环境非平稳，ε=0 就意味着"永不纠错"。10 臂测试台上 ε=0.1 通常显著优于 ε=0.01 和 ε=0：探索花掉的 10% 步数，换来的是找到并锁定真正最优臂。

⚠️ 误区三："哪个方法最好"有标准答案

UCB 方向性探索通常优于 ε-贪心，乐观初值在特定设定下又能反超，梯度老虎机在动作很多时更稳——没有方法在所有问题上最优。工程上的正确姿势是：明确你的问题是否平稳、动作空间多大、奖励噪声多强，再挑匹配的工具。

💡 本章给下一章留的账

本章的一切建立在"无状态"上：动作之间互不干涉，拉这个臂不影响那个臂的明天。可现实里决策相互影响——这一步棋改变了之后的所有局面。状态一旦出现，"动作价值"就必须升级为"状态与动作共同的价值"，这正是第 3 章 MDP 的任务。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
动作价值（Action Value）q*(a)
点击翻面 →
定义选动作 a 时的期望奖励：q*(a) = 𝔼[R | A=a]。
解决问题给"哪个动作好"一个客观标尺。
直觉每台老虎机隐藏的"真实赔率"。
误区与估计 Q(a) 混为一谈——真值不可见，只能逼近。
何时用第 3 章升级为 q_π(s,a) 与 q*(s,a)，贯穿全书。
概念卡 2
样本均值与增量式更新
点击翻面 →
定义用已得奖励的平均估计 q*；增量式 Q ← Q + (1/n)[R − Q]。
解决问题从带噪声的样本中无偏地估计动作价值，且 O(1) 内存。
直觉每次只把估计往新样本方向挪一小步。
误区以为收敛性免费——它需要"每臂无穷次"的探索保证。
何时用元模板：MC/TD/DQN 的更新全是"旧+步长×误差"。
概念卡 3
ε-贪心（ε-Greedy）
点击翻面 →
定义以 1−ε 概率选当前 Q 最大的动作，以 ε 概率均匀随机选任意动作。
解决问题以最小代价保证持续探索，防止锁死次优。
直觉九成熟客点招牌菜，一成机会随机尝鲜。
误区以为探索只洒向差臂——它均匀洒在全部臂上，含最优臂。
何时用第 5-7 章所有 on-policy 算法的默认探索机制。
概念卡 4
UCB（Upper Confidence Bound）
点击翻面 →
定义选 argmax [Q(a) + c√(ln t / N(a))]，估值加不确定性加成。
解决问题让探索有方向：优先投向没把握的臂。
直觉给每个臂报一个"乐观到几乎不可能再高"的价，选报价最高的。
误区把 ln t 当玄学——它来自置信区间的严格衰减要求。
何时用平稳小动作空间；启发第 8 章 MCTS 中的 UCT 树搜索。
概念卡 5
梯度老虎机（Gradient Bandit）
点击翻面 →
定义学动作偏好 H(a)，按 softmax 选；按奖励与基线之差升降偏好。
解决问题不估计价值也能学策略；偏好只需相对大小。
直觉比平均好就加分、比平均差就减分的态度分。
误区以为 H 是价值——H 只有相对意义，平移不变。
何时用第 13 章策略梯度的雏形；基线思想直通 actor-critic。
概念卡 6
非平稳与恒定步长 α
点击翻面 →
定义目标随时间变化的问题；用恒定 α 使估计成为指数近因加权平均。
解决问题1/n 步长萎缩后无法跟踪目标漂移。
直觉旧事按 (1−α) 逐次打对折，新账永远有话语权。
误区以为 α 恒定是近似技巧——它是非平稳性的必然要求。
何时用几乎所有实际 RL 系统（真实环境很少严格平稳）。

📝分层习题

L1 概念辨析以下说法哪些正确？① ε-贪心的探索分支只会在非最优臂中随机；② 样本均值估计在纯贪心策略下也保证收敛到 q*；③ UCB 中从未试过的臂会被优先选中；④ 梯度老虎机的偏好 H(a) 平移一个常数后，softmax 概率不变。
提示

逐条对照：探索分支的均匀性、收敛前提、N=0 的处理、softmax 的平移性质。

完整解答
①错：探索分支在全部动作中均匀随机，包括当前最优臂（它因此多获 ε/k 的概率）。②错：纯贪心可能锁死某臂，其余臂采样次数不再增长，收敛前提被破坏。③对：N=0 时置信项视为无穷大。④对：softmax 分子分母同乘 ec，比值不变——偏好只有相对意义。
L1 概念辨析"既然探索的期望收益低，最优策略就应该尽快停止探索。"这句话对吗？
提示

分平稳/非平稳两种环境讨论；想想 ε 衰减策略与恒定 ε 各自的适用面。

完整解答
在严格平稳的环境里，随估计收敛而衰减 ε（如 εt = 1/t）确实合理。但真实环境多是非平稳的，此时停止探索等于放弃跟踪目标变化——所以实践中常保留一个小的恒定 ε。结论：该说法只在理想平稳假设下成立，不是普适原则。
L2 手算推导某臂已选 5 次，Q5 = 1.6。第 6 次奖励 R6 = 4。(a) 用增量式求 Q6；(b) 改用恒定步长 α = 0.5，求 Q6，并解释两种步长下结果差异的含义。
提示

(a) 步长是 1/6；(b) 步长固定 0.5。比较两个新估计离旧估计的距离。

完整解答
(a) Q6 = 1.6 + (1/6)(4 − 1.6) = 1.6 + 0.4 = 2.0（验证：(1.6×5+4)/6 = 12/6 = 2 ✓）。
(b) Q6 = 1.6 + 0.5×(4 − 1.6) = 1.6 + 1.2 = 2.8。
差异：恒定 α 给新样本 50% 的权重，更新更激进——能跟踪非平稳目标，但估计波动也更大；1/n 给新样本 1/6 权重，平稳环境下更稳、最终收敛。
L2 手算推导UCB 选择：t = 101（ln 101 ≈ 4.6151，√4.6151 ≈ 2.1483），c = 1。三个臂：A 的 Q=1.0、N=20；B 的 Q=0.9、N=5；C 的 Q=0.5、N=2。求各臂的 UCB 总分并选出动作。
提示

分别算 c√(ln t / N)：N=20 → √0.2308；N=5 → √0.9230；N=2 → √2.3076。

完整解答
A：置信项 = √0.2308 ≈ 0.4804 → 总分 1.0 + 0.4804 = 1.4804
B：置信项 = √0.9230 ≈ 0.9607 → 总分 0.9 + 0.9607 = 1.8607
C：置信项 = √2.3076 ≈ 1.5191 → 总分 0.5 + 1.5191 = 2.0191
选 C：虽然估值最低，但最少的尝试次数给了它最大的不确定性加成。这正是 UCB 与贪心的分水岭。
L3 建模应用某新闻 App 要做文章推荐：每次用户打开，从候选池中推一篇，观察是否点击。产品方担心"总是推历史点击率最高的文章，新文章永远没机会"。请：(a) 指出这是哪类问题（普通/上下文老虎机/完整 RL）；(b) 给出两套解决方案并说明各自机制；(c) 指出若用户兴趣随时间变化，方案要做什么调整。
提示

(a) 用户画像是不是上下文？推荐是否改变下一个用户？(c) 联系 2.2 节的非平稳讨论。

完整解答
(a) 上下文老虎机：用户画像是上下文，推荐是动作，点击是即时奖励；单次推荐不改变下一个到达的用户。
(b) 方案一 ε-贪心：90% 推当前最优，10% 随机推（含新文章）——简单但探索盲目；方案二 UCB：新文章 N=0 时置信项无穷大，自动获得曝光，且探索优先级随不确定性排序——更省流量。
(c) 兴趣漂移意味着非平稳：步长改用恒定 α（指数近因加权），且 ε 不宜衰减到 0；UCB 的 ln t 机制假设平稳，可改用滑动窗口统计 N 与 Q。

自测 1
增量式更新 Qn+1 = Qn + (1/(n+1))[Rn+1 − Qn] 中，方括号里的量最准确的含义是：
  • A. 新奖励的绝对大小
  • B. 学习率
  • C. 预测误差：新信息与旧估计的差
  • D. 动作的真实价值 q*(a)
解析：C 正确，它决定更新的方向与幅度。A 错：与旧估计无关就无法定向；B 错：步长是 1/(n+1)；D 错：真值不可见，若可见就无需估计了。
自测 2
10 臂测试台，ε-贪心、ε=0.1，当前 Q 最大的是 5 号臂。5 号臂被选中的概率是：
  • A. 0.9
  • B. 0.91
  • C. 0.99
  • D. 0.1
解析：B 正确——利用分支 0.9 必中 5 号，探索分支 0.1 均匀选 10 臂再贡献 0.01，合计 0.91。A 错：漏掉探索分支也可能选中它；C 错：把 ε 当成了只洒在差臂上；D 错：0.1 是探索总占比。
自测 3
非平稳老虎机中，用恒定步长 α 替代 1/n 的根本原因是：
  • A. 恒定 α 计算量更小
  • B. 恒定 α 使估计收敛更快
  • C. 1/n 在数学上不合法
  • D. 1/n 的权重对新样本越来越小，无法跟踪目标漂移；恒定 α 让近期样本保持权重
解析：D 正确。A 错：两者都是 O(1)；B 错：恰好相反，恒定 α 永不完全收敛；C 错：1/n 在平稳环境下是最优选择。代价与收益的取舍才是本质。
自测 4
UCB 公式中，当某臂 N(a) = 0（从未被试过）时，标准处理是：
  • A. 视为置信项无穷大，优先选中它
  • B. 视为置信项为零，最后才选
  • C. 随机赋一个尝试次数
  • D. 报错，算法无法运行
解析：A 正确——未试过的臂不确定性最大，必须先试。B 错：方向反了，会永远冷落新臂；C 错：破坏理论保证；D 错：公式本身按"先选 N=0 的臂"约定运行良好。
自测 5
梯度老虎机中，若奖励 Rt 高于基线 R̄t，则：
  • A. 只有被选中动作的偏好下降
  • B. 所有动作的偏好都上升
  • C. 被选中动作的偏好上升，其余动作的偏好下降
  • D. 所有偏好不变，只更新基线
解析：C 正确——R−R̄>0 时，选中项加 α(R−R̄)(1−π)，其余项减 α(R−R̄)π。A、B、D 都与更新规则不符；该规则保证"比平均好"的经验提升该动作的相对受欢迎度。
