5.1为什么没有模型就学不了：从动态规划的软肋说起

先顺口交代一句：前四章手算用的是 4×4 gridworld，只因格子少、表格放得下，便于手推 Bellman；从本章起改用 Sutton 原书的 5×5——无模型方法要展示完整回合的回报序列，5×5 的路径长度和数值更贴近原书图表，第 6–8 章的算例都沿用它。

第4章的动态规划（Dynamic Programming, DP）看起来很完美：策略评估、策略改进、价值迭代，一套流程收敛到最优。但它有一个常被忽略的前提——你必须知道环境的完备模型：对每个状态 s 和动作 a，都要写出四元组概率 p(s′, r | s, a)。策略评估里的每一次更新，都要对这个分布求期望。

现实任务几乎从不给你这张表。玩扑克时你不知道对手的发牌分布；机器人行走时你写不出关节力矩到下一姿态的转移函数；推荐系统里你更不可能枚举用户点击的完整条件概率。你能做的只有一件事：让智能体真的去环境里跑，跑出一条条 回合（episode）：

S₀, A₀, R₁, S₁, A₁, R₂, …, ST−1, AT−1, RT

蒙特卡洛方法（Monte Carlo Methods）的思想朴素到近乎笨拙：价值的定义本来就是"期望回报"，那就用实际跑出来的回报取平均来逼近这个期望。不需要模型，不需要自举，只需要经验——而且是"完整的"经验：必须跑到回合结束，才知道这条轨迹到底值多少。

💡 关键一跃

DP 是"看着地图规划"，蒙特卡洛是"亲自走几趟再下结论"。vπ(s) 的定义是数学期望，期望算不出来时，统计学的第一反应永远是：抽样，然后平均。大数定律保证样本均值收敛到期望——这就是蒙特卡洛方法全部的理论根基。

⚠️ 常见误区

"蒙特卡洛是一种新算法。" 错。蒙特卡洛是一种估计哲学：用样本平均替代期望。它可以套在预测问题上（估计 vπ）、控制问题上（找最优策略），也会贯穿本书后面所有方法——第6章的 TD、第7章的 n 步方法，本质上都是在"从经验中平均"这件事上做时间维度上的折中。

5.2一条完整回合怎么变成数字：回报序列与增量均值

上一节说"跑完整回合取平均"，这一节把它落成具体数字。环境是 5×5 gridworld：25 个格子，起点在左上角 (1,1)，终点在右下角 (5,5)；每走一步奖励 −1，进入终点奖励 +10 且回合结束；折扣因子 γ = 0.9。我们评估一个确定性的"傻瓜策略" π：先一路向右，再一路向下。

这个策略从 (1,1) 出发的轨迹是固定的：(1,1) → (1,2) → (1,3) → (1,4) → (1,5) → (2,5) → (3,5) → (4,5) → (5,5)。共 8 步，前 7 步各得 −1，最后一步进终点得 +10。回报（Return）从终点往回算，递推式 Gt = Rt+1 + γ·Gt+1：

增量式均值：不用把历史回报全存下来

最直接的估计是 V(s) = (G₁ + G₂ + … + Gn) / n。但每来一条新回合就重算总和既浪费内存又浪费时间。增量式均值（Incremental Mean）把第 n 个样本并入旧均值：

Vn = Vn−1 + 1n · ( Gn − Vn−1 )

手算一遍：设第一条回合给出 G₁ = −0.434，则 V₁ = −0.434。第二条回合（策略扰动后走了条稍好的路）给出 G₂ = 2.2，则：

V₂ = −0.434 + 12 × ( 2.2 − (−0.434) ) = −0.434 + 2.6342 = −0.434 + 1.317 = 0.883

注意这个公式的结构：新估计 = 旧估计 + 步长 × (目标 − 旧估计)。请记住它——从本章的 MC 到第6章的 TD、Sarsa、Q-learning，所有更新都长这个样子，区别只在于"目标"是什么。

💡 关键一跃

步长 1/n 会随样本增多而越来越小，这是"样本均值"的精确实现。但在非平稳环境（比如策略本身在不断改进）里，你反而希望新样本永远有发言权，于是用常数步长 α：V ← V + α(G − V)。常数 α 不再收敛到单点，而是在真值附近小幅波动——这是用"永不收敛"换"永远跟踪"。

⚠️ 常见误区

"α = 1/n 严格优于常数 α。" 只在平稳分布下成立。MC 控制里策略一直在变，价值函数是移动靶；若用 1/n，后期新经验的影响趋近于零，估计会"冻结"在旧策略的价值上。这就是为什么实际控制算法几乎都用常数 α（如 0.1）。

5.3首次访问还是每次访问：同一状态的两次相遇

上一节的回合里每个状态只出现一次。但随机策略下，一条轨迹完全可能两次经过同一个状态——比如智能体在 (2,3) 附近兜了个圈子。这时一个微妙的问题出现了：这一回合给状态 s 贡献了两个回报样本，用哪个？

  • 首次访问 MC（First-Visit MC）：只用第一次到达 s 之后的那段回报；
  • 每次访问 MC（Every-Visit MC）：每一次到达 s 后的回报都算作一个独立样本。

最小完整例子（3 状态链上兜圈）：回合轨迹 A → B → A → C → 终止，奖励依次为 −1, −1, −1, +10，γ = 0.9。倒推回报：

  • C（t=3）：G₃ = 10
  • A 的第二次访问（t=2）：G₂ = −1 + 0.9 × 10 = 8
  • B（t=1）：G₁ = −1 + 0.9 × 8 = 6.2
  • A 的第一次访问（t=0）：G₀ = −1 + 0.9 × 6.2 = 4.58
方法V(A) 的样本本回合后 V(A) 的估计
首次访问 MC只用 G₀ = 4.584.58
每次访问 MCG₀ = 4.58 与 G₂ = 8 都算(4.58 + 8) / 2 = 6.29

同一条回合，两种方法给出不同的估计：4.58 vs 6.29。差异的来源是：第二次访问的回报 8 嵌在第一次访问的回报 4.58 里（4.58 = −1 + 0.9 × 6.2，而 6.2 又由 8 推出），两个样本统计上相关，不是独立同分布。首次访问 MC 的样本来自定义良好的"从 s 出发的回报分布"，理论分析（无偏性、大数定律）干净漂亮，所以书上的收敛性证明都以它为对象；每次访问 MC 的样本有偏但方差特性不同，实践中同样收敛，有时还更容易实现成增量形式。

💡 关键一跃

把"一次访问后的尾段轨迹"看作一个样本，那么一条长回合其实是一捆彼此重叠的样本。首次访问是"每回合每状态只取一个，保证样本定义干净"；每次访问是"重叠也照单全收，用相关性换样本量"。两者都收敛——区别只在收敛的理论性质与中间过程的表现。

⚠️ 常见误区

"首次访问无偏，所以实践中一定用首次访问。" 未必。无偏性是对"从 s 出发的回报"这个随机变量而言的估计性质，不等于"对下游任务更好"。在函数逼近（第9章起）和在线更新场景里，每次访问的变体反而更常用。选择依据是收敛性质与实现成本，不是"无偏"这块招牌。

5.4从评估到控制：探索是绕不开的门票

会估计 vπ 还不够，我们的目标是找到最优策略。照抄 DP 的 generalized policy iteration（GPI）框架：评估当前策略 → 对所有状态贪心改进 → 再评估 → 再改进……但这里藏着一个 DP 没有的麻烦。

DP 的贪心改进是对模型求 max 算出来的；MC 没有模型，改进只能依赖动作价值函数（Action-Value Function）qπ(s, a)——"在 s 做 a 然后跟 π，值多少"。有了 q，贪心改进就是 π′(s) = argmaxa q(s, a)，完全不需要模型。这正是 MC 控制偏爱 q 而不是 v 的原因。

但估计 q(s, a) 的前提是：每个 (s, a) 对都被尝试过。一个确定性贪心策略在 s 永远只选一个动作，其他动作的 q 永远得不到样本——万一没被选的那个才是好的呢？这就是探索问题在 MC 里的样子。三条出路：

  • 探索性开端（Exploring Starts, ES）：强制每条回合从随机 (s, a) 出发，保证所有对都有非零采样概率。简单，但很多任务做不到（你没法命令机器人"从半空中某个姿态开始"）。
  • ε-贪心策略（ε-greedy）：以 1−ε 选当前最优动作，以 ε 均匀随机。on-policy 路线：评估和改进的就是这个带噪声的策略本身，GLIE（Greedy in the Limit with Infinite Exploration，让 ε 随时间衰减到 0）保证收敛到最优。
  • 离策略（off-policy）：干脆让"跑数据的策略"和"要学的策略"分家——这是下一节的主题。
💡 关键一跃

MC 控制的死穴不在"平均"，而在"覆盖"。价值估计准不准是统计问题，有没有数据是存在性问题。所有 MC 控制算法的设计，本质上都是在回答：用什么机制保证每个 (s, a) 对迟早被试到足够多次？

⚠️ 常见误区

"ε-贪心只是工程 trick，理论上不重要。" 恰恰相反：没有探索机制，MC 控制连收敛的前提都不满足。GLIE 的两个条件——每个 (s, a) 被访问无穷多次、且策略极限为贪心——缺一不可，它们就是 MC 控制收敛定理的核心假设。

5.5离策略蒙特卡洛：用别人的数据学自己的策略

ε-贪心的 on-policy 有个结构性妥协：你评估的是一个永远带 10% 噪声的策略。能不能更贪心一点——学一个纯贪心的目标策略，同时让一个更"浪"的策略去收集数据？这就是离策略（Off-Policy）设定：

  • 目标策略（Target Policy）π：我们想学、想评估的策略（通常是贪心的）；
  • 行为策略（Behavior Policy）b：实际在环境里跑、产生数据的策略（通常更随机，保证覆盖，即 π(a|s) > 0 蕴含 b(a|s) > 0）。

数据是按 b 的口味采的，直接平均得到的是 vb 而不是 vπ。纠偏的工具是重要性采样（Importance Sampling）：一条轨迹在 π 下出现的相对可能性，等于逐动作概率比的连乘——重要性采样比（Importance-Sampling Ratio）：

ρt:T−1 = ∏k=tT−1 π(Ak | Sk)b(Ak | Sk)

注意：环境的转移概率完全不出现——它同时出现在轨迹在两个策略下的似然里，被约掉了。这就是为什么离策略方法依然不需要模型。

手算：一个比率、两种估计

设某状态 s 下有两个动作，目标策略 π 是确定性的（选 a₁ 概率 1），行为策略 b 均匀（各 0.5）。一条回合从 s 出发且前两个决策都恰好选了 a₁：

ρ = 10.5 × 10.5 = 4

若某步 b 选了 a₂，则该步 π(a₂|s) = 0，整条 ρ = 0——这条轨迹在 π 下根本不可能发生，权重为零。现在收集到两条回合：

回合是否符合 πρ回报 G
第1条两步都选 a₁410
第2条第一步选了 a₂0−6

普通重要性采样（Ordinary IS）对 ρG 直接取平均：

V(s) = 4 × 10 + 0 × (−6)2 = 402 = 20

估计值 20，比实际见过的任何回报（10 和 −6）都大！这不是 bug，而是普通 IS 的定义使然：它是无偏的（数学期望恰好是 vπ），但方差可以非常夸张，单次估计可能飞出合理范围。加权重要性采样（Weighted IS）改用权重之和做分母：

V(s) = 4 × 10 + 0 × (−6)4 + 0 = 404 = 10

结果 10，落在已见回报范围之内。加权 IS 有偏（分母里的权重和本身也是随机的），但偏差随样本量消失，且方差通常小得多——实践中几乎总是首选。当回合带折扣时，还有进一步按折扣长度加权的折扣感知重要性采样（Discount-Aware IS），把"长轨迹的高折扣权重"也考虑进比率里，思想相同：让权重更忠实地反映 π 下回报的构成。

💡 关键一跃

重要性采样本质上是"按稀有程度补发权重"：在 π 看来很正常、在 b 看来很少见的行为，每条样本要顶好几条用（ρ = 4 意味着这条样本代表 π 世界里 4 条的量）；π 绝不可能做的行为直接作废（ρ = 0）。普通 IS 忠实但暴躁，加权 IS 用一点偏差换温顺。

⚠️ 常见误区

"ρ 里应该有环境的转移概率。" 没有。推导中 π 与 b 下的轨迹似然分别是 ∏π(a|s)·p(s′|s,a) 和 ∏b(a|s)·p(s′|s,a)，环境项一模一样，比值里全部约去，只剩下策略比。这正是离策略方法"免模型"的关键——也是它脆弱的地方：比率连乘随轨迹变长急剧膨胀，长回合下 ρ 的方差是 MC 离策略方法的阿喀琉斯之踵。

回忆 5.5-2
普通 IS 与加权 IS 的公式差在哪？为什么两条样本（ρ=4, G=10；ρ=0, G=−6）下普通 IS 给出 20 而加权 IS 给出 10？
点击翻面 →
参考答案
普通 IS 分母是样本条数 n：(4×10+0)/2 = 20，无偏但可能超出已见回报范围、方差大；加权 IS 分母是权重和 Σρ：(4×10)/(4+0) = 10，有偏但偏差渐近消失、方差小，实践中更常用。

5.6错误直觉清算："无偏估计，所以 MC 比别的都好"

前面五节给了 MC 一副干净的理论画像：样本均值、无偏、大数定律。这很容易催生一个危险的直觉："MC 是统计上最'正确'的方法，应该优先于一切带偏的方法。" 这条直觉错在把"无偏"当成了全部。拆开看：

  • 无偏 ≠ 好用。普通重要性采样严格无偏，刚才的例子里它给出了 20 这个比所有观测都大的估计——你要真拿它去指导决策，方差会要了你的命。估计量的好坏看的是均方误差（偏差² + 方差），不是只看偏差那一项。
  • "必须等回合结束"不是小毛病。下棋要等终局才知道输赢，但很多任务是持续性的（机器人控制、服务器调度），根本没有"回合结束"这回事；就算有，等到结束才更新意味着学习信号严重延迟。第6章的 TD 用"自举"换掉"等到底"，付出的代价正是引入偏差——而这笔交易在大多数任务里是赚的。
  • "MC 不用模型所以永远安全"。MC 确实不对环境动态建模，但离策略 MC 里的重要性采样比对策略概率极其敏感：b 的某个概率写错一点，连乘之后 ρ 就会系统性失真。免模型不等于免假设。
💡 关键一跃

记住一句话：MC 用零偏差换取零先验，代价是高方差和必须等待。它是不是好方法，取决于你的任务里"回合短不短、方差忍不忍得了"。这个"偏差–方差–等待时间"的三角权衡，会一路贯穿第6、7章。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
蒙特卡洛预测（Monte Carlo Prediction）
点击翻面 →
定义用策略跑完整回合，以实际回报的平均值估计状态价值 vπ(s) 的方法。
解决问题环境模型 p(s′,r|s,a) 未知时，动态规划无法求期望，只能改用采样平均。
直觉问一家餐厅好不好吃：不看菜单（模型），自己去吃十次取平均。
误区以为它适用于任何任务——没有终止态的持续任务里回报永远算不完。
何时用回合制任务、有仿真器可大量采样的场景；也是第6、7章一切改进的参照系。
概念卡 2
回报（Return, Gt）
点击翻面 →
定义从时刻 t 到回合结束的折扣奖励和：Gt = Rt+1 + γRt+2 + …，递推写作 Gt = Rt+1 + γGt+1。
解决问题把"一整条轨迹好不好"压缩成一个数，让平均成为可能。
直觉学期总评：期末成绩权重最大（γ 折现未来），但每一场平时分都算进去。
误区以为必须正着逐项加——倒推递推只要 O(T)，正着算是 O(T²)。
何时用所有价值方法的更新目标：MC 直接用它，TD 用它的"一步截断版"。
概念卡 3
首次访问 / 每次访问（First-Visit / Every-Visit）
点击翻面 →
定义一回合内状态 s 多次出现时，只取首次尾迹回报 vs 每次尾迹回报都计样本。
解决问题一条回合里同一状态的多个"候选样本"如何取舍。
直觉首次访问像"一次采访只录一段"，每次访问像"同一个人每句话都算一条证言"。
误区以为每次访问"重复计数所以错误"——两者都收敛，只是样本相关性与理论性质不同。
何时用理论证明用首次访问；在线/函数逼近场景常用每次访问的增量变体。
概念卡 4
增量式均值（Incremental Mean）
点击翻面 →
定义Vn ← Vn−1 + α(Gn − Vn−1)，α = 1/n 时精确等于样本均值。
解决问题避免存储全部历史回报，O(1) 内存完成均值维护。
直觉老班主任更新对学生的印象：新表现和旧印象的差，乘一个小小的权重。
误区以为 α = 1/n 永远最好——非平稳目标（策略在变）下它会"冻结"，要用常数 α。
何时用全书所有更新规则的母形式；第6章 TD 只是把目标 G 换成自举目标。
概念卡 5
探索性开端与 GLIE（Exploring Starts / GLIE）
点击翻面 →
定义ES：回合从随机 (s,a) 出发；GLIE：无限探索且 ε 渐近衰减到 0 的探索调度。
解决问题贪心改进需要所有 (s,a) 的 q 值，而贪心策略自己不去碰非贪心的动作。
直觉想评价所有菜，就得偶尔点一道"今日最差候选"尝尝。
误区以为探索率固定 ε = 0.1 也能收敛到最优——收敛的是 ε-最优，要 GLIE 衰减才到真最优。
何时用on-policy MC 控制的收敛保障；第6章 Sarsa 沿用同样的探索框架。
概念卡 6
重要性采样（Importance Sampling）
点击翻面 →
定义用逐动作策略概率比 ρ 给行为策略产生的回报重新加权，以估计目标策略的价值。
解决问题想学贪心策略 π，手头的数据却是探索策略 b 跑出来的，分布对不上。
直觉选举民调按人口结构加权：稀有的关键群体，每一票要当好几票计。
误区以为 ρ 含环境转移概率——它恰好被约掉，只剩策略比；真正的麻烦是长轨迹下 ρ 方差爆炸。
何时用一切离策略方法的纠偏核心：第7章 n 步离策略、第12章策略梯度都靠它。

📝分层习题

L1 概念辨析判断并说明理由：「蒙特卡洛方法估计的是样本均值，所以它一定是有偏的；动态规划用精确期望，所以它无偏。」这个说法对吗？
提示

先分清"对谁无偏"：MC 的估计是哪个随机变量的无偏估计？DP 的"精确"又建立在什么前提上？

完整解答

说法错误。逐层拆：

① MC 的样本均值（普通 IS 或直接平均）恰好是对 vπ(s) 的无偏估计——大数定律与期望的线性性保证 E[平均G] = E[G] = vπ(s)。说"一定是有偏的"正好说反了（加权 IS 有偏，但那是另一种估计量）。

② DP 在"模型 p(s′,r|s,a) 完全正确"的前提下确实算出精确期望；但真实场景中模型往往是学出来或拍出来的，模型误差会原封不动地传进价值——此时 DP 是有偏的，偏差来自模型而非统计。

③ 易错点：把"无偏"当成绝对属性。无偏永远是"相对某个真值、在某组假设下"的性质。MC 的假设是采样忠实于真实交互；DP 的假设是模型正确。比较方法时必须连假设一起比较。

L1 概念辨析在 5×5 gridworld 中，状态 (1,3) 在一条回合里出现两次（智能体中途绕回）。同学说："既然每个状态的回报都要用到，那首次访问 MC 就是错的，应该用每次访问。" 你同意吗？
提示

两种方法的样本定义各是什么？收敛性定理对两者分别怎么说？

完整解答

不同意。首次访问并不是"丢弃数据"的权宜之计，而是刻意选择了一个定义干净的采样对象：每个样本都是"从 s 出发的完整回报"这一随机变量的一次独立实现（跨回合意义下），无偏性与大数定律直接成立。每次访问把同回合内相互嵌套的回报（如 4.58 与 8）都计入，样本间相关，但同样可以证明收敛到 vπ。

同学的错误在于把"用了更多数据"等同于"估计更正确"。样本量多 ≠ 估计性质好——相关样本的边际信息是递减的。两种方法都收敛，选择依据是理论性质与实现便利，不是"谁用的数据多"。

L2 手算推导在 5×5 gridworld（步进 −1、终点 +10、γ = 0.9）中，策略走出一条较短回合：(2,4) → (2,5) → (3,5) → (4,5) → (5,5)。求这条回合中状态 (2,4) 和 (3,5) 的回报；若此前 V((2,4)) 已有两个样本均值 1.0，用 α = 1/3 的增量式把本条样本并入，写出完整过程。
提示

从终止端倒推：G((4,5)) = 10，然后逐格乘 0.9 减 1。增量式先算这是第几个样本。

完整解答

第一步：倒推回报。

  • G((4,5)) = 10（进终点拿 +10）
  • G((3,5)) = −1 + 0.9 × 10 = 8
  • G((2,5)) = −1 + 0.9 × 8 = 6.2
  • G((2,4)) = −1 + 0.9 × 6.2 = 4.58

第二步：增量并入。已有 n = 2 个样本、均值 V₂ = 1.0，本条是第 3 个样本，α = 1/3：

V₃ = V₂ + (1/3)(G − V₂) = 1.0 + (1/3)(4.58 − 1.0) = 1.0 + (1/3) × 3.58 = 1.0 + 1.193333… ≈ 2.193

验算：若前两条样本均值 1.0，则总和 2.0；加 4.58 得 6.58，除以 3 = 2.1933…，与增量式一致。✓

L2 手算推导目标策略 π 在某两状态链上恒选动作 a₁（概率 1），行为策略 b 等概率（0.5/0.5）两动作。收集到三条从状态 s 出发的回合：① 两步都选 a₁，G = 6；② 第一步 a₁、第二步 a₂，G = −4；③ 两步都选 a₁，G = 2。分别用普通 IS 与加权 IS 估计 Vπ(s)，写出 ρ、分子分母与结果，并评论哪个更可信。
提示

先逐条算 ρ：只有"π 概率为零"的步会把整条 ρ 打成 0。普通 IS 分母是 3，加权 IS 分母是 ρ 之和。

完整解答

各条 ρ：

  • 回合①：(1/0.5) × (1/0.5) = 4
  • 回合②：第一步 (1/0.5)，第二步 π(a₂|s)/b(a₂|s) = 0/0.5 = 0，连乘得 0
  • 回合③：(1/0.5) × (1/0.5) = 4

普通 IS：V(s) = (4×6 + 0×(−4) + 4×2) / 3 = (24 + 0 + 8)/3 = 32/3 ≈ 10.67

加权 IS：V(s) = (4×6 + 0×(−4) + 4×2) / (4 + 0 + 4) = 32/8 = 4

评论：普通 IS 给出 10.67，比所有观测回报（6, −4, 2）都大，典型的高方差表现；加权 IS 给出 4，是"π 一致的两条样本的加权平均"，恰等于 (6+2)/2，更可信。样本量大时普通 IS 的无偏性会兑现，但小样本下加权 IS 几乎总是更好的选择。

L3 建模应用你在做一个"围棋 AI 陪练"项目：环境规则完全已知（有精确对弈引擎），但想评估一个"中盘让子策略"的胜率。团队里有人提议用动态规划精确求解，有人提议蒙特卡洛。请为这个项目选择方法路线，画出你的评估流程图（mermaid），并说明：① 为什么 DP 在这里不可行；② 用 on-policy 还是 off-policy，重要性采样在这里会遇到什么具体麻烦。
提示

想想围棋的状态数与分支因子；再想想一局棋的回合长度对 ρ 连乘意味着什么。

完整解答

① 为什么 DP 不可行：虽然规则模型"已知"，但 DP 的每次更新要对所有后继状态求期望并维护全状态空间的价值表——围棋合法状态数约 10¹⁷⁰，远超任何存储。DP 的瓶颈不只是"模型未知"，还有"状态空间太大"；MC 用采样绕开枚举，只访问实际经过的状态。

② 选 off-policy + 加权 IS（让探索性更强的行为策略对局，评估让子目标策略）。具体麻烦：一局围棋通常 150–300 手，重要性采样比要连乘 150–300 个策略概率比；只要中盘有几手 π 与 b 分歧大，ρ 就会指数级膨胀或归零，估计方差完全失控。这正是第6–7章引入自举、截断轨迹的动机之一。

解析：D 正确——这正是离策略方法免模型的关键推导。A 错：不是省略，是严格约掉。B 错：p 在两个策略下完全相同（环境不因策略而变），不是互为倒数。C 错：MC 对环境随机性没有任何假设，随机环境的 p 照样被约去。
自测 5
两条样本（ρ=4, G=10）与（ρ=0, G=−6）。普通 IS 与加权 IS 的估计分别是：
  • A. 10 与 20
  • B. 20 与 10
  • C. 都是 10
  • D. 都是 20
解析：B 正确。普通 IS 分母为样本数 2：(4×10+0)/2 = 20；加权 IS 分母为权重和 4：(4×10)/4 = 10。A 把两者写反了。C/D 忽略了两种估计量分母不同这一本质差异——这个差异正是"无偏高方差 vs 有偏低方差"权衡的来源。
