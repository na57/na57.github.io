10.1从预测到控制：动作价值与半梯度 Sarsa

第9章解决了逼近预测：给定策略 π，用 wᵀx(s) 逼近 vπ(s)。但预测从来不是终点——回顾 Ch5–8 的表格型控制（MC 控制、Sarsa、Q-learning），它们全都围绕动作价值 Q(s,a) 展开。为什么？因为控制要在同一个状态里比较不同动作，用 ε-贪心选出下一步；只有 v̂(s) 做不到这一点：没有环境模型时，状态值无法告诉你"哪个动作通向高价值的后继"。这就是本章的第一步——把逼近对象从 v 换成 动作价值函数（Action-Value Function）：

q̂(s, a, w) = wᵀx(s, a)

关键设计：特征向量 x(s,a) 把动作也编码进去，一个 w 同时服务所有动作。在状态 s 要决策时，对每个候选动作 a 算一次 q̂(s,·,w)，取最大者（或以 ε 概率随机）——这就是 ε-贪心策略改进。

更新规则是 Ch6 Sarsa 的直接推广——半梯度 Sarsa（Semi-gradient Sarsa），一种在策略（On-policy）控制：行为策略与目标策略同为对 q̂ 的 ε-贪心。

w ← w + α [ R + γ q̂(S′, A′, w) − q̂(S, A, w) ] ∇q̂(S, A, w)

线性逼近 q̂ = wᵀx(s,a) 时，∇q̂(S,A,w) = x(S,A)——梯度就是特征本身。若 S′ 是终止态，约定 q̂(终止, ·) = 0。

完整算例：两步回合，手算 w 的两次更新

回合片段：(S₀, right) → R=0 → S₁；(S₁, right) → R=1 → 终止。特征 x(S₀,right)=(1,0)、x(S₁,right)=(0,1)，初始 w₀=(0.2, 0.5)，α=0.5，γ=1。

步骤当前 (S,A)q̂(S,A)R自举项δ更新后 w
1(S₀,right)0.20γ·q̂(S₁,right)=0.50 + 0.5 − 0.2 = 0.3(0.35, 0.5)
2(S₁,right)0.51终止 = 01 + 0 − 0.5 = 0.5(0.35, 0.75)

逐步验算：

  • 第1步：q̂(S₀,right) = w·x = 0.2×1 + 0.5×0 = 0.2；δ = 0 + 1×0.5 − 0.2 = 0.3；w ← (0.2,0.5) + 0.5×0.3×(1,0) = (0.2+0.15, 0.5) = (0.35, 0.5)。
  • 第2步：δ = 1 + 0 − 0.5 = 0.5；w ← (0.35,0.5) + 0.5×0.5×(0,1) = (0.35, 0.5+0.25) = (0.35, 0.75)。
  • 对照真值：q(S₁,right)=1，q(S₀,right)=0+1×1=1。w 的两个分量都从初始值朝 1 方向移动（0.2→0.35，0.5→0.75）——方向正确。
💡 关键一跃

半梯度 Sarsa = Ch6 的表格 Sarsa 把"查表项"换成 wᵀx(s,a)。表格只是 x 为 one-hot 特征的特例——本章所有公式令 x 取 one-hot 就退化回 Ch6。你早就见过它，只是换了一身衣服。

⚠️ 常见误区

"动作多了，那就给每个动作单独训练一个函数吧。" 不必。特征是 (s,a) 的函数，所有动作共享一个 w，动作间的泛化（相似动作价值相近）正是白送的收益。把它学成 |𝒜| 个互不相干的模型，等于把泛化能力扔进垃圾桶。（实践中确有"共享主干 + 每动作一个输出头"的网络，但那本质仍是共享表示，不是独立训练。）

10.2n 步半梯度 Sarsa 与 Mountain Car

上一节的一步 Sarsa 自举快、方差小，但 Ch7 已经告诉我们：一步 TD 与蒙特卡洛之间有一整个谱系，n 步往往比两个端点都好。逼近之下同样如此——把更新靶子从一步 TD 目标换成 n 步回报（n-step Return）即可：

Gt:t+n = Rt+1 + γRt+2 + ⋯ + γn−1Rt+n + γn q̂(St+n, At+n, w)
w ← w + α [ Gt:t+n − q̂(St, At, w) ] ∇q̂(St, At, w)

结构与 Ch9 的 n 步预测完全平行：靶子减估计、乘梯度、乘步长。前 n−1 个奖励是实测，第 n 步用当前 q̂ 自举。

Mountain Car（例 10.1）：连续状态的第一场实战

一辆动力不足的小车卡在两山之间的谷底，直接踩油门冲不上坡，必须先反向荡起来积蓄动能才能翻过山顶。状态是 (位置, 速度) 两个连续量；奖励恒为 −1，直到过顶回合结束。

连续状态没法列表——这是函数逼近的用武之地。Sutton 用的特征是 瓦片编码（Tile Coding）：

  • 在二维状态空间上铺多层网格，层与层之间彼此错开一小段距离；
  • 任一状态落在每层的恰好一个格子里，把该格对应的特征置 1，其余置 0；
  • 总特征数很大，但每一步只有少数几个非零——稀疏二值特征，线性 q̂ = wᵀx 就够用。

为什么有效：邻近的状态在大多数层里落进相同或相邻的格子，共享大量瓦片——对一个状态的更新自动泛化到附近状态；多层的偏移又提供了分辨率。配上 ε-贪心与 n 步（Sutton 用 n=1 与 n=8 对比，中等 n 学习明显更快），线性半梯度 Sarsa 就能轻松学会"荡上去"的策略。

💡 关键一跃

瓦片编码 = 手工设计的"核"。它把"邻近状态价值应相近"这个先验硬编码进特征表示，用粗粒度的划分换取线性方法的稳定性、速度和可解释性——在深度网络流行之前，这就是连续控制的标准做法。

⚠️ 常见误区

"n 越大信息越全，直接取到回合结束最好。" 错。n 大则偏向蒙特卡洛——方差大、要等更久才能更新；n 小则偏向一步 TD——自举偏置大。这个权衡在逼近下原样存在，Mountain Car 上中等 n 通常优于两端。

10.3平均奖励：没有终点时"好"的定义

前两节都默认回合会结束——Mountain Car 总会过顶。但大量真实任务是 持续任务（Continuing Task）：服务器调度、恒温控制、常驻机器人，没有终止态，交互永不停止。相对地，有终止态的叫 回合任务（Episodic Task）。没有终点，"总回报"发散，那"好"到底指什么？本节给出答案：平均奖励（Average Reward）——策略 π 下每步奖励的长期平均：

r(π) = limh→∞ 1h ∑t=1..h 𝔼[Rt] = ∑s μπ(s) ∑a π(a|s) ∑s′,r p(s′,r|s,a) · r

其中 μπ 是策略 π 诱导的稳态分布（Stationary Distribution）。当马尔可夫链满足遍历性（Ergodicity）——从任何状态出发都能到达任何状态——极限存在且与起始状态无关，r(π) 是策略的固有属性。

完整算例：两状态 MRP 的 r(π) 与差分值

单个策略（无选择，MRP）：A→B 确定性、R=0；B→A 确定性、R=2。

flowchart LR A["状态 A"] -->|"R = 0"| B["状态 B"] B -->|"R = 2"| A
图 10.1 两状态确定性 MRP：每两步拿到奖励 2，平均每步 1。

第一步，求稳态分布：链是周期 2 的确定性环，长期看一半时间在 A、一半在 B，μ(A) = μ(B) = 1/2。

第二步，求 r(π)：r(π) = μ(A)·0 + μ(B)·2 = 0.5×0 + 0.5×2 = 1。直觉检验：每两步进账 2，平均每步 1 ✓。

有了平均奖励，就能定义 差分回报（Differential Return）——每一步先扣掉平均水平再累计：

Gt = Rt+1 − r(π) + Rt+2 − r(π) + Rt+3 − r(π) + ⋯

各项围绕零波动，遍历性保证这个无穷级数收敛（不像原始回报那样发散）。相应的 差分值函数（Differential Value Function）vπ(s) = 𝔼π[Gt | St=s] 满足差分 Bellman 方程：

v(s) = 𝔼[ R − r(π) + v(S′) ]

第三步，求差分值：v(A) = 0 − 1 + v(B)；v(B) = 2 − 1 + v(A) = 1 + v(A)。取基准 v(A) = 0，则 v(B) = 1。回代检查：v(A) = −1 + 1 = 0 ✓。注意：把所有 v 同时加一个常数 c，方程两边依然成立——差分值只确定到加性常数，有意义的只是状态间的相对差（B 比 A 好 1）。

💡 关键一跃

平均奖励像一条"基准线"：每步奖励先与基准线比较，高出记正、低于记负。差分值衡量的不是"这个状态值多少"，而是"从这里出发，能比平均水平好多少"。

⚠️ 常见误区

"平均奖励嘛，把历史奖励求个平均不就行了。" 不行。历史平均只给你一个孤零零的数；Bellman 结构——用后继的值表示当前的值——必须靠差分回报才成立。没有这个递归结构，就没有 TD 更新可用，第9章的全套武器都作废。

10.4为什么逼近之下折扣设置站不住

上一节给持续任务立了新目标，但你应该追问：表格法里 γ<1 的折扣用得好好的，为什么非换不可？答案是：折扣目标的"干净"依赖表格表示，一旦换逼近就塌了。

表格法：每个状态有独立的表项，v̂ 可以精确等于 vπ，"所有状态误差同时为零"是可达的、毫不含糊的目标。γ<1 只管保证回报收敛，目标定义毫无歧义。

函数逼近：w 的维度远小于状态数，v̂ 不可能处处等于 vπ，必须回答"在哪个状态上误差更重要"。Ch9 的目标是投影误差 ‖vπ − v̂‖μπ——按策略的稳态分布 μπ 加权。麻烦正在这里：

💡 关键一跃

μπ 依赖被评估的策略本身。策略一改，状态分布跟着改，误差的权重跟着改——"什么叫好"的尺子随被测量者一起动。于是"最优策略"陷入循环定义：最优 = 按它自己引起的分布加权误差最小的策略？这在概念上是站不住的。而平均奖励目标 r(π) 是一个单一标量，不依赖任何 w、不依赖状态加权，定义干干净净。

结论：continuing + 函数逼近 → 用平均奖励；episodic 任务（有终止态吸收，分布的麻烦不出现）折扣照用。

⚠️ 常见误区

"这是纯哲学洁癖，工程上无所谓。" 恰恰相反：目标里含 μπ 时，连"策略改进了没有"都可能无法判定——两个策略的投影误差是在两套不同权重下算出来的，直接比较没有意义。目标不干净，改进无从谈起。

10.5差分半梯度 Sarsa

目标定了，算法就是把 10.1 的半梯度 Sarsa 改成"差分版"：γ 退休，换成在 δ 里减去平均奖励的估计 r̄。核心是 差分 TD 误差（Differential TD Error）：

δt = Rt+1 − r̄t + q̂(St+1, At+1, w) − q̂(St, At, w)

以及一组双时标（Two-time-scale）更新——w 和 r̄ 各走各的速度：

w ← w + α δt ∇q̂(St, At, w)      r̄ ← r̄ + β δt

取 β≪α：r̄ 移动得慢，w 在"近似冻结的 r̄"下快速追踪差分动作值，然后 r̄ 再缓缓挪一步。两个回路时间尺度分离，避免互相追逐振荡。策略照旧是对 q̂ 的 ε-贪心——在策略控制。

完整算例：两状态 MRP 上的两步更新

沿用 10.3 的 MRP（A→B 得 0，B→A 得 2，真值 r(π)=1）。特征 x(A)=(1,0)、x(B)=(0,1)，初始 w₀=(0.5,0.5)，r̄₀=0.5，α=0.5，β=0.1。

转移Rq̂ 当前q̂ 下一δ = R − r̄ + 下一 − 当前更新后 w更新后 r̄
A→B00.50.50 − 0.5 + 0.5 − 0.5 = −0.5(0.25, 0.5)0.45
B→A20.50.252 − 0.45 + 0.25 − 0.5 = 1.3(0.25, 1.15)0.58

逐步验算：

  • 转移 A→B（R=0）：q̂(A)=0.5，q̂(B)=0.5，δ = 0 − 0.5 + 0.5 − 0.5 = −0.5；w ← (0.5,0.5) + 0.5×(−0.5)×x(A) = (0.5−0.25, 0.5) = (0.25, 0.5)；r̄ ← 0.5 + 0.1×(−0.5) = 0.45。
  • 转移 B→A（R=2）：此时 q̂(B)=0.5、q̂(A)=0.25，δ = 2 − 0.45 + 0.25 − 0.5 = 1.3；w ← (0.25,0.5) + 0.5×1.3×x(B) = (0.25, 0.5+0.65) = (0.25, 1.15)；r̄ ← 0.45 + 0.1×1.3 = 0.58。
  • 方向检查：真值 r(π)=1，r̄ 从 0.5 → 0.45 → 0.58 震荡上行，朝 1 靠拢；w 的 B 分量涨到 1.15、A 分量降到 0.25——正是 10.3 差分值 v(A)=0、v(B)=1（允许差一个常数）的形状：B 比 A 好约 1。
💡 关键一跃

r̄ 是"会学习的基准线"。δ 一肩挑两职：告诉 w 哪个状态-动作比预期好多少，同时告诉 r̄ 平均水平该上调还是下调。一个信号，两处受用。

⚠️ 常见误区

"r̄ 直接用历史奖励的滑动平均估计不就行了？" 不行。滑动平均估的是行为分布下的滞后均值，与当前值函数不自洽；用 δ 驱动 r̄ 才与差分 Bellman 方程一致——w 与 r̄ 收敛到同一组方程的解，滑动平均做不到这一点。

10.6错误直觉："γ 取 0.999 就万事大吉"

听完 10.3–10.5，很多人心里还剩最后一个抵抗：何必发明新目标？γ 取得足够接近 1，折扣不就约等于平均了吗？三条反驳：

  1. 方差爆炸：γ→1 时折扣回报的有效累计时域约 1/(1−γ) 步——γ=0.999 就是 1000 步的奖励噪声全灌进一个更新信号，学习慢且抖。
  2. μ_π 依赖不会消失：10.4 的循环定义源于"目标里含随策略变动的权重"，γ 取得再大，这个结构性毛病原样保留。
  3. 最优策略不一致：γ=0.999 的折扣最优策略 ≠ 平均奖励最优策略——折扣把近期奖励不成比例地加权，会偏爱"先甜后苦"的行为；只有取 γ→1 的病态极限，两者才趋于一致。
💡 关键一跃

平均奖励是 continuing 任务的母语，γ<1 是 episodic 任务的母语。用错语言不是完全不能表达，而是词不达意——你以为说的是"长期表现好"，实际说的是"近期表现被放大一千倍的好"。

⚠️ 常见误区

"反正工程上大家都用折扣，跑出来的策略也不差。" 工程惯性与理论正确性是两回事。实践里调得动不代表目标在概念上站得住；知道它不干净，至少在结果异常时知道去哪里找 bug。

📝分层习题

L1 概念辨析控制为什么用 q̂(s,a)，而预测只用 v̂(s) 就够？
提示

想想 ε-贪心在决策的那一刻需要什么信息；没有模型时，v̂(s) 缺了什么。

完整解答

控制的核心动作是在同一状态比较不同动作，据此做 ε-贪心策略改进——动作必须能作为函数的输入，这就是 q̂(s,a,w) = wᵀx(s,a)。预测只需要回答"这个状态值多少"，v̂(s) 即可。

没有模型时，v̂(s) 无法推出该选哪个动作：知道状态 s 值 5，却不知道 a₁、a₂ 各自通向哪里、哪个更好。有模型时可以用 v̂ 做一步前瞻（max_a Σ p·v̂(s′)），但无模型设定下此路不通。

L1 概念辨析差分回报 Gt 里为什么要每一项都减去 r(π)？
提示

不减的话，这个无穷级数会怎么样？减了之后各项的符号意味着什么？

完整解答

不减时，continuing 任务的原始回报 ΣR 随步数线性增长（平均每步进账 r(π)>0 时趋于 +∞），级数发散，无法定义值函数。

逐项减去 r(π) 后，各项变成"这一步比平均水平好多少"，围绕零波动；遍历性保证正负大体抵消，级数收敛。收敛了才有 vπ(s)=𝔼[Gt|s]，才有差分 Bellman 方程 v(s)=𝔼[R − r(π) + v(S′)]——减掉 r(π) 是 Bellman 递归结构得以成立的前提，不是可有可无的装饰。

L2 手算推导手算一步差分半梯度 Sarsa：x(A)=(1,0)、x(B)=(0,1)，w=(0.4,0.4)，r̄=0.8；发生转移 A→B、R=1，B 非终止；α=0.5，β=0.1。求更新后的 w 与 r̄。
提示

先算两个 q̂，再算 δ = R − r̄ + q̂(B) − q̂(A)，最后分别用 α、β 更新 w（沿 x(A) 方向）与 r̄。

完整解答

① q̂(A) = w·x(A) = 0.4×1 + 0.4×0 = 0.4；q̂(B) = 0.4×0 + 0.4×1 = 0.4。

② δ = R − r̄ + q̂(B) − q̂(A) = 1 − 0.8 + 0.4 − 0.4 = 0.2。

③ w ← w + αδ∇q̂(A) = (0.4,0.4) + 0.5×0.2×(1,0) = (0.4+0.1, 0.4) = (0.5, 0.4)。

④ r̄ ← r̄ + βδ = 0.8 + 0.1×0.2 = 0.82。

解读：这一步奖励 1 高于基准 0.8，δ>0，于是 A 的权重上调（A 变得更"值钱"），基准线 r̄ 也随之上调。

L2 手算推导三状态环 MRP：A→B（R=0）、B→C（R=0）、C→A（R=3），全部确定性。求 r(π) 与一组差分值，并回代验证。
提示

确定性环上每个状态的长期占比相同；差分 Bellman 方程逐边列出，取一个状态为基准 0 再解。

完整解答

① 稳态分布：周期 3 的确定性环，μ(A)=μ(B)=μ(C)=1/3。

② r(π) = (1/3)×0 + (1/3)×0 + (1/3)×3 = 1。直觉：每三步进账 3，平均每步 1 ✓。

③ 差分 Bellman 方程逐边展开：

v(A) = 0 − 1 + v(B)；  v(B) = 0 − 1 + v(C)；  v(C) = 3 − 1 + v(A) = 2 + v(A)。

④ 取基准 v(A) = 0 → v(B) = −1 + v(C)，v(C) = 2 + 0 = 2 → v(B) = −1 + 2 = 1。

得 v(A)=0，v(B)=1，v(C)=2。

⑤ 回代验证：v(A) = −1 + 1 = 0 ✓；v(B) = −1 + 2 = 1 ✓；v(C) = 2 + 0 = 2 ✓。含义：离大奖励越近的状态越值钱（C 下一步就拿 3）。

L3 建模应用服务器访问控制（参照 Sutton 例 10.2 Access-Control Queuing）：10 台服务器各自忙闲不一，客户按 4 种优先级到来；每个到达的客户，你要决定"接受"（分配一台空闲服务器，按优先级获得奖励）还是"拒绝"（奖励 0）。服务器服务完会释放。要求：写出状态/动作/奖励，设计特征，写出差分半梯度 Sarsa 的一步更新，并说明为什么这个任务必须用平均奖励而不是折扣。
提示

状态要同时描述"资源剩多少"和"这单值多少"；动作只有两个；想想任务有没有终点、状态分布跟不跟策略走。

完整解答

MDP 三要素：

  • 状态 s = (空闲服务器数 n ∈ {0,…,10}, 当前到达客户优先级 h ∈ {1,2,3,4})；
  • 动作 a ∈ {接受, 拒绝}（n=0 时只能拒绝）；
  • 奖励 R = 2h−1（接受优先级 h 的客户，得 1/2/4/8），拒绝得 0。

特征设计：x(s,a) 用 one-hot 的交叉积——空闲数 one-hot(11 维) × 优先级 one-hot(4 维) × 动作指示(2 维)，共 88 维的稀疏二值向量，q̂(s,a)=wᵀx(s,a)。

一步更新：δ = R − r̄ + q̂(S′,A′,w) − q̂(S,A,w)；w ← w + αδ·x(S,A)；r̄ ← r̄ + βδ（β≪α）。策略为对 q̂ 的 ε-贪心。

为什么必须用平均奖励：①客流不停，任务天然 continuing，没有终止态；②状态分布随策略变化——拒绝得多、空闲服务器就多，μπ 明显依赖 π，正中 10.4 的折扣目标失效情形；③业务关心的本来就是"单位时间收益"，即 r(π) 本身。学出来的策略会呈现合理形状：空闲多时几乎都接，只剩一台空闲时只接高优先级客户。
