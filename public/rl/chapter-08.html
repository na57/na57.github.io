CHAPTER 08 · 表格型无模型方法

表格型方法的统一：规划与学习

第5–7章把无模型学习的武器备齐了；本章把它们收进同一个坐标系，再让经验顺手喂出一个环境模型——用模型在"脑内"重演经验，把每一次更新都花在刀刃上。

本章在主线上的位置：第5–7章给出了从 MC 到 TD 到 n 步的完整谱系 → 本章用一个统一视图收编它们，并让"学来的模型"反过来产生经验（Dyna），用优先扫掠把更新花在刀刃上 → 第9章起离开表格、进入函数逼近。
第8章回答主线上的一个问题：无模型方法（学习）与有模型方法（规划）真的是两回事吗？能不能让同一个更新公式同时消化真实经验和模拟经验？

8.1统一视图：三个维度收编前五章

第5章蒙特卡洛、第6章时序差分、第7章 n 步自举，看上去是三个不同的算法，各有一套公式、一套直觉。但把它们和第4章的动态规划摆在一起，你会发现它们其实生活在同一个设计空间（Design Space）里，只是坐标不同。这个空间由三个维度张成：

  • 更新深度：目标值回望多远。一步（TD(0)、DP）→ n 步（第7章）→ 直到回合结束（MC，深度 ∞）。
  • 更新宽度：目标值对后继取的是采样更新（Sample Update，只用一个实际采到的后继）还是期望更新（Expected Update，对所有后继按概率加权求和）。
  • 策略关系：在策略（On-Policy，学的就是正在行为的策略）还是离策略（Off-Policy，学目标策略、用行为策略采数据）。
方法更新深度更新宽度策略关系目标值的"造法"
动态规划（DP）1 步期望均可∑ p(s′,r|s,a) [ r + γV(s′) ]
蒙特卡洛（MC）∞（整回合）采样均可实际回报 Gt
TD(0) / Sarsa1 步采样在策略R + γQ(S′, A′)
Q-learning1 步采样离策略R + γ maxa′ Q(S′, a′)

注意期望 Sarsa 的位置：它在目标动作处做了一步期望，说明"宽度"不是非黑即白——你可以只在目标值的某一部分取期望。这三个维度是坐标轴，不是三档开关；已经学过的每一个方法都是这个空间里的一个点，而空间里还空着大量没命名的点。

更重要的是，所有这些点的更新骨架是同一个：

新估计 ← 旧估计 + 步长 × ( 目标 − 旧估计 )

第5–7章的全部差别，只是在"目标怎么造"上做排列组合：MC 用整回合回报造目标，TD 用一步自举造目标，n 步用 n 步回报造目标，DP 用模型期望造目标。骨架纹丝不动。

💡 关键一跃

这把统一视图的钥匙会一路用到函数逼近：第9章之后，V 和 Q 从查表换成参数化函数，"目标怎么造"的排列组合原封不动地保留，更新骨架也原封不动。换掉的只是价值的表示方式。所以现在把三维坐标系刻进脑子，后面五章都是它的填格子游戏。

⚠️ 常见误区

"三个维度是给算法排名次的：期望比采样精确，所以期望更新全面优于采样更新。" 错。期望更新消掉了采样方差，但①它要么需要模型、要么需要额外算力枚举后继；②在函数逼近下，期望目标把函数逼近误差按概率加权地"焊死"进估计，而采样更新有时反而能平均掉一部分误差。选宽度是在"方差、算力、模型可得性"之间做交易，没有免费的精确。

8.2模型：从经验里长出的世界模拟器

上一节把无模型方法收编进了统一视图。但"经验"这条线索还有另一半没挖完：经验除了直接喂给更新公式（学价值），还能喂出别的东西——模型（Model）。所谓模型，就是智能体对环境动态的内在表示：在状态 s 做动作 a，会得到什么奖励 r、落到哪个后继 s′。

模型分两种成色：

  • 分布模型（Distribution Model）：给出完整的转移与奖励分布 p(s′, r | s, a)。有了它就能做期望更新——第4章的动态规划用的就是这种模型。
  • 样本模型（Sample Model）：不给你完整分布，只按环境的概率吐出一个个采样 (r, s′)。问它"所有可能的后继是什么"，它答不上来；让它"模拟一步"，它能给你一条 plausible 的结果。

在表格型设定下，学一个样本模型便宜到近乎免费：一个字典就够了。每经历一步 (s, a) → (r, s′)，就往字典里记一笔：

Model(s, a) ← (r, s′)

对确定性环境，这条规则一次命中、永远正确；对随机环境，字典里为每个 (s, a) 存下历次出现的 (r, s′)，模拟时按经验频率抽一条——这就是该 (s, a) 处经验分布的忠实采样器。之后想"在脑内重演一步"，从字典里随机挑一个见过的 (s, a)，查出它当初产生的 (r, s′)，一条模拟经验（Simulated Experience）就造出来了，一分钱真实交互都不用花。

于是同一条经验有了两种用途：

  • 直接强化学习（Direct RL）：经验直接喂更新公式，改进价值函数与策略——第5–7章干的全是这个；
  • 间接用途：经验先喂给模型学习，模型再产出模拟经验去改进价值与策略——这就是规划（Planning），下一节 Dyna 的主角。
💡 关键一跃

直接 RL 是"吃一堑长一智"，模型学习是"把堑记下来，以后在脑子里反复摔"。同一条真实经验被利用了两次：一次当场更新 Q，一次存进模型供日后无限次重放。经验的利用率，就是样本复杂度的命脉。

⚠️ 常见误区

"有模型就是 model-based，没模型就是 model-free，按算法名册站队。" 边界其实不在名册上，而在一个问题上：价值/策略的改进是否经由模型产生的经验。Q-learning 本身不学模型，是 model-free；DP 全程用模型，是 model-based；而下一节的 Dyna-Q 两者都是——直接更新走 model-free 通路，规划更新走 model-based 通路，同一个智能体，两条通路并行。

8.3Dyna：真实经验与模拟经验同炉

上一节说经验有直接与间接两种用途，那自然有个问题：能不能两条通路同时开？ 这就是 Dyna 架构的回答。以 Dyna-Q 为例，每在真实环境里走一步，发生三件事：经验直接更新一次 Q（直接 RL）；经验更新一次模型（模型学习）；然后模型产出 n 条模拟经验，每条再更新一次 Q（Q-planning）。

图 8.1 Dyna-Q 架构：真实经验兵分两路——直接更新 Q，同时训练模型；模型产出的模拟经验再做 n 次 Q-planning。注意两个更新用的是同一个 Q-learning 公式，只是经验来源不同。

关键在于：直接 RL 更新和 Q-planning 更新是同一个公式，Q(S, A) ← Q(S, A) + α [ R + γ maxa′ Q(S′, a′) − Q(S, A) ]，只是前者吃真实经验、后者吃模拟经验。Dyna 不是一个新算法，而是一个把"学习"与"规划"焊在一起的架构——里面装的更新规则可以换成 Sarsa、期望 Sarsa 中的任何一格。

核心算例：一条确定性链上的完整推演

环境是一条确定性链：A → B → C → 终点，只有"向右"一个有效动作，进终点得奖励 +1，其余奖励为 0。γ = 0.9，α = 0.5，所有 Q 初始化为 0。

第一步：真实经验 (C, 右, +1, 终止)。智能体真的从 C 走进了终点，拿到 +1。直接 RL 更新：

Q(C, 右) = 0 + 0.5 × ( 1 + 0.9 × 0 − 0 ) = 0.5

同时模型学习记下一笔：Model(C, 右) = (+1, 终止)。

第二步：Q-planning，做 n = 3 次模拟。假设三次都恰好抽中了字典里唯一的条目 (C, 右)（小字典下这很常见）：

  • 模拟 1：目标 = 1 + 0.9 × 0 = 1，Q(C, 右) = 0.5 + 0.5 × (1 − 0.5) = 0.75
  • 模拟 2：Q(C, 右) = 0.75 + 0.5 × (1 − 0.75) = 0.875
  • 模拟 3：Q(C, 右) = 0.875 + 0.5 × (1 − 0.875) = 0.9375

注意这三次模拟做的是同一件事：在同一个 (C, 右) 上反复迭代，把 Q 从 0.5 一步步推向真值 1。真实环境一步只给一次更新，模型让它当场又收敛了三次——这就是"模拟经验在同一目标上反复迭代等价于加速收敛"。

第三步：下一条真实经验 (B, 右, 0, C)。智能体从 B 走到 C，奖励 0。直接 RL 更新：

Q(B, 右) = 0 + 0.5 × ( 0 + 0.9 × 0.9375 − 0 ) = 0.5 × 0.84375 = 0.421875

看这一步：B 自己没拿到任何奖励，但因为 bootstrap 目标里的 Q(C, 右) 已经被规划推到了 0.9375，价值顺着链回传了一格。没有 planning 的话，此刻 Q(C, 右) 只有 0.5，Q(B, 右) 只能学到 0.225——planning 把上游的学习也加速了。

💡 关键一跃

Dyna 的时间账本：真实交互是最贵的资源（机器人要真的动、用户要真的等），模型内模拟几乎免费。Dyna 用一份真实经验撬动 n 份额外更新，本质上是用算力换样本。CPU 闲着也是闲着，不如让智能体在脑内把刚经历的世界多推演几遍。

⚠️ 常见误区

"planning 步数 n 越大越好，反正模拟不要钱。" 错在模型的质量上：模拟经验服从的是学来的模型，不是真实环境。模型错一点，n 次规划就把这个错误往 Q 表里夯 n 次——n 越大，错误被放大得越扎实。下一节专门处理"模型会错"这件事。

8.4模型会错：阻塞、捷径与 Dyna-Q+

上一节末尾埋了个雷：模拟经验服从的是学来的模型，模型错了，planning 越勤快错得越扎实。模型出错最隐蔽的一种不是"从来没学对"，而是环境变了，模型过时了。过时有两个方向，性质完全不同：

  • 环境变坏：阻塞（Blocking）——原来畅通的路被堵了。模型还记着老路，模拟经验依然把智能体往死胡同里引；好在真实交互会立刻给出互相矛盾的反馈，模型迟早被纠正。这类错误是"自爆"的。
  • 环境变好：捷径（Shortcut）——某处新开了一条更短的路。这才是真正的麻烦：模型里没有的路，永远不会被模拟，也就永远不会被发现。智能体沿着旧路走得越顺，ε-贪心偶然拐进新路的机会越少，新路在模型里就始终是空白。规划越充分，策略越确定，发现捷径的概率反而越低。

Sutton 书中的对照实验（迷宫环境跑到一半，偷偷打开一条更短的通道）正是演示这个不对称性：普通 Dyna-Q 能较快适应阻塞，却对捷径长期"失明"，一直沿着旧路走；而改变后的环境给了更高的潜在回报，智能体毫无察觉。

出路是给"久未尝试"一个制度性的奖励。Dyna-Q+ 记录每个 (s, a) 已经多久没在真实经验里出现过，记为 τ 步；规划（以及更新）时把奖励改成：

r + κ√τ

即：模拟 (s, a) 时，用的奖励不是模型记的 r，而是 r + κ√τ。一个动作越久没在真实世界里试过，它在规划里就显得越诱人——万一环境变好了、它其实变强了呢？κ 是个小系数，控制"怀旧奖励"的强度。效果上，Dyna-Q+ 会定期去重新探索那些冷门的动作，捷径一旦出现就会被撞上。

要说明的是，r + κ√τ 只是表格型设定下的一个启发式：它为每个 (s, a) 维护一个计时器，这在表格装得下时才可行。但它背后的思想——给"不确定性/久违"本身发奖金——是探索问题的一条主线，后面探索专题里会以更系统的形式回来（上置信界、计数奖励都与它一脉相承）。

💡 关键一跃

阻塞与捷径的不对称，本质是误差能否自我暴露：模型高估了某条路（阻塞），现实会打它的脸；模型压根不知道某条路（捷径），现实没有任何机会说话。所以探索机制的首要任务不是"纠错"，而是"让未知的选项保持发言权"。Dyna-Q+ 的 κ√τ 就是给沉默多数发的一张话筒。

⚠️ 常见误区

"Dyna-Q+ 的奖励加成是为了更快收敛。" 恰恰相反：κ√τ 故意让 Q 值偏离当前模型认为的最优，用短期回报的牺牲换对模型盲区的好奇。它服务的是长期发现，不是短期收敛。收敛性证明里这个加成项是要衰减处理的，别把手段当目的。

8.5优先扫掠：让优先级排队代替随机抽样

Dyna-Q 的 planning 从字典里随机抽 (s, a) 来模拟。这在字典小、价值都在剧烈变化时没问题；但学到后期，绝大多数 (s, a) 的 Q 值已经收敛，随机抽样会把算力大把浪费在"再更新一次也不会变"的地方。真正值得更新的，是那些估计刚刚被现实或下游变化打脸的位置——TD 误差大的地方。

优先扫掠（Prioritized Sweeping）把随机抽样换成一个优先级队列：

  • 每次更新后，算该 (s, a) 的 TD 误差绝对值 |δ|；若 |δ| 超过阈值 θ，就把这个 (s, a) 按 |δ| 为优先级入队；
  • 每次规划：弹出优先级最高的 (s, a)，执行一次更新；
  • 更新完之后，反向追溯：查模型，找出所有一步之内能到达 s 的前驱 (s⁻, a⁻)，预测它们更新后的 TD 误差，超过 θ 的也入队。

最后这条"前驱入队"是灵魂：一个状态的价值变了，受影响最大的是它的一步前驱；前驱变了再往前传。价值变化像涟漪一样从终点向外逐格扩散，每一圈只更新那些变化还显著的格子。

核心算例：终点处扔下一颗石子

接 8.3 的链 A → B → C → 终点（进终点 +1），α = 0.5，γ = 0.9，θ = 0.1，所有 Q 初始为 0。智能体第一次从 C 走进终点，拿到 +1：

① 计算 |δ|：|δ(C, 右)| = |1 + 0.9 × 0 − 0| = 1.0 > θ → 入队，优先级 1.0。

② 弹出 (C, 右)，更新：Q(C, 右) = 0 + 0.5 × 1.0 = 0.5。查模型找前驱：(B, 右) 一步可达 C。预测其误差：|δ(B, 右)| = |0 + 0.9 × 0.5 − 0| = 0.45 > θ → 入队，优先级 0.45。

③ 弹出 (B, 右)，更新：Q(B, 右) = 0 + 0.5 × 0.45 = 0.225。前驱 (A, 右)：|δ(A, 右)| = 0.9 × 0.225 = 0.2025 > θ → 入队。

④ 弹出 (A, 右)，更新：Q(A, 右) = 0 + 0.5 × 0.2025 = 0.10125。再找更上游：|δ| = 0.9 × 0.10125 = 0.091125 < θ → 不入队，扫掠停止。

步骤弹出更新结果前驱预测 |δ|判定
①—（真实经验触发）—|δ(C,右)| = 1.0入队 1.0
②(C, 右)Q = 0.5|δ(B,右)| = 0.9 × 0.5 = 0.45入队 0.45
③(B, 右)Q = 0.225|δ(A,右)| = 0.9 × 0.225 = 0.2025入队 0.2025
④(A, 右)Q = 0.10125上游 |δ| = 0.9 × 0.10125 = 0.091125< θ，停止

四次更新，价值从终点反向逐格传播，每格恰好一次，没有任何一次更新花在"已经收敛"的地方。算力自动聚焦在"惊讶"的前沿（frontier）上——这就是优先扫掠的全部追求。

💡 关键一跃

还记得第4章动态规划要一遍一遍扫整个状态空间吗？优先扫掠是它的"在线版"：不再地毯式扫描，只扫重要的。TD 误差就是"哪里还值得扫"的探测器，模型（反向）就是涟漪扩散的地图。θ 是探测器的灵敏度：θ→0 时涟漪传得又远又久，近乎退化成全空间反复更新；θ 太大时石子落水也激不起浪，几乎不做 planning。

⚠️ 常见误区

"优先扫掠总是比随机规划划算。" 不一定。维护优先级队列、为每个状态反查前驱列表，都是有开销的；状态空间小、单次更新便宜时，随机抽样的简单粗暴可能总体更快。优先扫掠的甜头在"状态空间大、变化局部"的任务里——比如环境刚发生局部变化，涟漪恰好只在该区域扩散。

8.6规划与学习的对偶 + 错误直觉清算

走到这里，本章开头的主线问题已经有了答案。把两个名词并排摆开：

  • 学习（Learning）：用真实经验做更新——经验来自环境；
  • 规划（Planning）：用模拟经验做更新——经验来自模型。

Dyna 证明了二者共用同一个更新公式，差别只在经验的来源。这就是规划与学习的对偶（Duality of Planning and Learning）：试错中学到的，和脑内推演算到的，在算法眼里是同构的"经验流"。人类棋手复盘（真实对局）与打谱推演（脑中模拟）长棋力走的是同一条神经回路——Dyna 就是这个事实的计算版。

本章收尾前，清算三条最容易带走的错误直觉：

  • "Dyna 是一个新算法。" 错。Dyna 是一个架构（Architecture），不是算法：它只规定"直接 RL + 模型学习 + Q-planning"三条管线怎么接，管线里装的更新公式可以是 Q-learning、Sarsa、期望 Sarsa 中的任何一格——统一视图的每个点都能塞进 Dyna 的壳。
  • "模型越准 Dyna 越好，所以要先花大量经验把模型学准。" 在表格型确定性环境里成立（字典模型一次学对）；但在随机环境里，字典模型本身就是有偏的采样器，planning 步数越多，这个偏差被放大得越扎实。正确姿势是边学模型边规划、用真实经验持续纠正模型，而不是"先练内功再出山"。
  • "优先扫掠总是划算。" 队列维护与前驱反查有真实开销；状态空间小、更新便宜时，随机规划可能更简单有效。优先扫掠的价值在"大状态空间 + 局部变化"的场景，不是普适加速器。
💡 关键一跃

一句话带走本章：真实经验与模拟经验是同一种燃料，灌进同一个更新引擎；模型是炼油厂，Dyna-Q+ 防止油品老化，优先扫掠把油优先送到最需要动力的气缸。 至此表格型方法全部就绪——下一章要换掉的，是"表格"这个容器本身。

📝分层习题

L1 概念辨析判断并说明理由：「Dyna-Q 属于 model-based 方法，所以它不需要真实经验，靠模型模拟就够了。」这个说法对吗？
提示

Dyna-Q 里模型是从哪来的？把模型的"粮食"断掉会怎样？再想想 model-based / model-free 的划分标准。

完整解答

说法错误，错在两层。

① 模型本身是靠真实经验学出来的（Model(s, a) ← (r, s′)）。断掉真实经验，字典永远是空的，模拟经验一条也造不出来；环境一旦变化，旧模型还会把规划带进沟里。真实经验是 Dyna 的"源头活水"。

② 说 Dyna-Q"属于 model-based"也只对了一半。按本章的划分标准——价值/策略的改进是否经由模型产生的经验——Dyna-Q 的直接 RL 通路是 model-free，Q-planning 通路是 model-based，两者都是。它恰恰是本章用来证明"两派方法可以同炉"的范例，而不是站队的证据。

L1 概念辨析在优先扫掠中，如果把阈值 θ 设为 0 会发生什么？设得非常大又会怎样？这两种极端各自等价于什么？
提示

θ 控制的是"什么值得入队"。θ→0 时队列里会涌进什么？θ 极大时队列里还剩什么？

完整解答

θ → 0：任何非零误差都能入队，涟漪永不衰减——一个变化会沿着前驱链传遍整个可达状态空间，且已入队的 (s, a) 在值微调后又可能重新超标入队，近乎退化为对整个状态空间的反复更新（类似动态规划的反复扫描），彻底失去"聚焦"的意义，还白白背着队列维护开销。

θ 极大：几乎没有任何 |δ| 能越过门槛，队列常年为空，几乎不做 planning——方法退化回纯直接 RL（相当于 Dyna 的 n = 0）。

θ 是"聚焦程度"的旋钮：小到 0 等于不聚焦，大到顶等于不规划。工程上常取与"有实际意义的 Q 值变化量"同量级的小正数（如算例中的 0.1）。

L2 手算推导复算 8.3 的全部数字（确定性链 A→B→C→终点，进终点 +1，γ = 0.9，α = 0.5，全零初始化）：真实经验 (C,右,+1,终止) 后的 Q(C,右)；三次 Q-planning（均抽中 (C,右)）后的 Q(C,右)；以及真实经验 (B,右,0,C) 后的 Q(B,右)。然后追问：若 α = 1，上述五个更新值各是多少？
提示

更新式 Q ← Q + α(目标 − Q)，链上只有一个动作，max 不用真的取。α = 1 时更新式变成 Q ← 目标。

完整解答

α = 0.5 的五步：

  • 真实 (C,右,+1,终止)：Q(C,右) = 0 + 0.5×(1 + 0.9×0 − 0) = 0.5
  • 模拟 1：Q = 0.5 + 0.5×(1 − 0.5) = 0.75
  • 模拟 2：Q = 0.75 + 0.5×(1 − 0.75) = 0.875
  • 模拟 3：Q = 0.875 + 0.5×(1 − 0.875) = 0.9375
  • 真实 (B,右,0,C)：Q(B,右) = 0 + 0.5×(0 + 0.9×0.9375 − 0) = 0.5×0.84375 = 0.421875

α = 1 的五步：更新式退化为 Q ← 目标。

  • 真实 (C,右,+1,终止)：Q(C,右) = 1 + 0.9×0 = 1（一步到真值）
  • 模拟 1：Q = 1 + 0.9×0 = 1；模拟 2：Q = 1；模拟 3：Q = 1（已在真值，原地不动）
  • 真实 (B,右,0,C)：Q(B,右) = 0 + 0.9×1 = 0.9

对照可见：α = 1 在确定性环境里一步收敛，planning 的"反复迭代"不再产生增量；α < 1 时 planning 的价值正是在两次真实交互之间把同一目标多推几步。

L2 手算推导4 格链 D→C→B→终点（每格只有"向右"动作），进终点奖励 +2，γ = 0.9，α = 0.5，θ = 0.2，所有 Q 初始为 0。智能体从 B 走进终点拿到 +2。完整走一遍优先扫掠：写清每次 |δ| 计算、入队判定、弹出与更新，直到扫掠停止。
提示

真实经验先触发 (B,右) 入队；每次弹出更新后，唯一前驱沿链往左退一格，预测误差 = γ × 刚更新的 Q 值变化。

完整解答

① 真实经验 (B,右,+2,终止)：|δ(B,右)| = |2 + 0.9×0 − 0| = 2 > θ=0.2 → 入队，优先级 2。

② 弹出 (B,右)，更新：Q(B,右) = 0 + 0.5×2 = 1。前驱 (C,右)：预测 |δ(C,右)| = |0 + 0.9×1 − 0| = 0.9 > 0.2 → 入队，优先级 0.9。

③ 弹出 (C,右)，更新：Q(C,右) = 0 + 0.5×0.9 = 0.45。前驱 (D,右)：预测 |δ(D,右)| = |0 + 0.9×0.45 − 0| = 0.405 > 0.2 → 入队，优先级 0.405。

④ 弹出 (D,右)，更新：Q(D,右) = 0 + 0.5×0.405 = 0.2025。D 没有更上游的前驱（链的起点）→ 队列空，扫掠停止。

结果：Q(B,右)=1，Q(C,右)=0.45，Q(D,右)=0.2025。三次更新、每格一次，价值 2 → 1 → 0.45 → 0.2025 沿链反向传播，与 8.5 算例同构（那里第 ④ 步之后更上游 |δ| = 0.091125 < θ 而停止，这里则是链本身到头）。

L3 建模应用仓库 AGV 调度：真实跑一单要 10 分钟（真实经验昂贵），但有一个廉价仿真器可批量模拟。某天某个货架区刚改了布局。请设计一个 Dyna 风格方案：① 真实经验与模拟经验的分工比例思路；② 模型随布局漂移过时怎么办；③ 为什么此时优先扫掠特别有用。画出架构图（mermaid）。
提示

昂贵资源的预算怎么定？布局改动后哪个量会最先"报警"？报警信号集中在地图的哪个区域？

完整解答

① 分工比例：真实经验只承担两样不可替代的工作——学模型（校准仿真器）和少量直接 RL；把绝大部分更新次数留给廉价的 Q-planning。比例思路：按"真实单成本 / 仿真单成本"来配，例如每 1 条真实经验配 50–100 次模拟更新（n 大），真实交互的边际成本被摊薄。仿真器本身也可作为模型来源之一（相当于字典模型的数据扩充），但仍需真实单定期校验。

② 模型漂移：两道工序。被动：真实单一旦给出与模型矛盾的 (r, s′)，立即覆盖字典条目（模型持续重学）。主动：Dyna-Q+ 的 κ√τ 让久未真实验证的 (s, a) 在规划中显得更诱人，驱使 AGV 定期实地复查——布局改动（一种"捷径/阻塞"混合事件）发生后，旧模型的盲区会被探索奖励逐步照亮；改动频繁时还可定期全量重学模型。

③ 优先扫掠的主场：布局改动只影响仓库的一个局部区域。改动后，该区域的 (s, a) 首先出现大 |δ|，入队；涟漪沿前驱链只在与改动区域拓扑相关的格子上扩散，远离改区的状态根本不占算力。若用随机 planning，绝大多数模拟更新会落在与改动无关的 95% 区域——优先扫掠恰好把算力钉死在"惊讶"的 frontier 上。

8.3 算例（α=0.5、γ=0.9、全零初始化）：真实经验 (C,右,+1,终止) 并做 3 次 Q-planning（均抽中 (C,右)）后，Q(C,右) 与随后真实经验 (B,右,0,C) 更新出的 Q(B,右) 分别是：

自测 4
关于优先扫掠的阈值 θ，下列说法正确的是：
  • A. θ→0 近乎退化为全空间反复更新，θ 过大则几乎不做 planning
  • B. θ 越小，规划越聚焦，所以 θ 应尽量小
  • C. θ 只影响更新顺序，不影响哪些 (s,a) 被更新
  • D. θ 必须等于步长 α

  • C. Dyna 是一个新算法，其更新公式不同于 Q-learning

句1：这章解决什么问题？——
