3.1从老虎机到 MDP：状态入场

第 2 章的上下文老虎机已经引入了状态，但动作不影响下一个状态。本章补上最后一条边：动作 → 状态转移。一旦动作改变未来，"这一步赚多少"就不再等于"这一步值多少"——决策有了长期后果。

马尔可夫决策过程（Markov Decision Process, MDP）用四个要素刻画这类问题：

  • 状态集合 𝒮、动作集合 𝒜、奖励集合 ℛ（本章假定三者都有限，故称有限 MDP）；
  • 动态函数（Dynamics）p(s′, r | s, a)：在状态 s 执行动作 a 后，转移到 s′ 并得到奖励 r 的概率。

关键的假设藏在 p 的写法里：它只依赖 (s, a)，不依赖更早的历史。这就是马尔可夫性质（Markov Property）：状态是对未来的充分统计量——知道现在，过去怎么来的无所谓。

在网格世界里把 p 写具体

回到第 1 章的 4×4 网格世界（终点 (1,1) 与 (4,4)，每步 −1，撞墙停原地，γ=1）：

情形p(s′, r | s, a) 的取值
s=(2,2)，a=上p((1,2), −1 | (2,2), 上) = 1，其余组合为 0（确定性转移）
s=(1,3)，a=上（撞墙）p((1,3), −1 | (1,3), 上) = 1——原地不动，奖励仍是 −1
s=(2,1)，a=左（撞墙）p((2,1), −1 | (2,1), 左) = 1
s=(1,2)，a=左（进终点）p((1,1), −1 | (1,2), 左) = 1；终点是吸收态，回合结束

这个环境是确定性的（每个 (s,a) 只对应一个结果），但 MDP 框架完全允许随机转移——比如"机器人打滑"可以写成 p=0.8 到目标格、0.2 到相邻格。p 就是环境的"物理定律"，第 4 章会假定它已知。

图 3.1 MDP 的单步转移。注意与第 1 章闭环图的区别：现在转移规则 p 被显式写出，它是环境的全部"物理"。
⚠️ 常见误区

"马尔可夫性质是说环境没有记忆"——不准确。它说的是状态这个变量已经把记忆装下了。如果历史真的影响未来（如牌局里出过的牌），解决办法是把历史信息塞进状态里（记牌），而不是放弃马尔可夫框架。"状态要足以决策"是建模者的责任，不是环境的义务。

3.2策略与值函数：给"局面的好坏"下定义

有了 MDP，第 1 章的词汇可以全部严格化。策略（Policy）π(a|s)：在状态 s 选动作 a 的概率——注意是概率分布，确定性策略只是它的特例（某动作概率为 1）。

值函数是"回报的期望"。两个版本，分工不同：

vπ(s) = 𝔼π[ Gt | St = s ]　　（状态值函数 State-Value Function）
qπ(s, a) = 𝔼π[ Gt | St = s, At = a ]　　（动作值函数 Action-Value Function）

读法：v_π(s) = "在 s，之后一切按 π 行事，平均能拿多少回报"；q_π(s,a) = "在 s，先强制走一步 a，之后按 π 行事，平均能拿多少"。一个是"局面分"，一个是"这步棋分"。选择动作时需要的是后者；描述局面时前者更简洁。

网格世界实例：均匀随机策略的值

设策略为"四个方向各 1/4 概率"的均匀随机策略。第 4 章会教你如何算出它的值函数，这里先给出收敛结果（每个格子的数 = 从该格出发、随机乱走到终点的期望步数取负）：

列1列2列3列4
行10−14−20−22
行2−14−18−20−20
行3−20−20−18−14
行4−22−20−140

读表：(2,2) 的值是 −18——随机乱走平均要 18 步才能到终点；角落 (1,4) 是 −22，离两个终点都最远。注意两个终点值为 0（已结束，无更多 −1）。值函数把"延迟回报"变成了每个格子上一个可以比较的数字——这正是第 1 章许下的承诺。

💡 关键一跃

值函数的定义里有三个主角：状态 s、策略 π、期望 𝔼。换策略，同状态的值就变——值永远是"相对于某个策略"的。所以 v_π 不是地图的属性，是"地图 + 走法"的共同属性。

3.3Bellman 期望方程：值函数的自我引用

上一节定义了 v_π，但"对未来无穷步取期望"没法直接算。出路藏在第 1 章的递推 Gt = Rt+1 + γGt+1 里：把期望拆开，会发现 v_π(s) 可以由后继状态的 v_π(s′) 表示——

vπ(s) = ∑a π(a|s) ∑s′,r p(s′,r|s,a) [ r + γ vπ(s′) ]

这就是Bellman 期望方程（Bellman Expectation Equation）。读法分两层：先按策略 π 对动作取平均（∑a），再按环境动态 p 对结果取平均（∑s′,r）；方括号 = 即时奖励 + 折扣后的"下一局面分"。当前局面的分 = 一步之后的平均收获 + 下一局面的分。

q_π 有完全平行的一式：

qπ(s,a) = ∑s′,r p(s′,r|s,a) [ r + γ ∑a′ π(a′|s′) qπ(s′,a′) ]

网格世界手算验证：(2,2) 的值为什么是 −18

用 3.2 节的收敛值表来"验证方程成立"。均匀随机策略下，(2,2) 四方向各 1/4：

  • 上 → (1,2)：r + γv = −1 + (−14) = −15
  • 下 → (3,2)：r + γv = −1 + (−20) = −21
  • 左 → (2,1)：r + γv = −1 + (−14) = −15
  • 右 → (2,3)：r + γv = −1 + (−20) = −21
vπ(2,2) = ¼ × [ (−15) + (−21) + (−15) + (−21) ] = ¼ × (−72) = −18 ✓

与表中值一致——Bellman 方程在收敛值上严格成立。再验证一个带撞墙的：(1,3)，上撞墙停在 (1,3)：

  • 上 → 停 (1,3)：−1 + (−20) = −21；下 → (2,3)：−1 + (−20) = −21
  • 左 → (1,2)：−1 + (−14) = −15；右 → (1,4)：−1 + (−22) = −23
vπ(1,3) = ¼ × [ (−21) + (−21) + (−15) + (−23) ] = ¼ × (−80) = −20 ✓
✅ 判定规则

Bellman 期望方程对任意策略成立，它不是优化工具而是一致性条件：一组数若真是 v_π，就必须在每个状态上满足它。有限 MDP 中它是 |𝒮| 个未知数、|𝒮| 个方程的线性方程组——可解。怎么高效解，是第 4 章的事。

3.4Bellman 最优方程：从"评价"到"最好"

评价一个策略还不够，我们要的是最好的策略。定义最优状态值函数 v*(s) = maxπ v_π(s)：所有策略里能拿到的最高局面分；最优动作值函数 q*(s,a) = maxπ q_π(s,a)。可以证明：有限 MDP 中 v*、q* 存在且唯一（但达到它们的策略可以不唯一——多条路一样近）。

v* 也满足一个自我引用方程，只是把"按 π 取平均"换成"取 max"：

v*(s) = maxa ∑s′,r p(s′,r|s,a) [ r + γ v*(s′) ]
q*(s,a) = ∑s′,r p(s′,r|s,a) [ r + γ maxa′ q*(s′,a′) ]

这就是Bellman 最优方程（Bellman Optimality Equation）。直觉：最优局面的分 = 选最好的那步棋，再领最优的下一局面分。注意它是非线性的（max 在里面），不能像期望方程那样解线性方程组——第 4 章用迭代对付它。

网格世界：最优值表与一次验证

4×4 网格世界的最优值函数（每格 = 到最近终点的最少步数取负）：

列1列2列3列4
行10−1−2−3
行2−1−2−3−2
行3−2−3−2−1
行4−3−2−10

验证 (2,2)（v* = −2）。四个动作的"r + γv*(s′)"：

  • 上 → (1,2)：−1 + (−1) = −2；左 → (2,1)：−1 + (−1) = −2
  • 下 → (3,2)：−1 + (−3) = −4；右 → (2,3)：−1 + (−3) = −4
v*(2,2) = max{ −2, −2, −4, −4 } = −2 ✓　（上、左并列最优）

为什么 q* 一出来，最优策略就是白送的

拿到 q* 后，最优策略无需任何额外搜索：在每个状态选 argmaxa q*(s,a) 即可。因为 q* 已经把"先走 a 之后全最优"的长期后果折进了分数——对 q* 的一步贪心，等价于对全局的最优。这叫贪心化，第 4 章的策略改进定理会给它严格证明。

⚠️ 常见误区

"对 v* 也能一步贪心"——不行！v*(s′) 是下一个局面的分，从 s 选动作需要知道"哪个 a 能把我送到好的 s′"，这必须借助 p 算期望（即先算 q）。有了 q* 才能甩开模型直接查表。这个 v 与 q 的微妙差别，第 6、7 章选算法时会反复出现。

3.5错误直觉大扫除

⚠️ 误区一：值函数就是"这一格的奖励"

网格世界里每步即时奖励都是 −1，但各格 v_π 从 −14 到 −22 不等。值是对未来全部奖励的折扣期望，即时奖励只是方程里的 r 一项。看到 v(2,2)=−18 要读出"随机走平均还要 18 步"，而不是"这一格扣 18 分"。

⚠️ 误区二：γ 小是"近视的缺陷"

γ 是任务定义的一部分：它规定了多远算远。金融风控里 γ 接近 1，高频交易里 γ 很小——都是合理的任务设定。把 γ 当超参数随手调，等于悄悄换了优化目标。

⚠️ 误区三：马尔可夫假设是"作弊的简化"

它不是对世界的断言，而是对状态设计的要求：凡影响未来的历史信息都应装进状态。扑克牌把"已出的牌"记入状态后就马尔可夫了。真正的问题不是假设太强，而是状态设计太懒。

💡 本章给下一章留的账

现在手里有两组方程：Bellman 期望方程（评价 π）与最优方程（定义 v*）。但它们都是"方程组"——16 个格子的网格世界就是 16 个互相纠缠的方程。如何系统地解出 v_π 与 v*？第 4 章的动态规划给出第一套答案：只要 p 已知，就能迭代求解。

解决问题把延迟回报折算成每个局面的"好坏分"。
直觉棋手扫一眼棋盘说"我占优"的那个数。
误区当成即时奖励；它是关于未来的预测，且依赖 π。
何时用第 4 章策略评估的对象；第 9 章被参数化逼近。
概念卡 5
动作值函数 q_π(s,a)
点击翻面 →
定义𝔼_π[G_t | S_t=s, A_t=a]：先走 a 再按 π 的期望回报。
解决问题直接回答"这步棋值多少"，支持无模型选动作。
直觉每个候选落子的"出价单"。
误区与 v_π 混用——选动作要 q，只有 v 还得借 p 折算。
何时用第 6、7 章 Q-learning/SARSA 的主角；贪心化的依据。
概念卡 6
Bellman 最优方程
点击翻面 →
定义v*(s) = max_a Σp[r + γv*(s′)]：最优值的自我引用。
解决问题把"最优"从策略搜索变成方程求解。
直觉最好的局面 = 走最好的那步 + 领最好的下一局面。
误区当线性方程组解——max 使其非线性，须迭代。
何时用第 4 章值迭代的更新规则直接由它改写而来。

📝分层习题

L1 概念辨析以下说法哪些正确？① v_π(s) 只与状态 s 有关，与策略无关；② Bellman 期望方程对任意策略成立；③ 已知 q* 后，无需知道 p 也能选出最优动作；④ 已知 v* 后，无需知道 p 也能选出最优动作。
提示

逐条对照值函数定义中的下标 π、期望方程的适用条件、q 与 v 在"选动作"上的差别。

完整解答
①错：v_π 是"按 π 走下去"的期望回报，换 π 值就变。②对：它是一致性条件，任意策略的值函数都满足。③对：argmax_a q*(s,a) 即最优动作，q* 已含转移后果。④错：v* 是下一状态的分，从动作到状态必须经 p 取期望——没有 p 算不出 q，无法选动作。
L1 概念辨析"既然最优值函数唯一，最优策略也必然唯一。"对吗？
提示

想想网格世界 (2,2) 的 max：上 −2、左 −2。

完整解答
不对。v* 是 max 的结果，唯一；但取得 max 的动作可以有多个并列（(2,2) 的上与左同为 −2）。每个并列最优动作的任意组合都是一个最优策略——值唯一，策略可以不唯一。
L2 手算推导用 3.2 节收敛值表，验证 v_π(2,3) = −20（均匀随机策略，γ=1，每步 −1）。(2,3) 的四邻：(1,3)=−20，(3,3)=−18，(2,2)=−18，(2,4)=−20。
提示

套 Bellman 期望方程：v_π(s) = ¼ Σ[r + v(邻)]，四邻无撞墙。

完整解答
上：(−1)+(−20)=−21；下：(−1)+(−18)=−19；左：(−1)+(−18)=−19；右：(−1)+(−20)=−21。
v_π(2,3) = ¼ × (−21−19−19−21) = ¼ × (−80) = −20 ✓ 与表中值一致。
L2 手算推导用 3.4 节最优值表，验证 v*(3,3) = −2，并给出 (3,3) 的全部最优动作。(3,3) 四邻：上 (2,3)=−3，下 (4,3)=−1，左 (3,2)=−3，右 (3,4)=−1。
提示

套 Bellman 最优方程：v*(s) = max_a [−1 + v*(邻)]。

完整解答
上：−1+(−3)=−4；下：−1+(−1)=−2；左：−1+(−3)=−4；右：−1+(−1)=−2。
v*(3,3) = max{−4, −2, −4, −2} = −2 ✓；最优动作：下、右（都走向终点 (4,4) 方向）。这再次说明最优策略不唯一。
L3 建模应用把"电梯调度"建模为 MDP：一部电梯服务 10 层楼，乘客随机在各层按上下按钮，电梯决定上/下/停/开关门。请给出状态、动作、奖励、动态函数的来源，指出马尔可夫性质由什么保证，以及为什么直接求 v* 不现实。
提示

状态要装下"影响未来的全部信息"；想想 p 从哪来、状态空间多大。

完整解答
状态：电梯位置与方向、各层上下按钮状态、轿内目的楼层集合、（可选）各层等待人数估计。动作：上行/下行/停层/开关门。奖励：每步 −Σ各层等待时间增量（或 −等待人数），送达乘客 +1。动态函数 p：电梯运动确定，但乘客到达随机——p 需从历史客流数据估计或仿真生成。马尔可夫性：由"按钮状态 + 轿内目的地"等状态分量保证（历史已被装进去）。为何难求 v*：状态组合爆炸（2¹⁰ 按钮 × 10 层 × 方向……），p 又含随机客流——正是第 5 章以后无模型方法、第 9 章函数逼近的用武之地。

马尔可夫性质的准确含义是：

自测 2
v_π(s) 定义中的期望 𝔼π 是对什么取的？
  • A. 只对环境的随机转移
  • B. 只对策略的随机选择
  • C. 对策略选择与环境转移共同产生的整条轨迹
  • D. 对初始状态的分布
解析：C 正确——轨迹由 π 与 p 共同生成。A、B 各漏一半；D 错：期望值以 S_t=s 为条件，初始分布不进入定义。
自测 3
Bellman 期望方程 v_π(s) = Σ_a π(a|s) Σ_{s′,r} p[r + γv_π(s′)] 的本质是：
  • A. 值函数必须满足的一致性条件（自我引用），可化为线性方程组求解
  • B. 一种通过试错学习值函数的算法
  • C. 只有最优策略才满足的方程
  • D. 把回报定义改写成期望的形式变换
解析：A 正确，它对任意策略成立且未知数以线性方式出现。B 错：它不含任何学习/采样机制；C 错：任意策略都满足；D 错：关键在于用了 G_t=R+γG_{t+1} 的递归结构，不是简单变形。
自测 4
已知 q*(s,a) 后获得最优策略的正确做法是：
  • A. 对每个状态做一步策略评估
  • B. 解一组 Bellman 期望方程
  • C. 用动态函数 p 做一次前向搜索
  • D. 直接对每个状态取 argmax_a q*(s,a)
解析：D 正确，q* 已把长期后果折入。A、B 错：评价已经完成，无需再做；C 错：查表即可，前向搜索是对 v* 或未知 q 时的补救。
自测 5
Bellman 最优方程比期望方程更难解，因为：

  • C. 它要求奖励非负

解析：B 正确，故第 4 章用迭代法逼近。A 错：两者都含 γ；C 错：对奖励符号无要求；D 错：恰好相反，v* 唯一，是策略可能不唯一。

句1：这章解决什么问题？——
参考答案：当动作会改变未来状态时，如何严格定义"局面的好坏"——用有限 MDP（𝒮, 𝒜, ℛ, p）建模序贯决策，用值函数 v_π/q_π 把延迟回报折算成状态与动作的分。
句2：核心机制是什么？——
参考答案：Bellman 方程。利用 G_t = R + γG_{t+1} 的递归，值函数被写成自我引用的一致性条件（期望方程，线性）；把按策略平均换成 max 即得最优方程（非线性），v*/q* 唯一且对 q* 一步贪心即最优策略。
句3：它和前后章怎么分工？——
参考答案：第 2 章只有动作没有状态，本章补全状态与转移给出建模语言；但 Bellman 方程只是"列方程"，第 4 章在 p 已知时用动态规划求解，第 5 章起讨论 p 未知时用采样逼近。
