12.1为什么需要 λ：把"等多久"变成一个旋钮

第 5–8 章的回答是二选一：蒙特卡洛（Monte Carlo, MC）等到本局结束、用完整回报， unbiased 但方差大；时序差分（Temporal-Difference, TD(0)）每步用 R + γV(S′) 自举，方差小但偏差大。第 7 章的 n 步回报说明中间还有一整排选项，但它们仍是"离散地选 n"。

本节的问题是：能不能让"看多远"变成一个可以连续调节的参数，而不是整数？答案是把所有 n 步回报按指数衰减的权重叠加，得到 λ 回报（λ-return）。先回顾 n 步回报的记号：

Gt:t+n = Rt+1 + γRt+2 + … + γn−1Rt+n + γnV(St+n)

λ 回报把它对所有 n 加权求和（权重像"几何分布"一样逐层衰减），并规定终止后剩下的权重全部给完整回报：

Gλt = (1 − λ) ∑n≥1 λn−1 Gt:t+n   （+ 终止时的残差项 λT−t−1Gt:T）

手算一：权重到底加不加得到 1

取 λ = 0.5、距离本局结束还有 4 步（T − t = 4）。逐项算权重：

n权重 (1−λ)λn−1数值含义
1(1−0.5)×0.500.500一步回报 Gt:t+1
2(1−0.5)×0.510.250两步回报
3(1−0.5)×0.520.125三步回报
4（终止）残差 λ30.125完整回报 Gt:T
合计1.000权重归一到 1

为什么残差恰好是 λ3？因为无限几何级数的总和是 1：

(1 − λ) ∑n≥1 λn−1 = (1 − λ) · 11 − λ = 1

前 3 项已经用掉了 0.5 + 0.25 + 0.125 = 0.875，剩下的 0.125 无处可去，只能整体交给"剩余的完整回报"——这正是残差项。λ = 0 时只剩一步回报（退化为 TD(0)）；λ = 1 时所有中间权重为 0，只剩完整回报（退化为 MC）。

💡 关键一跃

λ 不是"看几步"，而是"每多看一眼，重要性就打一次 λ 折"。λ 小 → 信任近处、快速自举；λ 大 → 信任远处、接近 MC。λ 是偏差—方差旋钮，0 和 1 是两个端点，中间是连续的。

⚠️ 常见误区

λ 回报本身不是一个能在线运行的算法：算 Gλt 需要知道未来所有回报，还得知道何时终止才能补残差项。它是"前向视角"（Forward View）的分析工具——一个用来定义"理想目标"的数学对象。下一节才把它变成每步可执行的算法。

12.2资格迹：让 TD 误差沿"最近走过的路"回传

上一节给了理想目标 Gλ，但它要等整局。这一节换个方向看同一件事：与其向后等回报，不如让每步产生的 TD 误差向前"回敬"给最近访问过的状态。承载这份记忆的就是资格迹（Eligibility Trace）。

每个状态配一个迹变量 et(s)，含义是"这个状态对当前误差负有多少责任"：

e0(s) = 0，  et(s) = γλ · et−1(s) + 1{St = s}

每步先算 TD 误差 δt = Rt+1 + γV(St+1) − V(St)，然后所有状态按自己的迹同步更新：

V(s) ← V(s) + α · δt · et(s)  （对所有 s，而不只是 St）

这就是 TD(λ)。γλ 同时做两件事：γ 让"越远的状态，其回报被折扣得越少"（与目标定义一致），λ 让"越旧的责任，衰减得越快"（与权重定义一致）。

手算二：一条三状态轨迹，三种算法

设定：表格型，γ = 1，λ = 0.5，α = 0.1，V(A) = V(B) = 0。轨迹：A --(R=0)--> B --(R=1)--> 终止。用累积迹，逐时间步记表：

t转移δte(A)e(B)ΔV(A)ΔV(B)
1A→B，R=00 + 0 − 0 = 01000
2B→终止，R=11 + 0 − 0 = 1γλ×1 = 0.50.5×0+1 = 10.1×1×0.5 = 0.050.1×1×1 = 0.10

t=1 时 δ 为零（两个价值都是 0，回报也是 0），所以迹虽然立起来了，但没人被更新——这正是"迹只是责任额度，真正付账要等误差出现"。t=2 误差出现，A 凭 0.5 的残存额度拿到一半的更新量。对比三种结果：

算法V(A)V(B)为什么
TD(0)00.10只更新当前状态 B
TD(λ=0.5)0.050.10A 按迹 0.5 拿到一半责任
MC（等价 λ=1）0.100.10A 的迹保持 1，全额更新

0.05 恰好落在 0 与 0.10 正中间——这不是巧合，而是"前向视角与后向视角在表格、离线、每局意义上等价"的一个数值切片：后向视角（Backward View）用迹累积，前向视角（Forward View）用 λ 回报加权，两者算出的总更新量相同。

✅ 两种迹

累积迹（Accumulating Trace）就是上面的 e ← γλe + 1，同一状态被多次访问会累加到大于 1，责任叠加。替换迹（Replacing Trace）把该状态直接置为 1（或 max(1, e)），表示"只记最近一次访问"。替换迹在实践中常更稳，但只在近似意义上仍对应 λ 回报。

⚠️ 常见误区

迹不是"把奖励向后传播"。回传的载体是 TD 误差 δ，而 δ 里混着自举的价值估计；迹决定的是"这个误差该按什么比例记在谁头上"。另外 λ 在迹里不是"衰减奖励"，它衰减的是责任——奖励本身的折扣由 γ 负责。把两者混为一谈，就会在推导时把 γλ 写成 λ。

12.3Sarsa(λ)：把迹搬进控制

上一节只解决了预测。要控制，迹就得从"状态"升级到"状态—动作对"，因为控制中我们要评估的是 Q(s,a)。做法很直接：给每个 (s,a) 配一条迹，误差照旧是 Sarsa 的 δ：

et(s,a) = γλ et−1(s,a) + 1{St=s, At=a}
δt = Rt+1 + γQ(St+1, At+1) − Q(St, At)
Q(s,a) ← Q(s,a) + αδtet(s,a)

注意 δ 里出现了 At+1——它必须先被选出来才能算误差，这就是 Sarsa 名字的来历（S, A, R, S′, A′）。用上节的同一条轨迹代入（动作记为"右""左"），数字完全一样：t=1 时 δ = 0，e(A,右) = 1；t=2 时 δ = 1，e(A,右) 衰减到 0.5，Q(A,右) 得 0.05，Q(B,左) 得 0.10。

💡 一句话记住

Sarsa(λ) = Sarsa 的误差 + TD(λ) 的责任记账。策略改善仍是 ε-贪心（第 5 章），只是"改善"之前，价值已经被迹更新得更接近 λ 回报目标。

⚠️ 常见误区

迹里记的是实际执行过的动作，包括探索动作。所以 Sarsa(λ) 学到的是"带探索的行为策略"的价值——这与 Sarsa 的 on-policy 本性一致。如果你想要的是贪心目标策略的价值，就该换到下一节的 Q(λ)，并且处理切断问题。

12.4Watkins 的 Q(λ)：离策略为什么必须"切断"

上一节的迹忠实记录了"实际走过的路"。Q-learning 想要的却是"如果按贪心走会怎样"——目标和行为分家了。矛盾就在这里：一条迹代表"执行过的动作在历史上负过的责任"，可目标策略根本没执行过那些动作，凭什么用贪心目标去更新它们？

Watkins 的 Q(λ) 采取最保守的做法：一旦下一步的行为动作不是贪心动作，就把所有迹清零。

若 At+1 = argmaxa Q(St+1, a)：正常更新迹与 Q
否则：e(s,a) ← 0（全部切断），只做当前对的单步更新

直觉：迹只在"行为仍然沿着目标策略走"的段落里有效。一旦行为偏离，这段历史就不能再用贪心目标去解释，信用链必须断掉重来。这与第 7 章"树回溯 / 重要性采样"的动机同源：离策略的多步信用，必须解决"行为与目标不一致"的分布错配，切断是最粗暴的一种解法。

切断有多频繁：一个真算的数

设行为策略是 ε-贪心、ε = 0.1，且贪心动作唯一。每步选中贪心动作的概率近似 1 − ε = 0.9（忽略 ε 里恰好抽中贪心项的 1/|A| 修正）。一条迹能连续存活 L 步的概率是 0.9L，几何分布的期望：

E[L] = 0.91 − 0.9 = 9 步

也就是说，ε = 0.1 时迹平均活不过 10 步。λ 想传递的"长程信用"在离策略下名存实亡——这是 Q(λ) 相对 Sarsa(λ) 优势缩水的根本原因，也是后续"树回溯 Q(λ)"（第 7 章树回溯的推广）出现的原因。

⚠️ 常见误区

以为 Q(λ) 是"Q-learning + 迹"，性能必然更好。实际相反：离策略 + 频繁切断，迹经常还没积累就被清零。选 Q(λ) 不是因为"更先进"，而是因为你确实需要离策略（比如行为策略来自旧数据或人类示教）。

12.5真实在线学习：前后向等价在逼近下失效之后

12.2 节说"前向视角 = 后向视角"，但那是在表格 + 离线 + 每局批量更新的理想条件下。真实场景三个条件全破：用函数逼近（权重向量 w 共享）、边经历边更新（在线）、策略还在变。此时"每步都用当前 w 算 δ"会让迹与真实 λ 回报之间出现系统性错位——这就是真实在线学习（True Online Learning）要修的问题。

修正的关键是荷兰迹（Dutch Trace）。线性函数逼近下，累积迹是 e ← γλe + x，而荷兰迹多了一项修正：

e ← γλ e + (1 − α γλ e⊤x) x

括号里的 (1 − αγλe⊤x) 是一个标量，作用是扣掉"这次更新会顺带改变未来迹所指向方向"的那部分重复计入。用荷兰迹的真实在线 TD(λ)满足：每一步的更新量，恰好等于"假设此刻本局终止、对当前 w 施加 λ 回报更新"的更新量——在离线性情形下是精确相等，而普通 TD(λ) 只是近似。

✅ 为什么值得关心

它把"λ 回报是什么"和"算法每步做什么"重新对齐了。这使得调 λ、比较算法、做理论分析时，"前向视角"重新成为可信的参照系；代价是每步多一次内积，且公式只对线性逼近有干净的解释。

⚠️ 常见误区

以为迹 + 函数逼近只是"把 e 换成向量"。真正的坑在致命三合（Deadly Triad）：函数逼近 + 自举 + 离策略三者同时出现时，即使表格算法收敛的版本也可能发散。迹会放大这种不稳定（更新沿特征方向反复叠加），所以第 11 章讨论的收敛条件在这里仍然是前提，而不是被迹"解决"了。

12.6错误直觉专场：资格迹只是"加速技巧"吗？

这章最容易被一句话打包带走："资格迹就是一种让 TD 学得更快的工程技巧。"这句话有一半是对的，另一半会在你把它用到函数逼近时咬你一口。逐条拆：

说法判定准确的说法
"迹只是加速，最终答案不变"表格下勉强对，逼近下错表格预测中不同 λ 都收敛到 vπ，变的是瞬态速度与样本效率；函数逼近下不同 λ 收敛到不同的不动点，λ 改变了你在优化什么目标。
"迹把奖励反向传播，像反向传播算法"错回传的是 TD 误差 δ，不是奖励；迹只是决定每个状态分到多少 δ。奖励进入 δ 的分子，仅此一次。
"λ 越大越好，越接近真实回报"错λ 大 → 方差大、收敛慢；λ 小 → 偏差大。λ 是旋钮，不是越大越好。
"迹可以免费替代经验回放"错迹只保留"责任额度"，不保留原始转移样本；它无法像回放那样重复利用旧数据或打破相关性。
💡 一句话校正

迹的本质是把"多步信用分配"改写成一个每步可维护的记账系统：它改变的是"误差该记在谁头上、记多久"，因此在表格下只影响速度，在逼近下会影响收敛目标。它从来不是"同一算法的 turbo 按钮"。

"资格迹只是加速技巧"在什么条件下算对、什么条件下错？

参考答案
表格预测下勉强对：所有 λ 收敛到同一 vπ，只改瞬态效率；函数逼近下错：λ 改变不动点（优化目标本身），不同 λ 收敛到不同解。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
λ 回报（λ-return）
点击翻面 →
定义所有 n 步回报按 (1−λ)λn−1 加权的和，终止时残差 λT−t−1 给完整回报。
解决问题把 MC 与 TD 的"离散选择"变成连续旋钮，量化偏差—方差折中。
直觉每多看远一步，重要性就打一次 λ 折。
误区以为它是可在线执行的算法——它只是定义目标的前向视角。
何时用分析目标；由 TD(λ)、Sarsa(λ) 的后向视角逼近实现。
概念卡 2
资格迹（Eligibility Trace）
点击翻面 →
定义每个状态（或状态—动作对）的记账变量 e，按 γλ 衰减、访问时 +1，表示"对当前误差负多少责"。
解决问题让多步信用分配能在每步维护，不必保存整条轨迹。
直觉沙滩上的脚印：越新越清晰（γλ 衰减），越旧越淡。
误区以为迹在传播奖励；它传播的是 TD 误差，且不保留原始样本。
何时用TD(λ)、Sarsa(λ)、Q(λ)；函数逼近下与特征同维。
概念卡 3
前向视角 / 后向视角（Forward / Backward View）
点击翻面 →
定义前向：用 λ 回报算目标；后向：用迹在每步回传 TD 误差。表格离线每局意义下两者等价。
解决问题前向给"该学什么"的清晰定义，后向给"怎么在线学"的可执行机制。
直觉前向是事后复盘，后向是边打边记分。
误区以为等价无条件成立——函数逼近 + 在线下会失效（要荷兰迹修正）。
何时用比较算法、做理论分析；第 13 章策略梯度的回报估计也常两种视角。
概念卡 4
Sarsa(λ)
点击翻面 →
定义on-policy 控制 + 状态—动作迹：e(s,a)=γλe+1，Q += αδe，δ 为 Sarsa 误差。
解决问题让控制也享受多步信用分配的样本效率。
直觉Sarsa 的误差 + TD(λ) 的记账本。
误区以为迹只记贪心动作——探索动作同样留迹（on-policy）。
何时用需要在线、依赖自身探索数据的控制任务。
概念卡 5
Watkins 的 Q(λ)
点击翻面 →
定义Q-learning + 迹；一旦行为动作偏离贪心动作，全部迹清零。
解决问题离策略下多步信用与目标策略不一致时的合法处理。
直觉脚印一旦离开目标路线，整串脚印作废。
误区以为它总优于 Sarsa(λ)——ε=0.1 时迹平均只活 9 步。
何时用必须离策略时（旧数据、示教数据）；更优解是树回溯 Q(λ)。
概念卡 6
荷兰迹与真实在线 TD(λ)（Dutch Trace / True Online）
点击翻面 →
定义e ← γλe + (1−αγλe⊤x)x；用它的在线 TD(λ) 每步更新恰等于"此刻终止"的 λ 回报更新（线性情形精确）。
解决问题修复函数逼近 + 在线更新下前向/后向视角的错位。
直觉记账时顺便扣掉"这笔账会改变未来记账口径"的重复部分。
误区以为它解决了致命三合的发散——它只修正等价性。
何时用线性/特征逼近下的在线 λ 学习；深度 RL 的 λ 变体多受它启发。

📝分层习题

L1 概念辨析判断："λ = 1 的 TD(λ) 与蒙特卡洛在每局意义下等价，因此 λ 只是 MC 与 TD(0) 之间的插值，没有新东西。"
提示

想一想：λ 回报是一个连续旋钮，但"每步都能更新"这件事本身，是不是 MC 做不到的？

完整解答
前半对、后半错。λ=1 时迹不衰减，每局结束的总更新确实等于 MC 的更新（表格、离线意义下）；但 TD(λ) 的机制价值在于每步都能产生更新，λ=1 时它等价于"把 MC 的整局更新摊到每一步去做"，而不是"等整局再算"。此外 λ 还在函数逼近下改变不动点。把它降格为"插值"会漏掉后向视角这个可在线执行的机制。
L1 概念辨析判断："Watkins 的 Q(λ) 在行为动作偏离贪心动作时清零迹，是为了节省计算量。"
提示

清零是"省事"还是"必须"？如果不清零，用贪心目标去更新一条"执行的是探索动作"的迹，会算出什么？

完整解答
错。切断是正确性要求，不是优化：迹代表"执行过的动作负过的责任"，而 Q-learning 的目标是贪心动作的价值。行为偏离目标后，这段迹无法再用贪心目标解释，继续更新等于把探索路径的信用记到目标策略头上（分布错配）。代价是迹变短、优势缩水（ε=0.1 时平均只活 9 步）。
L2 手算推导λ = 0.5，某局还剩 4 步结束。写出 λ 回报的四项权重并验证归一；再把 λ 改成 0.8，重算四项权重（残差用 λ3），说明分布的变化。
提示

前 3 项用 (1−λ)λn−1，第 4 项残差用 λT−t−1 = λ3。

完整解答

λ = 0.5：0.5、0.25、0.125、残差 0.125；和 = 1.000。

λ = 0.8：n=1 → 0.2×1 = 0.200；n=2 → 0.2×0.8 = 0.160；n=3 → 0.2×0.64 = 0.128；残差 0.83 = 0.512。和 = 0.200+0.160+0.128+0.512 = 1.000。

解读：λ 从 0.5 升到 0.8，完整回报的权重从 0.125 涨到 0.512——目标迅速向 MC 靠拢，前几步回报几乎被忽略（0.2 与 0.16）。λ 越大，越"信远处"。

L2 手算推导用 12.2 节的轨迹（A→B，R=0；B→终止，R=1），把 λ 从 0.5 改为 1.0（γ=1，α=0.1，V 初值 0），重算两步的迹与更新量，并说明为什么结果与 MC 一致。
提示

λ=1 时迹的衰减因子是 γλ = 1，t=2 时 e(A) 保持原值。

完整解答

t=1：δ = 0+0−0 = 0；e(A)=1，e(B)=0；无更新。

t=2：δ = 1+0−0 = 1；e(B) = 0+1 = 1；e(A) = 1×1 = 1（不衰减）。ΔV(A) = 0.1×1×1 = 0.10，ΔV(B) = 0.10。

与 MC 一致的原因：λ=1 时迹永不衰减，凡是访问过的状态都保留全额责任 1，于是本局结束时每个被访问状态的更新量都等于 α×完整回报，正是常 MC 的更新。

L3 建模应用仓库机器人负责"取货→放货"，一局约 300 步，奖励稀疏：只有放对货架时 +1，中途碰撞 −1。①你选 λ 偏大还是偏小，为什么？②若训练数据来自由人工遥控产生的旧轨迹（离策略），迹会遇到什么问题、怎么缓解？③写出你在 ②中的更新式（用 Q(λ) 或树回溯，说明取舍）。
提示

稀疏奖励 → 信用分配距离长；离策略 → 行为与目标不一致；两件事都指向"迹能不能活到奖励出现的时刻"。

完整解答

① 稀疏奖励 + 长回合：奖励出现前有大量无信息步骤，TD(0) 的偏差会让价值传播极慢，应偏大 λ（如 0.8–0.95）让信用传得更远。但碰撞惩罚又带来高方差，可用替换迹（每次访问重置为 1）稳定，并以 n 步截断兜底。

② 人工遥控 = 离策略：行为策略含人类偏好与噪声，贪心目标与行为频繁分歧，Watkins 切断会让迹平均只活 ~9 步（ε 近似 0.1 时），λ 的长程优势消失；极端稀疏奖励下几乎学不动。

③ 缓解：树回溯 Q(λ)（第 7 章树回溯 + 迹）。更新式：δ = R + γ maxa′Q(S′,a′) − Q(S,A)（目标仍贪心），但对迹做选择性回溯——仅当行为动作恰在贪心集合内才允许迹跨越，否则只把该步的 δ 记到当前对，不乘到历史迹上。取舍：比 Watkins 保留更多信用、比重要性采样方差低；代价是实现复杂、需要维护贪心集合。

  • C. 只有迹等于 1 的状态
  • D. 未来会访问的状态

  • B. 每步都清零迹，保证离策略正确性
  • C. 只在回合结束时清零，平时不切

选 A。切断是分布错配的合法处理。B 过度清零等于退化成单步 Q-learning，丢掉了 λ 的意义；C 等于让迹跨越不匹配的片段，目标被污染；D 把正确性问题误当性能问题。

  • B. 表格下近似成立（只改瞬态速度），函数逼近下不成立（λ 改变不动点）
