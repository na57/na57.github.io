6.1为什么不等回合结束：TD(0) 的一步自举

第5章的蒙特卡洛有两个绕不开的代价：① 必须等回合结束——回报 Gt 要到终止时刻才算得出，持续性任务（没有终止态）根本无法更新，长回合任务则学习信号严重延迟；② 高方差——Gt 是整条随机轨迹的累加，轨迹里每一个随机环节都把噪声灌进这一个数里。

回想第4章的动态规划：它也更新价值，却从来不等回合结束——因为它用贝尔曼方程自举：拿后继状态的旧估计 V(S′) 当替身。DP 的死穴是需要模型。那么自然的问题是：能不能像 MC 一样只采样一步、又像 DP 一样拿旧估计自举？这就是时序差分学习（Temporal-Difference Learning, TD）的全部出发点。

最简单的 TD——表格型 TD(0)（Tabular TD(0)）——在每经历一步转移 (S, R, S′) 后立刻更新：

V(S) ← V(S) + α · [ R + γV(S′) − V(S) ]

对比 MC 的更新 V(S) ← V(S) + α(G − V(S))：结构一模一样（旧估计 + 步长 ×（目标 − 旧估计）），唯一区别是目标——MC 用等到底才拿到的 G，TD 用一步之后立刻可得的 R + γV(S′)，称为 TD 目标（TD Target）。这里有两个关键操作同时发生：采样（Sampling）——R 和 S′ 是真实经历的一步，不对模型求期望；自举（Bootstrapping）——目标里掺了旧估计 V(S′)，用自己的猜测更新自己的猜测。

真算例：5×5 gridworld 上的一次更新

沿用第5章的环境：5×5 gridworld，每步奖励 −1，进入右下角终点 +10，γ = 0.9。设当前 V((1,4)) = 0.5，智能体从 (1,4) 向右走到 (1,5)，得奖励 −1，而表中存着 V((1,5)) = 4.0，步长 α = 0.1。一步步算：

  • 第一步，算 TD 目标：R + γV(S′) = −1 + 0.9 × 4.0 = −1 + 3.6 = 2.6
  • 第二步，算目标与旧估计的差：2.6 − 0.5 = 2.1
  • 第三步，按步长靠拢：新 V((1,4)) = 0.5 + 0.1 × 2.1 = 0.5 + 0.21 = 0.71

对比一下：第5章的 MC 在这条轨迹上要等到回合结束，才能用倒推出的 G = 3.122 做目标更新 (1,4)；TD 只用了一步，拿自举目标 2.6 当场更新。2.6 不是"真值"——它掺了旧估计 4.0——但它现在就可用，而且会随着 V((1,5)) 自己被反复更新而越来越准。

三种方法在"是否采样、是否自举"两个维度上的位置：

方法采样（免模型）自举（不等结束）更新目标
动态规划 DP否（对模型求期望）是Σ p(s′,r|s,a)[r + γV(s′)]
蒙特卡洛 MC是否Gt（完整回合回报）
TD(0)是是R + γV(S′)
💡 关键一跃

TD 目标 R + γV(S′) 是对"这一步之后世界会值多少"的一步截断估计：真实奖励只有一步，剩下的路全部用旧猜测顶上。MC 说"走完再信"，DP 说"查表再信"，TD 说"走一步、信一半"——用一点偏差（旧估计不准）换两样东西：不用等待、方差大降。

⚠️ 常见误区

"自举是循环论证，所以 TD 不可能收敛。" 错。自举听起来像拽着自己的鞋带站起来，但表格型 MDP 的贝尔曼算子是压缩映射，R 里携带的真实奖励每一步都注入了新信息，反复迭代后 V 会被真实奖励"锚定"到 vπ 上。表格型 + 适当步长（满足 Σα = ∞、Σα² < ∞）下 TD(0) 收敛有严格保证。

6.2TD 误差 δ：一切更新的信号

上一节的算例里，第二步算出的"目标 − 旧估计"= 2.1 出现得很自然。这个量重要到有专门的名字和符号——TD 误差（TD Error）：

δ = R + γV(S′) − V(S)

整个更新式可以写成 V(S) ← V(S) + α·δ。δ 衡量的是：这一步实际发生的情况，比我原来以为的好（或差）多少。在 6.1 的算例中 δ = 2.6 − 0.5 = 2.1 > 0，说明这一步比预期好，于是 V((1,4)) 被上调。

δ 的直觉是"意外程度"：δ = 0 意味着现实与预期完全一致，无可学习；δ 越大，这一步带来的新信息越多。神经科学里有个著名的对应：多巴胺神经元的放电模式与 TD 误差的时序特征高度吻合——奖励意外到来时放电（δ > 0）、预期中的奖励到来时平静（δ ≈ 0）、预期奖励落空时抑制（δ < 0）。注意这只是一个类比：它帮助记忆 δ 的角色，不构成任何生物学断言。

δ 还有一个漂亮的结构性质：蒙特卡洛误差可以写成沿途各步 TD 误差的折扣和：

Gt − V(St) = ∑k=0T−t−1 γk · δt+k

不必死记推导，抓住直觉：MC 等到底才知道的总误差，等于把一路上每步的"小意外"折现累加起来。TD 是每走一步就结算一次小意外，MC 是攒到最后一起结算——这正是两者"更新时机"差异的代数表达（第7章 n 步方法将把这个观察推广成完整的谱系）。

💡 关键一跃

δ 是强化学习里唯一的"通货"。TD(0)、Sarsa、Q-learning、后面的 Actor-Critic，更新式长得各不相同，但全是"估计 ← 估计 + 步长 × δ"的变装。读懂 δ，就读懂了整条主线的更新语法。

⚠️ 常见误区

"δ 是估计误差，所以 δ 越小学习越好。" 错把信号当病灶。δ 大说明这一步信息量大——学习正在吸收新东西。策略改进期（价值函数还在剧烈变化）δ 天然偏大，这是健康的；真正的收敛标志是 δ 在期望意义下趋近于零，而不是每个样本的 δ 都小。强行追求小 δ，等于要求"别告诉我任何我不知道的事"。

6.3Sarsa：沿着自己的行为策略学

前两节解决的是预测（给固定策略估价值）。要做控制（找更好的策略），与第5章同理，我们要学动作价值 Q(s, a)。TD 控制的最直接方案来自一个五元组——每一步更新用到：

( S, A, R, S′, A′ )

五个字母念出来就是 "S-A-R-S-A"——Sarsa 的名字由来。其中 A′ 是行为策略（通常是 ε-贪心）在 S′ 处实际选出的下一个动作。更新式：

Q(S, A) ← Q(S, A) + α · [ R + γQ(S′, A′) − Q(S, A) ]

Sarsa 是在策略（On-Policy，又译"同策略"）方法：它评估和改进的，就是产生数据的那个策略本身——包括其中 ε-贪心的探索成分。目标 R + γQ(S′, A′) 里的 A′ 来自行为策略的真实采样，所以 Sarsa 学的价值忠实地反映了"我这个偶尔手滑的策略，继续执行下去值多少"。

Cliff Walking 上的表现

本章第二个环境：Cliff Walking（悬崖行走），4×12 网格，起点在左下角，终点在右下角，底排中间一整段是悬崖——踏入悬崖奖励 −100 并被送回起点，其余每步奖励 −1。理论上最短路径贴着悬崖边走（全程 −13 左右），但贴着悬崖意味着：ε-贪心每一次"手滑"探索，都可能一步踏空掉下去。

Sarsa 学到的是什么？因为它的目标里包含"下一步我可能手滑"这件事（A′ 是真实采样的，手滑动作会真的被算进价值），悬崖边的状态在 Sarsa 眼里价值会被探索风险拉低，于是它学到一条绕开悬崖的"安全路径"——走得远一些，但全程几乎不掉下去。从"含 ε 探索的策略的真实回报"角度看，这是更优的选择。

💡 关键一跃

On-policy 学的是"我会成为的那个我"，不是"理想中的我"。Sarsa 把探索噪声当作自身性格的一部分计入价值——所以它天生风险敏感，在危险环境里自动变得保守。

⚠️ 常见误区

"Sarsa 保守，所以它比 Q-learning 差。" 看评价标准。若比"学到的确定性策略的质量"（学完后把 ε 关掉再跑），Q-learning 学到的才是最优策略；但若比在线学习期间的真实累积回报（学习过程中一直在被探索拖累），Sarsa 常常更好。安全攸关、边学边跑的场景里，"保守"是优点而不是缺点。

6.4Q-learning：盯着最优策略学（离策略）

Sarsa 的目标用"实际选中的 A′"。如果我根本不想管行为策略下一步会做什么，只想知道"从 S′ 起按最优动作走值多少"呢？把 Q(S′, A′) 换成 maxa Q(S′, a)，就是Q-learning：

Q(S, A) ← Q(S, A) + α · [ R + γ · maxa Q(S′, a) − Q(S, A) ]

Q-learning 是离策略（Off-Policy）方法：目标策略（想学的）是纯贪心策略，行为策略（实际跑数据的）是 ε-贪心——两者不是同一个策略。更新目标 maxa Q(S′, a) 与"行为策略下一步实际选了什么"完全无关，这就是"离"字的含义：学习目标脱离了行为策略的采样。

同一条转移上的对比算例（核心）

设状态 s 执行动作 a，当前 Q(s, a) = 1.0，得奖励 R = −1，进入 s′。在 s′ 处的 Q 表：Q(s′, 右) = 4.0——这恰好是 ε-贪心行为策略实际选中的动作；而 maxa Q(s′, ·) = 4.5，对应最优动作"下"。γ = 0.9，α = 0.1。同一条转移，两个算法各算一遍：

算法目标计算目标值更新计算新 Q(s,a)
Sarsa−1 + 0.9 × 4.02.61.0 + 0.1 × (2.6 − 1.0) = 1.0 + 0.161.16
Q-learning−1 + 0.9 × 4.53.051.0 + 0.1 × (3.05 − 1.0) = 1.0 + 0.2051.205

差异的来源一目了然：Sarsa 的目标包含"下一步我可能手滑"——它信任的是行为策略实际选中的那个动作（哪怕它是探索产物）；Q-learning 假装下一步一定走最优，用 max 把"理想下一步"当目标。同一份数据，Sarsa 学"我现在这套带噪声的打法值多少"，Q-learning 学"把噪声关掉后的极限打法值多少"。

放回 Cliff Walking：Q-learning 的目标策略是贪心的，它会学到贴着悬崖边的最短路径——那是真最优。但学习期间它还在用 ε-贪心跑数据，贴着悬崖走意味着每次探索手滑就掉下悬崖吃 −100。于是出现教科书里的经典现象：Q-learning 学到的策略更优，但在线学习期间它的累积回报反而比 Sarsa 差——它不断为自己向往的险路付出探索的学费，而 Sarsa 早就绕着走了。（此处只做定性描述；不同随机种子与参数下的具体曲线数值以实验为准。）

💡 关键一跃

Sarsa 与 Q-learning 的全部差别，浓缩在一个问题上："更新目标里的下一步，按现实（我实际会怎么走）算，还是按理想（最优会怎么走）算？" 前者在策略、风险敏感；后者离策略、直奔最优但要承受探索的代价。

⚠️ 常见误区

"Q-learning 更新时用了 max，所以它学的是贪心策略，因此它也是 on-policy。" 前半对、结论错。on/off-policy 的判据是"评估的目标策略与产生数据的行为策略是不是同一个"。Q-learning 的目标策略是纯贪心，行为策略是 ε-贪心，两者明确分离——它是离策略的教科书例子。详见 6.6 节的清算。

6.5期望 Sarsa 与最大化偏差

Sarsa 用"采样出来的 A′"，Q-learning 用"max"。两者之间还有一个选项：对下一步动作按策略求期望——期望 Sarsa（Expected Sarsa）：

Q(S, A) ← Q(S, A) + α · [ R + γ · ∑a π(a | S′) Q(S′, a) − Q(S, A) ]

手算：同一个 s′，三种目标

接 6.4 的设定，补充完整 s′ 处 4 个动作的 Q 值：下 4.5（贪心动作）、右 4.0、上 3.0、左 2.0。ε = 0.1 的 ε-贪心策略给出的概率：π(下) = 1 − ε + ε/4 = 0.9 + 0.025 = 0.925，其余三个动作各 π = ε/4 = 0.025。期望 Sarsa 的目标分两步算：

  • 第一步，对 s′ 求期望：0.925 × 4.5 + 0.025 × (4.0 + 3.0 + 2.0) = 4.1625 + 0.025 × 9.0 = 4.1625 + 0.225 = 4.3875
  • 第二步，组装 TD 目标：−1 + 0.9 × 4.3875 = −1 + 3.94875 = 2.94875 ≈ 2.949

更新：Q(s, a) = 1.0 + 0.1 × (2.94875 − 1.0) = 1.0 + 0.194875 = 1.194875 ≈ 1.195——恰好落在 Sarsa 的 1.16 与 Q-learning 的 1.205 之间。三个算法在同一条转移上的目标并排：Sarsa 2.6（采样谁信谁）＜ 期望 Sarsa 2.949（按策略取期望）＜ Q-learning 3.05（只信最优）。

期望 Sarsa 消除了什么？Sarsa 的目标里，"采样到哪个 A′"本身是随机的——同样一条转移，A′ 抽到 4.0 和抽到 2.0 给出不同目标，这是额外的方差来源。期望 Sarsa 用解析的期望替代这次采样，把"选哪个 a′"的方差整个消掉，代价是每个更新要多算一个加权和（表格型下很便宜）。注意它可以两用：π 取行为策略时是 on-policy 的期望版 Sarsa；π 取贪心策略时就退化成 Q-learning 的确定性目标。

最大化偏差：max 的隐藏税

Q-learning 的 max 看着无辜，其实藏着一个系统性陷阱——最大化偏差（Maximization Bias）：对含噪声的估计取 max，期望意义下会得到正偏差。一个小算例：设 s′ 有 3 个动作，真实价值全是 −0.1，但小样本下我们的估计是 +0.3、−0.4、+0.1——估计本身无偏（噪声均值为零），可 max(0.3, −0.4, 0.1) = +0.3，而真实的 max 是 −0.1。max 专门挑出"噪声最走运"的那个动作，于是 max 的期望系统性高于期望的 max。

解法是双 Q 学习（Double Q-learning）：维护两张 Q 表 Q₁、Q₂，每次更新随机选一张。若选 Q₁：用 Q₁ 选 argmax 动作，用 Q₂ 评估该动作。接上面的例子：设 Q₁ 认为 +0.3 的动作最优，但用独立的 Q₂ 去评估它，得 Q₂（该动作） = −0.05——目标就用 −0.05 而非 0.3，正偏差被消除。直观地说：挑选和打分用了两套独立的噪声，"挑中走运者"的运气就无法传到分数里。

💡 关键一跃

三种目标的谱系：Sarsa 信一次采样（方差大、含探索）→ 期望 Sarsa 信策略期望（方差小、忠实于 π）→ Q-learning 信 max（零方差于选动作，但引入最大化偏差）。双 Q 学习则是给 max 配的解药。选择目标，就是在"方差、偏差、保真于哪个策略"之间点菜。

⚠️ 常见误区

"最大化偏差只存在于 Q-learning。" 错。任何对噪声估计取 max 的更新都有此风险——DP 的策略改进、函数逼近下的一切贪心化操作都在危险区内。Q-learning 只是它最典型的案发地。反过来也要记住：真值完全已知时 max 没有偏差——偏差来自"噪声 + max"的组合，不是 max 本身。

6.6错误直觉清算："TD 比 MC 更准"、"Q-learning 是 on-policy"

TD 家族讲完了，趁概念还热，清算三条最容易带走的错误直觉。

  • "TD 比 MC 准。" 错。准不准要看偏差–方差两端：MC 目标 G 是完整回报，无偏但方差大；TD 目标 R + γV(S′) 掺了旧估计，有偏但方差小。这是一场偏差–方差权衡（bias–variance tradeoff），不是谁"更准"——在不同任务、不同学习阶段，赢家不同。第7章的 n 步方法正是要在这条权衡曲线上自由移动。
  • "Q-learning 是 on-policy。" 错。它的更新目标是 max——即贪心目标策略下的自举，而数据由 ε-贪心行为策略产生，目标策略与行为策略明确分离，是离策略的教科书例子。Sarsa（目标用实际采样的 A′）才是 on-policy。判据永远只有一条：学的那个策略，和跑数据的那个策略，是不是同一个？
  • "TD 收敛了就是学对了。" 仅在表格型 + 适当步长下成立。一旦进入函数逼近（第9章起），自举 + 函数逼近 + 离策略三者叠加会形成"致命三联"（deadly triad），Q-learning 式更新可能发散。本章所有收敛保证，离开表格这个温室都要重新审查。
💡 关键一跃

本章真正的结构是一组"权衡坐标"：更新时机（立即 vs 等结束）、目标来源（采样 vs 期望 vs max）、学的策略（行为策略 vs 贪心策略）。Sarsa、Q-learning、期望 Sarsa 不是三个孤立的算法，而是这三根坐标轴上的三个点。

点击翻面 →

📝分层习题

L1 概念辨析判断并说明理由：「Q-learning 因为用了 max 选动作，所以它是 on-policy 方法的一个更贪心版本。」这个说法对吗？
提示

回到 on/off-policy 的唯一判据：被学习的目标策略与产生数据的行为策略是不是同一个？

完整解答

说法错误。逐层拆：

① on-policy / off-policy 的判据与"用不用 max"无关，只看一件事：更新目标所对应的策略，与跑出这条数据的行为策略，是否为同一个。

② Q-learning 的目标 R + γ max_a Q(S′,a) 对应的是纯贪心目标策略；而它跑数据用的是 ε-贪心行为策略。两者明确分离，是离策略的教科书例子。"max"恰恰是它"离"的证据，不是"在"的证据。

③ 若真想要"更贪心的 on-policy"，应沿着 GLIE 思路让行为策略的 ε 渐近衰减到 0——那时 Sarsa 学的就是极限贪心策略。这是 on-policy 路线收敛到最优的正道，与 Q-learning 的离策略路线是两种设计。

L1 概念辨析当 ε = 0 时，期望 Sarsa 退化成什么？它和 Q-learning 此时完全等价吗？Sarsa 在 ε = 0 时又如何？
提示

ε = 0 时 ε-贪心策略的概率分布长什么样？把它代入期望 Sarsa 的加权和，再代入 Sarsa 的采样目标。

完整解答

ε = 0 时，ε-贪心退化为纯贪心策略：最优动作概率 1，其余 0。

① 代入期望 Sarsa：Σ_a π(a|S′)Q(S′,a) = 1 × Q(S′, argmax) = max_a Q(S′,a)。目标退化为与 Q-learning 完全相同；此时行为策略也即贪心（无探索），两算法完全等价。

② Sarsa 在 ε = 0 时，A′ 由贪心策略确定性选出，也恰好是 argmax，更新目标同样变成 R + γ max——数值上三者在此退化点合一。但本质不同：ε = 0 的 Sarsa 已停止探索，各 (s,a) 覆盖不再保证，控制收敛的前提被破坏；且一旦 ε > 0，Sarsa 与 Q-learning 立刻分道扬镳（6.4 的 1.16 vs 1.205），而期望 Sarsa 与 Q-learning 的差异则随 ε 连续变化。所以说"期望 Sarsa 在 ε=0 时与 Q-learning 等价"对，"Sarsa 在 ε=0 时也是"在数值上对、在算法性质上不成立（它牺牲了探索保证）。

L2 手算推导用 6.1 的条件重做一次 TD(0) 更新：V((1,4)) = 0.5，走到 (1,5)，R = −1，V((1,5)) = 4.0，γ = 0.9。先按 α = 0.1 算，再把 α 换成 0.5 算一次，对比两次结果并解释 α 的作用。
提示

TD 目标两次相同；变的只是"向目标靠拢的比例"。

完整解答

共同的目标与 δ：TD 目标 = −1 + 0.9 × 4.0 = 2.6；δ = 2.6 − 0.5 = 2.1。

α = 0.1：新 V = 0.5 + 0.1 × 2.1 = 0.5 + 0.21 = 0.71。

α = 0.5：新 V = 0.5 + 0.5 × 2.1 = 0.5 + 1.05 = 1.55。

对比与解释：同一目标 2.6，α = 0.1 只靠拢了差距的 10%（0.71），α = 0.5 靠拢了一半（1.55）。α 控制的是对新信息的信任速度：α 大学得快但对单个噪声样本反应剧烈（方差大），α 小学得稳但慢。这也解释了第5章的取舍：非平稳环境用常数 α 保持跟踪，但要承受真值附近的持续波动。

L2 手算推导Q(s,a) = 2.0，执行 a 得 R = −1，进入 s′。s′ 处 Q 值：a₁ = 3.0（行为策略实际选中）、a₂ = 5.0（最大值）。γ = 0.9，α = 0.1。分别写出 Sarsa 与 Q-learning 的完整更新过程。
提示

Sarsa 用实际选中的 a₁；Q-learning 无视实际选择，用 max。各自先算目标，再走"旧 + α×（目标 − 旧）"。

完整解答

Sarsa（用 a₁ = 3.0）：

① 目标 = R + γQ(s′,a₁) = −1 + 0.9 × 3.0 = −1 + 2.7 = 1.7

② δ = 1.7 − 2.0 = −0.3（这一步比预期差）

③ 新 Q = 2.0 + 0.1 × (−0.3) = 2.0 − 0.03 = 1.97

Q-learning（用 max = 5.0）：

① 目标 = R + γ max_a Q(s′,a) = −1 + 0.9 × 5.0 = −1 + 4.5 = 3.5

② δ = 3.5 − 2.0 = 1.5

③ 新 Q = 2.0 + 0.1 × 1.5 = 2.0 + 0.15 = 2.15

对比：同一条转移，Sarsa 把 Q 往下调（它忠实记录了"实际选了个次优动作"），Q-learning 把 Q 往上调（它只关心最优动作的前景）。这正是 6.4 节"现实 vs 理想"差异的又一次现身。

L3 建模应用某仓库用送货机器人沿货架边缘的窄道送货：窄道旁就是 2 米高的装卸平台边缘，掉下去机器人报废（类比 Cliff Walking）。机器人装有仿真器，也可以在真实仓库里边干边学。团队讨论：用 Sarsa 还是 Q-learning？请分"真实在线学习"与"仿真离线训练后部署"两种模式给出选择与理由，并画出决策流程图（mermaid）。
提示

关键问题：学习期间的探索代价由谁承担？真实机器人掉下去谁赔？仿真里掉下去又如何？

完整解答

① 真实在线学习（边送货边学）→ 选 Sarsa 或期望 Sarsa。探索代价由真实资产承担：Q-learning 会向往贴边的最短路径，学习期间 ε-贪心每次手滑都可能让机器人掉下平台；Sarsa 把"我可能手滑"计入价值，自动学到远离边缘的安全路径，在线累积回报（含事故成本）更好。期望 Sarsa 还能进一步降低选动作的方差。安全攸关 + 在线，on-policy 是正解。

② 仿真离线训练后部署 → 选 Q-learning（可配双 Q）。仿真里掉下去零成本，探索随便浪；目标是学到真正最短的最优策略再部署到真实仓库，Q-learning 直奔贪心目标策略，正是所需。噪声大时配双 Q 学习抑制最大化偏差。部署后若要继续在线微调，切回 Sarsa 类方法。

一句话判据：探索代价谁承担——真实世界承担就选 on-policy，仿真器承担就选 off-policy。

解析：A 正确。B 错：用 max 的是 Q-learning，不是 Sarsa。C 错：Sarsa 目标策略就是行为策略，分布一致，无需重要性采样（那是第5章离策略 MC 的工具）。D 错：目标与行为策略分离描述的是 Q-learning，恰与 Sarsa 相反。
自测 4
Q(s,a) = 1.0，R = −1，进入 s′；Q(s′,右) = 4.0（实际选中），max_a Q(s′,·) = 4.5，γ = 0.9，α = 0.1。Sarsa 与 Q-learning 更新后的 Q 分别是：
  • A. 1.16 与 1.16
  • B. 1.205 与 1.16
  • C. 2.6 与 3.05
  • D. 1.16 与 1.205
解析：D 正确。Sarsa 目标 −1+0.9×4.0 = 2.6，更新 1.0+0.1×1.6 = 1.16；Q-learning 目标 −1+0.9×4.5 = 3.05，更新 1.0+0.1×2.05 = 1.205。A 错：让 Q-learning 也用了实际选中的 4.0。B 错：两者写反。C 错：2.6 与 3.05 是两个目标值，还没走"旧 + α×(目标 − 旧)"那一步。
自测 5
某 s′ 处三个动作真值都是 −0.1，估计值为 +0.3、−0.4、+0.1。关于最大化偏差与双 Q 学习，正确的是：
  • A. max(0.3, −0.4, 0.1) = 0.3 是无偏的，因为三个估计的均值噪声为零
  • B. max 会系统性高估，双 Q 用 Q₁ 选动作、Q₂ 评估（如 −0.05），用 −0.05 做目标消除正偏差
  • C. 最大化偏差只出现在 Sarsa 中
  • D. 双 Q 学习需要环境模型才能工作
解析：B 正确——E[max] > max(E)，挑选与评估用两套独立估计后偏差消除。A 错：估计无偏推不出 max 无偏，max 专挑噪声最走运者。C 错：Sarsa 目标无 max，不受此偏差影响；案发地是 Q-learning 及一切贪心化更新。D 错：双 Q 仍是纯采样的无模型方法，只是维护两张 Q 表。

句1：这章解决什么问题？——
参考答案：蒙特卡洛必须等回合结束才能更新，持续性任务无法使用、长回合任务信号延迟且方差大。本章解决"能否每走一步就用自举目标立刻更新价值"。
句2：核心机制是什么？——

句3：它和前后章怎么分工？——
参考答案：第5章 MC 提供"采样、不自举"的一端，本章 TD 占据"采样 + 一步自举"，第7章 n 步自举把目标长度参数化，在两者之间连续取值，统一成完整的偏差–方差谱系；本章的 Q-learning 与最大化偏差问题还将在第11章（DQN/Double DQN）以函数逼近的形式回归。
