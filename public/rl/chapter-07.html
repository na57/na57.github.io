7.1一步与全程之间：为什么需要 n 步

第5、6两章各给了我们一个更新目标，它们恰好站在一条光谱的两端：

  • 蒙特卡洛目标：用整条回合的完整回报 Gt。它是对真实价值的无偏估计，但方差大——回报里每一步的随机性都累加进来；而且必须等回合结束才能更新。
  • TD(0) 目标：只用一步真实奖励 Rt+1 + γV(St+1)，剩下的靠自举。方差小、立刻可更新，但自举把当前估计的误差直接缝进了目标——有偏，对初始估计敏感。

这不是"二选一"的选择题，而是一条光谱（spectrum）：TD 用 1 步真实奖励，MC 用全部 T−t 步真实奖励，中间还隔着 2 步、3 步、……、n 步。n 步回报（n-step Return）的定义是把真实奖励用到第 n 步，然后用估计值收尾：

Gt:t+n = Rt+1 + γRt+2 + … + γn−1Rt+n + γn V(St+n)

两个端点立刻可以验证：n = 1 时，Gt:t+1 = Rt+1 + γV(St+1)，正是第6章的 TD 目标；n ≥ T−t 时，尾部 V(ST) = 0（终止态价值为零），公式退化为完整回报 Gt，即 MC 目标。n 步回报把 MC 和 TD 统一成了同一个家族的两个特例。

核心算例：同一条轨迹，五个不同的更新目标

沿用 5×5 gridworld（每步 −1、终点 +10、γ = 0.9）。设从 s₀ 出发的一条 5 步轨迹，奖励序列 R₁…R₅ = −1, −1, −1, −1, +10 后终止，当前估计 V(s₁) = 3、V(s₂) = 4、V(s₃) = 5、V(s₄) = 6。对 t = 0 逐个计算：

n目标计算过程数值信息构成
1G0:1−1 + 0.9 × 31.71 步真实 + 旧估计 V(s₁)
2G0:2−1 + 0.9×(−1) + 0.81 × 4 = −1.9 + 3.241.342 步真实 + 旧估计 V(s₂)
3G0:3−1 − 0.9 − 0.81 + 0.729 × 5 = −2.71 + 3.6450.9353 步真实 + 旧估计 V(s₃)
4G0:4−1 − 0.9 − 0.81 − 0.729 + 0.6561 × 6 = −3.439 + 3.93660.49764 步真实 + 旧估计 V(s₄)
≥5G（完整回报）−3.439 + 0.6561 × 103.122全部真实奖励，零自举

盯住这张表的变化规律：n 越小，目标里"旧估计"的占比越大——G0:4 用 γ⁴V(s₄) = 3.9366 收尾，而真实尾巴值 6.561，旧估计 V(s₄) = 6 低估了真实结局，于是目标被拉低到 0.4976。这就是自举偏差的具象化。n 越大，真实奖励占比越大，偏差消退，但每一步真实奖励都携带环境的随机性——方差随之上升。n 就是这个旋钮：往小拧，用偏差换方差；往大拧，用方差换偏差。

💡 关键一跃

把更新目标想成一笔钱：真实奖励是"现金"，自举的 V 是"赊账"。TD(0) 只收一步现金其余全赊，MC 全程现金概不赊账，n 步回报收 n 步现金再赊尾款。现金稳但来得慢、波动大；赊账快但账本的信用取决于你当前的估计准不准。

⚠️ 常见误区

"n 步目标要等多走 n 步才更新，所以 n 步比 TD 慢。" 形式上说没错——回合内 t 时刻的经验要到 t+n 时刻才用来更新，确有 n 步延迟。但每次更新一次消化了 n 步真实奖励的信息，单条经验的信息量是 TD(0) 的 n 倍。书上的 19 状态随机游走实验表明：中等大小的 n 学习最快，优于 n=1 也优于完整 MC。延迟是真的，"更慢"是假的。

7.2n 步 TD 与 n 步 Sarsa：把目标装进更新式

上一节造好了目标，这一节把它装进标准的更新骨架"新估计 = 旧估计 + 步长 × (目标 − 旧估计)"。n 步 TD（n-step TD）用于状态价值预测：

V(St) ← V(St) + α [ Gt:t+n − V(St) ]

注意时间结构：Gt:t+n 里出现 Rt+n 与 V(St+n)，所以 t 时刻的这次更新要等到 t+n 时刻才能执行。实现上通常缓存最近 n 步的 (S, A, R)，在 τ = t−n+1 时刻统一结算。

控制问题沿用第6章 Sarsa 的思路：把状态价值换成动作价值，让采样到的动作序列自己提供目标。n 步 Sarsa（n-step Sarsa）的动作价值版回报为：

Gt:t+n(q) = Rt+1 + γRt+2 + … + γn−1Rt+n + γn Q(St+n, At+n)
Q(St, At) ← Q(St, At) + α [ Gt:t+n(q) − Q(St, At) ]

结构与 Sarsa 完全一致：采样五元组链条 (St, At, Rt+1, …, St+n, At+n)，尾部用下一个实际执行的动作 At+n 的 Q 值自举——仍然是 on-policy。配套的还有 n 步期望 Sarsa（n-step Expected Sarsa）：把尾部 Q(St+n, At+n) 换成对策略 π 的期望 Σa π(a|St+n) Q(St+n, a)，消去尾部的采样随机性，思想与第6章的期望 Sarsa 一脉相承，此处不再展开。

算例：一次 5 步 Sarsa 更新

沿用 7.1 的轨迹。回合全长 5 步，取 n = 5 时目标就是完整回报 G = 3.122（尾部终止态 Q = 0）。设当前 Q(s₀, a₀) = 2.0，步长 α = 0.1：

Q(s₀, a₀) ← 2.0 + 0.1 × ( 3.122 − 2.0 ) = 2.0 + 0.1 × 1.122 = 2.0 + 0.1122 = 2.1122

对比：若用 1 步 Sarsa，目标是 R₁ + γQ(s₁,a₁)，更新幅度受旧估计 Q(s₁,a₁) 牵制；5 步目标直接由真实奖励构成，这一下就把"终点有 +10"的信息完整灌进了 Q(s₀, a₀)——尽管它为此多等了 4 步。

💡 关键一跃

n 步 Sarsa 与 Sarsa 的关系，就像 n 步回报与 TD 目标的关系：算法骨架一行不动，只换目标的"真实含量"。这也再次印证了第5章的那句话——所有更新都长一个样子，区别只在目标是什么。

⚠️ 常见误区

"n 步 Sarsa 的尾部可以随便用 maxa Q 收尾，那就变成 Q-learning 了。" 不能随意混搭。尾部用 At+n（实际采样动作）保持 on-policy 语义；尾部换成 max 得到的"n 步 Q-learning"是离策略方法，目标和采样分布对不上，必须用 7.3 的重要性采样或树备份等专门机制纠偏，直接替换会引入系统性误差。

7.3n 步离策略：逐段重要性采样比

上一节是 on-policy：行为策略就是目标策略。若要像第5章 5.5 节那样让行为策略 b 跑数据、目标策略 π 学价值，就必须纠偏。好消息是：n 步目标里"来自采样的部分"只有前 n 步，所以第5章那个要连乘到回合结束的重要性采样比，只需截断到 n 步：

ρt:t+n−1 = ∏k=tmin(t+n−1, T−1) π(Ak | Sk)b(Ak | Sk)

更新式只是把 ρ 乘进步长里：

V(St) ← V(St) + α · ρt:t+n−1 · [ Gt:t+n − V(St) ]

直觉和第5章完全相同：ρ 是整个步长的缩放因子——ρ = 0 意味着这段轨迹在 π 下不可能发生，样本作废（增量为零）；ρ 大意味着这段轨迹在 π 下比 b 下更典型，一条要顶几条用，步长被放大。

算例：一次 3 步离策略更新

设某 3 步片段中，三步的动作概率比如下：

步 kπ(Ak|Sk)b(Ak|Sk)比率
第1步0.90.51.8
第2步0.20.50.4
第3步0.90.51.8
ρ = 1.8 × 0.4 × 1.8 = 1.296

设 α = 0.1，该样本的误差项 (Gt:t+3 − V) = 2，则实际更新增量：

ΔV = α · ρ · (G − V) = 0.1 × 1.296 × 2 = 0.2592

对比 on-policy（ρ ≡ 1）的增量 0.2：这条样本在 π 眼中"更典型"，权重被放大到 1.296 倍。若第2步换成 π 概率为 0 的动作，ρ 立刻归零，整条 3 步样本直接作废。

💡 关键一跃

截断到 n 步是离策略方法的"减压阀"：第5章里 ρ 要连乘整回合（可能上百步），方差随长度指数膨胀；截到 n 步后，连乘项数被锁死在 n，方差被控制在 n 的尺度上——n 越小越稳。这就是为什么"n"在离策略里同样是偏差–方差旋钮：截得越短，越依赖自举（偏差），但 ρ 越温驯（方差）。

⚠️ 常见误区

"截断到 n 步就解决了重要性采样的方差问题，是免费的午餐。" 不是。截断只截到 n 步，意味着目标尾部仍然是自举的估计值——你压住了 ρ 的方差，付出的代价是目标重新引入偏差。这是偏差–方差的又一次取舍，和第5章"普通 IS 无偏但暴躁"的教训是同一枚硬币的两面。

7.4λ 回报：给所有 n 步一个几何权重

7.1 留下了一个悬而未决的问题：n 到底选几？2 步有 2 步的道理，4 步有 4 步的道理。与其纠结选哪一个，不如把所有 n 步目标加权平均全用上——谁的意见都听，但按几何衰减的权重听。这就是 λ 回报（λ-return）：

Gtλ = (1−λ) ∑n=1T−t−1 λn−1 Gt:t+n + λT−t−1 Gt

结构解读：每一项 n 步回报分到权重 (1−λ)λn−1，随 n 按几何速度衰减；回合末尾剩余的全部质量 λT−t−1 一次性落在完整回报 Gt 上，保证所有权重之和恰好为 1。

权重算例：λ = 0.8，距终止 T−t = 5

项权重公式权重值作用对象
n=1(1−λ)λ⁰0.2Gt:t+1（一步 TD 目标）
n=2(1−λ)λ¹0.2 × 0.8 = 0.16Gt:t+2
n=3(1−λ)λ²0.2 × 0.64 = 0.128Gt:t+3
n=4(1−λ)λ³0.2 × 0.512 = 0.1024Gt:t+4
末项λ⁴0.4096完整回报 Gt

验证权重归一：0.2 + 0.16 + 0.128 + 0.1024 + 0.4096 = 1.0 ✓。注意 λ 的几何意义：λ 越大，权重衰减越慢，长尾越厚，越多质量压在长 n 步（乃至完整回报）上。

数值算例：把 7.1 的五个目标加权成一个

直接代入 7.1 算出的 G0:1 = 1.7、G0:2 = 1.34、G0:3 = 0.935、G0:4 = 0.4976、G = 3.122：

G0λ = 0.2×1.7 + 0.16×1.34 + 0.128×0.935 + 0.1024×0.4976 + 0.4096×3.122
= 0.34 + 0.2144 + 0.11968 + 0.05095424 + 1.2787712 ≈ 2.004

λ 回报 2.004 落在最小目标 0.4976 与最大目标 3.122 之间——这正是加权平均的折中本性：偏差比方差小的短 n 目标拉它向下，完整的真实回报拉它向上。

最后要坦白一个代价：以上计算需要先拿到全部 n 步回报，也就是要等回合结束才能动手——这叫前向视角（forward view）：站在 t 时刻向前眺望整条未来轨迹。它理论上一清二楚，却不能在线运行。真正可用的实现是等价的后向视角（backward view）：边往前走边用"资格迹"（eligibility traces）把刚获得的 TD 误差分摊给刚路过的状态，数学上与前向视角严格等价、计算上却完全在线。这套机制属于第12章的内容，本章只需记住：λ 回报是目标，资格迹是实现它的引擎。

💡 关键一跃

λ 回报回答的不是"选哪个 n"，而是"不选"——它承认光谱上每个位置都有信息，用几何权重把它们编成一支合唱团：短 n 目标人多声大（权重高），长 n 目标人少但嗓门远（看得远）。λ 调节的就是合唱团的"声部平衡"。

⚠️ 常见误区

"λ = 0.8 表示'相信 80% 的一步回报'。" 错。λ 控制的是权重沿 n 衰减的速度（权重按 λ 几何衰减），不是对某个单一 n 的信任度。λ = 0.8 时一步目标只分到 0.2 的权重，完整回报反而分到 0.4096——最大的单一份额在末端。想看"纯一步"，要用 λ = 0（见习题与自测）。

前向视角需要 t 时刻之后的全部 n 步回报（直到回合结束）才能算出 Gtλ，无法在线更新。后向视角用资格迹：每步产生 TD 误差后，按迹的衰减即时分摊给刚访问过的状态，与 λ 回报严格等价且完全在线——第12章展开。

7.5错误直觉清算："n 步只是实现细节"

学完前三节，容易滑向一个轻描淡写的结论："n 步方法不就是 TD 的工程量变体吗，选个顺手的 n 就行了。" 这条直觉必须清算。拆开看三处错误：

  • 错因一：n 不是细节，是偏差–方差的工作点。n 直接决定更新目标里"真实奖励"与"旧估计"的配比，同一任务里 1 步和 5 步的收敛速度可差出数倍。书上的 19 状态随机游走实验结论是：中等 n 最优——这和你选学习率 α 一样，是头等重要的超参数，不是实现细节。
  • 错因二：n 不是越大越接近 MC 越好。MC 端"无偏"的光环只在估计成熟后兑现。训练早期价值函数还在剧烈变化，大 n 目标把大量真实奖励砸向一个还在漂移的估计，更新方向反复被旧值污染过的小目标反而更稳——Cliff Walking 这类对初期估计敏感的任务里，大步长光谱端会明显吃亏。就像 7.1 算例展示的：旧估计偏低时，小 n 的目标也被拉低，但拉得少、回头快。
  • 错因三："λ 回报和 n 步是两派方法。"不是。λ 回报就是全部 n 步回报的几何加权平均，是把整条光谱收成一个数的统一视角。n 步家族是"选一个点"，λ 回报是"全都要，但按几何权重分账"——同一个世界，两种表述。

实用建议：怎么选 n

  1. 先让 TD(0) 跑通（n=1）：实现最简单，延迟最小，先确认环境接口、更新代码、α 量级都对。
  2. 再试 n ∈ {2, 4, 8}：固定其他超参数，画每个 n 的回报–回合数学习曲线。
  3. 比较的是"学习速度"而不是渐近性能：哪个 n 的曲线上升最快、最早稳定，就用哪个；不要盲目追大 n。
  4. 若任务回合长且随机性强（ρ 或回报方差大），偏好小 n；若环境近乎确定、回合短，可以放大 n 甚至接近 MC 端。
💡 关键一跃

第5章到第7章讲的其实是同一件事的三次表述：MC 说"全真"，TD 说"全赊"，n 步说"真 n 赊尾"，λ 回报说"按比例都真一点"。记住这条链，你就握住了表格型无模型方法的主轴。

概念卡 1
n 步回报（n-step Return, Gt:t+n）
点击翻面 →
定义用 n 步真实奖励加尾部估计收尾的更新目标：Rt+1+…+γn−1Rt+n+γnV(St+n)。
解决问题MC（全真实、高方差、须等待）与 TD(0)（全自举、有偏、敏感初值）之间没有折中方案。
直觉收 n 步现金、尾款赊账：现金占比由 n 调节。
误区以为 n 越大越接近 MC 就越好——估计未稳定时大 n 被旧值污染，中等 n 常常最快。
何时用一切需要在偏差与方差间调工作点的表格型任务；第8章统一视图的基本构件。
概念卡 2
n 步 Sarsa（n-step Sarsa）
点击翻面 →
定义on-policy 控制：Q(St,At) ← Q + α[Gt:t+n(q) − Q]，尾部用实际采样的 Q(St+n,At+n)。
解决问题一步 Sarsa 单步信息量太少，奖励传播慢；n 步让一次更新消化 n 步真实经验。
直觉Sarsa 的五元组从"一截短链"换成"n 节链条"。
误区尾部随意换 max Q 就当 Q-learning——那样变成离策略，必须另行纠偏。
何时用回合中等长度、奖励稀疏的 on-policy 控制；期望 Sarsa 变体可去尾部采样噪声。
概念卡 3
n 步离策略与截断重要性采样（Off-policy n-step / Truncated IS）
点击翻面 →
定义V ← V + α·ρt:t+n−1·(Gt:t+n − V)，ρ 只连乘 n 步策略概率比。
解决问题第5章整回合 ρ 连乘方差爆炸；截断到 n 步把方差锁在 n 的尺度上。
直觉减压阀：连乘链条越短，权重越温驯。
误区以为截断是免费的——压住 ρ 方差的代价是自举尾部重新引入偏差。
何时用用日志数据/探索策略评估贪心目标的场景；第12章离策略策略学习的 precursor。
概念卡 4
λ 回报（λ-return, Gtλ）
点击翻面 →
定义全部 n 步回报的几何加权平均：(1−λ)Σλn−1Gt:t+n + λT−t−1Gt，权重和为 1。
解决问题"n 选几"的难题：不选，全部用上、按 λ 分账。
直觉合唱团：短 n 人多声大，长 n 人少但看得远，λ 调声部平衡。
误区λ=0.8 不是"信 80% 的一步回报"——λ 是衰减速度；最大单一权重 λT−t−1 常在完整回报上。
何时用TD(λ) 一族方法的目标定义；第12章资格迹的理论标尺。
概念卡 5
前向视角与后向视角（Forward / Backward View）
点击翻面 →
定义前向：站在 t 向未来看，用全部 n 步回报合成 Gtλ；后向：边走边用资格迹把 TD 误差分摊给刚路过的状态。
解决问题λ 回报前向计算要等回合结束，无法在线；后向视角给出严格等价的在线实现。
直觉前向是"先记账后结算"，后向是"随手把功劳分给刚走过的地方"。
误区以为两者是近似关系——它们数学上严格等价，只是计算顺序不同。
何时用第12章资格迹（TD(λ)、Sarsa(λ)）的核心机制；本章只需记住方向。
概念卡 6
n 的选择（偏差–方差旋钮）
点击翻面 →
定义n 控制更新目标中真实奖励与自举估计的配比：小 n 低方差有偏，大 n 无偏高方差。
解决问题没有普适最优的更新目标，必须按任务特性选工作点。
直觉收音机调台旋钮：往左噪声小但信号闷，往右信号全但杂音大，中间有最佳点。
误区当成实现细节随手定——它与 α 同为头等超参数，收敛速度可差数倍。
何时用任何 n 步/TD(λ) 实践：先 TD(0) 跑通，再试 {2,4,8} 比学习曲线。

📝分层习题

L1 概念辨析判断并说明理由：「n 步回报中 n 越大偏差越小、方差越大，所以应该尽量取大的 n。」
提示

"偏差小"是相对真值而言的渐近性质。训练早期，目标里的真实奖励要和什么样的估计配合？回想 7.1 算例中 G0:4 为什么只有 0.4976。

完整解答

说法错误。前半句"n 越大偏差越小、方差越大"在统计意义上成立，但结论"应该尽量大"漏掉了三个关键事实：

① 偏差小的前提是估计已经收敛。训练早期 V 还在剧烈变化，大 n 目标虽含大量真实奖励，但更新对象是尚在漂移的旧估计——7.1 算例中完整回报 3.122 与 G0:4 = 0.4976 的巨大差异正来自旧估计 V(s₄)=6 的失真。大 n 把这些失真"固化"进更多状态的更新里。

② 方差不是免费的。大 n 目标方差大，需要更多样本或更小 α 来压制，样本效率反而下降。

③ 实验证据相反：书上 19 状态随机游走实验显示中等 n 学习最快，优于 n=1 与大 n 两端。正确结论是：n 是需要按任务调节的超参数，不是越大越好。

L1 概念辨析「λ = 1 的 λ 回报等价于什么目标？λ = 0 呢？」请从 λ 回报定义式出发回答。
提示

把 λ = 1 和 λ = 0 分别代入 Gtλ = (1−λ)Σλn−1Gt:t+n + λT−t−1Gt，看哪些项存活。

完整解答

λ = 1：(1−λ) = 0，求和项全部消失；末项 λT−t−1 = 1，故 Gtλ = Gt，退化为完整回报（MC 目标）。

λ = 0：求和项中 λn−1 在 n ≥ 2 时为 0，只有 n=1 项存活且权重 (1−0)×0⁰ = 1；末项 0T−t−1 = 0。故 Gtλ = Gt:t+1 = Rt+1 + γV(St+1)，退化为一步 TD 目标。

这印证了"λ 是光谱参数"：λ 从 0 拧到 1，方法从 TD(0) 连续滑向 MC，与 n 从 1 拧到 T−t 是同一个光谱的两种参数化。

L2 手算推导一条 3 步终止的轨迹：奖励 R₁ = −1, R₂ = −1, R₃ = +5（T = 3），γ = 0.9，当前估计 V(s₁) = 2、V(s₂) = 3（终止态价值为 0）。计算 G0:1、G0:2 与完整回报 G，写出全部步骤，并指出三者偏差–方差排序。
提示

G0:1 用 V(s₁) 收尾，G0:2 用 V(s₂) 收尾，完整回报在 R₃ 后终止、无需自举。先列公式再代数字。

完整解答

G0:1（1 步真实 + V(s₁)）：

G0:1 = R₁ + γV(s₁) = −1 + 0.9 × 2 = −1 + 1.8 = 0.8

G0:2（2 步真实 + V(s₂)）：

G0:2 = R₁ + γR₂ + γ²V(s₂) = −1 + 0.9×(−1) + 0.81×3 = −1 − 0.9 + 2.43 = −1.9 + 2.43 = 0.53

完整回报 G（3 步后终止，无自举）：

G = R₁ + γR₂ + γ²R₃ = −1 + 0.9×(−1) + 0.81×5 = −1.9 + 4.05 = 2.15

偏差–方差排序：真实结局 2.15，而 V(s₂)=3、V(s₁)=2 的旧估计都把目标往下拉：G0:1 = 0.8 与 G0:2 = 0.53 的偏差（|0.8−2.15|、|0.53−2.15|）远大于 G 的零偏差；方差排序相反：G0:1 只含 1 个随机奖励最稳，G 含 3 个最晃。即 偏差：G < G0:2 < G0:1；方差：G0:1 < G0:2 < G。

L2 手算推导一次 2 步离策略更新：两步的策略概率分别为 π 侧 1 与 0.25、b 侧各 0.5；α = 0.2，误差项 (Gt:t+2 − V) = 1.5。求 ρ 与本次更新增量。若第二步 π 的概率改为 0，结果如何？说明原因。
提示

ρ 是两步比率连乘；增量 = α·ρ·(G−V)。第二步 π = 0 时连乘中有一因子为 0。

完整解答

第一步比率：1 / 0.5 = 2；第二步比率：0.25 / 0.5 = 0.5。

截断采样比：ρ = 2 × 0.5 = 1.0。

更新增量：ΔV = α·ρ·(G−V) = 0.2 × 1.0 × 1.5 = 0.3。注意 ρ = 1.0 纯属巧合：单步比率 2（π 下更典型）与 0.5（π 下较少见）恰好抵消。

若第二步 π = 0：ρ = 2 × 0 = 0，增量 = 0.2 × 0 × 1.5 = 0，该样本作废。原因：这条轨迹包含一个目标策略 π 绝不可能执行的动作，它对"π 下的价值"不携带任何信息——重要性采样的覆盖假设（π 支持的动作 b 必须可能采样）在此被违反方向恰好相反：是 π 不支持 b 采到的动作，该轨迹只能丢弃。

L3 建模应用一台机械臂做连续装配作业，任务无自然回合终止（持续数月不间断运行），价值函数从零初始化。有人提议用纯 MC 评估当前控制策略，有人提议全程 TD(0)。指出两条路线各自的致命问题，给出"先 TD(0) 预训练、再切换 n=4"的分阶段方案，并用 mermaid 画出方案流程。
提示

持续任务里"完整回报"意味着什么？TD(0) 的偏差来自哪里，什么时候它会自动减轻？

完整解答

纯 MC 的致命问题：任务永不终止，完整回报是无穷项折扣和，任何有限时刻都拿不到一个"完整样本"，更新一次也无法执行——MC 在本任务中根本不适用。

全程 TD(0) 的致命问题：TD(0) 可以在线更新，但其目标 R + γV′ 的偏差完全由当前估计 V′ 承载。从零初始化意味着早期目标几乎全是噪声自举——机械臂早期价值严重失真，更新方向可能被错误的初始估计带偏，恢复缓慢。

分阶段方案：

① 阶段一 TD(0) 预训练：利用其低方差、即时更新的特性，让 V 快速脱离糟糕的初始值、进入合理量级；

② 阶段二切换 n = 4：估计已稳定后，自举尾部的失真大幅减轻，此时用 4 步真实奖励精修价值，降低残余偏差；

③ 持续监控回报曲线，若性能停滞再在 {2, 8} 中微调 n。

逻辑：偏差来自"旧估计不准"，而"不准"随学习自动减轻——所以先用低方差方法把估计养准，再放大 n 收割低偏差。

参考答案：第5章 MC 等到回合结束才更新（无偏但方差大），第6章 TD 只看一步（低方差但有偏、敏感初值）。本章解决"能否在一步自举与整回合回报之间选一个中间步数，连续平衡偏差与方差"。
句2：核心机制是什么？——
参考答案：n 步回报 Gt:t+n 用 n 步真实奖励加 γn 折扣的尾部估计收尾，套进"旧估计 + α(目标−旧估计)"骨架即得 n 步 TD 与 n 步 Sarsa；离策略时把重要性采样比截断到 n 步；λ 回报用几何权重 (1−λ)λn−1 把所有 n 步目标加权平均，权重和为 1。
句3：它和前后章怎么分工？——
参考答案：第5、6章各占据光谱一端，本章把两端连成连续光谱并用 λ 回报统一；第8章把这条光谱纳入统一视图并引入规划；λ 回报的在线实现（资格迹、后向视角）则留给第12章。
