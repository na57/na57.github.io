13.1为什么绕过值函数：策略的三处断裂

前 11 章共享一个固定套路：先学 Q 或 V，再用 argmax（或 ε-贪心）把值"翻译"成动作。这个翻译器在三种场景下会断：

断裂点场景为什么 argmax 救不了
连续动作机械臂力矩、方向盘转角 ∈ ℝ无穷多个动作，maxa Q(s,a) 是一个非凸优化问题，每步都要现场求解
随机最优石头剪刀布、部分可观测的牌局最优策略本身必须是随机的；argmax 只能给出确定性策略
逼近突变函数逼近下的 QQ 的微小变化可能让 argmax 结果跳变，策略不随参数光滑变化，无法保证改进方向

对策是策略近似（Policy Approximation）：直接写 π(a|s,θ)，让 θ 成为优化对象。离散动作用软最大（Softmax）参数化，给每个动作一个偏好值 h(s,a,θ)：

π(a|s,θ) = eh(s,a,θ)∑b eh(s,b,θ)

优化目标定义成起始状态的价值：J(θ) = vπθ(s₀)。问题随之变成：J 对 θ 的梯度怎么算？梯度里有两层依赖——动作概率依赖 θ，而状态分布也依赖 θ（策略改变你会走到哪里）。后者需要对环境转移求导，而我们没有模型。13.2 的定理正是解决这个死结。

⚠️ 常见误区

以为"直接学策略"就是丢掉值函数。本章后半会看到：值函数没有消失，它从"策略的来源"降级为"梯度的降噪器"（基线 / critic）。策略梯度方法与值方法不是替代关系，而是分工关系。

13.2策略梯度定理：把"往哪调"变成一个期望

上一节的死结：∇J 里藏着 ∇μ(s)（状态分布的梯度），需要模型。策略梯度定理（Policy Gradient Theorem）证明：这个项会在推导中自行消失。分四步走，不跳步：

第 1 步：展开定义。J(θ) = vπ(s₀)，先对任意状态展开：

∇vπ(s) = ∇ ∑a π(a|s) qπ(s,a)

第 2 步：乘积法则。

= ∑a [ ∇π(a|s) qπ(s,a) + π(a|s) ∇qπ(s,a) ]

第 3 步：把 ∇q 再展开。qπ(s,a) = ∑r,s′ p(r,s′|s,a)[ r + γvπ(s′) ]，其中 ∇r = 0、∇p = 0（环境参数与 θ 无关），所以：

∇qπ(s,a) = γ ∑s′ p(s′|s,a) ∇vπ(s′)

代回去，∇vπ(s) 里又出现 ∇vπ(s′)——这是一个递归。把它沿时间不断展开，每项都是一个"以某概率到达某状态 s′"的贡献。

第 4 步：收成期望。展开的所有"到达概率"加总，正是策略 π 下的折扣状态分布 μ(s)。所有含 ∇μ 的项都被吸收进"在 μ 下取期望"：

∇J(θ) ∝ ∑s μ(s) ∑a ∇π(a|s,θ) qπ(s,a) = Eπ[ ∇lnπ(A|S,θ) · qπ(S,A) ]

最后一步用了对数导数技巧：∇π = π · ∇lnπ，把 ∇π(a|s) 换成 π(a|s)∇lnπ(a|s) 后，对 a 的求和变成对采样动作的期望。

✅ 定理的礼物

∇lnπ 只涉及策略自身（我们有解析式），qπ 可以从采样估计，μ 根本不需要出现——整个梯度可以在不知道环境模型的前提下用样本估计。这就是策略梯度"无模型"的来源：不是假设了模型，而是模型项被定理消掉了。

⚠️ 常见误区

把 ∝（正比于）当成等号。∇J = 常数 × E[∇lnπ · q]，这个常数与 θ 无关（它来自折扣状态分布的归一），所以梯度方向无偏、可用于上升；但写理论推导时不能随手把 ∝ 写成 =。 episodic 与 continuing 任务的常数含义也略有差别。

13.3REINFORCE：用采样回报顶替 q

定理里还有 qπ(S,A) 未知。最简单的估计：在当前轨迹上，用 t 时刻之后的实际回报 Gt 顶替它。Gt 是 qπ(St,At) 的无偏采样，所以

θ ← θ + α · Gt · ∇lnπ(At|St, θ)

仍是梯度方向的无偏估计。这就是 REINFORCE（蒙特卡洛策略梯度）。每步的更新直觉：回报高 → 沿"提高这个动作对数概率"的方向走；回报低 → 反向。

手算：一步更新，全数字

单状态、两动作 L / R，softmax 偏好即参数本身：h = θL, θR。初始 θL = θR = 0，α = 0.1。第一步采样：

  • π(R|θ) = e⁰/(e⁰+e⁰) = 0.5；同理 π(L) = 0.5
  • 采样到 R，轨迹回报 G = 1
  • ∇θR lnπ(R) = 1 − π(R) = 0.5；∇θL lnπ(R) = 0 − π(L) = −0.5
  • ΔθR = 0.1 × 1 × 0.5 = +0.05；ΔθL = 0.1 × 1 × (−0.5) = −0.05

更新后 θR = 0.05, θL = −0.05，新概率：

π(R) = e0.05e0.05 + e−0.05 = 1.05131.0513 + 0.9512 ≈ 0.525

一次正回报把 R 的概率从 0.500 推到 0.525。注意 ∇lnπ 自带"1 − π"因子：已经高概率的动作，同样的回报推得更少——概率天然饱和。

⚠️ 常见误区

"无偏 = 好用"。Gt 是 MC 回报，方差大：同一个状态两条轨迹的 G 可能差好几倍，参数被噪声来回拉扯。更隐蔽的问题：若所有回报都为正，所有被采到的动作概率都被推高（只是幅度不同），学习效率低。下一节的基线正是为此而来。

13.4带基线的 REINFORCE：不花代价的方差削减

上一节的症结：梯度估计的方差大，且"全正回报推高一切"。办法是减掉一个只依赖状态的基线（Baseline）b(s)：

θ ← θ + α · ( Gt − b(St) ) · ∇lnπ(At|St, θ)

为什么这不会改变梯度的期望？一行推导（对每个 s 的动作求和）：

∑a b(s) ∇π(a|s,θ) = b(s) ∇ ∑a π(a|s,θ) = b(s) ∇1 = 0

概率和恒为 1，梯度为零——基线项在期望中自动消失。它只能改方差，不能改方向。

方差到底降多少：一个可以验证的玩具

单状态、π(L) = π(R) = 0.5，参数 θR。梯度系数：采到 L 时 g = ∇lnπ(L) = −0.5，采到 R 时 g = +0.5。设回报只依赖动作：GL = 6，GR = 4。取基线 b = 5（平均回报）。

采到 L（p=0.5）采到 R（p=0.5）EE[·²]Var
无基线 G·g6×(−0.5) = −34×0.5 = +2−0.50.5×9+0.5×4 = 6.56.5−0.25 = 6.25
有基线 (G−5)·g1×(−0.5) = −0.5(−1)×0.5 = −0.5−0.50.250.25−0.25 = 0

期望同为 −0.5（方向不变，回报更差的 R 被相对压下去），方差从 6.25 降到 0。归零是这个玩具的特例（回报恰好只依赖动作、基线恰好等于均值），真实任务不会归零；但机制是普遍的：基线越接近"该状态下的期望回报"，剩余波动越小。而"状态的期望回报"正是 V(s)——这就是下一节 critic 登场的理由。

💡 直觉

基线回答的不是"这个动作好不好"，而是"这个结果比预期好多少"。G − b > 0 才推概率，< 0 就压概率。没有基线时，"好"的绝对标准不存在，只有相对标准才产生干净的信号。

13.5Actor-Critic：让学出来的 V 当基线

基线最好是 V(s)，但 V 也不知道——那就学一个。行动者—评论家（Actor-Critic）同时维护两套参数：

  • Actor（策略）：θ，按 ∇lnπ 方向更新；
  • Critic（价值）：w，学 V(s;w)，产出基线与 δ。

用一步 TD 误差代替 G − b（δ 本身就约等于 G − V，因为 E[R + γV(S′)] − V(S) ≈ q − V）：

δt = Rt+1 + γV(St+1;w) − V(St;w)
θ ← θ + αθ δt ∇lnπ(At|St,θ)，  w ← w + αw δt ∇wV(St;w)

手算：一步 actor-critic

承接 13.3 的状态与策略（π(R) = 0.5），设 critic 已学到 V(s) = 0.5，本步 R = 1、S′ 终止（V = 0），γ = 1，αθ = αw = 0.1：

  • δ = 1 + 1×0 − 0.5 = 0.5
  • Actor：ΔθR = 0.1 × 0.5 × (1−0.5) = +0.025（对照 13.3 纯 REINFORCE 的 +0.05：critic 已预见了半数回报，"惊喜"只剩一半）
  • Critic：V(s) ← 0.5 + 0.1×0.5 = 0.55
  • 若下一步同样转移再来一次：δ = 1 − 0.55 = 0.45，更新量进一步缩小——回报被逐步"消化"进 V，actor 的驱动信号自动衰减
✅ 偏差换方差

一步 δ 有偏（V 还没学准），但方差远低于 MC 的 G；而且不需要等回合结束，每个样本在线就能更新。这是把第 6 章 TD 的哲学搬到了策略空间：自举不是妥协，是在线性的来源。

⚠️ 常见误区

以为 actor 和 critic 可以用同一个步长、同一份数据随便混。实践中 critic 要学得快（它 supplying 基线，错一点 actor 就偏），通常 αw > αθ（两个时间尺度）；且两者看到的数据来自同一行为策略，critic 的偏差会直接变成 actor 的系统性错推。

13.6连续动作：高斯策略

连续动作空间不能枚举、不能 argmax——但策略梯度根本不需要枚举动作，它只需要 π(a|s,θ) 能采样、能算 ∇lnπ。标准选择是高斯策略（Gaussian Policy）：均值由参数决定，方差固定或也可学：

a ~ N( μ(s;θ), σ² )，  ∇θ lnπ(a|s,θ) = a − μ(s;θ)σ² · ∇θμ(s;θ)

手算：一维线性均值

设 μ = θ（x(s) = 1 的线性情形），σ = 1，当前 θ = 1.0。采到 a = 1.6，δ = 0.5，α = 0.1：

  • ∇θlnπ = (1.6 − 1.0)/1 × 1 = 0.6（动作比均值大 → 梯度指向"把均值调大"）
  • Δθ = 0.1 × 0.5 × 0.6 = +0.03 → 新 μ = 1.03

若采到 a = 0.7（比均值小）且 δ 仍为正，∇lnπ = −0.3，均值会被往回拉——高斯策略的梯度方向永远指向"让采样分布向高 δ 的动作集中"。σ 控制探索强度：σ 大 → 采样分散、梯度噪声大；σ 也可参数化让算法自己学。

⚠️ 常见误区

以为连续动作可以先离散化再用 DQN。离散化把维度灾难搬进动作维：7 个关节各 20 档就是 20⁷ ≈ 12.8 亿个动作。高斯策略用两个参数（μ、σ）覆盖整个实数轴，这是策略参数化相对值方法的结构性胜利。

13.7错误直觉专场："策略梯度不需要值函数"

本章最容易被带走的一句话："策略梯度方法摆脱了值函数。"逐条拆：

说法判定准确的说法
"策略梯度不需要值函数"错定理里的 qπ(S,A) 就是值函数；REINFORCE 用采样 G 估计它，actor-critic 直接学它。摆脱的是"用值函数 argmax 导出策略"，不是值函数本身。
"策略梯度收敛到全局最优"错J(θ) 对 θ 一般非凸，梯度上升只保证到局部最优（表格 softmax 表示下有凸性结果，但函数逼近下不成立）。
"基线引入偏差，不如纯 REINFORCE 干净"错基线项期望恒为 0（∑b∇π = b∇1 = 0），只改方差。一步 actor-critic 的 δ 才有偏，那是拿偏差换方差与在线性的主动选择。
"策略梯度天然比值方法样本效率高"错恰好相反：MC 版 REINFORCE 方差大、样本效率低；actor-critic 用自举追回部分效率，但值方法的离策略 + 回放组合在样本效率上常常更强。
💡 一句话校正

策略梯度与值方法的关系不是"取代"，而是重新分工：策略负责"怎么动"（参数化、可随机、可连续），值函数负责"动得比预期好多少"（基线、critic、δ）。两者在 actor-critic 里会师，谁也不可缺席。

毕业三问

读完全书，用自己的话回答下面三问。先默答，再展开对照。

第一问：预测与控制如何统一？
参考答案：统一在广义策略迭代（Generalized Policy Iteration, GPI）——评估（预测：这个策略值多少）与改善（控制：据此换个更好的）两个过程交替或同时进行，互为对方的目标。值方法里改善靠 argmax，策略梯度里改善靠沿 ∇J 上升；MC、TD、actor-critic 只是 GPI 在"评估的颗粒度与时机"上的不同实例。预测给控制提供方向，控制给预测提供新的评估对象，循环收敛到最优。
第二问：为什么表格法会"崩"？
参考答案：要分清两层。第一层是规模崩：状态数指数增长，表格存储与每个状态的访问次数都撑不住，且表格把每个状态当孤岛、无泛化——这是第 9 章函数逼近登场的理由。第二层才是收敛崩：函数逼近 + 自举 + 离策略构成致命三合，目标随参数漂移，半梯度方法可能发散（第 10–11 章）。表格法本身在自己的世界里收敛得很好；"崩"是把它推出自己世界的代价。
第三问：值方法与策略方法怎么取舍？
参考答案：值方法样本效率高、离策略与回放成熟、理论收敛性强，但策略被 argmax 绑架：进不了连续动作、给不了随机最优、逼近下会跳变。策略方法直接优化目标、可随机可连续、策略随参数光滑变化，但梯度方差大、易局部最优、步长敏感。实践的答案是不取舍：actor-critic 让值函数当 critic 降噪、让参数化策略当 actor 行动——第 13 章的终点恰是第 5–11 章与第 13 章的合流。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
策略近似（Policy Approximation）
点击翻面 →
定义直接写 π(a|s,θ)（如 softmax、高斯），让策略成为可微参数化对象。
解决问题值函数 + argmax 在连续动作、随机最优、逼近突变三处断裂。
直觉不再"先估价再翻译"，直接雕刻"怎么动"这件事本身。
误区以为它抛弃了值函数——值函数降级为降噪器，并未消失。
何时用连续控制、需要随机策略、策略需光滑变化的场合。
概念卡 2
策略梯度定理（Policy Gradient Theorem）
点击翻面 →
定义∇J(θ) ∝ Eπ[∇lnπ(A|S,θ)·qπ(S,A)]，μ(s) 的梯度被定理吸收。
解决问题让梯度可在无环境模型时用采样估计。
直觉"往哪调参数"= 对数概率的变化方向 × 这个动作值多少。
误区把 ∝ 当 =；忘了 q 仍是未知量需要估计。
何时用一切策略梯度方法的理论地基（REINFORCE、AC、PPO 皆是其实例）。
概念卡 3
REINFORCE（蒙特卡洛策略梯度）
点击翻面 →
定义θ ← θ + αGt∇lnπ(At|St,θ)：用实际回报 G 顶替定理中的 q。
解决问题给出第一个可运行的无模型策略梯度算法。
直觉回报高就推高这个动作的对数概率，低就压。
误区以为无偏就够好——MC 回报的方差让训练极慢。
何时用概念验证、基线/AC 的前身；episodic 任务。
概念卡 4
基线（Baseline）
点击翻面 →
定义从 G 中减去只依赖状态的 b(s)：更新用 (G−b)∇lnπ；期望不变（∑b∇π=b∇1=0）。
解决问题不改变梯度方向的前提下压缩方差。
直觉只奖励"超出预期的部分"，预期之内的涨跌不算功过。
误区以为基线引入偏差——它只改方差；有偏的是自举的 δ。
何时用一切 REINFORCE 实践；最优基线 ≈ V(s)，通向 actor-critic。
概念卡 5
Actor-Critic（行动者—评论家）
点击翻面 →
定义双参数结构：actor 按 αθ·δ·∇lnπ 更新策略，critic 按 αw·δ·∇V 学价值，δ = R+γV′−V。
解决问题基线 V 未知 → 学一个；同时用自举换取在线性与低方差。
直觉演员演戏，评论家打分；惊喜（δ）是唯一的沟通语言。
误区以为两者可用同一步长同一目标——通常 αw > αθ，critic 偏差会传染 actor。
何时用现代深度 RL 的主力框架（A2C、PPO、DDPG 的骨架）。
概念卡 6
高斯策略（Gaussian Policy）
点击翻面 →
定义a ~ N(μ(s;θ), σ²)；∇θlnπ = (a−μ)/σ² · ∇θμ。
解决问题连续动作空间的策略参数化：两个参数覆盖整条实数轴。
直觉均值是"当前想做的动作"，σ 是"敢试探多远"。
误区以为连续动作可离散化后用 DQN——动作维指数爆炸。
何时用机器人控制、任何连续控制任务；σ 也可参数化学习。
概念卡 7
广义策略迭代（GPI）
点击翻面 →
定义评估与改善两个过程交替/并行推进，互为对方目标，驱动策略向最优收敛的总框架。
解决问题统一预测与控制：MC/TD/DP/actor-critic 全是它的实例。
直觉一个量体温、一个开药方，反复迭代直到康复。
误区以为评估必须做完才能改善——第 5 章起就在用"边评估边改善"。
何时用理解全书所有收敛性论证的共同骨架；毕业三问第一问的答案。

📝分层习题

L1 概念辨析判断："REINFORCE 的梯度估计是无偏的，因此它的方差也小，不需要基线。"
提示

无偏与方差是估计量的哪两个不同性质？MC 回报的方差来自哪里？

完整解答
错。无偏只保证估计量的期望等于真梯度，不约束单次实现的波动。Gt 是整段轨迹回报的采样，随机性沿每一步累积，方差很大——这正是需要基线的原因。基线减掉状态级期望回报（期望不变：∑b∇π=0），只压缩方差。"无偏"与"低方差"是估计量的两个独立维度。
L1 概念辨析判断："加入基线 b(s) 后，策略梯度的期望会改变，只是实践中影响不大。"
提示

对固定 s，计算 ∑a b(s)∇π(a|s,θ)。概率对 a 求和是多少？

完整解答
错。期望严格不变，不是"影响不大"：∑a b(s)∇π(a|s,θ) = b(s)∇∑aπ(a|s,θ) = b(s)∇1 = 0，对每个状态 s 都成立，取期望后基线项恒为 0。前提是 b 不依赖动作 a（若 b 依赖 a，此推导失效——所以基线只能是状态函数）。
L2 手算推导承接 13.3 的设置（两动作 L/R，softmax 偏好即参数，α = 0.1），新一局开始：θL = 0.2, θR = 0。本步采到动作 L，回报 G = 2。计算 π(R)、两个参数的更新量、更新后的 π(R)。
提示

先算 π(R) = e⁰/(e0.2+e⁰)；∇θRlnπ(L) = 0−π(R)，∇θLlnπ(L) = 1−π(L) = π(R)。e0.2 ≈ 1.2214。

完整解答

π(R) = 1/(1.2214+1) = 1/2.2214 ≈ 0.4502；π(L) ≈ 0.5498。

ΔθR = 0.1×2×(−0.4502) = −0.090；ΔθL = 0.1×2×0.4502 = +0.090。

新参数：θL = 0.29，θR = −0.09。新 π(R) = e−0.09/(e0.29+e−0.09) = 0.9139/(1.3364+0.9139) = 0.9139/2.2503 ≈ 0.406。

解读：回报 +2 给了被采到的 L，L 的偏好上升、R 下降，π(R) 从 0.450 降到 0.406——奖励什么就放大什么。

L2 手算推导13.4 的玩具例（π(L)=π(R)=0.5，gL=−0.5，gR=+0.5，GL=6，GR=4），把基线从 5 改为 4。重算梯度期望与方差，与无基线（Var=6.25）、b=5（Var=0）对比，说明基线选取的影响。
提示

逐项算 (G−b)·g 的两个取值，再算 E、E[·²]、Var = E[·²] − E²。

完整解答

b=4：L 分支 (6−4)×(−0.5) = −1；R 分支 (4−4)×0.5 = 0。

E = 0.5×(−1) + 0.5×0 = −0.5（与无基线、b=5 完全相同，再次验证基线无偏）。

E[·²] = 0.5×1 + 0.5×0 = 0.5；Var = 0.5 − 0.25 = 0.25。

对比：无基线 6.25 → b=4 时 0.25 → b=5 时 0。基线越接近状态期望回报（本例 5），方差越小；即使取偏差的 4，方差也已缩到原来的 4%。方向永远不变，变的只是噪声。

L3 建模应用六轴机械臂做"拧紧螺丝"：动作是 6 维连续力矩（各 ∈ [−2, 2] N·m），状态是关节角与角速度，奖励 = −(角度误差)² − 0.01×(力矩平方和)，回合结束于拧紧或超时。①为什么不用 DQN 类方法？②给出策略的形式与 ∇lnπ；③基线/critic 选什么、δ 怎么写；④指出一个会导致训练不稳的设计错误。
提示

先数动作空间的"大小"；再想高斯策略需要哪两个参数化头；最后想 δ 里谁依赖逼近器。

完整解答

① DQN 需要 maxa Q(s,a)：动作是 6 维连续向量，每步都要解一个 6 维非凸优化，不可行；离散化若每轴 20 档则是 20⁶ = 6400 万动作，指数爆炸。

② 高斯策略：μ(s;θ) 为 6 维（网络输出 6 个均值），σ 可固定（如 0.3）或让网络再输出 log σ。∇θlnπ(a|s,θ) = ∑i=1..6 (ai−μi)/σi² · ∇θμi。采样即得动作，天然带探索。

③ critic 学 V(s;w)（同结构网络、输出标量）；δ = R + γV(s′;w) − V(s;w)，actor 用 δ·∇lnπ 上升，critic 最小化 δ²。奖励 shaping 已含力矩惩罚，critic 会把"省力"的偏好通过 δ 传给 actor。

④ 典型错误：σ 固定过小（如 0.01）——探索消失、梯度方差反而爆炸（(a−μ)/σ² 被放大 10⁴ 倍），且易困在初始策略；或 actor 与 critic 共用大步长，critic 未收敛时 δ 噪声直接带偏策略。正确做法：σ 可学习、αw > αθ（两个时间尺度）。

句1：这章解决什么问题？——
参考答案：前 11 章的策略都是从值函数经 argmax 翻译出来的，这条翻译链在连续动作、随机最优、逼近突变三处断裂；本章把策略本身参数化，直接对 J(θ) = vπ(s₀) 做梯度上升。
句2：核心机制是什么？——
参考答案：策略梯度定理把 ∇J 写成 E[∇lnπ · qπ]（μ 的梯度被定理吸收，无模型可估）；REINFORCE 用采样 G 顶 q（无偏高方差），基线 b(s) 零代价降方差（∑b∇π=0），actor-critic 学 V 当基线并用 δ 自举换在线性；连续动作用高斯策略，∇lnπ = (a−μ)/σ²·∇μ。
句3：它和前后章怎么分工？——
参考答案：本章是全书终点。Ch1–4 定义目标（贝尔曼方程），Ch5–8 用采样替代模型，Ch9–11 用逼近替代查表，Ch12 缝合时间信用；本章把"行动"本身也变成参数——值函数没有退场，而是与参数化策略在 actor-critic 里会师，GPI 的骨架贯穿始终。
