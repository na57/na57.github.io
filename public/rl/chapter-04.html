4.1为什么 DP 可行：把等式读成更新规则

第 3 章留下两组方程：Bellman 期望方程（v_π 的一致性条件）与最优方程（v* 的定义）。动态规划（Dynamic Programming, DP）的核心动作只有一步：把等号"="改读成赋值"←"。等式 v = T(v) 变成迭代 v ← T(v)，反复施加点映射 T，值就一步步逼近不动点。

为什么这样一定收敛？因为 Bellman 算子是压缩映射（Contraction）：每迭代一次，当前估计与真值的最大误差至少缩小 γ 倍（γ<1 时；回合制 γ=1 也有类似保证）。几何级数衰减 → 必然收敛。本章所有算法的收敛性都根植于此。

另一个关键操作是自举（Bootstrapping）：用当前的估计值去更新另一个估计值——不等真实回报走完，先拿"下一局面的当前估值"顶上。DP 全程自举，这是它与第 5 章蒙特卡洛方法（等真实回报）最本质的区别。

⚠️ 前提声明

本章一切算法都要求动态函数 p(s′,r|s,a) 完全已知——每个式子里的 ∑_{s′,r} p[·] 都要真的算出来。现实中 p 通常未知，所以 DP 在全书里更像"理论基准"与"算法模板"：第 5–8 章做的事，就是把这里的期望换成采样，其余骨架原样保留。

4.2策略评估：迭代算出 v_π

第一个任务：给定策略 π，求它的值函数 v_π（这叫策略评估 Policy Evaluation，也叫预测问题）。把 Bellman 期望方程改写成更新：

Vk+1(s) ← ∑a π(a|s) ∑s′,r p(s′,r|s,a) [ r + γ Vk(s′) ]

从任意 V₀（通常全 0）开始，一轮轮扫描所有状态（每轮叫一次 sweep），直到变化量小于阈值。

网格世界手算：均匀随机策略的前三轮

4×4 网格世界（终点 (1,1)、(4,4)，每步 −1，γ=1，撞墙停原地），均匀随机策略（四方向各 ¼），V₀ 全 0，每轮用上一轮的值整体更新：

第 1 轮：每个非终点状态，四邻的 V₀ 都是 0，故 V₁(s) = ¼ × 4 × (−1 + 0) = −1（全部非终点格子）。

第 2 轮（用 V₁ 更新）：以 (1,2) 为例——上撞墙停 (1,2)、左进终点 (1,1)、下到 (2,2)、右到 (1,3)：

V₂(1,2) = ¼[(−1+(−1)) + (−1+0) + (−1+(−1)) + (−1+(−1))] = ¼×(−7) = −1.75

(2,2) 四邻全是非终点：V₂(2,2) = ¼ × 4 × (−1 + (−1)) = −2。（书上四舍五入把 −1.75 记作 −1.7。）

第 3 轮（用 V₂ 更新）：(2,2) 的四邻 V₂ 值：上 (1,2)=−1.75、下 (3,2)=−2、左 (2,1)=−1.75、右 (2,3)=−2：

V₃(2,2) = ¼[(−2.75) + (−3) + (−2.75) + (−3)] = ¼×(−11.5) = −2.875

继续扫下去，值单调下降并收敛到第 3 章见过的终值表：

行2−14−18−20−20

观察收敛过程的信息流向：终点值 0 是"水源"，第 1 轮只浸润到终点隔壁，第 2 轮再扩一圈——值像水波一样从终点向外扩散，每轮传播一格。这就是自举的物理图像。

💡 关键一跃

策略评估什么也没"学"，它只是把 p 与 π 提供的信息反复搅拌直到自洽。信息全部来自模型——这就是为什么 DP 不需要与环境交互。

4.3策略改进：对 v_π 贪心为什么一定更好

算出 v_π 之后自然一问：能不能用它造一个更好的策略？做法：对每个状态，选让 q_π(s,a) 最大的动作（对 v_π 贪心化）。

这凭什么更好？策略改进定理（Policy Improvement Theorem）：若新策略 π′ 在每个状态都满足 q_π(s, π′(s)) ≥ v_π(s)，则 v_{π′}(s) ≥ v_π(s) 对所有状态成立；只要某处严格大于，就严格更好。直觉：既然"先走一步更优的 a、之后照旧"都不亏，那永远这么走只会更好——一步不亏 ⟹ 步步不亏。

网格世界手算：一次完整的策略改进

拿 4.2 节收敛的 v_π（随机策略），对每个状态算四个动作的 q_π(s,a) = −1 + v_π(邻)（γ=1，确定性转移），取 argmax：

(1,3)：左→(1,2)：−1+(−14)=−15；上撞墙停 (1,3)：−1+(−20)=−21；右→(1,4)：−1+(−22)=−23；下→(2,3)：−1+(−20)=−21。
→ argmax = 左（q=−15），改进后该状态只走左。

(2,2)：上→(1,2)：−15；左→(2,1)：−15；下→(3,2)：−21；右→(2,3)：−21。
→ 上、左并列最优（q=−15），任选其一（或各半概率）。

对所有状态做完，得到的新策略是"朝最近终点走"的最短路策略——它恰好已经是最优策略：(1,3) 的新值 = −2（距终点 2 步）。这个环境里，一次"评估 + 改进"就从随机策略直达最优；一般问题需要多轮交替，这就是下一节的策略迭代。

✅ 判定规则

若对 v_π 贪心化后策略没有变化（处处 q_π(s, π(s)) 已是最大），则 π 已满足 Bellman 最优方程——π 就是 π*。"改进不动了"是最优性的判据。

4.4策略迭代与值迭代：交替的艺术

把 4.2 与 4.3 拼起来：策略迭代（Policy Iteration）——评估当前策略到收敛，贪心改进，再评估新策略…… 有限 MDP 中策略数量有限且每轮严格改进，故有限步内必收敛到 π*。

可策略评估本身就要迭代好多轮，太贵。观察：改进只需要"足够好的 v_π"，不必等它完全收敛。把评估压缩到只扫一轮就改进，就得到值迭代（Value Iteration）——直接把 Bellman 最优方程改写成更新：

Vk+1(s) ← maxa ∑s′,r p(s′,r|s,a) [ r + γ Vk(s′) ]

注意：式子里没有显式的策略——评估与改进被 max 合并成一步。收敛后对 V* 贪心即得 π*。

手算例：2×2 网格上的值迭代，两轮收敛

2×2 网格：(1,1) 为唯一终点；每步 −1；γ=1；撞墙停原地；V₀ 全 0。非终点状态只有 (1,2)、(2,1)、(2,2)。

第 1 轮：每个状态四个动作的 [r + γV₀(邻)] 全是 −1 + 0 = −1，max = −1。V₁：三格全 −1。

第 2 轮：

  • (1,2)：左→终点 (1,1)：−1+0 = −1；下→(2,2)：−1+(−1) = −2；上/右撞墙停：−2。max = −1（走左）。
  • (2,1)：对称，max = −1（走上）。
  • (2,2)：上→(1,2)：−1+(−1) = −2；左→(2,1)：−2；右/下撞墙停：−2。max = −2。

第 3 轮：(1,2) 走下变为 −1+(−2)=−3，仍不如走左 −1；(2,2) 上/左仍是 −2——所有值不再变化，收敛。收敛趋势：V(2,2)：0 → −1 → −2 → −2（恰好等于到终点的最少步数取负）。

提取最优策略：对 V* 贪心——(2,2) 的上与左 q 同为 −2，并列最优，任选一个即最优策略。

💡 关键一跃

策略迭代与值迭代是同一谱系的两端：评估跑无穷轮再改进 = 策略迭代；评估只跑一轮就改进 = 值迭代；中间还有"跑 k 轮"的截断策略评估。理解成一个旋钮，而不是两个孤立算法。

4.5异步 DP 与广义策略迭代

前面的算法每轮都要扫描全部状态——状态多时一轮 sweep 就是天价。异步 DP（Asynchronous DP）松绑这个要求：按任意顺序、任意频率更新状态（甚至只更新当前轨迹经过的状态），只要每个状态被无限次更新，收敛性依然成立。这为"把计算花在重要状态上"开了门——第 8 章的优先级清扫（Prioritized Sweeping）与实时动态规划就是沿这条路走。

再抽象一层：几乎所有 RL 算法都可以看成两个过程的交替——评估（让值函数符合当前策略）与改进（让策略对值函数贪心）。这个总框架叫广义策略迭代（Generalized Policy Iteration, GPI）。两个过程不必各自跑完：它们可以交替、交错、甚至同时进行；只要双方都持续进行，联合过程就收敛到最优。

⚠️ 维数灾难

DP 的全部计算按"状态数 × 动作数"计价。状态空间随变量个数指数增长（Bellman 称之为 curse of dimensionality）——10 层楼电梯的状态就已经爆炸。这不是 DP 的实现问题，而是表格法的天花板；第 9 章函数逼近就是冲着它来的。

4.6错误直觉大扫除

⚠️ 误区一："DP 是 RL 的主流实用方法"

恰恰相反：DP 要求完整模型 p，而 RL 的主战场恰恰是模型未知。DP 的价值在于它提供了全部后续算法的思想模板——策略评估/改进的交替（GPI）、自举更新、贪心化——第 5–8 章做的就是把"精确期望"换成"采样估计"。说"DP 需要模型，所以不是无模型方法"，这不是贬低，是分类。

⚠️ 误区二："值迭代是独立于策略迭代的另一种算法"

值迭代 = 策略评估只扫一轮的策略迭代。把 max 写开，它每一步都隐含着"对当前值贪心"的改进动作。两者是同一谱系（评估轮数旋钮）的两端，不是两种思想。

⚠️ 误区三："自举是用猜测更新猜测，不靠谱"

自举的确引入了"用估计更新估计"的偏差，但 Bellman 算子的压缩性保证误差不累积、反而几何衰减。真正的问题不在自举本身，而在模型：DP 的自举用的是精确期望（有 p），无模型方法的自举还要再叠一层采样噪声——这是第 6、7 章要处理的。

💡 本章给下一章留的账

本章每个更新式里都有 ∑_{s′,r} p(s′,r|s,a)[·]——一个必须精确算出的期望。如果 p 未知，这个期望怎么办？第 5 章的回答：不算了，让智能体去环境里跑几局，用样本均值代替期望——蒙特卡洛方法登场。

点击翻面 →
定义若 q_π(s,π′(s)) ≥ v_π(s) 处处成立，则 v_{π′} ≥ v_π。
解决问题给"对值函数贪心化"一个严格的全局收益保证。
直觉一步不亏，步步不亏。
误区以为贪心是短视——对 v_π 贪心包含全部未来（在 π 之下）。
何时用策略迭代/值迭代收敛证明的核心；GPI 改进侧的合法性。
概念卡 3
策略迭代（Policy Iteration）
点击翻面 →
定义评估到收敛 → 贪心改进 → 再评估，交替直到改进不动。
解决问题模型已知时求最优策略；有限步必收敛。
直觉先给当前走法打分，再按分数改走法，改完重打。
误区以为每轮评估必须完美——截断评估同样有效（旋钮）。
何时用小状态空间精确求解；GPI 的具体实例。
概念卡 4
值迭代（Value Iteration）
点击翻面 →
定义V_{k+1}(s) ← max_a Σ p[r + γV_k(s′)]；评估改进合并为一步。
解决问题去掉策略迭代的内层评估循环，直接逼近 v*。
直觉每次更新都假装"下一步已经走最优"。
误区当成与策略迭代无关的算法——它是评估截断到一轮的特例。
何时用第 7 章 Q-learning 的模型版原型；规划算法的基础。
概念卡 5
异步 DP（Asynchronous DP）
点击翻面 →
定义按任意顺序/频率更新状态，只要每个状态被无限次更新。
解决问题全状态扫描太贵；把计算集中到重要/新近的状态上。
直觉不全班齐读，谁没跟上给谁补课。
误区以为异步是近似——满足条件时收敛性一样有保证。
何时用第 8 章优先级清扫、实时 DP；大规模状态空间。
概念卡 6
广义策略迭代（GPI）
点击翻面 →
定义评估（值向策略靠拢）与改进（策略向值贪心）两过程的总框架。
解决问题统一理解几乎所有 RL 算法的收敛结构。
直觉两人互相追赶调整，最后一起停在山顶。
误区以为两过程必须交替跑完——可持续交错、部分推进。
何时用第 5-13 章所有方法（MC/TD/actor-critic）的分析框架。

📝分层习题

L1 概念辨析以下说法哪些正确？① DP 算法不需要与环境交互；② 值迭代中不存在策略；③ 策略迭代每轮都必须把策略评估跑到完全收敛；④ 自举是指用估计值更新估计值。
提示

对照：DP 的信息来源、值迭代中隐含的改进、截断策略评估、bootstrapping 定义。

完整解答
①对：期望用已知的 p 精确算出。②错：没有显式维护策略，但 max 操作隐含着每轮的贪心改进。③错：截断评估（甚至一轮）同样收敛，值迭代就是极端情形。④对：这正是自举的定义，DP 全程自举。
L1 概念辨析"策略改进定理只保证新策略在改进的那些状态上更好，其余状态可能变差。"对吗？
提示

定理的结论是对所有状态 v_{π′}(s) ≥ v_π(s)。想想证明里"一步不亏⟹步步不亏"的展开。

完整解答
不对。定理结论是对所有状态不变差：v_{π′}(s) ≥ v_π(s) ∀s。原因：把 v_π(s) ≤ q_π(s,π′(s)) 反复展开，每一步替换都不亏，整条轨迹的期望回报只会不降——不存在"拆东墙补西墙"。
L2 手算推导策略评估第 2 轮：已知 V₁ 中所有非终点状态为 −1、终点为 0（均匀随机策略，γ=1，撞墙停原地）。手算 V₂(2,1)。(2,1) 的邻：上→终点 (1,1)，下→(3,1)，左撞墙停 (2,1)，右→(2,2)。
提示

套更新式：¼ Σ[r + V₁(邻)]，注意左动作撞墙停在原地，邻就是 (2,1) 自己。

完整解答
上：−1 + 0 = −1；下：−1 + (−1) = −2；左（停 (2,1)）：−1 + (−1) = −2；右：−1 + (−1) = −2。
V₂(2,1) = ¼ × (−1 −2 −2 −2) = ¼ × (−7) = −1.75。
与 (1,2) 同值——它们都一格贴终点，位置对称。
L2 手算推导值迭代手算：2×2 网格（终点 (1,1)，每步 −1，γ=1，撞墙停原地），V₁ 三格全 −1。求第 2 轮 V₂(2,2)，并写出收敛后 (2,2) 的贪心策略。
提示

列出 (2,2) 四个动作的 [r + V₁(邻)]：上→(1,2)、左→(2,1)、右撞墙、下撞墙。取 max。

完整解答
上：−1 + V₁(1,2) = −1 + (−1) = −2；左：−1 + V₁(2,1) = −2；右（停）：−1 + V₁(2,2) = −2；下（停）：−2。
V₂(2,2) = max = −2。第 3 轮四个动作仍为 −2（邻居已收敛到 −1），值不再变 → 收敛。
贪心策略：上或左（q 同为 −2，并列最优，走向终点 (1,1)）。
L3 建模应用某棋类游戏的状态转移规则完全已知（规则即模型），状态数约 10⁵。团队争论用"策略迭代"还是"值迭代"。请给出你的选择与理由，并说明若状态数涨到 10¹⁰ 时 DP 会撞上什么墙、应转向书中的哪类方法。
提示

比较两者每轮迭代成本与收敛轮数；10¹⁰ 时算一算"状态数×动作数"意味着什么。

完整解答
10⁵ 状态：两者都可行。倾向值迭代：策略迭代每轮内嵌完整评估（多轮 sweep），总成本 = 外层轮数 × 评估成本；值迭代每轮只扫一遍且 max 合并了改进，实践中常更快出近似解，且可用异步/按轨迹更新进一步省算力。
10¹⁰ 状态：一轮 sweep 就要遍历全部状态，内存（值表）与时间双双爆炸——维数灾难。应转向：无模型采样方法（第 5-7 章，只访问实际经过的状态）+ 函数逼近（第 9 章，用参数化函数代替值表，泛化到未访问状态）。
