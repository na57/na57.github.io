三问

整门课只问三件事：能不能算、多难算、什么机器识别什么语言

板块核心问题典型结论（在本书何处）
可计算性（Computability）能不能算？能否被机械地解决停机问题不可判定（第5章）
复杂度（Complexity）多难算？多少时间、多少空间P 与 NP 之问（第7、8章）
自动机与语言（Automata & Languages）什么机器识别什么语言从有限自动机一路升级到图灵机
三件事共用同一套语言——字面意义的「语言」。下一页看为什么。
例子

判定问题可以原封不动翻译成语言成员问题

把整数写成二进制：11 写成 1011。定义集合：

$$\text{PRIMES} = \{\, w \mid w \text{ 是某个素数的二进制表示} \,\}$$
✅ 1011 ∈ PRIMES
1011 = 11，是素数——「11 是素数吗」与「1011 属于 PRIMES 吗」是同一个问题
❌ 1111 ∉ PRIMES
1111 = 15 = 3 × 5，不是素数——答案为否的实例同样在语言之外
判定问题（Decision Problem）⇔ 语言成员问题：答案为「是」的实例的编码，恰好组成一个集合。
接口

数、图、程序都能编码成串，语言是计算的通用接口

$$\text{CONNECTED} = \{\, \langle G\rangle \mid G \text{ 是连通图} \,\} \quad\text{——图编码为 01 串 } \langle G\rangle$$
💡 关键一跃：语言是计算的通用接口——任何问题编码为字符串后，「解决这个问题」就等价于「判定串是否属于某个集合」。从此，研究计算 = 研究「哪些语言能被哪类机器识别」。
⚠️ 此「语言」非彼语言：没有语法、语义或用途要求——某个字母表上字符串的任意一个集合都叫语言。这个冷僻的定义正是它力量的来源。
定义

三个定义装下全书所有对象：字母表、字符串、语言

🔤 字母表（Alphabet）
任意非空有限集 Σ，如 {0, 1}；字符串是符号的有限序列，长度 |w|；空串 ε，|ε| = 0
⭐ 克林闭包（Kleene Star）
Σ* = Σ 上所有有限长串的集合；含 ε，每个串有限长，但集合本身无限
$$\boldsymbol{\text{语言（Language）} = \Sigma^{*} \text{ 的任意子集}}$$
读法：随便挑一堆串——哪怕毫无规律——都是一个语言。「任意」二字是全定义的灵魂。
辨析

空串、空语言、只含空串的语言是三件不同的东西

写法它是什么类型大小 / 长度
$\varnothing$空语言，一个串都不含语言（集合）元素数 0
$\{\varepsilon\}$只含空串的语言语言（集合）元素数 1
$\varepsilon$空串本身字符串（不是集合）长度 0
💡 ε 是空信封，∅ 是空抽屉，{ε} 是只装了一个空信封的抽屉。ε ∈ {ε} 成立，ε ∈ ∅ 不成立。
运算

∅·A = ∅ 而 {ε}·A = A：边界情形立刻有后果

🕳️ ∅·A = ∅
空抽屉里拿不出串，一个配对都凑不成——连接结果为空
📨 {ε}·A = A
唯一的配对伙伴是 ε，拼上等于没拼——ε 是连接的单位元
$$\varnothing \cdot A = \varnothing \qquad \{\varepsilon\} \cdot A = A$$
记忆口诀：空集是连接的「零」，{ε} 是连接的「一」。归纳奠基、A⁰ = {ε} 全靠它。

演练

克林闭包按层筛：A* 里长度 ≤2 的串只有四个

$$A^{*} = A^0 \cup A^1 \cup A^2 \cup \cdots \quad\text{——}A\text{ 中串任意次拼接（含一块都不拼）}$$

① $A^0 = \{\varepsilon\}$：ε 长度 0，入选

② $A^1 = A = \{0, 01\}$：0 长度 1、01 长度 2，都入选

③ $A^2 = \{00, 001, 010, 0101\}$：仅 00 长度 2 合格；A³ 起长度 ≥ 3，全部出局

$$\boldsymbol{A^{*} \text{ 中长度} \le 2 \text{ 的串} = \{\varepsilon,\ 0,\ 01,\ 00\}}$$

有限自动机只有四样本事：两个状态就能记住「最后一个符号」

洞察

状态是机器对已读内容的全部记忆

💡 状态 = 机器对「已读内容」的全部记忆。状态有限 ⟹ 记忆量有硬上限，与输入长度无关。
✅ 能做到
记住「最后一个符号是什么」只需 2 个状态——与输入多长无关
🚫 做不到
「数一数 0 和 1 是否一样多」需要无界记忆——有限状态永远不够
第2章的一切能力与局限，都从这个观察长出来。
工具箱

本书每个定理都要证明：归纳法把无穷压缩成两步

1奠基：直接验证 P(0) 成立
2归纳假设：假定 P(k) 对某个 k ≥ 0 成立
3归纳步：在此假定下证明 P(k+1) 成立
4结论：由归纳法，P(n) 对所有 n ≥ 0 成立
先记住构造性证明（Proof by Construction）这个名字：第2章起「要证能识别，就造一台机器」。归纳的难点是对什么量归纳：串长、运行步数、或结构层数。
推导

|xy| = |x| + |y|：归纳假设用在关键的第四步

① 奠基（|y| = 0）：y = ε，$|x\varepsilon| = |x| = |x| + 0 = |x| + |y|$ ✓

② 归纳假设：设对所有 |y| = k 的串 y 与任意 x，$|xy| = |x| + |y|$

③ 归纳步：取 |y| = k+1，写成 y = wa（a 是末尾符号，|w| = k）：

$$|xy| = |x(wa)| = |(xw)a| = |xw| + 1 \;\xrightarrow{\text{归纳假设}}\; |x| + k + 1$$

代入 → 结合律 → 长度定义 → 对 xw 用归纳假设（|w| = k） → 即 |x| + (k+1) = |x| + |y| ✓

$$\boldsymbol{|xy| = |x| + |y|} \quad\text{对任意串 } x, y \text{ 成立} \;\;∎$$

推导

反证法三段式：假设敌人存在，跟它走到撞墙

① 假设结论不成立：设 $\sqrt{2} = a/b$ 为既约分数（a、b 最大公因数为 1）

② 推出矛盾：$a^2 = 2b^2 \Rightarrow a$ 偶，设 $a = 2c$；代回得 $b^2 = 2c^2 \Rightarrow b$ 偶

$$a,\ b \text{ 皆偶} \;\Rightarrow\; \text{有公因子 } 2 \;\Rightarrow\; \text{与「既约」矛盾} \;\Rightarrow\; \boldsymbol{\sqrt{2}} \textbf{ 是无理数} \;\;∎$$
「既约」是整枚炸弹的引信：没有它，「a、b 皆偶」就撞不到墙。埋假设时就要想好撞哪堵墙。

伏笔

鸽巢原理一句大白话，埋下第2章泵引理的伏笔

$$n+1 \text{ 只鸽子进 } n \text{ 个洞} \;\Rightarrow\; \text{必有一洞至少两只}$$
套到有限自动机：状态有限、输入可任意长 ⇒ 读足够长的输入，访问状态次数超过状态总数 ⇒ 必有状态被重复访问 ⇒ 行为开始循环。
这个「状态重复」正是第2章泵引理的核心机关——用来证明某类语言不能被有限自动机识别。这就是本章留给下一章的账。
避坑

本章最容易栽的三个跟头

❌ ε、∅、{ε} 差不多
✅ 类型全不同：ε 是串（长度 0），∅ 是 0 个元素的语言，{ε} 是 1 个元素的语言。∅·A = ∅ 而 {ε}·A = A——空信封、空抽屉、只装空信封的抽屉。
❌ 语言必须有规律、有意义才配叫语言
✅ 语言 = Σ* 的任意子集，随机挑 5 个串也是语言。允许「任意」，「不可识别」才有谈论对象（第5章主角正是这种语言）。
❌ 归纳法是循环论证
✅ 奠基独立验证 P(0)，归纳步只传递 P(k) ⟹ P(k+1)，从未预设目标位置。真正的错误是漏奠基和方向搞反。

1解决什么：把「计算」变成数学对象——判定问题 ⇔ 语言成员问题

$$\boldsymbol{\text{语言} = \Sigma^{*} \text{ 的任意子集}} \quad\text{——合上书也要能默写}$$
