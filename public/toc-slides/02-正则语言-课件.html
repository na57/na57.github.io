动机

圆圈箭头的直觉够聊天，不够证明定理

任务：识别「含子串 001 的二进制串」。人眼一眼看出，机器呢？

$$\text{机器全部的记忆} = \text{「我此刻在哪个状态」}$$
🤔 它该记住什么？
记住已经读过的整段串？记忆会无限膨胀，不再「有限」
🧐 最少几个状态？没有严格定义，「最少」连问都问不清楚
💡 出路：把「有限记忆的机器」压缩成一个五元组——定义先行，定理随后。
定义

DFA = 五个部件，δ 是全函数不许卡死

🗺️ Q：有限状态集——全部记忆的载体
🔤 Σ：有限字母表——输入符号的来源
🚩 q₀ ∈ Q：起始状态　｜　F ⊆ Q：接受状态集
⚙️ δ : Q × Σ → Q：转移函数（Transition Function）
「在状态 q 读到 a，下一步去 δ(q,a)」
δ 是全函数：每个状态读每个符号都有唯一出边，缺边必须补陷阱态（Trap State）兜底
$$\boldsymbol{M = (Q,\ \Sigma,\ \delta,\ q_0,\ F)} \qquad \text{接受 } w \iff \hat{\delta}(q_0, w) \in F$$
读法：一台机器 = 状态集、字母表、转移表、起点、终点——被某台 DFA 识别的语言就叫正则语言（Regular Language）。
例子

设计 001 自动机：先给每个状态写一句人话含义

状态要记住什么（人话含义）
q₀还没见到任何可用的 0（刚开始，或最近一个符号是 1）
q₁刚见到一个 0，期待下一个 0
q₂刚见到 00，期待 1——再读 1 就成功
* q₃已见过 001，任务完成——之后读什么都无所谓（接受态）
🔑 设计口诀：状态含义先行，转移表随后自动出现——本章一切构造题的第一招。
例子

含义一定，8 条转移边自动长出来

状态读 0读 1含义
→ q₀q₁q₀还没见可用的 0
q₁q₂q₀刚见一个 0
q₂q₂q₃刚见 00
* q₃q₃q₃已见 001（接受）
⚠️ 最易错的边：q₂ 读 0 自环——…000 的最后两位仍是 00，进度不倒退

状态图与转移表完全等价，可互相翻译

跑两条轨迹：0010 接受，010 拒绝

机器从不回看已读的串，唯一依据是当前状态——这就是「有限记忆」的全部含义。
定义

NFA = DFA ＋ 分身术 ＋ 免费跳槽

$$\boldsymbol{\delta : Q \times (\Sigma \cup \{\varepsilon\}) \to \mathcal{P}(Q)}$$
  • 读一个符号到达一个状态集合（零个、一个或多个）——分支可分裂，也可死亡
  • 允许 ε 转移（ε-transition）：不读任何符号就能换状态
  • 存在性语义：存在至少一条分支读完整个输入并停在接受态 ⇒ 接受
🕵️ 分身术侦探：分身随便死，有一个破案就算破案。不是概率，也不是并行加速——只是描述更紧凑。
例子

「以 ab 结尾」：p 原地打转猜，q 验证，r 接受

flowchart LR s(["start"]) --> p("p") p -- "a, b" --> p p -- "a" --> q("q") q -- "b" --> r(("r"))
状态集合视角：{p} →(a) {p,q} →(a) {p,q} →(b) {p,r}，r ∈ F ⇒ 接受
分支路径结局
1p →(a) p →(a) p →(b) p停在 p ⇒ 该分支拒绝
2p →(a) q →(a) ✗q 读 a 无出边，中途死亡
3p →(a) p →(a) q →(b) r停在 r ⇒ 接受
有一条活路就算接受——其余分支拒绝或死亡都不影响。
推导

子集构造四步：先并 δ，再取 ε 闭包

flowchart LR st(["start"]) --> s("s") s -- "ε" --> p("p") p -- "a, b" --> p p -- "a" --> q("q") q -- "b" --> r(("r"))

① 起态取闭包：s 沿 ε 边免费漂到 p

$$A = E(\{s\}) = \{s, p\}$$

② A 的转移：先并 δ 再取 ε 闭包

$$A \xrightarrow{a} \emptyset \cup \{p,q\} = \{p,q\} =: B \qquad A \xrightarrow{b} \{p\} =: C$$
$$\text{③}\ B \xrightarrow{a} \{p,q\} = B\ (\text{自环}) \quad B \xrightarrow{b} \{p,r\} =: D \qquad C \xrightarrow{a} B \quad C \xrightarrow{b} C\ (\text{自环})$$
$$\boldsymbol{D \xrightarrow{a} B \quad D \xrightarrow{b} C \qquad \text{含 } r \text{ 的集合才是接受态} \Rightarrow \text{只有 } D}$$

定义

正则表达式：三条基础 ＋ 三条组合，归纳构造

🧱 基础：∅（空语言）· ε（只含空串）· a（只含单符串 a）
🔧 组合：并 R₁∪R₂ · 连接 R₁∘R₂ · 星号 R*（克林闭包，含 ε）
优先级：星号 > 连接 > 并
01*∪0 = (0(1*))∪0，不是 (01)*
正则表达式描述的语言
0*10*恰好含一个 1 的串
(01 ∪ 10)*由 01 和 10 两种砖块拼成的串（含 ε）
Σ*1以 1 结尾的串
(0 ∪ 1)*= Σ*，全体二进制串
构造

Thompson 构造：自底向上，只用 ε 边缝合

步搭什么怎么搭
1–2片段 a、b新初态 --符号--> 新接受态
3ab（连接）用 ε 边把 b 缝在 a 后面
4ab ∪ a（并）新初态两条 ε 边分接两片；旧接受态 ε 接新接受态
5(ab ∪ a)*（星号）新初态 ε 直通新接受态（保空串）；接受态 ε 回头成环
flowchart LR st(["start"]) --> s0("s0") s0 -- "ε" --> u0("u0") s0 -- "ε" --> f0(("f0")) u0 -- "a" --> u1("u1") u0 -- "a" --> m("·") m -- "b" --> u1 u1 -- "ε" --> u0 u1 -- "ε" --> f0
(ab ∪ a)* 简化示意：u1→u0 回头 ε 边就是星号；s0→f0 直通边保证 ε 被接受（完整 12 节点版见讲义图 2.6）
枢纽

DFA = NFA = 正则表达式：同一类语言的三个译本

flowchart LR D["DFA"] <--> N["NFA"] N <--> R["正则表达式"] D <--> R
🔍 识别器视角（DFA / NFA）
给一台机器，串喂进去判 Yes / No
✍️ 生成 / 模式视角（正则表达式）
写一个表达式，声明串的构造方式
等价两方向：RE →(Thompson) NFA；NFA → RE 用 GNFA 逐状态消去，记思想即可。做实现用 DFA，做设计用 NFA，写模式用 RE。
反转

泵引理：有限状态走长路必绕圈，绕圈段可泵

p 个状态的 DFA 读长度 ≥ p 的串，经过 p+1 个状态 ⇒ 鸽巢：必有状态被踩两次 ⇒ 中段 y 是循环，多绕几圈或不绕，机器分不出来。

$$\text{若 } A \text{ 正则，则存在泵长 } p:\ s \in A,\ |s| \ge p \Rightarrow s = xyz,\ \ \text{(1) } \forall i \ge 0,\ xy^iz \in A \quad \text{(2) } |y| > 0 \quad \text{(3) } |xy| \le p$$
  • (1) 是「泵」本身：中段可任意重复或删除
  • (2) 保证泵的东西非空，否则引理毫无意义
  • (3) 把循环段锁死在串的前 p 个字符内——做题的关键
演练

0ⁿ1ⁿ 非正则：假设拿泵长 → 选魔法串 → 泵出矛盾

① 假设拿泵长：假设 B 正则 ⇒ 泵长 p；选魔法串（与 p 挂钩）

$$s = 0^p 1^p \in B,\quad |s| = 2p \ge p \Rightarrow \text{存在分解 } s = xyz$$

② 锁死 y：本来要分三种情况（y 纯 0 区 / 跨界 / 纯 1 区），但条件 (3) 一步锁死

$$|xy| \le p \Rightarrow xy \text{ 全落在前 } p \text{ 个字符（全是 0）} \Rightarrow y = 0^k,\ k \ge 1$$
$$\text{取 } i = 2:\ xy^2z = 0^{p+k}1^p \notin B\ \text{违反 (1)} \Rightarrow \boldsymbol{B \text{ 非正则}}\ \blacksquare$$
✍️

解读

博弈视角：对方选 p 和分解，我方选 s 和泵次，必须全胜

量谁选约束
泵长 p对方任选我方不能挑顺手的 p
分解 s = xyz对方任选只受 |y|>0、|xy|≤p 约束
魔法串 s我方选与 p 挂钩，让对方无处可逃
泵次 i我方选通常取 i=2 或 i=0
🎮 胜负规则：我方后手出招，必须对对方所有合法应手全胜——存在一种分解泵不出矛盾，证明就失败。
避坑

四个高频误区：方向用反，整题零分

❌ 「NFA 表达能力比 DFA 强」
✅ 子集构造保证二者语言类相同。NFA 省的是描述长度，代价是转 DFA 最坏膨胀 $2^n$ 倍
❌ 「泵引理能证明语言是正则的」——本章头号红线
✅ 单向蕴含：正则 ⇒ 可泵。只能反证非正则；满足泵条件的语言未必正则，方向用反整题零分
❌ 「正则语言都是有限语言」
✅ a* 是无限语言，一个状态自环就识别了。看的是记忆是否有界，不是语言大小
❌ 「DFA 的 δ 可以缺省，卡死就当拒绝」
✅ δ 是全函数；卡死拒读是 NFA 的特权，DFA 必须显式补陷阱态
