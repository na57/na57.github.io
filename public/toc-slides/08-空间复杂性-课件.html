8.1 定义

输入带只读、空间只计工作带——「log n 空间」才说得出

📖 输入带（input tape）
只读，存放输入 w，不占空间额度——「题目」免费看
✏️ 工作带（work tape）
可读可写，算法的「草稿纸」——空间只计这条带上被扫过的格子数
$$\boldsymbol{\mathrm{SPACE}(f(n))=\{L\mid L\ \text{能被确定 TM 在}\ O(f(n))\ \text{工作格内判定}\}}；\ \mathrm{NSPACE}\ \text{为非确定版}$$
若输入也计费，任何算法空间 ≥ n，log n 类（L、NL）无从定义——只读输入带把「题目」与「草稿纸」分开。但「看到哪」要靠工作带上的指针记住（$O(\log n)$ 位），8.4 节反复用。
8.1 手算

枚举 $2^n$ 个赋值 ≠ 要 $2^n$ 格：SAT 只需线性空间

① 算法：按字典序枚举全部 $2^n$ 个赋值，逐子句代入求值；碰到满足的立刻接受，全部试完则拒绝。

工作带内容占用格子作用
当前赋值 $(x_1,\dots,x_n)$$n$ 格兼作 $n$ 位二进制计数器：每次 +1 得下一个赋值
子句扫描指针$O(\log m)\subseteq O(n)$记住正在检查第几个子句（$m$ = 子句数 ≤ 输入长）
求值暂存$O(1)$代入当前字面量、算当前子句真值，用完即弃
合计$O(n)$时间 $2^n\cdot\mathrm{poly}(n)$，空间线性

② 关键动作：检查完一个赋值，同一批格子直接覆写给下一个用——$2^n$ 次求值从头到尾只占 $n+O(\log n)$ 格。

$$\boldsymbol{\mathrm{SAT}\in\mathrm{SPACE}(n)}\qquad\text{——对照第 7 章：时间上只会 } 2^n \text{ 枚举}$$

按空格 / → 逐步展开推导

直觉

空间像白板可复用；格局只有 $2^{O(f)}$ 个——后两节的发动机

🧽 空间像白板
擦了能再写——一枚格子可以服务任意多次计算；枚举指数候选逐个生成、逐个丢弃
🎫 时间像车票
用一张少一张——走过的步数回不来；枚举指数候选是真金白银
$$\boldsymbol{|\mathrm{Conf}|=|Q|\cdot n\cdot f(n)\cdot |\Gamma|^{f(n)}=2^{O(f(n))}\quad(f(n)\ge \log n)}$$
格局（configuration）= 状态 + 输入头位置 + 工作头位置 + 工作带内容。多项式空间 ⟹ 指数多个格局；对数空间 ⟹ 只有多项式个——Savitch 与 L/NL 共同的发动机。
8.2 定理

$\mathrm{NSPACE}(f)\subseteq\mathrm{SPACE}(f^2)$——非确定在空间上只卖平方价

$$\textbf{Savitch 定理：}\quad \boldsymbol{f(n)\ge\log n\ \Longrightarrow\ \mathrm{NSPACE}(f(n))\subseteq\mathrm{SPACE}(f(n)^2)}$$
⏳ 对照第 7 章（时间）
NP 能否免费确定化成 P？无人知晓——最好的确定性模拟要付指数代价
🗺️ 化归为格局可达性
格局图：顶点 = 格局、边 = 一步转移；N 接受 w ⟺ $c_{\text{start}}$ 可达 $c_{\text{accept}}$

格局总数 $t_0=2^{O(f)}$；若可达，必有 ≤ $t_0$ 步的路径（更长必有重复格局，绕圈段可删）⟹ 问题化归为：用尽量少的空间，判定「$c_1$ 到 $c_2$ 是否存在至多 t 步的路径」。

8.2 手算 · 互动

reach 对半砍：任意时刻空间 = 深度 × 每层 = $O(f^2)$

① 基例 $t=1$：检查 $c_1=c_2$ 或模拟一步直接转移——$O(f)$ 空间。

② 递归 $t>1$：枚举中点 $c_m$（复用同一 $O(f)$ 格区），先后递归 $\mathrm{reach}(c_1,c_m,\lceil t/2\rceil)$ 与 $\mathrm{reach}(c_m,c_2,\lceil t/2\rceil)$，两段皆真则真——兄弟调用复用同一批格子。

③ 每层与深度：每层栈帧存 $c_m$ + 枚举进度，$O(f)$ 格；每层 t 减半，深度 $=O(\log t)=O(f)$（因 $t=2^{O(f)}$）。

图 8.1：两次递归先后进行——空间取 max 不求和，平方而非指数的来源
✍️
暂停推导

拿一张纸，自己算这笔空间账：每层栈帧存什么、递归多深、合计多少——提示：深度 = log t，而 t = 2 的 O(f) 次方

$$\boldsymbol{\text{合计} = \text{深度}\times\text{每层} = O(f)\times O(f) = O(f^2)}\ \blacksquare$$

8.2 推论

空间省下了，时间被打回原形——但两条推论立刻能用

$$T(t)\approx 2^{O(f)}\cdot 2\cdot T(t/2)\ \Longrightarrow\ T(t_0)=2^{O(f^2)}\ \text{——指数时间，Savitch 只保空间}$$
推论推导链对照时间维度
$NL\subseteq\mathrm{SPACE}(\log^2 n)$取 $f=\log n$：$\mathrm{NSPACE}(\log n)\subseteq\mathrm{SPACE}((\log n)^2)$「NP ⊆ ?」只有指数上界，是否多项式未知
PSPACE = NPSPACE取 $f$ 为任意多项式 $p$：$\mathrm{NSPACE}(p)\subseteq\mathrm{SPACE}(p^2)$，$p^2$ 仍多项式P ?= NP 是世纪悬案；空间非确定几乎免费
💡 空间可以「轮流坐庄」（兄弟调用复用同一批格子），时间只能「排队买单」（两次调用先后真实发生，耗时加和而非取 max）——本章与第 7 章全部分歧的根。
8.3 定义

PSPACE 卡位四环链：P ⊆ NP ⊆ PSPACE ⊆ EXPTIME

$$\boldsymbol{\mathrm{PSPACE}=\bigcup_{k\ge 1}\mathrm{SPACE}(n^k)}\qquad\text{（由 Savitch：PSPACE = NPSPACE，不必区分确定/非确定）}$$
包含关系一句话论证（不许跳步）
$P\subseteq NP$第 7 章：判定算法本身就是无视证书的验证者
$P\subseteq \mathrm{PSPACE}$多项式时间内工作头最多走多项式格——时间花在哪，空间用到哪
$NP\subseteq \mathrm{PSPACE}$SAT ∈ SPACE(n)（例 1）+ 任意 $A\in NP$ 有 $A\le_p \mathrm{SAT}$，归约只耗多项式空间
$\mathrm{PSPACE}\subseteq \mathrm{EXPTIME}$$n^k$ 空间机器只有 $2^{O(n^k)}$ 个格局，跑超时必循环即拒绝
第三环的杠杆结构：用一个完全问题 + 归约封闭性，把整个类抬进去。哪几环严格（P ≠ PSPACE？PSPACE ≠ EXPTIME？）至今未证。
8.3 定义

TQBF：∀ 与 ∃ 交替，就是一盘棋的必胜判定

$$\text{TQBF：判定全量化公式是否为真，例：}\ \forall x\,\exists y\;[(x\lor y)\land(\neg x\lor\neg y)]$$
🚶 ∃ 读「存在一步」
我方走一步：选一个赋值——只需一支走通
🛡️ ∀ 读「对任意应手」
对方应一步：所有走法都要扛住——两支全真才算
$$\boldsymbol{B\ \text{是 PSPACE 完全} \iff \text{① } B\in\mathrm{PSPACE};\ \ \text{② } \forall A\in\mathrm{PSPACE},\ A\le_p B}$$
SAT 问「存在一步好棋吗」，TQBF 问「这盘棋 ∃ 方有必胜策略吗」——博弈的天花板比找解的天花板（NP 完全）整整高一层。
8.3 手算

递归求值只存一条路径：深度 ≤ n、每层 $O(\log n)$

① φ 无量词：直接代入求真值，$O(1)$ 工作格。

② $\varphi=\exists x\,\psi$：先后递归 $\psi[x{=}T]$ 与 $\psi[x{=}F]$，一支真即真——第二支复用第一支的格子。

③ $\varphi=\forall x\,\psi$：同样两支递归，都真才真。

$$\text{深度}\le n,\ \text{每层}\ O(\log n) \Longrightarrow\ \text{总空间}\ O(n\log n)\subset\mathrm{poly}$$

图 8.2：∀ 节点两支全真才真；任何时刻只存「根到当前叶」一条路径——空间省、时间费
8.3 手算

同一个 ψ，∃x∀y 为假、∀x∃y 为真——量词顺序就是先后手

$\psi(x,y)=(x\lor y)\land(\neg x\lor\neg y)$ 的语义：两子句分别排除「同假」「同真」⟹ $\psi$ 为真 ⟺ $x$、$y$ 恰一真一假（异或）。

公式两支求值结论
$\forall x\exists y\,\psi$$x{=}T$：$\psi=\neg y$，∃y 取 $y{=}F$ 真；$x{=}F$：$\psi=y$，∃y 取 $y{=}T$ 真∀ 两支全真 → 真
$\exists x\forall y\,\psi$$x{=}T$：∀y 在 $y{=}T$ 处失败（$\neg T=F$）；$x{=}F$：∀y 在 $y{=}F$ 处失败∃ 两支皆假 → 假
直觉：∃ 在前 = 先手承诺，x 一出手就被对方握着 y 的反手；∀ 在前 = 后手优势，y 看 x 出牌再应——量词换序，答案翻转。
8.3 定理

不铺 tableau 改猜中点——TQBF 是 PSPACE 难

😱 困难
M 可跑 $2^{O(n^k)}$ 步；照搬 Cook–Levin 铺 tableau，行数指数——公式超长，归约失败
💡 出路（与 Savitch 同构）
∃ 猜中点、∀ 并查两段半程；两子目标共享同一段后续公式，长度不翻倍
$$\exists c_m\ \forall (c,d)\in\{(c_1,c_m),(c_m,c_2)\}:\quad c\ \text{在}\ \le\lceil t/2\rceil\ \text{步内可达}\ d$$

递归 $\log 2^{O(n^k)}=O(n^k)$ 层、每层添多项式长；基例 $t=1$ 用 Cook–Levin 局部窗口公式 ⟹ 总长度多项式。$\varphi_{M,w}$ 为真 ⟺ $c_{\text{start}}$ 可达 $c_{\text{accept}}$ ⟺ $w\in A$。

8.4 定义

log n 恰够几张便签：L 与 NL 是流式计算的化身

$$\boldsymbol{L=\mathrm{SPACE}(\log n),\qquad NL=\mathrm{NSPACE}(\log n)}$$
🧮 为什么 log n 是「有意义的下限」
记住一个输入位置编号就要 $\log n$ 位——$\log n$ 位恰够 $O(1)$ 个输入指针 + 几个计数器；再少连位置都记不住
📄 流式计算的数学化身
输入随便翻、反复读、不能改；手边只有几张便签纸——大数据流式处理的理论底盘
Savitch 要求 $f\ge\log n$ 正是为这个尺度量身定做。几张便签能干什么？出人意料地多：PATH、图连通、2SAT 全在 NL 里。
8.4 手算

边走边猜：PATH ∈ NL，且是 NL 完全

① 算法：从 s 出发重复 ≤ n 次，非确定猜当前顶点一条出边走到邻居；走到 t 接受，步数用尽拒绝。

② 工作带：当前顶点编号 + 步数计数器，各 $O(\log n)$ 位——合计 $O(\log n)$ ✓（对照标记法 $\Omega(n)$：把「记住历史」换成「猜对未来」）

③ NL 完全两关键：格局仅 $n^{O(1)}$ 个（对数空间机器的命门）；对数空间归约 $\le_L$：双重循环枚举格局对、逐条边输出，自身只用 $O(\log n)$。

8.5 避坑

空间不是时间——三个最顽固的误解

❌ 「空间和时间一样稀缺、一样贵」
✅ 反例①：SAT 指数时间却只要 $n$ 格；反例②：非确定消除，时间维度是悬案，空间维度 Savitch 只收平方税（PSPACE = NPSPACE）。根源：空间可复用，时间不可复用。
❌ 「PSPACE 完全 = 无解 / 不可判定」
✅ TQBF 可判定、多项式空间可解、有已知指数时间算法；「完全」是 PSPACE 难度天花板，与「不可判定」隔着整个第 4–6 章——「比 NP 完全更难」只是分级相对。
❌ 「NL 显然等于 P，L 显然等于 NL」
✅ NL ⊆ P 不反推 PATH ∈ L——确定的、只用几张便签的可达性算法几十年无人找到（最好仅 Savitch 的 $\log^2 n$）。空间世界每一个相等都是定理，不是显然。
