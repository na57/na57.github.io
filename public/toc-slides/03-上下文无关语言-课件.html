动机

死穴不是「状态少」，是「有限」本身

第2章已证硬事实：$\{0^n1^n \mid n \ge 0\}$ 不是正则语言——但它的结构只是括号配对。

$$\text{判断 } 0\text{ 与 } 1\text{ 个数相等} \;\Rightarrow\; \text{记住一个}\textbf{任意大}\text{的数} \;\Rightarrow\; \text{有限记忆必输}$$
😇 「状态不够多？」
给我 10 亿状态的 DFA，我就取 $n=$ 10 亿零 1——照样输。与大小无关。
🙂 「结构很复杂？」
恰恰相反：左一堆 0、右同样多个 1，嵌套配对，程序员每天都在用。
💡 本章方案：记忆必须随输入变长而增长；最克制的增长方式 = 栈（后进先出）。
定义

上下文无关文法（CFG）= 四元组 $(V, \Sigma, R, S)$

分量名称含义
$V$变元（Variable）的有限集等待被展开的「占位符」，如 $S$、$A$、$E$
$\Sigma$终结符（Terminal）的有限集最终串里真正出现的字符，与 $V$ 不相交
$R$规则（Rule / Production）的有限集每条形如 $A \to w$：左部是单个变元，右部任意串
$S$起始变元（Start Variable）一切推导的起点，$S \in V$
$$L(G) = \{\, w \in \Sigma^* \mid S \Rightarrow^* w \,\}\quad\text{——所有能从 } S \text{ 推出的纯终结符串}$$
「上下文无关」的准确含义：展开变元 $A$ 时不需要看它左右邻居——规则左部永远是孤零零一个 $A$。
例子

两条规则生成 $\{0^n1^n\}$：靠结构，不靠数

文法 $G$：$V=\{S\}$，$\Sigma=\{0,1\}$，规则只有两条——$S \to 0S1 \mid \varepsilon$。

$$S \Rightarrow 0\underline{S}1 \Rightarrow 00\underline{S}11 \Rightarrow 000\underline{S}111 \Rightarrow 000111$$

前 3 步各用一次 $S \to 0S1$，最后一步用 $S \to \varepsilon$ 消掉 $S$（下划线 = 本步被替换的变元）

读法：$S \to 0S1$ 不是「抹掉 S 换三个符号」，而是「一个 0、一个更小的同类结构、一个 1」。每用一次，0 和 1 的个数生而相等——文法用结构记账。递归定义 + 终止出口（$S\to\varepsilon$），就是 CFG 表达嵌套配对的全部秘密。
推导树

叶子从左到右读出串；判歧义看「树」不看「序列」

flowchart TB
  A["S"] --> B["0"]
  A --> C["S"]
  A --> D["1"]
  C --> E["0"]
  C --> F["S"]
  C --> G["1"]
  F --> H["ε"]

串 $0011$ 的推导树（Parse Tree）：叶子从左到右读 $0\cdot 0\cdot\varepsilon\cdot 1\cdot 1 = 0011$；$000111$ 只是在 $F$ 处多套一层。

⚠️ 推导序列 ≠ 推导树：同一棵树可对应多个序列（先展开哪个变元只是次序不同）。歧义的判据是「树是否唯一」——等价地，最左推导（Leftmost Derivation）是否唯一。
歧义

一个串，两棵推导树——这就是歧义（Ambiguity）

表达式文法 $E \to E+E \mid E\times E \mid (E) \mid a$，串 $a+a\times a$ 有两棵推导树：

  A["E"] --> B["E"]
  A --> M["×"]
  A --> C["E"]
  B --> D["E"]
  B --> P["+"]
  B --> E2["E"]
  D --> F["a"]
  E2 --> G["a"]
  C --> H["a"]
树（甲）：顶层是 ×，先算 +
根部用 $E\to E\times E$ → 解读 $(a+a)\times a$

  A["E"] --> B["E"]
  A --> P["+"]
  A --> C["E"]
  B --> D["a"]
  C --> E2["E"]
  C --> M["×"]
  C --> F["E"]

  F --> H["a"]
树（乙）：顶层是 +，先算 ×
根部用 $E\to E+E$ → 解读 $a+(a\times a)$
两棵树的叶子都是 $a+a\times a$，语义却不同——编译器靠树定语义，两棵树 = 两种意思。
消歧

歧义分两种：文法的病可治，语言的天性没治

✅ 文法的病（可治）
分层改写：$E \to E+T \mid T$，$T \to T\times F \mid F$，$F \to (E) \mid a$
强制 $\times$ 比 $+$ 先归约——每个串只剩一棵树。这就是「乘除优先于加减」。
🚫 语言的天性（没治）
固有二义（Inherently Ambiguous）语言：每个生成它的 CFG 都是歧义文法。
经典例子 $\{a^ib^jc^k \mid i=j \text{ 或 } j=k\}$——$i=j=k$ 的串注定两棵树。
💡 直觉：文法歧义可以换文法消除；固有二义是语言本身的属性，换任何文法都没用。
范式

乔姆斯基范式（CNF）：右部只许「两个变元」或「一个终结符」

$$\boldsymbol{A \to BC \qquad A \to a \qquad S \to \varepsilon}\quad\text{（} B,C \text{ 不得是起始变元；} \varepsilon \text{ 只许挂在 } S \text{ 上）}$$
🎯 为什么值得
规则形态统一 → 推导树必为二叉树，算法（CYK 成员判定）和证明才好做。
🛠️ 能做到吗
能。任意 CFG 都可转成 CNF，且语言不变——下一页五步转换，一步不跳。
读法：右部要么「两个变元」，要么「一个终结符」，空串只由起始变元直接产生——再没有别的花样。
推导

五步转换：每步消灭一种违规形态，语言始终不变

Sipser 原例 $G$：$S \to ASA \mid aB$，　$A \to B \mid S$，　$B \to b \mid \varepsilon$

① 加新起始变元：新增 $S_0 \to S$——起始变元不许出现在任何右部（旧 $S$ 出现在 $A\to S$ 右部）。

② 消 $\varepsilon$ 规则：先闭包算全可空变元 $=\{B, A\}$（$A\to B$ 连锁！）；删 $B\to\varepsilon$，补 $S \to SA \mid AS \mid A$、$S \to a$（$S\to S$ 这类自环不补）。

③ 消单一规则（Unit Rule）：$A\to B$、$A\to S$、$S_0\to S$ 三条——把被指向变元的右部直接搬过来，再删规则（绕行一步变直达）。

④ 拆长规则：新增 $A_1 \to SA$，所有 $ASA$ 换成 $AA_1$。⑤ 终结符立规：新增 $U \to a$，所有 $aB$ 换成 $UB$。

$$S_0 \to AA_1 \mid UB \mid a \mid SA \mid AS,\;\; A \to AA_1 \mid b \mid UB \mid a \mid SA \mid AS,\;\; B \to b,\;\; A_1 \to SA,\;\; U \to a$$

按空格 / → 逐步展开推导（$S$ 的规则与 $S_0$ 相同，从略）

定义

下推自动机（PDA）= 有限状态 + 一条栈

分量名称含义
$Q$有限状态集老本行，来自有限自动机
$\Sigma$输入字母表输入串的字符
$\Gamma$栈字母表栈里可写的记号，可与 $\Sigma$ 不同
$\delta$转移函数见下方公式——本章与 DFA 的核心差异
$q_0, F$初态 / 接受状态集出发点与双线圈
$$\delta : Q \times (\Sigma \cup \{\varepsilon\}) \times (\Gamma \cup \{\varepsilon\}) \to \mathcal{P}(Q \times (\Gamma \cup \{\varepsilon\}))$$
读法：每步「读一个输入符号（或不读）、弹栈顶一个符号（或不弹）、转新状态并推一个符号入栈（或不推）」，边标签写作「读, 弹 → 推」。值域是幂集 $\mathcal{P}(\cdot)$——PDA 天生非确定型（Nondeterministic）。
例子

读 0 记账，读 1 销账：刚好数清 $\{0^n1^n\}$

flowchart LR
  s(["start"]) --> q1(("q1"))
  q1 -- "ε, ε → $" --> q2(("q2"))
  q2 -- "0, ε → 0" --> q2
  q2 -- "1, 0 → ε" --> q3(("q3"))
  q3 -- "1, 0 → ε" --> q3
  q3 -- "ε, $ → ε" --> q4(("q4"))
  • $q_1$（初态）：不读输入，压栈底标记 $\$$ → $q_2$；$q_2$（记账）：读 0 压 0 循环，读 1 弹 0 → $q_3$
  • $q_3$（销账）：循环「$1,0\to\varepsilon$」，栈顶露出 $\$$ 就弹掉 → $q_4$（接受）
$\$$ = 账本最后一页：只有栈里恰好只剩它，才说明 0 全部配对成功。$q_2 \to q_3$ 单向——开始销账就不能再记新账。

拒绝

栈顶不符就卡死：001 与 011 的死法

❌ 001（账没销完）
栈到 $00\$$；读 1 销一笔剩 $0\$$，输入已尽。$q_3\to q_4$ 要求栈顶是 $\$$，栈顶却是 $0$ → 卡死在非接受态。
❌ 011（无账可销）
读到第二个 1 时栈顶已是 $\$$，而「$1,0\to\varepsilon$」要求弹 $0$ → 弹不出，卡死。
💡 栈 $=$ 只记「还没配对的开放项」的记事本：push 是记账，pop 是销账，$\$$ 是账本最后一页。后进先出恰好匹配嵌套结构「最后开的最先关」——没有 $\$$ 就分不清「账刚销平」与「栈本来空」，$010$ 这类乱序串会被误收。
等价

生成视角 = 识别视角：CFG 与 PDA 等价

$$\boldsymbol{L \text{ 是上下文无关语言} \iff \text{存在一台 PDA 识别 } L}$$

CFG → PDA 的构造思想：让栈实时模拟最左推导——

🎬 开局：压 $S\$$（$S$ 在上，$\$$ 垫底）
🔀 栈顶是变元 $A$：非确定地猜一条规则 $A\to w$，弹 $A$、把 $w$ 逆序压栈
✔️ 栈顶是终结符 $a$：必须读输入匹配，「$a,a\to\varepsilon$」弹掉——不匹配则此分支死亡
🏁 栈顶是 $\$$：弹掉进接受态；输入恰好读完则接受
⚠️ 「猜规则」就是 PDA 非确定性的来源：变元有多条规则时确定型机器没法猜——这是下一页红线的根源。
构造

栈是最左推导的实时镜像

文法 $S \to aTb \mid b$，$T \to Ta \mid \varepsilon$（生成 $\{a^nb\}$）；输入 $aab$（栈顶在左）：

最左推导PDA 动作栈内容已读输入
$S$（起点）压 $\$$、再压 $S$$S\$$—
$S \Rightarrow aTb$弹 $S$，逆序压 $aTb$$aTb\$$—
（前缀 $a$ 已成形）匹配：读 $a$，弹 $a$$Tb\$$$a$
$aTb \Rightarrow aTab \Rightarrow aab$弹 $T$ 逆序压 $Ta$；再弹 $T$（$T\to\varepsilon$）$ab\$$$a$
（终结符逐个核对）读 $a$ 弹 $a$、读 $b$ 弹 $b$$\$$$aab$
推导完成 $aab$弹 $\$$，进接受态（空）$aab$ — 接受
规律：任意时刻「已读输入 + 栈内容（顶到底，去掉 $\$$）」= 当前最左推导的句型。反向 PDA→CFG：为每对状态设变元 $A_{pq}$，生成「从 $p$ 空栈到 $q$ 空栈」的所有串——繁琐但机械。
边界

CFL 泵引理：切五段，同步泵两段

$$A \text{ 是 CFL} \Rightarrow \exists p,\ \forall s \in A,\ |s|\ge p:\ s = uvxyz,\ \ uv^ixy^iz \in A\ (i\ge 0),\ \ |vy|>0,\ \ |vxy|\le p$$
正则泵引理（第2章）CFL 泵引理（本章）
切几段3 段：$xyz$5 段：$uvxyz$
泵哪几段中间 1 段 $y$2 段 $v$、$y$ 同步泵
长度条件$|xy| \le p$$|vxy| \le p$
直觉来源DFA 状态图的循环路径推导树高路径上的重复变元
树足够高 ⟹ 根到某片叶子的路径上必有变元 $R$ 出现两次：上层 $R$ 的子树整个套进下层（$i=2$）或取下层换上层（$i=0$）——多出的左右两翼分居 $x$ 两侧，所以必须同步泵。
反证

$\{a^nb^nc^n\}$ 不是上下文无关语言

① 假设与选串：设 $D$ 是 CFL，得泵长 $p$；选 $s = a^pb^pc^p \in D$，$|s|=3p \ge p$ ⟹ 存在切分 $s=uvxyz$ 满足三条件。

② 按窗口 $vxy$ 的位置分情况（总开关：$|vxy|\le p$，三区各长 $p$ ⟹ 窗口至多跨两个相邻区，绝不同时触及 $a$ 区与 $c$ 区）：

  • 情况一：$vxy$ 全落在某一字母区内——泵 $uv^2xy^2z$：只增加该字母，另两个不动，三者不再相等，$\notin D$。
  • 情况二：$vxy$ 横跨两个相邻区——$v$ 或 $y$ 含两种字母则泵出乱序；各含一种则第三个字母保持 $p$ 个不变，仍不相等，$\notin D$。
$$\text{所有窗口位置均矛盾} \;\Rightarrow\; \text{假设不成立} \;\Rightarrow\; \boldsymbol{D = \{a^nb^nc^n\} \text{ 不是 CFL}} \;\blacksquare$$

按空格 / → 逐步展开三段式（泵 $i=0$ 抽掉一段同样有效，写证明任选最顺手的）

避坑

三条错误直觉，集中清算

❌ 「CFG 能生成所有语言」
✅ $\{a^nb^nc^n\}$ 就不是 CFL。递归规则表达得了嵌套配对，表达不了「三个独立计数同时相等」——语言的世界远大于 CFL。
❌ 「确定型 PDA ≡ 非确定型 PDA」（本章最大红线）
✅ 从 NFA≡DFA 平移过来的幻觉。子集构造对栈失效（各分支栈内容无法合并）；非确定型严格更强，确定型识别的 DCFL 是 CFL 的真子类（LR 文法在这一层）。
❌ 「有了栈就什么都能数」
✅ 栈只能后进先出，一次配对消费一层计数。两次独立计数要两条栈或可随机存取的带——那已等价于图灵机，是第4章的机器。
小结

三句话讲完第3章

1解决什么：给「数不了数」的机器加一条栈，识别能力扩展到哪里？新边界在哪？
2核心机制：CFG（规则递归生成）与 PDA（状态 + 栈识别）互相构造、严格等价；栈 = 恰好一层计数记忆
3承上启下：正则 ⊊ CFL ⊊ 图灵机可识别；「两次独立计数」的缺口正是第4章图灵机登场的第一动机
$$L \text{ 是 CFL} \iff \exists\, \text{PDA 识别 } L; \qquad s = uvxyz:\ uv^ixy^iz \in A,\ |vy|>0,\ |vxy|\le p \quad\text{——合上书也要能默写}$$
本 章 结 束
