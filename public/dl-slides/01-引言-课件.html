动机

规则写不尽也写不硬：知识库在「识别一只猫」上必然卡死

写一个程序识别照片里的猫。最直白的办法：把你知道的一切写进程序——猫有尖耳朵、猫有胡须、强光下瞳孔是竖的……这就是知识库（Knowledge Base）方法。

🐱 规则写不尽
耳朵被遮挡怎么办？卡通猫算不算猫？例外无穷无尽
📐 规则写不硬
「胡须」在像素里长什么样？根本无法用规则精确描述
⚠️ 1980 年代的 Cyc 项目试图人工录入常识，几十年下来依然脆弱——根源：知识在人脑里，而不在机器能直接用的形式里
卡点

机器能学规律，但「看哪里」还得人指——成败全压在特征工程上

转向机器学习（Machine Learning）：不写规则，给机器看大量「猫 / 非猫」的例子，让它自己找规律——逻辑回归、支持向量机都是这个思路。

⚠️ 隐蔽前提：你得先告诉机器「看哪里」。机器不认得像素，得先人工提取特征：耳朵轮廓的弧度、纹理的方向、色块的分布——这一步叫特征工程（Feature Engineering）
✅ 特征设计得好
简单模型也能用
❌ 特征设计不出来
模型就无能为力
💡 让机器认出猫的真正难点——「从像素到概念」——仍然由人扛着

定义

一个神经元 = 加权求和 ＋ 与阈值比较

1943 年 McCulloch 和 Pitts 给出最早的数学模型——McCulloch-Pitts 阈值单元（Threshold Unit）：

➕ 部件一：加权求和
把各输入按权重加起来：$s = w_1x_1 + w_2x_2$
⚖️ 部件二：与阈值比较
加权和与阈值 $\theta$ 比大小，决定输出 1 还是 0
$$\boldsymbol{f(x_1,x_2) = 1 \;\text{当}\; w_1x_1 + w_2x_2 \geq \theta,\quad \text{否则}\; f(x_1,x_2) = 0}$$
读法：几何上 $w_1x_1+w_2x_2=\theta$ 是一条直线——单元的工作就是用一条直线把平面切成两半，一半输出 0，一半输出 1
演练

四点代入全对：一个阈值单元就是一个 AND 门

取 $w_1 = 1$，$w_2 = 1$，$\theta = 1.5$；逐一代入四个输入，算 $s = x_1 + x_2$，再与 $1.5$ 比较：

① $(0,0)$：$s = 0+0 = 0$，$0 \lt 1.5$，输出 $0$；AND 真值 $0$ ✓

② $(0,1)$：$s = 0+1 = 1$，$1 \lt 1.5$，输出 $0$；真值 $0$ ✓　　③ $(1,0)$：$s = 1+0 = 1$，$1 \lt 1.5$，输出 $0$；真值 $0$ ✓

④ $(1,1)$：$s = 1+1 = 2$，$2 \geq 1.5$，输出 $1$；AND 真值 $1$ ✓ —— 四行全对

✍️
暂停推导

先自己动手：把四个输入点逐一代入 $s = x_1 + x_2$，写出每行的 s 值、与 1.5 的比较结果和输出，再对照 AND 真值表

挑战

XOR 的四条要求，写成四个不等式

XOR（异或）要求：$(0,0){\to}0$，$(0,1){\to}1$，$(1,0){\to}1$，$(1,1){\to}0$。设 $f = w_1x_1 + w_2x_2 + b$，规定 $f \gt 0$ 输出 1，$f \leq 0$ 输出 0：

要求代入 $f = w_1x_1 + w_2x_2 + b$不等式
$(0,0) \to 0$$b \leq 0$① $b \leq 0$
$(0,1) \to 1$$w_2 + b \gt 0$② $w_2 + b \gt 0$
$(1,0) \to 1$$w_1 + b \gt 0$③ $w_1 + b \gt 0$
$(1,1) \to 0$$w_1 + w_2 + b \leq 0$④ $w_1 + w_2 + b \leq 0$
💡 问题化为纯代数题：是否存在一组 $(w_1, w_2, b)$ 同时满足 ①–④？
推导

四个不等式两两相撞：XOR 线性不可分，无解

① 把 ② 与 ③ 相加

$$\text{②}+\text{③：}\quad w_1 + w_2 + 2b \gt 0$$

② 两边减去 $b$（由 ① $b \leq 0$ 知 $-b \geq 0$）

$$w_1 + w_2 + b \gt -b \geq 0 \;\Longrightarrow\; w_1 + w_2 + b \gt 0$$
$$\boldsymbol{w_1+w_2+b \gt 0 \;\text{与④}\; w_1+w_2+b \leq 0 \;\text{直接矛盾} \;\Longrightarrow\; \text{无解}}$$
不存在任何一组 $(w_1, w_2, b)$ 同时满足四条要求——这就是线性不可分（Linearly Inseparable）。1969 年 Minsky 与 Papert 把它写进《Perceptrons》，直接导致第一波神经网络研究大撤退

出路

单层不行就叠一层：三个单元就能拼出 XOR

flowchart TB X1["输入 x₁"] --> H1["单元①：算 AND"] X2["输入 x₂"] --> H1 X1 --> H2["单元②：算 NAND"] X2 --> H2 H1 --> O["单元③：线性组合"] H2 --> O O --> Y["输出 = XOR"]
🧩 思路
一个单元画一条直线不够，就把两个单元的输出再喂给第三个单元——先算 AND 和 NAND，再组合，XOR 就能表达

算法

ADALINE 的划时代之处：权重不用人调，从误差里自动更新

1960 年 ADALINE（自适应线性神经元）：权重不用人调，而是用规则从误差里自动更新——这就是 LMS 算法（Least Mean Squares，最小均方，又称 Widrow-Hoff 规则）：

$$\boldsymbol{w \leftarrow w + \alpha\,(t - \hat{y})\,x}$$
📥 已知
$t$ 目标输出；$\hat{y} = w \cdot x$ 当前预测；$\alpha$ 学习率
🧭 直觉
误差 $(t-\hat{y})$ 定方向：偏低顺 $x$ 加，偏高顺 $x$ 减；$\alpha$ 定步子
读法：新权重 = 旧权重 ＋ 学习率 × 误差 × 输入——机器学习最核心的循环就这么朴素
手算

一步 LMS：权重从 (0,0) 挪到 (0.1, 0.2)，预测从 0 到 0.5

设 $w = (0,0)$，输入 $x = (1,2)$，目标 $t = 1$，学习率 $\alpha = 0.1$：

① 算预测：$\hat{y} = w \cdot x = 0 \times 1 + 0 \times 2 = 0$

② 算误差：$t - \hat{y} = 1 - 0 = 1$

③ 算修正量：$\alpha(t-\hat{y})x = 0.1 \times 1 \times (1,2) = (0.1,\ 0.2)$

④ 更新：$w \leftarrow (0,0) + (0.1,0.2) = (0.1,\ 0.2)$

⑤ 验证：$\hat{y}_{new} = 0.1 \times 1 + 0.2 \times 2 = 0.5$（比 0 更接近目标 1 ✓）

朝目标靠近了一步但没一步到位——$\alpha$ 控制步子大小，这正是「迭代逼近」的雏形

史话

反向传播解决了「怎么学」，却输给了数据少、算力弱

🕸️ 联结主义（Connectionism）的核心主张：智能藏在大量简单单元的连接方式里
  • 1986：Rumelhart、Hinton、Williams 推广反向传播（Backpropagation）——把输出误差沿网络逐层回传，按比例分摊给每层权重，「多层网络怎么学」有了通用算法
  • 1990s 初：LeCun 的卷积网络（LeNet）识别手写邮编，被银行实际部署
⚠️ 遇冷两个现实原因：① 数据太少、算力太弱，深层网络训不动（梯度在层层回传中衰减）；② 核方法（SVM）与集成方法理论更漂亮、小数据更好用，吸走了学术界的注意力——1995 年前后神经网络再成冷门
史话

2006 点火、2012 引爆：数据 × 算力追上了思想

🔥 2006 深度信念网（Deep Belief Network）
Hinton 等：逐层无监督预训练先把各层权重初始化到「不错的位置」，再整体微调——深层网络第一次被可靠地训练起来
💥 2012 AlexNet 转折
GPU 训练深度卷积网络，ImageNet 竞赛错误率从上年冠军的 26% 砍到 16%——震惊计算机视觉界，深度学习成为主流范式
$$\text{AlexNet：ImageNet 错误率 } 26\% \;\longrightarrow\; 16\%\quad(2012)$$
💡 三次浪潮说明同一件事：算法思想早就有了，每次复兴都是「数据 × 算力」追上了思想——反向传播 1986 年就有，它等了 26 年才等到 GPU 和 ImageNet
三要素

三条曲线同时跨过门槛：数据、算力、模型规模

维度1980s–90s（联结主义时代）2012（AlexNet 转折）2020s（今天）
典型数据量$10^2$–$10^3$ 样本ImageNet 约 $10^6$ 张图像网络级语料 $10^{12}$ 词元
单机算力CPU 约 $10^8$–$10^9$ FLOPSGPU 约 $10^{12}$ FLOPS集群训练总量超 $10^{20}$ FLOPS
模型规模$10^3$–$10^5$（LeNet 约 $6\times 10^4$）AlexNet 约 $6\times 10^7$大模型 $10^{11}$ 量级
💡 爆发三要素同时到位：数据（$10^3 \to 10^6$ 以上）、算力（GPU 跨过 $10^{12}$ FLOPS）、算法（逐层预训练、ReLU、Dropout 让深网训得动、训得稳）
规律

规模带来质变：能力不是平缓爬坡，而是在阈值处突然解锁

📈 实证规律：规模带来质变
数据量、参数量、训练算力同步放大，深度模型的能力不是平缓提升，而是在某些阈值处突然解锁新行为——例如大模型规模跨过某量级后突然会做多步推理
🏗️ 为什么强调「深」
层数加深后，同样的参数预算能表达的函数族指数级扩大——浅而宽的网络要用天文数字的单元才能逼近深网轻松表达的层级函数
✅ 判定规则：判断一个「深度学习时代」的说法是否靠谱，就看它是否同时回应数据、算力、算法三要素——只说「算法突破」而回避数据与算力条件的叙事，都是不完整的历史
避坑

引言最容易踩的三个坑

❌ 深度学习可以替代所有特征工程
✅ 它替代的是手工设计底层特征；数据怎么采、标签怎么标、任务怎么定义、输出怎么表示，这些「高层设计」仍决定成败，而且仍是人的活
❌ XOR 证明的是神经网络不行
✅ 恰好相反——它证明的是单个线性单元不行；加上隐藏层和非线性激活，三个单元就能实现 XOR。把「线性模型的局限」误读成「神经网络的局限」，是读这段历史最常犯的错
❌ 深度学习是 2006 年之后才发明的全新技术
✅ 感知机、反向传播、卷积网络分别来自 1958、1986、1989 年；2006 年之后的贡献是让深网训得动的工程与算法突破，以及数据算力条件的成熟
小结

三句话讲完第1章
