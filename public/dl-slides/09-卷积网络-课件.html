主线

三条结构假设把参数量压下去，把表达力留下来

1问题：全连接对图像一无所知 → 参数量爆炸，第一层就上亿
2出路：局部连接 + 参数共享 → 小核滑窗复用，参数压下两个数量级
3副产品：参数共享白送等变表示 → 池化再把等变折成近似不变
4对账：感受野递推 → 两层 3×3 顶一个 5×5，小核堆叠够用且更省
这条链就是本章的目录：9.1 算账 → 9.2 卷积运算 → 9.3 等变 → 9.4 池化 → 9.5 感受野 → 9.6 装机
动机

全连接搬到图像上，第一层就要上亿参数

$\text{全连接：}\ 3072 \times 256 + 256 = 786{,}688$
$\text{卷积：}\ 5 \times 5 \times 3 \times 64 + 64 = \boldsymbol{4{,}864}$
接法输入规模输出规模参数量
全连接3072（32×32×3）256 单元786,688
卷积 5×53072（32×32×3）64 通道4,864
全连接150,528（224×224×3）1000 单元≈1.5 亿
💡 两种接法都抽出 64 组特征：786,688 ÷ 4,864 ≈ 162 倍——差距不是优化出来的，是假设换的。
定义

局部连接与参数共享：两条假设换掉 162 倍参数

🔍 局部连接（Local Connectivity）
像素的意义几乎只由附近像素决定 → 神经元只看一个小窗口，稠密大矩阵换成小核
🔁 参数共享（Parameter Sharing）
「边缘」在左上角和右下角是同一种特征 → 同一组核权重在所有位置复用
卷积 = 把图像先验折现成参数折扣：局部连接指数级瘦身，参数共享再除以一个位置数。
别误以为「参数少 = 表达力差」：全连接那 786,688 个参数里，大多数在学数据中根本不存在的自由度；卷积删掉的是冗余。
定义

深度学习的「卷积」是不翻转核的互相关

📐 数学卷积（Convolution）
核先翻转 180° 再滑动相乘：$I(i-m,\,j-n)\cdot K(m,n)$
🧮 互相关（Cross-correlation）
核不翻转，对齐窗口逐元素相乘求和：$I(i+m,\,j+n)\cdot K(m,n)$
$$\boldsymbol{S(i,\,j) = \sum_{m}\sum_{n} I(i+m,\; j+n)\, K(m,\,n)}$$
读法：输出在第 i 行第 j 列的值 = 窗口与核对应位置相乘再求和。核是学出来的，翻转只是换个参数化方式，学习自己吸收。

直觉

滑窗三步循环：取窗口、对齐相乘、求和落图

卷积层 = 一个可学习的小模板在输入上滑动，每到一个位置问一句「这里像不像我」；特征图（Feature Map）就是一张「相像程度地图」。
手算

输出尺寸一个公式搞定：先向下取整，再加 1

$$\boldsymbol{\text{输出边长} = \left\lfloor \frac{n + 2p - k}{s} \right\rfloor + 1}\ \ \text{（n 输入 · k 核 · p 填充 Padding · s 步幅 Stride）}$$
nkps代入输出边长
32501⌊(32+0−5)/1⌋+1 = 27+128（valid：无填充缩小）
32521⌊(32+4−5)/1⌋+1 = 31+132（same：p=(k−1)/2 保尺寸）
32502⌊(32−5)/2⌋+1 = ⌊13.5⌋+1 = 13+114（步幅 2，约减半）
两个高频错误：忘了 +1；把 13.5 四舍五入成 14 再加 1 得 15。先取整，再加 1。
定义

参数共享白送等变性：输入平移，输出跟着平移

🔄 等变（Equivariance）
先变换再算 = 先算再变换：猫往右挪一格，特征图里的「猫脸响应」也往右挪一格
🎯 为什么必然成立
核在任何位置都是同一个 → 同一模式在不同位置必然触发同一响应；位置信息留在特征图坐标里
$$\boldsymbol{f(g(x)) = g(f(x))}\ \ \text{（g 是平移：先平移后卷积 = 先卷积后平移）}$$
参数共享把「检测什么」与「在哪里检测」解耦——不必为「猫在左边」和「猫在右边」各学一套特征。
演练

输入右移一格，输出也右移一格——动手验证

输入 $x=[1,2,3,0,0]$，核 $w=[1,0,-1]$（valid，步幅 1，输出长度 5−3+1=3）

① 原输入：s₁ = 1×1+2×0+3×(−1) = −2；s₂ = 2×1+3×0+0×(−1) = 2；s₃ = 3×1+0+0 = 3　→　$s=[-2,\,2,\,3]$

✍️
暂停推导

把输入整体右移一位得 x′=[0,1,2,3,0]，亲手算出三个输出值，再和原输出逐格对照。

② 移位后：s′₁ = 0×1+1×0+2×(−1) = −2；s′₂ = 1×1+2×0+3×(−1) = −2；s′₃ = 2×1+3×0+0×(−1) = 2　→　$s′=[-2,\,-2,\,2]$

③ 对照：s′ 的后两格 [−2, 2] = s 的前两格——输出整体跟着输入右移一格（左端新格对应新进入视野的窗口）。

定义

池化把等变折成近似不变，而且零参数

🏆 最大池化（Max Pooling）
每个窗口取最大值：只汇报「有没有」，不汇报「在哪里」——最常用
➗ 平均池化（Average Pooling）
每个窗口取均值：保留整体强度的平滑版本
窗口内最大值挪到任何位置，输出都不变 → 对窗口尺度微小平移的近似不变——把卷积的等变「折」成不变的那一步。
池化（Pooling）没有任何可学习参数：反向传播只把梯度路由给窗口内最大的位置，它是梯度的「路由器」，不是被训练的对象。

定义

感受野逐层递推：两层 3×3 顶一个 5×5

感受野（Receptive Field）= 某输出神经元在原始输入上能影响它的区域大小。输入层 r₀ = 1。

$$\boldsymbol{r_{l} = r_{l-1} + (k-1)\cdot \prod_{i} s_{i}}\ \ \text{（新核每扩一格 = 在放大了 ∏s 倍的旧视野边缘贴一圈）}$$
情形递推过程感受野
两层 3×3，全 s=1r₁ = 1+2×1 = 3；r₂ = 3+2×1 = 55×5（= 单层 5×5）
三层 3×3，全 s=1r₃ = 5+2×1 = 77×7（= 单层 7×7）
两层 3×3，第二层 s=2r₁ = 3；r₂ = 3+2×2 = 77×7（步幅让视野翻倍）
别漏掉步幅连乘项：池化或大步幅卷积以连乘方式进入公式，漏掉会严重低估深层神经元的视野。
推导

同样的视野，小核堆叠省 28% 参数还多一次非线性

① 感受野相同的两种方案，各算权重参数（通道数 C）

$\text{两层 3×3：}\ 2\times(3\times 3\times C\times C) = 18C^{2} \qquad \text{单层 5×5：}\ 5\times 5\times C\times C = 25C^{2}$

② 节省比例

$\dfrac{25C^{2}-18C^{2}}{25C^{2}} = \dfrac{7}{25} = \boldsymbol{28\%}$
$$\boldsymbol{18C^{2} \lt 25C^{2}}\ \text{且多一次 ReLU —— VGG 的论证：}\ \textbf{一切大核都应拆成 3×3 堆叠}$$

直觉

深度在堆视野：从边缘、纹理、部件到整只猫

flowchart TB A["输入层 · 视野 1×1"] --> B["第1层 3×3核 · 视野 3×3"] B --> C["第2层 3×3核 · 视野 5×5"] C --> D["第3层 3×3核 · 视野 7×7"]
神经元像越站越高的瞭望员：浅层看边缘 → 中层看纹理与部件 → 深层看整个物体。层级特征由感受野的生长节奏决定。
装机

标准 CNN：三段式堆叠，空间递减、通道递增

flowchart TB A["输入 224×224×3"] --> B["卷积 → ReLU → 池化 × N"] B --> C["112×112×64 → 56×56×128 …"] C --> D["展平"] D --> E["全连接分类头"]
三条独立旋钮：核大小 × 层数管感受野；步幅 × 池化管分辨率下降节奏；通道数管语义容量。经典架构都是这三条旋钮的不同拧法。
零件

1×1 卷积只管通道混合；架构史是三条旋钮的拧法

🎛️ 1×1 卷积（1×1 Convolution）
不看空间邻域，只在每个像素位置对通道做线性组合：256→64 通道，1×1 要 16,448 参数，3×3 要 147,520——便宜约 9 倍
📜 架构脉络
LeNet(1998，conv-pool 鼻祖) → AlexNet(2012，ReLU+GPU) → VGG(2014，全 3×3) → ResNet(2015，残差连接，是第8章优化问题的结构解法)
别以为越深越好、通道越多越好：深度受优化难度约束；通道每翻一倍，该层参数与计算量约翻四倍——架构是感受野、分辨率、参数预算的平衡。
避坑

三个高频误解：等变的归属、池化的参数、核的翻转

❌ 卷积自带平移不变性
✅ 卷积给的是等变（猫挪响应跟着挪，位置被保留）；近似不变归池化，且只对窗口尺度的微小平移成立。等变←卷积，不变←池化。
❌ max pooling 有可学习参数，参与梯度更新
✅ 它零参数，是固定的取 max 规则；窗口大小与步幅是超参数。反向传播只把梯度路由给窗口内最大位置。
❌ 卷积层会先把核翻转 180°
✅ 工程上永远是互相关，翻转已被学习吸收；但训练完成后核已固定，再翻转 = 换函数，输出必然改变——自由属于训练，不属于推理。

小结

三句话讲完第 9 章

1解决什么：全连接不懂图像结构（786,688 vs 4,864），三条结构假设把参数量压下两个数量级还保持表达力
2主线答案：平移不变的先验 = 让同一个核在所有位置复用 → 参数共享是其实现，等变是白送的性质，池化折成任务要的不变
3遗留问题：序列与时间轴上的结构先验还没解决 → 第 10 章序列建模接管
$$\boldsymbol{\text{输出边长} = \left\lfloor \frac{n+2p-k}{s} \right\rfloor + 1 \qquad r_{l} = r_{l-1} + (k-1)\prod_{i}s_{i}}\ \text{——合上书也要能默写}$$
