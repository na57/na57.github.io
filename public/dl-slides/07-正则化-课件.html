主线

一条链：容量惹祸 → 刹车偏好 → 四件武器 → 超参数欠账

1矛盾：大容量模型连噪声一起背——训练误差走低，测试误差反升

定义

正则化 = 允许训练误差升高、只为缩小泛化差距的任何修改

🎯 正则化（Regularization）
为降低泛化误差（而非训练误差）对学习算法做的任何修改
📏 泛化差距（Generalization Gap）
测试误差 − 训练误差——本章一切手段真正要压下去的指标
$$\text{泛化差距} = \text{测试误差} - \text{训练误差} \quad\Longrightarrow\quad \text{交易：训练误差略升，换它大降}$$
读法：训练误差只回答「记住没有」，泛化差距才回答「学会没有」——9 次多项式记住了（0.0），但没学会（差距 47.5）。

武器一

L2 惩罚 = 给损失加「权重平方和」，每步更新先把权重乘个折扣

在目标函数后加 L2 惩罚（L2 Regularization），神经网络里常叫权重衰减（Weight Decay）：

$$\tilde{J}(\boldsymbol{w}) = J(\boldsymbol{w}) + \frac{\alpha}{2}\,\boldsymbol{w}^{\!\top}\boldsymbol{w} \qquad (\alpha \geq 0\ \text{控制强度})$$
$$\boldsymbol{w} \leftarrow \boldsymbol{w} - \eta(\nabla J + \alpha\boldsymbol{w}) = \boldsymbol{(1-\eta\alpha)\,w} - \eta\nabla J$$
每步更新前权重先乘 $(1-\eta\alpha)$——在「衰减」。注意：只罚权重 $\boldsymbol{w}$、不罚偏置；$\alpha$ 太大则全部压向 0，直接欠拟合。
推导

二次近似 + 特征分解：L2 沿每个特征方向做标量缩放

① 在最优点附近做二次近似（一阶项在 $\boldsymbol{w}^*$ 处为 0，曲率装进海森矩阵 $\boldsymbol{H}$）

$$J(\boldsymbol{w}) \approx J(\boldsymbol{w}^*) + \tfrac{1}{2}(\boldsymbol{w}-\boldsymbol{w}^*)^{\!\top}\boldsymbol{H}(\boldsymbol{w}-\boldsymbol{w}^*)$$

② 加惩罚、求梯度、令其为零

$$\boldsymbol{H}(\tilde{\boldsymbol{w}}-\boldsymbol{w}^*) + \alpha\tilde{\boldsymbol{w}} = 0 \;\Rightarrow\; (\boldsymbol{H}+\alpha\boldsymbol{I})\tilde{\boldsymbol{w}} = \boldsymbol{H}\boldsymbol{w}^*$$

③ 对 $\boldsymbol{H}=\boldsymbol{Q}\boldsymbol{\Lambda}\boldsymbol{Q}^{\!\top}$ 特征分解，逐方向看

$$\tilde{\boldsymbol{w}} = (\boldsymbol{H}+\alpha\boldsymbol{I})^{-1}\boldsymbol{H}\boldsymbol{w}^* \qquad \text{方向 } i \text{ 缩放：}\ \boldsymbol{\dfrac{\lambda_i}{\lambda_i+\alpha}}$$

演练

手算 L2：敏感方向留 91%，平坦方向剩 9%——数据决定谁值得保留

设定：$\lambda_1 = 1$（敏感方向）、$\lambda_2 = 0.01$（平坦方向）、$\alpha = 0.1$、$\boldsymbol{w}^* = [0.8,\ 0.3]$

① 敏感方向缩放：$\dfrac{\lambda_1}{\lambda_1+\alpha} = \dfrac{1}{1.1} \approx \mathbf{0.909}$ —— 保留约 91%，几乎不动

② 平坦方向缩放：$\dfrac{\lambda_2}{\lambda_2+\alpha} = \dfrac{0.01}{0.11} \approx \mathbf{0.091}$ —— 只剩约 9%，压向 0

③ 代入：$\tilde{\boldsymbol{w}} \approx [0.8 \times 0.909,\ 0.3 \times 0.091] \approx \mathbf{[0.727,\ 0.027]}$

✍️

对照

L1 菱形棱角戳在坐标轴上出稀疏；L2 圆面只缩不归零

⭕ L2：圆形等惩罚面
光滑无极点，等高线任意角度相切 → 权重整体缩小，很少恰好为 0
🔶 L1：菱形等惩罚面
$\tilde{J} = J + \alpha\|\boldsymbol{w}\|_1$，棱角在坐标轴上 → 最优解停在角上，某些权重恰好为 0
口诀：L2 只缩不归零，L1 菱形出稀疏——稀疏解（Sparse Solution）= 自动特征选择；稀疏性来自 L1 在 0 点的棱角，不是惩罚强度的产物。
为什么偏置不罚：偏置不乘输入、不参与「乱弯」，罚它只引入欠拟合，没有正则化收益。
武器二

数据集增强：让模型见过同一只猫的一百种摆法，偶然就不再被当规律

数据集增强（Dataset Augmentation）：对训练样本做保持标签不变的变换，人造扩充训练集。

✅ 可以做
图像平移几像素、水平翻转、轻微旋转、缩放、加噪；语音加背景噪声
🚫 红线：变换不得改标签
数字 6 翻转成 9、字母 b 翻转成 d——OCR 里这类操作是掺错标签
💡 本质是把领域先验（「这些变换不改语义」）注入模型；但增强样本高度相关，信息量不如真实新数据。
武器二·续

标签平滑把最优分差从无穷大拴回 log 18 ≈ 2.89

$$\boldsymbol{y}_{\text{smooth}} = (1-\varepsilon)\,\boldsymbol{y}_{\text{hard}} + \frac{\varepsilon}{k}\cdot\boldsymbol{1}$$

手算（3 分类，$\boldsymbol{y}=[1,0,0]$，$\varepsilon=0.1$）：真实类取 $1-\varepsilon=0.9$，其余两类各 $\varepsilon/(k-1)=0.05$

$$[1,\ 0,\ 0] \;\longrightarrow\; \boldsymbol{[0.9,\ 0.05,\ 0.05]} \qquad 0.9+0.05+0.05 = 1.0\ \checkmark$$
硬标签要 softmax 输出精确 1 → logit 趋向 $+\infty$；软标签的最优 logit 差只需 $\log(0.9/0.05)=\log 18 \approx 2.89$——有限的差距，权重不再膨胀。

深挖

训练轮数 ≈ 等效容量：限轮数 = 把权重约束在起点附近的小球里

参数从初始点（约 0）出发：走 5 步可达区域是小球，走 5000 步可达区域大得多——可达区域大小 = 等效容量。

$$\text{二次损失下：早停} \;\approx\; \text{L2 权重衰减（都把权重约束在 0 附近）}$$
早停自带「容量随数据自动调节」属性：数据多，自然停得晚，等效容量随数据量放大——最便宜的正则化。
两条纪律：用验证集而非测试集早停（测试集参与选择会被污染）；设耐心（Patience），如连续 5 轮不改善才停，抗抖动。
武器四

Dropout：训练时随机删单元再除以 p，测试时不删——期望因此守恒

$$\text{训练：}\ \tilde{\boldsymbol{h}} = \frac{\boldsymbol{h}\odot\boldsymbol{m}}{p}\quad (P(m_i{=}1)=p) \qquad \text{测试：直接用}\ \boldsymbol{h}$$
flowchart TB A["原激活 h = 2, 4, 6, 8"] --> B["乘掩码 m = 1, 0, 1, 0"] B --> C["稀疏子网络 2, 0, 6, 0"] C --> D["除以 p = 0.5 → 4, 0, 12, 0"]
$\odot$ 是逐元素乘积（Element-wise Product）。$\mathbb{E}[m_i]=p$，故 $\mathbb{E}[\tilde{h}_i]=h_i$：期望守恒，测试阶段才能无缝用完整网络。
手算

本步实际输出 16、期望恰为 20：单次波动，期望严格守恒

$\boldsymbol{h}=[2,4,6,8]$，$p=0.5$，掩码 $\boldsymbol{m}=[1,0,1,0]$，下游权重 $\boldsymbol{w}=[1,1,1,1]$：

① 逐元素乘：$\boldsymbol{h}\odot\boldsymbol{m} = [2\times1,\ 4\times0,\ 6\times1,\ 8\times0] = [2,\ 0,\ 6,\ 0]$

② 除以 $p$：$\tilde{\boldsymbol{h}} = [2/0.5,\ 0,\ 6/0.5,\ 0] = \mathbf{[4,\ 0,\ 12,\ 0]}$

③ 验期望：不 dropout 时 $\boldsymbol{w}\cdot\boldsymbol{h} = 20$；本步实际 $4+0+12+0=16$，但 $\mathbb{E}[\boldsymbol{w}\cdot\tilde{\boldsymbol{h}}] = \boldsymbol{w}\cdot\boldsymbol{h} = \mathbf{20}\ \checkmark$

机理

两个视角：2ⁿ 个子网络的廉价集成 + 打散单元间共适应

🗳️ 集成视角
$n$ 个单元有 $2^n$ 种掩码 = 指数级多个共享权重的子网络；测试时完整网络 ≈ 它们的集成平均（集成 = 降方差）
🧩 冗余视角
队友随时缺席 → 每个单元被迫学出独立有用的特征，打散共适应（Co-adaptation）
一句话：训练时反复把网络「打残」，让任何单元都不可靠，逼整个网络学会冗余与分布式表示。
实践细节：输入层保留概率应更高（如 0.8）——输入特征丢不起。
推广

对抗训练：把正则化从「参数方向」推到「输入扰动方向」

对抗样本（Adversarial Example）：输入加肉眼不可见的精心扰动，输出剧变——本质是输入空间某些方向上的泛化失败。

$$\text{对抗训练（Adversarial Training）：}\ \boldsymbol{x}' = \boldsymbol{x} + \varepsilon\cdot\mathrm{sign}(\nabla_{\boldsymbol{x}} J)\ \text{混入训练集}$$
效果 ≈ 惩罚「输出对输入的梯度范数」——与数据增强一脉相承，是本章思想的最远延伸。
反直觉：对抗样本源于高维空间的过度线性而非非线性——每维只改 $\varepsilon$，上万维同向累加即翻转输出。
避坑

三个高频错误：看错指标、罚错对象、搞反训练与测试

❌ 训练误差越低模型越好
✅ 9 次多项式训练 0.0、测试 47.5——看泛化差距不看训练误差；训练误差只回答「记住没有」。
❌ L2 把 α 调大就有稀疏解；偏置也一起罚
✅ $\lambda_i/(\lambda_i+\alpha)$ 对有限 $\alpha$ 恒大于 0，稀疏是 L1 的事；偏置不乘输入，罚它只致欠拟合。
❌ 测试时也开 dropout；用 inverted dropout 却忘了训练时除 p
✅ 训练要随机、测试要确定：测试用完整网络 = 取期望；忘除 p 则训练/测试激活尺度对不上。
