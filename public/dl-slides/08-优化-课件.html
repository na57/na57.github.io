主线

目标有噪声、曲面有病态，于是步长要衰减、方向要惯性、坐标要缩放

1底牌：期望误差不可算，只能优化抽样的经验风险——梯度是带噪声的指南针（8.1）
2病根：曲面病态，同一学习率让快方向发散、慢方向爬行（8.2）
3治噪：学习率必须衰减，满足和发散、平方和收敛（8.3）
4治病：动量放大一致方向、抵消震荡（8.4）；Adam 逐坐标配步长（8.5）
这条链就是本章目录：8.1 目标 → 8.2 病态 → 8.3 步长 → 8.4 动量 → 8.5 自适应 → 8.6 二阶方法与结构。
动机

梯度算得出，训练却可能原地爆炸或慢如蜗牛

第6、7章之后，模型、反向传播、正则化目标一应俱全——但一个条件数 100 的二次碗就足以让训练翻车：

$$\eta=0.025\;(\text{越界 }0.02)\Rightarrow 10\text{ 步误差 }\times 57.7\;;\qquad \eta=0.01\Rightarrow \text{慢方向降九成需 }230\text{ 步}$$
🥶 冷水一：目标不对
期望泛化误差算不了，只能优化抽样的经验风险——梯度带噪声。
🥶 冷水二：曲面病态
方向间曲率悬殊，同一学习率被快慢两个方向两头卡死。
💡 本章方案：给带噪声的指南针配四件装备——minibatch、学习率衰减、动量、自适应学习率。
定义

我们优化的从来不是真目标，只是经验风险的替身

🗺️ 经验风险（Empirical Risk）
真实分布 pdata 未知，用训练集平均损失代替期望损失；最小化它即经验风险最小化（ERM）。
📋 代理损失（Surrogate Loss）
0-1 损失处处梯度为 0，换成可微的负对数似然；且不降到最小——早停防过拟合。
$$J(\theta)=\mathbb{E}_{(x,y)\sim\hat{p}_{\text{data}}}\,L(f(x;\theta),y)=\frac{1}{m}\sum_{i=1}^{m}L\!\left(f(x^{(i)};\theta),\,y^{(i)}\right)$$
读法：没见过题库全集，只能把手头这沓真题当全集刷——而且刷的还是替身题，只刷八分熟。
minibatch

批量翻一百倍，梯度精度只提高十倍

$$\text{标准误（Standard Error）}\quad \mathrm{SE}=\frac{\sigma}{\sqrt{m'}}$$
批量大小 m′标准误 σ/√m′（σ = 1）相对上一档
11/√1 = 1—
1001/√100 = 0.1样本 ×100，误差 ÷10
100001/√10000 = 0.01样本 ×100，误差 ÷10
√m′ 律 = 收益递减：小批量每步便宜、能走更多步，噪声还有点正则化效果——这就是小批量划算的全部理由。
定义

曲率悬殊时，同一个学习率被快慢两个方向两头卡死

⛰️ 病态条件（Ill Conditioning）
损失曲面各方向曲率（Curvature）悬殊：陡如悬崖与平如平原并存，局部由海森矩阵（Hessian）H 刻画。
📏 条件数（Condition Number）
κ = 最大特征值 / 最小特征值；每个特征方向的误差每步乘 |1 − ηλ|，收敛要求 η 小于 2/λmax。
$$\kappa(H)=\frac{\lambda_{\max}}{\lambda_{\min}}\;,\qquad \text{稳定步长界：}\ \eta \lt \frac{2}{\lambda_{\max}}$$
画面：梯度下降像只有一档速度的车——沿峡谷壁来回弹跳随时翻车，沿峡谷底慢如蜗牛。
推导

学习率越界千分之五，十步误差放大五十八倍

① 写稳定界：λmax = 100、λmin = 1，κ = 100；取 η = 0.025 越界

$$\eta \lt \frac{2}{\lambda_{\max}}=\frac{2}{100}=0.02\;,\qquad \eta=0.025\ \text{越界 }0.005$$

② 快方向每步误差因子：绝对值大于 1 → 每步放大

$$|1-\eta\lambda_{\max}|=|1-0.025\times 100|=|1-2.5|=1.5$$
$$1.5^{5}\approx 7.59\;\Rightarrow\;\boldsymbol{1.5^{10}\approx 57.7}\ \text{——十步放大近 58 倍，发散}$$

对照

守规矩的代价：快方向一步收敛，慢方向要二百三十步

η = 0.01（守界）：快方向 |1 − 0.01×100| = 0，一步清零；慢方向每步 ×0.99：

$$0.99^{n}=0.1\Rightarrow n=\frac{\lg 0.1}{\lg 0.99}\approx\frac{-1}{-0.004365}\approx \boldsymbol{230\text{ 步}}$$
同一个 η，不可能同时讨好两个方向——这就是病态条件的诅咒。

峡谷状损失面：沿壁弹跳翻车，沿底慢如蜗牛

收敛条件

步长之和要发散，平方和要收敛，SGD 才肯停下

$$\sum_{t=1}^{\infty}\eta_t=\infty \qquad\text{且}\qquad \sum_{t=1}^{\infty}\eta_t^{2} \lt \infty$$
验证 ηt = 0.1/t级数结论
∑ ηt0.1 ×（1 + 1/2 + 1/3 + …）= 0.1 × 调和级数发散 → ∞ ✓
∑ ηt²0.01 ×（1 + 1/4 + 1/9 + …）= 0.01 × π²/6≈ 0.0164 收敛 ✓
常数 ηt = η∑ η² = ∞第二条失败 ✗
一句话：步子总量要够走任意远（和发散），后期步子要小到能被噪声原谅（平方和收敛）。
噪声地板

常数学习率让参数在最优点附近永远随机游走

  • 最优点处真实梯度 = 0，但估计梯度 ĝ 方差不为 0 → 更新 $-\eta\hat{g}$ 是均值 0、幅度 ∝ η 的随机跳动
  • η 不衰减 → 跳动不衰减 → 参数永远做半径 ≈ η ×（噪声水平）的随机游走，能靠近，停不下
  • 调大 batch 只能按 √m′ 律压噪声，除全量梯度外方差永远严格大于 0
$$\eta_t=\Bigl(1-\frac{t}{T}\Bigr)\eta_0+\frac{t}{T}\eta_T\;,\qquad \eta_T\approx 1\%\,\eta_0$$
💡 随机性不随训练消失，只能靠步长消失来对冲——工程上用线性衰减收尾。
动量

动量不改步长，改步长由历史梯度的加权平均决定

$$\boldsymbol{v\leftarrow \alpha v-\varepsilon\nabla J\;,\qquad \theta\leftarrow \theta+v}$$
🌀 部件A：指数加权移动平均（EWMA）
v 是历史梯度的指数加权平均；α = 0.9 时影响延续约 1/(1−α) = 10 步。
⚖️ 部件B：共识累加、分歧抵消
一致方向梯度越积越大（加速）；震荡方向梯度正负翻转、相互抵消（抑振）。
画面：参数是小球，梯度是坡度，α 是无摩擦程度——冲下谷底越滚越快，撞上谷壁来回弹、平均为零。
演练

一致方向上，动量把步速放大整整十倍

① v1 = 0.9×0 − 0.02 = −0.02；v2 = 0.9×(−0.02) − 0.02 = −0.038；v3 = 0.9×(−0.038) − 0.02 = −0.0542

② 稳态：令 v∞ = 0.9v∞ − 0.02 ⟹ 0.1v∞ = −0.02

$$v_{\infty}=-\frac{\varepsilon\nabla}{1-\alpha}=-\frac{0.02}{0.1}=\boldsymbol{-0.2}\;,\quad \text{放大 }\frac{1}{1-\alpha}=10\text{ 倍（裸 SGD 仅 }-0.02\text{）}$$
✍️

谱系

从 SGD 到 Adam，每一步都在给不同方向配不同速度

flowchart TB S["SGD：所有参数共享一个步长"] --> M["动量：时间维加惯性，放大共识、抵消震荡"] M --> R["RMSProp：空间维逐坐标，按梯度平方缩放步长"] R --> AD["Adam：动量 + RMSProp + 偏差修正"]
💡 谱系一句话：动量治「时间上的震荡」，RMSProp 治「坐标间的悬殊」，Adam 把两味药缝在一起再补冷启动。
RMSProp

历史梯度越大的坐标，实际步长压得越小

$$r\leftarrow \beta_2 r+(1-\beta_2)g^{2}\;,\qquad \Delta\theta=-\frac{\varepsilon}{\sqrt{r}+\delta}\,g$$
  • 快方向 g 持续大 → r 大 → 步长被压缩，不发散；慢方向 g 持续小 → r 小 → 步长相对放大，不爬行
  • δ ≈ 10⁻⁸：防 r 极小时除零爆炸，不是摆设
RMSProp 只有二阶矩缩放：无一阶动量、无偏差修正——这两块短板由 Adam 补齐。
Adam

Adam = 动量 + RMSProp + 偏差修正，信噪比驱动

$$m\leftarrow\beta_1 m+(1-\beta_1)g\quad\text{（一阶矩≈动量）}$$
$$v\leftarrow\beta_2 v+(1-\beta_2)g^{2}\quad\text{（二阶矩≈RMSProp）}$$
$$\hat{m}=\frac{m}{1-\beta_1^{t}}\;,\ \hat{v}=\frac{v}{1-\beta_2^{t}}\quad\text{（偏差修正）}$$
$$\boldsymbol{\Delta\theta=-\varepsilon\,\frac{\hat{m}}{\sqrt{\hat{v}}+\delta}}$$
读法：分子是「梯度的共识」，分母是「梯度的规模」——方向稳则比值 ≈ ±1 全速走 ε，方向乱则趋 0 自动减速。
推导

Adam 首步有效步长约等于 ε，与梯度大小几乎无关

① 两个矩（g = 2，β₁ = 0.9，β₂ = 0.999，ε = 0.001，m₀ = v₀ = 0）

$$m_1=0.9\times 0+0.1\times 2=0.2\;,\qquad v_1=0.999\times 0+0.001\times 4=0.004$$

② 偏差修正：恰好还原观测本身

$$\hat{m}_1=\frac{0.2}{1-0.9}=\frac{0.2}{0.1}=2\;,\qquad \hat{v}_1=\frac{0.004}{1-0.999}=\frac{0.004}{0.001}=4$$
$$\Delta\theta=-0.001\times\frac{2}{\sqrt{4}+10^{-8}}\approx \boldsymbol{-0.001}\ \text{（裸 SGD 同条件 }-0.002\text{）}$$

深挖

省掉偏差修正，首步更新立刻大三倍

$$\text{不修正：}\ \Delta\theta=-0.001\times\frac{0.2}{\sqrt{0.004}}\approx -0.001\times\frac{0.2}{0.0632}\approx \boldsymbol{-0.00316}\ \text{（大三倍多）}$$
  • m、v 从 0 启动被压向 0：m₁ 仅真值的 1/10，v₁ 仅真值的 1/1000
  • 两个偏差差两个数量级，开根号后比例失衡 → 步长与方向一起失真
  • 1 − βᵗ 把估计拉回无偏；t 变大后 βᵗ → 0，修正自动退场
一句话：冷启动时二阶矩偏得最狠，偏差修正专治这个；它不是可选项，是 Adam 的一部分。
二阶与结构

牛顿法出局，BN 用重参数化把曲面捋平

🏛️ 牛顿法（Newton's Method）
H⁻¹∇J 一步纠正所有方向曲率；但 n = 10⁹ 时 H 要存 10¹⁸ 个数、求逆 O(n³)——存储与算力上直接出局。
🦴 批量归一化（BN）的优化视角
每层输入减均值除标准差再仿射 = 重参数化（Reparameterization）：解耦层间尺度、捋平曲面、改善条件数 → 可用更大学习率。
一枚硬币的两面：算法迁就曲面（动量、Adam），结构改造曲面（BN、残差连接）。训练困难时先问该换算法还是该改结构。
避坑

本章最容易错的三件事

❌ loss 后期抖动 = 模型坏了，换模型
✅ 多数是常数学习率撞上噪声地板——噪声方差不为零，参数永远随机游走；衰减 η 即解。
❌ 训练发散 = 反向传播算错了
✅ 多数只是 η 越过 2/λmax（例中 0.025 对界 0.02，只差 0.005）；先砍学习率再怀疑梯度。
❌ Adam 免调学习率，偏差修正可省
✅ ε 仍是第一超参数；不修正首步更新放大三倍多。口诀：抖动先衰减，发散先砍 η，修正不能省。
