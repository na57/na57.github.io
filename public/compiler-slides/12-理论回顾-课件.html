定义

乔姆斯基层级：四级语言，恰好对应四种自动机

型别语言类对应自动机能表达不能表达
3 型正则语言有穷自动机 FA单词结构：标识符、数aⁿbⁿ（任意深配对计数）
2 型上下文无关下推自动机 PDA嵌套括号、表达式、aⁿbⁿwcw、「先声明后使用」
1 型上下文有关线性有界自动机 LBAaⁿbⁿcⁿ、声明-使用约束——（分析代价不可承受）
0 型递归可枚举图灵机 TM一切可计算之物停机问题等不可判定问题
整个计算机科学最漂亮的对应之一：文法规则形态 ↔ 语言类 ↔ 识别机器，三者一一对齐。
实质

层级上升 ＝ 记忆能力升级，一级一个价格

FA只有状态、没有外部记忆 → 泵引理：n 状态走 n 步必有环 → 数不清 aⁿbⁿ
PDA加一个栈 → 任意深嵌套能数；但栈读完前一半就空 → wcw 仍够不着
LBA带长受输入线性限制 → 可做局部上下文检查
TM带长无限 → 能算一切可算的，同时继承不可判定性
💡 关键一跃：乔姆斯基层级是一张「记忆能力价格表」——表达力更强，判定与分析的成本更高。
选型

最弱够用：词法买 3 型，语法买 2 型，语义在树上外挂

🔤 词法 → 3 型正则
只数不配对；O(n) 识别，还能从正则描述自动生成分析器（Lex）
🌳 语法 → 2 型 CFG
任意深嵌套必须有栈；LL/LR 保持线性时间
🏷️ 语义 → 属性文法
1 型分析代价不可承受 → 在 CFG 树上外挂语义计算
⚠️ C / Java 的语法并不是纯 CFG：「先声明后使用」「类型匹配」「重载决议」都超出 CFG，推给语义分析兜底。
全链

(a|b)*abb：正则 → NFA → DFA → 最小 DFA，一环都不许跳

1Thompson 构造：按模板拼装出 NFA（11 个状态，含 ε 边）
2子集构造：DFA 每态 ＝ NFA 状态子集，闭包迭代（11 态 → 5 态）
3划分求精：按「接受/非接受」起步，不一致就分裂（5 态 → 4 态）
语言 ＝ 以 abb 结尾的所有 a/b 串：够小能算到底，够典型覆盖全部构造。每一环都机械可执行——所以词法分析器能自动生成。
第一环

Thompson NFA：左半 (a|b)* 自循环，右半 abb 三步直路

0 是起点，10（绿色）是唯一接受态；ε 边不消耗字符，是模板拼装的接缝
第二环

子集构造：DFA 每态 ＝ NFA 状态子集，11 态收成 5 态

DFA 状态NFA 子集（ε-闭包后）读 a 到读 b 到
A（起点）{0,1,2,4,7}BC
B{1,2,3,4,6,7,8}BD
C{1,2,4,5,6,7}BC
D{1,2,4,5,6,7,9}BE
E（接受）{1,2,4,5,6,7,10}BC
每一步都是「先 move 再 ε-闭包」的机械迭代：A 读 a → {3,8} → 闭包 {1,2,3,4,6,7,8} ＝ B。没有新子集即终止。
演练

划分求精：先分 D，再分 B，{A,C} 稳定——5 态压到 4 态

① 初始划分：{A,B,C,D} ｜ {E}（按「接受 / 非接受」二分）

② 检查读 b：A→C 组内、B→D 组内、C→C 组内、D→E 组外 → 分裂 D：{A,B,C} ｜ {D} ｜ {E}

③ 检查 {A,B,C}：读 a 都到 B（一致）；读 b，A→C、C→C 组内，B→D 组外 → 分裂 B：{A,C} ｜ {B} ｜ {D} ｜ {E}

④ 检查 {A,C}：读 a 都到 B、读 b 都到 C → 稳定。终止，共 4 个状态

第三环

最小 DFA 四态：abab 拒绝、aabb 接受，且同构意义下唯一

flowchart TB P0(("S0={A,C}")) -->|"a"| P1(("S1={B}")) P0 -->|"b"| P0 P1 -->|"a"| P1 P1 -->|"b"| P2(("S2={D}")) P2 -->|"a"| P1 P2 -->|"b"| P3(("S3={E}")) P3 -->|"a"| P1 P3 -->|"b"| P0 classDef acc fill:#e4f0e9,stroke:#33735a,stroke-width:2.5px,color:#33735a; class P3 acc;
✅ aabb：S0→S1→S1→S2→S3 接受
❌ abab：S0→S1→S2→S1→S2，停在非接受态，拒绝
子集构造最坏 2ⁿ（本例 11 态只生出 5 态，运气好）；最小 DFA 在同构意义下唯一——Myhill-Nerode 定理的礼物。
意义

每环机械可执行：理论把一门手艺变成一台机器

1Thompson ＝ 模板拼装；子集构造 ＝ 闭包迭代；最小化 ＝ 划分求精——无需灵感
2所以 Lex / Flex 能从正则描述自动生成词法分析器
💡 世界观：NFA 是「并行试探所有可能」，DFA 是「把试探结果预先算成状态」——不确定性在编译期一次性付清，换运行期线性时间。LR 分析表是同一种「预付」。
空档

确定性 PDA 弱于非确定 PDA——这个空档正是 LL / LR 存在的理由

📚 等价性
非确定 PDA 与 CFG 识别能力恰好等价
⚡ 空档
确定性 PDA 更弱；编译器只玩得起确定性（线性时间）→ 必须刻画「确定性可分析的 CFG 子类」
💡 LL 与 LR ＝ 确定性、线性时间内可分析的文法子类。理论划边界，工程在边界内挑工具。
边界

LR 比 LL 强，因为它见得更多才决策

LL（自顶向下，最左推导）LR（自底向上，最右推导的逆）
判定时机只看向前 k 个单词就选定产生式右部全部进栈后，再看向前 k 个符号归约
能力边界容不下左递归与公共左因子；文法类较小LR(1) 严格大于任何 LL(k)；左递归天然无害
工程取舍递归下降直观，错误定位好表驱动、能力强，由 Yacc/Bison 生成
$$\text{能力包含链：}\quad \boldsymbol{\mathrm{LL}(k) \subset \mathrm{LR}(k)}\qquad \text{——LL 在押注，LR 在等牌}$$
补缺口

CFG 管结构对不对，属性文法管结构上算的数对不对

⬆️ 综合属性
自底向上：由子节点的值算出父节点的值（如表达式的类型与值）
⬇️ 继承属性
自顶向下或横向：由父节点、兄弟节点算（如声明把类型传给变量表）
$$\text{求值顺序 ＝ 属性依赖图的拓扑序；成环即不可求值}$$
三件套齐活：词法 ＝ FA（无记忆），语法 ＝ 确定性 PDA（一个栈），语义 ＝ 属性文法（树上外挂计算器）。
天花板

停机问题笼罩优化篇：完美优化器不存在，只有安全的近似

1停机问题：连「程序会不会停」都不可判定（图灵机）
2Rice 定理：程序语言的任何非平凡语义性质都不可判定——「两程序等价」在内
3死命令：优化必须保守（sound）——宁可漏优化，不可改错程序
第9章数据流方程取交汇运算、第11章指针别名「可能相等即当相等」——保守原则的理论根源就在这里。
回扣①

前端三站：解决什么、边界在哪、遗留什么

工序解决什么能力边界遗留问题
词法分析字符流 → 单词流正则语言：数不清任意深配对几乎没有——工具全自动
语法分析单词流 → 语法树确定性 CFG：左递归须改写、二义性须消除错误恢复至今仍是手艺
语义分析语法树 → 带类型的树属性文法可求值性：依赖成环即死跨模块语义检查越来越贵
读法：每站都只用刚好够强的机器——边界不是缺陷，是选型原则的必然代价。
回扣②

后端四站＋运行时：边界从「贵」变成「不可判定」

工序解决什么能力边界遗留问题
中间代码（Ch6）树 → 三地址码几乎无（纯翻译）IR 设计的权衡
优化（Ch9）算什么最省不可判定 → 保守近似完美优化器不存在
代码生成（Ch8）落到物理机器指令选择／寄存器分配 NP 难靠启发式逼近
调度与并行（Ch10–11）指令怎么排、循环怎么拆依赖分析精度：指针别名理论上可行 ≠ 工程上够得着
运行时（Ch7）栈、堆、GC暂停时间与内存开销的权衡低延迟 GC 仍在演进
共性：每站只用刚好够强的机器，都拿安全换可行。
毕业

毕业三问：能各讲八成，这门课就算真正毕业

问1词法正则、语法 CFG、语义属性文法——为什么一层比一层强，代价是什么？（每层只买刚好够用的表达力）
问2优化凭什么敢改代码？（语义保持；程序等价不可判定 → 必须保守）
问3从源程序到机器码，每站把信息翻译成什么形态？（丢什么、沉淀什么）
每个问题先自己作答，再与讲义 12.5 的参考答案比对——八成即毕业。
避坑

三个回马枪：优化改语义、子集构造总便宜、LR 淘汰 LL

❌ 优化会改变程序行为让它更快
✅ 一切合法优化都是语义保持变换：对所有输入可观察行为一致；改的是成本，不是语义。
❌ 子集构造永远这么便宜
✅ n 态 NFA 最多 2ⁿ 个子集，理论可指数爆炸（本例 11→5 属运气好）；但最小 DFA 同构唯一，与路径无关。
❌ LR 更强，LL 该淘汰
✅ 能力之外还有工程维度：手写递归下降可读可调试、错误恢复好（GCC/Clang 前端即如此）。理论给上界，选型看综合成本。
小结

三句话讲完第12章，也讲完全书

1解决什么：把每道工序映射回理论地基，标出能力边界
2核心图景：层级是记忆能力价格表，每层只买刚好够用的机器；全链机械可执行 → 前端可自动生成
3全书边界：停机问题与 Rice 定理 → 优化必须保守，完美优化器不存在
$$\text{每层只买刚好够用的表达力：词法＝FA，语法＝确定性 PDA，语义＝属性文法，优化＝安全的保守近似}$$
