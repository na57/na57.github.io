主线

先问能不能拆，再问拆完快不快，最后落到分析的极限

1出发点：单核 ILP 见顶（功耗墙）→ 多核＋共享内存，线程级并行
2算得动吗：阿姆达尔定律——串行部分压住加速比上界
3跑得对吗：距离向量逐层判定 DOALL，无跨迭代依赖才可拆
4跑得快吗：cache 顶不住 → 循环分块＋i-k-j 换序
5统一视角：交换／分块／倾斜 ＝ 迭代空间上的仿射变换

动机

阿姆达尔定律：5% 串行，64 核也只有 15.4 倍

$$S(p) = \frac{1}{f_s + (1-f_s)/p}\qquad \text{串行占 } f_s\text{，用 } p \text{ 个核}$$
设定算式加速比
f_s＝5%，p＝641 / (0.05 ＋ 0.95/64) ＝ 1 / 0.0648≈ 15.4 倍
f_s＝5%，p → ∞1 / 0.0520 倍封顶
串行部分不消灭，堆核没用——头号目标是找到「全体迭代互不依赖」的循环。
定义

迭代空间是一张网格，依赖是网格上的向量

🕸️ 迭代空间
d 层嵌套循环的全体迭代 ＝ ℤ 的 d 次方中的整点集合，每个整点 (i, j) 是一次迭代
➡️ 依赖距离向量
迭代 (i₁, j₁) 写、迭代 (i₂, j₂) 读同一位置，则 d ＝ (i₂−i₁, j₂−j₁)
$$\text{读必在写后} \;\Longrightarrow\; \text{合法距离向量}\ \boldsymbol{d}\ \text{字典序非负（第一个非零分量为正）}$$
读法：距离向量就是「这次写，多久之后被读」的网格坐标差。
定义

DOALL 判定：所有距离向量的第 k 分量为 0，第 k 层才可拆

$$\forall d \in D:\ d_k = 0 \;\Longleftrightarrow\; \text{第 } k \text{ 层是 DOALL（可切块分给多核）}$$
✅ 分量为 0 的含义
写和读永远落在同一迭代行上，那一层就是自由的
⚠️ 两个「别搞错」
是「所有」向量为 0，一个例外即否决；DOALL 是逐层性质，不是整体性质
操作顺序固定：写出全部距离向量 → 逐层看分量 → 分量全 0 的层切块并行。
例1

矩阵加：依赖集为空，两层都是 DOALL，零通信

C[i][j] = A[i][j] + B[i][j]　（两层循环 i、j）
1查写：每个 C[i][j] 恰好被一个迭代写一次 → 无输出依赖
2查读：A、B 全程只读不写 → 读与写永不冲突
3结论：D ＝ 空集 → 分量条件平凡成立 → 两层都是 DOALL
4 个核按 i 切 4 段即可，零通信——这种循环又叫「尴尬并行」：并行起来毫不费力。
演练

A[i][j]=A[i−1][j]+A[i][j−1]：两个向量，两层全锁死

① 读 A[i−1][j] ← 写于迭代 (i−1, j) → 距离 (1, 0)

② 读 A[i][j−1] ← 写于迭代 (i, j−1) → 距离 (0, 1)

③ D ＝ {(1,0), (0,1)}，均字典序非负 ✓；但第 1 分量含 1、第 2 分量含 1 → 两层都不可并行

✍️
暂停推导

先自己写出距离向量集合，再逐层判定 i 层与 j 层是否 DOALL。

flowchart TB n11["(1,1)"] -->|"纵向 (1,0)"| n21["(2,1)"] n12["(1,2)"] -->|"纵向 (1,0)"| n22["(2,2)"] n13["(1,3)"] -->|"纵向 (1,0)"| n23["(2,3)"] n11 -->|"横向 (0,1)"| n12 n12 -->|"横向 (0,1)"| n13 n21 -->|"横向 (0,1)"| n22 n22 -->|"横向 (0,1)"| n23
每个迭代都要等左边与上边的邻居——但对角线 (1,1)、(2,2)… 之间没有箭头（波前并行的伏笔）
对照

改成 A[i][j]=A[i−1][j]+1：i 层锁死，j 层照样 DOALL

A[i][j] = A[i−1][j] + 1　→　D ＝ {(1, 0)}
🔒 i 层（第 1 分量）
分量 ＝ 1 ≠ 0 → 携带依赖，行间排队
🔓 j 层（第 2 分量）
所有向量分量 ＝ 0 → DOALL：固定一行，行内 N 个元素同时算
纪律：写出全部距离向量再逐层判定——不能看见下标里有减号就断言「整个循环不可并行」。并行化不必全有或全无。
换战场

矩阵乘＋cache：算得快不如喂得快

C[i][j] += A[i][k] × B[k][j]　（i-j-k 三重循环，行优先布局）
参数值含义
N1024矩阵规模，三个数组各 8 MB
元素8 B（double）一行 cache 装 8 个元素
C（cache 容量）32 KB典型 L1——三个数组谁都装不下
L（行大小）64 B一次 miss 搬一整行
一次主存访问比一次算术慢两个数量级——后半章只问一件事：miss 多少次？
手算

不分块：B 按列步长 1024，次次 miss——合计 9/8·N³

数组内层访问模式miss 次数
B[k][j]按列：步长 N 个元素，无两次访问同行N³
A[i][k]按行连续：一行服务 8 次（跨 j 复用被 B 的整列挤掉）N³/8
C[i][j]k 循环内反复用同一元素N²/8
$$\mathrm{miss}_{\text{不分块}} \approx N^3 + \frac{N^3}{8} + \frac{N^2}{8} \approx \boldsymbol{\frac{9}{8}N^3}$$
分块

三块同时驻留：3B²×8 ≤ C，贴着容量线取 B＝32

$$\text{三块同时驻留：}\quad 3B^2 \times 8 \le C \;\Longrightarrow\; B^2 \le \frac{32768}{24} \approx 1365.3 \;\Longrightarrow\; B \le 36.9$$
✅ B ＝ 32（取 2 的幂）
3 × 32² × 8 ＝ 24576 ≤ 32768，成立
❌ B ＝ 37
3 × 37² × 8 ＝ 32856 ＞ 32768，超限
分块＝把时间局部性捏出来：三个小块反复用，用完再扔。艺术在于贴着容量线取最大，不是越大越好。
手算

分块后：miss ＝ N³/(4B)，B＝32 即除以 128

1每个 B×B 块：每行 B 个连续元素占 B/8 个 cache 行，共 B 行 → 每块 miss B²/8 次；A、B 两块合计 B²/4
2块三元组总数 ＝ (N/B)³
3相乘：(N/B)³ × B²/4 ＝ N³/(4B)（C 的 N²/8 可忽略）
$$\mathrm{miss}_{\text{分块}} \approx \frac{N^3}{4B}\qquad B{=}32 \text{ 时即 } \frac{N^3}{128}$$
前提：三块驻留得下。B 一旦过容量线，三块互相挤压，miss 反弹回 O(N³)。
数字

N＝1024：12.08 亿次 → 852 万次，约 142 倍

形态ABC合计
不分块（i-j-k）N³/8 ≈ 1.34×10⁸N³ ≈ 1.07×10⁹N²/8 ≈ 1.3×10⁵1.208×10⁹
分块 B＝32N³/(4B) ≈ 8.39×10⁶N²/8 ≈ 1.3×10⁵8.52×10⁶
$$\frac{1.208\times 10^{9}}{8.52\times 10^{6}} \approx \boldsymbol{142}\ \text{倍——同一份计算，只差循环结构}$$
换序

i-k-j：不动数据不动 cache，按列访问直接消失

内层走 j 时访问模式效果
C[i][j]按行连续，步长 1一行服务 8 次
B[k][j]按行连续，步长 1按列访问消失
A[i][k]内层不变相当于常量
与第10章对照：指令调度重排基本块里的指令，循环交换重排迭代空间里的整点——同一个思想「在依赖允许的范围内换顺序」，两个粒度各显神通。
统一

交换、分块、倾斜 ＝ 迭代空间上的同一个矩阵乘法

变换矩阵 / 坐标干了什么
交换 interchangeM＝[[0,1],[1,0]]，即 i′=j, j′=i内外层互换；i-k-j 即两次交换
分块 tiling引入块下标 ⌊i/B⌋，坐标重塑大迭代空间切成小块，块内驻留 cache
倾斜 skewingM＝[[1,1],[0,1]]，即 s=i+j, t=j把例2 变成沿反对角线的波前并行
$$\text{合法性：}\ \forall d \in D,\ M\!\cdot\! d\ \text{字典序非负（读不得先于写）}$$
手算

例2 加倾斜：(1,0)→(1,0)、(0,1)→(1,1)，反对角线成自由维

$$M=\begin{pmatrix}1&1\\0&1\end{pmatrix}\quad M(1,0)^{\!\top}=(1,0)^{\!\top}\ \checkmark\qquad M(0,1)^{\!\top}=(1,1)^{\!\top}\ \checkmark\ \text{均字典序为正，合法}$$
1新坐标 s＝i＋j，t＝j：s 相同的迭代构成一条反对角线
2新依赖的 s 分量都是 1 → 依赖只存在于对角线之间，同一条线上 t 层自由
3固定一条反对角线，线上迭代同时算 → 波前并行：两层全锁死的循环硬是挤出了并行
避坑

三个真实误解：堆核即加速、块越大越好、变换无中生有

❌ 开 p 个线程就近乎快 p 倍
✅ 阿姆达尔压住上界（5% 串行 ⇒ 64 核 ≈ 15 倍）；还有同步开销、负载不均、伪共享——两核写同一 cache 行的不同字节也会互相挤掉。
❌ 分块的块越大越好
✅ 过 3B²×8 ≤ C 的容量线，三块互相挤压，miss 反弹回 O(N³)；L2/L3 各有最优块大小，工程上常做两级分块。
❌ 仿射变换总能把串行循环变并行
✅ 强递推（A[i]=A[i−1]+A[i−2]）把迭代串成链，任何合法矩阵都变不出 DOALL 层——框架只能搜索最优，不能无中生有。
接口

指针别名：理论上可行与工程上可做之间的缝

第10章 指令级并行本章 并行与局部性
粒度单核内重排指令核间切分迭代＋cache 分块
依赖分析寄存器读写 → DAG数组下标 → 距离向量
共同敌人停顿（等操作数）cache miss（等数据）＋别名（不敢拆）
指针别名无法精确判定 → 分析只能保守假设「可能依赖」→ 本可并行的循环被判成串行。这条缝是工程不足还是原理所限？第12章从可判定性高度回看。
小结

三句话讲完第11章

1解决什么：把循环安全拆到多核，并把并行放大的访存量摁回 cache
2核心机制：距离向量判 DOALL → 分块驻留 → 换序顺步长 → 仿射变换统一
3承上启下：别名让分析变保守 → 第12章回看可判定性
$$\forall d\,{\in}\,D:\ d_k{=}0 \Leftrightarrow \text{第}k\text{层DOALL}\qquad \mathrm{miss}_{\text{分块}} \approx \frac{N^3}{4B}\ \ (3B^2{\times}8 \le C)$$
本 章 结 束

能拆的层才拆，摁得住的数据才快
