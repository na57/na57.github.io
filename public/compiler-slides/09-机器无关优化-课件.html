动机

$$\text{原始循环体：} 12 \text{ 条语句、每次迭代 } 2 \text{ 次乘法} \;\Rightarrow\; n=1000 \text{ 时白算上千次}$$

定义

基本块 ＝ 最长直线段；首领三规则划定边界

🧱 基本块（Basic Block）
只能从首句进入、末句离开的最长直线三地址码序列——块内控制流平凡，是优化的天然单位
🚩 首领规则（找块头）
① 第一条语句
② 任何跳转的目标语句
③ 紧跟跳转之后的那条语句
$$\text{每个首领} \rightarrow \text{下一首领之前} \;=\; \boldsymbol{\text{一个基本块}}$$
读法：块内直线到底、块间才有岔路；优化因此分两层——块内靠恒等变换，块间靠流图上的数据流分析。

板斧一

公共子表达式消除：算过且分量没变，就抄上次的答案

步骤发现动作为什么语义不变
1(5) t3=4*i 与 (3) 相同，之间 i 未改删 (5)，(6) 中 t3→t1同一个 i，同一个乘积
2(10) t8=4*i 同理，(3) 到 (10) i 未改删 (10)，(11) 中 t8→t1t3、t8 与 t1 此后处处等价
前提条件：从上次计算到这次使用之间，表达式的所有运算分量都没有被重新定值——只看字面相同是会出事的。
板斧二三

复写传播合并 t9/i，死代码收尾：B3 从 12 条瘦到 10 条

📋 复写传播（Copy Propagation）
x = y 之后，能用 y 的地方就不用 x；t9=i+1；i=t9 合并为 i = i + 1
🗑️ 死代码消除（Dead Code Elimination）
定值后再无人读＝死代码；t9 随复写传播消失，判活靠活跃性
$$\text{B3：} 12 \text{ 条} \;\longrightarrow\; \boldsymbol{10} \text{ 条（已消两次重复的 } 4*i \text{）}$$
三板斧共同套路：找一个「两处必相等」的事实 → 换掉一处 → 删掉变空的语句。每个变换背后都站着一个「为什么相等」的理由。
循环优化

t5=x+1 每次迭代都重算？三条前置条件全过，外提到前头块

循环不变式（Loop-Invariant）：运算分量在循环内都不改变；外提落脚的块叫前头块（Preheader）

  1. 所在块支配循环所有出口，或变量离开后不活跃 —— t5 在 B4 无人用 ✓
  2. 循环中该变量只有这一条定值 —— t5 只在 (7) 定值 ✓
  3. 运算分量的使用不来自循环内其他定值 —— x 在循环内无定值 ✓
$$\text{B1 变为：} i=0;\ \boldsymbol{t5 = x+1} \text{（只算一次）} \quad \text{B3 删 (7)}$$
跨块

全局消除多查两件事：支配 ＋ 到达定值相同

✅ 能消：(15) v = x+1 → v = t5
B1 支配 B4，且任何路径上 x 未被重定值——两次计算的运算分量同一定值
❌ 不能消：B4 若算 4*i
B3 里算 t1 时的 i 是循环内的值，到 B4 的 i 已是 n——分量来自不同定值
局部消除靠眼睛扫一个块；全局消除必须靠数据流分析查「到达定值」——9.5 节的主角提前登场。
总账

优化终点：循环体 7 条、每次迭代只剩 1 次业务乘法

块优化后代码说明
B1 前头块t5 = x+1; n4 = 4*n; t1 = 0外提＋削弱初始化，只算一次
B2if t1 ≥ n4 goto B4归纳变量消除后的循环判断
B3（7 条）t2=a[t1]; t4=b[t1]; t6=t4*t5; t7=t2+t6; a[t1]=t7; t1=t1+4; goto B2只剩 1 次乘法（业务本身）
B4v = t5全局公共子表达式的收获
$$\text{循环体 } 12 \text{ 条} \to \boldsymbol{7} \text{ 条，} 2 \text{ 次乘法} \to \boldsymbol{1} \text{ 次；} n{=}1000 \text{ 省约 } 5000 \text{ 条指令、} 1000 \text{ 次乘法}$$
推导

强度削弱：i 每轮加 1，4·i 就每轮加 4——乘法换加法

① 前头块初始化：进循环时 i = 0，故 t1 = 4·0 = 0

$$\text{前头块：} t1 = 4 \times i_0 = 0 \quad \text{（维护不变式 } t1 \equiv 4 \cdot i \text{）}$$

② 循环体删乘法：t1 = 4*i 处直接使用 t1 当前值

$$t2 = a[t1],\;\; t4 = b[t1],\;\; a[t1] = t7 \quad \text{（不再出现 } 4*i \text{）}$$

③ 循环尾补增量：i 增 1 ⟹ 4·i 增 4，加法跟上

$$i = i+1 \;\Rightarrow\; \boldsymbol{t1 = t1 + 4} \quad \text{（对迭代次数归纳可证 } t1 \equiv 4i \text{）}$$

收尾

判断改写到 t1 身上：i ≥ n ⟺ t1 ≥ n4，i 整个变死代码

$$i \ge n \;\Longleftrightarrow\; 4i \ge 4n \;\Longleftrightarrow\; \boldsymbol{t1 \ge n4} \quad \text{（前头块预计算 } n4 = 4*n \text{）}$$
  • 改写后 i 在循环内再无读者：i=0 与 i=i+1 成死代码，一并删除
  • B2 变为 if t1 ≥ n4 goto B4；循环判断、寻址都只在 t1 一个变量上进行
前提：步长为正、初值非负且不溢出时等价才成立；拿不准符号与范围，宁可不削。
定义

到达定值 ＝ gen/kill 局部事实 ＋ 一对前向方程

🌱 gen[B]
B 内生成、且块尾仍有效的定值
🔪 kill[B]
B 内对同一变量的重定值，把别处的定值杀掉
$$\boldsymbol{\mathrm{IN}[B] = \bigcup_{P\,\text{是}\,B\,\text{的前驱}} \mathrm{OUT}[P]} \qquad \boldsymbol{\mathrm{OUT}[B] = \mathrm{gen}[B] \cup (\mathrm{IN}[B] - \mathrm{kill}[B])}$$
读法：入口是所有前驱出口的并集；出口是自己新生的，并上「穿过来的」（入口里没被杀掉的那部分）。

两轮迭代到不动点：回边把 B3 的定值带回循环头

第一轮（初值全 ∅）：B1 出 {d1,d2} → B2 入 {d1,d2} → B3 出 {d3,d4} → B4 入 {d1,d2}

第二轮：B2 的 IN = OUT[B1] ∪ OUT[B3] = {d1,d2} ∪ {d3,d4} = {d1,d2,d3,d4}（回边起效）；B4 的 IN 同步变大；B3 的 OUT 不变

第三轮：所有集合不再变化 → 到达不动点，迭代结束

原则

活跃变量向后看；全章底线是保守原则

$$\text{活跃变量（后向）：} \mathrm{IN}[B] = \mathrm{use}[B] \cup (\mathrm{OUT}[B] - \mathrm{def}[B]),\quad \mathrm{OUT}[B] = \bigcup_{S\,\text{是后继}} \mathrm{IN}[S]$$
🧭 同一模子
局部事实（gen/kill 或 use/def）＋沿边「并/交＋传递」→ 迭代到不动点；方向与汇合运算一换就是新分析
🛡️ 保守原则
宁可不优化，不可改语义；分析说「也许被改」时优化器必须收手——这不是无能，是底线
避坑

三个真实误解：字面相同、无脑外提、跳转开块

❌ 两个表达式字面相同就能消
✅ 必须确认两次之间所有运算分量都未被重定值——先看分量变没变，再谈消不消。
❌ 循环不变式无脑外提总安全
✅ 循环可能一次不执行时，外提等于强制执行；「支配所有出口或不活跃」防的就是这类事故。
❌ 跳转语句自动开新块
✅ 开新块的是「跳转目标」和「跳转之后那条」；(14) goto (2) 只是 B3 块尾，不是首领。
