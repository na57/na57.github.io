Philosophy

设计理念

PIOC 围绕统一、智能、模块、安全四大核心理念，构建可扩展的个人数字化基础设施。

📡

统一数据中枢

整合 MySQL、MongoDB、RESTful API 等多源数据，通过统一的 Provider 适配层，将分散的数据汇聚为个人数字资产。

✨

AI 智能驱动

内置 AI Text-to-SQL 查询引擎与自然语言问答能力，让数据分析像对话一样简单，从数据中获取洞察。

🧩

模块化架构

抽象接口 + Provider 实现 + 工厂模式配置，每个应用模块独立开发、独立部署，按需插拔扩展。

🔐

安全可控

基于 JWT 的认证体系与 RBAC 权限模型，配合完整的操作审计日志，确保数据安全与访问可控。

应用矩阵

PIOC 涵盖系统管理、教学服务、资产管理、智能应用等六大类超过 20 个功能模块。

TC
教师中心
对接数据中台，汇聚教职工基本信息、教学工作量、教研成果、研究生导师等全景数据。
中台对接 数据聚合
CC
课程中心
研究生课程信息管理，支持课程详情、教材关联、授课安排等维度的数据查询与分析。
课程管理 教学数据
IT
IT 资产中心
信息系统、虚拟机、Web应用、DNS记录等 IT 资产全生命周期管理，支持合规巡检与拓扑可视化。
资产管理 拓扑图 合规巡检
IDC
IDC 机房管理
机房设备资产、机柜规划、设备类型配置与上下架审批流程管理。
设备管理 审批流程
DO
数据对象
面向非技术人员的数据查询与分析工具，通过自然语言对话完成复杂数据检索与可视化展示。
AI 问答 Text-to-SQL
LT
听力训练
基于艾宾浩斯遗忘曲线的听力复习计划，智能安排复习间隔，提升语言学习效率。
艾宾浩斯 学习工具
DS
数据源管理
统一管理 MySQL、MongoDB 等数据源的连接配置，支持应用级别的数据源切换与动态配置。
多源管理 动态配置
KM
密钥管理
RSA、ECC、EdDSA 等加密密钥的生成、存储与使用管理，保障系统通信与数据安全。
加密算法 安全基础设施
WX
企业微信集成
企业微信账号、应用与消息模板的统一管理，实现系统与企业微信生态的无缝对接。
第三方集成 消息推送
Technology

技术亮点

采用业界前沿技术栈与架构模式，兼顾开发效率与系统可扩展性。

⚡

Next.js 16 + React 19

基于最新版 Next.js App Router 构建，服务端组件与客户端组件混合渲染，首屏加载极速，SEO 友好。

🧠

AI Text-to-SQL 引擎

自然语言转 SQL 查询，内置 SQL 安全检查（仅 SELECT）、自动 LIMIT 限制与图表推荐，降低数据查询门槛。

🔀

Provider 多源适配

抽象数据接口 + 具体 Provider 实现，自动发现与加载。新增数据源只需实现接口即可零侵入接入。

🔐

JWT + RBAC 安全体系

无状态 JWT 认证配合基于角色的访问控制，支持应用级权限粒度，完整记录操作审计日志。

⚙️

工厂模式配置管理

createAppConfigBundle 工厂统一创建应用配置包，BaseDataService 基类提供通用能力，消除重复代码。

📊

ECharts 拓扑可视化

IT 资产中心内置力导向图引擎，支持节点拖拽、邻接高亮、层级展开，直观呈现系统资产关联关系。
