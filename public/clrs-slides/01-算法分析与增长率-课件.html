主线

一条链：秒表不可靠 → 先证对 → 再分情形 → 最后只看增长率

4扔掉常数与低阶项 → Θ / O / Ω 与增长率坐标系，一次论断对所有规模有效
这条链就是本章目录：1.1 动机 → 1.2 正确性 → 1.3 情形 → 1.4 记号 → 1.5 增长率。
动机

掐秒表比算法，有三个救不回来的缺陷

🖥️ 依赖机器与实现
换电脑、换语言、换编译器，结论可能反过来。
🎲 只测了有限输入
被测输入上快 ≠ 所有输入上快。
📈 测不出规模趋势
n=100 时 A 赢，n=10⁷ 时谁赢？只能重跑。
✅ 要的度量
与机器无关 · 对所有输入发言 · 预测大规模行为。
💡 满足这三条的度量 = 算法分析（Analysis of Algorithms）：先证对，再算阶。

逆序对（Inversion）：$i \lt j$ 且 $A[i] \gt A[j]$ 的位置对。每次右移消灭一个逆序对。

对决

$8n^2$ 与 $64n\lg n$ 的交叉点在 n=43/44：常数管小，增长率管大

n插入 $8n^2$归并 $64n\lg n$谁赢
328 × 1024 = 819264 × 32 × 5 = 10240插入（lg 32 = 5）
438 × 1849 = 1479264 × 43 × 5.426 ≈ 14932插入（lg 43 ≈ 5.426）
448 × 1936 = 1548864 × 44 × 5.459 ≈ 15373归并（lg 44 ≈ 5.459）
$$n \le 43\ \text{插入更快},\quad n \ge 44\ \text{归并反超};\qquad n=10^6:\ 8{\times}10^{12}\ \text{vs}\ 1.3{\times}10^{9}\ (\text{差约}\ 6300\ \text{倍})$$
⚠️ 渐进结论只对充分大的 n 发言——这也是很多语言标准库在短数组上回落到插入排序的原因。
定义

循环不变式 = 藏在循环里的数学归纳法，走三步

① 初始化（Initialization）
第一次迭代开始前命题成立 ≈ 归纳基础。
② 保持（Maintenance）
迭代前成立 ⟹ 迭代后仍成立 ≈ 归纳递推。
③ 终止（Termination）
循环结束条件 + 不变式 ⟹ 目标结论（循环特有）。
$$\text{不变式：每次迭代开始前都为真的命题}$$
读法：不变式是「每一步都对」的陈述；终止步把「每一步对」兑换成「最终结果对」。
⚠️ 测试只能证伪不能证实（Dijkstra）——正确性只能靠证明。
推导

插入排序正确性：三步各打一颗勾，结论自动落地

① 初始化：j = 2 时 A[1..j−1] = A[1..1] 只含一个元素，单元素天然有序。✓

② 保持：key 插在「第一个 ≤ 它的元素」之后 ⟹ A[1..j] 有序；移动只是重排，不丢不加。✓

③ 终止：j = n+1 时代入不变式 ⟹ A[1..n] 由原元素组成且已排好序 = 排序的定义。✓

$$\boldsymbol{\text{不变式：迭代前 } A[1..j{-}1] \text{ 由原元素组成且有序}}$$
❌ 不变式只写「A[1..j−1] 有序」 → ✅ 必须加上「由原元素组成」——否则每次写入 42 的程序也满足前者。

情形

最坏 $\frac{n(n-1)}{2}$、平均 $\frac{n(n-1)}{4}$：减半但还是平方级

$$T_{\text{最坏}}(n)=1+2+\cdots+(n-1)=\frac{n(n-1)}{2}=\Theta(n^2)$$
$$E[\text{逆序对}]=\binom{n}{2}\cdot\frac{1}{2}=\frac{n(n-1)}{4}$$
每对位置以 1/2 概率成逆序对（对称性），期望线性相加——不要求各对独立。

定义

Θ 上下夹、O 盖顶、Ω 铺底：$\Theta = O \wedge \Omega$

$$\boldsymbol{f(n)=\Theta(g(n)) \iff \exists\, c_1,c_2,n_0 \gt 0,\ \forall n \ge n_0:\ 0 \le c_1 g(n) \le f(n) \le c_2 g(n)}$$
$$f(n)=O(g(n)) \iff \exists\, c,n_0:\ 0 \le f(n) \le c\,g(n)$$

渐近上界：盖天花板

$$f(n)=\Omega(g(n)) \iff \exists\, c,n_0:\ 0 \le c\,g(n) \le f(n)$$

渐近下界：铺地板

💡 常数只要「存在」即可，不必最优——$\frac{1}{14}$ 这种丑数完全合法。$n_0$ 的意思是「等函数发育定型后再量」。
演练

手算 $\frac{1}{2}n^2-3n=\Theta(n^2)$：负低阶项靠「$n_0$ 取大」躲过

① 右半（找 c₂）：$-3n \le 0 \Rightarrow \frac{1}{2}n^2-3n \le \frac{1}{2}n^2$，取 $c_2=\frac{1}{2}$，对一切 $n\ge 0$ 成立。✓

② 左半（找 c₁ 与 n₀）：$c_1 \le \frac{1}{2}-\frac{3}{n}$；取 $c_1=\frac{1}{14}$，需 $\frac{3}{n}\le\frac{3}{7}$ 即 $n \ge 7$。✓

③ 边界验证 n=7：$c_1 n^2 = 3.5$，$f(7)=24.5-21=3.5$，$c_2 n^2=24.5$，确实 $3.5 \le 3.5 \le 24.5$ ✓

$$\boldsymbol{c_1=\tfrac{1}{14},\quad c_2=\tfrac{1}{2},\quad n_0=7 \;\Rightarrow\; \tfrac{1}{2}n^2-3n=\Theta(n^2)}$$
✍️

避坑

三个雷：记号 ≠ 情形、渐进不管小 n、平均必须有分布

❌ O 表示最坏、Ω 表示最好
✅ 记号谈的是函数的界，情形谈的是输入类别，两维独立。最好情形照样用 Θ（插入排序最好情形 Θ(n)）；n 也是 O(n²)。
❌ 平方级永远比 n lg n 慢
✅ n ≤ 43 时插入赢归并。Θ 只承诺「存在 n₀，超过后成立」，小规模的胜负由常数因子决定。
❌ 平均情形不需要分布假设
✅ 平均 = 对输入分布取期望。n(n−1)/4 依赖「均匀随机排列」这个假设，换分布结论就变。
