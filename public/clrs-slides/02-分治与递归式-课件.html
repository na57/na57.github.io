本章是 ① 分析基础 的收官：第1章给语言，本章给求解器；后面八章的复杂度推导都从这里取工具。

主线

一条阶梯：三段式 → 递归树猜 → 代入法证 → 主定理查表

1分治三段式：分 / 治 / 合 → 递归式 $T(n)=aT(n/b)+D(n)+C(n)$
2递归树：展开看每层代价与层数 → 猜出答案量级（直观但不严谨）
3代入法：猜上界 → 归纳验证 → 配常数与基例，把猜测变成证明
4主定理：$aT(n/b)+f(n)$ 查表判三种情形；缝隙回落递归树
这条阶梯的第 4 级有个缺口——主定理并非万能，本章最后一节专门处理缝隙。
动机

分治 = 分 + 治 + 合，代价写成 $T(n)=aT(n/b)+f(n)$

分（Divide）：切成 a 个规模 $n/b$ 的子问题，代价 $D(n)$
治（Conquer）：递归解子问题，规模到常数直接解
合（Combine）：拼回答案，代价 $C(n)$
$$T(n)=a\,T(n/b)+D(n)+C(n)$$
$$\text{归并排序：}\ T(n)=2T(n/2)+\Theta(n)$$
⚠️ 右边还有 T，不是封闭形式——不能直接代 n 求值，这就是「递归式」的麻烦。
样例

归并排序：每层合并都是 8c，一共 4 层

工具一

代入法三步：猜解 → 归纳 → 配常数（外加基例）

① 猜（Guess）：猜出 $T(n) \le c\,g(n)$ 的形式，带未知常数
② 归纳（Induct）：假设规模 $\lt n$ 时成立，代入递归式推出 $n$ 时成立
③ 配常数：把归纳中冒出的减项「吸收」进常数，取 $c$ 足够大
④ 查基例：归纳只能从 $n_0$ 往上推，起点必须单独验证
$$\text{猜：}T(n) \le cn\lg n \;\Rightarrow\; \text{证：}\forall n \ge n_0\ \text{成立}$$
⚠️ 代入法不提供「怎么猜」——猜错就重猜；但一旦证成，结论就是严格的。
推导

代入法证 $T(n)=2T(n/2)+n$：c ≥ 1 吸收减项，基例挪到 n=2

① 猜：$T(n) \le c\,n\lg n$（$c$ 待定）。

② 代入：$T(n) \le 2c\cdot\frac{n}{2}\lg\frac{n}{2}+n = c\,n(\lg n-1)+n = c\,n\lg n - c\,n + n$。

③ 吸收减项：只需 $-cn+n \le 0 \iff c \ge 1$，故 $T(n) \le c\,n\lg n$ ✓

④ 基例：$n=1$ 时 $c\cdot 1\cdot\lg 1=0$，而 $T(1)\ge 1$，夹不住 → 起点改 $n=2$：$T(2)=4 \le 2c$，取 $c \ge 2$。

$$\boldsymbol{c \ge 2,\ n_0=2 \;\Rightarrow\; T(n)=O(n\lg n)}$$
✍️
暂停推导

盖住第 ③④ 步：你能自己算出 c 的下界，并发现 n=1 的基例陷阱吗？

陷阱

基例翻车：$n=1$ 时 $c\,n\lg n=0$，永远夹不住 T(1)

$$n=1:\quad c\cdot 1\cdot\lg 1 = 0 \quad\text{但}\quad T(1)\ge 1$$
❌ $0 \ge 1$ 不成立 → 归纳在起点断裂，证明不闭合。
$$n=2:\quad T(2)=4 \le c\cdot 2\cdot\lg 2 = 2c \;\Rightarrow\; c \ge 2$$
✅ 修补：把 $n_0$ 挪到 2（或 3、10），有限个小规模单独处理；把 $c$ 调大覆盖它们。
这不是作弊——渐近分析只对充分大的 n 发言，$n_0$ 正是「等函数发育定型」的意思。
工具二

递归树算 $3T(n/4)+cn^2$：等比求和得 $\frac{16}{13}cn^2$

① 展开：根 $cn^2$；三个孩子各 $c\left(\frac{n}{4}\right)^2=\frac{cn^2}{16}$，合计 $\frac{3}{16}cn^2$。

② 层数：$n \to n/4 \to n/16 \to \cdots \to 1$，共 $\log_4 n$ 层。

③ 等比求和：公比 $\frac{3}{16}$，$\displaystyle\sum_{k\ge 0}\left(\frac{3}{16}\right)^k cn^2=\frac{cn^2}{1-\frac{3}{16}}=\frac{16}{13}cn^2$。

$$\boldsymbol{T(n) \le \frac{16}{13}cn^2 = O(n^2)}\quad\text{（取 } d=\tfrac{16}{13}c \text{，归纳即可严格化）}$$
层节点数单节点代价本层合计

13$cn^2/16$$\frac{3}{16}cn^2$
29$cn^2/256$$\left(\frac{3}{16}\right)^2 cn^2$
合计（等比）——$\frac{16}{13}cn^2$

判别

递归树只有三种剧情：层代价相等 / 递减 / 递增

剧情层代价形态总代价由谁支配例子
① 相等每层都是 $cn$叶子层 × 层数$T(n)=2T(n/2)+n \Rightarrow \Theta(n\lg n)$
② 递减公比 $\frac{3}{16} \lt 1$根（乘 $1/(1-r)=\frac{16}{13}$）$T(n)=3T(n/4)+cn^2 \Rightarrow O(n^2)$
③ 递增公比 $\gt 1$叶子$T(n)=3T(n/2)+n \Rightarrow \Theta(n^{\lg 3})$
判别动作统一：算相邻两层的比值。常数 → 乘层数；小于 1 → 等比收敛到根；大于 1 → 看叶子。
💡 主定理就是把这三张脸背成三个公式——下一页直接查表。
工具三

主定理：拿 $n^{\log_b a}$ 当分水岭，比出三种情形

$$T(n)=a\,T(n/b)+f(n),\qquad a\ge 1,\ b \gt 1,\qquad \text{分水岭 } n^{\log_b a}$$
情形条件结论直觉
1$f(n)=O(n^{\log_b a-\epsilon})$，$\epsilon \gt 0$$T(n)=\Theta(n^{\log_b a})$叶子主导
2$f(n)=\Theta(n^{\log_b a})$$T(n)=\Theta(n^{\log_b a}\lg n)$每层同价
3$f(n)=\Omega(n^{\log_b a+\epsilon})$ 且 $a f(n/b)\le c f(n),\ c \lt 1$$T(n)=\Theta(f(n))$根主导
⚠️ 「多项式因子」指差 $n^{\epsilon}$；只差一个 $\lg n$ 不算，三扇门会同时关上。
查表

三个数值例：情形一、二、三各打一发

递归式分水岭 $n^{\log_b a}$与 $f(n)$ 比情形结论
$T(n)=9T(n/3)+n$$n^2$$n$ 小一个因子1$\Theta(n^2)$
$T(n)=T(2n/3)+1$$n^0=1$同阶2$\Theta(\lg n)$
$T(n)=3T(n/4)+n\lg n$$n^{\log_4 3}\approx n^{0.79}$$n\lg n$ 大一个因子3$\Theta(n\lg n)$
情形二的直觉：$T(n)=T(2n/3)+1$ 的规模每层缩到 2/3，缩到 1 要 $\log_{3/2} n$ 层 ≈ 1.7 lg n，故 $\Theta(\lg n)$。
💡 主定理的三种情形，就是上页递归树三种剧情的公式化。
缝隙

$2T(n/2)+n\lg n$：三扇门同时关上

$$T(n)=2T(n/2)+n\lg n,\qquad n^{\log_2 2}=n,\qquad f(n)=n\lg n$$
情形要求本例通过？
1$f(n)$ 比 $n$ 小一个多项式因子$n\lg n$ 反而更大❌
2$f(n)=\Theta(n)$差一个 $\lg n$，不同阶❌
3$f(n)$ 比 $n$ 大一个多项式因子只大 $\lg n$，不够 $n^{\epsilon}$❌
❌ 三扇门全关 ≠ 无解，只是主定理不发言。正确动作：回递归树，自己动手。
缝隙

回递归树：第 i 层代价 $n\lg n - i\,n$，等差求和得 $\Theta(n\lg^2 n)$

层 i子问题数单个代价本层合计
01$n\lg n$$n\lg n$
12$\frac{n}{2}\lg\frac{n}{2}$$n\lg n - n$
24$\frac{n}{4}\lg\frac{n}{4}$$n\lg n - 2n$
$\lg n$$n$常数≈ 0
$$\sum_{i=0}^{\lg n}\big(n\lg n-i\,n\big)=\frac{\lg n}{2}\cdot n\lg n=\Theta(n\lg^2 n)$$
层代价等差递减（每次少 n），不是几何递减——所以总代价是「层数 × 中间层代价」，多出一个 lg 因子。
避坑

三个雷：主定理万能、猜错也证、基例不管

❌ 主定理万能
✅ 只覆盖多项式差距；$f(n)=n\lg n$ 这类卡中间的例子三扇门全关，须回递归树手算。
❌ 猜错了也能证出来
✅ 归纳顺着猜测走：猜 $O(n^2)$ 当然证得出 $O(n^2)$，但那不是紧界。先猜紧的，证不出再放松。
❌ 基例可以不管
✅ $n=1$ 时 $c\,n\lg n=0$ 必然夹不住，起点必须挪到 $n\ge 2$ 并单独验证。
⚠️ 情形三别漏正则条件 $a f(n/b) \le c f(n)$（$c \lt 1$），否则可能得出错误结论。

小结

三句话讲完第2章

1解决什么：分治时间 = 递归式，右边自引用，要求封闭形式 → 三件工具
2核心机制：递归树猜（相等乘层数 / 递减跟根 / 递增看叶）→ 代入法证 → 主定理查表

$$\boldsymbol{T(n)=aT(n/b)+f(n)\ \text{对比}\ n^{\log_b a}:\ \text{小}\Rightarrow\Theta(n^{\log_b a});\ \text{同}\Rightarrow\Theta(n^{\log_b a}\lg n);\ \text{大}\Rightarrow\Theta(f(n))}$$
