问题

11 个活动争一间教室：贪心规则只有一句「选结束最早且兼容」

活动 $i$ 占用区间 $[s_i, f_i)$，选最多的互不重叠活动（已按结束时间排序）：

$i$1234567891011
$s_i$130535688212
$f_i$4567991011121416
💡 贪心 = DP 的特权版：有贪心选择性质时，每步只看一个分支，表都不用填。排序 $\Theta(n\log n)$ + 扫描 $\Theta(n)$。
手算

顺一遍：{a₁, a₄, a₈, a₁₁} 共 4 个，就是最优

① 选 a₁（结束 4）：a₂ 开始 3、a₃ 开始 0，均早于 4，跳过。

② 选 a₄（开始 5 ≥ 4，结束 7）：a₅、a₆、a₇ 开始 3、5、6，均早于 7，跳过。

③ 选 a₈（开始 8 ≥ 7，结束 11）：a₉、a₁₀ 开始 8、2，均早于 11，跳过。

④ 选 a₁₁（开始 12 ≥ 11，结束 16）。

$$\text{结果 } \{a_1, a_4, a_8, a_{11}\},\ \text{共 } \boldsymbol{4} \text{ 个活动} \;=\; \text{最优}$$

反例

三个「看似合理」的直觉规则全部阵亡——直觉不值钱，证明才算数

❌ 选开始最早的
✅ 反例：一个占满全天的活动开始最早，选了它，其余活动全部泡汤。
❌ 选时长最短的
✅ 反例：短活动卡在两个长活动中间，选它同时挤掉两个本来兼容的活动。
❌ 选冲突最少的
✅ 反例可构造：冲突最少的活动恰好挡在关键位置，选了它总数反而变少。
只有「结束最早」活下来——贪心规则必须过交换论证这一关，直觉一分不值。
证明

交换论证四步：把最优解改造成贪心解，且不变差

① 任取最优解 OPT：设 a₁ 结束最早，OPT 中最早结束的是 aₖ。

② 找第一个分歧：若 aₖ 就是 a₁，得证；否则 $f_1 \le f_k$（a₁ 结束最早）。

③ 交换：把 OPT 中的 aₖ 换成 a₁——其余活动都在 fₖ 之后开始，故与 a₁ 兼容；解仍合法、大小不变。

④ 归纳：剩余活动构成同构子问题，配合最优子结构递推到底。

$$\boldsymbol{\exists}\ \text{包含贪心选择的最优解} \;\Rightarrow\; \text{贪心安全（只需「不差」，不求「一样好」）}$$

推广

拟阵 = 遗传性 ＋ 交换性：Kruskal 正确的深层原因

🧬 遗传性（Hereditary）
独立集的子集仍独立——如同线性无关向量组，拿掉几个向量仍无关。
🔄 交换性（Exchange）
$|A| \lt |B|$ 时，A 总能从 B 借一个元素扩充——小的无关组总能从大的补向量。
$$\text{独立集构成拟阵} \;\Rightarrow\; \text{按权重贪心选取} \boldsymbol{\text{恒最优}}$$
读法：拟阵上贪心被统一证明最优——第7章 Kruskal 对，是因为无环边集恰是拟阵。懂拟阵不为证明更快，而为知道「贪心何时一定有救」。
问题

Huffman：把「编码问题」翻译成「树的代价问题」

6 个字符的频率（千次），设计前缀码（Prefix Code：任何码字不是另一码字的前缀）使总码长最小：

字符abcdef
频率4513121695
前缀码 ⇔ 二叉树：左枝读 0、右枝读 1，根到叶的路径就是码字。
$$\min \sum_{c} f(c)\cdot \mathrm{depth}(c)$$
直觉：常见字符给短码、生僻字符给长码——莫尔斯电码的严格最优版。贪心对象从「选哪个」变成「合并哪两个」。

动机

最坏一次 O(n) 的操作，对外到底该报价多少？

动态表（vector / ArrayList）容量满时翻倍扩容，一次插入要搬移全部旧元素：

插入次序12345…9…
本次代价12315…9…
😇 按最坏报 O(n)
太悲观：扩容很稀少，绝大多数插入只是写一格。
🙂 按最好报 O(1)
不诚实：扩容那次真的要搬一整张表。
💡 摊还分析：对任意操作序列的总代价取上界，再平摊到每次操作——接下来三本账各算一遍。
账法一

聚合分析：总算账 ÷ 操作数 ＝ 3

n 次插入：自身代价共 n；扩容复制量是等比数列 $1+2+4+\cdots$，总和小于 $2n$：

$$\text{总代价} = n + \sum_{j=0}^{\lfloor \lg n\rfloor} 2^j \;\lt\; n + 2n = 3n \;\Rightarrow\; \text{每次插入摊还 } \boldsymbol{3}$$
验证 n = 9：$9 + (1+2+4+8) = 24 \lt 27 = 3\times 9$ ✓　——全程无概率，对最坏插入序列同样成立。
账法二

记账法：每次插入预收 3 元，扩容时存款刚好付清搬移费

1第 1 元：付本次插入本身（现收现付）。
2第 2 元：存起来，付「自己将来被搬移」的费用。
3第 3 元：存给表里某个老元素，付「它将来被搬移」的费用。
扩容时刻对账：一半新元素自带存款付自己，另一半老元素靠新一轮插入存的第 3 元支付——收 3 支 3，账永远平衡，故摊还代价 $= 3$。
账法三

势能法：势能存进结构状态里，两种情形都算出 3

$$\Phi(T) = 2\cdot num - size,\qquad \hat{c} = \text{实际代价} + \Delta\Phi$$
  • 不扩容的插入：$\hat{c} = 1 + 2 = \boldsymbol{3}$（势能 +2 存进表里）。
  • 触发扩容的插入（$num = size = k$）：实际代价 $k+1$，$\Phi$ 从 $k$ 降到 $2$，$\hat{c} = (k+1) + (2-k) = \boldsymbol{3}$（势能释放付搬移）。
⚠️ 增长方式决定生死：每次只加固定大小（如 +100）→ 总代价 $\Theta(n^2)$、摊还 $\Theta(n)$；任何大于 1 的固定倍率都行，1.5 倍扩容摊还约 4，仍是常数。$\Phi \ge 0$ 且初值为 0，故摊还是实际总代价的上界。
辨析

摊还 ≠ 平均：一个对最坏序列打包报价，一个对随机输入取期望

维度摊还代价（Amortized）平均情况代价（Average-Case）
是否涉及概率完全不涉及对输入分布取期望
保证对象任何操作序列的总代价上界随机输入下的期望代价
最坏序列依然成立（动态表连插 n 次 ≤ 3n）不成立（快排坏划分退到 $\Theta(n^2)$）
典型例子动态表插入摊还 O(1)快排平均 $O(n\log n)$
证明工具聚合 / 记账 / 势能概率期望（第1、3章）
自检口径：「任意操作序列总代价 ÷ 操作数」用摊还；依赖「输入随机 / 哈希随机」用期望。
避坑

本章三个最容易踩的坑

❌ 「直观的贪心规则都行」
✅ 开始最早、时长最短、冲突最少全部有反例，只有「结束最早」活下来——规则必须过交换论证，直觉一分不值。
❌ 「交换论证要证交换后一样好」
✅ 只需证「不差」：我们要的只是「存在」含贪心选择的最优解，不要求所有最优解都长这样。
❌ 「扩容怎么扩都行」
✅ 每次 +100 的固定增量 → 摊还 $\Theta(n)$；倍率 ＞ 1 才是常数摊还（1.5 倍 ≈ 4）。口诀：倍率是命根，增量是灾难。

小结

三句话讲完第9章

1解决什么：何时局部最优就是全局最优（贪心）；代价剧烈波动时如何公平计价（摊还）。
2核心机制：贪心 = 贪心选择性质 + 最优子结构，交换论证证安全（{a₁,a₄,a₈,a₁₁}、224 千位）；摊还 = 聚合 / 记账 / 势能三本账（每次插入摊还 3）。
3承上启下：DP 是保守通解，贪心是特权快解，摊还是成本会计——Ch10 处理两者都失败的 NP 难。
$$\hat{c}_i = c_i + \Delta\Phi_i,\quad \Phi = 2\cdot num - size \;\Rightarrow\; \hat{c} = \boldsymbol{3} \quad\text{——合上书也要能默写}$$
