主线

从「怎么存」到「时间戳变现」，一条五环因果链

1现实关系是一张网 → 先解决怎么存：邻接表 vs 邻接矩阵的三笔账
2存好了就要系统地走遍全图：不漏、不重
3两种走法：BFS 按层推进得最少边数；DFS 钻到底留下时间戳
4时间戳变现：完成时间逆序 = 拓扑序；两遍 DFS = 强连通分量
5看清边界：本章边无权，只回答结构问题 → 带权留给第 7 章
这条链对应小节：6.1 存图 → 6.2 BFS → 6.3 DFS → 6.4 拓扑排序 → 6.5 强连通分量。
动机

同样一张稀疏图，两种存法差出两个数量级

一个稀疏图：$|V|=1000$ 个顶点、$|E|=5000$ 条边（社交网络、网页链接里很常见）。

$$\text{矩阵： } V^2 = 10^6 \text{ 项} \qquad\text{对}\qquad \text{表： } V+E \approx 6\times 10^3 \text{ 项}$$
🗒️ 邻接矩阵：两两打勾的点名册
一百万个格子里 99.5% 是 0；遍历邻居还要扫整行 1000 格
📇 邻接表：按人存的通讯录
只记真实存在的约 6000 条边；链上有几个邻居就看几个
💡 本章方案：默认用邻接表，遍历算法复杂度才压得住。
定义

图 = 顶点集 ＋ 边集；存法 = 邻接表 或 邻接矩阵

📇 邻接表（Adjacency List）
数组 Adj，Adj[u] 装 u 的全部出边终点——按人存的通讯录
🗒️ 邻接矩阵（Adjacency Matrix）
$|V|\times|V|$ 的 0-1 矩阵，M[u][v]=1 当且仅当 (u,v) 是边——两两打勾的点名册
$$\text{邻接表空间 } \boldsymbol{\Theta(V+E)},\qquad \text{邻接矩阵空间 } \boldsymbol{\Theta(V^2)}$$
读法：稀疏图（边远少于顶点平方）用表；稠密图或要频繁回答「u、v 之间有没有边」用矩阵。

6.1

三笔账一算，遍历算法的默认输入就是邻接表

代价项邻接矩阵邻接表
空间$\Theta(V^2)$：1000×1000 = $10^6$ 项 ≈ 1MB$\Theta(V+E)$：约 6000 项，省两个数量级
查一条边 (u,v)$O(1)$：直接读 M[u][v]$O(\deg(u))$：扫 u 的整条链，平均 5
遍历 u 的全部邻居$O(V)$：扫整行 1000 项，哪怕只有 5 个 1$O(\deg(u))$：链上有几个看几个
无向图附加账矩阵对称，浪费一半每条边存两份共 2|E| 项，仍 $\Theta(E)$
BFS/DFS 的主循环都是「扫邻居」——矩阵把这一步从 $O(\deg)$ 拖成 $O(V)$，整体从 $\Theta(V+E)$ 恶化成 $\Theta(V^2)$。所以本章默认邻接表。
6.2

BFS 像涟漪按层扩张：颜色 ＋ 队列 ＋ d 和 π

🎨 三色标记
白 = 未发现；灰 = 已发现未处理完；黑 = 已处理完
🥇 先进先出队列
先发现先处理，保证按层推进、不插队
🏷️ 每个顶点记两值
d = 从 s 出发的边数；π（前驱 Predecessor）= 被谁发现
规则一句：队首取 u 扫 Adj[u]，遇白色邻居 v 就涂灰、记 d[v]=d[u]+1、π[v]=u、入队；u 扫完涂黑。

广度优先搜索（Breadth-First Search, BFS）：先访问距离 1 的，再访问距离 2 的……

6.2

队列层单调 ⇒ 首次发现即最少边数，总代价 Θ(V+E)

✅ 为什么 d 一定最少：队列任意时刻至多跨两层，第 k 层先于第 k+1 层出队——所以 v 第一次被发现时，走的边数已是所有可能里最小的。这是 BFS 一切结论的地基。
$$d[v] = \text{从 } s \text{ 到 } v \text{ 的最少边数（无权图的最短路径，Shortest Path）}$$
$$\text{BFS 时间 } \boldsymbol{\Theta(V+E)}\ \text{（顶点入出队各一次 + 每条边查一次，邻接表下）}$$
6.3

DFS 一路钻到底，值钱的产物是两个时间戳

🕐 发现时刻 d
第一次碰到这个顶点的时刻——涂灰的瞬间
🕑 完成时刻 f
邻接表扫完、收工回溯的时刻——涂黑的瞬间
$$\text{时钟从 1 起，每次「发现」或「完成」} +1 \;\Rightarrow\; n \text{ 个顶点共 } 2n \text{ 个时刻}$$
直觉：每个顶点的 (d, f) 是一个区间；区间的包含关系 = 祖先与后代的关系。时间戳（Timestamp）是图结构的 X 光。

括号化定理（Parenthesis Theorem）：任意两顶点的区间 [d, f] 要么完全不相交，要么一个完全包含另一个，包含者恰是祖先。验证：s[1,12] 包含一切；a[2,5] 包含 c[3,4]；b[6,11] 与 a[2,5] 完全分离。
6.3

四种边：看终点颜色，再比两个发现时刻

类型判定（遍历 u→v 的瞬间）含义
树边（Tree Edge）v 白色首次发现 v，进入 DFS 树
回边（Back Edge）v 灰色v 是 u 的祖先 ⇒ 存在环
前向边（Forward Edge）v 黑色，且 d[v] 大于 d[u]v 是 u 的后代（非树边）
横向边（Cross Edge）v 黑色，且 d[v] 小于 d[u]v 在另一棵子树或另一棵树
⚠️ 四分类只对有向图完整成立：无向图的 DFS 只有树边和回边。
6.3

G 的 9 条边逐条归案：5 树边、2 回边、1 前向、1 横向

6.3

判环只需一次 DFS：回边 ⟺ 有向图有环

$$\text{有向图有环} \;\boldsymbol{\iff}\; \text{DFS 发现回边（指向灰色祖先的边）}$$
⇐ 有回边 u→v（v 灰色祖先）：树上本有 v 到 u 的路径，加上这条回边即闭合成环。
⇒ 有环：环上最早被发现的顶点，在未完成时必被环上的前驱指到——那时它是灰色，那条边必是回边。
代价 $\Theta(V+E)$：死锁检测、依赖环检查都用它。
6.4

拓扑排序 = 跑一遍 DFS，按完成时间从大到小排

前提：约束图是有向无环图（Directed Acyclic Graph, DAG）；所求：拓扑排序（Topological Sort）——每条边 u→v 都有 u 排在 v 前。

$$\text{拓扑序} = \text{DFS 完成时间 } \boldsymbol{f} \text{ 的逆序}$$
正确性一句：DAG 无回边，任何边只是树/前向/横向边，三种都满足 f[u] 大于 f[v]。

6.5

Kosaraju：两遍 DFS，把任意有向图缩成 DAG

强连通分量（Strongly Connected Components, SCC）：互相可达的极大顶点集；捏成点后得到的分量图一定是 DAG。

① 第一遍：在 G 上跑 DFS，记录每个顶点的完成时间 f
② 第二遍：构造转置图（Transpose Graph）$G^T$（所有边反向），按 f 从大到小做 DFS——每棵树 = 一个分量

避坑

三个最常见的雷：矩阵迷信、带权误会、四边泛化

❌ 矩阵查边 O(1)，所以矩阵总是更好
✅ 遍历的主循环是「扫邻居」：矩阵把它从 $O(\deg)$ 拖成 $O(V)$，整体从 $\Theta(V+E)$ 恶化成 $\Theta(V^2)$——$|V|=10^5$ 时 $10^{10}$ 次操作跑不完。
❌ BFS 求的是最短路，带权图也能用
✅ 本章边无权，d 是边数不是权重和；边带权时「层数少」不等于「代价小」，那是第 7 章 Dijkstra 的事。
❌ 四种边到处都有
✅ 前向边、横向边只在有向图出现；无向边双向可达，任何非树边都指向祖先——无向图只有树边和回边。

小结

三句话讲完第6章

1解决什么：图怎么存、怎么走遍，走一遍顺带算出最少边数、环、拓扑序、强连通分量
2核心机制：BFS 按层扩张得最少边数；DFS 留下时间戳，边分类、拓扑排序、SCC 全从时间戳读出
3承上启下：本章边无权只答结构问题；第 7 章加边权求最短路与最小生成树
$$\text{BFS 与 DFS 的时间都是 } \boldsymbol{\Theta(V+E)} \quad\text{——合上书也要能默写}$$
