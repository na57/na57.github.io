# PGM 课件制作规范

> 用途：本规范 + `assets/deck-template.html` 是 PGM 全套 23 章 HTML 课件的唯一制作依据。
> 任何后续会话制作新章节时：复制模板 → 按本规范填内容 → 写完对照「自检清单」。
> 样板课件：`../03-贝叶斯网络-课件.html`（第3章，18页）。

---

## 〇、三条最容易走样的红线（先看这个）

1. **每页只讲一个论点，标题必须是「结论句」**——禁止「3.2 概述」「定义与性质」这类名词性标题。正确示范：「链式法则按图砍掉多余条件，就是因子分解」。
2. **旁白写在 `data-narration` 属性里，口语化，且禁止半角双引号 `"`**。这是视频流水线的唯一旁白来源；半角引号会截断 HTML 属性导致整页旁白丢失。引用一律用「」。
3. **内容不溢出舞台**：单页内容 bottom 不得超过 676px（720 − 44 页脚余量）。mermaid 图必须用 `.mmd` 容器限高；公式行数多时用 `\text{}` 把引导句并进公式块省高度。写完用无头浏览器逐页量 `getBoundingClientRect().bottom`。

## 一、技术选型（不许更换）

| 项 | 选型 | 说明 |
|---|---|---|
| 文件形态 | **单文件 HTML**，双击可开 | 不引外部 CSS/JS（除下述两项） |
| 舞台 | `#stage` 固定 **1280×720**，`transform: translate(-50%,-50%) scale(s)` 等比缩放 | `s = min(窗口宽/1280, 窗口高/720)`，resize 时重算 |
| 底色 | 页面底 `#0f172a`（深色），舞台白底 `#ffffff`，阴影 `0 0 40px rgba(0,0,0,.4)` | |
| 翻页 | `← / → / 空格 / PageUp / PageDown / Home / End` + 点击左右半屏 + 右下圆钮 | 推导页内：翻页键先推进 `.step`，步尽才翻页 |
| 直达参数 | `?slide=N` 跳到第 N 页；`&autohide=1` 隐藏进度条/页脚/导航，且强制显示全部 `.step` | 视频截图流水线依赖此参数 |
| 公式 | MathJax v3 **本地引用** `assets/tex-svg.js`（tex-svg 全量单文件组件，约 2MB，自带字体数据），配置见模板 `<head>` | 断网/file:// 均正常；扩展宏按需自动加载 `assets/input/tex/extensions/*.js`（当前已含 `cancel.js`、`boldsymbol.js`、`enclose.js`），**新增宏若报 `ERR_FILE_NOT_FOUND`，从 jsdelivr 同名路径下载补齐该目录** |
| 图示 | **一律 mermaid**（用户全局规则），本地引用 `assets/mermaid.min.js`（相对路径，离线可用），`startOnLoad:false` + **激活时懒渲染** | 版本与讲义一致（PGM讲义/assets/mermaid.min.js 的拷贝）；懒渲染实现见模板 JS，勿改回 startOnLoad |
| 字体栈 | `-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "WenQuanYi Micro Hei", sans-serif` | |
| 主色板 | `--primary:#1a365d; --accent:#2b6cb0; --accent-light:#ebf8ff; --warning:#dd6b20; --warn-bg:#fffaf0; --success:#38a169; --danger:#e53e3e` | 全套课件统一，不随章节换色 |

### MathJax 配置（逐字照抄模板）

```javascript
window.MathJax = {
  tex: { inlineMath: [['$','$'],['\\(','\\)']], displayMath: [['$$','$$'],['\\[','\\]']],
         processEscapes: true, tags: 'none' },
  svg: { fontCache: 'global', scale: 1.05 },
  options: { skipHtmlTags: ['script','noscript','style','textarea','pre','code'] }
};
```

### mermaid 初始化 + 懒渲染（逐字照抄模板，勿改回 startOnLoad:true）

```javascript
mermaid.initialize({ startOnLoad: false, theme: "base",
  themeVariables: { primaryColor:"#ebf8ff", primaryBorderColor:"#2b6cb0",
    primaryTextColor:"#1a365d", lineColor:"#718096",
    fontFamily:"-apple-system, PingFang SC, sans-serif", fontSize:"15px" },
  flowchart: { curve: "linear", htmlLabels: false } });

// 页面激活时才渲染该页的图，data-done 防重复（隐藏页 display:none 时渲染会得到 0 宽高退化 SVG）
function renderMermaid(slide){
  if (typeof mermaid === 'undefined') return;
  const nodes = Array.from(slide.querySelectorAll('.mermaid:not([data-done])'));
  if (!nodes.length) return;
  nodes.forEach(n => n.setAttribute('data-done', ''));
  mermaid.run({ nodes }).catch(() => nodes.forEach(n => n.removeAttribute('data-done')));
}
// render() 翻页函数末尾调用：renderMermaid(slides[idx]);
```

## 三、组件清单（class 名固定，新组件先加到模板再用）

| 组件 | class | 用途 |
|---|---|---|
| 结论式标题 | `.slide-head > .sec + h3` | 徽章（节号/角色）+ 一句话结论 |
| 普通公式 | `.formula` | 过程公式 |
| 结论公式 | `.formula.formula-concl` | 本章要记住的最终公式（橙） |
| 提示框 | `.tip`（蓝）/ `.deep`（绿，洞察/口诀）/ `.warn`（橙，警告） | 补充说明 |
| 误区框 | `.trap`（红） | 「❌ 误解 → ✅ 纠正」格式 |
| 推导分步 | `.step` | 互动模式默认隐藏，空格/→ 逐步 `.on`；autohide 模式全显 |
| 暂停互动 | `.pause` | ✍️ 图标 + 「暂停推导」；配合旁白中的触发句（见五） |
| 双栏 | `.cols > .col` | 对比、图+表、图+文字 |
| 因果链 | `.chain > .link(.no+.txt)` | 编号圆圈 + 一行一环的主线链 |
| 图容器 | `.mmd(.mmd-sm/.mmd-tall) > .mermaid` ＋可选 `.cap` 图注 | mermaid 一律放容器里限高 |
| 封面/结束页 | `.slide.slide-cover`（kicker/h1/sub/divider/question/meta） | 首尾各一页 |

## 四、内容范式

### 页数与骨架
- **18–26 页/章**。按「讲解节奏」切页，不按讲义小节切。
- 标准骨架（可按章微调，但 ★ 项必须出现）：
  1. ★ 封面：章号+章名+一句「本章要回答的问题」（`.question` 框）
  2. ★ 全书位置：一页 mermaid 全局链图，当前章高亮（`classDef here`）
  3. ★ 本章主线：`.chain` 因果链，一条线，不写并列清单
  4. 动机页：用一个具体例子逼出「为什么需要本章」
  5. ★ 核心定义页：定义 = 部件拆解（常双栏：图+表/图+式）
  6. ★ 一条完整手算/推导演示：`.step` 分步，每步一行解释（全章选最能代表本章方法的一条）
  7. 重点难点页（如反直觉概念单独一页深挖）
  8. ★ 误区页：1–3 个真实误解 + 为什么错（`.trap`）
  9. 与相邻章的接口页：一句话钩子
  10. ★ 小结页：三句话讲完本章 + 一句「下一章为什么存在」
  11. ★ 结束页（`.slide-cover`）：毕业挑战清单 + 下一章预告
- **不写「目录页/章节列表页」**——课件是能讲的内容，不是讲义的目录复读。

### 什么坚决不上幻灯片
- 讲义的回忆卡片、分层习题、复习计划、自测题（那是讲义的学习闭环，不是讲台内容）
- 超过 2 层的嵌套列表；超过 8 个节点的 mermaid 图；超过 6 行的表格正文
- 大段定义原文（定义拆成「部件卡片 + 一句读法」）

## 五、旁白范式（写进每页 `data-narration`）

| 项 | 规范 |
|---|---|
| 时长 | 每页讲 40–60 秒 ≈ **180–280 字**；全章合计 15–20 分钟 |
| 口吻 | 中文口语、第一人称（「我们看」「你注意到」），讲人话，不念定义原文 |
| 开头 | 承接上页：「到这里……」「前面说了 X，现在……」；封面页先问好并抛出本章问题 |
| 过渡 | 结尾常带一句钩向下一页：「……这就是下一页要讲的」「先记住它的长相」 |
| 公式 | **写口语读法，不写 LaTeX**：写「P D 乘 P I 乘……」「二的一百次方」，不写 `P(D)`（TTS 会把括号念坏）；符号下标读「v 零」「x 一」 |
| 引号 | **禁止半角 `"`**（截断属性）；用「」 |
| 互动停顿 | 手算页需要视频留白时，在旁白中部写触发句「先暂停视频自己推一遍。**推出来了吗？**好，对答案……」——流水线按此正则把该页音频拆成 a/停顿/b 三段。每章 1–2 处即可，别滥用 |

## 六、视频流水线兼容要求（对接 make-explainer-video 技能，逐条硬性）

1. 每页必须是 `<section class="slide" data-narration="...">`，旁白只放这个属性里，别放隐藏 div。
2. `data-narration` 内禁止半角双引号 `"`。
3. 必须支持 `?slide=N&autohide=1`：截图脚本靠它逐页打开、隐藏导航并显示全部 `.step`。
4. 舞台固定 1280×720，截图视口 1920×1080（scale=1.5）——不要在 autohide 模式下留白边：舞台居中缩放逻辑保持不变即可。
5. 同一 display 公式块里不能有两个 `\tag{}`，编号改用 `\;\;(1)` 内联。
6. 推导页高度紧张时，用 `\text{}` 把引导句并入公式块，而不是加新段落。
7. mermaid 与 MathJax 均为**本地引用**（`assets/`），课件在 file:// 与断网下必须完整可用；mermaid 必须 `startOnLoad:false` + 页面激活时 `mermaid.run({nodes})` 懒渲染（隐藏页 `display:none` 时渲染会得到 0 宽高的退化 SVG）。
8. 交付前自检：抽取脚本 `extract_narration.py 课件.html -o build/ --expect <页数>` 必须通过且段数 = 页数。

## 七、常见坑（踩过的，别再踩）

- **单页塞两个论点** → 页数超了就拆页，别压缩。页数上限 26 是保护线。
- **标题写成名词短语**（「d-分离简介」）→ 必须是结论句（「所有路径只有三种基本单元，各有通断规则」）。
- **mermaid 图溢出**：单图 >8 节点或svg高度>330px 时拆成 `.mmd-row` 多小图；三结构类并列图用三个独立 `.mermaid` 块横排。
- **mermaid 隐藏页渲染出 0 宽高退化图**（2026-11 第3章真踩过）：`startOnLoad:true` 会在加载时统一渲染全部 `.mermaid`，而非首页都是 `display:none`、容器宽高为 0 → 生成 18×18 的退化 SVG，用户双击打开从头翻页时图全是空的。修法固定为：`startOnLoad:false` + 翻页激活时对该页调 `mermaid.run({nodes})`（见上方代码），配 CSS `.mmd .mermaid{visibility:hidden}` / `[data-done]{visibility:visible}` 防源码闪现。
- **mermaid 横向链图缩成一条线**：`.mermaid` 是 flex 子元素会 shrink-to-fit，必须写 `.mmd .mermaid{width:100%}`（模板已内置，勿删），否则 LR 长链渲染成几像素高的细条。
- **MathJax 本地化后公式不渲染**（同一批踩过）：`tex-svg.js` 本体本地加载成功，但 `\cancel`、`\boldsymbol` 等扩展走 autoload 按需动态请求 `assets/input/tex/extensions/*.js`（cancel 还会再依赖 enclose），缺文件就整个公式页静默不渲染、露出 LaTeX 源码。处理流程：DevTools Network 里看到 `ERR_FILE_NOT_FOUND` → 从 jsdelivr `mathjax@3/es5/input/tex/extensions/同名.js` 下载补齐 → 断网复测。
- **验证用 `?slide=N` 直达，漏掉双击场景**（本次 bug 没被发现的原因）：直达时被测页恰好是加载时唯一可见页，mermaid 渲染有真实宽高，掩盖了隐藏页 0 宽高问题。**交付验证必须 file:// 双击场景逐页翻阅**（从第1页按 → 翻到最后，每页停留截图），只跑 `?slide=N` 或 http 服务都不算数。
- **公式溢出**：display 公式块最多 2 行；放不下就拆成「过程 .formula + 结论 .formula-concl」两块。
- **旁白写成书面语**：自检方法——读一遍，如果出现「亦即」「综上」「由定义可知」，重写。
- **旁白念符号串**：`P(G|D,I)` 要写成「给定 D 和 I 时 G 的概率」，禁止让 TTS 念字母串。
- **step 页忘记 autohide 全显**：`.step` 的 CSS 强制规则（`body.autohide .step{opacity:1 !important}`）不可删，否则截图截到半成品。
- **改讲义原意**：符号、数值、例子、结论必须与 `PGM讲义/chapter-NN.html` 逐一对齐（如学生例子是 5 变量 **4** 条边）。
- **术语不附英文**：首次出现给英文原名（如「解释消除（Explaining Away）」），但旁白里念中文，英文最多念一次全称，不念缩写字母串。

## 八、制作流程（新章节标准动作）

```bash
# 1. 复制模板（在本目录 PGM课件/ 下）
cp assets/deck-template.html "NN-章名-课件.html"
# 2. 读 PGM讲义/chapter-NN.html，提炼主线链 + 选一条推导 + 选 1-3 个误区
# 3. 按骨架填 18-26 页，每页写 data-narration
# 4. 自检（见下），然后交付用户审阅
```

### 交付前自检清单
- [ ] 页数 18–26，骨架 ★ 项齐全，无目录页
- [ ] 每个标题都是结论句；每页只讲一个论点
- [ ] 每页有 `data-narration`，180–280 字，无半角双引号，无 LaTeX
- [ ] 手算页有 `.step` 分步；互动停顿页旁白含「推出来了吗？」类触发句
- [ ] mermaid 全部在 `.mmd` 容器内，无 >8 节点大图
- [ ] `?slide=N&autohide=1` 逐页打开：无溢出、无导航残留、step 全显
- [ ] `extract_narration.py --expect <页数>` 通过
- [ ] 符号/例子/结论与对应讲义章一致；术语首次出现带英文
- [ ] **file:// 双击场景逐页截图（必做，不能省）**：用浏览器以 `file://` 直开课件（不带任何参数），从第 1 页按 → 翻到最后，每页停留 ≥2 秒并截图，逐页确认 mermaid 图真实出现（非空白、非细条、非源码文本）、公式已渲染（无裸露 LaTeX）；同时看 DevTools 控制台无报错、`assets/*.js` 请求全部 200
- [ ] **断网复测**：断网状态下重复上一条翻阅，公式与图必须全部正常（MathJax/mermaid 均为本地资源）；若 DevTools 出现 `ERR_FILE_NOT_FOUND`（MathJax autoload 扩展缺文件），按「常见坑」流程补齐后重测
