1.1为什么 L2 距离不够：它看不见格子之间的远近

这是全书的起点，所以先看清楚旧工具到底哪里坏了。假设我们要比较定义在三个位置 {1, 2, 3} 上的三个直方图（概率向量）：

直方图位置 1位置 2位置 3直觉上离 a 多远
a100—
b010近（质量挪了 1 格）
c001远（质量挪了 2 格）

用 L2 距离算一算（逐分量相减、平方、开根号）：

‖a − b‖₂ = √((1−0)² + (0−1)² + (0−0)²) = √2，  ‖a − c‖₂ = √((1−0)² + (0−0)² + (0−1)²) = √2

两个距离一模一样。但任何有空间直觉的人都会说：把质量从位置 1 挪到位置 2，和挪到位置 3，代价不该一样。L2 把直方图的每个格子当成互相垂直的坐标轴，它知道"第 2 格和第 3 格不同"，却不知道"位置 2 离位置 1 只有一步，位置 3 离位置 1 有两步"。

同样的毛病出现在图像上：把一张图整体平移 1 个像素，和平移 10 个像素，逐像素的 L2 差别都很大，而且大小关系甚至可能颠倒。L2 只认"同一个格子里的数值差"，完全不利用底层空间的距离结构。

💡 关键一跃

比较分布时，我们缺的不是"数值差"，而是把数值差和位置差绑在一起的度量：质量差多少，乘以要搬多远。

⚠️ 常见误区

以为"换个范数"（L1、L∞）就能解决。错：所有逐分量定义的范数都把格子当独立坐标，问题出在"逐分量"本身，不在 p 取几。

1.2把分布看成土堆：离散测度与 Dirac 记号

上一节说 L2 看不见几何，这一节给出承载几何的数学对象。1781 年，Monge 提出过一个朴素问题：把一堆土从一个坑填到另一个坑，怎样搬最省力？把"土堆"抽象成数学，就是离散测度（Discrete Measure）：

μ = ∑i=1ⁿ aᵢ δxᵢ，  aᵢ ≥ 0，  ∑i aᵢ = 1

读法：在位置 x₁, x₂, …, xₙ 上各放了一小堆土，第 i 堆的质量是 aᵢ；总质量归一化为 1。Dirac 测度（Dirac Mass）δx 就是"全部质量集中在点 x 上"的理想化分布。所有位置 {xᵢ} 的集合叫做分布的支撑集（Support）。

这个记号一举多得：

  • 直方图是特例：xᵢ 固定在规则格点上，只有权重 aᵢ 在变；
  • 点云也是特例：aᵢ = 1/n 都相等，只有位置 xᵢ 在变（机器学习里的经验分布 μ̂ = (1/n)∑δxᵢ）；
  • 位置 xᵢ 带着空间结构，几何被天然装进了对象里。

用土堆的语言，两个分布"像不像"就变成：把 μ 这堆土 reshaped 成 ν 那堆土，最少要花多少搬运代价。搬运有两条铁律（后面会变成数学约束）：质量不能凭空产生或消失；把质量 m 搬距离 d，代价是 m × d。

✅ 手算示例：两个两原子分布

μ = 0.5δ₀ + 0.5δ₄（一半土在 0，一半土在 4），ν = 0.5δ₁ + 0.5δ₃。最省力的搬法：0 处的 0.5 搬到 1（距离 1），4 处的 0.5 搬到 3（距离 1）。总代价 = 0.5×1 + 0.5×1 = 1。这就是 W₁(μ,ν) = 1。

⚠️ 常见误区

把 δx 当成"在 x 处取值无穷大的函数"。Dirac 是测度不是函数：它没有函数值，只有"对集合称重"的能力——δx(A) = 1 当 x∈A，否则 0。手写推导时把它当"单位质量的质点"最安全。

1.3两种距离的性格：Wasserstein 连续，KL 会"翻脸"

有了土堆模型，就可以正式介绍本书的主角。Wasserstein 距离（Wasserstein Distance）定义为把 μ 搬成 ν 的最小总代价：

Wp(μ, ν) = ( 最小搬运方案下 ∫ ‖x − y‖ᵖ 的总量 )1/p

"最小搬运方案"严格是什么，是第2章的任务；本章只需要它的性质。最常用的对比对象是 KL 散度（Kullback–Leibler Divergence）：

KL(μ ‖ ν) = ∫ log( dμdν ) dμ

用一个极端实验看两者的性格差异。考虑单原子分布族 μt = δt（全部质量在 t），与参考分布 ν = δ₀ 比较，让 t 从 0 慢慢滑到 1：

tKL(δt ‖ δ₀)W₁(δt, δ₀)
000
0.001+∞0.001
0.5+∞0.5
1+∞1

只要支撑集不重叠，KL 立刻跳到 +∞，并且无论 t 是 0.001 还是 100，它给出的信息完全一样："不行"。W₁ 则随位移线性、连续地变化，还带有正确的数量级。后果很实际：想对分布参数求梯度时（生成模型、分布拟合），KL 在支撑集不交的区域梯度为零或根本无定义，Wasserstein 却能持续提供"往哪边搬更近"的方向——这正是 Wasserstein GAN 等应用（第8章）的出发点。

💡 一句话记住两者分工

KL 问的是"两个分布的质量有没有重叠、比例差多少"，不看位置；Wasserstein 问的是"把质量搬过去要走多远"，位置就是价格。

⚠️ 常见误区

以为 Wasserstein 全面碾压 KL。不是：W 依赖底层空间的距离 ‖x−y‖（换几何就换答案），且没有闭式可微的密度比值可用；极大似然、变分推断里 KL 仍是主力。工具按场景选，第8章会反复用到这个判断力。

📝分层习题

L1 概念辨析判断对错：两个离散分布的支撑集不相交时，它们之间的 KL 散度是一个很大的有限数（比如 10⁶），可以用梯度下降最小化它。
提示

回想密度比 dμ/dν 在支撑集不交时会发生什么；+∞ 能求梯度吗？

完整解答

错。支撑集不交时密度比在 μ 的质量处无定义，KL(μ‖ν) = +∞，不是一个"很大的有限数"。+∞ 没有可用梯度（任何有限扰动只要不创造重叠，KL 仍是 ∞），梯度下降完全失效。正确替代：改用 Wasserstein 距离或先做平滑（第4章的熵正则也有此效）。易错点：把数值计算中"log 一个很小的数"误当作 KL 的真实行为——那是密度近似非零带来的假象。

L1 概念辨析选择：下列哪个量随 δt 中 t 的微小变化而连续变化？（A）KL(δt‖δ₀)（B）三箱直方图视角下的 L2 距离（C）W₁(δt, δ₀)（D）都不连续。
提示

逐个想：t 从 0 挪到 0.001，每个量的值怎么跳？

完整解答

C。W₁(δt,δ₀) = |t|，随 t 连续线性变化。A 错：t≠0 即跳为 +∞。B 错：把 δt 嵌进固定格子直方图后，t 跨过格点边界时 L2 发生跳变，且格子内移动看不见。D 自然错。本题考点：连续性正是 Wasserstein 支撑梯度优化的原因。

L2 手算推导设 μ = 0.5δ₀ + 0.5δ₄，ν = 0.5δ₁ + 0.5δ₃，底空间距离为绝对值。手算 W₁(μ,ν) 与 W₂(μ,ν)²（即 p=2 时的最优总代价，不开根号）。
提示

先论证"0→1、4→3"是最优搬法（交叉搬只会更远），再分别代入距离 d 与 d²。

完整解答

步骤1：两种配对方案。方案甲（同向配）：0→1（距离1）、4→3（距离1）；方案乙（交叉配）：0→3（距离3）、4→1（距离3）。甲的总代价显然更小，且任何"交叉"都可用交换论证改进（三角不等式），故甲最优。

步骤2：W₁ = 0.5×1 + 0.5×1 = 1。

步骤3：W₂² = 0.5×1² + 0.5×1² = 1（于是 W₂ = 1）。注意 W₂² 与 W₁ 数值相同纯属本例距离都为 1 的巧合，一般不相等。

L2 手算推导三箱直方图 a=(1,0,0)、b=(0,1,0)、c=(0,0,1) 位于位置 {1,2,3}，底距离为位置差绝对值。手算 W₁(a,b) 与 W₁(a,c)，并与 L2 距离对比，写出结论。
提示

每个直方图都是单原子：全部质量 1 集中在一个位置，搬运代价 = 质量 × 距离。

完整解答

a = δ₁，b = δ₂，c = δ₃（都是单原子测度）。单原子之间只有唯一搬法：整体搬过去。

W₁(a,b) = 1×|1−2| = 1；W₁(a,c) = 1×|1−3| = 2。

对比：‖a−b‖₂ = ‖a−c‖₂ = √2。结论：L2 认为 b、c 离 a 一样远，W₁ 正确区分出 c 更远（2 倍），恢复了位置几何。这就是 1.1 节问题的定量答案。

L3 建模应用你要做一个"以图搜图"系统：把每张灰度图归一化（像素亮度总和为 1）后比较相似度。同事建议直接对亮度向量算 L2。请指出该方案在什么情况下会系统性出错，并给出基于最优传输的建模：分布是什么、底空间距离是什么、为什么它能修复问题。
提示

想"整图平移/缩放一小下"会发生什么；把亮度当质量、像素坐标当位置。

完整解答

出错场景：同一主体轻微平移、缩放、形变时，逐像素 L2 会给出巨大距离（1.1 节的病症）。

OT 建模：图像 I 归一化为 μ_I = ∑ᵢ aᵢδ_{xᵢ}，xᵢ ∈ ℤ² 是像素坐标，aᵢ = 亮度ᵢ/总亮度；底空间距离取像素坐标的欧氏距离 ‖x−y‖。相似度取 W₁(μ_I, μ_J)（或第4章的熵正则版本，可在百万像素规模计算）。

修复原理：主体平移 ε，W₁ 只增加约 ε 量级，相似度连续退化而非崩溃；同时亮度总量守恒由"分布"约束自动保证。代价：计算量大，需第3–4章的算法支撑。

  • C. ‖a−b‖₂ = ‖a−c‖₂ 且 W₁(a,b) = W₁(a,c)
  • D. ‖a−b‖₂ < ‖a−c‖₂ 且 W₁(a,b) < W₁(a,c)
解析：L2 两者都是 √2（逐分量范数看不见位置），W₁ 分别是 1 和 2（搬运距离不同），故 B。A、D 错在以为 L2 能区分；C 错在以为 W 和 L2 一样"瞎"——W 恰恰是为修复这一点而生。
自测 2
μ = ∑ᵢ aᵢδ_{xᵢ} 中，点云（经验分布）对应的特例是：
  • A. xᵢ 固定在格点上，aᵢ 任意
  • B. aᵢ 任意，xᵢ 任意
  • C. aᵢ = 1/n 固定，xᵢ 为样本位置
  • D. n = 1 且 a₁ = 1
解析：经验分布给每个样本等权 1/n，信息全在样本位置 xᵢ 上，故 C。A 是直方图而非点云；B 是一般离散测度，不是特例；D 是单个 Dirac，连"云"都不是。
自测 3
KL(δ₀.₅ ‖ δ₀) 的值是：
  • A. +∞
  • B. 0.5
  • C. log 2
  • D. 0
解析：支撑集 {0.5} 与 {0} 不交，密度比 dμ/dν 不存在，KL = +∞，选 A。B 错在把 W₁ 的答案搬给 KL（W₁ = 0.5）；C 错在套用了均匀分布的公式；D 错在以为"差别小"KL 就小——KL 对支撑集不交零容忍。
自测 4
用梯度下降拟合分布参数 θ（μ_θ = δ_θ，目标 δ₁），从 θ=0 出发，下列哪种损失能给出有效梯度？
  • A. KL(μ_θ ‖ δ₁)
  • B. 把 μ_θ 嵌入直方图后的 L2
  • C. 都不行
  • D. W₁(μ_θ, δ₁)
解析：W₁ = |θ−1|，梯度恒定指向 1，选 D。A 错：θ≠1 时 KL=+∞ 无梯度。B 错：格子化后在格子内部损失是常数（梯度为零），跨格点又跳变。C 错正是因为 D 可行。
自测 5
μ = 0.5δ₀ + 0.5δ₄，ν = 0.5δ₁ + 0.5δ₃，W₁(μ,ν) = ？
  • A. 2
  • B. 1
  • C. 0.5
  • D. 4
解析：0→1 搬 0.5（代价0.5），4→3 搬 0.5（代价0.5），共 1，选 B。A 错在忘记乘质量 0.5（把距离直接相加）；C 错在只算了一堆土；D 错在用了交叉配对（0→3、4→1），那不是最优方案。

🗣️ 用自己的话，三句话讲完本章

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：L2/KL 等经典度量比较概率分布时看不见底层空间的几何（平移一点和两点给出同样或无穷的答案），本章要引入一种"带几何"的分布距离。
句2：核心机制是什么？——
参考答案：把分布建模成单位质量的土堆（离散测度 ∑aᵢδ_{xᵢ}），定义分布间距离为"把土堆 reshaped 成另一个的最小搬运代价"，即 Wasserstein 距离，它随位移连续变化。
句3：它和前后章怎么分工？——
参考答案：本章只给动机和直觉；第2章把"最小搬运代价"严格化（Monge 映射与 Kantorovich 耦合）；第3–4章解决"怎么算出来"（LP 与 Sinkhorn）。
