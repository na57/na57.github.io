3.1把 OT 写成 LP：变量是 n×m 矩阵，约束只有两条边际

第2章的 Kantorovich 问题落到离散测度 μ = ∑ᵢ aᵢδ_{xᵢ}、ν = ∑ⱼ bⱼδ_{yⱼ} 上，耦合 π 就是一张 n×m 的非负矩阵 P。给定成本矩阵（Cost Matrix）Cᵢⱼ = c(xᵢ,yⱼ)，离散 OT 是一个标准线性规划：

minP ⟨C, P⟩ = ∑ᵢⱼ CᵢⱼPᵢⱼ，  s.t.  P1m = a，  Pᵀ1n = b，  P ≥ 0

数一数规模：变量 n×m 个（n=m 时就是 n²），等式约束 n+m 个（但有一个冗余——所有行和之和与所有列和之和都是 1，独立约束只有 n+m−1 个）。LP 的基本定理告诉我们：最优解可以在基本可行解（Basic Feasible Solution, BFS）上取到，而 BFS 的非零元个数 ≤ 独立约束数 = n+m−1。

这个稀疏性结论很反直觉：P 有 n² 个格子，最优解却只填其中约 2n 个——99% 以上的格子是零。2.2 节的 2×2 例已经演示过：π* 只有 3 个非零元（= 2+2−1）。这正是北西角规则和运输单纯形能成立的结构性原因。

💡 关键一跃

运输问题的约束矩阵是全幺模（Totally Unimodular）的：当 a、b 是整数时，每个 BFS 自动是整数解。所以运输 LP 从不需要整数规划——单纯形法直接给出整数答案。这也解释了 BFS 的组合本质：它对应支撑图里的一棵生成树。

⚠️ 常见误区

以为 LP 有 n² 个变量就"没法算"。变量多不可怕，结构才重要：全幺模 + 稀疏基让专用算法（运输单纯形、网络单纯形）远快于通用 LP 求解器。真正可怕的是后面 3.4 节要算的渐进账。

3.2北西角规则：三步贪心填出第一个可行解

单纯形法需要一个初始 BFS。运输问题的经典做法是北西角规则（Northwest Corner Rule）：从矩阵左上角开始，贪心地把当前行剩余供应和当前列剩余需求的较小者填进去，然后划掉耗尽的一行（或一列），继续向右下走。

✅ 手算示例：3×3 北西角全流程

供应 a = (0.3, 0.5, 0.2)，需求 b = (0.4, 0.4, 0.2)，成本矩阵：

C列1 (需0.4)列2 (需0.4)列3 (需0.2)供应
行12130.3
行21420.5
行33210.2

逐步执行：

第1步（格(1,1)）：min(行1余0.3, 列1需0.4) = 0.3 → π₁₁ = 0.3。行1耗尽，划掉行1；列1还需 0.1。

第2步（格(2,1)）：min(行2余0.5, 列1需0.1) = 0.1 → π₂₁ = 0.1。列1满足，划掉列1；行2还剩 0.4。

第3步（格(2,2)）：min(行2余0.4, 列2需0.4) = 0.4 → π₂₂ = 0.4。行2与列2同时耗尽——这是退化情形，两个一起划掉。

第4步（格(3,3)）：只剩行3余0.2、列3需0.2 → π₃₃ = 0.2。收工。

初始解 P⁰：π₁₁=0.3, π₂₁=0.1, π₂₂=0.4, π₃₃=0.2，代价 = 0.3×2 + 0.1×1 + 0.4×4 + 0.2×1 = 0.6+0.1+1.6+0.2 = 2.5。注意只有 4 个非零元，少于 n+m−1 = 5——第3步的"同时耗尽"造成了退化，基里少了一个元素，下一步要补。

北西角完全不看成本（π₂₂ 走的恰是最贵的格子 4），所以它给的只是"合法起点"，通常离最优很远。改进它是下一节的事。

⚠️ 常见误区

以为北西角在"优化"。它只求可行、不求好——连成本矩阵都不看。想要好一点的起点可用最小元素法（每次选当前最便宜格子），但同样不保证最优；真正的最优化只能靠下一节的检验数迭代。

3.3运输单纯形：用势发现"哪条闲置路线能省钱"

有了初始解，怎么判断它好不好、怎么改进？运输单纯形（Transportation Simplex）每轮做三件事：求势 → 算检验数 → 沿环调整。

求势：对每个基元（非零元所在格 (i,j)）令 uᵢ + vⱼ = Cᵢⱼ。n+m 个未知数、n+m−1 个方程，令 u₁ = 0 即可解出。这个 (u,v) 正是第2章对偶势 φ、ψ 的离散化身。检验数：对每个非基元格算 Δᵢⱼ = Cᵢⱼ − uᵢ − vⱼ。Δᵢⱼ < 0 意味着"把流量挪进格子 (i,j) 能省钱"；全部 Δᵢⱼ ≥ 0 则已达最优——这就是 2.4 节对偶约束 φ+ψ ≤ c 的等价位。沿环调整：把负检验数格子加入基，它在基的支撑树里形成唯一一个环，沿环交替 +/- 调整流量 δ，δ 取环上减方最小值。

✅ 手算示例：两轮枢轴从 2.5 降到 1.2

第1轮：上节解只有 4 个非零元，补零基元 (3,2) 凑齐基 {(1,1),(2,1),(2,2),(3,2),(3,3)}。令 u₁=0 解方程组 uᵢ+vⱼ=Cᵢⱼ：

基元方程结果
(1,1)u₁+v₁=2v₁=2
(2,1)u₂+v₁=1u₂=−1
(2,2)u₂+v₂=4v₂=5
(3,2)u₃+v₂=2u₃=−3
(3,3)u₃+v₃=1v₃=4

势：u=(0,−1,−3)，v=(2,5,4)。算非基元检验数：Δ₁₂ = 1−0−5 = −4（其余如 Δ₁₃=3−0−4=−1、Δ₃₁=3+3−2=4 等，选最负的 −4 进基）。

格子 (1,2) 进基形成环 (1,2)+ → (2,2)− → (2,1)+ → (1,1)−。减方是 (2,2)=0.4 与 (1,1)=0.3，δ = min(0.4, 0.3) = 0.3。更新：π₁₂=0.3, π₂₂=0.4−0.3=0.1, π₂₁=0.1+0.3=0.4, π₁₁=0.3−0.3=0（出基）。新代价 = 2.5 − 4×0.3 = 1.3（验证：0.3×1+0.4×1+0.1×4+0.2×1 = 1.3 ✓）。

第2轮：补零基元 (2,3) 后重求势，算得 Δ₃₂ = 2−u₃−v₂ = −1，(3,2) 进基。环 (3,2)+ → (2,2)− → (2,3)+ → (3,3)−，δ = min(π₂₂, π₃₃) = min(0.1, 0.2) = 0.1。更新：π₃₂=0.1, π₂₂=0（出基）, π₂₃=0.1, π₃₃=0.2−0.1=0.1。新代价 = 1.3 − 1×0.1 = 1.2。

最优性证书：当前基 {(1,2),(2,1),(2,3),(3,2),(3,3)}，求势得 u=(0,2,1)、v=(−1,1,0)，验证全部非基元检验数：Δ₁₁=2−0+1=3，Δ₁₃=3−0−0=3，Δ₂₂=4−2−1=1，Δ₃₁=3−1+1=3，全部 ≥ 0 → 1.2 即最优。最终方案：π₁₂=0.3, π₂₁=0.4, π₂₃=0.1, π₃₂=0.1, π₃₃=0.1。

把视角再抬高一层：运输问题是一张二分图上的最小费用流，基就是图里的生成树，换基就是在树上加一条边成环、再断一条边——这正是网络单纯形（Network Simplex）：在图上维护一棵生成树，每次用一条"划算的弦"替换树上的一条边。一句话版本到此为止，细节留给优化课程。

💡 关键一跃

势 (u,v) 不是 bookkeeping 技巧，它就是第2章的对偶势：Δᵢⱼ = Cᵢⱼ − uᵢ − vⱼ ≥ 0 正是对偶约束 φ+ψ ≤ c。检验数全负消失的那一刻，对偶可行且与原始值相等——最优性证书自动到手，不需要额外验证。

3.4复杂度账：精确 LP 在哪里撞墙，一维为什么例外

运输单纯形实战很快，但最坏情形仍是指数的；即使换用内点法或网络单纯形的多项式实现，一般 n×n 的 OT 也要 ~O(n³) 量级的运算。代入数字感受一下：n = 10³ 时约 10⁹ 次运算，秒级；n = 10⁵（一张 300×300 图像的像素数）时约 10¹⁵ 次，完全不可行。而机器学习要比较的分布动辄 n = 10⁵ ~ 10⁷。这就是全书的核心张力：OT 理论漂亮，精确计算却贵得离谱。

有一个重要例外：一维。2.3 节的分位数公式说最优方案 = 单调重排，离散化后只需：把 xᵢ、yⱼ 各自排序（O(n log n)），再用双指针从左到右配对质量（O(n)）。总复杂度 O(n log n)，n = 10⁷ 也毫无压力。第6章的切片 Wasserstein（Sliced Wasserstein）正是把高维投影回一维来白嫖这个特例。

方法复杂度n = 10⁵ 可行？精度
通用 LP（内点法）~O(n³) 以上✗精确
网络/拍卖算法~O(n³) 级，常数小勉强~✗精确
一维排序法O(n log n)✓精确（仅一维）
熵正则 Sinkhorn（第4章）O(n²)/轮，可并行✓近似（偏差随 ε 缩）
⚠️ 常见误区

把"多项式时间"当"可扩展"。O(n³) 是多项式，但 n=10⁵ 时就是算不动；可扩展性要看绝对量级与常数、并行性、内存（n² 的成本矩阵在 n=10⁵ 时就要 80GB）。第4章的 Sinkhorn 每轮 O(n²) 且全矩阵乘法——GPU 友好，这才是它胜出的真正原因。

📝分层习题

L1 概念辨析判断对错：北西角规则给出的初始解一定是最优解的一个好近似，因为它系统地覆盖了所有行列。
提示

回看 3.2 例：π₂₂=0.4 走的格子成本是多少？这个成本在全矩阵里排第几？

完整解答

错。北西角完全不读成本矩阵：例中它把 0.4 的流量塞进全矩阵第二贵的格子 (2,2)=4，代价 2.5，而最优值是 1.2——差距超过一倍。系统性覆盖只保证可行，不保证好。易错点：把"确定性构造"误认为"合理优化"；贪心方向（左上→右下）与成本结构毫无关系。

L1 概念辨析选择：运输问题中检验数 Δᵢⱼ = Cᵢⱼ − uᵢ − vⱼ 全部非负时，可以断定：（A）当前解可行（B）当前解最优（C）需要补零基元（D）发生了退化。
提示

把 Δᵢⱼ ≥ 0 翻译成第2章对偶约束的语言。

完整解答

B。Δᵢⱼ ≥ 0 ⟺ uᵢ+vⱼ ≤ Cᵢⱼ，即 (u,−v 方向的) 对偶势满足全部对偶约束；此时对偶可行且对偶值=原始值，强对偶保证最优。A 错：可行性在每一步都成立，与检验数无关。C、D 错：退化是基的大小问题，与最优性判定无关。

L2 手算推导供应 a=(0.5,0.5)，需求 b=(0.3,0.7)，C=[[4,2],[1,3]]。用北西角规则求初始解与代价，再算势与检验数，判断是否最优；若不最优，做一次枢轴并给出最优值。
提示

北西角先填 (1,1)=0.3；2×2 时环就是整个矩阵四角，δ 取减方最小值。

完整解答

步骤1（北西角）：(1,1)：min(0.5,0.3)=0.3 → π₁₁=0.3，列1满；行1余0.2。(1,2)：π₁₂=0.2，行1满；列2余0.5。(2,2)：π₂₂=0.5。代价 = 0.3×4+0.2×2+0.5×3 = 1.2+0.4+1.5 = 3.1。

步骤2（求势）：基 {(1,1),(1,2),(2,2)}。u₁=0 ⇒ v₁=4；v₂=C₁₂−u₁=2；u₂=C₂₂−v₂=1。检验数 Δ₂₁ = C₂₁−u₂−v₁ = 1−1−4 = −4 < 0，非最优。

步骤3（枢轴）：(2,1) 进基，环 (2,1)+ → (1,1)− → (1,2)+ → (2,2)−，δ = min(π₁₁,π₂₂) = min(0.3,0.5) = 0.3。更新：π₂₁=0.3, π₁₁=0, π₁₂=0.5, π₂₂=0.2。新代价 = 0.5×2+0.3×1+0.2×3 = 1+0.3+0.6 = 1.9（= 3.1−4×0.3 ✓）。

步骤4（验证）：新基 {(1,2),(2,1),(2,2)}，u=(0,2,?)——u₁=0, v₂=2, u₂=1, v₁=0；Δ₁₁=4−0−0=4 ≥ 0，其余非基元无 → 最优，最优值 1.9。

L2 手算推导对 3.3 节最优解（π₁₂=0.3, π₂₁=0.4, π₂₃=0.1, π₃₂=0.1, π₃₃=0.1，代价 1.2），用第2章的对偶语言验证：(i) 势 u=(0,2,1)、v=(−1,1,0) 满足全部 9 条对偶约束；(ii) 对偶值等于原始值；(iii) 互补松弛成立。
提示

对偶值 = ∑ᵢ aᵢuᵢ + ∑ⱼ bⱼvⱼ；互补松弛要求非零 πᵢⱼ 处约束取等。

完整解答

(i) 逐格核验 uᵢ+vⱼ ≤ Cᵢⱼ：行1（u₁=0）：(1,1) −1≤2 ✓，(1,2) 1=1 ✓，(1,3) 0≤3 ✓；行2（u₂=2）：(2,1) 1=1 ✓，(2,2) 3≤4 ✓，(2,3) 2=2 ✓；行3（u₃=1）：(3,1) 0≤3 ✓，(3,2) 2=2 ✓，(3,3) 1=1 ✓。9 条全过。

(ii) 对偶值 = (0.3×0+0.5×2+0.2×1) + (0.4×(−1)+0.4×1+0.2×0) = (0+1+0.2) + (−0.4+0.4+0) = 1.2 = 原始值 ✓。

(iii) 非零 π 的位置 (1,2),(2,1),(2,3),(3,2),(3,3) 恰好是上面取等的 5 格 → 互补松弛成立 ✓。这张证书一旦写出，任何人无需重跑算法即可确认 1.2 最优。

L3 建模应用你要在两张 500×500 的灰度图（各 25 万像素）之间算 OT 距离做图像检索。团队有人提议："直接调商业 LP 求解器，反正运输问题是多项式的。" 请列出三条反对理由（内存、时间、硬件利用率各一），并给出你的替代方案。
提示

算一算 C 矩阵的元素个数与字节数；n³ 代入 2.5×10⁵；想想 LP 求解器能不能用 GPU。

完整解答

反对理由：①内存：n=2.5×10⁵，C 有 n²=6.25×10¹⁰ 个 double，约 500GB，普通机器放不下；②时间：~O(n³) ≈ 1.6×10¹⁶ 次运算，以 10⁹ 次/秒计要约 180 天一张图；③硬件：单纯形/内点法是顺序稀疏算法，几乎无法用 GPU 并行，而这正是图像场景的标配硬件。

替代方案：用第4章的熵正则 + Sinkhorn：每轮迭代是矩阵-向量乘（O(n²) 且可 GPU 并行），配合 ε 折减（先大后小）控制偏差；若追求更高吞吐，可用第6章的切片 Wasserstein（投影到一维后排序，O(n log n)/方向）。检索场景还可以先降采样到 64×64 再算，精度损失远小于算法差异。

  • D. 环上减方格子的最小流量
