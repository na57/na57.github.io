4.1为什么加熵：把组合难题烫平成光滑凸问题

第3章结尾的账很清楚：精确 LP 约 O(n³)，n = 10⁵ 不可行。病根不只在复杂度——LP 的最优解卡在多面体顶点上，找它本质上是组合搜索（选哪 n+m−1 个格子非零），这类问题天然抗拒并行化和矩阵运算。Cuturi 2013 年的破局思路是：不改约束，改目标——给线性目标加一项熵：

minP ∈ U(a,b) ⟨C, P⟩ − εH(P)，  其中 H(P) = −∑ᵢⱼ Pᵢⱼ (log Pᵢⱼ − 1)

U(a,b) 仍是满足两条边际约束的耦合多面体；ε > 0 是正则参数（Regularization Parameter）。熵 H(P) 度量耦合的"分散程度"：所有质量挤在少数格子上时 H 小，均匀摊开时 H 大。减去 εH 就是奖励分散——算法会偏爱"雨露均沾"的耦合。

这一项换来三个立竿见影的性质。第一，严格凸：熵是严格凹函数，线性项加严格凹项得到严格凸目标，最优解唯一——不再有"一堆等价最优顶点"。第二，可微：最优值和最优解都光滑地依赖于输入 (a, b, C)，这意味着 OT 可以嵌进神经网络做反向传播——这是它能进机器学习流水线的关键门票。第三，结构显式：下一节会看到，解有闭式骨架 P = diag(u)Kdiag(v)，只剩两个向量要解。

两个极限行为必须先记住，它们是全章的罗盘：

极限行为读法
ε → 0解 → 真实 OT 的最优耦合（熵最大者）正则项消失，回到原 LP
ε → ∞解 → 独立耦合 abᵀ成本被淹没，只剩"尽量分散"的纯熵项
💡 关键一跃

物理学类比：⟨C,P⟩ 是能量，H(P) 是熵，ε 是温度。ε=0 的系统冻结在能量最低的构型（LP 顶点）；升温后系统按 Boltzmann 分布摊开；温度无穷大时完全无视能量、均匀混合。Sinkhorn 解的 K = e^(−C/ε) 正是 Gibbs/Boltzmann 权重——这不是巧合，是同一个变分原理。

⚠️ 常见误区

以为加熵只是"数值技巧"，逼近同一个答案。不：它解的是另一个问题。ε > 0 时 ⟨C,P_ε⟩ 严格大于真实 OT 代价（本章 4.3 会算出偏差 0.424）。这个差叫熵偏差，是用速度买来的账单——4.4 节专门算这笔账。

4.2Sinkhorn 定理：解一定是"行缩放 × 核 × 列缩放"

熵正则问题的约束只有两组边际，拉格朗日乘子 f ∈ Rⁿ、g ∈ Rⁿ（就是第2、3章对偶势的化身）。拉格朗日函数 L = ⟨C,P⟩ − εH(P) + ⟨f, a − P1⟩ + ⟨g, b − Pᵀ1⟩。对 Pᵢⱼ 求导置零：

∂L/∂Pᵢⱼ = Cᵢⱼ + ε log Pᵢⱼ − fᵢ − gⱼ = 0   ⟹   Pᵢⱼ = e^(fᵢ/ε) · e^(−Cᵢⱼ/ε) · e^(gⱼ/ε)

一行 KKT，结构全部现身：定义Gibbs 核（Gibbs Kernel）Kᵢⱼ = e^(−Cᵢⱼ/ε)，再令 uᵢ = e^(fᵢ/ε)、vⱼ = e^(gⱼ/ε)，则

P = diag(u) K diag(v)，  即 Pᵢⱼ = uᵢ Kᵢⱼ vⱼ

也就是说：熵正则 OT 的解，必然是"正对角阵夹一个固定核"的形式。问题从解 n² 个 Pᵢⱼ，塌缩成解 2n 个数 (u, v)。剩下的事只有满足边际：

diag(u) K v = a，  diag(v) Kᵀ u = b

这组方程没有闭式解，但有个天然的不动点迭代——Sinkhorn 算法（Sinkhorn's Algorithm，1964 年的矩阵缩放定理在 OT 上的复活）：交替固定一个解另一个：

u ← a ./ (K v)，  v ← b ./ (Kᵀ u)

读法：K v 是"当前 v 下每行实际运出的量"，u 把它纠回到 a；Kᵀu 同理纠列。所以 Sinkhorn 就是交替做行归一化和列归一化，直到行列边际同时吻合。Sinkhorn 定理保证：只要 K 全正（ε > 0 时恒成立），迭代收敛到唯一解。

✅ 为什么这对 GPU 是天作之合

每轮迭代 = 两次矩阵-向量乘（Kv、Kᵀu）+ 两次逐元素除法。没有分支、没有 pivot、没有稀疏数据结构——全是稠密矩阵运算，复杂度 O(n²)/轮，且在 GPU 上是教科书级的并行 kernel。第3章 LP 的 ~O(n³) 顺序算法 vs 本章 O(n²) 可并行迭代，这就是"算得快"的全部来源。

⚠️ 常见误区

把 u、v 当成新变量从零理解。它们就是第3章势 (u,v) 的指数化：uᵢ = e^(fᵢ/ε)。Sinkhorn 迭代与运输单纯形解的是同一对对偶方程，只是一个用组合枢轴、一个用乘性更新。对偶这条线从第2章一路贯穿到本章。

✅ 手算示例：C 对称、两轮收敛

设 C = [[1,0,1],[0,1,1],[1,1,0]]（对角错开的 0/1 结构），a = b = (1/3, 1/3, 1/3)，取 ε = 1。

第2轮（更新 v）：Kᵀ u¹ = 0.1920 ×（K 的每列列和）= 0.1920 × 1.736 ≈ (0.3333, 0.3333, 0.3333)。于是 v¹ = b./(Kᵀu¹) = (1/3)/0.3333 = (1.0, 1.0, 1.0)。

行列边际都吻合。注意结构：C=0 的三个格子（π₁₂, π₂₁, π₃₃）拿到 0.1920，C=1 的六个格子各拿 0.0707——核把"贵"的格子压小，但不压成零。

和真实 OT 对账：这个例子的精确 OT 一目了然——把全部质量走 C=0 的格子，π₁₂ = π₂₁ = π₃₃ = 1/3，代价 0。而熵正则解的运输代价 ⟨C, P⟩ = 6 × 0.0707 ≈ 0.424。这 0.424 就是熵偏差（Entropic Bias）：ε = 1 的"温度"把 43% 的质量烘到了贵格子上。

再看熵：这个解的 −∑PᵢⱼlogPᵢⱼ ≈ 2.07，距理论最大 log 9 ≈ 2.197（均匀耦合）已经很近——ε=1 下熵项确实在强行摊平解。把 ε 调小，0.0707 那些格子会指数级缩水，代价逼近 0；但 4.4 节会看到，代价是迭代变慢、数值开始不稳。

💡 关键一跃

对比第3章：单纯形的最优解稀疏（≤2n−1 个非零元），Sinkhorn 的解稠密（K 全正 ⟹ P 全正）。这是两种算法的指纹：精确 OT 走边边角角，熵正则 OT 雨露均沾。要稀疏解就后处理（取最大/阈值化），要光滑可微就接受稠密。

4.4ε 的权衡：快与准的拔河，以及数值下溢的暗礁

ε 是全章唯一的旋钮，它同时控制三件事，而且方向相反：

ε 大（高温）ε 小（低温）
解的形态糊：趋近 abᵀ，贵格子分到大量质量锐：逼近真实 OT 的稀疏解
熵偏差大（4.3 例 ε=1 时 0.424）小，ε→0 时消失
收敛速度快（几轮到位）慢：线性收敛速率随 ε 减小而恶化
数值稳定安全危险：e^(−Cᵢⱼ/ε) 下溢成 0

第三条暗礁最要命。ε = 0.01、Cᵢⱼ = 10 时，e^(−1000) 在双精度下直接是 0——K 变成稀疏零矩阵，行归一化时 a./(Kv) 除以零，迭代当场爆炸。所以"把 ε 调小逼近真解"在朴素实现里走不通。

解法是对数域稳定化（Log-domain Stabilization）：不碰 u、v，直接在对偶变量 f = ε log u、g = ε log v 上迭代，所有矩阵-向量乘换成 log-sum-exp：

f ← ε·( log a − LSEⱼ( (gⱼ − Cᵢⱼ)/ε ) )，  g ← ε·( log b − LSEᵢ( (fᵢ − Cᵢⱼ)/ε ) )

log-sum-exp 有标准防溢技巧（先减最大值再求和），于是任意小的 ε 都能稳定迭代。代价是 log/exp 比乘法贵，且实现更绕——工程上常见折中是ε 折减（ε-annealing）：先用大 ε 快速收敛到粗解，逐步降温微调。

收敛怎么判？监控边际违反度（Marginal Violation）：‖diag(u)Kv − a‖₁ + ‖diag(v)Kᵀu − b‖₁ 小于阈值即停。理论保证是线性收敛（误差每轮乘一个小于 1 的因子），但这个因子随 ε 变小趋近 1——4.3 例两轮收敛是 ε=1 且高度对称的奢侈，不可外推。

💡 关键一跃

第3–4章合起来是一个完整的工程决策：要精确、n ≲ 10³——用网络单纯形；要规模、可微、GPU、能容忍 ε 级偏差——用 Sinkhorn（小 ε 配 log-domain，或 ε 折减）。没有银弹，只有旋钮。

⚠️ 常见误区

拿 ⟨C, P_ε⟩ 当 Wasserstein 距离用。它含熵偏差且不对称、不满足三角不等式（甚至 ⟨C,P⟩ 对相同分布也非零——4.3 例中 μ=ν 时"距离"是 0.424 不是 0！）。要当距离用得做 Sinkhorn divergence：OT_ε(a,b) − ½OT_ε(a,a) − ½OT_ε(b,b)，第6章展开。

解决问题小 ε 时 K 下溢成零、归一化除零的崩溃。
直觉不碰概率本身，只搬它的对数——避开下溢雷区。
误区以为免费；log/exp 更贵且实现绕，小 ε 才值得启用。
何时用ε 小到朴素 Sinkhorn 出现 NaN/Inf 时。

📝分层习题

L1 概念辨析判断对错：ε 越大，Sinkhorn 给出的解越接近真实最优传输的解，因为迭代收敛更快。
提示

收敛快 ≠ 逼近真解。回忆 ε → ∞ 时解趋向什么。

完整解答

错。ε 大收敛确实快，但解趋向独立耦合 abᵀ——成本矩阵被熵淹没，解与真实 OT 无关。逼近真解要 ε 小（代价是收敛慢、数值险）。易错点：把"算法收敛快"与"收敛到想要的解"混为一谈；Sinkhorn 永远精确地解它那个被正则化的问题，问题本身离 OT 多远由 ε 决定。

L1 概念辨析选择：Sinkhorn 每轮迭代复杂度 O(n²) 的根本原因是（A）需要解 n 个线性方程组（B）核心运算是两次稠密矩阵-向量乘 Kv 与 Kᵀu（C）要存储 n² 个对偶变量（D）边际约束有 n² 条。
提示

矩阵-向量乘是 n² 次乘加；对偶变量只有 2n 个。

完整解答

B。每轮 = Kv 与 Kᵀu 两个 n×n 矩阵-向量乘（各 n² 次乘加）加逐元素除法。A 错：没有解方程组，只有显式更新；C 错：对偶变量 (u,v) 只有 2n 个（存 K 才是 n²，但那是内存不是每轮运算）；D 错：边际约束只有 n+m 条。

L2 手算推导C = [[0,1],[1,0]]，a = b = (0.5, 0.5)，ε = 1。手算 Sinkhorn 至收敛（利用对称性），给出 u、v、P，并计算熵正则代价与熵偏差（真实 OT 代价为 0）。
提示

K 的对角是 1、反对角是 e⁻¹≈0.368；对称性保证 u、v 各分量相等。

完整解答

K = [[1, 0.368],[0.368, 1]]。v⁰=(1,1)：Kv⁰ = (1.368, 1.368)，u¹ = (0.5/1.368, 0.5/1.368) ≈ (0.3655, 0.3655)。Kᵀu¹ = (0.3655×1.368)×(1,1) = (0.5, 0.5)，v¹ = (0.5/0.5)×(1,1) = (1,1)。已收敛。

P = 0.3655·K = [[0.3655, 0.1345],[0.1345, 0.3655]]（0.3655×0.368 ≈ 0.1345）。行和 = 0.5 ✓。

熵正则代价 ⟨C,P⟩ = 0.3655×0 + 0.1345×1 + 0.1345×1 + 0.3655×0 = 0.269。真实 OT 是恒等映射，代价 0 → 熵偏差 = 0.269（ε=1 时 27% 的质量被烘到了反对角）。

L2 手算推导从熵正则问题的拉格朗日函数出发，完整推导 Pᵢⱼ = e^(fᵢ/ε)·e^(−Cᵢⱼ/ε)·e^(gⱼ/ε)，并说明为什么这组 KKT 条件足以刻画最优解（不需要二阶条件）。
提示

L = ⟨C,P⟩ − εH(P) + ⟨f, a−P1⟩ + ⟨g, b−Pᵀ1⟩；对 Pᵢⱼ 求导时 H 贡献 ε log Pᵢⱼ。

完整解答

∂H/∂Pᵢⱼ = −log Pᵢⱼ（由 H = −∑Pᵢⱼ(logPᵢⱼ−1)，导数为 −log Pᵢⱼ − 1 + 1 = −log Pᵢⱼ）。

∂L/∂Pᵢⱼ = Cᵢⱼ + ε log Pᵢⱼ − fᵢ − gⱼ = 0 ⟹ log Pᵢⱼ = (fᵢ + gⱼ − Cᵢⱼ)/ε ⟹ Pᵢⱼ = e^(fᵢ/ε)·e^(−Cᵢⱼ/ε)·e^(gⱼ/ε)。

充分性：目标函数严格凸（线性项 + 严格凹熵项 ×(−ε)），约束是线性的，故 KKT 条件不仅必要而且充分，且解唯一——这正是加熵换来的红利，LP 就没有这个待遇（最优解不唯一）。

L3 建模应用你要在 n = 5000 的词向量分布间算 OT 做文档相似度，要求"尽量接近真实 Wasserstein 值"。同事建议直接 ε = 10⁻⁴ 跑朴素 Sinkhorn。指出这个方案的两个具体故障模式，给出你的完整方案（含 ε 策略、实现方式、收敛监控）。
提示

词向量距离量级多大？e^(−C/10⁻⁴) 会怎样？小 ε 下迭代多少轮？

完整解答

故障1（数值）：词向量平方距离量级约 1–10，C/ε ~ 10⁴–10⁵，e^(−C/ε) 全部下溢为 0，Kv = 0，a./(Kv) 除零 → NaN，第一轮就崩。故障2（收敛）：即使换成 log-domain 不崩，ε=10⁻⁴ 的线性收敛因子几乎为 1，所需轮数爆炸，5000² × 海量轮数反而比 LP 还慢。

方案：①ε 折减——从 ε ≈ median(C) 量级起步（偏差大但几轮收敛），几何降温（如 ×0.5/轮）至目标精度；②小 ε 段切换 log-domain 迭代（log-sum-exp 防溢）；③每轮监控边际违反度 ‖P1−a‖₁+‖Pᵀ1−b‖₁ < 10⁻⁶ 即停；④若要当距离用，汇报 Sinkhorn divergence 而非裸 ⟨C,P⟩，消掉自传输偏差。内存上 n=5000 的 K 约 200MB（float64），单 GPU 可放下。

自测 2
Gibbs 核 K 的定义是：
  • A. Kᵢⱼ = −Cᵢⱼ/ε
  • B. Kᵢⱼ = e^(−εCᵢⱼ)
  • C. Kᵢⱼ = e^(−Cᵢⱼ/ε)
  • D. Kᵢⱼ = 1/(1 + Cᵢⱼ/ε)

自测 4
ε → ∞ 时，熵正则 OT 的解趋向：
  • A. 真实 OT 的最优耦合
  • B. 只有一个非零元的耦合

自测 5
