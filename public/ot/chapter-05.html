5.1为什么回到对偶：运输方案之外的"价格体系"

第2章把 Kantorovich 松弛写成线性规划，第3章用单纯形解它，第4章加熵加速。三章下来我们手里有"方案" π，却一直没有认真看过对偶变量。现在把镜头转过去——因为"这把尺子是不是真尺子"的证据，恰恰藏在对偶里。

Kantorovich 问题的对偶问题（Dual Problem）是：找两个势函数（Kantorovich Potentials）φ 定义在源空间 𝒳、ψ 定义在目标空间 𝒴，最大化

max  ∫𝒳 φ(x) dμ(x) + ∫𝒴 ψ(y) dν(y)，  约束：φ(x) + ψ(y) ≤ c(x, y)  ∀x, y

经济读法沿用第2章的物流公司故事：φ(x) 是公司"在 x 处收货"的报价，ψ(y) 是"在 y 处交货"的报价；约束 φ(x)+ψ(y) ≤ c(x,y) 保证自运不比外包贵，否则你自己干了。对偶就是：外包公司拼命抬价，但不敢越过任何一条真实运费。强对偶定理保证：最大报价总额 = 最小运输成本——两套账算的是同一件事。

离散情形就是第3章的老熟人：约束 fᵢ + gⱼ ≤ Cᵢⱼ，目标 max ∑ᵢ fᵢaᵢ + ∑ⱼ gⱼbⱼ。连续情形只是把下标换成积分。所以本章的"对偶"不是新东西，是把第2、3章的影子变量扶正为主角。

✅ 手算示例：两点分布验证强对偶

取 𝒳 = 𝒴 = ℝ，μ = δ₀，ν = δ₁，成本 c(x,y) = |x − y|。原问题：唯一的耦合把 0 处的全部质量运到 1，成本 = 1。

对偶：约束 φ(0) + ψ(1) ≤ 1，目标 max φ(0) + ψ(1)。约束直接给出上界 1，取 φ(0) = 0、ψ(1) = 1 达到——对偶最优值 = 1 = 原问题最优值。强对偶在最小的例子里就已经可见。

再试一对势：φ(0) = −3、ψ(1) = 4 同样取到 1。这暴露一个事实：势函数不唯一——同时加任意常数再减回去，目标不变。真正唯一的是"价差"，不是绝对价格。

势不唯一这件事马上逼出一个化简：既然只有价差要紧，能不能只留一个函数？固定 φ，ψ 要最大化就只能顶到约束的上沿：

ψ(y) = φc(y) ≝ infx [ c(x, y) − φ(x) ]

这个 ψ 叫 φ 的 c-变换（c-transform）。它把对偶问题从"两个函数"压缩成"一个函数"：max ∫φ dμ + ∫φ^c dν，无约束。c = |x−y|（距离成本）时还有个更漂亮的结论：最优 φ 恰好是 1-Lipschitz 函数，且 φ^c = −φ——这条直接长成第7章 WGAN 的地基。

💡 关键一跃

原问题问"货怎么走最省"，对偶问"怎么定价最能赚"。对偶势就是 OT 内置的价格体系：φ(x) − φ(x′) 度量 x 与 x′ 在运输市场上的"身价差"。后面的 W₁ 对偶（E f 之差取上确界）和 Wasserstein 重心的梯度，全都从这个价格体系里长出来。

⚠️ 常见误区

把势函数 φ 当成"位置 x 的固有属性"。错：φ 依赖整个问题（μ、ν、c 都换它就换），且整体平移不变——φ 和 φ + 常数是同一个解。能比较的是差值 φ(x) − φ(x′)，不是绝对值。这也是 c-变换合法的原因：它自动吸收了平移自由度。

5.2W_p 是距离：三公理逐条过堂

上一节确认了对偶最优值等于运输成本。现在定义本章主角：Wasserstein 距离（Wasserstein Distance，也叫 Earth Mover's Distance）：底空间带度量 d 时，

Wp(α, β) = ( minπ ∈ U(α,β) ∫ d(x, y)p dπ(x, y) )1/p，  p ≥ 1

注意两层结构：里层是 Kantorovich 问题（成本取 dp），外层开 p 次方。这个"开方"不是装饰——p ≥ 2 时不开方的量根本不满足三角不等式，开了方才成为距离。下面把三公理逐条过堂。

公理内容证明要点
同一性W_p(α,β) = 0 ⟺ α = βα=β 取对角耦合 (id,id)#α 代价 0；反之代价 0 迫使 π 集中在对角线上
对称性W_p(α,β) = W_p(β,α)耦合转置 π(x,y) → π(y,x)，成本 d 对称
三角不等式W_p(α,γ) ≤ W_p(α,β) + W_p(β,γ)粘合引理：把 α–β 与 β–γ 两个最优耦合沿中间分布 β 粘成一个三边际耦合，再用底空间的三角不等式 + Minkowski

三角不等式的证明是本章技术上最值得记住的一步。粘合引理（Gluing Lemma）：给定 π₁ ∈ U(α,β) 和 π₂ ∈ U(β,γ)，存在一个三边际耦合 σ(x,y,z)，它的 (x,y) 边际是 π₁、(y,z) 边际是 π₂。直观做法：以 y 为桥，按条件分布 π₁(x|y)·π₂(z|y) 独立拼接（离散情形就是 σᵢⱼₖ = π¹ᵢⱼ π²ⱼₖ / bⱼ）。于是

Wp(α,γ) ≤ ( ∫ d(x,z)p dσ )1/p ≤ ( ∫ [d(x,y) + d(y,z)]p dσ )1/p ≤ Wp(α,β) + Wp(β,γ)

第一步：σ 的 (x,z) 边际是合法耦合，W_p 是最小值所以更小；第二步：底空间三角不等式；第三步：对 Lp 范数用 Minkowski 不等式（这就是为什么必须开 1/p 次方——p=1 时 Minkowski 退化为加法，p > 1 时不开方不等式不成立）。

W_p 之所以珍贵，要对比着看。下面这张表是第1章动机的兑现：

散度/距离μ=δ₀, ν=δ_θ（θ→0）是距离？支撑不重叠时
KL 散度+∞（θ ≠ 0）否（不对称）无穷大，无梯度
总变差 TV1（常数）是饱和为常数，无梯度
Wasserstein W₁|θ| → 0是有限且随位置光滑变化，有梯度

更系统的结论是：W_p 度量化了 p 阶矩有限的分布空间上的"弱收敛 + p 阶矩收敛"——即 W_p(μₙ, μ) → 0 恰好等价于 μₙ 弱收敛且 p 阶矩收敛。这把"分布序列逼近"这件模糊的事变成了有尺度的收敛，第7章 GAN 训练要的就是这个性质。

💡 关键一跃

KL/TV 只问"两个分布在同一点上质量差多少"，看不到点与点之间的远近；Wasserstein 把底空间的几何 d(x,y) 抬进分布层面——所以它能感知"分布整体平移了一点点"。一句话：KL 是账本审计，Wasserstein 是搬运计费。后者自带尺子。

⚠️ 常见误区

把"最小运输成本"直接当距离用，忘了开 1/p 次方。⟨C, π*⟩ 在 p ≥ 2 时不满足三角不等式——比如直线段上搬两段的成本平方和会小于合并搬，尺度乱了。只有 W_p = (·)^{1/p} 才是距离。另外第4章的熵正则代价 ⟨C,P_ε⟩ 连同一性都不满足（μ=ν 时值非零），更不能当距离；修法 Sinkhorn divergence 见第6章。

5.3一维闭式解：分位数函数把 OT 变成竖式减法

一般维数下 W_p 没有闭式解，但一维是个幸福的例外，而且它是全讲义最常回用的手算工具（第6章切片法完全靠它）。原因直观：在直线上搬土，最优方案必然是单调的——左边的土给左边的坑。任何"交叉运输"（x₁ < x₂ 却送到 y₂ < y₁ 之后位置颠倒）都可以解开交叉、严格省成本（这是成本 |x−y|^p 的凸性，即 Monge 代价的次模性）。

"单调地把一个分布重排成另一个"用数学说就是分位数对分位数。记 F_α 为累积分布函数，分位数函数（Quantile Function）F_α⁻¹(t) = inf{ x : F_α(x) ≥ t }，则最优映射 T = F_β⁻¹ ∘ F_α，且

Wpp(α, β) = ∫₀¹ | F_α⁻¹(t) − F_β⁻¹(t) |p dt

读法：把两个分布都按"累计质量 t ∈ [0,1]"重新编号，同一编号处的位置差取 p 次方再积分。W₁ 尤其简单：W₁ 就是两条累积分布函数之间的面积（∫|F_α − F_β| dx，由换元可得与上式一致）。

✅ 手算示例 1：两个对称二点分布的 W₁

μ = 0.5δ₀ + 0.5δ₂，ν = 0.5δ₁ + 0.5δ₃。

分位数：F_μ⁻¹(t) = 0（t ≤ 0.5）、2（t > 0.5）；F_ν⁻¹(t) = 1（t ≤ 0.5）、3（t > 0.5）。

W₁ = ∫₀¹ |F_μ⁻¹ − F_ν⁻¹| dt = ∫₀^0.5 |0−1| dt + ∫_0.5¹ |2−3| dt = 0.5 × 1 + 0.5 × 1 = 1。

验证：最优耦合 π(0,1) = 0.5、π(2,3) = 0.5，每对距离 1，总成本 0.5×1 + 0.5×1 = 1 ✓。

✅ 手算示例 2：非对称权重，必须走分位数

μ = (1/3)δ₀ + (2/3)δ₁，ν = 0.5δ₀ + 0.5δ₂。求 W₁。

第1步（分位数）：F_μ⁻¹(t) = 0（t ≤ 1/3）、1（t > 1/3）；F_ν⁻¹(t) = 0（t ≤ 1/2）、2（t > 1/2）。

第2步（分段积分）：断点 1/3 与 1/2 把 [0,1] 切成三段——

区间F_μ⁻¹F_ν⁻¹差贡献
[0, 1/3]0000
[1/3, 1/2]101(1/2 − 1/3) × 1 = 1/6
[1/2, 1]121(1 − 1/2) × 1 = 1/2

第3步（求和）：W₁ = 0 + 1/6 + 1/2 = 2/3 ≈ 0.667。

对账：μ 在 0 处有 1/3，ν 在 0 处要 0.5——μ 得从 x=1 调 1/6 到 0（走 1 个单位）；μ 在 1 处剩 2/3 − 1/6 = 1/2 全部运到 2（走 1 个单位）。成本 = 1/6 × 1 + 1/2 × 1 = 2/3 ✓。分位数积分与"逐个消缺口"的直觉完全吻合。

第二条结论常被忽略但极其有用：一维时 p 无论取几，最优耦合都是同一个（单调重排），p 只改变"距离差的计费方式"。这让一维 OT 成为所有高维近似方法（第6章切片）的免费午餐。

💡 关键一跃

分位数函数是把任意分布"拉直成均匀分布"的那把熨斗：F⁻¹(t) 告诉你第 t 份质量坐在哪里。一维 OT 就是在熨平后的坐标系里做竖式减法——这解释了为什么直线上 OT 便宜（排序 O(n log n) 即解），也埋下了第6章 Sliced Wasserstein 的全部思想：把高维投影成一堆一维，逐维熨平再平均。

⚠️ 常见误区

以为"一维最优 = 按位置顺序一一配对"在非对称权重下仍成立。例2里 μ 的 x=1 处有 2/3 质量，要被劈成两股（1/6 回头到 0，1/2 前送去 2）——一对一映射根本不存在，必须允许质量分裂（Monge 失败、Kantorovich 兜底，第2章的松弛在这里现身）。闭式解用分位数而非"配对"，正是为了天然容纳分裂。

5.4距离之上的几何：位移插值与 Wasserstein 重心

有了距离，下一个本能问题是：这个距离空间里有没有"直线"？答案是肯定的，而且比欧氏空间的直线更有内容。

设 T 是从 μ 到 ν 的最优映射（一维或平方成本下它存在，第6章 Brenier 定理给保证），位移插值（Displacement Interpolation，McCann 1997）定义为

μt = ( (1−t)·id + t·T )# μ，  t ∈ [0,1]

读法：每个粒子 x 沿直线匀速滑向自己的目的地 T(x)，t 时刻的全体快照构成 μ_t。可以证明 μ_t 是 Wasserstein 空间里的测地线（Geodesic）：W₂(μ_s, μ_t) = |t − s|·W₂(μ₀, μ₁)。对比朴素线性插值 (1−t)μ + tν——那只是两个分布"叠化"，中间时刻出现重影；位移插值是"形状真的在搬家"，中间时刻是一个个像样的中间形状。这就是为什么图形学里形变动画（morphing）用 OT 而不是淡入淡出。

✅ 手算示例 3：两个单点分布的插值，测地线逐点验证

μ = δ₀，ν = δ₂（ℝ 上），T(x) = x + 2。

μ_t = δ_{(1−t)·0 + t·2} = δ_{2t}：t=0 时在 0，t=0.5 时在 1，t=1 时在 2。

验证测地线性质：W₂(μ_s, μ_t) = |2t − 2s| = |t−s| × 2，而 W₂(μ₀,μ₁) = 2，恰好 W₂(μ_s,μ_t) = |t−s|·W₂(μ₀,μ₁) ✓——等速、无弯折，这就是"直线"。

对比线性插值：(1−t)δ₀ + tδ₂ 在 t=0.5 时是 {0,2} 两点各半——中间形状是"劈开的两个重影"，不是 δ₁。差距一目了然。

插值是两个分布的事，重心是任意多个的事。Wasserstein 重心（Wasserstein Barycenter）：给定分布 ν₁…ν_K 与权重 λ_k ≥ 0（∑λ_k = 1），

ν* = arg minν ∑k=1..K λk W22(ν, νk)

它是"在 Wasserstein 几何里的加权平均"：欧氏空间里平均是 ∑λ_k x_k，这里平均的是整个分布。应用图景很直接：把同一字体的 26 个字母各看作一个形状分布，"平均字体"就是 Wasserstein 重心；把一组人脸照片看作像素分布，重心给出"平均脸"且保留清晰边缘（线性平均只会糊）。

重心还有一个更几何的读法：重心坐标与流形上的插值。固定一组"锚"分布 {ν_k}，任何分布 ν 都可以通过求解重心问题的反问题，被表示成权重 λ(ν)——这组权重就是 ν 在以锚为顶点的 Wasserstein 单纯形上的"重心坐标"。在这层坐标里做线性插值，再映回分布空间，就实现了"沿流形插值"：权重空间直线移动，分布空间沿测地网滑动。第7章的域适应里"把目标域表示成源域类别的凸组合"用的正是这套坐标。

💡 关键一跃

本章的三件套是一条升级链：对偶给出"价格" → 最优值成为"距离" → 距离上长出"几何"（测地线、重心、坐标）。OT 至此不再是一个优化问题，而是一个带有完整几何结构的分布空间——应用章节里所有"对齐、插值、平均"的操作，都是在这个空间里做初等几何。

⚠️ 常见误区

把 Wasserstein 重心等同于逐点线性平均 ∑λ_k ν_k。两者天壤之别：两个相距 10 的单峰分布，线性平均是双峰（两团质量原地保留、各半），Wasserstein 重心是中间位置的单峰（质量整体搬过去）。混用这两者在图像平均、形状匹配里会得到完全不同的结果——要"平均形状"用重心，要"混合样本"用线性。

概念卡 1
Kantorovich 对偶（Kantorovich Duality）
点击翻面 →
定义max ∫φ dμ + ∫ψ dν，约束 φ(x)+ψ(y) ≤ c(x,y)。
解决问题给运输成本一套"价格"解释，并是证明 W_p 性质的工具。
直觉外包公司报价：不敢越过任何一条真实运费。
误区把 φ 当成位置的固有属性；它依赖整个问题且平移不唯一。
何时用第6章半离散对偶、第7章 WGAN 的 KR 对偶。
概念卡 2
c-变换（c-transform）
点击翻面 →
定义φ^c(y) = inf_x [c(x,y) − φ(x)]，给定 φ 时 ψ 的最优选择。
解决问题把双函数对偶压缩成单函数无约束问题。
直觉报价顶到约束上沿，一分利润不浪费。
误区以为 φ 任意；距离成本下最优 φ 自动 1-Lipschitz。
何时用第7章 WGAN：W₁ = sup_{Lip f≤1} E_μ f − E_ν f 的来源。
概念卡 3
Wasserstein 距离（Wasserstein Distance）
点击翻面 →
定义W_p(α,β) = (min_π ∫ d(x,y)^p dπ)^{1/p}。
解决问题在分布之间给出带底空间几何的真距离。
直觉搬运计费：感知整体平移，不像 KL 只看同点差值。
误区忘掉 1/p 次方——不开方的最小成本不是距离。
何时用一切需要"分布间距离"的场景；第7章 ML 损失。
概念卡 4
粘合引理（Gluing Lemma）
点击翻面 →
定义π₁∈U(α,β) 与 π₂∈U(β,γ) 可粘成三边际耦合 σ(x,y,z)。
解决问题W_p 三角不等式的证明工具。
直觉以中间站 β 为桥，把两段运输拼成一张三联运单。
误区以为拼接自动成立；需要按条件分布显式构造。
何时用所有需要"经由中间分布接力"的论证。
概念卡 5
分位数函数（Quantile Function）
点击翻面 →
定义F⁻¹(t) = inf{x : F(x) ≥ t}，第 t 份质量的位置。
解决问题一维 OT 闭式解：W_p^p = ∫₀¹|F_α⁻¹−F_β⁻¹|^p dt。
直觉把分布熨平成均匀后的坐标尺。
误区以为一维最优是一对一映射；权重不等时质量必须分裂。
何时用第6章 Sliced Wasserstein 的核心引擎。
概念卡 6
位移插值（Displacement Interpolation）
点击翻面 →
定义μ_t = ((1−t)id + tT)#μ，粒子沿最优映射匀速滑动。
解决问题给出 Wasserstein 空间的测地线（分布间的"直线"）。
直觉搬家的中途快照，而不是两张照片叠化。
误区与线性插值 (1−t)μ+tν 混用——后者中间出重影。
何时用形状 morphing、第7章图形学应用。
概念卡 7
Wasserstein 重心（Wasserstein Barycenter）
点击翻面 →
定义argmin_ν Σ λ_k W₂²(ν, ν_k)，分布的加权几何平均。
解决问题在分布空间定义"平均形状"，并给出重心坐标。
直觉把多个分布往中间搬，而不是原地混合。
误区当成线性平均 Σλ_k ν_k；分离单峰会变双峰。
何时用第7章域适应的目标表示、第8章多边际 OT。

📝分层习题

L1 概念辨析判断对错：既然强对偶保证原问题与对偶问题最优值相等，那么求出对偶最优解 (φ, ψ) 后，任意满足 φ(x)+ψ(y) = c(x,y) 的 (x,y) 对都可以作为最优传输的运输对。
提示

互补松弛条件只在最优耦合的支撑集上成立；反方向的蕴涵需要什么？

完整解答

错。方向反了：互补松弛说"最优耦合 π* 的支撑集上必有 φ(x)+ψ(y)=c(x,y)"（π* 只走价格顶满的边），但"等号成立的 (x,y)"可能比 π* 的支撑集大得多——所有顶满约束的边构成一个图，最优耦合只是其中一个满足边际的子图。例如 μ=ν=均匀于 {0,1}、c=|x−y| 时 φ≡0、ψ(y)=y 使 (0,0)、(1,1) 顶满，但 (0,0) 与 (1,1) 之外还有别的对偶解能让别的边也顶满。易错点：把"支撑集 ⊂ 等号集"误读成"等号集 = 支撑集"。

L1 概念辨析选择：下列量中，满足距离三公理（同一性、对称性、三角不等式）的是（A）min_π ∫ d(x,y)² dπ（B）W₂ = (min_π ∫ d(x,y)² dπ)^{1/2}（C）KL(μ‖ν)（D）熵正则代价 ⟨C, P_ε⟩。
提示

逐个检查同一性（μ=ν 时是否为 0）与三角不等式（Minkowski 需要哪一步）。

完整解答

B。A 错：不开平方时三角不等式不成立（Minkowski 只对范数成立）；C 错：KL 不对称，且支撑不同时为无穷，连同一性方向的有限性都没有；D 错：第4章算过 μ=ν 时 ⟨C,P_ε⟩ = 0.424 ≠ 0，同一性直接失败。易错点：A 与 B 只差一个开方，正是这个开方决定了"是不是距离"。

L2 手算推导μ = 0.25δ₀ + 0.75δ_₂，ν = 0.5δ₁ + 0.5δ₃。用分位数闭式解手算 W₁，并给出对应的最优耦合验证。
提示

断点在哪里？分三段积分；耦合验证时让 μ 的 x=2 处质量劈成两股。

完整解答

F_μ⁻¹(t) = 0（t ≤ 0.25）、2（t > 0.25）；F_ν⁻¹(t) = 1（t ≤ 0.5）、3（t > 0.5）。断点 0.25、0.5 分三段：

[0, 0.25]：|0−1| = 1，贡献 0.25；[0.25, 0.5]：|2−1| = 1，贡献 0.25；[0.5, 1]：|2−3| = 1，贡献 0.5。

W₁ = 0.25 + 0.25 + 0.5 = 1。

耦合验证：π(0,1) = 0.25（μ 的 0 全给 ν 的 1），ν 的 1 还缺 0.25 由 π(2,1) = 0.25 补上，剩余 π(2,3) = 0.5。成本 = 0.25×1 + 0.25×1 + 0.5×1 = 1 ✓。注意 x=2 的 0.75 质量被劈成 0.25 + 0.5 两股——Monge 映射不存在，Kantorovich 耦合兜底。

L2 手算推导设 μ = δ_a、ν = δ_b 为 ℝ 上两个单点分布。(i) 写出位移插值 μ_t；(ii) 验证 W₂(μ_s, μ_t) = |t−s|·W₂(μ,ν)；(iii) 计算 ν₁ = δ_a、ν₂ = δ_b 各半权重的 Wasserstein 重心，并与线性平均比较。
提示

重心问题是 min_ν ½W₂²(ν,δ_a) + ½W₂²(ν,δ_b)；先对候选 ν = δ_x 求解，再论证一般解也是单点。

完整解答

(i) T(x) = x + (b−a)，μ_t = δ_{a + t(b−a)}。

(ii) W₂(μ_s, μ_t) = |a + t(b−a) − a − s(b−a)| = |t−s|·|b−a| = |t−s|·W₂(μ,ν) ✓。

(iii) 对 ν = δ_x：½(x−a)² + ½(x−b)²，求导 (x−a) + (x−b) = 0，x = (a+b)/2。一般情形：重心目标 ∫(x−a)²dν + ∫(x−b)²dν 的一半…完整写法：令 m = ∫x dν 为 ν 的均值，展开 ½E[(X−a)²] + ½E[(X−b)²] = E[X²] − m(a+b) + (a²+b²)/2，在均值固定为 (a+b)/2 时由 E[X²] ≥ m² 取等 ⟺ ν 是单点。故重心 = δ_{(a+b)/2}。线性平均 = ½δ_a + ½δ_b 是双峰——两者完全不同：重心把质量搬到中点，线性平均原地各留一半。

L3 建模应用你在做字体设计工具：已把 10 款黑体字体的字母"a"轮廓各自转成单位质量的形状分布 ν₁…ν_₁₀。产品经理要求生成"介于这 10 款之间的平均字体"。同事的方案是把 10 个轮廓图做像素级加权平均。指出该方案的问题，给出你基于本章工具的完整方案（含目标函数、几何含义、需要的数值子程序）。
提示

像素平均对形状做了什么？重心问题的输入输出各是什么？

完整解答

像素平均的问题：两个位置错开的细笔画平均后变成"两条淡笔画"而非"中间一条笔画"——线性平均保留质量位置、只调浓度，笔画会重影、发虚，这是把分布当图片混合。

方案：求 Wasserstein 重心 ν* = argmin_ν Σ_{k=1..10} (1/10) W₂²(ν, ν_k)。几何含义：在 W₂ 几何里找"到 10 款字体距离平方和最小"的分布，笔画会被整体搬到折中位置而非叠化。数值子程序：离散化后（每款字体 → 点云/网格分布），用第4章 Sinkhorn 计算 W₂² 及其对 ν 的梯度，迭代更新重心（barycentric Sinkhorn 迭代：交替求各 ν_k 到当前重心的耦合、再按耦合力矩更新重心位置与质量）；要中间风格时调整权重 λ 即可在同一框架内滑动（重心坐标）。
