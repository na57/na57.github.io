2.1Monge 的原始定义：为什么"每堆土整体搬"会无解

第1章把分布比作土堆，说距离是"最小搬运代价"。Monge 1781 年的原始想法是：给每一点 x 处的土指定一个去向 T(x)，整个搬运由一张传输映射（Transport Map）T 完成。它要满足两件事：

第一，土都搬对了地方——这就是推前测度（Push-forward Measure）约束：

T#μ = ν，  即对任意集合 B：  ν(B) = μ( T⁻¹(B) )

读法：目标区域 B 收到的土，恰好等于所有"被 T 送进 B"的出发点的土。第二，总代价最小：

minT : T#μ = ν ∫ c( x, T(x) ) dμ(x)

这个定义干净利落，但藏着一个致命刚性：每个 x 处的质量必须整体去同一个地方 T(x)，不许劈开。下面的例子让它当场翻车。

⚠️ 无解反例（必须记住）

μ = δ₀（1 单位土全在 0），ν = 0.5δ₋₁ + 0.5δ₁（左右各要 0.5）。任何映射 T 只能把 0 送到一个点：T(0)=−1 则右边收不到土，T(0)=1 则左边收不到土。不存在满足 T#μ = ν 的映射。可直觉上"把土劈成两半"明明可行——Monge 的定义把可行解挡在了门外。

即使映射存在，Monge 问题的约束集 {T : T#μ = ν} 也非凸：两个合法映射的平均一般不再是映射（平均后一个 x 被送到两个地方）。非凸约束 + 可能为空，这个定义无法作为计算起点。

💡 关键一跃

修 bug 的思路只有一个：允许质量劈分。不再问"x 去哪儿"，改问"x 的质量里有多大比例去 y"。优化对象从"映射"换成"一张从出发地到目的地的流量表"。

2.2Kantorovich 的松弛：把映射换成耦合，问题永远有解

上一节说 Monge 死在"不许劈分"。Kantorovich 1942 年的松弛只用一步就盘活全局：引入耦合（Coupling）π(x,y)——"从 x 搬到 y 的质量"。它只需要满足两条边际约束（Marginal Constraints）：

Π(μ,ν) = { π ≥ 0 : ∫π(x,y)dy = μ(x)，∫π(x,y)dx = ν(y) }

第一行说"从 x 运出的总量恰好是 x 的土"，第二行说"运进 y 的总量恰好是 y 的需求"。离散情形下 π 就是一张非负矩阵 P，行和等于 μ 的权重向量 a，列和等于 ν 的权重向量 b。Kantorovich 问题：

minπ ∈ Π(μ,ν) ∫ c(x,y) dπ(x,y)

注意三点：Π(μ,ν) 是凸集（两个耦合的凸组合仍是耦合）；它永远非空（独立耦合 π = μ⊗ν 总在里头）；目标函数对 π 是线性的。凸集上线性函数的最小值——这是一个标准线性规划，第3章的全部算法都建立在这一步上。

回头看 2.1 的无解例：耦合 π 允许 δ₀ 的质量劈成 0.5 去 −1、0.5 去 1，Kantorovich 问题立刻有解，代价 = 0.5×1 + 0.5×1 = 1。松弛把"不可能的搬运"变成"一张合法的流量表"。

⚠️ 常见误区

以为耦合 π(x,y) 是"x 和 y 的联合分布"就完事了。它确实是联合分布，但边际被钉死：行和列和必须分别等于 μ 和 ν。随便一个联合分布不行——独立耦合 μ⊗ν 是合法但几乎从不最优的极端。

2.3一维闭式解：分位数函数把最优耦合直接写出来

上一节把问题化成 LP，但 LP 要留给第3章。一维情形有个奢侈的例外：不用解 LP，最优耦合有闭式解（Closed-form Solution）。工具是分位数函数（Quantile Function）——累积分布函数（CDF）的广义逆：

F⁻¹(t) = inf{ x : F(x) ≥ t }，  t ∈ [0,1]

直觉：把 μ 和 ν 各自看成一条 [0,1] 上的"质量传送带"，F⁻¹(t) 是 μ 带上 t 处的位置，G⁻¹(t) 是 ν 带上 t 处的位置。最优方案 = 同刻度对齐：μ 带上 t 处的质量搬去 ν 带上 t 处。这叫单调重排（Monotone Rearrangement）——两堆土都从最左端开始配对，绝不交叉。

Wp(μ,ν)p = ∫₀¹ | F⁻¹(t) − G⁻¹(t) |ᵖ dt
✅ 手算示例：两个三原子分布的分位数积分

μ = 0.3δ₁ + 0.3δ₂ + 0.4δ₅，ν = 0.5δ₀ + 0.5δ₄。先把分位数函数分段写出来：

t 区间[0, 0.3)[0.3, 0.5)[0.5, 0.6)[0.6, 1]
F⁻¹(t)（μ）1225
G⁻¹(t)（ν）0044
|F⁻¹−G⁻¹|1221

W₁ = 0.3×1 + 0.2×2 + 0.1×2 + 0.4×1 = 0.3 + 0.4 + 0.2 + 0.4 = 1.3。

W₂² = 0.3×1² + 0.2×2² + 0.1×2² + 0.4×1² = 0.3 + 0.8 + 0.4 + 0.4 = 1.9（W₂ ≈ 1.38）。

最优耦合顺带读出：μ 的 0.3（在1）→ ν 的 0.3（在0）；μ 的 0.2（在2）→ ν 的 0.2（在0）；μ 的 0.1（在2）→ ν 的 0.1（在4）；μ 的 0.4（在5）→ ν 的 0.4（在4）。

为什么单调重排最优？交叉必可改进：若 x₁ < x₂ 却配成 x₁→y₂、x₂→y₁（y₁ < y₂），交换成 x₁→y₁、x₂→y₂ 后代价不增（对 c(x,y)=|x−y|ᵖ、p≥1 逐一验证不等式即可）。于是任何最优方案都可"梳"成单调的。

⚠️ 常见误区

把分位数闭式解当成普遍规律。它只在一维成立；二维以上没有单调性的天然替代品，闭式解一般不存在（c = 二次型且 μ 高斯时是著名特例，第5章会见）。高维老老实实回到 LP（第3章）或 Sinkhorn（第4章）。

2.4Kantorovich 对偶：用"定价"重新讲述同一个问题

LP 必有对偶，Kantorovich 问题的对偶是全书最有经济学直觉的对象。引入两端的对偶势（Dual Potentials）φ(x)、ψ(y)，对偶问题是：

maxφ, ψ ∫ φ(x)dμ + ∫ ψ(y)dν，  s.t.  φ(x) + ψ(y) ≤ c(x,y)

经济读法：你把搬运外包给一家公司。公司在出发地 x 按 φ(x) 向你收"装车费"，在目的地 y 按 ψ(y) 给你"卸货补贴"；它要保证自己报价有竞争力——任何地方的组合报价 φ(x)+ψ(y) 都不能超过你自己搬的市价 c(x,y)。公司利润最大化（∫φdμ + ∫ψdν）时，它的最高报价恰好等于你自己搬的最小代价——这就是强对偶。

✅ 手算验证：2×2 例的强对偶

沿用 2.2 的例子：μ=(0.4,0.6) 在 {0,1}，ν=(0.7,0.3) 在 {0,2}，C=[[0,4],[1,1]]，原始最优值 = 0.6。

取对偶势 φ = (0, 1)（即 φ(0)=0, φ(1)=1），ψ = (0, 0)。验证四条约束：

(x,y)φ(x)+ψ(y)c(x,y)≤ 成立？
(0,0)00✓（取等）
(0,2)04✓
(1,0)11✓（取等）
(1,2)11✓（取等）

对偶值 = 0.4×0 + 0.6×1 + 0.7×0 + 0.3×0 = 0.6 = 原始值，强对偶验证完毕。再看取等的位置 (0,0)、(1,0)、(1,2)——恰好是最优耦合 π* 的三个非零元！这不是巧合：互补松弛（Complementary Slackness）说 πᵢⱼ > 0 的位置必有 φᵢ+ψⱼ = cᵢⱼ。

一个重要的特例：当 c(x,y) = |x−y|（底距离本身）时，可以证明最优处 ψ = −φ 且 φ 是 1-Lipschitz 的，对偶坍缩成 Kantorovich–Rubinstein 公式（Kantorovich–Rubinstein Duality）：

W₁(μ,ν) = max‖φ‖Lip ≤ 1 ∫ φ dμ − ∫ φ dν

这个"对 Lipschitz 函数取最大期望差"的形式，就是第8章 WGAN 判别器的数学原型。

💡 一句话记住对偶

原始问题算"最小搬运费"，对偶问题算"外包公司敢报的最高价"，两者相等。对偶势 φ、ψ 不只是数学工具——它给每条运输路线发了"是否最省"的证书（互补松弛）。

📝分层习题

L1 概念辨析判断对错：Kantorovich 问题的最优耦合存在时，它一定对应某个 Monge 映射（即质量不需要劈分）。
提示

回想 2.2 节 2×2 例的最优解 π* = [[0.4,0],[0.3,0.3]]：x=1 的质量去了几个地方？

完整解答

错。2×2 例的最优耦合把 x=1 的 0.6 劈成 0.3+0.3 送往两处，任何映射都做不到这一点（映射要求 π 每行至多一个非零元）。一般地，最优耦合是映射当且仅当某种"非退化"条件成立（连续情形 μ 无原子时由 Brenier 类定理保证，第5章）；离散情形下最优解经常是真正劈分的。易错点：把"最优解存在"与"映射形式的最优解存在"混为一谈。

L1 概念辨析选择：下列哪个对象一定属于 Π(μ,ν)？（A）最大化 ∫c dπ 的 π（B）独立耦合 μ⊗ν（C）满足 π≥0 的任意联合分布（D）最优对偶势 (φ,ψ)。
提示

Π 的定义只有两条边际约束加非负，逐个核对。

完整解答

B。μ⊗ν 的两个边际天然就是 μ 和 ν，永远在 Π 里——这也证明了 Π 非空。A 错：最大化者未必在 Π 中（何况我们求最小）。C 错：任意非负联合分布的边际可以不是 μ、ν。D 错：对偶势是对偶问题的变量，不是耦合。

L2 手算推导μ = 0.5δ₀ + 0.5δ₂，ν = 0.5δ₁ + 0.5δ₃，c(x,y)=|x−y|²。先写出成本矩阵，参数化 Π(μ,ν)，再求最优耦合与最小代价。
提示

成本矩阵四个元素是 (0−1)²、(0−3)²、(2−1)²、(2−3)²；设 π₁₁=t 用边际约束推出其余三格与 t 的范围。

完整解答

步骤1：C = [[1, 9], [1, 1]]（行 x=0,2；列 y=1,3）。

步骤2：π₁₁=t ⇒ π₁₂=0.5−t，π₂₁=0.5−t，π₂₂=t；非负要求 t∈[0, 0.5]。

步骤3：代价 = t + 9(0.5−t) + (0.5−t) + t = 5 − 8t，随 t 递减，取 t = 0.5。

步骤4：π* = [[0.5, 0], [0, 0.5]]，最小代价 = 5 − 4 = 1。读法：0→1、2→3，各搬 0.5 单位、单位代价 1。本例最优解恰好是映射（对角耦合），与上一道 L1 题形成对照。

L2 手算推导μ = 0.25δ₀ + 0.25δ₁ + 0.5δ₃，ν = 0.5δ₂ + 0.5δ₄。用分位数函数手算 W₁ 与 W₂²。
提示

断点在 t = 0.25, 0.5, 1（μ）与 t = 0.5（ν）；合起来把 [0,1] 切成 [0,.25)、[.25,.5)、[.5,1] 三段。

完整解答

步骤1：分段。F⁻¹：t∈[0,.25) 取 0，[.25,.5) 取 1，[.5,1] 取 3。G⁻¹：t∈[0,.5) 取 2，[.5,1] 取 4。

步骤2：三段距离 |[0,.25): |0−2|=2；[.25,.5): |1−2|=1；[.5,1]: |3−4|=1。

步骤3：W₁ = 0.25×2 + 0.25×1 + 0.5×1 = 0.5 + 0.25 + 0.5 = 1.25。

步骤4：W₂² = 0.25×4 + 0.25×1 + 0.5×1 = 1 + 0.25 + 0.5 = 1.75（W₂ ≈ 1.32）。

L3 建模应用某城市有 2 个仓库（存量 0.4、0.6）和 2 个商店（需求 0.7、0.3），单位运输成本是距离的平方，数据与 2.2 节 2×2 例相同。老板问："为什么不让仓库 1 也分担一点商店 2 的需求？" 用对偶势的语言向老板解释最优方案（0.4 留本地、0.3+0.3 从仓库 2 发出）为什么合理。
提示

用对偶势 φ=(0,1)、ψ=(0,0) 算出每条路线的"报价余量" c − φ − ψ，看哪条路线余量最大。

完整解答

对偶势 φ=(0,1)、ψ=(0,0) 给出各路线报价余量：(0→店1) 0−0−0=0（顶格在用）；(1→店1) 1−1−0=0（顶格在用）；(1→店2) 1−1−0=0（顶格在用）；(0→店2) 4−0−0=4（余量 4，闲置）。

解释：仓库 1 → 商店 2 的自搬市价是 4，而公司报价只有 0——走这条路每单位要亏 4 的"机会成本"，所以最优方案一克都不走（互补松弛：余量 > 0 的路线 π=0）。仓库 1 的 0.4 全部就近供给店 1 是免费的；店 1 剩余 0.3 需求与店 2 的 0.3 由仓库 2 以单位成本 1 供应。

建模要点：成本用距离平方会强烈惩罚长途（4 vs 1），最优解倾向于"近处饱和供应"；若成本改为距离本身，结论会不同——成本函数的选择本身就是业务决策。

  • B. 势函数不能超过 1
