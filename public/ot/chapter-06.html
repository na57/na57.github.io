6.1Brenier 定理：平方成本下最优方案是一张"凸梯度"地图

第5章确认 W_p 是距离，但 Kantorovich 耦合 π 是联合测度——连续域上它是一个无穷维对象，既存不下来也算不动。第2章的老问题回来了：什么时候方案能塌缩成一张映射？回忆 Monge 问题（Monge Problem）：找映射 T 最小化

infT : T#μ = ν ∫ c(x, T(x)) dμ(x)

第2、5章都见过它的死穴：μ = δ₀、ν 两点劈开时，一个点不能拆两半，映射不存在。但有一类成本 + 一类源分布，死穴消失——这就是本章第一块基石。

Brenier 定理（Brenier's Theorem，1991）：取平方欧氏成本 c(x,y) = ‖x − y‖²，若 μ 在 ℝᵈ 上绝对连续（absolutely continuous，有密度、不给任何零测集质量），则最优 Monge 映射存在且（μ-几乎处处）唯一，并且它恰是某个凸函数的梯度：

T = ∇u，  u : ℝᵈ → ℝ 为凸函数

为什么是"凸梯度"？一维时凸函数 u 的导数 u′ 单调不减——T = ∇u 就是"单调映射"的高维推广：不交叉、不翻转，近处的点送去近处。这与第5章一维"最优方案必单调"的直觉完全咬合。再看必要条件：最优处扰动 T 一小步成本不降，变分运算恰好给出 T = ∇(‖x‖²/2 − φ(x)) 的形式，其中 φ 是第5章的对偶势；‖x‖²/2 − φ 凸当且仅当对偶约束顶紧——Brenier 映射就是第5章价格体系在平方成本下的显影。

✅ 手算示例：U[0,1] 搬到 U[2,3]

μ = U[0,1]，ν = U[2,3]，c(x,y) = (x−y)²。一维最优映射由单调重排给出（分位数复合，第5章工具）：

F_μ(x) = x（x ∈ [0,1]）；F_ν(y) = y − 2（y ∈ [2,3]），故 F_ν⁻¹(t) = 2 + t。

T(x) = F_ν⁻¹(F_μ(x)) = x + 2。验证推前：x ~ U[0,1] ⟹ x+2 ~ U[2,3] ✓。

W₂² = ∫₀¹ (x + 2 − x)² dx = ∫₀¹ 4 dx = 4。与第5章分位数闭式核对：∫₀¹ |t − (2+t)|² dt = 4 ✓。

再看 u：T = u′ ⟹ u(x) = x²/2 + 2x，u″ = 1 > 0，确为凸函数——Brenier 预言的"凸梯度"在最小的例子里显形。

💡 关键一跃

Brenier 把"找无穷维耦合"变成"找一个凸函数"——优化空间从测度变成函数，且结构极强（梯度场、无交叉）。平方成本是钥匙：只有它让一阶条件直接给出梯度形式。换 |x−y| 之类的成本，最优映射可以大片不唯一（运输退化成"整段平移任意滑"）。

⚠️ 常见误区

把 Brenier 当成"任何两个分布间都有最优映射"。错，两个条件缺一不可：成本必须是平方型（更准确地说是扭曲条件满足的成本），μ 必须绝对连续。反例就在眼前：μ = δ₀、ν = 0.5δ₁ + 0.5δ_₃，质量必须劈叉，Monge 解不存在，只有 Kantorovich 耦合兜底（第5章 L2 习题刚算过这种劈叉）。

6.2半离散 OT：连续分布对点云，对偶塌缩成有限维凸函数

上一节要求两边都是"好"的连续分布。可现实最常见的局面是：一边连续（密度模型、渲染图像），一边离散（点云 y₁…y_m 带权重 bⱼ）。这叫半离散 OT（Semi-discrete OT）。它的惊人之处在于：对偶问题从无穷维自动塌缩成 m 维。

回看第5章对偶 max ∫φ dμ + ∫ψ dν。ν = Σⱼ bⱼδ_{yⱼ} 时，ψ 只需要在 m 个点 yⱼ 上取值——ψ 变成一个 m 维向量。再用 c-变换把 φ 顶到约束上沿：φ(x) = min_j [c(x, yⱼ) − ψⱼ]。对偶目标变成只含 ψ ∈ ℝᵐ 的凹函数：

g(ψ) = ∑j ψⱼ bⱼ + ∫ minj [ c(x, yⱼ) − ψⱼ ] dμ(x)

这个结构有漂亮的几何读法。固定 ψ，每个源点 x 会选择"调整后最便宜"的目标点——x 归给使 c(x,yⱼ) − ψⱼ 最小的那个 j。于是源空间被切成 m 块，第 j 块叫 Laguerre 单元（Laguerre Cell，即 power diagram 的胞腔）：

Lj(ψ) = { x : c(x, yⱼ) − ψⱼ ≤ c(x, yₖ) − ψₖ  ∀k }

ψⱼ 的经济含义沿用第5章：站点 yⱼ 的"收货补贴"——ψⱼ 越高，j 越抢手，单元越大。最优传输的约束只剩一句话：每个单元的 μ-质量恰好等于 bⱼ。g(ψ) 的梯度正是 (bⱼ − μ(Lⱼ(ψ)))，所以求解 = 用牛顿法/梯度法调 ψ 直到各单元质量达标。

💡 一句话看穿几何：这就是一次加权距离变换

平方成本时展开 c(x,yⱼ) − ψⱼ = ‖x‖² − 2⟨x,yⱼ⟩ + ‖yⱼ‖² − ψⱼ，比较它等价于比较加权平方距离场 ‖x − yⱼ‖² − ψⱼ——Laguerre 图就是对 m 个站点的加权距离做一次欧氏距离变换（weighted Voronoi / power diagram），单元边界即距离场相等处。ψ=0 时退化为普通 Voronoi 图；ψ 非零就是给每个站点发"半径补贴"再切蛋糕。

✅ 手算示例：一维两站点，全步骤

μ = U[0,1]（密度 1），ν = 0.5δ_{0.25} + 0.5δ_{0.75}，c = (x−y)²。设边界为 x*，单元 L₁ = [0, x*]，L₂ = [x*, 1]。

第 1 步：边界方程。两站在 x* 处调整后成本相等：(x* − 0.25)² − ψ₁ = (x* − 0.75)² − ψ₂。展开：x*² − 0.5x* + 0.0625 − ψ₁ = x*² − 1.5x* + 0.5625 − ψ₂ ⟹ x* = 0.5 + (ψ₁ − ψ₂)。

第 2 步：质量约束定 ψ。要求 μ(L₁) = x* = 0.5 ⟹ ψ₁ = ψ₂。对偶平移自由度（第5章：势加常数不变）允许取 ψ₁ = ψ₂ = 0，得 x* = 0.5。

第 3 步：算 W₂²。单元内全部质量运到本站：

W₂² = ∫₀^0.5 (x − 0.25)² dx + ∫_0.5^1 (x − 0.75)² dx = 2 × [ (x−0.25)³/3 ]₀^0.5 = 2 × (0.125/3 + 0.125/3) = 2 × (1/96) = 1/48 ≈ 0.0208。

对称性自检：μ 关于 0.5 对称、两站关于 0.5 对称 ⇒ ψ 必相等、边界必在中点 ✓。

⚠️ 常见误区

默认 ψ = 0（普通 Voronoi）就是最优划分。错：ψ=0 只在"普通 Voronoi 恰好质量匹配"时成立。上例若权重改成 (1/3, 2/3)，ψ 必须调整把边界推到 x* = 1/3——习题 L2 第二题就让你完整推一遍。半离散数值方法的全部工作量，就在"调 ψ 使单元质量等于 b"这一步。

6.3Sinkhorn divergence：把第4章欠下的熵偏差账还清

第4章留了一笔账：熵正则让 Sinkhorn 飞快，但 ⟨C, P_ε⟩ 不是距离——当时算出 μ = ν 时它竟等于 0.424 而非 0，同一性直接失败。如果拿它当机器学习损失（第7章的需求），模型会学到"把自己的分布挪开一点"这种荒唐梯度。Sinkhorn divergence（Sinkhorn Divergence）的修法朴素而有效：把两个"自运输"的偏差项减掉：

Sε(a, b) = OTε(a, b) − ½ OTε(a, a) − ½ OTε(b, b)

其中 OT_ε(a,b) = ⟨C, P_ε⟩ 是熵正则代价。接第4章的数：若 OT_ε(a,a) = OT_ε(b,b) = 0.424，则 S_ε(a,b) = OT_ε(a,b) − 0.424——那 0.424 的"直流偏置"被对称地抵消。

性质内容意义
同一性S_ε(a,a) = 0 自动成立结构使然，不用证明
非负性S_ε(a,b) ≥ 0（等号 ⟺ a = b）可以当损失/差异度量
ε → 0S_ε → OT（真实 Wasserstein 成本）小 ε 逼近第5章的尺子
ε → ∞S_ε → ½‖E[a] − E[b]‖² 型 MMD（能量距离）大 ε 退化为均值比较，插值于 OT 与 MMD 之间

实现上只比 Sinkhorn 贵一点：算三次 Sinkhorn（(a,b)、(a,a)、(b,b)），自项的缩放向量在迭代间可以复用。梯度经 Sinkhorn 层自动微分——第7章的生成模型损失函数到此配齐。

💡 关键一跃

信号处理直觉：OT_ε(a,b) 里混着一个与 a、b 各自"自缠绕程度"有关的直流分量，减掉两个自项就是去偏置。深层一点：OT_ε 可写成某种核范数的平方，S_ε 恰是对应的 MMD——非负性因此免费获得。

⚠️ 常见误区

以为 S_ε 彻底消除了 ε 的影响。没有——它消除的是"同一性失败"这类系统偏差，数值仍随 ε 变化（ε 大趋于 MMD、ε 小趋于 OT）。ε 依然要按第4章的尺度规则选：与成本矩阵的中位数同量级。另外 S_ε 不是距离（三角不等式一般不成立），当"差异度量/损失"用，别当"尺子"用。

6.4样本与切片：维数灾难面前，把高维问题射成一维

理论再美，现实给的不是密度函数而是 n 个样本 x₁…x_n。最直接的估计是插件估计（Plug-in Estimator）：用经验分布 μ̂ = (1/n)Σδ_{xᵢ} 算 W(μ̂, ν̂)。坏消息来得很快：E|W(μ̂,μ)| ~ n^{−1/d}。这就是维数灾难（Curse of Dimensionality）的统计形态——d=2 的图像要 1% 误差需 n ≈ 10⁴，d=100 的特征空间需要 n ≈ 10²⁰⁰，永远不够。

但第5章留了一张王牌：一维 W₂² 有分位数闭式解，排序即得，O(n log n)。Sliced Wasserstein 距离（Sliced Wasserstein Distance）的策略：把高维分布投影到所有一维方向上，对每个方向用闭式解，再对方向平均：

SW₂²(μ, ν) = ∫Sd−1 W₂²( Pθ#μ,  Pθ#ν ) dθ

P_θ(x) = ⟨x, θ⟩ 是到单位向量 θ 方向的投影。实现时随机采 L 个方向蒙特卡洛平均；每个方向上两个经验分布排序后逐位配对（一维单调重排，第5章），总成本 O(L·n log n)。SW 与 W 在弱收敛意义下等价（SW(μₙ,μ)→0 ⟺ μₙ⇀μ），所以它可以当替代品进损失函数。

✅ 手算示例：两个点的 SW₂²

ℝ² 中 μ = δ_{(0,0)}，ν = δ_{(1,0)}。方向 θ = (cos φ, sin φ) 上，两点的投影标量分别是 0 与 cos φ，一维 W₂² = cos²φ。于是

SW₂² = (1/2π) ∫₀^{2π} cos²φ dφ = (1/2π) × π = 1/2。

对比真实 W₂² = 1。SW ≠ W——它不是 W 的近似值，而是另一把共享拓扑的尺子。这一点必须钉死，否则后面所有使用都会误读数值。

💡 关键一跃

CT 扫描直觉：医生拍不到三维器官，就从所有角度拍一维投影再重建信息。Sliced Wasserstein 同理——方向积分把"高维无闭式解"换成"无穷多个一维闭式解的平均"。更妙的是投影与排序都可微，整条链路能反向传播。

⚠️ 常见误区

两个。其一：把 SW 当 W 的"高效近似算法"——上例算出 1/2 vs 1，数值本身不同，要的是它的拓扑与梯度方向，不是数值相等。其二：以为 L 个方向越大越接近 W——L 只降蒙特卡洛方差，极限是 SW 本身，永远到不了 W。需要真 W 的场合请回 Sinkhorn/半离散。

定义一维最优映射 T = F_ν⁻¹ ∘ F_μ，按分位数对齐搬运。
解决问题一维连续 OT 的显式解，手算与切片法的引擎。
直觉两队人各按身高排队，第 t 名配第 t 名。
误区以为一维也可劈叉时仍有映射；权重不等时必须用耦合。
何时用6.4 节 Sliced Wasserstein 每个投影方向的计算。
概念卡 3
半离散 OT（Semi-discrete OT）
点击翻面 →
定义μ 连续、ν = Σbⱼδ_{yⱼ} 的 OT；对偶塌缩为 m 维凹函数 g(ψ)。
解决问题连续密度对点云/网格的传输怎么算。
直觉给每个站点发补贴 ψⱼ，点源按调整后运费自选站点。
误区ψ=0 的普通 Voronoi 就是答案；质量不匹配时必须调 ψ。
何时用图形学网格生成、蓝噪声采样、第7章点云处理。
概念卡 4
Laguerre 单元（Laguerre Cell / Power Diagram）
点击翻面 →
定义Lⱼ(ψ) = {x : c(x,yⱼ)−ψⱼ 在所有站点中最小}。
解决问题半离散 OT 的几何显影：源空间的传输分区。
直觉加权距离变换切蛋糕；ψ 是每块蛋糕的"半径补贴"。
误区与普通 Voronoi 混同；ψ≠0 时边界偏移但仍是直线（平面）。
何时用半离散牛顿法：调 ψ 使 μ(Lⱼ)=bⱼ 的每一步迭代。
概念卡 5
Sinkhorn Divergence
点击翻面 →
定义S_ε(a,b) = OT_ε(a,b) − ½OT_ε(a,a) − ½OT_ε(b,b)。
解决问题熵正则代价的熵偏差（μ=ν 时值非零，第4章的 0.424）。
直觉减两个自项，像信号处理去直流偏置。
误区当成距离；三角不等式不成立，是差异度量不是尺子。
何时用第7章一切"以 OT 为损失"的 ML 训练。
概念卡 6
Sliced Wasserstein（SW）
点击翻面 →
定义SW₂²(μ,ν) = ∫_{S^{d−1}} W₂²(P_θ#μ, P_θ#ν) dθ。
解决问题高维样本下 W 的统计误差 n^{−1/d} 不可承受。
直觉CT 扫描：所有角度的一维投影平均，代替高维直算。
误区当成 W 的近似；它是共享拓扑的另一把尺子，数值不等。
何时用第7章生成模型、点云损失（O(L·n log n) 可微）。
概念卡 7
样本复杂度与维数灾难（Sample Complexity）
点击翻面 →
定义E|W(μ̂,μ)| ~ n^{−1/d}：n 个样本估计 W 的统计误差速率。
解决问题解释为什么高维 OT 不能靠"多采点"解决。
直觉d 维空间撒 n 个点，平均间隙 ~ n^{−1/d}，误差被间隙锁死。
误区以为 Sinkhorn 快就能对抗它；算法快 ≠ 统计误差小。
何时用第7章 mini-batch 偏差分析、何时改用 SW 的决策依据。

📝分层习题

L1 概念辨析判断对错：Brenier 定理保证 ℝᵈ 上任意两个概率分布之间都存在最优 Monge 映射 T = ∇u。
提示

定理对 μ 与成本各有什么要求？构造一个劈叉反例。

完整解答

错。两个条件缺一不可：(i) 成本为平方型 c = ‖x−y‖²；(ii) 源分布 μ 绝对连续（不给零测集赋质量）。反例：μ = δ₀，ν = 0.5δ₁ + 0.5δ_₃——单点质量必须劈成两股送往两处，任何映射都做不到，Monge 问题无解，只有 Kantorovich 耦合存在（第5章 L2 第一题刚手算过这种劈叉）。易错点：把"Kantorovich 松弛下总有解"误记成"Monge 下总有解"；Brenier 说的恰是"Monge 何时也有解"。

L1 概念辨析选择：下列量中，在 a = b 时严格为 0、且可直接用作无熵偏差的可微 OT 损失的是（A）OT_ε(a,b) = ⟨C, P_ε⟩（B）Sinkhorn divergence S_ε(a,b)（C）OT_ε(a,a)（D）εH(P_ε)。
提示

回忆第4章算过的 μ=ν 时哪个量等于 0.424。

完整解答

B。A 错：μ=ν 时 ⟨C,P_ε⟩ = 0.424 ≠ 0，同一性失败；C 错：那正是偏差项本身（自缠绕成本）；D 错：熵项是正则化子，不度量分布差异。B 对：S_ε(a,a) = OT_ε(a,a) − ½OT_ε(a,a) − ½OT_ε(a,a) = 0 恒成立，且可证明非负、凸、可微。易错点：A 与 B 数值相近时感觉"差不多"，但当损失用时，A 的系统偏差会被优化器利用，把分布往错方向推。

L2 手算推导μ = U[0,2]，ν = U[1,3]，c = (x−y)²。(i) 写出 Brenier 映射 T 与凸势 u；(ii) 计算 W₂²；(iii) 若成本换成 c(x,y) = |x−y|，W₁ 变吗？说明理由。
提示

一维单调重排；注意平移型问题里两种成本的关系。

完整解答

(i) F_μ(x) = x/2（[0,2]），F_ν⁻¹(t) = 1 + 2t。T(x) = F_ν⁻¹(F_μ(x)) = 1 + 2·(x/2) = x + 1。u′ = T ⟹ u(x) = x²/2 + x，u″ = 1 > 0 凸 ✓。

(ii) W₂² = ∫₀² (x + 1 − x)² · (1/2) dx = ∫₀² (1/2) dx = 1。（注意密度是 1/2 不是 1。）

(iii) 不变，W₁ = 1。一维纯平移中每个粒子都走距离 1，任何度量成本 |x−y| 的 p 次方在此例（距离恒为 1）下给出 1^p = 1。一般规律：一维 W₁ 不依赖"是否平方"，W₁ = ∫|F_μ⁻¹ − F_ν⁻¹| dt 总是成立；W₂ 才是平方成本的专属。易错点：(ii) 忘乘密度 1/2 会得 2。

L2 手算推导半离散手算：μ = U[0,1]，ν = (1/3)δ₀ + (2/3)δ₁，c = (x−y)²。(i) ψ₁ = ψ₂ = 0 时单元边界在哪、质量匹配吗？(ii) 调整 ψ 使质量匹配，求边界与 W₂²。
提示

边界方程 x² − ψ₁ = (x−1)² − ψ₂；质量匹配要求 L₁ = [0, x*] 的 μ-质量 = 1/3。

完整解答

(i) 边界方程：x*² − ψ₁ = (x*−1)² − ψ₂ ⟹ x*² − ψ₁ = x*² − 2x* + 1 − ψ₂ ⟹ 2x* = 1 + ψ₁ − ψ₂ ⟹ x* = 0.5 + (ψ₁−ψ₂)/2。ψ=0 时 x* = 0.5，μ(L₁) = 0.5 ≠ 1/3——不匹配，站点 0 的单元太大，要缩小 ⟹ 降低 ψ₁ 相对 ψ₂。

(ii) 质量匹配要求 x* = 1/3 ⟹ ψ₁ − ψ₂ = 2(1/3 − 1/2) = −1/3（取 ψ₂ = 0、ψ₁ = −1/3：站点 0 被"罚款"，单元收缩）。

W₂² = ∫₀^{1/3} x² dx + ∫_{1/3}¹ (x−1)² dx = [x³/3]₀^{1/3} + [(x−1)³/3]_{1/3}¹ = (1/81) + (0 − (−2/3)³/3) = 1/81 + 8/81 = 9/81 = 1/9 ≈ 0.111。

L3 建模应用你在做三维扫描后处理：激光雷达给出一个约 200 万点的地面点云（视为离散分布 ν），设计软件里有一个连续参数化的地形曲面模型（密度 μ_θ，θ 是少数形状参数）。目标：调 θ 让曲面的质量分布贴合点云。给出完整方案：选哪类 OT 工具、目标函数怎么写、梯度从哪来、为什么不用"直接 Sinkhorn 两经验分布"也不用 SW。
提示

一边连续一边离散是什么问题？μ_θ 有解析密度意味着什么？

完整解答

选型：半离散 OT。μ_θ 有连续密度、ν 是 200 万原子点云——正是半离散的设定。

目标函数：min_θ g_θ 的对偶值，即 W₂²(μ_θ, ν) = max_ψ { Σⱼ ψⱼbⱼ + ∫ min_j [c(x,yⱼ)−ψⱼ] dμ_θ }，内层用牛顿法解 ψ（每步要算 Laguerre 单元 Lⱼ(ψ) 的 μ_θ-质量及其对 ψ、θ 的导数）。

梯度：Danskin 定理——最优值对 θ 的梯度只需在最优 ψ* 处对 μ_θ 求导（ψ* 视为常数），单元积分对 θ 的导数由 μ_θ 的解析密度显式给出，全自动微分也可。

为什么不用两经验分布 Sinkhorn：把 μ_θ 离散化成 200 万点再跑 Sinkhorn 是 2×10⁶ 平方规模的核矩阵，内存爆炸且丢掉了 μ_θ 的解析结构。为什么不用 SW：本问题需要"真 W₂"的数值与映射（曲面贴合是几何任务，SW 是另一把尺子），且 μ_θ 连续可积分，半离散恰好精确利用这一点。额外收益：Laguerre 单元本身即"曲面上的分区图"，可直接可视化贴合质量。
