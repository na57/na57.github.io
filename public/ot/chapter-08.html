扩展与前沿：GW、非平衡、多边际

本章回答的核心问题：前七章的 OT 有三个隐藏假设——两边住在同一空间、质量严格守恒、一次只对齐两个分布。现实会逐条撕掉它们：词向量与图形不共享坐标（跨空间）、细胞会分裂（质量变化）、多视角数据要同时对齐（多边际）。本章给每条假设配一个扩展，并给全书主线收尾。

8.1Gromov–Wasserstein：没有共同坐标，就比"内部距离结构"

第7章的对齐都假设两边住在同一空间 ℝᵈ，可以算 c(x,y) = ‖x−y‖。但有一类对齐根本没有公共坐标：英文词向量对法文词向量、两个不同扫描仪出的三维形状、两张蛋白质接触图。坐标系本身不可比，唯一可比的是每个空间内部的"谁离谁远"。Gromov–Wasserstein 距离（Gromov–Wasserstein Distance）的想法：不比点，比距离矩阵。设 (X, d_X, a) 与 (Y, d_Y, b) 是两个带测度的度量空间，

GW²(a, b) = minπ ∈ Π(a,b) ∑i,j,k,l | dX(xᵢ, xₖ) − dY(yⱼ, yₗ) |² πij πkl

读法：耦合 π 把 xᵢ 配给 yⱼ、把 xₖ 配给 yₗ；若这两对的"内部距离"一致（d_X(xᵢ,xₖ) ≈ d_Y(yⱼ,yₗ)），惩罚为零。π 的任务是保结构：近者仍配近者，远者仍配远者。GW 为零当且仅当两空间"等距同构"（允许重标号与刚体变换）——所以它天生对旋转、平移、坐标轴置换免疫，这正是形状匹配想要的。

代价是结构：目标里出现 π_ij·π_kl，是 π 的二次函数——二次分配问题（Quadratic Assignment Problem, QAP），非凸、NP-hard，不再有 LP 的漂亮理论，也没有全局最优保证。工程上用固定点迭代（Fixed-point Iteration，条件梯度的特例）：固定当前 πⁿ，把目标对 π 的梯度算出来当作线性成本 M，解一个普通（熵正则）线性 OT 得 πⁿ⁺¹，反复迭代。每步只解一个第3、4章就会的问题。

✅ 手算示例：一步固定点迭代，全步骤

两个 2 点空间：X = {x₁,x₂}，d_X = [[0,1],[1,0]]；Y = {y₁,y₂}，d_Y = [[0,2],[2,0]]；权重 a = b = (0.5, 0.5)。初始 π⁰ = diag(0.5, 0.5)（x₁↔y₁、x₂↔y₂）。

第 1 步：算梯度成本矩阵 M_ij = Σ_{k,l} (d_X(i,k) − d_Y(j,l))² π⁰_kl。π⁰ 只有对角两项 0.5，故 M_ij = 0.5(d_X(i,1) − d_Y(j,1))² + 0.5(d_X(i,2) − d_Y(j,2))²。

第 2 步：逐个元素。M₁₁ = 0.5(0−0)² + 0.5(1−2)² = 0.5；M₁₂ = 0.5(0−2)² + 0.5(1−0)² = 2 + 0.5 = 2.5；M₂₁ = 0.5(1−0)² + 0.5(0−2)² = 2.5；M₂₂ = 0.5(1−2)² + 0.5(0−0)² = 0.5。

第 3 步：解线性 OT min ⟨M, π⟩，边际 (0.5,0.5)。对角成本 0.5 远低于交叉 2.5，最优保持对角：π¹ = diag(0.5) = π⁰——一步收敛到固定点。

第 4 步：算 GW²。非零项只有 (i,j)=(k,l) 与两对交叉：(1,1,2,2) 与 (2,2,1,1) 各贡献 (1−2)²·0.5·0.5 = 0.25。GW² = 0.25 + 0.25 = 0.5。

几何读法：两个空间结构相同（两点对称），只是尺度差一倍——GW² = 0.5 精确度量了"结构对、尺度错"的失配，而经典 W 在这种坐标不可比时根本无从定义。

💡 关键一跃

GW 把"分布"升级为"度量空间 + 分布"（metric measure space）。比较对象从坐标变成关系——这与第5章的思想一脉相承：W 是"分布的几何"，GW 是"几何的几何"。固定点迭代的每步都在说：当前配对下，哪些配对让结构误差最小？

⚠️ 常见误区

把 GW 当成距离直接套第5章的性质。GW² 是二次型、非凸：固定点迭代只保证收敛到局部极小，初值不同答案不同（上例若从 π⁰ = 反对角出发会收敛到另一个解）。另外 GW 只能定义到"等距同构类"上——两个经刚体变换后完全重合的形状 GW = 0，这在形状分析里是特性，在需要区分朝向的任务里就是盲区。

8.2非平衡 OT：质量不守恒时，把硬约束换成软惩罚

经典 OT 的铁律：a、b 都是概率分布，总质量都为 1，耦合的两条边际约束是硬等式。但第7章没处理的场景大量存在：单细胞发育中细胞会分裂，总质量随时间增长；两张照片亮度总量不同；分布被裁剪、遮挡、部分观测。非平衡 OT（Unbalanced OT）的修法：硬约束软化为KL 惩罚（KL Penalty，也可用 TV 等散度），允许 P 的边际偏离 a、b，但按偏离程度付费：

minP ≥ 0 ⟨C, P⟩ + τ·KL(P𝟙 ∥ a) + τ·KL(Pᵀ𝟙 ∥ b)

其中 KL 用非归一化版本 KL(u∥v) = Σ u log(u/v) − u + v。τ 是"边际违规的单价"：τ → ∞ 收回经典 OT（不敢偏离）；τ 有限时，搬运太贵就让质量就地产生或湮灭——OT 从"守恒搬运"变成"搬运与买卖的混合经济"。

✅ 手算示例：质量怎么变——几何平均 √2

一点情形：a = 1·δ₀，b = 2·δ₀（同一点，目标要求两倍质量），c(0,0) = 0。设 P 在 (0,0) 放质量 m。

目标：f(m) = τ·KL(m∥1) + τ·KL(m∥2) = τ(m log m − m + 1) + τ(m log(m/2) − m + 2)。

一阶条件：f′(m) = τ log m + τ log(m/2) = τ log(m²/2) = 0 ⟹ m² = 2 ⟹ m = √2 ≈ 1.414。

读法：最优质量是两端的几何平均——源头"多产"0.414、终端"少收"0.586，两边各付一半 KL 罚款，谁也不用全额搬。质量不是被搬过去的，是在最优处被创造出来的。τ 越大罚款越贵，m 越贴近"少创造、多搬运"的经典行为。

好消息是算法几乎不用换。广义 Sinkhorn（Generalized Sinkhorn）仍是交替缩放，只是行/列缩放带上幂指数：

u ← ( a ∕ (Kv) )τ∕(τ+ε)，  v ← ( b ∕ (Kᵀu) )τ∕(τ+ε)

幂 τ/(τ+ε) ∈ (0,1)：τ → ∞ 时幂趋于 1，收回第4章的标准 Sinkhorn（硬边际）；τ 有限时每次只朝目标走"τ/(τ+ε) 步"，边际被允许保留偏差——软约束直接写进了迭代的指数里。KL 换成 TV 时，缩放公式再变，但"交替缩放"的骨架不变，这正是 Sinkhorn 框架的弹性。

💡 关键一跃

非平衡 OT 的统一视角：边际约束从"等式"降级为"散度惩罚"，τ 就是汇率——搬运成本与质量生灭成本在市场上竞争。单细胞 RNA 测序的轨迹推断（Waddington-OT）用的正是它：细胞分裂使总质量增长，KL 松弛让"今天的细胞"可以比"昨天的"多。

⚠️ 常见误区

先归一化再跑经典 Sinkhorn。归一化把"质量差"这个最重要的信号（细胞增殖率、遮挡比例）当噪声洗掉了——非平衡 OT 的全部价值恰在于保留并定价这个差。另一个误区：τ 取默认。τ 是物理量（每公斤质量的生灭价格），必须按场景标定，τ 太小则什么都不搬、全靠就地生灭。

8.3多边际 OT：k 个分布一起对齐，重心是它的特例

第7章的 Wasserstein 重心要同时顾及 k 个分布——这已不是"两两耦合"能表达的。多边际 OT（Multi-marginal OT）直接定义在 k 元联合张量上：给定 k 个分布 a₁…a_k 与 k 元成本 c(x₁,…,x_k)，

minπ ∈ Π(a₁,…,a_k) ∫ c(x₁,…,x_k) dπ(x₁,…,x_k)

可行集 Π(a₁,…,a_k) 要求 π 的 k 条边际（沿每个坐标轴投影）分别等于 a₁…a_k——第2章的两条边际约束升级为 k 条。耦合 π 是一张 k 维"运输表"：π(x₁,…,x_k) 表示 k 个分布各出一点组成"对齐的 k 元组"的概率。

最重要的特例就是第7章的重心：取成本为各点到均值的平方距离之和

c(x₁,…,x_k) = ∑i=1..k ‖ xᵢ − x̄ ‖²，  x̄ = 1k ∑i xᵢ

此时多边际 OT 的解恰好编码了"对齐的 k 元组的均值"，把所有 k 元组的均值按 π 加权就得到 Wasserstein 重心——重心 = 多边际 OT 的均值投影。Agueh–Carlier 正是用这条线把重心问题化成了多边际 LP。

✅ 手算示例：3 边际、2 点、全体一致免费

k = 3，每个分布 a₁ = a₂ = a₃ = (0.5, 0.5) 在 {0,1} 上，成本用上式（到均值的平方和）。

第 1 步：列成本。k 元组 (0,0,0)、(1,1,1)：x̄ = 0 或 1，c = 0。混合型如 (0,0,1)：x̄ = 1/3，c = (1/3)² + (1/3)² + (2/3)² = 1/9 + 1/9 + 4/9 = 2/3。由对称性，所有 6 个混合组 c = 2/3。

第 2 步：构造可行解。π 在 (0,0,0) 与 (1,1,1) 上各放 0.5：每条边际投影都给出 (0.5, 0.5) ✓。成本 = 0.5·0 + 0.5·0 = 0。

第 3 步：最优性。c ≥ 0 且达到 0，故为全局最优。读法：三方完全一致时对齐免费；任何"意见不合"的 k 元组都按到均值的距离付分裂税——重心成本结构奖励共识、惩罚分歧。

第 4 步：看规模。每个分布 n 个点时，π 是 nᵏ 维张量，边际约束 k·n 条——O(nᵏ) 组合爆炸：n=100、k=5 就是 10¹⁰ 个变量，LP 直接无解。

救场还是熵正则。多边际 Sinkhorn（Multi-marginal Sinkhorn）：熵正则化后最优解仍是缩放形式 π = diag(u₁) K diag(u₂) … diag(u_k)，K = exp(−C/ε) 是 k 维核张量，k 个缩放向量 u₁…u_k 交替更新（每个向量固定其余，让对应边际达标），每步复杂度仍为核张量的缩放入出。代价也照旧：ε 引入偏差（第4章的账），张量本身的存储 O(nᵏ) 仍在——实践中常用低秩/采样近似绕开显式张量。

💡 关键一跃

全书算法主线在这里汇拢：LP（Ch3）→ 熵正则 Sinkhorn（Ch4）→ 对偶（Ch5）→ 连续工具（Ch6）→ 应用（Ch7）→ 三个扩展全部沿用同一骨架——GW 每步解线性 OT、非平衡改缩放幂、多边际加缩放向量。框架的每个扩展都是老算法的再参数化，这就是 OT 作为"平台"的威力。

⚠️ 常见误区

把多边际问题拆成两两 OT 依次做。两两对齐不满足传递性（A 对齐 B、B 对齐 C 不蕴含 A、B、C 三方一致），只有 k 元张量上的联合约束能表达"全体一致"（上例的免费条款）。另一个误区：忘了重心的正确算法是多边际而非"轮流求两两 W₂ 平均"——轮流平均不收敛到真重心。

8.4全书收束：从搬土方到梯度流

八章走完了。回看主线：第1章把"搬土方"写成概率度量问题，第2章立起 Monge/Kantorovich 两种形式，第3章确认它是 LP，第4章用熵正则换来 Sinkhorn 的速度，第5章把最优值锻造成真距离 W_p 并展开对偶与几何，第6章把工具带进连续域（Brenier、半离散、S_ε、SW），第7章装进机器学习流水线，本章拆掉三条隐藏假设。剩下的前沿指针，记两个就够：

其一，Benamou–Brenier 动态公式（Benamou–Brenier Formula）：W₂² 不只能静态定义，它等于"最优流"的动能——在所有把 ρ₀ 连续演化到 ρ₁ 的速度场 v 中，

W₂²(ρ₀, ρ₁) = min(ρ, v) ∫₀¹ ∫ ‖v(x,t)‖² ρ(x,t) dx dt，  满足连续性方程 ∂ₜρ + ∇·(ρv) = 0

连续性方程就是质量守恒的微分形式。这条公式把 OT 接进流体力学与扩散：第5章的位移插值正是沿测地线的等速流。其二，JKO 格式（Jordan–Kinderlehrer–Otto Scheme）：要模拟热方程、多孔介质方程这类扩散/聚集过程，可以按时间步反复解 min_ρ W₂²(ρ, ρⁿ)/(2h) + F(ρ)——用 W₂ 距离当"惯性"、用能量 F 当"驱动力"，Wasserstein 几何让一大类 PDE 变成了梯度下降。这是 OT 通向分析学的大门，也是全书"几何"二字最深的兑现。

💡 一句话主线（全书的答案）

搬土方之问 → Monge/Kantorovich 立义 → LP 与 Sinkhorn 给算法 → 对偶成距离、连续域给工具 → 机器学习落地 → GW、非平衡、多边际拆掉最后的假设——OT 是一台"给分布世界造几何"的机器：先定义什么是"远"，再让一切计算沿这个"远"展开。

📝分层习题

L1 概念辨析判断对错：GW 距离为零当且仅当两个分布在同一坐标系下逐点重合。
提示

GW 比的是什么？旋转一个形状后 GW 变吗？

完整解答

错。GW = 0 当且仅当两个度量测度空间等距同构——允许重标号与刚体变换。旋转、平移、镜像一个形状后 GW 仍为零，这恰是 GW 的设计目标（形状匹配要对姿态免疫）。把"坐标重合"当成判定标准，等于把 GW 又拉回了需要共同空间的经典 W——两个概念的根本区别正在于此。易错点：在需要区分左右手（镜像）的任务里误用 GW，会发现它把互为镜像的形状判成零距离。

L1 概念辨析选择：非平衡 OT 中 τ 的作用是（A）控制熵正则强度（B）控制边际违规的惩罚单价，τ→∞ 收回经典 OT（C）控制迭代步数（D）控制质量总量。
提示

τ 出现在目标式的哪一项前面？广义 Sinkhorn 的幂里它扮演什么角色？

完整解答

B。τ 乘在两个 KL 惩罚项前，是"每公斤边际违规的价格"：τ→∞ 违规无限贵，回到硬边际的经典 OT；τ 有限则允许生灭。A 错：熵正则强度由 ε 控制（第4章的参数），τ 与 ε 在广义 Sinkhorn 的幂 τ/(τ+ε) 里各司其职；C 错：迭代步数由收敛阈值决定；D 错：质量总量由最优解内生决定（如本章的 √2），τ 只影响它的权衡。易错点：τ 与 ε 都出现在公式里，常记混——ε 管光滑，τ 管守恒。

L2 手算推导GW 固定点迭代的另一半：同 8.1 算例，但初值取反对角 π⁰ = [[0, 0.5],[0.5, 0]]（x₁↔y₂、x₂↔y₁）。(i) 重算梯度成本矩阵 M；(ii) 解线性 OT 给出 π¹；(iii) 算此配对下的 GW²，与 8.1 的 0.5 比较，说明非凸性的后果。
提示

M_ij = 0.5(d_X(i,1) − d_Y(j,2))² + 0.5(d_X(i,2) − d_Y(j,1))²（注意 π⁰ 的支持在反对角）。

完整解答

(i) M₁₁ = 0.5(0−2)² + 0.5(1−0)² = 2 + 0.5 = 2.5；M₁₂ = 0.5(0−0)² + 0.5(1−2)² = 0.5；M₂₁ = 0.5(1−2)² + 0.5(0−0)² = 0.5；M₂₂ = 0.5(1−0)² + 0.5(0−2)² = 2.5。M = [[2.5, 0.5],[0.5, 2.5]]。

(ii) 反对角成本 0.5 远低于对角 2.5，线性 OT 最优保持反对角：π¹ = π⁰——一步收敛到固定点。

(iii) GW²：非零交叉项 (1,2,2,1) 与 (2,1,1,2)：(d_X(1,2) − d_Y(2,1))²·0.25 = (1−2)²·0.25 = 0.25，两项合计 0.5。数值与 8.1 相同！读法：本例两个空间对称，两种配对 GW² 都是 0.5——两个局部极小值相同是巧合（对称性使然）；一般问题中不同初值收敛到 GW² 不同的局部解，这就是非凸的代价：没有全局保证，要多初值重启。易错点：以为"一步收敛"等于"全局最优"——它只是说明初值已经坐在局部极小上。

L2 手算推导非平衡 OT 的 τ 依赖：a = 1·δ₀，b = 2·δ₀，c(0,0) = 0 改为 c(0,0) = c₀ > 0（搬运也要花钱）。目标 f(m) = c₀·m + τ(m log m − m + 1) + τ(m log(m/2) − m + 2)。(i) 写出一阶条件；(ii) 求 m*（用 c₀、τ 表示）；(iii) 讨论 c₀ → ∞ 与 τ → ∞ 两个极限，给出经济读法。
提示

对 m 求导，log m 与 log(m/2) 的系数都是 τ，c₀ 是常数项。

完整解答

(i) f′(m) = c₀ + τ log m + τ log(m/2) = c₀ + τ log(m²/2) = 0。

(ii) log(m²/2) = −c₀/τ ⟹ m² = 2e^{−c₀/τ} ⟹ m* = √2 · e^{−c₀/(2τ)}。

(iii) c₀ → ∞（搬运无限贵）：m* → 0——宁可完全不生不灭也不搬，退化为"两边各自为政"。τ → ∞（违规无限贵）：m* → √2……注意此时 KL 惩罚把 m 锁向使两项 KL 都小的折中（几何平均），若再加上"总质量必须守恒"的硬约束（经典 OT），问题根本无可行解（1 ≠ 2）——这正说明非平衡松弛的必要性。经济读法：c₀/τ 是"搬运与生灭的比价"，比价越高越倾向不生不灭；m* 随比价指数衰减。易错点：把 τ→∞ 读成"回到经典"——经典问题在此不可行，τ→∞ 是"尽量接近经典"的极限。

L3 建模应用你实验室有三个平台测同一批细胞的基因表达：RNA-seq（平台 A）、ATAC-seq（平台 B）、蛋白组（平台 C）。三个平台 feature 空间完全不同、细胞数不同（各自 8000 / 9500 / 12000，且有细胞在部分平台死亡丢失）。要得到一个"对齐的细胞图谱"用于下游发育分析。给出完整方案：用本章哪几件工具、各自解决哪个假设缺口、怎么组合、怎么验收。
提示

空间不同 → ？质量不守恒 → ？三方同时 → ？

完整解答

三个缺口各配一件工具：

(i) 空间不同（无公共坐标）→ GW：每个平台内部算细胞-细胞距离矩阵 d_A、d_B、d_C（用各自 feature 的相关距离），用 GW 系列方法对齐结构。平台两两间没有可比的 c(x,y)，经典 W 无从定义。

(ii) 质量不守恒（细胞死亡/丢失、数量不同）→ 非平衡松弛：边际用 KL 惩罚而非硬等式，τ 按"细胞死亡比例"的生物学先验标定；绝不做"先归一化到同细胞数"。

(iii) 三方同时（两两对齐无传递性）→ 多边际/多向推广：用 GW 的多边际版（或多张量联合）让三个平台共享一个对齐结构，避免 A↔B、B↔C 分别对齐后 A 与 C 对不上。

组合：目标 = 多边际 GW（保结构）+ τ·KL 边际松弛（容许生灭），算法 = 固定点迭代（每步解一个非平衡多边际 Sinkhorn 子问题：k 个缩放向量、幂 τ/(τ+ε)），初值多重启几次取 GW 值最小者。

验收：三项——结构保持度（同一细胞群在三个平台的邻居重合率）；生物学合理性（发育轨迹的伪时间排序与已知标记基因一致）；稳健性（重抽样后对齐的耦合矩阵变化小）。下游发育分析若用到质量增长（细胞增殖），非平衡项的 τ 还要与增殖率联合校验。
