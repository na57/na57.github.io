3.1凸函数的定义：割线在曲线之上

第2章用"两点连线段不离开集合"定义了凸集。函数不是集合，没法直接套用，但函数有图像：把图像上两点连起来，就得到一条割线。如果整条割线都不低于曲线，这个函数就"向上弯"，这就是凸函数的全部定义。

定义（凸函数，Convex Function）。函数 f : ℝⁿ → ℝ 称为凸函数，如果它的定义域 dom f 是凸集，且对任意 x, y ∈ dom f 与任意 θ ∈ [0, 1]，都有

f(θx + (1 − θ)y) ≤ θf(x) + (1 − θ)f(y)

左边是"先插值自变量，再代入函数"（曲线上的点）；右边是"先算函数值，再插值"（割线上的点）。曲线不高于割线，函数就是凸的。若 θ ∈ (0, 1) 且 x ≠ y 时严格小于号恒成立，称 严格凸（Strictly Convex）；若 −f 凸，则称 f 为凹函数（Concave Function）。

数值验证。取 f(x) = x²，x = −1，y = 2，θ = 0.5（即中点）：

左边 = f(0.5·(−1) + 0.5·2) = f(0.5) = 0.25
右边 = 0.5·f(−1) + 0.5·f(2) = 0.5·1 + 0.5·4 = 2.5

0.25 ≤ 2.5 ✓。曲线在中点处只有 0.25，而割线中点是 2.5，割线远远在曲线之上。

图 3.2 凸函数的一维画像：绿点（曲线上）永远不低于橙点（割线上）。注意 θ ∈ [0,1]，这是与 Ch2 凸集定义同款的限制。

一个预告。f(x) = x⁴ 在 x = 0 处仍然是严格凸的（可以验证 x⁴ 的割线严格在曲线上方），但它的二阶导在 0 处等于 0——这个细节在 3.7 讲强凸时会回来咬人。

💡 关键一跃

凸函数的定义和凸集的定义是同一条"线段不等式"，只是作用对象从"点"换成了"函数值"。θ 同样被关进 [0, 1]——因为割线是线段，不是直线。

⚠️ 常见误区

把不等号方向记反。记忆锚点：凸函数"碗口朝上"，两点之间的曲线被割线罩在下面，所以是 f(插值点) ≤ 插值(f 值)。不等号反过来（≥）定义的是凹函数。

3.2一阶条件与二阶条件：两条判定捷径

上一节的定义要对所有 x、y、θ 验证，实操中根本查不完。如果函数可微，微积分给了两条捷径：一阶条件把"割线"换成"切线"，二阶条件把不等式换成"Hessian 半正定"。

一阶条件（First-Order Condition）。设 f 可微且定义域凸，则 f 凸 当且仅当对任意 x, y ∈ dom f：

f(y) ≥ f(x) + ∇f(x)ᵀ(y − x)

右边是 f 在 x 处的切线（切超平面）。整条切线是函数的全局下界——这是凸函数最重要的几何性质，Ch5 的对偶性正是从这里长出来的。

数值例。f(x) = x²，在 x = 1 处：∇f(1) = 2，切线为

ℓ(y) = f(1) + 2·(y − 1) = 1 + 2y − 2 = 2y − 1

取 y = 3 验证：ℓ(3) = 2·3 − 1 = 5，而 f(3) = 9，5 ≤ 9 ✓。取 y = 0 再验证：ℓ(0) = −1 ≤ 0 = f(0) ✓。切线永远趴在曲线下面。

二阶条件。设 f 二阶可微且定义域凸，则 f 凸 当且仅当对任意 x ∈ dom f：

∇²f(x) ⪰ 0（Hessian 半正定）

二元完整例子。f(x₁, x₂) = x₁² + 4x₂²。梯度 ∇f = (2x₁, 8x₂)，Hessian 为常数矩阵 diag(2, 8)。它的两个特征值是 2 和 8，全为正 ⟹ Hessian 处处正定 ⟹ f 凸（还是强凸，见 3.7）。

反例。f(x) = x³ 的二阶导是 6x，在 x < 0 时为负（比如 x = −1 处为 −6），二阶条件失败 ⟹ x³ 在 ℝ 上非凸。也可以直接看到它在 (−∞, 0) 上"碗口朝下"。

✅ 判定规则

实战判定凸函数的顺序：先看它是不是由已知凸函数经保凸运算组装出来的（3.5，最快）；不行再算 Hessian 查半正定（3.2）；都不行才回到定义或一阶条件硬证（3.1）。

⚠️ 常见误区

以为"二阶导处处非负"才等价于凸——漏了定义域必须凸这个前提。比如 f(x) = 1/x² 在 x > 0 与 x < 0 各自二阶导为正，但定义域若不连通（取成 ℝ\{0}），整体不是凸函数。先查定义域，再查 Hessian。

3.3上镜图与下水平集：把函数变回集合

上一节的两条捷径都要求可微。但 |x|、max 这类重要凸函数偏偏不可微。有没有一条不靠微积分的判定通道？有：把函数问题翻译回第2章的集合语言。

定义（上镜图，Epigraph）。函数 f : ℝⁿ → ℝ 的上镜图是 ℝⁿ⁺¹ 中的集合

epi f = { (x, t) ∈ ℝⁿ⁺¹ : x ∈ dom f, f(x) ≤ t }

一句话：函数图像上方（含图像）的全部点。对 f(x) = x²，epi f 就是抛物线"碗里"装满的整个区域。

桥定理。f 是凸函数 ⟺ epi f 是凸集。这就是本章与 Ch2 的桥：函数凸性的定义里藏着的那条割线，正是上镜图里两点连线不离开的条件。由此，Ch2 的全部保凸集运算都能搬过来为函数所用（3.5 的逐点最大就靠它）。

下水平集（Sublevel Set）。对任意 α ∈ ℝ，

Cα = { x ∈ dom f : f(x) ≤ α }

若 f 凸，则每个下水平集都是凸集。例：f(x) = x² 的 4-下水平集是 { x : x² ≤ 4 } = [−2, 2]，一个区间，显然凸。

⚠️ 常见误区

把"下水平集凸"当成充要条件。反之不然：f(x) = √|x| 的下水平集都是区间（凸），但它本身不是凸函数。下水平集恒凸的函数叫拟凸函数（Quasiconvex Function），是比凸更弱的一类，本书 Ch4 会一带而过。

💡 关键一跃

epi f 把"函数凸"变成"集合凸"，第2章的一整套工具（交集、仿射映射、分离超平面）立刻全部可用。数学里这种"换个空间看问题"的翻译手法，比正面硬刚省力得多。

3.4Jensen 不等式与凸函数例子库

定义里的割线不等式只涉及两个点。把它推广到"任意凸组合"甚至"期望"，就得到概率与机器学习中用得最多的一个不等式。

Jensen 不等式（Jensen's Inequality）。若 f 凸，则对任意随机变量 X（取值在 dom f 内）：

f(E[X]) ≤ E[f(X)]

数值验证。f(x) = x²，X 以各 1/2 的概率取 1 和 3：

E[f(X)] = 0.5·1² + 0.5·3² = 0.5 + 4.5 = 5
f(E[X]) = (0.5·1 + 0.5·3)² = 2² = 4 ≤ 5 ✓

直觉：凸函数"先平均再代入"比"先代入再平均"更省——波动会被凸性放大成额外的代价，这正是"方差 ≥ 0"的来源（E[X²] − (E[X])² = 5 − 4 = 1）。

例子库（每个都值得单独记住）。

函数定义域为什么凸（一句直觉）
eˣℝ二阶导 eˣ > 0，越涨越快
−log xx > 0二阶导 1/x² > 0；信息论的主角
xᵀQx（Q ⪰ 0）ℝⁿHessian = 2Q ⪰ 0，多维"碗"
任意范数（Norm）‖x‖ℝⁿ三角不等式 + 正齐次 ⟹ 割线不等式直接成立
max{x₁, …, xₙ}ℝⁿ若干平面取最高处，是一个"帐篷顶"
log-sum-exp：log(∑i exi)ℝⁿmax 的光滑逼近，Hessian 可证半正定

log-sum-exp 数值感。取 x = (0, 0)：f(0, 0) = log(e⁰ + e⁰) = log 2 ≈ 0.693。此时 max = 0，光滑逼近多付的代价是 log 2。再取 x = (0, 5)：log(1 + e⁵) ≈ log(148.4) ≈ 5.007，与 max = 5 只差 0.007——分量差距越大，逼近越准。

💡 关键一跃

Jensen 不等式是"定义不等式"对概率分布的推广：割线上的两点换成整个分布的重心。记住一个画面：碗底函数上撒一把点，函数值的平均永远在平均值的函数之上。

⚠️ 常见误区

把 −log x 和 log x 的凸性记混。log x 是凹的（二阶导 −1/x² < 0），它的相反数 −log x 才凸。机器学习里最小化的负对数似然，凸性来自那个负号。

3.5保凸运算：凸函数的乐高

上一节攒了一小盒"已知凸"的积木。这一节的问题是：怎么把积木拼成大件而不破坏凸性？保凸运算（Operations Preserving Convexity）就是拼搭规则。实战中 90% 的凸性论证都是"查积木 + 查规则"，而不是回到定义。

规则一：非负加权和。若 f₁, …, fₘ 凸且系数 wi ≥ 0，则 w₁f₁ + ⋯ + wₘfₘ 凸。例：3x² + 2eˣ 仍凸（两个凸函数的正系数组合）。注意系数必须非负：x² − eˣ 的凸性就要重新检查。

规则二：仿射复合。若 f 凸，则 g(x) = f(Ax + b) 凸。例：‖Ax − b‖² 凸（范数平方是凸函数，套上仿射映射仍凸）——最小二乘的目标函数就是这么来的。

规则三：逐点最大（Pointwise Maximum）。若 f₁, f₂ 凸，则 g(x) = max{ f₁(x), f₂(x) } 凸。用上镜图看最清楚：epi g = epi f₁ ∩ epi f₂，凸集的交集仍凸（Ch2 的规则）。

数值例。g(x) = max{ x², (x−2)² }。在 x = 1 处两段取值都是 1，正好相接：x < 1 时第一段更高（如 x = 0：max{0, 4} = 4），x > 1 时第二段更高（如 x = 2：max{4, 0} = 4）。接缝处没有尖坑，整体仍是一个"碗"，凸性完好。

规则四：标量复合。f(x) = h(g(x))，若 h 凸且非减、g 凸，则 f 凸。例：ex²——外层 h = eˣ 凸且单调增，内层 g = x² 凸，复合仍凸。可验证二阶导：(2 + 4x²)ex² > 0。

规则五（一个有名的新积木）：二次-over-线性。

f(x, y) = x²y，定义域 y > 0

它是凸函数（可用 Hessian 半正定验证）。数字感：f(2, 1) = 4/1 = 4；f(2, 4) = 1——分母越大代价越小。它在 Ch6 的逼近问题里会反复出现。

✅ 判定规则

标量复合口诀：外凸增、内任意凸 ⟹ 复合凸；若外层凸且非增，则要求内层凹。记不住就现场算二阶导，别凭感觉。

⚠️ 常见误区

以为"凸 ∘ 凸 = 凸"无条件成立。反例：h = e−x 凸（但递减），g = x² 凸，复合 e−x² 在原点附近是钟形，二阶导 (4x² − 2)e−x² 在 x = 0 处为 −2 < 0，非凸。外层必须非减这一条不能省。

3.6共轭函数：给凸函数一个"对偶画像"

到目前我们只用"点的位置"描述函数。还有第二种坐标系：用切线的斜率与截距描述函数。共轭函数就是这个翻译器，它是 Ch5 拉格朗日对偶的预热。

定义（共轭函数，Conjugate Function / Fenchel 共轭）。对任意函数 f : ℝⁿ → ℝ，定义

f*(y) = supx ∈ dom f ( yᵀx − f(x) )

读法：固定斜率 y，在所有 x 上找"斜率为 y 的直线与函数图像的最大缝隙"。这个最大缝隙就是该斜率对应切线的截距（取负）。

手算例 1：f(x) = x²/2。最大化 yx − x²/2。对 x 求导置零：y − x = 0，得 x = y（二阶导 −1 < 0，确为最大）。代回：

f*(y) = y·y − y²2 = y²2

二次函数的共轭还是二次函数——它在这种坐标变换下"自我封闭"。数字核对：y = 2 时 f*(2) = 2，而 supx(2x − x²/2) 在 x = 2 处取到 4 − 2 = 2 ✓。

手算例 2：f(x) = eˣ。最大化 yx − eˣ。当 y > 0，一阶条件 y − eˣ = 0 给出驻点 x = log y，代回：

f*(y) = y log y − y（y > 0）

数字核对：y = 1 时驻点 x = log 1 = 0，f*(1) = 1·0 − e⁰ = −1 = 1·log 1 − 1 ✓。指数函数的共轭是负熵函数——信息论里它们是同一件东西的两种写法。

为什么 f* 恒凸？固定 x，函数 y ↦ yᵀx − f(x) 是关于 y 的仿射函数（既凸又凹）。f* 是一族仿射函数的逐点上确界——逐点最大保持凸性（3.5 规则三推广到无穷多个），所以 f* 恒凸，无论 f 本身是否凸。

💡 关键一跃

函数有两种身份证：点值列表 (x, f(x))，或切线列表 (斜率 y, 截距 −f*(y))。共轭函数是从第一张身份证换到第二张。对凸函数而言两张身份证互相唯一确定（f** = f），这就是 Ch5 对偶的代数种子。

⚠️ 常见误区

以为求共轭时 sup 总能用"求导置零"解决。只有当 f 可微且驻点在内部时才行；遇到 |x| 这类不可微函数，sup 可能在不可微点或边界取到，要按段讨论。求导法只是顺手的工具，不是定义的一部分。

3.7强凸与条件数：凸也有"胖瘦"之分

到这里，x² 和 x⁴ 都是凸函数，判定通过。但它们的"碗形"完全不同：一个碗壁挺拔，一个在底部几乎是平的。这个差别不影响"能不能优化"，却直接决定第9章的算法"跑多快"。本章最后一节给这个差别定量。

定义（强凸，Strong Convexity）。函数 f 称为 m-强凸（m > 0），如果

g(x) = f(x) − m2‖x‖² 仍是凸函数

直觉：从 f 里减去一个碗口向上的抛物面之后居然还是凸的，说明 f 自己至少弯得比这个抛物面更厉害。可微时等价于 ∇²f(x) ⪰ mI（Hessian 的最小特征值不低于 m）。

正例。f(x) = x² 是 2-强凸：f″ = 2，减去 (m/2)x² 后剩 (2−m)/2·x²… 准确算：g(x) = x² − (m/2)x² = (1 − m/2)x²，当 m = 2 时 g = 0，是凸函数（线性函数既凸又凹）✓。

反例。f(x) = x⁴ 严格凸（3.1 预告过）但不强凸：f″(x) = 12x² 在 x = 0 处为 0，对任意 m > 0，在 0 附近都有 f″(x) < m，条件 ∇²f ⪰ mI 失败。严格凸只保证"没有平段"，不保证"弯得足够快"。

二次函数的条件数（Condition Number）。对 f(x) = ½xᵀQx（Q ≻ 0），有 m = λmin(Q)、M = λmax(Q)（最大特征值给出 Hessian 的上界 M I ⪰ ∇²f），定义

κ = Mm = λmax(Q)λmin(Q)

数值例。Q = diag(1, 100)：m = 1，M = 100，κ = 100。等高线是长轴与短轴之比为 10 的扁椭圆（长度比 = √100 : √1）。在这么扁的碗里，梯度下降会来回 zigzag、前进极慢——这是 Ch9 的核心痛点，也是预条件、动量法等加速技术存在的理由。κ 越接近 1，碗越圆，优化越快。

💡 关键一跃

凸性回答"局部最优 = 全局最优"（能不能解）；强凸与条件数回答"算法多快找到它"（解得多快）。m 管收敛速度的下界保证，κ 管等高线的畸形程度。

⚠️ 常见误区

把"严格凸 ⟹ 强凸"当成定理。x⁴ 就是反例：严格凸但 0 点处曲率为零，任何 m > 0 都守不住。三者关系要记牢：强凸 ⟹ 严格凸 ⟹ 凸，反向都不成立（线性函数凸但不严格凸）。

📝分层习题

L1 概念辨析f(x) = |x| 在 x = 0 处不可导。它还是凸函数吗？给出理由。
提示

凸函数的定义（3.1）里出现过"可导"两个字吗？回到定义，用绝对值的三角不等式验证割线不等式。

完整解答

是凸函数。定义只要求定义域凸（ℝ 是凸集 ✓）加割线不等式，不要求可导。验证：对任意 x, y ∈ ℝ 与 θ ∈ [0,1]，由绝对值的三角不等式与正齐次性，

|θx + (1−θ)y| ≤ |θx| + |(1−θ)y| = θ|x| + (1−θ)|y|，

正是割线不等式 ✓。几何上，|x| 是一个尖底碗，0 点处割线仍罩在曲线上方。易错点：把"可微"误当成凸的必要条件——一阶/二阶条件只是捷径，不是定义；不可微点处改用次梯度（本书不作展开）。

L1 概念辨析两个凸函数的乘积一定是凸函数吗？若是请证明，若不是请给反例。
提示

先试试两个最简单的凸函数 f(x) = g(x) = x（线性函数既凸又凹），乘积是什么？再试一正一衰减的组合，算二阶导看看变不变号。

完整解答

不一定。先看一个"碰巧成立"的陷阱：f(x) = x 与 g(x) = x 都凸（线性），乘积 x² 恰好仍凸——这容易让人误以为乘积保凸。

真正的反例：f(x) = x²（凸），g(x) = e−x（二阶导 e−x > 0，凸）。乘积 h(x) = x²e−x，求二阶导：

h′(x) = (2x − x²)e−x，

h″(x) = (2 − 2x)e−x − (2x − x²)e−x = (x² − 4x + 2)e−x。

取 x = 4：h″(4) = (16 − 16 + 2)e−4 = 2e−4 > 0；但取 x = 1：h″(1) = (1 − 4 + 2)e−1 = −e−1 < 0。二阶导变号 ⟹ h 非凸。

结论：保凸运算清单里没有乘法，3.5 的五条规则之外的操作都要重新证明。

L2 手算推导用二阶条件判定 f(x₁, x₂) = 2x₁² + x₂² − 2x₁x₂ 是否为凸函数。
提示

先写出梯度（两个一阶偏导），再写 2×2 Hessian（四个二阶偏导，交叉项各算一次）。2×2 矩阵正定的判别：左上角元素 > 0 且行列式 > 0（Sylvester 判据）。

完整解答

第一步：梯度。∂f/∂x₁ = 4x₁ − 2x₂；∂f/∂x₂ = 2x₂ − 2x₁。

第二步：Hessian。∂²f/∂x₁² = 4；∂²f/∂x₁∂x₂ = −2；∂²f/∂x₂∂x₁ = −2；∂²f/∂x₂² = 2。所以

∇²f = [ 4 −2 ; −2 2 ]（常数矩阵）

第三步：Sylvester 判据（顺序主子式全正 ⟺ 正定）。

一阶主子式：4 > 0 ✓

二阶主子式（行列式）：4·2 − (−2)·(−2) = 8 − 4 = 4 > 0 ✓

第四步：结论。Hessian 处处正定 ⟹ ∇²f ⪰ 0 恒成立（实则更强，是正定的），且定义域 ℝ² 是凸集 ⟹ f 是凸函数（事实上是 m-强凸，m = λmin = 3 − √5 ≈ 0.764，可不解出）。

L2 手算推导求 f(x) = x·log x（x > 0，负熵函数）的共轭函数 f*(y)。
提示

写出要最大化的函数 φ(x) = yx − x·log x；对 x 求一阶导置零解出驻点 x̂(y)；代回 φ 化简。注意 log x 的导数是 1/x，(x log x)′ = log x + 1。

完整解答

第一步：写出目标。f*(y) = supx > 0 φ(x)，其中 φ(x) = yx − x·log x。

第二步：一阶条件。φ′(x) = y − (log x + 1) = 0 ⟹ log x = y − 1 ⟹ 驻点 x̂ = ey−1 > 0，落在定义域内 ✓。

第三步：验证是最大值。φ″(x) = −1/x < 0（x > 0），φ 是凹函数，驻点即全局最大点 ✓。且 x → 0⁺ 与 x → ∞ 时 φ 都不超过驻点值。

第四步：代回化简。

φ(x̂) = y·ey−1 − ey−1·log(ey−1) = y·ey−1 − ey−1·(y − 1)

= ey−1·(y − (y − 1)) = ey−1·1 = ey−1。

结论：f*(y) = ey−1，y ∈ ℝ。核对：3.6 讲 eˣ 的共轭是 y log y − y，这里负熵的共轭是 ey−1——两者几乎互逆，只差一个平移，不是巧合（f** = f 的镜像关系）。

L3 建模应用要用一条直线 ŷ = a + bx 拟合三个数据点 (0, 1)、(1, 3)、(2, 2)，目标是最小化最大绝对残差（切比雪夫准则）：mina,b max{ |a − 1|, |a + b − 3|, |a + 2b − 2| }。说明这个目标函数为什么关于 (a, b) 是凸的，并计算 a = 1, b = 1 处的目标值。
提示

把每一项残差写成"a, b 的什么映射 + 什么函数"的复合？|·| 是什么函数的特例？三条规则串起来：范数（凸）→ 仿射复合 → 逐点最大。

完整解答

凸性论证（三步，全部来自 3.4 + 3.5）：

① 每项残差 rᵢ(a, b) = a + b·xᵢ − yᵢ 是 (a, b) 的仿射函数：如 r₂ = a + b − 3。

② 绝对值 |·| 是一维范数，范数是凸函数（3.4 例子库，三角不等式保证）。凸函数与仿射映射复合仍凸（规则二）⟹ 每项 |rᵢ(a, b)| 凸。

③ 三个凸函数的逐点最大仍凸（规则三）⟹ 目标函数 max{ |r₁|, |r₂|, |r₃| } 关于 (a, b) 凸。

所以这是一个无约束凸优化问题，任意局部最优即全局最优。

数值验证 a = 1, b = 1：

|a − 1| = |1 − 1| = 0；

|a + b − 3| = |1 + 1 − 3| = |−1| = 1；

|a + 2b − 2| = |1 + 2 − 2| = |1| = 1；

目标值 = max{0, 1, 1} = 1。此时最大残差出现在第 2、3 个点上（"最坏情形"被两个点同时顶住，这是 minimax 问题的典型现象）。

解析：B 正确——三者是严格递进的加强关系；x⁴ 在 0 点 f″=0，任何 m > 0 都在 0 附近守不住 ∇²f ⪰ mI。A 错：正是被 x⁴ 否定的命题；C 错：m-强凸（m > 0）要求 ∇²f ⪰ mI ≻ 0 处处成立，二阶导（最小特征值）不能取到 0；D 错：κ 越小碗越圆，梯度下降越快，κ 大才 zigzag 变慢（Ch9）。
