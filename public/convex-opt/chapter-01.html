1.1数学优化问题长什么样：把"选最好"写成一行公式

现实里"做决策"这件事无处不在：工厂要安排产量使利润最大，工程师要选参数使误差最小，投资者要配资产使风险最小、收益最大。它们千变万化，但都能压成同一个骨架——数学优化问题（Mathematical Optimization Problem）的标准形（Standard Form）：

minimize   f₀(x)
subject to   fi(x) ≤ 0,   i = 1,…,m
                 hi(x) = 0,   i = 1,…,p

各部件的名字：

  • x = (x₁,…,xn) 叫决策变量（Decision Variable）——我们能调的旋钮；
  • f₀ 叫目标函数（Objective Function）——要最小化的那个东西；
  • fi(x) ≤ 0 叫不等式约束（Inequality Constraint）；
  • hi(x) = 0 叫等式约束（Equality Constraint）；
  • 满足所有约束的 x 组成的集合叫可行域（Feasible Set），记作 𝒟 或 𝒳；
  • 可行域中使 f₀ 取到最小的点叫最优解（Optimal Point），记作 x*；对应的目标值叫最优值（Optimal Value），记作 p*。若可行域为空，约定 p* = +∞；若目标在可行域上无下界，约定 p* = −∞。
💡 关键一跃

优化问题 = "在三明治里挑最薄的"。决策变量是你可以动的层，约束是面包片和外皮（不能超出），目标函数是厚度。你的任务是在不破坏三明治的前提下把它压到最薄。

一个可以完整手算的例子。考虑二维问题：

minimize   (x₁ − 2)² + (x₂ + 1)²
subject to   x₁ + x₂ ≤ 0

第 1 步：先看无约束最优在哪里。目标是到点 (2, −1) 的平方距离，无约束最小值显然在 (2, −1) 处取得，值为 0。

第 2 步：检查这个点是否可行。代入约束：x₁ + x₂ = 2 + (−1) = 1 > 0，不可行。所以无约束最优不能直接用。

第 3 步：直觉——把不可行点"投影"到可行域边界上。目标函数的等值线是以 (2, −1) 为圆心的同心圆。可行域是直线 x₁ + x₂ = 0 左下方的半平面。最优可行点就是圆心到这条直线的垂足。圆心 (2, −1) 到直线 x₁ + x₂ = 0 的垂线方向是 (1, 1)/√2。垂足满足 x₁ + x₂ = 0 且 (x₁ − 2, x₂ + 1) 与 (1, 1) 平行，即 x₁ − 2 = x₂ + 1。联立两式：

x₁ + x₂ = 0
x₁ − x₂ = 3

相加得 2x₁ = 3 ⟹ x₁ = 1.5，于是 x₂ = −1.5。

第 4 步：算出最优值。

p* = (1.5 − 2)² + (−1.5 + 1)² = (−0.5)² + (−0.5)² = 0.25 + 0.25 = 0.5

所以 x* = (1.5, −1.5)，p* = 0.5。可以验算：1.5 + (−1.5) = 0，约束恰好压边界，完全可行。

⚠️ 常见误区

把"无约束最优"当成"约束最优"。本例中无约束最优 (2, −1) 不可行，直接拿来用会违反约束。约束优化的正确答案往往压在边界上，而不是停在目标函数的谷底。

1.2为什么一般优化问题难解：局部最优 ≠ 全局最优

上一节我们居然徒手解出了一个优化问题。但这容易让你误以为"优化不过如此"。真相是：一般的优化问题，没有已知的有效算法能可靠地求出全局最优。根本原因只有一句话——

✅ 核心事实

在一般的非线性优化中，算法能找到的往往只是局部最优（Local Optimum，附近没有比它更好的点），而我们真正想要的是全局最优（Global Optimum，整个可行域里最好的点）。二者可以相差很远。

一个能算清楚的一维例子。考虑无约束问题

minimize   f(x) = x⁴ − 3x² + x

求导得 f ′(x) = 4x³ − 6x + 1。代入几个点：

xf(x) = x⁴ − 3x² + xf ′(x)是什么
−1.55.0625 − 6.75 − 1.5 = −3.1875−13.5 + 9 + 1 = −3.5（近似为 0 附近）局部极小
11 − 3 + 1 = −14 − 6 + 1 = −1（近似为 0 附近）局部极小

两个局部极小值 −3.1875 和 −1 不一样！如果你从一个 x ≈ 1 的初始点出发做梯度下降，会收敛到 x ≈ 1 的那个坑，得到 −1；从 x ≈ −1.5 出发，会收敛到另一个坑，得到 −3.1875。算法看到了什么，取决于它从哪里出发。在一维你还能画出来看，到了 100 维你根本看不见。

除了多局部极小，一般优化还有别的坑：

  • 可行域不连通。例如约束 sin(x) ≥ 0 把可行域切成一段一段，算法从一个片段跳不到另一个；
  • 变量是离散或整数的。例如 x ∈ {0, 1}，求导和梯度都失去意义，组合数随规模指数爆炸；
  • 目标函数不可微、不可解析。可能是仿真输出，连梯度都拿不到。
⚠️ 常见误区

"我跑了梯度下降，得到了一个解，所以这是最优解。"——错。梯度下降最多保证收敛到某个局部最优（甚至只是驻点），全局最优没有任何保证。把它当成最优解，是许多工程事故的源头。

1.3两个可解的老前辈：最小二乘与线性规划

既然一般优化这么难，历史上有没有什么问题是被人类彻底驯服的？有，而且至少有两个——它们不是巧合，而是凸优化的两个特例。

① 最小二乘（Least Squares）

形式：minimize ‖Ax − b‖²，其中 A 是 m×n 矩阵，b 是 m 维向量。它没有约束，目标函数是二次型。它的解有闭式公式——正规方程（Normal Equations）：

x* = (AᵀA)⁻¹Aᵀb

前提：A 列满秩（这保证 AᵀA 可逆）。

完整手算一例。设 3 个数据点大致落在一条直线 y = a + bt 上，t = 0, 1, 2 时 y = 1, 2, 2。写成 Ax ≈ b：

A = ⎡1 0⎤
     ⎢1 1⎥
     ⎣1 2⎦,    b = (1, 2, 2)ᵀ,    x = (a, b)ᵀ

第 1 步：算 AᵀA。

AᵀA = ⎡1 1 1⎤ ⎡1 0⎤ ⎡3 3⎤
         ⎣0 1 2⎦ ⎢1 1⎥ = ⎣3 5⎦
                 ⎣1 2⎦

逐项验证：左上 = 1·1+1·1+1·1 = 3；右上 = 1·0+1·1+1·2 = 3；右下 = 0·0+1·1+2·2 = 5。

第 2 步：求逆。det(AᵀA) = 3·5 − 3·3 = 15 − 9 = 6。所以

(AᵀA)⁻¹ = 16 ⎡ 5 −3⎤
                    ⎣−3 3⎦

第 3 步：算 Aᵀb。

Aᵀb = (1·1 + 1·2 + 1·2,  0·1 + 1·2 + 2·2)ᵀ = (5, 7)ᵀ

第 4 步：相乘。

x* = 16 ⎡ 5 −3⎤ ⎡5⎤ 16 ⎡25 − 21⎤ 16 ⎡4⎤ ⎡2/3⎤
          ⎣−3 3⎦ ⎣7⎦ =         ⎣−15 + 21⎦ =         ⎣6⎦ = ⎣ 1 ⎦

所以最佳直线是 y = 2/3 + t。可以验算：t=0 时预测 0.667（实际 1，残差 −0.333）；t=1 时预测 1.667（实际 2，残差 −0.333）；t=2 时预测 2.667（实际 2，残差 0.667）。平方和 = 1/9 + 1/9 + 4/9 = 6/9 = 2/3，这是任何其他直线都无法再压低的。

② 线性规划（Linear Program, LP）

形式：目标与所有约束都是线性（仿射）函数。

minimize   cᵀx
subject to   Ax ≤ b

可行域是若干半空间的交集——一个多面体（Polyhedron）。核心几何事实：

✅ LP 顶点性质

线性规划如果有最优解，一定存在某个顶点（Vertex，多面体的角点）是最优解。直觉：目标函数是线性的，沿等值面方向往里推，推不动的时候一定卡在角上。

手算一例。

maximize   x₁ + x₂
subject to   x₁ + 2x₂ ≤ 4
                 x₁ ≥ 0, x₂ ≥ 0

可行域是三角形，三个顶点：(0, 0)、(4, 0)、(0, 2)。逐个代入目标：

顶点目标值 x₁ + x₂
(0, 0)0
(4, 0)4 ← 最大
(0, 2)2

最优解 x* = (4, 0)，最优值 p* = 4。简单到"枚举顶点就行"——这正是单纯形法（Simplex Method）的思想：在顶点之间跳跃，直到不能改进。

💡 关键一跃

最小二乘和线性规划看似风马牛不相及，但它们有一个共同点：都不存在"局部最优 ≠ 全局最优"的麻烦。最小二乘的目标是凸二次型，LP 的目标是线性（既凸又凹），可行域都是凸集。它们共享的护身符，叫"凸性"。

⚠️ 常见误区

把"LP 有最优解 ⟹ 唯一最优解在顶点"误读成"最优解一定唯一"。其实若目标等值线与多面体某条边平行，整条边都是最优解（顶点只是其中之一）。例如 max x₁ + x₂ 但约束改成 x₁ + x₂ ≤ 4，整条斜边上的点都是最优。

1.4凸优化：恰好可解的那一类

上一节我们看到：最小二乘和 LP 之所以好解，是因为它们"凸"。这一节把这种感觉变成定义。

定义预告（细节在第 2–4 章展开）。一个优化问题是凸优化问题（Convex Optimization Problem），如果：

  • 目标函数 f₀ 是凸函数（Convex Function）；
  • 所有不等式约束函数 f₁,…,fm 都是凸函数；
  • 所有等式约束函数 h₁,…,hp 都是仿射（Affine）的，即 hi(x) = aiᵀx − bi。

这套"凸 + 仿射"的组合换来一条金钥匙性质：

✅ 凸优化的核心性质

凸优化问题中，任何局部最优解都是全局最优解。（严格证明见第 4 章。）这意味着：只要你的算法找到任何一个局部最优，就可以放心地收工。

一个能严格论证的小例。

minimize   x₁² + x₂²
subject to   x₁ + x₂ ≥ 2

求解（用柯西不等式）。对任意可行点 (x₁, x₂)，由柯西不等式

(x₁ + x₂)² ≤ (1² + 1²)(x₁² + x₂²) = 2(x₁² + x₂²)

代入约束 x₁ + x₂ ≥ 2，得 4 ≤ (x₁ + x₂)² ≤ 2(x₁² + x₂²)，所以 x₁² + x₂² ≥ 2。等号成立当且仅当 (x₁, x₂) 与 (1, 1) 平行且取等，即 x₁ = x₂ = 1。所以 x* = (1, 1)，p* = 2。不需要迭代，纯靠不等式就把全局最优钉死——这就是凸问题的威力。

最小二乘和 LP 都是凸优化的特例：

  • 最小二乘：目标 ‖Ax − b‖² = xᵀAᵀAx − 2bᵀAx + bᵀb 是凸二次型；
  • LP：目标 cᵀx 线性（既凸又仿射），约束 aiᵀx ≤ bi 仿射（既凸又凹）。

凸优化把这两个老前辈统一到一个框架里，并开放出大量新问题——逼近、估计、控制、金融、机器学习——都能套进去求解。

⚠️ 常见误区

"凸 ⟹ 一定有闭式解。"错。最小二乘是少数幸运儿；多数凸优化没有显式解，需要迭代算法（第 9–11 章）。凸性保证的是"迭代算法不会被局部坑困住"，不是"不用迭代"。

本章的代价与遗留问题。本章声称"凸优化可解"，但留了一个明显的尾巴：给定一个函数、一个集合，凭什么说它是凸的？光凭"看起来像碗"不够，需要严格的定义、判定条件和一套保凸运算。这正是接下来两章的任务：

  • 第 2 章 凸集：把"可行域是凸的"这件事说死——什么叫凸集、哪些是现成的凸集、哪些运算保持凸性；
  • 第 3 章 凸函数：把"目标是凸的"这件事说死——凸函数的定义、判定条件（梯度、Hessian）、保凸运算。
💡 关键一跃

凸优化不是一个"算法"，而是一种问题分类学。它的价值不在于给你一个求解器，而在于告诉你：一旦你识别出问题是凸的，就可以放心套用一整箱成熟工具——这是从"无解"跨到"可解"的那一步。

⚠️ 常见误区

"学好凸优化 = 学会内点法。"错。内点法只是工具箱里的一件工具。真正的功夫在前两步：把问题识别为凸、把它写成标准形。很多工程师卡的不是算法，而是看不出问题是凸的。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
优化问题标准形（Optimization Problem in Standard Form）
点击翻面 →
定义min f₀(x) s.t. fᵢ(x)≤0 (i=1..m)、hᵢ(x)=0 (i=1..p)。
解决问题把任何"在限制下求最好"的决策问题统一成同一个代数骨架。
直觉像填一张标准表格：变量填什么、目标填什么、限制填什么。
误区以为约束只能是不等式；其实等式约束单独列一类（仿射时更友好）。
何时用Ch4 把所有凸优化问题都归到这个标准形下讨论。
概念卡 2
可行域与最优值（Feasible Set & Optimal Value）
点击翻面 →
定义可行域 = 满足所有约束的 x 之集；最优值 p* = inf f₀(可行域)。
解决问题把"约束"和"目标"分离，让我们能独立谈论"哪些点合法"与"哪个值最好"。
直觉可行域是操场，最优值是在操场里能跑出的最好成绩。
误区可行域空 ⟹ p* = 0；正确约定是 p* = +∞。
何时用Ch2 凸集就是专门研究可行域形状的章节。
概念卡 3
局部最优与全局最优（Local vs Global Optimum）
点击翻面 →
定义局部最优：某邻域内最优；全局最优：整个可行域内最优。
解决问题区分"算法能找到的"和"我们真正想要的"，是所有优化困难的根源。
直觉山里有多个坑；你蒙眼走路只能找到脚下的坑，不一定是最深的那个。
误区以为梯度下降收敛 = 找到全局最优；其实只保证到某个局部坑。
何时用Ch4 的核心定理就是"凸问题中二者合一"。
概念卡 4
最小二乘（Least Squares）
点击翻面 →
定义min ‖Ax − b‖²，目标为凸二次型，无约束。
解决问题拟合数据、最小化误差的最经典模型，有闭式解。
直觉把 b 投影到 A 的列空间上，垂足就是最优解。
误区以为总有唯一解；当 A 列不满秩时解不唯一，正规方程不可逆。
何时用Ch6 逼近与拟合整章都是它的扩展（加权、正则、鲁棒）。
概念卡 5
线性规划（Linear Program, LP）
点击翻面 →
定义min cᵀx s.t. Ax ≤ b（或加等式、变量非负）。
解决问题目标与约束全线性时的最优分配问题，应用面极广。
直觉可行域是多面体，最优解一定能在某个顶点上找到。
误区以为最优解必唯一；其实可能整条边/整个面都最优。
何时用Ch4 把它列为凸优化的标准特例；Ch6–8 大量应用。
概念卡 6
凸优化问题（Convex Optimization Problem）
点击翻面 →
定义标准形中 f₀ 与所有 fᵢ 凸、所有 hᵢ 仿射的优化问题。
解决问题圈出"可解"的问题类，让我们放心调用一整套算法。
直觉目标像一个碗，可行域像一个凸的盘子——谷底只有一个。
误区以为凸 ⟹ 一定有解析解；多数凸问题仍需迭代求解。
何时用Ch4 给形式定义与判定，Ch9–11 给通用求解算法。

📝分层习题

L1 概念辨析判断：问题 min x³ s.t. x ≤ −1 的最优值存在吗？若存在是多少？
提示

当 x → −∞ 时，x³ → ? 这个方向是否违反约束 x ≤ −1？

完整解答

可行域是 (−∞, −1]，非空。但当 x → −∞ 时，f(x) = x³ → −∞，且所有足够负的 x 都满足约束。所以目标在可行域上无下界，按约定 p* = −∞，不存在最优解（最优值"存在"但等于 −∞，没有取得它的 x）。

易错点：答"p* = −1"或"x* = −1"——那是把约束当成了下界。x ≤ −1 限制的是 x 不能太大，对 x 多小毫无约束。

L1 概念辨析概念边界：当可行域为空时，按约定最优值 p* 等于多少？为什么是这个约定而不是 0？
提示

回忆 p* 的定义：p* = inf{ f₀(x) | x 可行 }。空集的 inf 在数学里约定等于多少？min 是 inf 的一种。

完整解答

p* = +∞。理由：p* 定义为可行域上 f₀ 的下确界（inf）。空集的下确界约定为 +∞（因为任何实数都是空集的下界，"最大下界"是 +∞）。直觉：无可行点意味着"要满足约束得付出无穷大代价"。取 0 是错的——0 没有任何特殊地位，且会让"空约束"与"最优值恰为 0"不可区分。

L2 手算推导手算：min x² − 4x s.t. 0 ≤ x ≤ 1 的最优解与最优值。
提示

先配方，把目标写成 (x − a)² + b 的形式，看无约束最小在哪里；然后判断这个最小点是否在可行域内；不在的话比较端点。

完整解答

第 1 步：配方。f(x) = x² − 4x = (x − 2)² − 4。

第 2 步：找无约束最小。无约束下 f 在 x = 2 处取得最小值 −4。

第 3 步：检查可行性。x = 2 不满足 0 ≤ x ≤ 1，不可行。

第 4 步：分析目标在可行域上的形状。f 是开口向上的抛物线，对称轴 x = 2。在区间 [0, 1] 上（对称轴左侧），f 严格递减。所以最小值在右端点 x = 1 取得。

第 5 步：端点比较（保险起见都算）。f(0) = 0 − 0 = 0；f(1) = 1 − 4 = −3。

结论：x* = 1，p* = −3。

L2 手算推导用正规方程手算 min ‖Ax − b‖²，其中 A = (1, 1)ᵀ（2×1 列向量），b = (2, 4)ᵀ。
提示

x 是标量。先算 AᵀA（一个数），再算 Aᵀb（一个数），相除。

完整解答

第 1 步：AᵀA = (1, 1) · (1, 1)ᵀ = 1·1 + 1·1 = 2。

第 2 步：Aᵀb = (1, 1) · (2, 4)ᵀ = 1·2 + 1·4 = 6。

第 3 步：x* = (AᵀA)⁻¹Aᵀb = 6 / 2 = 3。

验证：‖Ax* − b‖² = (1·3 − 2)² + (1·3 − 4)² = 1 + 1 = 2。若换 x = 2.9，残差 (0.9)² + (−1.1)² = 0.81 + 1.21 = 2.02 > 2，确认 x* = 3 更优。直觉上，x* = 3 就是 2 和 4 的算术平均——一个数据点都没有时，"最佳拟合常数"就是均值。

L3 建模应用某工厂生产两种产品 A、B，每件利润分别为 3、5。生产受两类资源约束：(i) 工时：2x₁ + x₂ ≤ 10；(ii) 原料：x₁ + 2x₂ ≤ 8；产量非负。写出最大化利润的 LP，并枚举可行域所有顶点求出最优生产方案与最优利润。
提示

把"利润最大"写成线性目标；可行域是多边形，顶点坐标靠两两求约束交点得到；最后逐点代目标。

完整解答

LP 模型：

maximize   3x₁ + 5x₂
subject to   2x₁ + x₂ ≤ 10
                  x₁ + 2x₂ ≤ 8
                  x₁ ≥ 0, x₂ ≥ 0

求顶点。可行域由 4 条直线围成：x₁ = 0、x₂ = 0、2x₁ + x₂ = 10、x₁ + 2x₂ = 8。两两求交：

  • x₁ = 0 与 x₂ = 0：得 (0, 0)。
  • x₂ = 0 与 2x₁ + x₂ = 10：得 x₁ = 5，即 (5, 0)。检查另一约束：5 + 0 = 5 ≤ 8 ✓。
  • 2x₁ + x₂ = 10 与 x₁ + 2x₂ = 8：第一式 ×2 减第二式得 3x₁ = 12，x₁ = 4，代回得 x₂ = 2。即 (4, 2)。
  • x₁ = 0 与 x₁ + 2x₂ = 8：得 x₂ = 4，即 (0, 4)。检查另一约束：0 + 4 = 4 ≤ 10 ✓。

枚举目标值：

  • (0, 0)：3·0 + 5·0 = 0
  • (5, 0)：3·5 + 5·0 = 15
  • (4, 2)：3·4 + 5·2 = 12 + 10 = 22 ← 最优
  • (0, 4)：3·0 + 5·4 = 20

结论：最优生产方案 x* = (4, 2)——A 产品 4 件、B 产品 2 件，最大利润 22。

自测 1
下列哪个写法是优化问题的标准形？
  • A. max f₀(x) s.t. fᵢ(x) ≤ 0
  • B. min f₀(x) s.t. fᵢ(x) ≤ 0, hᵢ(x) = 0
  • C. min f₀(x) s.t. fᵢ(x) ≥ 0
  • D. 求 f₀(x) 的极小值，约束任意
B 对：标准形固定为 min（不是 max），不等式约束写成 fᵢ(x) ≤ 0，等式约束写成 hᵢ(x) = 0。
A 错：是 max；任何 max 都可以通过取负转化为 min，标准形只用 min。
C 错：不等号方向反了；标准形统一为 ≤ 0（若想 ≥，把函数取负）。
D 错："约束任意"不是数学形式；标准形要求明确列出每个约束为 ≤ 0 或 = 0。
自测 2
关于 p* 与 x* 的区别，下列说法正确的是？
  • A. p* 是一个点，x* 是一个实数
  • B. p* 与 x* 总是同时存在
  • C. p* 是最优值（实数或 ±∞），x* 是取得该值的可行点
  • D. 可行域为空时 p* = 0
C 对：p* 是值，x* 是点；二者类型不同。可行域空时 p* = +∞；目标无下界时 p* = −∞。
A 错：正好说反了——x* 是点，p* 是实数。
B 错：可以 p* 存在而 x* 不存在（如 L1-1，p* = −∞ 但没有任何 x 取得它）。
D 错：空可行域约定 p* = +∞，不是 0。
自测 3
为什么"梯度下降收敛了"不能保证"找到了全局最优"？
  • A. 一般问题可能有多个局部最优，梯度下降只能保证收敛到其中一个，依赖初始点
  • B. 梯度下降步长总是太大，跳过全局最优
  • C. 全局最优不存在
  • D. 梯度下降只适用于线性函数
A 对：一般非凸问题有多个局部坑（如 f(x) = x⁴ − 3x² + x 在 x ≈ −1.5 与 x ≈ 1 各有一个局部极小），梯度下降只保证走到某个局部最优，依赖初始点。
B 错：步长是收敛性问题，不是"局部 vs 全局"的根本障碍；小步长也跳不出局部坑。
C 错：全局最优通常存在（如连续函数在紧集上），只是算法找不到。
D 错：梯度下降适用于任何可微函数，但"可微"≠"凸"。
自测 4
最小二乘问题 min ‖Ax − b‖² 的解由正规方程 x* = (AᵀA)⁻¹Aᵀb 给出，前提是？
  • A. A 是方阵
  • B. b 在 A 的列空间里
  • C. A 是对称矩阵
  • D. A 列满秩，从而 AᵀA 可逆
D 对：正规方程的关键是 AᵀA 可逆，而这等价于 A 的列线性无关（列满秩）。
A 错：A 不必是方阵；最小二乘常见情形恰是 m > n 的"高矩阵"。
B 错：b 在 A 的列空间时残差为 0，是特例；一般 b 不在列空间，最小二乘才有意义。
C 错：A 不必对称；AᵀA 总是对称半正定，列满秩时是正定。
自测 5
关于线性规划（LP）的最优解，下列说法正确的是？
  • A. LP 的最优解一定唯一
  • B. 若 LP 有最优解，则必有某个顶点是最优解
  • C. LP 的最优解一定在可行域内部
  • D. LP 不能用枚举顶点的方法解
B 对：这是 LP 的核心几何性质，单纯形法的理论基础。
A 错：当目标等值线与多面体某边/面平行时，最优解不唯一（但仍有顶点最优解）。
C 错：恰好相反——线性目标在内部点总能再改进，最优一定在边界（顶点）上。
D 错：理论上枚举所有顶点就能解 LP（顶点数有限）；只是实际中顶点太多，单纯形法用"相邻跳跃"代替穷举。

🗣️ 用自己的话，三句话讲完本章

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：本章回答"什么样的优化问题是可解的"。一般优化问题因局部最优 ≠ 全局最优而难解，但凸优化问题恰好规避了这个麻烦——任何局部最优都是全局最优，所以可以被可靠且高效地求解。
句2：核心机制是什么？——
参考答案：核心机制是"凸性"：目标函数凸、不等式约束凸、等式约束仿射。凸性让目标等值面与可行域的几何都"规整"，保证局部信息（梯度）足以引导到全局最优，不会出现多个互不通气的局部坑。
句3：它和前后章怎么分工？——
参考答案：本章是地图——提出"凸优化可解"这个论断但不动手证明；第 2、3 章把"凸"变成可判定的几何（凸集）与代数（凸函数）语言；第 4、5 章在这个语言上定义凸优化问题并研究对偶；第 6–8 章做应用建模，第 9–11 章给求解算法。
