5.1拉格朗日函数：把约束"折进"目标

第4章把问题写成了标准形式：min f₀(x)，约束 fᵢ(x) ≤ 0（i = 1,…,m）、hᵢ(x) = 0（i = 1,…,p），最优值记 p*。但它带出一个问题：约束让搜索变得束手束脚——能不能把约束"消掉"，变成一个无约束问题？

想法朴素得像菜市场砍价：违反约束不被直接禁止，而是要交罚款。给第 i 个不等式约束定一个单价 λᵢ ≥ 0，违反多少（fᵢ(x) 超出 0 多少）就付多少；等式约束 hᵢ(x) 偏离 0 也要付费，但正负两个方向都可能偏，所以单价 νᵢ 可正可负。总账单就是拉格朗日函数（Lagrangian）：

L(x, λ, ν) = f₀(x) + ∑i=1..m λᵢ fᵢ(x) + ∑i=1..p νᵢ hᵢ(x)，λ ⪰ 0

λ 与 ν 叫拉格朗日乘子（Lagrange Multiplier），也叫对偶变量（Dual Variable）。λᵢ ≥ 0 这个限制是方向性的关键：我们只想惩罚"违反"（fᵢ > 0），不想奖励"宽松"（fᵢ < 0）——若允许 λᵢ < 0，最小化 L 时会故意把 fᵢ 压得很负来赚奖金，下界就失效了。

最小例子。min x²，约束 x ≥ 1。先写成标准形：1 − x ≤ 0。于是

L(x, λ) = x² + λ(1 − x)，λ ≥ 0

直观检查：若取 x = 0（违反约束 1 个单位），L = 0 + λ·1 = λ——比不罚的 f₀ = 0 贵了 λ；λ 越大，违反越不划算。而可行点 x = 2 处 L = 4 + λ·(−1) = 4 − λ ≤ 4：可行点上 L 永远不超过 f₀，因为罚款项 ≤ 0。这个不对称性正是下一节"下界机器"的燃料。

💡 关键一跃

拉格朗日函数把"禁止违规"换成"违规计价"：λ 是每条约束的影子单价。原问题 = 商家在"价格最狠"时也得付的账；对偶问题 = 定价者把价格调到最狠。两人算的是同一笔账的两个方向。

⚠️ 常见误区

忘了先把约束化成标准形 fᵢ(x) ≤ 0 就套公式。x ≥ 1 必须写成 1 − x ≤ 0，L 里才是 +λ(1−x)。方向写反（写成 λ(x−1)）会让 λ ≥ 0 变成奖励违规，整个对偶理论当场报废。

5.2对偶函数：一台白送的下界机器

上一节把约束折成了价格，但它带出一个问题：价格给定后，这笔账最低能低到多少？把 L 对 x 取最小，消去原变量，剩下的只是 (λ, ν) 的函数——对偶函数（Dual Function）：

g(λ, ν) = infx L(x, λ, ν) = infx ( f₀(x) + ∑ λᵢ fᵢ(x) + ∑ νᵢ hᵢ(x) )

它有两条白送的性质——不需要任何凸性假设：

✅ 两条白送的性质

① g 恒为凹函数：固定 x 时 L 是 (λ,ν) 的仿射函数；一族仿射函数逐点取下确界，结果必凹（回忆 Ch3：仿射函数既凸又凹，逐点 inf 保凹）。
② g(λ,ν) ≤ p* 对一切 λ ⪰ 0 成立：任取可行点 x̃，由 5.1 知 L(x̃,λ,ν) ≤ f₀(x̃)；左边对 x 取 inf 只会更小，右边对可行 x̃ 取 min 得 p*。链条：g(λ,ν) ≤ L(x̃,λ,ν) ≤ f₀(x̃) → 取下确界与最小值 → g ≤ p*。

完整手算（接 5.1 的例子）。min x² s.t. 1−x ≤ 0，L = x² + λ(1−x)。固定 λ ≥ 0，L 是关于 x 的开口向上抛物线，最小点在导数为零处：

∂L/∂x = 2x − λ = 0 ⟹ x = λ/2

代回：

g(λ) = (λ/2)² + λ(1 − λ/2) = λ²/4 + λ − λ²/2 = λ − λ²/4

逐数字验证下界性质：λ = 1 时 g(1) = 1 − 1/4 = 0.75 ≤ p* = 1 ✓；λ = 2 时 g(2) = 2 − 1 = 1 = p*——这个下界竟然顶到了天花板（强对偶的预告）；λ = 3 时 g(3) = 3 − 9/4 = 0.75 ≤ 1 ✓；λ = 10 时 g(10) = 10 − 25 = −15 ≤ 1 ✓（下界可以很差，但永远不越界）。

图 5.1 例 min x² s.t. x≥1 的对偶函数 g(λ) = λ − λ²/4：处处不超过 p*，顶点处取到 d* = 1 = p*。
⚠️ 常见误区

以为"g 是凹函数"需要原问题凸。不需要：g 是 (λ,ν) 的仿射函数族的逐点下确界，无论 f₀、fᵢ 长什么样都凹。这意味着"最大化 g"永远是一个凸优化问题——哪怕原问题不是。这是对偶最有用的副产品之一。

5.3对偶问题与弱对偶：把下界推到最高

上一节说每个 λ ⪰ 0 都给一张"下界证书"，但它带出一个问题：哪张证书最硬？自然把 g 推到最大——这就是对偶问题（Dual Problem）：

max g(λ, ν)　s.t.　λ ⪰ 0

最优值记 d*。由 5.2 的性质②，每个可行的 (λ,ν) 都满足 g ≤ p*，取 max 后依然成立——这就是弱对偶（Weak Duality）：

d* ≤ p*　恒成立（不需要凸性）

差值 p* − d* 叫对偶间隙（Duality Gap）。弱对偶的一个重要推论：若对偶问题无界（d* = +∞），原问题必不可行（p* = +∞）——否则 d* ≤ p* 矛盾。

LP 完整手算例。min x₁ + 2x₂，约束 x₁ + x₂ ≥ 1，x₁, x₂ ≥ 0。

第 1 步：化标准形。三个不等式：1 − x₁ − x₂ ≤ 0，−x₁ ≤ 0，−x₂ ≤ 0。

第 2 步：写拉格朗日函数（乘子 λ, μ₁, μ₂ ≥ 0）：

L = x₁ + 2x₂ + λ(1 − x₁ − x₂) − μ₁x₁ − μ₂x₂ = (1 − λ − μ₁)x₁ + (2 − λ − μ₂)x₂ + λ

第 3 步：对自由的 x₁、x₂ 取 inf。线性函数 c·x 在 x 自由时：系数 ≠ 0 则 inf = −∞；系数 = 0 则贡献为 0。故 g 有限 ⟺

1 − λ − μ₁ = 0 且 2 − λ − μ₂ = 0，此时 g = λ

第 4 步：写出对偶可行域。μ₁ = 1 − λ ≥ 0 ⟹ λ ≤ 1；μ₂ = 2 − λ ≥ 0 ⟹ λ ≤ 2；连同 λ ≥ 0，对偶问题是：

max λ　s.t.　0 ≤ λ ≤ 1　⟹　d* = 1

第 5 步：对照原问题。可行域里 x₁+x₂ ≥ 1 且非负，目标 x₁+2x₂ 的最小值在 x* = (1, 0) 处取得（用便宜的 x₁ 扛下全部需求），p* = 1。于是 p* = d* = 1，间隙为 0——LP 上强对偶成立，5.4 会解释这不是巧合。

💡 关键一跃

对偶问题的每个可行解都是原问题的一张"下限发票"：你不必解原问题，只要随便给个合法的 (λ,ν) 算出 g，就能理直气壮地说"最优值不会低于这个数"。优化器来回报价（下界升、上界降）夹逼 p*，是第 11 章内点法的工作方式。

⚠️ 常见误区

对自由变量取 inf 时漏看"系数必须为零"这一约束，直接把 g 当成处处有限的函数。本例里若写 g(λ,μ) = λ 而不附带 1−λ−μ₁ = 0、2−λ−μ₂ = 0，等于把 −∞ 的区域藏了起来，对偶问题的可行域就错了。

5.4强对偶与 Slater 条件：何时下界顶到天花板

上一节 LP 例子里 p* = d*，但它带出一个问题：这是常态还是运气？d* = p* 叫强对偶（Strong Duality）。先看一个可以逐行验算的反例：它不恒成立。

正对偶间隙反例（完整验算）。min f(x) = x³ − 3x，约束 x ≤ −1（标准形：x + 1 ≤ 0）。

原问题：f′(x) = 3x² − 3。当 x ≤ −1 时 x² ≥ 1，故 f′(x) ≥ 0——f 在 (−∞, −1] 上单调递增，最小值在右端点取得：x* = −1，p* = f(−1) = −1 + 3 = 2。

对偶：L(x,λ) = x³ − 3x + λ(x + 1)。固定任意 λ ≥ 0，令 x → −∞，x³ 项主导一切，L → −∞。于是 g(λ) = −∞ 对所有 λ ≥ 0 成立，d* = −∞。

p* = 2，d* = −∞　⟹　对偶间隙 = +∞

病因是非凸：f 的三次曲线在约束边界附近的形状，让任何线性"罚款"都压不住左侧的深渊。要补一句实话：凸问题也可能有间隙（当约束互相打架、可行域结构病态时），所以"凸" alone 还不够，还差一个技术性补丁——

✅ Slater 条件（Slater's Condition）

对凸问题（f₀ 与诸 fᵢ 凸、hᵢ 仿射）：若存在严格可行点 x̃，使所有不等式约束严格成立 fᵢ(x̃) < 0（等式照常 hᵢ(x̃) = 0），则强对偶 d* = p* 成立。
特例：LP 只要可行（不必严格），强对偶就成立。

"严格"二字不能省。fᵢ(x̃) ≤ 0 只叫可行；Slater 要的是可行域有"内点"——每条不等式都留出正余量。直觉：贴着墙走的可行域，下界机器可能够不到天花板；留一条缝，价格机制才有调节空间。

验证 5.3 的 LP。取 x̃ = (0.6, 0.6)：1 − 0.6 − 0.6 = −0.2 < 0 ✓；−0.6 < 0 ✓；−0.6 < 0 ✓。三个约束全部严格成立，Slater 条件满足，解释了 5.3 里 p* = d* = 1 不是巧合。（其实对 LP 只要有任意可行点就够，这里是双重保险。）

⚠️ 常见误区

把强对偶当成默认性质。正确的心智模型是：弱对偶免费，强对偶有门票——门票 = 凸性 + Slater（或 LP 可行性）。做题时先验门票再引用 d* = p*，否则结论没有依据。

5.5KKT 条件：最优解的"四件套"

上一节搞定了"下界何时等于最优值"，但它带出一个问题：怎么认出（或求出）那个取到 p* 的点 x* 本身？答案是把"原始"与"对偶"两边的最优性要求列成一张清单——KKT 条件（Karush–Kuhn–Tucker Conditions）：

✅ KKT 四条件

① 原始可行：fᵢ(x*) ≤ 0，hᵢ(x*) = 0；
② 对偶可行：λ* ⪰ 0；
③ 互补松弛（Complementary Slackness）：λ*ᵢ fᵢ(x*) = 0 对每个 i；
④ 驻点：∇f₀(x*) + ∑ λ*ᵢ ∇fᵢ(x*) + ∑ ν*ᵢ ∇hᵢ(x*) = 0。
对凸问题，KKT 是最优的充分必要条件：x* 最优 ⟺ 存在 (λ*,ν*) 使四条同成立。

互补松弛在说什么？λ*ᵢ fᵢ(x*) = 0 意味着每个约束二选一：要么贴紧（fᵢ = 0，称激活/active），要么价格为零（λ*ᵢ = 0）。闲置的约束不值钱，值钱的约束必须贴紧——这条把经济直觉变成了代数筛子。

手算验证 1（回看 5.1 的例）。min x² s.t. 1−x ≤ 0。驻点：2x − λ = 0；互补松弛：λ(1−x) = 0。分两种情形：

  • 情形 λ* = 0：驻点给 x = 0，但原始可行要求 x ≥ 1，矛盾——排除。
  • 情形 1 − x = 0：x* = 1，代入驻点 λ* = 2 ≥ 0 ✓。四条件全过。

故 x* = 1，λ* = 2，p* = 1——与 5.2 里 g(2) = 1 完全对上：λ* = 2 正是对偶函数取最大值的点。 primal 与 dual 在最优点会师。

手算验证 2（等式约束最小范数）。min (1/2)(x₁² + x₂²) s.t. x₁ + x₂ = 2。L = (1/2)(x₁² + x₂²) + ν(x₁ + x₂ − 2)。等式约束没有互补松弛（恒等于 0），只需驻点 + 可行：

  • 驻点：∂L/∂x₁ = x₁ + ν = 0；∂L/∂x₂ = x₂ + ν = 0 ⟹ x₁ = x₂ = −ν。
  • 代入约束：−2ν = 2 ⟹ ν* = −1。
  • 故 x* = (1, 1)，p* = (1/2)(1+1) = 1。几何直觉：原点到直线 x₁+x₂=2 的垂足正是 (1,1)，距离的平方的一半为 1 ✓。
💡 关键一跃

KKT 是一张"最优性证书"的验收单：任何人给你一个 x*，你不必重做优化，只需逐项打勾四条。凸问题里勾满即最优——验证比求解便宜得多，这正是对偶机器的核心红利。

⚠️ 常见误区

只解驻点方程（④）就宣布最优。驻点是无约束最优的条件；有约束时必须四件套齐查。少了互补松弛，无法排除"约束贴着但价格为零"或"价格挂着但约束闲着"的假点；少了原始可行，λ=0 的驻点解（如本例 x=0）会混进来。另外：非凸问题上 KKT 只是必要条件，勾满不保证最优。

5.6对偶变量是影子价格：灵敏度解释

上一节把 λ* 当成代数学里的乘子，但它带出一个问题：λ* 的大小有没有现实含义？有——它是约束的"价格"。把约束右端扰动，定义扰动问题（Perturbed Problem）的最优值函数：

p*(u, v) = min f₀(x)　s.t.　fᵢ(x) ≤ uᵢ，hᵢ(x) = vᵢ
✅ 灵敏度定理（强对偶下）

λ*ᵢ = −∂p*/∂uᵢ，ν*ᵢ = −∂p*/∂vᵢ。
即：把第 i 条约束放松一单位（uᵢ 加 1），最优值的改善率恰为 λ*ᵢ。负号是方向约定：放松（u 变大）时 p* 下降，而 λ* 取正值。

数字验证（接 5.5 的例）。min x² s.t. x ≥ u（u > 0），标准形 u − x ≤ 0。显然 x* = u，故 p*(u) = u²，dp*/du = 2u。u = 1 时：−∂p*/∂u = −2·1 = −2，加符号约定得 λ* = 2——与 5.5 手算的 λ* = 2 分毫不差 ✓。

翻译成操作语言：把约束从 x ≥ 1 放松到 x ≥ 0.99（Δu = −0.01），最优值约改善 λ*·0.01 = 0.02——精确值 p*(0.99) = 0.9801，确实降了 0.0199 ≈ 0.02（差 0.0001 是二阶项）。

为什么叫"价格"：若约束是"预算 ≤ B"、目标是利润最大化类问题（符号翻转后同理），λ* 就是再多 1 元预算能换多少利润——边际价值。互补松弛此时读作：预算没花完（约束闲置）时边际价值为零；λ* > 0 时预算必然花光。5.5 例中 λ* = 2：约束 x ≥ 1 是激活的（x* = 1 贴紧），放松它有正收益，完全自洽。

⚠️ 常见误区

符号记反：以为 λ*ᵢ = +∂p*/∂uᵢ。记住"放松约束，最优值只降不升（对 min 问题）"：uᵢ 增大 ⟹ 可行域变大 ⟹ p* 减小 ⟹ ∂p*/∂uᵢ ≤ 0；而 λ*ᵢ ≥ 0，所以中间必须有个负号。另外此结论是局部的（一阶近似），大步扰动要重解问题。

5.7本章总结与遗留：从下界到算法

回看整条链：约束折进目标（L）→ 对 x 取 inf（g）→ 推高下界（对偶问题）→ 弱对偶免费、强对偶要门票（Slater）→ KKT 四条件给证书 → λ* 读出价格。对偶机器一共交付三样东西：

  • 下界证书：任何 λ ⪰ 0 都给 g(λ,ν) ≤ p*，无需解原问题（5.2 里 λ=1 就白捡 0.75）；
  • 最优性判据：KKT 四条件，验证一个点比求一个点便宜得多（5.5 两个手算）；
  • 算法入口：对偶问题恒为凹最大化（凸优化），可以在 λ 空间做上升；原始-对偶成对推进能夹逼间隙。

遗留问题：KKT 告诉你"怎么验收"，没告诉你"怎么搜索"——四条方程一般是非线性的，没有求根公式。怎么迭代逼近解？这是阶段④的全部内容：Ch9 先解决无约束问题的迭代下降（梯度法、牛顿法），Ch10 把等式约束并入牛顿步，Ch11 内点法用对偶间隙作进度条，把不等式约束问题化回一串等式约束问题。本章的 d*、p* 与间隙，正是那条进度条的刻度。

📝分层习题

L1 概念辨析判断：对任意优化问题（包括非凸问题），弱对偶 d* ≤ p* 都成立。这个说法对吗？
提示

回看弱对偶证明的两步：可行点上 L(x̃,λ,ν) ≤ f₀(x̃)；对 x 取 inf、对可行 x̃ 取 min。这两步哪一步用到了凸性？

完整解答
对。证明只用两件事：① 可行点上罚款项 ∑λᵢfᵢ(x̃) ≤ 0（靠 λ ⪰ 0 与可行性）；② inf 与 min 的单调性。全程没有凸性登场。凸性只在强对偶（d* = p*）中才需要——5.4 的非凸反例里弱对偶照样成立（−∞ ≤ 2）。易错点：把"对偶理论"整体贴上"凸优化专属"标签，混淆弱与强的前提。
L1 概念辨析判断：若某问题的对偶问题无界（d* = +∞），则原问题不可行。对吗？
提示

用反证法 + 弱对偶：假设原问题可行，p* 会怎样？

完整解答
对。若原问题可行，则 p* < +∞（某可行点给出有限目标值）。弱对偶要求 d* ≤ p*，与 d* = +∞ 矛盾。故原问题不可行（约定不可行时 p* = +∞）。易错点：方向记反——是"对偶无界 ⟹ 原始不可行"，对偶"无界"指的是最大化 g 可以到 +∞，不是可行域大。
L2 手算推导求 min x₁ + x₂ s.t. x₁² + x₂² ≤ 2 的对偶问题，解出 d*，并验证强对偶。
提示

标准形：x₁² + x₂² − 2 ≤ 0，乘子 λ ≥ 0。固定 λ > 0 后 L 关于每个 xᵢ 是开口向上的抛物线，分别求导取极小，代回得 g(λ)，再对 λ 求极大。原问题用对称性直接看。

完整解答
第 1 步：L = x₁ + x₂ + λ(x₁² + x₂² − 2)，λ ≥ 0。
第 2 步：∂L/∂xᵢ = 1 + 2λxᵢ = 0 ⟹ xᵢ = −1/(2λ)（λ = 0 时 L 线性无下界，g = −∞，只考虑 λ > 0）。
第 3 步：代回。x₁ + x₂ = −1/λ；x₁² + x₂² = 2·(1/(2λ))² = 1/(2λ²)。
g(λ) = −1/λ + λ(1/(2λ²) − 2) = −1/λ + 1/(2λ) − 2λ = −1/(2λ) − 2λ。
第 4 步：极大化 g。g′(λ) = 1/(2λ²) − 2 = 0 ⟹ λ*² = 1/4 ⟹ λ* = 1/2（取正）。
d* = g(1/2) = −1/(2·(1/2)) − 2·(1/2) = −1 − 1 = −2。
第 5 步：原问题。目标等值线是斜率 −1 的直线，向 (−1,−1) 方向推到贴圆：对称点 x* = (−1, −1)，检验 (−1)² + (−1)² = 2 ≤ 2 ✓（贴紧）。p* = −2。
结论：p* = d* = −2，强对偶成立 ✓（问题是凸的且原点即严格可行点，Slater 门票在手）。
L2 手算推导用 KKT 条件求 min x₁² + x₂² s.t. x₁ + x₂ ≥ 2 的最优解，并逐条验证四条件。
提示

标准形 2 − x₁ − x₂ ≤ 0。写驻点方程后按互补松弛分两种情形：λ = 0 或约束贴紧。

完整解答
第 1 步：L = x₁² + x₂² + λ(2 − x₁ − x₂)，λ ≥ 0。
第 2 步：驻点 ∂L/∂x₁ = 2x₁ − λ = 0，∂L/∂x₂ = 2x₂ − λ = 0 ⟹ x₁ = x₂ = λ/2。
第 3 步：互补松弛 λ(2 − x₁ − x₂) = 0，分情形：
・情形 λ = 0：x₁ = x₂ = 0，但 0 + 0 ≥ 2 不成立，违反原始可行，排除。
・情形约束贴紧：x₁ + x₂ = 2，代入 λ/2 + λ/2 = 2 ⟹ λ = 2。
第 4 步：x* = (1, 1)，λ* = 2。验证四条件：① 1+1 ≥ 2 ✓；② λ* = 2 ≥ 0 ✓；③ 2·(2−1−1) = 0 ✓；④ 2·1 − 2 = 0（两个分量均成立）✓。
结论：凸问题 + KKT 全过 ⟹ x* = (1,1) 最优，p* = 2。几何上：原点到直线 x₁+x₂=2 的垂足恰为 (1,1)，距离平方 = 2 ✓。
L3 建模应用一座电厂有两台机组，发电 q₁、q₂（单位：百兆瓦）的每小时成本分别为 C₁ = q₁²、C₂ = 2q₂²（元）。电网要求总供电 q₁ + q₂ = 6。用 KKT 条件求最小成本调度，并解释对偶乘子的经济含义。
提示

等式约束问题：L = q₁² + 2q₂² + ν(6 − q₁ − q₂)。只有驻点 + 可行两条（等式约束无互补松弛）。解出 ν 后想想：多要 1 单位电，成本涨多少？

完整解答
建模：min q₁² + 2q₂² s.t. q₁ + q₂ = 6（目标凸、约束仿射，KKT 充分必要）。
驻点：∂L/∂q₁ = 2q₁ − ν = 0 ⟹ q₁ = ν/2；∂L/∂q₂ = 4q₂ − ν = 0 ⟹ q₂ = ν/4。
代入约束：ν/2 + ν/4 = 6 ⟹ 3ν/4 = 6 ⟹ ν* = 8。
最优调度：q₁* = 4，q₂* = 2。最小成本 = 4² + 2·2² = 16 + 8 = 24 元/小时。
检验直觉：最优处两机组边际成本相等——2q₁* = 8，4q₂* = 8，都等于 ν*（等边际原理）。
ν* = 8 的含义：供电需求的影子价格。若电网多要 1 百兆瓦（6 → 7），最小成本约上涨 8 元/小时（精确值：(16/3)² + 2(4/3)² = 256/9 + 32/9 = 32，涨 8 元整——二次成本下恰为线性外推值+二阶修正的巧合对上）。报价、扩容决策都以这个数字为锚。

  • B. 把约束放松到 x ≥ 0.99，最优值约下降 0.02；λ*ᵢ = −∂p*/∂uᵢ 的负号正来自"放松使 p* 下降"
  • C. λ* = 2 表示最优解 x* = 2
  • D. λ* = 2 表示对偶问题的最优值 d* = 2
解析：B 对——放松（u 减 0.01）预测 p* 降 λ*·0.01 = 0.02，精确降 0.0199，一阶吻合；负号因 min 问题放松约束时 p* 下降而 λ* 取正。A 错——方向反了：收紧约束（u 增）只会让 p* 上升（变差），谈不上"改善"；C 错——λ 是乘子不是解，本例 x* = 1；D 错——d* = p* = 1，λ* = 2 是取到 d* 的乘子取值，不是对偶最优值本身。
