9.1下降方法与回溯线搜索：每步只要「够好」不要「最好」

迭代格式 x⁺ = x + tΔx：方向 Δx 满足 ∇fᵀΔx < 0（下降方向，Descent Direction），步长 t 由线搜索确定。精确线搜索（Exact Line Search）解一维问题 min_t f(x+tΔx)；回溯线搜索（Backtracking Line Search，Armijo 规则）只要「足够下降」：

接受条件：f(x + tΔx) ≤ f(x) + α·t·∇fᵀΔx，   α∈(0, 1/2)；不满足就 t := βt，β∈(0,1)

完整手算例：f(x)=x² 的一步回溯

当前 x=2，∇f=4，取最速下降方向 Δx=−4，α=1/4，β=1/2。

步t左端 f(x+tΔx)右端 f(x)+αt∇fᵀΔx判定
① 初试1f(−2)=44 + (1/4)(1)(−16) = 04 ≤ 0？否 → 回溯
② t:=βt1/2f(0)=04 + (1/4)(1/2)(−16) = 20 ≤ 2 ✓ 接受
③ 更新x⁺ = 2 + (1/2)(−4)x⁺ = 0，一步到最优

注意两个要点：① 回溯只评估函数值，不需要解任何子问题；② 这个例子里精确线搜索也给 t=1/2（f(2−4t) 极小点在 t=1/2），回溯一次即命中——简单问题上两者差别不大，差别在高维与病态时显现。

💡 关键一跃

Armijo 条件的几何：右端是一条比真实下降「打点折」的直线（斜率打 α 折）。接受 t 只要真实曲线压过这条打折线即可——α 越小越宽容，β 越小回溯越狠。整个设计哲学：用可检查的充分条件代替最优条件，这个思想在 Ch11 的内点法里还会回来。

⚠️ 常见误区

「步长越小越安全，所以 t 取很小总没错」——错。过小的步长让收敛慢到不可用（线性收敛的底数 c 接近 1）；回溯的设计恰恰是「先试大、不行再缩」，初试 t=1 在 Newton 方法里甚至是收敛理论的要求（近优解区必须接受全步长才能二次收敛）。

9.2梯度下降的收敛率：条件数说了算

梯度法每一步只花一阶信息，代价比 Newton 低一个量级——值得为它建立精确的速率理论。强凸（Strongly Convex）假设：mI ⪯ ∇²f(x) ⪯ MI（0 < m ≤ M），条件数 κ = M/m。结论：

f(x⁽ᵏ⁾) − p* ≤ cᵏ (f(x⁽⁰⁾) − p*)，   回溯：c = 1 − m/M；  精确线搜索（二次）：c = ((κ−1)/(κ+1))²

误差以几何级数收缩——这叫线性收敛（Linear Convergence，指 log 误差随 k 线性下降）。κ 越接近 1（等高线越圆），c 越小，收敛越快；κ 越大（等高线越扁），c→1，梯度法陷入锯齿（Zigzag）爬行。

完整手算例：一步精确线搜索命中理论收缩因子

f(x₁,x₂) = ½(x₁² + 10x₂²)，Q = diag(1,10)，κ = 10。起点 x⁽⁰⁾ = (10, 1)。

步骤计算结果
① 梯度g = Qx = (10, 10)
② 精确步长t = gᵀg / gᵀQg = 200 / (100+1000)t = 2/11 ≈ 0.1818
③ 更新x⁽¹⁾ = x⁽⁰⁾ − t·g = (10−20/11·… ) 逐分量算x⁽¹⁾ = (90/11, −9/11) ≈ (8.18, −0.82)
④ f 值f(x⁰) = ½(100+10) = 55；f(x¹) = ½(8100/121 + 10·81/121)f(x¹) = 4455/121 ≈ 36.82
⑤ 收缩比36.82 / 55≈ 0.669 = (9/11)² ✓

(κ−1)/(κ+1) = 9/11，平方得 0.669——理论值与实际一步的收缩分毫不差。再看方向：x₁ 分量从 10 降到 8.18（慢），x₂ 从 1 降到 −0.82（冲过头）——这就是锯齿：梯度方向被长轴「绑架」，在扁椭球的两壁间来回弹。

💡 关键一跃

梯度法的全部毛病可以归结成一句话：它用的是「局部最陡」方向，而最优解在「全局谷底」方向。条件数 κ 就是这两个方向偏离的度量。Newton 法的本质（9.3）正是用二阶信息把坐标系「揉圆」——等效于把 κ 变成 1。

⚠️ 常见误区

「线性收敛 = 慢」——术语陷阱。线性收敛是指数级收缩（cᵏ），已经很快；真正慢的是次线性（如 O(1/k)，次梯度法、不可微问题）。把「线性」理解成「一次函数速度」是最常见的误读：看 log 误差，它是斜率 log c 的直线。

9.3Newton 方法：二阶信息的代价与回报

Newton 步（Newton Step）：在当前点做二阶 Taylor 近似并取其极小点：

Δx_nt = −∇²f(x)⁻¹ ∇f(x)，   x⁺ = x + Δx_nt

两个标志性性质。① 二次函数一步收敛：f 二次时二阶近似就是 f 本身。对 9.2 的例：x⁺ = x − Q⁻¹(Qx) = x − x = 0——一步到最优，与起点无关。② 近优解区二次收敛：‖误差⁺‖ ≤ C·‖误差‖²。数字看一眼：

完整手算例：f(x)=x²+x⁴ 的三步 Newton

f′ = 2x+4x³，f″ = 2+12x²。Newton 更新：

x⁺ = x − 2x+4x³2+12x² = 4x³1+6x²
步x误差 = |x−0|误差行为
起点11
①4/7 ≈ 0.57140.5714压缩 0.57×
②4(0.5714)³/(1+6·0.5714²) ≈ 0.7466/2.959≈ 0.2523≈ 误差² 量级
③4(0.2523)³/(1+6·0.2523²) ≈ 0.0643/1.382≈ 0.04650.2523² = 0.0637，同级 ✓

有效数字每次近乎翻倍——这就是二次收敛的体感。代价：每步要算 Hessian 并解线性系统（O(n³) 稠密）。阻尼 Newton（Damped Newton）：远离最优时用回溯线搜索包一层（保证全局收敛），近优解区自动接受全步长（进入二次收敛）。停止准则用 Newton 减量（Newton Decrement）：λ² = ∇fᵀ∇²f⁻¹∇f，λ²/2 是 f(x)−p* 的估计。最后，自和谐（Self-Concordant）函数类让「多远算近优解区、需要几步阻尼」有了与问题数据无关的通用界——log-barrier 恰是此类，这是第11章复杂度证明的钥匙。

💡 关键一跃

Newton = 先把坐标系用 Hessian 揉圆（f(x+p) 在尺度 ∇²f 下看就是球），再在新坐标里走最速下降。所以它仿射不变：对变量做任何可逆线性变换，Newton 轨迹不变——梯度法则会被同一个变换毁掉。这就是为什么「条件数」三个字在 Newton 章节里消失了。

⚠️ 常见误区

「Newton 法总是比梯度法好」——错。每步代价 O(n³) vs O(n)：n=10⁶ 时 Newton 一步都算不动，梯度法跑得欢。正确的问题不是「哪个好」而是「迭代数 × 每步代价，总账谁小」（9.4）。另外非凸问题上 Newton 可能奔向鞍点——本章一切结论都在凸假设下。

9.4收敛率全景与复杂度账

三档速率并排看（「迭代数 × 每步代价」才算总账）：

速率档误差行为代表算法每步代价适用
次线性O(1/k)次梯度法O(n)不可微（LASSO、SVM 合页）
线性cᵏ，c=((κ−1)/(κ+1))²梯度法 + 回溯O(n)（矩阵向量乘）大规模光滑、κ 适中
二次误差逐次平方阻尼 NewtonO(n³) 解系统中小规模、要高精度

算一笔总账：9.2 的例要把 f 从 55 压到 55×10⁻⁶，梯度法需 k ≥ log(10⁻⁶)/log(0.669) ≈ 34 步，每步 O(n)，总账 ≈ 34n；Newton 对该二次问题 1 步，每步 O(n³)。n=2 时 Newton 赢；n=10⁵ 时梯度法 34×10⁵ 次浮点 vs Newton 一步 (10⁵)³=10¹⁵ 次——量级反转。没有免费的二次收敛：它用每步代价买迭代次数。

本章的方法都吃不了约束。Ch10 先把等式约束嵌进 Newton（KKT 系统），Ch11 再用 log 障碍把不等式软化进目标——无约束算法是这两章的发动机。

💡 关键一跃

选算法的决策树：不可微 → 次梯度/近端（O(1/k)）；光滑且 n 大 → 梯度家族（每步便宜）；光滑、n 中小、要 8 位精度 → Newton（步数一位数）。Ch11 的内点法之所以统治凸优化实践，正因为它把「带约束」化成了「一串 Newton 能解的无约束问题」，迭代数还很少。

⚠️ 常见误区

「迭代次数少 = 算法好」——9.4 的全部要点就是反例：Newton 一步顶梯度法几十步，但每步贵 n² 倍。比较算法必须报两个数：迭代数与每步代价。只报一个的论文/汇报都值得一问。

自和谐（Self-Concordance）
点击翻面 →

📝分层习题

L1 概念辨析判断对错：「Newton 法用于非凸函数时，只要 Hessian 可逆，仍保证收敛到全局最小。」
提示

Newton 步是二阶模型的极小点——但非凸时 Hessian 可能不定，模型的「极小」方向还是下降方向吗？

完整解答
错。非凸时 ∇²f 可能不定，Δx_nt 可以不是下降方向，Newton 可能奔向极大点或鞍点；即便收敛也只是驻点，无全局性可言。本章全部保证（下降、二次收敛、λ² 停止准则）都建立在凸性（∇²f ≻ 0）之上。这也是「先证凸、再上算法」工作流的来历。
L1 概念辨析选择：下列哪个说法正确描述了线性收敛？A. 误差每步减少一个固定常数；B. 误差每步乘以一个小于 1 的固定因子；C. 误差与迭代次数成反比；D. 误差每步被平方。
提示

写出 cᵏ 的形式，再对照每个选项的数学翻译。

完整解答
B。线性收敛 = 几何级数 cᵏ：每步乘以固定因子 c<1，log 误差随 k 线性下降。A 错：那是「每步减常数」，线性下降趋势会停在 0 以下，对应的是次梯度法的某些界，不是 cᵏ。C 错：1/k 是次线性（次梯度法）。D 错：逐次平方是二次收敛（Newton），比线性快得多。四个选项正好对应速率谱上的四个不同点，值得背下来。
L2 手算推导f(x)=x²，x=4，用最速下降方向与 α=1/4、β=1/2 的回溯线搜索，手算接受的步长与新点（写出每次试验的左右两端）。
提示

∇f(4)=8，Δx=−8，∇fᵀΔx=−64。从 t=1 试起。

完整解答
① t=1：左端 f(4−8)=f(−4)=16；右端 f(4)+αt∇fᵀΔx=16+(1/4)(−64)=0。16≤0 否 → 回溯。② t=1/2：左端 f(4−4)=f(0)=0；右端 16+(1/4)(1/2)(−64)=8。0≤8 ✓ 接受。③ x⁺=4+(1/2)(−8)=0，一步到最优（二次+对角，意料之中）。④ 注：精确线搜索步长同为 1/2（f(4−8t) 极小点），此例回溯一次即中。
L2 手算推导f(x₁,x₂)=½(x₁²+γx₂²)，γ=4，x⁽⁰⁾=(4,1)。手算一步精确线搜索梯度步，并验证 f 的收缩比等于 ((γ−1)/(γ+1))²。
提示

g=(4,4)；t = gᵀg/gᵀQg，Q=diag(1,4)；再算 f 前后值之比。

完整解答
① g = ∇f(x⁰) = (4, 4)。② t = gᵀg/gᵀQg = 32/(16+64) = 32/80 = 2/5。③ x¹ = (4−(2/5)·4, 1−(2/5)·4) = (4·3/5, −3/5) = (12/5, −3/5)。④ f(x⁰)=½(16+4)=10；f(x¹)=½(144/25 + 4·9/25)=½·(144+36)/25=½·180/25=18/5=3.6。⑤ 收缩比 3.6/10 = 0.36；理论 ((4−1)/(4+1))² = (3/5)² = 9/25 = 0.36 ✓ 完全吻合。
L3 建模应用你要解一个 logistic 回归（光滑、严格凸、n=2000 维、样本 m=10⁶）：工程团队提议「直接上全 Newton，反正它二次收敛」。请用本章的总账框架评估这个提议，给出你的算法选择、停止准则与预估代价结构（不要求精确数字，要求量纲与决策逻辑正确）。
提示

报两个数：迭代数与每步代价。Newton 每步要解多大的系统？梯度/拟牛顿呢？logistic 的 Hessian 有什么结构？

完整解答
评估：Newton 迭代数确实小（logistic 近自和谐，通常 10–20 步到 10⁻⁸），但每步要解 2000×2000 稠密系统 O(n³)≈8×10⁹ 浮点/步，且每步组 Hessian 要扫全数据 O(mn)≈2×10⁹。总账约 20×(8×10⁹)≈1.6×10¹¹。替代：梯度法每步 O(mn)≈2×10⁹ 但 κ 可能大使步数上千；拟牛顿（L-BFGS）每步 O(n·r)（r 为记忆窗口）+ 同样 O(mn) 梯度，迭代数通常几十到一两百。决策：n=2000 其实不算大——若内存放得下 2000² 的 Hessian（32MB），阻尼 Newton 配 λ²/2≤10⁻⁸ 停止准则是干净利落的正确选择，总账 10¹¹ 量级秒级可解；若 n 再大两个量级则转 L-BFGS。给团队的话：「Newton 在这里是对的，但对的理由是 n 小而不是收敛快——迭代数×每步代价都报出来再拍板。」

自测 1
回溯线搜索相对精确线搜索的核心优势是：
  • A. 每步找到的 t 更大，收敛更快
  • B. 只需评估函数值，避免解一维子问题，且有全局收敛保证
  • C. 不需要下降方向
  • D. 总能给出比精确线搜索更小的函数值
解析：B 对——Armijo 用「充分下降」这个可检查条件替代一维最优化，每次回溯只算函数值，理论上有全局收敛保证。A 错：回溯的 t 通常小于等于精确步长，优势不在步长大小。C 错：∇fᵀΔx<0 仍是前提，条件里就含梯度。D 错：充分下降不保证最小——9.1 例中两者恰好一致是二次问题的巧合，一般情况下精确线搜索单步降得更多（但贵）。
自测 2
强凸问题 f(x₁,x₂)=½(x₁²+γx₂²) 上梯度法锯齿的根本原因是：
  • A. 步长太大导致发散
  • B. 目标函数不光滑
  • C. 负梯度垂直于等高线切线，扁椭球中该方向偏离谷底方向
  • D. 初值离最优点太远
解析：C 对——最陡下降方向是等高线的法向；扁椭球（κ 大）中法向几乎横切长轴而非指向中心，于是来回弹。A 错：精确/回溯线搜索下不会发散，锯齿是慢不是散。B 错：二次函数任意阶光滑，锯齿与光滑性无关。D 错：远近只改变迭代数常数，不改变锯齿机制——任何起点都会锯齿。
自测 3
Newton 法对严格凸二次函数一步收敛，因为：
  • A. 二阶 Taylor 模型此时就是函数本身，Newton 步直接解出模型极小点
  • B. 二次函数的梯度很小
  • C. 回溯线搜索总能接受 t=1
  • D. Hessian 是单位阵
解析：A 对——二次函数的二阶展开无截断误差，min 模型 = min 原函数，x⁺=x−Q⁻¹(Qx−q̃)=最优解。B 错：梯度大小与收敛机制无关，起点梯度可以任意大。C 错：因果倒置——正是因为 Newton 步已是最优，t=1 才被接受；且非二次时近优解区之外 t=1 常被拒绝。D 错：Q 任意对称正定即可，无需单位阵——这正是 Newton 消除条件数影响的体现。
自测 4
Newton 减量 λ² = ∇fᵀ∇²f⁻¹∇f 用作停止准则的依据是：
  • A. λ² 等于真实次优间隙 f(x)−p*
  • B. λ² 与梯度范数成正比
  • C. λ² 大说明 Hessian 病态
  • D. 二阶模型给出 f(x)−p* ≈ λ²/2，是无需 p* 的可计算估计
解析：D 对——把当前点代入二阶模型，模型宣称的剩余下降量恰为 λ²/2，且只用 ∇f 与 ∇²f，不需要知道 p*。A 错：它只是二阶估计，非等式；近优解区才高度准确。B 错：λ² 用 Hessian 度量加权了梯度，与 ‖∇f‖² 可差 κ 倍——这正是它比梯度范数更适合做停止准则的原因（仿射不变）。C 错：λ² 不诊断病态，Newton 法本身对条件数免疫。
自测 5
n=10⁶ 的大规模光滑强凸问题，要求中等精度（ε=10⁻⁴），首选通常是：
  • A. 精确线搜索梯度法
  • B. 全 Newton 法
  • C. 回溯线搜索梯度法（或加速梯度/L-BFGS）
  • D. 次梯度法
解析：C 对——每步 O(n) 量级、只算梯度，中等精度下总账最小；回溯避免了一维子问题。A 错：n=10⁶ 时精确线搜索每步都要解一维优化，代价不可接受。B 错：Newton 每步解 10⁶×10⁶ 系统 ≈10¹⁸ 浮点，一步都走不动。D 错：问题光滑时用次梯度是把 cᵏ 自废成 O(1/k)，精度 10⁻⁴ 要约 10⁸ 步——光滑信息不该浪费。
