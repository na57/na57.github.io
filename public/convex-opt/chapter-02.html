2.1为什么先学集合：直线与仿射集

第1章说：凸优化问题"能可靠求解"，代价是问题的可行域和目标函数都必须是凸的。这立刻带出一个问题："可行域是凸的"到底怎么判定？可行域是若干个点组成的集合，所以一切的起点是给"集合的形状"立一套语言。最规矩的一类集合先登场。

定义（仿射集，Affine Set）。集合 C ⊆ ℝn 称为仿射集，如果对任意 x₁, x₂ ∈ C 与任意实数 θ ∈ ℝ，都有

θx₁ + (1 − θ)x₂ ∈ C

θ 取遍全体实数时，θx₁ + (1−θ)x₂ 扫过过这两点的整条直线。所以仿射集一句话：过集合中任意两点的整条直线仍在集合内。

二维完整例子。取直线 x₁ + x₂ = 1 上的两点 x₁ = (1, 0)、x₂ = (0, 1)。把 θ 推出 [0,1] 之外，取 θ = 2：

2·(1, 0) + (1 − 2)·(0, 1) = (2, 0) − (0, 1) = (2, −1)

验证它仍在集合内：2 + (−1) = 1 ✓。再取 θ = −1：(−1)·(1,0) + 2·(0,1) = (−1, 2)，而 −1 + 2 = 1 ✓。整条直线都在集合里——这正是仿射集的要求。

最重要的仿射集：线性方程组的解集。设 C = {x : Ax = b}。若 Ax₁ = b 且 Ax₂ = b，则对任意 θ ∈ ℝ：

A(θx₁ + (1−θ)x₂) = θAx₁ + (1−θ)Ax₂ = θb + (1−θ)b = b

所以线性方程组的解集必为仿射集。直线、平面、超平面、整个空间、单个点，都是仿射集。

💡 关键一跃

仿射集就是"完全没有拐弯"的集合：它不能弯、不能断、不能缺。θ 不受限制，意味着集合必须向两端无限延伸（除非它只是一个点）。

⚠️ 常见误区

把 θ 误限制在 [0,1]。仿射组合允许 θ = 2 或 θ = −1 这类"外插"取值；θ 被限制在 [0,1] 时得到的是线段，那是下一节凸集的故事。混淆两者，后面所有定义都会错位。

2.2凸集与凸组合：把 θ 关进 [0,1]

上一节让 θ 跑遍全直线，得到的仿射集太"稀"了——半空间、圆盘都不在其中。本节只改动一处：把 θ 限制在 [0,1]，立刻得到本书真正的主角。

定义（凸集，Convex Set）。集合 C 称为凸集，如果对任意 x₁, x₂ ∈ C 与任意 θ ∈ [0, 1]，都有 θx₁ + (1−θ)x₂ ∈ C。θ 在 [0,1] 内取值时，这个点扫过两点间的线段——所以凸集一句话：连接集合中任意两点的线段不离开集合。

凸组合与凸包。点 x = θ₁x₁ + ⋯ + θkxk 若满足 θ₁ + ⋯ + θk = 1 且每个 θi ≥ 0，就称为这些点的凸组合（Convex Combination）。一个集合中所有点的全体凸组合构成的集合，叫做它的凸包（Convex Hull）——它是包含原集合的最小凸集。

二维完整例子。三点 (0,0)、(2,0)、(0,2) 的凸包是以它们为顶点的实心三角形。点 (0.5, 0.5) 在三角形内，它的一组凸组合是：

(0.5, 0.5) = 0.5·(0,0) + 0.25·(2,0) + 0.25·(0,2)

逐项验证：第一坐标 0.25·2 = 0.5 ✓，第二坐标 0.25·2 = 0.5 ✓；系数和 0.5 + 0.25 + 0.25 = 1 ✓，且全部非负 ✓。

反例（圆环不凸）。取半径在 1 与 2 之间的圆环 C = {x : 1 ≤ ‖x‖ ≤ 2}。点 (1,0) 与 (−1,0) 都在 C 中（范数都是 1）。取中点 θ = 0.5：

0.5·(1,0) + 0.5·(−1,0) = (0,0)，‖(0,0)‖ = 0 ∉ [1, 2]

中点掉进了中间的"洞"里——线段离开了集合，所以圆环不凸。

图 2.2 凸与不凸的一眼判据：任取两点连线，线段必须全程留在集合内；右边月牙形两点的中点落在空白处，故不凸。
💡 关键一跃

凸 = 没有洞、没有凹陷、没有断开。从集合里任意两点互相"看"，视线（线段）全程不离开集合——凸集里的任意两点都互相可见。

⚠️ 常见误区

以为"系数和为 1"就是凸组合。凸组合要求非负 + 和为 1，缺一不可：2x₁ − x₂ 系数和为 1 但有负系数，只是仿射组合，可能跑出凸集；2x₁ + 2x₂ 系数非负但和不为 1，更不是凸组合。

2.3锥与凸锥：只允许"正向缩放"

上一节把 θ 关进 [0,1] 得到线段。换一个限制方式会怎样：不要求和为 1，只要求系数非负？这给出第三类基本集合。

定义（锥，Cone 与凸锥，Convex Cone）。集合 C 是锥，如果 x ∈ C 且 θ ≥ 0 蕴含 θx ∈ C（对正向缩放封闭）。C 是凸锥，如果对任意 x₁, x₂ ∈ C 与 θ₁, θ₂ ≥ 0，都有

θ₁x₁ + θ₂x₂ ∈ C

形如 θ₁x₁ + ⋯ + θkxk（θi ≥ 0）的点叫锥组合（Conic Combination，又称非负组合）；全体锥组合构成锥包（Conic Hull）。

二维完整例子：非负象限 ℝ²₊ 是凸锥。取 x₁ = (1, 0)、x₂ = (0, 2)，系数 θ₁ = 1、θ₂ = 2：

1·(1, 0) + 2·(0, 2) = (1, 4) ∈ ℝ²₊ ✓

两个坐标都非负，仍在第一象限。事实上非负象限对任意非负组合封闭：非负数乘非负数再加起来，结果还是非负的。

反例：是锥但不凸。取 C = {(x, y) : xy ≥ 0}，即第一、三象限（含坐标轴）的并。它确实是锥：任一点乘以 θ ≥ 0，两坐标同号关系不变。但它不是凸锥。取 (2, 1)（第一象限，2·1 = 2 ≥ 0）与 (−1, −2)（第三象限，(−1)·(−2) = 2 ≥ 0），中点为：

0.5·(2,1) + 0.5·(−1,−2) = (0.5, −0.5)，0.5 × (−0.5) = −0.25 < 0

中点跑到第二象限，离开了 C。所以这个锥带"分叉"，不是凸锥。

💡 关键一跃

锥是从原点射出的一束"光线"（正向射线）。凸锥是这束光线不带分叉：光束内任意两束光的非负叠加仍在光束内。

⚠️ 常见误区

以为"锥"自动就是"凸锥"。一、三象限的并是锥但不是凸锥——锥只对缩放封闭，不对混合封闭。另外注意：凸锥一定是凸集（取 θ₁ + θ₂ = 1 即退化为凸组合），但凸集不一定是锥（单位圆盘凸，乘 2 就跑出去了）。

2.4重要凸集清单：五种现成的凸构件

前三节立了三条抽象判据，但它们带出一个实际问题：手头上哪些集合可以直接拿来用？本节给出五种最常见、且都已证明为凸的构件。建模时的功夫，就是把可行域写成这些构件的组合。

① 超平面（Hyperplane）：{x : aᵀx = b}，a ≠ 0。它是仿射集（§2.1 已证），故也是凸集。取 a = (2, 1)、b = 4：点 (2, 0) 满足 2·2 + 1·0 = 4 ✓，点 (1, 2) 满足 2·1 + 1·2 = 4 ✓，两点都在超平面上。

② 半空间（Halfspace）：{x : aᵀx ≤ b}。超平面把空间切成两半，每一半都是凸集（它不是仿射集——直线会越界）。仍用 a = (2,1)、b = 4：点 (0,0) 得 0 ≤ 4，在内；点 (3,0) 得 6 > 4，在外。

③ 欧氏球（Euclidean Ball）：B(xc, r) = {x : ‖x − xc‖₂ ≤ r}。取球心 (0,0)、半径 1：点 (0.6, 0.8) 的范数 = √(0.36 + 0.64) = √1 = 1，恰好落在边界上；点 (0.3, 0.3) 范数 ≈ 0.42 < 1，在内部。凸性来自三角不等式：两点的凸组合到球心的距离不超过 θr + (1−θ)r = r。

④ 椭球（Ellipsoid）：{x : (x − xc)ᵀP⁻¹(x − xc) ≤ 1}，其中 P 对称正定（P ≻ 0）。取 xc = (0,0)、P = diag(4, 1)，则 P⁻¹ = diag(1/4, 1)，椭球方程为 x₁²/4 + x₂² ≤ 1：半轴长为 √4 = 2 与 √1 = 1。验证：(2, 0) 得 4/4 + 0 = 1，在边界；(0, 1) 得 0 + 1 = 1，在边界；(1, 0) 得 1/4 ≤ 1，在内部。

⑤ 多面体（Polyhedron）：有限个半空间与超平面的交，常写作 {x : Ax ≤ b, Cx = d}（不等式按分量理解）。例：由 x₁ + x₂ ≤ 2、x₁ ≥ 0、x₂ ≥ 0 围成的三角形，三个顶点为 (0,0)、(2,0)、(0,2)。验证内点 (1, 0.5)：1 + 0.5 = 1.5 ≤ 2 ✓，两坐标非负 ✓。

还有第六位主角——半定锥（Positive Semidefinite Cone）：全体 n×n 对称半正定矩阵 {X : X ⪰ 0} 构成一个凸锥。它是半定规划（SDP）的可行域，将在第4章正式登场，本章只需知道它在这个清单里。

构件标准写法本章数字例在内 / 在外的验证点
超平面aᵀx = b2x₁ + x₂ = 4(2,0) 在上；无"内外"之分
半空间aᵀx ≤ b2x₁ + x₂ ≤ 4(0,0) 在内；(3,0) 在外
欧氏球‖x − xc‖₂ ≤ rB((0,0), 1)(0.6,0.8) 在边界；(2,0) 在外
椭球(x−xc)ᵀP⁻¹(x−xc) ≤ 1x₁²/4 + x₂² ≤ 1(2,0) 在边界；(1,0) 在内

💡 关键一跃

这张清单是"凸集的乐高"：超平面与半空间是一维一刀切的产物，球和椭球是"距离不超标的点"的集合，多面体是有限刀切完剩下的那块。遇到新集合，先问它像清单里的谁。

⚠️ 常见误区

把超平面和半空间混为一谈。{x : aᵀx = b} 只有薄薄一层（n−1 维），是仿射集；{x : aᵀx ≤ b} 是厚厚的半边空间，凸但不仿射。写约束时一个等号之差，可行域天差地别。

2.5保凸运算：怎么从旧凸集造新凸集

上一节备齐了五种构件，但真正的建模问题往往是构件的组合："同时满足两组约束""把可行域缩放平移一下"——这些操作做完还是凸集吗？本节回答：哪些运算保持凸性。这是本章最实用的一节。

① 任意交集保凸。若一族集合（可以无穷多个）每个都凸，则它们的交也凸。证明一行：交集中任取两点，它们同时在每个集合里，故线段也在每个集合里，从而在线段在交里。数字例：两个半空间 x₁ + x₂ ≤ 2 与 x₁ − x₂ ≤ 0 的交是一个角域（无界多面体）。验证点 (0.5, 1)：0.5 + 1 = 1.5 ≤ 2 ✓，0.5 − 1 = −0.5 ≤ 0 ✓，确实在交集中。推论：多面体（有限个半空间的交）自动是凸集——这就是 §2.4 ⑤ 为什么成立。

② 仿射映射保凸。设 f(x) = Ax + b。若 C 凸，则像集 f(C) 凸；若 D 凸，则原像 f⁻¹(D) 也凸。证明（像集）：取像集中两点 y₁ = Ax₁ + b、y₂ = Ax₂ + b，则

θy₁ + (1−θ)y₂ = A(θx₁ + (1−θ)x₂) + b ∈ f(C)

因为括号里的点在凸集 C 中。数字例：单位球 B((0,0), 1) 经对角缩放 x ↦ diag(2, 1)x（即 (x₁, x₂) ↦ (2x₁, x₂)），变成半轴为 2 和 1 的椭球 {y : y₁²/4 + y₂² ≤ 1}。验证边界点：(1, 0) 在球面上（范数 1），映到 (2, 0)，而 2²/4 + 0 = 1 ✓，恰在椭球边界上。这顺便解释了椭球为什么凸：它是球的仿射像。

③ 透视函数与线性分式变换。透视函数（Perspective）P(x, t) = x/t（要求 t > 0）保持凸性；它与仿射映射复合得到线性分式函数（Linear-Fractional）f(x) = (Ax + b)/(cᵀx + d)（分母为正处），同样保凸。一维数字例：f(x) = 1/x 把区间 [1, 2]（凸集）映为 [1/2, 1] = [0.5, 1]，仍是一个区间，仍然凸。

✅ 判定规则

判断"新集合是否凸"时，先别急着验证线段定义——试着把它写成已知凸集经保凸运算（交、仿射映射、透视/线性分式）得到的产物。能写出来，凸性自动成立。

⚠️ 常见误区

以为"并集"也保凸。两个凸集的并通常不凸：两个不相交圆盘的并，取两盘各一点，连线中点落在两盘之间的空白处（习题 L1-1 会让你动手验证）。保凸清单里没有并集。

多面体 = 有限个半空间与超平面的交；半空间、超平面都凸，交集保凸，故多面体自动凸。

2.6分离超平面定理：不碰的凸集总能被切开

前五节都是"单个凸集内部"的性质，本节给出一个关于两个凸集的定理——它是第5章对偶理论全部几何直觉的来源。

分离超平面定理（Separating Hyperplane Theorem）。设 C、D 是两个非空凸集且不相交（C ∩ D = ∅），则存在 a ≠ 0 与 b，使得

aᵀx ≤ b 对所有 x ∈ C 成立，且 aᵀx ≥ b 对所有 x ∈ D 成立

即超平面 {x : aᵀx = b} 把两个集合分到两侧。若两集都是闭集且至少一个有界，还能做到严格分离（两边的不等号都严格）。

二维完整例子。取闭圆盘 B((0,0), 1) 与 B((3,0), 1)。圆心距 = 3 > 1 + 1 = 2，两盘不相交。取竖直直线 x₁ = 1.5，即 a = (1, 0)、b = 1.5：

  • 左盘任一点满足 x₁ ≤ ‖x‖ ≤ 1 < 1.5（如最右点 (1,0)）；
  • 右盘任一点满足 x₁ ≥ 3 − ‖x − (3,0)‖ ≥ 2 > 1.5（如最左点 (2,0)）。

两侧严格不等，直线 x₁ = 1.5 是一条严格分离超平面。

图 2.3 两个不相交圆盘 B((0,0),1) 与 B((3,0),1)：直线 x₁ = 1.5 严格把它们分到两侧。注意缝隙的宽度来自圆心距 3 超出半径和 2 的部分。

相关结论：支撑超平面（Supporting Hyperplane）。对凸集 C 边界上的任一点 x₀，存在 a ≠ 0 使 aᵀx ≤ aᵀx₀ 对所有 x ∈ C 成立——即过边界点可以贴一张超平面，让整个集合躺在它一侧。它是分离定理用于"单点与集合"的推论。

💡 关键一跃

凸性把"两个集合不碰"这件几何事实，翻译成"存在一张超平面"这件代数事实。有了超平面，就有了 a 和 b 这两组数——后续对偶理论里的乘子，本质上就是这些分离超平面的法向量。

⚠️ 常见误区

以为分离总是严格的。两个凸集仅仅不相交，未必能严格分离（例如两个开半空间贴着同一张超平面）；严格分离需要额外条件，常用版本是：两集均闭且至少一个有界。另外，定理只对凸集成立——月牙形可以"抱住"一个点，使直线无法分开它们。

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
仿射集（Affine Set）
点击翻面 →
定义过集合中任意两点的整条直线仍在集合内：θx₁+(1−θ)x₂ ∈ C，θ ∈ ℝ。
解决问题给出最规矩的一类集合；线性方程组 Ax=b 的解集是它，等式约束因此好处理。
直觉完全不能拐弯的集合：直线、平面、全空间、单个点。
误区把 θ 限制在 [0,1]——那是凸集；仿射允许外插到线段之外。
何时用Ch4 处理等式约束 Cx=d；Ch10 等式约束优化的可行域就是仿射集。
概念卡 2
凸集（Convex Set）
点击翻面 →
定义连接集合中任意两点的线段仍在集合内：θx₁+(1−θ)x₂ ∈ C，θ ∈ [0,1]。
解决问题凸优化对可行域的全部要求；局部最优即全局最优的几何根源。
直觉没有洞、没有凹陷：集合里任意两点互相"看得见"。
误区只验证几个特殊点对就宣布凸；必须对任意两点与任意 θ 成立。
何时用贯穿全书；Ch4 判定一个优化问题是否凸的第一步。
概念卡 3
凸组合与凸包（Convex Combination & Hull）
点击翻面 →
定义凸组合：θ₁x₁+⋯+θₖxₖ，θᵢ ≥ 0 且和为 1；凸包 = 全体凸组合构成的集合。
解决问题凸包把任意集合"补"成最小凸集，是用有限点描述多面体的工具。
直觉用皮筋套住所有点，皮筋收缩后围成的区域就是凸包。
误区忘记系数必须非负——只要求和为 1 得到的是仿射组合，可能跑出凸包。
何时用Ch4 顶点多面体表示；LP 最优解可在顶点（凸组合的端点）取得。
概念卡 4
凸锥（Convex Cone）
点击翻面 →
定义对任意 x₁,x₂ ∈ C 与 θ₁,θ₂ ≥ 0，都有 θ₁x₁+θ₂x₂ ∈ C。
解决问题描述"非负缩放 + 混合"封闭的集合；非负象限、半定锥都是它。
直觉从原点射出的一束不分叉的光线。
误区以为锥必然凸——一、三象限的并是锥但带分叉，不凸。
何时用Ch4 的广义不等式与锥规划；Ch5 对偶锥的定义。
概念卡 5
超平面与半空间（Hyperplane & Halfspace）
点击翻面 →
定义超平面 {x : aᵀx = b}（a≠0）；半空间 {x : aᵀx ≤ b}。
解决问题线性约束的基本单元：等式给超平面，不等式给半空间。
直觉超平面是一刀切下去的"刀口"，半空间是刀口某一侧的全部。
误区混淆二者：超平面是 n−1 维的薄片（仿射），半空间是 n 维的厚块（凸而不仿射）。
何时用一切线性约束的写法；分离/支撑超平面定理的主角。
概念卡 6
多面体（Polyhedron）
点击翻面 →
定义有限个半空间与超平面的交：{x : Ax ≤ b, Cx = d}。
解决问题线性规划（LP）可行域的标准形状；凸性由"交集保凸"免费得到。
直觉用有限把平面刀切出来的一块（可能有界如三角形，也可能无界如角域）。
误区以为多面体必须有界——角域、半空间本身也是多面体。
何时用Ch4 线性规划；L3 习题的可行域；单纯形法在顶点间跳跃。
概念卡 7
分离超平面定理（Separating Hyperplane Theorem）
点击翻面 →
定义两个非空不相交凸集，必存在超平面 aᵀx = b 使一个满足 aᵀx ≤ b、另一个满足 aᵀx ≥ b。
解决问题把"几何上不碰"翻译成"代数上存在 (a,b)"，是对偶与最优性条件的桥梁。
直觉两块不碰的肥肉之间，总能插进一张薄板把它们隔开。
误区以为总能严格分离——需要"闭 + 至少一个有界"等额外条件。
何时用Ch5 对偶理论的几何核心；支撑超平面是它在边界点的特例。

📝分层习题

L1 概念辨析两个凸集的并集一定是凸集吗？给出结论并说明理由。
提示

试着构造最小的反例：在平面上找两个最简单的凸集（圆盘），让它们分开一段距离，然后检验某条线段。

完整解答

结论：不一定。反例：取闭圆盘 B((0,0), 1) 与 B((3,0), 1)，各自都是凸集（§2.4），但圆心距 3 > 2，互不相交。

取左盘点 (−1, 0)（范数 1，在左盘）与右盘点 (4, 0)（到 (3,0) 距离 1，在右盘）。连线中点（θ = 0.5）：

0.5·(−1,0) + 0.5·(4,0) = (1.5, 0)

(1.5,0) 到 (0,0) 的距离是 1.5 > 1，不在左盘；到 (3,0) 的距离是 1.5 > 1，不在右盘。中点不在并集里，故并集不凸。

易错点：不要以为"每个分量凸，合起来就凸"。保凸清单里只有交集，没有并集（§2.5）。

L1 概念辨析集合 {x ∈ ℝ² : x₁² ≤ x₂}（抛物线上方及边界区域）是凸集吗？
提示

按定义验证：任取区域内两点 (a₁, a₂)、(b₁, b₂)，写出中点（θ = 1/2），检验中点是否满足不等式。会用到 (u+v)² ≤ 2u² + 2v²。

完整解答

结论：是凸集。任取 (a₁,a₂)、(b₁,b₂) 满足 a₁² ≤ a₂、b₁² ≤ b₂。考察中点 ((a₁+b₁)/2, (a₂+b₂)/2)：

((a₁+b₁)/2)² = (a₁² + 2a₁b₁ + b₁²)/4 ≤ (a₁² + (a₁²+b₁²) + b₁²)/4 = (a₁² + b₁²)/2

（用了 2a₁b₁ ≤ a₁² + b₁²）。而 (a₁² + b₁²)/2 ≤ (a₂ + b₂)/2，恰好是中点的第二坐标。故中点满足 x₁² ≤ x₂，在集合内。中点情形成立后，由习题 L2-1 的结论（集合闭，中点封闭 ⟹ 凸），整个区域是凸集。

剧透：这个区域是函数 f(x₁) = x₁² 的"上镜图"（epigraph）。第3章将证明：函数凸 ⟺ 上镜图是凸集——x₁² 是凸函数，所以这片区域凸。先把几何直觉存起来。

L2 手算推导中点法判定凸性：设集合 C ⊆ ℝⁿ 是闭集，且 C 中任意两点的中点都在 C 中。证明 C 是凸集（即对所有 θ ∈ [0,1] 成立，而不只是 θ = 1/2）。
提示

分两步。第一步：对"二进制分数"θ = k/2ᵐ（k, m 为整数，0 ≤ k ≤ 2ᵐ）用归纳法证明 θx+(1−θ)y ∈ C——把奇数 k 的情形写成两个偶数分子的中点。第二步：任意 θ ∈ [0,1] 用二进制展开逼近，用闭性取极限。

完整解答

第一步：二进制分数成立。固定 x, y ∈ C，证明命题 P(m)：对所有 k ∈ {0, 1, …, 2ᵐ}，点 (k/2ᵐ)x + (1 − k/2ᵐ)y ∈ C。对 m 归纳。

基例 m = 0：k = 0 给出 y ∈ C，k = 1 给出 x ∈ C。成立。

归纳步：设 P(m) 成立，证 P(m+1)。取 k ∈ {0, …, 2ᵐ⁺¹}。

情形 1：k 为偶数，k = 2j。则 k/2ᵐ⁺¹ = j/2ᵐ，由 P(m) 直接得 (j/2ᵐ)x + (1 − j/2ᵐ)y ∈ C。

情形 2：k 为奇数。则 k−1 与 k+1 都是偶数，且都在 {0, …, 2ᵐ⁺¹} 内。注意 k/2ᵐ⁺¹ 恰好是 (k−1)/2ᵐ⁺¹ 与 (k+1)/2ᵐ⁺¹ 的算术平均。由情形 1，点 u = ((k−1)/2ᵐ⁺¹)x + (1 − (k−1)/2ᵐ⁺¹)y 与 v = ((k+1)/2ᵐ⁺¹)x + (1 − (k+1)/2ᵐ⁺¹)y 都在 C 中。由假设，中点 (u+v)/2 ∈ C。而

(u+v)/2 = (k/2ᵐ⁺¹)x + (1 − k/2ᵐ⁺¹)y

正是目标点。故 P(m+1) 成立。归纳完成：所有二进制分数 θ = k/2ᵐ 都满足。

第二步：取极限。任取 θ ∈ [0,1]，写二进制展开 θ = Σ bᵢ2⁻ⁱ，截断得 θₘ = ⌊2ᵐθ⌋/2ᵐ，则 θₘ 是二进制分数且 θₘ → θ。点列 zₘ = θₘx + (1−θₘ)y 由第一步知 zₘ ∈ C，且 zₘ → z = θx + (1−θ)y。C 是闭集，极限点 z ∈ C。∎

易错点：只归纳中点、不取极限，只能得到"二进制分数稠密集上成立"；闭性是把稠密推进到全部 θ 的钥匙，缺一不可。

L2 手算推导三点 (0,0)、(4,0)、(0,3) 的凸包内有一点 (1,1)。求 (1,1) 关于这三个顶点的一组凸组合系数，并验证。
提示

设 (1,1) = α(0,0) + β(4,0) + γ(0,3)。逐坐标列方程：第一坐标只含 β，第二坐标只含 γ；解出后用 α = 1 − β − γ 补足。

完整解答

设 (1,1) = α(0,0) + β(4,0) + γ(0,3)，约束 α+β+γ = 1，α,β,γ ≥ 0。

第一坐标：0·α + 4β + 0·γ = 1 ⟹ β = 1/4。

第二坐标：0·α + 0·β + 3γ = 1 ⟹ γ = 1/3。

系数和：α = 1 − 1/4 − 1/3 = 12/12 − 3/12 − 4/12 = 5/12。

验证：系数和 5/12 + 1/4 + 1/3 = 5/12 + 3/12 + 4/12 = 12/12 = 1 ✓；三者 5/12、1/4、1/3 全部非负 ✓。

组合：5/12·(0,0) + 1/4·(4,0) + 1/3·(0,3) = (0,0) + (1,0) + (0,1) = (1,1) ✓。

所以 (1,1) 确实在凸包（三角形）内，一组凸组合系数为 (α, β, γ) = (5/12, 1/4, 1/3)。

L3 建模应用某线性规划的可行域由 x₁ + x₂ ≤ 4、x₁ ≤ 2、x₁ ≥ 0、x₂ ≥ 0 给出。画出该区域，列出全部顶点，说明它是几个半空间的交，并判断点 (1,1) 是否可行。
提示

顶点 = 每次取两条边界线求交点，再检验这个交点是否满足其余全部不等式。四条边界：x₁+x₂=4、x₁=2、x₁=0、x₂=0。

完整解答

顶点枚举（两两边界求交，再筛掉违约点）：

  • x₁=0 与 x₂=0：交 (0,0)。检验：0+0=0 ≤ 4 ✓，0 ≤ 2 ✓。是顶点。
  • x₁=2 与 x₂=0：交 (2,0)。检验：2+0=2 ≤ 4 ✓。是顶点。
  • x₁=2 与 x₁+x₂=4：交 (2,2)。检验：2 ≤ 2 ✓，2 ≥ 0 ✓。是顶点。
  • x₁=0 与 x₁+x₂=4：交 (0,4)。检验：0 ≤ 2 ✓。是顶点。
  • x₁=0 与 x₂=0 已列；x₂=0 与 x₁+x₂=4 交 (4,0)，但 x₁=4 > 2 违约，舍去。

全部顶点：(0,0)、(2,0)、(2,2)、(0,4)，围成一个四边形（梯形）。

结构判定：可行域 = {x : x₁+x₂≤4} ∩ {x : x₁≤2} ∩ {x : x₁≥0} ∩ {x : x₂≥0}，即 4 个半空间的交，因此是多面体；由"交集保凸"（§2.5）自动是凸集。它也可以写成四个顶点的凸包。

点 (1,1) 是否可行：1+1 = 2 ≤ 4 ✓；1 ≤ 2 ✓；1 ≥ 0 ✓；1 ≥ 0 ✓。四条全部满足，(1,1) 可行（位于四边形内部）。

解析：D 正确——θy₁+(1−θ)y₂ = A(θx₁+(1−θ)x₂)+b，括号内是凸集里的点（§2.5）。A 错：两个不相交圆盘的并，连线中点落在缝隙里（习题 L1-1 已证）。B 错：取圆盘 B((2,0),1)，其中心对称是 B((−2,0),1)，两者并集同样不凸。C 错：并集不保凸，与是否平移无关。保凸清单是：交集、仿射映射、透视/线性分式——都不含"并"。
