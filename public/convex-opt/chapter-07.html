7.1最大似然：把「最像真的」变成一道优化题

第6章的拟合是从「误差最小」出发的；统计学换一个问法：观测数据 y 已经摆在那里，哪个参数 θ 最有可能产生它？设观测的概率密度为 p(y;θ)，最大似然估计（Maximum Likelihood Estimation, MLE）就是：

θ̂ = argmaxθ p(y;θ) = argmaxθ ℓ(θ)，  ℓ(θ) = log p(y;θ)

取对数有两个理由：① 独立观测的联合密度是乘积 ∏p(yᵢ;θ)，对数把它变成求和 ∑log p(yᵢ;θ)——求和结构是优化的朋友；② log 严格递增，不改变 argmax 的位置。真正决定这题好不好解的是第三条性质：ℓ(θ) 关于 θ 是否凹。凹函数最大化 = 凸优化（目标取负即凸函数最小化），第9–11章的算法全盘适用。

完整手算例：抛硬币的 ML 估计

硬币正面概率 p 未知，抛 n=10 次，k=7 次正面。似然 p^k(1−p)^(n−k)，对数似然：

ℓ(p) = 7 ln p + 3 ln(1−p)
步骤计算结果
① 一阶导ℓ′(p) = 7/p − 3/(1−p)
② 置零7/p = 3/(1−p) → 7(1−p) = 3p → 7 = 10pp̂ = 7/10 = 0.7
③ 二阶导验证ℓ″(p) = −7/p² − 3/(1−p)²，两项恒负ℓ 严格凹 ✓
④ 结论凹函数的唯一驻点即全局最大p̂ = k/n = 0.7 就是全局最优

直觉答案「频率=概率」在这里被严格证明：ℓ 严格凹 ⟹ 驻点唯一且全局最优。这个「k/n」谁都会猜，但只有凹性保证了它不是某个局部陷阱——这就是凸性在统计学里的意义。

💡 关键一跃

ML 估计好解不好解，一眼看凹性：对数似然关于参数凹（或能化成凹），就是凸优化；不凹，就只能爬山碰运气。指数族分布（高斯、Bernoulli、Poisson…）的对数似然关于自然参数自动凹——这不是巧合，是指数族的结构性礼物。

⚠️ 常见误区

「ML 估计就是最优估计」——错。ML 只是「让已发生的数据最可能」的估计；它没有告诉你这个估计本身方差多大、偏差多少。7.3 节的检测器设计和 7.4 节的实验设计，正是在回答「怎么让估计更准」，而不是「哪个参数最像」。

7.2高斯测量：ML 与最小二乘的会师

上一节给出了一般原则；本节看最重要的特例。线性测量模型 y = Ax + w，噪声 w ~ N(0, σ²I)。此时：

ℓ(x) = 常数 − 12σ² ‖y − Ax‖₂²

最大化 ℓ 等价于最小化 ‖y−Ax‖₂²——高斯噪声下的 ML 估计就是第6章的最小二乘。第6章的残差平方和在这里获得了概率身份：它是（差一个常数倍）负对数似然。反过来，若噪声不是高斯而是重尾分布，ML 给出的罚函数恰好是 Huber 那一族——第6章的罚函数表格，每一行背后都站着一个噪声分布。

完整手算例：同一点测三次

对未知 μ 独立测量 3 次，y = 2, 4, 6，σ²=1。ℓ(μ) = 常数 − ½∑(yᵢ−μ)²，最大化即最小化 ∑(yᵢ−μ)²：

ddμ ∑(yᵢ−μ)² = −2∑(yᵢ−μ) = 0  ⟹  μ̂ = 2+4+63 = 4

样本均值就是 ML 估计。顺带，这个目标是严格凸的二次函数，唯一驻点即全局最优——又一次「凸性保证」。

再看协方差估计（Covariance Estimation）：y₁,…,yₙ 来自 N(0, Σ)，均值已知为 0，估计 Σ。对数似然（差常数）：

ℓ(Σ) = −n2 log det Σ − 12 ∑ yᵢᵀΣ⁻¹yᵢ

这个函数对 Σ 不凹，但换变量 S = Σ⁻¹ 后，−log det S⁻¹…整理得 ℓ(S) = (n/2)log det S − (1/2)tr(S·∑yᵢyᵢᵀ)，log det 凹、tr 线性，故 ℓ 关于 S 凹——问题可解。置梯度为零得闭式解：

Σ̂ = 1n ∑ yᵢyᵢᵀ  （样本协方差矩阵）

样本少、维度高时 Σ̂ 接近奇异，加 δI 正则（Σ̂+δI）——这正是第6章 Tikhonov 的统计翻版：它对应于「给协方差一个各向同性的先验」。

💡 关键一跃

同一个问题换身衣服反复出现：第6章的岭回归 = 高斯噪声 + 高斯先验下的 MAP；样本协方差 + δI = 协方差的正则化 ML。正则化从来都不是补丁，是被显式写出来的先验。

⚠️ 常见误区

「ML = 最小二乘」不能脱离前提乱用。这个等价只在「噪声独立同分布高斯、方差已知且各分量相同」时成立。噪声相关（协方差非对角）时，ML 是加权最小二乘（白化后再投影）；噪声重尾时，ML 是稳健罚——罚函数的形状由噪声分布决定。

7.3假设检验：检测器本身是一个优化变量

估计回答「参数是多少」，假设检验（Hypothesis Testing）回答「哪个假设为真」。二选一检验：观测 X ∈ {0, 1}，在两个假设下的分布为：

P(X=0)P(X=1)
H₀0.90.1
H₁0.30.7

检测器 T 是一个判决规则。两类错误：虚警（False Positive，H₀ 为真却判 H₁）与漏检（False Negative，H₁ 为真却判 H₀）。看确定性检测器「X=1 判 H₁，X=0 判 H₀」：

P_fp = P₀(X=1) = 0.1，   P_fn = P₁(X=0) = 0.3，   总错误率 = 0.1 + 0.3 = 0.4

换「X=1 判 H₀」会更糟（0.9+0.7=1.6）。这个例子太简单，但把问题一般化就精彩了：允许随机化检测器（Randomized Detector）——观测到 X=k 时以概率 tₖ 判 H₁。那么：

P_fp = 0.9t₀ + 0.1t₁，   P_fn = 0.3(1−t₀) + 0.7(1−t₁)

两者都是 t₀, t₁ ∈ [0,1] 的线性函数。于是「min P_fp + P_fn」或「P_fp ≤ α 下 min P_fn」都是 LP——检测器设计是一个凸优化问题。Neyman–Pearson 引理进一步告诉我们：最优检测器必是似然比检验（Likelihood Ratio Test）——比较 p₁(x)/p₀(x) 与阈值。本例中 L(1)=0.7/0.1=7 ≫ L(0)=0.3/0.9=1/3，X=1 强烈支持 H₁，与上面的判决一致。

扫一遍阈值（或扫一遍加权组合），把 (P_fp, P_fn) 的可达到点对画出来，就是 ROC 曲线（Receiver Operating Characteristic）——检测问题的 Pareto 前沿，和第6章的权衡曲线是同一个数学对象。

💡 关键一跃

「设计检测器」听起来是统计决策，写出来却是对判决概率 tₖ 的线性规划。统计问题的可解性，常常在你把「决策规则」本身当作优化变量之后才显现——变量选对了，凸性就来了。

⚠️ 常见误区

「虚警率和漏检率可以同时任意小」——错。两者被 ROC 曲线锁死在一条 Pareto 前沿上：压低一个必然抬高另一个（除非换更 informative 的观测）。选工作点是工程判断，和选正则参数 λ 一模一样。

7.4实验设计：在采集数据之前就优化

前三节都假设数据已经在手。更上游的问题是：测什么、各测多久，才能让估计最准？设可选实验 k=1,…,p，第 k 个实验给出方向 vₖ 上的测量，误差协方差为：

E(λ) = ( ∑k λₖ vₖvₖᵀ )⁻¹，   λₖ ≥ 0，∑λₖ = 1

λₖ 是分配给实验 k 的时间（预算）占比。「估计最准」要压小 E——但 E 是矩阵，怎么压？取标量化：D-最优设计（D-optimal Design）最大化 log det(∑λₖvₖvₖᵀ)（等价于最小化置信椭球体积 log det E）。log det 在 PD 锥上凹，约束是单纯形——凸问题。

完整手算例：两个实验的预算分配

v₁ = (1, 0)ᵀ，v₂ = (0, 1)ᵀ。则 ∑λₖvₖvₖᵀ = diag(λ₁, λ₂)，目标：

max log det diag(λ₁,λ₂) = log(λ₁λ₂)，   λ₁+λ₂=1

由对称性（或 AM–GM：λ₁λ₂ ≤ ((λ₁+λ₂)/2)² = 1/4，等号当且仅当 λ₁=λ₂）：

λ₁ = λ₂ = 12

直觉：两个方向都重要且互相垂直，预算平分。若把 v₂ 换成 (1,1)ᵀ/√2（与 v₁ 部分相关），两个实验信息重叠，最优解会把更多预算投向能补充 v₁ 的方向——定性结论：预算跟着「信息增量」走，不跟「实验个数」走。

💡 关键一跃

实验设计是「在数据到来之前做的优化」。它把第7章闭环了：设计（选 λ）→ 采集 → 估计（ML）→ 评估（E 越小越准）→ 回头改设计。凸优化让这一整圈每一步都有算法。

⚠️ 常见误区

「每个实验分到的预算应该和它的测量精度成正比」——不一定。预算分配看的是 vₖ 张成的方向结构：两个高度相关的实验，即使各自都很精确，也不值得平分预算。D-最优度量的是联合信息量（椭球体积），不是单实验质量。

对数似然的凹性
点击翻面 →
定义ℓ(θ)=log p(y;θ) 关于 θ 是凹函数。
解决问题它是 ML 问题可用凸优化全局求解的充要线索。
直觉凹的山只有一个顶——爬到哪里哪里就是最高峰，没有假山顶。

概念卡 3
协方差估计（Covariance Estimation）
点击翻面 →
定义由样本估计 Σ；ML 解为样本协方差 Σ̂=(1/n)∑yᵢyᵢᵀ。
解决问题多变量数据的二阶结构刻画，是加权最小二乘与 whitening 的输入。
直觉把样本的「云团形状」用一个椭球（由 Σ 决定）描出来。
误区直接对 Σ 优化——对数似然对 Σ 不凹，要换变量 S=Σ⁻¹ 才是凸问题。
何时用高维数据降维、风险建模；样本不足时配 +δI 正则（Tikhonov 的统计版）。
概念卡 4
随机化检测器（Randomized Detector）
点击翻面 →
定义观测 X=k 时以概率 tₖ 判 H₁ 的判决规则，tₖ∈[0,1]。
解决问题把检测器设计变成对 t 的 LP——错误率是 t 的线性函数。
直觉拿不准的观测就掷一枚带偏硬币，「掷多偏」本身可以优化。
误区以为随机化是偷懒。Pareto 前沿内部的点只能靠随机化达到，确定性规则做不到。
何时用虚警受限的检验设计；NP 引理保证最优解就是似然比加阈值。
概念卡 5
ROC 曲线
点击翻面 →
定义所有可达到的 (P_fp, P_fn/P_det) 点构成的 Pareto 前沿。
解决问题回答「这个观测系统最多能多好」，并把选工作点与选阈值分离。
直觉检测器的「权衡菜单」：你要多低的虚警，就得接受多高的漏检。
误区以为曲线上的点有优劣。曲线上处处 Pareto 最优，选点看代价权重，不看曲线。
何时用评估与比较检测系统；与 Ch6 权衡曲线、Ch8 间隔权衡同一思想。
概念卡 6
D-最优实验设计
点击翻面 →
定义max log det(∑λₖvₖvₖᵀ)，s.t. λ≥0、∑λ=1：最小化置信椭球体积。
解决问题数据采集前的预算分配——测什么、各测多久，估计才最准。
直觉把预算撒向「信息增量」最大的方向，而不是最忙的实验。
误区按实验精度均分预算；方向相关的实验信息重叠，不该平分。

📝分层习题

L1 概念辨析判断对错并说明理由：「只要模型是可微的，最大似然估计就能用凸优化求全局最优。」
提示

可微性解决的是「能不能求导」；全局最优需要的是另一种几何性质。回想 7.1 的凹性判据。

完整解答
错。可微 ≠ 凹。混合高斯、隐变量模型的似然通常多峰（非凹），梯度法只能找到局部极大，初值不同答案不同。ML 问题能全局求解的依据是对数似然关于参数凹（指数族对自然参数自动满足）。可微性只是让「爬山」可执行，凹性才保证「山只有一个顶」。
L1 概念辨析选择：把检测器的错误率写成判决概率 tₖ 的函数后，「min(P_fp + P_fn)」与「P_fp≤α 下 min P_fn」分别属于：A. 都非凸；B. 前者 LP、后者非凸；C. 都是 LP；D. 前者 LP、后者 QP。
提示

看 P_fp、P_fn 关于 t 的表达式各是什么次数；约束 P_fp≤α 是什么类型的约束。

完整解答
C。P_fp 与 P_fn 都是 t 的线性函数：前者目标线性 + 箱约束 [0,1]，是 LP；后者目标线性 + 一个线性不等式约束，仍是 LP。B、D 错在以为加约束会升级问题类型——线性约束不改变 LP 身份。A 错得最远：整个 7.3 节的要点就是这个问题的变量选对了之后天然线性。
L2 手算推导Poisson 分布 p(k;λ) = λᵏe^(−λ)/k!。观测到独立样本 k₁=2、k₂=3、k₃=4，手算 λ 的 ML 估计，并验证对数似然凹。
提示

写出联合似然取对数：ℓ(λ) = (∑kᵢ)ln λ − nλ + 常数。对 λ 求导置零；二阶导检查符号。

完整解答
① ℓ(λ) = ∑(kᵢlnλ − λ − ln kᵢ!) = 9lnλ − 3λ + 常数。② 一阶条件：ℓ′(λ) = 9/λ − 3 = 0 → λ̂ = 3。③ 二阶导：ℓ″(λ) = −9/λ² < 0，严格凹，故 λ̂=3 是全局最优。④ 规律验证：Poisson 的 ML 估计 = 样本均值 (2+3+4)/3 = 3 ✓。又一次看到「指数族的 ML = 样本均值」这一结构性结果。
L2 手算推导对 7.3 节的检验问题（H₀: (0.9,0.1)，H₁: (0.3,0.7)），手算随机化检测器的最优 t₀、t₁（目标 min P_fp + P_fn），并给出最小总错误率。
提示

把总错误率展开成 t₀、t₁ 的线性函数，注意 t∈[0,1] 的箱约束：线性函数在区间端点取最优。

完整解答
① 总错误 E = P_fp + P_fn = [0.9t₀+0.1t₁] + [0.3(1−t₀)+0.7(1−t₁)] = 1 + 0.6t₀ − 0.6t₁。② 要在 [0,1]² 上最小化：t₀ 系数 +0.6>0 → t₀=0；t₁ 系数 −0.6<0 → t₁=1。③ 最小总错误 E = 1 + 0 − 0.6 = 0.4，即「X=0 判 H₀、X=1 判 H₁」——与正文确定性检测器一致。④ 读法：X=0 在 H₀ 下更常见（0.9 vs 0.3），X=1 在 H₁ 下更常见（0.7 vs 0.1），似然比检验的结论完全一致，LP 自动把它找了回来。
L3 建模应用某医学筛查：疾病患病率极低，检测试剂在「有病人群」中灵敏度 0.95、在「健康人群」中虚警率 0.05。医院问：能不能把虚警压到 0.01 以下，同时漏检几乎不升？请用本章语言建模（变量、目标、约束），说明这是什么类型的优化问题，并给出求解思路与你会向医院解释的那句话。
提示

允许随机化判决（阳性时以概率 t₁ 报阳、阴性时以 t₀ 报阳）。把两个错误率写成 t 的函数，再把医院的要求写成约束。

完整解答
建模：变量 t₀, t₁ ∈ [0,1]（随机化检测器）。P_fp = 0.95t₀·… 按正文记号直接写：P_fp = 0.95·t₀ + 0.05·t₁（健康组中按试剂表现拆分），P_fn = 0.05(1−t₀)·… 整理为标准形 min P_fn s.t. P_fp ≤ 0.01，0≤t≤1——目标和约束都是 t 的线性函数，是 LP。求解思路：两变量 LP，可在 (t₀,t₁) 平面上图解，或枚举约束交点；一般结论是压低虚警必然收紧 t₁，漏检随之上移，最优解落在约束边界 P_fp=0.01 上。向医院解释的那句话：「虚警和漏检被 ROC 曲线锁在同一条前沿上，0.01 的虚警能买到多低的漏检是算出来的，不是许愿——我们能做的是在这条前沿上找到你指定虚警下的最低点，并告诉你它具体是多少。」若想整体下移曲线，只能换更准的试剂（更好的观测），而不是更聪明的判决。

自测 1
ML 估计问题能用凸优化求全局最优的关键性质是：
  • A. 似然函数处处可微
  • B. 对数似然关于参数是凹函数
  • C. 样本量足够大
  • D. 参数个数小于样本个数
解析：B 对——最大化凹函数（= 最小化凸函数）才有全局最优保证，这是凸优化的地基。A 错：可微多峰函数照样有局部极大（如混合高斯）。C 错：大样本改善的是估计的统计性质（渐近无偏/有效），不改变目标函数的几何形状，非凹还是非凹。D 错：参数与样本的数量关系影响的是适定性，与凹凸性无关。
自测 2
「高斯噪声下 ML = 最小二乘」成立需要的前提是：
  • A. 噪声是任意对称分布
  • B. 噪声均值为零即可
  • C. 噪声独立、同方差的高斯分布
  • D. 测量矩阵 A 列满秩
解析：C 对——只有 w~N(0,σ²I) 时负对数似然才恰好正比于 ‖y−Ax‖²。A 错：对称重尾分布（如 Laplace）给出的是 ℓ1 型罚，不是平方。B 错：零均值加相关噪声给出加权最小二乘，不是普通最小二乘。D 错：列满秩保证最小二乘解唯一，与「ML 是否等于最小二乘」这个统计等价无关。
自测 3
协方差 ML 估计中，把变量从 Σ 换成 S = Σ⁻¹ 的原因是：
  • A. 对数似然关于 S 凹（log det S 凹 + 线性项），问题变凸
  • B. S 的元素更少，计算更快
  • C. Σ 不可逆时 S 仍然存在
  • D. 换变量后不再需要 log det
解析：A 对——ℓ 关于 Σ 不凹，关于 S 是「log det 凹函数 + 线性函数」，故可全局求解，解完换回 Σ̂=(1/n)∑yᵢyᵢᵀ。B 错：S 与 Σ 同为对称矩阵，自由度相同。C 错：S=Σ⁻¹ 存在恰恰要求 Σ 可逆，方向说反了。D 错：log det 仍在目标里，只是变成了凹的那一项。
自测 4
随机化检测器设计问题是 LP，根本原因是：
  • A. 因为观测只取两个值
  • B. 因为 Neyman–Pearson 引理
  • C. 因为 LP 求解器比 QP 快
  • D. 因为虚警率与漏检率都是判决概率 tₖ 的线性函数
解析：D 对——目标与约束关于变量 t 全线性，这是 LP 的定义；本质是把「判决规则」本身设为优化变量。A 错：观测取任意多个值时仍是 LP（线性结构来自 t 的加权求和，与取值个数无关）。B 错：NP 引理告诉我们最优解长什么样（似然比检验），不是凸性的来源。C 错：求解速度是结果不是原因，且不构成数学上的归类依据。
自测 5
D-最优实验设计中，目标取 log det(∑λₖvₖvₖᵀ) 的几何含义是：
  • A. 最大化实验方向的总长度
  • B. 最小化参数置信椭球的体积（log det E 的负号形式）
  • C. 最大化各实验测量值的和
  • D. 使 λ 尽量均匀分布的熵正则
解析：B 对——误差协方差 E=(∑λvₖvₖᵀ)⁻¹，置信椭球体积 ∝ det E 的平方根，log det 取负号后等价于最大化 log det(∑λvₖvₖᵀ)，且该函数凹、问题凸。A 错：方向长度与被分配的信息量无直接关系。C 错：测量值的和与估计精度无关。D 错：均匀分配只是双正交特例的巧合结论（AM–GM 等号），不是目标本身的设计意图。
