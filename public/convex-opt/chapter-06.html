6.1为什么需要范数逼近：从「拟合一条直线」说起

第4、5章给了你一台判定机：拿来一个问题，判断它是不是凸的；是凸的，就有 KKT 条件刻画最优解。但真实世界递到你手上的从来不是标准形，而是 一堆数据 和一句模糊的要求：「帮我找个规律」。把这句模糊的话翻译成凸问题，就是建模，也是第6–8章的主题。

最古老的拟合任务：观测到 m 组数据 (tᵢ, yᵢ)，怀疑 y 大约是 t 的线性函数 y = c·t + d。参数是 x = (c, d)ᵀ。每个数据点给出一个残差（Residual）：ri = c·tᵢ + d − yᵢ，即「模型预测 − 实测」。全体残差写成矩阵形式：

r = Ax − b，  范数逼近问题（Norm Approximation）：minimize ‖Ax − b‖

三要素：参数 x（要调的东西）、残差 Ax−b（误差的载体，仿射于参数）、范数（把误差向量压成一个数的规则）。范数是凸的，残差仿射于 x，复合仍凸——所以无论选哪种范数，范数逼近问题都是凸问题。这是本章一切结论的地基。

选 ℓ2 范数就是最小二乘（Least Squares）：min ‖Ax−b‖₂²。它是光滑凸函数，梯度置零得：

∇x ‖Ax−b‖₂² = 2Aᵀ(Ax−b) = 0  ⟹  正规方程（Normal Equations）：AᵀAx̂ = Aᵀb

完整手算例：3 个点的最小二乘直线

数据 (t, y)： (0, 1)、(1, 2)、(2, 2)，拟合 y = c·t + d。

步骤计算结果
① 写出 A 与 bA 每行 = (tᵢ, 1)，b = (y₁,y₂,y₃)ᵀA = [[0,1],[1,1],[2,1]]，b = (1,2,2)ᵀ
② 算 AᵀA第一列平方和 0+1+4=5；列内积 0+1+2=3；第二列平方和 3AᵀA = [[5,3],[3,3]]
③ 算 Aᵀb(0·1+1·2+2·2, 1+2+2)Aᵀb = (6, 5)ᵀ
④ 解方程组5c+3d=6，3c+3d=5，两式相减 2c=1c = 1/2，代入得 d = 7/6
⑤ 验残差r = Ax̂−b = (7/6−1, 5/3−2, 13/6−2)r = (1/6, −1/3, 1/6)
⑥ 验正交Aᵀr 第一分量 0·(1/6)+1·(−1/3)+2·(1/6)=0；第二分量 1/6−1/3+1/6=0Aᵀr = 0 ✓

平方误差 ‖r‖₂² = 1/36 + 4/36 + 1/36 = 1/6 ≈ 0.167。任何别的 (c, d) 都不会更小——凸问题的梯度零点就是全局最优。

💡 关键一跃

最小二乘 = 把观测向量 b 正交投影 到 A 的列空间上。Ax̂ 是列空间里离 b 最近的点，残差 r 与列空间垂直（Aᵀr=0 正是垂直的代数写法）。

⚠️ 常见误区

「‖r‖₂ 最小意味着每个残差都很小」——错。ℓ2 只惩罚平方和：一个残差为 3 和九个残差为 1 的平方和相同（9），但 ℓ2 会「 prefer 」后者吗？恰恰相反：平方把大残差放得更大，所以 ℓ2 会拼命压低最大残差——这正是它怕离群点的原因：一个坏数据点会绑架整条拟合曲线。6.4 节的 Huber 罚就是为此而生。

6.2为什么要正则化：过拟合与病态是一对双胞胎

上一节给了一个干净利落的闭式解，但它有两个软肋。其一：当 A 的列接近线性相关时，AᵀA 接近奇异，正规方程的解会剧烈抖动——数据动一点，参数飞出去很远（病态）。其二：参数个数逼近数据个数时，模型能把噪声也一并「学」下来（过拟合）。这两个问题的药方是同一个：在目标里加一项正则化（Regularization）罚项，惩罚参数的「不安分」。

Tikhonov 正则化（岭回归 Ridge）：minimize ‖Ax−b‖₂² + λ‖x‖₂²，λ > 0

两个凸的二次函数相加仍凸，梯度置零：

2Aᵀ(Ax−b) + 2λx = 0  ⟹  (AᵀA + λI)x̂ = Aᵀb

AᵀA 只是半正定，可能奇异；但加上 λI 之后，所有特征值至少抬升 λ，所以 AᵀA+λI 对任意 λ>0 一定对称正定、一定可逆——病态被治好了。

完整手算例：一维岭回归

只有一个参数、一个方程：A = [1]，b = [2]，即 min (x−2)² + λx²。求导：2(x−2) + 2λx = 0，得：

λ 越大，解越被「拉回」原点（收缩 shrinkage），拟合越差但参数越温和。把两个目标 J_fit = ‖Ax−b‖² 与 J_reg = ‖x‖² 的取值对画出来，扫一遍 λ 就得到权衡曲线（Trade-off Curve）——它是两个目标的 Pareto 前沿，每个 λ 对应曲线上一点。

💡 关键一跃

正则化就是多目标优化的「加权求和」标量化：J_fit + λ·J_reg。λ 是汇率——「我愿用多少个单位的拟合误差，换一个单位的参数温和」。权衡曲线告诉你所有不亏本的兑换率，选哪一点是工程判断，不是数学结论。

⚠️ 常见误区

「λ 越大越稳健，所以宁大勿小」——错。λ→∞ 时 x̂→0，模型什么都不拟合，稳健到无用。λ 必须在权衡曲线上选：常用做法是留出一部分数据做交叉验证，选验证误差最小的 λ。

6.3为什么 ℓ1 正则能给出「真正的零」：LASSO 与稀疏

上一节的罚项 ‖x‖₂² 把参数往原点拉，但永远不会恰好拉到 0——看一维例 x̂=2/(1+λ)，只要 λ 有限，x̂ 就不是零。可很多场景我们想要的恰恰是零：从 1000 个候选特征里挑出真正有用的 10 个（特征选择），从一堆基函数里挑出一小组来表达信号（基追踪）。把罚项换成 ℓ1 范数：

LASSO（Least Absolute Shrinkage and Selection Operator）：minimize ‖Ax−b‖₂² + λ‖x‖₁

ℓ1 范数凸而不可微（在 0 处有棱角），没有闭式解，但仍是凸问题，第9–11章的算法能解。为什么它会产生精确的零？看一维就全明白了。

完整手算例：一维软阈值

min ½(x−2)² + λ|x|。分段讨论（|x| 在 0 处不可微，用次梯度）：

区域导数/次梯度条件结论
x > 0(x−2) + λ = 0 → x = 2−λ，仅当 λ<2 时合法λ<2 时 x̂ = 2−λ
x < 0(x−2) − λ = 0 → x = 2+λ > 0，矛盾无解
x = 0次梯度 (0−2) + λ·[−1,1] = [−2−λ, −2+λ] 需含 0λ ≥ 2 时 x̂ = 0
x̂ = sign(2)·max(|2|−λ, 0) —— 这就是软阈值（Soft Thresholding）算子

对比：λ=1 时岭回归给 x̂=1、LASSO 也给 x̂=1；λ=3 时岭回归给 x̂=0.5（小但非零），LASSO 给 x̂=0（精确为零）。差别在于：ℓ1 在 0 处的次梯度是一整个区间 [−λ, λ]，只要数据的「拉力」(−2) 落在这个区间内，最优解就钉死在 0；而 x² 在 0 处导数恰为 0，没有「容差区间」，任何拉力都能把解拉离原点。

💡 关键一跃

几何版本：ℓ2 球是圆的，等高线与它相切于任意方向；ℓ1 球是带尖角的菱形，尖角全在坐标轴上，等高线大概率先碰到尖角——于是解落在坐标轴上，其余分量为零。棱角制造稀疏。

⚠️ 常见误区

「ℓ1 是 ℓ0（数非零个数）的精确等价」——错。ℓ0 非凸、组合爆炸；ℓ1 只是它的凸放松，在相当广泛的条件下（RIP、不相干性）恰好恢复出 ℓ0 的解，但并不总是。把放松当等价，会在反例上栽跟头。

6.4换一支尺子：稳健罚函数与控制最坏情形

前三节一直在问「残差怎么罚」。更一般的写法是罚函数逼近（Penalty Function Approximation）：min ∑ᵢ φ(rᵢ)，φ 是对称凸函数、φ(0)=0。选不同的 φ，就是在回答「你最在乎哪种误差」。

罚函数 φ(u)形式在乎什么问题类型
二次 u²u²平均表现，怕大残差最小二乘（闭式解）
绝对值 |u||u|抗离群（大残差只线性增长）可化 LP
Huber|u|≤M: u²；|u|>M: 2M|u|−M²小残差精修、大残差不绑架光滑凸，QP 可解
死区 deadzonemax(|u|−a, 0)a 以内的误差免费可化 LP
log-barrier−log(1−u²/a²)（|u|<a）残差绝不允许碰 ±a光滑凸 → 第11章内点法

Huber 罚（Huber Penalty）是最实用的稳健选择：小残差用平方（保持光滑与精修能力），大残差改线性（导数被钳在 ±2M，单个离群点的拉力有上限）。而「控制最坏情形」对应 ℓ∞：

Chebyshev 逼近：minimize ‖Ax−b‖∞  ⟺  LP：minimize t，s.t. −t ≤ aᵢᵀx−bᵢ ≤ t，i=1,…,m

完整手算例：同样 3 个点，换 ℓ∞ 尺子

数据还是 (0,1)、(1,2)、(2,2)，拟合 y = c·t + d，目标 min max{|d−1|, |c+d−2|, |2c+d−2|}。最优时三个残差必然「等幅振荡」（若不满足，把直线平移/旋转还能再压 t），即残差形如 (+t, −t, +t)：

步骤方程结果
① 设残差模式d−1 = t；c+d−2 = −t；2c+d−2 = t三个方程三个未知数 (c,d,t)
② 由 ① 得d = 1+t
③ 由 ② 得c = 2−t−d = 1−2t
④ 代入 ③ 式2(1−2t) + (1+t) − 2 = t → 1−3t = tt = 1/4
⑤ 回代d = 5/4，c = 1/2直线 y = ½t + 5/4，最坏误差 1/4

对比 6.1 的最小二乘解（同一条斜率 c=½，但 d=7/6）：最小二乘的最大残差是 1/3 ≈ 0.333，Chebyshev 把它压到 1/4 = 0.25，代价是平方误差从 1/6 升到 1/16+1/16+1/16=3/16。选范数就是选偏好：ℓ2 在乎总账，ℓ∞ 在乎最惨的那一个。

💡 关键一跃

注意表里最后一行：log-barrier 罚把「|残差| 不许超过 a」这条硬约束软化成目标里的一堵对数墙。这正是第11章内点法的胚胎——今天它是拟合里的一支尺子，到时候它会成为处理一切不等式约束的通用机制。

⚠️ 常见误区

「ℓ∞ 控制最坏情形，所以它最稳健」——恰恰相反。ℓ∞ 把全部注意力押在最差数据点上，如果那一点本身是离群点，整个解被它拖走。抗离群的是 ℓ1/Huber（对大残差反应迟钝），不是 ℓ∞（对大残差反应过敏）。

解决问题特征选择/基追踪：需要解「恰好有很多零」时，ℓ2 做不到，ℓ1 能。
直觉ℓ1 球是带棱角的菱形，尖角在坐标轴上，等高线先碰尖角 → 稀疏解。
误区ℓ1 ≠ ℓ0。它只是 ℓ0 的凸放松，恢复稀疏解需要条件，不是恒等式。
何时用稀疏建模；压缩感知；作为不可微凸问题，是 Ch9 次梯度法/近端法的典型客户。
概念卡 5
Huber 罚（Huber Penalty）
点击翻面 →
定义|u|≤M 取 u²，|u|>M 取 2M|u|−M²；一次连续可微的凸罚。
解决问题数据里混着离群点时，既要 ℓ2 的精修能力，又要 ℓ1 的抗绑架能力。
直觉对残差「限量供应愤怒」：误差在 M 以内认真计较，超过 M 就只剩固定力度的反对。
误区以为稳健 = 不在乎大误差。Huber 仍线性增长地惩罚大误差，只是不再平方放大。
何时用带野值的回归/标定；Ch7 中对应一类重尾噪声分布的 ML 估计。
概念卡 6
Chebyshev 逼近（ℓ∞ / Minimax）
点击翻面 →
定义min ‖Ax−b‖∞，最小化最大残差；等价 LP：min t, −t≤r≤t。
解决问题最坏情形比平均表现更要紧的场合（安全裕度、最坏保证）。
直觉只盯最惨的那个数据点，把它伺候好了，其他人自动达标。
误区以为它「稳健」。它对最差单点过敏，一个离群点就能拖走整个解——稳健请用 Huber/ℓ1。
何时用鲁棒设计、最坏情况分析；也是「把 min-max 目标 epigraph 化成 LP」的标准范例。

📝分层习题

L1 概念辨析判断对错并说明理由：「只要数据量足够大，最小二乘拟合就不需要正则化。」
提示

正则化治的两个病——病态与过拟合——分别随数据量增大而消失吗？想一想 A 的列相关结构是不是数据量能改变的。

完整解答
错（说得绝对了）。数据量增大能压住过拟合（参数个数远小于样本数时，噪声平均掉了），但治不了病态：如果 A 的两列本身就接近平行（如两个几乎相同的传感器），增大数据量不改变列空间的退化方向，AᵀA 依旧接近奇异，正则化仍然必要。正则化的两个动机要分开看。
L1 概念辨析选择：min‖Ax−b‖₁ 和 min‖Ax−b‖₂² 分别属于哪类问题？A. 都是 QP；B. 前者 LP、后者 QP；C. 前者可化 LP、后者是 QP；D. 都不可解。
提示

|rᵢ| 本身不是线性的，但可以用辅助变量 sᵢ ≥ ±rᵢ 把它「epigraph 化」。平方和是二次凸函数。

完整解答
C。min‖r‖₁ 引入 sᵢ ≥ rᵢ、sᵢ ≥ −rᵢ，化 min∑sᵢ 的 LP；min‖r‖₂² 目标含二次项，是 QP（且无约束时闭式解）。A 错在把 ℓ1 也当二次；B 错在「前者就是 LP」——严格说需要改写一步；D 显然错，两者都是凸问题。这个「引入辅助变量把范数撑成约束」的手法在 Ch4 已经见过，本章反复用。
L2 手算推导用正规方程手算过原点直线 y = c·t 对数据 (1, 2)、(2, 3)、(3, 3) 的最小二乘拟合，并验证残差与 A 的列正交。
提示

此时参数只有 c 一个，A 是一列 (1,2,3)ᵀ。正规方程退化为一个一元方程：c = ∑tᵢyᵢ / ∑tᵢ²。

完整解答
① A = (1,2,3)ᵀ，b = (2,3,3)ᵀ。② AᵀA = 1+4+9 = 14；Aᵀb = 2+6+9 = 17。③ c = 17/14 ≈ 1.214。④ 残差 r = cA − b = (17/14−2, 34/14−3, 51/14−3) = (−11/14, −8/14, 9/14)。⑤ 正交验证：Aᵀr = 1·(−11/14) + 2·(−8/14) + 3·(9/14) = (−11−16+27)/14 = 0 ✓。平方误差 = (121+64+81)/196 = 266/196 ≈ 1.36。
L2 手算推导手算 min ½(x+3)² + 2|x| 的最优解，要求分 x>0、x<0、x=0 三段讨论（不许直接套软阈值公式）。
提示

x>0 和 x<0 时函数光滑可直接求导；x=0 处用次梯度：∂|x| = [−1, 1]，最优性条件是 0 ∈ 次梯度集。

完整解答
① x>0：f' = (x+3)+2 = x+5 > 0，函数递增，无极小点。② x<0：f' = (x+3)−2 = x+1 = 0 → x = −1，合法（在 x<0 区域内），f(−1) = ½·4 + 2 = 4。③ x=0：次梯度 (0+3) + 2·[−1,1] = [1, 5]，不含 0，故 0 不是最优点。④ 比较：唯一候选 x̂ = −1。验证软阈值公式：v=−3, λ=2 → sign(−3)·max(3−2,0) = −1 ✓。
L3 建模应用某工厂用 50 个标定数据点拟合温度传感器的响应曲线（参数 20 个）。已知其中约 3 个点因记录事故严重失真；同时工程师相信 20 个参数里真正起作用的只有少数几个。请写出完整的优化模型（变量、目标、每一项的理由），并说明为什么不能只用纯最小二乘。
提示

两种「不干净」分别对应本章哪两件工具？残差里混离群点 → 哪种罚？参数要稀疏 → 哪种正则？两者能不能同时出现在一个凸目标里？

完整解答
模型：minimize ∑ᵢ φ_Huber(aᵢᵀx − bᵢ) + λ‖x‖₁。① 拟合项用 Huber 罚：3 个失真点是大残差，ℓ2 会把它们平方放大、绑架整条曲线，Huber 对大残差只线性惩罚，压得住野值。② 正则项用 ℓ1：要「少数参数起作用」即要稀疏解，ℓ1 的棱角把无关参数钉在精确的 0（ℓ2 只能缩小不能清零）。③ 两项都是凸的，和仍凸，问题可解。④ 纯最小二乘两个毛病都犯：被 3 个野值拖偏，且 20 个参数全非零无法做特征筛选。M 与 λ 用交叉验证在权衡曲线上选。

✍️本章自测

点击选项判分，答错会给出原因。

自测 1
正规方程 AᵀAx̂ = Aᵀb 的几何含义是：
  • A. 最优解处残差为零
  • B. 最优残差与 A 的列空间正交
  • C. A 必须是方阵且可逆
  • D. 残差与观测向量 b 正交
解析：B 对——Aᵀr=0 逐字读就是「r 与 A 的每一列垂直」，即 Ax̂ 是 b 在列空间上的正交投影。A 错：只有 b 恰好落在列空间里（可插值）时残差才为零，一般数据做不到。C 错：只需 A 列满秩使 AᵀA 可逆，A 自身是 m×n 长矩阵，根本谈不上可逆。D 错：残差垂直于列空间，不垂直于 b；若 r⊥b 则投影长度为零，几乎不可能。
自测 2
Tikhonov 正则化中，AᵀA + λI（λ>0）为什么一定可逆？
  • A. 因为 λI 自身可逆，两个矩阵之和跟着可逆
  • B. 因为 A 列满秩
  • C. 因为 AᵀA 半正定，加 λI 后特征值全部 ≥ λ > 0
  • D. 因为 λ 可以任意大
解析：C 对——半正定矩阵的特征值 ≥0，同时加 λI 把谱整体平移 λ，全部特征值 ≥λ>0，对称正定必可逆。A 错：可逆矩阵加奇异矩阵不一定可逆（如 I + (−I) = 0），关键是「半正定 + 正倍单位阵」这个结构。B 错：列满秩是充分非必要，本题恰恰要在列相关时也成立。D 错：λ 的大小不影响可逆性的成立，只影响解的收缩程度。
自测 3
LASSO（ℓ1 正则）能产生精确为零的解分量，根本原因是：
  • A. |x| 在 0 处不可微，次梯度是一个区间，数据拉力落进区间时解被钉在 0
  • B. ℓ1 范数与 ℓ0「非零个数」精确等价
  • C. 只要 λ 取得足够大，任何正则化都能给出精确的零
  • D. ℓ1 目标有闭式解，恰好常取到零
解析：A 对——软阈值推导显示 λ 超过 |v| 时最优解恰好为 0，本质是 0 处次梯度区间 [−λ,λ] 提供了「容差带」。B 错：ℓ1 只是 ℓ0 的凸放松，在 RIP 等条件下才恰好恢复，不是恒等。C 错：岭回归 λ→∞ 时 x̂=2/(1+λ)→0 但永不为 0——「趋向零」与「精确为零」是 ℓ2 与 ℓ1 的本质区别。D 错：LASSO 一般没有闭式解（一维才有软阈值公式），要靠迭代算法。
自测 4
Huber 罚 φ(u) 在大残差区域（|u|>M）的增长方式是：
  • A. 平方增长，比 ℓ2 惩罚更重
  • B. 保持不变，大误差不再受罚
  • C. 指数增长，彻底排除大误差
  • D. 线性增长，导数被钳在 ±2M
解析：D 对——|u|>M 时 φ=2M|u|−M²，斜率恒为 ±2M，离群点的拉力有上限，所以稳健。A 错：平方增长正是 ℓ2 怕离群点的原因，Huber 的设计目的恰是摆脱它。B 错：罚函数取常数则不凸（且不惩罚大误差），Huber 只是「限量」不是「免责」。C 错：指数增长比平方更激进，与稳健目标南辕北辙；那更接近 log-barrier 的「禁止」逻辑（第11章）。
自测 5
min ‖Ax−b‖∞ 化为 LP 的标准手法是：
  • A. 对目标开平方，转化为 QP
  • B. 引入标量 t，约束 −t ≤ aᵢᵀx−bᵢ ≤ t，最小化 t
  • C. 枚举残差绝对值取到最大的那个数据点
  • D. 对 ‖·‖∞ 取对数后用梯度法
解析：B 对——这是 epigraph 变换：t 是 max|rᵢ| 的上界，2m 条线性约束把「所有 |rᵢ|≤t」写全，目标 min t，标准 LP。A 错：ℓ∞ 与平方无关，开平方不改变 max 结构也化不成 QP。C 错：最优点由谁取到 max 事先未知，枚举是组合爆炸；LP 一步搞定正是凸优化的威力。D 错：取对数既无必要（已能精确化 LP）也破坏结构。
