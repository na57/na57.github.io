8.1投影与距离：最近点为什么是唯一的

给一个闭凸集 C 和一点 x₀，投影（Projection）是 C 中离 x₀ 最近的点：

PC(x₀) = argmin ‖x − x₀‖₂   s.t. x ∈ C

目标严格凸、可行域凸——解存在且唯一。这个唯一性是几何优化的基石：距离 dist(x₀, C) = ‖P_C(x₀) − x₀‖ 也因此是良定义的凸函数。

完整手算例：点到超平面的投影

超平面 H = {x | aᵀx = b}，a = (1,1)ᵀ，b = 2，x₀ = (3,0)ᵀ。投影公式：

x̂ = x₀ + b − aᵀx₀‖a‖₂² · a
步骤计算结果
① 算 aᵀx₀1·3 + 1·03
② 算 ‖a‖²1² + 1²2
③ 算偏移系数(2 − 3)/2−1/2
④ 得投影点(3,0) + (−1/2)(1,1)x̂ = (2.5, −0.5)
⑤ 验证在 H 上2.5 + (−0.5)= 2 ✓
⑥ 算距离|aᵀx₀−b| / ‖a‖ = 1/√2≈ 0.707

公式的读法：x₀ 不在平面上，就沿法方向 a 走回去，走的距离恰好是「超欠的量 ÷ 法向量长度」。KKT 条件（第5章）给出同样的式子：最优处残差 x̂−x₀ 必与 a 平行——垂直是最近的唯一方式。

同类问题一并成立：点到半空间的距离（越界才投影）、两凸集间距离 min‖x−y‖（变量 (x,y)，联合凸）、点在集上的ℓ₁/ℓ∞ 投影（改范数仍凸）。

💡 关键一跃

投影 = 凸优化的「几何原子操作」。第9章的投影梯度法、机器学习里的约束更新，本质都是「走一步、投回来」。把投影算熟，等于拿到了所有约束优化的入场券。

⚠️ 常见误区

「最近点就是垂直投影」只在集合光滑（如超平面、球）时成立。集合有棱角（如多面体的顶点）时，最近点可能就在顶点上，此时残差方向落在该点的法锥里而不唯一——KKT 的乘子不唯一，但投影点仍然唯一。别把「投影唯一」误读成「法方向唯一」。

8.2中心问题：一个集合的「中心」到底在哪

「中心」不是一个概念，是一族定义，各自对应一个凸问题。先看最直观的：Chebyshev 中心（Chebyshev Center）——集合内能放下的最大球的球心。对多面体 {x | aᵢᵀx ≤ bᵢ}，半径 R 的球（心 x）含于第 i 个半空间的条件是 aᵢᵀx + R‖aᵢ‖ ≤ bᵢ，于是：

maximize R   s.t. aᵢᵀx + R‖aᵢ‖₂ ≤ bᵢ，i=1,…,m —— 这是 LP

完整手算例：三角形的最大内切圆

三角形 x≥0、y≥0、x+y≤4。三条边的法向量模长：‖(−1,0)‖=1，‖(0,−1)‖=1，‖(1,1)‖=√2。约束化为：

x ≥ R，  y ≥ R，  x + y + R√2 ≤ 4
步骤推导结果
① 用对称性区域关于 y=x 对称，最优心必在其上x = y
② 顶紧三约束最大 R 时三边同时相切：x = y = R
③ 代入第三式2R + R√2 = 4R(2+√2) = 4
④ 解出R = 4/(2+√2) = 4(2−√2)/2R = 2(2−√2) ≈ 1.172
⑤ 中心x = y = R(1.172, 1.172)

第二个定义：解析中心（Analytic Center）——maximize ∑ᵢ log(bᵢ − aᵢᵀx)。对数把每个约束的「剩余量」拉平：离任何一面墙太近都会被 −∞ 惩罚。手算例：区间 0≤x≤4，max log x + log(4−x)，导数 1/x − 1/(4−x) = 0 → x = 2。注意它与 Chebyshev 中心在这里重合，但一般不同：解析中心对「墙的排列」更敏感。

💡 关键一跃

解析中心就是第11章的伏笔：∑log(bᵢ−aᵢᵀx) 正是对数障碍函数（差一个负号）。内点法的全部迭代，可以理解为「在不断变化的目标力场下反复求解析中心的推广」。本章先认识这个函数的长相。

⚠️ 常见误区

「中心只有一个，算哪个都一样」——错。Chebyshev 中心（最深）、解析中心（对数最平）、重心（体积均分）一般互不相同，且只有前两个是凸问题。重心虽好（仿射不变）却 #P-难算——几何直觉与可计算性经常打架，凸优化站在可计算这一边。

8.3极值体积椭球：用 log det 量「大小」

椭球 ℰ = {Bu + d | ‖u‖₂ ≤ 1}（B 对称正定）。它的体积正比于 det B——要优化体积，就优化 log det B，而 log det 在正定锥上是凹函数（第3章保凸运算的存货），于是两个经典问题都凸：

  • 最大内切椭球（含于多面体 aᵢᵀx≤bᵢ）：maximize log det B，s.t. ‖Baᵢ‖ + aᵢᵀd ≤ bᵢ。
  • 最小外接椭球（Löwner–John 椭球，覆盖点集 v₁,…,vₖ）：minimize log det B⁻¹，s.t. ‖Bvᵢ + d‖ ≤ 1。

小例验证：覆盖 (±1, 0)、(0, ±1) 四点的最小外接椭球就是单位圆盘 B=I、d=0——四点都满足 ‖vᵢ‖=1 贴边，且任何方向的压缩（det B⁻¹ 想变大）都会把该方向的点甩出去。 log det 目标精确地编码了「各方向体积的乘积」这一权衡。

💡 关键一跃

det 度量体积（行列式 = 线性变换的体积缩放率），log 把它变成凹函数可乘可拆。第7章 D-最优设计用的是同一个 log det——那不是巧合：实验设计就是在选「信息椭球」的形状。

⚠️ 常见误区

「最大内切椭球和 Chebyshev 中心是一回事」——不是。Chebyshev 中心只许用球（B = rI，各向同性）；内切椭球允许各方向不同半径（B 任意正定），体积可以大得多。球是椭球的特例，LP 是 SDP 的特例——模型每放宽一层，问题类型就升一档。

8.4分类与间隔：最好的分界面是「最宽的缝」

两类点 {xᵢ} 带标签 yᵢ ∈ {+1, −1}。线性可分 ⟺ 存在 (w, b) 使 yᵢ(wᵀxᵢ + b) ≥ 1（把 w 归一化后的写法，「1」是 wlog 的间隔基准）。最大间隔分类器（Max-Margin Classifier，SVM 的核心）：

minimize ½‖w‖₂²   s.t. yᵢ(wᵀxᵢ + b) ≥ 1，i=1,…,m —— QP，间隔 = 2/‖w‖

完整手算例：2+2 点的最大间隔线

正类 (0,0)、(0,2)；负类 (2,0)、(2,2)。

步骤推导结果
① 用对称性点集关于水平中线 y=1 对称 → w₂=0w = (w₁, 0)
② 写约束正类：b ≥ 1（x₁=0 处）；负类：−(2w₁+b) ≥ 1
③ 顶紧取等b = 1；2w₁ + 1 = −1w₁ = −1
④ 得解w = (−1, 0)，b = 1，分离面 −x₁+1=0x₁ = 1
⑤ 验证四点(0,0): +1·(0+1)=1 ✓；(0,2): 1 ✓；(2,0): −1·(−2+1)=1 ✓；(2,2): 1 ✓全部 ≥1
⑥ 间隔2/‖w‖ = 2/12（正类线 x₁=0 到负类线 x₁=2 的缝宽）

四点全部「顶」在间隔边界上——它们就是支持向量（Support Vector）：删掉任何一个，间隔都会变；删掉非边界点则无影响。QP 的 KKT 条件会自动把这件事说出来（乘子 λᵢ>0 恰好在边界点上）。

数据不可分时引入松弛 ξᵢ ≥ 0：min ½‖w‖² + C∑ξᵢ，s.t. yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ——软间隔，仍是 QP，C 又是那个熟悉的权衡旋钮（第6章的 λ 换了件衣服）。

💡 关键一跃

「分得开」是一族解（可行域），「分得最开」才是唯一解。把可行性问题升级成优化问题的那一步，就是选一个目标——这里选「间隔最大」，它直接控制泛化能力（VC 维论证的入口）。

⚠️ 常见误区

「间隔 = 分离面到最近点的距离」——差一倍：几何间隔是从分离面到任一类最近点的距离 1/‖w‖，而「间隔」通常指缝的总宽 2/‖w‖。手算时混用会让答案差一个因子 2，考试中最常见的失分点。

📝分层习题

L1 概念辨析判断对错：「点 x₀ 到凸集 C 的投影唯一，意味着投影点处的法方向也唯一。」
提示

想一个棱角分明的集合（如正方形）和投影恰好在顶点上的情形。

完整解答
错。投影点唯一由目标的严格凸性保证；但法方向（KKT 乘子对应的方向）在棱角处构成整个法锥，不唯一。例：x₀=(2,2) 投影到正方形 [0,1]²，投影点是顶点 (1,1)，任何 (u,v) 且 u,v>0 的方向都满足最优性条件。「点唯一」与「方向唯一」是两回事。
L1 概念辨析选择：Chebyshev 中心问题对多面体是 LP 的关键原因是：A. 目标是线性的；B. 约束 aᵢᵀx+R‖aᵢ‖≤bᵢ 关于 (x,R) 是线性的；C. 多面体是凸的；D. A 和 B 共同。
提示

注意 ‖aᵢ‖ 是已知常数，不是变量。LP 需要目标与约束都关于变量线性。

完整解答
D。变量是 (x, R)；aᵢ、‖aᵢ‖、bᵢ 都是常数，所以约束关于 (x,R) 线性，目标 R 线性——合起来是 LP。A 或 B 单独都不充分（线性目标加非线性约束不是 LP）。C 错：可行域凸只保证「凸问题」，不保证「LP」这一更强分类——Chebyshev 中心对一般凸集（如椭球）就不是 LP 而是 SOCP。
L2 手算推导手算点 x₀=(0,3) 到直线 x₁+x₂=0 的投影与距离。
提示

a=(1,1)ᵀ，b=0。套投影公式，注意符号。

完整解答
① aᵀx₀ = 0+3 = 3；‖a‖² = 2。② 偏移系数 (b−aᵀx₀)/‖a‖² = (0−3)/2 = −3/2。③ x̂ = (0,3) + (−3/2)(1,1) = (−1.5, 1.5)。④ 验证：−1.5+1.5 = 0 ✓ 在平面上。⑤ 距离 = |3−0|/√2 = 3/√2 ≈ 2.121。⑥ 复核：‖x̂−x₀‖ = ‖(−1.5,−1.5)‖ = 1.5√2 = 3/√2 ✓ 两法一致。
L2 手算推导对正类 (0,0)、负类 (3,0) 两点，手算最大间隔分类器的 w、b 与间隔。
提示

对称性给分离面在 x₁=1.5；把约束顶紧取等号解 w、b。

完整解答
① 一维问题，设 w=(w₁,0)。② 约束：正类 b≥1；负类 −(3w₁+b)≥1。③ 顶紧：b=1，3w₁=−2，w₁=−2/3。④ w=(−2/3,0)，b=1，分离面 −(2/3)x₁+1=0 即 x₁=1.5 ✓ 正在中点。⑤ 验证：正类 y(wᵀx+b)=+1·(0+1)=1 ✓；负类 −1·(−2+1)=1 ✓。⑥ 间隔 = 2/‖w‖ = 2/(2/3) = 3，恰为两点间距 ✓（两点情形缝宽=点距，合理）。
L3 建模应用某仓库要在不规则多边形库区（已知半空间描述 aᵢᵀx≤bᵢ，i=1..8）里设一个消防栓，要求「离库区内任何可能着火点的最坏供水距离最小」。又：库区中心还要放一个控制柜，要求「离所有围墙尽量远」。分别写出两个优化模型、给出问题类型，并说明两者答案一般不同的原因。
提示

「最坏供水距离」是对库区内所有点取 max 再对栓位取 min——这是什么结构？「离墙尽量远」对应本章哪个中心？

完整解答
① 消防栓：minimize max_{y∈库区} ‖x−y‖，即 1-中心问题（最小外接球心）：min R s.t. ‖y−x‖≤R 对所有 y∈库区。对多面体只需包住顶点：min R s.t. ‖vⱼ−x‖≤R，j=1..k（顶点），是 SOCP（二阶锥约束），可用内点法解。② 控制柜：Chebyshev 中心 max R′ s.t. aᵢᵀx+R′‖aᵢ‖≤bᵢ，是 LP。③ 两者一般不同：消防栓盯的是「最远着火点」（外向，顶点决定），控制柜盯的是「最近围墙」（内向，边界决定）；一个外接、一个内切，目标与约束结构都不同，除非库区高度对称否则不会重合。这正是本章「中心不是唯一概念」的实战版。

自测 1
点到闭凸集的投影唯一，根本原因是：
  • A. 凸集是连通的
  • B. 距离函数是凸的
  • C. 平方距离目标严格凸 + 可行域凸
  • D. 投影点处法方向唯一
解析：C 对——严格凸函数在凸集上至多一个极小点，闭性保证存在。A 错：连通性与唯一性无关（圆环连通但非凸，投影可不唯一）。B 错：凸函数可以有整片极小点（如常数）；要「严格凸」才唯一，所以用平方距离叙述最干净。D 错：因果倒置且命题为假——棱角处法方向（法锥）不唯一，但投影点仍唯一。
自测 2
Chebyshev 中心约束 aᵢᵀx + R‖aᵢ‖₂ ≤ bᵢ 中 R‖aᵢ‖ 的含义是：
  • A. 球心到原点的距离上限
  • B. 半径为 R 的球含于半空间 aᵢᵀx≤bᵢ 所需的额外裕量
  • C. 法向量的正则化项
  • D. 数值稳定性的松弛量
解析：B 对——球内点沿法向 aᵢ/‖aᵢ‖ 最多比球心多走 R，对应约束值被推高 R‖aᵢ‖，这就是「整个球都在半空间里」的充要条件。A 错：与原点无关，是到各面墙的关系。C 错：‖aᵢ‖ 是已知常数不是罚项；忘了乘它才是常见错误。D 错：它是精确的几何条件，不是数值技巧。
自测 3
解析中心与第11章内点法的关系是：
  • A. 解析中心就是 log-barrier 子问题在目标权重 t→0 时的解（中心路径起点）
  • B. 两者毫无关系，只是共用 log 函数
  • C. 解析中心是内点法的终点（最优解）
  • D. 解析中心只能用 LP 求解器计算
解析：A 对——内点法最小化 t·f₀(x)+φ(x)，φ=−∑log(bᵢ−aᵢᵀx)；t→0 时目标只剩 −φ，即解析中心；t→∞ 时走向最优解，整条轨迹叫中心路径。B 错：是同一函数族的结构关系，不是巧合。C 错：终点是最优解（贴边界），解析中心在深内部，正好相反。D 错：log 目标非线性，用 Newton 解（Ch9–10 工具），不是 LP。
自测 4
最大间隔分类器 min ½‖w‖² s.t. yᵢ(wᵀxᵢ+b)≥1 中，「1」的作用是：
  • A. 随便定的常数，换成 2 会改变解的方向
  • B. 防止 w=0 的平凡解
  • C. 样本点的数量
  • D. 固定 (w,b) 的缩放自由度，使间隔 = 2/‖w‖ 成为确定量
解析：D 对——(w,b) 可以任意正倍缩放而不改分离面；约束右边的「1」把这个自由度钉死（函数间隔=1），于是最大化几何间隔 ⟺ 最小化 ‖w‖。A 错：换成任何正常数 c，解只差缩放 w′=w/c，分离面与几何间隔不变——正因为它「随便」，才必须钉住。B 错：w=0 本就被 yᵢ·b≥1 的正负类共存排除，不是「1」的职责。C 错：与样本数无关。
自测 5
极值体积椭球问题之所以是凸问题，关键在：
  • A. det B 是 B 的凸函数
  • B. log det 在正定锥上凹，log 单调不改变极值点位置
  • C. 椭球是对称的
  • D. 约束 ‖Bvᵢ+d‖≤1 是线性的
解析：B 对——体积 ∝ det B，det 本身非凹非凸不能直接优化；log det 在 PD 锥上凹，log 单调保 argmax，于是「最大内切」是凹最大化、「最小外接」用 log det B⁻¹ 同样处理。A 错：det 非凸。C 错：对称性只简化描述，不产生凸性。D 错：该约束关于 (B,d) 是范数复合线性映射——是凸约束（SOCP），但「线性」说法错误，且光有约束凸不够，目标凹性才是关键。
