10.1消元法：把约束问题变回无约束

第9章我们有了可靠的 Newton 法，但它不认识约束。面对 min f(x) s.t. Ax=b，最古老的想法是：既然 Ax=b 把 x 钉在一个仿射集上，那就先把这个仿射集参数化，代回目标，变回无约束问题。

设 A ∈ Rp×n，rank A = p。分三步：

  1. 找一个特解 x̂：Ax̂ = b；
  2. 找 A 的零空间基矩阵 F ∈ Rn×(n−p)：AF = 0；
  3. 写 x = Fz + x̂，z ∈ Rn−p，问题变成无约束的 min f(Fz + x̂)。

完整手算例。解 min f(x,y) = ½(x² + 2y²)，约束 x + y = 1。

代入 y = 1 − x：

f̃(x) = ½[x² + 2(1−x)²] = ½(3x² − 4x + 2)

求导置零：

f̃′(x) = 3x − 4 + 2 · 0 ⇒ 3x − 2 = 0 ⇒ x* = 23， y* = 13
p* = ½( 49 + 2·19 ) = 13

消元把变量从 2 个减到 1 个，一维求导直接出答案。但注意：消元不是免费的——求零空间基 F 本身要一次分解，而且当 A 稀疏时 F 往往是稠密的，会把结构毁掉。这是 10.4 代价账的伏笔。

💡 关键一跃

等式约束 Ax=b 不是「限制」，而是「降维」：可行集是一个 n−p 维的仿射子空间。消元法就是换个坐标系，在这个子空间里做无约束优化。

⚠️ 常见误区

误区：「消元总是更简单」。错。当 p 很小（比如只有 10 个约束钉住 1000 个变量）时，消元后还有 990 维，且 F 是 1000×990 的稠密阵——还不如直接解原来的 KKT 系统。消元适合 p 接近 n 或 A 结构特殊的情形。

10.2KKT 条件与可行起点 Newton

不消元也能刻画最优性。Lagrange 函数 L(x,ν) = f(x) + νᵀ(Ax−b)，最优性条件（KKT 条件，Karush–Kuhn–Tucker conditions）是：

∇f(x*) + Aᵀν* = 0   （对偶可行），    Ax* = b   （原始可行）

验算 10.1 的例。∇f = (x, 2y)，在 x*=(2/3, 1/3) 处 ∇f=(2/3, 2/3)。取 ν*=−2/3，则 ∇f + ν*·(1,1) = (0, 0) ✓，且 x*+y*=1 ✓。最优性得证。

现在把 Newton 法搬过来。若当前点 x 已经可行（Ax=b），我们要求下一步 仍在可行集上，即 A(x+Δx)=b，也就是 AΔx=0。对 f 做二阶展开并在约束下极小化，得到的增量方程是（KKT 系统，KKT system）：

[ ∇²f(x)A  Aᵀ0 ] · (Δx; ν⁺) = ( −∇f(x); 0 )

这是一个 (n+p)×(n+p) 的线性方程组：左上角是 Hessian，右下角是零块。解出 Δx 后，用回溯线搜索（保证 A(x+tΔx)=b 自动成立）定步长，迭代到 Newton 减量 λ²/2 ≤ ε 为止。

完整手算例。同题 min ½(x²+2y²) s.t. x+y=1，从可行点 x⁰=(1, 0) 出发。

∇f(x⁰) = (1, 0)，∇²f = [[1,0],[0,2]]。KKT 增量方程：

Δx + ν⁺ = −1，   2Δy + ν⁺ = 0，   Δx + Δy = 0

第三式给 Δy=−Δx，代入前两式相减：3Δx = −1，得

Δx = −13，  Δy = 13，  ν⁺ = −23

取 t=1：x⁰+Δx = (2/3, 1/3) = x*。一步收敛——f 是二次函数，Newton 对二次问题本来就应该一步到位，这正是收敛性验证。

💡 关键一跃

可行起点 Newton = 在切空间 {d : Ad=0} 里做无约束 Newton。KKT 系统的下半块 AΔx=0 就是「不许离开可行集」的代数表达。

⚠️ 常见误区

误区：「KKT 矩阵右下角是 0、不定，所以数值上不可靠」。错。虽然 KKT 矩阵不定（有正有负特征值），但只要 ∇²f 在 A 的零空间上正定（f 沿可行方向凸），它就一定非奇异，解唯一。不定 ≠ 奇异。

10.3不可行起点 Newton：找不到可行点怎么办

可行起点 Newton 有个前提：你得先有一个可行点。对一般 Ax=b，找一个可行点本身就要解线性方程。更优雅的做法是干脆从任意点出发，让 Newton 同时消灭两种残差：

rdual(x,ν) = ∇f(x) + Aᵀν，    rpri(x,ν) = Ax − b

最优点就是 r=(rdual, rpri)=0 的根。对 r 做一阶 Taylor 展开，得到（不可行起点 Newton 步，infeasible-start Newton step）：

[ ∇²f(x)   Aᵀ ; A   0 ] · (Δx; Δν) = −( rdual; rpri )

和可行版唯一的区别：右端下半不再是 0，而是 −(Ax−b)。步长用回溯线搜索压残差范数 ‖r‖，直到同时原始可行、对偶可行。

完整手算例。还是 min ½(x²+2y²) s.t. x+y=1，这次从 不可行点 x⁰=(0,0)、ν⁰=0 出发。

残差：rdual = ∇f(x⁰)+Aᵀν⁰ = (0,0)，rpri = x⁰+y⁰−1 = −1。增量方程：

Δx + Δν = 0，   2Δy + Δν = 0，   Δx + Δy = 1

前两式得 Δν=−Δx=−2Δy，即 Δx=2Δy；代入第三式：3Δy=1，得

Δx = 23，  Δy = 13

t=1 一步：x = (2/3, 1/3)，直接落在最优点上——二次问题 + 线性约束，残差是仿射的，Newton 依然一步到位。这次我们没有事先求任何可行点。

💡 关键一跃

不可行起点 Newton 把「求解优化问题」变成「求非线性方程组 r(x,ν)=0 的根」。可行性不再是一步一步保持的不变量，而是和最优性一起被逼近的终点。

⚠️ 常见误区

误区：「不可行起点法既然更方便，收敛性质应该一样好」。要小心：它的线搜索压的是残差范数而非目标值，分析上更微妙；且对强非凸问题，残差下降不代表接近最优。对凸问题两者都多项式时间可证，这就是我们只讨论凸情形的红利。

10.4代价账：消元 vs 直接解 KKT，结构就是钱

每个 Newton 步的代价 = 组装并求解 KKT 系统。账面算法有三档：

方法每步主项代价适用情形
消元后解 (n−p) 维 Newton 系统O((n−p)³)p 接近 n，消元后维数小
直接解 (n+p) 维 KKT 系统（稠密）O((n+p)³)无结构可借时的保底
KKT + Schur 补（H 易求逆）O(n·p²) 或更低H 对角/分块对角，A 稀疏

具体数字账。设 n=1000，p=10（10 个等式约束，如资源/守恒约束），Hessian 为对角阵（可分离目标，非常常见）：

  • 消元：需要解 990×990 稠密系统，约 (990)³ ≈ 9.7×10⁸ flops，且 F 是 1000×990 稠密阵，组装就贵；
  • 直接解 KKT：1010×1010 不定系统，约 (1010)³ ≈ 1.0×10⁹ flops；
  • Schur 补：先算 S = A H⁻¹ Aᵀ（H 对角 ⇒ H⁻¹ 免费，S 是 10×10，组装 O(n·p²)=10⁵），再解 S·w = rhs 只要 O(p³)=10³，回代 O(n)。每步约 10⁵ flops，比稠密路线便宜四个数量级。

再和第9章的迭代次数相乘，就是等式约束问题的总账：总代价 ≈ Newton 步数（对凸问题通常 15–30 步，与规模几乎无关）× 每步代价（由结构决定）。步数这项是凸性的礼物，每步代价这项是线性代数的战场。

💡 关键一跃

Schur 补的本质：先解乘子 ν（p 维小系统），再回代 x。约束少（p≪n）时，「先在乘子空间里算清楚」永远比「在原始空间里硬解」便宜。

⚠️ 常见误区

误区：「约束越多问题越难算」。不一定。p 大时 Schur 补的 p×p 系统变贵，但消元后的 n−p 维系统变小——p 大反而该走消元路线。选算法的依据是 p 与 n 的相对大小和稀疏结构，不是约束的绝对数量。

📝分层习题

L1 概念辨析判断：「KKT 矩阵因为右下角是零块、特征值有正有负，所以它是奇异的，Newton 步不唯一。」这句话对不对？
提示

不定（indefinite）和奇异（singular）是两回事。想想保证非奇异需要什么条件。

完整解答
不对。KKT 矩阵不定但非奇异，只要：① A 行满秩；② ∇²f 在 A 的零空间上正定（即 d≠0、Ad=0 ⇒ dᵀ∇²f d > 0）。凸问题自动满足②。此时方程组解 (Δx, ν⁺) 唯一。把「不定」与「奇异」混淆是本节最常见的错误。
L1 概念辨析消元法在什么参数情形下比直接解 KKT 系统更划算？
提示

比较 (n−p)³ 与 (n+p)³，再想想 F 矩阵的稀疏性。

完整解答
当 p 接近 n（消元后维数 n−p 很小）时消元划算；当 p≪n 时消元后仍是 ≈n 维问题，且零空间基 F 通常稠密，反而不如直接解带结构的 KKT 系统（尤其 Schur 补路线，代价 O(n·p²)）。
L2 手算推导用消元法解 min ½(x₁² + x₂² + x₃²) s.t. x₁+x₂+x₃=3，并用 KKT 条件验证。
提示

代入 x₃=3−x₁−x₂，对 x₁、x₂ 各求偏导；乘子 ν 由 ∇f+ν·(1,1,1)=0 读出。

完整解答
f̃=½[x₁²+x₂²+(3−x₁−x₂)²]。∂f̃/∂x₁ = x₁−(3−x₁−x₂)=0，∂f̃/∂x₂ = x₂−(3−x₁−x₂)=0。两式相减得 x₁=x₂，代回得 3x₁=3，x₁=x₂=1，x₃=1。最优值 p*=3/2。验证：∇f=(1,1,1)，ν=−1 使 ∇f+ν·(1,1,1)=0 ✓，且 x₁+x₂+x₃=3 ✓。几何意义：原点到平面 x₁+x₂+x₃=3 的最近点是 (1,1,1)，距离 √3。
L2 手算推导对 min ½(x²+y²) s.t. x−y=2，从不可行点 x⁰=(0,0)、ν⁰=0 出发，手算一步不可行起点 Newton。
提示

残差 r_dual=(0,0)，r_pri=−2；增量方程 HΔx+AᵀΔν=0、AΔx=2，A=(1,−1)。

完整解答
∇²f=I。方程：Δx+Δν=0，Δy−Δν=0，Δx−Δy=2。前两式 Δx=−Δν、Δy=Δν，代入第三式 −2Δν=2 ⇒ Δν=−1，Δx=1，Δy=−1。t=1 得 x=(1,−1)，满足约束且 ∇f=(1,−1)=−ν·(1,−1)（ν=−1），一步到达最优。最优值 p*=1。
L3 建模应用电网潮流：n=500 个节点的注入功率 x 满足平衡方程 Ax=b（p=5 个区域守恒约束），目标是最小化发电成本 ½∑cᵢxᵢ²（cᵢ>0）。选什么算法框架？每步代价多少？
提示

Hessian 是什么结构？p 与 n 的比例支持哪条路线？

完整解答
Hessian = diag(c₁..c₅₀₀) 对角正定，A 是稀疏的节点-区域关联阵。目标凸 + 线性约束 ⇒ 等式约束凸问题。选可行起点（或不可行起点）Newton + Schur 补：S=A H⁻¹ Aᵀ 只有 5×5，H⁻¹=diag(1/cᵢ) 免费。每步代价 O(n·p²)≈500×25=1.25×10⁴，Newton 步数约 15–25 步，总代价约 10⁵–10⁶ flops，毫秒级。若误用稠密路线，(505)³≈1.3×10⁸/步，慢四个数量级。

自测 1
min ½(x²+2y²) s.t. x+y=1 的 KKT 乘子 ν* 等于？
  • A. 2/3
  • B. −2/3
  • C. 0
  • D. 1/3
解析：∇f(x*)=(2/3, 2/3)，约束梯度是 (1,1)，要 ∇f+ν·(1,1)=0 必须 ν*=−2/3，B 对。A 符号错——忘记 KKT 条件是 ∇f+Aᵀν=0 而不是 ∇f=Aᵀν；C 错，ν=0 意味着约束不起作用，但无约束最优 (0,0) 不可行；D 是 y* 的值，张冠李戴。
自测 2
可行起点 Newton 中，为什么回溯线搜索不需要检查可行性？
  • A. 因为步长 t≤1 时约束自动满足
  • B. 因为 f 是凸的
  • C. 因为增量方程含 AΔx=0，沿 Δx 走任何步长都留在可行集上
  • D. 因为乘子 ν⁺ 会校正约束违反
解析：C 对。A(x+tΔx)=Ax+tAΔx=b+0=b，线性约束 + 切向步 ⇒ 任意 t 均可行，线搜索只需管目标下降。A 错，「t≤1」不是原因，t>1 也照样可行；B 错，凸性保证的是收敛性而非每步可行性；D 错，ν 不进入 x 的更新，谈不上「校正」。
自测 3
不可行起点 Newton 与可行起点 Newton 的增量方程，形式上的区别是？
  • A. 右端下半块从 0 换成 −(Ax−b)
  • B. 系数矩阵右下角从 0 换成 I
  • C. 左上的 Hessian 换成梯度
  • D. 乘子不再出现在方程中
解析：A 对。系数矩阵完全一样（都是 [H Aᵀ; A 0]），唯一区别是右端：可行起点已在可行集上，原始残差为 0；不可行起点要同时压原始残差 −(Ax−b)。B 错，系数矩阵不动；C 错，Hessian 不能换；D 错，Δν 仍是未知量之一。
自测 4
n=1000、p=10、Hessian 对角时，Schur 补路线每个 Newton 步的代价量级是？
  • A. O(10⁹)
  • B. O(10⁷)
  • C. O(10³)
  • D. O(10⁵)
解析：D 对。组装 S=A H⁻¹ Aᵀ 要 O(n·p²)=1000×100=10⁵，解 10×10 系统只要 O(10³)，主项是组装，合计约 10⁵。A 是直接解稠密 KKT（或消元）的账；B 是中间档，不符合此处结构；C 只算了解 p 维小系统，漏掉了组装 S 的 O(n·p²) 主项——这是最常见的漏项。
自测 5
「约束越多，等式约束问题一定越难算」——这个论断的问题在哪？
  • A. 没有问题，约束当然越多越难
  • B. p 大时消元后维数 n−p 反而变小，走消元路线可能更便宜；难度取决于 p 与 n 的相对大小和结构
  • C. 约束多会让问题变非凸
  • D. 约束多时 Newton 法不再收敛
解析：B 对。p 大 ⇒ Schur 补的 p×p 系统变贵，但消元后的 (n−p) 维系统变小——p 接近 n 时消元几乎免费。A 错在把直觉当结论；C 错，线性等式约束不改变凸性；D 错，只要 A 行满秩且 f 凸，Newton 收敛性与 p 无直接关系。

句1：这章解决什么问题？——

句3：它和前后章怎么分工？——
第9章给了无约束的下降框架，本章把等式约束折进每一步的线性代数里；第11章再用对数障碍把不等式约束也折进目标函数，最终每步仍归结为解本章这种 KKT 系统。
