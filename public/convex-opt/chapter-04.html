4.1标准形式：凸优化问题的"身份证"

Ch2 给了我们凸集，Ch3 给了我们凸函数，但它们只是词汇。本章要回答的第一个问题是：怎样用这些词汇"造句"——把现实里的最小化任务写成一张能被理论识别的身份证？这张身份证就是标准形式（Standard Form）。

定义。一个优化问题的标准形式是：

minimize  f₀(x)
subject to  fi(x) ≤ 0,  i = 1,…,m
              aiᵀx = bi,  i = 1,…,p

其中 x ∈ ℝⁿ 是优化变量（Optimization Variable），f₀ 是目标函数（Objective Function），fi(x) ≤ 0 是不等式约束，aiᵀx = bi 是等式约束。若它还是凸优化问题（Convex Optimization Problem），还需满足：

  • 目标 f₀ 是凸函数；
  • 每个不等式约束函数 fi 是凸函数；
  • 每个等式约束是仿射的：hi(x) = aiᵀx − bi。

四个关键名词。问题的域（Domain）是所有函数定义域的交集 𝒟 = ⋂ dom fi；满足全部约束的点组成可行域（Feasible Set）；可行域上 f₀ 的下确界是最优值（Optimal Value）p*；达到最优值的可行点是最优解（Optimal Point）x*。约定：可行域为空时 p* = +∞；f₀ 在可行域上无下界时 p* = −∞。

小例（含全部四个名词）。考虑 min x² s.t. x ≥ 1。改写成标准形：min f₀(x) = x² s.t. f₁(x) = 1 − x ≤ 0。

名词本例取值验证
域 𝒟ℝf₀ = x² 与 f₁ = 1−x 处处有定义
可行域[1, +∞)1−x ≤ 0 ⟺ x ≥ 1
最优值 p*1x² 在 [1,+∞) 上的最小值
最优解 x*1f₀(1) = 1 = p*

凸性检查：f₀(x) = x² 二阶导为 2 > 0，凸 ✓；f₁(x) = 1 − x 是仿射（仿射函数既凸又凹）✓；无等式约束 ✓。所以这是一个凸优化问题。

⚠️ 常见误区

"等式约束为什么必须仿射？"因为等式 h(x) = 0 相当于同时要求 h(x) ≤ 0 与 h(x) ≥ 0，即 h 与 −h 都要凸——同时凸且凹的函数只有仿射函数。例如等式约束 x² = 1 把可行域变成两个孤立点 {−1, 1}，它不是凸集，问题也就不是凸优化问题。

💡 关键一跃

标准形式不是束缚，而是"接口约定"：一旦你的问题能塞进这个接口，后面整本书的定理、算法、软件就全部免费可用。建模的功夫，大半花在"改写"上。

4.2局部最优=全局最优：凸性的全部回报

上一节给出了凸问题的身份证，但它带出一个问题：办这张身份证值多少钱？本节兑现回报——它是整个凸优化理论最核心的一条定理。

定义。可行点 x 是局部最优（Local Optimum），如果存在 r > 0，使得对所有满足 ‖y − x‖ ≤ r 的可行点 y，都有 f₀(y) ≥ f₀(x)。也就是说：在 x 的某个小邻域里，没有可行点比它更好。

✅ 定理（局部 ⟹ 全局）

对凸优化问题，任何局部最优解都是全局最优解。

完整证明（反证法）。设 x 是局部最优（半径 r），但不是全局最优，即存在可行点 y 使 f₀(y) < f₀(x)。取线段上的点

z = θy + (1−θ)x，θ ∈ [0, 1]

分三步：

  • 第 1 步（z 可行）：可行域是凸集（凸不等式的下水平集 ∩ 仿射等式的解集，都是凸集，交集仍凸），x、y 可行 ⟹ 线段上任意 z 可行。
  • 第 2 步（f₀(z) < f₀(x)）：由 f₀ 的凸性，f₀(z) ≤ (1−θ)f₀(x) + θf₀(y) < (1−θ)f₀(x) + θf₀(x) = f₀(x)，对任意 θ ∈ (0, 1] 严格成立。
  • 第 3 步（z 落入邻域）：‖z − x‖ = θ‖y − x‖，取 θ 足够小（例如 θ = r/(2‖y−x‖)），则 ‖z − x‖ = r/2 ≤ r，即 z 落在 x 的局部最优邻域内。

第 2 步说 z 比 x 好，第 3 步说 z 在邻域里——这与"x 局部最优"矛盾。∎

数字例（凸，局部=全局兑现）。min (x−3)² s.t. 0 ≤ x ≤ 1。目标凸（二阶导 2>0），可行域 [0,1] 是区间（凸），故为凸问题。在 [0,1] 上函数单调递减（导数 2(x−3) < 0），唯一的"局部"最小点是 x* = 1，值 (1−3)² = 4。由定理，它就是全局最优——尽管无约束最小点 x = 3 远在可行域外。

对照（非凸，局部≠全局）。f(x) = x⁴ − 3x² + x。求导 f′(x) = 4x³ − 6x + 1，可验证 x = −1.5 与 x = 1 都是驻点且二阶导为正（f″(−1.5) = 21 > 0，f″(1) = 6 > 0），都是局部极小：

局部极小点函数值地位
x = −1.5f = 5.0625 − 6.75 − 1.5 = −3.1875全局最优 ✓
x = 1f = 1 − 3 + 1 = −1只是局部最优 ✗

站在 x = 1 往四周看，"局部最优"成立，但它离真最优 −3.1875 还差得远——这就是非凸问题的陷阱，也是凸性值钱的地方。

💡 关键一跃

证明的全部机关只有一步：可行域凸保证"线段在域内"，目标凸保证"线段上的函数值不超过端点连线"。两个"凸"各出一半力，把任何远处的更优点拉成邻域内的矛盾。这就是为什么 4.1 坚持把约束函数都定为凸——每一个条件都在这条定理里领工资。

⚠️ 常见误区

定理不保证最优解唯一。min 0·x（常数目标）的可行域里每个点都是全局最优。定理只说"局部最优的集合 ⊆ 全局最优的集合"，两者可以是一大片。

4.3最优性条件：可行点处梯度指向哪

上一节说"凸问题的局部最优就是全局最优"，但它带出一个操作性问题：给定一个可行点，我手算时怎么判断它是不是最优？当 f₀ 可微时，有一个干净的几何判据。

✅ 最优性条件（Optimality Condition）

设 f₀ 可微、问题为凸，则可行点 x* 最优，当且仅当对所有可行点 y：

∇f₀(x*)ᵀ(y − x*) ≥ 0

几何读法。y − x* 是从 x* 指向可行域内部的任意方向；∇f₀(x*) 是函数上升最快的方向。条件说：任何可行方向与梯度的夹角都不超过 90°——从 x* 出发，没有一个可行方向是"下坡"的。

为什么成立（直觉证明）。凸函数的一阶刻画：f₀(y) ≥ f₀(x*) + ∇f₀(x*)ᵀ(y−x*)。若梯度项 ≥ 0，则 f₀(y) ≥ f₀(x*)，对所有可行 y 成立——这正是最优的定义。反向（最优 ⟹ 条件成立）用反证：若存在可行 y 使梯度项 < 0，沿该方向走一小步函数值下降，矛盾。

手算例。min x₁² + x₂² s.t. x₁ + x₂ ≥ 2。这是"离原点最近的可行点"，几何上 x* = (1, 1)（直线 x₁+x₂=2 上离原点最近的是垂足）。验证最优性条件：

  • ∇f₀(x) = (2x₁, 2x₂)，故 ∇f₀(x*) = (2, 2)；
  • 对任意可行 y（即 y₁+y₂ ≥ 2）：
∇f₀(x*)ᵀ(y−x*) = 2(y₁−1) + 2(y₂−1) = 2(y₁ + y₂ − 2) ≥ 0 ✓

抽一个具体数字验证：y = (3, 0) 可行（3+0=3≥2），梯度项 = 2(3−1) + 2(0−1) = 4 − 2 = 2 ≥ 0 ✓；且 f₀(3,0) = 9 > 2 = f₀(1,1) ✓。再看非可行 y = (0.5, 0.5)：梯度项 = 2(−0.5)+2(−0.5) = −2 < 0——条件"失败"，但它本来就不可行，不在检验范围内。

⚠️ 常见误区

"最优 ⟹ ∇f₀(x*) = 0"是无约束才成立的特例。带约束时最优点的梯度通常不为零——上例 ∇f₀(1,1) = (2,2) ≠ 0。约束问题的正确表述是"梯度与所有可行方向不冲突"，而不是"梯度消失"。

4.4等价变换：同一问题的不同外衣

上一节给了最优性的检验标准，但它带出一个现实问题：手头的问题往往不是标准形——目标带 max、约束带 ≥、变量被等式拴住，怎么办？本节给三件常用的"换装工具"，换完后最优解集合一一对应，问题仍是凸的。

工具一：消除等式约束。若 Ax = b 有解，其通解可写成 x = Fz + x₀（x₀ 是任一特解，F 的列张成 A 的零空间）。代入后得到关于 z 的无等式约束问题。凸性保持：凸函数复合仿射映射仍凸。

工具二：引入松弛变量（Slack Variable）。不等式 fi(x) ≤ 0 ⟺ 存在 si ≥ 0 使 fi(x) + si = 0。把不等式换成"等式 + 非负约束"，这是许多 LP 求解器要求的标准外观。

工具三：上镜图形式（Epigraph Form）。任何 min f₀(x) 都等价于：

minimize  t   subject to  f₀(x) − t ≤ 0

新目标 t 是线性的（总是凸），约束 f₀(x) − t ≤ 0 关于 (x, t) 凸当且仅当 f₀ 凸。几何含义：把"压到函数最低点"改成"把一条水平线 t 从上往下压，直到碰到函数图像"——压住图像的那条线的最低高度就是 p*。

完整例：min max{x², (x−1)²+1}。逐点取 max 的函数凸（两个凸函数的 max 仍凸），但目标不可微，直接求导无从下手。换上镜图外衣：

minimize  t   subject to  x² ≤ t,  (x−1)² + 1 ≤ t

这是一个凸问题（约束函数 x²−t 与 (x−1)²+1−t 都关于 (x,t) 凸）。手算求解：

  • 第 1 步：对固定的 x，t 越小越好，最优时 t 必等于两段中较大者——两条约束至少一条取等号。
  • 第 2 步：考察 x = 0.5。第一段 x² = 0.25；第二段 (0.5−1)²+1 = 0.25+1 = 1.25。max 在 x=0.5 处由第二段取得（1.25 > 0.25），故该点目标值 = 1.25。
  • 第 3 步：检查第二段还有没有下降空间。第二段 (x−1)²+1 在 x = 1 处取最小值 1；但在 x = 1 处第一段 = 1，max = 1 < 1.25！所以 x = 1（t = 1）比 x = 0.5 更好。
  • 第 4 步：断言 x* = 1，t* = 1。验证：x = 1 时第一段 x² = 1 ≤ 1 ✓，第二段 (1−1)²+1 = 1 ≤ 1 ✓，t = 1 可行；而任何 t < 1 都会违反第二段在 x = 1 的约束……更严格地：max{x², (x−1)²+1} ≥ 1 恒成立（若 x² < 1 则 (x−1)² ≥ 0 且两段之和在 x∈[0,1] 上……直接代入 x = 1 即得等号），故 p* = t* = 1。

这个例子也示范了建模直觉：min 套 max 的结构（极小化最坏情形）几乎总是上镜图变换的信号灯。

⚠️ 常见误区

等价变换保持最优值与最优解的对应，但不保持"长相"：引入 t 后变量多了一个，约束多了两条。别把"等价"理解成"同一个问题"——它是"答案可以互相翻译的两个问题"。

💡 关键一跃

等价变换是凸优化的"翻译学"：判断不了原形是否凸，就译成能判断的等价形。Ch3 学的凸性保持规则（仿射复合、max、下水平集）正是翻译合法性的词典。

4.5家族图谱一：LP、QP、QCQP、SOCP

有了标准形和等价变换，下一个问题是：哪些凸问题已经"有名有姓"、有现成求解器？本节认前四个最常见的家族，按"约束与目标的形状"递进。

① 线性规划（Linear Program, LP）。目标与约束全仿射：

minimize  cᵀx   subject to  Gx ≤ h,  Ax = b

可行域是多面体，最优值若存在则必在顶点取得（线性函数在多面体上的极值点）。顶点法小例：max x₁+x₂ s.t. x₁+2x₂ ≤ 4，x₁ ≥ 0，x₂ ≥ 0。可行域是三角形，顶点只有三个：

顶点目标值 x₁+x₂
(0, 0)0
(4, 0)4 ← 最优
(0, 2)2

最优解 x* = (4, 0)，最优值 4（注意把 max 写成标准形是 min −x₁−x₂，p* = −4，符号翻转别弄丢）。

② 二次规划（Quadratic Program, QP）。目标是凸二次型，约束仍仿射：

minimize  12xᵀPx + qᵀx   subject to  Gx ≤ h,  Ax = b，P ⪰ 0

P ⪰ 0（半正定）正是目标凸的判据。手算例（两资产组合）：min w₁² + 2w₂² s.t. w₁+w₂ = 1。用 4.4 的工具一消元：w₂ = 1−w₁，代入得

f(w₁) = w₁² + 2(1−w₁)² = 3w₁² − 4w₁ + 2

求导 f′ = 6w₁ − 4 = 0 ⟹ w₁* = 2/3，w₂* = 1/3。二阶导 6 > 0 确认极小。最小值：

f(2/3) = 3·(4/9) − 4·(2/3) + 2 = 43 − 83 + 2 = 23 ≈ 0.667

读法：资产 2 的"惩罚系数"是资产 1 的两倍，所以少配它（1/3 < 2/3）——QP 把"风险厌恶程度"直接翻译成了权重比例。

③ 二次约束二次规划（Quadratically Constrained QP, QCQP）。在 QP 基础上，允许不等式约束也是凸二次型：xᵀPix + qiᵀx + ri ≤ 0（Pi ⪰ 0）。例：min x₁²+x₂² s.t. (x₁−1)²+(x₂−1)² ≤ 1——"离原点最近、且落在圆盘内"的点。

④ 二阶锥规划（Second-Order Cone Program, SOCP）。目标线性，约束是二阶锥：‖Aix + bi‖₂ ≤ ciᵀx + di。例：min x₁+x₂ s.t. √(x₁²+x₂²) ≤ 1 ——范数约束天然是二阶锥。包含关系 LP ⊆ QP ⊆ QCQP ⊆ SOCP，一个比一个能装，求解难度也一个比一个高。

💡 关键一跃

记家族用"约束的曲面次数"：LP 全是平面；QP 目标是抛物面、约束平面；QCQP 约束也可以是抛物面；SOCP 允许"锥面"（范数）。曲面越弯，表达力越强，算法越重。

4.6家族图谱二：几何规划与半定规划 + 本章遗留

上一节的家族都"长得像多项式"。本节认两个会变脸的家族：一个要取对数才露出凸相，一个变量干脆是矩阵。然后盘点本章欠下的账。

⑤ 几何规划（Geometric Program, GP）。变量 x 要求分量为正。两个积木：

  • 单项式（Monomial）：c·x₁^a₁·x₂^a₂···xₙ^aₙ，其中 c > 0，指数 aᵢ 任意实数；
  • 正项式（Posynomial）：单项式之和，如 2x₁²·x₂⁻¹ + 3x₃^0.5。

GP 指：目标与不等式约束是正项式（≤ 1 或 ≤ 0 的形式）、等式约束是单项式的优化问题。GP 本身不凸，但做变量替换 yᵢ = log xᵢ 再对目标取对数，就变成凸问题——所以 GP 算"广义凸家族"，可直接高效求解。

手算例：min x + 2/x（x > 0）。目标 x + 2x⁻¹ 是两个单项式之和（c=1,a=1 与 c=2,a=−1），是合法正项式，这是一个一元 GP。直接求导：

f′(x) = 1 − 2x² = 0  ⟹  x* = √2 ≈ 1.414

最优值 f(√2) = √2 + 2/√2 = √2 + √2 = 2√2 ≈ 2.83。验证二阶导 f″(x) = 4/x³ > 0（x>0），确认极小。顺带一提：对数变换后 z = ln x，目标变 ln(e^z + 2e^(−z))，这是 log-sum-exp 型，Ch3 已知它凸——两条路殊途同归。

⑥ 半定规划（Semidefinite Program, SDP）。变量是对称矩阵 X，目标与约束对 X 线性，外加线性矩阵不等式（Linear Matrix Inequality, LMI）：x₁F₁ + x₂F₂ + ⋯ + xₙFₙ + G ⪯ 0。一句话：把 LP 里的"非负向量"升级成"半正定矩阵"。SDP 是目前能高效求解的最大家族之一，控制论与组合优化放松都靠它（细节留给后续章节）。

家族目标约束一句判别特征
LP线性仿射全是直线/平面
QP凸二次仿射目标是抛物面
QCQP凸二次凸二次约束也可以是抛物面
SOCP线性二阶锥出现范数 ≤ 线性
GP正项式正项式/单项式取对数后变凸
SDP线性（矩阵变量）LMI变量是半正定矩阵

本章遗留（通向 Ch5 的账单）。到这儿我们会"认"问题了：写标准形、证局部=全局、查最优性条件、换装、归类。但两件最实际的事还没做：第一，怎么真正求出 x*？第二，给定一个可行点，怎么向别人证明它离最优不超过多少？对偶理论给出的正是后一个问题的答案——为 p* 构造可计算的下界与最优性证书，而证书又反过来指路算法。这是第 5 章的主线。

⚠️ 常见误区

看到多项式形状就喊 GP：GP 的系数必须全为正（c > 0），变量必须为正。min x − 2/x 含负系数，不是正项式，不能直接套 GP——虽然这一题碰巧也好解，但判别规则就是规则。

解决问题让"在邻域里找不到更优点"成为停下来的合法理由，算法敢放心收敛。

点击翻面 →

点击翻面 →

📝分层习题

L1 概念辨析问题 min x² s.t. x² ≤ −1 的最优值 p* 是多少？它是凸优化问题吗？
提示

先别管目标函数长什么样，先问：可行域里有几个点？回想 4.1 对空可行域的约定。

完整解答

可行域为空。x² ≤ −1 对任何实数 x 都不成立（x² ≥ 0 > −1），所以一个可行点都没有。

按约定 p* = +∞。4.1 规定：可行域为空时最优值定义为 +∞（"不可行"比"任意大"更糟）。

它仍然是凸优化问题。目标 x² 凸、约束函数 x²+1 凸——凸性是函数的性质，与可行域是否为空无关。"是凸问题"和"有解"是两回事：凸问题照样可以不可行。易错点：认为"无解所以问题提法错了"——提法完全合法，答案就是 +∞。

L1 概念辨析判断：min x³ + x s.t. x ≥ 0 是凸优化问题吗？
提示

逐项检查标准形的三条要求。对目标函数用二阶导判凸，注意 x 的整个定义域而不只是可行域。

完整解答

不是凸优化问题。写成标准形：目标 f₀(x) = x³+x，约束 −x ≤ 0（仿射，✓）。但 f₀″(x) = 6x 在 x < 0 时为负，f₀ 在其自然定义域 ℝ 上不是凸函数。

为什么容易误判：① 可行域 [0,+∞) 是凸集 ✓，但可行域凸不够，必须目标凸；② 在可行域 [0,+∞) 上 f₀″ = 6x ≥ 0，函数在该区间上确实凸，而且这题恰好易解（f₀ 在 [0,+∞) 单调递增，x* = 0，p* = 0）——但 Boyd 的定义要求目标函数本身凸，"碰巧好解"不改变分类。

教训：判凸看函数不看可行域；问题易解 ≠ 问题是凸。

L2 手算推导用上镜图形式改写 min |x−1| + |x−2|，并求出最优值与全体最优解。
提示

每个绝对值 |u| 配一个上界变量 t：|u| ≤ t 等价于哪两条线性不等式？改写后再分析原问题：分段讨论 x 落在 (−∞,1)、[1,2]、(2,+∞) 时 f 的取值。

完整解答

第 1 步：引入上镜图变量。为 |x−1| 配 t₁、|x−2| 配 t₂。利用 |u| ≤ t ⟺ −t ≤ u ≤ t ⟺ u ≤ t 且 −u ≤ t：

minimize  t₁ + t₂   subject to  t₁ ≥ x−1,  t₁ ≥ 1−x,  t₂ ≥ x−2,  t₂ ≥ 2−x

目标线性，四条约束全仿射——这是一个 LP（凸 ✓）。

第 2 步：分析原目标。f(x) = |x−1|+|x−2| 分段：

  • x < 1：f = (1−x)+(2−x) = 3−2x，斜率 −2，严格递减；
  • 1 ≤ x ≤ 2：f = (x−1)+(2−x) = 1，恒等于 1；
  • x > 2：f = (x−1)+(x−2) = 2x−3，斜率 +2，严格递增。

第 3 步：结论。整个区间 [1,2] 上的每个点都是最优解，p* = 1。数值验证：x = 1.5 时 f = 0.5 + 0.5 = 1 ✓；x = 1 时 f = 0+1 = 1 ✓；x = 2 时 f = 1+0 = 1 ✓。在上镜图变量下：x=1.5, t₁=0.5, t₂=0.5 是 LP 的最优点之一（最优解不唯一，正好呼应 4.2 的误区框）。

L2 手算推导手算 min x₁² + x₂² − 2x₁ s.t. x₁ + x₂ = 2，给出最优解与最优值。
提示

用 4.4 的工具一：由等式约束解出 x₂ = 2−x₁，代入目标，变成一元无约束问题，求导找驻点，二阶导确认。

完整解答

第 1 步：消元。x₂ = 2 − x₁，代入目标：

f(x₁) = x₁² + (2−x₁)² − 2x₁ = x₁² + 4 − 4x₁ + x₁² − 2x₁ = 2x₁² − 6x₁ + 4

第 2 步：求驻点。f′(x₁) = 4x₁ − 6 = 0 ⟹ x₁* = 3/2。回代：x₂* = 2 − 3/2 = 1/2。

第 3 步：确认极小。f″(x₁) = 4 > 0，是（全局）极小——原问题目标 Hessian 是 2I ⪰ 0，等式约束仿射，是凸问题，局部=全局定理保证这就是全局最优。

第 4 步：算最优值。

p* = 2·(9/4) − 6·(3/2) + 4 = 92 − 9 + 4 = −12

验证（直接代入原目标）：(3/2)² + (1/2)² − 2·(3/2) = 9/4 + 1/4 − 3 = 10/4 − 3 = −1/2 ✓。

L3 建模应用三种食物单价分别为 2、3、1 元/单位，每单位含蛋白质 4、3、1 克。每天需要蛋白质至少 6 克，如何购买使总花费最小？写出优化问题、判断家族、求最优解。
提示

设 x₁、x₂、x₃ 为三种食物的购买量。目标与约束都是线性的。算一算每种食物"每元钱买几克蛋白"，直觉会告诉你答案，再用约束取等验证。

完整解答

第 1 步：建模。

minimize  2x₁ + 3x₂ + x₃   subject to  4x₁ + 3x₂ + x₃ ≥ 6,  x₁,x₂,x₃ ≥ 0

第 2 步：认家族。目标线性、约束仿射——这是 LP（写成标准形：min 2x₁+3x₂+x₃ s.t. 6−4x₁−3x₂−x₃ ≤ 0, −xᵢ ≤ 0）。

第 3 步：算性价比。每元蛋白质：食物 1 为 4/2 = 2 克/元；食物 2 为 3/3 = 1 克/元；食物 3 为 1/1 = 1 克/元。食物 1 性价比最高，全买食物 1。

第 4 步：最优解。x* = (1.5, 0, 0)。验证：蛋白质 4×1.5 = 6 克，恰好达标 ✓；花费 2×1.5 = 3 元。

第 5 步：最优性论证。每元最多买 2 克蛋白，6 克蛋白至少要 6/2 = 3 元；x* 花费恰为 3 元，达到下界，故 p* = 3。这其实已经是一次"下界证书"的原始版——Ch5 的对偶会把它系统化。

  • D. min t s.t. t ≥ x−1 且 t ≥ 1−x
解析：D 对——|u| ≤ t ⟺ u ≤ t 且 −u ≤ t，两条仿射约束，结果是 LP。A 错：等式 t = x−1 丢掉了 |·|，x=0 时 t=−1 比真值 1 还小。B 错：t ≥ (x−1)² 对应的目标是平方而非绝对值。C 错：目标没换掉，t 成了摆设。
自测 5
下列四个问题，哪一个不属于它声称的家族？
  • A. min 2x₁+3x₂ s.t. x₁+x₂=1, x≥0 —— 声称是 LP
  • B. min x − 2x⁻¹（x > 0）—— 声称是几何规划
  • C. min w₁²+2w₂² s.t. w₁+w₂=1 —— 声称是 QP
  • D. min x₁+x₂ s.t. √(x₁²+x₂²) ≤ 1 —— 声称是 SOCP
解析：B 对——GP 的正项式要求每个单项式系数严格为正，−2x⁻¹ 的系数为负，不是正项式，故不是 GP（尽管这个一元问题碰巧好解）。A 错：线性目标+仿射约束，标准 LP。C 错：P = diag(2,4) ⪰ 0，是凸 QP。D 错：范数 ≤ 常数正是二阶锥约束。
