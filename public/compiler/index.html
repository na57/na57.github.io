编译原理 · 互动讲义

共 12 章，覆盖龙书《编译原理》(第2版) 主体主线：字符流进来，先由正则驱动的词法分析切成单词 → 上下文无关文法把单词拧成语法树 → 属性文法把语义挂上树 → 语法制导翻译成三地址码 → 数据流分析支撑的机器无关优化把它改快 → 指令选择与寄存器分配把它落成机器码 → 运行环境给它栈和堆的家。
这套讲义针对两个真实的学习问题设计：看完就忘 和 串不起来——每章内置回忆卡片与自测题对抗遗忘，每页标注它在全书地图中的位置对抗碎片化。

怎么用这套讲义：三条法则

这三条法则已经内置在讲义的结构里，你只需要照着做。

1

先看主线图

学每章之前，先看页面顶部的「本章定位」条和下方的主线地图，回答：这一章解决什么问题？属于哪一段？它在还前面哪一章欠下的账？

2

读完合上书复述

每章结尾的「三句话复述」和「合上书挑战」，先出声说、动笔写，再点开核对。看懂不算懂——能手算子集构造、走一遍 LR 分析栈、做一次寄存器分配，才算这一章毕业。

3

按复习计划回看回忆卡

完成一章后，下方「复习中心」会在第 1、3、7、15 天提醒你回来重答回忆卡。到点只做一件事：翻卡 + 重做标记题。回忆本身就是最强的复习。
