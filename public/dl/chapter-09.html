9.1为什么全连接在图像上不可行：先算一笔参数量的账

第 6 章给了万能逼近器，第 7、8 章让它训得动、不翻车——看上去万事俱备。但把这些全连接网络直接搬到图像上，第一道坎不是精度，是参数量本身。本节不动任何新工具，只算账。

一张小图 32×32×3（宽 32、高 32、RGB 三通道），拉直成向量是 32 × 32 × 3 = 3072 维。用第 6 章的方式接一个仅 256 单元的隐藏层：

参数数 = 3072 × 256 + 256 = 786,432 + 256 = 786,688（权重 + 偏置）

换用本章的主角：一个 5×5 的卷积核（Convolution Kernel），输出 64 个通道（Channel）。它的参数只有：

参数数 = 5 × 5 × 3 × 64 + 64 = 4,800 + 64 = 4,864（每个核 5×5×3 权重，加每通道 1 个偏置）

两种接法都能从同一张图抽出 64 组特征，参数量的比值是：

786,6884,864 ≈ 162 倍

而这还只是 32×32 的小图。真实任务常见 224×224×3 的输入：拉直后是 150,528 维，若第一层全连接接 1000 个单元，参数为 150,528 × 1000 + 1000 ≈ 1.5 亿——一层就吃光全部显存预算，而且每个像素与其他所有像素两两连线，完全无视"相邻像素才相关"这一图像最基本的结构。

接法输入规模输出规模参数量
全连接3072（32×32×3）256 单元786,688
卷积 5×53072（32×32×3）64 通道4,864
全连接150,528（224×224×3）1000 单元≈1.5 亿

差距来自两条对图像成立的结构假设：其一，局部连接（Local Connectivity）——一个像素的意义几乎只由它附近的像素决定，神经元不必看全图，只看一个小窗口；其二，参数共享（Parameter Sharing）——"边缘""角点"这类特征出现在图的左上角和右下角是同一种特征，同一组权重可以在所有位置复用。全连接对这两条假设一无所知，所以它要为每个位置、每对像素单独付费。

💡 关键一跃

卷积不是"更聪明的算法"，而是把图像的两条先验折现成参数折扣：局部连接把稠密大矩阵换成小核（指数级瘦身），参数共享让小核在所有位置复用（再除以一个位置数）。162 倍不是优化出来的，是假设换的。

⚠️ 常见误区

以为"参数量少 = 表达力差"。恰恰相反：全连接的 786,688 个参数里，绝大多数在学习"左上角像素与右下角像素无关"这类数据里根本不存在的自由度；卷积用先验把这些冗余参数直接删掉，样本效率反而更高。另一个误区是以为卷积只能用于图像——凡是"局部相关 + 平移复用"成立的信号（音频、文本、时间序列）都适用。

9.2卷积运算：深度学习里的"卷积"为什么不翻转核

上一节说"小核滑窗复用"，这一节把这个运算定义清楚，并逐格手算一遍。数学里的卷积（Convolution）要求先把核翻转 180° 再滑动相乘；而深度学习框架实际算的是互相关（Cross-correlation）——核不翻转，直接对齐窗口逐元素相乘再求和：

S(i, j) = ∑m ∑n I(i+m, j+n) · K(m, n)（互相关；真卷积是 I(i−m, j−n)·K(m, n)）

为什么敢不翻转？因为核 K 是学出来的：翻转与否只是把学到的核镜像一下，学习算法自己会收敛到合适的版本。数学卷积的交换律等好性质在学习场景里用不上，所以整个领域心照不宣地把互相关叫"卷积"。

输出尺寸由三个超参数决定：核大小 k、填充（Padding，边缘补零圈数 p）、步幅（Stride，每次滑动距离 s）。输入边长 n 时：

💡 关键一跃

卷积层 = 一个可学习的小模板在输入上滑动，每到一个位置问一句"这里像不像我"。输出图（特征图，Feature Map）的每个值就是该位置的"相像程度"。填充管边界、步幅管密度、核管"像什么"——三者全部体现在 ⌊(n+2p−k)/s⌋+1 这一个式子里。

⚠️ 常见误区

两个高频错误：(1) 在考试或论文里把深度学习的"卷积"当成数学卷积，纠结核要不要翻转——工程上永远是互相关，翻转已被学习吸收；(2) 输出尺寸忘加 1 或忘向下取整：s=2 时 27/2=13.5，必须先取 ⌊13.5⌋=13 再加 1 得 14，直接四舍五入会错。

9.3参数共享与等变表示：输入平移，输出凭什么跟着平移

上一节的核在每个位置用的是同一组权重——这就是参数共享。它不仅省参数（9.1 的账），还白送一个结构性性质：等变（Equivariance）。函数 f 对变换 g 等变，意思是"先变换再算 f"与"先算 f 再变换"结果相同：f(g(x)) = g(f(x))。对卷积而言，g 就是平移：图像里的猫往右挪一格，特征图里"猫脸响应"也恰好往右挪一格。

完整例子（手算全程，1D 版）。输入 x = [1, 2, 3, 0, 0]，核 w = [1, 0, −1]，valid 模式（不填充、步幅 1），输出长度 5−3+1 = 3：

  1. s₁ = 1×1 + 2×0 + 3×(−1) = 1 + 0 − 3 = −2（窗口 [1,2,3]）
  2. s₂ = 2×1 + 3×0 + 0×(−1) = 2 + 0 + 0 = 2（窗口 [2,3,0]）
  3. s₃ = 3×1 + 0×0 + 0×(−1) = 3 + 0 + 0 = 3（窗口 [3,0,0]）

原输入的输出：s = [−2, 2, 3]。现在把输入整体右移一位：x′ = [0, 1, 2, 3, 0]，重算：

  1. s′₁ = 0×1 + 1×0 + 2×(−1) = 0 + 0 − 2 = −2（窗口 [0,1,2]，新进入视野）
  2. s′₂ = 1×1 + 2×0 + 3×(−1) = 1 + 0 − 3 = −2（窗口 [1,2,3]）
  3. s′₃ = 2×1 + 3×0 + 0×(−1) = 2 + 0 + 0 = 2（窗口 [2,3,0]）

移位后的输出 s′ = [−2, −2, 2]。逐格对照：s′ 的第 2、3 格 [−2, 2] 恰好就是 s 的第 1、2 格——输出整体跟着输入右移了一格，左端新冒出来的一格对应新进入视野的窗口。这就是"先平移后卷积 = 先卷积后平移"（边界处除外）。卷积能等变，根源正是参数共享：核在任何位置都是同一个，同一个模式在不同位置必然触发同一个响应。

💡 关键一跃

参数共享把"检测什么"与"在哪里检测"解耦了：核只管"像不像边缘"，位置信息原封不动地保留在特征图的坐标里。等变性意味着网络不需要为"猫在左边"和"猫在右边"各学一套特征——这正是卷积样本效率高的深层原因。

⚠️ 常见误区

以为卷积自带平移不变性（Translation Invariance）——不是。卷积给的是等变：猫挪了，响应也跟着挪，位置变化被忠实保留而不是抹掉。真正把位置信息抹掉、让"猫在左上还是右下都输出猫"的是下一节的池化。等变与不变一字之差，归属完全不同：等变 ← 卷积（参数共享）；近似不变 ← 池化。

9.4池化：如何把等变变成近似不变

上一节留下一个矛盾：卷积忠实保留位置（等变），但分类任务要的恰恰是忘掉位置——猫在图的哪个角落都该输出"猫"。池化（Pooling）就是夹在卷积层之间的"位置模糊器"：把特征图划分成不重叠的小窗口，每个窗口压成一个数。最常用的是最大池化（Max Pooling）——取窗口内最大值；也有平均池化（取均值）。

💡 关键一跃

最大池化像在窗口里只汇报"有没有"，不汇报"在哪里"：5 出现在窗口里这件事被保留，它在窗口的哪个格子被遗忘。牺牲精确位置，换来对小扰动的鲁棒和分辨率的可控下降。

⚠️ 常见误区

两个错误最常见：(1) 以为 max pooling 有可学习参数、要参与反向传播训练——它没有任何参数，只是一条固定的取最大值规则（反向传播只把梯度路由给窗口内最大的那个位置），不是可学习层；(2) 以为池化必不可少——现代网络常用步幅 2 的卷积直接替代池化降采样；池化是工具不是铁律。另外，需要精确位置的任务（分割、检测）要慎用池化，位置信息丢了就找不回来。

9.5感受野：一个神经元到底"看到"多大区域

9.2 的核只有 3×3 或 5×5，可图像里的物体动辄几十上百像素——一个看 3×3 窗口的神经元凭什么认出整只猫？答案藏在层数里：感受野（Receptive Field）指某个输出神经元在原始输入上能影响它的区域大小。单层 3×3 核只看 3×3，但第二层的 3×3 作用在第一层的输出上，每个输出点已经凝缩了 3×3 的信息——两层叠起来，视野就超过 3×3。

完整推导（手算全程）。输入层的感受野 r₀ = 1（每个点就是 1 个像素）。第 l 层核大小 k、之前各层步幅连乘为 ∏si，递推式为：

rl = rl−1 + (k − 1) · ∏i si

直觉：新核每往外扩一格，相当于在"已经放大 ∏si 倍"的旧视野边缘再贴一圈。

例 1：两层 3×3、全部 s=1。第一层：r₁ = 1 + (3−1)×1 = 3。第二层：r₂ = 3 + (3−1)×1 = 5。两层 3×3 的感受野 = 5×5，与单层 5×5 相同。

例 2：三层 3×3、全部 s=1。第三层：r₃ = 5 + 2×1 = 7。三层 3×3 顶一个 7×7。

例 3：中间夹一步 s=2。第一层 3×3 s=1：r₁ = 3；第二层 3×3 s=2：r₂ = 3 + 2×2 = 7——步幅让视野翻倍扩张，这就是 9.4 说的池化/大步幅"扩大感受野"。

既然两层 3×3 与单层 5×5 视野相同，选哪个？算参数账（设通道数为 C，只算权重）：

两层 3×3：2 × (3×3×C×C) = 18C² ；单层 5×5：5×5×C×C = 25C²
节省比例 = 25C² − 18C²25C² = 725 = 28%

同样的感受野，小核堆叠省 28% 参数，还多赚一次非线性激活（两层之间有一个 ReLU，单层没有）——表达力更强、参数更少。这正是 VGG 网络的核心论证：一切大核都应拆成 3×3 堆叠。

💡 关键一跃

感受野是深度网络"深度"二字的又一层含义：深度不仅堆非线性（第 6 章的视角），还在堆视野——越深的神经元看到的原始输入越大，从边缘、到纹理、到部件、到整个物体，层级特征天然由感受野的生长节奏决定。

⚠️ 常见误区

两个常见错误：(1) 以为"感受野 = 本层核大小"——必须逐层递推，且步幅（含池化的 2×2/s2）以连乘方式进入公式，漏掉 s 项会严重低估深层神经元的视野；(2) 以为感受野越大越好——小目标检测里过大的感受野会让目标淹没在背景上下文里，视野要与任务目标的尺度匹配。

9.6卷积网络的完整形态：从 conv-pool 堆叠到 ResNet

前面五节给了全部零件，本节把它们装成整机。一个标准卷积网络（CNN，Convolutional Neural Network）的前半段是同一台三段式机器的反复堆叠：

卷积 → 激活（ReLU） → 池化，重复 N 次 → 展平 → 全连接分类头

堆叠时的总节奏是空间尺寸递减、通道数递增：例如 224×224×3 → 112×112×64 → 56×56×128 → … 每降一次分辨率（步幅 2 卷积或池化），通道数翻倍补偿——空间信息在损失，语义信息在浓缩，感受野在膨胀，末端每个神经元都"看"过几乎整张图。

堆叠之外还有一个常用零件：1×1 卷积（1×1 Convolution）。核只有 1×1，不看任何空间邻域，只做一件事——在每个像素位置上对通道做线性组合。例如把 256 通道压到 64 通道：参数为 1×1×256×64 + 64 = 16,448；若用 3×3 做同样的通道变换则要 3×3×256×64 + 64 = 147,520，相差约 9 倍。要调通道数、不要视野时，1×1 是最便宜的选择。

一句话脉络：LeNet（1998，手写数字，conv-pool 堆叠的鼻祖）→ AlexNet（2012，ReLU + GPU，深度 CNN 复兴）→ VGG（2014，9.5 的论证：全 3×3 小核堆叠）→ ResNet（2015，残差连接让网络深到上百层，正是第 8 章优化问题的结构解法）。这条线解决的是"空间结构"，下一条线——序列与时间——是第 10 章的故事。

💡 关键一跃

设计 CNN 时只需盯住三条独立旋钮：核大小与层数管感受野（9.5），步幅与池化管分辨率下降节奏（9.4），通道数与 1×1 卷积管语义容量。所有经典架构都是这三条旋钮的不同拧法。

⚠️ 常见误区

以为"网络越深越好、通道越多越好"。深度受第 8 章优化难度约束（ResNet 的残差连接正是为此而生）；通道数每翻一倍，该层参数与计算量约翻四倍（通道同时出现在核的输入、输出两侧）。架构设计是感受野、分辨率、参数预算三者的平衡，不是单向堆料。

概念卡 1
卷积 / 互相关（Convolution / Cross-correlation）
点击翻面 →
定义小核在输入上滑动，逐窗口对齐相乘再求和：S(i,j) = ∑ₘ∑ₙ I(i+m, j+n)·K(m,n)。
解决问题全连接在图像上的参数量爆炸（786,688 vs 4,864）：用局部连接+滑窗复用替代稠密矩阵。
直觉可学习的小模板逐位置问"这里像不像我"，特征图就是一张"相像程度地图"。
误区纠结核要翻转 180°——工程上是互相关，翻转已被学习吸收。
何时用一切"局部相关+平移复用"的信号：图像、音频、文本；第 10 章序列建模的 1D 版本。
概念卡 2
参数共享（Parameter Sharing）
点击翻面 →
定义同一组核权重在所有空间位置复用，而不是每个位置一套独立权重。
解决问题把参数量从"像素对之间两两相连"压成"一个核的大小"；同时白送平移等变性。
直觉边缘出现在左上角和右下角是同一种边缘，没必要请两个侦探。
误区以为参数共享只是省内存的技巧——它是"模式与位置解耦"的结构先验，样本效率由此而来。
何时用卷积层的默认机制；第 10 章 RNN 沿时间轴共享参数是同一思想。
概念卡 3
等变与不变（Equivariance / Invariance）
点击翻面 →
定义等变：f(g(x)) = g(f(x))，输入平移则输出同步平移；不变：f(g(x)) = f(x)，输入平移输出不动。
解决问题等变保留位置信息供检测/分割用；不变抹掉位置供分类用——两者分工不同。
直觉等变是"猫动我也动"的影子；不变是"任你动，我只报有没有"的哨兵。
误区把平移不变性记在卷积头上——等变来自卷积（参数共享），近似不变来自池化，归属不能混。
何时用分类头前要不变（池化/全局池化）；检测分割要保位置，慎用池化。
概念卡 4
池化（Pooling）
点击翻面 →
定义把特征图划成小窗口各压成一个数的无参数操作；最大池化取 max，平均池化取均值。
解决问题把卷积的等变折成对微小平移的近似不变；降分辨率、扩大后续层感受野。
直觉窗口里只汇报"有没有"，不汇报"在哪里"。
误区以为有可学习参数（没有）；以为必不可少（可用 s=2 卷积替代）；分割任务乱用会丢位置。
何时用经典 CNN 的 conv-pool 堆叠；需要小范围平移鲁棒性与降采样时。
概念卡 5
感受野（Receptive Field）
点击翻面 →
定义某输出神经元在原始输入上能影响它的区域大小：rl = rl−1 + (k−1)·∏si。
解决问题回答"3×3 的小核凭什么认出大物体"——深度在堆视野，两层 3×3 = 一个 5×5。
直觉神经元像越站越高的瞭望员，层数每加一，看到的原图区域往外扩一圈。
误区以为等于本层核大小（要逐层递推且含步幅连乘）；以为越大越好（小目标会被背景淹没）。
何时用设计网络时核对深层视野是否覆盖目标尺度；VGG 小核堆叠论证的依据。
概念卡 6
填充与步幅（Padding / Stride）
点击翻面 →
定义填充 p：输入边缘补零圈数；步幅 s：核每次滑动的距离。输出边长 ⌊(n+2p−k)/s⌋+1。
解决问题填充管边界信息不流失与尺寸保持（same）；步幅管降采样节奏与计算量。
直觉填充是给照片加一圈白边让角落实物也能被窗口完整覆盖；步幅是侦探迈步的步长。
误区输出尺寸忘加 1 或忘向下取整（⌊13.5⌋+1 = 14，不是 14.5 或 15）。
何时用p=(k−1)/2 保尺寸（same）；s=2 替代池化降采样，现代 CNN 的主流做法。

📝分层习题

L1 概念辨析

判断并说明理由：(1) "深度学习框架里的卷积层在滑动窗口之前，会先把卷积核翻转 180°，因为数学上卷积就是这么定义的。" (2) "既然翻转不影响学习结果，那么把训练好的核翻转 180° 再推理，网络输出不变。"

提示

区分两件事：训练时学的是"翻转过的核"还是"未翻转的核"？推理时核已固定，还享受"翻转被吸收"的自由吗？

完整解答

(1) 错。深度学习框架实际计算的是互相关：核不翻转，直接对齐窗口逐元素相乘求和。之所以敢这么干，是因为核可学习——数学卷积要求的翻转只是参数化方式不同，学习算法自己会收敛到合适的核；交换律等数学性质在训练场景里用不上。说"框架会翻转"与事实相反。

(2) 错。"翻转被学习吸收"只在训练阶段成立：给互相关一个自由核，它能学到任何模式（包括某个数学卷积核的翻转版）。但训练完成后核已经固定为一个具体的数表，此时翻转它等于换了一个不同的函数：S(i,j) = ∑I·K 变为 ∑I·K_flipped，逐窗口的点积一般不同，输出必然改变。自由属于训练，不属于推理。

L1 概念辨析

判断并说明理由："max pooling 层和卷积层一样需要在反向传播中更新参数，只是它的参数是窗口大小 2×2 和步幅 2 这类超参数。"

提示

参数和超参数的区别是什么？反向传播更新的是哪一类？max pooling 前向计算里有任何可调的数吗？

完整解答

错，且错在两处。(1) max pooling 没有任何可学习参数：前向只是一条固定的"取窗口内最大值"规则，没有权重可更新；反向传播经过它时只是把上游梯度原样路由给窗口内取到最大值的那个位置，其余位置梯度为 0——它是梯度的"路由器"，不是被训练的对象。(2) 窗口大小与步幅是超参数，由人在训练前设定（或用验证集选），从不参与梯度更新。把它与卷积层并列说"一样需要更新参数"混淆了参数与超参数、可学习层与固定运算的界限。

L2 手算推导

用输出尺寸公式各算一遍（写全代入过程）：(1) n=28, k=3, p=1, s=2；(2) n=64, k=7, p=3, s=1。两问的输出边长各是多少？第 (2) 问的输出尺寸与输入有什么关系，为什么？

提示

公式只有一个：⌊(n+2p−k)/s⌋+1。先算括号里 n+2p−k，再除以 s 向下取整，最后加 1。第 (2) 问注意 p 与 k 的关系。

完整解答

(1) n+2p−k = 28 + 2×1 − 3 = 27；27/2 = 13.5，向下取整 ⌊13.5⌋ = 13；加 1 得输出边长 14。（验证直觉：28 的输入步幅 2，尺寸约减半为 14 ✓）

(2) n+2p−k = 64 + 2×3 − 7 = 64 + 6 − 7 = 63；63/1 = 63；加 1 得输出边长 64。

第 (2) 问输出边长 = 输入边长（64 = 64）。原因：p = (k−1)/2 = (7−1)/2 = 3 时，2p = k−1，于是 n+2p−k = n−1，除以 s=1 再加 1 恰好回到 n——这就是 same 填充的设计方程，奇数核配 p=(k−1)/2 可保尺寸不变。

L2 手算推导

某网络连堆四层 3×3 卷积，全部 s=1、无池化。(1) 用递推式逐层求感受野；(2) 它与单层多大核的感受野相同？(3) 设通道数为 C，比较"四层 3×3"与"该等效单层大核"的权重参数量，算出节省比例；(4) 除参数外，四层方案还比单层方案多什么？

提示

r₀ = 1，每层加 (k−1)·∏si，这里每层的 ∏si 都是 1。参数量：每层 k×k×C×C，四层相加。

完整解答

(1) r₁ = 1 + (3−1)×1 = 3；r₂ = 3 + 2 = 5；r₃ = 5 + 2 = 7；r₄ = 7 + 2 = 9。四层 3×3 感受野为 9×9。

(2) 与单层 9×9 核的感受野相同（1 + (9−1)×1 = 9 ✓）。

(3) 四层 3×3：4 × 9C² = 36C²；单层 9×9：81C²。节省 (81−36)/81 = 45/81 ≈ 55.6%。

(4) 多三次非线性激活（每两层之间一个 ReLU，单层一次都没有）：同样的视野下，四层方案是四段仿射+三段非线性复合的函数，表达力远强于单层的一次仿射。这正是 VGG"小核堆叠"论证的完整版：感受野相同、参数更少（本题省约 56%，9.5 两层对 5×5 的情形省 28%）、非线性更多。

L3 建模应用

你在做一个医学影像分类项目：输入 224×224×3 的 X 光片，二分类。设计网络的前三层卷积，要求：第一层就把分辨率降下来（早期降采样省算力），三层结束时感受野达到 15×15 左右、通道数到 128。逐层给出核大小/步幅/填充/通道数，并逐层手算输出尺寸、感受野与参数量（含偏置），最后汇总三层总参数。

提示

参考成熟做法：第一层用大核大步幅（如 7×7、s=2、p=3），之后换 3×3。感受野递推别忘了步幅连乘项：第一层之后 ∏si 就含 2 了。参数量 = k×k×Cin×Cout + Cout。

完整解答

设计（参考答案）：第一层 7×7、s=2、p=3、64 通道；第二层 3×3、s=1、p=1、64 通道；第三层 3×3、s=2、p=1、128 通道。

第一层：输出边长 ⌊(224+6−7)/2⌋+1 = ⌊223/2⌋+1 = 111+1 = 112 → 112×112×64。感受野 r₁ = 1 + 6×1 = 7。参数 7×7×3×64 + 64 = 9,408 + 64 = 9,472。

第二层：输出边长 ⌊(112+2−3)/1⌋+1 = 111+1 = 112 → 112×112×64（same）。感受野 r₂ = 7 + (3−1)×2 = 11（此前步幅连乘 = 2）。参数 3×3×64×64 + 64 = 36,864 + 64 = 36,928。

第三层：输出边长 ⌊(112+2−3)/2⌋+1 = ⌊111/2⌋+1 = 55+1 = 56 → 56×56×128。感受野 r₃ = 11 + (3−1)×(2×1) = 15（此前步幅连乘 = 2×1 = 2）。参数 3×3×64×128 + 128 = 73,728 + 128 = 73,856。

汇总：三层总参数 9,472 + 36,928 + 73,856 = 120,256；分辨率 224 → 112 → 112 → 56，通道 3 → 64 → 64 → 128，感受野 7 → 11 → 15，全部满足要求。对照 9.1：若第一改用全连接哪怕只接 1000 单元也要约 1.5 亿参数——三层卷积合计才 12 万。

  • D. 两者都来自数据增强，与网络结构无关
解析：A 对——9.3 的 1D 例子逐格验证过：x=[1,2,3,0,0] 卷积得 [−2,2,3]，输入右移后输出为 [−2,−2,2]，响应同步右移（等变）；9.4 窗口 [[1,3],[0,5]] 中 5 任意挪动池化输出恒为 5（近似不变）。B 错：卷积忠实保留位置，不会"顺便"不变；池化也不只是加速器，它改变的是表示的位置敏感性。C 错：归属恰好颠倒。D 错：数据增强（第 7 章）是训练侧注入先验，等变/不变是架构本身的前向性质，没增强也成立。
自测 4
关于 max pooling，下列说法正确的是：
  • A. 它有可学习参数，反向传播会更新窗口权重
  • B. 它提供对任意幅度平移的完全不变性
  • C. 它缩小分辨率，因此会缩小后续层的感受野
  • D. 它无参数；提供对窗口尺度微小平移的近似不变性；分辨率减半使后续层感受野扩大
解析：D 对——三个性质都在 9.4 验证过：无参数（纯取 max 规则）、窗口内最大值挪动输出不变（近似不变）、4×4→2×2 后后续核每步相当于原图两步（感受野扩大）。A 错：max pooling 是固定规则层，窗口大小/步幅是超参数，不参与梯度更新。B 错：不变性只在池化窗口尺度内成立，大平移仍会改变输出——所以叫"近似"。C 错：方向反了，分辨率下降让同样的核覆盖更大的原图区域，感受野是扩大（9.5 例 3：s=2 使两层 3×3 直达 r=7）。
自测 5
三层 3×3 卷积堆叠（全部 s=1、无池化）的感受野是多少？相比单层等效大核，参数是省了还是费了？
  • A. 9×9；参数 27C² 比单层 9×9 的 81C² 省——三层堆叠又小又省
  • B. 7×7；参数 27C² 比单层 7×7 的 49C² 省约 45%，还多两次非线性
  • C. 7×7；参数 27C² 与单层 7×7 的 49C² 相同，只是更深
  • D. 5×5；因为感受野只由最深层核大小决定
解析：B 对——r₀=1，逐层加 2：3、5、7；参数三层 3×9C² = 27C² 对单层 7×7 = 49C²，省 22/49 ≈ 45%，且层间多两次 ReLU。A 错：9×9 是把核大小线性相加又加错（3+3+3），且 27C² 与 81C² 的比值安错了感受野。C 错：27C² ≠ 49C²，参数明明省了约 45%。D 错：感受野由所有层递推决定（rl = rl−1 + (k−1)·∏si），不是只看最后一层；两层才是 5×5。
