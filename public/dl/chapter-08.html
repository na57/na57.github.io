8.1为什么不用训练误差当目标：经验风险与 minibatch

第6、7章之后，我们手里有模型、有反向传播、有正则化好的目标函数——看起来"沿负梯度走"就完事了。本章的第一个冷水是：我们真正想优化的东西，根本没法直接优化。机器学习的终极目标是期望泛化误差（Expected Generalization Error）：在真实数据生成分布 pdata 上，损失 L 的期望。问题是我们手里没有 pdata，只有从它采样出的训练集。

能做的只有退而求其次：用训练集上的平均损失代替期望损失——这叫经验风险（Empirical Risk），最小化它就是经验风险最小化（Empirical Risk Minimization，ERM）：

J(θ) = E(x,y)~p̂data L(f(x; θ), y) = 1m ∑i=1m L(f(x⁽ⁱ⁾; θ), y⁽ⁱ⁾)

这仍然有两个妥协。第一，经验风险最小化本身往往不可行——0-1 损失处处梯度为 0，所以实际优化的是代理损失（Surrogate Loss），如负对数似然；而且它容易过拟合（第7章整章在补这个洞），实践中甚至不把它降到最小，早停就退场了。第二，就算只算经验风险的梯度，每步也要遍历全部 m 个样本：训练集有上千万样本时，一步更新就要前向、反向各跑一遍全库，慢到不可用。

出路是抽样：每次只取一个小批量（minibatch，记 m′ 个样本）估计梯度。估计有多准？把每个样本的梯度看成均值为真梯度的随机变量，样本梯度的标准差为 σ，则 m′ 个样本平均梯度的标准误（Standard Error）为：

SE = σ√m′

完整例子（手算全程）。设样本梯度标准差 σ = 1，分别取 m′ = 1、100、10000：

批量大小 m′标准误 σ/√m′相对上一档
11/√1 = 1—
1001/√100 = 1/10 = 0.1样本 ×100，误差 ÷10
100001/√10000 = 1/100 = 0.01样本 ×100，误差 ÷10

规律一目了然：样本量增大 100 倍，梯度估计精度只提高 10 倍——√m′ 律决定了收益递减。从 100 涨到 10000，算力翻百倍，只换来一位小数的精度；而小 batch 虽然噪声大，却有两个意外之喜：每步便宜可以走更多步，噪声本身还有点正则化效果。这就是为什么深度学习几乎全用几十到几百的小批量，而不是全量梯度。

💡 关键一跃

这一节把"优化"的底牌换了：我们优化的不是真正的目标（泛化误差），甚至不是经验风险本身，而是一个抽样估计出来的、有噪声的梯度方向。本章后面所有算法——动量、Adam——都可以看成在这个"带噪声的指南针"下如何走得更稳。

⚠️ 常见误区

两个误区：(1) 以为 batch 越大梯度越准、训练就一定越好——√m′ 律让精度收益递减，而大 batch 泛化往往更差，需配合调高学习率等技巧；(2) 以为优化目标就是"把训练误差降到 0"——那是过拟合的同义词，第7章的正则化与早停恰恰在阻止这件事。另外样本必须随机抽取：按类别排序的 batch 会让估计严重有偏。

8.2为什么梯度下降会原地爆炸：病态条件

上一节解决了"梯度从哪来"。现在假设梯度精确已知（先不管噪声），训练是不是就稳了？远不是。梯度下降最大的敌人叫病态条件（Ill Conditioning）：损失曲面在不同方向上的曲率（Curvature，二阶导数）相差悬殊——有的方向陡峭如悬崖，有的方向平缓如平原。曲面局部由海森矩阵（Hessian Matrix）H 刻画，曲率悬殊的程度用条件数（Condition Number）度量：

κ(H) = λmaxλmin（H 的最大与最小特征值之比）

为什么悬殊的曲率让梯度下降两难？沿特征值 λi 的特征方向看，梯度下降每步把该方向的误差乘以因子 (1 − ηλi)（对二次问题可精确推得）。要收敛，所有方向都必须满足 |1 − ηλi| < 1，解出 η < 2/λmax——稳定步长由最陡方向封顶；而慢方向的速度又被同一个 η 卡住：|1 − ηλmin| 越接近 1，走得越慢。

完整例子（手算全程）。二次问题，Hessian 特征值 λmax = 100（快方向）、λmin = 1（慢方向），条件数 κ = 100。稳定要求 η < 2/100 = 0.02。

情形一：η = 0.025（越界，发散）。快方向每步误差乘 |1 − ηλmax| = |1 − 0.025×100| = |1 − 2.5| = 1.5。逐步推演：1 步后 ×1.5，2 步后 ×2.25，3 步后 ×3.375……10 步后放大 1.5¹⁰：

步数123510
快方向误差倍数（1.5ⁿ）1.52.253.3757.59≈ 57.7

验证最后一步：1.5⁵ = 7.59375，1.5¹⁰ = 7.59375² ≈ 57.67——误差放大约 58 倍，越走越远离最优，这就是发散。表现为训练 loss 突然暴涨甚至 NaN。

情形二：η = 0.01（守界，慢得煎熬）。快方向：|1 − 0.01×100| = |1 − 1| = 0——一步就把快方向误差清零，完美。慢方向：|1 − 0.01×1| = 0.99，每步只削减 1%。想把慢方向误差降到 1/10，要解 0.99ⁿ = 0.1：

n = lg 0.1lg 0.99 ≈ −1−0.004365 ≈ 229.1，即约 230 步

验证：0.99²³⁰ ≈ e230×ln 0.99 ≈ e−2.312 ≈ 0.099 ✓。看这笔账：快方向一步收敛，慢方向要 230 步——同一个学习率，不可能同时讨好两个方向。这就是病态条件的诅咒：η 稍大就发散，η 守规矩就爬行。条件数 100 还算温和，深度网络的 Hessian 条件数动辄成千上万。

💡 关键一跃

病态条件下梯度下降像一个只有一档速度的车：在峡谷状的损失曲面上，沿峡谷壁（快方向）来回弹跳、随时翻车，沿峡谷底（慢方向）却慢如蜗牛。后面 8.4 的动量、8.5 的自适应学习率，本质都是给不同方向配不同速度——治病态条件的根。

⚠️ 常见误区

把发散归咎于"梯度算错了"——多数时候反向传播没错，是 η 相对 λmax 太大（8.2 的例子只差 0.005 就越界）。反向也成立：以为"学习率小就一定收敛"——小学习率只保证不发散，不保证来得及收敛，慢方向 230 步才降 90%，实践中等于没收敛。还有：梯度方向≠最优方向，病态时负梯度几乎垂直指向峡谷壁，而不是指向谷底终点。

8.3为什么学习率必须衰减：随机梯度下降的收敛条件

8.1 说梯度是抽样估计的、带噪声；8.2 说曲面病态、步长两难。把两个麻烦叠加，就是深度学习的日常：随机梯度下降（Stochastic Gradient Descent，SGD）——每个 minibatch 上沿估计梯度的反方向走一步。SGD 要想（在凸情形下渐近）收敛，学习率不能一成不变，必须满足一对经典条件：

∑t=1∞ ηt = ∞ 且 ∑t=1∞ ηt² < ∞

第一条说：步长之和必须发散——否则总位移有上限，万一最优点在远处就永远走不到。第二条说：步长平方和必须收敛——步长衰减要足够快，才能压住噪声的累积扰动。

完整例子（验证一个合法、一个非法）。取 ηt = 0.1/t：

条件级数结论
∑ ηt0.1 × (1 + 1/2 + 1/3 + …) = 0.1 × 调和级数发散 → ∞ ✓
∑ ηt²0.01 × (1 + 1/4 + 1/9 + …) = 0.01 × π²/6 ≈ 0.0164收敛 ✓（p = 2 的 p 级数）

所以 ηt = 0.1/t 满足收敛条件。反过来，常数学习率 ηt = η 不满足：∑η² = ∞，第二条直接失败。

常数学习率失败在哪？直觉很具体：假设参数已经站在最优点的碗里，此时真实梯度为 0，但 minibatch 估计的梯度不为 0——它在 0 附近随机波动，方差不为零。每步更新 −η·ĝ 就是一个以 0 为均值、幅度正比于 η 的随机跳动。η 不衰减，跳动幅度不衰减，参数永远在最优点附近做半径 ≈ η ×（噪声水平）的随机游走——能靠近，却永远停不下。这就是实践中训练后期 loss 曲线"抖动着不下去"的原因之一。要让跳动消失，只能让 ηt → 0。工程上常用线性衰减：第 t 轮取 ηt = (1 − t/T)η₀ + (t/T)ηT，到第 T 轮降到 η₀ 的 1% 左右。

💡 关键一跃

两个条件一句话：步子总量要够走任意远（∑ηt 发散），但后期步子要小到能被噪声原谅（∑ηt² 收敛）。常数步长满足了前者、死在后者的本质上——随机性不随训练消失，只能靠步长消失来对冲。

⚠️ 常见误区

以为"loss 后期抖动 = 模型坏了"，急着换模型——多数时候只是常数学习率撞上噪声地板，衰减 η 即解。另一个极端是衰减过快：ηt = 0.1/t² 的 ∑ηt 收敛，总位移有限，参数可能在半路"冻僵"，离最优点还差得远。实践折中：线性衰减到很小的末值，而不是理论上严格的 1/t。

8.4动量：为什么给梯度装上惯性就能又快又稳

回到 8.2 的峡谷困境：负梯度在快方向（峡谷壁）上来回震荡，在慢方向（峡谷底）上爬行。8.3 的答案是衰减步长——治噪，但对病态无能为力。动量（Momentum）换了个思路：不改步长本身，改"步长由什么决定"——维护一个速度变量 v，让历史梯度的加权平均来推动参数：

v ← αv − ε∇J，  θ ← θ + v

α ∈ [0, 1) 是动量系数（常取 0.9），ε 是学习率。v 是过去梯度的指数加权移动平均（Exponentially Weighted Moving Average）：方向一致的梯度会越积越大，方向来回翻转的梯度会相互抵消——这正是峡谷问题需要的对症药。

完整例子（手算全程）。α = 0.9，ε = 0.01，梯度恒为 ∇ = 2（模拟峡谷底：方向永远一致的慢方向），初始 v₀ = 0，逐代 vt = 0.9vt−1 − 0.01×2：

步 t计算vt
10.9×0 − 0.02−0.02
20.9×(−0.02) − 0.02 = −0.018 − 0.02−0.038
30.9×(−0.038) − 0.02 = −0.0342 − 0.02−0.0542
∞v∞ = 0.9v∞ − 0.02 ⟹ 0.1v∞ = −0.02−0.2

核对稳态：设 v∞ 满足 v∞ = αv∞ − ε∇，解出

v∞ = − ε∇1 − α = − 0.020.1 = −0.2，速度放大 11 − α = 10 倍

对比：裸 SGD 在同样梯度下每步只走 −ε∇ = −0.02；动量的终端速度 −0.2 是它的 10 倍。再看峡谷壁方向：梯度正负交替，加进 v 里正负抵消，速度涨不起来——震荡被自动抑制。一个方向加速 10 倍、一个方向被按住，8.2 的"同一 η 无法兼顾两方向"就此化解。α 的作用期也直白：1/(1−α) = 10，即历史梯度的影响大约延续 10 步。

💡 关键一跃

动量的物理画面：参数是小球，梯度是坡度，α 是"无摩擦程度"。小球冲下峡谷底会越滚越快（一致方向积累），撞上峡谷壁会被弹回但来回撞平均为零（震荡抵消）。一句话：动量放大的是"共识"，抵消的是"分歧"。

⚠️ 常见误区

以为 α 越大约好——α = 0.99 放大 100 倍，但惯性太大，冲过谷底要等很久才回头，ε 必须同步调小；常见搭配是 α = 0.9 配原 ε 的 1/10 左右。另一个误区：把动量当"自适应学习率"——它对所有参数仍共享同一个 ε，逐坐标缩放是 8.5 的事。还有 Nesterov 动量（先走到 θ + αv 再算梯度）是它的一个常用变体，多花一次前向，理论上更稳。

8.5自适应学习率：RMSProp 与 Adam 凭什么给每个参数配步长

动量解决了"时间维度"上的快慢，但还有一个更直接的对症思路没出场：8.2 的病根是不同方向曲率不同、共享一个学习率——那就给每个参数单独配学习率。这就是自适应学习率（Adaptive Learning Rate）一族算法。

先看 RMSProp（Root Mean Square Propagation）：维护梯度平方的指数加权平均 r，用它的平方根去除学习率——历史上该方向梯度越大，实际步长压得越小：

r ← β₂r + (1 − β₂)g²，  Δθ = − ε√r + δ g

效果正是 8.2 想要的：快方向（g 持续很大）r 大、步长被压缩，不发散；慢方向（g 持续很小）r 小、步长相对放大，不爬行。RMSProp 没有动量、没有偏差修正，结构简单。

Adam（Adaptive Moment Estimation）= RMSProp 的逐坐标缩放 + 动量的一阶平均 + 一项常被忽视却关键的偏差修正（Bias Correction）：

m ← β₁m + (1 − β₁)g  （一阶矩，相当于动量）
v ← β₂v + (1 − β₂)g²  （二阶矩，相当于 RMSProp 的 r）
m̂ = m1 − β₁ᵗ， v̂ = v1 − β₂ᵗ  （偏差修正，t 是步数）
Δθ = − ε m̂√v̂ + δ

完整例子（手算全程）。g = 2，β₁ = 0.9，β₂ = 0.999，ε = 0.001，δ = 10⁻⁸，初始 m₀ = 0、v₀ = 0，算第一步：

步骤计算结果
一阶矩 m₁0.9×0 + (1 − 0.9)×2 = 0.1×20.2
二阶矩 v₁0.999×0 + (1 − 0.999)×2² = 0.001×40.004
修正 m̂₁0.2 / (1 − 0.9¹) = 0.2 / 0.12
修正 v̂₁0.004 / (1 − 0.999¹) = 0.004 / 0.0014
更新量 Δθ−0.001 × 2 / (√4 + 10⁻⁸) ≈ −0.001 × 2/2≈ −0.001

对比同一个 g = 2 下裸 SGD（ε = 0.001）：Δθ = −0.001×2 = −0.002——Adam 首步的有效步长 ≈ ε，是裸 SGD 的一半且与 g 的大小几乎无关（g 翻倍时 m̂ 翻倍、√v̂ 也翻倍，两者抵消）。这正是 Adam 的设计意图：步长以 ε 为天然单位，超参数含义清晰。

再看偏差修正的必要性：如果跳过修正直接用 m₁ = 0.2、v₁ = 0.004，则 Δθ = −0.001 × 0.2/(√0.004) = −0.001 × 0.2/0.0632 ≈ −0.00316——比正常值大三倍还多。原因：m、v 从 0 启动，初期被"压向 0"（m₁ 只有真值 2 的 1/10，v₁ 只有真值 4 的 1/1000），且二阶矩的偏差（1/1000）比一阶矩（1/10）严重得多，开根号后比例失衡。修正项 1 − βᵗ 恰好把估计拉回无偏：t = 1 时 m̂ = 2、v̂ = 4 恰好就是观测本身；t 变大后 βᵗ → 0，修正自动退场。

💡 关键一跃

Adam 一句话：信噪比驱动。分子 m̂ 是"梯度的共识"（信号），分母 √v̂ 是"梯度的规模"，比值 m̂/√v̂ 像信噪比——方向稳定时比值接近 ±1（全速走 ε），方向混乱时比值趋 0（自动减速）。它把 8.4 的"惯性"和 RMSProp 的"逐坐标缩放"缝在了一起，再加偏差修正保证冷启动不偏。

⚠️ 常见误区

(1) 以为 Adam 不需要调学习率——ε 仍是第一超参数，只是容忍度比 SGD 高；(2) 漏掉偏差修正——冷启动时二阶矩偏差 1/1000 级，不修正会让首几步更新放大数倍且方向失真；(3) 以为 Adam 全面优于 SGD——不少视觉任务上，调好衰减的 SGD + 动量泛化更好，Adam 赢在收敛快、不挑食；(4) 以为分母 δ 是摆设——它防 v̂ 极小时除零爆炸，量级 10⁻⁸ 即可。

8.6二阶方法为什么用不起：批量归一化的优化视角

8.2 的病态条件，教科书里有现成答案：牛顿法（Newton's Method）直接用 H⁻¹∇J 一步纠正所有方向的曲率差异。问题是深度网络有 n 个参数，H 有 n² 个元素——n = 10⁹ 的模型，存 H 就要 10¹⁸ 个数，更别提求逆的 n³ 量级计算。二阶方法在精确曲率上是赢家，在存储与算力上直接出局，只剩近似版本（如 K-FAC）在特定场景可用。

更工程化的出路是改造曲面本身。批量归一化（Batch Normalization，BN）把每层的输入在 batch 内减均值、除标准差再仿射还原：从优化视角看，它做了一次重参数化（Reparameterization）——层与层之间的尺度不再互相追逐放大，损失曲面被"捋平"，条件数显著改善，于是可以安全地用更大的学习率。这解释了 BN 实践中"让训练又快又稳"的现象：它表面是归一化技巧，实质是曲面的整脊手术。结构怎么配合优化，是第9章卷积网络、第10章序列建模继续展开的故事。

💡 关键一跃

优化算法与网络结构是一枚硬币的两面：算法迁就曲面（动量、Adam），结构改造曲面（BN、残差连接）。遇到训练困难，先问"该换算法还是该改结构"，往往比埋头调参有效。

⚠️ 常见误区

把 BN 的好处全归于"缓解内部协变量偏移"——这是原始论文的叙事，后来的研究更支持"平滑损失曲面、改善条件数"的优化解释。另外 BN 依赖 batch 统计，小 batch 下估计不准，这正是 8.1 抽样噪声在结构层面的回响。

概念卡 1
经验风险最小化（Empirical Risk Minimization）

解决问题真实分布 pdata 未知，期望泛化误差无法直接优化——ERM 给出可计算的目标。
直觉没见过题库全集，只能把手头这沓真题当全集来刷。
误区以为把经验风险降到 0 就是好——那正是过拟合；实际还换用代理损失并早停。

概念卡 2
Minibatch 梯度估计（Minibatch Gradient Estimation）
点击翻面 →
定义每次抽 m′ 个样本估计梯度，标准误 SE = σ/√m′。
解决问题全量梯度每步遍历整个训练集，大到不可算；抽样用噪声换速度。
直觉抽样民调：样本翻 100 倍，误差只缩小 10 倍，收益递减。
误区以为 batch 越大越好——精度按 √m′ 增长，大 batch 泛化常更差；且必须随机抽样。
何时用所有深度训练的默认；batch 大小是第11章方法论的核心超参之一。
概念卡 3
条件数（Condition Number）
点击翻面 →
定义κ = λ_max/λ_min：Hessian 最陡与最平方向的曲率之比。
解决问题度量病态：κ 大则稳定步长 η < 2/λ_max 与慢方向速度 ηλ_min 被两头卡死。
直觉峡谷状山谷：沿壁会弹跳翻车，沿底慢如蜗牛，同一车速两头难。
误区以为发散是梯度算错——多数只是 η 越过了 2/λ_max（例中 0.025 对 0.02）。
何时用诊断训练震荡/发散的第一嫌疑；动量、Adam、BN 都在间接降 κ 的害。
概念卡 4
动量（Momentum）
点击翻面 →
定义v ← αv − ε∇J，θ ← θ + v：用梯度的指数加权平均推动参数。
解决问题病态曲面上慢方向爬行、快方向震荡——一致方向加速 1/(1−α) 倍，震荡方向抵消。
直觉小球滚下山：共识越滚越快，分歧来回撞墙平均为零。
误区α 越大越好——0.99 放大 100 倍但回头慢，ε 须同步缩小；它仍共享单一 ε。
何时用SGD 的默认搭档（α = 0.9）；视觉任务精调常胜 Adam。
概念卡 5
RMSProp（Root Mean Square Propagation）
点击翻面 →
定义r ← β₂r + (1−β₂)g²，Δθ = −εg/(√r + δ)：按历史梯度尺度逐坐标压步长。
解决问题不同参数梯度尺度悬殊、共享一个学习率两头难（8.2 的逐坐标版答案）。
直觉给每个参数装独立的油门限位：历来冲得猛的坐标自动限小。
误区以为它含动量——RMSProp 只有二阶矩缩放，无一阶平均、无偏差修正。
何时用循环网络等非平稳目标的老牌选择；今天多被 Adam 替代。
概念卡 6
Adam（Adaptive Moment Estimation）
点击翻面 →
定义一阶动量 m + 二阶缩放 v + 偏差修正 1−βᵗ，Δθ = −εm̂/(√v̂ + δ)。
解决问题把动量的"方向共识"与 RMSProp 的"逐坐标缩放"合并，并用修正治好冷启动偏 0。
直觉信噪比驱动：方向稳则 m̂/√v̂ ≈ ±1 全速走 ε，方向乱则自动减速。
误区免调学习率（ε 仍关键）；省略偏差修正（首步放大 3 倍多）；永远优于 SGD（泛化未必）。
何时用绝大多数深度学习任务的开箱默认；第9、10章训练卷积与序列模型时的起点。

📝分层习题

L1 概念辨析

某任务当前用 batch = 64 训练，梯度估计标准误为 0.05。若把 batch 翻 4 倍到 256，标准误变为多少？要再把标准误减半，batch 需要变成多少？用 √m′ 律说明这种"堆样本换精度"的策略什么时候不划算。

提示

SE = σ/√m′：m′ 翻 4 倍，√m′ 翻几倍？从 256 再让 SE 减半，√m′ 要翻几倍，对应 m′ 翻几倍？

完整解答

(1) m′ 从 64 到 256 是 ×4，√m′ 是 ×2，所以标准误减半：0.05 → 0.025。（验算：σ = 0.05×√64 = 0.05×8 = 0.4；0.4/√256 = 0.4/16 = 0.025 ✓）

(2) 再减半要求 √m′ 再 ×2，即 m′ ×4：256 × 4 = 1024。

(3) 规律：精度每提高一倍，样本量要翻 4 倍——成本平方增长、精度线性增长。当 batch 已经较大、梯度噪声已不是训练的主要瓶颈（比如病态条件、学习率设置才是瓶颈）时，继续堆样本就是拿 4 倍算力换微不足道的方向精度，远不如换用动量或自适应学习率划算。

L1 概念辨析

判断并说明理由："常数学习率的 SGD 之所以后期 loss 震荡，是因为 batch 太小；只要把 batch 调大，就能在常数学习率下收敛到精确最优点。"

提示

batch 调大让噪声变小，但能让噪声严格等于 0 吗？常数步长 × 非零噪声方差，在最优点处会发生什么？

完整解答

错。大 batch 只能按 √m′ 律压低噪声（且收益递减），除全量梯度外方差永远严格大于 0。在最优点处真实梯度为 0，更新量 −ηĝ 是均值为 0、幅度 ∝ ησ/√m′ 的随机跳动——只要 η 不衰减、噪声不为 0，参数就永远在最优点附近随机游走，无法停在精确最优点。这正是收敛条件 ∑ηt² < ∞ 的意义：噪声消不掉，只能靠步长衰减到 0 来让跳动消失。全量梯度理论上可以，但 8.1 已说明它慢到不可用，且实践中没人这么做。

L2 手算推导

换一组数重算 8.2 的病态分析：λ_max = 50、λ_min = 0.5。求：(1) 条件数与稳定步长界；(2) η = 0.05 时快方向每步误差因子与 5 步后的放大倍数；(3) η = 0.02 时快、慢方向的每步因子，以及慢方向误差降到 1/10 所需步数（精确到个位）。

提示

稳定界 η < 2/λ_max；每方向误差因子 |1 − ηλ|；步数解 |1 − ηλ_min|ⁿ = 0.1，取对数。lg 0.99 ≈ −0.004365。

完整解答

(1) κ = 50/0.5 = 100；稳定要求 η < 2/50 = 0.04。

(2) η = 0.05：快方向因子 |1 − 0.05×50| = |1 − 2.5| = 1.5；5 步放大 1.5⁵ = 1.5²×1.5²×1.5 = 2.25×2.25×1.5 = 5.0625×1.5 ≈ 7.59 倍，发散。

(3) η = 0.02：快方向 |1 − 0.02×50| = |1 − 1| = 0（一步清零）；慢方向 |1 − 0.02×0.5| = |1 − 0.01| = 0.99。解 0.99ⁿ = 0.1：n = lg 0.1 / lg 0.99 = −1/(−0.004365) ≈ 229.1，取整 230 步（0.99²³⁰ ≈ 0.099 ✓）。

对照 8.2：条件数同为 100，稳定界、慢方向步数完全相同——决定命运的只有特征值的比值与位置，不是绝对大小。

L2 手算推导

换一组数重算 8.4 的动量：α = 0.95、ε = 0.01、恒定梯度 ∇ = 1、v₀ = 0。求：(1) 前三步 v₁、v₂、v₃；(2) 稳态 v∞ 与放大倍数；(3) 对比 8.4 正文（α = 0.9、∇ = 2 → v∞ = −0.2），说明 α 与 ∇ 各自如何影响终端速度。

提示

逐代 vt = 0.95vt−1 − 0.01×1；稳态解 v∞ = −ε∇/(1−α)。

完整解答

(1) v₁ = 0.95×0 − 0.01 = −0.01；v₂ = 0.95×(−0.01) − 0.01 = −0.0095 − 0.01 = −0.0195；v₃ = 0.95×(−0.0195) − 0.01 = −0.018525 − 0.01 = −0.028525。

(2) 稳态：v∞ = 0.95v∞ − 0.01 ⟹ 0.05v∞ = −0.01 ⟹ v∞ = −0.2。放大倍数 1/(1−α) = 1/0.05 = 20 倍（裸 SGD 每步 −0.01，稳态 −0.2）。

(3) 正文 v∞ = −0.01×2/(1−0.9) = −0.02/0.1 = −0.2；本题 v∞ = −0.01×1/(1−0.95) = −0.01/0.05 = −0.2——殊途同归。规律：v∞ 与 ∇ 成正比、与 (1−α) 成反比。α 从 0.9 到 0.95，放大从 10 倍变 20 倍（代价是惯性影响从约 10 步拉长到约 20 步，调头更迟钝）；∇ 减半则终端速度等比减半。调 α 是调"放大与惯性"的权衡，改不了"速度与梯度成正比"这一基本面。

L3 建模应用

你接手一个训练现场：训练 loss 在 2.0 附近剧烈上下震荡、长期不下降，验证 loss 同步抖动。画出"现象 → 诊断 → 改法"的完整决策树，覆盖至少三条不同根因，并说明每条分支的验证方法（怎么确认诊断对了）。

提示

先区分震荡的形态：发散型（越震越大甚至 NaN）、平台抖动型（均值不降、幅度稳定）、噪声地板型（缓慢下降但锯齿密）。分别对应本章哪三节？

完整解答

决策树（参考答案）：

① loss 越震越大、出现 NaN → 病态条件 + 学习率越界（8.2）：η 超过 2/λ_max，快方向误差每步放大（如 ×1.5）。改法：学习率砍半重试；加梯度裁剪。验证：η 减半后若立刻不再发散，确诊。

② 均值不降、在固定区间来回弹 → 峡谷震荡（8.2 + 8.4）：曲率悬殊，负梯度在两壁间弹跳。改法：加动量 α = 0.9（震荡方向梯度正负交替，在指数平均中抵消），或换 Adam（快方向步长被 √v̂ 自动压缩）。验证：加动量后 loss 曲线振幅显著收窄且均值恢复下降，确诊。

③ 整体下降但锯齿密集、后期原地抖动 → 噪声地板（8.1 + 8.3）：常数学习率 × 非零梯度噪声方差，参数在最优点附近随机游走。改法：启用学习率衰减（线性降到 η₀ 的 1%），或适度调大 batch（按 √m′ 律压噪声）。验证：衰减开启后抖动幅度随 η 同步缩小、loss 再下台阶，确诊。

排查顺序理由：先看是否发散（会毁掉一切，最先排除），再看是否结构性震荡（动量/Adam 对症），最后处理噪声地板（衰减是收尾手段）。三条分支共享一个方法论：每次只改一个变量，用"改动后现象是否如预测变化"来闭环验证诊断。

自测 1
minibatch 大小从 100 增加到 10000，梯度估计的标准误大约如何变化？这说明了什么？
  • A. 缩小 100 倍——标准误与 m′ 成反比
  • B. 缩小 10 倍——标准误按 1/√m′ 下降，样本 ×100 只换精度 ×10，收益递减
  • C. 不变——标准误只取决于模型本身

自测 2
二次问题的 Hessian 特征值为 λ_max = 100、λ_min = 1，取 η = 0.025。10 步之后快方向的误差会变成原来的约多少倍？为什么？
  • A. 约 0.35 倍——η 偏小，误差正常收缩
  • B. 恰好 1 倍——误差原地踏步
  • C. 约 57.7 倍——η = 0.025 越过稳定界 2/λ_max = 0.02，每步误差乘 |1−2.5| = 1.5，1.5¹⁰ ≈ 57.7，发散
  • D. 约 0.001 倍——学习率越大收敛越快
解析：C 对——稳定要求 η < 0.02，0.025 越界；快方向因子 |1 − 0.025×100| = 1.5，10 步放大 1.5¹⁰ ≈ 57.67。A 错：0.35 是合法小步长下的收缩，不是这里的剧情。B 错：|1−ηλ| = 1 需要 ηλ = 0 或 2，0.025×100 = 2.5 两头都不沾。D 错：方向完全反了——越过稳定界后学习率越大发散越快。
自测 3
关于 SGD 的收敛条件与常数学习率，下列哪项正确？
  • A. 只要梯度估计无偏，常数学习率就能收敛到精确最优点
  • B. 收敛条件是 ∑ηt < ∞ 且 ∑ηt² = ∞
  • C. 常数学习率后期震荡是因为 batch 太小，调大 batch 即可停下
  • D. 条件是 ∑ηt = ∞ 且 ∑ηt² < ∞；常数 η 违反后者，因为最优点附近噪声方差不为零，参数永远做幅度 ∝ η 的随机游走
解析：D 对——两个条件分别保证"走得远"与"停得下"；噪声消不掉只能靠 ηt → 0 对冲。A 错：无偏只保证方向平均正确，方差仍在，常数步长把方差转成永久震荡。B 错：两个条件恰好写反了。C 错：大 batch 按 √m′ 律只能压低噪声、不能清零；要让跳动消失必须衰减 η。
自测 4
动量系数 α = 0.9、学习率 ε = 0.01、梯度恒为 2，稳态速度与"动量如何起作用"的正确说法是：
  • A. v∞ = −0.2，是裸 SGD 步长的 1/(1−α) = 10 倍；一致方向梯度在指数平均中累加，震荡方向梯度相互抵消
  • B. v∞ = −0.02，与裸 SGD 相同——动量只平滑不改变速度
  • C. v∞ = −0.2，放大 α = 0.9 倍；动量给每个参数配了独立学习率
  • D. v∞ 不存在——有动量就不收敛
解析：A 对——v∞ = −ε∇/(1−α) = −0.02/0.1 = −0.2，是裸 SGD（−0.02）的 10 倍；峡谷底加速、峡谷壁抵消正是 8.4 的手算结论。B 错：平滑的代价与收益都是放大终端速度。C 错：放大倍数是 1/(1−α) = 10 而非 α = 0.9，且逐坐标学习率是 Adam 的事，动量仍共享单一 ε。D 错：恒定梯度下递推有封闭稳态，vt → −0.2。
自测 5
Adam 第一步（g = 2，β₁ = 0.9，β₂ = 0.999，ε = 0.001）算出 m₁ = 0.2、v₁ = 0.004。若省略偏差修正，直接更新 Δθ = −ε·m₁/√v₁，结果是约 −0.00316，比修正后的 −0.001 大三倍多。偏差修正为什么不可省？

  • B. m、v 从 0 启动、初期被压向 0，且二阶矩偏差（×1/1000）比一阶矩（×1/10）严重，开根号后比例失衡；除以 1−βᵗ 把估计拉回无偏
