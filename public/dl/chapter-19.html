19.1推断为什么难：后验里的求和

第16章到第18章反复对付的是配分函数 Z——对全部状态求和。但带隐藏变量的模型（RBM、稀疏编码、第20章的深 Belief 网）还有第二笔账：训练每一步都要回答"给定可见变量 v，隐藏变量 h 最可能是什么"，也就是后验分布 p(h|v)（Posterior）。由贝叶斯公式：

p(h|v) = p(h, v)p(v)，其中 p(v) = ∑h p(h, v)

分子好算——模型定义直接给出联合概率；分母又是那个熟悉的怪兽：对全部隐藏状态求和。h 是 100 个二值变量时，这个求和有 2¹⁰⁰ ≈ 10³⁰ 项。这与配分函数是同一头怪兽的另一张脸：Z 是对全部 (h, v) 求和，p(v) 是固定 v 对全部 h 求和，都是指数级。

完整手算一个小例子，看清"能算"与"算不动"的边界。两个二值隐藏变量 h = (h₁, h₂) ∈ {0,1}²，一个二值观测 v。只看 v = 0 那一行的联合概率（未归一化的联合表）：

p(h,v=0)：h=(0,0) ↦ 0.05，(0,1) ↦ 0.10，(1,0) ↦ 0.15，(1,1) ↦ 0.20

第一步，算分母——把 4 个状态加起来：

p(v=0) = 0.05 + 0.10 + 0.15 + 0.20 = 0.5

第二步，逐个除以分母，得到后验：

p(h|v=0) = (0.050.5, 0.100.5, 0.150.5, 0.200.5) = (0.1, 0.2, 0.3, 0.4)

最可能的隐藏配置是 h = (1,1)，占后验质量 40%。为什么这里算得动？因为只有 4 个状态。把 h 换成 100 维（比如一层 RBM 隐藏单元），同样这两步就要对 2¹⁰⁰ 个状态求和再逐个相除——第17章的抽样是一类出路，本章给出另一类：不精确求和，引入一个好算的分布 q(h) 去逼近真后验。

💡 关键一跃

推断难，难在"列出所有可能性再加起来"。本章的核心思路是把这个"列表问题"换成"搜索问题"：在一族可调分布 q 里找一个最像真后验的——推断从此变成优化。这正是"变分推断"一词中"变分"的含义：在函数空间里做优化。

⚠️ 常见误区

把 p(h|v) 的难处与 Z 的难处当成两回事。其实两者同根同源：都是指数级状态空间上的求和。不同只在用途——Z 是归一化常数，训练里出现在梯度负相；p(v) 是边缘似然，推断里出现在后验分母。认清"同一头怪兽"才能理解为什么第17–19章的武器可以互相借用。

19.2把推断变成优化：ELBO 分解

上一节说了解法方向：引入近似分布 q(h)。但"逼近"要有一个可优化的目标——怎么衡量 q 离真后验有多近，又怎么把"训练模型"（最大化 log p(v)）与"逼近后验"统一起来？答案是一个只用到 Jensen 不等式一步的恒等式。定义 证据下界（ELBO, Evidence Lower Bound）：

ℒ(q) = Eh∼q[log p(h, v)] − Eh∼q[log q(h)]

它与真正的目标 log p(v) 之间只差一个 KL 散度：

log p(v) = ℒ(q) + KL( q(h) ‖ p(h|v) )

其中 KL(q‖p) = Σ_h q(h) log[q(h)/p(h|v)] ≥ 0，等号当且仅当 q = p 处处相等。于是 ℒ(q) ≤ log p(v)：ℒ 是 log 证据的下界。最大化 ℒ 同时做两件事——让 q 更接近真后验（缩小 KL），让 log p(v) 本身变大（抬高似然）。q 取到真后验时 KL = 0，下界收紧为等式。

完整手算验证这个分解。一维二值 h，固定 v，联合表 p(h=0, v) = 0.1、p(h=1, v) = 0.2。则 p(v) = 0.3，真后验 q* = (0.1/0.3, 0.2/0.3) = (1/3, 2/3)。

第一组：q = q*。ℒ = Σ_h q(h) log[p(h,v)/q(h)]：

ℒ = 13 log0.11/3 + 23 log0.22/3 = 13 log 0.3 + 23 log 0.3 = log 0.3 ≈ −1.204 ✓

下界顶满，恰好等于 log p(v)，此时 KL(q*‖p) = 0——恒等式两边严丝合缝。

第二组：q = (0.5, 0.5)（乱猜的均匀后验）。同样套定义：

ℒ = 0.5 log0.10.5 + 0.5 log0.20.5 = 0.5 log 0.2 + 0.5 log 0.4 = 0.5 log 0.08 ≈ −1.263

与 log p(v) ≈ −1.204 之间差了约 0.059——这个差不是误差，正是 KL(q‖真后验)：0.5log(0.5/(1/3)) + 0.5log(0.5/(2/3)) = 0.5log(3/4) + 0.5log(3/4)... 逐项算即得 0.059。q 越偏，下界越松；这就是"最大化 ℒ"会把 q 推向真后验的几何原因。

💡 关键一跃

整个变分推断的地基只有一句话：KL 散度非负，所以减去它的东西是个下界。ELBO 的另一张面孔是 ℒ = E_q[log p(v|h)] − KL(q(h)‖p(h))——"重建质量减去与先验的距离"，第20章 VAE 的损失函数就是这一形式的直接化身。

⚠️ 常见误区

以为最大化 ℒ 只是在逼近后验。它同时在做两件事：逼近后验（降 KL）与抬高似然（升 log p(v)）——两者共用同一个 ℒ，分不清时容易误读训练曲线。另一个误区：以为 ℒ 顶到 log p(v) 就算完了。只有 q 恰好是真后验时才顶到；q 受限于某个分布族时，ℒ 与 log p(v) 之间永远隔着一段不可消除的 KL。

19.3EM 算法：ELBO 的交替最大化

ℒ(q) 里其实住着两组可调的东西：近似分布 q 与模型参数 θ（藏在 p(h,v;θ) 里）。EM 算法（Expectation-Maximization Algorithm）是最经典的调法——坐标上升：固定一个，最大化另一个，交替进行：

  1. E 步（Expectation）：固定 θ = θ_old，对 q 最大化 ℒ。由分解式，此时 log p(v;θ_old) 不变，最大化 ℒ 等价于最小化 KL——最优解直接写出：q*(h) = p(h|v; θ_old)，即把 q 设成当前参数下的真后验，KL 归零，ℒ 顶到 log p(v;θ_old)。
  2. M 步（Maximization）：固定 q 不动，对 θ 最大化 ℒ。注意 ℒ 的第二项 E_q[log q] 与 θ 无关，只需最大化 E_q[log p(h, v; θ)]——即在当前后验下，最大化"补全数据"的完全对数似然。

为什么这套交替一定有效？看 log p(v) 的轨迹：E 步后 ℒ = log p(v;θ_old)（下界贴住当前值）；M 步增大 ℒ（θ_new 不比旧的差）——而 log p(v;θ_new) ≥ ℒ(θ_new) ≥ ℒ(θ_old) = log p(v;θ_old)。log 证据单调不降，所以 EM 必收敛（到局部最优）。

用 19.2 的小例子走一遍 E 步：设当前参数给出联合表 p(h=0,v)=0.1、p(h=1,v)=0.2。E 步令 q = (1/3, 2/3)——19.2 已算过，此时 ℒ = log 0.3，KL = 0，下界顶满。接下来 M 步拿这个 q 去重新估计 θ（比如调整联合表里的参数使 E_q[log p(h,v;θ)] 最大），完成后回到 E 步再算新后验……如此往复，log p(v) 像台阶一样一步步爬升，每一步都不允许下降。

✅ 判定规则

EM 的两个硬限制：①只保证局部最优——坐标上升爬到的是离出发点最近的山头，初值不同答案不同，实践中要多次随机初始化取最好；②精确 E 步本身可能就算不动——q* = p(h|v) 正是 19.1 那个要枚举 2ⁿ 个状态的后验！EM 把推断困难原封不动地留在了 E 步里。高维模型要用 EM，必须把 E 步也近似化——这就是 19.4 均值场登场的理由。

⚠️ 常见误区

把 E 步的"Expectation"理解成"采样平均"。E 步的名字来自 M 步里要算的期望 E_q[log p(h,v)]，而不是第17章那种蒙特卡洛采样——经典 EM 的 E 步是精确解析地写出后验。另一个误区：以为 EM 单调不降就收敛到全局最优——单调只保证不回头，不保证爬到最高的山。

19.4均值场变分推断与重参数化

19.3 的结尾留下死结：E 步要算真后验，高维算不动。均值场变分推断（Mean Field Variational Inference）的解法是限制 q 的分布族：假设各隐藏变量相互独立，

q(h) = ∏i qi(hi)

真后验几乎从不独立，所以 KL 无法归零，ℒ 顶不到 log p(v)——但换来的是可算性：在受限族内最大化 ℒ，对每个 qᵢ 轮流做坐标上升，最优更新式为：

log qi(hi) = Eq₋ᵢ[log p̃(h, v)] + const

即：固定其他所有变量的当前近似，对联合对数概率取期望，归一化后即得 qᵢ 的新值。轮流更新直到收敛——每一步 ℒ 都不降。

完整手算一步坐标更新。两个二值隐藏变量，未归一化联合（v 已观测、并入常数）：log p̃(h) = h₁h₂ ln2 + h₁ ln3。更新 q₁：

log q₁(h₁) = Eq₂[h₁h₂ ln2 + h₁ ln3] + const = h₁( ln2 · E[h₂] + ln3 ) + const

设当前 E[h₂] = 0.5。逐个取值算分值：h₁ = 1 时，分值 = 0.5·ln2 + ln3 = ln√2 + ln3 = ln(3√2)；h₁ = 0 时，分值 = 0。取指数还原成未归一化概率：q̃₁(1) = 3√2 ≈ 4.243，q̃₁(0) = 1。归一化：

q₁(1) = 3√21 + 3√2 ≈ 4.2435.243 ≈ 0.809，q₁(0) ≈ 0.191

一步完成。接着用新的 E[h₁] ≈ 0.809 去更新 q₂，如此轮流，直到 ℒ 不再上升。

均值场把推断变成了确定性的迭代优化，但还差最后一块拼图才能成为深度学习的主力：梯度怎么穿过采样传回 q 的参数。答案是重参数化技巧（Reparameterization Trick）：不直接从 N(μ, σ²) 采 z，而是先采 ε ∼ N(0,1)，再令

z = μ + σ · ε

采样结果不变（仍是 N(μ,σ²) 的样本），但 z 变成了 μ 与 σ 的确定性函数——梯度可以沿这条代数通路回传。对高斯近似后验与标准高斯先验，KL 还有闭式解，不必采样估计：

KL( N(μ,σ²) ‖ N(0,1) ) = 12( μ² + σ² − 1 − ln σ² )

手算一个数：μ = 0.5、σ = 1 时，KL = ½(0.25 + 1 − 1 − 0) = 0.125。这两项——重参数化与闭式 KL——正是第20章 VAE 损失函数里"重建项 + KL 项"的全部机关。

💡 关键一跃

均值场的本质是用独立性换可算性：把联合后验这团乱麻切成一条条独立的单变量分布，每条都能解析更新。重参数化的本质是把随机性挪到参数之外：随机节点变确定节点，反向传播畅通无阻。两个技巧一合流，就是 VAE。

⚠️ 常见误区

均值场最隐蔽的代价：独立性假设系统性低估后验方差。真后验若是"h₁h₂ 要么同 0 要么同 1"的强相关分布，均值场不敢把质量同时摊在两个峰上（独立分布做不到），只好收缩到一个峰附近——估计出的不确定性比真实的小。用均值场的后验方差做决策，会过度自信。

误区以为最大化 ℒ 只在逼近后验——它同时还在抬高似然。
何时用EM、变分推断、VAE 损失函数的统一地基。
概念卡 3
KL 散度（Kullback-Leibler Divergence）
点击翻面 →
定义KL(q‖p) = Σ q log(q/p) ≥ 0，等号当且仅当 q = p。
解决问题度量近似分布与目标分布的"距离"，撑起 ELBO 的分解。
直觉用 q 的编码描述 p 的事件，平均多花的比特数。
误区以为对称——KL(q‖p) ≠ KL(p‖q)，方向决定行为。
何时用ELBO 的缝隙、VAE 的正则项、模型比较。
概念卡 4
EM 算法（Expectation-Maximization）
点击翻面 →
定义E 步令 q = p(h|v;θ_old)，M 步最大化 E_q[log p(h,v;θ)]，交替进行。
解决问题含隐藏变量模型的经典最大似然训练框架。
直觉先猜答案（E），再按猜的答案调参数（M），反复。
误区以为单调不降 = 全局最优——只保证局部最优，初值敏感。
何时用高斯混合模型、HMM；理解变分 EM 的起点。
概念卡 5
均值场（Mean Field Approximation）
点击翻面 →
定义限制 q(h) = ∏ᵢqᵢ(hᵢ)，坐标更新 log qᵢ = E_{q₋ᵢ}[log p̃] + const。
解决问题真后验算不动时，在独立分布族内逼近后验。
直觉轮流问每个变量："给定其他人的平均看法，你该信什么？"
误区低估后验方差——独立假设不敢摊开质量，过度自信。
何时用大隐藏空间的解析推断；结构化模型的实用推断引擎。
概念卡 6
重参数化技巧（Reparameterization Trick）
点击翻面 →
定义z = μ + σ·ε，ε∼N(0,1)，把采样写成参数的确定性函数。
解决问题让梯度穿过随机采样节点回传到分布参数 μ、σ。
直觉把骰子挪到网络外面：随机性固定，参数只做变换。
误区以为只适用高斯——任何可写成 g(ε;θ) 的分布都能用。
何时用第20章 VAE 编码器的标准配置，随机深度网络的梯度通路。

📝分层习题

L1 概念辨析判断对错：最大化 ELBO 时，只要 q 的分布族足够灵活，ℒ 最终能等于 log p(v)。
提示

回忆分解式 log p(v) = ℒ + KL。ℒ = log p(v) 需要什么条件？足够灵活的 q 族能满足这个条件吗？

完整解答
对。ℒ = log p(v) 当且仅当 KL(q‖p(h|v)) = 0，即 q 恰好是真后验。q 族足够灵活（包含真后验）时，最大化 ℒ 的最优解就是真后验，下界收紧为等式。反过来，均值场这类受限族（强制独立）一般不含真后验，KL 有不可消除的剩余，ℒ 永远低于 log p(v)——灵活度决定下界的松紧。
L1 概念辨析判断对错：EM 算法保证收敛到全局最优，因为 log p(v) 每一步都不降。
提示

"单调不降"与"全局最优"是同一回事吗？坐标上升在多峰地形上会爬到哪？

完整解答
错。单调不降只保证 log p(v) 不回头、必收敛到某个驻点，但不保证那是全局最高的峰——多峰地形里，坐标上升爬到的是离初始值最近的山头。两次不同初始化可能给出不同的最终参数与不同的 log p(v)。实践中标准做法是多次随机初始化，取 log p(v) 最大的一轮结果。
L2 手算推导一维二值 h，p(h=0,v) = 0.1、p(h=1,v) = 0.2，近似后验 q = (0.4, 0.6)。(a) 计算 ℒ(q)；(b) 计算 KL(q‖真后验)；(c) 验证 log p(v) = ℒ + KL。（保留 3 位小数）
提示

真后验 = 联合/边缘 = (1/3, 2/3)。ℒ = Σ q log(p(h,v)/q(h))；KL = Σ q log(q/q*)。

完整解答
(a) ℒ = 0.4·log(0.1/0.4) + 0.6·log(0.2/0.6) = 0.4·log(0.25) + 0.6·log(1/3)
= 0.4×(−1.386) + 0.6×(−1.099) = −0.554 − 0.659 = −1.213；
(b) KL = 0.4·log(0.4/(1/3)) + 0.6·log(0.6/(2/3)) = 0.4·log(1.2) + 0.6·log(0.9)
= 0.4×0.182 + 0.6×(−0.105) = 0.073 − 0.063 = 0.010；
(c) ℒ + KL = −1.213 + 0.010 = −1.204 = log 0.3 ✓ 分解恒等式逐项吻合。
L2 手算推导log p̃(h) = h₁h₂ ln2 + h₁ ln3（二值 h₁、h₂）。当前 E[h₁] = 0.8。用均值场坐标更新式求新的 q₂(1)。（步骤写全）
提示

套 log q₂(h₂) = E_{q₁}[log p̃(h)] + const，对 h₂ = 1 与 h₂ = 0 分别算分值，再归一化。

完整解答
第一步，写出更新式：log q₂(h₂) = E_{q₁}[h₁h₂ ln2 + h₁ ln3] + const = h₂ ln2 · E[h₁] + E[h₁] ln3 + const。
注意第二项 E[h₁]ln3 不含 h₂，归入 const。
第二步，代入 E[h₁] = 0.8：h₂ = 1 的分值 = 0.8·ln2 = ln(2^0.8)；h₂ = 0 的分值 = 0。
第三步，取指数：q̃₂(1) = 2^0.8 ≈ 1.741，q̃₂(0) = 1。
第四步，归一化：q₂(1) = 1.741/(1 + 1.741) = 1.741/2.741 ≈ 0.635，q₂(0) ≈ 0.365。
对照直觉：h₁ 多半是 1，而 h₁=1 且 h₂=1 时有 ln2 的加成——所以 q₂ 被推向 1，合情合理。
L3 建模应用你要训练一个 100 个二值隐藏单元的潜变量模型。同学提议："直接用经典 EM，E 步精确算 p(h|v)。"请指出这条路为什么走不通，给出本章的可行替代方案（两套），并说明各自付出了什么代价。
提示

精确 E 步要对多少个隐藏状态求和？均值场牺牲了什么性质？重参数化 + 神经网络（摊销推断）牺牲了什么换来什么？

完整解答
走不通的原因：精确 E 步 q*(h) = p(h|v;θ_old) 的分母要对 2¹⁰⁰ ≈ 10³⁰ 个隐藏状态求和，每个训练样本、每一轮迭代都要做一次——计算上完全不可行。
替代一：均值场变分推断。限制 q(h) = ∏ᵢqᵢ(hᵢ)，坐标上升轮流更新（log qᵢ = E_{q₋ᵢ}[log p̃] + const），每步解析可算。代价：独立性假设与真后验有不可消除的 KL 缝隙，且系统性低估后验方差。
替代二：摊销推断 + 重参数化（即第20章 VAE 路线）。用一个神经网络（编码器）从 v 直接输出 q 的参数 (μ, σ)，z = μ + σ·ε 让梯度穿过采样，端到端最大化 ELBO。代价：q 受限于编码器能表达的分布族（摊销缝隙），且引入采样噪声；换来的是所有样本共享一次前向的推断成本，训练可用 SGD。
两案共同的哲学：精确推断不可行，就接受一个有界的近似缝隙，换可扩展性。

自测 1
后验 p(h|v) 难以精确计算的根本原因是？
  • A. 联合概率 p(h,v) 没有解析表达式
  • B. 分母 p(v) = Σ_h p(h,v) 要对指数多个隐藏状态求和
  • C. 贝叶斯公式在高维不成立
  • D. 隐藏变量之间必然存在连续取值
解析：B 对——难点全在分母的边缘化求和，n 个二值隐藏单元就是 2ⁿ 项。A 错：联合概率由模型定义直接给出，恰恰是好算的那部分；C 错：贝叶斯公式在任何维度都成立，失效的是计算能力不是公式；D 错：离散隐藏变量同样算不动，困难来自状态数而非取值类型。
自测 2
关于 ELBO 与 log p(v) 的关系，正确的是？
  • A. ℒ(q) ≤ log p(v)，等号当且仅当 q 等于真后验
  • B. ℒ(q) ≥ log p(v)，因为 KL 散度非负
  • C. ℒ(q) = log p(v) 恒成立，与 q 无关
  • D. ℒ(q) ≤ log p(v)，等号当且仅当 q 是均匀分布
解析：A 对——log p(v) = ℒ + KL，KL ≥ 0 给出下界，KL = 0（q = 真后验）时收紧。B 把不等式方向说反了：KL 非负恰恰是"砍掉非负项剩下的是下界"，不是上界；C 错：等式只在 q 恰好为真后验时成立，一般 q 留有一段 KL 缝隙；D 错：均匀分布与真后验毫无必然关系，等号条件只看 q 是否等于真后验。
自测 3
KL(q‖p) = 0 的充要条件是？
  • A. q 与 p 的均值相等
  • B. q 与 p 的方差相等
  • C. q 与 p 处处相等（同一分布）
  • D. q 是 p 的均值场近似
解析：C 对——KL 是分布间的度量，为零当且仅当两个分布完全相同。A 和 B 错：均值、方差相等只是矩匹配，分布形状仍可以天差地别，KL 照样很大；D 错：均值场近似受独立性约束，一般无法等于真后验，KL 恰好不为零——这正是受限族的近似缝隙。
自测 4
EM 算法中，E 步与 M 步分别做什么？
  • A. E 步更新模型参数，M 步计算后验分布
  • B. E 步从后验采样 n 个样本，M 步用样本平均更新参数
  • C. E 步与 M 步都最大化 ℒ，但 E 步用梯度下降、M 步用坐标上升
  • D. E 步固定 θ 令 q = p(h|v;θ_old)，M 步固定 q 最大化 E_q[log p(h,v;θ)]
解析：D 对——E 步把 q 顶到当前参数下的真后验（KL 归零），M 步在固定 q 下更新 θ，两步都是对 ℒ 的坐标上升。A 恰好把两步说反了；B 错：经典 EM 的 E 步是解析写出后验，不是采样——那是蒙特卡洛 EM 的变体；C 错：两步都不用梯度下降，E 步有闭式解 q* = p(h|v;θ_old)，M 步通常也是解析或凸优化。
自测 5
均值场的坐标更新式 log qᵢ(hᵢ) = E_{q₋ᵢ}[log p̃(h,v)] + const 来自？
  • A. 对 p(h|v) 做重要性采样
  • B. 在独立分布族 q = ∏ᵢqᵢ 内最大化 ℒ，对 qᵢ 求变分置零
  • C. 对 log p(v) 做泰勒展开保留一阶项
  • D. Gibbs 采样一步的接受率推导
解析：B 对——把 ℒ 视为各 qᵢ 的泛函，固定其余 q₋ᵢ 对 qᵢ 求变分（加归一化约束）置零，即得该更新式。A 错：更新式是解析的坐标上升，与采样无关；C 错：这里没有泰勒展开，推导用的是变分法；D 错：Gibbs 是第17章的采样方法，更新的是"状态"而非"分布参数"，公式长得像（都用条件信息）但来源完全不同。
