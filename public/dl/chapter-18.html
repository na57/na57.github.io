18.1梯度里的两只拳头：正相与负相

第17章的结尾我们留下一句话：MCMC 能近似负相，但每一步训练都跑一条长链太贵。要看清贵在哪、以及后面三节的替代方案为什么可行，得先把对数似然的梯度拆开来看。对无向模型 p(x) = p̃(x)/Z，对数似然对参数 θ 的梯度是：

∇θ log p(x) = ∇θ log p̃(x) − ∇θ log Z

第一项叫正相（Positive Phase）：只涉及当前数据点，直接对未归一化能量求梯度，便宜。第二项叫负相（Negative Phase）：因为 Z = Σₓ p̃(x) 要对全状态求和，可以证明 ∇log Z = E_{x∼p}[∇log p̃(x)]——一个模型分布下的期望，要从模型里采样才能估计，贵得离谱。

完整手算一个最小例子。单变量二态模型 p̃(x) = e^{θx}，x ∈ {0,1}。配分函数 Z = e^{θ·0} + e^{θ·1} = 1 + e^θ。设 θ = 0，此时 p(0) = p(1) = 1/2，分布均匀。数据点 x = 1：

正相： ∂ log p̃(x)∂θ = ∂(θx)∂θ = x = 1
负相： Ep[x] = 0 · 12 + 1 · 12 = 0.5
总梯度： 1 − 0.5 = 0.5

三步走完。直觉非常直白：正相把数据点的能量往下压（让模型更相信见过的样本），负相把模型在全空间上的能量往上抬（防止所有状态的概率一起膨胀），两者相减才是净效果。梯度 0.5 > 0，说明该增大 θ——正是"让 x=1 更可能"的方向。

💡 关键一跃

正相与负相是一场拔河：正相只看数据，负相要看遍模型。训练无向模型的全部麻烦都集中在负相那一项——它需要"从当前模型采样"，而当前模型正是我们在训练的东西。后面三节的所有技巧，本质都是在说：负相这个期望，能不能不算、或者便宜地算？

⚠️ 常见误区

把负相当成"正则项"或"惩罚项"随便丢掉。错。丢掉负相，模型会让所有状态的 p̃ 一起膨胀、log p̃ 单调上升但 p 永远不变——你训练了个寂寞。负相不是可选项，它是归一化的化身：正是它逼模型在"抬高数据"与"压低他处"之间做权衡。

18.2伪似然：把联合换成一排条件

上一节给了两相分解，但它带出一个问题：负相需要对全空间求和，能不能干脆换一个不含全局 Z 的目标？伪似然（Pseudo-Likelihood）的答案是：不优化联合似然，改为优化每个变量的条件似然之和。

log 伪似然 = ∑i log p(xi | x−i)

关键在于：每个条件分布里只对一个变量求归一化，Z 从"对 2ⁿ 个状态求和"变成"对当前变量的几个取值求和"——二值变量时就是两项相加，便宜到可以解析计算。

完整手算。两个二值变量 x₁, x₂ ∈ {0,1}，模型 p̃(x₁,x₂) = e^{θx₁x₂}，数据点 (1,1)。条件分布：

p(x₁=1 | x₂=1) = e^θe^θ + e^0 = e^θ1 + e^θ = σ(θ)

σ 是 sigmoid。对 θ 求导：∂log σ(θ)/∂θ = 1 − σ(θ)。θ = 0 时 σ(0) = 0.5，导数为 1 − 0.5 = 0.5。对称地，p(x₂=1|x₁=1) 那一项也贡献 0.5。伪似然梯度合计 = 0.5 + 0.5 = 1.0。对比：同一数据点的精确似然梯度是 1 − E[x₁x₂] = 1 − 0.25 = 0.75——伪似然把同一个数据点用了两次，数值上偏大，但方向一致。

💡 关键一跃

伪似然的赌注是：联合分布难归一，条件分布好归一。把"这个家像不像真的"拆成 n 个"给定邻居、这间屋子像不像真的"，每个子问题都能解析求解。虽然伪似然不等于似然，但在很多场景下它给出一致估计——n 趋于无穷时收敛到真参数。

⚠️ 常见误区

以为伪似然就是似然的另一种写法。不是。伪似然把每个数据点重复使用 n 次，目标函数本身已经换了；它估计出的参数在有限样本下有偏，只是渐近一致。另一个误区：以为伪似然总能替代似然——当变量强耦合、条件分布不能刻画全局结构时，伪似然会给出误导性答案。

18.3对比散度：只跑 k 步的短链（CD-k）

上一节把联合换成了条件，但它带出一个问题：伪似然改变了目标，不是似然了。能不能保留似然目标，只把负相那个 MCMC 近似做得更便宜？对比散度（Contrastive Divergence, CD-k）是 Hinton 的著名赌注：负相期望用从数据点出发、只跑 k 步的 Gibbs 链得到的样本去估计。这些没收敛的样本叫幻想粒子（Fantasy Particles）——它们离平稳分布还远，但方向足够对。

完整手算 CD-1。模型 p̃(x₁,x₂) = e^{θx₁x₂}，数据 (1,1)，θ = 0。从数据点 (1,1) 出发跑一步 Gibbs：

  1. 第 1 步：固定 x₂=1，更新 x₁。p(x₁=1|x₂=1) = σ(θ) = σ(0) = 0.5。设随机数让我们采到 x₁=1 → 状态仍 (1,1)；
  2. 第 2 步：固定 x₁=1，更新 x₂。p(x₂=1|x₁=1) = σ(0) = 0.5。设这次采到 x₂=0 → 幻想粒子 = (1,0)。

CD-1 梯度 = 数据统计 − 幻想粒子统计：

∇θCD-1 = x₁数据x₂数据 − x₁幻想x₂幻想 = 1×1 − 1×0 = 1.0

对比精确负相：θ=0 时四个状态 (0,0),(0,1),(1,0),(1,1) 各 1/4，E[x₁x₂] = 1/4，精确梯度 = 1 − 0.25 = 0.75。CD-1 给出 1.0——方向对，数值偏大。这就是 Hinton 的赌注：训练早期方向对就够，偏差点没关系，反正下一批数据来了还会修正。

💡 关键一跃

CD 的深刻之处在于重新定义了"好近似"：不需要链收敛，只需要梯度方向有用。从数据点出发跑 k 步，样本必然比模型分布更"像数据"——于是负相被低估、梯度被放大，但这个放大恰好指向增大数据似然的方向。训练 RBM 的标准配方就是 CD-1 或 CD-10，便宜到可以塞进深度学习的 SGD 循环。

⚠️ 常见误区

以为 CD 是似然梯度的无偏近似。错。除非 k → ∞（链收敛），CD 不是任何似然目标的梯度——它是个有偏但便宜的替代。实践含义：用 CD 训练时不能拿训练似然当收敛指标（它可能上升也可能抖动），要看重建误差或在验证集上的表现。另一个坑：k 太小链走不远，模型分布在远离数据的区域永远得不到负相压制，可能出现"远处概率质量偷偷膨胀"的病态。

18.4得分匹配与噪声对比估计

上一节的 CD 还是要跑链（哪怕短），而且引入了系统性偏差。这一节给两个更激进的方案：干脆让 Z 在目标函数里彻底消失。

第一个是得分匹配（Score Matching）。定义 score 为对数密度对 x 的梯度：∇ₓ log p(x)。注意恒等式：

∇x log p(x) = ∇x log p̃(x) − ∇x log Z = ∇x log p̃(x)

为什么第二项是零？log Z 是常数，对 x 求导恒等于 0。所以模型的 score 与 Z 无关。得分匹配的目标是最小化模型 score 与数据 score 之间的均方误差：

J(θ) = Ex∼pdata[ ||∇x log pmodel(x) − ∇x log pdata(x)||² ]

问题是我们不知道数据的 score。Hyvärinen 的关键洞察：用分部积分展开上式，交叉项可以改写为只含模型 score 的二阶导，目标等价于

J(θ) = Epdata[ ½||∇x log pmodel||² + tr(∇x² log pmodel) ] + 常数

——只含模型量的期望，Z 彻底消失。

完整手算一个一维例子。模型是高斯 N(μ, 1)，真实数据均值 μ* = 2。模型的 score 是 ∇ₓ log p(x) = −(x−μ)。真实 score 是 −(x−2)。两者差为 (x−2)−(x−μ) = μ−2，与 x 无关。均方误差 = (μ−2)²，加 ½ 系数：J(μ) = ½(2−μ)²。最优解 μ = 2，精确恢复真值，全程没有 Z 出场（尽管高斯的 Z 本来就算得出）。

第二个是噪声对比估计（Noise Contrastive Estimation, NCE）。思想一句话：把"估计密度"改写成"区分真样本与噪声样本"的二分类问题。真样本标签 1（来自 p_data），噪声标签 0（来自一个简单分布 p_noise，如高斯或均匀）。训练一个 logistic 分类器，让它输出 P(标签=1|x)；可以证明当分类器最优时，它隐含的密度比恰好是 p_data/p_noise——把模型密度当作分类器里的未知参数（连带 Z 一起当作可学习的标量参数）训练即可。

💡 关键一跃

两个方法的共同点：换一个让 Z 变得无害的目标。得分匹配利用"Z 对 x 的导数为零"让它在 score 里消失；NCE 把 Z 升级成一个显式参数，让分类任务自己学出它。深度学习里 NCE 的后代无处不在——word2vec 的负采样就是它的简化版。

⚠️ 常见误区

得分匹配的代价：目标里有模型的二阶导（Hessian 的迹），高维下计算昂贵——这是它没能取代 CD 成为 RBM 标配的原因。NCE 的坑：估计质量严重依赖噪声分布选得好不好——噪声太简单，分类器学到的是平凡特征；噪声太难，又训不动。经验法则：噪声应尽可能接近数据分布但又保持好采样。

解决问题不碰 Z：score 里 ∇ₓ log Z = 0，归一化常数自动消失。
直觉不匹配密度本身，匹配密度的"坡度"——坡度对了形状就对。
误区以为免费午餐——目标里有 Hessian 的迹，高维下比 CD 更贵。
何时用连续能量模型；近年扩散模型的去噪得分匹配是它的现代化身。
概念卡 6
噪声对比估计（Noise Contrastive Estimation, NCE）
点击翻面 →
定义把密度估计改写为区分真样本与噪声样本的 logistic 二分类。
解决问题归一化难题：把 Z 升级为分类器内部一个可学习参数，与模型一起训练。
直觉学不会"长什么样"，就先学会"不像什么"——分类边界隐含密度比。
误区噪声分布随便选——噪声太简单分类器学到平凡特征，太难训不动。
何时用word2vec 负采样、语言模型大词表 softmax 的替代、自监督对比学习的祖先。

📝分层习题

L1 概念辨析判断对错：对比散度 CD-k 是对数似然梯度的无偏估计，只要样本量够大就能收敛到真梯度。
提示

CD 用跑 k 步的链代替收敛的链。k 有限时，幻想粒子的分布等于模型的平稳分布吗？

完整解答
错。CD 用的是只跑 k 步的短链样本，其分布与模型的平稳分布有系统差异——偏差不会随样本量增加而消失，只会随 k 增大而缩小。除非 k→∞（链真正收敛），CD 不是任何似然目标的梯度。它是有偏但方向有用的近似：Hinton 的赌注是训练早期方向对就够，偏差点由后续批次修正。
L1 概念辨析判断对错：伪似然之所以便宜，是因为它用一个解析公式逼近联合分布的 Z。
提示

伪似然优化的还是联合似然吗？每个条件分布 p(xᵢ|x₋ᵢ) 的归一化要对多少项求和？

完整解答
错。伪似然根本不逼近 Z——它把目标函数换成了条件似然之和 Σᵢ log p(xᵢ|x₋ᵢ)。便宜的来源是：每个条件分布只对一个变量的取值求和（二值变量就是两项），归一化从"对 2ⁿ 个状态"变成"对当前变量的几个取值"，可解析计算。代价是目标不再是似然，同一数据点被重复使用 n 次。
L2 手算推导单变量二态模型 p̃(x) = e^{θx}，x∈{0,1}，数据点 x=1。(a) 写出 Z(θ)；(b) 求 θ=0 时的正相、负相、总梯度；(c) 求 θ=1 时的负相（保留两位小数），并解释它为什么变大。
提示

(a) Z = e^{θ·0} + e^{θ·1}；(b) 正相 = x，负相 = E_p[x]；(c) θ 变大时 p(1) 怎么变？

完整解答
(a) Z(θ) = 1 + e^θ；
(b) θ=0 时 p(0)=p(1)=1/2。正相 = ∂(θx)/∂θ = x = 1；负相 = E[x] = 0×0.5 + 1×0.5 = 0.5；总梯度 = 1 − 0.5 = 0.5；
(c) θ=1 时 p(1) = e/(1+e) ≈ 2.718/3.718 ≈ 0.731，负相 = E[x] = 0×(1−0.731) + 1×0.731 ≈ 0.73。
物理解释：θ 越大模型越相信 x=1，E[x] 越接近 1；总梯度 1−0.73=0.27 比 θ=0 时的 0.5 小——这正是梯度下降的"自我刹车"：参数越接近让模型匹配数据的程度，梯度越小。
L2 手算推导两个二值变量模型 p̃(x₁,x₂) = e^{θx₁x₂}，θ=0，数据 (1,1)。一次 CD-1：第 1 步固定 x₂=1 更新 x₁，采到 x₁=1；第 2 步固定 x₁=1 更新 x₂，采到 x₂=1。(a) 幻想粒子是什么？(b) 本次 CD-1 梯度是多少？(c) 与课文中采到 x₂=0 的情形（梯度 1.0）对比，说明什么？
提示

(a) k 步 Gibbs 后的状态；(b) 数据统计 − 幻想统计；(c) 两次结果不同——CD 是随机估计量，想想"期望意义下"与"单次实现"。

完整解答
(a) 幻想粒子 = (1, 1)（两步都没改动，恰好回到数据点）；
(b) CD-1 梯度 = x₁数据x₂数据 − x₁幻想x₂幻想 = 1×1 − 1×1 = 0；
(c) 本次梯度 0，课文那次梯度 1.0——CD 是随机估计量，单次实现波动大。期望意义下：θ=0 时四个状态各 1/4，E[幻想粒子的 x₁x₂] 介于数据统计与平稳分布之间，平均梯度为正但小于 1.0。这暴露 CD 的实践特点：单样本梯度噪声极大，必须配合小学习率或多幻想粒子平均（PCD/mini-batch）。
L3 建模应用你要训练一个 784 维二值 RBM（MNIST），手头有第17章的 MCMC 工具箱与本章的四件武器。请为"训练循环里的负相"选一个方案，说明：①选哪个、为什么；②排除其他三个的理由各一句；③给出两个这个方案在 RBM 上的具体实践风险。
提示

逐件检查：伪似然在 784 个变量上的成本？得分匹配的二阶导在 784 维上多大？NCE 的噪声分布要怎么选？CD 的 k 步链在 RBM 的块结构下好不好走？

完整解答
选 CD-k（块 Gibbs，k=1 或 10）。
排除：①伪似然——784 个条件分布每个都要算一次，虽然每个便宜但总数大，且 RBM 的隐藏单元使条件结构复杂；②得分匹配——目标含 784×784 Hessian 的迹，每个训练步都要算二阶导，成本爆炸；③NCE——要为 784 维二值数据设计一个既接近数据又好采样的噪声分布，没有显然答案。
CD 流程：从 mini-batch 数据点初始化可见层 → 块 Gibbs 交替采样隐藏层（p(hⱼ|v) = σ(Wⱼv + bⱼ)）与可见层 → k 步后取状态算幻想统计 → 数据统计 − 幻想统计 = 梯度。
两个风险：①k 太小，模型在远离数据的区域概率质量偷偷膨胀（"暗物质"问题），生成样本出现伪影；②单样本梯度噪声极大，需 mini-batch 平均或 PCD（把上批的幻想粒子留作本批起点）稳住训练。

✍️本章自测

点击选项判分，答错会给出原因。

自测 1
对无向模型 p = p̃/Z，对数似然梯度 ∇log p 中的"负相"指的是？
  • A. −∇log p̃，即对未归一化能量取负
  • B. ∇log Z = E_{x∼p}[∇log p̃]，模型分布下的期望
  • C. 数据分布下 ∇log p̃ 的期望
  • D. 正则化项，防止参数过大
解析：B 对——负相 = ∇log Z，而 Z 是 p̃ 的全状态求和，其梯度等于模型分布下的期望，需要从模型采样才能估计。A 错：那是把 p̃ 取负，与 Z 无关；C 错：数据分布下的期望是正相的另一形式，恰好说反；D 错：负相不是正则项，它是归一化的化身，丢掉它训练空转。
自测 2
伪似然比精确似然便宜的根本原因是？
  • A. 它用一个更小的模型近似原模型
  • B. 它丢弃了相关性强的变量
  • C. 每个条件分布的归一化只对单个变量的取值求和，可解析计算
  • D. 它用蒙特卡洛采样近似 Z
解析：C 对——伪似然 = Σᵢ log p(xᵢ|x₋ᵢ)，每个条件分布只对 xᵢ 的取值求和（二值时两项），Z 从指数级求和变成几项相加。A 错：模型本身没换；B 错：没有丢变量，每个变量都被轮到；D 错：那是第17章 MCMC 的思路，伪似然恰恰是为了避开采样。
自测 3
模型 p̃(x₁,x₂) = e^{θx₁x₂}，θ=0，数据 (1,1)，一次 CD-1 得到幻想粒子 (1,0)。本次 CD-1 梯度是？
  • A. 1.0
  • B. 0.75
  • C. 0.5
  • D. 0
解析：A 对——CD 梯度 = 数据统计 − 幻想统计 = 1×1 − 1×0 = 1.0。B 错：0.75 是精确似然梯度（1 − E[x₁x₂] = 1 − 0.25），那是用收敛分布算的结果，不是 CD-1；C 错：0.5 是伪似然单项的梯度，张冠李戴；D 错：0 对应幻想粒子恰等于数据点的情形（本课习题 L2 第二题），不是这里。
自测 4
得分匹配能让配分函数 Z 从目标函数中消失，关键是因为？
  • A. 它用蒙特卡洛采样估计 Z 并代入
  • B. 它假设 Z 等于 1（自归一化）
  • C. 它把 Z 当作可学习参数，让优化器自己学
  • D. score 里 ∇ₓ log Z = 0——log Z 是常数，对 x 求导恒为零
解析：D 对——∇ₓ log p = ∇ₓ log p̃ − ∇ₓ log Z，第二项因 Z 不依赖 x 而恒为零，所以模型的 score 与 Z 无关，匹配 score 就自动绕开了 Z。A 错：那是第17章思路；B 错：自归一化是另一个技巧（且往往不成立），不是得分匹配；C 错：把 Z 当可学习参数是 NCE 的做法，与得分匹配无关。
自测 5
噪声对比估计（NCE）的核心思想是？
  • A. 用蒙特卡洛采样估计负相，链跑 k 步
  • B. 把密度估计改写为"区分真样本与噪声样本"的二分类，Z 变成可学习参数
  • C. 用伪似然替代似然，绕开全局归一化
  • D. 用噪声扰动数据，做数据增强
解析：B 对——NCE 训练一个 logistic 分类器区分真样本（标签 1）与噪声样本（标签 0），最优分类器隐含密度比 p_data/p_noise，Z 作为分类器内部一个标量参数被一并学出。A 错：那是 CD；C 错：那是伪似然；D 错：数据增强不解决配分函数问题，与 NCE 的思想完全不同。

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：训练含配分函数 Z 的无向模型时，负相 ∇log Z 是模型分布下的期望，精确算不动、用第17章的 MCMC 跑长链又太贵——本章解决"怎样不算精确 Z 也能拿到好用的训练梯度"。
句2：核心机制是什么？——
参考答案：四件武器——伪似然把联合似然换成一排条件似然（Z 局部可算）；对比散度 CD-k 用从数据点出发跑 k 步的短链样本（幻想粒子）近似负相，有偏但方向对；得分匹配改匹配 score，利用 ∇ₓ log Z = 0 让 Z 自动消失；NCE 把密度估计改写成真/噪声二分类，把 Z 升级为可学习参数。
句3：它和前后章怎么分工？——
参考答案：第17章给的是"采样近似 Z"的通用武器，本章给的是"绕开 Z"的专用武器，其中 CD-k 内部的采样器就是第17章的 Gibbs；但本章的目标都被改造过（伪似然≠似然，CD 有偏，SM/NCE 换了目标），第19章走向更系统的"换目标"——变分推断，把推断也变成优化。
