14.1欠完备自编码器：自己当自己的老师

第13章的线性因子模型用"隐变量 h 生成 x"的概率视角解释数据结构，但它留了一个工程味十足的问题：如果不写概率模型，能不能直接训一个网络把数据的结构"挤"出来？自编码器就是这条路的答案。它的思路朴素得近乎狡猾：没有老师，就自己当自己的老师——让网络预测输入本身。

一个自编码器（Autoencoder）由两半组成：编码器（Encoder）f 把输入 x 压成内部表示 h = f(x)，解码器（Decoder）g 再把 h 还原成 x̂ = g(h)。训练目标是让输出尽量等于输入，即最小化重构误差（Reconstruction Error）：

L(x, g(f(x))) = ‖x − x̂‖²

光看这个目标会觉得荒唐：恒等函数 g(f(x)) = x 不就是零误差吗，能学到什么？学问全在限制上。最经典的限制是让中间表示 h 的维度小于输入维度 d——h 是一道瓶颈（Bottleneck），这样的自编码器叫欠完备自编码器（Undercomplete Autoencoder）。数据被迫挤过窄门，网络只好学"哪些信息最值得保留"：就像把一节课压缩成三行笔记，你必须抓住主干。

定理直觉：线性自编码器与 PCA 的关系

如果编码器和解码器都是线性的（f(x) = Wx，g(h) = Wᵀh 之类），损失用均方误差，那么可以证明（推导要点见下）：最优解 h 张成的子空间与 PCA 的主子空间相同。也就是说，线性自编码器学到的东西和主成分分析（PCA）是同一片"最优低维子空间"——但有一个重要差别：自编码器学到的基向量不必正交、不必归一，只要张成同一空间就行；PCA 则强制基正交且按方差排序。

推导要点（知道结论即可，不必背）：MSE 损失对权重求梯度并令其为零，得到的驻点条件等价于"解码矩阵的列空间 = 数据协方差矩阵前 k 个特征向量张成的空间"；任何可逆变换作用在 h 上再被解码器抵消，损失不变——所以解在一整个等价类里，只钉死了子空间，钉不死基。

💡 关键一跃

线性自编码器 ≈ PCA，这听起来是坏消息（"就这？"），其实是好消息：它说明自编码器的训练目标在最简单的情形下与经典方法一致，而一旦把 f、g 换成非线性网络，自编码器立刻获得 PCA 没有的能力——学弯曲的流形。PCA 是线性自编码器的特例，不是反过来。

手算例 1：h = 1 瓶颈下的重构误差

取二维数据点 x⁽¹⁾ = (2, 0.4)，x⁽²⁾ = (0, −0.3)，x⁽³⁾ = (−2, −0.1)。设编码向量 w = (1, 0)（把输入投到第一坐标轴上），即编码 h = w·x；解码器用同一向量重构 x̂ = h·w。逐点计算：

点编码 h = w·x重构 x̂ = h·w残差 x − x̂平方误差 ‖x − x̂‖²
(2, 0.4)h = 1×2 + 0×0.4 = 2x̂ = 2×(1,0) = (2, 0)(0, 0.4)0² + 0.4² = 0.16
(0, −0.3)h = 1×0 + 0×(−0.3) = 0x̂ = 0×(1,0) = (0, 0)(0, −0.3)0² + (−0.3)² = 0.09
(−2, −0.1)h = 1×(−2) + 0×(−0.1) = −2x̂ = −2×(1,0) = (−2, 0)(0, −0.1)0² + (−0.1)² = 0.01

总重构误差 = 0.16 + 0.09 + 0.01 = 0.26，平均 MSE = 0.26 ÷ 3 ≈ 0.087。注意看：每个点的第一坐标都被完美保留，第二坐标被全部丢弃——残差永远只在被丢掉的维度上。这三个点本来就几乎躺在 x 轴附近（第二坐标都很小），所以损失不大。这就是"PCA 投影到手算层面"的样子：w = (1, 0) 正好是数据方差最大的方向。

⚠️ 常见误区

"瓶颈只是压缩手段，越窄越好"——错。瓶颈宽度是信息预算：h 太窄，连数据的真实维度都装不下，重构误差会系统性偏大，等于强迫网络扔掉有用结构。选 h 的原则是"略大于数据的本征维度"，而不是"能压多窄压多窄"。

14.2过完备的危险与正则化自编码器家族

上一节靠瓶颈挡住了恒等复制。但如果任务需要 h 的维度大于等于 d（过完备，Overcomplete）呢？麻烦立刻出现：维度够宽时，网络可以原封不动把 x 搬进 h 再原样搬出，重构误差为零，却什么都没学到——它作弊成功了。要救回过完备情形，不能只靠"窄"，得靠惩罚：在损失里加正则项 Ω(h)，让"偷懒的恒等"付出代价。这就引出正则化自编码器三兄弟。

① 稀疏自编码器：让每个隐单元大多数时候闭嘴

稀疏自编码器（Sparse Autoencoder）在重构误差外加一项稀疏惩罚 Ω(h)，强迫每个隐单元的平均激活很低。常用做法是：对 sigmoid 隐单元 j，设它在整个训练集上的平均激活 ρ̂ⱼ，要求它接近一个稀疏目标 ρ（如 0.05），用 KL 散度（Kullback-Leibler Divergence）度量偏离：

Ω(h) = ∑j KL(ρ ‖ ρ̂ⱼ)，其中 KL(ρ ‖ ρ̂ⱼ) = ρ logρρ̂ⱼ + (1 − ρ) log1 − ρ1 − ρ̂ⱼ

手算例 2：一次 KL 稀疏惩罚。设 ρ = 0.05，某隐单元在 4 个样本上的激活为 0.9, 0.02, 0.01, 0.88。取近似对数值：log 2 ≈ 0.693，log 5 ≈ 1.609，log 20 ≈ 3.00。

步骤算式结果
1. 算平均激活 ρ̂ⱼ(0.9 + 0.02 + 0.01 + 0.88) ÷ 4 = 1.81 ÷ 4ρ̂ⱼ = 0.4525
2. 算第一项 ρ log(ρ/ρ̂ⱼ)0.05 × log(0.05 ÷ 0.4525) = 0.05 × log(0.1105)log(0.1105) ≈ −2.20 ⟹ ≈ −0.110
3. 算第二项 (1−ρ) log((1−ρ)/(1−ρ̂ⱼ))0.95 × log(0.95 ÷ 0.5475) = 0.95 × log(1.735)log(1.735) ≈ 0.551 ⟹ ≈ 0.524
4. 相加−0.110 + 0.524KL ≈ 0.414

0.414 是个不小的惩罚：这个单元在 4 个样本里激活了 2 次（平均 0.45），离"每 20 个样本才激活一次"的目标太远，损失会逼它变懒。对比理想情形：若 ρ̂ⱼ = ρ = 0.05，则两个分式都等于 1，log 1 = 0，KL = 0——零惩罚。惩罚非负、且在 ρ̂ⱼ = ρ 时取零，正是 KL 散度的性质。

② 去噪自编码器：把脏输入还原成干净输入

去噪自编码器（Denoising Autoencoder，DAE）换了堵法：不限制 h，而是污染输入——把 x 加噪成 x̃（比如随机把一些像素置零，或加高斯噪声），让网络重构出干净的 x：最小化 L(x, g(f(x̃)))。这时恒等复制无利可图——照抄 x̃ 只会把噪声也抄下来，误差反而大。要拿到低损失，网络必须学会"数据长什么样"，把不属于数据流形的噪声推回去。几何上说，DAE 学到的是指向数据流形的修正方向：对任何偏离流形的点，它都知道该往哪挪。

③ 收缩自编码器：让编码器对微小扰动不敏感

收缩自编码器（Contractive Autoencoder，CAE）更直接：惩罚编码器在 x 处的雅可比矩阵的 Frobenius 范数平方 ‖J_f(x)‖²_F，即让所有偏导 ∂hᵢ/∂xⱼ 的平方和尽量小。含义：输入动一小步，h 几乎不动——编码器对无用扰动"收缩"了敏感度，只保留对流形切方向的响应。在 sigmoid 激活下有个漂亮的化简：∂hᵢ/∂xⱼ = hᵢ(1 − hᵢ)Wᵢⱼ，所以

‖J_f(x)‖²_F = ∑i (hᵢ(1 − hᵢ))² ∑j Wᵢⱼ²

惩罚项把"激活接近 0.5（最不饱和、最敏感）"的单元压向 0 或 1，把大权重的连接削小——网络自发选择"对哪些方向装聋作哑"。

💡 关键一跃

三种正则看似不同，目标却一致：在"容量足够作弊"时，用惩罚把作弊的解排除掉。稀疏让 h 变得难得激活，去噪让 f 对噪声不敏感，收缩让 f 的导数在数据流形外趋零——都在回答同一个问题："什么样的 h 才算真正抓住了结构？"

⚠️ 常见误区

"DAE 和 CAE 是一回事"——目标相近（都让编码器鲁棒），机制不同：DAE 靠训练数据里真的注入噪声逼出鲁棒性，是数据层面的手段；CAE 靠解析地惩罚雅可比，是模型层面的手段。DAE 不需要算导数，CAE 不需要造噪声；实践中 DAE 更常用，CAE 的理论刻画更干净。

14.3稀疏编码与自编码器的关系：推断被"摊销"了

上一节的稀疏自编码器让人想起一个更早的名字：稀疏编码（Sparse Coding）。两者容易混淆，但骨架完全不同。稀疏编码是一个两步优化：给定字典 D（一组基向量），对每个样本 x 先做一次推断——解一个带 L1 惩罚的优化，找出稀疏表示 h* = argminh ‖x − Dh‖² + λ‖h‖₁；再固定所有 h*，优化字典 D 本身。每一步推断都是一次完整的内层优化，没有"前馈"这回事。

手算例 3：为什么 L1 推断选单列而不是混合

设字典 D 有两列单位向量 d₁、d₂，夹角 60°（所以 d₁·d₂ = cos 60° = 0.5），样本 x 正好在 d₁ 方向上，取 x = d₁。比较两个候选表示（令重构项相同或相近时比 L1 代价）：

候选 h重构 Dh重构误差 ‖x − Dh‖²L1 代价 λ‖h‖₁总目标
h_a = (1, 0)1·d₁ + 0·d₂ = d₁‖d₁ − d₁‖² = 0λ(1 + 0) = λλ
h_b = (0.5, 0.5)0.5(d₁ + d₂)见下方计算 ≈ 0.134λ(0.5 + 0.5) = λ0.134 + λ

h_b 的重构误差计算：‖0.5(d₁+d₂) − d₁‖² = ‖0.5d₂ − 0.5d₁‖² = 0.25‖d₂ − d₁‖² = 0.25(‖d₂‖² + ‖d₁‖² − 2d₁·d₂) = 0.25(1 + 1 − 2×0.5) = 0.25×0.5 = 0.125 ≈ 0.13（上面四舍五入写作 0.134 也无妨，精确值 0.125）。结论：h_a 同时赢得两项——重构误差 0 < 0.125，L1 代价 λ = λ 持平但重构项完胜，所以 L1 推断选出单列 (1, 0)。更一般的规律：L1 范数偏好"少而准"的解，哪怕混合能重构得一样好，L1 也会先把小系数压到零——这就是"稀疏"二字的来历。（若想找"混合也零误差"的反例：把 x 换成 d₁+d₂ 方向，单列重构必有误差，混合零误差，但 L1 会倾向系数尽量集中——核心机制相同。）

对比之下，自编码器把这两步变成一步：编码器 f 是一个学成的前馈函数，一次性直接吐出 h = f(x)，不再为每个样本跑内层优化。这在文献里叫摊销推断（Amortized Inference）——把"每次都要解一遍的推断问题"的成本，摊销到一次性的编码器训练里去。代价是：摊销的 f 是次优的（任何固定函数都比不过逐样本精确优化），收益是：推断从"每个样本一次迭代优化"变成"一次矩阵乘法"，快几个数量级，而且 f 本身就是一个可复用的特征提取器。

💡 关键一跃

稀疏编码是"为每个样本解一道优化题"，自编码器是"训练一个函数去猜这道题的最优解"。这个"用前馈网络摊销推断"的思想远不止于此——第 19 章的变分自编码器（VAE）会把它用到概率隐变量的推断上，成为现代生成模型的基石之一。

14.4从去噪自编码器到大模型预训练：一条谱系

上一节的摊销推断让自编码器变得实用。但真正让它名留青史的，是它开启的一条思想谱系——今天的大模型预训练，追根溯源就长在这条线上。把节点按时间排开：

逐个看这条链：① DAE（2008，Vincent 等）：证明"从污染版本还原干净版本"能逼出对扰动鲁棒的表示；② 去噪分数匹配：理论上更漂亮——DAE 学到的修正方向 x̂ − x̃ 恰好正比于数据分布的对数密度梯度（score），即一个指向数据流形的向量场，这把自编码器和能量模型（第 17 章）正式接通；③ word2vec（2013）：用上下文预测中心词（或反过来），词向量自动带语义——"预测缺失部分"作为无监督信号首次在文本上大获成功；④ ELMo（2018）：双向语言模型，词的表示随上下文变化；⑤ BERT（2018）：掩码语言模型（Masked Language Model）——随机遮住约 15% 的 token 让模型还原，这正是序列版的去噪自编码器：token 版"加噪还原"；⑥ GPT 系列：自回归（Autoregressive）预测下一个 token，可以看作"按序重构整段文本"。

为什么这条谱系能成立？因为重构/还原任务强迫模型把"世界的结构"压进表示里。要还原被遮住的词，模型必须懂语法、懂常识、懂上下文逻辑；要还原被污染的图像块，模型必须懂物体的形状与纹理。不需要任何人告诉它"什么是语法"——还原压力自己会把这些结构逼出来。这正是本章主线问题"没有标签时如何让网络抓住数据关键结构"在今天最大规模的实现。

✅ 判定规则

判断一个无监督预训练方法是否在这条谱系上，就问一句：它的监督信号是不是来自"输入本身的缺失/污染版本"？是——它就是自编码器家族的后代；不是（如对比学习靠样本间关系）——那是另一条线的故事（第 15 章会碰到）。

14.5应用与局限：重构误差的边界

上一节把自编码器推上了神坛。收尾前必须泼一盆冷水：自编码器有自己的能力边界，越界使用就是误用。先看它能干什么，再看它干不了什么。

三个经典应用

① 降维与可视化。瓶颈层 h 就是现成的低维坐标。比 PCA 强的地方在于：非线性的 f 和 g 能把弯曲的数据流形（如手写数字的连续形变）展平到低维，而 PCA 只能找线性子空间。把 h 设成 2 维，就能把高维数据画在散点图上肉眼检查聚类。

② 以图搜图 / 信息检索的哈希编码。把每张图片编码成短的二值码 h，检索时在码空间找近邻即可，不必比对原图。语义相近的图编码相近——这是编码器学到的"语义距离"。

③ 异常检测。思路：只用正常样本训练自编码器，它对正常样本重构得好、对没见过的异常样本重构得差。设定阈值即可报警。数字例：设正常样本的 MSE 大多落在 0.01–0.05，取阈值 τ = 0.10；上线后三个新样本的 MSE 分别为 0.03、0.08、0.31，则前两个判正常、第三个（0.31 > 0.10）判异常。阈值的依据：取训练集重构误差的某个高分位数（如 99%），留一点余量防误报。

两个根本局限

局限一：重构好 ≠ 表示有用。MSE 只在乎像素级还原，不在乎语义。一个把光照变化记得清清楚楚、却把物体类别弄混的编码器，照样拿低重构误差。表示"好不好"取决于下游任务，这是第 15 章（表示学习）要正面回答的问题。

局限二：生成能力弱。自编码器只学过"给 x 编码再还原"，没学过"凭空造一个像样的 x"——h 空间里的分布是什么样、怎么从里面采样，它一概不知。而且 MSE 损失隐含"误差服从高斯分布"的假设，对像素级生成任务会输出模糊的平均结果（把所有可能的清晰答案平均成模糊一团）。要生成新样本，需要的是能刻画 p(x) 本身的模型——第 17 章的生成模型（VAE、GAN、扩散模型）正是为此而来。

💡 本章收尾

自编码器的历史地位很微妙：作为表示提取器它依然是工具箱常客，作为预训练思想它孕育了整个大模型时代，但作为生成模型它力不从心。带着"重构好≠表示有用、会还原≠会生成"这两句告诫进入第 15 章与第 17 章，你就知道这两章各自要解决什么。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
重构误差（Reconstruction Error）
点击翻面 →
定义自编码器的训练目标 L(x, g(f(x)))，最常用 ‖x − x̂‖²。
解决问题无标签时提供监督信号：让输出逼近输入本身。
直觉自己当老师：把输入抄写一遍，但限制抄写过程必须抓重点。
误区以为重构误差小 = 表示好——它只保证像素级还原，不保证语义有用。
何时用本章所有模型；Ch17 生成模型里被替换为更强的目标。
概念卡 2
瓶颈（Bottleneck）
点击翻面 →
定义自编码器中维度小于输入的中间层 h，欠完备设计的核心。
解决问题阻止恒等复制：数据必须挤过窄门，网络被迫学取舍。
直觉一节课压成三行笔记——不抓主干就写不下。
误区越窄越好——太窄装不下数据本征维度，误差系统性偏大。
何时用降维可视化；Ch15 讨论表示维度时反复出现。
概念卡 3
稀疏自编码器（Sparse Autoencoder）
点击翻面 →
定义加稀疏惩罚 Ω(h) 的自编码器，常用 KL(ρ‖ρ̂ⱼ) 压低隐单元平均激活。
解决问题过完备时防作弊：让每个隐单元大多数时候闭嘴。
直觉一支纪律严明的队伍，每人只在特定口令下才出动。
误区以为稀疏 = 大部分权重为零——稀疏的是激活值，不是参数。
何时用特征可解释性分析；近年也被用于解剖大模型内部特征。
概念卡 4
去噪自编码器（Denoising Autoencoder）
点击翻面 →
定义把加噪输入 x̃ 重构回干净 x 的自编码器，最小化 L(x, g(f(x̃)))。
解决问题不限制容量也能防作弊：照抄含噪输入必受罚。
直觉让保洁员看脏房间照片学"房间本来什么样"——他必须懂房间结构。
误区与 CAE 混为一谈——DAE 靠注入噪声（数据层面），CAE 靠惩罚雅可比（模型层面）。
何时用鲁棒特征学习；思想直通 BERT 掩码预训练（见 14.4）。
概念卡 5
收缩自编码器（Contractive Autoencoder）
点击翻面 →
定义惩罚编码器雅可比 Frobenius 范数 ‖J_f(x)‖²_F 的自编码器。
解决问题让 h 对输入的微小扰动不敏感，只保留流形切方向的变化。
直觉对无关方向的"装聋作哑"——风吹草动不再改变你对物体的判断。
误区以为惩罚越大越好——过度收缩会让 h 对有用方向也迟钝。
何时用理论分析流形学习；与 DAE 互补的鲁棒化手段。
概念卡 6
摊销推断（Amortized Inference）
点击翻面 →
定义训练一个前馈函数一次性预测隐表示，代替逐样本的内层优化。
解决问题稀疏编码式的逐样本优化太慢，无法大规模部署。
直觉把每道题都现解，改为背熟解题套路直接套。
误区以为摊销解是最优解——它牺牲了逐样本精度换速度。
何时用Ch19 变分自编码器（VAE）的编码器正是摊销推断。

📝分层习题

L1 概念辨析

判断对错："只要自编码器在测试集上的重构误差很小，就说明它学到的表示 h 是有用的。"如果错，说明理由并举一个反例。

提示

想想 14.5 的局限一：重构误差度量的是什么层面？表示的"用处"由谁决定？

完整解答

错。重构误差只度量"输入能不能被还原"，不度量"表示是否对下游任务有用"。反例：一个把图像的光照、背景噪声编码得巨细无遗、却不区分猫和狗的编码器，照样可能重构误差很低——但对分类任务它的表示毫无价值。反过来，一个扔掉了大量像素细节、只保留语义轮廓的编码器重构误差偏高，表示却可能极好。易错点：把"训练目标达成"误当"学习目标达成"——训练目标只是手段，下游任务才是目的。

L1 概念辨析

辨析：DAE 与 CAE 都想让编码器对扰动鲁棒，它们的正则目标有何本质不同？各自的代价是什么？

提示

一个改动的是训练数据，一个改动的是损失函数；想想各自的计算开销。

完整解答

DAE：数据层面注入噪声，训练目标仍是重构误差，不需要算任何导数，实现简单；代价是要设计噪声分布，且只对注入过的那类扰动鲁棒。CAE：模型层面惩罚雅可比范数 ‖J_f‖²_F，解析地压制所有方向的敏感度；代价是要计算雅可比（可借 sigmoid 化简，深网时仍贵），且惩罚强度需要调。一句话：DAE 用"见过的噪声"买鲁棒，CAE 用"压平的导数"买鲁棒。

L2 手算推导

给定编码向量 w = (1, 0)（h = w·x，x̂ = h·w），对数据点 (1, 0.2)、(0, −0.4)、(−1, 0) 逐个计算：编码 h、重构 x̂、平方误差，并求总 MSE。

提示

照 14.1 手算例 1 的流程：h = w·x 只取第一坐标；x̂ = (h, 0)；误差 = 第二坐标的平方。

完整解答

① (1, 0.2)：h = 1×1 + 0×0.2 = 1；x̂ = 1×(1,0) = (1, 0)；残差 (0, 0.2)；误差 = 0.04
② (0, −0.4)：h = 1×0 + 0×(−0.4) = 0；x̂ = (0, 0)；残差 (0, −0.4)；误差 = 0.16
③ (−1, 0)：h = 1×(−1) + 0×0 = −1；x̂ = (−1, 0)；残差 (0, 0)；误差 = 0

总误差 = 0.04 + 0.16 + 0 = 0.20；MSE = 0.20 ÷ 3 ≈ 0.067。第三个点恰好在保留方向上，零误差——瓶颈只丢"垂直于 w"的信息。

L2 手算推导

某隐单元在 5 个样本上的激活为 0.05, 0.9, 0.05, 0.05, 0.05，稀疏目标 ρ = 0.2。计算 ρ̂ⱼ 与 KL(ρ‖ρ̂ⱼ)（用 log 2 ≈ 0.693，log 5 ≈ 1.609，log 11 ≈ 2.398 等近似值，步骤写全）。

提示

先算平均激活，再套 KL(ρ‖ρ̂ⱼ) = ρ log(ρ/ρ̂ⱼ) + (1−ρ) log((1−ρ)/(1−ρ̂ⱼ))。

完整解答

① ρ̂ⱼ = (0.05 + 0.9 + 0.05 + 0.05 + 0.05) ÷ 5 = 1.10 ÷ 5 = 0.22
② 第一项：ρ log(ρ/ρ̂ⱼ) = 0.2 × log(0.2 ÷ 0.22) = 0.2 × log(0.909) ≈ 0.2 × (−0.0953) ≈ −0.019
③ 第二项：(1−ρ) log((1−ρ)/(1−ρ̂ⱼ)) = 0.8 × log(0.8 ÷ 0.78) = 0.8 × log(1.0256) ≈ 0.8 × 0.0253 ≈ 0.020
④ KL ≈ −0.019 + 0.020 = 0.001

惩罚几乎为零——ρ̂ⱼ = 0.22 离目标 0.2 很近，这个单元"纪律良好"。对比 14.2 手算例 2 的 0.414：离目标越远，惩罚增长越快。注意"5 个样本激活 1 次"恰好对应 20% 的平均激活，直觉与计算吻合。

L3 建模应用

场景：工厂有 200 个传感器，每秒钟产生一个 200 维读数向量。工厂积累了半年的正常运行数据，但几乎没有故障期的标注数据。请你设计一个基于自编码器的异常检测方案：① 网络结构（输入/瓶颈/输出各多大）；② 瓶颈维度的选择依据；③ 报警阈值的设定方法；④ 为什么不直接用 PCA。

提示

训练集是什么？瓶颈维度可以先怎么估、再怎么验证？PCA 在什么情况下会漏报？

完整解答

① 结构：输入 200 维 → 编码器若干隐层（如 128 → 64）→ 瓶颈 h（如 16 维）→ 解码器对称（64 → 128）→ 输出 200 维；激活用 ReLU/sigmoid，损失用 MSE，只用正常数据训练。

② 瓶颈维度依据：先粗估数据的本征维度（如看 PCA 方差解释率达 95% 需要几个主成分，设为 k₀），取 h ≈ k₀ 或略大；再用验证集（正常数据切出一块）扫几个候选 h，选"验证重构误差开始不再明显下降"的最小值——太窄丢结构（正常样本也报警），太宽容易对异常也重构得太好（漏报）。

③ 阈值设定：在训练集（或留出验证集）上算所有正常样本的 MSE，取其 99% 分位数 τ₀，上线阈值 τ = τ₀ 乘以安全系数（如 1.2）；报警率过高就上调，漏掉已知故障就下调。

④ 为什么不用 PCA：PCA 只能检测"偏离线性子空间"的异常；如果故障模式恰好落在某几个主成分张成的平面内（如两个传感器同比例漂移，合成方向仍在主子空间内），PCA 的重构误差依然很小，会漏报。非线性自编码器能学弯曲的"正常流形"，对这类沿弯流形滑动但偏离正常区域的异常更敏感。此外 PCA 没有非线性压缩，同样维度下信息保留能力更弱。

为什么说 BERT 的掩码语言模型可以看作"序列版去噪自编码器"？
  • A. 遮住部分 token（加噪）再还原（重构干净输入），与 DAE"污染再还原"的机制同构，只是对象从连续像素换成离散 token
  • B. 因为 BERT 的编码器和解码器都是卷积网络
  • C. 因为 BERT 用了瓶颈结构压缩句子
  • D. 因为 BERT 训练时也最小化像素级 MSE
解析：A 对——机制的对应关系是：遮 token ≈ 加噪，还原 ≈ 重构，表示被迫吸收语言结构。B 错：BERT 是 Transformer，与卷积无关。C 错：BERT 没有维度瓶颈，它的"限制"是信息缺失而非通道变窄。D 错：token 是离散的，用的是交叉熵，不是 MSE。
自测 5
用自编码器做异常检测时，"重构误差超过阈值就报警"这一规则成立的前提是什么？
  • A. 训练集里混入了足够多的异常样本，让网络学会区分
  • B. 训练集几乎全是正常样本，网络只学会了正常数据的流形，对偏离该流形的异常重构不好
  • C. 阈值必须取 0，任何误差都报警
  • D. 瓶颈维度必须大于输入维度
解析：B 对——方案的根基是"网络只会重构它见过的分布"；混入异常样本会把异常也学进去，规则失效。A 错：那会变成分类问题，且异常样本极难收集（题目场景正是如此）。C 错：正常样本也有非零误差，阈值取 0 会全员误报，应取训练误差的高分位数。D 错：瓶颈大于输入反而可能让异常也被轻易重构（恒等作弊），漏报更多。
