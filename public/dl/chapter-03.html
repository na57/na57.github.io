3.1为什么需要概率：因为世界不给确定的答案

第 2 章的线性代数是确定性的语言：矩阵乘向量，答案唯一。但机器学习面对的现实不是这样——摄像头画面有噪点、用户行为难以预料、训练数据永远只是世界的样本。我们需要一门"承认不确定"的数学语言，这就是概率论。

花书把不确定性的来源归为三类，记住它们，你就知道什么时候该怪数据、什么时候该怪模型：

来源含义例子能不能消除
系统内在随机过程本身就是随机的掷骰子、放射性衰变不能，只能建模
观察不完全该看的没看全扑克牌里看不见对手的牌；监控盲区加传感器可部分缓解
模型不完全我们主动丢弃了信息用低分辨率图识别物体，丢掉细节换更强模型可部分缓解

同一个"概率"，两派人有两种读法：

  • 频率派（Frequentist）：概率 = 事件在无限次重复试验中出现的频率。骰子掷出 6 的概率是 1/6，因为掷一百万次约有六分之一是 6。
  • 贝叶斯派（Bayesian）：概率 = 对事件的相信程度（degree of belief）。"明天下雨的概率 70%"不是重复试验，而是我对这件事的信心可以被量化、被新证据更新。

一句话对照：频率派说"世界本来如此"，贝叶斯派说"我目前相信到这种程度"。深度学习两派都用：数据分布按频率派理解，模型参数的不确定性按贝叶斯派理解。

💡 关键一跃

概率不是"放弃精确"，而是给不确定本身造了一把可计算的尺子：每个命题赋一个 0 到 1 的数，配上几条运算规则，不确定就可以像数字一样加减乘除、代入公式。这就是它能成为 AI 推理语言的原因。

⚠️ 常见误区

"概率 0.5 就是我不知道"——错。概率 0.5 是一个最强的断言：两种结果完全等可能。真正的"不知道"是无法给出一个分布，那恰恰无法用概率论处理。

3.2概率规则与贝叶斯定理：从"阳性"反推"患病"

上一节说概率是一把尺子，这一节给它配上刻度与运算规则。先立四条基本规则（都以"事件"或"随机变量取值"为对象）：

  • 加法规则（边缘化）：P(x) = ∑y P(x, y)——把不关心的变量求和消掉。
  • 乘法规则：P(x, y) = P(y | x) · P(x)。
  • 条件概率（Conditional Probability）：P(y | x) = P(x, y) / P(x)，前提是 P(x) > 0。
  • 独立性：x ⊥ y ⟺ P(x, y) = P(x) · P(y)。

把乘法规则的两个写法联立：P(x, y) = P(y|x)·P(x) = P(x|y)·P(y)，移项即得贝叶斯定理（Bayes' Theorem）：

P(x | y) = P(y | x) · P(x)P(y)

它的用途是方向反转：我们知道"原因 → 结果"（P(结果|原因)），想反推"结果 → 原因"（P(原因|结果)）。分母 P(y) 通常用全概率公式展开：P(y) = P(y|x)P(x) + P(y|¬x)P(¬x)。

完整手算：医疗检测问题

某种病的患病率 P(病) = 0.01；检测的敏感度 P(阳|病) = 0.95；特异度 P(阴|健康) = 0.95（即假阳性率 P(阳|健康) = 0.05）。现在一个人检出阳性，他真患病的概率是多少？

第一步：用全概率公式算 P(阳)。阳性有两条来路——"真病人检出阳"和"健康人误报阳"：

P(阳) = P(阳|病)·P(病) + P(阳|健康)·P(健康) = 0.95 × 0.01 + 0.05 × 0.99 = 0.0095 + 0.0495 = 0.059

第二步：代入贝叶斯定理。分子是"真阳性"那一条路 0.0095：

P(病|阳) = 0.95 × 0.010.059 = 0.00950.059 ≈ 0.161

第三步：解读。检出阳性，真患病的概率不到 17%！直觉上"95% 准确的检测"应该很可靠，为什么反差这么大？因为分母里的假阳性 0.0495 是真阳性 0.0095 的 5 倍多——健康人基数（0.99）远大于病人基数（0.01）。忽视先验患病率、只看检测准确率，就是著名的基础率谬误（Base Rate Fallacy）。

✅ 判定规则

贝叶斯定理三件套：先验 P(原因)、似然 P(结果|原因)、证据 P(结果)。后验 = 似然 × 先验 ÷ 证据。以后看到任何"检测""诊断""垃圾邮件过滤"问题，先找这三个数。

⚠️ 常见误区

"P(阳|病) = 0.95 所以 P(病|阳) = 0.95"——错。条件概率不能随意换方向，两者差一个先验的权重。本例中一个是 0.95，另一个只有 0.161。

3.3随机变量与常见分布：给"不确定"一个变量名

有了规则，还缺一个操作对象。随机变量（Random Variable）是一个"取值随试验结果而定的变量"——它本身不是数，而是从试验结果到数的映射。用大写 X 记变量，小写 x 记它取到的具体值。

随机变量分两类，描述工具不同：

  • 离散型：用概率质量函数（PMF, Probability Mass Function）P(X = x)，每个取值一个概率，全部加起来等于 1。例：骰子。
  • 连续型：用概率密度函数（PDF, Probability Density Function）p(x)。注意：p(x) 本身不是概率，某点的概率恒为 0；只有区间 [a, b] 上的积分 ∫ab p(x)dx 才是概率，且全空间积分为 1。

三个最常用的分布

  • 伯努利分布（Bernoulli Distribution）：一次是非试验，P(X=1) = p，P(X=0) = 1−p。例：一枚不均匀的硬币。
  • categorical 分布（Categorical Distribution）：伯努利的多类别版，k 个类别各有概率 p₁…pₖ，∑ pi = 1。分类模型的输出就是它。
  • 正态分布（Normal Distribution）：连续型，钟形曲线，由均值 μ 与方差 σ² 完全决定。3.4 节会专门讲它为什么无处不在。

期望与方差：分布的"重心"与"胖瘦"

期望（Expectation）E[X] = ∑x x·P(x)，是所有取值的概率加权平均；方差（Variance）Var(X) = E[(X − E[X])²]，衡量取值偏离期望的程度。实战中常用等价公式 Var(X) = E[X²] − (E[X])²。

实算一：均匀骰子。X 等概率取 1 到 6，每个 P = 1/6。

E[X] = 16(1+2+3+4+5+6) = 216 = 3.5

E[X²] 逐项列出：1²=1，2²=4，3²=9，4²=16，5²=25，6²=36：

E[X²] = 16(1+4+9+16+25+36) = 916
Var(X) = E[X²] − (E[X])² = 916 − 12.25 = 3512 ≈ 2.92

实算二：伯努利 p = 0.3。P(X=1) = 0.3，P(X=0) = 0.7。

E[X] = 1 × 0.3 + 0 × 0.7 = 0.3
E[X²] = 1² × 0.3 + 0² × 0.7 = 0.3
Var(X) = E[X²] − (E[X])² = 0.3 − 0.09 = 0.21

这正是伯努利方差的通用结论 Var(X) = p(1−p) = 0.3 × 0.7 的验证。

💡 关键一跃

期望是分布的重心：把 PMF 想成一根杆上各点挂的砝码，E[X] 就是让它平衡的那个支点。方差是砝码分布的胖瘦：离支点越远，杆越难平衡。

⚠️ 常见误区

"连续变量的 PDF 值 p(0.5) = 1.8 说明概率超过 1，不可能"——错。PDF 是密度不是概率，可以大于 1；只有区间积分才必须是 ≤ 1 的概率。

3.4深度学习最爱的分布：高斯、指数、Laplace 与 Dirac

上一节给了分布的概念，这一节选型：深度学习反复使用的就这几个。

高斯分布（Gaussian Distribution，即正态分布）：密度由 μ 与 σ² 决定，p(x) 与 exp(−(x−μ)²/(2σ²)) 成正比。为什么它无处不在？中心极限定理（Central Limit Theorem）的直觉：当许多个独立的小噪声叠加在一起，无论每个噪声各自长什么样，总和都趋向高斯。测量误差、像素噪点、参数初始化——都是"许多小因素之和"，所以默认假设高斯往往是对的。

指数分布与 Laplace 分布：

  • 指数分布（Exponential Distribution）：p(x) = λ·e^(−λx)（x ≥ 0），在 0 处有一个尖峰，向右指数衰减——建模"等待时间"或"非负且偏向 0"的量。
  • 拉普拉斯分布（Laplace Distribution）：把指数分布镜像到负半轴，在 μ 处形成尖峰，p(x) 与 e^(−|x−μ|/b) 成正比。

现在先埋一个钩子：对参数加"Laplace 先验"等价于 L1 正则（绝对值惩罚），加"高斯先验"等价于 L2 正则（平方惩罚）——第 5 章讲贝叶斯推断、第 7 章讲正则化时会把这个钩子拉满。

Dirac 分布与经验分布：Dirac 分布（Dirac Distribution）把全部概率质量压在一个点上（密度是无穷窄无穷高的"尖刺" δ(x−μ)）。把训练集里每个样本放一个 Dirac 尖刺、各分 1/m 的质量，就得到经验分布（Empirical Distribution）——"从数据估计分布"的最原始形式，第 5 章的最大似然估计就建立在它之上。

混合分布：把几个分布按比例混合，P(x) = ∑k P(c=k)·P(x|c=k)，其中 c 是看不见的潜变量（Latent Variable）——"数据由几个隐藏类别各自生成"的建模思想，后面的混合模型与生成模型全靠它。

✅ 判定规则

选分布三问：取值离散还是连续？连续的话有没有尖峰/长尾/对称性？是不是"许多小因素之和"？答案分别指向 categorical、Laplace/指数、高斯。

3.5信息论：给"信息量"造第二把尺子

概率量化了"不确定"，信息论（Information Theory）进一步量化"一个消息带来多少信息"。基本单位是比特（bit）。

自信息：越罕见，越惊人

事件 x 的自信息（Self-information）：

I(x) = −log₂ P(x)

"太阳从东边升起"信息量约等于 0（P ≈ 1）；罕见事件信息量大（P 小，−log₂P 大）。概率减半，信息量多 1 bit。

熵：分布的平均不确定性

熵（Entropy）是整个分布的自信息期望：H(X) = E[−log₂ P(x)] = −∑x P(x)·log₂ P(x)。它回答："这个分布平均有多难预测？"

实算：p = (1/2, 1/4, 1/8, 1/8)。逐项写：log₂(1/2) = −1，log₂(1/4) = −2，log₂(1/8) = −3：

H = −[ ½·(−1) + ¼·(−2) + ⅛·(−3) + ⅛·(−3) ] = ½·1 + ¼·2 + ⅛·3 + ⅛·3 = 0.5 + 0.5 + 0.375 + 0.375 = 1.75 bit

对照：4 个结果若均匀分布，熵是 log₂4 = 2 bit。1.75 < 2，分布越不均匀越好预测，熵越低。

KL 散度：两个分布差多少

KL 散度（KL Divergence，Kullback–Leibler Divergence）度量"用 q 近似 p 时多付的代价"：

DKL(p ‖ q) = ∑x p(x) · log₂ p(x)q(x)

实算：p = (0.5, 0.5)，q = (0.25, 0.75)。逐项写：

x₁ 项：0.5 · log₂0.50.25 = 0.5 · log₂ 2 = 0.5 · 1 = 0.5
x₂ 项：0.5 · log₂0.50.75 = 0.5 · log₂23 = 0.5 · (−0.5850) = −0.2925
DKL(p ‖ q) = 0.5 − 0.2925 ≈ 0.2075 bit

注意：DKL(p‖q) ≠ DKL(q‖p)，KL 散度不对称，所以它叫"散度"而不叫"距离"。它永远 ≥ 0，当且仅当 p = q 时等于 0。

交叉熵：深度学习的损失函数从这里来

交叉熵（Cross-Entropy）H(p, q) = −∑x p(x)·log₂ q(x)，它与熵、KL 散度满足：

H(p, q) = H(p) + DKL(p ‖ q)

用上面同一组数字验证：H(p) = 1 bit（p 是两个 0.5），所以 H(p, q) = 1 + 0.2075 ≈ 1.2075 bit。

结论（本章最重要的一句话）：训练分类器时，标签分布 p 是固定的，H(p) 是常数。于是最小化交叉熵 H(p, q) ⟺ 最小化 DKL(p‖q) ⟺ 让模型输出分布 q 逼近标签分布 p。这就是第 5、6 章交叉熵损失的全部来历。

💡 关键一跃

交叉熵 = 熵 + KL 散度，可以读作"编码代价 = 不可消除的本底 + 用错分布的浪费"。训练能消掉的只有后者，所以优化交叉熵就是在消除"用错分布"的部分。

⚠️ 常见误区

"DKL(p‖q) = 0.2075 那 DKL(q‖p) 也一样"——错。换方向重算：0.25·log₂(0.25/0.5) + 0.75·log₂(0.75/0.5) = 0.25·(−1) + 0.75·log₂(1.5) = −0.25 + 0.75 × 0.5850 ≈ 0.1887，确实不相等。

3.6独立与条件独立：对抗联合分布的指数爆炸

本章一直在单变量上演算，现实却是成百上千个变量。麻烦来了：n 个二值变量的联合分布需要 2ⁿ 个概率项——n = 100 时是 2¹⁰⁰，宇宙原子总数都装不下。这叫联合分布的指数爆炸。

出路是用结构性假设把大分布拆成小分布的乘积：

  • 独立性：若 x ⊥ y，则 P(x, y) = P(x)·P(y)。n 个相互独立的二值变量，只需 n 个参数而不是 2ⁿ 个。
  • 条件独立性：给定 z 时 x ⊥ y，即 P(x, y | z) = P(x|z)·P(y|z)。例：知道"是否感冒"之后，"发烧"与"咳嗽"近似条件独立。

一个变量的"绝对独立"很少见，但"给定某些变量后的条件独立"处处存在。把变量画成节点、把（条件）依赖画成边，联合分布就能按图结构分解——这就是图模型（结构化概率模型）的思想，第 16 章会展开，这里只需记住：独立性假设是把指数问题降回多项式问题的唯一杠杆。

✅ 判定规则

看到联合分布先数参数：没有独立性假设时二值变量要 2ⁿ 项；每发现一条（条件）独立关系，就把一个大因子拆成几个小因子，参数量随之骤降。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
随机变量（Random Variable）
点击翻面 →
定义从试验结果到数值的映射，大写记变量、小写记取值。
解决问题把"不确定的事件"变成可以代数运算的对象。
直觉一个"还没开奖"的变量：取值范围与概率事先写好。
误区把它当成一个普通数值变量，忘了它带一个分布。
何时用本章全部；第 5 章把数据与参数都建模为随机变量。
概念卡 2
条件概率（Conditional Probability）
点击翻面 →
定义P(y|x) = P(x,y)/P(x)：已知 x 发生后 y 的概率。
解决问题让"新证据"能更新原有判断。
直觉把样本空间缩小到"x 已发生"的那一块重新算比例。
误区以为 P(y|x) 与 P(x|y) 可以互换——方向不能乱换。
何时用贝叶斯定理、条件独立、链式法则都靠它。
概念卡 3
贝叶斯定理（Bayes' Theorem）
点击翻面 →
定义P(x|y) = P(y|x)·P(x)/P(y)，分母用全概率展开。
解决问题把"原因→结果"翻转为"结果→原因"的诊断。
直觉后验 = 似然 × 先验 ÷ 证据：证据越稀罕，越要怀疑常见解释。
误区忽视先验（基础率谬误），把检测准确率当成确诊率。
何时用第 5 章最大后验估计、贝叶斯推断；一切诊断类问题。
概念卡 4
期望与方差（Expectation & Variance）
点击翻面 →
定义E[X]=∑x·P(x)；Var(X)=E[X²]−(E[X])²。
解决问题用两个数概括分布的重心与离散程度。
直觉期望是杆的支点，方差是砝码摊开的胖瘦。
误区以为 E[XY]=E[X]E[Y] 总成立——只有独立时才成立。
何时用第 4 章梯度期望、第 8 章优化中的噪声分析。
概念卡 5
高斯分布（Gaussian Distribution）
点击翻面 →
定义由 μ、σ² 决定的钟形连续分布，密度与 exp(−(x−μ)²/2σ²) 成正比。
解决问题为"连续噪声"提供一个只有两个参数的默认模型。
直觉许多独立小噪声之和必然长成钟形（中心极限定理）。
误区以为它"总是对的"——重尾现象（极端值多）时失效。
何时用参数初始化、噪声建模、VAE（第 20 章）先验。
概念卡 6
熵（Entropy）
点击翻面 →
定义H(X) = −∑ p(x)·log₂ p(x)，分布的平均自信息。
解决问题给"一个分布有多难预测"一个比特数。
直觉平均要猜多少次才猜中；越均匀越难猜，熵越大。
误区把熵当成单个事件的属性——它是整个分布的属性。
何时用交叉熵损失的本底；决策树的信息增益。
概念卡 7
KL 散度（KL Divergence）
点击翻面 →
定义D_KL(p‖q) = ∑ p·log₂(p/q)，用 q 近似 p 多付的比特。
解决问题量化"两个分布差多少"，且 ≥ 0、相等时为 0。
直觉按 p 的真实频率发牌，却用 q 的策略编码，多花的成本。
误区以为它对称、是"距离"——D_KL(p‖q) ≠ D_KL(q‖p)。
何时用交叉熵损失、变分推断（第 19、20 章）的核心度量。
概念卡 8
交叉熵（Cross-Entropy）
点击翻面 →
定义H(p,q) = −∑ p·log₂ q = H(p) + D_KL(p‖q)。
解决问题给一个可直接对模型输出 q 求导的训练目标。
直觉本底熵消不掉，能优化的只有"用错分布"的那部分。
误区以为交叉熵就是熵——它涉及两个分布，不是单一分布的属性。
何时用第 5、6 章起所有分类器的默认损失函数。

📝分层习题

L1 概念辨析

判断对错并说明理由：① "连续随机变量的 PDF 满足 p(x) ≤ 1"。② "若 P(A) = 0.9，P(B) = 0.9，则 P(A∩B) = 0.81"。

提示

① 回想 PDF 是密度还是概率；② 回想乘法规则在什么前提下才能直接相乘。

完整解答

① 错。PDF 是密度，可以大于 1（例如区间 [0, 0.5] 上的均匀分布密度恒为 2）；只有区间积分才必须 ≤ 1。

② 错。P(A∩B) = P(A)·P(B) = 0.81 仅在 A 与 B 独立时成立；题中未给独立性，无法计算（范围在 0.8 到 0.9 之间）。

L1 概念辨析

选择：下列哪个量一定非负？（a）自信息 I(x)（b）熵 H(X)（c）KL 散度 D_KL(p‖q)（d）交叉熵 H(p,q)。

提示

逐个检查定义式中每一项的符号；KL 散度的非负性是一条定理（Gibbs 不等式）。

完整解答

全部非负。I(x) = −log₂p，p ≤ 1 故 log₂p ≤ 0，I ≥ 0；H 是非负量的加权和；D_KL ≥ 0 由 Gibbs 不等式保证，当且仅当 p = q 时取 0；H(p,q) = H(p) + D_KL ≥ 0。易错点：以为 KL 散度可以取负——它不行，但组成它的单项 p·log₂(p/q) 可以为负（见 3.5 实算中的 −0.2925）。

L2 手算推导

换一组数字重做贝叶斯：某病患病率 P(病) = 0.005，敏感度 P(阳|病) = 0.99，特异度 P(阴|健康) = 0.98。求全概率 P(阳) 与后验 P(病|阳)，保留三位小数。

提示

先写假阳性率 P(阳|健康) = 1 − 0.98；再套全概率公式；最后代入贝叶斯定理。

完整解答

P(阳|健康) = 0.02。

P(阳) = 0.99 × 0.005 + 0.02 × 0.995 = 0.00495 + 0.0199 = 0.02485。

P(病|阳) = 0.00495 / 0.02485 ≈ 0.199。

解读：即使敏感度高达 99%，由于患病率只有 0.5%，阳性者真患病的概率也只有约 20%——基础率仍然主导。

L2 手算推导

换一组分布手算熵与 KL：p = (1/4, 1/4, 1/4, 1/4)，q = (1/2, 1/4, 1/8, 1/8)。求 H(p)、H(q)、D_KL(p‖q)，并验证 H(p,q) = H(p) + D_KL(p‖q)。（log₂(1/2) = −1，log₂(1/4) = −2，log₂(1/8) = −3）

提示

H(p) 是均匀分布的熵；D_KL(p‖q) 逐项写 pi·log₂(pi/qi)，共四项。

完整解答

H(p) = −4 × (1/4)·log₂(1/4) = 2 bit。

H(q) = ½·1 + ¼·2 + ⅛·3 + ⅛·3 = 1.75 bit（同 3.5 节）。

D_KL(p‖q) 逐项：

项1：¼·log₂(¼/½) = ¼·(−1) = −0.25；项2：¼·log₂(¼/¼) = 0；项3：¼·log₂(¼/⅛) = ¼·1 = 0.25；项4 同项3 = 0.25。

D_KL(p‖q) = −0.25 + 0 + 0.25 + 0.25 = 0.25 bit。

验证：H(p,q) = −[¼·log₂½ + ¼·log₂¼ + ¼·log₂⅛ + ¼·log₂⅛] = ¼·(1+2+3+3) = 2.25 bit = 2 + 0.25 ✓。

L3 建模应用

某工厂用两个传感器 A、B 监测同一台机器是否故障（F）。给定 F 时，A 与 B 的报警近似独立。已知 P(F) = 0.02，P(A报警|F) = 0.9，P(B报警|F) = 0.8，且健康时误报率均为 0.05。① 用条件独立写出 P(A报警, B报警 | F) 的分解；② 求 F 发生时双报警的概率；③ 说明如果错误地假设 A、B 无条件独立，建模会丢掉什么。

提示

① 套条件独立定义；② 直接相乘；③ 想想"无条件独立"与"给定 F 条件独立"的差别——不条件化时 A、B 其实相关吗？

完整解答

① 条件独立给出 P(A,B|F) = P(A|F)·P(B|F)，联合分布由 2² 项分解为两个单传感器条件分布的乘积。

② P(A报警, B报警 | F) = 0.9 × 0.8 = 0.72。

③ 若不条件化，A 与 B 通过共同的 F 而相关（机器故障时两者一起报警），无条件独立假设是错的，会丢掉"双报警强烈提示故障"这一关键信息，导致诊断模型严重低估双报警时的故障概率。这正是 3.6 节"条件独立比绝对独立更常见、更有用"的实例，也是图模型按结构分解联合分布的动机。
