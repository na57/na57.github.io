13.1潜变量模型总框架：为什么引入看不见的量

第 6–11 章的网络都是"输入 → 输出"的判别式思路，第 12 章把它们用到了各个领域。但有一类问题它们答不了：没有任何标签，只说"这里有一堆高维数据"，你能说出它是怎么生成的吗？本章回到无监督的起点，引入一个朴素却威力巨大的想法——潜变量模型（Latent Variable Model）：观测到的高维数据 x，其实是由少量看不见的隐因子 h 生成的。

为什么相信这个想法？看人脸照片：一张 1000 维的像素向量，看似有 1000 个自由度，但真正决定这张照片的不过是几十个因素——光照方向与强度、头部的姿态角、表情、身份特征（脸型、五官）。两张"同一人在同一姿态下、只差光照"的照片，在像素空间里相距很远，在"因子空间"里却只差一点。观测维度高，不等于有效维度高。

把这个直觉写成数学，就是本章所有模型的共同骨架：

x = Wh + μ + ε，其中 h ~ p(h)，ε 是噪声

逐项解读：

符号名称含义
x ∈ Rⁿ观测变量看得见的 n 维数据（如 1000 维像素）
h ∈ Rᵏ，k ≪ n潜变量 / 因子看不见的 k 个生成因素（光照、姿态……）
W ∈ Rⁿˣᵏ载荷矩阵（Loading Matrix）每个因子如何线性影响每个观测维度
μ均值偏移数据的整体中心
ε噪声因子解释不了的剩余部分，其协方差结构决定模型分支
p(h)先验对因子"长什么样"的事先假设（高斯？稀疏？独立？）

边际分布由积分给出：p(x) = ∫ p(x|h) p(h) dh。"看见 x 之后反推 h"则是后验 p(h|x) ∝ p(x|h)p(h)——生成是顺流而下，推断是逆流而上。本章三个模型的唯一差别就在于：p(h) 怎么设、ε 的协方差怎么设。概率PCA 与因子分析设 h 为高斯，ICA 设 h 为非高斯且相互独立。

💡 关键一跃

潜变量模型就像调音台：听众只听到混好的音乐（x），但录音师面前是几路独立的旋钮（h）。本章的任务就是只凭混好的成品，反推出旋钮的位置与线路的连接方式（W）。

⚠️ 常见误区

"潜变量是真实存在的物理量，我们要发现它"——不对。h 是建模假设，是我们为解释数据的相关结构而发明的工具。不同假设（高斯/稀疏/独立）会给出不同的 h，哪个"对"取决于它能否简洁地解释数据并服务于下游任务，而不是它是否对应某个物理实体。

13.2概率 PCA 与它的 EM：给定 x，怎么反推 h

上一节给了骨架，这节填上第一组具体假设。概率 PCA（Probabilistic PCA，PPCA）假设：

p(h) = 𝒩(0, I)，p(x|h) = 𝒩(Wh + μ, σ²I)

即因子是标准高斯，噪声各向同性（每个观测维度共享同一个噪声方差 σ²）。给定 h 后 x 的分布是球形高斯，中心在 Wh + μ。

训练目标是最大化观测数据的似然 p(x)。麻烦在于：h 看不见，似然里含积分，无法直接对 W 求导置零求解——这正是 EM 算法（Expectation-Maximization）的标准用武之地：E 步用当前 W 算出每个样本的后验 p(h|x)，M 步假装 h 已知、用这些"软估计"重新拟合 W，两步交替上升似然。

E 步公式：后验也是高斯

h | x = 𝒩( M⁻¹Wᵀ(x − μ), σ²M⁻¹ )，其中 M = WᵀW + σ²I

记住两件事就够：后验均值 = M⁻¹Wᵀ(x − μ)，后验协方差 = σ²M⁻¹。下面用一组具体数字把每一步算完。

手算例 1：PPCA 的一步 EM（E 步完整推导）

设定：观测维度 n = 2，因子维度 k = 1。载荷矩阵 W = (1, 1)ᵀ（2×1 列向量），噪声 σ² = 0.5，均值 μ = (0, 0)ᵀ。观测到一个样本 x = (3, 1)ᵀ。求后验 p(h|x)。

步骤算式结果
1. 算 WᵀW（1×1 标量）WᵀW = 1×1 + 1×12
2. 算 M = WᵀW + σ²IM = 2 + 0.5M = 2.5
3. 算 M⁻¹（标量求逆）M⁻¹ = 1 / 2.5M⁻¹ = 0.4
4. 算 x − μ(3, 1)ᵀ − (0, 0)ᵀ(3, 1)ᵀ
5. 算 Wᵀ(x − μ)（标量）1×3 + 1×14
6. 后验均值 = M⁻¹Wᵀ(x−μ)0.4 × 4E[h|x] = 1.6
7. 后验方差 = σ²M⁻¹0.5 × 0.4Var[h|x] = 0.2

结论：p(h|x) = 𝒩(1.6, 0.2)。直觉检验：x = (3,1) 在方向 (1,1) 上的投影长度约为 (3+1)/√2 ≈ 2.83，除掉噪声与先验的"回缩"，后验均值 1.6 比朴素投影小——这正是先验 p(h)=𝒩(0,I) 把估计往 0 拉的结果（收缩效应）。

M 步：用后验重新拟合 W

M 步对每个样本计算两个充分统计量：E[h⁽ⁱ⁾|x⁽ⁱ⁾]（后验均值）与 E[h⁽ⁱ⁾h⁽ⁱ⁾ᵀ] = σ²M⁻¹ + E[h]E[h]ᵀ（后验二阶矩），然后更新：

W ← [ ∑i (x⁽ⁱ⁾ − μ) E[h⁽ⁱ⁾]ᵀ ] [ ∑i E[h⁽ⁱ⁾h⁽ⁱ⁾ᵀ] ]⁻¹

逐项解释：左边的分子是"观测与因子软估计的互相关"——x 的哪几维跟着哪个因子动；右边的分母是"因子的自相关（含不确定性 σ²M⁻¹）"——除掉因子自身的尺度。整个式子就是用软估计的 h 对 x 做最小二乘回归。

手算例 2：接上例，算出 M 步的新 W

步骤算式结果
1. 二阶矩 E[hhᵀ]σ²M⁻¹ + E[h]² = 0.2 + 1.6²0.2 + 2.56 = 2.76
2. 分子 (x−μ)E[h]ᵀ(3, 1)ᵀ × 1.6(4.8, 1.6)ᵀ
3. 除以分母(4.8, 1.6)ᵀ / 2.76W_new ≈ (1.74, 0.58)ᵀ
4. 直觉检验x = (3,1) 的第一维更强W_new 第一分量变大、第二分量变小 ✓

注意第 1 步为什么不能省掉 σ²M⁻¹：那是后验的不确定性。把它丢掉相当于假装 h 被精确观测到，会系统性高估 E[hhᵀ]、让 W 的更新缩水。EM 交替这两个步骤，似然单调不降，直到收敛。

💡 关键一跃

EM 的本质是"鸡生蛋"的迭代：知道 W 就能推 h（E 步），知道 h 就能拟合 W（M 步）。两个都不知道时，就交替地"假装知道另一个"，每轮都让似然变好。

⚠️ 常见误区

"E 步后验均值就是 h 的真值"——不是。E[h|x] 只是最优猜测，后验仍有方差 σ²M⁻¹。M 步里 E[hhᵀ] = σ²M⁻¹ + E[h]E[h]ᵀ 的第一项正是这份不确定性的账本，丢掉它就不是 EM 而是"硬指派"，似然不再保证单调上升。

13.3PCA 与因子分析的关系：只差一个噪声假设

上一节的 PPCA 里藏着一个经典算法：当噪声 σ²→0 时，PPCA 的后验退化为"把 x 正交投影到 W 的子空间"，似然最大的 W 恰好张成经典 PCA 的主子空间。所以经典 PCA = 概率 PCA 在 σ²→0 时的极限——PCA 不再是一个孤立的降维技巧，而是潜变量模型家族的一员。

因子分析（Factor Analysis，FA）走的是另一条岔路：噪声协方差不是球形的 σ²I，而是对角阵 Ψ = diag(ψ₁, …, ψₙ)——每个观测维度有自己独立的噪声水平：

p(h) = 𝒩(0, I)，p(x|h) = 𝒩(Wh + μ, Ψ)，Ψ 为对角阵

含义上的差别：PPCA 说"所有维度一样脏，剩下的都是因子"；FA 说"维度各有各的脏法，只有跨维度的共变才归因于因子"。

旋转不变性的关键差别

两个模型对"W 右乘一个正交旋转 R"的反应不同：

模型对旋转 W → WR 的反应结论
PCA（σ²→0）旋转会破坏"按方差大小排序"的结构主子方向唯一（可辨识，只差符号）
因子分析WWᵀ 不变，似然不变因子方向允许任意旋转，需额外准则才能定方向

手算例 3：同一个协方差矩阵，PCA 与 FA 给出不同方向

设 2 维观测数据的协方差矩阵为 Σ = [[4, 2], [2, 2]]（即第一行 (4,2)，第二行 (2,2)）。

PCA 方向（最大特征值对应的特征向量）：

步骤算式结果
1. 特征方程 det(Σ − λI) = 0(4−λ)(2−λ) − 4 = λ² − 6λ + 4 = 0λ = 3 ± √5
2. 取大根λ₁ = 3 + √5λ₁ ≈ 5.236（λ₂ ≈ 0.764）
3. 代回求方向(4 − λ₁)v₁ + 2v₂ = 0 ⟹ v₂ = (λ₁−4)/2 · v₁v₂ = (√5−1)/2 ≈ 0.618 v₁
4. 主方向v ∝ (1, 0.618)与 x₁ 轴夹角 ≈ 31.7°

因子分析方向（单因子，Σ = wwᵀ + Ψ）：写出约束：w₁w₂ = 2（非对角元），w₁² + ψ₁ = 4，w₂² + ψ₂ = 2。未知数 4 个、方程 3 个，有无穷多解——这正是旋转不唯一的代数证据。取一组合法解 ψ₁ = 2：

步骤算式结果
1. 由 w₁² + ψ₁ = 4，取 ψ₁ = 2w₁² = 2w₁ = √2 ≈ 1.414
2. 由 w₁w₂ = 2w₂ = 2 / √2w₂ = √2 ≈ 1.414
3. 由 w₂² + ψ₂ = 2ψ₂ = 2 − 2ψ₂ = 0
4. 因子方向w ∝ (1, 1)与 x₁ 轴夹角 = 45°
5. 验证重构wwᵀ + Ψ = [[2,2],[2,2]] + [[2,0],[0,0]]= [[4,2],[2,2]] = Σ ✓

同一个 Σ：PCA 给出 31.7°，FA 给出 45°，二者方向不同且都"对"——它们回答的问题不同：PCA 找方差最大的方向，FA 找能解释协方差的公共因子。而且 FA 若换一个 ψ₁ 取值，方向还会变；PCA 的方向则唯一确定。

💡 关键一跃

PCA、PPCA、FA 是同一家族按噪声假设排成的光谱：PCA（无噪声）⊂ PPCA（球形噪声）⊂ FA（对角噪声）。噪声假设越自由，能吸收进"维度私有噪声"的成分越多，留给因子的就只剩跨维度的共变。

⚠️ 常见误区

"因子分析就是旋转后的 PCA"——不对。FA 的旋转自由度来自它的对角噪声模型，是似然层面上的不可辨识；PCA 没有对角噪声，主方向由方差排序唯一锁定。把 FA 的因子直接当 PCA 主成分解读方向，是最常见的误用。

13.4ICA：要的不是"不相关"，而是"独立"

前面两个模型里 h 都是高斯。高斯有个"致命弱点"：高斯分布旋转之后仍是高斯，方向信息被彻底抹平——这就是 FA 旋转不唯一的根源。要恢复真正的因子方向，必须假设 h 是非高斯且相互独立的，这就是独立成分分析（Independent Component Analysis，ICA）。

经典场景是鸡尾酒会问题（Cocktail Party Problem）：房间里 2 个说话人同时讲话，2 个麦克风各自录到两路声音的混合 x₁ = 2s₁ + s₂、x₂ = s₁ + s₂。能不能只凭录到的混合信号 (x₁, x₂)，把原始说话声 (s₁, s₂) 分离出来？直觉依据：两个说话人统计独立——一个人说什么不影响另一个说什么。ICA 的目标就是找解混矩阵 W 使 h = Wx 的各分量统计独立。

独立性判据：最大化非高斯性

中心极限定理说：多个独立信号的混合，会比任何单一信号更接近高斯。反过来，越不"高斯"的方向，越接近独立成分。常用度量是峭度（Kurtosis）：

kurt(h) = E[h⁴] − 3(E[h²])²

高斯变量的峭度恰为 0；均匀分布等"平坦"分布峭度为负（亚高斯）；稀疏、重尾分布峭度为正（超高斯）。ICA 即寻找使 |kurt| 最大化的投影方向（或用更稳健的负熵近似）。注意分界线：不相关（协方差为 0）只是二阶约束，独立要求所有阶统计都解耦——两个变量可以协方差为 0 却强依赖（如 h 均匀、x = h²）。

手算例 4：混合 → 白化 → 验证单位协方差

设两个独立源 s₁、s₂ 零均值、方差为 1，混合矩阵 A = [[2, 1], [1, 1]]，即 x = As。我们只拿到 x，分两步找回源。

第 1 步：算出观测的协方差。由 Cov(s) = I，得 Cov(x) = AAᵀ：

步骤算式结果
1. AAᵀ 的 (1,1) 元2×2 + 1×15
2. AAᵀ 的 (1,2) 与 (2,1) 元2×1 + 1×13
3. AAᵀ 的 (2,2) 元1×1 + 1×12
4. 观测协方差Cov(x) = AAᵀΣₓ = [[5, 3], [3, 2]]

第 2 步：白化。取白化矩阵 P = [[1/√5, 0], [−3/√5, √5]]（由 Σₓ 的 Cholesky 分解求逆得到），令 z = Px。逐格验证 Cov(z) = PΣₓPᵀ = I：

步骤算式结果
1. 先算 PΣₓ 第 1 行(1/√5)×(5, 3) + 0(√5, 3/√5)
2. PΣₓ 第 2 行(−3/√5)×(5,3) + √5×(3,2)(−3√5+3√5, −9/√5+2√5) = (0, 1/√5)
3. (PΣₓPᵀ)₁₁√5×(1/√5) + (3/√5)×01 ✓
4. (PΣₓPᵀ)₁₂√5×(−3/√5) + (3/√5)×√5−3 + 3 = 0 ✓
5. (PΣₓPᵀ)₂₁0×(1/√5) + (1/√5)×00 ✓
6. (PΣₓPᵀ)₂₂0×(−3/√5) + (1/√5)×√51 ✓

Cov(z) = I 验证完毕。但故事没完：算一下 z 与 s 的关系——z = PAs，而

PA = [[2/√5, 1/√5], [−1/√5, 2/√5]] —— 每行模长为 1，两行正交，恰是一个旋转矩阵

也就是说，白化之后 z 是源 s 的一个纯旋转：相关被消除了，但两个分量仍是两个源的混合，并不独立。任何旋转 R 都有 Cov(Rz) = RIRᵀ = I——白化（PCA 能做的全部）永远差一个旋转，而这最后一个旋转只有靠非高斯性判据（最大化 |kurt|）才能找到，这就是 ICA 比 PCA 多走的那一步。

ICA 的三种不唯一性

不唯一性含义为什么无妨
符号h 与 −h 同样独立说话声反相，内容不变
顺序h₁、h₂ 可对调谁先谁后只是命名
幅度h 与 c·h 无法区分（被 W 吸收）音量大小归一化即可

另外一条硬限制：最多只能有一个高斯源——两个高斯源的混合在任何旋转下都一样，ICA 对它们无能为力。

💡 关键一跃

PCA 与 ICA 的分工：PCA 消除二阶相关（白化），ICA 消除高阶依赖（旋转到独立）。前者只能走到"协方差为单位阵"，后者靠"非高斯性"走完最后一程——高斯分布没有方向偏好，非高斯分布有。

⚠️ 常见误区

"不相关就是独立"——错。不相关只约束二阶矩（E[h₁h₂]=E[h₁]E[h₂]），独立要求联合分布完全分解 p(h₁,h₂)=p(h₁)p(h₂)。反例：h 均匀分布于 [−1,1]，y = h²，则 Cov(h, y) = E[h³] − E[h]E[h²] = 0，但 y 完全被 h 决定——极端不独立。

13.5慢特征分析与稀疏编码：给第 14 章埋下的两条伏笔

线性因子模型的三条支路到此讲完，但它们共享一个沉默的假设：因子之间没有结构、没有偏好。本节介绍两个补充性的"偏好原则"，它们将在第 14 章以非线性的形式复活。

慢特征分析：时间上相邻的帧，因子应该相近

慢特征分析（Slow Feature Analysis，SFA）的出发点：真实世界的原因（物体身份、位置、光照）随时间变化得慢，而像素级的观测变化得快。于是给因子加一条约束——让学到的 h(t) 在时间维度上尽量平滑：

minimize   E[ ( h(t+1) − h(t) )² ]

配合"因子要有足够方差、彼此不相关"的约束（否则全学成常数就是平凡的"最慢"），SFA 能从视频序列里提取出"物体是什么"这类慢变量，而把快速抖动的像素细节滤掉。直觉：变得慢的，才配叫"原因"。

稀疏编码：每次只动用少数几个因子

稀疏编码（Sparse Coding）换了另一种偏好：不要求因子独立或慢，而要求对每一个样本，h 中只有少数分量非零：

minimize   ‖x − Wh‖² + λ ∑j |hj|

第一项是重构误差（x 要被 W h 解释好），第二项是稀疏惩罚（L1 范数逼大多数 hⱼ 为 0），λ 权衡两者。典型结果是 W 的列学成类似"视觉皮层简单细胞"的局部边缘检测器——每个输入只用少数几根"基"拼出来。稀疏编码的框架已经隐隐是"编码器 + 重构"的结构：把 x 编码成 h，再从 h 重构 x——这正是下一章自编码器（Autoencoder）的直系祖先，只差把"线性"换成"神经网络"。

💡 关键一跃

本章所有模型都在回答同一个问题的不同侧面：什么是"好"的因子？PPCA/FA 说"能解释协方差的"，ICA 说"统计独立的"，SFA 说"随时间慢的"，稀疏编码说"用得省的"。第 14 章会问：如果因子与观测之间根本不是线性关系呢？——答案是把 W 换成神经网络，这就是自编码器。

⚠️ 常见误区

"稀疏编码的稀疏性是为了省存储"——不是主要目的。稀疏性是一种归纳偏好：它逼模型把信息分摊到过完备的基上，学出局部化、可解释的特征；省存储只是副产品，表征质量才是动机。

点击翻面 →

点击翻面 →

📝分层习题

L1 概念辨析

判断对错："两个随机变量协方差为 0（不相关），它们就一定相互独立。"如果对，给出证明思路；如果错，给出一个具体反例并验证它"不相关但不独立"。

提示

想想 13.4 warning 框里的例子：让一个变量完全决定另一个变量，但把依赖关系藏在对称性里，使二阶矩恰好为 0。

完整解答

错。反例：设 h 在 [−1, 1] 上均匀分布，令 y = h²。

验证不相关：E[h] = 0（对称区间），E[h³] = 0（奇函数在对称区间积分为 0），所以 Cov(h, y) = E[h·h²] − E[h]·E[h²] = E[h³] − 0 = 0，二者不相关。

验证不独立：y 由 h 完全决定——知道 h 就唯一确定 y，没有任何随机性可言，p(y|h) 是退化分布，显然 p(h,y) ≠ p(h)p(y)。

为什么易错：高斯分布下"不相关 ⟹ 独立"成立，很多人把它当成了普遍规律。它只对联合高斯成立；一般分布里独立是远比不相关强的条件（所有阶统计都解耦），这正是 ICA 不能只靠 PCA 白化的原因。

L1 概念辨析

填空并说明理由：PCA / 概率 PCA / 因子分析三者中，假设噪声协方差为 σ²I 的是____；假设噪声协方差为对角阵 Ψ 的是____；可视为 σ²→0 极限的是____。哪一个模型允许因子方向任意旋转？为什么？

提示

回忆 13.3 的"噪声假设光谱"：无噪声 → 球形噪声 → 对角噪声。旋转自由度看"WWᵀ 在似然里出现时右乘正交阵是否改变似然"。

完整解答

σ²I：概率 PCA；Ψ：因子分析；σ²→0 的极限：经典 PCA（是概率 PCA 的极限）。

允许任意旋转的是因子分析：它的似然只通过 WWᵀ + Ψ 依赖 W，对 W 右乘任何正交阵 R，(WR)(WR)ᵀ = WRRᵀWᵀ = WWᵀ，似然完全不变，故因子方向不可辨识，需要额外的旋转准则（如心理学中的 varimax）。PCA 则不同：主方向按特征值大小排序，旋转会破坏这个排序，方向唯一（只差符号）。

L2 手算推导

概率 PCA，n = 2 维观测、k = 1 维因子。当前 W = (1, 0)ᵀ，σ² = 1，μ = (0, 0)ᵀ，观测到 x = (2, 2)ᵀ。① 按 E 步公式手算后验 p(h|x) 的均值与方差（M 的构造、求逆、各步乘法写全）；② 解释为什么后验方差小于先验方差 1。

提示

照搬 13.2 手算例 1 的七步表：M = WᵀW + σ²I 是 1×1 标量；注意 W 的第二个分量是 0，x 的第二维还起不起作用？

完整解答

① 逐步计算：

1. WᵀW = 1×1 + 0×0 = 1
2. M = WᵀW + σ²I = 1 + 1 = 2
3. M⁻¹ = 1/2 = 0.5
4. x − μ = (2, 2)ᵀ
5. Wᵀ(x − μ) = 1×2 + 0×2 = 2
6. 后验均值 = M⁻¹Wᵀ(x−μ) = 0.5 × 2 = 1
7. 后验方差 = σ²M⁻¹ = 1 × 0.5 = 0.5

所以 p(h|x) = 𝒩(1, 0.5)。

② 后验方差 0.5 < 先验方差 1：观测 x 带来了关于 h 的信息，不确定性被压缩；这正是贝叶斯推断"数据收紧信念"的体现。注意 x 的第二维（值为 2）没有进入计算——因为 W 的第二分量为 0，说明当前模型认为因子 h 不影响观测的第二维，该维的信息对推断 h 无用。

L2 手算推导

对某个候选源信号，观测到 3 个样本值：h = −2, 1, 1（已零均值）。① 用样本均值代替期望，手算峭度 kurt(h) = E[h⁴] − 3(E[h²])²，每一步写全；② 根据符号判断它是亚高斯还是超高斯；③ 说明为什么"峭度非零"使它适合被 ICA 分离。

提示

先算 E[h²]，再算 E[h⁴]，最后代入公式。对照组：高斯的峭度恰为 0。

完整解答

① 逐步计算：

1. E[h²] = ( (−2)² + 1² + 1² ) / 3 = (4 + 1 + 1)/3 = 6/3 = 2
2. E[h⁴] = ( (−2)⁴ + 1⁴ + 1⁴ ) / 3 = (16 + 1 + 1)/3 = 18/3 = 6
3. 3(E[h²])² = 3 × 2² = 12
4. kurt(h) = 6 − 12 = −6

② kurt = −6 < 0，是亚高斯（比高斯更平坦，如均匀分布一族）。

③ ICA 的判据是最大化非高斯性：高斯峭度恰为 0，混合信号比任何单源更接近高斯（中心极限定理），因此 |kurt| 越大、离 0 越远，说明该方向越可能是独立成分。kurt = −6 显著偏离 0，该源非高斯性强，适合被 ICA 分离；若算出来接近 0，则 ICA 对该源无能为力（高斯源在任何旋转下都一样）。

L3 建模应用

场景：一间会议室里 3 个人同时讲话，房间四周布了 6 个麦克风，录到 6 路混合波形。① 选模型：为什么选 ICA 而不是 PCA 或因子分析？② 写出生成假设（各符号的维度标清楚）；③ 用 mermaid 画出"3 个源 → 混合 → 6 路观测 → 白化降维 → 旋转解混 → 3 路独立信号"的结构；④ 说出用 ICA 的两条理由与两条局限。

提示

三个说话人说话内容互相影响吗？这对应哪个假设？6 路观测、3 个源，ICA 通常需要方阵混合——先用哪一步把 6 降到 3？想想混响和"源最多一个高斯"的限制。

完整解答

① 选 ICA：三个说话人说话的内容统计上相互独立，这是本场景最强的先验。PCA 只能去相关（二阶），分不开混合；因子分析假设高斯因子，而高斯在任何旋转下不可辨识，同样分不开。只有 ICA 以"统计独立"为目标，匹配场景。

② 生成假设：x = As + ε，其中 s ∈ R³（3 个源，独立、非高斯），A ∈ R⁶ˣ³（6×3 混合矩阵，由麦克风位置与声学路径决定），x ∈ R⁶（6 路观测），ε 为小噪声（常忽略）。

③ 结构图：

flowchart TB S["3个说话人 独立非高斯源 s"] --> M["线性混合 x = As"] M --> X["6路麦克风观测 x"] X --> W1["PCA白化并降维 6到3"] W1 --> R["ICA找旋转 最大化非高斯性"] R --> O["3路分离信号 h"]
盲源分离流水线：白化把问题化为旋转，ICA 靠非高斯性找到最后的旋转。

④ 理由与局限：理由（a）独立性假设与"各说各话"精确匹配；（b）白化降维（6→3）后只需估计一个 3×3 旋转，参数少、可求解。局限（a）模型是瞬时线性混合，真实会议室有混响与传播延迟，卷积混合下 ICA 失效或需卷积扩展；（b）分离结果有符号、顺序、幅度三种不唯一，若某个说话人信号接近高斯（如稳态嗡鸣）则无法分离（最多容忍一个高斯源）。

自测 2
概率 PCA 中，E 步后验 p(h|x) 的协方差是 σ²M⁻¹（M = WᵀW + σ²I）。在 M 步更新 W 时，E[hhᵀ] 应该怎么算？
  • A. 直接等于 E[h]E[h]ᵀ，后验均值乘自己的转置就行
  • B. 等于 σ²M⁻¹ + E[h]E[h]ᵀ，必须把后验不确定性加回来
  • C. 等于 σ²I，与 W 无关
  • D. 等于单位阵 I，因为先验是 𝒩(0, I)
解析：B 对——二阶矩 = 协方差 + 均值外积：E[hhᵀ] = Var[h|x] + E[h]E[h]ᵀ = σ²M⁻¹ + E[h]E[h]ᵀ。A 错：丢掉 σ²M⁻¹ 等于假装 h 被精确观测，系统性高估二阶矩，EM 的似然单调性保证随之失效。C 错：后验协方差依赖 W（通过 M），并非常数 σ²I。D 错：那是先验协方差，观测 x 之后不确定性已被压缩为 σ²M⁻¹。
自测 3
关于 PCA 与因子分析，下列说法正确的是？
  • A. 因子分析就是旋转后的 PCA，两者数学上完全等价
  • B. PCA 允许因子方向任意旋转，因子分析的方向唯一
  • C. 因子分析的噪声协方差是 σ²I，比 PCA 的 Ψ 更一般
  • D. 经典 PCA 是概率 PCA 在 σ²→0 时的极限；因子分析改用对角噪声 Ψ，其似然只依赖 WWᵀ，故因子方向允许任意旋转，而 PCA 的主方向由方差排序唯一确定
解析：D 对——三个要点都在：极限关系、对角噪声、旋转自由度的不对称（13.3 手算例中同一 Σ 下 PCA 给 31.7°、FA 给 45°）。A 错：噪声模型不同，似然不同，二者不等价。B 错：恰好说反——旋转自由度属于 FA（WWᵀ 不变），PCA 方向唯一。C 错：也说反——FA 用 Ψ（对角阵），PPCA 才用 σ²I；Ψ 比 σ²I 更自由。
自测 4
ICA 凭什么做到 PCA 做不到的"分离"？
  • A. ICA 要求分量统计独立而非仅不相关，靠最大化非高斯性（如 |峭度|）找到白化之后剩下的那个旋转；PCA 消除二阶相关后，任何旋转都保持单位协方差，无法定方向
  • B. ICA 用的数据比 PCA 多
  • C. ICA 是非线性模型，PCA 是线性模型
  • D. ICA 假设源是高斯的，比 PCA 的假设更强
解析：A 对——白化后 z 与源只差一个旋转（13.4 中 PA 恰为旋转矩阵），二阶方法到此为止；非高斯性给分布带来"方向偏好"，才能锁定旋转。B 错：差别在判据而非数据量。C 错：ICA 同样是线性混合模型 x = As。D 错：恰恰相反，ICA 要求源非高斯——若源全是高斯，任何旋转都不可区分，ICA 失效（最多容忍一个高斯源）。
自测 5
下列关于 ICA 不唯一性与稀疏编码的说法，正确的是？
  • A. ICA 能唯一确定每个源的符号、顺序与幅度，只是计算较慢
  • B. ICA 无法确定源的符号、顺序、幅度（分别对应反相、换序、缩放后仍独立）；稀疏编码的目标函数是重构误差加 L1 稀疏惩罚，其"编码+重构"结构是自编码器的线性祖先
  • C. ICA 的不唯一性说明它没有实用价值
  • D. 稀疏编码的稀疏惩罚是为了压缩存储空间
解析：B 对——h 与 −h、换序、c·h 同样满足独立性（幅度被 W 吸收），这三种不唯一无妨应用；稀疏编码 min ‖x−Wh‖² + λΣ|hⱼ| 正是 Ch14 稀疏自编码器的前身。A 错：这三项恰是原理上无法确定的。C 错：分离语音时反相、换序、缩放都不影响内容与后续处理。D 错：稀疏性是为表征质量服务的归纳偏好（学出局部的、可解释的基），省存储只是副产品。

🗣️ 用自己的话，三句话讲完本章

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：高维观测数据其实只有少量自由度（人脸照片由光照、姿态、身份几十个因素生成），本章回答"如何用少量隐因子解释高维观测数据"——用潜变量模型 x = Wh + μ + ε 把观测间的相关结构归因于看不见、带先验的因子 h。
句2：核心机制是什么？——
参考答案：同一个生成骨架，按先验与噪声假设分三支——p(h) 高斯 + 球形噪声得概率 PCA（用 EM 训练，E 步后验 𝒩(M⁻¹Wᵀ(x−μ), σ²M⁻¹)，σ²→0 退化为经典 PCA）；噪声改对角阵 Ψ 得因子分析（方向允许旋转）；h 改非高斯独立得 ICA（白化后靠最大化峭度等非高斯性判据找到最后的旋转）。
句3：它和前后章怎么分工？——
参考答案：第12章展示了深度学习的应用，本章开启"表示与推断"阶段，给出线性表示的极限与全部家底；线性混合解释不了真实数据的非线性因子，慢特征与稀疏编码已露出"编码+重构"的雏形——第14章把线性映射换成神经网络，就是自编码器。
