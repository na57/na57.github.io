20.1玻尔兹曼机家族：RBM、DBN、DBM

第16章把无向模型定义为 p(x) = p̃(x)/Z，当时就说 Z 算不动。玻尔兹曼机家族是这条路线最纯正的后代：明知 Z 算不动，依然用能量函数建模，训练和采样全靠第17、18章的武器硬撑。最核心的成员是受限玻尔兹曼机（Restricted Boltzmann Machine, RBM）：可见层 v 与隐藏层 h 两层二值单元，层内无连接、层间全连接——"受限"指的就是砍掉层内连接这一条。

它的能量函数为：

E(v, h) = −vᵀWh − bᵀv − cᵀh，p(v, h) = e−E(v,h)Z

先算一笔维度账。MNIST 图像：v 是 784 维像素，h 取 500 个隐藏单元。参数只有三块：连接矩阵 W 是 784×500，可见偏置 b 是 784，隐藏偏置 c 是 500，合计 392000 + 784 + 500 = 393 284 个参数——训练侧完全可承受。但配分函数 Z 要对 (v, h) 的全部 2¹²⁸⁴ 个状态求和：2¹²⁸⁴ ≈ 10³⁸⁶，比全宇宙原子数（约 10⁸⁰）大了 300 多个数量级。参数账很省，归一化账彻底算不动——这就是无向模型的宿命。

Z 算不动，但条件分布好算。"受限"买来的最大礼物是：给定 v 时各隐藏单元相互独立，给定 h 时各可见单元相互独立。推导只一步：能量函数对 h_j 是线性的，p(h_j=1|v) 正比于 e 的线性指数，归一化两项即得 sigmoid：

p(h_j = 1 | v) = σ(c_j + vᵀW_:j)，p(v_i = 1 | h) = σ(b_i + W_i: h)

完整手算一个最小例子。设某个隐藏单元与两个可见单元相连，权重 w = (2, −1)，偏置 c = 0，可见层取值 v = (1, 1)。分值 = c + vᵀw = 0 + (1×2 + 1×(−1)) = 1，于是：

p(h = 1 | v) = σ(1) = 11 + e−1 ≈ 0.731

两个条件分布都便宜，第17章的 Gibbs 采样就能整块地用：交替采样 h|v 与 v|h（块 Gibbs，block Gibbs，一次更新一整层而不是一个变量）。训练时的正相用数据，负相需要模型分布的样本——用第18章的 CD-k 只跑 k 步链。前面章节的两件武器在这里合流：采样靠第17章的块 Gibbs，训练靠第18章的 CD-k。

家族另两名成员。深度信念网络（Deep Belief Network, DBN）：把多个 RBM 逐层训练后堆叠，下层连接改作有向（生成时自顶向下），只有顶层联合分布保持无向——是一种有向+无向的混合结构，预训练权重再用作前馈网络的初始化，这是 2006 年点燃深度学习复兴的那把火。深度玻尔兹曼机（Deep Boltzmann Machine, DBM）：多层全部无向，理论更纯粹，但层间相互耦合使条件分布不再独立，推断必须借助第19章的均值场近似——第三件武器在此合流。

💡 关键一跃

RBM 的全部工程智慧就一条：用"层内无连接"把联合分布的难题切成条件分布的易事。联合 p(v,h) 有 2¹²⁸⁴ 个状态算不动，但每个条件 p(h_j|v) 只是一个 sigmoid。第17章早就说过：MCMC 不需要知道 Z，只需要能算条件分布或能量比。

⚠️ 常见误区

把"受限"理解成"简单到能精确计算"。错。"受限"只让条件分布简单了，配分函数 Z 依然是 2¹²⁸⁴ 个状态的求和，依然算不动；CD-k 的梯度仍然是有偏近似。RBM 不是绕开了 Z，而是学会了在 Z 的阴影下生存。

20.2有向生成模型与生成随机网络（GSN）

上一节的麻烦全来自无向模型的 Z。第二条路线干脆釜底抽薪：用有向图建模，条件概率逐个归一化，联合分布自动归一——Z 根本不存在。最简单的代表是sigmoid 信念网络（Sigmoid Belief Network）：一个以 sigmoid 为条件分布的有向无环图模型，p(x) = ∏ᵢ p(xᵢ | 父节点)，每个条件项自己归一，乘积自然归一。

但天下没有免费的午餐。有向模型把归一化的难题消灭了，却把难题转移到了推断上：给定可见单元求隐藏单元的后验 p(h|v)，在有向图里会因"解释远离"（explaining away）而高度耦合，精确后验同样指数级。这正是第19章变分推断的主战场——用 q(h) 近似真实后验。无向模型难在训练（Z），有向模型难在推断（后验），总有一个地方要付账。

本节第二个角色更有野心。生成随机网络（Generative Stochastic Network, GSN）：既然第17章的马尔可夫链能从复杂分布采样，为什么不把马尔可夫链本身当模型来学？GSN 用一个神经网络参数化转移算子 p(x′|x)（典型地学一个"去噪"转移：把被污染的数据点拉回数据流形），采样就是反复运行这条链。训练时只需让每一步转移分布靠近目标条件分布，每步都是归一化的——又一次绕开了 Z。

算一笔维度账看 GSN 的妙处。RBM 的联合状态有 2¹²⁸⁴ 个，而 GSN 每步只是一个条件分布网络：输入一个 784 维向量、输出一个 784 维向量，参数量取决于网络宽度而与状态空间大小无关——2ⁿ 的诅咒从模型结构里被删除了。代价是：采样仍要走马尔可夫链，继承了链的全部毛病（相关、要暖机、混合慢）。

✅ 判定规则

两类模型放在主线上的位置：sigmoid 信念网络把账从"训练"转嫁给"推断"，配第19章武器；GSN 把"采样算法"升级成"模型本身"，配第17章武器。看一个生成模型，先问两句话：Z 去哪了？后验谁算？——答案就定位了它在全景图里的坐标。

⚠️ 常见误区

以为有向模型"没有 Z 就全面优于无向模型"。有向模型消灭了归一化难题，却引入了推断难题和结构假设（必须指定变量顺序或父节点）；无向模型表达对称关系更自然。选哪边取决于你要频繁算的是什么：频繁采样选有向，频繁做条件化推理则要看后验是否好近似。

20.3变分自编码器（VAE）

有向模型好采样但后验难算，第19章给了变分推断这件武器：用一个参数化的 q(z|x) 逼近真后验，最大化证据下界 ELBO。变分自编码器（Variational Autoencoder, VAE）就是把这件武器做成神经网络的标准产品：生成模型 p(x|z) 与推断模型 q(z|x) 各用一个网络，联合训练。编码器把图像压成隐变量分布，解码器把隐变量还原成图像——第14章自编码器的概率版。

先算结构账。经典 VAE 在 MNIST 上：编码器 784 → 400 → 输出 μ 和 σ 各 20 维，解码器 20 → 400 → 784。参数量逐块数：784×400 ≈ 31.4 万，400→(20+20) 约 1.6 万，20×400 = 0.8 万，400×784 ≈ 31.4 万，合计约 65 万个参数，隐空间只有 20 维——一张 784 像素的图被压缩进 20 个高斯旋钮。

训练目标是最大化 ELBO（第19章的记号）：

ELBO = Ez∼q[ log p(x|z) ] − KL( q(z|x) ‖ p(z) )

第一项是重建项：从 q 采出 z，解码器还原 x 的似然越高越好；第二项是 KL 正则项：q(z|x) 别偏离先验 p(z) = N(0, I) 太远。当 q 和 p 都是高斯时，KL 有闭式解，一维情形：

KL = 12(μ² + σ² − 1 − ln σ²)

完整手算一项：编码器对某维度输出 μ = 0.5、σ = 1，则 KL = ½(0.25 + 1 − 1 − ln 1) = ½ × 0.25 = 0.125。直觉对照：σ = 1 恰好等于先验方差，唯一被罚的是均值偏离了 0 半个单位。

还剩一个工程难关：z 是从 q(z|x) 采出来的，采样操作不可导，梯度怎么传回编码器？重参数化技巧（Reparameterization Trick）：把"采 z ∼ N(μ, σ²)"改写为"采 ε ∼ N(0,1)，算 z = μ + σε"。随机性被挪进与参数无关的 ε，μ 和 σ 到 z 的路径变成纯计算——梯度顺着加法和乘法流回编码器。这是第17章逆变换采样思想（标准高斯好采）与第19章变分目标的合流。

💡 关键一跃

VAE 是"用可优化性换精确性"的典范：真实似然 log p(x) 算不动，就最大化它的下界 ELBO；下界与真值之间的缝隙恰好是 KL(q‖真后验)——推断越准，缝隙越小。一笔买卖：接受一个下界，换来端到端的梯度训练。

⚠️ 常见误区

抱怨"VAE 生成的图模糊，是不是实现有 bug"。多半不是 bug，是目标使然：重建项用逐像素似然，最优解是对多个合理取值的平均，平均出来就是模糊；KL 项又把后验往标准高斯上拉，进一步压缩信息量。想要锐利图像，换目标（如 GAN）而不是修 bug。

20.4生成对抗网络（GAN）与自回归模型

收官一节的两位主角走了两个极端。生成对抗网络（Generative Adversarial Network, GAN）比 VAE 更激进：连似然的下界都不要了。它把生成建模改写成一场双人博弈：生成器 G 从噪声 z 造样本，判别器 D 判断样本是真是假，两者对同一个价值函数做零和对抗：

minG maxD V = Ex∼p_data[log D(x)] + Ez[log(1 − D(G(z)))]

先求最优判别器。固定 G，V 对 D 逐点求极值：形如 a·log D + b·log(1−D) 的函数在 D = a/(a+b) 处取最大，因此：

D*(x) = pdata(x)pdata(x) + pg(x)

完整手算一个点：某区域真实数据密度 p_data = 0.6、生成密度 p_g = 0.2，则 D* = 0.6/(0.6+0.2) = 0.75——判别器输出"75% 像真的"，不武断地押 0 或 1，而是如实反映两个密度的比例。

再把 D* 代回 V，可以得到 G 真正在优化的东西：

V(D*) = −log 4 + 2 · JSD(pdata ‖ pg)

JSD 是 Jensen-Shannon 散度，非负、当且仅当两分布相等时为 0。所以 G 的全局最优是 p_g = p_data，此时 V(D*) = −log 4 ≈ −1.386，JSD = 0，判别器对所有输入都输出 0.5——彻底分不清真假，博弈达到纳什均衡。

理论漂亮，训练难缠，三大著名困难。①min-max 不收敛只震荡：梯度下降-上升在鞍点附近打转，loss 曲线抖个不停却无法判断是收敛中还是发散中。②模式坍塌（Mode Collapse）：生成器发现骗过判别器不需要学会所有模式，把千差万别的 z 全映射到少数几个输出——造一百张"手写数字"全是同一个 7。③梯度消失：D 太完美时 log(1−D(G(z))) 饱和趋平，G 收不到梯度信号；实践中常改用 log D(G(z)) 让梯度更肥。

另一个极端是自回归模型（Autoregressive Model）：用概率链式法则把联合分布拆成 p(x) = ∏ᵢ p(xᵢ | x₁, …, x_{i−1})，每个条件用一个网络输出（如 256 类 softmax）。每个条件自己归一，乘积自动归一——根本没有 Z！维度账：一张 28×28 的图拆成 784 个条件分布，每个是像素值上的 256 类 softmax；似然精确可算，训练就是普通的极大似然。代价：生成必须逐像素串行，784 次前向才能出一张图，快不起来。GAN 牺牲似然换样本质量，自回归牺牲速度换精确似然——全景图的两极。

💡 关键一跃

这张表就是全书的句号：每个生成模型都是对"Z 怎么办"的一种回答。硬打（RBM/DBN/DBM）、结构性绕开（GSN/VAE/自回归）、干脆换游戏规则（GAN）。没有免费的午餐，只有不同的账单——选型就是选你愿意付哪种代价。

⚠️ 常见误区

问"GAN 和 VAE 谁的似然大"。GAN 没有显式似然，这个问题在结构上无答案——评估 GAN 只能靠间接手段（样本质量、最近邻对比、人工评价），这不是工程缺陷而是设计选择的后果。拿似然标准要求 GAN，等于用体重标准要求百米运动员。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
受限玻尔兹曼机（RBM）
点击翻面 →
定义可见层×隐藏层、层内无连接的无向能量模型，E = −vᵀWh − bᵀv − cᵀh。
解决问题用可分解的条件分布表达联合分布，学数据的隐藏结构。
直觉受限换条件独立：联合算不动，条件全是 sigmoid。
误区以为受限=简单——Z 仍对 2 的 1284 次方个状态求和。
何时用二值/近二值表示学习；DBN 的砖块；CD-k 的练兵场。
概念卡 2
深度信念网络（DBN）
点击翻面 →
定义多个 RBM 逐层预训练后堆叠：下层有向生成、顶层无向联合的混合模型。
解决问题2006 年首次证明深层网络可以有效训练，点燃深度学习复兴。
直觉一层一层学，每层只需解决一个 RBM 的小问题。
误区把它当全无向模型——只有顶层联合无向，下层是有向的。
何时用无标注数据预训练初始化；历史上的深网破冰船。
概念卡 3
深度玻尔兹曼机（DBM）
点击翻面 →
定义多层全部无向的能量模型，层间全连接。
解决问题比 DBN 更纯粹的无向多层表示，双向推断。
直觉每层既被下层证据推、又被上层先验拉。
误区以为比 RBM 只是"更深"——条件独立性丢失，推断必须均值场。
何时用需要双向推断的无向深模型；第19章均值场的最大客户。
概念卡 4
生成随机网络（GSN）
点击翻面 →
定义把马尔可夫链的转移算子本身参数化（学去噪转移）的生成模型。
解决问题把第17章的 MCMC 从"算法"升级成"模型"。
直觉学"走一步"而非"全局分布"，采样就是反复走。
误区以为绕开 Z 就零代价——继承链的相关与慢混合。
何时用去噪式生成；后来扩散模型的思想祖先。
概念卡 5
变分自编码器（VAE）
点击翻面 →
定义编码器 q(z|x) + 解码器 p(x|z)，最大化 ELBO 的隐变量模型。
解决问题让有向隐变量模型的推断与训练端到端可微。
直觉重建 + KL 拉正则，用下界换可优化性。
误区生成模糊当 bug——是逐像素似然目标的平均化本性。
何时用要平滑隐空间、可插值、近似似然可算的场景。
概念卡 6
生成对抗网络（GAN）
点击翻面 →
定义G 造假、D 辨假的 min-max 博弈；最优时 p_g = p_data，V = −log 4。
解决问题绕开显式似然，直接逼近"样本真假难辨"。
直觉造假者与鉴定师互相升级，直到以假乱真。
误区问它的似然——结构性无答案；震荡不收敛是常态。
何时用要锐利高质样本、不需要显式似然的生成任务。
概念卡 7
自回归模型（Autoregressive Model）
点击翻面 →
定义p(x) = ∏ᵢ p(xᵢ|x₁..xᵢ₋₁)，逐维条件分布相乘。
解决问题链式分解自带归一化——根本没有 Z，似然精确可算。
直觉像写作文：一个字一个字往外蹦，每个字看前面所有字。
误区以为精确似然=全面最优——生成串行，784 次前向出一张图。
何时用要精确似然与密度评估；序列数据的天然选择。

📝分层习题

L1 概念辨析判断对错：RBM 的"受限"使配分函数 Z 可以被精确计算。
提示

"受限"砍的是哪种连接？它让什么变简单了？Z 的定义变了吗？

完整解答
错。受限（层内无连接）让条件分布 p(h|v)、p(v|h) 分解为独立 sigmoid 的乘积，好算；但 Z = Σ_{v,h} e^(−E) 依然要对全部 2 的 (n_v+n_h) 次方个状态求和（784+500 维就是 2¹²⁸⁴），精确计算依然不可能。条件容易 ≠ 归一化容易，这是无向模型的结构性宿命。
L1 概念辨析判断对错：GAN 训练稳定后，可以通过最大化似然来评估它学得好不好。
提示

GAN 的模型定义里出现过 p_g(x) 的显式表达式吗？

完整解答
错。GAN 的生成器只定义了从 z 到样本的映射，从不给出 p_g(x) 的显式密度——似然在结构上就不存在，无从最大化也无从精确评估。评估只能靠间接代理（样本质量、最近邻对比等）。这是设计选择的后果，不是实现缺陷。
L2 手算推导RBM 中某隐藏单元连接三个可见单元，w = (1, 2, −1)，c = 0.5，v = (1, 0, 1)。(a) 求 p(h=1|v)；(b) 若 v 换成 (0, 1, 1)，概率变为多少？(c) 解释为什么同样的 w 对不同 v 给出不同概率。已知 σ(0.5)≈0.622，σ(1.5)≈0.818。
提示

先算分值 c + vᵀw，再过 sigmoid。注意 vᵀw 只对 v_i = 1 的维度求和。

完整解答
(a) 分值 = 0.5 + (1×1 + 0×2 + 1×(−1)) = 0.5 + 0 = 0.5，p = σ(0.5) ≈ 0.622；
(b) 分值 = 0.5 + (0×1 + 1×2 + 1×(−1)) = 0.5 + 1 = 1.5，p = σ(1.5) ≈ 0.818；
(c) 隐藏单元是可见模式的"检测器"：vᵀw 度量当前可见向量与权重模式的吻合度，吻合度越高分值越大、激活概率越高。RBM 的每一列权重学的就是一种它"想看"的特征。
L2 手算推导GAN 中，固定 G 后某点 p_data(x) = 0.8、p_g(x) = 0.8。(a) 求 D*(x)；(b) 求该点对 V 的贡献密度 a·logD + b·log(1−D) 的值；(c) 若全空间处处如此，V(D*) 等于多少？log 2 ≈ 0.693。
提示

(a) 套 D* = a/(a+b)；(b) 代入 D*=0.5 算两项之和；(c) 对照 V(D*) = −log 4 + 2·JSD 的公式。

完整解答
(a) D* = 0.8/(0.8+0.8) = 0.5——两密度相等时判别器完全无法区分；
(b) 0.8·log 0.5 + 0.8·log 0.5 = 1.6·(−0.693) ≈ −1.109；
(c) p_g = p_data 全局成立时 JSD = 0，V(D*) = −log 4 = −2×0.693 ≈ −1.386。
物理含义：纳什均衡点，判别器收益被压到理论下限，生成器胜利毕业。
L3 建模应用你要为一个百万张无标注图像的数据集建生成模型，需求：(i) 训练快、稳定；(ii) 需要给新图像一个密度分数做异常检测；(iii) 生成质量中等即可。从七类模型中选一类并给出理由，说明它用了第17/18/19章的哪件武器，再指出被排除的六类各因哪一条需求出局。
提示

需求(ii)要密度分数——哪些模型根本没有显式似然？需求(i)要稳定——谁靠 min-max 博弈、谁靠有偏短链？

完整解答
选 VAE。理由：ELBO 是单目标下界优化，训练稳定（满足 i）；q(z|x) 给出近似似然下界可当密度分数（满足 ii）；生成模糊但需求只要"中等"（满足 iii）。调用第19章武器：变分推断 + 重参数化让梯度穿采样。
排除：RBM/DBN/DBM——Z 算不动、密度分数无从谈起（败于 ii），CD 训练还有偏（败于 i）；GSN——链式采样无密度分数（败于 ii）；GAN——结构性无似然（败于 ii）且 min-max 不稳定（败于 i）；自回归——似然精确但百万规模下逐像素串行生成与逐维求值都太贵（险败于 i，密度评估成本也高）。
一句话：需求(ii)一出手，全景图就只剩有显式似然的三家，需求(i)再淘汰两家。

自测 1
784×500 的 RBM（含偏置）参数量与配分函数 Z 的求和规模分别是？
  • A. 参数约 39 万个，Z 对 2⁵⁰⁰ 个状态求和
  • B. 参数 393 284 个，Z 对 2¹²⁸⁴ 个状态求和
  • C. 参数约 40 万个，Z 对 784×500 个状态求和
  • D. 参数 393 284 个，Z 只需对可见层 2⁷⁸⁴ 个状态求和
解析：B 对——W 是 784×500 = 392 000，加偏置 784 + 500，共 393 284；Z 要对 (v,h) 联合的 2 的 (784+500) = 2¹²⁸⁴ 个状态求和。A 错在漏算了可见层的 2⁷⁸⁴ 倍；C 把"参数形状"当成了状态数，状态是每个单元 0/1 取值的组合，是指数而非乘积；D 错在 Z 的定义是联合分布的归一化，隐藏层的状态也必须求和（即便解析上可分解出部分和，代价依然指数级）。
自测 2
DBN 与 DBM 的结构差别是？
  • A. DBN 全无向，DBM 有向+无向混合
  • B. DBN 只有一层，DBM 有多层
  • C. DBN 下层有向、仅顶层联合无向（混合结构）；DBM 多层全部无向
  • D. 两者结构完全相同，只是训练算法不同
解析：C 对——这是两者的本质区别，也决定了训练难度：DBN 下层有向所以逐层预训练后生成容易；DBM 全无向所以推断要靠均值场。A 恰好说反了；B 错：两者都是多层；D 错：有向/无向是图结构的差别，不只是算法差别——结构决定条件独立性，进而决定一切。
自测 3
VAE 中编码器输出 μ = 0.5、σ = 1（一维），KL(q‖N(0,1)) = ½(μ²+σ²−1−lnσ²) 的值是？重参数化写为？
  • A. 0.125；z = μ + σε，ε∼N(0,1)
  • B. 0.25；z = μ + σε，ε∼N(0,1)
  • C. 0.125；z = μ · σε，ε∼N(0,1)
  • D. 0；z = μ + σε，ε∼N(0,1)
解析：A 对——½(0.25+1−1−ln1) = ½×0.25 = 0.125；重参数化是加法+缩放：z = μ + σε。B 忘了公式前面的 ½；C 把加法写成乘法，那样 z 的均值不再是 μ，且 σ→0 时 z 不趋近 μ，完全错了；D 错在以为 σ=1 就零惩罚——σ 虽等于先验方差，但 μ=0.5 偏离了先验均值，仍要付 0.125。
自测 4
固定 G 时 GAN 的最优判别器是？某点 p_data = 0.6、p_g = 0.2 时 D* 为？
  • A. D* = p_data − p_g；0.4
  • B. D* = p_data / p_g；3
  • C. D* = p_g / (p_data + p_g)；0.25
  • D. D* = p_data / (p_data + p_g)；0.75
解析：D 对——对 a·logD + b·log(1−D) 求导置零得 D* = a/(a+b)，代入 0.6/0.8 = 0.75。A 的差值可能为负，不是概率；B 的比值可能大于 1，且 p_g→0 时发散，判别器输出必须在 [0,1]；C 把分子放错了——输出应是"为真的概率"，当然用 p_data 做分子。
自测 5
自回归模型 p(x) = ∏ᵢ p(xᵢ|x₁..xᵢ₋₁) 为什么没有配分函数 Z？
  • A. 因为 Z 被近似成了一个常数，实践中可以忽略
  • B. 每个条件分布自己归一化，乘积自动归一，Z 结构性不存在
  • C. 因为用了 MCMC 采样，Z 在接受率里约掉了
  • D. 因为自回归模型是无向图模型，无向模型没有 Z
解析：B 对——链式分解的每个因子 p(xᵢ|前文) 都是合法的概率分布（如 256 类 softmax，和为 1），归一化分布的乘积依然归一，从头到尾不需要 Z。A 错：不是近似，是精确不存在；C 张冠李戴：那是 MCMC 绕开 Z 的方式，自回归根本不走链；D 错得离谱：恰好相反，是无向模型才有 Z，自回归是有向链式分解。

句1：这章解决什么问题？——
参考答案：第16章以来所有生成模型都卡在同一笔账上——配分函数 Z 对指数级状态求和。本章总清算七类深度生成模型，看它们各自如何对付这笔账、付什么代价。

参考答案：这是全书主线收官——第16章提出 Z 这笔账，第17章给采样武器（MCMC/Gibbs），第18章给绕开训练的目标（CD-k 等），第19章给近似推断（变分/均值场）；本章七类模型各自从武器库选用一件或几件：RBM 用 17+18，DBM 用 17+18+19，VAE 用 19，GAN 索性不要似然。每个模型都是对"Z 怎么办"的一种回答。
