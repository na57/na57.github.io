2.1从神经网络的一层说起：y = Wx + b

第1章说：神经网络就是"对数据反复做简单变换"。这句话听起来抽象，但它的第一层完全可以写出来、算出来。一个有两个输入、两个神经元（输出）的层，做的是这件事：

y = Wx + b

其中每个符号都有明确身份。线性代数给不同"形状"的数起了名字，这套术语全书通用：

第一步：算 Wx。矩阵乘向量的规则是"行点乘列"——W 的第 i 行与 x 逐分量相乘再求和，得到结果的第 i 个分量：

  • 第 1 个输出：y₁ 的"矩阵乘"部分 = 2×3 + 1×4 = 6 + 4 = 10
  • 第 2 个输出：y₂ 的"矩阵乘"部分 = 0×3 + (−1)×4 = 0 − 4 = −4

  • y₁ = 10 + 1 = 11
  • y₂ = −4 + 2 = −2

读法：W 的第 1 行 (2, 1) 是"第 1 个神经元给两个输入各配的权重"，它把输入加权混合；偏置 b₁ 是这个神经元自带的基准偏移。整个深度学习，说到底就是这个动作重复几百层（中间再夹非线性，见第 6 章）。

矩阵乘法的形状规则：(m×n) 矩阵乘 (n×1) 向量 → (m×1) 向量。内层的 n 必须对上，否则乘法不成立。上面的例子里 (2×2)·(2×1) → (2×1)，合法。

💡 关键一跃

一个矩阵就是一个"线性变换"的完整说明书：W 的第 i 行告诉你第 i 个输出"怎么混合"输入。记住这一句，本章后面所有工具（逆、特征值、SVD）都是在解剖这本说明书。

⚠️ 常见误区

"矩阵乘法是逐元素相乘"——错。逐元素相乘叫 Hadamard 积（记作 A ⊙ B），是另一种运算；默认的矩阵乘 AB 永远是"行点乘列"，AB 的第 (i, j) 个元素 = A 的第 i 行点乘 B 的第 j 列。

2.2范数：给"大小"一把尺

2.1 节给出了变换的语言。但训练网络时我们时刻要问："这个误差有多大？""这批参数有多大？"——向量和矩阵不是单个数，"大小"必须人为定义。范数（Norm）就是把向量映射成一个非负实数的函数 ‖·‖，满足三条公理：非负（且只在零向量处为 0）、齐次（‖αx‖ = |α|·‖x‖）、三角不等式（‖x+y‖ ≤ ‖x‖+‖y‖）。

同一向量，三把尺：手算 v = (3, −4)

L₁ 范数‖v‖₁ = ∑i|vi||3| + |−4| = 3 + 47
L₂ 范数‖v‖₂ = √(∑ivi²)√(3² + (−4)²) = √(9+16) = √255
L∞ 范数‖v‖∞ = maxi|vi|max(|3|, |−4|) = max(3, 4)4

同一个向量，三把尺量出 7、5、4——没有"哪个对"，只有"哪个合用"：L₁ 偏向稀疏（压小分量到 0），L₂ 是几何上的直线距离，L∞ 只看最坏的分量。

矩阵的大小：Frobenius 范数

矩阵也有"大小"。最常用的是 Frobenius 范数（Frobenius Norm）：把矩阵当成拉直的向量算 L₂，即所有元素平方和开根号。

手算小例子：取 B = [[1, 2], [2, −1]]（2×2），则

‖B‖F = √(1² + 2² + 2² + (−1)²) = √(1 + 4 + 4 + 1) = √10 ≈ 3.16

为什么 L² 正则又叫"权重衰减"

训练时常在损失函数上加一项 λ‖w‖₂²（λ 是强度系数），这叫 L² 正则化（Regularization，第 5、7 章）。它对参数更新做了什么？‖w‖₂² = ∑iwi²，对每个 wi 求导得 2λwi——梯度下降时每步都从 wi 里减去正比于它自身的量，也就是每一步都把权重按比例"缩小"一点。所以 L² 正则在优化层面等价于权重衰减（Weight Decay）：不直接砍断任何权重，只是持续地把所有权重的"个头"往下压，防止参数长得太大、模型太敏感。

💡 关键一跃

范数是"代价的语言"：损失函数度量预测误差（第 5 章），正则项度量参数代价（第 7 章），都要先选一把尺。选哪把尺，就是在声明"我认为什么样的误差/参数算大"。

⚠️ 常见误区

"‖x‖₂² 和 ‖x‖₂ 差不多，随便用"——不。‖x‖₂² = xᵀx 没有根号，求导干净（导数 2x），所以优化里几乎总是平方后使用；但它对大的分量惩罚更重，性质不同，写公式时不能混。

2.3线性相关与逆矩阵：Ax = b 何时有唯一解

2.1 节是"正着算"：已知 W 和 x 求 y。但机器学习里更常遇到"反着算"：已知 A 和 b，求满足 Ax = b 的 x（第 5 章线性回归就是这个问题）。能不能解、解有几个，全由矩阵 A 决定。

关键概念：列空间与线性相关

Ax 的几何含义：A 的各列以 x 的分量为系数做线性组合。所以 Ax = b 有解 ⟺ b 落在 A 的列张成的空间（列空间，Column Space）里。若 A 的某一列能被其他列线性表出，称各列线性相关（Linearly Dependent）——列空间塌缩了，有些 b 永远够不到；反之各列线性无关（Linearly Independent），方阵的列空间撑满全空间。各列线性相关的方阵也叫奇异矩阵（Singular Matrix）。

2×2 手算：行列式与逆

对 2×2 矩阵 A = [[a, b], [c, d]]：行列式（Determinant）det A = ad − bc；当 det A ≠ 0 时逆矩阵存在，A⁻¹ = (1/det A)·[[d, −b], [−c, a]]（口诀：主对角线交换、副对角线变号、除以行列式）。

取 A = [[2, 1], [1, 1]]，逐步算：

  • 第 1 步，det：2×1 − 1×1 = 2 − 1 = 1 ≠ 0，可逆。
  • 第 2 步，套公式：主对角线交换 → [[1, 1], [1, 2]]；副对角线变号 → [[1, −1], [−1, 2]]；除以 det = 1 不变。

✅ 判定规则

对方阵 A：det A ≠ 0 ⟺ 各列线性无关 ⟺ A 可逆 ⟺ Ax = b 对任意 b 有唯一解。det A = 0（奇异）时，方程要么无解（b 在列空间外），要么无穷多解（b 恰好在列空间内）——唯独不可能有唯一解。

⚠️ 常见误区

"det = 0 就是无解"——错。det = 0 只宣判"没有唯一解"，具体是无解还是无穷多解要看 b 是否落在列空间里。例如 A = [[1, 1], [1, 1]]（det = 0），b = (2, 2)ᵀ 时 x = (t, 2−t) 全是解；而 b = (2, 3)ᵀ 时无解。

2.4特征值与特征向量：找出变换"不肯转向"的方向

2.3 节回答了"能不能反解"。这一节换一个视角解剖矩阵：一个变换会把大多数向量转得乱七八糟，但总有几个特殊方向，向量躺在上面时只被伸缩、不被转向。这些方向叫特征向量（Eigenvector），伸缩倍数叫特征值（Eigenvalue）：

Av = λv

完整手算：A = [[2, 1], [1, 2]]

第 1 步，写特征方程。由 Av = λv 得 (A − λI)v = 0。v 非零又要把矩阵"乘没"，说明 A − λI 奇异，即 det(A − λI) = 0。

第 2 步，算行列式。A − λI = [[2−λ, 1], [1, 2−λ]]，按 2.3 的公式：

det(A − λI) = (2−λ)(2−λ) − 1×1 = (2−λ)² − 1 = 0

第 3 步，解 λ。(2−λ)² = 1 → 2−λ = ±1 → λ₁ = 3，λ₂ = 1。

第 4 步，对每个 λ 解 (A − λI)v = 0。

  • λ₁ = 3：A − 3I = [[−1, 1], [1, −1]]，方程 −v₁ + v₂ = 0 → v₁ = v₂。取 (1, 1)ᵀ，归一化（除以它的 L₂ 范数 √2）得 v₁ = (1, 1)ᵀ/√2。
  • λ₂ = 1：A − I = [[1, 1], [1, 1]]，方程 v₁ + v₂ = 0 → v₁ = −v₂。取 (1, −1)ᵀ，归一化得 v₂ = (1, −1)ᵀ/√2。

第 5 步，验证 Av₁ = 3v₁。把 (1, 1)ᵀ 代入（归一化系数两边都有，先不算）：A(1,1)ᵀ = (2×1+1×1, 1×1+2×1)ᵀ = (3, 3)ᵀ = 3·(1, 1)ᵀ ✓。同理可验 Av₂ = 1·v₂。

对角化：把矩阵拆成"换坐标 → 逐轴伸缩 → 换回来"

把两个特征向量并排成矩阵 V，特征值放对角线成 Λ：

A = VΛV⁻¹，其中 Λ = [[3, 0], [0, 1]]，V = [v₁ v₂] = 1√2[[1, 1], [1, −1]]

这就是特征分解（Eigendecomposition）。对称矩阵还有个福利：特征向量互相垂直，V 是正交矩阵，V⁻¹ = Vᵀ，所以这里 A = VΛVᵀ。

用它口算 A²：A² = (VΛVᵀ)(VΛVᵀ) = VΛ(VᵀV)ΛVᵀ = VΛ²Vᵀ（因为 VᵀV = I）。Λ² = [[9, 0], [0, 1]]，于是

A² = 12[[1, 1], [1, −1]]·[[9, 0], [0, 1]]·[[1, 1], [1, −1]] = 12[[9, 1], [9, −1]]·[[1, 1], [1, −1]] = 12[[10, 8], [8, 10]] = [[5, 4], [4, 5]]

直接验算 A·A：(1,1) 元 = 2×2+1×1 = 5 ✓，(1,2) 元 = 2×1+1×2 = 4 ✓。一致。一般地，Aᵏ = VΛᵏVᵀ——连乘一百次也只需把对角线上的数各自乘方，这就是特征分解的威力。

💡 关键一跃

特征分解 = 找到变换的"主轴"：在特征方向组成的新坐标系里，复杂的混合变换退化成"沿每个轴各乘一个数"。看懂了 λ₁ = 3、λ₂ = 1，就等于看懂了 A 把平面沿 (1,1) 方向拉 3 倍、沿 (1,−1) 方向原样不动。

⚠️ 常见误区

"每个矩阵都能特征分解"——错。只有有 n 个线性无关特征向量的 n×n 矩阵才可对角化（对称矩阵一定可以）；有的矩阵特征向量"不够用"（如 [[1, 1], [0, 1]]），不能写成 VΛV⁻¹。但别急——下一节的 SVD 对任意矩阵都成立。

2.5奇异值分解：任意矩阵 = 旋转 → 伸缩 → 旋转

特征分解有两个限制：只对方阵、且要求特征向量够数。奇异值分解（Singular Value Decomposition，SVD）打破这两个限制——任何矩阵（方的、长的、奇的、不满秩的）都能写成：

A = UΣVᵀ

其中 U、V 是正交矩阵（旋转/翻转，不改变长度），Σ 是对角矩阵，对角线上的非负数 σ₁ ≥ σ₂ ≥ … ≥ 0 叫奇异值（Singular Value）。几何上，任何线性变换都是三步：先用 Vᵀ 把输入转到"主轴坐标系"，再用 Σ 沿各轴伸缩 σi 倍，最后用 U 转到输出方向。

对称矩阵：SVD 退化为特征分解

2.4 节的对称矩阵 A = VΛVᵀ 与 SVD 的 UΣVᵀ 长得几乎一样——这不是巧合。对称矩阵（特征值全为非负时）的特征分解就是它的 SVD：U = V，σi = λi。所以 2.4 的例子（σ₁ = 3, σ₂ = 1）可以直接当作 SVD 读。特征值可以为负时，把负号并进 U 的对应列即可。

几何演示：diag(10, 0.1) 把圆拉成多扁的椭圆

取最极端的纯伸缩矩阵 A = diag(10, 0.1)（Σ 自己上场，没有旋转）。单位圆上的点 (cos θ, sin θ) 被映成 (10cos θ, 0.1sin θ)——一个半长轴 10、半短轴 0.1 的椭圆，长短轴之比 100 : 1。这个变换把 x 方向的信息放大 10 倍，却把 y 方向的信息压到几乎消失。

这个比值有名字：条件数（Condition Number）

κ(A) = σmaxσmin，本例 κ = 100.1 = 100

κ 的含义：解方程 Ax = b 时，输入的相对误差最多会被放大 κ 倍。κ = 1 的变换各向同性（如纯旋转），数值上最舒服；κ 越大，变换越"偏心"，反解越不稳定。本例 κ = 100：如果 b 有 1% 的测量噪声，解 x 在最坏方向上的误差可达 100%——这就是"病态"（ill-conditioned）。计算机浮点本身就有约 10⁻¹⁶ 的舍入误差，κ 一万亿时这点误差都会被放大到吞掉整个解。

💡 关键一跃

深度学习里处处在反解线性系统：最小二乘（第 5 章）、梯度在海森矩阵下的走向（第 4、8 章）。κ 就是"这条路好不好走"的体检指标——梯度下降在 κ 大的问题上会来回震荡、龟速前进，这正是第 4 章数值计算要解决的痛点。

⚠️ 常见误区

"行列式大 = 变换稳定"——错。det 只告诉你体积缩放倍数（det = ∏σi），diag(10, 0.1) 的 det = 1 跟单位阵一样"正常"，可它 κ = 100，病态得很。稳定性看 κ（σ 的悬殊），不看 det 的大小。

2.6迹、行列式与伪逆：特征值的两个"速查表"和一把万能钥匙

前面几节把矩阵拆开看了个够。最后收三个"用起来特别顺手"的小工具。

迹与行列式：特征值的和与积

迹（Trace）tr(A) = 对角线元素之和。行列式 det 前面已见过。当 A 可特征分解时，有两个免分解的速查公式：

tr(A) = ∑iλi，　det A = ∏iλi

用 2.4 的例子验证（A = [[2, 1], [1, 2]]，λ₁ = 3, λ₂ = 1）：

  • tr = 2 + 2 = 4，而 λ₁ + λ₂ = 3 + 1 = 4 ✓
  • det = 2×2 − 1×1 = 3，而 λ₁ × λ₂ = 3 × 1 = 3 ✓

手算完特征值后用这两条做交叉检验，五秒钟就能发现算错没有。det 还有个几何读法：变换对体积的缩放倍数——这解释了 det = 0 ⟺ 变换把空间压扁 ⟺ 奇异（与 2.3 节呼应）。

伪逆：当逆不存在时的"最优替身"

第 5 章的最小二乘问题长这样：样本比特征多，A 是又高又瘦的长方阵，Ax = b 通常无解——没有 x 能让所有样本同时满足。此时退而求其次：找使误差 ‖Ax − b‖₂ 最小的 x。这个"最优替身"由 Moore-Penrose 伪逆（Pseudoinverse）A⁺ 给出：x = A⁺b。它的构造正好要用 SVD：把 A = UΣVᵀ 中 Σ 的非零对角元取倒数再转置，得到 Σ⁺，则 A⁺ = VΣ⁺Uᵀ。当 A 本身可逆时，A⁺ 就是 A⁻¹——伪逆是真逆的推广。细节留给第 5 章，这里只需记住：无解的方程不是终点，伪逆给出"误差最小"的答案。

💡 关键一跃

本章工具串成一条线：逆矩阵管"有唯一解"，伪逆管"没解时找最优近似"，条件数管"解出来的东西信不信得过"。第 5 章会把这三件同时用在最小二乘上。

⚠️ 常见误区

"伪逆什么都能解，直接用就行"——小心。伪逆给的确实是 L₂ 意义下误差最小的解，但如果 A 条件数很大，这个解对数据噪声极其敏感（2.5 节），此时通常要加正则项（2.2 节的 L²）压一压。工具没错，场景要先体检。

点击翻面 →

解决问题特征分解只对方阵且可能不存在；SVD 对所有矩阵成立，是解剖变换的万能刀。

概念卡 6
条件数（Condition Number）
点击翻面 →
定义κ(A) = σ_max / σ_min，最大与最小奇异值之比。
解决问题量化反解线性系统时误差被放大的上限，回答"这个解信不信得过"。

伪逆（Moore-Penrose Pseudoinverse）
点击翻面 →
定义A⁺ = VΣ⁺Uᵀ（SVD 非零奇异值取倒数）；给出使 ‖Ax − b‖₂ 最小的解 x = A⁺b。
解决问题A 非方阵或奇异、方程无解时，仍给出"误差最小"的最优近似解。
直觉逆矩阵不存在时的"最优替身"；A 可逆时 A⁺ 就是 A⁻¹。

📝分层习题

L1 概念辨析判断并说明理由："若 ‖x‖ = 0，则 x 一定是零向量。"反过来，"零向量的范数一定是 0" 成立吗？
提示

回到范数的三条公理之一：非负性里"且只在零向量处为 0"这半句，读仔细它到底声明了几个方向。

完整解答

两个方向都成立。范数公理规定：‖x‖ = 0 ⟺ x = 0，是当且仅当。验证一下 L₂：‖x‖₂² = ∑xᵢ²，平方和为 0 必须每项为 0，即 x 每个分量都是 0，故 x 是零向量；反之零向量范数显然为 0。这条性质正是范数能当"误差是否归零"判据的原因——若去掉它（比如定义 f(x) = |x₁|），f((0, 5)) = 0 但向量非零，"损失为 0"就不再等于"预测全对"。

L1 概念辨析判断并说明理由："det A = 0 时，Ax = b 一定无解。"
提示

想想列空间。det = 0 说明列空间塌缩了，但 b 可能恰好躺在塌缩后的空间里。试构造一个 2×2 反例。

完整解答

错。det A = 0 只排除"唯一解"，剩下两种可能：无解或无穷多解。反例：A = [[1, 1], [1, 1]]（det = 1×1 − 1×1 = 0），取 b = (2, 2)ᵀ，则 x = (t, 2−t)ᵀ 对任意 t 都满足 Ax = b——无穷多解；而取 b = (2, 3)ᵀ 时两方程互相矛盾——无解。易错根源：把"没有唯一解"误读成"没有解"，中间漏掉了"无穷多解"这个分支。

L2 手算推导对 B = [[3, 1], [1, 3]] 完整手算特征分解：求特征值、归一化特征向量，写出 B = VΛVᵀ，并用它口算 B²。
提示

照搬 2.4 节的五步：det(B − λI) = 0 解 λ；对每个 λ 解 (B − λI)v = 0；归一化；组装 V 和 Λ；B² = VΛ²Vᵀ。最后直接乘 B·B 交叉验证。

完整解答

第 1 步：B − λI = [[3−λ, 1], [1, 3−λ]]。

第 2 步：det(B − λI) = (3−λ)² − 1 = 0 → (3−λ)² = 1 → 3−λ = ±1 → λ₁ = 4，λ₂ = 2。

第 3 步：λ₁ = 4 时 B − 4I = [[−1, 1], [1, −1]]，方程 −v₁ + v₂ = 0 → v₁ = v₂，取 (1, 1)ᵀ，归一化得 v₁ = (1, 1)ᵀ/√2；λ₂ = 2 时 B − 2I = [[1, 1], [1, 1]]，v₁ = −v₂，归一化得 v₂ = (1, −1)ᵀ/√2。

第 4 步：B = VΛVᵀ，Λ = [[4, 0], [0, 2]]，V = (1/√2)[[1, 1], [1, −1]]。

第 5 步：B² = VΛ²Vᵀ，Λ² = [[16, 0], [0, 4]]；VΛ² = (1/√2)[[16, 4], [16, −4]]；(VΛ²)Vᵀ = (1/2)[[16, 4], [16, −4]]·[[1, 1], [1, −1]] = (1/2)[[20, 12], [12, 20]] = [[10, 6], [6, 10]]。

交叉验证：B·B 的 (1,1) 元 = 3×3 + 1×1 = 10 ✓，(1,2) 元 = 3×1 + 1×3 = 6 ✓，(2,2) 元 = 1×1 + 3×3 = 10 ✓。一致。另外 tr = 6 = 4 + 2 ✓，det = 8 = 4 × 2 ✓，两条速查公式也都对上。

L2 手算推导(a) 对向量 v = (1, −2, 2) 手算 L₁、L₂、L∞ 范数；(b) 对矩阵 D = diag(6, 0.5) 求条件数 κ，并说明它解 Dx = b 时意味着什么。
提示

(a) 逐条套定义：绝对值之和 / 平方和开根号 / 最大绝对值。(b) 对角矩阵的奇异值就是对角元的绝对值，κ = σ_max / σ_min。

完整解答

(a) L₁ = |1| + |−2| + |2| = 1 + 2 + 2 = 5；L₂ = √(1 + 4 + 4) = √9 = 3；L∞ = max(1, 2, 2) = 2。

(b) D 的奇异值 σ₁ = 6，σ₂ = 0.5，κ = 6 / 0.5 = 12。含义：解 Dx = b 时，b 的相对误差在最坏方向（对应 σ_min 的方向，即 y 轴）最多被放大 12 倍——b 有 1% 噪声，解的 y 分量可能有 12% 误差。验证一下直觉：y 分量满足 0.5·x₂ = b₂，所以 x₂ = 2b₂，b₂ 的误差直接乘 2，而 x 方向误差除以 6——两个方向待遇悬殊，这正是 κ 捕捉的东西。

L3 建模应用你收集了 100 套房子的"面积 → 售价"数据，想用直线 ŷ = w·面积 + c 拟合。请把这个问题写成线性代数语言：(1) 每个样本给出一个方程，全部 100 个方程写成 Aw = b 的形式（指明 A 的形状）；(2) 这个方程组为什么通常无解？(3) 该用什么工具求"最优"的 (w, c)？(4) 如果数据里所有房子面积几乎相同（比如都在 89~91 平米），求出的解会有什么毛病？
提示

把未知数打包成向量 (w, c)ᵀ，每个样本贡献 A 的一行 [面积ᵢ, 1]。无解想"列空间"，最优解想本章最后一个工具，毛病想"两个自变量几乎成比例 → 奇异值悬殊"。

完整解答

(1) 第 i 个样本：w·面积ᵢ + c·1 = 售价ᵢ。令未知数向量 θ = (w, c)ᵀ，A 的第 i 行为 [面积ᵢ, 1]，b 的第 i 行为售价ᵢ，则全部方程写成 Aθ = b，A 是 100×2 的长方阵，θ 是 2×1，b 是 100×1。

(2) A 的列空间最多 2 维（它只有 2 列），而 b 生活在 100 维空间里——100 个含噪声的观测几乎不可能恰好落在一张 2 维平面上，所以方程通常无解（超定）。

(3) 用 Moore-Penrose 伪逆：θ = A⁺b，它使平方误差 ‖Aθ − b‖₂ 最小——这正是第 5 章的最小二乘。A⁺ 由 SVD 构造：A = UΣVᵀ → A⁺ = VΣ⁺Uᵀ。

(4) 面积几乎相同时，A 的两列 [面积列] 与 [全 1 列] 几乎成比例（近线性相关），第二个奇异值 σ₂ 趋近 0，κ = σ₁/σ₂ 巨大 → 系统病态。后果：w 和 c 对数据噪声极度敏感——同一小区再采一批房，拟合出的斜率可能从 +5000 翻到 −3000（截距反向补偿）。这正是第 4 章数值计算与第 7 章正则化要联手处理的问题。

  • C. A 有 100 个奇异值
  • D. A 一定是奇异矩阵
解析：B 对。κ 度量反解线性系统时相对误差的放大上限，κ = 100 即最坏方向上 1% 的输入噪声可变成约 100% 的解误差——病态。A 错：det = ∏σᵢ 是体积缩放，与 κ（σ 的比值）是两回事，diag(10, 0.1) 的 det = 1 而 κ = 100。C 错：κ 是比值，不透露奇异值的个数。D 错：奇异矩阵要求 σ_min = 0，此时 κ = ∞；κ = 100 只是"接近"病态，矩阵仍严格可逆。
