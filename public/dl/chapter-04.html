4.1上溢与下溢：机器里的「数」不是实数

第 2、3 章我们一直在理想的实数世界里推导。但计算机用固定位数存数：单精度浮点数（float32）能表示的范围大约只有 ±3.4 × 10³⁸。超出这个范围，就会发生两种事故：

  • 上溢（Overflow）：数值太大，存不下，直接变成 ∞（无穷大）。
  • 下溢（Underflow）：数值太接近 0，被四舍五入成 0。

这两种事故单独看都像边角问题，但它们会联手摧毁深度学习中最重要的一个函数——softmax 函数（Softmax Function）：

softmax(z)i = ezi∑j ezj

完整事故演示：设 logits 为 z = (1000, 1001)。直接按公式算：

  1. e¹⁰⁰⁰ ≈ 10⁴³⁴，远超 float32 上限 10³⁸ → 上溢，结果为 ∞。
  2. e¹⁰⁰¹ 同样 → ∞。
  3. softmax 第一项 = ∞ / (∞ + ∞) = ∞ / ∞ = NaN（Not a Number，非法值）。

一旦 NaN 进入计算图，之后所有运算都被污染——loss 是 NaN，梯度是 NaN，训练直接报废。而下溢同样致命：若 z 全是很小的负数，ezi 全部下溢成 0，分母 ∑ = 0，0/0 又是 NaN。

修复：LogSumExp 技巧（提出最大值）

核心观察：softmax 和 log-sum-exp 里所有 zi 同时减去同一个常数 m，结果在数学上完全不变。取 m = max(z) 就能把所有指数压到 ≤ 0，e 的幂次最大是 e⁰ = 1，永不溢出。这就是 LogSumExp 技巧（LogSumExp Trick）：

log ∑i ezi = m + log ∑i ezi − m，其中 m = maxi zi

纸笔手算：求 log(e¹⁰⁰⁰ + e¹⁰⁰¹)，步骤写全：

  1. 提出最大值：m = max(1000, 1001) = 1001。
  2. 提公因子：e¹⁰⁰⁰ + e¹⁰⁰¹ = e¹⁰⁰¹ · (e¹⁰⁰⁰⁻¹⁰⁰¹ + e¹⁰⁰¹⁻¹⁰⁰¹) = e¹⁰⁰¹ · (e⁻¹ + e⁰)。
  3. 取对数拆成两项：log[e¹⁰⁰¹ · (e⁻¹ + 1)] = log(e¹⁰⁰¹) + log(e⁻¹ + 1) = 1001 + log(e⁻¹ + 1)。
  4. 算小项：e⁻¹ ≈ 0.3679，e⁻¹ + 1 ≈ 1.3679。
  5. log(1.3679) ≈ 0.3133（因为 e⁰·³¹³³ ≈ 1.368）。
  6. 合并：log(e¹⁰⁰⁰ + e¹⁰⁰¹) ≈ 1001 + 0.3133 = 1001.3133。全程最大只算过 e⁰ = 1，没有溢出。

softmax 版本：z 减去 m = 1001 后变为 z′ = (−1, 0)，于是第一项

softmax(z)₁ = e⁻¹e⁻¹ + e⁰ = 11 + e ≈ 13.7183 ≈ 0.2689

第二项 = 1 − 0.2689 = 0.7311。与理论值完全一致，且没有任何一步触碰 e¹⁰⁰⁰。

💡 关键一跃

LogSumExp 的本质：softmax 只看 差距，不看绝对高度。z = (1000, 1001) 和 z′ = (−1, 0) 给出同一个分布。把「山峰整体平移到海平面」，风景不变，但不会撞上天花板。

⚠️ 常见误区

「减去 max 是近似，会损失精度」——错。ezi − m / ∑ ezj − m 与 ezi / ∑ ezj 在数学上严格相等（分子分母同乘 e−m），它不是近似，是恒等变形，唯一作用是规避溢出。

4.2病态条件：为什么 1% 的误差会变成 10%

上一节解决的是「数太大存不下」。但即使所有数都在浮点范围内，还有更隐蔽的敌人：舍入误差被放大。第 2 章我们见过 条件数（Condition Number）κ = λmax / λmin（最大与最小特征值绝对值之比）。本节看清它到底怎么咬人。

考虑函数 f(x) = A⁻¹x，取对角矩阵 A = diag(10, 0.1)，则 A⁻¹ = diag(0.1, 10)。条件数 κ = 10 / 0.1 = 100。

手算演示：给输入 x 加一个大小为 ε 的扰动（相当于 1% 量级的测量误差），看输出变化量 A⁻¹ε 在两个方向上的差别：

扰动方向扰动向量输出变化 A⁻¹ε放大倍数
沿 e₁ = (1, 0)(ε, 0)(0.1ε, 0)×0.1（缩小到十分之一）
沿 e₂ = (0, 1)(0, ε)(0, 10ε)×10（放大十倍）

同样大小的输入误差，一个方向被压成 1/10，另一个方向被放大 10 倍——两个方向的「待遇」相差整整 100 倍，正是条件数 κ = 100。输入扰动 1%，沿坏方向输出就偏 10%。

✅ 判定规则

κ 接近 1（如正交矩阵）：误差各方向同等传递，问题「良态」（well-conditioned）。κ 很大（如 10⁴ 以上）：问题「病态」（ill-conditioned），任何算法都救不了——因为误差来自输入的浮点表示本身，不是算法产生的。

⚠️ 常见误区

「换个更聪明的算法就能解决病态问题」——错。病态是问题本身的性质：输入的微小不确定性被矩阵结构放大。算法只能避免「再添乱」，无法消除输入误差被放大 κ 倍这个下限。能改善的是换问题（如重新缩放特征、加正则），不是换算法。

4.3基于梯度的优化：方向选对，步长别翻车

4.1、4.2 管「算得对」，从本节开始管「走得稳」。训练神经网络就是最小化损失函数，而我们几乎只有一个工具可用：沿着局部信息一步步往下走。

先把概念摆齐：

  • 导数（Derivative）：单变量函数在某点的瞬时变化率，f′(x) 是切线斜率。
  • 方向导数（Directional Derivative）：沿单位向量 u 方向的变化率 = ∇f · u。
  • 梯度（Gradient）：各偏导数组成的向量 ∇f = (∂f/∂x₁, …, ∂f/∂xₙ)。由方向导数公式可知：梯度方向是局部上升最快的方向，负梯度是下降最快的方向。
  • 雅可比矩阵（Jacobian Matrix）：向量值函数 f : ℝⁿ → ℝᵐ 的所有偏导数排成的 m × n 矩阵，Jij = ∂fi/∂xj。梯度是 m = 1 时的特例。

梯度下降（Gradient Descent）的更新公式：

xt+1 = xt − η ∇f(xt)　　（η 为学习率 Learning Rate）

一步完整手算：f(x) = x² − 4x + 1，x₀ = 0，η = 0.25。

  1. 求导：f′(x) = 2x − 4。
  2. 代入当前点：f′(0) = 2 × 0 − 4 = −4（斜率为负，函数在下降，应向右走）。
  3. 更新：x₁ = x₀ − η · f′(x₀) = 0 − 0.25 × (−4) = 0 + 1 = 1。
  4. 验证：f(0) = 1，f(1) = 1 − 4 + 1 = −2 < 1，确实下降了。✓

zigzag 震荡演示：f(x, y) = x² + 10y²，梯度 ∇f = (2x, 20y)，从 (1, 1) 出发，η = 0.1。注意这个函数 y 方向的曲率是 x 方向的 10 倍（条件数 10）。

  1. 第 1 步：∇f(1, 1) = (2 × 1, 20 × 1) = (2, 20)。更新：x₁ = 1 − 0.1 × 2 = 0.8；y₁ = 1 − 0.1 × 20 = −1。新点 (0.8, −1)——y 直接冲过了最优值 0，变成负数。
  2. 第 2 步：∇f(0.8, −1) = (1.6, −20)。更新：x₂ = 0.8 − 0.1 × 1.6 = 0.64；y₂ = −1 − 0.1 × (−20) = +1。新点 (0.64, 1)——y 又弹回 +1。

两步下来，x 方向稳步接近 0（1 → 0.8 → 0.64），y 方向却在 −1 和 +1 之间来回弹跳，毫无进展。这就是病态条件在优化中的样子：陡坡方向来回震荡，平地方向缓慢爬行，轨迹呈 zigzag 锯齿。

💡 关键一跃

梯度下降像一只蒙眼下山的山羊：每一步只敢沿最陡方向迈固定一小步。山谷越狭长（κ 越大），它越是在两壁之间撞来撞去，而不是沿谷底前进。

4.4海森矩阵与曲率：牛顿法为什么一步登顶

上一节的 zigzag 暴露了梯度下降的盲区：它只看一阶信息（哪边陡），看不见二阶信息（坡有多弯）。海森矩阵（Hessian Matrix）补齐这一课：Hij = ∂²f/∂xi∂xj，即所有二阶偏导排成的矩阵。梯度告诉你「往哪走」，海森告诉你「这个方向能走多远」。

牛顿法（Newton's Method）用二阶泰勒展开直接跳到当前抛物线的最低点：

x⁺ = x − f′(x)f″(x)　　（多维版：x⁺ = x − H⁻¹∇f(x)）

一步手算：还是 f(x) = x² − 4x + 1，从 x₀ = 0 出发：

  1. f′(x) = 2x − 4，f′(0) = −4。
  2. f″(x) = 2（处处相同，因为二次函数曲率恒定）。
  3. 牛顿更新：x₁ = x₀ − f′(x₀)/f″(x₀) = 0 − (−4)/2 = 2。
  4. 验证：f′(2) = 2 × 2 − 4 = 0，x = 2 正是全局最优解——一步到位，而 4.3 节的梯度下降只挪到 x = 1。

对二次函数，牛顿法一步到最优；对一般函数，它在最优解附近二次收敛，远快于梯度下降。代价是：要算并求逆海森矩阵，n 维参数下是 O(n³)，深度网络里根本用不起——这是后话（第 8 章的拟牛顿法正是来补这个洞的）。

用海森矩阵给临界点分类

临界点（∇f = 0 的点）有三种性格，由 H 的特征值符号判定。看三个对角海森的小例（对角元即特征值）：

海森矩阵特征值符号定性临界点类型
H = diag(2, 3)全正（正定）两个方向都向上弯局部极小值
H = diag(−2, −3)全负（负定）两个方向都向下弯局部极大值
H = diag(1, −2)有正有负（不定）一个方向向上弯、一个向下弯鞍点（Saddle Point）

鞍点在高维空间里是主角：n 维中随机一个临界点，要 n 个特征值全部为正才是极小值——维度越高，极小值越稀有，鞍点越常见。这是深度网络优化困难的核心原因之一。

病态条件如何锁死步长：η < 2/λmax

为什么 zigzag 例子里 η 不敢取大？用最简单的二次函数 f(x) = ½λx² 推导（任何光滑函数在最优点附近都近似长成这样）：

  1. 梯度：f′(x) = λx。
  2. GD 更新：xt+1 = xt − ηλxt = (1 − ηλ) xt。
  3. 每步把误差乘以因子 (1 − ηλ)。要收敛，必须 |1 − ηλ| < 1。
  4. 解不等式：−1 < 1 − ηλ < 1 ⟹ 0 < ηλ < 2 ⟹ η < 2/λ。
  5. 多方向时，最陡方向 λmax 最先违反条件，故全局要求 η < 2/λmax。

于是条件数 κ = λmax/λmin 大意味着：步长被 λmax 压得很小，而 λmin 方向的收缩因子 (1 − ηλmin) ≈ 1，几乎不动。震荡与爬行，全写在这一个不等式里。

💡 关键一跃

梯度下降问「哪边下坡」，牛顿法多问一句「坡有多弯」——用曲率把步长校准到恰好落在抛物线底部。海森矩阵就是优化问题的「地形图」。

⚠️ 常见误区

「梯度为 0 就是最优点」——错。∇f = 0 只是临界点，可能是极小、极大或鞍点。必须再看海森：正定才是极小。在高维深度网络里，遇到的临界点绝大多数是鞍点。

4.5约束优化初步：带着镣铐跳舞

前面几节都是「无约束」优化。但机器学习里常见约束：参数要在单位球面上、概率要和为 1、范数不能超过阈值。拉格朗日乘子法（Lagrange Multiplier）把等式约束问题变回无约束问题：给约束配一个乘子 λ，构造拉格朗日函数，然后对所有变量求导置零。

完整手算：min x² + y²，约束 x + y = 1（几何意义：直线 x + y = 1 上离原点最近的点）。

L(x, y, λ) = x² + y² + λ(x + y − 1)
  1. 对 x 求导置零：∂L/∂x = 2x + λ = 0 ⟹ x = −λ/2。
  2. 对 y 求导置零：∂L/∂y = 2y + λ = 0 ⟹ y = −λ/2。
  3. 由前两式：x = y（直觉：对称）。
  4. 对 λ 求导置零，正好还原约束：∂L/∂λ = x + y − 1 = 0。
  5. 代入 x = y：2x = 1 ⟹ x = y = 0.5，λ = −1。最小值 f = 0.25 + 0.25 = 0.5。✓

直觉：在最优点，目标函数的梯度与约束边界的法线共线（∇f = −λ∇g）——沿约束方向已经「无处可降」。

如果约束是不等式（如 x + y ≤ 1），拉格朗日条件要升级为 KKT 条件（KKT Conditions，Karush–Kuhn–Tucker）：核心新增一条「互补松弛」——要么约束不起作用（乘子为 0），要么约束恰好顶满（约束取等号），二者必居其一。KKT 是支持向量机（SVM）和许多正则化方法的理论基石，后续章节会再相遇。

💡 关键一跃

拉格朗日乘子是「约束的物价」：λ 告诉你约束每放松一点，目标函数能改善多少。λ = 0 意味着这个约束根本不值钱——最优解本来就在约束内部。

解决问题给「该往哪走」一个局部最优答案，是梯度下降的方向盘。

牛顿法（Newton's Method）
点击翻面 →
定义x⁺ = x − H⁻¹∇f(x)，用二阶展开直接跳向抛物线顶点。
解决问题克服 GD 只看坡向不看曲率的盲区，二次函数一步到最优。
直觉不但知道往哪走，还知道这步该迈多大——曲率校准步长。
误区以为处处优于 GD——海森负定时它会朝极大值跑。

鞍点（Saddle Point）
点击翻面 →
定义∇f = 0 且海森不定的临界点：某些方向极小、另一些方向极大。
解决问题解释高维训练中梯度消失般停滞的主因（不是局部极小）。
直觉马鞍中心：前后是谷、左右是峰，坐在上面不知道该去哪。
误区以为训练卡住就是陷入局部极小——高维里鞍点远比极小值多。

概念卡 8
KKT 条件（KKT Conditions）
点击翻面 →
定义不等式约束下最优解的必要条件：拉格朗日条件 + 互补松弛 + 乘子非负。
解决问题把「≤」约束纳入解析求解框架，而不只是「=」约束。
直觉约束要么顶满（起作用），要么不存在（乘子为 0），没有中间态。

📝分层习题

L1 概念辨析

判断正误并说明理由：「softmax 前减去 max(z) 是一种近似计算，会牺牲一点数值精度来换取不溢出。」

提示

把 e^(zᵢ − m) / ∑ e^(zⱼ − m) 的分子分母同乘 e^m，看看能得到什么。

完整解答

错误。分子分母同乘 e^m 后：e^(zᵢ−m)·e^m / ∑ e^(zⱼ−m)·e^m = e^zᵢ / ∑ e^zⱼ，与原式严格相等，零近似。它的唯一作用是把最大指数压到 e⁰ = 1，规避上溢。

易错点：把「数值稳定技巧」和「近似算法」混为一谈。判断标准是：恒等变形（同乘同除、提公因子）不损失任何精度。

L1 概念辨析

判断正误并说明理由：「矩阵 A 是病态的（κ 很大），但只要换用更精确的迭代算法求解 A⁻¹x，就能避免误差放大。」

提示

误差从哪里来？是算法算错的，还是输入的浮点表示本身就有的？

完整解答

错误。病态是问题本身的性质：输入 x 在浮点表示中已带舍入误差，而 A⁻¹ 会把某些方向的误差放大 κ 倍——这个放大由矩阵结构决定，与用什么算法无关。再好的算法也只能保证「不额外添乱」，无法低于「输入误差 × κ」这个下限。

可行的改善是改变问题本身：重新缩放特征、加正则项，把 κ 降下来。

L2 手算推导

设 z = (2000, 2002)。（a）用 LogSumExp 技巧手算 log(e²⁰⁰⁰ + e²⁰⁰²)，保留 4 位小数；（b）手算数值稳定的 softmax(z)，保留 4 位小数。已知 e⁻² ≈ 0.1353，log(1.1353) ≈ 0.1269。

提示

先取 m = max = 2002，提出 e²⁰⁰²，把两个指数分别写成 e⁻² 和 e⁰。

完整解答

（a）log-sum-exp：

① m = max(2000, 2002) = 2002。
② 提公因子：e²⁰⁰⁰ + e²⁰⁰² = e²⁰⁰² · (e⁻² + e⁰) = e²⁰⁰² · (e⁻² + 1)。
③ 取对数：log = 2002 + log(e⁻² + 1)。
④ 代入：e⁻² + 1 ≈ 1.1353，log(1.1353) ≈ 0.1269。
⑤ 结果：2002.1269。

（b）softmax：z′ = z − 2002 = (−2, 0)。
p₁ = e⁻² / (e⁻² + 1) ≈ 0.1353 / 1.1353 ≈ 0.1192；
p₂ = 1 / 1.1353 ≈ 0.8808（或 1 − 0.1192 = 0.8808）。
验算：0.1192 + 0.8808 = 1 ✓。

L2 手算推导

设 f(x) = x² + 2x − 3，从 x₀ = 2 出发。（a）用 η = 0.1 的梯度下降手算一步 x₁；（b）用牛顿法手算一步 x₁。两种方法的结果有何不同？为什么？

提示

先求 f′(x) = 2x + 2 与 f″(x) = 2，再分别代入两个更新公式。

完整解答

（a）梯度下降：f′(2) = 2×2 + 2 = 6。
x₁ = x₀ − η·f′(x₀) = 2 − 0.1×6 = 2 − 0.6 = 1.4。
验证：f(2) = 4+4−3 = 5，f(1.4) = 1.96+2.8−3 = 1.76 < 5，下降 ✓。

（b）牛顿法：x₁ = x₀ − f′(x₀)/f″(x₀) = 2 − 6/2 = 2 − 3 = −1。
验证：f′(−1) = −2 + 2 = 0，x = −1 恰为全局最优点（f(−1) = 1−2−3 = −4）。

差异：GD 只挪了 0.6（步长受 η 限制），牛顿法一步直达最优。原因：f 是二次函数，牛顿法的二阶模型是精确的，曲率信息把步长自动校准到恰好落地。

L3 建模应用

你在训练一个 softmax 分类器：logits 层直接输出未归一化分数，损失为交叉熵 −log softmax(z)。训练到一半 loss 突然变成 NaN，且此前 logits 的数值随训练越变越大。请：（a）指出 NaN 的最可能来源；（b）给出至少两个修复方案并说明各自利用了本章哪个知识点。

提示

从「logits 越变越大」出发，分别想：4.1 的溢出链路是什么？学习率与 4.4 的哪个不等式有关？

完整解答

（a）来源：logits 不断增大（权重发散的征兆），某个 zᵢ 超过约 88（float32 中 e⁸⁸ ≈ 1.7×10³⁸ 已达上限）→ e^zᵢ 上溢为 ∞ → softmax 出现 ∞/∞ = NaN → −log(NaN) 使 loss 为 NaN。深层原因往往是学习率过大，参数更新发散（违反 η < 2/λ_max 类型的稳定条件），把 logits 越推越大。

（b）修复方案：

① 数值稳定的 softmax/交叉熵：实现时先减 max(logits)（LogSumExp 技巧，4.1）。多数框架的交叉熵接口已内置此处理，直接传 logits 而不是先手动 softmax——治标，保证任何 logits 下都不溢出。

② 调小学习率：发散的根因是步长超过曲率允许的上限（4.4 节 η < 2/λ_max），把 η 减小一个数量级通常立即稳定——治本之一。

③ 梯度裁剪 / 特征与权重归一化：限制梯度范数防止单步暴冲；对输入做标准化降低条件数（4.2），让各方向曲率接近，步长不再被极端方向锁死。

自测 1
计算 softmax 前先减去 max(z)，根本原因是：
  • A. 让梯度更容易反向传播
  • B. 减 max 是恒等变形，同时把最大指数压到 e⁰ = 1，避免上溢产生 NaN
  • C. 让概率分布更均匀，防止某一个类别概率过大
  • D. 提高 softmax 的计算精度（它是一种近似但更准）
解析：B 对——e^(zᵢ−m)/∑e^(zⱼ−m) 与原式严格相等，且减 max 后最大项为 e⁰=1，不会溢出。A 错：减 max 与反向传播无关。C 错：分布形状完全不变（恒等变形）。D 错：它不是近似，严格相等；「提精度」说反了，它防的是溢出而非提高精度。
自测 2
一个矩阵的条件数 κ 很大，直接后果是：
  • A. 矩阵无法求逆
  • B. 矩阵的行列式为 0
  • C. 输入的微小误差在不同方向被放大/缩小的程度相差悬殊，换算法也救不了
  • D. 矩阵的特征值全部是复数
解析：C 对——κ = λ_max/λ_min 度量最坏方向的误差放大倍数，病态是问题本身的性质。A 错：κ 大不等于奇异，A = diag(10, 0.1) 完全可逆。B 错：diag(10, 0.1) 行列式 = 1，不是 0；κ 趋于无穷才逼近奇异。D 错：对称正定矩阵也能病态，特征值全是正实数。
自测 3
梯度 ∇f(x) 的方向含义是：
  • A. 函数值局部上升最快的方向（所以梯度下降走它的反方向）
  • B. 指向全局最小值的方向
  • C. 函数值不变的方向（等高线的切线方向）
  • D. 曲率最大的方向
解析：A 对——方向导数 ∇f·u 在 u 与 ∇f 同向时取最大值，故梯度是最速上升方向。B 错：梯度只含局部信息，不指向全局最优（否则一步就到了）。C 错：梯度与等高线垂直，切线方向的方向导数为 0。D 错：曲率信息在海森矩阵里，不在梯度里。
自测 4
某临界点处海森矩阵 H = diag(1, −2)，该点是：
  • A. 局部极小值
  • B. 局部极大值
  • C. 全局最小值
  • D. 鞍点

自测 5
牛顿法与梯度下降的本质区别是：
  • A. 牛顿法不用计算导数
  • B. 牛顿法用海森（二阶曲率）把步长自动校准，二次函数一步到最优；GD 只用一阶梯度，步长靠手调且被 λ_max 限制
