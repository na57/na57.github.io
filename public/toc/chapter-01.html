1.1为什么要把"问题"变成"语言"：计算理论的三问

1936 年图灵发问"什么是可计算的"时，人类连"计算"本身都没有数学定义——人人都说得出"我在算账"，却没人说得出"算账"作为一种过程，边界在哪里。计算理论的第一项工作，就是把这件模糊的事变成可以推理的对象。

全书围绕三个问题展开，对应三大板块：

板块核心问题典型结论（在本书何处）
可计算性（Computability）这个问题到底能不能被机械地解决？停机问题不可判定（第5章）
复杂度（Complexity）能算的话，要花多少时间、多少空间？P 与 NP 之问（第7、8章）
自动机与语言（Automata & Languages）用什么模型刻画"机器"，它能识别哪些语言？本部分：从有限自动机一路升级到图灵机

三个问题看似不同，却共用同一套语言——字面意义的"语言"。关键在于：数学家注意到，千姿百态的计算问题都可以先压缩成判定问题（Decision Problem），即答案只有"是 / 否"的问题；而一个判定问题，又完全可以由一个字符串集合来代表。

以"判断一个整数是否素数"为例。整数可以先写成二进制串（11 写成 1011），然后定义集合：

PRIMES = { w | w 是某个素数的二进制表示 }

于是"11 是素数吗"这个问题，与"字符串 1011 是否属于集合 PRIMES"是同一个问题：1011 ∈ PRIMES（11 是素数），1111 ∉ PRIMES（1111 是 15 = 3×5，不是素数）。判定问题被原封不动地翻译成了语言（Language）的成员资格问题。

这一招的通用性来自一个事实：数、图、逻辑公式、甚至程序本身，都能编码成有限字符串。比如一张图可以写成邻接矩阵的 01 串，记作 〈G〉；于是"图 G 是否连通"就对应语言 CONNECTED = { 〈G〉 | G 是连通图 }。一旦问题都变成了"串是否属于某个集合"，"机器能算什么"就变成了"机器能识别哪些集合"——这是可以精确定义、可以严格证明的。

💡 关键一跃

语言是计算的通用接口：任何问题编码为字符串后，"解决这个问题"就等价于"判定串是否属于某个集合"。从此，研究计算 = 研究"哪些语言能被哪类机器识别"。

⚠️ 常见误区

不要把这里的"语言"想成汉语、英语或 Python。计算理论中的语言没有任何语法、语义或用途要求——它只是"某个字母表上字符串的一个集合"，随意挑一堆串都算。这个冷僻的定义正是它力量的来源（详见 1.2 与 1.5）。

1.2字母表、字符串与语言：全部基本概念

上一节说"问题 = 语言"，但"语言"还只是一个说法。本节把整套基本概念一次给齐——它们每一个都简单得像常识，但后面几百页全盖在这块地基上。

字母表（Alphabet）是任意非空有限集，习惯记作 Σ，其中每个元素叫一个符号（Symbol）。例如 Σ = {0, 1}、Σ = {a, b, …, z}。字符串（String）是符号的有限序列，如 0110；串 w 的长度记作 |w|，即符号个数。空串（Empty String）记作 ε，是长度 0 的串：|ε| = 0。两个串的连接（Concatenation）xy 就是首尾相接；任何串连接空串都还是它自己：xε = εx = x。w 的反转记作 wᴿ，即把 w 的符号逐位倒序重写一遍，如 (0011)ᴿ = 1100。

Σ 上所有有限长字符串组成的集合记作 Σ*，读作"Σ 星"，这个运算叫克林闭包（Kleene Star）。例如 {0, 1}* = {ε, 0, 1, 00, 01, 10, 11, 000, …}——注意它含 ε，且虽然每个串都有限长，集合本身是无限的。最后，最重要的定义：

语言（Language）= Σ* 的任意子集

"任意"二字务必看重：{0, 01} 是语言，{w | w 是素数的二进制表示} 是语言，随手挑五个串组成的集合也是语言。

语言的运算

语言是集合，集合的运算（并 ∪、交 ∩、补）都适用。除此之外有三种语言特有的运算：

  • 连接：AB = { xy | x ∈ A, y ∈ B }——从 A 拿一个串、从 B 拿一个串，拼起来；所有拼法的集合。
  • 幂：Aⁿ 表示 A 与自己连接 n 次；约定 A⁰ = {ε}。
  • 星号：A* = A⁰ ∪ A¹ ∪ A² ∪ …——A 中串任意次拼接得到的所有串（含一块都不拼的 ε）。Σ* 正是这个定义的特例。

完整手算例子：Σ = {0, 1}，A = {0, 01}，B = {1, 10}

① A∪B：把两个集合的元素并起来，得 A∪B = {0, 01, 1, 10}。

② AB：A 有 2 个串、B 有 2 个串，逐对拼接共 2×2 = 4 种组合：

取自 A取自 B拼接结果
0101
010010
011011
01100110

四个结果互不相同，故 AB = {01, 010, 011, 0110}。

③ A* 中长度 ≤ 2 的全部串：按 A* = A⁰ ∪ A¹ ∪ A² ∪ … 逐层筛。

  • A⁰ = {ε}：ε 长度 0，入选。
  • A¹ = A = {0, 01}：0 长度 1 入选，01 长度 2 入选。
  • A² = AA = {0·0, 0·01, 01·0, 01·01} = {00, 001, 010, 0101}：00 长度 2 入选；001、010 长度 3，0101 长度 4，出局。
  • A³ 及更高层：每个串至少是 3 个 A 中串的连接，长度 ≥ 3，全部出局。

汇总：A* 中长度 ≤ 2 的串为 {ε, 0, 01, 00}。

三个极易混淆的对象

写法它是什么类型大小 / 长度
∅空语言，一个串都不含语言（集合）元素数 0
{ε}只含空串的语言语言（集合）元素数 1
ε空串本身字符串（不是集合）长度 0
💡 关键一跃

ε 是"空信封"，∅ 是"空抽屉"，{ε} 是"只装了一个空信封的抽屉"。三者类型都不同，后果立刻显现：∅·A = ∅（抽屉里拿不出东西，一个配对都凑不成），而 {ε}·A = A（唯一的配对伙伴是 ε，拼上等于没拼）。

⚠️ 常见误区

考试与证明里最常栽的跟头就是混淆 ∅、{ε}、ε。记住三条：ε ∈ {ε} 成立而 ε ∈ ∅ 不成立；{ε} 不是空语言，它有 1 个元素；ε 根本不是语言，它是一个串。后面归纳奠基、A⁰ 的定义全靠这一关不出错。

1.3自动机长什么样：先见森林（非正式预览）

语言定义好了，接下来的问题是：谁来判断一个串属不属于某语言？答案是机器。在给出形式化定义之前，先非正式地见一见全书最简单的机器——有限自动机（Finite Automaton）。

它只有四样本事：有限个状态；逐字符读输入，从左到右，每读一个符号做一次决定；按转移规则跳状态——"在当前状态读到这个符号，就跳到指定状态"；读完整个串后，停在某个接受状态就输出"接受"，否则输出"拒绝"。没有变量，没有内存，不能写东西——除了"我现在处于哪个状态"，它什么都记不住。

举例：识别语言 L = { w ∈ {0,1}* | w 以 1 结尾 } 的机器。它需要记住的信息只有一条："已读部分的最后一个符号是不是 1"。两个状态就够：

  • q0（初态）：已读部分不以 1 结尾（包括还没读任何东西）；
  • q1（接受状态）：已读部分以 1 结尾。

💡 关键一跃

状态 = 机器对"已读内容"的全部记忆。状态有限意味着记忆量有硬上限，与输入长度无关——这既是它能做的事（记住"最后一个符号是什么"只需 2 个状态）的根源，也是它做不到的事（"数一数 0 和 1 是否一样多"需要无界记忆）的根源。第2章的一切能力与局限，都从这个观察长出来。

⚠️ 常见误区

别把有限自动机当成一个"小程序"：它没有变量、没有纸笔、不能累加计数，唯一的信息载体就是当前状态。另外，本节只是预览——五元组形式化定义（状态集、字母表、转移函数、初态、接受状态集）和"一台机器识别一个语言"的严格含义，都留给第2章。

1.4证明工具箱（一）：构造性证明与数学归纳法

有了对象（语言）和玩家（机器），还缺规则：凭什么说一个论断成立？计算理论是数学——本书的每个结论都是定理，每个定理都要证明。阅读本书是读证明，考试与习题是写证明，"会证"远比"会背"重要。本节和下一节装备四件最常用的工具。

第一件先预告：构造性证明（Proof by Construction）——要证"某类语言能被识别"，就动手造出一台机器并验证它工作正常。从第2章起这会是你写得最多的证明类型，现在先记住这个名字。本节的主角是第二件工具。

数学归纳法：把无穷多情形压缩成两步

字符串可以任意长，机器可以运行任意多步——要证的命题往往形如"对所有长度 n 都成立"，n 有无穷多个，逐个验证不可能。数学归纳法（Mathematical Induction）就是为此设计的，骨架四步：

  1. 奠基：直接验证 P(0) 成立；
  2. 归纳假设：假定 P(k) 对某个 k ≥ 0 成立；
  3. 归纳步：在此假定下证明 P(k+1) 成立；
  4. 结论：由归纳法，P(n) 对所有 n ≥ 0 成立。

真正的难点不在骨架而在"对什么量归纳"：可以对串长 |w| 归纳、对机器运行步数归纳、也可以对结构（如表达式的嵌套层数）归纳。选对归纳变量，证明通常自己就展开了。

完整证明 1：对任意字符串 x, y，|xy| = |x| + |y|

命题 P(n)：对任意串 x 和任意长度为 n 的串 y，都有 |xy| = |x| + |y|。对 |y| 归纳（对 |x| 归纳同样可行，但连接的递归定义习惯从右端拆，故选 y）。

  • 奠基（n = 0）：|y| = 0 意味着 y = ε。于是 xy = xε = x（空串是连接的单位元），故 |xy| = |x| = |x| + 0 = |x| + |y|。奠基成立。✓
  • 归纳假设：设 P(k) 成立，即对所有 |y| = k 的串 y 与任意 x，|xy| = |x| + |y|。
  • 归纳步：任取 |y| = k + 1 的串 y。则 y 可以写成 y = wa，其中 a 是末尾那个符号、|w| = k。于是：
    |xy| = |x(wa)| = |(xw)a| = |xw| + 1 = (|x| + k) + 1 = |x| + (k + 1) = |x| + |y|
    逐步交代依据：第一步代入 y = wa；第二步是连接的结合性（先拼谁不影响结果串）；第三步是长度定义——串尾添一个符号，长度加一；第四步对 xw 用归纳假设（|w| = k，假设管得着它）；后两步是算术与 |y| = k + 1。P(k+1) 成立。✓
  • 结论：由数学归纳法，|xy| = |x| + |y| 对任意串 x, y 成立。∎

完整证明 2：对任意串 w，(wᴿ)ᴿ = w

先回顾反转的递归定义：εᴿ = ε；若串可写成 ua（u 是串、a 是单个符号），则 (ua)ᴿ = a·uᴿ。由此直接得到一个有用的局部事实：对单个符号 a 与任意串 v，(av)ᴿ = vᴿ·a（从右端逐字符拆 av 即得）。对 |w| 归纳。

  • 奠基（|w| = 0）：w = ε，(εᴿ)ᴿ = εᴿ = ε = w。✓
  • 归纳假设：对所有 |u| = k 的串 u，(uᴿ)ᴿ = u。
  • 归纳步：任取 |w| = k + 1，写成 w = ua，|u| = k。则
    (wᴿ)ᴿ = ((ua)ᴿ)ᴿ = (a·uᴿ)ᴿ = (uᴿ)ᴿ·a = u·a = w
    第一步代入 w = ua；第二步用反转定义 (ua)ᴿ = a·uᴿ；第三步用上面的局部事实（把 a·uᴿ 看成"单符号 a 接上串 uᴿ"）；第四步用归纳假设（|u| = k）；最后 u·a 就是 w。✓
  • 结论：由归纳法，(wᴿ)ᴿ = w 对一切串 w 成立。∎
⚠️ 常见误区

"归纳法是循环论证"——不是。奠基独立成立、不依赖结论；归纳步只负责把"P(k) 成立"传递成"P(k+1) 成立"，它没有预设任何 P(k+1)。真正的常见错误是另外两个：漏奠基（少了第一块多米诺骨牌，后面全白搭）和归纳方向搞反（把"设 P(k) 证 P(k+1)"写成"设 P(k+1) 证 P(k)"）。

何时用对串长 |w|、运行步数、结构层数归纳；第2章证"机器行为正确"几乎全靠它。

1.5证明工具箱（二）与错误直觉：反证法 + 本章误区集中清算

归纳法对付"任意长、任意多"的对象；还有一类命题——"不存在""不可能"——直接构造无从下手：你没法"造出一个不存在的东西"。这时需要另一件武器。

反证法：假设敌人存在，跟它走到撞墙

反证法（Proof by Contradiction）三段式：① 假设结论不成立 → ② 从假设推出与已知事实的矛盾 → ③ 故假设错、结论成立。

完整例子：√2 是无理数。先用到一个算术事实：奇数的平方是奇数——因为 (2k+1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1 仍是奇数；等价的逆否命题是"若 a² 为偶，则 a 为偶"。

  • ① 假设结论不成立：设 √2 是有理数，则可写成既约分数 √2 = a/b，其中 a、b 为正整数且最大公因数为 1（"既约"意味着分子分母没有公因子可约）。
  • ② 推出矛盾：两边平方得 a² = 2b²，故 a² 为偶数；由上面的算术事实，a 为偶数，设 a = 2c。代回：(2c)² = 2b²，即 4c² = 2b²，化简得 b² = 2c²，故 b² 为偶数，于是 b 也为偶数。现在 a、b 都是偶数，有公因子 2——与"a/b 既约"矛盾。
  • ③ 结论：假设不成立，√2 是无理数。∎

注意第②步里"既约"这个看似多余的条件是整枚炸弹的引信——没有它，"a、b 皆偶"就撞不到墙。写反证证明时，埋假设的那一刻就要想好最后撞哪堵墙。

鸽巢原理：一句大白话埋下第2章的伏笔

鸽巢原理（Pigeonhole Principle）：把 n + 1 只鸽子放进 n 个洞，必有一个洞里至少有两只。显然得近乎废话——但把它套到有限自动机上：机器只有有限个状态，输入却可以任意长；读一个足够长的输入时，访问状态的次数超过状态总数，必有某个状态被重复访问。这个"状态重复"正是第2章泵引理（证明某类语言不能被有限自动机识别）的核心机关。

本章错误直觉集中清算

⚠️ 误区 ①："归纳法是循环论证"

错。奠基独立验证 P(0)，不引用任何结论；归纳步只做传递 P(k) ⟹ P(k+1)，从未预设 P(k+1)。"假设了要证的东西"的幻觉来自没分清"假设前一个位置"与"假设目标位置"。

⚠️ 误区 ②："ε、∅、{ε} 差不多"

错。ε 是串（长度 0），∅ 是空语言（0 个元素），{ε} 是含一个串的语言（1 个元素）——类型都不同。运算后果立刻不同：∅·A = ∅，{ε}·A = A。归纳奠基和正则表达式里，这一关错一步全盘皆输。

⚠️ 误区 ③："语言必须有意义、有规律，随便一堆串不算语言"

错。语言就是 Σ* 的任意子集——随机挑五个串也是语言，绝大多数语言毫无规律可言。这个一般性正是力量来源：只有允许"任意"语言，"这个语言不可被任何机器识别"这类结论才有谈论的对象（第5章的主角就是这种语言）。

⚠️ 误区 ④："反证法证出的结论不够'真实'"

错。在本书采用的经典逻辑里，反证与构造性证明效力完全相同。√2 的无理性没有任何"构造性"证法能比上面的反证更直接；而第5章几乎所有"不可判定"的结论，本质上都靠反证（配合对角线法）拿下。

📝分层习题

L1 概念辨析设 Σ = {0, 1}。判断下列陈述的真假，并说明理由：(a) ε ∈ ∅；(b) ε ∈ {ε}；(c) ∅ ⊆ {ε}；(d) |ε| = 1；(e) {ε} 是空语言。
提示

先回答每个对象"是串还是集合"，再问"元素 / 子集"关系。⊆ 是集合之间的包含关系：A ⊆ B 表示 A 的每个元素都在 B 里。

完整解答
(a) 假。∅ 不含任何元素，ε 也不例外。(b) 真。{ε} 的唯一元素就是 ε。(c) 真。空集是任何集合的子集——"∅ 的每个元素都在 {ε} 里"空洞地成立（∅ 没有元素可违反它）。(d) 假。|ε| = 0；长度为 1 的串形如 "0" 或 "1"。(e) 假。空语言是 ∅，元素数为 0；{ε} 有 1 个元素，不是空语言。易错点是 (c)：很多人把 ⊆ 和 ∈ 混淆，或忘记空集是万能子集。
L1 概念辨析设 Σ = {a, b}。下列哪些是"Σ 上的语言"？(i) {a, ab, aab}；(ii) {w | w 是回文，即 w = wᴿ}；(iii) 闭着眼睛从 Σ* 里随机挑 5 个串组成的集合；(iv) {a, 你}（其中"你"是一个汉字）。
提示

语言 = Σ* 的任意子集。检查每条候选：它的每个元素是不是 Σ 上的有限字符串？至于"有没有规律"，定义根本不关心。

完整解答
(i) 是。三个元素都是 {a,b} 上的有限串，集合是 Σ* 的子集。(ii) 是。它由性质刻画，但每个成员仍是 Σ* 中的串——"用语言描述语言"完全合法。(iii) 是。"任意子集"包含随机挑的、毫无规律的子集；一般性正是定义的本意。(iv) 不是。"你"不是由 a、b 组成的串，故该集合不是 Σ* 的子集，不是 Σ 上的语言（它可以算作某个含"你"的更大字母表上的语言，但那就换了 Σ）。易错点是否定 (iii)：把"语言"误当成"有规律之串的集合"。
L2 手算推导设 Σ = {a, b}，A = {a, ab}，B = {b, ba}。求 AB 与 BA，并据此判断"语言连接满足交换律（AB = BA）"是否成立。步骤写全。
提示

AB 的每个元素形如 xy（x 从 A 取、y 从 B 取）：2×2 = 4 对，逐对拼接。BA 同理，只是顺序反过来。比较两个集合时，只需找出一个"在一边而不在另一边"的串即可判定不相等。

完整解答
算 AB：a·b = ab；a·ba = aba；ab·b = abb；ab·ba = abba。四者互不相同，故 AB = {ab, aba, abb, abba}。
算 BA：b·a = ba；b·ab = bab；ba·a = baa；ba·ab = baab。四者互不相同，故 BA = {ba, bab, baa, baab}。
判断是否相等：AB 中每个串都以 a 开头，BA 中每个串都以 b 开头，例如 ab ∈ AB 但 ab ∉ BA。故 AB ≠ BA——语言连接不满足交换律（它满足结合律，这点以后会用）。易错点：拼接顺序写反（ab·b 是先写 ab 再接 b，得 abb，不是 bab），以及用"元素个数相同"误判两集合相等。
L2 手算推导用数学归纳法证明：对任意串 w 与任意 n ≥ 0，|wⁿ| = n·|w|。（定义：w⁰ = ε，wⁿ⁺¹ = wⁿw。可直接引用 1.4 已证的 |xy| = |x| + |y|。）
提示

对 n 归纳（不是对 w——w 在整个证明中固定不动）。奠基处理 w⁰ = ε；归纳步用递归定义 wᵏ⁺¹ = wᵏw 把长度拆开。

完整解答
设 P(n)：对任意串 w，|wⁿ| = n·|w|。对 n 归纳。
奠基（n = 0）：|w⁰| = |ε| = 0 = 0·|w|。✓
归纳假设：设 P(k) 成立，即 |wᵏ| = k·|w|。
归纳步：|wᵏ⁺¹| = |wᵏw|（w 幂的递归定义）= |wᵏ| + |w|（1.4 已证结论，取 x = wᵏ、y = w）= k·|w| + |w|（归纳假设）= (k + 1)·|w|。P(k+1) 成立。✓
结论：由归纳法，|wⁿ| = n·|w| 对一切 n ≥ 0 与任意串 w 成立。∎
易错点：归纳步忘记交代每一步的依据（递归定义 / 已证定理 / 归纳假设各司其职）；或试图对 w 归纳——w 不是自然数，无处可"归"。
L3 建模应用把"判断一个十进制正整数能否被 3 整除"表述为一个语言判定问题，并说明为什么"有限记忆"的机器很可能够用来识别它。（提示：10 ≡ 1 (mod 3)；机器读数字时真正需要记住的是什么？）
提示

先选字母表、再写出语言定义。然后算一笔账：若当前已读部分的数值模 3 余 r，再读一个数字 d 后，新余数是多少？它与"已读的全部内容"相比，需要记住的信息量是多少？

完整解答
建模：取字母表 Σ = {0, 1, …, 9}，定义语言 DIV3 = { w ∈ Σ* | w 所表示的十进制数 ≡ 0 (mod 3) }。于是"判断整数 n 能否被 3 整除" ⇔ 判定 n 的十进制写法是否属于 DIV3。
为什么有限记忆可能够用：设已读部分的数值模 3 余 r。再读一个数字 d 后，新数值 = 旧值 × 10 + d，新余数 = (10r + d) mod 3 = (r + d) mod 3（因为 10 ≡ 1 (mod 3)）。也就是说，机器每读一个数字，只需要知道当前的余数 r ∈ {0, 1, 2} 就能算出下一个余数——无需记住已读的任何具体数字，更无需记住输入有多长。候选记忆只有 3 种取值，与输入长度无关，正好符合"有限个状态"的要求：用 3 个状态分别代表余数 0、1、2，初态与接受状态都是"余数 0"，读完接受 ⇔ 整除。顺带一提，(r + d) mod 3 反复累加正是"数位和模 3"的口算规则——机器版与小学版是同一个算法。正式构造（状态图与五元组）是第2章的开胃菜。

解析：B 对——把图编码为字符串 〈G〉（如邻接矩阵的 01 串），语言取"连通图的编码"这个子集即可。A 错："所有图"混入了不连通的图，无法区分答案为"是"的实例；C 错：{0,1}* 含所有串，连"非图编码"的串都在内，成员判定不携带任何信息；D 错：邻接矩阵、边列表都是现成的字符串编码方案。

🗣️ 用自己的话，三句话讲完本章

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：把"计算"变成可以严格证明的数学对象——任何判定问题都能编码为"字符串是否属于某个集合"，于是"机器能算什么"变成"机器能识别哪些语言"。（对应 1.1、1.2）
句2：核心机制是什么？——
参考答案：一套集合论定义（字母表、字符串、语言、克林闭包）圈定研究对象；机器模型（本章预览了有限自动机）充当识别语言的玩家；证明工具箱（构造、归纳、反证、鸽巢）为一切结论兜底。（对应 1.2–1.5）
句3：它和前后章怎么分工？——
参考答案：本章只给对象、玩家与证明规则，不证明任何关于机器能力的实质定理；第2、3章用这套语言研究两类具体机器（有限自动机、加栈的下推自动机）的能力边界；第4章起升级到图灵机问"什么根本不可算"，第7章起问"能算的多难算"。
