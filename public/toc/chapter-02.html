2.1确定型有限自动机：如何形式化"有限记忆"？

第1章我们非正式地见过自动机：几个圆圈、一些箭头、从起点跟着符号走。直觉够了，但证明定理需要数学对象。本节回答：怎样把"一台只有有限记忆的机器"压缩成一个五元组？

确定型有限自动机（Deterministic Finite Automaton，DFA）是一个五元组 M = (Q, Σ, δ, q₀, F)：

  • Q：有限状态集合——机器全部记忆的载体，它就"只能记住自己此刻在哪个状态"；
  • Σ：有限字母表——输入串由这里的符号组成；
  • δ : Q × Σ → Q：转移函数（Transition Function）——"在状态 q 读到符号 a，下一步去 δ(q, a)"；
  • q₀ ∈ Q：起始状态；
  • F ⊆ Q：接受状态集合。

形式化"接受"：把 δ 逐符号扩展到整串，记 δ̂(q, ε) = q，δ̂(q, wa) = δ(δ̂(q, w), a)。若 δ̂(q₀, w) ∈ F，则 M 接受 w。M 识别的语言 L(M) = { w | δ̂(q₀, w) ∈ F }。被某个 DFA 识别的语言称为正则语言（Regular Language）。

完整例子：识别"含子串 001 的二进制串"

设计之前先回答一个问题：每个状态要记住什么？机器只需要记住"001 这个模式目前已经匹配到哪里了"：

  • q₀：还没见到任何可用的 0（最近一个符号是 1，或刚开始）；
  • q₁：刚见到一个 0，期待下一个 0；
  • q₂：刚见到 00，期待 1——再读 1 就成功；
  • q₃：已经见过 001，任务完成——之后读什么都无所谓（接受态，也是陷阱态）。
flowchart LR s(["start"]) --> q0("q0") q0 -- "0" --> q1("q1") q0 -- "1" --> q0 q1 -- "0" --> q2("q2") q1 -- "1" --> q0 q2 -- "0" --> q2 q2 -- "1" --> q3(("q3")) q3 -- "0, 1" --> q3
图 2.1 识别"含子串 001"的 DFA。看 q₂ 读 0 仍回 q₂（00 后面再添 0 不算失败，最后一个 0 仍是候选结尾的第二位 0）；q₃ 双线圈，读什么都留在 q₃。

💡 关键一跃

设计 DFA = 回答"每个状态要记住什么"。先给每个状态写一句人话含义（如"刚见到 00"），转移边就自然长出来：对每个状态逐个问"此刻读到 0 怎么办、读到 1 怎么办"。状态含义先行，转移表随后自动出现——这是本章一切构造题的第一招。

⚠️ 常见误区

δ 是全函数：每个状态对每个符号都必须有出边，不允许"卡死"。初学者的状态图常常少画了"失败边"（比如 q₀ 读 1 去哪）。少了边，数学上它就不是 DFA。实在无处可去时，必须显式补一个自环的陷阱态兜底。

2.2非确定型有限自动机：让机器"猜"会怎样？

上一节的 DFA 每一步都被钉死。但有些语言用 DFA 设计很绕：比如"以 ab 结尾的串"，DFA 需要记住"上一个字符是不是 a"。如果允许机器猜——"我猜现在就是倒数第二位"——设计会直白得多。本节回答：猜测能力如何定义，它会不会改变机器的能力上限？

非确定型有限自动机（Nondeterministic Finite Automaton，NFA）与 DFA 的差别只在转移函数：

δ : Q × (Σ ∪ {ε}) → P(Q)
  • 读一个符号可以到达一个状态集合（零个、一个或多个），机器分裂成多个并行分支；
  • 允许 ε 转移（ε-transition）：不消耗任何输入符号就能跳槽到另一个状态；
  • 接受语义：只要存在至少一条计算分支读完整个输入后停在接受态，串就被接受。

完整例子：识别"以 ab 结尾的串"的 NFA

设计思路一句话：在 p 上原地打转随便读，猜某个 a 是倒数第二位，经 q 验证下一个符号是 b 后进接受态 r。

flowchart LR s(["start"]) --> p("p") p -- "a, b" --> p p -- "a" --> q("q") q -- "b" --> r(("r"))
图 2.2 识别"以 ab 结尾"的 NFA。看 p 读 a 有两条出边（留下或去 q）——这就是"猜"；q 没有 b 以外的出边，分支可死亡。

跑输入 aab，把全部分支列出来（初始只有 {p}）：

分支路径结局
分支 1p →(a) p →(a) p →(b) p读完停在 p，非接受态 ⇒ 该分支拒绝
分支 2p →(a) q →(a) ✗q 读 a 无出边，分支中途死亡
分支 3p →(a) p →(a) q →(b) r读完停在 r ⇒ 接受

三条分支里只要有一条活路到 r，整个输入 aab 就被接受。用"状态集合"的视角看同一过程：{p} →(a) {p,q} →(a) {p,q} →(b) {p,r}，r ∈ F 故接受——这正是下一节子集构造的读法。

💡 关键一跃

NFA 的"猜对就算"是存在性语义：它不是概率（没有 50% 这种数字），不是并行加速（不省时间，分支可以指数多），只是让描述更紧凑。你把 NFA 想成一个会分身术的侦探：分身再多，只要有一个分身破案，就算破案。

⚠️ 错误直觉预警

"NFA 比 DFA 强"是错觉。NFA 设计起来省事，但下一节就证明：每台 NFA 都能被一台 DFA 完全模拟，二者识别的语言类一模一样。猜测省的是描述长度，不是识别能力。

2.3子集构造：NFA 为什么不多算一个语言？

上一节留下悬念：猜测到底有没有增加能力？本节用本章第一个核心证明模板回答：没有。

✅ 定理

每个 NFA 都有与之等价的 DFA（识别完全相同的语言）。证明方法是子集构造（Subset Construction，也叫 Powerset Construction）：用 DFA 的一个状态代表"NFA 此刻可能处在的状态集合"。

构造的关键在 ε 转移：读符号前后，机器可能沿着 ε 边"免费"漂移。先定义 ε 闭包（ε-closure）E(R)：从集合 R 出发，只走 ε 边能到达的所有状态（含 R 自己）。

完整手算：对带 ε 的"以 ab 结尾"NFA 做子集构造

把 2.2 的 NFA 加一个新初态 s 和一条 ε 边，得到 4 个状态的 NFA：

flowchart LR st(["start"]) --> s("s") s -- "ε" --> p("p") p -- "a, b" --> p p -- "a" --> q("q") q -- "b" --> r(("r"))
图 2.3 带 ε 转移的版本：s 一开局就免费漂到 p，所以 {s} 的 ε 闭包是 {s, p}。

子集构造四步，一步不跳：

  1. 起态取闭包：DFA 起态 A = E({s}) = {s, p}（s 沿 ε 边免费到 p）。
  2. 每个集合 × 每个符号：先并 δ 再取闭包：
    • A = {s,p} 读 a：δ(s,a) ∪ δ(p,a) = ∅ ∪ {p,q} = {p,q}；ε 闭包仍是 {p,q} → 记为 B。读 b：∅ ∪ {p} = {p} → 记为 C。
    • B = {p,q} 读 a：{p,q} ∪ ∅ = {p,q}，闭包 {p,q} = B（自环）。读 b：{p} ∪ {r} = {p,r}，闭包 {p,r} → 记为 D。
    • C = {p} 读 a：{p,q} → B。读 b：{p} → C（自环）。
    • D = {p,r} 读 a：{p,q} ∪ ∅ = {p,q} → B。读 b：{p} ∪ ∅ = {p} → C。
  3. 接受集合：凡含 NFA 接受态 r 的集合 ⇒ 只有 D = {p, r}。
  4. 到没有新集合为止：A、B、C、D 都已展开，共 4 个状态，构造结束。

汇总成等价 DFA 的转移表：

DFA 状态= NFA 状态集合读 a读 b
→ A{s, p}BC
B{p, q}BD
C{p}BC
* D{p, r}BC
flowchart LR st(["start"]) --> A("A") A -- "a" --> B("B") A -- "b" --> C("C") B -- "a" --> B B -- "b" --> D(("D")) C -- "a" --> B C -- "b" --> C D -- "a" --> B D -- "b" --> C
图 2.4 子集构造得到的 4 状态 DFA。验证：aab 走 A→B→B→D 接受；ba 走 A→C→B 拒绝。与原 NFA 完全一致。

爆炸风险：n 个状态的 NFA，子集构造最多产生 2ⁿ 个 DFA 状态（每个子集一个）。2 状态变 4，10 状态理论上可变 1024——等价的代价可能是指数膨胀。

✅ 证明模板卡 · 子集构造流程

① 起态 = E({q₀})，先取 ε 闭包；② 对每个已达集合 R 和每个符号 a：先算 ⋃r∈R δ(r, a)，再对结果取 ε 闭包，得到新集合；③ 凡含原 NFA 接受态的集合全部标为接受；④ 重复 ② 直到没有新集合产生。四步机械执行，永不遗漏——考试大题照此走即可拿全分。

⚠️ 常见误区

"等价"指识别的语言相同，不是结构相同、更不是状态数相同。DFA 可能比原 NFA 大得多（最坏 2ⁿ）。另一个高频错误：第 ② 步忘记取 ε 闭包——只并了 δ 就停手，导致漏掉所有靠 ε 边白嫖的状态，整张表全错。

2.4正则表达式：换一种方式描述同一类语言

前三节是"识别器"视角：给一台机器，串喂进去判 Yes/No。本节换成"模式/生成"视角：写一个表达式，直接声明这个语言的串长什么样。答案依然指向同一类语言。

先看三种正则运算（Regular Operations）：并 A ∪ B、连接 A ∘ B = { xy | x∈A, y∈B }、星号 A* = { x₁x₂…xₖ | k ≥ 0，每个 xᵢ ∈ A }（含 ε）。正则语言对三者封闭——证明是构造性的：把两台 NFA 并联（新初态 ε 分两路）、串联（旧接受态 ε 接新初态）、或套星号回路（新初末态之间 ε 来去）。

flowchart LR u0["新初态"] -- "ε" --> n1["N1"] u0 -- "ε" --> n2["N2"] n1 -- "ε" --> uf["新接受"] n2 -- "ε" --> uf c1["N1"] -- "ε" --> c2["N2"] k0["新初态"] -- "ε" --> k1["N"] k0 -- "ε" --> kf["新接受"] k1 -- "ε" --> kf kf -. "ε 回头" .-> k1
图 2.5 封闭性三构造：上方并联（并）、左下串联（连接）、右下星号回路（新初态也可 ε 直达新接受态，保证含空串）。

正则表达式（Regular Expression）归纳定义：R 是正则表达式，当且仅当 R 是以下之一——

  1. ∅（空语言）、ε（只含空串）、a（a ∈ Σ，只含单符串 a）；
  2. (R₁ ∪ R₂)、(R₁ ∘ R₂)、(R₁*)，其中 R₁、R₂ 已是正则表达式。

优先级：星号 > 连接 > 并。所以 01* ∪ 0 = (0(1*)) ∪ 0，不要误读成 (01)*。

例子快练——遮住右列先自己想：

正则表达式描述的语言
0*10*恰好含一个 1 的串（0 围着一个 1）
(01 ∪ 10)*由 01 和 10 两种砖块拼成的串（含 ε）
Σ*1以 1 结尾的串
(0 ∪ 1)*= Σ*，全体二进制串

完整构造：为正则表达式 (ab ∪ a)* 搭等价 NFA

按归纳定义自底向上逐步搭建（Thompson 构造）：每个片段一个新初态、一个新接受态，组合时只用 ε 边缝合。

步骤搭什么怎么搭
1片段 a新初态 x₁ --a--> 新接受 x₂
2片段 b新初态 y₃ --b--> 新接受 y₄
3片段 ab（连接）y₁ --a--> y₂，再用 ε 边 y₂ --ε--> y₃ 把片段 b 缝在后面
4ab ∪ a（并）新初态 u₀ 用两条 ε 边分别接片段 a 与片段 ab 的初态；两片接受态各用 ε 边接新接受 u₁
5(ab ∪ a)*（星号）新初态 s₀ --ε--> u₀，且 s₀ --ε--> 新接受 f₀（保证空串被接受）；u₁ --ε--> u₀ 形成回路，u₁ --ε--> f₀ 收尾
flowchart LR st(["start"]) --> s0("s0") s0 -- "ε" --> u0("u0") s0 -- "ε" --> f0(("f0")) u0 -- "ε" --> x1("x1") u0 -- "ε" --> y1("y1") x1 -- "a" --> x2("x2") y1 -- "a" --> y2("y2") y2 -- "ε" --> y3("y3") y3 -- "b" --> y4("y4") x2 -- "ε" --> u1("u1") y4 -- "ε" --> u1 u1 -- "ε" --> u0 u1 -- "ε" --> f0
图 2.6 (ab ∪ a)* 的 Thompson 构造成品。看 u₁→u₀ 那条回头 ε 边——它就是星号；s₀→f₀ 的直通 ε 边保证 ε 被接受。

等价性定理：一个语言是正则的 ⟺ 它能被某个正则表达式描述。两个方向各一句话：RE → NFA 就是上面的归纳构造；NFA → RE 用 广义非确定型有限自动机（GNFA）逐个消去状态、把边上的标签滚成越来越大的正则表达式，本章只需记住思想。三者等价：DFA = NFA = 正则表达式。

💡 关键一跃

DFA/NFA 是识别器视角（给串判 Yes/No），正则表达式是生成/模式视角（声明串的构造方式）。三者是同一类语言的三种"语言"——就像同一件事的三个译本，按场合选用最顺手的一个：做实现用 DFA，做设计用 NFA，写模式用正则表达式。

2.5泵引理：正则语言的"体检报告"

前四节一直在证明"正则语言能做什么"，本节反转：证明某些语言做不到。工具只有一个直觉——鸽巢原理。

一台 DFA 只有 p 个状态。读一个长度 ≥ p 的串 s 时，路径上经过的状态数超过 p，必有某个状态被踩了两次。设第一次、第二次踩中同一状态之间读掉的那段为 y，那么 y 是一个循环：多绕几圈（y²、y³…）或一圈都不绕（y⁰），机器根本分不出来——这些串要么全在语言里，要么全不在。这就是泵引理（Pumping Lemma）。

✅ 泵引理（严格陈述）

若 A 是正则语言，则存在泵长 p ≥ 1，使得任意 s ∈ A 且 |s| ≥ p，都可分解为 s = xyz 且同时满足：
(1) 对任意 i ≥ 0，xyⁱz ∈ A；　(2) |y| > 0；　(3) |xy| ≤ p。

三个条件各司其职：(1) 是"泵"本身——中段可任意重复或删除；(2) 保证泵的东西非空，否则引理毫无意义；(3) 限制循环段出现的位置——必须落在串的前 p 个字符内，这是做题时锁死 y 形态的关键。

证明思想（三步）：① 取 p = 某台识别 A 的 DFA 的状态数；② 读 s 的前 p 个符号经过 p+1 个状态，鸽巢原理给出重复状态 qⱼ = qₖ；③ 令 y 为两次踩中 qⱼ 之间读掉的段，|y| > 0 且 |xy| ≤ p 自动成立，绕圈可泵。

完整三段式反证：B = { 0ⁿ1ⁿ | n ≥ 0 } 不是正则语言

第 ① 步 · 假设拿泵长：假设 B 正则，泵引理给出泵长 p。选串 s = 0ᵖ1ᵖ。显然 s ∈ B 且 |s| = 2p ≥ p，泵引理保证存在分解 s = xyz 满足三条件。

第 ② 步 · 分情况讨论 y 的位置（条件 |y| > 0 保证 y 非空）：

  • 情况一：y 全落在前半段 0 区。则 xy²z 中 0 的个数 > p，1 的个数 = p，0、1 不等 ⇒ xy²z ∉ B。
  • 情况二：y 横跨 0/1 边界，即 y 含 0 也含 1。则 xy²z 出现 …1…0…1…0… 的交错 ⇒ xy²z ∉ B。
  • 情况三：y 全落在后半段 1 区。则 xy²z 中 1 多于 0 ⇒ xy²z ∉ B。

——而条件 (3) |xy| ≤ p 其实直接排除了情况二、三：xy 整体落在前 p 个字符里，前 p 个字符全是 0，所以 y 必然是纯 0 段 0ᵏ（k ≥ 1）。考试里用这一步锁死，连分情况都省了。这里把三种情况列全，是为了让你看清每个条件到底在防什么。

第 ③ 步 · 矛盾收网：所有可能的分解都泵出 xy²z ∉ B，违反泵引理条件 (1)。假设不成立 ⇒ B 非正则。∎

✅ 证明模板卡 · 泵引理三段式

① 假设语言正则，拿到泵长 p；② 构造魔法串 s（与 p 挂钩，让任何合法分解都无处可逃，常用 p 次幂把 y 锁死在单一符号段）；③ 枚举 y 的全部位置情况（或用 |xy| ≤ p 一步锁死），逐一选出泵次 i（通常 i=2 或 i=0）使 xyⁱz 跑出语言外，得矛盾。
博弈解读：p 由对方任选、分解 xyz 由对方任选（只受条件 2、3 约束）；s 和泵次 i 由我方选。我方后手出招，必须对对方的所有可能应手全部取胜。

⚠️ 本章头号红线

泵引理是单向蕴含：正则 ⇒ 满足泵条件。它只能用来证"非正则"（逆否：泵条件被破坏 ⇒ 非正则），不能用来证"正则"——存在满足泵三条件却非正则的语言。"我验证了某串可泵，所以语言正则"是充分必要混淆，方向用反整题零分。

2.6错误直觉集中清算：本章最容易踩的四个坑

正文讲完了。考试和面试里丢分的往往不是不懂，而是直觉走偏。本节把本章四大误区钉死在墙上，每条都给出"为什么错"和"代价是什么"。

⚠️ 误区一："NFA 表达能力比 DFA 强"

错。2.3 的子集构造证明两者识别的语言类完全相同——都是正则语言。NFA 的优势只在简洁性：同一个语言，NFA 可能用 n 个状态，等价 DFA 最坏要 2ⁿ 个。猜测省的是描述长度，不是识别能力；想白捡简洁，代价是指数膨胀。

⚠️ 误区二："泵引理可以证明语言是正则的"

错，方向反了。泵引理是"正则 ⇒ 可泵"的单向蕴含，逆命题不成立。它唯一的用途是反证非正则：假设正则 → 推出泵条件被破坏 → 矛盾。拿它正向使用，等于拿体检合格标准去诊断健康人没病——逻辑上不成立。

⚠️ 误区三："正则语言都是有限语言"

错。a* = { ε, a, aa, aaa, … } 是无限语言，它有再小不过的两状态 DFA（其实一个状态就够）。正则与否看的是"识别所需的记忆是否有界"，不是语言的大小。有限语言一定正则，但正则语言可以无限——星号就是专门制造无限的运算。

⚠️ 误区四："DFA 的 δ 可以缺省，卡死就当拒绝"

错。δ : Q × Σ → Q 是全函数，每个状态对每个符号必须有唯一出边。"卡死拒读"是 NFA 的特权（δ 可以返回 ∅）。DFA 想表达"读到就失败"，必须显式补一个所有出边都指回自己的陷阱态（Trap/Dead State）——2.1 的 q₃ 就是接受版的陷阱态。

📝分层习题

L1 概念辨析判断：一台 NFA 读同一个输入串，能否同时存在两条都到达接受态的计算分支？
提示

回到接受语义的定义：它要求"存在至少一条"还是"恰好一条"？分支数量有没有上限？

完整解答
能。接受语义只要求"存在至少一条"分支读完停在接受态，对成功分支的数量毫无限制。例如"以 ab 结尾"的 NFA 读 aab 与读 aaab 时，在最后一个 a 处既留在 p 又去了 q——多条分支并存是 NFA 的常态。易错点：把"确定型"的唯一路径直觉带进 NFA，误以为分叉必须二选一。
L1 概念辨析判断正误并说明理由："若语言 L 满足泵引理的三个条件，则 L 是正则语言。"
提示

泵引理的蕴含方向是什么？充分和必要，哪个是哪个？

完整解答
错误。泵引理是单向蕴含：正则 ⇒ 满足泵条件。它的逆命题不成立——可以构造出满足全部三条泵条件、却被其他方法（如封闭性 + 更强的泵引理变体）证明非正则的语言。因此泵条件只是正则性的必要条件而非充分条件。它唯一的合法用途是反向：破坏泵条件 ⇒ 非正则。方向用反是本题最常见的零分姿势。
L2 手算推导设计识别"倒数第 2 位是 1"的二进制串的 NFA（不超过 3 个状态），然后对它执行子集构造的前两步（求 DFA 起态、算出起态在 0 和 1 下的后继集合）。
提示

让机器在原地打转随便读，"猜"某个 1 是倒数第 2 位——猜对之后还需再读恰好一个符号收尾。子集构造第一步永远先取 ε 闭包。

完整解答

NFA 设计（3 个状态）：q₀ 是起点，读 0、1 都自环（原地打转等待）；q₀ 读 1 时同时分叉到 q₁（猜这个 1 是倒数第 2 位）；q₁ 读 0 或 1 都到 q₂；q₂ 是唯一接受态，且无出边——读完输入时分支必须恰好停在 q₂。

验证：w = 011。q₀→(0)q₀→(1) 分叉 {q₀, q₁} →(1)：q₀ 自环 + q₀ 又分叉到 q₁ + 旧 q₁ 读 1 到 q₂ ⇒ 集合 {q₀, q₁, q₂}，含 q₂ 故接受；倒数第 2 位确为 1 ✓。w = 010：末位读后集合为 {q₀, q₁}，不含 q₂，拒绝 ✓。

子集构造前两步：

第 ① 步（起态）：本 NFA 无 ε 转移，A = E({q₀}) = {q₀}。

第 ② 步（起态的转移）：A 读 0：δ(q₀,0) = {q₀}，闭包 {q₀} ⇒ A →(0) A（自环）。A 读 1：δ(q₀,1) = {q₀, q₁}，闭包仍为 {q₀, q₁} ⇒ 新集合 B = {q₀, q₁}，A →(1) B。

（后续步骤供自检：B 读 0 → {q₀}∪{q₂} = {q₀, q₂}；B 读 1 → {q₀,q₁}∪{q₂} = {q₀,q₁,q₂}，后者含 q₂ 为接受态。）

L2 手算推导用泵引理证明 L = { w ∈ {0,1}* | w 中 0 与 1 的个数相等 } 不是正则语言，写完整三段式。
提示

魔法串仍然选 0ᵖ1ᵖ——它属于 L（0、1 各 p 个），且 |xy| ≤ p 能把 y 锁死在纯 0 段。

完整解答

第 ① 步：假设 L 正则，则存在泵长 p。选 s = 0ᵖ1ᵖ：s ∈ L（0、1 各 p 个）且 |s| = 2p ≥ p，故存在分解 s = xyz 满足 (1) 任意 i ≥ 0 有 xyⁱz ∈ L；(2) |y| > 0；(3) |xy| ≤ p。

第 ② 步：由条件 (3)，xy 整体落在 s 的前 p 个字符内，而前 p 个字符全是 0，故 y = 0ᵏ，由条件 (2) 知 k ≥ 1。取 i = 2：xy²z = 0ᵖ⁺ᵏ1ᵖ，其中 0 有 p+k 个、1 有 p 个，两者不等，故 xy²z ∉ L。

第 ③ 步：对任何满足 (2)(3) 的分解，泵两次都逃出 L，与条件 (1) 矛盾。假设不成立，故 L 非正则。∎（技巧点评：选串时让"被锁死的段"恰好是计数天平的某一端，泵它就打破平衡。）

L3 建模应用现实场景：编译器词法分析器要识别"合法标识符"——字母开头，后面跟任意多个字母或数字（如 x、tmp2、Loop9x）。① 写出描述它的正则表达式；② 说明为什么词法分析器最终基于 DFA 而不是直接模拟 NFA 来实现。
提示

把"字母"记为 L、"数字"记为 D，先拼出"首字符"和"后续字符"两个片段。再想想：词法分析要在每微秒处理海量字符，它承受得起分支回溯吗？

完整解答

① 正则表达式：L(L ∪ D)*，其中 L = a∪b∪…∪z∪A∪…∪Z，D = 0∪1∪…∪9。首字符强制来自 L（字母开头），后续任意次重复 L 或 D。

② 为什么用 DFA：DFA 每读一个字符只做一次查表转移，单趟扫描、每字符 O(1)、全程无回溯，吞吐稳定——这是词法分析的性能底线。NFA 直接模拟要维护"当前活跃状态集合"，实现复杂且常数因子大。工程上的标准流水线恰好是本章定理链的应用：正则表达式 →（Thompson 构造）NFA →（子集构造）DFA →（状态最小化）更小的 DFA。lex/flex 等工具走的就是这条路。正则表达式的表达能力不够识别配对结构（如括号配平——那需要第3章的下推自动机），但对标识符、数字字面量这类词法单位刚刚好。

  • C. 存在至少一条计算分支读完 w 并停在接受态
  • D. 随机挑一条分支，它停在接受态
C 正确：接受是存在性语义。A 错：那是全称要求，会把几乎所有 NFA 设计废掉；B 错：NFA 没有概率概念，"多数"无从谈起；D 错：不是随机机制，不接受"碰运气"式定义——只要一条活路存在就接受，与分支死活比例无关。
自测 3
对一台含 ε 转移的 NFA 做子集构造，等价 DFA 的起始状态是？
  • A. { q₀ }，只含 NFA 的起始状态
  • B. Q，NFA 全部状态的集合
  • C. E({ q₀ })，即 q₀ 沿 ε 边可达的所有状态（含 q₀）
  • D. F，NFA 的接受状态集合
C 正确：开局不读任何符号时，NFA 已能沿 ε 边免费漂移，所以 DFA 起态是 ε 闭包。A 错：漏掉 ε 可达状态，整张转移表从第一行就错；B 错：瞎猜的最大集合，与可达性无关；D 错：接受集决定的是"哪些集合标接受"，不是起点。
自测 4
泵引理可以用来？
  • A. 证明某个语言是正则的
  • B. 证明某个语言不是正则的
  • C. 两者都可以，视用法而定
  • D. 构造与 NFA 等价的 DFA
B 正确：泵引理是"正则 ⇒ 可泵"的单向蕴含，只能用其逆否（破坏泵条件 ⇒ 非正则）做反证。A、C 错：满足泵条件的语言未必正则，正向使用是充分必要混淆；D 错：构造等价 DFA 是子集构造的任务，与泵引理无关。
自测 5
证明 { 0ⁿ1ⁿ } 非正则时，为什么选 s = 0ᵖ1ᵖ 而不是随便取一个长串？
  • A. 因为它是该语言里最短的串
  • B. 因为配合条件 |xy| ≤ p，可把 y 锁死在纯 0 段，泵一次必出矛盾
  • C. 因为它最容易在状态图上画出来
  • D. 因为泵引理要求 s 必须是回文串
B 正确：魔法串的全部意义在于与 p 挂钩，让 |xy| ≤ p 这条约束替我们锁死 y 的形态，把"分情况讨论"压缩成一击必杀。A 错：ε 更短但 |s| ≥ p 不满足；C 错：选串是逻辑需要不是画图需要；D 错：泵引理对 s 的形状没有这种要求，0ᵖ1ᵖ 也不是回文。

🗣️ 用自己的话，三句话讲完本章

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：给"没有记忆的计算"（只有有限个状态）画完整画像：它能识别哪些语言（正则语言），以及它的能力边界精确划在哪里。
句2：核心机制是什么？——
参考答案：DFA、NFA、正则表达式是同一类语言的三种视角，等价性由子集构造（NFA→DFA）和 Thompson 构造（RE→NFA）建立；边界由泵引理刻画——有限状态走长路必绕圈，循环段可泵，像 0ⁿ1ⁿ 这样需要无限计数配对的语言因此出局。
句3：它和前后章怎么分工？——
参考答案：第1章备好语言与证明工具；本章用它们给最弱的机器封顶，留下"无记忆机器够不着 0ⁿ1ⁿ"这个边界；第3章给机器加一条栈变成下推自动机，恰好突破这个边界。
