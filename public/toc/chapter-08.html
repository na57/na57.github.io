8.1空间怎么度量：只读输入带 + 读写工作带

第 7 章问"算多快"，本章问"占多少"。但一动手就碰到一个模型问题：输入本身就占 n 个格子，如果把它计入空间消耗，那任何算法的空间都至少是 n——"只用 log n 空间"这种话就永远说不出口，而恰恰是这类亚线性空间（8.4 节的 L 与 NL）最有意思。

解决办法是把"题目"和"草稿纸"分开。空间复杂性使用如下模型：图灵机有两条带——

  • 输入带（input tape）：只读，存放输入 w，不占空间额度；
  • 工作带（work tape）：可读可写，是算法的草稿纸，空间只计这条带上被扫过的格子数。

于是：SPACE(f(n))（deterministic space）= 能被确定性图灵机在 O(f(n)) 工作带格子内判定的语言全体；NSPACE(f(n))（nondeterministic space）= 同一界限的非确定版。输入"免费看"，但每看一眼都得靠工作带上的指针记住看到哪了——这个细节 8.4 节会反复用。

例 1（完整手算）：SAT ∈ SPACE(n)

SAT = {⟨φ⟩ | 布尔公式 φ 存在满足赋值}。第 7 章只知道它最坏指数时间。它的空间消耗是多少？算法一句话：按字典序枚举全部 2ⁿ 个赋值，逐个子句代入求值，碰到满足的立刻接受，全部试完则拒绝。工作带上从头到尾只放三样东西：

工作带内容占用格子作用
当前赋值 (x₁, …, xₙ)n 格兼作 n 位二进制计数器：每次 +1 得到下一个赋值
子句扫描指针O(log m) ⊆ O(n)记住正在检查第几个子句（m = 子句数 ≤ 输入长）
求值暂存O(1)代入当前字面量、算当前子句的真值，用完即弃
合计O(n)时间 2ⁿ·poly(n)，空间线性

关键动作发生在循环体内部：检查完一个赋值，同一批格子直接覆写给下一个赋值用——2ⁿ 次求值从头到尾只占 n + O(log n) 个格子。对照第 7 章：同一个问题，时间上我们只会指数枚举，空间上却只需线性。差别不在机器，在资源本身的性质。

💡 关键直觉：空间可复用，时间不可复用

时间像车票，用一张少一张；空间像白板，擦了能再写。一枚格子可以服务任意多次计算——所以"枚举指数多个候选"在空间上是免费的（逐个生成、逐个丢弃），在时间上却是真金白银。本章几乎所有结果（Savitch、TQBF、NL）都是这条直觉的形式化。

⚠️ 误区预警：枚举 2ⁿ 个赋值 ≠ 需要 2ⁿ 个格子

初学者的第一反应是"候选太多，存不下"。但枚举从来不需要同时存下所有候选——只需要存当前这一个加一点点簿记。把"有多少种可能"误当成"要多少存储"，是把时间账和空间账混为一谈，8.5 节还会清算它。

最后记一条模型事实，8.2 与 8.4 直接引用：一台用 f(n) 格工作带的机器，一个格局（configuration，瞬时描述）由"状态 + 输入头位置 + 工作头位置 + 工作带内容"四元组成，总数为 |Q|·n·f(n)·|Γ|f(n)。当 f(n) ≥ log n 时这就是 2O(f(n))——多项式空间的机器有指数多个格局，对数空间的机器只有多项式个格局。这个计数是后面两节共同的发动机。

8.2Savitch 定理：非确定性的空间代价只有平方

第 7 章留下一个尴尬的对比：非确定时间（NP）能不能免费确定化（变成 P），无人知晓——最好的确定性模拟要付指数代价。换成空间再问一遍：NSPACE(f) 的机器，确定机要花多少空间来模拟？Savitch 定理（Savitch's theorem，1970）给出的答案好得出乎意料：只要平方。

✅ Savitch 定理

对任何 f(n) ≥ log n：NSPACE(f(n)) ⊆ SPACE(f(n)²)。非确定空间可以只用平方代价确定化。

证明：把"可达性"对半砍

设 N 是一台 f(n) 空间的非确定机。8.1 末尾算过：它的格局只有 t₀ = 2O(f) 个。于是"N 接受 w"⟺ 在格局图（顶点是格局、边是一步转移）中，从起始格局 c_start 可达接受格局 c_accept；而且若可达，必有一条不超过 t₀ 步的路径（更长的路径必有重复格局，绕圈段可删）。问题化成：用尽量少的空间判定"c₁ 到 c₂ 是否存在至多 t 步的路径"。

✅ reach(c₁, c₂, t)：存在从 c₁ 到 c₂ 至多 t 步的路径吗？

① 基例 t = 1：检查 c₁ = c₂，或模拟一步看 c₁ 能否直接转移到 c₂，O(f) 空间。
② 递归 t > 1：路径若存在，其中点 c_m 必存在。逐个枚举所有格局 c_m（复用同一 O(f) 格区），对每个候选先后递归 reach(c₁, c_m, ⌈t/2⌉) 与 reach(c_m, c₂, ⌈t/2⌉)；两段都为真则返回真。所有候选都失败则返回假。

正确性两个方向都不许跳：⇒ 真路径上走 ⌈t/2⌉ 步所到的那个格局，就是能通过检查的中点 c_m；⇐ 两段不超过 t/2 的半路径首尾相接，就是一条不超过 t 步的整路径。∎（这是"中点存在性"的纯逻辑，与机器细节无关。）

图 8.1 Savitch 的递归二分。两次递归调用先后进行，第二次把第一次用过的格子擦了再用——任意时刻的空间是"深度 × 每层"，不是"全部节点之和"，这就是平方而非指数的来源。

空间账（不许跳步）：

  • 每层栈帧存什么：当前枚举到的中点 c_m（一个格局，O(f) 格）+ 枚举进度簿记（O(f)）。每层共 O(f)。
  • 递归多深：每层把 t 减半，深度 = O(log t)。代入 t = t₀ = 2O(f)，得深度 O(f)。
  • 兄弟调用复用：reach(c₁, c_m, ·) 返回后，它占的格子全部释放给 reach(c_m, c₂, ·) 用——任何时刻栈上只有 O(f) 层活着。
  • 合计：深度 × 每层 = O(f) × O(f) = O(f²)。∎

时间账（必须泼的冷水）：设 T(t) 为 reach 的耗时。枚举 c_m 有 2O(f) 个候选，每个触发两次规模减半的递归：T(t) ≈ 2O(f) · 2 · T(t/2)。展开 log t = O(f) 层后 T(t₀) = 2O(f²)——指数时间。Savitch 定理从头到尾只承诺空间，时间被打回原形：这是"省空间费时间"的标准标本。

两条立刻能用的推论

推论推导链对照时间维度
NL ⊆ SPACE(log²n)取 f(n) = log n：NSPACE(log n) ⊆ SPACE((log n)²)，非确定对数空间可用 log²n 确定化时间类比"NP ⊆ ?"：只有指数上界，是否多项式未知
PSPACE = NPSPACE取 f 为任意多项式 p：NSPACE(p) ⊆ SPACE(p²)，而 p² 仍是多项式；反向包含显然P ?= NP 是世纪悬案；空间世界里非确定几乎免费
💡 为什么时间不能照抄这个证明

reach 省空间的机关是"兄弟调用复用同一批格子"。时间没有这个性质：两次递归调用必须先后真实发生，耗时是加和而不是取最大值。空间可以"轮流坐庄"，时间只能"排队买单"——这个不对称是本章与第 7 章全部分歧的根。

8.3PSPACE 与 TQBF：空间世界的"Cook–Levin"

8.1–8.2 在单条空间界限上做文章；现在仿照 P 的定义，把所有多项式空间合成一个类：PSPACE = ⋃k SPACE(nᵏ)，即确定性多项式空间可判定的语言全体。由 Savitch 定理，PSPACE = NPSPACE，所以不必区分确定与非确定版本——这是它与 P 的第一个不同。

它卡在哪个位置：一条四环包含链

包含关系论证（每环一句话，不许跳步）
P ⊆ NP第 7 章：判定算法本身就是无视证书的验证者
P ⊆ PSPACE多项式时间内工作头最多走多项式格——时间花在哪，空间就用到哪
NP ⊆ PSPACESAT ∈ SPACE(n)（例 1）；任意 A ∈ NP 有 A ≤ₚ SAT（Cook–Levin），多项式时间归约的输出只有多项式长，所用空间也就多项式——归约 + 线性空间算法复合仍是多项式空间
PSPACE ⊆ EXPTIMEnᵏ 空间的机器只有 2O(nᵏ) 个格局；跑超过这个步数必有格局重复即死循环，超时拒绝——指数时间足够判定

注意第三环的杠杆结构：用一个完全问题 + 归约封闭性，把整个类抬进去——和第 7 章"SAT 进 P 则全 NP 进 P"是同一件工具，方向相反。至于这些包含是否严格：P ≠ PSPACE、PSPACE ≠ EXPTIME 都未证（第 9 章只能用对角线给出 P ≠ EXPTIME 这种"跨档"分离）。

PSPACE 完全问题：TQBF

照搬 NP 完全的配方：PSPACE 完全（PSPACE-complete）：B 满足 ① B ∈ PSPACE；② 每个 A ∈ PSPACE 都 A ≤ₚ B。它们是 PSPACE 中最难的一批：任何一个若有多项式时间算法，整个 PSPACE（连带全部 NP）都塌进 P。

候选问题是 SAT 的"量词加强版"。TQBF（True Quantified Boolean Formula，真量词布尔公式，也叫 QBF）：判定一个所有变量都被量词束缚的公式是否为真，例如 ∀x ∃y [(x ∨ y) ∧ (¬x ∨ ¬y)]。∃ 读"存在一步"，∀ 读"对任意应手"——公式像在下一盘棋：∃ 方走一步，∀ 方应一步，轮流赋值后看残局真假。

定理 1：TQBF ∈ PSPACE（完整算法 + 空间账）

✅ 递归求值算法 eval(φ)

① φ 无量词：直接代入求真值，O(1) 工作格。
② φ = ∃x ψ：剥去量词，先后递归 eval(ψ 代 x=T) 与 eval(ψ 代 x=F)，第二次复用第一次的空间；一支为真即真。
③ φ = ∀x ψ：同样两支递归，都真才真。

空间账：递归深度 = 量词数 ≤ 变量数 ≤ n；每层只需记下"当前处理哪个变量、代了什么值"，O(log n) 格。总计 O(n log n)，当然是多项式。∎ 时间账照旧难看：分支因子 2、深度 n，叶节点 2ⁿ 个——又一次"指数时间、多项式空间"，与例 1 同族。

手算：同一副身体，两种量词顺序

取 ψ(x, y) = (x ∨ y) ∧ (¬x ∨ ¬y)。先看清它的语义：两个子句分别排除"x、y 同假"与"x、y 同真"，所以 ψ 为真 ⟺ x 与 y 恰好一真一假（异或）。

∀x ∃y ψ：x = T 时 ψ 化简为 (T ∨ y) ∧ (F ∨ ¬y) = ¬y，内层 ∃y 取 y = F，得真 ✓；x = F 时 ψ 化简为 y ∧ T = y，内层 ∃y 取 y = T，得真 ✓。∀ 节点两支全真 → 公式为真。

∃x ∀y ψ（量词换序）：x = T 时 ψ = ¬y，∀y 要求 y = T 处也真，但 ¬T = F，支为假；x = F 时 ψ = y，∀y 在 y = F 处失败，支为假。∃ 节点两支全假 → 公式为假。量词换序，答案翻转——这正是"博弈先后手"的直觉：先走方承诺一个 x 后，对方握着 y 的反手。

定理 2：TQBF 是 PSPACE 难的（归约骨架）

对任意 A ∈ PSPACE（由 nᵏ 空间机器 M 判定）与输入 w，要把"M 接受 w"编译成一个量词公式 φM,w，且长度必须多项式。

困难：M 可以跑 2O(nᵏ) 步。照搬 Cook–Levin 铺一张"步数 × 空间"的 tableau 公式，行数指数——公式超长，归约失败。

出路（与 Savitch 同构）：不铺整张表，改用中点递归表达可达性。把"c₁ 在 ≤ t 步内可达 c₂"写成公式：

∃cm ∀(c, d) ∈ {(c₁, cm), (cm, c₂)} ： c 在 ≤ ⌈t/2⌉ 步内可达 d

∃ 量词猜中点，∀ 量词"并查"两段半程——注意两个子目标共享同一段后续公式，这正是 Savitch 里"两次递归复用同一空间"的公式版：公式长度每层只加一个量词前缀，不翻倍。递归 log(2O(nᵏ)) = O(nᵏ) 层，每层添多项式长；基例 t = 1（一步可达）用 Cook–Levin 的局部窗口公式，也是多项式长。总长度多项式，构造过程本身多项式时间可输出。等价性：φM,w 为真 ⟺ c_start 可达 c_accept ⟺ M 接受 w ⟺ w ∈ A。∎（骨架完）

💡 一句话记住 TQBF

SAT 问"存在一步好棋吗"，TQBF 问"这盘棋 ∃ 方有必胜策略吗"——∀ 与 ∃ 交替 = 两位玩家轮流落子。所以广义象棋、围棋、五子棋的"必胜判定"清一色是 PSPACE 完全问题：博弈的天花板比"找解"的天花板（NP 完全）整整高一层。

8.4L 与 NL：几张便签纸能算什么

PSPACE 太粗，log n 是另一头最有内容的刻度。定义 L（Logspace）= SPACE(log n)，NL（Nondeterministic Logspace）= NSPACE(log n)。

为什么 log n 是"有意义的下限"：输入带只读免费，工作带的 log n 位恰好够存 O(1) 个指向输入的指针（一个位置编号 log n 位）加几个计数器。它正是"大数据流式处理"的数学化身：输入可以反复读但不能改，手边只有几张便签纸。Savitch 定理要求 f ≥ log n，就是为这个尺度量身定做的。

例 2（完整论证）：PATH ∈ NL

PATH = {⟨G, s, t⟩ | 有向图 G 中 s 可达 t}。第 7 章证过 PATH ∈ P（标记法，O(n·m) 时间）——但标记法要给所有顶点打标记，空间 Ω(n)。换成非确定对数空间：

✅ NL 算法：边走边猜

从 s 出发，重复至多 n 次：非确定地猜当前顶点的一条出边，走到邻居；走到 t 即接受，步数用尽则拒绝。工作带只存两样东西：当前顶点编号（log n 位）+ 步数计数器（数到 n 为止，log n 位）。合计 O(log n)。✓

对照标记法：确定性算法要"记住所有去过的地方"（Ω(n)），非确定算法只记"我在哪、走了几步"（O(log n)）——把"记住历史"换成了"猜对未来"。正确性：存在 s 到 t 的路径 ⟺ 某支猜测序列恰好沿它走通 ⟺ 机器接受。✓

PATH 是 NL 完全（归约思路）

空间版的归约要降级：对数空间归约（log-space reduction，记 ≤L）要求翻译函数本身只用 O(log n) 工作空间——输出可以很长，逐位写出、格子复用即可。否则归约机比被归约的问题还强，"难度传递"就失效了。

定理：PATH 在 ≤L 下是 NL 完全的。PATH ∈ NL 已证。取任意 A ∈ NL，设非确定机 N 用 c·log n 格判定 A。固定 w：N 的格局数 = 状态 × 输入头位置 × 工作头位置 × 工作带内容 = O(1)·n·O(log n)·2O(log n) = nO(1)——只有多项式个（这是对数空间机器的命门）。构造图 Gw：顶点 = 全体格局；边 = 一步转移；起点 = c_start；终点 = c_accept（不妨设 N 接受前清空工作带、读写头归位，使接受格局唯一）。于是 w ∈ A ⟺ c_start 可达 c_accept ⟺ ⟨Gw, c_start, c_accept⟩ ∈ PATH。输出方式：双重循环枚举格局对，逐对模拟一步验证、逐条边写出——任何时刻工作带只存两个格局各 O(log n) 位，归约确为 log 空间。✓ ∎（骨架完）

推论网：NL ⊆ P（A ≤L PATH 且 PATH ∈ P）；L ⊆ NL（确定是特殊的非确定）；NL ⊆ SPACE(log²n)（Savitch）。Immerman–Szelepcsényi 定理（1987/88 独立获证）还给出 NL = coNL——"不可达性"也能在 NL 中判定，技巧是归纳计数可达顶点数。对比时间维度 NP ?= coNP 至今未知，空间世界再次更"温顺"。

⚠️ L ?= NL：空间版的 P vs NP

PATH 是 NL 完全 ⇒ L = NL 当且仅当 PATH ∈ L，即"确定的、只用几张便签纸的可达性算法"。几十年无人找到（确定性最好成绩是 Savitch 的 log²n；另有随机化的 RL 结果），也没人证明不可能。它与 P ?= NP 同构，同样坚硬。

8.5错误直觉清算：空间不是时间

⚠️ 误区一："空间和时间一样稀缺、一样贵"

两个反例钉死它。① 同一个 SAT：时间上只会 2ⁿ 枚举，空间上例 1 只用 n 格——枚举在时间上付费、在空间上免费。② 非确定性消除：时间维度 NP ⊆ P 是世纪悬案，最好上界指数；空间维度 Savitch 只收平方税，PSPACE = NPSPACE 直接相等。根源一句话：空间可复用，时间不可复用。

⚠️ 误区二："PSPACE 完全问题 = 无解 / 不可判定"

TQBF 是可判定的（递归求值）、多项式空间可解的、有已知指数时间算法的。"PSPACE 完全"说的是它站在 PSPACE 难度的天花板：若它 ∈ P 则 P = PSPACE（连带 P = NP）。这与"不可判定"（第 4–6 章：算法根本不存在）隔着一整个可判定性理论；"比 NP 完全更难"也只是分级相对，不是无解宣判。

⚠️ 误区三："NL 显然等于 P（或 L 显然等于 NL）"

PATH 既是 NL 完全又 ∈ P，容易让人以为两个类"P 化"了。但 NL ⊆ P 只说明非确定对数空间不超出多项式时间；反过来 PATH ∈ L（确定的 log 空间可达性）无人证得——L ?= NL 是公开问题。本章已知的等式（NL = coNL、PSPACE = NPSPACE）恰恰提醒：空间世界的每一个相等都是定理，不是显然。

📝分层习题

L1 概念辨析判断对错："要枚举 2ⁿ 个赋值，就必须有能存 2ⁿ 个赋值的内存，所以 SAT 需要指数空间。"说明理由。
提示

枚举需要"同时"存下所有候选吗？回想 8.1 工作带账目表。

完整解答
错。枚举逐个生成、逐个验证、逐个丢弃：工作带只存当前赋值（n 格，兼作计数器）+ 子句指针 O(log m) + 求值暂存 O(1)，合计 O(n)。原命题把"候选数量"（时间维度）误当"存储需求"（空间维度）——空间可复用，同一批格子服务全部 2ⁿ 次求值。正确结论：SAT ∈ SPACE(n)，指数的是时间不是空间。
L1 概念辨析判断对错："由 Savitch 定理 NSPACE(n²) ⊆ SPACE(n⁴)，可见非确定空间类严格大于确定空间类。"
提示

定理给出的是包含（上界）还是分离（下界）？⊆ 能读出"严格大于"吗？

完整解答
前半对、后半错。代入 f = n² 确有 NSPACE(n²) ⊆ SPACE(n⁴)；但这是上界包含：非确定机器能算的，确定机器平方空间内也能算——恰恰说明非确定空间不更难模拟。在多项式尺度上结论更强：PSPACE = NPSPACE，两类相等。原命题把"⊆"误读为反向的严格分离，方向完全反了。
L2 手算推导对 ψ(x, y) = (x ∨ y) ∧ (¬x ∨ ¬y)，完整执行 TQBF 递归求值：(a) φ₁ = ∃x ∀y ψ；(b) φ₂ = ∀x ∃y ψ。写出每个节点的化简式与真值，给出两个结论并解释差异。
提示

先代外层量词的值，把公式化简成只含 y 的式子，再处理内层量词；注意 ∃ 与 ∀ 节点的"通过条件"不同。

完整解答

(a) φ₁ = ∃x ∀y ψ：x = T 时 ψ = (T∨y) ∧ (F∨¬y) = ¬y；∀y 要求 y = T 处也真，但 ¬T = F → 此支假。x = F 时 ψ = (F∨y) ∧ (T∨¬y) = y；∀y 在 y = F 处得 F → 此支假。∃ 节点两支皆假 → φ₁ 为假。

(b) φ₂ = ∀x ∃y ψ：x = T 时 ψ = ¬y；∃y 取 y = F，¬F = T → 此支真。x = F 时 ψ = y；∃y 取 y = T → 此支真。∀ 节点两支皆真 → φ₂ 为真。

差异根源：∃x∀y 要求"存在一个 x 通吃所有 y"，∀x∃y 允许"y 随 x 换"（后手优势）。空间账验证：深度 2 层、每层存一个变量与值，O(1) 级；时间 4 个叶节点——与定理 1 的 O(n log n) 空间、2ⁿ 时间账同型。

L2 手算推导设非确定机 N 判定语言 A 用 f(n) = 3·log₂n 格工作带（n ≥ 16），其格局总数上界为 2^(6 log₂ n) = n⁶。对初始调用 reach(c_start, c_accept, t) 回答：(1) t 取多少？(2) 递归深度？(3) 每层栈帧存什么、占多少？(4) 总空间？(5) 最终结论与时间代价。
提示

深度 = log₂ t；每层存一个格局；格局含工作带内容、两个头位置、状态。

完整解答

(1) 可达路径若存在，必有一条不超过格局总数的路径（更长必有重复格局可删），故 t = n⁶。

(2) 每层 t 减半：深度 = log₂(n⁶) = 6·log₂n = O(log n)。

(3) 每层存当前中点格局 c_m：工作带内容 3·log₂n 位 + 输入头位置 log₂n 位 + 工作头位置 O(log log n) + 状态 O(1)，合计 O(log n)；外加枚举进度 O(log n)。每层 O(log n)。

(4) 总空间 = 深度 × 每层 = O(log n) × O(log n) = O(log²n)（常数 6 × 3 等被吸收）。

(5) 结论：A ∈ SPACE(log²n)，即 NSPACE(3 log n) ⊆ SPACE(9 log²n)。时间代价 T ≈ 2^O(log²n)（准多项式，大于任何多项式）——Savitch 只保空间。

L3 建模应用某公司两个项目：① 仓库机器人："在 10⁶ 格的仓库地图里，从货架 A 能否走到出口？"——地图存在只读光盘上，算法只允许 O(log n) 级额外内存的流式读取；② 双人棋类残局分析："甲方是否有必胜策略？"分别判断两个功能背后的判定问题属于哪个类、依据是什么，并说明工程上敢承诺什么。
提示

一个是没有对手的可达性；一个是 ∃/∀ 交替的博弈。注意①的内存硬约束对应哪个类，②的"轮流走棋"对应哪个公式结构。

完整解答

① 本质是 PATH。非确定对数空间算法 ∈ NL（边走边猜，只存当前格子编号 + 步数）；但"确定性 + O(log n) 内存"正是 PATH ∈ L 吗——公开问题！已知可承诺：Savitch 风格 log²n 空间的确定性算法（时间准多项式），或退到多项式内存的标记法（O(n) 空间、O(n·m) 时间）。工程结论：敢承诺多项式时间，不敢承诺严格对数内存的确定性算法。

② 本质是 TQBF 型博弈："∃ 我方走法 ∀ 对方应手 ∃ … 终局胜"，量词交替深度 = 对局长度——PSPACE 完全。工程结论：只能承诺多项式空间（递归搜索复用栈）与指数时间；精确最优不现实，应转向限时 α-β 搜索、启发式评估——与第 7 章 NP 完全的"换赛道"逻辑相同。

同一张"状态图"，① 只是单人可达（NL/P 层），② 多了一个 ∀ 对手（PSPACE 层）——难度跃迁的全部原因。

  • B. f(n) ≥ log n 时 NSPACE(f(n)) ⊆ SPACE(f(n)²)，且模拟的时间代价可达指数级
  • C. NSPACE(f) ⊆ TIME(f²)，非确定空间可用平方时间模拟
  • D. SPACE(f) ⊆ NSPACE(f)，且已知两个类严格分离
选 B。A 错：代价是平方不是无损；C 错：这是空间类之间的包含，且确定性模拟的时间是 2^O(f²) 级而非 f²；D 前半是平凡包含（确定是特殊的非确定），后半错——无人证明分离，多项式尺度上反而相等（PSPACE = NPSPACE）。
自测 3
包含链中 NP ⊆ PSPACE 的标准论证是：
  • A. 枚举 NP 证书需要指数空间，而 PSPACE 有指数空间
  • B. SAT ∈ SPACE(n)，且任意 A ∈ NP 都有 A ≤ₚ SAT，多项式归约本身只耗多项式空间
  • C. PSPACE 的定义就是"NP 的空间版"，两者按定义包含
  • D. NP 完全问题不在 PSPACE 中
选 B。A 错且自相矛盾：枚举证书逐一生成、复用空间，只要多项式空间；C 错：PSPACE 是多项式空间可判定类，NP 是证书可验证类，定义不同，包含关系必须证明；D 错：NP 完全问题 ∈ NP ⊆ PSPACE。
自测 4
TQBF ∈ PSPACE 的递归求值算法，其资源账目是：
  • A. 每层递归保存整棵子树的真值表，共需指数空间
  • B. 深度 = 量词数，每层只存当前变量与所代值，总空间多项式；总时间 2ⁿ 级
  • C. 需要同时存储全部 2ⁿ 个赋值才能比较
  • D. 只需常数空间，因此 TQBF ∈ L
选 B。A 错：子树算完即弃，任何时刻只存根到当前叶的路径；C 是"枚举要全存"的误区再现，兄弟分支复用同一空间；D 错：深度可达 n 层、每层要记变量编号与值（Ω(log n)），远超常数，且 TQBF 是 PSPACE 完全，若 ∈ L 则 PSPACE = L。
自测 5
PATH ∈ NL 的非确定算法，其工作带上存放的是：
  • A. 从 s 到当前顶点的整条猜测路径
  • B. 当前顶点编号 + 步数计数器，各 O(log n) 位
  • C. 所有已访问顶点的集合，防止走回头路
  • D. 图的完整邻接矩阵副本
选 B。A 错：存整条路径要 Ω(n log n) 位，超支——算法只记"我在哪"，把"记住历史"换成"猜对未来"；C 错：已访问集合 Ω(n) 位，那是确定标记法的开销；D 错：邻接矩阵 n² 位，且输入带上的图只读免费，无需复制。

🗣️ 用自己的话，三句话讲完本章

对着空气（或室友）说出这三句。说卡壳的那句，回去重读对应小节。

句1：这章解决什么问题？——
参考答案：可判定的问题需要多少内存，空间是否像时间一样稀缺。用"只读输入带 + 工作带"模型定义 SPACE 与 NSPACE，第一个发现就是空间可复用：SAT 最坏指数时间，却只要线性空间。
句2：核心机制是什么？——
参考答案：Savitch 的 reach 过程把格局可达性对半砍——猜中点、两段递归、兄弟调用复用同一空间，深度 × 每层 = O(f²)，于是 NSPACE(f) ⊆ SPACE(f²)，PSPACE = NPSPACE。PSPACE 的代表是完全问题 TQBF（∀/∃ 交替的博弈公式，递归求值只花多项式空间）；对数尺度上 L/NL 由 PATH 代表，发动机是"log 空间机器的格局只有多项式个"。
句3：它和前后章怎么分工？——
参考答案：第 7 章量时间（P、NP、NP 完全），本章量空间（L、NL、PSPACE、TQBF）；空间世界里非确定几乎免费（平方税），留下 L ?= NL、P ?= PSPACE 两个悬案。第 9 章用对角线证明资源层级严格分离（更多时间/空间确实能算更多），第 10 章讲算不动时的出路（近似、随机化、交互证明）。
