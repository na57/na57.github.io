动机

参数太多存不下、全独立又太假，出路在工具上

100 个二元变量的联合分布，完整写出需要多少参数？

$$2^{100} - 1 \approx 1.3 \times 10^{30} \text{ 个参数 —— 存不下，也估不准}$$
😇 方案一：直接记联合分布
信息最全，但参数量指数爆炸，工程上不可行
🙂 方案二：假设所有变量独立
参数大省，但变量明明互相影响，假设假得没法用
💡 本章方案：备好换算工具与独立性语言——第3章用「图」在两个极端之间找平衡
定义

联合、边缘、条件：同一张分布表的三种看法

🗺️ 联合概率
$P(X, Y)$：几件事同时发生的概率，信息最全
🔭 边缘概率
$P(X) = \sum_y P(X, y)$：把不关心的变量加掉
✂️ 条件概率
$P(X \mid Y) = \dfrac{P(X, Y)}{P(Y)}$：已知一事后重新看另一事
读法：联合是全集，边缘是投影，条件是切片——后面所有换算都在这三种看法之间进行。
工具①

链式法则把任何联合分布拆成一串条件概率

$$P(X_1, \dots, X_n) = P(X_1)\, P(X_2 \mid X_1) \cdots P(X_n \mid X_1, \dots, X_{n-1})$$
✅ 永远成立
对任何分布都成立，没有用到任何独立性假设
⚠️ 没有简化
每个变量以「排在它之前的所有变量」为条件，一个都没省
链式法则（Chain Rule）：第3章的因子分解公式和它长得很像——但那是砍过条件的紧凑版。
手算

链式法则永远成立，但一个参数都省不了

① 四个二元变量 $A, B, C, D$，按链式法则展开

$$P(A,B,C,D) = P(A)\,P(B \mid A)\,P(C \mid A,B)\,P(D \mid A,B,C)$$

② 逐项数参数：每项的条件组合数翻倍

$$1 + 2 + 4 + 8 = 15$$
$$\boldsymbol{1+2+4+8 = 2^4 - 1 = 15} \quad \text{——和完整联合分布一样，一个没省}$$

工具②

贝叶斯规则只干一件事：把条件方向反转过来

$$P(X \mid Y) = \frac{P(Y \mid X)\, P(X)}{P(Y)}$$
$$\text{分母用全概率公式展开：} \quad P(Y) = \sum_x P(Y \mid x)\, P(x)$$
读法：反方向 = 正方向 × 先验 ÷ 证据。贝叶斯规则（Bayes' Rule）从不让你绕开先验 $P(X)$——这正是下一页的主角。
演练

阳性 ≠ 得病：基础率谬误（Base Rate Fallacy）亲手算一遍

① 设定：患病率 $P(D)=1\%$，灵敏度 $P(+ \mid D)=90\%$，假阳率 $P(+ \mid \neg D)=10\%$。列贝叶斯规则

$$P(D \mid +) = \frac{P(+ \mid D)\, P(D)}{P(+ \mid D)\, P(D) + P(+ \mid \neg D)\, P(\neg D)}$$

② 代入数字

$$= \frac{0.9 \times 0.01}{0.9 \times 0.01 + 0.1 \times 0.99} = \frac{0.009}{0.108}$$
$$\boldsymbol{P(D \mid +) \approx 8.3\%} \quad \text{——一万人：90 真阳性，混在 990 假阳性里}$$
✍️

定义

独立有两种：带不带条件，是两回事

🔓 边际独立（Marginal Independence）
天生互不相关，式中没有任何条件
$$P(X, Y) = P(X)\, P(Y)$$
🔒 条件独立（Conditional Independence）
给定 $Z$ 之后才互不相关，每项都挂在同一条件后
$$P(X, Y \mid Z) = P(X \mid Z)\, P(Y \mid Z) \;\; \text{记作 } (X \perp Y \mid Z)$$
判断之前先看式子里有没有「条件那一竖」——两种独立谁也推不出谁。
性质

条件独立是全书的语法：三个事实加一条对称性

1边际独立 推不出 条件独立：本来无关，给定共同结果后可能纠缠
2条件独立 推不出 边际独立：给定原因后无关，不看原因时明明相关
3条件独立是常态：现实相关大多有共同原因，给定原因相关即消失
$$\text{对称性：} \quad (X \perp Y \mid Z) \iff (Y \perp X \mid Z) \quad \text{——定义式两边位置对称，直接读出}$$
例子

给定共同原因之后，相关就消失了

「闹钟响」与「邻居出门」早上常同时发生——边际相关。

但给定「现在 7 点」之后，两者互不干扰——条件独立。

$$(\text{闹钟} \perp \text{邻居} \mid \text{时间}) \quad \text{成立，但边际不独立}$$
相关全部来自共同原因：这正是事实②「条件独立推不出边际独立」。
flowchart TD T["早上 7 点"] --> A["闹钟响"] T --> B["邻居出门"]

共同原因结构：一个原因指向两个结果，结果之间没有直接的边

直觉

链式法则砍掉多余条件，就是因子化的雏形

疾病 $D$ 引起症状 $S_1$、$S_2$，化验指标 $T$ 也只由 $D$ 决定。

$$\boldsymbol{P(D, S_1, S_2, T) = P(D)\, P(S_1 \mid D)\, P(S_2 \mid D)\, P(T \mid D)}$$
条件独立把 $P(S_2 \mid D, S_1)$、$P(T \mid D, S_1, S_2)$ 里多余的条件砍掉——大分布拆成小因子相乘。
flowchart TD D["疾病 D"] --> S1["症状一"] D --> S2["症状二"] D --> T["化验指标"]

每个变量只以父节点为条件——第3章因子分解就长这样

图论

图论只备四个词：节点、边、路径、有向无环图

概念一句话定义这门课里它是什么
节点 node图里的一个圈一个随机变量
边 edge节点间的连线，带箭头即有向边变量间的直接关系（箭头：原因 → 结果）
路径 path顺着边能走通的一串节点第3章判断「会不会互相影响」就看路径通不通
有向无环图 DAG边全有向、且不存在有向环的图贝叶斯网络的结构要求
DAG = Directed Acyclic Graph。为什么必须「无环」？这不是审美，是硬性要求——下一页。
机制

有环的图定义不了概率：定义会自己咬自己

flowchart LR A --> B --> C
✅ 无环：合法
能排出顺序：先定义 A，再 B，再 C
flowchart LR A --> B --> C --> A
❌ 有向环：非法
循环定义，谁都启动不了
无环保证存在一个拓扑序，让每个变量在原因定义好之后轮到自己——因子分解因此自洽。
避坑

两个最容易踩的坑，本章结束前就排掉

❌ 看到乘积分解就说是「独立」，把条件独立当成无条件独立
✅ 条件独立必须带条件：$P(X,Y \mid Z) = P(X \mid Z)\,P(Y \mid Z)$；它与边际独立 $P(X,Y)=P(X)P(Y)$ 谁也推不出谁。先看有没有「那一竖」。
❌ 检查阳性就等于得病（90% 灵敏度就直接信）
✅ 阳性里混着假阳性：$P(D \mid +) = \frac{0.009}{0.108} \approx 8.3\%$。反推原因，先验（基础率）必须到场。
接口

链式法则加条件独立，就是下一章的因子分解

链式法则（本章）因子分解（第3章）
每个变量以谁为条件之前的所有变量只有父节点
用了什么假设无——永远成立图声明的条件独立
4 个二元变量的参数15 个（一个没省）大幅压缩
钩子：第3章的全部工作，就是让链式法则变得紧凑——把「之前的所有变量」砍成「父节点」。
小结

三句话讲完第2章

1解决什么：为全书补齐数学语言——三种概率、两个换算工具、条件独立、四个图论词
2核心机制：链式法则无条件展开；贝叶斯规则反转条件方向、强迫先验参与；条件独立是全书语法
3承上启下：第1章说为什么做，本章给工具，第3章立刻全部用上
$$P(X_1,\dots,X_n)=\prod_i P(X_i \mid X_1,\dots,X_{i-1}) \qquad P(X \mid Y)=\frac{P(Y \mid X)\,P(X)}{\sum_x P(Y \mid x)\,P(x)} \;\;\text{——合上书也要能默写}$$
