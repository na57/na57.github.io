本章解决「多查询复用」——把消元的中间因子存进一棵树，随取随用

主线

给变量消去加缓存：把重复的运算存起来复用

1多查询下变量消去结构性重复：绕开查询变量的求和每次都重算
2出路：缓存中间因子 —— 但得事先知道它们长在哪些变量组上
3先弦化：消元半路加边就无法规划货架，弦图让中间因子形状事先定死
4最大团按分隔集连成满足运行交性质的树，中间因子 = 边上的消息
5收集＋分发两遍消息 → 全树校准 → 任意查询只做局部求和
这条链就是本章的目录：重复劳动 → 弦化 → 建树 → 消息传播 → 校准读答案 → 代价（树宽）
动机

同一网络查两次，大半个流程是第一次的回放

flowchart LR A["A"] --- B["B"] B --- C["C"] C --- D["D"] D --- A style A fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px style C fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px

四元环 A—B—C—D—A；每条边势函数：一致 5 / 不一致 1

🔁 查询 P(A)：顺序 D, C, B
消 D：$\varphi_3 \times \varphi_4 \to \psi(C,D,A)$，再 $\sum_D$ 得 $\tau_1(C,A)$
🔁 查询 P(C)：顺序 D, A, B
消 D：还是 $\varphi_3 \times \varphi_4$ —— 这张 8 行的表刚算过，原样重算
⚠️ 凡是不经过查询变量方向的求和，两次查询完全相同——重复不是巧合，是算法没有记忆
概念

环上的团不成树、消息传不下去——所以必须先弦化

flowchart LR A["A"] --- B["B"] B --- C["C"] C --- D["D"] D --- A A -.- C linkStyle 4 stroke:#b03a2e,stroke-width:2.5px;

消 D 时其邻居 C、A 必须相连 → 红色虚线 A—C 是填充边（fill-in edge）

✅ 弦图的决定性性质：存在完美消元序，消每个节点时邻居已是团——全部中间因子的作用域，建树前就能从最大团里读出来
演练

手算弦化：按 D, C, B, A 消元，只加一条填充边

① 消 D：邻居 {C, A} 不相连 ⟹ 加填充边 A—C；中间因子 $\psi(C,D,A)$

② 消 C：此时邻居 {B, A} 已有边（A—C 已加入）⟹ 作用域 {A,B,C} 已是团，不加边

③ 消 B、A：作用域 {A,B}、{A} 均为已有团 ⟹ 弦化完成，全图再无无弦环

构造

团树 = 最大团当节点，分隔集当传送带

flowchart LR C1["团 C1：{A,B,C}
ψ1 = φ(A,B) × φ(B,C)"] -- "分隔集 {A,C}" --- C2["团 C2：{A,C,D}
ψ2 = φ(C,D) × φ(D,A)"] style C1 fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px style C2 fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px
① 找最大团：两两全连且不能再扩大——只有 {A,B,C} 与 {A,C,D}
② 按分隔集连边：$S_{ij} = C_i \cap C_j = \{A,C\}$；多团时取分隔集总权重最大的生成树
③ 验证运行交性质：合法性底线，下一页讲透
💡 团树不是新图——是同一套消元计算的存档格式：团是工作站，分隔集是传送带，消息就是消元里的中间因子
重点

运行交性质：每个变量在树上必须占据一片连通区域

$$\text{若 } X \in C_i \text{ 且 } X \in C_j \;\Rightarrow\; X \text{ 出现在 } C_i \text{ 到 } C_j \text{ 唯一路径上的每一个团里}$$
flowchart LR K1["{A,B}"] --- K2["{C,D}"] K2 --- K3["{A,D}"] style K2 fill:#fae9e7,stroke:#b03a2e,stroke-width:2.5px

❌ 反例：A 在首尾两团，中间的团不含 A → A 的信息在途中断裂

⚠️ 少了运行交性质，尾部团拿到的「全局信息」漏掉了首部关于 A 的部分——校准等式直接失效
最大生成树只是顺手满足它的构造法；性质本身才是正确性的来源
定义

消息 = 消元的中间因子，只不过结果被记在边上

$$\delta_{i\to j}(S_{ij}) = \sum_{C_i \setminus S_{ij}} \psi_i(C_i) \cdot \prod_{k \in N(i)\setminus j} \delta_{k\to i}(S_{ki})$$

自己势能 × 除 j 外所有邻居的消息，再消去「只属于自己」的变量 → i 这一侧对分隔集的全部意见

$$\boldsymbol{\beta_i(C_i) = \psi_i(C_i) \cdot \prod_{k \in N(i)} \delta_{k\to i}(S_{ki}) = \tilde{P}(C_i)} \quad\text{（未归一化边缘）}$$
两遍传遍：收集（叶→根，逐级汇报）＋ 分发（根→叶，逐级传达）→ 校准：每边两侧团在分隔集上边缘一致

手算

收集消息 δ₂→₁：四个格子算出 26 / 10 / 10 / 26

① δ₂→₁(0,0) = ψ₂(0,0,0)+ψ₂(0,0,1) = 25+1 = 26

验证

校准等式：两侧同为 676 才算对——660 是查错格子的信号

① 左侧：对 β₁ 里的 B 求和（消息按下标 (A,C)=(0,0) 查，δ₂→₁ = 26）

$$\sum_B \beta_1(0,B,0) = 25\times 26 + 1\times 26 = 650 + 26 = \boldsymbol{676}$$

② 右侧：对 β₂ 里的 D 求和，两侧相等 ⟹ 校准通过 ✓

$$\sum_D \beta_2(0,0,D) = 25\times 26 + 1\times 26 = \boldsymbol{676} \;\checkmark$$
⚠️ 算出 660？说明读 C₁ 中 B=1 那行时按 (A,B)=(0,1) 查了消息格 10——消息下标是分隔集 (A,C)，应为 26。660 就是错的，676 直接覆盖它

读答案

一次校准后，P(A) 与 P(C) 都只是「换个方向求和」

$$\tilde{P}(a^0) = \sum_{B,C} \beta_1(0,B,C) = 650+50+26+50 = 776 \;\Rightarrow\; P(a^0) = \frac{776}{1552} = \boldsymbol{0.5}$$
$$\tilde{P}(c^0) = \sum_{A,B} \beta_1(A,B,0) = 776 \;\Rightarrow\; P(c^0) = \boldsymbol{0.5} \quad\text{（零次新传播）}$$
💡 配分函数 Z = 1552 也从团信念免费得到：$\sum \beta_1 = \sum \beta_2 = 1552$

一笔账：k 次查询，消元 6k 次运算，团树 6 次校准 + k 次局部求和

k 次查询：VE = 6k；团树 = 一次校准 + k 次局部求和 —— 查询越多，缓存省得越多
证据

证据是局部事件：乘进一个团，局部重传，树不用重建

1观测 X = x：任取一个含 X 的团
2把指示因子乘进它的势能（X ≠ x 的行清零）
3从该团出发重新传播——树结构与其他团势能都不变
✅ 增量更新 vs 变量消去的「每次从零开始」——证据持续到达的系统（诊断、传感器网络）几乎总选团树
代价

树宽是精确推理的天花板：成本 O(d 的 w+1 次方)

$$\text{树宽 } w = (\text{最优弦化下最大团大小}) - 1 \qquad \text{复杂度 } O(d^{w+1})$$

避坑

三个高频误解：新模型、随便连、万能升级

❌ 团树是新模型 / 近似算法
✅ 每步运算与消元完全相同，分布不变——它是消元的存档格式，是精确推理
❌ 最大团随便连成树就行
✅ 少了运行交性质，变量信息在途中断裂，校准等式失效——性质是底线，最大生成树只是构造法
❌ 团树建了就比消元强
✅ 单次查询建树更贵；树宽大时团表存不下。价值场景：多查询 / 在线证据 / 要全部边缘
接口

小结

三句话讲完第10章

1解决什么：消元对多查询重复劳动 → 给消元加缓存，一次校准回答所有查询
2核心机制：弦化定货架 → 最大团按分隔集连成满足运行交的树 → 收集＋分发两遍校准
3承上启下：Ch9 管单次消元，本章管多次复用；树宽封顶＋离不开树 → Ch11 近似推理
$$\beta_i(C_i) = \psi_i(C_i) \cdot \prod_{k \in N(i)} \delta_{k\to i}(S_{ki}) = \tilde{P}(C_i) \quad\text{——合上书也要能默写}$$
