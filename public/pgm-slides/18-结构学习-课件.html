主线

结构从哪来——给候选图打分，在图的空间里搜索

1结构未知 → 候选 DAG 超指数多，穷举不可能（NP-hard）
2不能穷举就要打分 → 评分 = 似然 − 复杂度惩罚（挡住过拟合）
3评分可分解：局部改动只重算一两个族 → 搜索变得可行
4爬山搜索：加边 / 删边 / 反转边，逐步提升评分
5天花板：I-等价 注定方向不可辨识 → 只能学到等价类 PDAG
这条链就是本章目录：难关 → 评分（BIC）→ 手算 → 分解与搜索 → 约束与 PC → 边界
动机

现实里没人给你图：结构恰恰是最缺的东西

😇 第17章的世界
结构 𝒢 已知 = 天上掉下来的礼物
参数学习退化为「数数据、填小表」
🌍 真实世界
基因调控没人画好；症状因果没人排好
结构正是最缺、最想发现的知识
💡 把第17章倒过来用：任一候选图都能快速估参数、算似然 → 每张图都有分可比。剩下两件事：分怎么打、图怎么搜
难关一

DAG 数量超指数爆炸：10 个节点就有 4.2 亿亿张候选图

n（节点数）234510

⚠️ 这不是指数，是超指数（Super-exponential）——比 $2^n$ 快得多；结构学习是 NP-hard 的离散组合优化
推论：一切结构学习算法都是启发式——在比宇宙原子还多的地图上找宝藏，只能靠指南针（评分）爬山，不能走遍

坏消息：「数据够多就能学出方向」是错觉——方向辨识靠 V-结构 / 干预 / 时间顺序，不靠样本量（第21章）
评分

纯似然必死：加边永不降低似然，饱和模型满分但零泛化

1给节点加一个父节点 → CPD 按新配置细分 → 自由度变大 → 似然只升不降
2推到极限：饱和模型（人人以所有人为父）的似然 = 经验分布本身，全场最高
3但它是死记硬背：参数比数据点还多 → 新数据一来立刻崩盘，零泛化
✅ 奥卡姆剃刀：似然只奖励「拟合得好」，从不惩罚「模型复杂」——拟合收益必须超过复杂度代价，一条边才配存在
定义

BIC = 拟合 − 复杂度：每个自由参数收半条 ln M 的「税」

$$\boldsymbol{\mathrm{Score}_{BIC}(\mathcal{G}:D) = \ell(\hat{\theta}_{\mathcal{G}}:D) - \frac{k}{2}\,\ln M}$$
📈 拟合项 $\ell(\hat{\theta}_{\mathcal{G}}:D)$
该结构下 MLE 参数的对数似然；随 $M$ 线性增长
💰 惩罚项 $\frac{k}{2}\ln M$
$k$ = 自由参数总数（所有 CPD 独立条目数）；随 $\ln M$ 缓慢增长
MDL 视角：最好结构 = 「描述模型的比特 + 用模型描述数据的比特」最小 —— 复杂模型自身描述就贵，天然被罚

$$\mathrm{BIC}_0 = -22.18 - \frac{2}{2}\ln 16 \approx -22.18 - 2.77 = \boldsymbol{-24.95}$$

手算

16 样本对决（下）：G₁ 胜出，且 Y→X 永远打平

① G₁（X→Y）：P(Y=0|X=0)=7/8=0.875，P(Y=1|X=1)=0.875；14 个样本走 0.875、2 个走 0.125

$$\ell_1 = 16\ln 0.5 + 14\ln 0.875 + 2\ln 0.125 \approx -11.09 - 1.87 - 4.16 = \boldsymbol{-17.12}$$

② 加惩罚并判决：$k=3$，似然提升 $5.06$ ＞ 惩罚增量 $1.39$ ⟹ 边成立

$$\mathrm{BIC}_1 = -17.12 - \tfrac{3}{2}\ln 16 \approx \boldsymbol{-21.28} \;>\; \mathrm{BIC}_0 = -24.95$$

③ 当场演示 I-等价：换成 Y→X，计数完全对称 ⟹ $\ell$ 一字不差仍是 $\boldsymbol{-17.12}$，BIC 相同——打平，且永远打平

分解

可分解性：局部改动只重算一两个族，搜索从全局变增量

$$\boldsymbol{\mathrm{Score}(\mathcal{G}:D) = \sum_{i=1}^{n} \mathrm{FamScore}\big(X_i,\ \mathrm{Pa}(X_i):D\big)}$$
🧩 含义
总分 = 各族局部得分之和（与第17章似然分解同源）
⚡ 威力
加 / 删 / 反转一条边 → 只有一两个族的分数变化，其余 $n-2$ 项原封不动
缓存每个（节点, 父节点集）组合的局部分 → 每次试探 = 查表 + 减法；改一扇窗只重算这间房，整栋楼不动
搜索

爬山搜索：加边 / 删边 / 反转边，每一步都走评分升得最猛的

flowchart LR A["初始图（常用空图）"] --> B["考察所有合法操作
加边 / 删边 / 反转边（保持无环）"] B --> C["执行评分提升最大者"] C --> D{"还有提升?"} D -- 是 --> B D -- 否 --> E["停：局部最优"]
⚠️ 局部最优是常态：方向陷阱（先加 A→B，对的却是 B→A）单步爬不出 → 多重启 / 禁忌搜索
💡 K2 变体：给定拓扑序后，每个节点只向前面的节点找父亲 → 搜索空间大幅收缩
约束

学出的图要服役：树宽大 → 推理指数级；入度 d → CPD 参数 2ᵈ 爆炸

🕸️ 树宽约束（Treewidth）
精确推理复杂度随树宽指数增长（Ch9–10）
评分可能选出「拟合好但推理跑不动」的稠密图 → 限制树宽（如 ≤ 4）
👪 最大入度约束
每节点父节点数 ≤ d
同时按住 CPD 参数量 $2^d$ 的爆炸，一箭双雕
直觉：买车不能只看速度，还要看你的路能不能开——约束是下游可用性的闸门
诚实一笔：「树宽受限的结构学习」本身也是 NP-hard，实践中用启发式近似执行
另一路

PC 算法：不比模型，直接问数据「哪些条件独立性成立」

1学骨架：完全无向图出发，枚举条件集 S 做独立性检验；找到 S 使 X⊥Y|S 成立就删边并记下分离集
2定向 V-结构：不相邻的 X、Y 有公共邻居 Z 且 Z ∉ 分离集 ⟹ 定向为 X→Z←Y
3传播方向：用「避免成环、避免新 V-结构」规则能定多少定多少 → 输出 PDAG
⚠️ 小样本现实：检验功效低，「检验不出相关」被误判为「独立」→ 漏真边；数据少时答案主要由先验决定（如稀疏偏好、专家禁边/必边）
避坑

三个高频误解：方向、惩罚、可分解，全都有人记反

❌ 「数据够多就能学出方向」
✅ X→Y 与 Y→X 在任何样本量下似然完全相同（本章手算为证）；方向辨识靠 V-结构 / 干预 / 时间信息，与样本量无关
❌ 「惩罚随 M 增长，所以数据越多越选简单模型」
✅ 方向恰好相反：似然项随 M 线性增长、惩罚只随 ln M 增长——数据越多 BIC 越敢选复杂结构；数据少时惩罚才主导
❌ 「可分解 = 保证全局最优」
✅ 可分解只保证每次试探算得快；爬山照样卡局部最优，多重启与禁忌搜索才是对策
接口

两条路线同一个天花板；第19章撤掉「数据完全」这个假设

评分搜索（爬山 / K2）约束方法（PC）
核心操作比较候选图得分做条件独立性检验
输出一个 DAG（等价类代表）PDAG（诚实保留不定方向）
小样本软肋惩罚主导 → 过度稀疏检验功效低 → 假独立、漏边
共同天花板I-等价：谁也逃不掉
钩子：本章假设每条数据每个变量都有值；有缺失、有隐变量时，计数与评分内核全部失灵——第19章 EM 登场
小结

三句话讲完第18章

1解决什么：结构未知时从数据发现依赖图——参数学习的前提，最贴近「从数据发现知识」
2核心机制：评分 ＋ 搜索——BIC 自带惩罚挡过拟合；可分解性让爬山（加/删/反转边）高效可行
3承上启下：I-等价注定只学到 PDAG；小样本靠先验；第19章处理数据不全
