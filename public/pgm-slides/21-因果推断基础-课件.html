主线

从「看到的」到「做出来的」，五步跨越

1观测只给 $P(Y\mid X)$，行动却需要 $P(Y\mid do(X))$——两个不同的量
2混杂让两者可以方向相反：辛普森悖论（例 1 手算）
3出路：BN 装上机制语义 → 结构因果模型，干预 = 删入边 + 固定取值
4何时观测数据就够：后门准则与调整公式；更一般交给 do-演算
5代价：同一观测分布可来自不同因果图——方向不在数据里
这条链就是本章的目录：两种查询 → 辛普森悖论 → SCM 与截断因子分解 → 后门准则 → do-演算与边界
动机

观测是「谁自己走了过来」，干预是「把所有人拧过去」

查询符号回答的问题数据来源
观测$P(Y \mid X = x)$在「自己取了 x 值」的那部分人里，Y 长什么样被动收集的数据
干预$P(Y \mid do(X = x))$如果把所有人的 X 都拧到 x，Y 会长什么样理想实验（随机对照）
写法只差一个 do，含义可以天差地别：观测里混着「自己走过来」的选择效应，干预把它抹平

例1：分层看有效的药，总体看可能「有害」

红色 S 是混杂因素：D←S→R 是「后门路径」

手算

观测手算：服药组 0.50 对不服药组 0.75，药「有害」

① 服药组的病情构成：$P(服)=0.2\times0.5+0.8\times0.5=0.5$，贝叶斯反推：

$$P(重\mid 服)=\frac{0.8\times0.5}{0.5}=\boldsymbol{0.8}, \qquad P(重\mid 不服)=\boldsymbol{0.2}$$

② 观测条件概率（按组内病情加权）：

$$P(愈\mid 服)=0.8\times0.4+0.2\times0.9=\boldsymbol{0.50}, \quad P(愈\mid 不服)=0.2\times0.35+0.8\times0.85=\boldsymbol{0.75}$$
$$\text{观测结论：} 0.50 < 0.75 \;\Rightarrow\; \text{药「看起来有害」——但分层里它明明有效！}$$
✍️
暂停推导

盖住答案，自己把第①②步推一遍：先算服药组里重症占多少，再算两组的康复率

手算

干预手算：0.65 对 0.60，结论整个翻转

① do(D) 的关键：干预不改变 S 的分布——病情在因果上先于服药，仍轻重各半

② 对全人群统一给药（按总体占比加权，不按组内构成）：

$$P(愈\mid do(服))=0.5\times0.9+0.5\times0.4=\boldsymbol{0.65}$$
$$P(愈\mid do(不服))=0.5\times0.85+0.5\times0.35=\boldsymbol{0.60}$$
$$\text{干预结论：} 0.65 > 0.60 \;\Rightarrow\; \text{药确实有效——辛普森悖论（Simpson's Paradox）}$$

重点

服药组背着八成重症：后门路径把病情偷运进相关性

flowchart LR S["S 病情（混杂）"] --> D["D 服药"] S --> R["R 康复"] D --> R style S fill:#fae9e7,stroke:#b03a2e,stroke-width:2.5px linkStyle 0 stroke:#b03a2e,stroke-width:2.5px linkStyle 1 stroke:#b03a2e,stroke-width:2.5px
🚪 后门 D←S→R（红色）：跑的是「病情差异」，不是药效——观测相关里混着它的贡献
💊 前门 D→R：这才是药的真实疗效，被后门噪声淹没
两者的差 = 混杂（Confounding）的大小：观测问「谁自己走来」，干预问「拧过去会怎样」
定义

结构因果模型 = 贝叶斯网络 ＋ 三条因果语义

⚙️ ① 机制（Mechanism）
每个 CPD 是一个物理过程：父节点决定子节点，不只是相关
🧩 ② 模块性（Modularity）
机制互相独立：可以敲掉其中一个（换掉 X 的生成方式），其余原封不动
➡️ ③ 边 = 因果方向：$\mathrm{Pa}(X_i)$ 是 $X_i$ 的直接原因（不是统计依赖，是因果依赖）
直觉：SCM 是乐高模型——每块积木（机制）独立，可以抽换其中一块；这让「干预」有了定义
机制

do = 手术：删掉 X 的入边、钉住取值，其余机制原封不动

flowchart LR S["S 病情"] --> D["D 服药"] S --> R["R 康复"] D --> R
干预前：D 由 S 决定（医生按病情开药）
flowchart LR S["S 病情"] D["D 固定为服"] R["R 康复"] S --> R D --> R style D fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px
do(D=服)：删 S→D，S→R 与 D→R 原样保留
口诀：删入边、固定值——切断 X 的原因，保留 X 的影响；只换一个机制，不动全世界
公式

截断因子分解：拿掉被干预变量的因子，其余照乘

$$P(X_1,\dots,X_n \mid do(X{=}x)) \;=\; \prod_{i:\,X_i \neq X} P\big(X_i \,\big|\, \mathrm{Pa}(X_i)\big) \quad\text{（X 处一律代入 } x\text{）}$$

套到例1：$P(S,D,R)=P(S)\,P(D\mid S)\,P(R\mid D,S)$，do(服) 后拿掉 $P(D\mid S)$：

$$\boldsymbol{P(S,R \mid do(服)) = P(S)\cdot P(R \mid 服,S)} \;\Rightarrow\; P(愈\mid do(服))=\textstyle\sum_s P(愈\mid 服,s)P(s)=0.65$$
这正是辛普森手算第二步的算法——现在它不是「偷偷假设」，而是 SCM 语义的直接推论

判据

挡住所有后门、且不含 X 的后代，观测数据就够用

🚧 条件①：阻断后门
Z 阻断所有从 X 指向 Y 的后门路径（以指向 X 的箭头开头，按 d-分离判定，X 的出边保留）
🚫 条件②：不含后代
Z 中不含 X 的任何后代——否则会截断因果路径本身
例1 验证：$Z=\{S\}$ 阻断唯一后门 D←S→R ✓，且 S 不是 D 的后代 ✓ —— 两关全过
直觉：把混杂的后门堵上，前门（因果路径）就干净了——观测数据于是能算出干预效果
公式

后门调整：分层算、再加权，0.65 与 0.60 重算成功

$$\boldsymbol{P(Y \mid do(X = x)) = \sum_{z} P(Y \mid X = x, Z = z)\cdot P(Z = z)}$$

例3·重算例1（$Z=\{S\}$，两个因子都来自观测分布）：

$$P(愈\mid do(服))=0.9\times0.5+0.4\times0.5=\boldsymbol{0.65}\;\checkmark \qquad P(愈\mid do(不服))=0.85\times0.5+0.35\times0.5=\boldsymbol{0.60}\;\checkmark$$
与截断因子分解结果一致；随机对照试验（RCT）是特例：随机化直接砍断 X 的全部入边，连分层都不用

工具

do-演算三条规则：把 do 消到底，效应就可识别

规则干什么成立条件（在动过手术的图上判独立）
规则1 插入/删除观测消掉多余的观测 z删掉 X 入边的图里，Y ⊥ Z | X, W
规则2 干预 ↔ 观测互换do(Z) 当普通条件看（灵魂）再删掉 Z 出边的图里，Y ⊥ Z | X, W
规则3 删除干预删掉多余的 do(Z)删 X 入边及无关 Z 入边的图里判独立
消到底 = 可识别（Identifiable）：后门调整就是一次成功推导；消不了 = 不可识别，只能改数据——加测量或做实验

前门准则（Frontdoor Criterion）由 do-演算严格推出：局部结构干净，就能绕开测不到的混杂
进阶

反事实三步：溯因 U=3，行动 do(X=2)，预测 Y′=7

机制 $Y = 2X + U$（X 药量，U 体质，外生噪声）；观测到某病人 $X=1,\;Y=5$：

① 溯因（Abduction）：由观测反推外生变量——这个病人的体质被唯一钉死

$$U = Y - 2X = 5 - 2 = \boldsymbol{3}$$

② 行动（Action）：模型改成 $do(X=2)$，机制与 U 的值都不变

③ 预测（Prediction）：在新模型里算平行世界的结果

$$\boldsymbol{Y' = 2\times 2 + 3 = 7} \quad\text{——「他若当时加倍药量，疗效会是 7」}$$
⚠️ 反事实比干预多要一样东西：溯因要求机制的完整函数形式——关联、干预、反事实是「因果之梯」三级，逐级假设更强

避坑

两个直觉，在因果推断里都会翻车

❌ 「数据量大就能消除混杂」
✅ 混杂是结构性偏差，不是随机噪声：数据再多，$P(愈\mid 服)$ 都稳稳收敛到 0.50 而不是 0.65。消混杂靠「知道因果结构 + 正确调整」，不靠堆数据
❌ 「控制的变量越多，估计越可靠」
✅ 控制中介 → 截断因果路径，效应被低估；控制对撞节点 → 打开假路径，制造虚假相关。控制谁由后门准则决定：先画图，再谈回归

小结

三句话讲完第21章

1解决什么：观测给 $P(Y\mid X)$，行动要 $P(Y\mid do(X))$，混杂让两者可方向相反
2核心机制：SCM 装机制语义；do = 删入边 + 固定值；截断因子分解给干预分布；后门被堵住时观测就够用
3承上启下：方向不在数据里（例2：0.8 vs 0.6）；Ch22 给结果打分，Ch23 把决策画进图
$$P(Y \mid do(X{=}x)) = \sum_{z} P(Y \mid x, z)\,P(z) \quad\text{——合上书也要能默写}$$
