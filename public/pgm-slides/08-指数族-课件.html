定义

指数族 = 自然参数、充分统计量、基础测度、对数配分函数

部件名称职责
\(\theta\)自然参数（Natural Parameters）模型的「旋钮」，学习要调的就是它
\(\phi(X)\)充分统计量（Sufficient Statistics）从数据中提取的、与 θ 有关的全部信息
\(h(X)\)基础测度（Base Measure）不含参数的剩余部分，常为 1
\(A(\theta)\)对数配分函数（Log-Partition）归一化常数的对数，保证加起来为 1
\[\boldsymbol{P(X \mid \theta) = h(X)\cdot \exp\big(\theta^{\top}\phi(X) - A(\theta)\big)}\]
读法：对数空间里是线性的——log P = θ·φ(X) − A(θ) + log h(X)，凡「取对数后变成特征加权和」的分布都在这个家族里
推导

伯努利改写四步：取对数、并同类项、读部件、验归一化

① 取对数，把乘积变加法（原始写法 \(P(X)=p^{X}(1-p)^{1-X}\)）：

\[\log P(X) = X\log p + (1-X)\log(1-p)\]

② 按 X 合并同类项（展开第二项再回收）：

\[\log P(X) = X\cdot\log\frac{p}{1-p} + \log(1-p)\]

③ 读出四部件（反解 \(p = e^{\theta}/(1+e^{\theta})\) 代入常数项）：

\[\boldsymbol{\phi(X)=X,\quad \theta=\log\frac{p}{1-p},\quad h(X)=1,\quad A(\theta)=\log(1+e^{\theta})}\]

④ 验证归一化：按定义算一遍，与上式吻合 ✔

\[\log\textstyle\sum_{x} h(x)e^{\theta\phi(x)} = \log(e^{0}+e^{\theta}) = \log(1+e^{\theta})\]

推导

高斯改写：自然参数常常不是你以为的那个老参数

① 展开指数上的平方 \((x-\mu)^{2}=x^{2}-2\mu x+\mu^{2}\)：

\[-\frac{(x-\mu)^{2}}{2\sigma^{2}} = -\frac{x^{2}}{2\sigma^{2}} + \frac{\mu}{\sigma^{2}}\,x - \frac{\mu^{2}}{2\sigma^{2}}\]

② 分类归堆：含 x 且含 μ → θ·φ；只含 x → h；只含 μ → −A：

\[\boldsymbol{\phi(x)=x,\quad \theta=\frac{\mu}{\sigma^{2}},\quad h(x)=\frac{1}{\sqrt{2\pi}\,\sigma}e^{-x^{2}/2\sigma^{2}},\quad A(\theta)=\frac{\sigma^{2}\theta^{2}}{2}}\]

③ 核对：\(h(x)\cdot\exp(\theta x - \sigma^{2}\theta^{2}/2)\) 展开合并，正好还原 \(-(x-\mu)^{2}/(2\sigma^{2})\) ✔

σ² 已知时 h 吞掉所有只含 x 的项——基础测度管「数据的底色」，A 管「参数的归一化」

洞察

正值表格取对数即特征加权和——一句话证完全家族

任取严格为正的表格因子 \(\psi(x_C)\)，取对数并展开（每种赋值配一个示性函数）：

\[\log\psi(x_C) = \sum_{i} w_i\, f_i(x_C),\qquad f_i(x_C)=1[x_C=\text{第 }i\text{ 种赋值}],\quad w_i=\log\psi(\text{第 }i\text{ 种赋值})\]
\[\boldsymbol{\psi = \exp\Big(\sum_i w_i f_i\Big)} \quad\Longrightarrow\quad \theta = w,\ \ \phi = (f_1, f_2, \dots)\]
推论：Ch3 表格 CPD、Ch4 对数线性 MRF（\(A(\theta)=\log Z\)）、Ch5 Logistic（伯努利族换线性参数）全部自动落入——指数族不是新模型，是旧模型换了坐标系

红利一

似然只通过充分统计量之和依赖数据——原始数据可扔

\[\ell(\theta; D) = \sum_{x\in D}\log P(x\mid\theta) = \theta^{\top}\Big[\textstyle\sum_{x\in D}\phi(x)\Big] - N\cdot A(\theta) + \text{常数}\]
🪙 伯努利
只需记住「几次正、几次负」，十次与十亿次同样只存两个数
🔔 高斯（σ² 已知）
只需记住样本和 \(\sum x\)，原始数据全部可扔
「充分」= 对估计 θ 而言，\(\sum_{x\in D}\phi(x)\) 带走了数据里与参数有关的全部信息——这是数据压缩的极限
红利二

A(θ) 的导数供应全部矩，而 A(θ) 就是 log Z

\[\nabla A(\theta) = E_{\theta}[\phi(X)],\qquad \nabla^{2} A(\theta) = \mathrm{Cov}_{\theta}[\phi(X)] \succeq 0 \;\Longrightarrow\; A \text{ 是凸函数}\]
\[\boldsymbol{A(\theta) = \log Z}\quad\text{—— 第4章配分函数的对数：学习永远绕不开推理}\]

手算

最大似然 = 矩匹配：把模型期望对齐到样本均值

① 写对数似然（数据 7 正 3 负，\(\sum\phi(x)=7\)，\(N=10\)）：

\[\ell(\theta) = 7\theta - 10\log(1+e^{\theta})\]

② 求导（A 的一阶导正是 sigmoid）：

\[\ell'(\theta) = 7 - 10\cdot\frac{e^{\theta}}{1+e^{\theta}}\]

③ 令导数为零解出 \(\hat\theta\)，换回 \(p\) 正是频率 \(7/10\)：

\[\frac{e^{\hat\theta}}{1+e^{\hat\theta}} = 0.7 \;\Rightarrow\; e^{\hat\theta} = \frac{7}{3} \;\Rightarrow\; \hat\theta = \log\frac{7}{3} \approx 0.847,\quad \hat p = 0.7\]
\[\boldsymbol{E_{\hat\theta}[\phi(X)] = \frac{1}{N}\sum_{x\in D}\phi(x)}\quad\text{模型期望 = 样本均值（此处 }0.7=0.7\text{ ✔）}\]

共轭

共轭先验下，贝叶斯更新退化为伪计数相加

① 写先验 Beta(2,2)——相当于「假想见过 1 正 1 反」：

\[P(p) \propto p^{1}(1-p)^{1}\]

② 写似然（观测 7 正 3 负）：

\[P(D\mid p) \propto p^{7}(1-p)^{3}\]

③ 相乘并认出来后验：同底数幂相加，后验均值 \(9/14 \approx 0.643\)（介于先验 0.5 与频率 0.7 之间）

\[P(p\mid D) \propto p^{1+7}(1-p)^{1+3} = p^{8}(1-p)^{4} \;\Longrightarrow\; \mathrm{Beta}(9,5)\]
\[\boldsymbol{(\alpha,\ \alpha_0) \leftarrow \Big(\alpha + \sum_{x\in D}\phi(x),\ \ \alpha_0 + N\Big)}\quad\text{后验 = 先验伪计数 + 充分统计量}\]

视角

最大熵一句话：指数形状 = 对已知信息之外不做任何假设

只知道几件事 \(E[\phi_k]=\alpha_k\)，其余一概不知 ⟹ 在所有满足约束的分布中选熵最大者，拉格朗日解恰好是：

\[\boldsymbol{P^{*}(x) \propto h(x)\cdot \exp\Big(\sum_{k}\lambda_k\,\phi_k(x)\Big)}\quad\text{—— 正是指数族，乘子 λ 即自然参数 θ}\]
例：高斯 = 只知道均值与方差时的最大熵分布。指数形状不是发明，是「最少假设」的必然结果
这个话题能开另一门课——本章只需记住结论：指数族到处冒出来，因为它最「诚实」

避坑

两个高频误区：家族名会骗人，矩匹配不保证闭式解

❌ 「指数族 = 指数分布的家族」
✅ 指数分布（Exponential Distribution）只是家族里一个普通成员；指数族是整个家族的名字——伯努利、高斯、多项、泊松都在里面
❌ 「矩匹配 ⟹ MLE 永远有闭式解」
✅ 只对伯努利等简单族成立；MRF 的 \(E_{\theta}[\phi]\) 要算 \(A(\theta)=\log Z\)，是指数级求和——只能迭代求解，这正是第20章困难的根源
