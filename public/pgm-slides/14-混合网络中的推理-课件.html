定位

本章解决「离散与连续交界处的推理」——第15章把它铺上时间轴，第19章回答参数从哪学来

主线

离散+连续混在一起，表格化会炸，只能拆开算、再缝回去

1现实模型离散与连续混杂：疾病与血压、体制与收益率、地形与读数
2离散化是陷阱：切粗丢精度，切细参数爆炸
3折中方案 CLG：连续保持高斯，离散保持表格，交互处「表格化的高斯」缝合
4消元试一遍：消连续父风平浪静，消离散父一分为二
5闭包灾难：分量指数爆炸 → 弱/强边缘化止血，或转近似
这条链就是本章的目录：动机 → CLG 定义 → 两种消去的命运 → 手算 → 闭包灾难 → 止血方案
动机

把连续变量离散化：切粗丢精度，切细参数爆炸

第一直觉：连续变量切成区间 → 全变离散 → 直接套第9章变量消去。两副毒药必选一副：

😇 切得粗（10 个区间）
CPD 确实小，但「血压 120–140」这种分辨率对诊断毫无意义——误差建模时就锁死
💥 切得细（1000 个区间）
两个连续变量相邻 ⟹ 因子表爆炸到百万项；消去复杂度以区间数为底数指数增长
$$\text{两个连续变量相邻，各切 } 1000 \text{ 区间} \;\Rightarrow\; \text{因子表 } \approx 10^{6} \text{ 项（存不下、算不动）}$$
💡 粗也不行、细也不行 ⟹ 只能让连续变量保持连续，换一套能装下两类变量的表示
本质

离散消元产表格、连续消元产函数——没有统一的封闭表示

➕ 离散变量的消去 = 求和
产出的是一张表格（有限行数）
∫ 连续变量的消去 = 积分
产出的是一个函数（无限精度）
⚠️ 混合网络要求同一套消息传递里同时做这两件事：表格 × 函数相乘之后，用什么数据结构装？
💡 出路：找一类对「乘积、积分、边缘化」封闭的连续分布 → 高斯（第7章已证）。连续保持高斯、离散保持表格、交互处用「表格索引的高斯」缝合 = CLG
定义

CLG（条件线性高斯）= 两条家规换来的「表格化的高斯」

🚫 家规①：离散变量不能有连续父节点
离散变量的 CPD 只依赖离散父母 = 普通表格
📈 家规②：连续变量 | 父母 = 线性高斯
均值是连续父的线性函数、方差固定；离散父只负责切换参数
$$\boldsymbol{P(X \mid D{=}d,\, Y_1,\dots,Y_k) = \mathcal{N}\big(\beta_0^{(d)} + \beta_1^{(d)} y_1 + \cdots + \beta_k^{(d)} y_k;\; \sigma^{2\,(d)}\big)}$$
读法：每个离散配置 d 配一套高斯参数 —— 表格的每行不再是概率数，而是一套（斜率, 截距, 方差）
例1

一个离散开关，就让连续变量的边缘变成双峰

d$P(D{=}d)$X 的分布
正常0.4$\mathcal{N}(0,1)$
老化0.6$\mathcal{N}(3,1)$

X 的边缘分布 = 混合高斯（Gaussian Mixture）

$$p(x) = 0.4\cdot\mathcal{N}(0,1) + 0.6\cdot\mathcal{N}(3,1) \quad\text{（双峰！）}$$
CLG 网络里连续变量的边缘天然是混合高斯：每个离散配置贡献一个高斯分量，权重就是该配置的概率
设定

线性高斯的完整形态：均值随父线性走，方差雷打不动

设 $X \sim \mathcal{N}(2,1)$，Y 以 X 为连续父：

$$Y \mid X{=}x \;\sim\; \mathcal{N}(3x+1,\; 4) \qquad \text{E}[Y\mid x]=3x+1 \text{ 是线性函数，} \mathrm{Var}(Y\mid x)=4 \text{ 与 } x \text{ 无关}$$

推导

消去连续父风平浪静：积分出来仍是单一高斯

① 写出积分：高斯 × 高斯再积分仍是高斯（第7章封闭性），只需算前两阶矩：

$$p(y) = \int \mathcal{N}(y;\,3x+1,4)\cdot\mathcal{N}(x;\,2,1)\,dx$$

② 算前两阶矩：期望用线性性，方差用条件方差公式：

$$\mathrm{E}[Y] = 3\cdot\mathrm{E}[X]+1 = 3{\times}2+1 = 7 \qquad \mathrm{Var}(Y) = 3^2\cdot\mathrm{Var}(X)+4 = 9{\times}1+4 = 13$$
$$\boldsymbol{p(y) = \mathcal{N}(7,\,13)} \qquad \text{一般地： } Y \sim \mathcal{N}\big(a\mu_x + b,\; a^2\sigma_x^2 + \sigma^2\big)$$

对照

消去离散父一分为二：单高斯裂成两分量混合

给 Y 再加离散父 $D\in\{d^0,d^1\}$，$P(d^0)=P(d^1)=0.5$，每个配置一套参数：

d$P(D{=}d)$$Y \mid X{=}x, D{=}d$ 的分布
$d^0$0.5$\mathcal{N}(3x+1,\,4)$
$d^1$0.5$\mathcal{N}(x-2,\,1)$
$$p(y\mid x) = 0.5\cdot\mathcal{N}(y;\,3x+1,4) + 0.5\cdot\mathcal{N}(y;\,x-2,1) \quad\text{（两分量混合）}$$
$$\mathrm{E}[Y\mid x] = 0.5\cdot(3x+1) + 0.5\cdot(x-2) = \boldsymbol{2x - 0.5} \quad\text{（恰好仍是线性）}$$
⚠️ 均值看起来没事 —— 但下一页算方差，CLG 的形式就保不住了
推导

方差随 x 变的那一刻，CLG 形式死亡

① 二阶矩（高斯有 $\mathrm{E}[Y^2]=\sigma^2+\mu^2$，两分量各贡献 $4+(3x{+}1)^2$ 与 $1+(x{-}2)^2$）：

$$\mathrm{E}[Y^2\mid x] = 0.5\cdot(9x^2+6x+5) + 0.5\cdot(x^2-4x+5) = 5x^2+x+5$$

② 方差 = 二阶矩 − 均值²：

$$\boldsymbol{\mathrm{Var}(Y\mid x) = (5x^2+x+5) - (2x-0.5)^2 = x^2 + 3x + 4.75}$$
⚠️ 方差随 x 变化，直接违反家规②「条件方差为常数」⟹ CLG 对消去连续父封闭，对消去离散父不封闭。口诀：消连续父还是一只钟，消离散父变成一群钟

演练

观测 X=2：密度乘先验再归一化，老化概率从 0.6 翻到 0.87

$$\text{① 写似然：}\; P(X{=}2\mid\text{正常}) = \tfrac{1}{\sqrt{2\pi}}e^{-2} \approx 0.0540 \qquad P(X{=}2\mid\text{老化}) = \tfrac{1}{\sqrt{2\pi}}e^{-0.5} \approx 0.2420$$
$$\text{② 乘先验：}\; \text{正常 } 0.4\times 0.0540 = 0.0216 \qquad \text{老化 } 0.6\times 0.2420 = 0.1452$$
$$\text{③ 归一化：}\; \boldsymbol{P(\text{老化}\mid X{=}2) = \frac{0.1452}{0.0216+0.1452} \approx 0.87} \qquad P(\text{正常}\mid X{=}2)\approx 0.13$$

手算

混合高斯的矩：1.8 与 3.16——矩匹配的第一次登场

① 均值（全期望公式）：

$$\mathrm{E}[X] = 0.4\times 0 + 0.6\times 3 = \boldsymbol{1.8}$$

② 方差（全方差公式 = 组内 + 组间）：

$$\underbrace{0.4{\times}1+0.6{\times}1}_{\text{组内 } =\, 1} \;+\; \underbrace{0.4{\times}(0{-}1.8)^2+0.6{\times}(3{-}1.8)^2}_{\text{组间 } =\, 1.296+0.864 \,=\, 2.16} \;\Rightarrow\; \mathrm{Var}(X) = \boldsymbol{3.16}$$
$$\text{矩匹配（Moment Matching）：} \quad 0.4\,\mathcal{N}(0,1)+0.6\,\mathcal{N}(3,1) \;\approx\; \boldsymbol{\mathcal{N}(1.8,\;3.16)}$$
保前两阶矩（均值、方差），丢分布形状（双峰性）—— 单高斯族内的最优近似

灾难

消去与离散「沾亲」的连续变量，分量数指数爆炸

  • 消去纯离散变量：✅ 安全，求和产表格
  • 消去只与连续变量打交道的连续变量：✅ 安全，积分解析仍是高斯
  • 消去与离散沾亲的连续变量：❌ 积分后落到离散因子上的，是每个离散配置一个不同的高斯

⚠️ 精确推理失败的根源不是算法慢，而是表示本身指数膨胀——消息还没算出来，就已经写不下了
止血

弱边缘化处处可用但不精确；强边缘化精确但常不可用

弱边缘化（Weak Marginalization）强边缘化（Strong Marginalization）
做法混合高斯一冒出来就矩匹配压回单高斯，再继续消元先消完全部连续变量，塌缩成纯离散网络后再做离散推理
保留 / 丢弃保前两阶矩（均值、方差），丢形状（双峰、偏度）全程精确，不丢任何东西
前提无——任何 CLG 可用道德化三角化后无离散-连续混合团
定位常规止血钳，但结果不再精确奢侈品：多数模型不满足，能用则用
💡 判别口诀：弱 = 拿近似换普适；强 = 拿顺序约束换精确
近似

EP、采样、假设密度滤波：矩匹配的三种化身

🎲 采样（接第12章）
Gibbs 采样天然适配：离散的条件分布是表格，连续的条件分布在 CLG 下是高斯——两种条件都好采样
📦 期望传播（Expectation Propagation, EP）
每条混合高斯消息立即矩匹配投影回单高斯再往下传 = 每步都做弱边缘化的消息传递版
⏱️ 假设密度滤波（Assumed Density Filtering）：在线场景每步推理后把信念投影回简单分布族——第15章切换卡尔曼滤波的标准做法
血缘：EP 与假设密度滤波的内核都是矩匹配 —— 整个混合网络推理的武器库，建立在「保前两阶矩、丢形状」这一个动作上
避坑

三个高频误解：封闭性、精确性、边缘形状

❌ 以为 CLG 对所有消去都封闭
✅ 只对「条件化连续证据」「消纯连续变量」封闭；消离散父 / 沾离散亲的连续变量 ⟹ 混合高斯破门，闭包当场死亡
❌ 以为弱边缘化是精确的
✅ 矩匹配保均值方差、丢形状——它是单高斯族内的最优近似，不是真消息
❌ 以为 CLG 中连续变量的边缘仍是高斯
✅ 只要有离散父 / 离散祖先，边缘就是混合高斯——双峰分布没有单高斯的形状
