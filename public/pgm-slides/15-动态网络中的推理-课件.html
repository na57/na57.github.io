主线

时间无限长，但马尔可夫性把状态压成一个信念

1序列无限长 → 展开成大网络，内存与计算都撑不住
22TBN ＋ 马尔可夫假设：给定现在，未来 ⊥ 过去 → 历史压成当前信念
3推理 = 沿链滚动的递推：前向做滤波/预测，后向倒流做平滑
4求和换取最大 ＋ 回溯指针 → 最可能序列（Viterbi）
5连续状态：线性高斯让递推闭式化 → 卡尔曼滤波
这条链就是本章目录：动机 → 2TBN → rollup → 四个任务 → 三组手算 → 卡尔曼
动机

不建一条大 BN 的两个硬理由：内存爆炸 ＋ 浪费结构

💥 理由一：内存随 T 无限增长
T 步展开 = $2T$ 个节点；在线场景（机器人定位、行情监控）T 无限长，内存跟着涨——不可接受。我们要空间复杂度与 T 无关的算法
🔁 理由二：通用消去看不见参数共享
展开网每一片完全相同，但消去算法看不见对称性：同样的计算重复 T 遍，消去顺序稍差，诱导宽度随 T 膨胀
💡 出路：马尔可夫假设让推理坍缩为固定大小的递推——每步只做一次「预测 ＋ 更新」，旧时刻全部扔掉
定义

DBN = 先验模板 ＋ 两时间片模板，参数只有一份

2TBN 模板（t → t+1）
转移边 X→X′ ＋ 发射边 X→O
flowchart LR X0["X⁰"] --> X1["X¹"] --> X2["X²"] X1 --> O1["O¹"] X2 --> O2["O²"] style X0 fill:#ebf8ff,stroke:#2b6cb0,stroke-width:2.5px
展开（Unrolling）
模板沿时间复制，参数全部共享
$$\boldsymbol{P(X^{0..T},O^{1..T}) = P(X^0)\prod_{t} P(X^{t+1}\mid X^t)\,P(O^t\mid X^t)} \quad\text{（参数一份，与 T 无关）}$$
最简单的特例：隐马尔可夫模型（Hidden Markov Model, HMM）——一个隐状态 ＋ 每时刻一个观测
机制

rollup：永远只维护接口变量 Xᵗ 的一个信念

flowchart LR A["历史 O¹…ᵗ
全部压缩"] --> B["信念 σᵗ
P(Xᵗ | O¹…ᵗ)"]:::hot B -->|① 预测：转移前推| C["预测信念"] D["新观测 Oᵗ⁺¹"] --> E["② 更新"] C --> E E --> F["信念 σᵗ⁺¹"]:::hot classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#7b341e
$$\text{每步成本 } O(d^2)，\text{内存 } O(d)，\text{都与序列长度 } T \text{ 无关} \quad（d = \text{状态数}）$$
马尔可夫性 = 接口变量：过去对未来的全部影响，浓缩在「当前状态的后验」这一个对象里
任务

四个任务一张表：区别只在「用哪些观测，问哪个时刻」

任务数学形式直觉典型算法
滤波（Filtering）$P(X^t \mid O^{1..t})$边看边猜现在前向递推 / 卡尔曼滤波
预测（Prediction）$P(X^{t+k} \mid O^{1..t})$用现在推未来滤波 ＋ 转移前推 k 步
平滑（Smoothing）$P(X^t \mid O^{1..T}),\ t<T$事后回看，修正历史前向-后向算法
最可能序列$\arg\max P(X^{0..T} \mid O^{1..T})$整条轨迹的整体最优解释Viterbi（max-product）
⚠️ 四个任务算法不同、答案也不同：要边缘用前向-后向，要路径用 Viterbi，别拿错
例子

天气-心情 HMM：先验 0.5，转移留 0.7，发射对 0.9

参数组取值
先验$P(X^1{=}0)=P(X^1{=}1)=0.5$
转移（惯性）留原状 $0.7$，翻转 $0.3$
发射（可信）观测=状态 $0.9$，错位 $0.1$
观测序列$O^1=1,\ O^2=1$
X∈{0阴郁, 1晴朗}，O∈{0,1} 是可见信号

两时间片展开，连续两个好信号

滤波

前向递推 = 预测（转移前推）＋ 更新（观测修正）

前向消息：$\alpha_t(x) = P(X^t{=}x,\ O^{1..t})$（未归一化的联合）

$$\boldsymbol{\alpha_{t+1}(x') = \underbrace{P(O^{t+1}\mid x')}_{\text{更新：观测修正}} \cdot \underbrace{\sum_{x} P(x'\mid x)\,\alpha_t(x)}_{\text{预测：转移前推}}}$$
每时刻只维护 $d$ 个数，每步 $O(d^2)$，与已流逝的时间无关——rollup 在此兑现；归一化后就是滤波分布，所有 $\alpha$ 之和顺手给出证据概率
手算

t=1：先验 × 第一个观测 → 滤波 0.9

① 阿尔法一的两个值（先验 × 发射 $P(O^1{=}1\mid X^1)$）：

$$\alpha_1(0) = 0.5 \times 0.1 = \boldsymbol{0.05}, \qquad \alpha_1(1) = 0.5 \times 0.9 = \boldsymbol{0.45}$$

② 归一化得滤波（两者之和 $=0.50$）：

$$P(X^1{=}1\mid O^1{=}1) = \frac{0.45}{0.50} = \boldsymbol{0.9}$$
一个好信号，把对半开的先验推到 0.9；记住未归一化的 0.05 / 0.45，下一步从它们出发

手算

t=2：预测 0.17/0.33 → 更新 → 滤波 ≈ 0.946

$$\text{① 预测：}\; 0.05{\times}0.7+0.45{\times}0.3 = \boldsymbol{0.17}, \qquad 0.05{\times}0.3+0.45{\times}0.7 = \boldsymbol{0.33}$$
$$\text{② 更新（乘发射）：}\; \alpha_2(0) = 0.1 \times 0.17 = \boldsymbol{0.017}, \qquad \alpha_2(1) = 0.9 \times 0.33 = \boldsymbol{0.297}$$
$$P(X^2{=}1\mid O^1,O^2) = \frac{0.297}{0.017+0.297} = \frac{0.297}{0.314} \approx \boldsymbol{0.946} \quad\text{（证据概率 } P(O^1,O^2)=0.314\text{）}$$
✍️

遮住答案，自己把 t=2 的预测与更新各推一遍——预测两个数、更新两个数、归一化一个数。

平滑

后向递推把未来证据倒流回来，α·β 会师得平滑

后向消息：$\beta_t(x) = P(O^{t+1..T} \mid X^t{=}x)$，边界 $\beta_T(x)=1$

$$\beta_t(x) = \sum_{x'} P(x'\mid x)\,P(O^{t+1}\mid x')\,\beta_{t+1}(x')$$
$$\boldsymbol{P(X^t{=}x \mid O^{1..T}) \;\propto\; \alpha_t(x)\cdot\beta_t(x)} \quad\text{（前向带过去，后向带未来，会师相乘）}$$
手算

β₁ = 0.34/0.66，平滑 0.946 > 滤波 0.9：未来修正历史

① 边界：$\beta_2(0)=\beta_2(1)=1$（没有未来观测）

② 倒推 $\beta_1$（代入转移 × 发射 $P(O^2{=}1\mid\cdot)$ × $\beta_2$）：

$$\beta_1(0) = 0.7{\times}0.1 + 0.3{\times}0.9 = \boldsymbol{0.34}, \qquad \beta_1(1) = 0.3{\times}0.1 + 0.7{\times}0.9 = \boldsymbol{0.66}$$

③ 会师（$\alpha_1 \cdot \beta_1$）：$0.05{\times}0.34 = 0.017$，　$0.45{\times}0.66 = 0.297$

$$P(X^1{=}1\mid O^1,O^2) = \frac{0.297}{0.314} \approx \boldsymbol{0.946} \;>\; \text{滤波 } 0.9$$
未来证据倒流修正历史：看完 $O^2{=}1$ 回看 $t{=}1$，「晴朗」的把握从 0.9 升到 0.946

按空格 / → 逐步展开推导

最可能序列

Viterbi = 链上的 max-product：∑ 换 max ＋ 回溯指针

$\delta_t(x)$ = 以 $X^t{=}x$ 结尾、解释 $O^{1..t}$ 的最优路径分数

$$\boldsymbol{\delta_{t+1}(x') = P(O^{t+1}\mid x') \cdot \max_{x}\ \big[ P(x'\mid x)\,\delta_t(x) \big]} \quad\text{＋ 回溯指针记赢家}$$
与前向递推唯一差别：$\sum$ 换成 $\max$，外加一根回溯指针——要边缘用 $\alpha$，要路径用 $\delta$
手算

Viterbi：δ₂ = 0.0135/0.2835，回溯得最可能序列 (1,1)

① t=1（与前向相同）：$\delta_1(0)=0.5{\times}0.1=0.05$，　$\delta_1(1)=0.5{\times}0.9=0.45$

② t=2，状态 0：$\delta_2(0) = 0.1 \times \max(0.05{\times}0.7,\ 0.45{\times}0.3) = 0.1\times\max(0.035,\ \boldsymbol{0.135}) = \boldsymbol{0.0135}$，指针 → $X^1{=}1$

③ t=2，状态 1：$\delta_2(1) = 0.9 \times \max(0.05{\times}0.3,\ 0.45{\times}0.7) = 0.9\times\max(0.015,\ \boldsymbol{0.315}) = \boldsymbol{0.2835}$，指针 → $X^1{=}1$

$$\text{回溯：终点 } X^2{=}1 \to X^1{=}1 \;\Rightarrow\; \text{最可能序列 } \boldsymbol{(1,1)}，\text{分数 } \boldsymbol{0.2835}$$

穷举验证：(0,0)=0.0035，(0,1)=0.0135，(1,0)=0.0135，(1,1)=0.2835 ✓ 一致

半步对比：前向把来路加总（0.17 / 0.33），Viterbi 只留最强来路（0.135 / 0.315）——序列一长，两者可分道扬镳

连续

线性高斯时递推闭式化：卡尔曼滤波，预测变宽、更新收窄

步骤公式本例数字直觉
预测均值$\mu_1^- = \mu_0$$10$随机游走不改中心
预测方差$\sigma_1^{-2} = \sigma_0^2 + Q$$4+1=\boldsymbol{5}$（变宽）不看新数据只会更不确定
卡尔曼增益$K = \frac{\sigma_1^{-2}}{\sigma_1^{-2}+R}$$\frac{5}{9} \approx 0.556$观测与预测的话语权分配
更新均值$\mu_1 = \mu_1^- + K(o^1-\mu_1^-)$$10 + \frac{5}{9}\times 2 = \frac{100}{9} \approx \boldsymbol{11.11}$按精度折中，偏向观测 12
更新方差$\sigma_1^2 = (1-K)\sigma_1^{-2}$$\frac{20}{9} \approx \boldsymbol{2.22}$（收窄）每条新观测都在压缩不确定性
💡 直觉：两台秤按精度（方差倒数）加权——观测更准，所以 11.11 偏向 12 而不是简单平均 11
固定滞后平滑（Fixed-lag Smoothing）：只回看 L 步，代价常数化、与总时长无关；非线性/非高斯 → 粒子滤波（接 Ch12）接棒
避坑

三个误区：重放、拼接、以为是近似

❌ 平滑 = 滤波的事后重放
✅ 平滑用了未来证据（$P(X^t|O^{1..T})$），答案可以不同于滤波——本例 0.9 → 0.946
❌ 最可能序列 = 逐时刻平滑取 arg max 再拼接
✅ 这是 Ch13「MAP ≠ 边缘 arg max」的时序版：联合最优路径可能经过边缘不占优的状态，要路径必须跑 Viterbi
❌ 前向-后向是近似算法
✅ 它精确：与展开网上精确消去结果一致，差别只在效率与内存
