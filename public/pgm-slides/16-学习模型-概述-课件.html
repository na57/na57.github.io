主线

先分类任务，再选范式，最后立评估规矩

1手工建模两次破产：参数填不动、结构本来就不知道 → 只能向数据求助
2先分类：两条轴钉住全部学习问题——学什么 × 看见多少
3每格选范式：最大似然全听数据 vs 贝叶斯用先验兜底
4威胁：过拟合——复杂模型训练分数永远更高，训练似然会撒谎
5规矩：评估只有两条诚实路线——留出数据看泛化 或 给似然加复杂度惩罚
这条链就是本章的目录：破产 → 分类 → 范式 → 过拟合 → 评估；17–20 章负责把每个格子填满
动机

手工建模两次破产：参数填不动，结构本来就不知道

$$20 \text{ 个二元父节点} \Rightarrow \text{CPD 有 } 2^{20} \approx 10^{6} \text{ 行} \quad\text{（没有专家填得动）}$$
💸 破产一 · 参数量
百万行 CPD 无人能逐行填写；第5章的局部结构（树 CPD、Noisy-Or）只是缓解——参数仍要从数据估
🧬 破产二 · 结构未知
基因调控谁调控谁、市场变量谁影响谁——专家只有猜测；结构本身正是最想挖出的知识
💡 学习三问：参数怎么估（结构已知）· 结构怎么找（图也要学）· 学得好不好怎么评（评估）
视角

学习是推理的逆问题：推理从模型算答案，学习从数据找回模型

🧭 逆问题更难：同一批数据，多个模型都解释得通 → 需要「偏好」打破平局（如偏爱简单结构）
🔗 两者互相咬住：评模型要做推理；Ch19/20 里学习的内层每一步又要调用推理
定义

全部学习问题钉在两根轴上：学什么 × 看见多少

🎯 轴一 · 学什么
参数学习（Parameter Learning）：结构已知，只填表
结构学习（Structure Learning）：连图也要从数据中发现
👀 轴二 · 看见多少
完全数据（Complete Data）：每条样本所有变量都有值
不完全数据（Incomplete Data）：有缺失值，或存在从未被观测的隐变量
两条轴正交 → 四个象限 = 第 17–20 章各就各位；隐变量伏笔：Ch14 混合高斯的「分量归属」就是天然隐变量
地图

四个象限各就各位：17 学参数、18 学结构、19 补缺失

结构已知（学参数）结构未知（学结构）
完全数据第17章：MLE = 频率计数，贝叶斯 = 加伪计数第18章：评分 + 搜索（BIC/BDe），约束法
不完全数据第19章：EM 算法（Expectation-Maximization）——猜隐变量 → 当完全数据学 → 迭代最难象限：结构与隐变量联合学习（Ch19 末 / Ch18 扩展）
🧭 三句话导航：结构已知吗？数据完整吗？是 BN 还是 MN？——三个答案直接定位到 17/18/19/20 中的一章
难度

往右走搜索空间爆炸，往下走似然从单峰变多峰

➡️ 沿轴一向右（加学结构）
连续参数空间 → 离散图空间：n 节点 DAG 数超指数增长
每个候选结构先解一次参数学习
⇒ 结构学习 = 参数学习 ＋ 外层组合搜索
⬇️ 沿轴二向下（数据缺失）
似然要对没看见的变量求和
单峰变多峰，闭式解消失 → 只能迭代（EM）
Ch14 混合高斯伏笔在此兑现：分量归属 = 天然隐变量
两种难法不一样：往右是组合爆炸，往下是闭式解消失——后面各章各有各的武器
暗线

BN 学习能闭式，MN 被配分函数拖住——所以单列第20章

😌 BN 学习
似然按 CPD 逐行分解 → 每行独立最大化
完全数据下 MLE = 频率计数，闭式解干净利落
😖 MN 学习
配分函数 Z 把所有参数耦成一团（第4章账单到期）
似然不能分解，连梯度都要靠推理来算 → Ch20 用伪似然等近似绕行
表示上的一小步差异 = 学习难度上的一大步——这就是 MN 单列第20章的全部理由
目标

「学好」有三种含义：逼近分布、答得准、结构真

目标要什么度量典型场景
密度估计（Density Estimation）模型 P̂ 逼近真实分布 P*留出数据上的对数似然（≈ KL 散度）生成、异常检测
预测（Prediction）特定查询（如分类）答得准留出数据上的错误率 / 损失诊断、分类
知识发现（Knowledge Discovery）结构本身是真的（边 = 真实机制）最难：需领域验证或因果假设（Ch21）基因网络、科学发现
⚠️ 知识发现最难评：统计分数相同的不同结构，机制可能完全不同（Ch18 的 I-等价、Ch21 的因果）
警告

训练似然会撒谎：越复杂的模型越会「背答案」

坏消息：复杂度一升，训练似然必升——它只度量「拟合」，不度量「学到」。

训练集上留出集上（没见过的数据）
复杂度 ↑似然单调上升 ↑似然先升后降（顶点在中等复杂度）
⚠️ 极端情形：「背下整个训练集」的模型训练似然最高，对新数据却一塌糊涂——这叫过拟合（Overfitting）；训练分与留出分之差 = 泛化差距
泛化（Generalization）= 模型在未见数据上的表现——评估的唯一诚实方式：在没见过的数据上考它
规矩

唯一诚实的考场是没见过的数据：留出评估看泛化

🎓 训练集
只用来学：估参数、搜结构都靠它
📝 验证集
模拟考：挑模型、选边数、调超参——参与「做决策」
🏁 测试集
毕业考：全程不能被偷看，只在最后报一次成绩
数据太少切不动 → 交叉验证（Cross-Validation）：每块数据轮流当考场，考完取平均
铁律：任何参与过决策的数据，都不能再给最终成绩签字——17–20 章每个实验都靠这条验收
替代

不留出也行？给似然开一张复杂度罚单——BIC 的直觉

$$\mathrm{BIC}(M)=\underbrace{\mathrm{LL}(M)}_{\text{奖励拟合}}-\underbrace{\frac{k}{2}\,\ln N}_{\text{惩罚复杂}}$$

$k$ = 独立参数个数，$N$ = 样本量——第一项奖拟合，第二项罚复杂，参数越多罚越重

门票直觉：每条新边须用 ½·ln N 的似然增益买门票——N=100 时 ≈ 2.3，N=10000 时 ≈ 4.6；数据越多，奥卡姆剃刀（Occam's Razor）越钝
罚单背后有贝叶斯积分的道理（BIC 是边际似然的大样本近似）——推导细节留给第18章
手算

例1 对决：8.5 的增益 ≫ 2.3 的门票，M₂ 赢得理直气壮

二元 X、Y，N=100，计数 (15, 5, 20, 60)。候选：M₁：X ⊥ Y（无边，k=2） vs M₂：X → Y（一条边，k=3）

① 算拟合：M₁ 用 P(x¹)=0.8、P(y¹)=0.65；M₂ 把 Y 按 X 拆两行：P(y¹|x⁰)=0.25、P(y¹|x¹)=0.75

$$\mathrm{LL}(M_1)=-114.78 \qquad \mathrm{LL}(M_2)=-106.28 \quad(\text{边赚来 } +8.5)$$
$$\text{② 算罚单 }(\tfrac{k}{2}\ln N)\text{：}\; \tfrac{2}{2}\ln 100 \approx 4.61 \quad\text{vs}\quad \tfrac{3}{2}\ln 100 \approx 6.91 \quad(\text{多付 } 2.3)$$
$$\text{③ 判决：}\; \boldsymbol{\mathrm{BIC}(M_1)=-119.39 \;<\; \mathrm{BIC}(M_2)=-113.19 \;\Rightarrow\; \text{加边 } X\to Y}$$
✍️
暂停推导

遮住答案，自己把两个结构的 BIC 各算一遍，说出「拟合赚多少、罚单付多少、净赚还是净亏」。

范式

MLE 全听数据，贝叶斯先收一笔「首付」——细节在第17章

$$\hat{\theta}=\arg\max_{\theta}\, P(D\mid\theta)$$

最大似然估计（Maximum Likelihood Estimation, MLE）
参数是固定未知数，选让数据最可能的

$$P(\theta\mid D)\propto P(D\mid\theta)\,P(\theta)$$

贝叶斯学习（Bayesian Learning）
参数也是随机变量：后验 ∝ 似然 × 先验

🪙 小样本差别最尖锐：3 次全正面 → MLE 宣布 P(正)=1（荒谬但忠于数据）；贝叶斯用先验把它拉向 0.5
先验是数据的「首付」，数据多了就还清——大样本下似然碾压先验，两者合一（Ch17 算到底）
权衡

结构错是重伤，参数歪是轻伤；学结构先会学参数

🩹 结构对、参数歪（轻伤）
定性结论全对：谁影响谁、哪些独立都没错，只是数字不准——多数推理结论依然稳健
🚑 结构错、参数再准也没用（重伤）
缺一条边 = 强行声明假独立；多一条边 = 引入假依赖——模型设定层面的伤，参数再精也补不回来
依赖方向：结构学习把参数学习当内层子程序——每评一个候选结构，先解一次「这个结构下最好的参数」⇒ 第17章是全部学习的地基
避坑

三个雷：训练高分 ≠ 学到，罚项不是拍脑袋，算力救不了结构学习

❌ 训练似然高 = 模型好
✅ 训练似然随复杂度单调上升，「背下训练集」分数最高也最没用；比较模型只看留出数据或带惩罚的评分
❌ BIC 的罚项是拍脑袋的人为偏好
✅ 贝叶斯评分把参数积分掉，复杂结构先验被摊薄、自动受罚——BIC 是对数边际似然的大样本近似，罚单有出处
❌ 结构学习只是搜索量大，算力够就行
✅ 除超指数图空间外，每个候选评分还内嵌一次参数学习；I-等价的图任何数据下同分——原理性不可辨识，算力救不了
接口

本章画地图，第17章拿下最优雅的那一格

本章（Ch16）下一章（Ch17）
任务分类任务 + 立评估规矩左上象限：结构已知 + 完全数据
关键事实四象限地图；训练似然会撒谎对数似然按 CPD 逐行分解，每行独立最大化

小结

三句话讲完第16章

1解决什么：手工建模在参数量与结构未知两处破产 → 模型只能从数据学；本章负责分类 + 立评估规矩
2核心机制：两条轴钉出四象限（17/18/19/20）；MLE 与贝叶斯两范式（小样本看先验、大样本合一）；结构比较靠评分（BIC = 拟合 − 复杂度惩罚）
3承上启下：前 15 章模型已知，本章起模型从数据长出来；Ch17 是地基；评估规矩直通每一章，知识发现的尽头是 Ch21 因果
$$\mathrm{BIC}(M)=\mathrm{LL}(M)-\frac{k}{2}\ln N \quad\text{——合上书也要能默写}$$
本 章 结 束

模型从数据里长出来，分数要从新数据里考出来
