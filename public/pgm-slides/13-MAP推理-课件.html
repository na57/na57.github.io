前面所有章算出分布，本章把分布压成一个答案，后面的章拿答案去行动

主线

任务一换，骨架不变，难度性质彻底改变

1边缘概率不够用：决策只要一个答案 → 任务从 ∑ 换成 max
2max 对乘法也满足分配律 → 消去骨架照搬，但要多记回溯指针
3取对数：连乘变连加 → MAP = 能量最小化，接进组合优化工具箱
4组合优化武器：LP 松弛与图割各守一块可解特例
5账单：MAP 是 NP-hard——一般情形没有多项式通用算法
每一页都是这条链上的一环：定义 → 消去 → 能量 → 难度 → 武器
概念

MAP：不要分布，只要一组「最可能的完整画面」

$$\boldsymbol{\mathrm{MAP}(Y \mid E{=}e) = \arg\max_{y}\, P(Y{=}y \mid E{=}e) = \arg\max_{y}\, P(Y{=}y, E{=}e)}$$

P(E=e) 与 y 无关 ⟹ 归一化常数不影响 arg max；Y = 全部非证据变量时称最可能解释（MPE）

💡 求和推理返回分布（每变量一个边缘）；MAP 返回一组赋值——画面内部的相容性只有联合视角看得见
反例

MAP ≠ 逐变量取最大：(x¹,y¹)=0.30 输给 (x¹,y⁰)=0.36

① 逐变量取最大：P(x¹)=0.66、P(y¹)=0.60 ⟹ (x¹,y¹)，联合只有 0.30

② 联合取最大：四格里最大是 (x¹,y⁰) = 0.36——两个答案真的不同

③ 原因：x¹ 的边缘胜利靠 (x¹,y⁰)+(x¹,y¹) 两格加总；要求「同落一格」时加总优势作废

直觉

边缘回答「平均倾向」，MAP 回答「哪幅完整画面最可信」

边缘推断
每个变量各自倾向什么
= 陪审团投票选「最可疑的个人」
相容性信息被加总抹平
MAP
哪一幅完整画面最可信
= 还原「最可能的完整案情」
各变量取值是否配套，只有联合视角看得见
⚠️ 所以医学诊断不能逐器官下结论、图像分割不能逐像素贴标签——两个任务不可互相代替
机制

Max-Product：∑ 换 max，外加一根「谁赢了」的回溯指针

$$\max_{x}\,[\,f(x)\cdot g\,] = g \cdot \max_{x} f(x) \quad (g \text{ 不含 } x) \quad\text{——分配律的 max 版，消去骨架照搬}$$
$$\boldsymbol{\tau(Y) = \max_{X}\, \varphi(X, Y), \qquad \delta(Y) = \arg\max_{X}\, \varphi(X, Y)} \quad\text{τ 存分数，δ 存赢家}$$
💡 复杂度与 Sum-Product VE 完全一样：O(n·d^{w+1})——但「相同」只是树上的相同，离开树两者命运分岔（13.4 见）

辨析

精确复杂度相同，可近似性天差地别——MAP 没有「部分正确」

❌ 「复杂度一样，所以 MAP 和边缘推断一样难」——那个相同只是精确算法在树上的相同
✅ 边缘推断：大量项加总，采样近似误差随 M 平滑下降（Ch12）
⚠️ MAP：差一位可能全错（无部分正确）；且验证不了「没有更高的」——要扫完指数空间
精确同价、近似天壤之别——这个差距就是下一页 NP-hard 的实质
概念

边缘 MAP：先对陪衬变量求和，再对查询变量取最大

$$\arg\max_{y}\, P(y \mid e) = \arg\max_{y} \sum_{w} P(y, w, e)$$
联合 MAP（MPE）边缘 MAP
查询对象全部非证据变量部分变量 Y，其余 W 是陪衬
需要的算子只有 max（Max-Product 直接给出）∑ 与 max 都要
消去顺序任意顺序均可∑ 变量必须先于 max 变量被消去
⚠️ 根源：max 与 ∑ 不可交换——下一页用数字算给你看
手算

顺序的铁证：先∑后max 得 162，先max后∑ 虚增到 168

$$\max_{x} \sum_{y} f(x,y) \;\le\; \sum_{y} \max_{x} f(x,y) \qquad \text{（等号仅当所有 } y \text{ 的冠军是同一个 } x\text{）}$$

① 正确顺序（先 ∑ 后 max）：每个 y 有 Σ_z φ₂ = 3 ⟹ x=0: 3×(26+28) = 162；x=1: 3×(16+30) = 138 ⟹ 边缘 MAP 为 x=0

② 对照：联合 MAP = (1,1,1)（单格最大 60），其 x 分量 = 1 ⟹ 与边缘 MAP 当场不一致

③ 错误顺序（先 max 后 ∑）：四格冠军各不同（52, 26 归 x=0；30, 60 归 x=1），全收进来 = 168 ≠ 162 ✗ 虚增

⚠️ 结论：∑ 变量必须先于 max 变量消去——顺序选择变少、诱导宽度可能变大，边缘 MAP 更难

换脸

MAP 的三张面孔：Max-Product、Max-Sum、能量最小化

$$\arg\max_{X} P(X) = \arg\max_{X} \sum_{C} \log \psi_C(X_C) = \arg\min_{X} \sum_{C} E_C(X_C) \qquad (E_C = -\log \psi_C)$$
🗣️ Max-Product：乘积上取最大——消息传递用
🗣️ Max-Sum：对数上取最大——防数值下溢，分数更直观
🗣️ 能量最小化：能量越低越可能——组合优化用
✅ log 单调增 ⟹ 不改变 arg max 位置；能量脸把 PGM 接进组合优化几十年工具箱（视觉去噪/分割的标准写法）
账单

NP-hard 的全部直觉：能解 MAP 就能顺手解 3-SAT

flowchart LR S["3-SAT 公式
子句的合取"] --> F["每个子句建一个因子
满足=1，违反=0"]:::hot F --> M{"MAP 分数 > 0 ?"} M -->|"是"| Y["公式可满足"] M -->|"否"| N["不可满足"] classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#c4651f;
$$\text{MAP 分数} > 0 \iff \exists\, \text{满足所有子句的赋值} \iff \text{3-SAT 可满足} \;\Rightarrow\; \text{MAP 至少和 3-SAT 一样难}$$
💡 两难对照：求和的难是「量大」，采样可摊薄；取最大的难是「藏针」——一根针插在指数大的草垛里，不承认差不多找到
武器一

LP 松弛：放松整数约束换上界，整数解即中奖

$$\max \sum_{i}\sum_{x_i} \theta_i(x_i)\,\mu_i(x_i) + \sum_{ij}\sum_{x_i,x_j} \theta_{ij}(x_i,x_j)\,\mu_{ij}(x_i,x_j) \qquad (\theta = \log \psi,\ \mu \in \{0,1\})$$
1ILP：0/1 指示变量 + 线性目标——整数约束是全部难度所在
2LP 松弛：{0,1} → [0,1]，多项式可解，给出 MAP 的上界
3松弛解恰为整数 ⟹ 就是精确 MAP（树上永远如此，松弛「紧」）；否则用切割平面逐步收紧
武器二

图割只在「二元＋成对＋子模」的绿洲里精确

$$\boldsymbol{E_{ij}(0,0) + E_{ij}(1,1) \;\le\; E_{ij}(0,1) + E_{ij}(1,0)} \quad\text{（子模性 = 「一致」比「不一致」便宜）}$$
✅ 三条件齐备（二元＋成对＋子模）⟹ MAP 精确转化为最小割，最大流算法秒解
⚠️ 多标签 → α-Expansion：每轮把「保持 vs 换成 α」编成二元子问题迭代改进（近似，视觉事实标准）
❌ 「图割能解 MAP」——三元以上、高阶项、非子模能量全部失效，退回 LP 松弛 / α-Expansion

避坑

三个高频误解：逐变量取最大、MAP 分量当边缘 MAP、图割万能

❌ 逐变量取边缘最大 = MAP
✅ 2×2 反例：边缘拼出 (x¹,y¹)=0.30，输给联合最可能 (x¹,y⁰)=0.36——加总优势在「同落一格」时作废
❌ 联合 MAP 的 x 分量 = 边缘 MAP
✅ 链例当场翻车：联合 MAP (1,1,1) 分量是 1，边缘 MAP 是 0（162 vs 138）——任务是哪个就解哪个
❌ 图割能解 MAP
✅ 只在「二元＋成对＋子模」同时成立时精确；否则退回 LP 松弛 / α-Expansion 等近似

小结

三句话讲完第13章

1解决什么：分布不够、只要一个答案 → 任务从 ∑ 换成 max，且换完反而更难
2核心机制：分配律 max 版＋回溯指针 → Max-Sum = 能量最小化 → LP 松弛 / 图割各守特例
3承上启下：求和的难是量大、MAP 的难是藏针（NP-hard）；Ch23 决策 = 效用下的 MAP
$$\mathrm{MAP}(Y \mid e) = \arg\max_{y} P(y, e) \;\ne\; \text{逐变量取边缘最大} \quad\text{——本章头条}$$
