本章解决「结果值多少」——前 21 章解决「会发生什么」，Ch23 解决「把两者画进一张图」

主线

概率只说明会发生什么，决策还要说值多少

1反例：治愈率 99% 的方案输给 95% —— 概率最大 ≠ 最优
2缺的是「值多少」：给结果打分需要效用函数，且打分不能拍脑袋
3四条理性偏好公理 ⟹ vNM 定理：理性 = 最大化期望效用
4效用形状 = 风险态度；属性一多，效用也可加性分解
5信息值多少钱也能算：VPI——价值全来自「改变行动」
这条链就是本章的目录：动机反例 → 公理与定理 → 风险态度 → 多属性分解 → 信息定价
动机

治愈率 99% 的方案是错的：概率最大 ≠ 最优

方案痊愈无创伤痊愈有创伤并发症治愈率
甲：保守治疗0.9500.0595%
乙：直接手术00.990.0199%

效用打分：痊愈无创伤 = 100，痊愈有创伤 = 75，并发症 = 40

$$EU(\text{甲}) = 0.95\times100 + 0.05\times40 = \boldsymbol{97}$$
$$EU(\text{乙}) = 0.99\times75 + 0.01\times40 = \boldsymbol{74.65}$$
💡 概率只称量「多可能发生」，决策还要称量「多想要」——4 个百分点的优势，补不回乙的每个成功都打七五折
定义

决策 = 行动集 ＋ 结果概率 ＋ 效用，三样齐了就取期望效用最大

🎯 行动集 $\mathcal{A}$
可选的方案：治 / 不治、甲 / 乙
🎲 $P(x \mid a)$：彩票（Lottery）
每个行动诱导结果上的概率分布——来自前 21 章（含干预）
⚖️ 效用 $U(x)$
每个结果值多少——本章的新零件
$$\boldsymbol{a^{*} = \arg\max_{a}\; EU(a) = \arg\max_{a} \sum_{x} P(x \mid a)\, U(x)} \quad\text{（期望效用最大化 Maximum Expected Utility，MEU）}$$
读法：评委打分 × 出场概率，总分最高者胜出。只有概率是「算命」，只有价值是「许愿」，两者相乘才是决策
公理

打分不拍脑袋：四条朴素公理管住「理性偏好」

公理内容通俗说
完备性（Completeness）任意两个彩票可比较：$L_1 \succ L_2$、$L_2 \succ L_1$ 或一样喜欢不许说「无法比较」
传递性（Transitivity）$L_1 \succ L_2$ 且 $L_2 \succ L_3$ ⟹ $L_1 \succ L_3$偏好不打圈
连续性（Continuity）$A \succ B \succ C$ ⟹ 存在 $p$ 使 $B$ 与 $[p\!:\!A;\, 1{-}p\!:\!C]$ 无差异中间结果能被某个赌局精确替代
独立性（Independence）$L_1 \succ L_2$ ⟹ $[p\!:\!L_1;\,1{-}p\!:\!L_3] \succ [p\!:\!L_2;\,1{-}p\!:\!L_3]$掺入共同部分不影响比较
偏好 $\succ$ 定义在彩票之间：决策被统一抽象成「在彩票之间做选择」，理论才能展开
定理

vNM 定理：满足四公理，理性就等价于最大化期望效用

$$\boldsymbol{A \succ B \;\Longleftrightarrow\; \mathbb{E}_{A}[U] > \mathbb{E}_{B}[U]} \quad\text{（von Neumann–Morgenstern）}$$

且 $U$ 在正仿射变换下唯一：$U' = aU + b\ (a>0)$ 表示完全相同的偏好（期望的线性 ⟹ 所有比较与 argmax 不变）

手算验证$EU(A)$$EU(B)$选择
原效用 $U$0.70.65选 A
$U' = 2U + 10$2×0.7+10 = 11.42×0.65+10 = 11.3仍选 A ✓
像摄氏与华氏：零点单位可平移缩放，「谁压过谁」不变——有意义的只是期望效用之差，不是数值本身
风险态度

期望值 50 万的赌局，多数人 40 万就肯卖——为什么？

$$L = [0.5\!:\ 100\text{万};\ 0.5\!:\ 0], \qquad E[L] = 50 \text{ 万（期望货币值）}$$
📏 确定性等价（Certainty Equivalent，CE）
「和彩票一样好的确定金额」：$U(CE) = \mathbb{E}_{L}[U]$
💸 风险溢价 $= E[L] - CE$
他愿意为免除风险付出的代价
⚠️ 多数人 CE 明显低于 50 万 ⟹ 「期望货币值最大就是最优」也不成立——结果的「原材料」要先过效用这道变换
手算

效用 √x 的探针：CE = 25，风险溢价 = 25

① 期望效用（先开根号再加权）：

$$EU = 0.5\times\sqrt{100} + 0.5\times\sqrt{0} = 0.5\times10 = \boldsymbol{5}$$

② 解 $U(CE) = EU$（确定性等价的定义）：

$$\sqrt{CE} = 5 \;\Longrightarrow\; CE = \boldsymbol{25}\text{（万）}$$
$$\text{风险溢价} = E[L] - CE = 50 - 25 = \boldsymbol{25}\text{（万）} \quad\text{CE < E[L] ⟹ 风险厌恶}$$
✍️

遮住答案：自己写出 EU、解出 CE、算出风险溢价，并说一句 CE 与 E[L] 的大小关系说明了什么。

对比

效用曲线的弯曲方向 = 三种风险性格

风险态度（Risk Attitude）效用曲线形状CE 与 E[L]典型行为
厌恶（凹，如 √x、ln x）增长放缓，边际效用递减$CE < E[L]$买保险、要稳定工资
中性（线性 U=x）直线$CE = E[L]$只看期望值（大公司的近似）
偏好（凸，如 x²）增长加速$CE > E[L]$买彩票、All-in 创业
凹效用的本质是边际效用递减：第一个 50 万改变命运，第二个只是添花——风险厌恶是偏好形状，不是不理性
多属性

属性一多就分解——效用也有自己的「因子分解」

真实结果是向量：治疗 =（生存年数，副作用），offer =（薪资，通勤）——直接评估多元 $U$ 指数级困难

$$\text{加性效用独立（Additive Utility Independence）} \;\Longrightarrow\; \boldsymbol{U(X_1,\dots,X_n) = \sum_i k_i\, U_i(X_i)},\quad \sum_i k_i = 1$$
🧩 $U_i$：单属性效用
各自归一化到 [0,1]，一维评估人人会做
🎚️ 权重 $k_i$：属性间的权衡
主观性没被消除，而是收拢到几个可讨论的旋钮上
与第 3–4 章同一个思想：独立性换可计算性。区别：概率分解出来是乘积，效用分解出来是加权和

VPI

信息也能标价：先知道再决策，比盲选多赚多少

$$\boldsymbol{\mathrm{VPI}(X) = \mathbb{E}_{X}\!\big[\max_{a}\, \mathbb{E}[U \mid X, a]\big] - \max_{a}\, \mathbb{E}[U \mid a]} \quad\text{（完美信息价值 VPI）}$$
📖 第一项：先看 X，按每种情况各选最优（逐项 max）
🙈 第二项：不看 X，被迫全局选一个（统一 max）
完美信息价值（Value of Perfect Information，VPI）两条性质：VPI ≥ 0 恒成立（逐项最优不差于统一最优）；X 与决策无关时 VPI = 0——信息的价值全来自「改变行动」
手算

例4 三步算出：这项检查最多值 4 个效用单位

$P(\text{病}) = 0.6$；效用：病且治 = 80，病不治 = 0，健康且治 = 90，健康不治 = 100

① 无信息最优：$EU(\text{治}) = 0.6{\times}80 + 0.4{\times}90 = \boldsymbol{84}$；$EU(\text{不治}) = 0.6{\times}0 + 0.4{\times}100 = 40$ ⟹ 选治

② 完美信息：有病（0.6）选治拿 80；健康（0.4）改选不治拿 100 ⟹ $\mathbb{E} = 0.6{\times}80 + 0.4{\times}100 = \boldsymbol{88}$

$$\boldsymbol{\mathrm{VPI} = 88 - 84 = 4} \quad\text{来源：} 0.4 \times (100 - 90) = 4 \text{（只有健康分支改了行动）}$$
检查费用折合 ≈3 单位就做，≈6 单位就不做——「信息的价值 = 能让你改主意的那些情形里，改对带来的收益」

避坑

三颗雷：钱、快乐值、信息，都不是目的本身

❌ 期望货币值最大就是最优
✅ 只有 U 对钱线性（风险中性）时成立；U=√x 的人会放弃 E[L]=50 万的赌局、选确定的 40 万
❌ 效用数值是绝对的「快乐值」（97 = 97 份快乐，还能跨人比）
✅ U 只有正仿射意义：有意义的只是期望效用之差；跨人比较在公理体系里没有定义
❌ 信息越多越好，能查就查
✅ 不改变行动的信息 VPI = 0，白送都不用看；且检查费用超过 VPI 就不该查
