动机

1948 年前只有手艺：摩尔斯电码、降速换可靠，极限无人知晓

1948 年以前，「压缩」和「通信」是两类手艺：电报员知道常见字母用短码（摩尔斯电码里 E 是一个点），电话工程师知道线路越吵越要放慢语速。

📦 压缩问题
一个信源产生的数据，最少能用多少比特无差错地表示？
📡 传输问题
一条有噪声的信道，最多能以多快的速率可靠地传信息？
⚠️ 问的不是「怎么设计一个好码」，而是「最好的码能好到什么程度」——别把极限问题当成技巧问题
💡 香农 1948《通信的数学理论》（A Mathematical Theory of Communication）：两个问题的答案惊人地对称
定义

三条常识只放行一种函数：信息量是概率对数的负值

直觉：信息量是意外程度——「明天太阳升起」没有信息量，「明天日食」信息量很大。意外程度由概率决定，且满足三条常识：

  • 单调性：概率越小信息量越大；必然事件（$p=1$）信息量为 0
  • 可加性：两个独立消息的信息量 = 各自信息量之和
  • 连续性：概率微小变化 ⟹ 信息量微小变化
$$\boldsymbol{h(x) = -\log_2 p(x)} \quad \text{单位：比特（bit）——自信息 Self-Information}$$
读法：底数取 2 单位是比特；取 e 叫奈特（nat），只差换算系数 $\log_2 e \approx 1.443$。能同时满足三条常识的函数，仅此一家
例子

确定的事不携带信息：概率 0.9 的消息只值 0.152 比特

消息概率 $p(x)$计算$h(x)$
公平硬币掷出正面$1/2$$-\log_2(1/2)$1 比特
均匀骰子掷出 6$1/6$$-\log_2(1/6)$≈ 2.585 比特
8 张牌等概率抽到指定一张$1/8$$-\log_2(1/8)$3 比特
彩票中头奖$1/10^7$$7\log_2 10$≈ 23.25 比特
明天下雨（当地雨季）$0.9$$-\log_2 0.9$≈ 0.152 比特
可加性演示：掷两次公平硬币（联合概率 $1/4$）信息量 = 2 比特 = 1 + 1，正是两个独立事件之和
例子

短码给常客：每符号 2 比特被变长码压下去

信源每步独立发出 A、B、C、D 之一，概率 $\boldsymbol{p} = (1/2,\ 1/4,\ 1/8,\ 1/8)$：

符号概率方案一：定长码方案二：前缀码
A（常客）$1/2$000
B$1/4$0110
C（稀客）$1/8$10110
D（稀客）$1/8$11111
📏 定长码：每符号恒用 2 比特，平均码长 $L=2$
✂️ 前缀码（Prefix Code）：任何码字都不是另一个码字的前缀 ⟹ 码流无歧义切分
手算

一笔账：0.5 加 0.5 加两个 0.375，平均码长 1.75

① 列式：平均码长 = 每个符号「概率 × 码长」求和：

$$L = \tfrac{1}{2}\times 1 + \tfrac{1}{4}\times 2 + \tfrac{1}{8}\times 3 + \tfrac{1}{8}\times 3$$

② 逐项相乘：

$$L = 0.5 + 0.5 + 0.375 + 0.375$$
$$\boldsymbol{L = 1.75\ \text{比特} \;\lt\; 2\ \text{比特}} \quad\text{——同样的数据，省 } 12.5\%$$
✍️

追问

1.75 不是巧合：熵是压缩的极限，这个码恰好够到它

还能更低吗？香农：不能低于一个只由分布决定的数——这个信源的熵 $H = 1.75$ 比特（Ch2 算出，Ch5 证明是最优下界）。

$$\text{信源编码定理（声明）：} \quad \text{平均码长}\ \boldsymbol{L \geq H}\ \text{，且存在码任意逼近}\ \boldsymbol{H}$$
🎯 刚才的前缀码恰好达到极限——学完 Ch5（香农码、Huffman 码）你能自己造出这种码
⚠️ 注意：单符号编码不一定到 $H$——一般分布要把符号串成块联合编码（Ch5 的缝隙）
信息论回答的不是「怎么设计好码」，而是「最好的码能好到什么程度」——极限本身才是主角
概念

自信息按概率取期望就是熵——第 2 章的全部起点

自信息是一条消息的信息量；信源是无穷多条消息背后的分布。问「平均每条消息给多少信息」，就是对 $h(x)$ 按概率取期望：

$$\boldsymbol{H(X) = \sum_x p(x)\,h(x) = -\sum_x p(x)\log_2 p(x)} \quad\text{——熵（预告，Ch2 严格定义）}$$
把例 1 的分布代进去：$\tfrac12\!\times\!1 + \tfrac14\!\times\!2 + \tfrac18\!\times\!3 + \tfrac18\!\times\!3 = 1.75$ ——平均码长的账和熵的账是同一笔账
直觉：熵 = 描述这个信源平均每符号最少花多少比特
例子

重复三遍：错误率 0.1 降到 0.028，速率只剩三分之一

flowchart LR X["发送比特 0 或 1"] --> C["噪声信道 翻转概率 p = 0.1"] C --> Y["接收比特 0 或 1"] classDef hot fill:#fbeedd,stroke:#c4651f,stroke-width:2.5px,color:#c4651f; class C hot;

朴素办法：重复三遍取多数。出错 ⟺ 3 次里翻错 ≥ 2 次：

$$P_e = 3p^2(1-p) + p^3 = 3\times 0.01\times 0.9 + 0.001 = 0.027 + 0.001 = \boldsymbol{0.028}$$
⚠️ 错误率 0.1 → 0.028，但速率变成原来的 1/3；想错误任意小就得重复任意多次——速率趋向 0
揭晓

香农的断言：0.531 比特/次是这条信道的限速牌

$$\text{二元熵：}H(0.1) = -0.1\log_2 0.1 - 0.9\log_2 0.9 = 0.1\times 3.3219 + 0.9\times 0.1520 = \boldsymbol{0.469}\ \text{比特}$$
$$\boldsymbol{C = 1 - H(0.1) = 0.531\ \text{比特/次}}$$
🐢 重复三遍码
速率 $1/3 \approx 0.333$，错误率只到 $0.028$；再降错误，速率 $\to 0$
🚀 信道编码定理（Ch7）
存在编码：速率接近 $0.531$ 且错误率任意小；超过 $0.531$ 则不可能
噪声吃掉的信息是 $H(Y|X)$，剩下能穿过的最多是 $\max I(X;Y)$——容量也由一个熵式的量给出
主角

全书 17 章，反复出场的只有三个度量

度量记号一句话回答的问题首次登场
熵（Entropy）$H(X)$描述 $X$ 平均需要多少比特？（不确定性的量）Ch2，压缩极限 Ch5
相对熵（Relative Entropy）$D(p\|q)$以为分布是 $q$、实际是 $p$，平均每条消息多付多少比特？Ch2，统计推断 Ch11
互信息（Mutual Information）$I(X;Y)$知道 $Y$ 后，$X$ 的不确定性减少多少比特？Ch2，信道容量 Ch7
三者都不是摆设：压缩极限 $H$、用错分布的代价 $D$、信道容量 $C=\max I$——全书的极限都用它们表达
谱系

三个度量不并列：熵和互信息都是相对熵的化身

1熵是原料：$H(X)$ 度量单个分布的不确定性
2互信息是差：知道 $Y$ 之前的不确定性 − 看完之后剩下的不确定性
3相对熵是发动机：$D(p\|q)$ 是万用扳手，一切不等式由「相对熵非负」推出
$$\boldsymbol{I(X;Y) = H(X) - H(X\,|\,Y) = D\big(p(x,y)\ \big\|\ p(x)p(y)\big)}$$
读法：互信息 = 联合分布与「独立乘积」之间的相对熵——离独立有多远，就共享多少信息
避坑

这一章的错误直觉：三个念头必须当场拧过来

❌ 概率越大，信息量越大
✅ 恰好相反：$h(x)$ 随 $p$ 严格递减，必然事件信息量为 0——信息 = 意外程度
❌ 比特就是一个 0/1 存储位
✅ 比特是信息量单位、成本下限：1.75 比特的信息量完全可能用 2 个物理位来存（码差就得多付）
❌ 相对熵是两个分布的距离
✅ 一般 $D(p\|q) \neq D(q\|p)$，也无三角不等式；读作「用错分布的代价」

小结

三句话讲完第1章

1解决什么：压缩与传输此前只有手艺没有极限 → 信息可用比特度量，极限因此有了答案
2核心机制：自信息 $h(x)=-\log_2 p(x)$（三条常识唯一决定）；熵是其期望，$D$、$I$ 是其派生
3承上启下：本章给地图和口号 → Ch2 钉死定义，Ch3–4 证明熵接管长序列，Ch5、Ch7 兑现承诺
$$\boldsymbol{h(x) = -\log_2 p(x)} \qquad \text{压缩极限} = \boldsymbol{H}, \quad \text{传输极限} = \boldsymbol{C} \quad\text{——合上书也要能默写}$$

信息可度量，极限可计算
