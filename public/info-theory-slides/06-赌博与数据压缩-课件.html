主线

乘积财富逼出对数，对数逼出凯利，凯利的值里站着熵

1赌局重复进行 → 财富是乘积过程，失手一场就按比例缩掉全部身家
2取对数化乘为加 → 大数定律逼出双倍率 W（对数财富的期望）
3最大化 W → 相对熵非负一步得 Kelly 准则 b* = p（按比例下注）
4最优值现身：均匀公平盘下 W** = log m − H(p)——熵直接变成钱
5情报抬升增长率：ΔW = I(X;Y)，互信息就是情报的货币价值
这条链就是本章的目录：乘积过程 → 双倍率 → Kelly → 熵入账 → 边信息定价
动机

平均分押不赚钱、全押热门必破产——两个极端都死了

赛马模型：每场结果 $X \in \{1,\dots,m\}$ 按 $p$ 独立产生；全部财产按 $b=(b_1,\dots,b_m)$ 分押（$b_i \ge 0,\ \sum b_i = 1$）；押中 $i$ 号，那一份钱变 $o_i$ 倍，其余全输光。

$$\text{掷币赛（本章主例）}：m=2,\quad p=\big(\tfrac{3}{4},\tfrac{1}{4}\big),\quad o=(2,2)$$
😇 策略一：平均分押 $b=(\tfrac12,\tfrac12)$
无论谁赢倍率恒为 1 —— 稳健，但一分不赚
😈 策略二：全押热门 $b=(1,0)$
期望财富 $1.5^n$ —— 激进，但冷门爆冷一次就归零
💡 两个极端都死了 ⟹ 中间的 $b$ 值得优化：这正是本章的优化问题
定义

财富是乘积过程，双倍率 W 是它的指数增长率

💰 财富过程：每场财富变为 $b(X_i)\,o(X_i)$ 倍，只有押中那份钱活回来
📈 取对数：乘积变求和，大数定律把长期行为逼成期望
$$S_n = \prod_{i=1}^{n} b(X_i)\,o(X_i), \qquad \tfrac{1}{n}\log_2 S_n = \tfrac{1}{n}\sum_{i=1}^n \log_2 b(X_i)o(X_i) \longrightarrow \mathbb{E}\big[\log_2 b(X)o(X)\big]$$
$$\boldsymbol{W(b,p) = \sum_{i=1}^{m} p_i \log_2(b_i\,o_i)}, \qquad S_n \approx 2^{\,nW}$$
读法：W 每场大 1 比特，财富翻一倍；W = 0 原地踏步；W < 0 指数衰减走向破产——所以叫「双倍率（Doubling Rate）」
重点

乘积过程里，几乎必然的事由 E log 决定，不由 E 决定

$$\text{全押热门：}\ \mathbb{E}[S_n] = \big(\tfrac{3}{4}\cdot 2\big)^n = 1.5^n \ \text{（期望爆炸）}\quad\text{但}\quad W = -\infty \ \text{（路径必死）}$$
🧮 算术平均 $\mathbb{E}$
被概率指数衰减 $(\tfrac34)^n \to 0$ 的极端路径绑架
📐 几何平均 $\mathbb{E}\log$
乘积过程的真正「平均」——你只走一条路径
对数给风险定价：$\log 0 = -\infty$ 给「破产」判无期徒刑；$\log$ 增长放缓，逼你在热门与冷门之间保持分散
手算

掷币赛两种直觉策略：W = 0 与 W = −∞

$$\text{平均分押 } b=(\tfrac12,\tfrac12)：\quad W = \tfrac{3}{4}\log_2\big(\tfrac{1}{2}\cdot 2\big) + \tfrac{1}{4}\log_2\big(\tfrac{1}{2}\cdot 2\big) = \tfrac34\cdot 0 + \tfrac14\cdot 0 = \boldsymbol{0}$$
$$\text{全押热门 } b=(1,0)：\quad W = \tfrac{3}{4}\log_2(1\cdot 2) + \tfrac{1}{4}\log_2(0\cdot 2) = \tfrac{3}{4} + \tfrac{1}{4}\cdot(-\infty) = \boldsymbol{-\infty}$$
⚠️ $W=-\infty$ 不是修辞：冷门每场概率 $\tfrac14$，$n$ 场至少出现一次的概率 $\to 1$；乘积过程里 0 是吸收壁，进去就出不来
推导

相对熵非负一步证出 b* = p，偏离代价恰为 D(p‖b)

① 拆开 W：对数里乘积变求和，赔率项与 $b$ 无关：

$$W(b,p) = \underbrace{\sum_i p_i \log_2 b_i}_{\text{要优化的部分}} + \underbrace{\sum_i p_i \log_2 o_i}_{\text{常数}}$$

② 相对熵非负（第2章旧工具 $D(p\|q)\ge 0$，等号 ⟺ $p=q$）：

$$D(p\|b) = \sum_i p_i \log_2\frac{p_i}{b_i} \ge 0 \;\;\Longrightarrow\;\; \sum_i p_i\log_2 b_i \le \sum_i p_i \log_2 p_i$$
$$\text{Kelly 准则：}\ \boldsymbol{b^* = p} \quad\text{且}\quad \boldsymbol{W(b^*,p) - W(b,p) = D(p\|b) \ge 0}$$

定理

均匀公平盘下熵直接变成钱：W** = log m − H(p)

⚖️ 公平赔率（Fair Odds）
$\sum_i \frac{1}{o_i} = 1$，庄家不抽水
🎲 均匀公平赔率
$o_i = m$：庄家按「每匹马等可能」开盘
$$W^{**} = \sum_i p_i \log_2(p_i \cdot m) = \log_2 m + \sum_i p_i \log_2 p_i = \boldsymbol{\log_2 m - H(p)}$$
读法：赛果每多 1 比特不确定性，赌客每场少赚 1 比特增长率；$p$ 均匀时 $H=\log_2 m$，$W^{**}=0$——真正不可预测的赛果谁都赚不到钱
手算

4 马赛验证：W** = log₂4 − 1.75 = 0.25 比特/场

马 $i$$p_i = b^*_i$中 $i$ 的倍率 $b^*_i o_i$$\log_2(\text{倍率})$贡献 $p_i\log_2$
1 号1/2211/2
2 号1/4100
3 号1/81/2−1−1/8
4 号1/81/2−1−1/8
$$p=\big(\tfrac12,\tfrac14,\tfrac18,\tfrac18\big),\ o_i=4：\quad W^{**} = \tfrac12 - \tfrac18 - \tfrac18 = \boldsymbol{0.25}\ \text{比特/场} \;=\; \log_2 4 - 1.75\ \checkmark$$
财富每场几何增长 $2^{0.25} \approx 1.19$ 倍；同一个 $H=1.75$，第5章是「省下的码长」，本章是「赚到的增长率」
定理

一条情报的货币价值恰好等于互信息：ΔW = I(X;Y)

🎫 有情报时的最优策略
条件版 Kelly：看到 $Y=y$ 就按条件分布下注 $b(x|y) = p(x|y)$
💵 情报的牌价
1 比特互信息 = 每场多赚 1 比特增长率 = 财富增速翻倍
$$\Delta W = \sum_{x,y} p(x,y)\,\log_2\frac{p(x|y)}{p(x)} = \boldsymbol{I(X;Y)}$$
读法：互信息就是情报的货币价值；与赛果独立的消息 $I=0$，内容再惊人也一文不值
手算

完全情报值 0.811 比特/场：ΔW = h(3/4)，两种算法吻合

$$\text{有情报：每场全押赢家，倍率恒为 }2：\quad W_{\text{with}} = \sum_i p_i \log_2(1\cdot 2) = \boldsymbol{1}\ \text{比特/场},\quad S_n = 2^n$$
$$\Delta W = W_{\text{with}} - W^* = 1 - 0.1887 = \boldsymbol{0.8113} \approx 0.811\ \text{比特/场}$$
$$\text{定理验证：}\ I(X;Y) = H(X) = H\big(\tfrac34\big) = \tfrac34\cdot 0.4150 + \tfrac14\cdot 2 = 0.3113 + 0.5000 = \boldsymbol{0.8113}\ \checkmark$$
财富曲线从 $1.14^n$ 提到 $2^n$——这条情报让增长率翻了 5 倍多
推广

把「马」换成「股票」，Kelly 就变成对数最优组合

赛马（本章）股市（第16章）
每场赛果 $X$市场每日状态
赔率向量 $o$各股票的相对收益
投注比例 $b$资产组合权重
Kelly $b^*=p$，最大化 $\mathbb{E}\log$对数最优组合（Log-Optimal Portfolio）：固定比例、每期再平衡
赛马里的每个结论，把名词换掉就是组合投资的结论——凯利准则是对数最优组合的离散原型

避坑

三个错误直觉：全押、公平盘没钱赚、情报越多越好

❌ 期望收益为正就值得全押
✅ 期望被概率 $\to 0$ 的极端路径绑架；几乎必然发生的事由 $\mathbb{E}\log$ 决定——全押以概率 1 破产
❌ 公平赔率下没人能赚钱
✅ 只有庄家的盘与真实分布吻合时 $W^{**}=0$；盘按错分布开（如均匀盘对偏斜 $p$），Kelly 赌客稳定抽水，速率 = 两个分布「差出来的熵」
❌ 情报越多越值钱
✅ 只有与赛果相关的情报才值钱；$Y$ 与 $X$ 独立时 $I(X;Y)=0$，$\Delta W = 0$，内容再惊人也一文不值
接口

本章的情报是白送的；穿过噪声还剩多少价值——那是第7章

本章（Ch6）下一章（Ch7 信道容量）
信息怎么来情报 $Y$ 免费递到手上信息要穿过噪声信道
核心问题这条情报值多少钱：$\Delta W = I(X;Y)$信道最多能传多少互信息：$C = \max I(X;Y)$
互信息的角色情报定价的牌价被推上主角：信道能力的度量
钩子：另一笔欠账——分布 $p$ 未知时能否边赌边学？那是第13章通用编码的地盘
小结

三句话讲完第6章

1解决什么：重复赌局的长期最优投注策略，及它的财富增长率由什么决定
2核心机制：乘积取对数化乘为加，大数定律逼出双倍率 $W$；相对熵非负给出 $b^*=p$，偏离代价 $D(p\|b)$；熵与互信息直接入账
3承上启下：Ch5 是熵这本账的正面，本章是另一面；Ch7 问信息穿过噪声还剩多少——信道容量
$$\boldsymbol{b^* = p}, \qquad \boldsymbol{W^{**} = \log_2 m - H(p)}, \qquad \boldsymbol{\Delta W = I(X;Y)} \quad\text{——合上书也要能默写}$$
本 章 结 束
