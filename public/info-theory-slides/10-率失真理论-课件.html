第5章钉死无损极限 H，第9章给出信道那头 C —— 本章回答信源这头的 R(D)

主线

无损走到头，只剩一条路：给失真标价，拿它换比特

1无损被 H 锁死；连续信源精确表示要无穷比特 → 必须允许失真
2给误差明码标价：失真度量 $d(x,\hat{x})$
3压缩方案抽象为试验信道，最小化互信息 → 率失真函数 R(D)
4两个闭式解：Bernoulli 得 $1-H_2(D)$，高斯得 $\frac12\log(\sigma^2/D)$
5分离定理：R(D) ≤ C ⟺ 失真 D 可达，信源信道两头缝合成完整链路
这条链就是本章的目录：动机 → 定义 → 两个闭式解 → 与信道容量会师
动机

连续信源的「无损压缩」在数学上不存在

取 $X \sim U[0,1]$，写成二进制小数 $0.b_1b_2b_3\dots$：

♾️ 精确表示 = 无限长比特串
任何有限比特的表示只对应一个区间，不是一个点 → 精确表示需要无穷多比特
⚠️ 微分熵有限 ≠ 信息量有限
$h(X)=\log 1 = 0$ 有限，但微分熵（Differential Entropy）不是表示 X 所需的比特数（第8章的警告）
问题必须改写：不问「最少多少比特精确表示」，而问「最少多少比特表示到误差不超过 D」
动机

坚持无损 = 为人感知不到的差别付比特

语音、图像、视频：人耳分不清 16 bit 与 15 bit 量化，人眼看不出相邻灰度 1 级的变化——MP3、JPEG 早已是现实

$$\textbf{中心结论：存在只由信源与失真度量决定的函数 } \boldsymbol{R(D)}\ \text{：失真}\le D\text{ 的方案码率} \ge R(D)\text{，且可任意接近}$$
💡 统一图景：无损是 D=0 的特例——离散信源 R(0)=H(X)（回到第5章），连续信源 R(0)=∞；R(D) 与 H、C 同级，是定理级极限
定义

失真度量：给每种误差明码标价

失真度量定义期望失真的含义
汉明失真（Hamming）$d(x,\hat{x}) = \mathbb{1}\{x \ne \hat{x}\}$错误概率 $\Pr(X \ne \hat{X})$
平方误差（Squared Error）$d(x,\hat{x}) = (x-\hat{x})^2$均方误差 $E[(X-\hat{X})^2]$
$$\text{序列失真按坐标平均：}\quad d(x^n,\hat{x}^n) = \frac{1}{n}\sum_{i=1}^{n} d(x_i,\hat{x}_i)$$
⚠️ 失真度量由应用选定，不是数学内生的——选错度量，优化得再准也答错了问题
定义

率失真函数：在所有假想「信道」上取最小互信息

🎛️ 试验信道（Test Channel）
条件分布 $p(\hat{x}|x)$：假装信源过了一道我们自选的「信道」，输出就是重建——它是优化变量，不是真实硬件
🎯 为什么最小化互信息
$I(X;\hat{X})$ 度量重建必须携带多少关于信源的信息——越小，描述 $\hat{X}$ 所需比特越少
$$\boldsymbol{R(D) = \min_{p(\hat{x}|x)\,:\; E[d(X,\hat{X})] \,\le\, D} I(X;\hat{X})}$$
读法：在所有满足失真预算 E[d] ≤ D 的试验信道中，找互信息最小的那个；D 只出现在约束里
性质

R(D) 的形状：非负、单调不增、凸——一条折扣曲线

1非负：$I(X;\hat{X}) \ge 0 \Rightarrow R(D) \ge 0$
2单调不增：D 只在约束里，预算放松 ⟹ 可行集变大 ⟹ 最小值不会变大
3凸：$I$ 对 $p(\hat{x}|x)$ 是凸函数，两可行信道混合仍可行且不超限，取下确界保持凸性
端点印证：Bernoulli 信源 $D \ge \tfrac12$ 时 $R(D)=0$——不看任何信息、恒输出 0，期望错误率恰好 1/2，一个比特都不用发
推导

Bernoulli(½)+汉明：任何方案都不低于 1 − H₂(D)

汉明失真下 $E[d] = \Pr(X \ne \hat{X}) \le D$，记错误比特 $E = X \oplus \hat{X}$：

$$I(X;\hat{X}) = \underbrace{H(X)}_{=\,1} - H(X|\hat{X}) = 1 - H(X\oplus\hat{X}\,|\,\hat{X}) \ge 1 - H(X\oplus\hat{X})$$
$$\boldsymbol{\ge\; 1 - H_2\big(\Pr(X\ne\hat{X})\big) \;\ge\; 1 - H_2(D)}$$
三步老工具：① 条件不增熵 $H(E|\hat{X}) \le H(E)$　② 错误比特的熵 = $H_2(\Pr(X\ne\hat{X}))$　③ $H_2(p)$ 在 $[0,\tfrac12]$ 单调增
推导

最优试验信道 = 一道以概率 D 翻转的二元对称信道

构造：$\hat{X}\sim\mathrm{Bern}(\tfrac12)$，$Z\sim\mathrm{Bern}(D)$ 独立，$X = \hat{X}\oplus Z$。验证三件事：

  • 失真对：$\Pr(X\ne\hat{X}) = \Pr(Z=1) = D$，顶满预算 ✓
  • 边缘对：对称信道保持均匀分布，$X\sim\mathrm{Bern}(\tfrac12)$ ✓
  • 互信息对：$I = H(X)-H(Z) = 1-H_2(D)$，等于下界 ✓
R(D) 曲线上每一点背后都站着一条最优试验信道——同时给出极限值与原则上的实现方式
手算

允许 10% 错误：每样本只需 0.531 bit，省下近一半

① 写定义：二元熵

$$H_2(p) = -p\log_2 p - (1-p)\log_2(1-p)$$

② 代入 D = 0.1（$\log_2 0.1 \approx -3.3219$，$\log_2 0.9 \approx -0.1520$）：

$$H_2(0.1) = -0.1\times(-3.3219) - 0.9\times(-0.1520) = 0.3322 + 0.1368 = \boldsymbol{0.4690}\ \text{bit}$$
$$\boldsymbol{R(0.1) = 1 - H_2(0.1) = 1 - 0.4690 = 0.531\ \text{bit/样本}}$$
✍️
暂停推导

遮住答案，自己把 H₂(0.1) 与 R(0.1) 各算一遍，再说出「0.531 比无损省了多少」。

定理

高斯信源 + 平方误差：唯一有漂亮闭式解的连续情形

$$X \sim \mathcal{N}(0,\sigma^2),\ \text{平方误差：}\quad \boldsymbol{R(D) = \frac12\log_2\frac{\sigma^2}{D}}\quad(0 \lt D \le \sigma^2)$$
🆓 D ≥ σ² 时 R(D) = 0
直接重建为均值 0，失真即方差 σ²，已满足预算——一个比特都不用花
♾️ D → 0 时 R(D) → ∞
连续信源的「无损」在数学上不存在：不是工程做不到，极限本身就是 ∞
语音 / 图像编码实践中最常用的基准近似——这条曲线就是所有有损编码器的「汇率表」
推导

下界四步：平移不变 → 条件不增熵 → 高斯熵最大 → 用足预算

$$I(X;\hat{X}) = h(X) - h(X-\hat{X}\,|\,\hat{X}) \;\ge\; h(X) - h(X-\hat{X}) \quad\text{（平移不变 + 条件不增熵）}$$
$$\ge\; \frac12\log(2\pi e\,\sigma^2) - \frac12\log\big(2\pi e\, E[(X-\hat{X})^2]\big) \quad\text{（给定方差，高斯微分熵最大）}$$
$$\ge\; \frac12\log(2\pi e\,\sigma^2) - \frac12\log(2\pi e\,D) \;=\; \boldsymbol{\frac12\log\frac{\sigma^2}{D}} \quad\text{（预算 }E[(X-\hat{X})^2]\le D\text{）}$$
关键在第三步：第8章「方差固定时高斯熵最大」把被减的项控制在最小——下界因此干净
推导

反向试验信道：先造好成品再配原料，三件事一眼可验

$$\text{反向写法：}\quad X = \hat{X} + Z,\qquad \hat{X}\sim\mathcal{N}(0,\sigma^2-D),\ \ Z\sim\mathcal{N}(0,D),\ \ \text{二者独立}$$
  1. 边缘对：独立高斯方差可加，$\mathrm{Var}(X) = (\sigma^2-D)+D = \sigma^2$ ✓
  2. 失真对：$E[(X-\hat{X})^2] = E[Z^2] = D$，恰好顶满预算 ✓
  3. 互信息对：$I = h(X) - h(Z) = \frac12\log(2\pi e\sigma^2) - \frac12\log(2\pi e D) = \frac12\log(\sigma^2/D)$，等于下界 ✓
⚠️ 叫「反向」是因为正向看这是 $\hat{X}\to X$ 的加噪信道——它是可达性的数学道具，不代表编码器真这么连
数值

σ²=4：D 每除以 2，码率多花 0.5 bit

Dσ²/DR(D) = ½log₂(σ²/D)
14½ × 2 = 1 bit
0.2516½ × 4 = 2 bit
规律：失真缩到 1/4，码率多花 1 bit——这条斜率是所有有损编码器的「汇率表」
与第9章同构：σ²/D 是「信源功率 / 失真功率」，P/N 是「信号功率 / 噪声功率」——同一个 ½log 结构
对偶

容量是信道的计价，率失真是信源的标价

信道容量 C率失真 R(D)
定义$C = \max_{p(x)} I(X;Y)$$R(D) = \min_{p(\hat{x}|x)} I(X;\hat{X})$
固定什么信道 $p(y|x)$信源 $p(x)$
优化什么选输入分布 $p(x)$选试验信道 $p(\hat{x}|x)$
回答这条信道最多能传多少这个信源最少要多少比特
通信可行的条件一句话：标价不超过计价，$R(D) \le C$——两个独立优化问题，只用这条不等式缝合
定理

分离定理：R(D) ≤ C ⟺ 失真 D 可达，两段分开设计即最优

$$\text{信源信道分离定理：}\quad \text{失真 } D \text{ 可达} \iff \boldsymbol{R(D) \le C}$$
比特是通用货币：信源编码器只认识 R(D)，信道编码器只认识 C——两拨人独立设计，拼起来端到端最优
例子

高斯信源过高斯信道：D_min = σ²·2⁻²ᶜ = 1/16

信源 $X\sim\mathcal{N}(0,1)$；AWGN 信道 $P/N = 15$（第9章已算）：

$$C = \frac12\log_2(1+P/N) = \frac12\log_2 16 = \boldsymbol{2\ \text{bit/次}}$$
$$R(D)\le C:\ \frac12\log_2\frac{1}{D}\le 2 \;\Longrightarrow\; D_{\min} = \sigma^2\cdot 2^{-2C} = 1\times 2^{-4} = \boldsymbol{\frac{1}{16} = 0.0625}$$
惊人之处：高斯对高斯，逐样本标量量化、逐符号用信道即达界——无失配最优的幸运配对；一般情形靠长码字逼近，但「两段分开」的架构依然最优
避坑

三个错误直觉：丢信息、怕分离、方向记反

❌ 「有失真就是随便丢信息」
✅ R(D) 是定理级极限：码率低于 R(D) 而失真不超 D 的方案不存在，与创意无关——正如容量之上无可靠通信
❌ 「分离设计会损失性能」，端到端联合优化一定更强
✅ 分离定理说「分开设计不损失最优性」——是许可不是强制（但两段都必须各自逼近极限）
❌ 「失真越大需要的比特越多」（把 R(D) 当增函数）
✅ 恰好相反：D 在约束里，预算越松可行集越大，R(D) 单调不增；D 足够大时 R(D)=0
接口

两个闭式解是幸运儿：一般信源的账，第11章来收

✅ 本章结清
Bernoulli：$R(D)=1-H_2(D)$
高斯：$R(D)=\frac12\log(\sigma^2/D)$
分离定理：$R(D)\le C$ 缝合成完整链路
📋 欠下的账（→ 第11章）
一般信源无闭式解；「失真事件概率随码长指数衰减多快」需要方法型（Method of Types）与 Sanov 定理
钩子：罕见事件的概率由相对熵精确刻画——第2章的老朋友，到第11章变成主角
小结

三句话讲完第10章

1解决什么：允许平均失真 D 时，描述信源最少要多少比特/样本——无损只是 D=0 的特例
2核心机制：试验信道上最小化互信息得 R(D)；Bernoulli 得 $1-H_2(D)$，高斯得 $\frac12\log(\sigma^2/D)$，可达性三步验证
3承上启下：H（第5章）＋ C（第9章）＋ R(D)（本章），分离定理缝合成链；无闭式解的账 → 第11章
$$R(D) = \min_{E[d]\le D} I(X;\hat{X}) \qquad \text{失真 }D\text{ 可达} \iff R(D) \le C \quad\text{——合上书也要能默写}$$
