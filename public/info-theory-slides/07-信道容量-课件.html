主线

本章主线：从「噪声吃掉多少」问到「C 可达又不可达」

动机

重复码用速率归零换可靠——香农说速率可以是正的

第1章的旧账：翻转概率 0.1 的二元信道，怎么抗噪？

🔁 重复码（朴素办法）
重复 3 遍取多数：错误率降到 0.028，速率只剩 1/3
重复 k 次：速率 1/k → 0——可靠是拿速率换的
🚀 香农声称（1948）
同一条信道：以 0.531 比特/次的正速率做到错误任意小
不靠重复，靠把码字拉长 n → ∞
矛盾摆在这：重复码「速率归零换可靠」，香农说「速率保持为正」——本章就是把这个声称证出来
定义

容量 C = max I(X;Y)：输入分布调到最优后，每次最多穿过的比特数

flowchart LR X["输入 X
离散字母表 𝒳"] --> CH["离散无记忆信道 DMC
转移矩阵 p(y|x)"] CH --> Y["输出 Y
离散字母表 𝒴"]
「无记忆」：每次使用的输出只由当次输入决定——信道的全部脾气都在 p(y|x) 这张表里
$$I(X;Y)=\underbrace{H(Y)}_{\text{输出总不确定性}}-\underbrace{H(Y|X)}_{\text{噪声自造的抖动}}$$
$$\boldsymbol{C=\max_{p(x)} I(X;Y)}\ \ \text{比特/次}$$
max 对输入分布取：信道调不了，p(x) 可以调；I 关于 p(x) 是凹函数，最大值必存在。C 只由 p(y|x) 决定，是信道属性
信道

BSC 的脾气全在一个数 p 里：对称性决定最优输入

flowchart LR X0["发 0"] -- "1−p" --> Y0["收 0"] X0 -- "p" --> Y1["收 1"] X1["发 1"] -- "p" --> Y0 X1 -- "1−p" --> Y1

二元对称信道 BSC(p)：两条交叉边是出错路径

  • 输入输出都是 {0,1}：以概率 p 被悄悄翻转，以 1−p 原样到达
  • 对称：对换 0 与 1 的角色，信道行为完全不变 ⟹ 最优输入将是均匀分布
  • p = 0：无噪声，每次恰好传 1 比特（$C=1$，定义校准通过）
p = 1/2 时输出与输入统计独立，信道彻底报废，C = 0
推导

无论发什么噪声都吃掉 H(p)：C = 1 − H(p)

$$\text{第一步：}\ H(Y|X)=p(0)\,H(p)+p(1)\,H(p)=H(p)\quad\text{（与输入分布无关）}$$
$$\text{第二步：}\ H(Y)\le 1,\ \text{输入均匀} \Rightarrow P(Y{=}0)=\tfrac12(1{-}p)+\tfrac12 p=\tfrac12\ \Rightarrow\ \text{等号达到}$$
$$\boldsymbol{C=\max_{p(x)} I(X;Y)=1-H(p)}\quad\text{（BSC 的容量）}$$
读法：每用一次信道，噪声固定吃掉 H(p) 比特，剩下 1 − H(p) 才是你的
手算

p = 0.11：噪声恰好吃掉一半容量

① 写二元熵（$\log_2\frac{1}{0.11}=3.1844$，$\log_2\frac{1}{0.89}=0.1681$ 已查好）：

$$H(0.11)=0.11\log_2\tfrac{1}{0.11}+0.89\log_2\tfrac{1}{0.89}$$

② 代入求和：

$$H(0.11)=0.11\times3.1844+0.89\times0.1681=0.3503+0.1496=0.4999\approx\boldsymbol{0.5}\text{ 比特}$$
$$\boldsymbol{C=1-H(0.11)\approx 1-0.5=0.5\ \text{比特/次}}\quad\text{（噪声吃掉恰好一半）}$$
✍️
暂停推导

遮住答案，自己把 H(0.11) 的两项乘法和求和完整算一遍，再减去它得到 C。

信道

BEC 是「明说丢了」：C = 1 − α

flowchart LR X0["发 0"] -- "1−α" --> Y0["收 0"] X0 -- "α" --> YE["收 e（被擦除）"] X1["发 1"] -- "α" --> YE X1 -- "1−α" --> Y1["收 1"]
与 BSC 的本质区别：收方知道这一位丢了（类比网络丢包），不是被悄悄改错

换条展开式更顺手：$I(X;Y)=H(X)-H(X|Y)$（谁好算用谁）

$$H(X|Y)=(1{-}\alpha)\cdot0+\alpha\cdot H(X)=\alpha H(X)$$

Y=0,1 时 X 确定（条件熵 0）；Y=e 时全未知（条件熵 H(X)）

$$\boldsymbol{C=\max_{p(x)}(1-\alpha)H(X)=1-\alpha}$$

输入均匀，H(X)=1 时达到

数值：α = 0.25 ⟹ C = 0.75 比特/次

对比

三条信道一张表：擦除是线性惩罚，翻转是非线性惩罚

信道噪声方式容量 C最优输入直觉
无噪声二元信道无（Y = X）1均匀每次恰好一比特
BSC(p)以 p 悄悄翻转1 − H(p)均匀翻转的不确定性 H(p) 被吃掉
BEC(α)以 α 擦除为 e1 − α均匀擦除比例线性缩减
💡 擦除 vs 翻转：BEC 按可用比例线性缩减（α=0.25 保住 3/4）；BSC 的惩罚是非线性的 H(p)，p=0.11 就吃掉一半——翻转的错会混在正确比特里骗人
同样是噪声：「明说丢了」远比「悄悄搞错」仁慈
可达

香农的绝招：不构造好码，证明随机抽一个几乎必然是好码

1随机编码：速率 R、用 n 次信道 ⟹ 2ⁿᴿ 个消息；码本每行一个长 n 码字，每个符号独立按最优 p(x) 抽取
2联合典型译码：收到 yⁿ，在码本中找唯一与之联合典型的码字，找到就译，否则报错
3错误分析：两类错误都被按住（下一页细账），R < C 时错误率随 n 指数归零
💡 类比：往高维空间撒点——典型序列约 2ⁿᴴ⁽ˣ⁾ 条、输出端能区分的「桶」约 2ⁿᴴ⁽ʸ⁾ 个；撒的点远少于桶时，点距自动拉开，空旷白送距离
对比重复码：速率 1/n → 0 换可靠；随机码速率保持 R，靠码长 n 换错误率指数下降
分析

只要 R < C，错误率随码长指数归零

  • 错误一：正确码字不联合典型 —— 由 AEP（Ch3），联合典型概率随 n → 1，此类错误 → 0
  • 错误二：错误码字撞上联合典型 —— 独立抽取恰好联合典型的概率 ≈ 2−nI，竞争者 2nR − 1 个，联合界：
$$P_e \lesssim 2^{nR}\cdot 2^{-nI(X;Y)} = 2^{\,n(R-I(X;Y))}\ \xrightarrow{R\lt I}\ 0\ \text{（指数归零）}$$
$$\text{量级：}\ n=1000,\ R-C=-0.1\ \Rightarrow\ P_e\sim 2^{-100}\approx 10^{-30}$$
最后一步很香农：随机码的平均错误率都这么小 ⟹ 至少存在一本具体的好码——虽然我们不知道它长什么样（存在性证明）
逆定理

Fano 不等式：猜得越错，剩下的疑问越大

$$H(X|\hat{Y})\le 1+P_e\log|\mathcal{X}|\quad\Rightarrow\quad H(W|\hat{W})\le 1+P_e\log M$$

推导骨架（E 为错误指示，E=1 当 Ŵ ≠ W）：

  • 一路：知道 W 和 Ŵ 就知道 E ⟹ $H(E,W|\hat{W})=H(W|\hat{W})$（E 免费附带）
  • 另一路：链式法则 $H(E|\hat{W})+H(W|\hat{W},E)\le 1+P_e\log M$（E=1 时 W 至多在 M 个值里，按 P_e 加权）
读法：猜错后剩下的疑问 =「错没错」1 比特 ＋「在 M 个候选里挑错项」log M 比特（按 P_e 加权）
逆定理

三环一扣：nR ≤ nC + nεₙ，任何方案都超不过 C

$$nR=H(W)=I(W;Y^n)+H(W|Y^n)\ \le\ I(X^n;Y^n)+n\varepsilon_n\ \le\ nC+n\varepsilon_n$$
1W 在 2ⁿᴿ 个消息上等概：H(W)=nR；熵分解 I ＋ H(·|·)（Ch2）
2Fano 压出 H(W|Yⁿ) ≤ nεₙ；W→Xⁿ→Yⁿ 马尔可夫链，数据处理不等式：I(W;Yⁿ) ≤ I(Xⁿ;Yⁿ)
3无记忆性：I(Xⁿ;Yⁿ) ≤ Σᵢ I(Xᵢ;Yᵢ) ≤ nC——n 次使用不互相创造信息
除以 n、令 εₙ → 0：R ≤ C，焊死。没分析任何具体方案，熵分解＋Fano＋数据处理三条普适原理把所有方案一网打尽
加深

反馈不增加容量，但能买到简单

$$\text{反馈不增容（DMC）：}\quad \boldsymbol{C_{FB}=C}$$

证明要点：无记忆性使 $I(W;Y^n)\le\sum_i I(X_i;Y_i)\le nC$ 在反馈下依然成立——反馈改变不了单次使用的互信息上限

📞 反馈真正的价值＝降低复杂度：BEC(α) 上「被擦除就重发」，平均每比特用 1/(1−α) 次信道，速率恰好 1−α = C，连编码都不用
⚠️ 边界：结论只对无记忆信道成立；有记忆信道（突发、衰落）可借反馈探测信道状态，容量严格增大
加深

分离定理：压缩与信道编码各干各的，合起来仍最优

🧱 信源信道分离定理：速率匹配（信源每秒产生的 H ≤ 信道每秒可用的 C）时，「先用 Ch5 压到 H、再按本章以 C 编码」两段各自独立最优，合起来即整体最优——联合一体化设计也超不过这个组合
💡 为什么是架构基石：压缩工程师逼近 H，通信工程师逼近 C，两层之间只传干净比特流，互不打扰——JPEG 压缩 ＋ 5G 的 LDPC/Polar 信道码就是这样各干各的
整条数字通信分层架构的理论许可，就是这条「分离不亏」；它也解释了为什么 Ch5 与本章可以分开学
避坑

三个高频误解，一次扫清

❌ 容量＝当前方案的实际速率
✅ C 是对所有输入分布取最大后的理论上限，只由 p(y|x) 决定。重复码在 BSC(0.11) 上速率只有 0.2，远低于 C；任何方案也不可能稳定超过 C
❌ p > 1/2 的 BSC 是废信道
✅ 收方把输出全部翻转即等效 BSC(1−p)，容量 1 − H(p) 仍为正；真正报废的是 p = 1/2（输出与输入独立，C = 0）
❌ 随机码是工程方案
✅ 它是存在性证明：码本指数级存储、逐条比对无法实现。工程上逼近 C 的是 LDPC 与 Polar 码——香农给地图，后人修公路

小结

三句话讲完第7章

1解决什么：有噪声信道可靠传输的速率极限 = C = max I(X;Y)——噪声吃掉 H(Y|X)，最优输入下剩下的就是容量
2核心机制：可达靠随机码＋联合典型译码（错误率 ≈ 2ⁿ⁽ᴿ⁻ᶜ⁾ → 0）；不可达靠 Fano＋数据处理把 nR ≤ nC + nεₙ 焊死
3承上启下：Ch5 兑现 H，本章兑现 C，分离定理焊成分层架构；连续世界待 Ch8 微分熵、Ch9 高斯信道
$$\boldsymbol{C=\max_{p(x)}I(X;Y)},\qquad \boldsymbol{C_{\mathrm{BSC}}=1-H(p)},\qquad \boldsymbol{C_{\mathrm{BEC}}=1-\alpha}\quad\text{——合上书也要能默写}$$
