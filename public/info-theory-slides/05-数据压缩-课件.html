主线

从「码流怎么切分」一路走到「平均码长逼近熵」

1码流须即时切分 → 前缀码（谁也不做别人的前缀）
2码长不能乱配 → Kraft 不等式圈定可行域
3约束下最优化 → 下界 L ≥ H，香农码先拿到 L < H+1
4贪心合并 → Huffman 码达到单符号最优，仍至多浪费 1 比特
5按整串编码 → 算术编码把浪费摊到趋零，贴着 H 走
这条链就是本章的目录：前缀码 → Kraft → 最优码的界 → Huffman → 算术编码
动机

单符号不撞车≠码流能切分：收到 001 有两种合法切法

信源 A、B、C 配码：A→0，B→01，C→1。接收方收到 001：

✂️ 切法一：0｜0｜1
译出 A A C —— 合法
✂️ 切法二：0｜01
译出 A B —— 同样合法
⚠️ 病根：A 的码字 0 是 B 的码字 01 的前缀——看到开头的 0，无法断定该落锤还是该等下一位
💡 本章方案：先立规矩（前缀码），再谈省比特（最优码长逼近熵）
定义

唯一可译 ⊃ 前缀码：能解码是最低标准，立刻解码才是工程追求

📖 唯一可译码（Uniquely Decodable）
任意码字串的拼接只有唯一一种切分方式
例：{0, 01} 唯一可译，但看到 0 要等下一位才能判定
⚡ 前缀码（Prefix Code，即时码）
没有任何码字是另一个码字的前缀
收到完整码字立即落锤，零等待、零回看
$$\boldsymbol{\text{前缀码} \subset \text{唯一可译码}},\qquad \text{但两者的可行码长集合相同（Kraft–McMillan）}$$
读法：任何唯一可译码的码长，前缀码也能做到——限制在前缀码里找最优，一分不亏
例子

好码 {0, 10, 110, 111}：码字全坐在二叉树的叶子上

收到码流 0101100111，贪心切分：

$$0\,|\,10\,|\,110\,|\,0\,|\,111 \;\text{——边走边判，看到完整码字立即落锤}$$
几何读法：「互不为前缀」⟺「所有码字都在叶子上，谁也不挡谁向下长的路」

定理

Kraft 不等式：每个码字认领一份树荫，总树荫不超过整棵树

长为 $l$ 的码字占住后代子树，份额 = $2^{-l}$（每深一层减半）；前缀条件 ⟹ 子树互不相交：

$$\boldsymbol{\sum_{i} 2^{-l_i} \le 1} \quad\text{（Kraft 不等式，Kraft Inequality）}$$
➡️ 必要性：任何前缀码都满足；McMillan 加强——任何唯一可译码也满足
⬅️ 充分性：满足不等式的码长集合，必能造出前缀码（按长度从小到大往树上放）
合起来：前缀码与唯一可译码的可行域完全相同——「能不能造」变成一次算术判定
手算

两组码长：一组恰好占满满树，一组超支判死刑

① 码长 (1, 2, 3, 3)——即码 {0, 10, 110, 111}：

$$2^{-1}+2^{-2}+2^{-3}+2^{-3} = \tfrac12+\tfrac14+\tfrac18+\tfrac18 = \boldsymbol{1} \;\checkmark\ \text{恰好占满（满树，一片叶子不浪费）}$$

② 码长 (1, 2, 2, 3)——假设有人想给 4 个符号配这组长度：

$$2^{-1}+2^{-2}+2^{-2}+2^{-3} = \tfrac12+\tfrac14+\tfrac14+\tfrac18 = \tfrac98 > 1 \;\text{✗ 不可能存在这样的前缀码}$$
⚠️ Kraft 约束的是码长集合：{0,10,110} 与 {0,01,011} 码长同为 (1,2,3)、和同为 7/8 ≤ 1，后者却不是前缀码

推导

相对熵非负一步推出 L ≥ H，浪费的每一比特都有名有姓

① 造辅助分布：记 Kraft 和 $c=\sum_i 2^{-l_i}\le 1$，令 $r_i = 2^{-l_i}/c$（非负、和为 1，合法分布）

② 码长改写代入：由 $r_i$ 定义取对数得 $l_i = -\log_2 r_i + \log_2 c$，代入 $L=\sum_i p_i l_i$：

$$L = -\sum_i p_i \log_2 r_i + \log_2 c$$

③ 与熵相减，两项皆非负：

$$\boldsymbol{L - H = \underbrace{D(p\,\|\,r)}_{\ge 0} + \underbrace{\log_2 \tfrac{1}{c}}_{\ge 0\ (c\le 1)} \;\ge\; 0}$$
等号 ⟺ $r=p$ 且 $c=1$，即每个 $p_i$ 都是 2 的负整数幂（二进分布 dyadic）——第1章的 $(\tfrac12,\tfrac14,\tfrac18,\tfrac18)$ 恰好打到 $H$，不是巧合

构造

香农码：理想码长向上取整，最多赔 1 比特

$$\boldsymbol{l_i = \big\lceil \log_2 \tfrac{1}{p_i} \big\rceil} \;\Rightarrow\; 2^{-l_i}\le p_i \;\Rightarrow\; \sum_i 2^{-l_i}\le 1\ \checkmark$$
$$\boldsymbol{H \;\le\; L_{\text{最优}} \;\lt\; H + 1} \quad\text{（本章中心不等式）}$$
$p_i$0.40.20.150.150.1
香农码长23334
$$H\approx 2.146,\quad L = 0.8+0.6+0.45+0.45+0.4 = \boldsymbol{2.7}\ \text{比特}$$
检验：$2.146 \le 2.7 < 3.146$ ✓　合法但不惊艳——离熵还有半比特多的缝
算法

Huffman 贪心合并：两条引理保证简单规则精确最优

🔧 规则：反复合并当前概率最小的两个节点，直到只剩根；再沿树回退赋 0/1
🌳 引理一（最深兄弟）
最优码中，概率最小的两个符号可安排为码长最长、互为兄弟（只差最后一位）——交换论证：没占最深叶子就换，L 只会变小
📉 引理二（合并归纳）
两兄弟合并成一个概率相加的新符号后，原问题最优码 = 新问题最优码再展开一步——规模缩一，最优性保持
两条合起来：每步合并最小两个都不会弄丢最优解 ⟹ 贪心精确最优，而非近似

突破

整数比特是单符号码的天花板——算术编码改给整条消息配码

💡 算术编码（Arithmetic Coding）：把整条消息映进 $[0,1)$ 里层层细分的一个子区间，区间内任挑一个短二进制小数就是码字

规则：按累计概率切区间，每读一个符号，当前区间按它的份额缩小一次

符号概率累计区间

C0.25$[0.75,\ 1)$
关键性质（下一页验证）：最终区间宽度 = 各符号概率之积 = 消息的概率

洞察

区间宽度 = 消息概率 ⟹ 码长 = 自信息，精确到分数比特

$$\boldsymbol{\text{码长} \approx -\log_2(\text{区间宽}) = -\log_2 p(\text{消息}) = \text{消息自信息}}$$
✅ 精度：前缀码把「码长 = 自信息」凑到整数位；算术编码做到分数比特精度——每条消息 ≤ 理想 + 2 比特，摊到 n 个符号上每符号 ≤ 2/n → 0
⚠️ 代价：码流不能按符号切开（010111 里找不出哪几位属于 A），解码须从头顺序；切区间需要已知分布，未知分布 → Ch13
这就是它能贴着 H 走的全部原因：自信息即码长的精确兑现
避坑

这一章的错误直觉：三个高频误解逐个拆

❌ 「不同符号给不同码字就能解码」
✅ 单符号一一对应只保证单个码字不撞车，不保证拼接后可切分——{0, 01, 1} 收到 001 就是歧义；可译性必须按「任意拼接」检验
❌ 「Σ2⁻ˡ ≤ 1 说明这个码是前缀码」
✅ Kraft 只约束码长集合，不验具体码字——{0,10,110} 与 {0,01,011} 码长同为 (1,2,3)，后者根本不是前缀码
❌ 「Huffman 最优 = 达到熵」
✅ Huffman 是单符号无前缀码中的最优，只保证 H ≤ L < H+1——主例 2.2 vs 2.146 的 0.054 缝，单符号层面无解，靠块编码或算术编码再逼近
