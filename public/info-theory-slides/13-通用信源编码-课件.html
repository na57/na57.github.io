动机

第五章的最优码有个隐蔽前提：你得先知道分布 p

已知 $p$ 时：最优码长 $l(x)=\log_2\frac{1}{p(x)}$，期望码长 $\mathbb{E}_p[l]=H(p)$。

现实中手里没有 $p$，只有两条路：

  • 猜一个 $q$ 硬编码 → 多付多少？（冗余分析）
  • 不估分布、直接对着序列编码 → 能多好？（通用编码）
文本、DNA、传感数据流——没有一个会附赠一张概率表。
要点

错用 q 的期望码长 = 真实熵 + 相对熵罚款

$$\mathbb{E}_p[l(X)] = \sum_x p(x)\log_2\frac{1}{q(x)} = H(p) + D(p\|q)$$

拆分：$\log_2\frac{1}{q(x)} = \log_2\frac{1}{p(x)} + \log_2\frac{p(x)}{q(x)}$，两项分别求和即得。

罚款 $D(p\|q)\ge 0$，等号仅当 $q=p$——猜错必多付，多付的量可精确计算。

这是全章地基：分布猜错的代价不是模糊的"变差"，而是精确的 D(p‖q) 比特/符号。
手算

手算：偷懒用均匀分布，每符号多付 0.1887 比特

① q 码长什么样　均匀分布下两符号各配 $\log_2 2=1$ bit，每符号恒用 1 bit，期望码长 $L=1$ bit。

② 真实熵　$h\!\left(\frac14\right)=-\frac14\log_2\frac14-\frac34\log_2\frac34=\frac14\times 2+\frac34\times 0.4150=0.5+0.3113=0.8113$ bit。

③ 冗余直接相减　$1-0.8113=0.1887$ bit/符号。

④ 验证恒等式　$D(p\|q)=\frac14\log_2\frac{1/4}{1/2}+\frac34\log_2\frac{3/4}{1/2}=\frac14\times(-1)+\frac34\times 0.5850=-0.25+0.4387=0.1887$ bit ✓

每符号多付 ≈ 19%：分布猜错不是小事，是明码标价的浪费。

要点

相对熵对尾部极端敏感：赌错分布的代价可以是无穷大

若 $p(x)>0$ 而 $q(x)=0$，则 $p(x)\log_2\frac{p(x)}{q(x)}=+\infty$——罚款无界。

工程含义：估计分布必须平滑（拉普拉斯、Good–Turing），给未见符号留概率。

更根本的选择：与其赌 $q$ 赌错，不如把"分布未知"本身当作设计前提。

"估得差不多就行"在尾部会翻车——这正是通用编码存在的理由。
要点

minimax 答案：归一化最大似然码，遗憾 = log₂Cₙ

$$R^*=\min_q\max_p\, D(p\|q)=\log_2 C_n,\qquad C_n=\sum_{x^n}\max_\theta p_\theta(x^n)$$

最优码 $q^*(x^n)=\dfrac{\max_\theta p_\theta(x^n)}{C_n}$：归一化最大似然（NML）。

$C_n$ 是参数族的"复杂度"度量：族越丰富，归一化常数越大，学费越贵。

对抗赛的最优解不是某个点估计，而是一个把"最难解释的序列"均匀摊平的分布。
手算

手算：n=2 伯努利，学费 log₂(5/2) ≈ 1.3219 比特

① 逐序列求最大似然　$\max_\theta p_\theta(x^2)$：$00\to(1-0)^2=1$；$01\to\frac12\cdot\frac12=\frac14$；$10\to\frac14$；$11\to 1^2=1$。

② 求和　$C_2=1+\frac14+\frac14+1=\frac52$。

③ 取对数　$R^*=\log_2\frac52\approx 1.3219$ 比特/序列。

序列取到最大的 θmax pθ
00θ = 01
01 / 10θ = 1/21/4
11θ = 11
两个符号就要 1.32 比特学费——"参数未知"在短序列上很贵。

按空格 / → 逐步展开推导

要点

学费按对数收、收益按线性长：每符号遗憾渐近为零

$$\log_2 C_n \approx \frac{k}{2}\log_2 n \;\;\Rightarrow\;\; \frac{R^*}{n}\approx \frac{k}{2n}\log_2 n \xrightarrow[n\to\infty]{} 0$$

$k$ 维参数族、$n$ 个符号：总学费 $\Theta(\log n)$，而熵 $nH$ 线性增长。

长序列：无知渐近免费；短序列：学费占比高——短文本难压不是算法的错。

通用编码不是"永远免费"，而是"越长越便宜"——渐近意义下追平已知分布的极限。
要点

贝叶斯混合码：平均冗余恰好是互信息 I(θ; Xⁿ)

$$m(x^n)=\int w(\theta)\,p_\theta(x^n)\,d\theta,\qquad \mathbb{E}_w\big[\mathbb{E}_{p_\theta} l - H\big] = I(\theta;X^n)$$

单序列视角：$\log_2\frac{1}{m(x^n)} \approx \log_2\frac{1}{\max_\theta p_\theta(x^n)} + O(1)$——混合码几乎免费。

平均视角：冗余 = 参数↔数据这条假想信道的容量。

minimax 与贝叶斯在此握手：log Cₙ 与 max_w I(θ;Xⁿ) 只差小量。
例子

例 3：两点先验的混合码，冗余又是 0.1887

① 混合　$\theta\in\{1/4,\,3/4\}$ 各以概率 $\frac12$，$n=1$：$m(1)=\frac12\cdot\frac14+\frac12\cdot\frac34=\frac12$，$m(0)=\frac12$——混合恰为均匀分布。

② 算互信息　边缘 $X$ 均匀，$H(X)=1$ bit；$H(X\mid\theta)=h(1/4)=0.8113$ bit（两个 $\theta$ 的熵相同）。

③ 得数　$I(\theta;X)=1-0.8113=0.1887$ bit——与例 1 的 $D(p\|q)$ 数值一致（$m$ 恰为均匀，且 $\mathrm{Bern}(\frac14)$ 与 $\mathrm{Bern}(\frac34)$ 对均匀的相对熵相等）。

minimax 与贝叶斯在最坏 / 平均两个方向上，量的是同一枚硬币。

按空格 / → 逐步展开推导

要点

竞争最优性：被甩开 c 比特的概率 ≤ 2^{-(c-1)}

$$P\big(l(x^n)\ge l'(x^n)+c\big)\le 2^{-(c-1)}\qquad(c=3\Rightarrow \tfrac14)$$

不承诺每次都赢，承诺很少输得惨——概率随劣势 $c$ 指数衰减。

想要"对每条序列都有保证"？统计框架到此为止，请 LZ 出场。

这是统计语言里的最强逐序列保证；更强的承诺要换一种语言。
要点

LZ78：字典从数据里现长，全程不谈概率

规则（重复到序列结束）：

  • 从当前位置匹配字典中最长旧短语 $w$；
  • 多读一个新字符 $c$，把 $wc$ 登记为字典新条目；
  • 输出二元组（$w$ 的编号，$c$）。
不估分布、不要先验——它赌的是"真实数据里重复模式远多于随机数据"。
手算

手算：13 比特串被切成 7 个短语

输入：1 0 1 1 0 1 0 1 0 0 0 1 0（13 bit）

步切出短语为何在此切入字典输出（指针, 新字符）
11字典空#1 = 1(0, 1)
200 不在字典#2 = 0(0, 0)
3111 = #1 在，11 不在#3 = 11(1, 1)
4010 = #2 在，01 不在#4 = 01(2, 1)
501001 = #4 在，010 不在#5 = 010(4, 0)
6000 = #2 在，00 不在#6 = 00(2, 0)
7101 = #1 在，10 不在，串读完#7 = 10(1, 0)
没有概率、只有指针；没有模型、只有记忆——这就是 LZ 的全部机制。
要点

数账：21 bit 输出 13 bit 输入——短串膨胀 62%

flowchart TB R["字典 空"] --> S1["1 → #1"] S1 --> S2["0 → #2"] S2 --> S3["11 → #3"] S3 --> S4["01 → #4"] S4 --> S5["010 → #5"] S5 --> S6["00 → #6"] S6 --> S7["10 → #7"]

指针位数　$0+1+2+2+3+3+3=14$ bit

新字符　$7\times 1=7$ bit

合计　$14+7=21$ bit（输入仅 13 bit）

短串膨胀是"字典还没长成"的学费——条目越深，指针摊得越薄。

按空格 / → 逐步展开推导

要点

长串翻盘：c ≲ √(2n)，每符号码长渐近趋向熵率

$$1+2+\cdots+c\le n \;\Rightarrow\; c\lesssim\sqrt{2n},\qquad \frac{c(\log_2 c+1)}{n}\xrightarrow[n\to\infty]{} \text{熵率}$$

字典越大 → 短语越长 → 指针被摊得越薄——膨胀只是开机成本。

工程后代：LZ77（滑动窗口）+ 哈夫曼二次压缩 = 你每天用的 zip。

不估分布却渐近最优——LZ 用"记忆"替代了"模型"。
要点

算术编码：整条序列只取整一次，浪费 ≤ 2 比特

$$l(x^n)=\Big\lceil \log_2\frac{1}{q(x^n)} \Big\rceil \le \log_2\frac{1}{q(x^n)}+1$$

机制：序列 ↔ 子区间，区间长度 $=q(x^n)$，输出区间内任一数的二进制小数。

整条序列只取整一次 → 每符号浪费 $\le 2/n \to 0$。

前面所有 log(1/q) 的账都不是理想化近似——算术编码让它们精确兑现。
避坑

三个坑：学费的渐近结构，别被短序列账面吓退

坑一　"分布估得差不多就行"——$D(p\|q)$ 对尾部敏感，估出零概率则罚款无界；必须平滑。

坑二　"minimax 遗憾 1.3 bit 太亏，不如赌一把"——摊到每符号 $O(\frac{\log n}{n})\to 0$；赌错的代价随 $n$ 线性放大。

坑三　"LZ 短串膨胀 62%，不行"——膨胀是开机学费；渐近码长 → 熵率，zip 天天在用。

共同药方：分清"一次性学费"与"每符号罚款"，别让开机成本吓退你。

小结

三句话：定价、压价、跳出统计——终点仍是熵

问题　分布未知能不能压缩？能，且代价可精确计算。

机制　罚款 $D(p\|q)$；minimax 压到 $\log_2 C_n$；贝叶斯冗余 $=I(\theta;X^n)$；LZ 用记忆替代模型，同样到熵。

分工　Ch5 已知分布到熵 → Ch13 未知分布渐近到熵 → Ch14 单条序列的极限 $K(x)$。

$$\mathbb{E}_p[l] = H(p) + D(p\|q)$$
熵依然是终点——只是这次，我们连分布都不知道。
