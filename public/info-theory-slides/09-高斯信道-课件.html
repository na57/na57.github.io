主线

连续波形信道，靠五步链变成一行容量公式

1连续波形没法代公式 → 采样定理切成每秒 2W 个自由度
2每个自由度 = Y = X + Z，噪声取高斯（物理 + 最坏情形）
3功率约束下优化：高斯输入让 h(Y) 最大 → C = ½log(1+P/N)
4多条子信道噪声不齐 → 注水 Pᵢ = (ν−Nᵢ)⁺ 一刀切平
52W × ½log → 带限公式，压出 −1.59 dB 能量地板
这条链就是本章的目录：切自由度 → 建模 → 单点容量 → 注水分功率 → 合成与极限
动机

没有功率约束，容量就是荒唐的无穷大

❓ 核心问题：一根带宽 3000 Hz 的电话线，功率受限、噪声给定——每秒最多能可靠传多少比特？
🚫 功率不受限
星座点越摆越密 ⟹ 容量 = ∞，答案毫无意义
💡 现实有电费
平均功率约束 $E[X^2]\le P$ ⟹ 容量才是有限的数
第7章的 $C=\max I(X;Y)$ 太抽象——本章要给它算出能按计算器的结果
桥梁

带宽 W 的信道 ＝ 每秒 2W 条并行小信道

💡 关键一跃：一根带宽 W 的电话线，在信息论眼里不是一条管道，而是每秒 2W 条并行的小信道——「每次使用」指 1/(2W) 秒里的一个自由度
采样定理（Nyquist）：带宽 W 的信号由每秒 2W 个等间隔采样完全决定，sinc 插值无损重建——采样不丢信息
定义

模型三件套：Y = X + Z、功率预算、最坏的高斯噪声

$$Y_i = X_i + Z_i, \quad Z_i \sim \mathcal{N}(0, N), \ \text{各次使用独立} \qquad \frac{1}{n}\sum_{i=1}^{n} x_i^2 \le P \ \Longleftrightarrow\ E[X^2] \le P$$
🌡️ 理由一：物理（CLT）
热噪声、散粒噪声是海量独立微小扰动的叠加，叠加和趋于高斯
🛡️ 理由二：最坏情形
固定方差下高斯微分熵最大（第8章）⟹ 噪声熵越大容量越小 ⟹ 高斯是同等功率下最坏的噪声
按高斯设计 = 给容量买保险；严格化（矩约束下最大熵）是第12章的内容，先记账
推导

三步推导：高斯输入够到了输出熵的天花板

① 拆互信息：给定 X 时 Y 只是 Z 的平移，h(Z) 与输入无关 ⟹ 最大化 I 就是最大化 h(Y)：

$$I(X;Y) = h(Y) - h(Y|X) = h(Y) - h(Z), \quad h(Z) = \tfrac{1}{2}\log(2\pi e N)$$

② 盖天花板：Var(Y) = Var(X) + N ≤ P + N，固定方差下高斯熵最大（第8章）：

$$h(Y) \le \tfrac{1}{2}\log\big(2\pi e\,\mathrm{Var}(Y)\big) \le \tfrac{1}{2}\log\big(2\pi e (P+N)\big)$$

③ 够得着：取 $X \sim \mathcal{N}(0, P)$，功率用满，独立高斯之和仍为高斯，两个 ≤ 同时取等：

$$\boldsymbol{C = \tfrac{1}{2}\log_2\!\Big(1 + \frac{P}{N}\Big)} \ \text{比特/次}, \quad X \sim \mathcal{N}(0, P)\ \text{时达到}$$

手算

信噪比放大 17 倍，容量只翻一倍——对数汇率

🧮 P/N = 15（约 12 dB）
① $1+15=16$　② $\log_2 16 = 4$　③ $C = \tfrac12 \times 4 = \boldsymbol{2}$ 比特/次
🧮 P/N = 255（约 24 dB）
① $1+255=256$　② $\log_2 256 = 8$　③ $C = \tfrac12 \times 8 = \boldsymbol{4}$ 比特/次
⚠️ 信噪比 15 → 255（×17），容量 2 → 4（×2）：C 对 P 是对数关系，功率换比特越换越不划算
读法：输出方差 (P+N) 与噪声方差 N 之比取对数的一半——能分辨的电平层数取对数；括号里的 +1 只有高信噪比才可略
几何

球体填充：往大球里摆小球，数出来的还是同一个 C

把 n 次使用看成 n 维向量：噪声球半径 $\sqrt{nN}$，接收向量落在半径 $\sqrt{n(P+N)}$ 的大球内；译码要求小噪声球互不重叠，能装的码字 ≈ 体积比：

$$M \approx \Big(\frac{\sqrt{n(P+N)}}{\sqrt{nN}}\Big)^{n} = \Big(1 + \frac{P}{N}\Big)^{n/2} \;\Rightarrow\; R = \tfrac{1}{n}\log_2 M = \tfrac{1}{2}\log_2\Big(1+\frac{P}{N}\Big)$$
🎱 直觉：往大房间里摆台球，每个球自带半径 √(nN) 的「私人空间」，互不重叠才分得清——和优化推导殊途同归
维度 n 越高，球体积越集中在表面附近，这个计数越精确——它是严格可达性证明的内核，不只是比喻
定理

总功率只有一份，往各条子信道各倒多少？

DSL / OFDM 把物理媒介切成 K 条子信道（Yᵢ = Xᵢ + Zᵢ，Zᵢ ~ N(0, Nᵢ)），总功率约束 ΣPᵢ ≤ P，容量是各信道之和的最大化：

$$C = \max_{\sum P_i \le P}\ \sum_{i=1}^{K} \tfrac{1}{2}\log_2\Big(1 + \frac{P_i}{N_i}\Big) \quad\text{（log 凹 + 约束线性 → KKT 求驻点）}$$
$$\boldsymbol{P_i = (\nu - N_i)^{+}}, \quad \nu\ \text{由}\ \sum_i (\nu - N_i)^{+} = P\ \text{唯一确定}; \qquad C = \sum_{P_i>0} \tfrac{1}{2}\log_2\frac{\nu}{N_i}$$
x⁺ = max(x, 0)——噪声比水位还深的信道，一滴功率都分不到

💡 每条信道 = 深度为 Nᵢ 的容器，功率 = 水：水面齐平于 ν，水量 = ν − Nᵢ；噪声 ≥ ν 的容器一滴水都进不去
演练

四步手算注水：假设、检验、分配、求容量

例 A：$N = (1, 2, 3)$，总功率 $P = 6$ —— 先假设三条全用，再检验：

① 解水位：$\sum_i(\nu-N_i) = 3\nu-(1{+}2{+}3) = 6 \;\Rightarrow\; \nu = \boldsymbol{4}$

② 检验：$\nu = 4 > 3 = \max N_i$ ✓ 每条噪声都低于水位，假设成立

③ 分配：$P = (4{-}1,\, 4{-}2,\, 4{-}3) = \boldsymbol{(3,\, 2,\, 1)}$，合计 $3{+}2{+}1 = 6$ ✓ 功率用尽

④ 容量：$C = \tfrac12\big[\log_2 4 + \log_2 2 + \log_2\tfrac{4}{3}\big] = \tfrac12[2+1+0.4150] \approx \boldsymbol{1.71}$ 比特

✍️

弃用

水位没不过噪声，这条信道一滴水都不给

例 B：$N = (1, 2, 8)$，总功率 $P = 5$ —— 这次有信道会被「淹死」：

  1. 试全用：$\nu = (P+\sum N_i)/3 = (5+11)/3 \approx 5.33$
  2. 检验：$5.33 \lt 8 = N_3$ ✗ 会分到负功率 ⟹ 弃用信道三
  3. 重算：$\nu = (5+1+2)/2 = 4$，$4 > 2$ ✓ 剩余噪声都低于水位
  4. 分配：$P = (4{-}1,\, 4{-}2,\, 0) = \boldsymbol{(3,\, 2,\, 0)}$
  5. 容量：$C = \tfrac12[\log_2 4 + \log_2 2] = \tfrac12(2+1) = \boldsymbol{1.5}$ 比特
⚙️ 工程对应：DSL / OFDM 会直接关掉被串扰毁掉的子载波——不是它坏了，是往里投功率太亏
合成

自由度乘单点容量，合成香农公式

白噪声双边功率谱密度 N₀/2 ⟹ 带宽 W 内噪声总功率 $N = N_0 W$；功率 P 摊到每秒 2W 个自由度 ⟹ 每个自由度信噪比 $P/(N_0 W)$：

$$2W \times \frac{1}{2}\log_2\Big(1+\frac{P}{N_0 W}\Big) \quad\text{（自由度 } \times \text{ 单点容量）}$$
$$\boldsymbol{C = W \cdot \log_2\Big(1 + \frac{P}{N_0 W}\Big)} \ \text{比特/秒} \quad\text{（带限 AWGN 信道容量）}$$
这就是著名的香农公式——物理信道的价格标签：带宽、功率、噪声谱密度给定，速率上限钉死
手算

3000 Hz、30 dB 的电话线，天花板约 29.9 kbps

老式电话线：带宽 $W = 3000$ Hz，信噪比 30 dB ⟹ $P/(N_0 W) = 10^3 = 1000$：

$$\text{① } 1+1000 = 1001 \qquad \text{② } \log_2 1001 = 9.967 \qquad \text{③ } C = 3000 \times 9.967 \approx \boldsymbol{29.9\ \text{kbps}}$$
这就是传统电话线信道的理论上限量级——上世纪 56k 调制解调器能逼近它，靠的正是把信噪比用到极限
想再快只剩两条路：加带宽或加功率——这两者怎么换算，是下一场戏
折中

无限带宽买不来无限容量：饱和到 P/(N₀·ln 2)

W 出现在两个位置：乘在外面（自由度变多），又藏在信噪比分母里（噪声功率 N₀W 同步变大）——加带宽不是免费的

$$W\log_2\Big(1+\frac{P}{N_0 W}\Big) \approx W\cdot\frac{P}{N_0 W \ln 2} = \frac{P}{N_0 \ln 2} \quad (W \to \infty,\ \log_2(1{+}x)\approx x/\ln 2)$$
⚠️ 汇率对比：功率换容量是对数汇率（9.2 节）；带宽换容量先接近线性、然后饱和——工程设计全在这场兑换里
极限

可靠通信的能量地板：E_b/N₀ ≥ ln 2，即 −1.59 dB

每比特能量 $E_b = P/R$；可靠传输要求 $R \le C \le P/(N_0\ln 2)$，两个不等式一夹：

$$\frac{E_b}{N_0} = \frac{P/N_0}{R} \ge \frac{P/N_0}{C} \ge \ln 2 = 0.693$$
$$10\log_{10}(0.693) = \boldsymbol{-1.59\ \text{dB}} \quad\text{（香农极限 Shannon Limit）}$$
它是负的：带宽足够时，信噪比低于 0 dB 照样可靠通信——深空通信、LDPC、Turbo 码几十年工程史都在逼近这条地板
避坑

三个直觉全错：功率、带宽、补偿差信道

❌ 功率翻倍，容量翻倍
✅ C 对 P 是对数关系：P/N 从 15 翻倍到 30，容量 2 → 2.48 比特，只多 24%——越换越亏
❌ 带宽越大，容量无限涨
✅ 噪声功率 N₀W 随带宽同步增长，容量饱和到 $P/(N_0\ln 2)$——带宽不是免费的
❌ 差信道噪声大，该多分功率补偿
✅ 恰好相反：log 边际收益递减，好信道多拿、深噪声信道判零——锦上添花，不是雪中送炭
