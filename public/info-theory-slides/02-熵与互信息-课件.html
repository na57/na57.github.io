主线

一条链：负对数定形，取平均得熵，熵再长出相对熵与互信息

1Ch1 欠账：极限由熵给出，但熵凭什么长这样？
2三条常识逼出负对数：单条消息的信息量定了形

动机

第一章的极限豪言，要靠本章的三个定义兑现

Ch1 给出单条消息的信息量 $h(x) = -\log_2 p(x)$，但工程面对的是不断发消息的信源（随机变量）：

❓ 不确定度
信源平均每条消息携带多少信息？
→ 需要「熵」
❓ 分布差距
真实是 p 却按 q 建模，代价多大？
→ 需要「相对熵」
❓ 信息共享
Y 里有多少关于 X 的信息？
→ 需要「互信息」
💡 没有这三个严格定义，Ch1 的「极限由熵给出」就是空话——本章把它们全部钉死
定义

熵 = 单条消息信息量按概率取平均

📨 部件一：单条消息信息量
$h(x) = -\log_2 p(x)$——概率越小，发生越惊人
📡 部件二：信源是随机变量
按分布 $p$ 不停发消息，问「平均每条带多少信息」
$$\boldsymbol{H(X) = E\big[-\log_2 p(X)\big] = -\sum_{x\in\mathcal{X}} p(x)\log_2 p(x)} \quad\text{（单位：比特）}$$
读法：熵是分布的性质，不是取值的性质（也可写作 $H(p)$）；约定 $0\log 0 = 0$；每项非负 ⟹ $H(X)\ge 0$
例子

分布 (1/2, 1/4, 1/8, 1/8) 的熵当场算出：1.75 比特

信源分布 $p = (\tfrac12, \tfrac14, \tfrac18, \tfrac18)$，一步不落：

$$H(X) = -\Big[\tfrac12\log_2\tfrac12 + \tfrac14\log_2\tfrac14 + \tfrac18\log_2\tfrac18 + \tfrac18\log_2\tfrac18\Big]$$
$$= \tfrac12\!\times\!1 + \tfrac14\!\times\!2 + \tfrac18\!\times\!3 + \tfrac18\!\times\!3 = 0.5 + 0.5 + 0.375 + 0.375 = \boldsymbol{1.75}\ \text{比特}$$
这正是 Ch1 例 1 前缀码达到的平均码长——熵与最优码长的关系不是巧合，是第 5 章的定理
性质

均匀分布最不确定：熵到顶就是 log 字母表大小

$$H(X) \le \log_2 |\mathcal{X}|,\ \text{等号}\iff\text{均匀分布}$$

4 符号信源：$H \le \log_2 4 = \boldsymbol{2}$ 比特；例 1 的 $1.75$ 离顶差 $0.25$——「不均匀省下的压缩空间」

🪙 二元熵函数（Binary Entropy Function）
$$H(p) = -p\log_2 p - (1-p)\log_2(1-p)$$关于 $p=\tfrac12$ 对称，$p=\tfrac12$ 取最大值 $1$ 比特；$H(0.1)=0.469$ 比特（Ch7 反复出现）
证明思路：取均匀分布 $u$，则 $D(p\|u) = \log_2|\mathcal{X}| - H(X) \ge 0$——2.3 节正式还债
定义

条件熵是两次平均：先固定 Y 算熵，再对 Y 加权

👥 联合熵（Joint Entropy）
把 $(X,Y)$ 当一个大变量照样定义：$$H(X,Y) = -\sum_{x,y} p(x,y)\log_2 p(x,y)$$
🔍 条件熵（Conditional Entropy）
已知 $Y$ 后 $X$ 还剩多少：$$H(X|Y) = \sum_y p(y)\,H(X|Y{=}y) = -\sum_{x,y} p(x,y)\log_2 p(x|y)$$
⚠️ 两次平均：内层是条件分布的熵 $H(X|Y{=}y)$，外层按 $p(y)$ 加权——外层出现的是联合概率 $p(x,y)$，手算出错的第一原因
法则

整体不确定度 = 先定一个，再加上还剩多少

$$\boldsymbol{H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)}$$

直觉：先告诉你 $X$（花 $H(X)$ 比特），再补「已知 $X$ 后还差多少 $Y$」（花 $H(Y|X)$ 比特）；$\log$ 乘法变加法立即可证

$$n\ \text{变量版：}\quad H(X_1,\dots,X_n) = \sum_{i=1}^{n} H\big(X_i \,\big|\, X_1,\dots,X_{i-1}\big)$$
第 4 章定义熵率全靠这条链——现在先在两个变量上把它用熟
例子

一张四乘四联合表，本章六个量全从它长出来

$p(x,y)$$Y{=}1$$Y{=}2$$Y{=}3$$Y{=}4$行和 $p(x)$
$X{=}1$$\tfrac18$$\tfrac1{16}$$\tfrac1{32}$$\tfrac1{32}$$\tfrac14$
$X{=}2$$\tfrac1{16}$$\tfrac18$$\tfrac1{32}$$\tfrac1{32}$$\tfrac14$
$X{=}3$$\tfrac1{16}$$\tfrac1{16}$$\tfrac1{16}$$\tfrac1{16}$$\tfrac14$
$X{=}4$$\tfrac14$$0$$0$$0$$\tfrac14$

边际熵：$p(x)$ 均匀 ⟹ $H(X) = \log_2 4 = \boldsymbol{2}$ 比特；$p(y) = (\tfrac12,\tfrac14,\tfrac18,\tfrac18)$ ⟹ 由例 1，$H(Y) = \boldsymbol{1.75}$ 比特
手算

六个量手算：两个方向的链式法则互相验证

① 逐行算 $H(Y|X{=}x)$ 再加权：四行条件熵 $= 1.75,\ 1.75,\ 2,\ 0$（第 3 行均匀、第 4 行确定）

$$H(Y|X) = \tfrac14(1.75 + 1.75 + 2 + 0) = \tfrac14 \times 5.5 = \boldsymbol{1.375}\ \text{比特}\;(=\tfrac{11}{8})$$

② 逐列算 $H(X|Y{=}y)$ 再加权：四列条件熵 $= 1.75,\ 1.5,\ 1.5,\ 1.5$

$$H(X|Y) = \tfrac12(1.75) + \tfrac14(1.5) + \tfrac18(1.5) + \tfrac18(1.5) = \boldsymbol{1.625}\ \text{比特}\;(=\tfrac{13}{8})$$
$$\boldsymbol{H(X,Y) = H(X)+H(Y|X) = 2+1.375 = 3.375 = H(Y)+H(X|Y) = 1.75+1.625}\ \checkmark$$
✍️
暂停推导

遮住答案，把四行的 H(Y|X=x) 与四列的 H(X|Y=y) 各算一遍，再核对两个方向的链式法则是否对上。

定义

真实是 p 却按 q 建模，这份代价就是相对熵

🌍 被乘位置 $p$：真实世界
负责加权——惊讶之差按真实发生的频率平均
🧭 被除位置 $q$：你的模型
你以为的分布 / 你设计的码——代价由它引起
$$\boldsymbol{D(p\|q) = \sum_x p(x)\log_2 \frac{p(x)}{q(x)} = E_p\Big[\log_2 \frac{p(X)}{q(X)}\Big]}$$
约定 $0\log\tfrac{0}{q}=0$；若某 $x$ 使 $p(x)>0$ 而 $q(x)=0$，则 $D(p\|q)=+\infty$——模型排除了真实会发生的事
手算

0.531 ≠ 0.737：相对熵有方向，不是距离

取 $p = (0.9, 0.1)$，$q = (0.5, 0.5)$（真实天气 90% 晴，你的模型以为 50/50）：

$$D(p\|q) = 0.9\log_2\tfrac{0.9}{0.5} + 0.1\log_2\tfrac{0.1}{0.5} = 0.9(0.848) + 0.1(-2.322) = \boldsymbol{0.531}\ \text{比特}$$
$$D(q\|p) = 0.5\log_2\tfrac{0.5}{0.9} + 0.5\log_2\tfrac{0.5}{0.1} = 0.5(-0.848) + 0.5(2.322) = \boldsymbol{0.737}\ \text{比特}$$
⚠️ $0.531 \ne 0.737$：不对称、无三角不等式、可为 $+\infty$ ⟹ 是「散度」不是「距离」；两个位置弄反，结论整个错向
解读

对均匀分布的相对熵 = 分布里藏着的压缩冗余

$$\boldsymbol{D(p\|u) = \sum_x p(x)\log_2\big[p(x)\cdot|\mathcal{X}|\big] = \log_2|\mathcal{X}| - H(p)}$$

例 1 的分布：$D(p\|u) = 2 - 1.75 = \boldsymbol{0.25}$ 比特——正是「离满熵」的那 $0.25$

第 5 章兑现：误用均匀模型设计编码，平均每符号比最优码多花 $0.25$ 比特 ⟹ 相对熵 = 用错分布的编码代价，这是它在全书最重要的物理解读
定义

互信息 = Y 把 X 的不确定度削掉的部分

✂️ 削掉视角
$I(X;Y) = H(X) - H(X|Y)$——$Y$ 削掉了多少困惑
📏 散度视角
真实联合分布 vs 「假装独立」的乘积分布 $p(x)p(y)$
$$\boldsymbol{I(X;Y) = \sum_{x,y} p(x,y)\log_2 \frac{p(x,y)}{p(x)p(y)} = D\big(p(x,y)\,\big\|\,p(x)p(y)\big)}$$
白送三性质：对称 $I(X;Y)=I(Y;X)$；非负 $I\ge 0$ 等号 $\iff$ 独立；自信息 $I(X;X)=H(X)$
收官

0.375 比特：两个方向算互信息必然相等

$$I(X;Y) = H(X) - H(X|Y) = 2 - 1.625 = \boldsymbol{0.375}\ \text{比特}\;(=\tfrac38)$$
$$\text{验证：}\ H(Y) - H(Y|X) = 1.75 - 1.375 = 0.375\ \checkmark$$
例 2 末尾「条件熵不对称」的谜底：残存可以一边大一边小，两边被削掉的部分必然相等——就是互信息

推导

Jensen 一步推出相对熵非负，全章不等式都是它换皮

① 基石：$\log$ 严格凹 ⟹ Jensen 不等式

$$E[\log_2 X] \le \log_2 E[X]$$

② 改写 $D$ 并套 Jensen：

$$D(p\|q) = -E_p\Big[\log_2\tfrac{q}{p}\Big] \ge -\log_2 E_p\Big[\tfrac{q}{p}\Big] = -\log_2 \sum_x p(x)\tfrac{q(x)}{p(x)} = -\log_2 1 = 0$$
$$\boldsymbol{D(p\|q) \ge 0\ (\text{等号}\iff p=q)}\ \Longrightarrow\ I \ge 0,\ \ H(X|Y)\le H(X),\ \ H \le \log_2|\mathcal{X}|$$

工具

加工造不出信息，残存困惑封死猜错率下限

⛓️ 数据处理不等式
$X \to Y \to Z$ 马尔可夫链 ⟹ $$I(X;Z) \le I(X;Y)$$任何后处理都不能恢复已丢失的关于 $X$ 的信息
🎯 Fano 不等式
用 $Y$ 估计 $X$，错误率 $P_e$ 满足：$$P_e \ge \frac{H(X|Y)-1}{\log_2|\mathcal{X}|}$$例：$H(X|Y)=1.5$、$|\mathcal{X}|=4$ ⟹ $P_e \ge \tfrac{0.5}{2} = \boldsymbol{0.25}$
食物链：Jensen → $D\ge 0$ → $I\ge 0$ 与条件化减熵 → 数据处理与 Fano——本章一半的不等式不用背
避坑

熵不是取值个数，散度不是距离，条件化不是处处有帮助

❌ 熵大 = 取值多
✅ 熵只看概率形状：1000 个取值但 99.99% 集中在一处，熵可接近 0；两个取值等概率，熵就是满的 1 比特
❌ $D(p\|q)$ 是 p 与 q 之间的「距离」
✅ 三重错误：不对称（$0.531 \ne 0.737$）、无三角不等式、可为 $+\infty$——它是有方向的代价，被除位置是你的模型
❌ $H(X|Y)\le H(X)$ 说明知道 $Y$ 永远有帮助
✅ 只对平均成立：对某个特定坏消息 $y$，$H(X|Y{=}y)$ 完全可以大于 $H(X)$；等号条件是独立
接口

定义已齐，凭什么极限正好是熵——那是第3章的事

本章（第2章 · 度量）第3章（渐近均分性 AEP）
回答的问题极限由什么量描述凭什么极限正好是 $H$，不多不少
对象单符号、单分布长序列、典型集（Typical Set）
工具熵 / 相对熵 / 互信息的定义与性质序列几乎必然落在大小 $\approx 2^{nH}$ 的典型集上
钩子：Ch1 的豪言、Ch2 的度量，都要靠 Ch3 的典型集兑现成压缩极限定理——互信息与相对熵将在那里第一次联手
小结

三句话讲完第2章

1解决什么：Ch1 说极限由熵给出 → 本章把不确定度（熵）、分布差距（相对熵）、信息共享（互信息）一次定义清楚并算熟
