2.1为什么时间会变成"递归式"：分治三段式与归并排序

第1章给了我们 Θ、O、Ω 这套描述增长的记号，但它只解决了"怎么描述"，没解决"怎么求出"。面对一个循环嵌套的算法，我们可以一层层数；可面对自己调用自己的算法，时间的表达式里会再次出现 T 自己——这就是本章要驯服的对象：递归式（Recurrence），即用更小输入上的函数值来定义自身的等式（或不等式）。

递归式从哪来？从分治（Divide and Conquer）的设计范式来。分治每个递归层做三件事，称为分治三段式：

  1. 分解（Divide）：把原问题切成若干同构的更小子问题；
  2. 解决（Conquer）：递归地解子问题；子问题足够小时直接解；
  3. 合并（Combine）：把子问题的解拼成原问题的解。

以归并排序（Merge Sort）为例，对 n 个数排序：

  • 分解：把数组从中间切成两半，各 n/2 个元素，耗时 Θ(1)（只算下标）；
  • 解决：递归排序两个子数组，耗时 2·T(n/2)；
  • 合并：MERGE 过程用两个指针扫过两个已序子数组，每个元素恰好被比较并写回一次，耗时 Θ(n)。

三段相加，得到归并排序的递归式（忽略向下取整的边界细节）：

T(n) = 2T(n/2) + Θ(n)，  T(1) = Θ(1)

这个式子本身不是答案——右边还有 T。怎么"解"它？最直接的暴力办法：把递归一层层展开成一棵树，把每一层的代价加起来。这就是下一节正式介绍的递归树（Recursion Tree）的雏形，这里先用具体数字走一遍。

完整手算例 1：n = 8 的归并排序递归树。设 MERGE 的合并代价为每层每个元素 c（常数），即规模为 m 的节点合并代价是 c·m。

层号节点数每个节点规模单点合并代价本层总代价
第 0 层（根）188c1 × 8c = 8c
第 1 层244c2 × 4c = 8c
第 2 层422c4 × 2c = 8c
第 3 层（叶）81c（直接返回）8 × c = 8c

逐层相加：8c + 8c + 8c + 8c = 32c。注意两个关键观察：

  • 每层代价恒为 cn：不管切到多细，节点数翻倍的同时单点规模减半，乘积不变，每层永远是 8c = cn；
  • 层数 = lg n + 1：规模从 8 每次减半到 1，要除 3 次（8→4→2→1），共 4 = lg 8 + 1 层。

所以总代价 = cn·(lg n + 1)。一般化为 T(n) = cn·lg n + cn，低阶项 cn 被 cn·lg n 吸收，得 T(n) = Θ(n lg n)。

💡 关键一跃

递归式不是答案，是"问题的另一种写法"。解递归式 = 把隐式的自我引用展开成显式的求和。归并排序的直觉一句话：每层干 n 的活，共 lg n 层，所以 n lg n。

⚠️ 常见误区

"分治 = 递归"。错。分治是一种设计范式（分解/解决/合并），递归只是它最常用的实现手段；分治也可以迭代实现（如自底向上的归并排序）。反过来递归也不一定是分治——如斐波那契的朴素递归，子问题不是"独立切分"而是大量重叠，这正是 Ch8 动态规划要修理的对象。

2.2有了猜测怎么证明：代入法

上一节的递归树让我们"看出"归并排序是 Θ(n lg n)，但"看出"不等于"证明"。代入法（Substitution Method）负责把猜测变成铁证：先猜一个界，再用数学归纳法验证它。名字里的"代入"指的是：把猜测的界代入归纳步骤的右边，看能不能推出左边。

完整手算例 2：证明 T(n) = 2T(⌊n/2⌋) + n = O(n lg n)。

第 1 步，猜：T(n) ≤ c·n·lg n，c 是待定正常数。注意我们猜的是带常数 c 的具体形式，不是符号 O 本身。

第 2 步，归纳假设：对所有比 n 小的正整数 m，假设 T(m) ≤ c·m·lg m 成立，特别地对 m = ⌊n/2⌋ 成立。

第 3 步，归纳步骤，把假设代入递归式右边：

T(n) ≤ 2·(c·⌊n/2⌋·lg⌊n/2⌋) + n
≤ c·n·lg(n/2) + n  （⌊n/2⌋ ≤ n/2，lg 单调增）
= c·n·(lg n − lg 2) + n
= c·n·lg n − c·n + n
≤ c·n·lg n  （只要 c ≥ 1，−cn + n ≤ 0）

归纳步骤走通了：只要取 c ≥ 1，就有 T(n) ≤ c·n·lg n。但证明还没完——归纳法还需要基例，而基例正是代入法最常翻车的暗礁。

边界条件陷阱。递归的基是 T(1) = 1（规模为 1 直接返回，代价常数 1）。但把 n = 1 代入猜测界：c·1·lg 1 = c·1·0 = 0，而 T(1) = 1 > 0，基例不成立！证明卡死在起点。解法不是换猜测，而是换基例：利用渐近记号只要求"n 足够大以后成立"这一点，把归纳基例从 n = 1 挪到 n = 2：

  • T(2) = 2·T(⌊2/2⌋) + 2 = 2·T(1) + 2 = 2·1 + 2 = 4；
  • 要 4 ≤ c·2·lg 2 = 2c，即 c ≥ 2。

取 c = 2（同时满足归纳步骤要求的 c ≥ 1），基例 n = 2 成立，归纳步骤对一切 n ≥ 3 成立，证明完成：T(n) = O(n lg n)。为什么换基例合法？因为 O 记号只约束渐近行为，有限个小的 n（这里是 n = 1）不影响结论；而归纳步骤里用到的最小值 ⌊n/2⌋ 在 n ≥ 3 时是 ⌊3/2⌋ = 1——咦，用到了 T(1)？没关系：T(1) 是递归定义给的已知值（= 1），不需要它满足猜测界；需要满足猜测界的只是归纳链条的起点 n = 2 和 n = 3（T(3) = 2T(1)+3 = 5 ≤ 2·3·lg 3 ≈ 9.5，也成立）。

💡 关键一跃

代入法 = "先射箭后画靶"的合法版：靶（猜测）随便画，但箭（归纳证明）必须真的射中。它的软肋是那个"猜"字——猜错了就证不动。猜从哪来？下一节的递归树就是猜测的生产车间。

⚠️ 常见误区

在归纳步骤里写出"T(n) ≤ 2·O(⌊n/2⌋·lg⌊n/2⌋) + n = O(n lg n)"——这是循环论证：O 记号是对"整类函数"的陈述，不能当作归纳假设里的具体不等式来代入。归纳假设必须是带显式常数的 T(m) ≤ c·m·lg m。另一个高频翻车点：忘记验证基例，或基例不成立时误以为"猜测错了"，其实往往只是基例要后移。

2.3猜测从哪来：递归树法

代入法证明漂亮，但它假设你手里已经有一个猜测。递归树法（Recursion Tree）就是生产猜测的机器：把递归式的每次展开画成一棵树，节点记该层的非递归代价，总代价 = 所有节点代价之和 = ∑（逐层代价）。2.1 节 n = 8 的例子就是一棵具体递归树；现在把它用到新的递归式上，并学会处理"层代价不相等"的情形。

完整手算例 3：T(n) = 3T(⌊n/4⌋) + cn²。每个节点分裂成 3 个规模缩为 1/4 的子节点，本节点合并代价 cn²（n 为该节点规模）。忽略取整，逐层算：

层号 i节点数 3i单点规模 n/4i单点代价 c(n/4i)²本层总代价
i = 01ncn²cn²
i = 13n/4cn²/16(3/16)cn²
i = 29n/16cn²/256(3/16)²cn²
i3in/4icn²/16i(3/16)icn²

通用式：第 i 层总代价 = 3i · c(n/4i)² = 3i · cn²/16i = (3/16)i·cn²。层代价按公比 3/16 递减——这是一棵"上重下轻"的树，根节点一层就占了近一半。

树有多高？规模 n/4i 缩到 1 时 i = log₄n，即叶在第 log₄n 层。叶子数是 3log₄n。用对数换底恒等式化简：3log₄n = nlog₄3 ≈ n0.79。每个叶子代价 Θ(1)，故叶子总代价 Θ(nlog₄3) ≈ Θ(n0.79)。

内部节点逐层求和，是一个几何级数：

T(n) = ∑i=0…∞ (3/16)i·cn² + Θ(nlog₄3) < cn² · 11 − 3/16 + Θ(nlog₄3) = 1613·cn² + Θ(nlog₄3) = O(n²)

两个求和细节：① 无穷级数放大法——实际只有 log₄n 项，但公比 3/16 < 1，补成无穷几何级数只会更大，用作上界合法且干净；② 叶子项 Θ(n0.79) 被 (16/13)cn² 主导（0.79 < 2），所以整棵树的代价被根主导，答案是 O(n²)。要得到 Θ(n²) 只需补一句：T(n) ≥ cn²（光根节点就有 cn²），所以 T(n) = Θ(n²)。得到猜测后，严格证明交给代入法即可。

💡 关键一跃

递归树求和只有三种剧情：层代价不变（归并排序：每层 cn，共 lg n 层 → n lg n）、几何递减（本例：根主导 → 看根）、几何递增（叶子主导 → 看叶子数）。下一节的主定理，就是把这三种剧情提炼成的查表公式。

⚠️ 常见误区

忘记数叶子。很多人加完内部各层就交卷，漏掉 Θ(叶子数) 这一项——在"几何递增"的树里（如 T(n) = 2T(n/2) + 1，叶子 2lg n = n 个），叶子恰恰是主角。规矩：任何递归树求和，内部层和叶子层分开算，再比大小。

2.4把三种剧情做成查表：主定理

上一节的"三种剧情"每次都要重新画树、重新求和，太费。主定理（Master Theorem）把递归树分析一劳永逸地封装成公式：对形如 T(n) = aT(n/b) + f(n) 的递归式（a ≥ 1 个子问题，每个规模缩为 1/b，b > 1，f(n) 是分解合并代价），答案由 f(n) 与分水岭函数 nlogba 的对比决定。nlogba 不是凭空来的——它正是上一节算过的叶子个数：树高 logbn，叶子 alogbn = nlogba 个。所以三情形比的就是"根侧的合并代价 f(n)"和"叶侧的规模 nlogba"谁主导。

✅ 主定理（三情形）

设 a ≥ 1，b > 1，f(n) 渐近正，T(n) = aT(n/b) + f(n)：

  1. 情形 1（叶主导）：若 f(n) = O(nlogba − ε)，某 ε > 0，即 f 多项式地小于叶子，则 T(n) = Θ(nlogba)；
  2. 情形 2（均衡）：若 f(n) = Θ(nlogba)，每层一样多，则 T(n) = Θ(nlogba·lg n)；
  3. 情形 3（根主导）：若 f(n) = Ω(nlogba + ε)，某 ε > 0，且满足正则条件（Regularity Condition）a·f(n/b) ≤ c·f(n)（某 c < 1、n 足够大），则 T(n) = Θ(f(n))。

注意情形 1 和 3 里的 ε：f 与叶子的差距必须是多项式级（差 nε 倍），只差一点对数因子不算——这是 2.5 节缝隙的来源。正则条件则保证"几何递减"在每层都成立，防止 f 锯齿形抖动破坏根主导。

数值例 A：T(n) = 9T(n/3) + n。a = 9，b = 3，分水岭 nlog₃9 = n²（log₃9 = 2）。f(n) = n = O(n2−1)，取 ε = 1，多项式地小于 n² → 情形 1 → T(n) = Θ(n²)。直觉：9 个儿子只缩 1/3，叶子 n² 个淹没一切。

数值例 B：T(n) = T(2n/3) + 1。a = 1，b = 3/2，分水岭 nlog3/21 = n⁰ = 1（任何数的 log 为 0）。f(n) = 1 = Θ(1) → 情形 2 → T(n) = Θ(lg n)。这就是"每层 1 份活、共 log3/2n 层"——二分查找型递归的模样。

数值例 C：T(n) = 3T(n/4) + n·lg n。a = 3，b = 4，分水岭 nlog₄3 ≈ n0.79。f(n) = n·lg n 比 n0.79 大，且 n·lg n = Ω(n0.79+ε)（如 ε = 0.1，n·lg n 增长快过 n0.89）→ 候选情形 3。还必须验正则条件：3·f(n/4) = 3·(n/4)·lg(n/4) = (3/4)n·(lg n − 2) ≤ (3/4)·n·lg n，取 c = 3/4 < 1 成立 → 情形 3 → T(n) = Θ(n lg n)。

💡 关键一跃

主定理使用的三步口诀：① 读出 a、b、f(n)；② 算分水岭 nlogba；③ 比大小定情形。比的时候先问"是不是差了一个 nε"，再（情形 3）补验正则条件。熟练后 30 秒一题。

⚠️ 常见误区

① 情形 3 忘记验正则条件就下结论——存在 f 满足 Ω 条件但正则条件失败的反例（见 2.5）；② 把"渐近更大"当"多项式更大"：f(n) = n·lg n 渐近大于 n，但比值只是 lg n 而非 nε，此时主定理情形 3 不可用；③ 看错 b：T(n) = T(2n/3) 的 b 是 3/2 不是 2/3，b 必须 > 1。

情形1：f = O(nlogba−ε) → Θ(nlogba)；情形2：f = Θ(nlogba) → Θ(nlogba lg n)；情形3：f = Ω(nlogba+ε) 且 a·f(n/b) ≤ c·f(n) → Θ(f)。分水岭 = 叶子个数。

2.5查表查不到的时候：主定理的缝隙

主定理好用，但它是一张"留了空白的地图"：情形之间、条件之外都有缝隙。本节给出一个掉进缝隙的经典递归式，并展示没有主定理时怎么办——退回递归树，一切照旧。

反例：T(n) = 2T(n/2) + n·lg n。按口诀走：a = 2，b = 2，分水岭 nlog₂2 = n。f(n) = n·lg n 与 n 比：

  • 情形 1？f 比 n 大，不是小，排除；
  • 情形 2？f 不是 Θ(n)，多了个 lg n 因子，排除；
  • 情形 3？f 渐近大于 n，但 f/n = lg n 不是多项式因子 nε：对任何 ε > 0，lg n 最终都长不过 nε，所以 f(n) ≠ Ω(n1+ε)，排除。

三扇门全关——它落在情形 2 与情形 3 之间的缝隙里，主定理不适用。

退回递归树手算。每个节点 2 个儿子、规模减半、本节点合并代价为"该点规模 × lg 该点规模"。第 i 层：2i 个节点，单点规模 n/2i，单点代价 (n/2i)·lg(n/2i)：

层号 i节点数单点规模本层总代价
i = 01nn·lg n
i = 12n/2n·(lg n − 1)
i = 24n/4n·(lg n − 2)
i2in/2in·(lg n − i)
lg n − 1n/22n·1

通用式：2i·(n/2i)·lg(n/2i) = n·(lg n − i)。树高 lg n（叶层规模 1，n 个叶子，叶子代价 Θ(n)）。内部各层相加：

∑i=0…lg n−1 n·(lg n − i) = n·∑k=1…lg n k = n · lg n·(lg n + 1)2 = Θ(n·lg² n)

（换元 k = lg n − i，等差数列 1+2+…+lg n = lg n·(lg n+1)/2。）叶子 Θ(n) 被吸收，答案 T(n) = Θ(n·lg² n)。直观看：层代价从 n·lg n 缓慢降到 n，既不递增也不几何递减，而是"每层都差不多 n·lg n 量级、共 lg n 层"，比情形 2 多出一个 lg n 因子。

另一类缝隙是正则条件失败：如 T(n) = 2T(n/2) + n·sin n 这类 f 周期性摆动的递归式，f 既不渐近正、也不满足 af(n/b) ≤ cf(n)，主定理同样沉默。记住教训：查表前先验条件，条件不成立就回递归树——递归树是永远可用的兜底方法。

⚠️ 常见误区

看到 f 渐近大于分水岭就套情形 3。T(n) = 2T(n/2) + n·lg n 正是为此准备的考题：n·lg n 渐近大于 n，但差距 lg n 不是多项式，情形 3 够不着。判定口诀：先算比值 f(n)/nlogba，再问"这个比值是 nε 吗？"——是常数走情形 2，是 nε 走情形 1 或 3，是 lg n 之类的对数因子→掉进缝隙，回递归树。

📝分层习题

L1 概念辨析递归式 T(n) = 2T(n/2) + n 与普通函数 f(n) = 2f(n/2) + n 在"求解"上有何本质区别？为什么说"递归式本身不是答案"？
提示

想一想：把 n 代入 f 和代入 T，得到的分别是什么？哪种表达式里"答案已经写在右边"，哪种还藏着未知数？

完整解答

普通函数 f(n) = 2f(n/2) + n 若真这样定义，同样是递归定义；这里的关键区别在我们如何对待它：递归式右边仍含 T 自身，代入一个 n 得到的不是数，而是"更小输入上的 T 值 + 已知项"，必须展开到基例或解成封闭形式（closed form，右边不再含 T）才有渐近结论。说"递归式不是答案"，是指它是问题的另一种表述：T(n) = 2T(n/2) + n 与 T(n) = Θ(n lg n) 描述同一算法，但前者不能直接和别的算法比快慢，后者能。本章三件工具（代入法/递归树/主定理）做的都是同一件事：把递归式翻译成封闭形式。易错点：把 T(n) = 2T(n/2) + n 当成"已经是 O(n lg n)"——式子里一个 Θ 都没有，谈不上结论。

L1 概念辨析判断正误并说明理由：① "T(n) = 2T(n/2) + n·lg n 中 f(n) 渐近大于 nlog₂2 = n，所以按主定理情形 3，T(n) = Θ(n·lg n)"。② "代入法证明中基例 n = 1 不满足猜测界，说明猜测错了，要重新猜。"
提示

① 情形 3 对 f 的要求是 Ω(nlogba + ε)——"渐近大"和"多项式地大"一样吗？② 渐近记号管不管有限个小 n？

完整解答

① 错。情形 3 要求 f(n) = Ω(nlogba + ε)，即差距必须是多项式因子 nε。这里 f/分水岭 = lg n，而对任何 ε > 0 都有 lg n = o(nε)，条件不成立，主定理不适用（缝隙）。真实答案是 Θ(n·lg² n)（见 2.5 节递归树）。该选项把"渐近更大"误当"多项式更大"，还多送了情形 3 一个它配不上的结论。② 错。基例失败首先应尝试基例后移：O 记号只约束 n 足够大之后的行为，改用 n = 2 作基例（T(2) = 4 ≤ 2c，c ≥ 2）即可修复，猜测本身是对的。只有当后移基例、加强归纳假设（如减去低阶项）都救不回来时，才说明猜测错了。

L2 手算推导用递归树求 T(n) = T(n/3) + T(2n/3) + cn 的渐近上界（忽略取整，子问题规模不必相同）。
提示

两个儿子规模不同，树是"歪"的：左边每步 ÷3，右边每步 ÷(3/2)。先问哪条路径最长（决定树高），再看每一层的总代价是多少——试着把第 0、1、2 层全加出来找规律。

完整解答

第 1 步，逐层代价。第 0 层：cn。第 1 层：c·(n/3) + c·(2n/3) = cn。第 2 层：c·(n/9) + c·(2n/9) + c·(2n/9) + c·(4n/9) = cn·(1/9+2/9+2/9+4/9) = cn。规律：只要一层上的节点都还"活着"（规模 ≥ 1），该层所有节点的规模之和恰为 n，故每个完整层的代价都是 cn。

第 2 步，树高。最浅路径走 ÷3：n/3i = 1 → i = log₃n；最深路径走 ÷(3/2)：n/(3/2)i = 1 → i = log3/2n。树高由最深路径定为 log3/2n（log₃n < log3/2n）。

第 3 步，上界求和。层数 ≤ log3/2n，每层代价 ≤ cn（靠底部的残缺层不足 cn），故 T(n) ≤ cn·log3/2n = cn·lg n / lg(3/2) ≈ 1.71·cn·lg n = O(n lg n)。配合下界：至少 log₃n 个完整层各贡献 cn，T(n) ≥ cn·log₃n = Ω(n lg n)，合起来 Θ(n lg n)。

注：这棵树正是 Ch3 快速排序"最坏 1/3-2/3 划分"的模型——即使划分歪成这样，代价仍只有 Θ(n lg n)，这就是快排对划分比例鲁棒的原因。

L2 手算推导用代入法证明 T(n) = 2T(⌊n/2⌋) + n = Ω(n lg n)。（与 2.2 节的上界合起来即得 Θ(n lg n)。）
提示

Ω 方向要猜 T(n) ≥ c·n·lg n（c > 0）。归纳步骤里注意 ⌊n/2⌋ ≥ (n−1)/2 ≥ n/3（n 足够大时）这类放缩；也试试更省事的：对 2 的幂次 n，⌊n/2⌋ = n/2 精确成立。

完整解答

猜：T(n) ≥ c·n·lg n，c > 0 待定。归纳假设：T(⌊n/2⌋) ≥ c·⌊n/2⌋·lg⌊n/2⌋。归纳步骤（n 为 2 的幂时最干净，⌊n/2⌋ = n/2）：

T(n) = 2T(n/2) + n ≥ 2·c·(n/2)·lg(n/2) + n = c·n·(lg n − 1) + n = c·n·lg n − c·n + n ≥ c·n·lg n，最后一步成立当且仅当 −cn + n ≥ 0，即 c ≤ 1。

基例：n = 2，T(2) = 2T(1) + 2 = 4 ≥ c·2·lg 2 = 2c，c ≤ 2，与 c ≤ 1 兼容，取 c = 1。结论：T(n) ≥ n·lg n（n ≥ 2），即 T(n) = Ω(n lg n)。合并 2.2 节的 O(n lg n)，得 T(n) = Θ(n lg n)。

对一般 n（非 2 的幂）：用 ⌊n/2⌋ ≥ n/3（n ≥ 3 时成立，因为 ⌊n/2⌋ ≥ (n−1)/2 ≥ n/3 ⟺ 3n−3 ≥ 2n ⟺ n ≥ 3），代入得 T(n) ≥ 2c(n/3)lg(n/3) + n = (2c/3)n·lg n − (2c/3)n·lg 3 + n，lg 3 ≈ 1.58 是常数，取 c 足够小（如 c = 1/2）后 −(2c/3)·1.58·n + n ≥ 0.47n > 0，结论不变。渐近分析里取整只影响常数，不影响阶。

L3 建模应用有序数组上的二分查找：每次与中间元素比较，不相等则递归查左半或右半。① 写出运行时间递归式；② 用主定理求解；③ 若把问题改成"最大子数组"的分治解法（答案要么全在左半、要么全在右半、要么跨越中点，跨中点情形需 Θ(n) 扫描），写出递归式并求解。
提示

二分查找：每次只进一个子问题（a = 1），规模减半，本层只做 O(1) 比较。最大子数组：两个子问题 + Θ(n) 的跨界合并——和归并排序同一个模板。

完整解答

① 二分查找：分解 Θ(1)，解决 T(n/2)，合并 Θ(1)，得 T(n) = T(n/2) + Θ(1)，基例 T(1) = Θ(1)。② 主定理：a = 1，b = 2，分水岭 nlog₂1 = n⁰ = 1，f(n) = Θ(1) 与分水岭同级 → 情形 2 → T(n) = Θ(lg n)。直观验证：每次砍掉一半，最多砍 lg n 次。

③ 最大子数组分治：分解 Θ(1)，解决 2T(n/2)，合并（跨中点向左向右各扫一遍）Θ(n)，得 T(n) = 2T(n/2) + Θ(n)——与归并排序完全同型。主定理：a = 2，b = 2，分水岭 nlog₂2 = n，f(n) = Θ(n) 同级 → 情形 2 → T(n) = Θ(n lg n)。对比：蛮力枚举所有子数组 O(n²)，分治降到 n lg n；预告：Ch8 动态规划（Kadane 算法）还能把它压到 Θ(n)。

本题的要害是识别结构：a（几个子问题）、b（规模缩小比例）、f(n)（本层干多少活）三个数读完，递归式自动成形，剩下的交给主定理。

解析：D 对。f/分水岭 = lg n 不是多项式因子 nε，卡在情形 2 与 3 之间的缝隙；递归树第 i 层代价 n(lg n − i)，求和 n·lg n·(lg n+1)/2 = Θ(n lg² n)。A 错：情形 3 要求 Ω(n1+ε)，"渐近大"不等于"多项式大"。B 错：情形 2 要求 f = Θ(n)，多个 lg n 因子就不算同级。C 错：f 比分水岭大而非小，方向都反了。
自测 5
T(n) = T(2n/3) + 1 用主定理解，结果是？
  • A. Θ(1)
  • B. Θ(lg n)
  • C. Θ(n)
  • D. 主定理不适用，因为 b 必须是整数
解析：B 对。a = 1，b = 3/2，分水岭 nlog3/21 = n⁰ = 1，f = 1 = Θ(1) 同级 → 情形 2 → Θ(lg n)，即二分查找型。A 错：Θ(1) 只是每层的代价，忘了乘层数 log3/2n。C 错：叶子只有 1 个（a = 1），不存在 n 个叶子来主导。D 错：主定理只要求 b > 1，3/2 完全合法。

句1：这章解决什么问题？——
参考答案：分治算法把时间写成了"自己引用自己"的递归式（如 T(n) = 2T(n/2) + Θ(n)），第1章的渐近记号只够描述、不够求解，本章解决"怎么把递归式解成封闭形式"。

句3：它和前后章怎么分工？——
参考答案：Ch1 给记号（怎么描述时间），本章给求解器（怎么求出时间）；Ch3 排序算法（归并/快排）的分析直接套用本章工具，快排的 1/3-2/3 歪树就是本章 L2 习题；Ch8 动态规划接手本章暴露的"子问题重叠时分治浪费"这一代价。
