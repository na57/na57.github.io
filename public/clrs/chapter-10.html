10.1为什么只讨论判定问题：优化问题的"降级"

第8、9章解决的都有多项式算法。本章面对的却是旅行商、布尔可满足这类"所有范式都失败"的问题。研究它们的第一步出人意料：把优化问题降级成判定问题。

判定问题（Decision Problem）：答案只有"是/否"的问题。任何优化问题都可配套一个判定版：

  • 优化：图 G 的最小顶点覆盖是多大？ → 判定：G 是否存在大小 ≤ k 的顶点覆盖？
  • 优化：最短环游路线多长？ → 判定：是否存在长度 ≤ B 的环游？

为什么"降级"不失一般性。两个方向的难度互相绑定：

  • 优化 ≥ 判定：会解优化就会解判定（算出最优值，与 k 比较即可）。
  • 判定 ≥ 优化（至多差对数倍）：会解判定，用二分查找 k（k 的范围多项式有界时），log 次调用即得最优值。

所以"判定版都难"⟹"优化版更难"——要证明一个优化问题难，只需证明它的判定版难。而判定问题的答案空间只有 {是, 否}，可以用形式语言精确化（一个判定问题 = 一个语言 L ⊆ {0,1}*），这是整个复杂度理论能数学化的原因。

💡 关键一跃

判定化不是把问题变弱，而是把"难度"这件事变得可定义、可比较。就像把"力气大"换成"能不能举起 100 公斤"——有了是非标准，才能排序。

⚠️ 常见误区

以为判定问题"太简单所以理论没意义"。恰恰相反：判定版是优化版的下界探针——判定版 NP 完全，优化版必然 NP 难。降级是为了证明难，不是为了求解。

10.2P、NP、NP 完全：三个类的精确定义

上一节把问题统一成判定形式。它带出一个问题："难"和"易"的边界画在哪？答案按"求解"与"验证"两种能力各画一条线。

P：存在多项式时间算法能求解的判定问题类。排序、最短路、LCS（判定版）都在 P 中——前九章的主角几乎全在这里。

NP（Nondeterministic Polynomial）：存在多项式长度的"证书"（certificate），可在多项式时间内验证"是"答案的判定问题类。例：顶点覆盖的证书就是那个顶点集——给我 k 个顶点，我 O(E) 就能检查它是否覆盖所有边。注意：验证容易 ≠ 求解容易。

P ⊆ NP 是显然的（能求解就能验证，证书都不需要）。P = NP？——"验证容易的问题是否求解也容易"——是计算机科学最大的未解之谜，悬赏百万美元，主流猜测是否定。

NP 完全（NP-Complete, NPC）：问题 L 满足两条：

  1. L ∈ NP（证书可验证）；
  2. 每个 NP 问题都能多项式归约到 L（L 是 NP 中"最难"的）。

推论极锋利：任何一个 NPC 问题若有多项式算法，则 P = NP，几千个难题一夜之间全部可解。所以"证明某问题是 NPC"在实践中等价于宣布"别找多项式精确算法了"。不在 NP 里但至少和 NPC 一样难的（如对应优化版）叫 NP 难（NP-Hard）。

✅ 判定规则

记忆锚点：P = 能快速解题；NP = 能快速验答案；NPC = NP 中人人可归约到它 = 最难的一群。P = NP 问的是"验题容易是否意味着解题容易"。

10.3多项式归约：3SAT → 独立集完整构造

上一节定义了"最难"，但定义里的条件②涉及"每个 NP 问题"，怎么可能逐一验证？它带出一个问题：如何证明一个具体问题是 NPC？工具是多项式归约（Polynomial-Time Reduction）：A ≤p B 表示"存在多项式可计算的变换 f，使 x 是 A 的是-实例 ⟺ f(x) 是 B 的是-实例"——即 A 不比 B 难。若已知 A 是 NPC 且 A ≤p B、B ∈ NP，则 B 也是 NPC。归约把"证明难"变成了"做一次构造"。

完整手算：3SAT ≤p 独立集。给定 3CNF 公式（每子句 3 个文字）：

φ = (x₁ ∨ x₂ ∨ x₃) ∧ (¬x₁ ∨ ¬x₂ ∨ x₃) ∧ (x₁ ∨ ¬x₂ ∨ ¬x₃)

构造（多项式时间）：每个子句建成一个三角形（3 个顶点互连，顶点 = 文字）；跨子句把每个文字与其所有否定形式连边（x₁ 与 ¬x₁ 连边等）。令 k = 子句数 = 3。

图 10.1 归约构造：每个子句一个三角形；虚线是跨子句的"矛盾边"（文字与其否定相连）。看：独立集大小能否达到 k=3？

双向论证：

  • φ 可满足 ⟹ 有大小 3 的独立集：取赋值 x₁=T, x₂=F, x₃=T。子句1 由 x₁ 满足，子句2 由 ¬x₂ 满足，子句3 由 x₁（或 ¬x₂）满足。从每个三角形各取一个"为真"的顶点：{x₁（句1), ¬x₂（句2), x₁（句3)}。三角形内只取一个（不互邻）；跨子句无矛盾边相连（赋值一致，不会同时取到 x 与 ¬x）。故是大小 3 的独立集。
  • 有大小 3 的独立集 ⟹ φ 可满足：独立集至多从每个三角形取一个顶点，取满 3 个必然每句一个；把取到的文字置真（矛盾边保证不会冲突），每个子句至少一个文字为真，φ 被满足。

构造规模：3k 个顶点、3k + O(文字对数) 条边，多项式。故 3SAT ≤p 独立集，独立集是 NPC。同理独立集 ≤p 顶点覆盖（S 是独立集 ⟺ V∖S 是顶点覆盖，k 换成 n−k），归约链继续生长。

💡 关键一跃

归约证明的方向感是新手最大的坑：要证新问题 B 难，是把已知难题 A 归约到 B（A ≤p B），即"B 强到能当 A 的解题器"。方向反了，整个证明作废。口诀：从已知难的，变到你想证的。

⚠️ 常见误区

忘记验证归约是多项式时间的。构造本身若需指数时间（如枚举所有赋值再画图），归约无效。所有构造步骤的复杂度必须明确报出——本例建图只需 O(k²) 扫文字对。

10.4顶点覆盖：2-近似完整手算

上一节证明了独立集、顶点覆盖是 NPC——精确求解无望（除非 P=NP）。它带出一个问题：工程上还要用，怎么办？答案是近似算法（Approximation Algorithm）：多项式时间给出保证不比最优差 ρ 倍的解，ρ 称近似比（Approximation Ratio）。

顶点覆盖的 2-近似算法（CLRS 的 APPROX-VERTEX-COVER）：

  1. C ← ∅；E′ ← E 的副本。
  2. 当 E′ 非空：任取一条边 (u,v)，把 u 和 v 都加入 C；从 E′ 删去所有与 u 或 v 关联的边。
  3. 返回 C。

完整手算。取路径图 a—b—c—d—e（5 个顶点，4 条边）：

  • 取边 (a,b)：C = {a,b}；删去 (a,b)、(b,c)。剩余 (c,d)、(d,e)。
  • 取边 (c,d)：C = {a,b,c,d}；删去 (c,d)、(d,e)。E′ 空，结束。

算法给出大小 4 的覆盖。最优解是 {b, d}（验证：b 覆盖 (a,b)、(b,c)；d 覆盖 (c,d)、(d,e)），大小 2。比值 4/2 = 2，恰好打满保证。

为什么至多 2 倍。算法取出的边集合 M 是一个匹配（两两无公共端点——因为取完就删关联边）。任何顶点覆盖至少要覆盖 M 中每条边，而匹配边互不共享端点，故 OPT ≥ |M|。算法 |C| = 2|M| ≤ 2·OPT。∎

💡 关键一跃

近似比证明的通用骨架：找一个可计算的下界 L ≤ OPT，再证算法输出 ≤ ρ·L。这里 L = |M|（匹配大小）。你不需要知道 OPT 是多少，只需要一个"OPT 不可能低于它"的锚点。

10.5Cook-Levin 与装箱：归约链的起点与另一条近似

上一节用了"已知 NPC 问题"，但归约链总得有个起点——第一个被证明 NPC 的问题从哪来？这就是 Cook-Levin 定理（1971）：

✅ 一句话含义

布尔可满足问题 SAT 是 NP 完全的。证明思路一句话版：任何 NP 问题的验证器都是多项式规模电路，把"存在一个证书使电路输出 1"整个编码成一个布尔公式——于是所有 NP 问题归约到 SAT。从此不再需要碰验证器：由 SAT 归约出 3SAT，再由 3SAT 长出独立集、顶点覆盖、团、哈密顿回路、TSP……整棵 NPC 家族树。

另一条近似线：装箱问题（Bin Packing）。物品大小 s₁…sₙ ∈ (0,1]，箱子容量 1，用最少的箱子装完。判定版是 NPC，精确无望。用首次适配（First Fit, FF）：按顺序处理物品，每个放入第一个装得下的箱子，都装不下才开新箱。

完整手算。物品序列：0.2, 0.5, 0.4, 0.7, 0.1, 0.3, 0.8（容量 1）：

  • 0.2 → 箱1（余 0.8）；0.5 → 箱1（余 0.3）；0.4 → 箱1 放不下，开 箱2（余 0.6）；
  • 0.7 → 箱1、箱2 都放不下，开 箱3（余 0.3）；0.1 → 箱1（余 0.2）；
  • 0.3 → 箱1 余 0.2 放不下 → 箱2（余 0.3）；0.8 → 箱1/2/3 都放不下，开 箱4。

FF 用 4 箱：{0.2,0.5,0.1}、{0.4,0.3}、{0.7}、{0.8}。最优 3 箱：{0.2,0.8}、{0.5,0.4,0.1}、{0.7,0.3}。

近似比证明（FF ≤ 2·OPT）。关键观察：FF 结束时，至多一个箱子装了不到一半——若有两个箱子 B₁、B₂ 都不到一半，B₂ 的第一个物品本可放入 B₁，矛盾。故 Σsᵢ > (FF−1)/2。而 OPT ≥ Σsᵢ（容量约束），得 FF < 2·Σsᵢ + 1 ≤ 2·OPT + 1，渐近近似比 2。

⚠️ 常见误区

以为"NPC 问题都有近似算法"。远非如此：TSP（无边权三角不等式）与最大团在 P≠NP 下任何常数近似比都不可达。难解性是分层的：有的可常数近似（顶点覆盖 2）、有的可对数近似（集合覆盖 ln n）、有的完全不可近似。证明 NPC 只是第一步，查它的可近似性才是工程起点。

合上书回答。这三问不是考点，是你带走全书的方式。

毕业第一问面对一个从未见过的计算问题，你的完整决策顺序是什么？
参考答案
① 先形式化：输入输出是什么、优化还是判定；② 找结构：有无最优子结构（→DP）、贪心选择性质（→贪心）、图结构（→第6、7章工具）、可序性（→排序检索工具）；③ 都无则怀疑难解：尝试从已知 NPC 问题归约证明之；④ 证明是 NPC 后不退场：查可近似性，上近似算法或指数精确算法（分支限界），并用摊还/复杂度语言报告代价。整条链就是全书目录的倒序使用。
毕业第二问"这个问题很难"在算法语言里到底意味着什么？和"我还没想到好算法"有什么区别？
参考答案
"很难"= 该问题（的判定版）被证明是 NP 完全的：它和 SAT、TSP 等几千个问题多项式等价，其中任何一个有多项式算法则全部有。这把"我没想到"的个人困境升级为"整个人类没想到"的客观证据——这就是归约的意义：把无能为力的责任从算法设计者转移到问题本身的结构上。而"我还没想到"只是尚未找到结构，两种状态用一次归约尝试来区分。
毕业第三问用一句话串起全书十章——这门课到底在教什么？
参考答案
参考答案：这门课教的是一套"问题—结构—代价"的翻译术——先给代价精确计价（①），再发现问题的结构决定代价的下限与算法上限（②③），最后用 DP/贪心榨干结构、用 NPC/近似承认并管理结构的尽头（④）；算法是表象，结构才是本体。

🃏概念卡：本章概念的一分钟画像

翻面前先自问：这个概念我能用一句话讲清楚吗？

概念卡 1
P（Polynomial Time）
点击翻面 →
定义存在多项式时间算法求解的判定问题类。
解决问题给"易解"一个精确定义，是复杂度分层的地基层。
直觉能直接考及格的科目。
误区以为 P = "实际够快"——n¹⁰⁰ 也在 P 中；它是理论边界，非工程边界。
何时用全书前九章的算法都是 P 成员的存在性证明。
概念卡 2
NP 与证书（Nondeterministic Polynomial / Certificate）
点击翻面 →
定义"是"实例有多项式长度证书、可多项式验证的判定问题类。
解决问题给"验证容易"下定义，从而把"求解可能很难"的问题圈进来。
直觉数独：填出来难，检查别人的答案容易。
误区以为 NP = "非多项式"——它是"非确定多项式"，P ⊆ NP。
何时用证 NPC 的第一步永远是先证"属于 NP"（给出证书与验证器）。
概念卡 3
多项式归约（Polynomial-Time Reduction）
点击翻面 →
定义A ≤p B：存在多项式变换 f，x∈A ⟺ f(x)∈B。
解决问题把"证明一个新问题难"变成"做一次构造"，难度得以传递。
直觉翻译器：能把中文题自动译成英文题，则英文题不比中文题容易。
误区方向搞反：证 B 难要把已知难的 A 归约到 B，不是从 B 出发。
何时用一切 NPC 证明的第二步；也用于算法复用（把新问题译成已解问题）。
概念卡 4
NP 完全（NP-Complete）
点击翻面 →
定义属于 NP 且所有 NP 问题都可归约到它的问题类。
解决问题给"难"提供可证明的客观标准，终止无效的多项式算法搜寻。
直觉几千把锁共用同一把钥匙：开任何一把 = 开所有。
误区以为 NPC 是"最难的问题"——它只是 NP 中最难；NP 之外还有更难的类。
何时用顶点覆盖、独立集、3SAT、TSP（判定版）、装箱……实践中"宣布放弃精确解"的依据。
概念卡 5
Cook-Levin 定理（Cook-Levin Theorem）
点击翻面 →
定义SAT 是 NP 完全的（1971，Cook；Levin 独立证明）。
解决问题提供归约链的起点，之后所有 NPC 证明不再需要直接面对"所有 NP 问题"。
直觉第一个被证明"全能"的翻译目标：验证电路本身可以写成公式。
误区以为它给 SAT 找了快速算法——恰恰相反，它给 SAT 发了"最难"证书。
何时用复杂度理论的基石；理解"为什么 3SAT 是归约的通用出发点"。
概念卡 6
近似算法与近似比（Approximation Algorithm / Ratio）
点击翻面 →
定义多项式时间给出保证 ≤ρ·OPT（最小化）的解；ρ 为近似比。
解决问题NPC 问题的工程退路：不要最优，要有质量担保的够用。
直觉买不起正品就买个有检测报告的平替——报告就是 ρ。
误区以为所有 NPC 问题都可近似——最大团等连常数比都不可达（P≠NP 下）。
何时用顶点覆盖 2-近似、装箱 FF 2-近似、度量 TSP 1.5-近似（Christofides）。

📝分层习题

L1 概念辨析判断：因为顶点覆盖是 NP 完全的，所以任何顶点覆盖实例都不可能在多项式时间内求解。
提示

NPC 说的是"所有实例"还是"存在一族实例"？想想二分图。

完整解答
错。NPC 是最坏情况复杂性：存在一族难实例，不代表每个实例都难。二分图上的顶点覆盖有多项式算法（Kőnig 定理：等于最大匹配）。易错点：把"最坏情况难"误读为"处处难"——实践中大量实例（稀疏图、小规模）依然可解。
L1 概念辨析判断：已知 A ≤p B 且 A ∈ P，则 B ∈ P。
提示

归约传递的是哪个方向的难度信息？"A 不比 B 难"说明谁更难？

完整解答
错。A ≤p B 的意思是 A 不比 B 难（B 至少和 A 一样难）。A 容易完全管不住 B：把排序归约到顶点覆盖也是合法归约，但 B 依然可以是 NPC。正确方向是：A ≤p B 且 B ∈ P ⟹ A ∈ P；或 A ≤p B 且 A 是 NPC 且 B∈NP ⟹ B 是 NPC。易错点：把归约当成"难度从 A 流向 B"的箭头，实际流动方向相反。
L2 手算推导对公式 φ = (x₁ ∨ x₂ ∨ ¬x₃) ∧ (¬x₁ ∨ ¬x₂ ∨ x₃) 执行 3SAT→独立集归约：画出图的结构描述（顶点、两类边），给出 k，并用满足赋值 x₁=T, x₂=T, x₃=T 找出对应的独立集。
提示

两个子句 = 两个三角形；矛盾边只连文字与其否定。赋值下每个子句哪些文字为真？

完整解答
顶点：句1 {x₁, x₂, ¬x₃}，句2 {¬x₁, ¬x₂, x₃}，共 6 个；k = 2。
三角形边：句1 三顶点两两相连；句2 同理。
矛盾边：x₁—¬x₁，x₂—¬x₂，¬x₃—x₃，共 3 条。
赋值 x₁=x₂=x₃=T：句1 中 x₁、x₂ 为真；句2 中 x₃ 为真。取独立集 {x₂（句1）, x₃（句2）}：不同三角形 ✓；二者间无矛盾边（x₂ 的否定 ¬x₂ 不在其中，x₃ 的否定 ¬x₃ 不在其中）✓。大小 2 = k，归约验证通过。
L2 手算推导在星图上运行顶点覆盖 2-近似：中心 c 连接叶子 v₁, v₂, v₃（共 3 条边）。给出算法可能的最坏输出与最优解，验证近似比不超过 2。
提示

算法的取边顺序是任意的——若第一步取 (c,v₁)，会发生什么？最优覆盖是哪个顶点？

完整解答
最坏执行：取边 (c,v₁) → C={c,v₁}，删去所有与 c、v₁ 关联的边——三条边全被删除（都关联 c），E′ 空，算法结束。输出大小 2。
最优解：{c}，大小 1（中心一个顶点覆盖所有边）。
比值 2/1 = 2，恰好达到近似比上界。这个例子说明 2-近似的界是紧的（tight）：存在实例让算法打满保证，分析无法再改进。
L3 建模应用你的团队要为物流公司做"车辆装载系统"：n 件货物（各有重量）、若干载重上限相同的卡车，目标用最少卡车运完。产品经理问："这周能上线精确最优版吗？"请用本章语言写一段回复：问题的判定版叫什么、属于哪个类、依据是什么；上线方案推荐什么算法、能承诺什么。
提示

把"最少卡车"改写成判定版；从哪个已知 NPC 问题能归约过来？工程上用什么近似？

完整解答
回复要点：
① 这是装箱问题（Bin Packing）。判定版："能否用 k 辆卡车装完"是 NP 完全的（可由划分问题 PARTITION 归约：k=2 的特例已是 NPC）。
② 因此在 P≠NP 的主流假设下，不存在多项式精确算法，"本周上线精确最优版"在原理上不可行（不是工期问题，是问题结构问题）——这就是"难"的客观含义，可以用归约链向上级解释。
③ 上线方案：First Fit Decreasing（先按重量降序排再 FF），可承诺渐近近似比 11/9·OPT+1（经典结果），实现成本一天以内；货物规模小（n≤20）时也可用分支限界给精确解。
④ 若需更强保证，报告应写明"近似比 ρ"而非含糊的"基本够用"。

自测 1
NP 的准确定义是？
  • A. 不存在多项式算法的问题类
  • B. 需要非确定性机器才能求解的问题类
  • C. "是"实例有多项式长度证书且可多项式验证的判定问题类
  • D. 所有指数时间问题的类
解析：C 对。A 错——NP 含 P（P 的问题也有证书：不用证书直接算）；B 错——非确定性是历史定义，且非确定机不是真实机器，证书定义才是工作定义；D 错——NP 与指数时间没有包含关系（NP 中也有 P 的问题，指数类 EXP 严格更大）。
自测 2
要证明新问题 B 是 NP 完全的，正确的步骤组合是？
  • A. 证明 B ≤p 3SAT，且 B ∈ NP
  • B. 证明 3SAT ≤p B（多项式构造 + 双向等价论证），且 B ∈ NP
  • C. 证明 B ≤p 3SAT 即可
  • D. 找到 B 的一个指数算法
解析：B 对——方向是"已知难的归约到 B"，加上 B∈NP 与归约的多项式性。A 错——方向反了，B≤p3SAT 只说明 B 不比 3SAT 难（所有 NP 问题都满足）；C 错——同 A 且缺成员性；D 错——NPC 问题都有平凡指数算法，这证明不了任何事。
自测 3
3SAT→独立集归约中，跨子句的"矛盾边"连接的是？
  • A. 每个文字与其所有否定形式（x 与 ¬x）
  • B. 相邻子句的对应位置文字
  • C. 所有含相同变量的顶点，无论正负
  • D. 每个子句的第一个文字
解析：A 对——矛盾边保证独立集取出的文字集合不自相矛盾，从而能翻译成合法赋值。B、D 错——无此构造，无法保证一致性；C 错——把 x 与 x 也连边会导致同一变量永远只能出现在一个子句的选择里，归约的双向等价立刻破裂。
自测 4
顶点覆盖 2-近似算法的正确性证明依赖于？
  • A. 贪心选择性质与交换论证
  • B. 最优子结构与重叠子问题
  • C. 势能法
  • D. 算法取出的边构成匹配 M，OPT ≥ |M| 且输出 |C| = 2|M|
解析：D 对——"可计算下界锚点"技术。A 错——该算法不是精确贪心，没有交换论证位置；B 错——顶点覆盖是 NPC，没有多项式 DP；C 错——势能法是摊还分析工具，与近似比无关。
自测 5
Cook-Levin 定理在 NP 完全理论中的作用是？
  • A. 证明了 P ≠ NP
  • B. 给出第一个 NPC 问题 SAT（所有 NP 验证器可编码为布尔公式），成为归约链起点
  • C. 给出 SAT 的多项式算法
  • D. 证明 3SAT 比 SAT 更难
