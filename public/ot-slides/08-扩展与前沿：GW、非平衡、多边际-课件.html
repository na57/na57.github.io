定义

没有共同坐标，就比「内部距离结构」——GW 的二次分配形式

🧭 多输入什么
两个内部距离矩阵 d_X、d_Y（加各自权重 a、b）。比较对象从「坐标」升级成「关系」：度量空间 + 分布（metric measure space）。
🛡️ 免疫什么
刚体变换与重标号。GW = 0 ⟺ 两空间等距同构（允许旋转、平移、置换）——形状匹配要的正是它。
$$\boldsymbol{GW^2(a,b)=\min_{\pi\in\Pi(a,b)}\ \sum_{i,j,k,l}\bigl|\,d_X(x_i,x_k)-d_Y(y_j,y_l)\,\bigr|^2\,\pi_{ij}\,\pi_{kl}}$$
读法：π 把 x_i 配给 y_j、把 x_k 配给 y_l，两对的「内部距离」一致就零惩罚——π 的任务是保结构：近者仍配近者，远者仍配远者。
特性

GW = 0 ⟺ 等距同构；代价是二次非凸，只有局部最优

✅ 特性面
GW = 0 ⟺ 两空间经重标号与刚体变换后完全重合。旋转、平移、换坐标系，GW 纹丝不动。
⚠️ 代价面
目标含 π_ij·π_kl 是 π 的二次函数 → 二次分配问题（Quadratic Assignment Problem, QAP）：非凸、NP-hard，无全局最优保证。
$$\text{固定点迭代（Fixed-point Iteration）：}\ \ M^{n}_{ij}=\textstyle\sum\limits_{k,l}\bigl(d_X(i,k)-d_Y(j,l)\bigr)^{2}\,\pi^{n}_{kl},\qquad \pi^{n+1}=\arg\min_{\pi\in\Pi(a,b)}\ \bigl\langle M^{n},\,\pi\bigr\rangle$$
每步只解一个第3、4章就会的线性 OT——新问题的内循环全是老算法。
推导

一步固定点迭代：M 的对角 0.5、交叉 2.5，一步收敛，GW² = 0.5

设定：d_X = [[0,1],[1,0]]，d_Y = [[0,2],[2,0]]，a = b = (0.5,0.5)，π⁰ = diag(0.5)（x₁↔y₁、x₂↔y₂）。

✍️
暂停推导

先自己动手：梯度成本 M 的四格、π¹、GW² 三个结果都写下来，再对答案。

① 梯度成本 M_ij = Σ_{k,l}(d_X(i,k)−d_Y(j,l))²π⁰_kl；π⁰ 只有对角两项 0.5：

$$M_{ij}=0.5\,\bigl(d_X(i,1)-d_Y(j,1)\bigr)^{2}+0.5\,\bigl(d_X(i,2)-d_Y(j,2)\bigr)^{2}$$

② 逐元素代入（对称，只算两格）：M₁₁ = 0.5·0²+0.5·(−1)² = 0.5，M₁₂ = 0.5·(−2)²+0.5·1² = 2.5

$$M=\begin{pmatrix}0.5 & 2.5\\ 2.5 & 0.5\end{pmatrix}$$

③ 解线性 OT min⟨M,π⟩：对角成本 0.5 远低于交叉 2.5，最优保持对角 ⟹ $\pi^{1}=\mathrm{diag}(0.5)=\pi^{0}$，一步收敛到固定点

$$\boldsymbol{GW^{2}=(1-2)^{2}\cdot 0.5\cdot 0.5+(1-2)^{2}\cdot 0.5\cdot 0.5=0.25+0.25=0.5}\ \ \text{结构对、尺度错：0.5 精确度量失配}$$

非凸

换个初值就换个答案——非凸的代价是多解，不是报错

🔁 反对角初值重算
π⁰ = [[0, 0.5],[0.5, 0]] ⟹ M = [[2.5, 0.5],[0.5, 2.5]] ⟹ π¹ = π⁰（保持反对角），GW² = 0.25 + 0.25 = 0.5——本例两空间对称，数值与对角初值相同纯属巧合。
🎯 一般问题的后果
不同初值收敛到 GW² 不同的局部极小——没有全局保证，答案依赖初值。
⚠️ 工程对策：多初值重启，取 GW 值最小者。切记：「一步收敛」≠「全局最优」，它只说明初值已经坐在某个局部极小上。
回头看上一页：M 的对角与交叉正好互换——初值坐到哪一侧，解就留在哪一侧。
定义

质量不守恒时，把硬约束换成软惩罚——KL 松弛两条边际

🛠️ 修法
硬等式 P𝟙 = a 降级为散度惩罚：允许偏离、按偏离付费。KL 用非归一化版本 KL(u‖v) = Σ u log(u/v) − u + v（也可换 TV）。
💱 τ 的角色
边际违规单价 = 质量生灭的「汇率」。τ → ∞ 收回经典 OT（不敢偏离）；τ 有限时搬运太贵就让质量就地产生或湮灭。
$$\boldsymbol{\min_{P\geq 0}\ \ \langle C,\,P\rangle\;+\;\tau\,\mathrm{KL}\bigl(P\mathbb{1}\,\bigl\|\,a\bigr)\;+\;\tau\,\mathrm{KL}\bigl(P^{T}\mathbb{1}\,\bigl\|\,b\bigr)}$$
读法：OT 从「守恒搬运」变成「搬运与买卖的混合经济」——非平衡 OT（Unbalanced OT）的全部价值在于保留并定价质量差。
手算

最优质量是几何平均：m = √2，生灭各付一半罚款

一点情形：a = 1·δ₀，b = 2·δ₀（同一点，目标要求两倍质量），c(0,0) = 0。设 P 在 (0,0) 放质量 m。

① 目标 = 两笔 KL 罚款之和

$$f(m)=\tau\,\bigl(m\log m-m+1\bigr)+\tau\,\Bigl(m\log\tfrac{m}{2}-m+2\Bigr)$$

② 一阶条件：两笔各贡献一个 log

$$f'(m)=\tau\log m+\tau\log\tfrac{m}{2}=\tau\log\tfrac{m^{2}}{2}=0\ \ \Longrightarrow\ \ m^{2}=2$$
$$\boldsymbol{m=\sqrt{2}\approx 1.414}\ \ \text{源头「多产」}0.414\text{、终端「少收」}0.586\text{——质量在最优处被创造出来}$$
τ 越大罚款越贵，m 越贴近「少创造、多搬运」的经典行为。

算法

算法不用换——交替缩放骨架不变，只是缩放带上幂 τ/(τ+ε)

$$\boldsymbol{u\;\leftarrow\;\Bigl(\frac{a}{Kv}\Bigr)^{\frac{\tau}{\tau+\varepsilon}},\qquad v\;\leftarrow\;\Bigl(\frac{b}{K^{T}u}\Bigr)^{\frac{\tau}{\tau+\varepsilon}}}$$
🔢 幂的读法
τ/(τ+ε) ∈ (0,1)：每步只朝硬边际走一部分，剩余偏差被允许保留；τ → ∞ 时幂趋 1，收回第4章标准 Sinkhorn。
🦴 骨架弹性
KL 换成 TV，缩放公式再变一轮，「交替缩放」骨架不动——软约束直接写进了指数里。
广义 Sinkhorn（Generalized Sinkhorn）：记住这句话——软约束没有改流程图，而是写进了迭代的幂。
应用

单细胞 RNA 轨迹：细胞会分裂，所以必须非平衡

🧬 问题
测「昨天」「今天」两批细胞的基因表达，推断每个细胞从哪个祖先分化而来，拼出发育轨迹。细胞分裂使总质量增长——增殖率正是最要紧的信号。
🧭 方案：Waddington-OT
非平衡 OT + KL 松弛：「今天的细胞」允许比「昨天的」多，多出的质量按 τ 定价；τ 按增殖率先验标定，绝不先归一化。
💡 统一视角：边际约束从「等式」降级为「散度惩罚」，τ 就是汇率——搬运成本与质量生灭成本在市场上竞争。
⚠️ 先归一化再跑经典 OT = 把增殖信号当噪声洗掉——这正是非平衡 OT 要防的头号误操作（误区页还会再敲一次）。
定义

k 个分布一起对齐——两条边际约束升级为 k 条

$$\boldsymbol{\min_{\pi\in\Pi(a_1,\dots,a_k)}\ \ \int c\bigl(x_1,\dots,x_k\bigr)\,d\pi\bigl(x_1,\dots,x_k\bigr)}$$
📦 可行集
π 的 k 条轴向边际（沿每个坐标轴投影）分别等于 a₁…a_k；π(x₁,…,x_k) = k 个分布各出一点、组成「对齐 k 元组」的概率。
🚫 为什么不能拆
两两对齐无传递性：A↔B、B↔C 不蕴含三方一致——只有 k 元张量上的联合约束能表达「全体一致」。
多边际 OT（Multi-marginal OT）：第2章的两条边际埋下全书所有推广的接口——本章把它升到 k 条。
特例

重心 = 多边际 OT 的均值投影——共识免费、分歧纳税

$$c\bigl(x_1,\dots,x_k\bigr)=\sum_{i=1}^{k}\bigl\|x_i-\bar{x}\bigr\|^{2},\quad \bar{x}=\tfrac{1}{k}\textstyle\sum\limits_{i}x_i\ \ \Rightarrow\ \ \text{解的 }k\text{ 元组均值按 }\pi\text{ 加权 }=\text{Wasserstein 重心（Agueh–Carlier）}$$
✅ 手算：k = 3，三个分布在 {0,1} 上各半——共识组 (0,0,0)、(1,1,1)：x̄ = 0 或 1，c = 0；混合组如 (0,0,1)：x̄ = 1/3，c = 1/9 + 1/9 + 4/9 = 2/3（对称地 6 组皆 2/3）。π 在两个共识组各放 0.5 ⟹ 每条边际投影 (0.5, 0.5) ✓，总成本 0，c ≥ 0 ⟹ 全局最优。
读法：三方完全一致时对齐免费；任何「意见不合」的 k 元组按到均值的距离付分裂税——重心成本结构奖励共识、惩罚分歧。
算法

代价是 O(nᵏ) 组合爆炸；救场还是熵正则，k 个缩放向量

💥 爆炸账
π 是 nᵏ 维张量，边际约束 k·n 条；n = 100、k = 5 ⟹ 10¹⁰ 个变量，LP 直接无解。
🔁 多边际 Sinkhorn
熵正则后 π = diag(u₁) K diag(u₂)…diag(u_k)，K = exp(−C/ε) 是 k 维核张量；k 个缩放向量交替更新——固定其余、让对应边际达标。
⚠️ 代价照旧：ε 引入偏差（第4章的账），张量存储 O(nᵏ) 仍在——实践中常用低秩 / 采样近似绕开显式张量。
骨架还是第4章那个交替缩放，只是缩放向量从 2 个升成 k 个——多边际 Sinkhorn（Multi-marginal Sinkhorn）。
前沿

W₂² 的另一副面孔：把分布「流」过去的最小动能

$$\boldsymbol{W_2^{2}(\rho_0,\rho_1)=\min_{(\rho,\,v)}\ \int_0^{1}\!\!\int\bigl\|v(x,t)\bigr\|^{2}\,\rho(x,t)\,dx\,dt},\qquad \text{约束：}\ \ \partial_t\rho+\nabla\cdot\bigl(\rho v\bigr)=0$$
🌊 读法
在所有把 ρ₀ 连续演化到 ρ₁ 的速度场 v 中，取动能最小者；连续性方程 = 质量守恒的微分形式。
🔗 接回第5章
位移插值正是沿测地线的等速流——Benamou–Brenier 公式是 W₂ 的动态定义，不是新距离。
这条公式把 OT 接进流体力学与扩散——静态最优与动态演化在这里握手。
前沿

JKO 格式：W₂ 当惯性、能量当驱动力，PDE 变成梯度下降

$$\boldsymbol{\rho^{\,n+1}=\arg\min_{\rho}\ \ \frac{W_2^{2}\bigl(\rho,\,\rho^{\,n}\bigr)}{2h}+F(\rho)}$$
🔁 在做什么
每个时间步解一次「贴近上一步（W₂²/(2h) 惯性）＋ 能量下降（F 驱动）」的平衡问题——模拟热方程、多孔介质方程等扩散/聚集过程。
🚪 为什么深
Wasserstein 几何让一大类 PDE 变成梯度流——OT 通向分析学的大门，全书「几何」二字最深的兑现。
JKO 格式（Jordan–Kinderlehrer–Otto Scheme）：梯度流视角下，扩散方程就是 Wasserstein 空间里的梯度下降。
避坑

本章三颗雷：GW 套距离性质、归一化洗信号、τ 取默认

❌ 把 GW 当普通距离，直接套第5章 W_p 的性质
✅ GW² 是二次非凸目标：固定点迭代只到局部极小，初值不同答案不同；且 GW 只定义在等距同构类上——旋转镜像后重合的形状 GW = 0，要区分朝向的任务里它是盲区。
❌ 先归一化到总质量 1，再跑经典 Sinkhorn
✅ 归一化把「质量差」这个最重要的信号（细胞增殖率、遮挡比例）当噪声洗掉了——非平衡 OT 的全部价值恰在于保留并定价这个差。
❌ τ 取默认值直接跑非平衡 OT
✅ τ 是物理量（每公斤质量生灭的价格），必须按场景标定：τ 太小什么都不搬、全靠就地生灭，τ → ∞ 才收回经典行为。

小结

三句话讲完第8章

1解决什么：三条隐藏假设（同一空间、质量守恒、两两对齐）被现实撕掉——跨空间、质量生灭、多方对齐各配一个扩展。
2核心机制：GW 比内部距离结构（非凸，固定点迭代每步解线性 OT）；非平衡用 KL 松弛（τ 定价生灭，缩放带幂）；多边际约束 k 条边际（重心是特例）。
3主线收束：主线问题已答——拆假设 OT 照样能打；遗留问题——非凸无全局保证、O(nᵏ) 爆炸、τ 标定，前沿指向梯度流与 PDE。
