动机

n² 个变量不可怕，没结构才可怕

第2章把 OT 写成了 LP，但规模摆在眼前——n = 10⁵（一张 300×300 图像的像素数）时：

$$\text{变量 } n^2 = 10^{10}\ \text{个}, \qquad \text{成本矩阵存储} \sim 80\,\text{GB}$$
😇 调通用 LP 求解器硬算
不把运输结构当回事，白白浪费稀疏基与全幺模两大红利。
🙂 担心要做整数规划
完全不用——全幺模保证 LP 松弛自动给出整数解。
💡 本章方案：把运输结构榨干——稀疏基 + 专用单纯形，先能手算，再谈扩展。
定义

离散 OT = 成本矩阵 C ＋ 运输表 P 的一个线性规划

🗺️ 成本矩阵 C（Cost Matrix）
$C_{ij}=c(x_i,y_j)$：全部两两搬运单价的 n×m 价目表。
📋 运输表 P
n×m 非负矩阵：$P_{ij}$ 是路线 $(i,j)$ 实际运多少；行和为 a，列和为 b。
$$\min_{P}\ \langle C,P\rangle=\sum_{i,j} C_{ij}P_{ij}, \quad\text{s.t.}\quad P\mathbf{1}_m=a,\;\; P^{\top}\mathbf{1}_n=b,\;\; P\geq 0$$
读法：在所有满足收发约束的运输方案里，找总运费最便宜的那张表——这就是运输问题（Transportation Problem）。
结构

最优解只填 n² 个格子里的 ≈2n 个，还自动是整数

$$\text{变量 } nm\ \text{个} \;\Rightarrow\; \text{独立约束 } n+m-1\ \text{条} \;\Rightarrow\; \text{BFS 非零元} \leq n+m-1 \approx 2n \ll n^2$$
  • 稀疏性：最优解可在基本可行解（Basic Feasible Solution）取到 ⇒ 99% 以上的格子是零。第2章 2×2 例已验证：最优值 0.6，π* 只有 3 个非零元 = 2+2−1。
  • 全幺模（Totally Unimodular）：a、b 为整数时每个 BFS 自动是整数解——运输 LP 从不需要整数规划。
  • 组合本质：一个 BFS 对应支撑图里的一棵生成树，这是后面环调整的根基。
结论：变量多不可怕，结构才重要——稀疏基 + 全幺模是北西角与运输单纯形能成立的原因。
起步

北西角规则：从左上角贪心填 min(行余, 列余)，只求可行不看成本

规则：在最左上未划掉的格子填入 min(行余量, 列余量)，划掉耗尽的一行（或一列），向右下推进，O(n+m) 步填完一个初始可行解。

全程手算例：a = (0.3, 0.5, 0.2)，b = (0.4, 0.4, 0.2)。注意成本 4 藏在格子 (2,2)——北西角看不见它。
手算

四步填完：初始代价 2.5，且「同时耗尽」造成退化

① 格 (1,1)：min(0.3, 0.4) = 0.3 → π₁₁ = 0.3。行1耗尽划掉；列1还需 0.1。

② 格 (2,1)：min(0.5, 0.1) = 0.1 → π₂₁ = 0.1。列1满足划掉；行2还剩 0.4。

③ 格 (2,2)：min(0.4, 0.4) = 0.4 → π₂₂ = 0.4。行2与列2同时耗尽——退化，一起划掉。

④ 格 (3,3)：只剩行3余 0.2、列3需 0.2 → π₃₃ = 0.2，收工。

$$\text{代价} = 0.3{\times}2 + 0.1{\times}1 + 0.4{\times}4 + 0.2{\times}1 = \boldsymbol{2.5}, \quad \text{非零元 } 4 \lt n+m-1 = 5$$

反思

北西角不看成本：它给的是「合法起点」，不是「好解」

❌ 证据：π₂₂ = 0.4 走的是全表第二贵的格子 C₂₂ = 4——规则根本没读成本。
⚠️ 差距：初始代价 2.5 vs 最优值 1.2，差了整整一倍多。
✅ 正确预期：北西角输出一张满足全部边际约束的基本可行解，作用是「给单纯形一个起点」。想要好一点的起点可用最小元素法，但真正的最优化只能靠检验数迭代——下一页登场。
改进

运输单纯形每轮三件事：求势 → 算检验数 → 沿环调整

flowchart TB A["① 求势
基元上 u+v=C"] --> B["② 算检验数
Δ=C−u−v"] B --> C{"有 Δ 为负？"} C -- "有" --> D["③ 沿环调整
负检验数格进基"] D --> A C -- "全 ≥0" --> E["最优，证书到手"]
$$\text{基元 } (i,j):\ u_i+v_j=C_{ij}; \qquad \text{非基元检验数 } \Delta_{ij}=C_{ij}-u_i-v_j \;\;(\Delta_{ij}\lt 0 \Rightarrow \text{能省钱})$$
(u, v) 就是第2章对偶势 φ、ψ 的离散化身；全部 Δ ≥ 0 ⟺ 对偶约束 φ+ψ ≤ c 成立。
手算

先补零基元凑齐 5 个基，解出势后 Δ₁₂ = −4 最负

退化补救：非零元只有 4 个，补零基元 (3,2)，基 = {(1,1), (2,1), (2,2), (3,2), (3,3)}，令 u₁ = 0：

基元方程结果基元方程结果
(1,1)u₁+v₁=2v₁=2(3,2)u₃+v₂=2u₃=−3
(2,1)u₂+v₁=1u₂=−1(3,3)u₃+v₃=1v₃=4
(2,2)u₂+v₂=4v₂=5势：u = (0, −1, −3)，v = (2, 5, 4)
$$\Delta_{12} = 1-0-5 = \boldsymbol{-4} \;\Rightarrow\; (1,2)\ \text{进基} \quad (\Delta_{13}=-1,\ \Delta_{31}=4\ \text{都不如它})$$
演练

沿环交替加减，δ 取减方最小流量：代价 2.5 → 1.3

① 找环：进基格 (1,2) 在基的支撑树里形成唯一环 (1,2)⁺ → (2,2)⁻ → (2,1)⁺ → (1,1)⁻。

② 定 δ：减方是 (2,2)=0.4 与 (1,1)=0.3，再大就有格子变负 ⇒ $\delta=\min(0.4,\,0.3)=\boldsymbol{0.3}$。

③ 更新：π₁₂=0.3，π₂₂=0.4−0.3=0.1，π₂₁=0.1+0.3=0.4，π₁₁=0（出基）。

$$\text{新代价} = 2.5 - 4\times0.3 = \boldsymbol{1.3} \quad (\text{验证：} 0.3{\times}1+0.4{\times}1+0.1{\times}4+0.2{\times}1=1.3\ \checkmark)$$
✍️

手算

第二轮：Δ₃₂ = −1 进基，δ = 0.1，代价 1.3 → 1.2

① 重求势（补零基元 (2,3) 后）：非基元检验数中 $\Delta_{32} = 2-u_3-v_2 = \boldsymbol{-1}$，(3,2) 进基。

② 找环定 δ：环 (3,2)⁺ → (2,2)⁻ → (2,3)⁺ → (3,3)⁻，$\delta=\min(\pi_{22},\,\pi_{33})=\min(0.1,\,0.2)=\boldsymbol{0.1}$。

③ 更新：π₃₂=0.1，π₂₂=0（出基），π₂₃=0.1，π₃₃=0.2−0.1=0.1。

$$\text{新代价} = 1.3 - 1\times0.1 = \boldsymbol{1.2} \qquad 2.5 \to 1.3 \to 1.2$$

按空格 / → 逐步展开推导

证书

检验数全部 ≥ 0 那一刻，最优性证书自动到手

当前基 {(1,2), (2,1), (2,3), (3,2), (3,3)}，求势得 $u=(0,2,1)$，$v=(-1,1,0)$，验全部非基元：

$$\Delta_{11}=2-0+1=3,\quad \Delta_{13}=3-0-0=3,\quad \Delta_{22}=4-2-1=1,\quad \Delta_{31}=3-1+1=3 \;\; \Rightarrow\;\; \boldsymbol{1.2\ \text{即最优}}$$
  • 对偶可行：$u_i+v_j\leq C_{ij}$ 全成立 ⟺ 第2章对偶约束 φ+ψ ≤ c 的离散版。
  • 强对偶：对偶值 = $\sum_i a_i u_i + \sum_j b_j v_j = 1.2$ = 原始值，无需重跑算法即可核验。
  • 最终方案：π₁₂=0.3，π₂₁=0.4，π₂₃=0.1，π₃₂=0.1，π₃₃=0.1。
视角

图语言里：基 = 生成树，换基 = 加弦成环再断边

最优基的支撑树：{(1,2),(2,1),(2,3),(3,2),(3,3)} 五条边 = n+m−1，恰好连通六个点不成环
网络单纯形（Network Simplex）：在图上维护一棵生成树，每轮用一条「划算的弦」（负检验数）替换树上的一条边——我们手算的两轮枢轴就是它。
算账

精确 LP 的墙：约 n³ 量级，n = 10⁵ 彻底不可行

$$n=10^3 \Rightarrow \sim 10^9\ \text{次（秒级）}; \qquad n=10^5 \Rightarrow \sim 10^{15}\ \text{次} + 80\,\text{GB 存储} \Rightarrow \textbf{撞墙}$$
方法复杂度n = 10⁵ 可行？精度
通用 LP（内点法）~O(n³) 以上✗精确
网络/拍卖算法~O(n³) 级，常数小勉强~✗精确
一维排序法O(n log n)✓精确（仅一维）
熵正则 Sinkhorn（第4章）O(n²)/轮，可并行✓近似
⚠️ 多项式 ≠ 可扩展：机器学习要比的分布动辄 n = 10⁵~10⁷，精确 LP 路线在这里撞墙。
例外

一维只要 O(n log n)：排序 + 双指针，全序结构救了场

1排序：x 与 y 各自排序，O(n log n)——这是全部的瓶颈
2配对：双指针从左到右对齐质量，O(n)（分位数闭式解的离散版）
3收工：总计 O(n log n)，n = 10⁷ 也毫无压力
$$\text{一维：}\ O(n\log n) \quad vs \quad \text{一般：}\ \sim O(n^3) \quad\Longrightarrow\quad \text{救场的是全序结构，不是规模}$$
伏笔：第6章的切片 Wasserstein（Sliced Wasserstein）正是把高维投影回一维来白嫖这个特例。
避坑

三个误解：北西角在优化 / 变量多没法算 / 多项式即可扩展

❌ 北西角规则在优化
✅ 它完全不看成本，只求可行——π₂₂=0.4 走全表第二贵格子就是证据。记法：北西角管「合法」，检验数管「好」。
❌ n² 个变量就没法算
✅ 结构才重要：全幺模 + 稀疏基（非零元 ≤ n+m−1）让运输单纯形远快于通用 LP，且自动整数、无需整数规划。
❌ 多项式时间 = 可扩展
✅ O(n³) 也是多项式，n = 10⁵ 照样撞墙；可扩展性要看绝对量级、内存（80GB）与并行性。
小结

主线问题 → 答案 → 遗留问题，三句话讲完第3章

1主线问题：Kantorovich LP（n² 个变量）怎么真算出来，代价有多大？
2答案：BFS 稀疏（≤ n+m−1 非零元）→ 北西角起步 → 求势/检验数/沿环逐轮降价；全部 Δ ≥ 0 即最优，对偶势自动成证书（2.5 → 1.3 → 1.2）
3遗留问题：精确算法 ~O(n³)，n 上万撞墙——速度这笔账怎么算？交给第4章
$$\min_{P}\ \langle C,P\rangle \quad \text{s.t.}\quad P\mathbf{1}_m=a,\;\; P^{\top}\mathbf{1}_n=b,\;\; P\geq 0 \quad\text{——合上书也要能默写}$$
