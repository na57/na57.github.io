主线

加熵烫平组合难题，矩阵缩放换来速度，偏差是账单

1旧账：精确 LP 约 O(n³)，解卡顶点 = 组合搜索，n 上万撞墙
2出路：不改约束改目标——加熵正则（Entropic Regularization），烫平成严格凸
3结构：一行 KKT 推出 P = diag(u)Kdiag(v)，n² 个未知数塌缩成 2n 个
4算法：Sinkhorn 交替行列归一，每轮 O(n²) 且全是矩阵乘法，GPU 友好
5账单：熵偏差 + 小 ε 的数值下溢——ε 是快与准的旋钮
这条链就是本章的目录：4.1 为什么加熵 → 4.2 核结构与迭代 → 4.3 手算两轮 → 4.4 ε 的权衡。
动机

LP 的病根不只是 n³：顶点搜索天生抗拒并行

n = 10⁵（一张 300×300 图像的像素数）时，第3章精确路线的账单：

$$O(n^3) \sim 10^{15}\ \text{次运算} \;\approx\; \text{每秒十亿次也要十来天}, \qquad \text{存储 } n^2 \sim 80\,\text{GB}$$
😇 网络单纯形（第3章）
精确、稀疏，但每步是顺序枢轴操作，分支满天飞——GPU 使不上劲。
🙂 直接堆算力
复杂度没变，墙还是那堵墙；顶点搜索本质是选哪 n+m−1 个格子非零的组合问题。
💡 Cuturi (2013) 的破局思路：不改约束，改目标——加一项熵，把组合难题烫平成光滑凸问题。
定义

熵正则问题 = 原约束不动 ＋ 目标减去 ε 倍的熵

🗺️ 可行域 U(a, b)：不动
行和为 a、列和为 b 的非负耦合多面体，一条约束都没改。
📋 目标：减去 εH(P)
熵奖励分散的耦合；ε > 0 是正则参数（Regularization Parameter），本章唯一旋钮。
$$\min_{P \in U(a,b)}\ \langle C,P\rangle - \varepsilon H(P), \qquad H(P) = -\sum_{ij} P_{ij}\big(\log P_{ij} - 1\big)$$
读法：在所有合法耦合里，找「运输成本 − ε × 分散程度」最小的那个。注意：它解的是另一个问题，不是原 LP 的近似算法。
红利

一项熵换三个性质：唯一、可微、有结构

1严格凸 ⇒ 解唯一：熵严格凹，线性＋严格凹 = 严格凸，不再有「一堆等价最优顶点」
2对输入可微：最优值与最优解光滑依赖 (a, b, C) ⇒ 可嵌进神经网络反向传播——进 ML 流水线的门票
3结构显式：解有闭式骨架 P = diag(u)Kdiag(v)，只剩两个向量要解（下一页推导）
物理图像：⟨C,P⟩ 是能量，H(P) 是熵，ε 是温度。ε=0 冻结在能量最低构型（LP 顶点）；升温按玻尔兹曼分布摊开；ε→∞ 无视成本均匀混合。后面的核 K 正是 Boltzmann 权重。
罗盘

两个极限端点：ε→0 回真 OT，ε→∞ 退化成独立耦合

极限解的行为读法
ε → 0（低温）解 → 真实 OT 的最优耦合（多解时取熵最大者）正则项消失，回到原 LP
ε → ∞（高温）解 → 独立耦合 abᵀ成本被淹没，只剩「尽量分散」的纯熵项
$$P_{\varepsilon} \xrightarrow{\varepsilon \to 0} P^{\star}\ (\text{真 OT}), \qquad P_{\varepsilon} \xrightarrow{\varepsilon \to \infty} ab^{\top}$$
⚠️ ε 从大到小，解从「糊到底的独立耦合」一路锐化到「真实的稀疏最优耦合」——调 ε 就是在糊但快与准但慢之间选位置。
推导

对 P 求导置零，解自动裂成「行缩放 × 核 × 列缩放」

① 写拉格朗日（乘子 f、g 就是第2、3章对偶势的化身）

$$\mathcal{L} = \langle C,P\rangle - \varepsilon H(P) + \langle f,\, a - P\mathbb{1}\rangle + \langle g,\, b - P^{\top}\mathbb{1}\rangle$$

② 对 Pij 求导置零（熵项贡献 ε log Pij）

$$\frac{\partial \mathcal{L}}{\partial P_{ij}} = C_{ij} + \varepsilon \log P_{ij} - f_i - g_j = 0 \;\Rightarrow\; P_{ij} = e^{f_i/\varepsilon} \cdot e^{-C_{ij}/\varepsilon} \cdot e^{g_j/\varepsilon}$$
$$\boldsymbol{P = \mathrm{diag}(u)\,K\,\mathrm{diag}(v)}, \qquad K_{ij} = e^{-C_{ij}/\varepsilon},\;\; u_i = e^{f_i/\varepsilon},\;\; v_j = e^{g_j/\varepsilon}$$

按空格 / → 逐步展开推导

未知量从 n² 个 Pij 塌缩成 2n 个 (u, v)；目标严格凸 ⇒ KKT 不仅必要而且充分，无需二阶条件。
算法

Sinkhorn 迭代 = 交替行归一化与列归一化

把 P = diag(u)Kdiag(v) 代回两条边际约束，再交替固定一个解另一个：

$$\mathrm{diag}(u)Kv = a, \qquad \mathrm{diag}(v)K^{\top}u = b$$
$$\boldsymbol{u \leftarrow a\,./\,(Kv), \qquad v \leftarrow b\,./\,(K^{\top}u)}$$
读法：Kv 是当前 v 下每行实际运出的量，u 把它纠回 a；列同理。每轮 = 两次矩阵-向量乘 + 两次逐元素除法，O(n²)/轮、无分支无枢轴——GPU 教科书级并行。K 全正（ε > 0 恒成立）⇒ Sinkhorn 定理保证收敛到唯一解。

认知

加熵不是数值技巧——它解的是另一个问题

🌵 LP 精确解（第3章）
稀疏：非零元 ≤ 2n−1，卡在多面体顶点上，走边边角角；偏差为零但不可微。
🌧️ 熵正则解（本章）
稠密：K 全正 ⇒ P 全正，雨露均沾；光滑可微但 ε > 0 时 ⟨C,P⟩ 严格大于真 OT。
⚠️ ε > 0 时 ⟨C, Pε⟩ > 真实 OT 恒成立——0.424 vs 0 就是铁证。报数时必须同时交代 ε 与偏差。
要稀疏解就后处理（取每行最大 / 阈值化）；要光滑可微就接受稠密。两种算法两种指纹，按需求选，别混着用。
权衡

ε 是唯一旋钮：偏差、速度、稳定性三件事方向相反

ε 大（高温）ε 小（低温）
解的形态糊：趋近 abᵀ，贵格子分到大量质量锐：逼近真实 OT 的稀疏解
熵偏差大（3×3 例 ε=1 时 0.424）小，ε→0 时消失
收敛速度快（几轮到位）慢：线性收敛速率因子 → 1，轮数爆炸
数值稳定安全危险：e^(−C/ε) 下溢成 0
⚠️ 别外推：3×3 例两轮收敛是 ε=1 且高度对称的奢侈。快与准是拔河，ε 是绳子的中点。
暗礁

小 ε 下 e^(−C/ε) 下溢成 0，归一化当场除零

ε = 0.01、Cij = 10 时：e^(−1000) 在双精度下就是 0 → K 变零矩阵 → a./(Kv) 除零 → 第一轮炸出 NaN。

$$\text{对数域稳定化：}\quad f \leftarrow \varepsilon\Big(\log a - \mathrm{LSE}_j\tfrac{g_j - C_{ij}}{\varepsilon}\Big), \qquad g \leftarrow \varepsilon\Big(\log b - \mathrm{LSE}_i\tfrac{f_i - C_{ij}}{\varepsilon}\Big)$$
  • 对数域稳定化（Log-domain Stabilization）：不碰 u、v，在对偶 f = ε log u、g = ε log v 上迭代；log-sum-exp 先减最大值再求和，任意小的 ε 都稳。代价：log/exp 比乘法贵。
  • ε 折减（ε-annealing）：工程折中——大 ε 快速收敛到粗解，再逐步降温微调。
  • 判停：监控边际违反度（Marginal Violation）‖diag(u)Kv − a‖₁ + ‖diag(v)Kᵀu − b‖₁，小于阈值即停。
决策

第3、4章合起来 = 完整选型：没有银弹，只有旋钮

🎯 要精确、n ≲ 10³
用网络单纯形：顶点解、稀疏、零偏差——精确解证场合的扳手。
🚀 要规模、可微、GPU、容忍 ε 级偏差
用 Sinkhorn：小 ε 配 log-domain 或 ε 折减——ML 流水线的默认引擎。
$$n = 5000:\quad K\ \text{约}\ 200\,\text{MB（float64，单 GPU 放得下）}, \qquad O(n^3)\ \text{LP 路线早已投降}$$
两章不是替代关系，是工具箱里的两把扳手：按「精度要求 × 规模 × 是否要梯度」选。
避坑

三颗雷：当成免费技巧 / ε 越小越好 / 拿它直接当距离

❌ 加熵只是数值技巧，逼近同一个答案
✅ 它解的是另一个问题：ε > 0 时 ⟨C,Pε⟩ 严格大于真 OT，0.424 就是账单。记法：速度换偏差，没有免费午餐。
❌ ε 越小越好
✅ 小了收敛变慢（速率因子 → 1），且 K 下溢成零矩阵、归一化除零。记法：火小准但慢，还可能糊锅——要 log-domain 护航。
❌ 拿 ⟨C, Pε⟩ 直接当 Wasserstein 距离用
✅ a = b 时值也是 0.424 ≠ 0，连「同一分布距离为零」都不满足。修法：Sinkhorn 散度减两个自传输项（第6章展开）。
