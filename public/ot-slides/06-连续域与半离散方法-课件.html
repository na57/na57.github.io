本章解决「连续怎么算」——连续分布上 OT 何时有映射解、一边连续一边离散怎么算、样本估计误差多大。

主线

从无穷维耦合到有限维引擎，一条五环因果链

1困难：连续耦合 π 是无穷维对象，存不下、算不动
2结构：Brenier 定理——平方成本 + μ 绝对连续 ⇒ 最优方案是凸函数的梯度
3引擎：一维单调重排 T = F_ν⁻¹∘F_μ，分位数复合可手算
4降维：半离散 OT 对偶塌缩成 m 维，Laguerre 单元切分源空间
5补救：S_ε 修熵偏差、SW 投影绕维数灾难；n^(−1/d) 是绕不开的账单
这条链就是本章的目录：环 2–3 对应 6.1（Brenier 与一维），环 4 对应 6.2（半离散），环 5 对应 6.3–6.4（S_ε、SW 与样本）。
动机

连续耦合是无穷维对象，映射形式才可能算得动

Kantorovich 耦合 π 是联合测度：离散时是一张表格，连续时是无穷维对象，存不下也算不动。Monge 问题只要一张映射：

$$\inf_{T:\,T_\#\mu=\nu}\ \int c\bigl(x,\,T(x)\bigr)\,d\mu(x)$$
🗺️ 映射形式的好处
每个 x 送去 T(x)，问题从无穷维测度变成一个函数，存得下、算得动。
💥 Monge 的死穴
μ 是单点、ν 劈成两处时，质量必须劈叉，任何映射都做不到——解不存在。
💡 关键问题：什么成本、什么源分布下死穴消失？答案就是下一页的 Brenier 定理。
定理

平方成本 + μ 绝对连续 ⇒ 最优映射是一个凸函数的梯度

📐 条件① 成本平方
c(x,y) = ‖x−y‖²，平方欧氏成本（更一般地要满足扭曲条件）。
🌊 条件② μ 绝对连续
μ 在 ℝᵈ 上有密度，不给任何零测集质量——原子劈叉被排除。
$$\boldsymbol{T=\nabla u,\qquad u:\mathbb{R}^d\to\mathbb{R}\ \text{为凸函数}}$$
读法：最优 Monge 映射存在且（μ-几乎处处）唯一，它恰是某凸函数的梯度——求连续 OT 就是求一个凸函数。
直觉

凸梯度就是「不交叉的单调搬运」的高维推广

一维时 u 凸 ⟹ u′ 单调不减 ⟹ T 单调：近处的点送去近处，不交叉、不翻转——与第5章「一维最优方案必单调」完全咬合。

$$T=\nabla\!\left(\frac{\|x\|^2}{2}-\varphi(x)\right)\quad(\varphi\ \text{为第5章的对偶势})$$
💡 关键一跃：‖x‖²/2 − φ 凸 ⟺ 对偶约束顶紧。Brenier 映射就是第5章价格体系在平方成本下的显影。
⚠️ 平方成本是钥匙：换成 |x−y|，最优映射可大片不唯一（整段平移任意滑），梯度结构全没了。
手算

U[0,1] 搬到 U[2,3]：单调重排三步走，W₂² = 4

① 分位数复合得映射：F_μ(x)=x，F_ν(y)=y−2 ⟹ F_ν⁻¹(t)=2+t

$$T(x)=F_\nu^{-1}\bigl(F_\mu(x)\bigr)=x+2\qquad(x\sim U[0,1]\Rightarrow x+2\sim U[2,3]\ \checkmark)$$

② 算成本：每个粒子都走距离 2

$$W_2^2=\int_0^1 (x+2-x)^2\,dx=\int_0^1 4\,dx=\boldsymbol{4}$$

③ 验证 Brenier 结构：T = u′ 积出凸势

$$u(x)=\frac{x^2}{2}+2x,\qquad u''=1\gt 0\ \Rightarrow\ u\ \text{凸}\ \checkmark$$

避坑

「平方成本 + 绝对连续」缺一个，Brenier 立刻垮台

❌ 误以为：任意两个分布之间都有最优 Monge 映射
✅ 反例就在眼前：μ = δ₀，ν = 0.5δ₁ + 0.5δ₃——单点质量必须劈叉，Monge 无解，只有 Kantorovich 耦合兜底（第5章 L2 习题刚算过）。
❌ 误以为：成本换成 |x−y| 结论照样成立
✅ 只有平方型成本让一阶条件给出梯度形式；|x−y| 下最优映射可大片不唯一（整段平移任意滑）。
口诀：平方定结构，连续保存在——「Kantorovich 总有解」与「Monge 何时有解」是两回事，Brenier 回答的是后者。
半离散

连续对点云：对偶自动塌缩成 m 维凹函数

设定：μ 连续（密度模型、渲染图像），ν = Σⱼ bⱼδ_{yⱼ}（点云 y₁…y_m）。ν 只有 m 个原子 ⟹ ψ 只需 m 个值，φ 被 c-变换顶到约束上沿后消去：

$$\boldsymbol{g(\psi)=\sum_{j=1}^{m}\psi_j b_j+\int \min_{j}\Bigl[\,c(x,y_j)-\psi_j\,\Bigr]\,d\mu(x)},\qquad \psi\in\mathbb{R}^m$$
📉 为什么只有 m 维
ψ 是 m 维向量；φ(x) = min_j [c(x,yⱼ) − ψⱼ] 被 c-变换消去，不再独立。
🎯 梯度有含义
∂g/∂ψⱼ = bⱼ − μ(Lⱼ(ψ))——求解 = 调 ψ 使各单元质量达标（牛顿法/梯度法）。
几何

Laguerre 单元 = 加权距离变换，ψ 是站点的收货补贴

$$L_j(\psi)=\{\,x:\ c(x,y_j)-\psi_j \leq c(x,y_k)-\psi_k\ \ \forall k\,\},\qquad \text{最优}\iff \mu\bigl(L_j(\psi)\bigr)=b_j$$
flowchart TB A["给站点发补贴 ψ"] --> B["比较加权距离 c 减 ψ"] B --> C["源空间切成 Laguerre 单元"] C --> D{"各单元 μ-质量 = b 吗"} D -- "否：调 ψ" --> A D -- "是" --> E["最优划分达成"]
💡 ψ = 0 时退化为普通 Voronoi 图；ψ ≠ 0 就是给站点发「半径补贴」再切蛋糕。ψⱼ 越高，j 越抢手，单元越大。
推导

两个站点、三步推导：半离散 OT 全程能手算

μ = U[0,1]，ν = 0.5δ₀.₂₅ + 0.5δ₀.₇₅，c = (x−y)²。设边界 x*：L₁ = [0, x*]，L₂ = [x*, 1]。

✍️
暂停推导

先自己动手：写出边界方程、用质量约束定 ψ、再积分算 W₂²，三个结果都写出来再对答案。

① 边界方程：两站在 x* 处调整后成本相等

$$(x^*-0.25)^2-\psi_1=(x^*-0.75)^2-\psi_2\ \Rightarrow\ x^*=0.5+(\psi_1-\psi_2)$$

② 质量约束定 ψ：μ(L₁) = x* = 0.5 ⟹ ψ₁ = ψ₂，取平移自由度 ψ₁ = ψ₂ = 0

$$\boldsymbol{x^*=0.5}$$

③ 算 W₂²：单元内质量全部运到本站，两段对称

$$W_2^2=\int_0^{0.5}(x-0.25)^2\,dx+\int_{0.5}^{1}(x-0.75)^2\,dx=2\times\frac{1}{96}=\boldsymbol{\frac{1}{48}\approx 0.0208}$$

修偏差

减掉两个「自运输」项，0.424 的直流偏置归零

第4章的账：μ = ν 时 ⟨C, P_ε⟩ = 0.424 ≠ 0，同一性失败——不能当损失。Sinkhorn divergence 把两个自项减掉：

$$\boldsymbol{S_\varepsilon(a,b)=OT_\varepsilon(a,b)-\tfrac{1}{2}OT_\varepsilon(a,a)-\tfrac{1}{2}OT_\varepsilon(b,b)}$$
🔧 修账原理
OT_ε(a,a) = OT_ε(b,b) = 0.424 时，S_ε = OT_ε(a,b) − 0.424——直流偏置对称抵消，S_ε(a,a) = 0 自动成立。
⚡ 实现成本
跑三次 Sinkhorn：(a,b)、(a,a)、(b,b)；自项缩放向量可复用，梯度经 Sinkhorn 层自动微分。
性质

S_ε 同一性自动为零，在 OT 与 MMD 之间插值

性质内容意义
同一性S_ε(a,a) = 0 自动成立结构使然，不用证明
非负性S_ε(a,b) ≥ 0，等号 ⟺ a = b可以当损失/差异度量
ε → 0S_ε → OT（真实 Wasserstein 成本）小 ε 逼近第5章的尺子
ε → ∞S_ε → ½‖E[a]−E[b]‖² 型 MMD大 ε 退化为均值比较
🔗 第7章要拿 OT 当机器学习损失：一模一样时为零、非负、可微、数值稳——S_ε 全占，损失函数到此配齐。
样本

样本误差 ~ n 的 −1/d 次方，高维堆样本没有出路

插件估计：用经验分布 μ̂ 替代真分布直接算 W。坏消息是：

$$\mathbb{E}\,\bigl|\,W(\hat\mu,\mu)\,\bigr|\ \sim\ \boldsymbol{n^{-1/d}}$$
🖼️ d = 2（图像）
1% 误差需要 n ≈ 10⁴ 个点——勉强够用。
🌌 d = 100（特征空间）
需要 n ≈ 10²⁰⁰ 个点——宇宙原子总数都不够。
⚠️ 算法快 ≠ 统计误差小：d 维空间撒 n 个点，平均间隙 ~ n^(−1/d)，误差被间隙锁死——高维不能靠堆样本。
切片

把高维问题射成无数条一维：Sliced Wasserstein

$$\boldsymbol{SW_2^2(\mu,\nu)=\int_{S^{d-1}} W_2^2\bigl(P_{\theta\#}\mu,\,P_{\theta\#}\nu\bigr)\,d\theta},\qquad P_\theta(x)=\langle x,\theta\rangle$$
flowchart TB A["高维分布 μ, ν"] --> B["投影到方向 θ"] B --> C["一维排序：分位数闭式解"] C --> D["对方向做平均"]
💡 CT 扫描直觉：拍不到三维器官，就从所有角度拍一维投影再重建信息——「高维无闭式解」换成「无穷多个一维闭式解的平均」。
实现：随机采 L 个方向蒙特卡洛平均，总成本 O(L·n log n)；投影与排序都可微，能反向传播；SW 与 W 弱收敛等价。
手算

两个点的算例：SW₂² = 1/2 ≠ W₂² = 1，是另一把尺子

ℝ² 中 μ = δ_{(0,0)}，ν = δ_{(1,0)}。方向 θ = (cos φ, sin φ) 上，两点投影标量分别为 0 与 cos φ。

① 单个方向：一维 W₂² = (cos φ − 0)²

$$W_2^2\bigl(P_{\theta\#}\mu,P_{\theta\#}\nu\bigr)=\cos^2\varphi$$

② 对方向平均：cos² 在整周期上的平均值是 1/2

$$SW_2^2=\frac{1}{2\pi}\int_0^{2\pi}\cos^2\varphi\,d\varphi=\frac{1}{2\pi}\times\pi=\boldsymbol{\frac{1}{2}}$$
$$\boldsymbol{SW_2^2=\tfrac{1}{2}\ \neq\ W_2^2=1}\quad\Rightarrow\quad\text{SW 共享拓扑与梯度方向，不是 W 的近似}$$

避坑

本章三颗雷：Voronoi 即最优、S_ε 消尽 ε、SW 逼近 W

❌ ψ = 0 的普通 Voronoi 就是最优划分
✅ 只在「恰好质量匹配」时成立。权重改成 (1/3, 2/3) 就必须调 ψ 把边界推到 x* = 1/3——调 ψ 使 μ(Lⱼ) = bⱼ 正是半离散数值方法的全部工作量。
❌ S_ε 彻底消除了 ε 的影响
✅ 消除的只是同一性失败这类系统偏差，数值仍随 ε 变化（ε 大趋 MMD、ε 小趋 OT）。且 S_ε 不是距离——当「差异度量/损失」用，别当尺子用。
❌ 方向数 L 越大，SW 越接近真实 W
✅ L 只降蒙特卡洛方差，极限是 SW 本身，永远到不了 W（算例：1/2 对 1）。要真 W 请回 Sinkhorn / 半离散。
