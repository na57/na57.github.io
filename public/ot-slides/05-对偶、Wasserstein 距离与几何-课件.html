对偶

对偶就是给运输市场配一套「不敢越线」的报价

💼 势函数 φ(x)（Kantorovich Potential）
外包公司在源点 x 的「收货报价」
📦 势函数 ψ(y)
外包公司在目标点 y 的「交货报价」
$$\max\ \int_{\mathcal{X}}\varphi\,\mathrm{d}\mu+\int_{\mathcal{Y}}\psi\,\mathrm{d}\nu,\qquad \text{s.t.}\ \ \varphi(x)+\psi(y)\leq c(x,y)\ \ \forall\,x,y$$
读法：外包公司拼命抬价，但任何一条线路的「收货价＋交货价」都不敢越过真实运费，否则你自己干了。强对偶：最大报价总额 = 最小运输成本。
验证

最小例子 δ₀→δ₁：最大报价与最小成本严丝合缝

① 原问题：唯一耦合把 0 处质量全运到 1（c = |x−y|）

$$\min_{\pi\in U(\delta_0,\delta_1)}\int |x-y|\,\mathrm{d}\pi \;=\; |0-1| \;=\; 1$$

② 对偶：约束 φ(0)+ψ(1) ≤ 1 直接给出上界 1，取 φ(0)=0、ψ(1)=1 达到

$$\max\ \varphi(0)+\psi(1)\;=\;1\;=\;\text{原问题最优值}\quad\checkmark$$
⚠️ 势不唯一：φ(0) = −3、ψ(1) = 4 同样取到 1。同时加常数再减回去，目标不变——唯一的是「价差」，不是绝对价格。

化简

c-变换顶满约束，把两个势压成一个无约束问题

固定 φ 后，ψ 要最大化只能处处顶到约束上沿——这就是 φ 的 c-变换（c-transform）：

$$\psi(y)\;=\;\varphi^{c}(y)\;:=\;\inf_{x}\Big[\,c(x,y)-\varphi(x)\,\Big]\qquad\Longrightarrow\qquad \max_{\varphi}\ \int\varphi\,\mathrm{d}\mu+\int\varphi^{c}\,\mathrm{d}\nu\ \ (\text{无约束})$$
距离成本 c(x,y) = |x−y| 时更漂亮：最优 φ 自动是 1-Lipschitz 函数，且 φc = −φ。
🔗 钩子：W₁ = sup‖f‖Lip≤1 𝔼μf − 𝔼νf —— 第7章 WGAN 的全部地基就埋在这里。
定义

W_p 是开了 p 分之一次方的最小成本，这个次方不能省

⚖️ 里层：Kantorovich 问题
成本取 d(x,y)p，在全部合法耦合 U(α,β) 上取最小
📐 外层：开 1/p 次方
把量纲从「成本的 p 次方」扳回「距离」
$$\boldsymbol{W_p(\alpha,\beta)\;=\;\Big(\min_{\pi\in U(\alpha,\beta)}\int d(x,y)^{p}\,\mathrm{d}\pi(x,y)\Big)^{1/p}},\qquad p\geq 1$$
读法：先算「搬完最少花多少」，再开 p 次方。不开方就不是距离——p ≥ 2 时它连三角不等式都过不了。
公理

同一性、对称性白送，三角不等式要借粘合引理

公理内容证明要点
同一性W_p(α,β) = 0 ⟺ α = βα=β 取对角耦合 (id,id)#α 代价 0；反之代价 0 迫使 π 集中在对角线上
对称性W_p(α,β) = W_p(β,α)耦合转置 π(x,y) → π(y,x)，成本 d 对称
三角不等式W_p(α,γ) ≤ W_p(α,β) + W_p(β,γ)粘合引理沿 β 粘成三边际耦合 + 底空间三角 + Minkowski
更强的结论：W_p 度量化「弱收敛 ＋ p 阶矩收敛」——W_p(μn, μ) → 0 恰好等价于 μn 弱收敛且 p 阶矩收敛。第7章 GAN 训练要的就是这个性质。
推导

以中间分布为桥粘两段运单，再靠 Minkowski 拆范数

① 粘合引理（Gluing Lemma）：π₁∈U(α,β) 与 π₂∈U(β,γ) 沿公共边际 β 粘成三边际耦合

$$\sigma(x,y,z):\quad \sigma_{\mathcal{X}\mathcal{Y}}=\pi_1,\ \ \sigma_{\mathcal{Y}\mathcal{Z}}=\pi_2,\qquad \text{离散：}\ \sigma_{ijk}=\frac{\pi^{1}_{ij}\,\pi^{2}_{jk}}{b_j}$$

② σ 的 (x,z) 边际是合法耦合 + 底空间三角不等式 d(x,z) ≤ d(x,y)+d(y,z)

$$W_p(\alpha,\gamma)\;\leq\;\Big(\int \big[\,d(x,y)+d(y,z)\,\big]^{p}\,\mathrm{d}\sigma\Big)^{1/p}$$

③ Minkowski 不等式拆 Lp 范数

$$\boldsymbol{W_p(\alpha,\gamma)\;\leq\;W_p(\alpha,\beta)+W_p(\beta,\gamma)}$$
第③步就是必须开 1/p 次方的原因：Minkowski 只对范数成立（p=1 时退化为加法），不开方链条当场断裂。

对比

KL 给无穷、TV 报常数，只有 W₁ 感知平移

散度 / 距离μ=δ₀, ν=δθ（θ→0）是距离？支撑不重叠时
KL 散度+∞（θ ≠ 0）否（不对称）无穷大，无梯度
总变差 TV1（常数）是饱和为常数，无梯度
Wasserstein W₁|θ| → 0是有限且随位置光滑变化，有梯度
KL/TV 只问「同一点上质量差多少」，看不到点与点的远近；Wasserstein 把底空间几何 d(x,y) 抬进分布层面——KL 是账本审计，Wasserstein 是搬运计费，后者自带尺子。
特例

直线上最优方案必为单调重排，分位数给出闭式解

任何「交叉运输」都可解开交叉严格省钱（|x−y|p 的凸性），故一维最优必然单调——左边的土给左边的坑。用分位数函数（Quantile Function）说就是：

$$F_\alpha^{-1}(t)=\inf\{\,x:\ F_\alpha(x)\geq t\,\},\qquad T^{\star}=F_\beta^{-1}\circ F_\alpha$$
$$\boldsymbol{W_p^{p}(\alpha,\beta)\;=\;\int_{0}^{1}\Big|\,F_\alpha^{-1}(t)-F_\beta^{-1}(t)\,\Big|^{p}\,\mathrm{d}t}$$
读法：两个分布按累计质量 t 重新编号，同一编号的位置差取 p 次方再积分。W₁ 就是两条 CDF 之间的面积；且一维最优耦合与 p 无关——p 只改计费方式。
手算

断点切三段，W₁ 手算出 2/3

μ = (1/3)δ₀ + (2/3)δ₁， ν = 0.5δ₀ + 0.5δ₂，求 W₁（非对称权重，必须走分位数）。

① 写分位数：Fμ−1(t) = 0（t ≤ 1/3）、1（t > 1/3）； Fν−1(t) = 0（t ≤ 1/2）、2（t > 1/2）

✍️
暂停推导

断点 1/3、1/2 已给出。合上答案，自己把 [0,1] 切成三段，逐段算 |Fμ−1 − Fν−1| 乘区间长度，求和得到 W₁。

区间Fμ−1Fν−1差贡献
[0, 1/3]0000
[1/3, 1/2]101(1/2 − 1/3) × 1 = 1/6
[1/2, 1]121(1 − 1/2) × 1 = 1/2

③ 求和 + 对账：W₁ = 0 + 1/6 + 1/2 = 2/3 ≈ 0.667。从 x=1 调 1/6 回 0、送 1/2 到 2，成本 1/6×1 + 1/2×1 = 2/3 ✓（x=1 的质量劈成两股——Monge 失败，Kantorovich 兜底）

快算

对称二点分布：两段各差 1，W₁ = 1

μ = 0.5δ₀ + 0.5δ₂， ν = 0.5δ₁ + 0.5δ₃。

① 分位数各两段：Fμ−1(t) = 0（t ≤ 0.5）、2（t > 0.5）； Fν−1(t) = 1（t ≤ 0.5）、3（t > 0.5）

② 两段各差 1，各积 0.5：W₁ = ∫₀0.5 |0−1| dt + ∫0.51 |2−3| dt = 0.5×1 + 0.5×1 = 1

③ 耦合验证：π(0,1) = 0.5、π(2,3) = 0.5，每对距离 1，总成本 0.5×1 + 0.5×1 = 1 ✓

口诀：断点切段、逐段量差、乘长度求和。

插值

位移插值让粒子匀速滑到目的地，是 Wasserstein 测地线

$$\mu_t=\big((1-t)\,\mathrm{id}+t\,T\big)_{\#}\,\mu,\qquad t\in[0,1]\ \ \Longrightarrow\ \ W_2(\mu_s,\mu_t)=|t-s|\cdot W_2(\mu_0,\mu_1)$$
🚀 位移插值（δ₀→δ₂，T(x)=x+2）
μt = δ2t：t=0.5 时是 δ₁——中间是「像样的中间形状」，等速无弯折
😵 线性插值 (1−t)μ + tν
t=0.5 时 = 0.5δ₀ + 0.5δ₂——劈开的两个重影，不是中间形状
位移插值是「形状真的在搬家」，线性插值只是「两张照片叠化」——这就是图形学 morphing 用 OT 而不用淡入淡出的原因。
重心

重心把质量搬到折中位置，线性平均只会叠出重影

$$\boldsymbol{\nu^{\star}=\arg\min_{\nu}\ \sum_{k=1}^{K}\lambda_k\,W_2^{2}(\nu,\nu_k)},\qquad \lambda_k\geq 0,\ \ \sum_{k}\lambda_k=1$$
✅ Wasserstein 重心（δ₀、δ₂ 各半权重）
min ½x² + ½(x−2)² → 求导 x + (x−2) = 0 → x = 1，重心 = δ₁（质量整体搬到中点）
❌ 线性平均
0.5δ₀ + 0.5δ₂——双峰，两团质量原地各留一半
应用：平均字体、平均脸——重心保留清晰形状，线性平均只会糊。权重 λ 还给出「重心坐标」，第7章域适应用它表示目标域。
避坑

别把势当固有属性，别忘了开方，别拿熵正则当距离

❌ 把 φ 当位置 x 的固有属性
✅ φ 依赖整个问题（μ、ν、c 一变它就变），且 φ 与 φ＋常数是同一个解——能比较的只有「价差」φ(x) − φ(x′)。
❌ 把最小成本 ⟨C, π*⟩ 直接当距离
✅ p ≥ 2 时不开方过不了三角不等式（Minkowski 只对范数成立）——只有 W_p = (·)1/p 才是距离。
❌ 拿熵正则代价 ⟨C, Pε⟩ 当距离
✅ 它连同一性都不满足：μ=ν 时值是 0.424 ≠ 0。修法 Sinkhorn divergence，见第6章。
